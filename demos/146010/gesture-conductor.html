解决的痛点

每个人都想玩音乐，但乐器太贵、学起来太难、一个人玩太无聊

乐器门槛高

买一把吉他几百块，报班学几个月。大多数人三分钟热度，乐器变成了"最贵的摆设"。

音乐游戏太局限

音游（节奏大师、太鼓达人）只能"跟着节奏按键"，你永远是被动跟随者，而不是主动创造者。

缺乏身体参与

按键盘、滑屏幕，跟音乐本身的身体性是割裂的。真正的音乐家全身都在动，而数字音乐工具只用了手指。

产品形态

一个 Web 应用（PWA），打开浏览器即可使用，无需下载安装

1

打开网页

浏览器打开，授权摄像头

2

摄像头识别手势

MediaPipe 实时追踪 21 个手部关键点

3

手势 → 音乐参数

手势映射为音量/速度/音色/独奏

4

Web Audio 合成

浏览器实时合成多声道音乐

手势 → 音乐映射表

每种手势对应一个音乐控制参数，像乐队指挥一样掌控全局

手势 动作描述 音乐参数 效果
👆 手掌向上移动 音量 整体音量增大，手掌越高音量越大
👇 手掌向下移动 音量 整体音量减小，手掌越低音量越小
🔄 手指画圈 速度 顺时针加速，逆时针减速
👆 手指点向某个方向 独奏 指向钢琴=钢琴独奏，指向鼓=鼓独奏
✋ 五指张开平推 暂停/播放 暂停或恢复音乐播放
👊 握拳 切换曲目 切换到下一首预设曲目
✌ 剪刀手晃动 混响 调整混响深度，模拟音乐厅效果

开发路线图 (MVP)

2 天可出 Demo，5 天完成 MVP

Day 1 · 手势识别核心

接入 MediaPipe Hands，实现实时手势追踪。定义并实现 7 种基础手势的识别逻辑（上移/下移/画圈/指向/张开/握拳/剪刀手）。

Day 2 · 音频引擎 + 映射

搭建 Web Audio API 多声道合成器（钢琴/鼓/贝斯/弦乐 4 个轨道）。实现手势→音乐参数的映射引擎，完成"手势控制音乐"的核心闭环。

Day 3 · UI + 可视化

设计手势骨架叠加层（21 点连线 + 实时手势标签）。搭建参数仪表盘（音量/速度/混响数值显示）。暗色主题 UI 适配。

Day 4 · 预设曲目 + 调优

内置 3 首预设曲目（古典/流行/电子各一），供 Demo 演示。手势识别精度调优，降低误触发率。移动端适配。

Day 5 · PWA + 打磨

添加 PWA 支持（离线使用 + 桌面安装）。整体性能和体验打磨。录制 Demo 视频。
