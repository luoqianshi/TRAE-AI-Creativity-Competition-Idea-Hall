库存口径

当前库存 = 入库数量 - 出库数量 - 退回供应商数量。若存在客户退货，可在后续版本增加“客户退货入库表”，公式中再加回客户退货数量。

成本口径

单位成本采用移动加权估算：入库总成本含采购金额与运费，出库销售成本按当前平均成本扣减，便于财务快速查看毛利。

微信小程序制作方案

以下为可落地的小程序页面、数据表和联动逻辑。该 HTML 可作为产品原型，开发时可按此拆分为 WXML、WXSS、JS 与云数据库集合。

联动规则

库存联动

入库增加库存，出库减少库存，退回供应商减少库存。产品维度使用 productKey = 产品名 + 规格 + 单位 + 包装规格，避免同名不同规格混淆。

财务联动

入库形成采购成本和应付，出库形成销售收入和应收，退回供应商冲减采购成本或形成供应商退款。利润 = 销售收入 - 销售成本 - 销售运费等费用。

本 HTML 为批发行业库存与财务联动原型，可继续扩展为正式微信小程序、Excel 模板或云数据库后台。
