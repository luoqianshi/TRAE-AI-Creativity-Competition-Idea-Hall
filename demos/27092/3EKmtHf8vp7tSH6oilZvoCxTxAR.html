AI 输入法 Agent

语音输入 → 候选栏智能补正 → 确认填入。输入法即 Agent 入口。

人类语音输入是核心，AI 在输入法候选栏中帮你补正、润色、执行操作。

核心理念：输入法即 Agent

不是 AI 替你写，而是你说的话经过 AI 补正和增强后填入。输入法候选栏就是 Agent 的交互界面。

人先说话

核心输入始终是人类的语音。你说出想表达的内容，AI 不做凭空生成，而是以你的话为起点进行后处理。

候选栏补正

语音识别后，候选项不止是文字。输入法候选栏同时展示：原话、补正文本、润色版本、正式版本，以及 Agent 可执行的操作。

Agent 即操作

候选栏中还可以出现 Agent 行动项：搜索、翻译、查询日历、生成回复变体。选一个，Agent 执行后把结果填入输入框。

交互流程

你说的每一句话，都经过输入法候选栏的智能处理

1

语音输入

用户说话，语音实时转文字。这是输入的唯一来源——AI 不凭空生成。

2

候选栏生成

输入法候选栏展示：原话、补正版、润色版、正式版，以及 Agent 可执行的操作项。

3

选择/调整

用户点选候选，或继续说话让 Agent 调整。不满意？再说话，Agent 重新生成候选。

4

确认填入

选中的内容直接填入当前输入框。用户的意图始终是起点，AI 只是帮它更好。

两种交互模式

输入法候选栏模式

轻量级，在日常输入中直接使用

  • ▸ 在任意输入框中语音输入，候选栏自动弹出
  • ▸ 候选栏同时展示：补正版、润色版、原话、Agent 操作
  • ▸ 点选即填入，像普通输入法选词一样自然
  • ▸ 适合日常聊天、快速回复、即时通讯

桌宠 CLI 深度模式

双击桌宠，独立对话，深度处理

  • ▸ 双击桌面 AI 宠物，弹出 CLI 终端界面
  • ▸ 截屏 OCR 自动识别当前上下文
  • ▸ 多轮对话迭代，Agent 生成详细方案后填入
  • ▸ 适合写方案、写邮件、深度创作等复杂场景

应用场景

日常聊天

语音说"火锅走起周六晚上不见不散"，候选栏给出补正版"火锅走起！周六晚上不见不散~"，选一个填入。

工作沟通

语音说"方案做完了你看下有问题告诉我"，候选栏给出正式版"方案已完成，请查阅，如有问题请随时反馈"，选一个填入。

翻译输入

语音说中文，候选栏中直接出现英文翻译版。选一个，英文翻译直接填入当前输入框。

Agent 操作

语音说"查一下明天天气"，候选栏出现 Agent 操作项：搜索天气并填入结果。选一个，Agent 执行后结果自动填入。

价值与意义

效率提升

  • 语音输入速度是键盘 3-5 倍，AI 补正消除口误和识别错误
  • 不需要切换应用，输入法候选栏就是 Agent 的操作界面
  • Agent 操作项可以直接执行搜索、翻译等任务，结果填入输入框

商业价值

  • 桌面端输入法市场长期停滞，AI 输入法 + 桌宠形态是颠覆性创新
  • 候选栏即 Agent 入口，这种交互范式可沉淀为专利壁垒
  • 桌宠天然具有社交传播属性，适合裂变增长

社会价值

无障碍沟通

语音输入 + AI 补正，帮助视障、肢障人群更便捷地使用桌面设备。

降低 AI 门槛

桌宠形态 + 候选栏交互，让不熟悉 AI 的用户也能自然使用，不需要学习提示词。

人机协作

人始终是起点——AI 不替代人类表达，而是帮人类表达得更好。输入法即 Agent 的理念探索人机协作新范式。
