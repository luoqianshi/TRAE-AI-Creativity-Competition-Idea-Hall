01 / 创意介绍

什么是 BeatPet？

🎵 创意名称

BeatPet —— Beat（节拍）+ Pet（宠物）。一只能听见音乐、能感受节奏、会随旋律呼吸的桌面宠物。

💡 想解决什么问题

现代人每天平均听音乐 2-4 小时，但音乐只是"背景音"，没有任何生命在陪你一起感受。桌宠类产品大多是"对话型 AI"，需要主动交互才有趣，没人说话时就静止不动，缺乏被动陪伴感。

🌟 为什么会想到做这个

作为一个写代码必须听音乐的人，常觉得"如果有只小生物能听见我听的歌，跟着节奏蹦跳，那该多治愈"。市面上的桌宠要么是静态贴纸，要么是套壳 ChatBot，没有一个是"真正在听音乐"的。于是我想：为什么不让宠物被音乐驱动？

📦 大概是什么产品

一个 Web App，打开浏览器即可体验。用户播放任何音乐（本地文件/麦克风/系统音频），BeatPet 实时分析音频信号，驱动一只可爱的虚拟宠物做出情绪反应。后续可包装为 Tauri 桌面宠物。

02 / 目标用户及痛点

谁会爱上 BeatPet

🎹

编曲人 / 音乐创作者

把自己编的鼓点放给 BeatPet 听，看它跟着节奏摇摆跳舞，作品被"听懂"的反馈感无可替代

📚

学生党

学习时放 BGM，需要一个治愈的陪伴物缓解孤独

🌙

独居青年

一个人住，回家放首歌，希望屏幕里有"活物"在回应

❌ 没有 BeatPet 之前

  • 听音乐只是"背景音"，没有生命在陪你一起感受
  • AI 桌宠需要主动对话，不说话就静止，被动感强
  • 音乐可视化工具偏"技术展示"，没有情感温度
  • 养真宠物成本高，虚拟宠物又太机械、没灵魂
  • 编曲人做完 demo 没人即时反馈，鼓点好不好没人"听见"
  • 独居时屏幕冷冰冰，缺少"活着"的陪伴感

✅ 有了 BeatPet 之后

  • 宠物能"听见"你听的音乐，跟着节奏蹦跳
  • 无需主动交互，放歌即可，被动陪伴零负担
  • 不同曲风触发不同情绪，宠物有真实的"性格"
  • 零养护成本，不用喂食铲屎，但永远在你身边
  • 编曲人放 demo 给它听，宠物是否摇摆就是最直观的"鼓点反馈"
  • 屏幕里多了一个活生生的小生命，治愈孤独
03 / 技术实现路径

音乐如何变成生命

BeatPet 的核心技术链路：用浏览器原生 WebAudio API 实时分析音频，提取音乐特征，映射为宠物情绪与行为。全程低延迟（<5ms）、60FPS、无需后端。

音频源 本地文件/麦克风/系统音频
→
WebAudio AnalyserNode FFT
→
特征提取 RMS/频段/频谱重心
→
Beat 检测 rolling mean + std
→
BPM 估计 间隔中位数平滑
→
情绪映射 多维情绪向量
→
状态机 多种宠物状态
→
动画渲染 Canvas 60FPS

04 / 差异化优势

为什么是音乐驱动

市面上桌宠产品大多是"AI 对话驱动"，BeatPet 是唯一"音乐信号驱动"的虚拟生命，赛道差异化明显。

对比维度 BeatPet（本项目） 传统桌宠 / AI 对话宠物
核心驱动 🎵 音乐信号实时分析 💬 AI 对话（HTTP 请求）
交互方式 被动陪伴，放歌即可 需主动打字对话
技术栈 WebAudio + Canvas（Web 原生） PyQt5 / Electron（重型）
体验门槛 打开链接即用，零安装 下载安装 exe / dmg
性能要求 低延迟（FFT <1ms），60FPS 等 API 返回，性能要求低
情感连接 宠物记住你的音乐口味 基于对话记忆
差异化 ✅ 赛道独特，非 ChatBot 套壳 ⚠️ 同质化严重
05 / 价值与意义

BeatPet 带来三层价值

💝

情绪价值

为 1 亿独居人群提供零负担的情感陪伴。宠物会随音乐呼吸、蹦跳、开心、激动，让屏幕不再是冷冰冰的玻璃，而是一个有温度的小世界。

⚡

效率价值

为程序员、学生等长时间用电脑的人群，提供"不打扰但一直在"的工作陪伴。宠物安静模式时不弹台词，只在 beat 触发时轻轻律动。

🌐

社交价值

用户可分享"我的音乐宠物"截图、宠物对某首歌的反应视频，形成社交传播。宠物的音乐口味画像可成为个性化标签。

📈 市场潜力

中国音乐用户超 7 亿，独居人口近 1 亿，治愈系经济市场规模超 千亿。BeatPet 切中"音乐 + 孤独 + 治愈"三大趋势的交叉点，具备明确的商业化路径（皮肤付费、音乐平台联名、IP 衍生品）。

07 / 后续探索方向

BeatPet 的进化路径

当前版本聚焦"音乐驱动的虚拟生命"核心闭环，未来计划沿四个方向逐步进化。以下为探索方向，非当前版本承诺。

🖥️

形态升级

从 Web App 进化为 Tauri 桌面宠物：透明窗口、悬浮置顶、可拖拽到桌面任意位置。让宠物真正"住"在你的屏幕里，工作写作时始终陪伴。

🤖

具身延伸

探索从数字具身走向实体具身：接入桌面级具身硬件（带舵机/扬声器/灯效），让宠物不仅能"听见"音乐，还能用身体律动、灯光闪烁表达情绪，把屏幕里的陪伴变成桌面上的真实存在。

🧠

能力扩展

引入音乐口味记忆，宠物记住你偏好的曲风并影响自身性格；规划多宠物选择、皮肤系统、成就系统，让陪伴关系随时间沉淀加深。

🌐

宠物自主社交

探索宠物替主人发现同好：宠物在后台自主与周围其他宠物交换音乐口味，用户每天只需查看"今天我家宠物和谁聊了什么"，就能发现身边听相似音乐的人——把浅社交交给宠物，把"遇见同好"留给用户。
