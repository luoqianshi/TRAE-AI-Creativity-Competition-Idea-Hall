01 / INTRO

创意介绍

PROBLEM
想解决什么问题

团队在面对复杂事件（如活动策划、应急演练、项目实施）时，沟通散乱、预案不全、执行失控、复盘无据—— 口述与文档无法可视化全局，分支预案缺失导致遇突发手足无措，复盘凭记忆缺乏实际对比依据。

MOTIVATION
为什么会想到做这个

灵感源自军事沙盘推演与思维导图的结合—— 若能把多人思维可视化、分支可推演、执行可指挥、事后可复盘，团队协作将如指挥一场战役般精准高效。 每个成员的想法都不该被埋没，每个分支都值得被推演。

PRODUCT
大概是什么产品

一款基于3D地图的多人协作预演与复盘系统（Web系统）， 覆盖"思维汇总→3D预演→实时指挥→复盘对比"全流程。 支持地图导入或AI生成、主线支线推演、群体决议与AI判断、执行期实时指挥、事后对比分析。

02 / PROCESS

核心流程

四阶段闭环：从思维汇聚到复盘对比，构建完整的预演沟通复盘链路

01
思维汇总
所有人对问题进行思考总结，系统将想法聚合为主线（综合方案）与支线（备选方案），支线可有多条。
AGGREGATE
02
3D预演
综合众人思维后生成3D地图视角流程模拟，地图可导入或AI生成。遇支线时可选群体决议或AI判断方案价值。
SIMULATE
03
实时指挥
事件进行时作为核心智囊，向主指挥人员汇报情况，告知实际负责人当前需进行的事项。
COMMAND
04
复盘对比
事件结束后将实际进展与预演模型对比展示，直观呈现偏差，了解实际过程中遇到的问题。
REVIEW
03 / LOGIC

主线与支线

多人思维如何汇聚为综合性模型，遇分支如何决策

M
主线 / Main Line
所有人想法集合的主要综合部分，是团队共识的核心执行路径，代表最主流的方案推演。
B
支线 / Branch
当遇到某一情况时，可选择按照另外一个方案进行。备选方案可有多条，因为同情境下思维集合可能有多种备选。
D
决议 / Decision
遇支线时两种决策方式：①全体判断决议选择合适方案，并进入更细致的条件构建；②由AI判断方案价值，自动选择最优路径。

当前痛点 / WITHOUT

  • 沟通靠口述与文档，思维分散，无法可视化全局
  • 预案只有主线无支线，遇突发情况手足无措
  • 执行时缺乏实时指挥参考，各岗位信息不对称
  • 复盘凭记忆，缺乏实际与预演的对比依据
  • 多人想法难以汇聚，决策易遗漏关键视角

策演沙盘 / WITH

  • 3D地图可视化全局，所有节点与路径一目了然
  • 主线+多条支线预案，遇分支可群体决议或AI判断
  • 执行期作为核心智囊，实时向指挥与负责人同步
  • 复盘时实际进展与预演模型对比，偏差清晰可见
  • 众人思维自动汇聚，综合模型不漏任何关键想法
