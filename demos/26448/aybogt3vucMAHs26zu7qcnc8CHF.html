PROJECT OVERVIEW

一款专为小说作者
打造的AI创作工具

NovelCraft 是一款基于 Electron + React 构建的桌面级 AI 小说创作编辑器。 我们采用 VS Code 式的专业软件设计理念，将小说创作所需的核心功能——人物管理、 时间线追踪、事件记录、AI 助手等，整合到一个统一、优雅的工作环境中。

PAIN POINTS

传统工具的痛点

作为小说创作者，你是否也遇到过这些问题？

😵

人物管理混乱

多个人物的性格、关系、外貌等信息散落在不同文档中， 查阅不便，设定容易出现矛盾。

⏰

时间线混乱

长篇小说中事件先后顺序容易出错， 前后逻辑矛盾难以避免，读者体验大打折扣。

📝

情节碎片化

章节之间的衔接缺乏全局视角， 伏笔与回收容易遗漏，结构松散难成体系。

🤖

缺乏AI辅助

现有写作工具没有智能助手功能， 创作灵感依赖个人积累，遇到瓶颈难以突破。

💻

格式不友好

Word等办公软件排版复杂， 功能臃肿，不适合纯文字创作场景。

💰

学习成本高

Scrivener等专业写作软件价格昂贵， 学习曲线陡峭，新手难以快速上手。
