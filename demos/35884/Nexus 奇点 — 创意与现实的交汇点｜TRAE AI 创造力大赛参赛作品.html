// 01 — PROBLEM

普通人的创意，为什么总是胎死腹中？

每个人都说过那句话："如果有这样一个产品就好了。" 可一旦动手把想法变成真东西，立刻被五道高墙挡在外面。

01

不会设计

设计公司报价几千到几万，自学 SolidWorks 半年起步，淘宝设计师质量参差不齐。

02

找不到供应商

不知道去哪找靠谱模具厂、代工厂，工厂信息高度分散，门外汉容易被坑。

03

不知道成本

开模费、材料费、注塑费、组装费各家口径不同，拿不到合理的成本预估。

04

专利申请复杂

外观专利、实用新型、发明专利流程繁琐，找谁代办、收多少钱都是黑箱。

05

迭代成本高

每次修改都要重新沟通设计师、重新排队工厂，一次微调就是 1-2 周。

06

资源极度不对称

大厂内部有完整产业链，普通人面对的是从零开始的信息黑洞。

这些门槛，让无数本可以变成现实的好创意，永远停留在了脑子里和聊天记录里。 Nexus 奇点要做的，就是把这些门槛逐一拆掉。
// 02 — SOLUTION

一个把想法直接"折叠"成产品的奇点

Nexus 奇点是一个 Web 端平台 + 移动 APP。 它把传统需要 1–2 个月、跨越十几道门槛的产品落地流程， 压缩成输入一句话 → 拿到设计方案 → 选定供应商三步。

核心模块

A

B

// 08 — COMPETITION DEMO

初赛 Demo：从一句话到一把便携智能链锁

初赛 Demo 完整还原"普通人 → 创意 → 产品方案 → 供应商"的真实闭环。 以一款带锁链的便携智能挂锁（可用于行李箱、共享单车、户外装备、储物柜等场景）为例，区别于已经高度同质化的入户门锁。

"我想做一把可以用手机远程开锁、带锁链的便携智能挂锁，能扣在行李箱、单车、储物柜上。"
  1. AI 解析创意 识别品类（便携安防 / 智能挂锁 / 链锁），核心能力（远程开锁 / 蓝牙 + NB-IoT 通讯 / 防剪锁链 / 电量管理），使用场景（行李箱、单车、户外装备、共享储物柜），自动匹配"便携链锁"设计模板。
  2. 生成产品方案 输出锁体 + 锁链分解结构图、外观设计图、核心模块（指纹 + 蓝牙 + NB-IoT + 防撬传感 + 应急 USB-C 解锁）、推荐材料（锌合金锁体 + 304 不锈钢防剪锁链 + 食品级硅胶防刮套）。
  3. BOM 与成本估算 给出整机 BOM 与单台预估成本区间：¥85–¥160；开模费预估 ¥20,000–¥45,000；首批起订量推荐 500–1000 把。
  4. 智能推荐供应商 匹配锁体压铸模具厂 2 家、不锈钢锁链供应商 2 家、PCB 供应商 2 家、组装代工厂 2 家、专利代理机构 1 家，全部带历史评分与样品寄送选项。
  5. 一键下单 + 协同迭代 用户在线选择供应商，发起样品制作；后续修改通过参数化界面拖拽即可（如调整锁链长度、锁体厚度），分钟级生成新方案。
