三大 核心功能

扫描 · 更新 · 分发，把繁琐的资源管理交给 Open Manager

SCAN

智能扫描 + 自动去重

扫描 D:\skills 与 D:\github（macOS/Linux 自动适配 ~/skills 与 ~/github），基于 SHA256 内容哈希识别重复资源，9 大预设分类 + 自定义分类，让杂乱无章的文件夹变成有序的资产库。

SYNC

一键批量更新

点击 更新全部 ，内部自动执行 git clone --depth 1 拉取所有项目最新版。先备份再更新，更新失败自动回滚，不破坏任何本地修改。版本号自动从 git tag / pyproject.toml / package.json 提取。

SYNC

一键分发到 AI 工具

勾选 skills + 勾选目标工具（Trae / Claude Code / OpenClaw / 自定义路径），即可一键复制。批量分发 + 自动覆盖，切换工作设备、配置团队环境时节省 90% 时间。
