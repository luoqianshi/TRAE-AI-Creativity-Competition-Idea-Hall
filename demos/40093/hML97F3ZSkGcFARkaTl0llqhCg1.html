PROBLEM

我们发现了什么问题

央国企职场人在追求升职加薪的路上，面临着一连串让人头疼的障碍

🧭

方向迷茫，无人指路

想升职加薪却不知道该考什么证、学什么技能。身边缺乏职业导师，网上信息碎片化，不知道哪条路才适合自己。

🔍

信息杂乱，难辨真伪

网上考试信息参差不齐，到处是培训机构广告。想找到官方考试文件、报考条件、考试时间，需要翻遍十几个网站。

📚

资料难找，选择困难

备考资料散落各处，市面学习 APP 太多，不知道哪个适合自己。排学习计划更是费时费力，还没开始就先累了。

⚡

多线作战，手忙脚乱

经常需要同时准备两个考试或学习计划，时间冲突、精力分散，缺乏统一管理工具，容易顾此失彼。

🗺️

缺乏规划，看不到路

不知道从现在到目标还差什么条件，硬性要求、软性技能一锅粥。没有清晰的路径图，缺乏成就感和动力。

🎯

动力不足，容易放弃

备考是场持久战，没有正向反馈很难坚持。需要游戏化的激励机制，让每一步都有获得感。

SOLUTION

人生修炼手册怎么做

MVP 聚焦两大核心功能，用 AI 解决方向和信息两大首要痛点

MVP 核心
🧭

AI 职业方向推荐

基于用户当前岗位、职级、行业，AI 智能分析央国企晋升路径，推荐最适合的考试证书和学习方向， 像一个懂你的职业导师，给你指明方向。

  • 输入岗位信息，AI 匹配晋升路径
  • 推荐含金量高的证书和考试
  • 分析硬性条件与软性技能缺口
  • 生成短期/长期职业发展建议
MVP 核心
📡

官方考试信息聚合

定时搜索 Agent 自动收集各渠道官方考试信息，整合报考条件、考试时间、官方文件， 一站式获取权威信息，告别信息差。

  • 定时 Agent 自动抓取官方考试公告
  • 结构化展示报考条件与时间节点
  • 官方文件原文链接，溯源可信
  • 考试提醒，不再错过报名
TARGET USER

为谁而做

聚焦央国企职场人群，解决他们最真实的晋升焦虑

💼

央国企职场晋升者

20-40岁 央国企在职 追求晋升 考证党 信息焦虑

使用场景：

• 年底评优、岗位竞聘前，想快速补齐证书短板

• 看到同事考证升职，自己也想行动却不知从何入手

• 同时准备职称考试和职业资格考试，需要统筹安排

• 想了解某个证书是否值得考、报考条件是什么

VALUE

为什么有价值

从效率、商业、社会三个维度，创造真实价值

⚡

效率提升

将分散在十几个网站的考试信息整合为一站式查询，AI 自动生成学习计划，帮用户节省 80% 的信息搜集和规划时间，把精力集中在学习本身。

💰

商业价值

精准触达高付费意愿的职场人群，可通过考试报名导流、优质课程推荐、企业内训合作等模式变现。用户生命周期长，复购率高。

🌟

社会价值

打破职业信息差，让普通职场人也能获得优质的职业规划资源。助力人才成长，促进社会公平，让每一份努力都有清晰的方向。
