🎯 痛点洞察

你是否也被这些问题困扰？

每一位科研人都绕不开的阅读难题

⏱

研读效率低

一篇 20 页的英文论文，从标题、摘要、图表到参考文献，往往要花数小时才能抓住核心贡献。

🔍

信息碎片化

同一概念在不同段落中反复出现，却难以在短时间内建立完整的知识脉络，也难以快速定位来源。

🌐

语言门槛高

大量高水平文献以英文发表，专业术语密集、句式复杂，非英语母语者阅读存在明显障碍。

📑

引用溯源难

想了解某句话的来龙去脉，却在 PDF、浏览器、笔记之间反复切换，找不到原始依据。

⚙️

工具链路长

现有工具（PDF 阅读器、检索引擎、翻译、笔记）相互独立，缺乏一个能统一完成全流程的方案。

🔒

隐私与离线需求

部分未公开的研究内容不便上传到云端，需要一套能离线运行、保护隐私的本地化方案。

一个系统，解决论文研读全流程

「论文智读」把 PDF 解析、学术结构识别、混合检索、递归问答、翻译与术语整理 打包在一个可本地部署的 Gradio 界面里，让你专注思考，而不是「找资料」。

1

拖拽上传

支持单篇/批量 PDF 上传，自动识别论文结构并建立索引。

2

结构分析

自动识别章节、参考文献、术语表与问题卡，一键速读。

3

智能问答

提出中文或英文问题，系统自动检索多轮、生成答案并附来源。

4

对比翻译

跨多篇论文对比观点，或一键翻译专业段落，降低语言门槛。

✨ 核心功能

为论文研读而生的 6 大能力

📤

智能 PDF 解析

自动识别论文章节结构、双栏排版、图表与参考文献，保留原文逻辑而非简单切块。

🔍

混合检索

FAISS 语义向量 + BM25 关键词检索 + CrossEncoder 重排，兼顾语义与精确匹配。

🔁

递归多轮问答

首次检索后如信息不足，系统自动补充查询并合并结果，直至答案完整、可追溯。

📖

速读与术语表

基于首末段落自动生成 8 句速读摘要，并抽取高频术语形成术语表。

🔗

引用追踪

自动识别论文中的参考文献编号，点击即可查看对应条目，便于进一步检索。

🌏

中英翻译

整段翻译、术语翻译、摘要翻译一键完成，让外文论文不再有语言门槛。

❓ 常见问题

使用前你可能想问

必须联网才能使用吗？ +
不需要。所有核心功能（解析、索引、检索、问答、翻译）都能在完全离线状态下运行，只要本地已经下载了 Embedding、CrossEncoder 与 Ollama 模型。
对电脑配置有什么要求？ +
推荐 16GB 内存 + 50GB 以上可用磁盘空间；GPU 并非必须，有 NVIDIA 显卡可进一步加速。纯 CPU 也能正常运行，只是推理速度稍慢。
是否支持中文论文？ +
支持。系统已针对中文章节编号、参考文献格式与中文术语识别做了优化，并在 Embedding 与关键词检索两部分都做了中文兼容。
生成的答案一定正确吗？ +
大模型输出仍可能存在幻觉。本系统通过「附带来源段落」「可信度评分」「冲突检测」三重校验，帮助你判断答案是否可信——核心原则是「辅助判断，而非替代阅读」。
可以接入自己的模型吗？ +
可以。只要在 `.env` 文件里修改模型名称与 API 地址，或在 `model_manager.py` 中新增本地模型路径即可；Ollama 兼容几乎所有主流开源大模型。
是否适合完全不会编程的用户？ +
只要按照「环境配置说明-附件一.md」完成一次环境搭建，后续日常使用只需双击 `run.bat`，所有操作均通过浏览器完成，无需写代码。
