Problem

旅行决策的"冷启动"问题

很多年轻人不是不想旅行，而是不知道去哪、懒得规划、选不出来。传统旅行 App 要求用户先知道目的地，但用户恰恰不知道去哪——真正难的不是搜索，而是从"我现在的状态"出发，做出一个适合自己的旅行决定。

"旅行冲动很容易流失——很多人本来想出去，但因为规划太麻烦，最后变成'算了，下次吧'。"

How It Works

搭子怎么想的——React 循环决策链

从"我好累"到"买张去三亚的机票"之间，AI 搭子用 React 循环（Reason→Act→Observe）一步步帮你决策。它不会只回答"去哪里玩"，而是像一个朋友一样说："你现在太累了，不适合高强度路线，去海边躺三天吧。"

Features

三大核心功能

01

情绪识别驱动推荐

8种情绪 → 5种出走签 → 个性化目的地匹配。Agent 的 React 循环（读懂你→排除法→优先匹配→预算估算）全程可视化，每步决策都有自然语言解释。用户画像自动提取并持久化，越用越懂你。

02

完整出行方案

目的地推荐、情绪与偏好分析、行程规划、出片攻略、穿搭推荐、机票参考、打包清单、避坑提醒——8个维度，从决策到出行一站式输出。机票卡片含携程真实搜索链接，行程天数可动态调整。

03

连续对话调整

不是一次性生成器，而是支持连续对话。用户可以继续说"便宜一点""近一点""不要热门城市""更安静一点""换个海边城市""去7天"，Agent 根据反馈继续调整方案。

Business Model

商业模式：情绪-决策-出发

AI 旅行搭子不是替代旅行平台，而是站在旅行决策的更前一步。情绪→决策→出发的链路，每一步都有变现路径。相比传统OTA的"搜索-比价-下单"，差异在于"情绪-决策-出发"。

✈️

机票/酒店分销

推荐目的地后，接入携程/飞猪/美团OTA平台。机票卡片已含真实搜索链接。

Value

价值与意义

🌟 产品价值

把旅行推荐的入口从"搜索目的地"前移到"表达心情"。用户不需要先输入"三亚三日游攻略"，只需要说"我好累，想看海"。

Agent 理解这句话背后的真实需求：疲惫、放空、低强度、海边、短途、少决策压力，然后自动生成适合的旅行方案。这让 AI 不只是内容生成工具，而是旅行决策伙伴。

💰 商业价值

旅行决策天然连接机票、酒店、当地玩乐、攻略内容和品牌消费。AI 旅行搭子成为更前置的旅行消费入口。

6条变现路径（OTA分销/穿搭电商/旅拍服务/精准营销/装备电商/定制订阅）形成商业闭环，情绪→目的地的决策链是差异化护城河。

🌿 社会价值

对很多年轻人来说，旅行不只是消费，而是一种恢复能量的方式。帮助高压生活中的人，把一句"我好累"转化成一次真实可执行的出走。

降低旅行规划门槛，让更多人能从情绪困住的状态里，找到一个具体的出口。从"我想消失几天"到"那就去海边躺三天吧"，不再需要反复纠结。
