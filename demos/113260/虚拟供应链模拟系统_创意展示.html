Core Features

核心能力矩阵

从建模到推演、从分析到复盘，SupplyTwin 覆盖供应链决策全流程。

01 // DRAG & DROP

拖拽式供应链建模

在画布上拖入供应商、工厂、仓库、零售商节点，用连线定义物流关系。无需编程，5分钟搭建一条完整的供应链网络。

02 // WHAT-IF ENGINE

What-If 情景引擎

内置 20+ 种突发事件模板（自然灾害、地缘冲突、需求暴增、供应商倒闭等），支持自定义事件参数，一键注入网络。

03 // AI REASONING

AI 多方案推演

AI 自动分析事件影响范围，生成 3-5 套备选方案。每套方案附带成本估算、交期预测、风险评分，量化对比一目了然。

04 // RISK RADAR

风险雷达可视化

多维度雷达图展示每套方案在成本、交期、质量、灵活性、风险五个维度的表现，帮助决策者快速识别最优解。

05 // TEAM COLLAB

团队协作决策

推演结果一键分享给团队，支持多人标注意见和投票。决策过程全程记录，形成可追溯的决策日志。

06 // REPLAY MODE

历史复盘模式

导入真实历史数据，回溯重大供应链事件，模拟"如果当时选了B方案会怎样"。从过去的决策中学习，持续优化策略。
