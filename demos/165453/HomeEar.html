/ 核心亮点

零训练、纯规则、
开箱即用

不依赖神经网络模型，不需要收集数据集和训练。基于家电提示音的物理特征——高频短促单频音 + 固定次数重复——用 FFT 频谱分析和状态机即可精准识别。

  • ✓
    零训练识别无需数据集、无需模型训练，烧录即用，降低使用门槛
  • ✓
    纯 FFT 规则引擎基于频谱特征的物理识别，无黑盒，可解释、可调试
  • ✓
    频谱调参助手内置 spectrum_tuner 工具，串口可视化实时频谱， calibration 轻松完成
  • ✓
    OLED 实时反馈0.96 寸屏幕显示识别结果 + 动态频谱条，状态一目了然
  • ✓
    RGB 状态灯5 种家电对应 5 种颜色，远距离一眼识别告警类型
  • ✓
    可选 MQTT 推送配合 Home Assistant 或巴法云，实现手机远程通知
