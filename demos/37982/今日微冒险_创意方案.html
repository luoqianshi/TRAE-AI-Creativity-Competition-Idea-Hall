PART 01 · 创意介绍

你的生活，是不是按了自动巡航？

同一个闹钟 · 同一条路线 · 同一家店 · 同一句「还行」

你有没有发现，生活正在被「自动巡航」接管？每天走同一条路去上班，去同一家店吃午饭，回同一条路回家，说同一句「还行」。不是不想改变，是不知道怎么改变——推荐 App 推的是「别人觉得好」的，社交平台推的是「别人在玩」的，但没有一个产品告诉你：你今天可以做什么不一样的事。

「今日微冒险」由此而生：它不是又一个推荐工具，而是一个每天给你一张冒险卡片的小程序——打开应用，看到今天的小冒险，去做，打卡，生成一张旅行青蛙风格的明信片分享。整个过程不超过 15 分钟，但你的今天，不再和昨天一模一样。

生活不是缺少美，
而是缺少一次说走就走的微冒险。
— 改编自罗丹

产品形态支持 微信小程序 + 独立 APP，小程序无需下载即用即走，APP 提供更完整的推送和体验。核心体验路径极简：打开 → 看卡 → 去做 → 打卡 → 分享。接入天气 API 智能推荐任务，每天推送三档难度，用户自选。

PART 06 · 技术架构与路线图

四周，从零到上线

Taro 小程序 + React Native APP + Vercel Postgres · AI 辅助全流程

前端技术栈

  • Taro 3（微信小程序跨端框架）
  • React Native（独立 APP）
  • Tailwind CSS + Framer Motion
  • html2canvas（明信片生成）
  • 小程序订阅消息 / APP 推送

后端 & 数据

  • Next.js API Routes（Serverless）
  • Prisma ORM + Vercel Postgres
  • Vercel KV（天气缓存 + Streak）
  • Vercel Cron（每日任务刷新 + 推送）
  • 和风天气 API（天气感知）
  • 高德地图 API（LBS 任务 POI）

核心算法

  • 任务推荐：排除近期 + 偏好加权 + 天气筛选
  • 模板引擎：变量填充生成 3200+ 组合
  • Streak 计算：时区感知 + 复活卡机制
  • 明信片生成：DOM → Canvas → PNG

AI 辅助开发

  • Prisma Schema 生成与审核
  • 200+ 任务文案批量生成
  • 推荐算法逻辑编写
  • 明信片模板 HTML 生成
  • 推送逻辑 + Cron 配置
