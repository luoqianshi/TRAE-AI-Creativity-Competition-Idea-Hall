问题

现有文件管理方案 并不友好

云服务成本高且在内网环境下传输速度受限，私密文件也面临安全隐患。NAS 设备昂贵且操作门槛高，ownCloud、TrueNAS、NextCloud 等开源软件对非技术用户部署过于繁琐。

01 · 云

成本与安全之痛

公有云订阅费用持续上涨，企业级套餐价格高昂；敏感文件上传至第三方服务器，隐私与合规风险难以把控。

02 · 硬件

NAS 价格与门槛双高

专业 NAS 硬件动辄数千元，self-host 又需 Docker、网络、内网穿透等大量学习成本，普通用户难以驾驭。

03 · 检索

缺乏智能检索能力

现有文件管理软件仅提供基础存储服务，无法对内容进行识别、分类与语义检索，海量文件形同垃圾。

04 · 协同

跨设备协作效率低

手机、电脑、平板之间文件互传依赖数据线或第三方中转，效率低下；不同设备间无法共享个人知识库。

方案

egos — 让个人文件管理 回归简单

egos 基于 p2p + http 网络，无需复杂的内网穿透服务即可远程访问设备文件；集成 RAG 服务对文件内容自动识别，跨设备共享个人知识库。提供 一键安装、零配置 的极致体验。

1

极致简单的安装体验

下载即用，无需复杂的网络配置或系统调优。即使是非技术人员，也能在 5 分钟内完成部署。

2

AI 加持的智能管理

基于 transformers 与 langchain 自动识别文件内容，让文件从沉默的数据变成可检索的知识。

3

本地优先的隐私保护

所有文件保存在本地设备，灵活可控的存储策略，你的数据始终属于你。

4

P2P 驱动的设备互联

WebRTC + http 跨网络直连，无需内网穿透或中转服务器，手机、电脑、平板无缝同步。

核心功能

三大模块 · 构建完整的文件智能体

从文件存储、内容理解到设备协同，egos 提供端到端的能力闭环。

Module 01

智能文件管理

统一的文件存储、检索与备份服务。基于 S3 兼容协议与本地文件系统双适配，配合 SQLite 元数据库，实现毫秒级文件检索。

  • S3 兼容存储 + 本地文件系统双模式
  • SQLite 索引数据库，毫秒级元数据查询
  • 多端文件同步与版本管理
  • 灵活的备份策略与快照机制
Module 02

AI 个人知识库

基于 transformers 自动识别文件内容，tesseract 提取图片文字，langchain 串联 RAG 流程，让所有文件成为可被自然语言检索的知识。

  • transformers 多模态内容理解
  • tesseract OCR 图像文字提取
  • langchain + lanceDB 向量检索
  • 自动分类、标签生成与知识卡片
Module 03

跨设备 P2P 共享

WebRTC + http 协议构建 P2P 网络，所有设备同步共享文件与知识库。无需内网穿透，真正点对点的私密协作。

  • WebRTC 端到端加密传输
  • HTTP 局域网发现与连接
  • 跨网络文件直连与分享
  • 所有设备共享同一知识库视图
