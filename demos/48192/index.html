01 / 创意介绍 // intro

AI 写论文的速度暴涨，
人类消化论文的速度却没跟上。

" 它不是又一个会总结的助手，而是持续学习你的那一个同门。
$ whoami
› 开题焦虑的研一新生？还是准备投稿的博三老手？
$ pal --remember
› 记住你的领域、解释深度、表达习惯，每次讲解都"对味儿"。

在 AI 生成论文日益泛滥的时代，人类消化论文的速度却远未跟上。赛博论文搭子正为解决这一矛盾而生——它是一个能持续学习你的语言风格、研究背景和阅读目标的 Web 端个性化论文伴读工具，帮你把每篇论文"拆细、读透、记住"。

灵感源于一个普遍痛点：市面上不少 AI 论文助手虽然能自动总结、分段解释，但输出千篇一律，永远无法适配你当下的身份。赛博论文搭子会像你身边最默契的那个同门，长期记住你的研究领域、偏好的解释深度、甚至习惯的表达方式。

产品形态为一个轻量级 Web 网页，打开即用，无需复杂配置。

02 / 目标用户与痛点 // pain-points

给所有人的答案都一样，
是读论文工具最大的背叛。

目标用户：广大硕博研究生、青年科研工作者。使用场景：日常文献阅读、组会准备、论文开题或写作前的文献调研。

USER ▸ 研一新生 · 需要入门图解 博三老手 · 需要批判对比 跨学科者 · 被英文论文劝退
PAIN_01
01缺搭子属性

每次对话都是"陌生人"

现有 AI 论文工具缺乏"一对一固定搭子"属性，无法沉淀用户的研究偏好和认知习惯。每次开启都从零开始，默契无从积累。

PAIN_02
02千篇一律

新人老手拿到同一份答案

读论文行为高度个性化：新人需要入门级图解，资深者需要批判性对比。但工具给所有人的答案完全一样，对味成了奢望。

PAIN_03
03阅读不连贯

看完即忘，反复查阅

阅读历史不连贯，无法积累成个人知识库，导致反复查阅同一篇论文的低效循环。读过的论文，没有变成你的资产。
