高等数学可视化——直觉构建器

用 3D 交互可视化，让数学概念从抽象公式变成可触摸的直觉

问题与灵感

核心痛点：大学高数下册的多元函数微分、重积分、Taylor 级数等概念天然是 3D 的，但教学只能用 2D 板书和静态图，学生"会算但不理解"。

灵感来源：定积分的黎曼和、偏导数的切平面、二重积分的曲顶柱体——这些概念的本质都是几何直觉。如果学生能直接"看到并操作"这些 3D 形态，理解门槛将大幅降低。

产品形态：纯前端网页应用，浏览器直接打开，无需安装。

目标用户与场景

核心用户：大学本科正在学习高等数学的学生

使用场景：课后复习遇到"这个概念到底什么意思"时，打开浏览器直接交互探索

当前痛点：

- GeoGebra 是通用绘图器，没有教学引导，新手不知从何开始

- 网课视频被动观看，无法交互

- 教材只有静态图，3D 概念全靠脑补

核心价值

效率提升 将"靠想象理解 3D 概念"的认知负荷降为"直接看到并操作"

社会价值 高数是全国理工科必修课，免费可视化工具能降低数学学习门槛

已实现的可视化模块

模块 1：黎曼和逼近 2D

拖动滑块增加分割数 n，矩形面积逐步逼近曲线下真实面积。支持左端点/右端点/中点取点方式切换，实时显示误差和收敛度。

Sₙ = Σ f(xᵢ) · Δx

交互：→ 分割数滑块(1-200) → 取点方式切换 → 动画演示(n从4到128) → 矩形hover高亮+面积值

模块 2：旋转体体积 3D

将曲线绕 x 轴旋转，从 0° 到 360° 逐步生成旋转体。打开圆盘切片可直观看到体积微元分解。

V = π ∫ₐᵇ [f(x)]² dx

交互：→ 旋转角度滑块(0-360°) → 圆盘切片开关 → 轨道控制自由旋转

模块 3：偏导数与切平面 3D 下册重点

在 3D 曲面上拖动一个点，实时显示该点处的切平面。用红色箭头标注 x 方向偏导数，蓝色箭头标注 y 方向偏导数，绿色箭头标注梯度向量方向。

z = f(x₀,y₀) + fₓ(x-x₀) + fᵧ(y-y₀)

交互：→ 4种曲面切换(抛物面/马鞍面/正弦波/高斯) → 点坐标滑块 → 切平面+偏导数箭头+梯度向量

模块 4：二重积分 3D 下册重点

3D 场景展示曲顶柱体（底面+曲面+侧面围合），用小柱体网格逼近曲顶柱体体积，类似黎曼和的 3D 版本。

∬ᴰ f(x,y) dA ≈ ΣΣ f(xᵢ,yⱼ) Δx·Δy

交互：→ 曲面选择 → 分割数nx/ny滑块 → 分割柱体显示/隐藏 → 近似值vs精确值

模块 5：Taylor 级数逼近 2D 下册重点

原函数曲线(粉色)与 Taylor 多项式曲线(青色)叠加显示，拖动项数滑块观察多项式逐步逼近原函数的过程，红色区域显示逼近误差。

Tₙ(x) = Σ f⁽ᵏ⁾(a)/k! · (x-a)ᵏ

交互：→ 函数选择(sin/cos/eˣ/ln(1+x)) → 逼近中心点滑块 → 逼近阶数0-15 → 收敛性警告
