Technical Architecture

技术原理

硬件能力图谱 + 约束求解 + 需求反推

⚡

硬件能力图谱

为每款主流开发板建立能力画像：GPIO数量、运算能力、接口类型、功耗、支持的通信协议。方案匹配时先做"能力过滤"——只推荐板子能力范围内能实现的项目。

🔄

多约束优化求解

将用户的约束条件（场景、技能、工具、预算）建模为约束方程。方案推荐是在"能力范围内"的候选池中，用约束条件做筛选排序，最大化"适合度"评分。

🎨

需求反推引擎

不同于教程推荐的"项目→用户选"模式，采用"用户需求→反推方案"模式。核心逻辑：用户描述想解决的问题 → AI 在能力图谱中查找解决方案 → 评估约束条件匹配度 → 输出最适合的3-5个方案。

🛠

材料成本估算

每个推荐方案附带精确的材料清单（含具体型号）和成本估算，参考电商平台实时价格区间，确保用户在动手前就知道需要花多少钱、买什么东西。

Use Cases

三大匹配场景

宿舍场景

树莓派宿舍智能灯控

小李有树莓派4B但没编程经验，宿舍不让用大功率设备。工具匹配出"红外遥控灯控"方案——利用树莓派红外发射头，模拟空调/台灯遥控器信号，通过手机网页控制，无需焊接，额外成本只需15元（红外LED+杜邦线），难度"入门级"。

课程选题

嵌入式课项目选题

大三学生小张要交一个嵌入式课期末项目，有Arduino Uno和基础焊接工具。工具根据课程要求匹配出"温湿度自动浇花系统"方案——用DHT11传感器+水泵继电器，实现土壤干燥自动浇水，难度适中、演示效果好，额外材料35元。

家庭场景

家里快递提醒器

阿杰住在偏远小区，快递经常被丢在门口。工具匹配出ESP32+震动传感器方案——贴在门上，检测到震动后通过WiFi推送手机通知，成本仅30元，不需要焊接，用Arduino IDE烧录现成代码。

User Story

用户故事

我大二下学期买了块树莓派4B，当时满心欢喜觉得自己要开始做各种硬件项目了。结果打开浏览器搜"树莓派能做什么"，看到了几百个项目——NAS、智能音箱、人脸识别门禁、游戏机……每个都好酷，但每个都不太适合我。我住宿舍，不能焊接，不会Python，预算只有几十块。看了三天教程越看越焦虑，觉得树莓派就是个吃灰的玩意儿。

后来同学推荐我用这个匹配工具。我选了"树莓派4B + 无额外模块 + 宿舍场景 + 不会编程 + 没有焊接工具 + 预算50元以内"。工具10秒后给了我三个方案：第一名是"红外遥控万能遥控器"——用树莓派控制宿舍的空调和台灯，不用焊接只要插杜邦线，有现成的开源代码改改就行；第二名是"备忘录桌面时钟"——用OLED屏显示每日课程和待办，花了45块买了个屏幕。我选了红外遥控方案，照着材料清单花了15块买了红外LED和杜邦线，下载了开源代码改了改遥控码，一个下午就搞定了。室友们都惊呆了——"你还会树莓派？"其实我只是用对了工具，找到了适合我条件的项目，而不是跟风做那些不适合我的。
