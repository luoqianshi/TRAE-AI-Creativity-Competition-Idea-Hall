// 02 · 能力系统

五块肌肉，撑起一个能交付的作品

VibeGym 不只是 Prompt 生成器，它把造物过程拆成可训练的核心能力。

✅

交付前体检

发布不是按一下上传。默认样例、密钥安全、移动首屏、演示路径逐项过。

// 03 · 学习路径

从想法到交付，四步走完

跟着路径练，每一步都有明确的产出和检查点。

  1. 01

    校准想法

    把「我想做个 X」拆成用户、场景、最小可用动作。

  2. 02

    切出 V0

    只保留一个核心闭环，砍掉所有「以后再说」的功能。

  3. 03

    指挥 AI

    用结构化 Prompt 驱动 AI，而不是等它猜你要什么。

  4. 04

    救回项目

    报错、跑偏、卡死。用求救单和记忆卡把项目拽回正轨。
