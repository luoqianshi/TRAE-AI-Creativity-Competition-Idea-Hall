1一句话定位

LearnCopilot 是一款基于大模型的对话式辅助学习软件，把"整段时间的系统学习"和"碎片时间的强化记忆"结合在一起，服务于时间碎片化、任务繁多、却需要在短时间内系统掌握一门知识的用户——打工人、期末大学生、想快速切入新领域的研究者与研发人员。

核心公式：整段课堂 × 碎片推送 × 自适应频次 × 个性化引导 = 让知识真正"进脑子"

6关键功能模块

模块 A · 用户画像与计划生成

设计哲学：计划生成前，先用「心理学 + 行为学」双视角对用户做"立体"刻画。千人千面，因材施教。

  • 五维画像采集：性格认知 / 学习行为 / 作息注意力 / 知识基线 / 能力倾向
  • 典型用户原型（6 类 Persona）：三分钟热度型、慢热稳健型、保守谨慎型、易受挫型、完美主义型、拖延型
  • 心理学微调模型：单独调优针对学习/教育心理学的模型，输出"应对策略文档"
  • 循循善诱逻辑：自律型用户未完成时直接询问调整；拖延型用户改"询问"为"小步启动"
🔥
三分钟热度型
一上来激情高，2–3 天就熄火
短周期小目标 + 即时反馈
🐢
慢热稳健型
前 1–2 周沉默，中后段爆发
整段课时长逐步递增 + 过程评分
🦊
保守谨慎型
即使懂也不轻易表态，怕出错
低风险题开场 + 区分"理解"与"表达"
🦌
易受挫型
难题一卡就放弃
难度梯度更细 + 主动给"脚手架"提示
🐯
完美主义型
一题卡住 30 分钟不放手
设置"反思阈值"，超时主动建议跳过
🐱
拖延型
任务一拖再拖
小步启动 + "微行动"激励

模块 B · 整段学习课堂（讲-练-评-补）

  • 课程内容讲解：5–15 分钟一节，逐步递进
  • 例题设计：覆盖核心知识点，难度随掌握度提升
  • 两种答题模式：
    • 有纸笔模式 口述/输入要点 → 系统评分
    • 无纸笔模式 必须完整口述/打字描述解题过程，逐步评分

模块 C · 碎片化短问推送

  • 推送时机：基于作息习惯 + 历史间隔 + 当前时段
  • 推送形式：Android 弹窗（类似 IM 消息）
  • 题目长度：1 行题干 + 4 行内答案
自适应算法：
快 + 对 减少该知识点推送（4h → 8h）
慢 + 错 增加该知识点推送（4h → 1h）
连续 3 次未答 暂停 24h，标记为「抗拒点」

模块 D · 高峰强化模式

  • 切换为"高频知识点驱动"模式（如期末、项目冲刺）
  • LLM 主动检索公开资料与常考内容
  • 推送强度上调（每天 10–20 道短问）
  • 提供「知识点清单」+「重难点排行」

🤖 老师：线性代数 · 特征值与特征向量

对于 n 阶方阵 A，若存在非零向量 v 和数 λ，使得 A·v = λ·v 成立，则称 λ 为 A 的一个特征值，v 为对应的特征向量。

⚡ 效率价值（无痛系统性掌握）

核心认知：我们的目标不是碎片化，而是让每个人在尽量不痛苦的情况下，以尽量快的速度完成系统性知识的学习。

  • 系统性掌握：整段课堂是主战场（结构化课程 + 难度递进 + 例题体系），碎片推送是辅助巩固
  • 贴身个性化：千人千面，不再"一刀切"

🌍 社会价值（终身学习 + 资源平权）

核心愿景：让所有愿意提升自己的人——无论背景、资源、地域——都能站在同一条起跑线上。代价只是一份午餐钱。
  • 不止学生：服务所有愿意提升自己的普通人（职场、转行、兴趣、退休）
  • 资源平权：弥补资源差，让偏远地区与三四线用户也能用上 AI 辅导
  • 应对知识爆炸：传统批量教育效率到顶，LearnCopilot 把"正确路径 + 贴身指导"做到人人可负担
  • 终身学习：让学习贯穿一生
