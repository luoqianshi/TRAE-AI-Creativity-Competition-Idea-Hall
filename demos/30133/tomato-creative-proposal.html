一、创意名称与介绍

"让专注变得像游戏一样好玩 —— 用可爱的番茄形象陪伴你，用金币和皮肤奖励你，让每个番茄周期都充满期待。"

🎯 想解决什么问题

传统番茄工作法计时工具功能单一、缺乏反馈激励机制，用户难以长期坚持。长时间专注工作枯燥乏味，缺少陪伴感和正向反馈，导致效率提升不明显，很多人"装了番茄 App 但从来不用"。

💡 为什么会想到做这个

我们发现学生、程序员和办公人员都在尝试用番茄工作法提升效率，但纯计时器的体验实在太单调了。完成一个番茄周期后没有奖励、没有成就感、没有陪伴感，动力自然不足。我们希望把"计时"变成一件有趣的事情，让用户期待下一个番茄周期，在不知不觉中养成专注的习惯。

📦 大概是什么产品

一款基于 .NET Framework + WinForms 开发的 Windows 桌面应用，采用双窗体设计：

  • 主窗体（Form1）：任务输入与管理（支持最多 5 个任务）、番茄皮肤商店、装饰背包、金币管理与奖励机制、数据持久化保存。
  • 番茄窗体（Form2）：独立悬浮在屏幕右上角，以 8 帧动画番茄形象展示计时状态，右键菜单支持 13 种环境音切换、短休息 / 长休息模式设置，支持最小化到系统托盘后台运行。

完成番茄时钟有概率获得金币奖励（5-500 随机）或解锁新皮肤装饰，金币可在商店中购买更多主题番茄皮肤（西瓜、菠萝、巫师帽番茄等）。所有进度自动保存到本地 picData.json 文件。

😰 当前痛点（没有这款产品时）

  • 枯燥坚持难：纯计时器功能单一，没有陪伴感，用户难以坚持使用超过几天；
  • 缺少正向反馈：完成一个番茄周期后没有任何奖励或成就感，动力不足；
  • 任务可视化差：手动记录任务进度繁琐，无法直观看到当前任务的完成情况；
  • 背景音乐切换麻烦：想播放白噪音/咖啡馆音乐，需要额外打开音乐 App 手动播放，还可能被广告打断；
  • 数据无法持久化：用普通应用计时，配置、皮肤、进度无法保存，换电脑或重启后全部丢失；
  • 休息容易被忽视：专注时往往忘记休息，或者休息时间失控，反而影响效率。

四、价值与意义

⚡ 效率提升价值

  • 将「枯燥的计时」升级为「有陪伴感的专注游戏」，用户完成番茄时钟的意愿显著提升；
  • 随机奖励机制（金币掉落、皮肤解锁）强化正反馈，让用户期待「下一个番茄周期」；
  • 任务管理 + 计时一体化，减少在多个应用间切换的时间损耗；
  • 内置 13 种环境背景音乐，无需额外打开音乐软件，降低专注被打断的概率；
  • 数据自动保存到本地 JSON，用户无需手动备份，降低使用门槛。

🌍 社会价值

  • 番茄工作法是被广泛验证的高效工作方法，本项目用低门槛 Windows 桌面应用形式推广它；
  • 对于学生群体而言，长期坚持番茄工作法可以改善拖延症、提升学习效率；
  • 项目代码遵循 MIT 开源协议，C# 开发者可基于本项目二次开发，有较好的技术传播与教学价值；
  • 无广告、无内购、完全本地运行，保护用户隐私，适合对数据安全有要求的办公场景。

💼 商业价值（扩展方向）

  • 未来可基于桌面端推出轻量级 Web 版 / 移动端 App（iOS/Android），形成多端协同；
  • 皮肤商店可引入用户创作机制，打造创作者生态，让有设计能力的用户贡献自定义皮肤；
  • 可接入 团队版，用于企业内部员工时间管理和项目进度可视化；
  • 基于用户番茄数据提供个性化效率分析报告（每周/每月专注时长、任务完成率、最佳工作时段等）。

📐 核心设计亮点

🖼

8 帧动画番茄形象

Timer 组件每 2 秒切换一帧，实现循环播放的番茄动画效果，比静态图片更有陪伴感。

🎶

自定义 LoopStream

基于 NAudio WaveStream 实现无缝循环播放，背景音乐到达末尾自动跳回开头，无需手动重播。

⌨️

全局键盘 & 鼠标活动检测

通过 Win32 API GetAsyncKeyState 全局检测键盘按键，联动番茄窗体的右臂装饰切换。

💾

JSON 本地持久化

金币数量、已解锁装饰、当前皮肤配置自动写入 picData.json，下次启动自动恢复。

📄

固定位置分页机制

商店/背包仅创建 4 个固定 PictureBox 复用，避免创建大量控件，性能更优。

🎰

随机奖励机制

完成番茄时钟后触发 Random 事件，有概率获得金币（5-500）或解锁新皮肤装饰，类似游戏掉落。

六、开发与落地路线

Phase 1 · MVP 已完成（当前版本）双窗体番茄时钟 + 任务管理 + 金币奖励系统 + 13 种背景音效 + JSON 持久化。
Phase 2 · 美化与扩展增加更多番茄主题皮肤、优化动画流畅度、支持自定义计时周期（默认 25 分钟可调整）。
Phase 3 · 多端协同开发 Web 版 + 移动端 App，实现番茄数据云端同步，多端无缝切换。
Phase 4 · 生态建设开放皮肤创作 SDK，支持用户上传自定义皮肤；引入团队协作版，支持小组任务共享。
Phase 5 · 数据智能基于用户番茄数据生成个性化效率报告，分析最佳工作时段，推荐休息与专注组合。
