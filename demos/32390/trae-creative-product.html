01 · 为什么做这个项目

痛点

高中数理化生的短视频课件需求爆发，但教师、教育博主和在线教育团队普遍不会剪视频、找不到合适的版权素材，也难以负担专业动画制作。

灵感

教材知识点天然结构化，却缺少一条从“知识点”到“可视化动画”再到“短视频”的自动化产线。AI 应该成为这条产线的导演。

产品形态

一个面向教育创作者的 AI 动画短视频生成 Web 系统：输入学科、年级和知识点，AI 自动生成脚本、动画代码、配音、字幕并合成成片。

02 · 核心创新：Textbook → Code → Video

不同于传统的“文案 + 素材库”剪辑工具，LessonPress 让 AI 直接编写可执行的动画指令。系统把每个 [动画: ...] 标签翻译成 Python 可视化代码，动态生成与知识点完全匹配的画面。

输入知识点
→
AI 生成脚本
→
[动画] 指令
→
Python 动画代码
→
配音 + 字幕 + 视频

04 · 目标用户与场景

高中教师

快速把抽象概念变成课堂导入视频，让学生课前预习更直观。

知识类 UP 主

批量生成系列短视频，保持日更或周更节奏，不再受素材和剪辑限制。

公益教育团队

为偏远地区制作低成本、高质量的可视化课程，促进教育普惠。

05 · 价值与意义

效率提升

将“知识点 → 成片”的时间从数小时压缩到几分钟，支持批量生成与一键下载 SRT/MP4。

社会价值

降低优质教育视频的制作门槛，让可视化教学资源更容易覆盖到教育资源薄弱地区。

创作价值

AI 不再只是写文案，而是同时担任编剧、动画师和剪辑师，释放人类创造力。

06 · 技术栈

React + Vite + TypeScript + Tailwind 构建的杂志式编辑界面；FastAPI 后端提供 /edu-scripts 教育脚本生成、动画引擎调度与视频合成；Python matplotlib / Pillow 负责把 [动画: ...] 指令渲染为画面片段。
