04 / FEATURES

核心功能

基于「AI 辅助研究」原则，打造完整的量化研究闭环

📊

多数据源集成

自动切换 baostock/AKShare/pytdx 获取 A 股行情、基本面、资金数据，统一 DataFrame 输出，支持代理绕过

🤖

多 Agent 研究团队

新闻分析师、基本面分析师、技术分析师、风控官、研究助理协作，模拟真实基金公司投研流程

⚡

策略插件化框架

策略插件化设计，统一接口：prepare_features → generate_signal → position_sizing → risk_check

🛡️

系统化风控引擎

单票仓位限制、行业集中度、换手率限制、流动性筛选、回撤熔断，全方位保护投资组合

📈

回测验证框架

支持信号回测、权重回测、因子分组回测、Walk-forward 验证，内置简化实现不依赖 VectorBT

📚

层级记忆系统
