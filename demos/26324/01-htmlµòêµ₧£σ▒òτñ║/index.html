CLI 命令体系

完整的命令行操作接口

init

初始化项目，创建必要的配置文件和目录结构

$ ffsmgr init

source add

添加同步源，指定别名和路径

$ ffsmgr source add docs /path/to/docs

source list

列出所有源，支持分页显示

$ ffsmgr source list --limit 10 --page 1

target add

为源添加同步目标

$ ffsmgr target add docs backup /path/to/backup --mode mirror

target list

列出指定源的所有目标

$ ffsmgr target list docs --limit 10

sync target

同步指定源的目标

$ ffsmgr sync target docs backup

sync source

同步源的所有目标

$ ffsmgr sync source docs

sync all

同步所有源的所有目标

$ ffsmgr sync all

核心功能模块

源管理、目标管理、同步执行三大核心

📁 源管理 (Source)

添加、删除、更新、排序、置顶同步源

支持全局包含/排除规则配置

最小同步模式扫描

🗁 目标管理 (Target)

为每个源配置多个同步目标

独立同步模式设置 (two-way/mirror/update)

独立包含/排除规则

♻ 同步执行 (Sync)

调用 FreeFileSync 执行同步

支持单目标/单源/全量同步

退出码映射与结果反馈

⚙ 过滤规则

全局与目标级规则分离

支持增量添加/删除规则

最小同步自动扫描
