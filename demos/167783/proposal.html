📊痛点分析

⏰

忘记服药 / 重复服药

老年慢性病患者需长期规律服药，但因记忆力减退，常出现漏服或重复用药的情况，直接影响治疗效果。

🧱

药箱过期无人清理

家庭药箱中药品长期积压，过期药物未被及时发现和清理，误服过期药品存在安全隐患。

⚠️

多科室开药风险

老人辗转多个科室就诊，可能出现药物相互作用或重复成分，缺乏统一管理的工具来识别风险。

👨‍👩‍👦

子女不在身边无法了解

子女工作繁忙无法每日陪伴，对老人的用药情况缺乏可见性，难以及时发现和干预用药问题。

🛠️解决方案

📱

药品智能录入

支持拍照识别药品名称，自动录入药名、剂量、频次等关键信息，免去手动输入的繁琐操作。

🔔

个性化用药提醒

根据医嘱设定精准的服药时间和频次，通过弹窗、声音等多方式提醒，确保每次服药不遗漏。

📦

家庭药箱管理

统一管理家庭所有药品，实时追踪库存与有效期，过期前主动预警，一键生成清理清单。

📈

用药依从性统计

自动记录每日服药情况，生成可视化统计报表，帮助患者和家属直观了解用药规律与依从率。

👥目标用户

🧑‍❤️‍🧑 老年慢性病患者

需要长期、规律服用多种药物，且记忆力逐渐减退的老年群体，帮助他们建立科学的用药习惯。

👩‍👦 家庭照护者

需要远程了解和监督家中老人用药情况的子女或家属，即使不在身边也能掌握老人的健康动态。

🏥 社区基层医疗机构

负责辖区内慢性病患者管理的社区卫生服务中心，可通过该工具提升患者管理效率和随访质量。

💻技术实现

🌐 单页HTML应用 💾 localStorage 本地存储 📱 响应式移动端优先

技术架构说明

本项目采用纯前端方案，以单个 HTML 文件交付，无需后端服务器和数据库。所有药品数据、用药计划、服药记录均存储在浏览器的 localStorage 中，确保数据隐私安全，同时支持离线使用。

界面采用移动端优先的响应式设计，使用 CSS Grid 和 Flexbox 实现灵活布局，适配手机、平板和桌面多种屏幕尺寸。整体代码轻量，加载迅速，部署方便，可随时分享给需要的家庭使用。
