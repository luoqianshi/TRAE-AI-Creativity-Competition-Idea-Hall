[INFO] PAIN POINT // 为什么会想到做这个

回一封邮件改七遍，
改完还怕语气不对。

收到一封邮件——客户催进度、老板要汇报、同事把锅甩过来、HR 发了 offer 要回复、教授问要不要推荐信——第一反应往往是"这封邮件到底怎么回才得体"。想半天憋不出开头，写完了又怕语气太软或太硬，发了又后悔。

我自己刚工作那年，回一封客户催进度的邮件改了七遍——第一版太卑微显得没底气，第二版太硬怕得罪客户，第三版太啰嗦不像专业回复。后来请教同事才知道，得体邮件的关键不是文笔，而是"对方是谁、我想达到什么效果、用什么语气"这三件事先想清楚，正文自然就出来了。但每次都靠同事把关不现实。

[INFO] HOW IT WORKS // 一条命令，四步出稿

把"写邮件"变成一条命令

填四个字段——收件人身份、邮件大意、想达到的效果、语气偏好——点击运行，终端逐字打印出一封能直接发的草稿，并附语气分析。不满意？一键切换语气重新生成，四种分寸对比着选。

STEP 01

选场景

从六个高频场景里选一个最接近的，自动带出收件人和意图。

STEP 02

填大意

一句话写清邮件核心，可编辑预填的提示。

STEP 03

选语气

正式 / 友好 / 强硬 / 委婉，同封信四种分寸。

STEP 04

出稿

终端逐字打印草稿+语气分析，复制或换语气重生成。

[INFO] VALUE // 价值与意义

把老员工的"邮件分寸感"显性化

EFFICIENCY · 效率提升

把"写一封邮件改七遍"压缩成"填四个字段、十秒出草稿"。省下的是每天被难回邮件卡住的那半小时，把精力还给真正的工作。

SOCIAL · 社会价值

职场沟通的分寸感是隐形能力，决定新人能否快速被信任。这个工具把老员工心照不宣的分寸感显性化成可学习的草稿，让没有前辈带的人也能写出得体邮件。

[INFO] COLOPHON // 创作说明

这个终端，是怎么用 TRAE 跑起来的

我在 TRAE Work 中先把"邮件回复"这件事拆成六个环节：收件人身份 → 邮件大意 → 想达到的效果 → 语气偏好 → 草稿生成 → 语气分析与可调整。先梳理清楚六个高频场景（客户催进度、老板要汇报、同事推锅、拒绝 offer、请求推荐信、请假），每个场景配四种语气（正式/友好/强硬/委婉）共 24 套草稿，把"邮件分寸感"拆解成可复用的结构。

然后用 TRAE IDE 构建了这个科技感暗色终端风格的展示页：整个页面模拟命令行界面，用户像在终端里填参数一样输入收件人、大意、效果、语气，点击生成后，输出区会像终端回显一样逐字打印出一封得体的回复草稿，并附语气分析和切换语气的选项。页面重点演示产品怎么把"写邮件"这件纠结事变成一条命令，而不是只做功能介绍。

后续可在 TRAE 中继续扩展更多场景、多语言草稿和真正的 LLM 接入，让它从模板生成升级成个性化邮件助手。
