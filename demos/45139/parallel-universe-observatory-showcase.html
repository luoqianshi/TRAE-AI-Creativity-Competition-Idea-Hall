生活娱乐 + 平行宇宙天文台

Demo 简介

是什么： 一个以宇宙星空为主题的情感记录与成长陪伴网站
面向谁： 18-35岁年轻群体，追求精神成长、情感表达和自我探索的用户
❤️ 🌟 💭 ⚡ 🙏 🌱 👥 💪 💡
九大行星功能模块
情感星、梦想星、烦恼星、习惯星、感恩星、成长星、社交星、健康星、智慧星，每个行星对应一种人生主题，支持用户记录、管理和回顾。
行星组合系统
502种行星组合，每种组合解锁独特的功能页面（每日镜像、内在小孩对话、习惯星图、感恩花园等），基于种子算法生成稳定且独特的内容。
星灵智能助手
双模式交互（悬浮球 + 星灵殿），支持自然语言对话、语音朗读（小美音色）、深度记忆系统、智能任务管理和数据分析。

Demo 创作思路

灵感来源： 现代人生活节奏快，压力大，需要一个安静的空间来记录内心世界。宇宙星空的神秘与浩瀚能给人带来宁静和力量。
解决痛点： 用户缺乏系统化的自我记录工具；孤独感普遍，缺乏情感陪伴；碎片化信息泛滥，需要专注的沉浸式空间。
方向选择： 生活娱乐赛道聚焦情感疗愈和精神陪伴；社会公益附加赛体现心理健康层面的社会价值。

TRAE 实践过程

1. 项目初始化
使用 TRAE 创建 React + TypeScript + Vite 项目，配置 Tailwind CSS 3 和 React Router 7。
2. 核心功能开发
创建九大行星数据结构和页面组件；实现行星组合算法（502种组合）；开发种子随机算法生成独特功能模块。
3. 星灵 Agent 开发
集成 DeepSeek API 实现 AI 对话；使用 Zustand 管理全局状态；实现语音合成功能（Web Speech API）；开发深度记忆系统、智能任务系统、数据分析模块。
4. 视觉效果优化
使用 Three.js 实现 3D 星空背景；应用玻璃拟态设计风格；添加粒子动画和动态主题色彩。
