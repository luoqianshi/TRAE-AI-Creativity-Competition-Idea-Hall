智能关系管理与可视化图谱平台

运用人工智能与图计算技术，将复杂的人际网络转化为清晰可视的关系图谱，帮助您洞察人脉价值、激活潜在连接、实现关系资产的智能化管理。

核心功能

四大核心能力，重构人脉管理

从关系录入到智能分析，从可视化探索到价值激活，全方位赋能您的人脉资产运营

USERS

关系管理

人物卡片管理（姓名/电话/标签/备注），支持微信、通讯录、CSV批量导入，智能分组（家庭/朋友/同事/其他）。

NETWORK

关系图谱可视化

展示人物关联关系，支持拖拽调整布局，多种视图模式（网络/树形/环形），直观呈现人脉网络结构。

TREE

我的家族树

编辑亲戚信息，采用心理学家谱图表示法，清晰展示世代关系，助力家族文化传承。

NOTE

互动记录

会面、通话、礼物记录，重要日期提醒（生日/纪念日），互动频次统计分析。

进阶功能

深度赋能，超越基础管理

为追求极致体验的用户提供的高级功能模块

LOCK

本地加密存储

AES加密算法保护敏感数据，本地存储确保隐私安全，让您的人脉信息安心无忧。

HEART

关系健康度分析

AI评估关系质量，分析互动频率与深度，提供个性化维护建议，提升关系管理效率。

SYNC

多平台同步

与微信、企业微信双向同步联系人与互动记录，打破信息孤岛，统一管理入口。

GROUP

团队协作

支持家庭、项目组共同编辑关系网，多人协作管理，提升团队人脉资源共享效率。

技术实现

简洁高效的技术方案

专注前端实现，无需复杂后端架构，快速落地核心功能

FRONT

现代化前端框架

React + TypeScript + TailwindCSS，快速构建美观界面，确保代码可维护性。

CHART

关系图谱可视化

ECharts 图可视化库，实现关系网络图、家族树等多种视图展示。

STORE

本地数据存储

IndexedDB 浏览器本地存储，数据保存在用户设备上，安全可靠。
