## 1. 产品概述

"远程守护" 是一款专为异地子女协助家中长辈操控电视而设计的远程交互 Web 应用。用户通过手机浏览器即可远程选择电视品牌、发起带实时字幕的语音通话，并随时调用遥控面板指导长辈完成电视设置与调整，弥合代际数字鸿沟。

- **目标用户**：异地工作的子女（主控端）与家中长辈（被协助端）
- **核心价值**：让科技温度跨越距离，长辈无需理解复杂操作，子女一键远程协助

## 2. 核心功能

### 2.1 用户角色
| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 协助者（子女） | 手机浏览器打开应用 | 选择品牌、发起通话、远程遥控、字幕管理 |
| 被协助者（长辈） | 接听通话、查看大字字幕 | 接听语音、查看字幕、确认操作 |

### 2.2 功能模块
1. **首页控制台**：连接状态、快捷入口、最近协助记录
2. **电视品牌选择页**：品牌网格、型号匹配、连接配对
3. **远程遥控台**：虚拟遥控器、方向键、菜单导航、快捷键
4. **语音通话字幕页**：实时语音通话、双向字幕显示、字号调节

## 3. 核心流程

**主流程**：用户打开应用 → 选择家中电视品牌 → 系统匹配型号并发起配对 → 配对成功进入遥控台 → 一键发起语音通话 → 通话中实时显示字幕 → 通过遥控器指导长辈操作 → 完成协助挂断通话。

    "D --> E[选择电视品牌]"
    "E --> F[匹配型号并配对]"
    "F --> G[配对成功]"
    "C -- 是 --> G"
    "G --> H[进入远程遥控台]"

    "K --> L[完成协助挂断]"
    "L --> M[返回首页记录协助]"

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：暖琥珀色 `#E8743C`（关怀温暖）+ 深墨蓝 `#1A2332`（科技沉稳）+ 米白 `#FAF6F0`（柔和背景）
- **辅助色**：薄荷绿 `#4ECDC4`（成功/在线）、暖红 `#E63946`（挂断/警示）
- **按钮风格**：大圆角（16px）、立体投影、按压反馈动效，便于长辈识别
- **字体**：标题用 "Noto Serif SC"（思源宋体，传递稳重温度），正文用 "Noto Sans SC"（思源黑体，清晰易读）
- **字号**：基础字号 18px，长辈模式可放大至 24px，按钮文字 20px+
- **布局**：移动优先的单列卡片布局，底部固定导航栏，拇指友好区域放置主操作
- **图标**：线性 + 圆角填充混合图标，搭配语义化文字标签

### 4.3 响应式设计
- **移动优先**：以手机竖屏 375px 为基准设计，最大宽度 480px 居中
- **平板适配**：768px 以上切换为双栏布局，遥控器与字幕并排
- **触控优化**：所有可点击元素最小 48×48px，间距 ≥ 8px，支持长按、滑动
- **长辈模式**：全局字号放大 1.3 倍，对比度增强，简化动画

### 4.4 3D 场景指引（不适用）
本项目以 2D 界面为主，不涉及 3D 场景。
