创意名称 + 创意介绍
Creative Introduction

想解决什么问题

上班族和学生党长时间使用电脑和手机，颈部酸痛僵硬成为普遍问题，但用户往往缺乏简单有效的活动方式——去健身房太费时间，做颈椎操又枯燥无聊，想活动又不知道该怎么动。

为什么会想到做这个

我自己长时间使用电脑和手机，每次用久了都会脖子疼。我发现市面上现有的解决方案要么太复杂（下载运动 APP、去健身房），要么太枯燥（看视频学颈椎操）。

同时我在做一个头部体感射击游戏"雷霆战机"时惊喜地发现：玩完一局脖子竟然不疼了——于是我意识到：

如果能用游戏的方式驱动用户活动颈部，把"运动"变成"玩游戏的副产品"，那将是一种全新的、让人乐于接受的健康方案。

大概是什么产品

一个轻量级的网页互动游戏平台。用户通过浏览器打开链接即可游玩（无需下载、无需注册），平台利用浏览器端 AI 技术（MediaPipe）实时识别用户的头部动作和面部表情，驱动多款体感小游戏，让用户在游戏中自然活动颈部，缓解颈椎疲劳。

目标用户及痛点
Target Users & Pain Points

面向哪些用户

👔 办公室白领
每天面对电脑 8 小时以上，经常肩颈酸痛。工作间隙想活动一下，但不知道怎么动。
📚 学生党
长时间低头看书、用手机学习。课间休息想玩点什么，但又希望同时对身体好。
📱 重度手机用户
刷视频、打手游，经常一低头几小时。想放松脖子，但又想同时"玩"点什么。
👴 银发群体
居家时间多、久坐少动。希望有简单、无压力的活动方式，不需要学习复杂操作。

用户的核心诉求

「我不想做健身，但我想做游戏。如果游戏恰好能让我活动脖子，那就太好了。」

在什么场景下使用

序号 使用场景 使用方式
1 💼 工作间隙 工作 1 小时后，花 2-3 分钟玩一局，活动脖子
2 📖 课间休息 学生课间玩一两局，代替枯燥的课间操
3 📱 刷手机疲劳期 手机刷久了脖子疼，打开活动一下
4 🏠 居家休闲 晚上不想做重度运动，但想活动一下
5 👥 团队破冰 公司群 / 同学群分享链接，大家一起玩、比分数

当前痛点（如果没有这个产品）

  • 颈椎酸痛但不知道该做什么动作，不知道哪些动作有效
  • 健身/运动 APP 需要下载、注册、学习使用，门槛太高
  • 颈椎操视频枯燥乏味，靠意志力坚持，难成习惯
  • 想去活动身体，但又想同时"玩"点什么——两者难以兼顾
  • 体感游戏需要专业设备（VR 眼镜、游戏主机），成本高、使用场景受限
  • 长期忍着疼痛不处理，可能发展成慢性颈椎问题，影响生活质量

价值与意义
Value & Meaning

🎯 社会价值

维度 说明
健康干预 针对越来越普遍的颈椎健康问题，提供一种随时随地可用的轻量级解决方案。中国颈椎问题人群已达约 2 亿人，且呈年轻化趋势。
行为习惯改变 把"运动 / 活动颈部"这件需要意志力的事，变成了"我想玩游戏"这件自发的事。用游戏化的方式降低健康行为的启动门槛。
全民可及 纯网页方案，不需要任何付费硬件，打开链接即可使用。无论是办公室白领、学生还是老人，都可以零门槛使用。
隐私友好 所有 AI 识别在用户的浏览器本地运行，视频画面不会上传到任何服务器，保护用户隐私。

维度 说明
使用效率 "打开 → 允许摄像头 → 玩"三步搞定，每局 60-90 秒，不占用大量工作/学习时间。
制作效率 基于一个核心能力（头部坐标识别）可以持续扩展多款游戏，每款游戏对应一种颈部活动方式。
传播效率 链接即产品，用户可以一键分享给同事、朋友，健康活动变成社交话题。

用户操作流程
User Flow
用户打开链接（微信 / 浏览器输入网址） ↓ 浏览器询问「是否允许使用摄像头？」 ↓ 用户点击「允许」 ↓ 进入主页：看到多款小游戏（卡片式列表） ↓ 用户选择一个游戏（如「雷霆战机」） ↓ 进入游戏 → 人脸自动识别 → 开始游戏 ↓ 约 60-90 秒 → 游戏结束 ↓ 显示本局得分 + 活动记录（「你活动了脖子 X 次！」） ↓ 继续玩其他游戏 / 分享给朋友

整体架构

┌──────────────────────────────────────┐ │ 前端（用户浏览器） │ │ ┌─────────────────────────────────┐ │ │ │ HTML5 页面 + CSS（界面） │ │ │ │ ───────────────────────────── │ │ │ │ MediaPipe Face Mesh（人脸 AI）│ │ │ │ └→ 提取 468 个面部特征点 │ │ │ │ └→ 实时坐标 → 驱动游戏 │ │ │ └─────────────────────────────────┘ │ └────────────────────────┬─────────────┘ │ ▼ ┌─────────────────────────┐ │ 后端（轻量级数据存储）│ │ · 游戏排行榜 │ │ · 用户活动记录 │ │ · 共享挑战码 │ └─────────────────────────┘

技术选型

模块 技术 说明
前端 HTML5 + CSS + JavaScript 纯静态页面，加载快，浏览器兼容好
AI 识别 Google MediaPipe Face Mesh 浏览器端运行，不上传视频，保护隐私
摄像头 WebRTC API（浏览器原生） HTTPS 环境下可获取摄像头权限
数据库 JSONbin.io / Firebase 免费额度充足，存储排行榜和活动数据
部署 Netlify Drop / GitHub Pages 静态托管，免费且全球可用
