1. 创意名称 + 创意介绍

创意名称：知言（AIChatHub）—— Android 端多 AI 智能聊天客户端

一句话介绍：一款原生 Android 应用，统一接入 8 套国内外主流 AI 服务商，把"聊天"这件事做到本地化、可定制、可保护隐私。

核心功能（全部已上线，v1.3.8）

多服务商统一接入
内置 OpenAI / DeepSeek / 通义 / 智谱 / 豆包 / Kimi / Claude / Gemini 共 8 套默认配置，统一遵循 OpenAI Chat Completions 协议，任意兼容协议可"添加服务商"接入。
多会话 + 系统提示词
每个会话可锁定不同服务商 + 模型 + system prompt；内置 6 套预设（翻译 / 代码 / 文案 / 总结 / 面试 / 导师）。
角色管理（Persona）
可创建 / 编辑 / 删除自定义角色，选中后自动作为 system prompt 注入；分类支持伴侣 / 导师 / 故事 / 其他。
角色记忆（Memory）
从对话中自动抽取 4 类记忆（事实 / 偏好 / 关系 / 事件），可手工新增；支持「仅本对话」与「跨会话」两种作用域。
多模态输入
支持图片附件，自动转 Base64 dataURL 走 OpenAI 协议转发；Markdown 内嵌图片。
语音输入 + TTS 朗读
基于系统 SpeechRecognizer + TextToSpeech，可在设置中调节语速 / 音调 / 自动朗读。
Markdown 渲染
代码块、标题、粗体、斜体、行内代码、有序 / 无序列表，纯 Compose Text 渲染（不走 WebView）。
会话管理
置顶、标签筛选与编辑、多选批量删除、消息引用回复、消息收藏夹、消息搜索。
导出与分享
支持导出 PDF 文档 与 Markdown 文本 两种格式，一键分享到其他 App（PDF 走 FileProvider 授权）。
AI 主动消息
可按计划让 AI 主动给用户发消息，配合前台保活服务 + 系统通知。
朋友圈（Moments）
可发布图文动态，支持评论 / 回复 / 删除；AI 角色也会自动评论（v1.3.9）。
夜间免打扰
可设置时间窗口（默认 22:00–08:00，跨午夜），期间 AI 不主动推送消息。
加密 + 本地化
API Key 走 EncryptedSharedPreferences（AES-256 GCM）；备份走 PBKDF2 + AES-GCM；禁止云备份与设备迁移。
用量统计
会话数 / 消息数 / 总 token（输入 + 输出分别统计）/ 总字符 / Top 5 会话 / Top 5 服务商·模型 / 近 7 日趋势 / 缓存命中率。
Material 3 Expressive 主题
动态取色（Android 12+）、明暗模式、自定义主题色、字体大小缩放（4 档）、Edge-to-Edge。
安全审计
v1.3.8 已通过 VULN-001 ~ 008 共 8 项审查 + 5 项防御纵深改进（TLS / KDF / 密钥清零 / 协程 / 日志等）。
运行环境检测
检测 Root / Magisk / Frida / Xposed，设置页有"安全状态卡"提示。

技术栈

Kotlin 2.0 Jetpack Compose Material 3 Hilt Room Retrofit / OkHttp Kotlinx Serialization Coroutines / Flow

适配：minSdk 28（Android 9.0）~ targetSdk 36（Android 16）

2. 目标用户及痛点

目标用户

  • 同时使用多个 AI 服务、需要统一管理 API Key 的开发者 / 产品经理 / 研究者
  • 想让 AI 长期"保持同一个人格"并记住自己偏好的重度聊天用户
  • 重视数据隐私、希望所有对话都留在本机、不依赖云账号的安全敏感用户
  • 喜欢自定义 system prompt、把 AI 调成"专属翻译 / 文案 / 编程 / 面试官"的进阶用户

当前痛点

  • Web 端各 AI 服务商账号分散、对话历史无法统一管理、API Key 常以明文保存在浏览器
  • 想让 AI"记住"用户信息，每次新会话都要手动复制粘贴一长串人设
  • 多模态在 Web 端体验割裂；语音输入 / TTS 朗读需要额外的网页或工具
  • 移动端缺少一款"全功能 + 可定制 + 数据不外流"的 AI 聊天客户端
  • 用国外 App 担心对话被收集；用国内 App 担心风格单一、无法切换多模型

3. 价值与意义

  • 效率提升：把"分散的 AI 服务 + 散落的聊天记录 + 重复写的 system prompt"统一到一个本地 App，切换服务商只改一次配置，跨会话自动复用记忆，省掉每次新对话的人设粘贴。
  • 隐私保护：API Key AES-256 GCM 加密、备份 PBKDF2 + AES-GCM、allowBackup=false、network_security_config 默认禁明文，所有数据留在本机，满足对数据敏感的个体开发者与重度用户。
  • 创作增强：可创建多个 Persona，配合自动记忆、引用回复、消息收藏、PDF / Markdown 导出，让 AI 真正成为"长期陪聊的某个角色"，而不是"每次都从零开始"的一次性对话。
  • 可扩展：完全遵循 OpenAI Chat Completions 协议，自带 8 个国内 / 国外主流服务商；任何兼容协议（自建网关 / 零一万物 / 企业中转）"添加服务商"即可接入；服务商可启用 / 停用，删除后会话卡片友好提示"服务商 XXX（已删除）"。
  • 作者理念：开源（MIT），技术栈与 AI 协议完全开放，欢迎社区贡献新服务商、新协议、新场景。
