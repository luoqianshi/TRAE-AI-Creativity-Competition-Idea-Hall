目标用户

谁需要 SearchAnything？

从个人用户到企业团队，从知识工作者到 AI 开发者——任何被"找不到文件"困扰的人。

知识工作者 / 文档管理者

电脑上有大量 Word、Excel、PPT、PDF 文档，经常需要根据内容关键词找到某个文件，而不是只靠文件名。

痛点："我记得文档里写过这段话，但死活找不到是哪个文件。"——文件名记不住，内容又搜不了。

媒体内容创作者

积累了大量视频素材、音频录音、设计文件，需要通过语音内容或画面中的人脸快速定位素材。

痛点："这段话是哪个视频里说的？"——音视频完全没有文字索引，只能一个个播放试听。

AI 应用开发者

开发 AI Agent / RAG 系统时，需要让 AI 能够高效检索本地电脑上的各种语义内容，作为知识库基础套件。

痛点：用 rg.exe 搜不了 PDF 内容，扫描版 PDF 完全无能为力，音视频更是盲区，文件夹一大就慢得不可用。

普通电脑用户（含老旧设备）

家用电脑上照片、视频、文档堆积如山，想找一张旧照片里的人、一段录音里的话，但电脑配置不高甚至没有独立显卡。

痛点："照片太多找不到人""录音太长不想听"——但电脑老旧跑不动大型 AI 工具，需要轻量级方案。

核心能力

一个工具，搜索所有内容类型

从文件名到文件内容，从图片文字到语音对话，从压缩包到设计文件——全覆盖。

全文内容搜索

Word / Excel / PPT / PDF / Markdown / 纯文本，支持中文分词、拼音搜索、正则匹配。

图片 OCR 识别

PaddleOCR PP-OCRv6 引擎，识别图片、扫描版 PDF、Office 内嵌图片中的文字。

跨媒体人脸搜索

YuNet + ArcFace 人脸识别，在图片、视频帧、PDF、Office 文档中按人脸搜索。

音视频语音搜索

本地 Moonshine 语音转写引擎，将音频/视频中的语音转为文字并索引，搜话即搜音视频。

压缩包内容索引

ZIP / 7Z / RAR / TAR 等格式，虚拟路径索引包内文件，无需解压即可搜索。

极速 NTFS 扫描

Windows NTFS USN Journal 技术，全盘文件秒级枚举，增量更新仅处理变更文件。
