01 / 创意介绍

为什么想到做这个？

在办公室或学习环境中，很多人喜欢边听音乐边工作，但传统音乐播放器的界面往往过于醒目和复杂——大大的窗口、花哨的皮肤、各种推荐和评论，不仅容易吸引周围人的注意，也会分散自己的工作注意力。

迷你音乐播放器就是为了解决这个痛点而生：一个极简的悬浮小窗，安静地待在屏幕角落，既能随时控制播放，又不会引起注意。多音源聚合搜索，一个应用听遍全网音乐。

02 / 核心功能

小而强大的功能设计

🪟

极简悬浮窗

仅 320×110 像素的迷你窗口，始终置顶，可随意拖动到屏幕任意角落，透明边框设计低调不突兀。

🔍

多音源搜索

支持网易云音乐、QQ音乐、酷狗音乐、B站音频四大平台，一次搜索多平台结果，再也不用来回切换App。

📥

系统托盘

支持最小化到系统托盘，完全不占用任务栏空间，右键菜单快捷控制播放/暂停/上一首/下一首。

🌐

网络状态指示

实时显示网络连接状态（绿色在线/红色离线），不用等到搜索失败才发现网络有问题。

🔁

单曲循环

一键开启单曲循环模式，遇到喜欢的歌可以无限循环播放，适合工作时的背景音需求。

🎯

跳过任务栏

窗口不出现在任务栏中，Alt+Tab 切换窗口时也不会显示，真正做到低调使用。

03 / 痛点分析

传统音乐播放器窗口大、功能多，在办公室打开容易被老板或同事看到，影响不好。

工作时任务栏已经堆满了窗口，音乐播放器还要占一个位置，切换起来眼花缭乱。

🎭

推荐、评论、社区、直播……各种功能让人分心，本来只想听歌，结果刷了半小时。

06 / 技术方案

基于 Electron 的跨平台实现

采用 Electron 框架开发，一套代码可打包为 Windows / macOS / Linux 多平台应用。 通过本地代理服务器解决音乐平台防盗链问题，确保音频流畅播放。

Electron Node.js 原生 JavaScript HTML5 Audio 本地 HTTP 代理 IPC 通信 系统托盘集成 多音源 API 聚合
