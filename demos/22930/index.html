SCENARIOS

适用场景

无论是在哪个平台、哪种直播形式，CaptGuard 都能无缝融入你的工作流。

🖥️

个人电脑直播

在 OBS / 抖音直播伴侣 / B站直播姬中新建文本源，指向 CaptGuard 输出的字幕文件，即可实时显示字幕。

🎙️

多人对谈 / 连麦

支持多路音频输入，分别识别并标注发言人，自动过滤所有声道中的敏感词，适合圆桌讨论类节目。

🎬

录播后期 / 内容复盘

所有字幕自动存入 SQLite 数据库，直播结束后可导出为 SRT / TXT，直接用于剪辑或内容分析。

FEATURES

核心功能

聚焦「语音→字幕→净化→输出」这条链路，每个环节做到极致。

🎤

实时语音识别

基于本地或云端 ASR 引擎，将麦克风 / 系统音频实时转写为文字，延迟控制在 1 秒以内。

支持 普通话 / 英语
🔇

智能脏话屏蔽

内置敏感词库，匹配结果自动替换为「哔—」或「***」，支持用户通过 YAML 自定义词库，区分严格 / 宽松模式。

自定义词库
🔌

OBS / 直播软件 一键对接

字幕通过「文件输出 + 文本源」或「WebSocket 实时推送」两种方式送入 OBS，无需插件，即配即用。

零插件
⚙️

YAML 配置系统

所有设置（音频源、识别引擎、词库路径、字幕样式、输出方式）集中在一个 YAML 文件中，改配置即改行为。

config.yaml
💾

SQLite 历史记录

每句字幕自动附带时间戳存入本地数据库，支持按时间、关键词搜索回看，导出为 SRT / CSV / JSON。

导出 SRT
🖥️

桌面 GUI 界面

基于 Python 原生 GUI 框架，提供简洁的控制面板：开始/停止、实时字幕预览、词库管理、历史查询，无需记忆命令。
