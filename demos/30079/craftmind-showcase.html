Pain Points

想解决什么问题？

Minecraft 是一款自由度极高的沙盒游戏，但「自由」也意味着玩家需要承担大量重复性劳动——挖矿、建造、采集、合成…… 当你想要一个能在游戏里真正「陪伴」你的 AI 时，现有的解决方案都存在致命缺陷：

🤖

现有 Bot 只会「执行脚本」

传统 Minecraft Bot 只能按预设流程跑，遇到突发情况（被怪攻击、背包满了、掉进岩浆）就卡死或崩溃。

🧠

AI 不懂「游戏常识」

通用 LLM 调用工具时不知道岩浆会烧死自己、不知道晚上要躲起来、不知道饥饿值低要吃食物——缺乏生存本能。

💬

自动游玩时「失联」

AI 在执行任务时完全无视玩家的消息，像消失了一样。玩家说话它不回，体验极差。

🔄

长时间运行必崩

内存泄漏、事件监听器堆积、conversationHistory 无限膨胀……运行超过 30 分钟基本都会出问题。

Inspiration

为什么会想到做这个？

灵感来源于一个简单的想法：如果 AI 能像一个真正的「游戏伙伴」那样在 Minecraft 里和你一起玩呢？

// THE VISION
「不是工具，是伙伴」

我希望打造的不是一个冷冰冰的自动化脚本，而是一个有记忆、有性格、懂生存规则、 能和玩家自然对话的 AI 实体。它会观察环境、制定计划、执行任务， 同时在你需要的时候立刻回应你的消息。它能独立通关生存模式， 也能配合你一起建房子、探险、战斗。

  • Hermes 冻结快照架构 — 会话期间保持系统提示稳定，LLM 缓存命中率最大化
  • RAG 记忆检索引擎 — ONNX Embedding 驱动的长期记忆检索，记得你说过的一切
  • Plan-Execute 计划模式 — LLM 一次性规划多步操作，批量执行减少 API 调用
  • 依赖感知快速失败 — 材料不足时自动跳过后续无效操作，不浪费时间
  • 五层纵深防御体系 — 并发保护 / 原子锁 / 频率限制 / 资源节流 / 断线恢复
Product

大概是什么产品？

一款基于 Electron + Mineflayer + LLM 的桌面端智能伴侣应用（Windows）， 用户通过可视化界面连接 Minecraft 服务器，AI 以游戏内实体的形式存在并自主行动。

🖥️

桌面应用 (Electron)

原生 Windows 桌面客户端，包含配置面板、日志面板、连接管理器。打包为单文件 exe，双击即用。

🎮

Minecraft Bot (Mineflayer)

以真实玩家身份进入服务器，能看到周围环境、能移动/挖掘/放置/攻击/合成，与普通玩家无异。

⚡

AI 大脑 (LLM)

支持 OpenAI 兼容 API，通过 Tool Calling 机制让 LLM 自主决策调用游戏操作工具，实现 ReAct 循环推理。

📚

知识 & 记忆 (RAG)

内置 Minecraft 生存指南知识库 + ONNX Embedding 长期记忆检索，AI 有「经验」也有「回忆」。
