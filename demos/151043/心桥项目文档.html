第一部分：用户测评得分公式

1. PHQ-9 抑郁筛查量表

PHQ-9（Patient Health Questionnaire-9）由美国哥伦比亚大学研制，用于评估受测者过去两周内的抑郁症状频率，是目前国际公认的高效抑郁筛查工具。

评分规则：共9道题目，每题0-3分。0=完全没有，1=几天，2=一半以上天数，3=几乎每天。总分 = 各题得分之和，范围0-27分。

9道题目：

  1. 做事时提不起劲或没有兴趣
  2. 感到心情低落、沮丧或绝望
  3. 入睡困难、睡不安稳或睡眠过多
  4. 感觉疲倦或没有活力
  5. 食欲不振或吃太多
  6. 觉得自己很糟，或觉得自己很失败，或让自己和家人失望
  7. 对事物专注有困难，例如看报纸或看电视
  8. 动作或说话速度缓慢到别人可以察觉，或正好相反——变得躁动不安
  9. 有不如死掉或用某种方式伤害自己的念头

评分标准：

0-4分无明显抑郁症状
5-9分轻度抑郁（建议心理调节）
10-14分中度抑郁（需专业评估）
15-19分中重度抑郁（建议就医）
20-27分重度抑郁（需立即干预）

2. GAD-7 焦虑筛查量表

GAD-7（Generalized Anxiety Disorder-7）是国际广泛使用的焦虑筛查工具，具有良好的信度和效度。

评分规则：共7道题目，每题0-3分（同PHQ-9评分方式：0=完全没有，1=几天，2=一半以上天数，3=几乎每天）。总分 = 各题得分之和，范围0-21分。

7道题目：

  1. 感到紧张、焦虑或烦躁
  2. 不能停止或控制担忧
  3. 对各种事情过度担忧
  4. 难以放松下来
  5. 容易感到疲劳
  6. 出现坐立不安、来回走动的情况
  7. 感到害怕，好像有可怕的事情要发生

评分标准：

0-4分无明显焦虑
5-9分轻度焦虑（需重视自我调节）
10-14分中度焦虑（建议专业干预）
15-21分重度焦虑（强烈建议就医）

3. 心桥综合测评公式（本项目原创）

本项目在PHQ-9和GAD-7的基础上，增加了"厌学指数"维度，以更全面地评估青少年心理健康状态。三个维度通过加权公式整合为一个综合得分。

综合得分计算公式 综合得分 = PHQ-9得分 × 0.4 + GAD-7得分 × 0.3 + 厌学指数 × 0.3

厌学指数：自定义3道题目，每题0-3分（评分方式同PHQ-9），总分范围0-9分。

  1. 过去两周，有多少天你觉得去上学是一件痛苦的事？
  2. 过去两周，有多少天你在学校无法集中注意力？
  3. 过去两周，有多少天你完成作业感到非常困难或完全不想做？

厌学指数评分标准：

0-3分正常
4-6分轻度厌学
7-9分严重厌学

综合得分范围0-18分，分级标准：

0-3分心理健康状态良好，建议日常关注
4-7分轻度困扰，建议使用平台自助工具调节
8-11分中度困扰，推荐AI深度干预 + 家长端指导
12-18分需要关注，建议转介专业心理咨询

根据综合得分推荐干预模块：

综合得分 推荐模式 说明
低分（0-3） 每日心情记录 以情绪日记为主，持续追踪心理状态变化
中分（4-7） AI对话疏导 通过AI模拟对话，引导情绪表达与自我调节
中高分（8-11） CBT认知行为练习 使用控辩方技术等CBT核心方法进行认知重构
高分（12-18） 建议寻求专业帮助 展示心理援助热线信息，引导用户寻求专业支持

第二部分：干预方法论

1. 认知行为疗法（CBT）

认知行为疗法（Cognitive Behavioral Therapy）是心桥平台的核心干预方法论。其核心理念为：认知是引发情绪和行为的内在原因，两个核心干预点是"改变认知"和"改变行为"。

CBT咨询结构：

开始环节
→
中间环节
→
结束环节
  • 开始环节：获取最新信息、心情评估、议程设置
  • 中间环节：概念化、心理教育、CBT干预
  • 结束环节：回顾总结、反馈、布置练习

关键技术详解：

控辩方技术
让孩子列出支持消极想法的证据（反方证据）和反对消极想法的证据（正方证据），通过正反对比实现认知重构。
孩子觉得"上学没意思"。反方证据（没意思）：成天坐在教室不能聊天，老师课听不懂。正方证据（有意思）：能跟好朋友聊天，有好玩的体育运动，有好吃的午餐。认知重构结果："上学有有意思的地方"。
接纳策略
带着症状去生活，不追求完全消除不适感，鼓励在有限条件下积极行动。
孩子说头痛不想上学，策略是"即使不舒服也鼓励去学校，哪怕只上第2节第3节课"。
替代策略
用更合适的、更安全的行为替代不良行为，提供可执行的行为方案。
跟父母争吵时想摔东西，引导离开现场到别的地方去，做深呼吸或短暂散步。
降低策略
逐步减少问题行为的发生频率或时长，配合正向激励，避免"一刀切"式的禁止。
沉迷手机游戏，从每天6小时逐步降到5小时、4小时，配合激励措施。
合作策略
降低预期要求，能做多少做多少，减少因完不成任务而产生的挫败感和抗拒心理。
孩子拒绝完成课堂练习，协商改为"能做多少就做多少"。
沟通协商
引导双方互相倾听，表达各自想法和需求，通过协商达成一致的解决方案。
与同学发生冲突，聊清楚各自的想法和感受，达成双方都能接受的约定。

2. 情绪聚焦疗法（EFT）

情绪聚焦疗法（Emotion-Focused Therapy）在本项目中与CBT配合使用，旨在重新编码"情绪-行为回路"。当青少年陷入固定的负面情绪与行为循环时，EFT帮助他们识别并打破这一模式。

核心步骤：

识别情绪
→
接纳情绪
→
表达情绪
→
调节情绪

3. 正念放松训练

正念放松训练用于急性情绪调节，帮助青少年在焦虑或冲动发作时快速恢复平静。平台内置以下练习引导：

  • 呼吸练习：4-7-8呼吸法——吸气4秒，屏气7秒，呼气8秒。循环3-5次可有效降低心率和焦虑感。
  • 身体扫描：从头到脚逐步关注身体各部位的感觉，察觉紧张区域并有意放松，每次约10-15分钟。
  • 适用场景：急性情绪调节，减少焦虑和冲动行为，改善睡眠质量。

4. 家庭系统干预

青少年的心理问题往往与家庭系统密切相关。心桥平台在面向学生端的同时，也为家长端提供指导信息：

  • 家长沟通技巧培训：教授积极倾听、非评判性回应、共情表达等核心沟通技能，帮助家长建立与孩子之间的信任关系。
  • 亲子关系修复指导：针对家庭矛盾提供修复性沟通策略，帮助理解孩子的情绪需求。
  • 家庭作业协作机制：建立合理的期望与激励机制，避免因学业压力加剧亲子冲突。

第三部分：Demo开发方案与代码解释

1. 技术方案

项目方案
技术栈HTML + CSS + JavaScript（纯前端单文件）
数据存储浏览器 localStorage
部署方式零门槛，评委打开浏览器即可体验，无需服务器

选择纯前端方案的理由：初赛Demo的核心目标是"能运行、能体验"。纯前端方案零部署成本，评委只需打开HTML文件即可在浏览器中直接体验全部功能，最符合大赛评审的便捷性要求。

2. 页面结构（4个核心页面）

采用Tab/路由切换方式实现单页应用（SPA），4个核心页面如下：

首页
温暖治愈的视觉设计，展示平台名称"心桥"，设置"开始测评"入口按钮，底部附简短项目介绍，营造安全、可信赖的第一印象。
测评页
展示PHQ-9简化版（选取核心5题）+ GAD-7简化版（选取核心3题）+ 厌学指数（3题），共计11题。每题提供4个选项单选。用户提交后系统自动计算综合得分并展示分级结果。
干预页
根据测评得分动态推荐不同内容：
低分（0-3）→ 情绪日记记录界面，用于日常心情追踪；
中分（4-7）→ AI对话界面，使用预设关键词匹配进行疏导回复；
中高分（8-11）→ CBT练习卡片，包含控辩方技术交互式练习；
高分（12-18）→ 显示"建议寻求专业帮助"提示页，提供心理援助热线信息。
报告页
展示历次测评得分、情绪变化趋势图（基于模拟数据）、个性化建议，帮助用户直观了解自身心理状态的变化轨迹。

3. 核心代码逻辑解释

（1）测评得分计算函数

遍历所有题目的选中选项，将各选项对应的分值累加，得到PHQ-9得分、GAD-7得分和厌学指数，然后应用综合公式计算最终得分：

function calculateScore() { let phqScore = 0, gadScore = 0, burnoutScore = 0; // 遍历PHQ-9题目（共5题简化版） for (let i = 1; i <= 5; i++) { phqScore += getSelectedValue('phq_' + i); } // 遍历GAD-7题目（共3题简化版） for (let i = 1; i <= 3; i++) { gadScore += getSelectedValue('gad_' + i); } // 遍历厌学指数题目（共3题） for (let i = 1; i <= 3; i++) { burnoutScore += getSelectedValue('burnout_' + i); } // 应用综合测评公式 let total = phqScore * 0.4 + gadScore * 0.3 + burnoutScore * 0.3; return { phqScore, gadScore, burnoutScore, total }; }

（2）AI对话模拟逻辑

基于关键词匹配规则，对用户输入进行语义匹配并返回相应回复。高危关键词触发紧急求助提示：

function getAIResponse(userInput) { const text = userInput.toLowerCase(); // 高危关键词：立即显示求助热线 const dangerWords = ['不想活', '死', '自杀', '伤害自己']; if (dangerWords.some(w => text.includes(w))) { return '我注意到你正在经历非常艰难的时刻。' + '请立即拨打心理援助热线：全国24小时心理危机干预热线 400-161-9995'; } // 情绪类关键词：返回接纳与共情回复 if (text.includes('烦') || text.includes('难过') || text.includes('哭')) { return '我能感受到你现在很不舒服，这种情绪是很正常的。' + '你能试着告诉我，是什么事情让你感到烦恼吗？'; } // 学业类关键词：返回厌学相关回复 if (text.includes('学') || text.includes('作业') || text.includes('考试')) { return '听起来学业方面给你带来了不小的压力。' + '我们可以一起看看，有没有什么方法能让学习变得轻松一点？'; } // 默认回复 return '谢谢你愿意和我分享。你能再多说一些吗？'; }

（3）CBT控辩方练习逻辑

展示一个消极想法，用户分别填写"不好的证据"和"好的证据"，系统整合后生成认知重构建议：

function generateReframe(negativeThought, badEvidence, goodEvidence) { let suggestion = ''; // 如果正方证据数量充足，生成积极重构 if (goodEvidence.trim().length > 0) { suggestion = '你找到了一些支持积极想法的证据：' + goodEvidence + '。这说明 "' + negativeThought + '" 并不是全部事实。' + '一个更平衡的看法可能是："' + negativeThought + '，但也有好的方面。"'; } else { suggestion = '目前还不太容易找到积极的证据，这完全没关系。' + '我们可以试着换个角度看问题，或者做一些让你开心的小事。'; } return suggestion; }

（4）数据持久化

每次测评完成后，将结果（含时间戳、各维度得分、综合得分）存入 localStorage。报告页从 localStorage 中读取历史数据，展示得分趋势变化：

// 保存测评结果 function saveResult(result) { const history = JSON.parse(localStorage.getItem('xinqiao_history') || '[]'); history.push({ date: new Date().toISOString(), phq: result.phqScore, gad: result.gadScore, burnout: result.burnoutScore, total: result.total }); localStorage.setItem('xinqiao_history', JSON.stringify(history)); } // 读取历史数据 function getHistory() { return JSON.parse(localStorage.getItem('xinqiao_history') || '[]'); }

第四部分：常见问题与解答（Q&A）

Q1：这个平台能替代专业心理咨询吗？
不能。心桥定位为"第一道心理支持防线"，用于早期筛查和轻度困扰的自我调节。中重度心理问题必须转介专业心理咨询师或精神科医生。平台会在高危情况下（如检测到自伤、自杀相关关键词）明确提示用户寻求专业帮助，并提供心理援助热线号码。
Q2：AI对话的回复是预设的还是真正的大模型？
Demo阶段使用关键词匹配的预设回复来演示交互逻辑。这种方案确保了回复的安全性和可控性，适合作为概念验证。复赛阶段计划接入大语言模型API，实现更自然、更智能的对话体验，同时保留安全关键词拦截机制。
Q3：如何保护用户隐私？
所有数据存储在用户本地浏览器的 localStorage 中，不上传到任何服务器。这意味着数据完全由用户掌控，不存在集中化的数据泄露风险。家长端只显示匿名化的建议信息，不暴露孩子的具体对话内容，充分保护青少年隐私。
Q4：测评量表的科学依据是什么？
PHQ-9和GAD-7是国际公认的标准化心理筛查工具，已在全球范围内的临床实践和学术研究中得到广泛验证和应用。厌学指数为项目原创设计，参考了CBT咨询实践中的评估框架，旨在补充标准量表对学业适应维度的覆盖。
Q5：为什么选择纯前端方案？
初赛Demo的核心目标是"能运行、能体验"。纯前端方案零部署成本，不需要服务器、数据库或后端框架，评委只需打开HTML文件即可在浏览器中直接体验全部功能。这一方案最符合大赛评审的便捷性要求，也最大程度降低了技术故障的风险。
