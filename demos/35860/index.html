缘昔 01 / 初心

不是普通日记。
是以后还能回来的
某一天。

选择一个日期，记下一件具体的事。等时间走远，再从同一天回到当时的心情、文字和照片。

三种视角 02 / 功能
01

首页

看见今天，快速写下今天，也让“过去的今天”和最近记录自然回到眼前。

今天 / 过去的今天 / 最近记录
02

日历

在月份之间移动，选择任意日期。有记录的日子带小点，今天用圆角描边标记。

月份切换 / 日期选择 / 记录标记
03

记录

写下一件具体的事，选择此刻的心情，留一张照片。随时保存、修改或删除。

文字 / 心情 / 单张照片
一次记录 03 / 路径

三步，把今天留住。

  1. 01选择一天

    今天，或日历里的任何一天。

  2. 02记录一件事

    具体到一句话，也已经足够。

  3. 03以后再回来

    从同一个日期重新遇见当时。

安静地保存 04 / 隐私

记忆只留在
你的手机里。

01不需要账号

02不连接云端

03不发起网络请求

04数据保存在本机

让记忆更长久 06 / 下一步

接下来，可以慢慢加入。

  • 01数据导出

    让记忆可以被带走和长期保管。

  • 02多张照片

    一件事不必只留下一个画面。

  • 03搜索

    从人、地点和一句话里找到过去。

  • 04提醒

    在合适的时候，邀请你回来看看。

  • 05本地数据库

    为更长时间、更多记录做好准备。
