创意起源

痛点与灵感

我们在日常工作中发现了会议场景下的普遍困境，这也是 MemoFlow 诞生的起点。

会议之痛

  • 会议中既要参与讨论又要记录，手忙脚乱遗漏关键信息
  • 会后回顾录音耗时巨大，30分钟会议花1小时整理笔记
  • 行动项散落各处，缺乏统一追踪，导致执行断层
  • 跨部门会议的责任归属模糊，谁干什么、何时完成无据可查

灵感来源

  • 大语言模型在语音识别与摘要方面已日趋成熟
  • 「会议即产品」— 将会议产出结构化、可执行、可追踪
  • 微信小程序 + Web 双端覆盖所有办公场景
  • 打通会议与项目管理，让「说了什么」直接变成「要做什么」
产品形态

小程序 + Web 双端协同

MemoFlow 提供微信小程序和 Web 管理后台两个产品形态，覆盖移动办公与桌面深度工作场景。

微信小程序

会议现场一键开启录音转写，实时查看AI生成的摘要和行动项。支持语音输入补充备注，会中即可确认待办责任人。

实时转写 语音交互 即时分享

Web 管理后台

汇集全部会议记录，提供全文搜索、行动项看板、周报自动生成和团队协作空间。支持导出多种格式，与企业IM无缝对接。

看板管理 数据导出 团队协作

核心功能

四大核心能力

MemoFlow 围绕「记录—理解—分发—追踪」闭环，构建完整的会议智能化工作流。

实时语音转写

基于深度语音识别引擎，支持中英混合、多人说话人分离，毫秒级延迟实时上屏。会议进行中即可阅读转写文本，支持标记重点时刻。

智能会议摘要

大语言模型在会议结束后秒级生成结构化摘要：核心议题、讨论要点、决策结论、分歧意见一目了然。提供简要版与详细版自由切换。

行动项自动提取

AI 从会议内容中自动识别「谁、做什么、何时完成」，生成结构化待办卡片。支持手动增删改、优先级标注与一键分发至企业协作工具。

进度追踪与看板

所有行动项集中管理，可视化看板直观展示进度状态（待开始/进行中/已完成/阻塞）。延期自动提醒，关联下一次会议实现闭环追踪。
