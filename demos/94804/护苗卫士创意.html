创意名称 + 创意介绍

创意名称：护苗卫士 — 让每个家庭都能用上专业的青少年上网保护工具

想解决什么问题：孩子上网浏览不适宜内容，家长需要一款可靠的技术工具来辅助管控。护苗卫士定位为免费使用的 Windows 家长控制方案，提供内核级三层过滤与智能计分能力，兼顾保护效果与隐私安全。

为什么会想到做这个：国家监管体系、平台内容审核、厂商系统级管控已在青少年上网保护方面做出巨大贡献，成果显著。但实践中仍有漏网之鱼，特别是 VPN 软件普及后，加密流量让传统过滤手段失效。作为技术从业者和家长，希望提供一款免费、技术路线更深入的 Windows 终端补充方案，将多年系统级开发经验沉淀为这款产品，为现有保护体系补上终端最后一道防线。

大概是什么产品：面向家庭的 Windows 家长控制软件，实现三层网络过滤、加权计分智能判定、VPN 模式兼容、秒级 UIA 监控关标签，从网络层到应用层全方位守护孩子上网安全。

当前痛点

家长在管控孩子上网时面临的挑战：
- 动态域名、CDN让黑名单跟不上
- 孩子技术能力越来越强，能轻松绕过
- Windows平台的家长控制确实不如iOS/Android完善
- 使用浏览器插件，孩子可以轻松绕过或卸载
- 使用系统 hosts 屏蔽，无法应对 HTTPS 加密内容和动态域名
- 家长时间有限，无法全程陪同，担心孩子误接触不良内容
- 年龄较大的孩子可能获取管理员权限，导致权限控制类软件失效

核心架构：三层漏斗过滤

借鉴网络安全的纵深防御理念，每一层过滤逐步收窄范围，兼顾性能与准确性。只有穿透前三层的流量才会进入内容扫描，大幅减少不必要的解密开销。

第零层 进程识别 仅拦截浏览器进程（Edge/Chrome/360），游戏/IDE/系统服务直接放行
▼
第一层 SNI 黑名单 ClientHello 阶段匹配域名黑名单，命中即丢包 + IP 拉黑，零延迟
▼
第二层 SNI 白名单 命中白名单的站点 TLS 透传直连，不解密不扫描，零性能损耗
▼
第三层 MITM 内容扫描 透明代理解密 → URL/标题/正文加权计分 → 过阈值才拦截
▼
兜底层 UIA 秒级监控 VPN 模式下主力：1s 轮询浏览器标签标题，命中即 Ctrl+W 关闭

智能计分：告别"命中即杀"

传统方案"命中一个关键词就拦截"，导致新闻报道、性教育网站被误杀。护苗卫士采用加权计分算法：累加页面中所有命中关键词的权重，总分超过阈值才拦截。

📊 计分演示

权重分级：高危词 50 / 中危词 30 / 低危词 10  |  拦截阈值：100

✔ 场景 A：新闻报道"强*案"

强* +50 仅一个高危词
总分：50 < 阈值 100 ✔ 不拦截（防误杀）

✘ 场景 B：真正的不良网站

肉* +50
颜* +50
色* +30
总分：130 ≥ 阈值 100 ✘ 拦截！
