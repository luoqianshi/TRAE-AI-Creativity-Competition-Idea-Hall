路标 RoadMark

让 AI 从“回答问题的工具”，变成能长期陪你走完备考这段路的学习伙伴：会规划、会复盘、会追踪，也会在你低谷的时候提醒你怎么调整。

主动规划：不是等你来问 闭环追踪：计划-执行-复盘 长期陪伴：看见变化与原因
先看方案 S 看产品流程 F 直接看功能 C

一句话定位

学习 Agent

RoadMark 不是“更聪明的聊天机器人”，而是把学习目标、每日计划、错题薄弱点、成绩波动和状态记录串成一条线， 让学生每天都知道：今天该做什么、为什么会退步、下一步怎么走。

解决什么 不知道怎么学、怎么复盘、怎么调整
怎么做 目标驱动 + 闭环追踪 + 主动提醒
差异点 长期记录与策略，而非一次性回答
落地形态 面向备考周期的学习伙伴系统

项目背景

01 / Background

我是一名北京初中生，在准备中考的过程中长期使用 AI 工具学习。它们很有用：能讲题、能给答案、能改作文。 但越用越发现一个问题：我最难的时候，往往不是“不会一道题”，而是不知道今天该怎么学、为什么这周退步、下一步要怎么调整。

AI 能回答“这题怎么做”，却很少能回答：“你现在最该做的是什么？”

现在的学习数据是割裂的：计划写在纸上、错题在本子里、成绩在群里、状态在心里。 这些信息如果不被串起来，就很难形成真正的复盘，也很难坚持。

我想要的是一个能长期记住我、理解我节奏的伙伴：它不替我学习，但能把路标放在前面。

核心问题（痛点）

02 / Pain

我把问题拆成三类。它们不复杂，但很真实，也直接影响备考效率与心态。

AI 只是被动回答

你不问，它就沉默；你问错方向，它也照答不误。

缺少主动性 不懂节奏 不做规划

学习信息是割裂的

计划、错题、成绩、状态各自为战，复盘很难持续。

数据碎片 复习随机 难追踪

低谷时不知道怎么办

退步时最需要的是“下一步”，而不是更多鸡汤或更多题。

缺少解释 缺少行动 缺少提醒

项目方案：做一个长期陪伴的学习 Agent

03 / Solution

RoadMark 的想法很简单：把 AI 的角色从“答题助手”往前挪一步，变成一个能把学习过程串起来的 Agent。 它会主动做三件事：规划、追踪、纠偏。

P1

先定目标，再谈效率

输入考试时间、目标分数、当前水平后，先把路画出来：剩余时间怎么分配，薄弱点先补哪一块。

P2

每天都有闭环，不留“空白天”

每日计划不是清单，而是“今天为什么做这些 + 做完如何复盘 + 明天怎么调整”。

P3

难的时候给行动，不给空话

连续低效、拖延或某科长时间没复习，就直接提醒：哪里断了，怎么补回来。

我希望它做到的事

更像伙伴

如果我今天状态不好，它不用“夸我很棒”，也不用“逼我更努力”。它只要像一个靠谱的学习搭子一样告诉我： 今天先做哪两件事最值，做完再看要不要加量。

今日任务 有优先级、有预计耗时、有理由
薄弱点 基于错题归类，不靠感觉
成绩波动 找到原因，而不是只看分数
提醒机制 低效/拖延/缺复习时主动出手

这份页面是提案展示页；如果进入实现阶段，RoadMark 会是一套围绕备考周期运行的学习系统。

核心功能（六项）

04 / Core

每一项功能都服务一个目的：让学习从“临时应对”变成“可追踪的过程”。下面的卡片可以点开看更具体的“主动行为”示例。

学习目标管理

输入考试时间、目标分数、当前成绩，自动规划路径。

主动行为示例： 把剩余天数拆成周计划；标注关键节点（模考/一轮复习结束）；把“目标分”翻译成每科可接受的失分区间。

每日学习计划

结合剩余天数与薄弱科目，生成今天的任务。

主动行为示例： 不只给“做三页题”，而是给“先补哪一类、做完如何检查、今天预计 90 分钟够不够”的可执行安排。

错题与薄弱点分析

记录错题，自动归类知识点，并安排复习。

主动行为示例： 把错题按“概念不清 / 计算失误 / 审题偏差”分类；生成 1-3-7 天复习节奏；提醒“这周这块没回头看”。

模拟考试分析

输入成绩后，分析进步/退步原因。

主动行为示例： 对比上一次：哪些题型失分更集中；是“知识点”还是“时间分配”导致；给出下一次模考前的三条具体改法。

每日复盘

记录完成情况与情绪状态，让调整有依据。

主动行为示例： 用很短的方式记录：今天完成了多少、哪里卡住、心态如何；第二天计划会自动根据“完成度与状态”做微调。

主动提醒

连续低效、拖延或长期没复习时，主动提醒。

主动行为示例： 识别“连续三天计划完成率低”；给出轻量调整方案（减量+保底任务）；提醒“某科两周未回顾薄弱点”并插入复习。

输入目标：把“想提高”变成一条路

先确定时间与目标，AI 才能决定“优先补什么”。否则每天做题再多，也可能只是把精力花在不紧急的地方。

这一环最常见的坑 目标是口号，计划是随手写的，最后只能靠临时抱佛脚。
RoadMark 的做法 把目标拆成“周节奏 + 失分区间 + 复习频率”，让每一天都有明确方向。
你会看到的变化 今天学什么不再靠感觉；复盘时能说清“为什么”。

未来计划（可落地的迭代路线）

06 / Roadmap

我希望 RoadMark 先把“闭环”跑通，再慢慢变强。下面是我能想到、也更容易一步步做出来的路线。

阶段 1 / 先跑通

目标 + 每日计划 + 复盘

先解决“今天学什么、做完怎么总结”。把坚持这件事变得更容易，而不是更焦虑。

阶段 2 / 更聪明

错题归类与复习节奏

把错题从“收藏”变成“复习计划的一部分”，让薄弱点能被反复击中、逐步变少。

阶段 3 / 更像人

学习风格适配与提醒策略

有人适合短冲刺，有人适合稳定推进。提醒也应当克制：它不是老师，更像一个会看脸色的搭子。

阶段 4 / 更可靠

隐私、离线与家校协同（可选）

学习数据很敏感。尽量本地化存储、可导出；如果需要分享给家长/老师，也要由学生自己决定。

结尾口号

07 / Closing

“学习不是一场聊天记录，而是一段可以被照亮的路。”

RoadMark 想做的不是替你学、也不是让你卷得更狠。 它只想在你最需要方向的时候，给你一个清晰的路标：今天做什么，为什么做，做完下一步去哪。
