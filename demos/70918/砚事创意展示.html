创意介绍

· CONCEPT

砚事是一款水墨书卷风的极简待办记录应用。它把传统文人的案头美学——宣纸、朱砂、宋体、印章——搬进手机，让"记一件待办"变成"落一笔墨"。

市面上的待办 App 普遍是欧美极简风或功能堆砌的工具，冷冰冰的勾选框、刺眼的红色提醒。用户想要的不是更多功能，而是一个让人愿意每天打开、随手记下生活的地方。砚事用书卷美学重新定义了"记录"的仪式感：成则钤印为记，弃则撕去此卷，急以朱砂、常以赭石、缓取竹青。

产品形态为 PWA 网页应用 + Android 原生安装（Capacitor 打包），纯前端本地优先，数据存手机不联网，零隐私顾虑。

设计语言

· DESIGN LANGUAGE

色彩即功能。砚事不靠图标和文字标注优先级，而是用三色墨韵直接传达：朱砂为急、赭石为常、竹青为缓。一眼扫过，轻重缓急尽收眼底。

核心功能

· FEATURES
印

钤印已成

左滑任务卡片即完成，朱砂印章带落印动画与音效，仪式感拉满。不是勾选，是落印。

墨

水墨手势

左滑完成、右滑删除，移动端触控优先。单手操作，三秒完成一次记录与处理。

言

语音口述

备注支持语音输入，原生识别优先、浏览器回退。开口即记，不必打字。

卷

卷宗统计

完成率环形图、连续打卡天数、缓急分布、类别分布。数据可视化也是水墨风。

夜

日 夜 随

日间宣纸、夜间墨黑、跟随系统三模式。主题切换丝滑无闪。

离

本地优先

数据全部存于 localStorage，无后端、无网络请求、无账号。隐私绝对安全。

用户痛点

· PAIN POINTS

主流待办 App

  • 视觉同质化，冷冰冰的勾选框
  • 功能臃肿，注册同步协作一堆
  • 数据上云，隐私说不清楚
  • 红色刺眼提醒，制造焦虑感
  • 缺少打开的欲望，只是工具

砚事

  • 水墨书卷美学，每天愿意打开
  • 极简极轻，回车即记，滑动即办
  • 纯本地存储，零联网零隐私顾虑
  • 朱砂赭石竹青，温润不刺眼
  • 钤印落定的仪式感，记录即修行

价值与意义

· VALUE

效率提升：把"记录"和"完成"做到极致轻量。输入框回车即记，左滑即成，右滑即删，三秒内完成一次操作。手势优先设计让单手操作毫无压力。

文化传承：在工具全面西化、App 视觉高度同质化的当下，砚事证明传统文化美学与现代交互可以无缝融合。宣纸不是复古噱头，朱砂不是装饰花纹——它们本身就是功能语言。让年轻用户在每日使用中，自然而然接触传统书卷美学，这本身就是一次活态的文化传承。

技术架构

· TECH STACK

纯前端三层架构，无后端服务。视图层 React + Tailwind，状态层 Zustand + persist 持久化，PWA + Capacitor 双端覆盖。
