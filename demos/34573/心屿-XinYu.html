How to Use · XinYu Guide

🌱 欢迎使用心屿

心屿是一款基于认知行为疗法（CBT）的个人疗愈工具，配合 AI 对话帮助你记录和觉察情绪。所有内容仅保存在你当前浏览器的本地，不会上传任何服务器。建议每周使用 2-3 次，每次 15-20 分钟，效果最佳。

1

倾诉对话

这是你的主要入口。可以把它当作一个懂你的倾听者：

  • 想说什么都可以——工作压力、人际关系、睡眠问题
  • 可以直接描述情境，也可以发泄情绪
  • 底部胶囊按钮可快速触发特定练习（呼吸、接地、危机支持等）
  • 无需按 AI 的方式说话——自然地表达就好
2

三栏记录法

这是 CBT 最经典的工具。当你被某件事困扰时：

  • 情境：客观描述发生了什么（不加判断）
  • 自动思维：第一时间冒出来的想法（通常是批判自己的）
  • 平衡思维：用证据反驳/补充，用更全面的视角看待
  • 保存后可以回看，观察自己思维模式的变化
3

认知偏差识别

8 种常见的思维陷阱，点击卡片可以让 AI 帮你分析：

  • 全有全无思维 / 过度概括 / 灾难化
  • 情绪推理 / 人格化 / 读心术
  • 应该思维 / 贴标签
  • 识别它们，是从它们影响下解脱的第一步
4

身体扫描

当你感到焦虑或疲惫时，身体常常比大脑先"知道"：

  • 点击人体图上的每个部位，写下你的觉察
  • 比如："肩膀很紧，像被一块石头压住"
  • 做这个练习时，试着慢呼吸（4 秒吸气，7 秒呼气）
5

写作疗愈

表达性写作是被研究证实有效的情绪调节方法：

  • "换一个引导"会给你不同的写作主题
  • 不必担心语法、逻辑、文采——只要真诚
  • 建议每天写 10-15 分钟，连续写 3-4 天
6

安全计划

这是你的"情绪急救包"——在你状态好的时候填写：

  • 列出你信任的人和电话
  • 写下让你平静下来的具体活动
  • 承诺：无论情绪多强烈，不会伤害自己
  • 当危机发生时，先拨打 400-161-9995
7

AI 设置（混元/元宝）

心屿的 AI 对话功能需要你提供腾讯云混元 API 密钥来调用：

  • 前往腾讯云控制台「混元」获取 API Key
  • 或使用兼容 OpenAI 格式的其它服务（DeepSeek、硅基流动等）
  • 在「AI 设置」面板填入 API Key 和 API Base 地址
  • 密钥只保存在本地浏览器，不上传任何服务器
  • 可以点击「测试连接」验证密钥是否有效
8

温馨提示

心屿是自助工具，不替代专业心理服务：

  • 如果你感到持续的痛苦，请寻求专业心理咨询
  • 如有自伤/自杀念头，请立即拨打 400-161-9995
  • 清除浏览器数据会删除所有本地记录，请谨慎清理
  • 顶部主题色可以自由切换，找到最舒适的视觉
  • 移动端可直接滑动查看所有内容 ✨
