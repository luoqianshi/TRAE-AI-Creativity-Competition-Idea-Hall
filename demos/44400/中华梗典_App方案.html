技术方案

技术选型 & 架构

以快速上线、多端覆盖为首要原则，采用跨端框架一套代码发布至小程序 + H5 + App。

层级 方案 说明
跨端框架 uni-app (Vue3) 或 React Native uni-app 一套代码同时编译到微信小程序、H5、iOS/Android App；React Native 性能更佳但成本更高，根据团队技术栈选择。
后端服务 Node.js + Fastify PostgreSQL RESTful API，梗词数据存储在 PostgreSQL，全文检索使用 PostgreSQL 内置 tsvector；热度数据用 Redis 缓存。
内容采集 Python 爬虫 定时任务 定时爬取微博热搜、抖音热榜、B站热词，AI 辅助提取潜在新梗，人工审核后入库；初期以人工运营为主。
AI 辅助 大模型 API 调用 AI 接口自动生成梗词解析初稿、例句和近义梗推荐，编辑审核后发布，大幅降低内容生产成本。
推送通知 微信订阅消息 Firebase FCM 每日梗报通过微信订阅消息触达小程序用户；App 端用 FCM/APNs 推送。
云基础设施 腾讯云 CloudBase 腾讯云 CVM / CloudBase 托管后端，CDN 加速媒体资源，初期月成本可控制在千元以内。

功能模块拆解

梗词数据库
梗词条目、释义、例句、起源故事、热度数据、分类 Tag、时间轴，核心数据结构，所有功能的基础。
核心
全文搜索引擎
支持模糊匹配、拼音搜索、同义词扩展；搜索结果按热度、时间、相关度多维度排序。
重要
热度算法
综合社交平台提及量、用户搜索量、收藏量三个维度，计算实时热度分值，驱动榜单和推荐系统。
核心
用户系统
微信一键登录，用户收藏、投稿、评论、积分体系；匿名模式下也可浏览全部内容，降低注册门槛。
标准
内容审核
UGC 投稿经 AI 初审 + 人工复审双重机制，过滤违规内容；敏感词库定期维护。
必要
推送 & 通知
每日梗报定时推送，用户可自定义推送类型（新梗、热梗突破、收藏梗更新），精细化运营抓手。

产品路线图

三期开发计划

从 MVP 快速验证，到内容护城河，再到商业化变现，循序渐进。

MVP

第一期 · MVP 上线（0–3 个月）

核心目标是以最低成本快速验证用户需求，完成小程序 + H5 基础版上线，初始收录 500+ 梗词，编辑手工运营。

梗词数据库基础版 搜索功能 今日梗报（手工） 梗词详情页 老梗时光机（年份） 微信登录 + 收藏
成长

第二期 · 自动化 + 社区（3–9 个月）

接入多平台爬虫实现热梗自动采集，引入 AI 辅助生成解析文案，开放 UGC 投稿，上线 App 原生版本。

爬虫自动采集 AI 解析初稿 UGC 投稿 + 审核 用户评论 实时热度榜 iOS/Android App 每日推送通知
变现

第三期 · 变现 + 生态（9 个月+）

建立可持续商业模式，推出会员订阅、品牌合作热梗报告，探索梗表情包周边，构建完整梗文化生态。

梗典会员订阅 品牌热梗周报 梗测试游戏化 梗表情包市场 API 开放平台 梗王勋章体系

商业化路径

PHASE 1 · 免费增长
口碑传播 + 内容营销
每日梗报成为社交货币，用户自发分享到朋友圈、微信群；短视频平台梗解说号吸引精准用户。
PHASE 2 · 会员变现
梗典会员 ¥12/月
会员享受：提前看每日梗报、无限收藏、专属梗测试、去除广告；预计 1% 用户转化即可覆盖服务器成本。
PHASE 3 · B端变现
品牌热梗报告
向品牌方、内容团队出售"月度热梗分析报告"，帮助其判断哪些梗适合投放、哪些梗已过时，单客年费可观。
