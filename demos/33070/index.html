THE PROBLEM

很多 Todo，很少开始

普通待办清单擅长记录任务，但真正卡住我们的，往往不是"忘了做"，而是"迟迟没开始做"。

!

任务写下来了，还是不想开始

清单越写越长，真正动手的那一项迟迟停留在第二天。真正问题不在记录，而在进入状态的阻力。

≫

计划越写越大，压力越来越高

完整路线图、阶段性目标、里程碑——规划得越详细，第一步反而越不敢踏出。

⏰

提醒只会催促，却不会降低难度

系统不断弹"该做了"，却从未帮用户把"大任务"变成"现在可以做的那一步"。

→

缺少一个低压力的行动入口

用户需要的不是另一个任务管理工具，而是一个能温柔地把自己送进行动状态的入口。

COMPARISON

普通 TodoList vs StartList

记录和提醒是重要的，但用户在开始之前，更需要一个被降低难度的最小行动。

普通 TodoList StartList 关键差异
记录任务 帮助开始第一步 从 "记录" 到 "行动"
提醒用户 降低任务难度 从 "催促" 到 "拆解"
展示任务列表 只展示当前最小行动 从 "一长串" 到 "一步"
卡住后没有反馈 支持继续降级，直到能动手 从 "停滞" 到 "持续有出路"
完成后只改状态 沉淀 Skill，帮助下一次更好地启动 从 "一次性" 到 "越用越准"

HOW IT WORKS

一次任务启动的完整闭环

在 Todo 和 Do 之间，搭一座低阻力的桥。

1
模糊任务输入
用户描述想做却没开始的事
2
启动阻力分析
AI 评估任务难度与阻力原因
3
最小行动生成
拆解为 3-5 分钟可完成的行动
4
Agent 预准备材料
草稿、模板、清单供用户直接修改
5
Start Mode 聚焦执行
5 分钟倒计时，只做这一件事
6
完成 / 卡住降级
继续拆小，直到能动手
7
Skill 沉淀
记录成功/失败路径，下次复用

        VALUE

        效率提升 & 商业价值

        对用户，它是更温和、更有效的行动入口；对赛道，它是一套可复用、可规模化的 AI 任务启动方案。

        ⚡

        效率提升

        把"从 Todo 到 Do"的时间从几小时、几天压缩到 3–5 分钟；AI 自动分析启动阻力，替用户省下犹豫、决策和准备成本。

        📈

        商业价值

        作为 SaaS 产品形态（网页端），可面向学生、自学者、求职者、知识工作者四类人群；以单次任务启动为付费 / 订阅场景，符合 AI Agent 产品趋势。

        🤖

        可复用的 AI 能力

        核心能力不是"写 Todo"，而是"识别任务类型 → 评估阻力 → 切分最小行动 → 预生成材料 → 沉淀 Skill"，可横向扩展到更多行业和岗位。

        ↻

        可沉淀的体验飞轮

        每一次启动都会沉淀一条 Skill（成功 / 失败路径），随着用户数增加，启动建议越来越精准，形成越用越好的正向循环。
