看得见的内存，学得会的 C++

传统 C++ 学习中，内存模型是最大的拦路虎。指针指向哪里？对象何时析构？智能指针如何转移所有权？这些问题仅凭文字和图表难以理解。

  • ✓ 栈/堆视图实时展示 — 清晰看到每个变量的内存地址与值
  • ✓ 对象生命周期追踪 — 构造、拷贝、移动、析构调用一目了然
  • ✓ 智能指针动画演示 — unique_ptr / shared_ptr / weak_ptr 所有权转移
  • ✓ 单步执行控制 — 逐语句观察内存变化，支持暂停、重置
  • ✓ 高频考点案例库 — 智能指针、容器扩容、异常栈展开等经典案例
