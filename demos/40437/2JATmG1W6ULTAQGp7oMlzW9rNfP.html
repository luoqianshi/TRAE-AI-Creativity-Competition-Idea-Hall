AI 漫途旅行规划师

智能规划 · 省市县区全覆盖 · 个性化行程

赛道：生活娱乐

💡创意介绍

想解决什么问题

做旅行攻略耗时费力，要在多个 App 之间来回切换查景点、查美食、查酒店、查交通，信息分散且难以统筹。用户面对一个陌生城市时，往往不知道该去哪、吃什么、住哪里、怎么走。

为什么会想到做这个

每次计划出行都要打开小红书查攻略、打开大众点评找美食、打开携程订酒店、打开高德查路线，一个行程要花好几个小时甚至几天时间整理。如果有一个工具能一站式解决"去哪玩+吃什么+住哪+怎么走"，就能让旅行回归轻松本质。

大概是什么产品

一个全栈 Web 应用——基于 Node.js + Express + SQLite 后端，原生 HTML/CSS/JS 前端。覆盖全国 34 个省级行政区、355 个城市、1141 个区县，提供省市区三级联动选择，智能生成个性化旅行行程。

🎯目标用户及痛点

面向哪些用户

  • 自由行旅客：不想跟团、追求个性化体验的旅行者
  • 周末出游人群：短途旅行、说走就走的上班族
  • 家庭出行决策者：需要统筹预算、交通、景点的家庭旅行规划人
  • 学生穷游党：预算有限、追求性价比的年轻旅行者

在什么场景下使用

  • 计划一次 3-5 天的国内旅行，需要快速了解目的地
  • 临时决定周末出游，需要快速生成行程
  • 去陌生城市出差，想顺便逛逛当地景点
  • 对比多个城市，选择最适合的旅行目的地

当前痛点

  • ❌ 信息分散：景点、美食、酒店、交通散落在不同 App
  • ❌ 城市覆盖不足：多数攻略只覆盖热门城市，小众目的地无数据
  • ❌ 交通信息单一：只显示飞机，忽略火车、长途汽车等实际出行方式
  • ❌ 缺乏个性化：无法根据预算、天数、偏好生成定制行程

✨核心功能

🗺️ 省市区三级联动

覆盖全国 34 省 355 市 1141 区县，选择省份后自动加载城市，再加载区县，精准定位目的地。

🎯 智能行程规划

根据预算、天数、出行偏好，自动生成每日行程安排，包含景点、美食、酒店推荐。

🚄 完整交通信息

6 种交通方式全覆盖：火车/高铁、长途汽车、地铁、公交、出租、机场，符合中国实际出行习惯。

🌤️ 四季天气参考

每个城市提供春夏秋冬四季气温与出行建议，帮助选择最佳出行时间。

🏨 景点美食酒店

每个城市配备景点、特色美食、酒店推荐，含评分、价格、标签等详细信息。

💾 数据持久化

SQLite 数据库存储，支持数据快速检索与扩展，无需独立数据库服务。

💎价值与意义

效率提升

将原本需要数小时甚至数天的攻略整理工作，缩短至几分钟。用户选择目的地后即可获得完整的景点、美食、酒店、交通、天气信息，一键生成行程。

社会价值

覆盖全国 355 个城市（含大量非热门城市），让小众目的地也能被发现。促进旅游资源均衡发展，减少热门城市过度拥挤，带动三四线城市旅游经济。

商业价值

可扩展为 OTA 平台，对接酒店预订、机票火车票购买、景点门票等业务，形成旅行服务闭环，具备清晰的商业化路径。

🔧技术实现

技术栈

Node.js Express SQLite 原生 HTML/CSS/JS RESTful API

架构亮点

  • 数据分片存储：全国数据按地理区域拆分为 6 个数据文件，便于维护
  • 智能数据生成：非热门城市自动生成基础旅行数据，确保无空结果
  • 批量事务插入：335 个城市 5700+ 条数据 0.72 秒完成填充
  • 非常用端口：Web 服务使用 8848 端口，避免端口冲突

🚀 Demo 运行方式

1. 安装依赖：npm install

2. 初始化数据库：npm run init-db && npm run seed-db

3. 启动服务：npm start

4. 访问：http://localhost:8848

📁项目结构

  • server.js - Express 后端服务（端口 8848）
  • scripts/init-db.js - 数据库表结构初始化
  • scripts/seed-db.js - 数据填充脚本（批量事务）
  • scripts/seed-data-1~5.js - 省市区数据（按地理区域分片）
  • scripts/seed-data-extra.js - 补充城市数据
  • scripts/seed-travel.js - 热门城市详细旅行数据
  • scripts/seed-travel-default.js - 默认旅行数据生成器
  • scripts/seed-transport.js - 智能交通信息生成
  • public/index.html - 前端页面
  • public/js/app.js - 前端交互逻辑
  • public/css/style.css - 样式文件
