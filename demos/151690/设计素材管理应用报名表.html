Game Asset Manager — 设计素材资源管理程序

基于 Electron + React + KD-Tree 的智能素材管理桌面应用，为游戏/影视场景设计师打造一站式素材收集、整理与以图搜图工作流

1 创意名称与创意介绍

创意名称：Game Asset Manager（游戏场景设计师素材管理工具）

想解决什么问题：游戏与影视场景设计师每天需要从 ArtStation、Pinterest、Lofter、小红书等数十个设计网站收集参考素材，但素材散落在各处下载文件夹中，缺乏统一管理分类；想找"类似那张图"时只能靠记忆翻文件夹，效率极低。

为什么会想到做这个：在毕业设计研究游戏场景设计流程时，我发现设计师的素材管理方式高度依赖手工分类和文件夹层级，缺乏专业素材管理工具的本地化、可扩展方案。同时，日常使用 Trae IDE 进行开发时，深受其 AI 辅助能力启发，希望将 AI 以图搜图、智能标签等能力融入素材管理工作流，有序积累素材，辅助设计师更好地进行创意工作。

大概是什么产品：一款基于 Electron 构建的跨平台桌面应用（支持 Windows/macOS），覆盖素材采集 → 整理分类 → 智能搜索 → 细节浏览 → 导出复用全工作流，配套 Chrome 浏览器扩展实现一键网页素材采集，下载未被平台压缩的高清原图，并记录图片所在网页网址和本地保存位置，核心特色是本地 KD-Tree 加速的以图搜图引擎。

2 目标用户及痛点
核心用户群体 游戏场景或角色设计师、原画设计师、插画师、UI/UX 设计师、建筑规划师
使用场景 项目前期素材调研、风格参考收集、场景氛围图整理、日常灵感素材积累
典型工作流 采集：浏览器扩展右键一键采集网页图片 → 整理：自动归类、打标签、记录来源 → 搜索：本地以图搜图 + 外部网站搜相似图 → 浏览：图片查看器细节观察 + 来源回访 → 导出：定位文件目录 + 项目使用记录追踪

🔴 没有本产品时的痛点

  • 素材散落在"下载"文件夹各处，文件名无意义（如 final-01.jpg）
  • 想找"类似某张图"的素材只能靠记忆翻文件夹，费时费力
  • 从网页保存图片后丢失来源 URL，无法追溯原始参考出处
  • 想在 ArtStation/Pinterest 搜索类似图片需要手动重新上传
  • 缺乏统一的标签体系，素材分类全靠手动建文件夹
  • 素材重复下载严重，相同图片被反复保存

🟢 使用本产品后的改善

  • 浏览器扩展右键一键采集，自动记录来源网页 URL 和标题
  • 本地以图搜图引擎（KD-Tree + 颜色直方图 + 感知哈希）毫秒级搜索相似素材
  • 支持跳转 Google Lens / Pinterest / ArtStation 等外部网站搜索更多相似图
  • 自定义标签组 + 文件夹层级双维度管理，灵活适配不同项目需求
  • MD5 去重，自动识别重复素材
  • 图片查看器支持滚轮缩放、拖拽平移、键盘导航，方便细节观察
3 价值与意义

效率提升：本产品将设计师的素材管理工作流从"手动下载→重命名→建文件夹→翻找"升级为"一键采集→自动标注→智能搜索→跨平台搜图"，显著提升素材管理效率。

商业价值：面向游戏工作室、影视特效公司、独立设计师群体的专业素材管理工具市场存在空白。对标 Eagle（定价 ¥199/年），本产品以本地化、可扩展、开源生态为核心竞争力，可作为团队内部素材共享平台的客户端基础。未来可扩展为团队协作版，支持素材库共享、评论批注、版本管理等企业级功能。

社会价值：帮助创意工作者高效管理灵感素材，减少重复劳动，将更多时间投入创作本身。同时，素材来源追溯功能有助于设计师尊重原创版权，与原作者达成合作，建立健康的设计参考文化。
