Product Idea

产品创意：把“一个投研团队”压缩成一个可运行的 Agent 系统

传统投研需要研究员、行业分析师、财务分析师、估值分析师、风控人员和报告撰写人员协作。 这个产品的核心创意，是把完整投研流程拆成多个专业 Agent，每个 Agent 调用专门 Skill，像一个小型买方研究团队一样协同工作。

痛

解决投研效率问题

A股企业信息分散在公告、财报、新闻、交易所、东方财富、巨潮资讯和宏观政策中。 人工整理成本高、重复劳动多，普通AI问答又容易缺少数据来源。

智

多Agent自动协作

每个 Agent 负责一个专业环节：公司画像、财务分析、行业研究、新闻舆情、可比公司、估值、风险、催化剂和报告审查。

商

可商业化交付

既能作为 Python Web 产品独立部署，也能打包成 OpenClaw/Hermes Skill，让其他 Agent 直接调用，形成可复用的投研能力模块。

Multi-Agent Architecture

多Agent架构：从数据采集到报告审查，全链路自动化

系统不是一次性把问题丢给大模型，而是由 Orchestrator Agent 进行任务拆解、并行调度、结果汇总和质量审查。

Company Profile Agent 公司画像、主营业务、股权结构
Financial Agent 财务报表、ROE、现金流、杜邦分析
Industry Agent 行业空间、竞争格局、产业链位置
News Sentiment Agent 公告、新闻、舆情、事件时间线
AI

Orchestrator Agent

总控投研经理：负责拆解任务、调用技能、监控进度、聚合结论、发现数据缺口，并把结果交给报告写作与质量审查 Agent。

Comps Agent 同行可比公司筛选与估值对比
Valuation Agent PE/PB/PS、历史分位、DCF情景估值
Risk Agent 财务、经营、政策、估值风险矩阵
Report Review Agent 审查幻觉、无来源数据和合规风险

不只是Web产品，也是一组可复用的投研 Skills

系统可以独立运行，也可以把能力拆成多个 Skill 包，让 OpenClaw、Hermes 或其他 Agent 平台直接调用。

01

ashare-full-research-agent

完整投研技能：输入A股公司，自动调用公司画像、财务、行业、估值、风控、报告写作全流程。

02

ashare-financial-analysis

专注财务分析：财报抓取、指标计算、现金流质量、杜邦分析、异常财务信号识别。

03

ashare-valuation

专注估值分析：相对估值、历史分位、DCF、情景分析、敏感性分析和估值区间输出。

04

ashare-comps

可比公司分析：自动筛选同行公司，解释选择逻辑，生成估值对比表和分位判断。

05

ashare-risk-check

风险审查技能：构建财务、经营、政策、估值、治理、流动性等多维风险矩阵。

06

ashare-report-writer

报告写作技能：把所有中间结果整理成机构风格 Markdown、DOCX、PDF 和 Excel 模型。

这套产品的本质：让个人也拥有“机构级投研流水线”

它把分散的数据源、复杂的财务计算、行业判断、估值模型和报告写作，变成一套可运行、可复用、可扩展的多 Agent 系统。 对个人投资者，它是研究助手；对内容创作者，它是深度分析引擎；对投研团队，它是自动化生产力工具。
