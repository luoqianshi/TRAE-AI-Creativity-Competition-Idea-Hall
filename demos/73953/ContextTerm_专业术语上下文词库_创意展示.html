ContextTerm

一个面向 C 语言、Linux、嵌入式等原版资料阅读场景的“专业术语上下文词库”，帮助学习者把专业名词放回原文语境中理解、复习与沉淀。

创意介绍

阅读英文原版技术书籍时，很多专业名词并不是简单翻译就能理解。例如在 C 语言、Linux 内核、操作系统、嵌入式开发资料中，同一个词可能同时涉及概念、代码语境和工程实践。 ContextTerm 希望把“单词本”升级为“上下文术语本”，让用户保存原文句子、所在章节、术语解释、代码示例和复习计划。

学习工作 专业英语 C语言 Linux 嵌入式学习

目标用户与使用场景

目标用户 研究生、计算机/电子信息专业学生、嵌入式开发学习者、准备阅读英文技术文档和原版书籍的工程师。
使用场景 阅读 C 语言原版书、Linux 手册、内核文档、芯片手册或英文论文时，遇到专业术语即可保存上下文并生成学习卡片。
核心痛点 普通词典只能给出孤立翻译，传统单词本脱离技术语境，导致用户记住了中文意思，却无法真正理解术语在代码和系统中的作用。

核心功能设想

上下文收藏 保存术语、原句、段落、章节来源和用户自己的理解笔记。
专业解释生成 根据 C/Linux/嵌入式语境生成更贴近技术场景的解释，而不是机械翻译。
代码关联 对术语自动关联代码片段、命令示例或典型使用场景。
复习计划 基于遗忘曲线生成术语卡片，帮助长期掌握专业词汇。

产品示意

原文摘录：

The kernel uses a system call interface to provide controlled access to hardware resources.

术语：system call

中文解释：系统调用，是用户程序请求操作系统内核服务的一种接口。

技术语境：在 Linux 中，用户态程序不能直接操作硬件资源，需要通过系统调用进入内核态完成文件、进程、内存等操作。

关联示例：open()、read()、write()、fork()
