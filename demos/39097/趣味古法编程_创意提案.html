卷 · 一

项 目 缘 起

——当 Agent 时代遇见古法智慧——

时代之问

当 GPT、Claude、Gemini、Sora 与各类编程 Agent 如同"天降神兵"，代码的生成变得前所未有地容易。一个初学者只需说出一句话，便可获得一个可以运行的项目。然而，"会用工具"与"懂其所以然"之间，正裂开一道前所未有的鸿沟——工具越智能，底层原理越珍贵。

与此同时，东方古法智慧（诸子百家、易经、五行、天干地支、兵法、诗词、医理、匠作）正被大多数年轻人视为"老古董"。然而，这些看似陈旧的体系，恰恰蕴含着与现代系统科学、抽象建模、算法思维异曲同工之妙的"结构化思考"与"系统直觉"。

一个核心洞察

古法不是过去，而是另一种"建模语言"；编程不是未来，而是当前最通用的"思维工具"。当二者在 Agent 时代相遇，一次全新的学习范式革命正悄然发生。——产品发起人手记

我们观察到四个关键信号：

  • 信号一：学习者面对 AI 生成的代码，只能"复制粘贴"，无法辨别对错。
  • 信号二：理工科课程中"枯燥的原理"与"有趣的应用"严重脱节。
  • 信号三：东方文化产品日趋符号化，缺乏严肃的"思维训练"级内容。
  • 信号四：Agent 工具链成熟，使得"内容生产"与"学习体验"的耦合前所未有地紧密。

为什么是"古法 + 编程"？

卷 · 四

核 心 理 念

——古今对话的三条学习之道——

道一：隐喻即理解

抽象概念的理解，最有效的路径不是"再给一个定义"，而是"给一个与日常生活、历史文化相通的隐喻"。每一个编程原理，我们都以古法意象为"船"，载学习者渡过抽象之河。

例："函数调用栈"可喻为"一叠层层相托的竹简"——每写上一卷便放下一卷，要读时须从最上一卷读起。
例："递归"可喻为"庄周梦蝶"——蝶梦为周，周复梦蝶，直至止境方醒。

道二：叙事即记忆

知识点孤立是"枯燥"之根。我们让每个原理卷成为一则完整的叙事——有角色（古人 / 虚拟先生 / Agent 师友）、有冲突（"为何这样设计而非那样"）、有高潮（终于悟了的恍然大悟）、有余韵（"还能这样用"的迁移思考）。

道三：手作即真知

不做"看客式学习"。每一卷都必须包含可动手的小实验——用最小可运行的代码片段、可交互的可视化、可"拆解再组装"的 Agent 任务链，让学习者亲手"摸"到原理的运作。

"不闻不若闻之，闻之不若见之，见之不若知之，知之不若行之。"——荀子

产品哲学 · 与 Agent 的关系

Agent 不是我们的"敌人"，而是我们的"师友 + 教具 + 陪练"。我们不教"如何避免用 AI"，而是教"如何在 AI 面前，做一个更聪明的人"。

Agent 为师

由 Agent 担任"助教"，随问随答，个性化讲解。

Agent 为具

让 Agent 生成"错误示例"供学习者判读，训练批判性思维。

Agent 为友

与学习者共同"对弈式编程"，在对话中发现原理。

课 程 体 系

——六艺六卷 · 从术入道——

总体架构 · 六艺六卷

借鉴周代"六艺"（礼、乐、射、御、书、数）的结构，我们设计六大原理卷，每一卷对应一组核心的编程/系统/算法原理，并以一个东方古法体系作为贯穿隐喻。六卷从"术"入"道"，层层递进。

六卷详解

卷次卷名古法主题对应原理核心产出
卷一易经之卷太极生两仪 · 六十四卦二进制、布尔逻辑、真值表、状态机用位运算解卦；写一个六爻占卜小程序
卷二五行之卷金木水火土 · 生克制化数据流、依赖图、反馈循环、队列模拟"五行生克系统"，调试循环依赖
卷三甲子之卷天干地支 · 六十甲子模运算、循环队列、周期函数、日历算法实现"干支纪年转换器"；LCM/GCD 可视化
卷四兵法之卷孙子兵法 · 五事七计搜索算法、决策树、剪枝、启发式、博弈论实现"围魏救赵"式路径搜索小游戏
卷五本草之卷本草纲目 · 分类纲目面向对象、继承多态、树结构、数据库设计搭建"中医古籍知识库"检索系统
卷六天工之卷天工开物 · 匠作流程工程化、流水线、并发调度、Agent 协作用多个 Agent 协同还原"造纸流程"

每一卷内部结构 · 七步式

  1. 引子 · 故事——以一则古人轶事或生活场景引入主题（约 3 分钟）
  2. 古法 · 精读——深入一则古法文本或图式（约 8 分钟）
  3. 原理 · 映射——将古法结构"翻译"为编程概念（约 10 分钟）
  4. 代码 · 手作——最小可运行代码片段，亲手敲一遍（约 15 分钟）
  5. Agent · 对话——与专属 Agent 进行 3 轮问答辩论（约 10 分钟）
  6. 闯关 · 试炼——一道原理题 + 一个改错任务（约 10 分钟）
  7. 余韵 · 迁移——"这个原理还能用到哪里？"开放性思考题（约 5 分钟）

每卷合计约 60 分钟 × 8 节课 = 8 小时深度学习时间，加上练习与社区互动，累计学习体验周期约 1–2 周。

难度梯度 · 三境

初识 · 小学生也能懂

完全零基础可读。用"讲故事 + 动手做"的方式，让 12 岁以上的学习者也能理解核心概念。

深究 · 程序员的修行

含原理推导、数学证明、工程应用。供 CS 学生与从业者系统打磨基础。

化用 · 创新者的乐园

鼓励学习者以古法为灵感，创造自己的算法/系统，产出可分享的作品。

产 品 形 态

——书院 + 工坊 + 江湖三重结构——

产品总览

"趣味古法编程"并非单一的 App 或视频课，而是一个由「书院」（内容）+「工坊」（实践）+「江湖」（社区）构成的三维学习生态。用户在三个空间之间流动，形成"读 —— 做 —— 论"的闭环。

第一空间 · 木华山高书院（内容空间）

  • 卷轴式阅读界面：每课以"展开卷轴"的动画进入，文字竖排/横排可选，插图为水墨风 SVG。
  • 每句可点 · 每图可动：鼠标悬停关键字，弹出"古法小注 / 原理小注 / 代码类比"三层注解。
  • 内嵌代码编辑器：关键段落附带可运行代码窗，"读书"与"敲键盘"无缝切换。
  • 原理大师 Agent：每卷有一个独立 Agent，可与之对话、辩论、请教。
  • 学习节奏自适应：根据答题正确率，动态调整讲解深度与习题难度。

第二空间 · 百工工坊（实践空间）

  • 古法代码挑战：固定主题 · 有限代码行数 · 实现即通关。
  • AI 辨错任务：Agent 故意生成"有原理性缺陷的代码"，用户需指出问题并修正。
  • 可视化原理沙盒：拖拽式建模器，可搭建五行系统、干支周期等可视化模型。
  • 多 Agent 协同工坊：分派多个 Agent 扮演匠作角色，用户扮演工头统筹调度。
  • 作品上链存证：学习者作品可生成"玄机印记"，以作成长纪念。

第三空间 · 问道江湖（社区空间）

  • 论道场："今日一题"的辩论式问答区，每人可贡献一种古法视角。
  • 诗酒社：以"古法 × 编程"为主题的创意内容区（诗词、漫画、短视频、音乐）。
  • 师徒制：高段位用户可开设私教席，带新学员入门，获得薪火值。
  • 月度江湖会：线上直播的原理竞赛/辩论赛，可获得限定江湖印章。
  • 作品集市：优秀作品可在此亮相，被品牌方与合作方发现。

内 容 产 出 引 擎

——古法 × AI Agent 的双重驱动——

内容生产循环 · 四步

  1. 原典研读：由历史学家 / 科学家 / 工程师组成的内容团队共同选定主题。
  2. 隐喻建模：建立"古法概念 → 编程原理"的双向映射表，并反复论证其严谨性。
  3. Agent 辅助创作：调用专用 Agent 将映射"翻译"为故事、图示、代码示例与练习题。
  4. 专家校订 + 用户反馈：经两位以上专家校审后上线，并基于互动数据持续迭代。

"原理大师 Agent"的三重人格

先生人格（讲解）

温润严谨，以古法故事为引，娓娓道来，循循善诱。

辩者人格（提问）

苏格拉底式反诘，不断追问"为什么这样设计？"训练批判性思维。

师友人格（协作）

八大风险与预案

风险类别风险描述发生概率应对策略
内容质量风险古法隐喻穿凿，被学界批评"伪科学"中建立"原典顾问 + 原理顾问"双审机制；保留学术讨论通道。
用户定位风险"文化 + 技术"定位小众，难以规模化中以"原理至上"为主线，古法作为加分项；对不同人群动态调节比例。
产品体验风险界面过于文艺，不适技术学习者的高效习惯中低提供"阅读模式/写作模式"双主题切换；用户可一键关闭古风视觉。
技术合规风险使用 Agent 生成内容涉及 AI 合规；数据跨境问题中采用国内合规大模型；所有 Agent 生成内容标注明确；走合规备案通道。
团队构成风险难以同时招募顶尖文化学者与顶尖工程师中高采用"全职 + 顾问"混合结构；与高校/研究所建立研究伙伴关系；核心团队以"文理双修"为选人标准。
成本结构风险内容生产成本高，持续投入压力大中上线初期聚焦基础六卷，优先验证学习效果；使用共创机制降低持续内容投入；与机构合作共享资源。
品牌联想风险被误认成"玄学课程"或"迷信产品"中首页清晰声明"原理教学本质"；由科学顾问团背书；语言严谨，不做任何迷信承诺。
市场波动风险AI 热过后，学习者兴趣转向其他方向中高以"底层原理"为核心品牌主张，不绑定任何具体技术；提前布局横向卷系（数学、物理、设计）。

价 值 主 张

——一纸结语——
我们不卖焦虑，也不教捷径。
我们只做一件事——
以古法悟原理，以代码通天下。

在 AI 似乎可以代劳一切的时代，
帮助每一个人找回"真正理解"的权力，
做一个"能读、能判、能改、能创"的原理大师。

一页摘要

  • 时代机遇：华语世界 STEM 教育市场中，"原理型学习"仍是蓝海；Agent 时代的到来使这一需求加速爆发。
  • 核心产品："趣味古法编程"——以东方古法为隐喻、以编程原理为骨的沉浸式学习生态（内容 + 实践 + 社区）。
  • 独特价值：古法隐喻系统 × Agent 师友体系 × 东方美学品牌，三者叠加，形成独一无二的学习体验。
  • 产品理念：完全免费、开放共享，以学习效果与社区口碑为唯一驱动力。
  • 团队要求：历史学家 × 计算机科学家 × 课程设计师 × 工程师 × 品牌运营的"文理兼备"团队。
  • 长期愿景：成为跨学科的原理思维教育第一品牌，走向海外华人市场，最终成为文化输出的一个新符号。
