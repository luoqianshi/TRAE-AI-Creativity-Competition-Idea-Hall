# 🏆 世界杯冠军预测系统

基于2022卡塔尔世界杯小组赛数据的数据分析和冠军预测网页应用。

## 📋 功能特性

### 1. 小组赛结果展示
- 展示8个小组32支球队的完整小组赛数据
- 包括积分、胜平负、净胜球等详细信息
- 自动排序显示小组排名

### 2. 球队数据统计
- 国际排名和历史战绩
- 世界杯冠军次数
- 最佳成绩
- 关键球员信息
- 优势与劣势分析
- 球队平均年龄

### 3. 淘汰赛预测
- 支持逐轮预测：1/8决赛 → 1/4决赛 → 半决赛 → 决赛
- 每场比赛都有详细的预测依据
- 基于球队排名、冠军次数、关键球员等指标
- 记录预测历史

### 4. 数据可视化
- 积分分布柱状图
- 冠军次数饼图
- 球队年龄分布横向柱状图
- 进攻效率对比雷达图

## 📊 预测依据

预测系统综合考虑以下指标：

1. **国际排名** - FIFA排名越低，基础实力分越高
2. **世界杯冠军次数** - 历史底蕴加成
3. **关键球员状态** - 核心球员对比赛的影响
4. **小组赛表现** - 当前赛事状态
5. **年龄结构** - 球队平均年龄

## ⚠️ 注意事项

- 本预测系统仅供参考娱乐
- 数据来源于2022年卡塔尔世界杯
- 实际比赛结果可能与预测不符

## 📝 使用说明

1. 打开网页后，默认显示小组赛结果
2. 点击"球队数据"标签可查看各队详细信息
3. 在"淘汰赛预测"页面，点击"预测本轮"按钮进行预测
4. 预测完成后会自动进入下一轮的对阵
5. "数据可视化"页面提供多种图表分析

## 🎯 预测示例

每场预测都会显示：
- 比赛双方信息（排名、冠军次数）
- 预测比分
- 详细的预测依据说明
