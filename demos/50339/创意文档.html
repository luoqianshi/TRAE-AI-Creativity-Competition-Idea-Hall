1. 创意名称 + 创意介绍

创意名称

家仪录——中国人的生活礼仪导航

想解决什么问题

年轻人离开家乡后，婚丧嫁娶的节日礼仪没人教；老一辈不在了，"我家的规矩"就断了；异地婚姻中，双方家庭习俗不同经常闹矛盾。

为什么会想到做这个

每次过年走亲戚、参加婚礼葬礼，都是老一辈口头告诉我们该做什么不该做什么。但一旦他们不在场，我们就像"文化孤儿"一样手足无措。市面上有商务礼仪课、有星座运势 App、有老黄历，但没有专门解决"中国民间日常礼仪"的数字化工具。

大概是什么产品

移动端网页应用（PWA），手机浏览器打开即用，无需下载安装。功能完整后可封装为微信小程序。

关于小程序
目前采用网页版是因为开发快、跨平台、演示方便。后续可无缝迁移为微信小程序，调用微信录音、订阅消息等能力，体验会更完整。

2. 目标用户及痛点

面向哪些用户
  • 异地工作、常年不在家的年轻人
  • 跨地区结婚的夫妻
  • 刚经历亲人离世、不知道怎么办的家属
  • 想记录家族记忆但不知道怎么开始的晚辈
在什么场景下使用
🎉 过年回老家前——查"去丈母娘家该带什么"
💐 参加葬礼当天——查"穿什么颜色、白包包多少"
💍 结婚前——协调"男方要磕头、女方只作揖"的习俗冲突
🎤 过年回家——帮奶奶录一段"咱家年三十的规矩"
📜 日常疑惑——"筷子能不能插在饭上？"
当前痛点（如果没有家仪录）
过年去对象家，不知道带什么。只能临时在超市随便买点水果，结果对方父母觉得没诚意，自己还不知道问题出在哪。
参加葬礼，穿了件红色外套到场。发现所有人穿黑色，尴尬得想钻地缝，但又不能中途离开换一件。
结婚前双方父母吵起来。男方家要磕头，女方家不接受，新人夹在中间和稀泥，婚礼还没办先闹了不愉快。
奶奶走后，再也想不起她的规矩。只记得她说过"年三十要做点什么"，但具体是什么，再也问不到了。
异地工作，遇到白事不知道流程。想帮忙却帮不上，只能干站着，怕被说"不懂礼数"。

结论：没有专门解决"中国民间日常礼仪"的数字化工具，年轻人只能靠猜、靠问、靠尴尬试错。

3. 价值与意义

社会价值：非遗的活态传承

民俗本身就是非物质文化遗产，但现有非遗保护都在做"展示"（博物馆、纪录片），没有人做"实用"——让年轻人在真实人生场景中用得上。我们用数字化手段实现了民俗的"活态传承"：不是把习俗封存在玻璃柜里，而是让它在婚礼、丧礼、春节里继续被使用。

情感价值：家族记忆的容器

"记传承"模块让长辈的声音和讲究可以被录音保存、AI 转写、代代查阅。这不是知识库，是家族记忆的容器。奶奶走了，但她的声音还在。

4. 核心功能

🔎 查礼仪

按地区+场景查询中国传统礼仪，支持自然语言提问（"我山东的，大年初一能扫地吗？"），每条知识附带【我家版本】。

🎤 记传承

子女帮老人录音讲述"我们家的讲究"，AI 自动转写文字，形成"家族礼仪志"。不是百度百科，是"我家的独特记忆"。

📖 办大事

婚礼、丧礼、满月、乔迁全流程向导，含地区差异标注和冲突协调器。

5. 技术方案

  • 前端：纯 HTML/CSS/Vanilla JS 单页应用
  • 录音：Web Audio API + MediaRecorder
  • 语音转写：Web Speech API（浏览器内置）
  • AI 问答：大模型 API 文本生成
  • 存储：localStorage（初赛 Demo）/ 后端数据库（完整版）

6. 初赛 Demo 演示路径

  1. 开场——展示首页：家乡设置 + 今日习俗推荐 + 三大入口
  2. 查礼仪——搜索"我山东的，大年初一能扫地吗"，展示通用答案 + 【我家版本】
  3. 记传承——播放奶奶关于年三十规矩的录音（转写文字）
  4. 办大事——展示丧礼时间线 + 地区差异标注 + 冲突协调器
