异世午梦

IMMERSIVE ACTION ROLE-PLAYING GAME

1 创意名称 + 创意介绍

「异世午梦」—— 一款以深度 Build 构筑与高自由度战斗为核心的动作角色扮演游戏。

痛点 想解决什么问题： 当前市场 ARPG 游戏存在两极分化——要么战斗爽快但 Build 深度不足，重玩性低；要么系统庞杂晦涩，新手望而却步。缺乏一款在"易上手"与"耐玩性"之间找到平衡的作品。

动机 为什么会想到做这个： 团队核心成员均为多年 ARPG 爱好者，从《暗黑破坏神》到《艾尔登法环》，我们亲历了品类进化的每一个节点。但始终渴望一款能融合"深度角色构筑"与"酣畅动作体验"的游戏——既然市场没有，那就自己造一个。

形态 大概是什么产品： 基于 Godot 引擎 开发的 PC / 主机平台 3D 动作角色扮演游戏，核心玩法围绕"装备技能自由搭配 × 属性深度养成 × 高策略战斗"展开。

2 目标用户及痛点

用户画像 面向哪些用户： 核心 ARPG 玩家群体（年龄 18–35 岁），喜爱刷宝、Build 构筑、挑战高难度 Boss 的中重度游戏玩家；同时也兼顾偏好剧情驱动与沉浸式世界探索的 RPG 爱好者。

场景 在什么场景下使用：

  • 休闲时间打开游戏，在无缝连接的幻想世界中探索、战斗、收集
  • 钻研装备词缀与技能连招，构筑独一无二的角色 Build
  • 挑战设计精巧的 Boss 战，在反复磨练中提升操作技巧
  • 与其他玩家分享配装思路、速通策略与战斗录像

痛点 当前痛点：

  • 深度缺失——部分热销 ARPG 的装备系统流于表面，搭配维度单一，通关后缺乏持续动力
  • 门槛过高——硬核向作品学习曲线陡峭，大量隐性机制、复杂属性面板让新玩家无所适从
  • 体验割裂——战斗与成长体系脱节，刷宝沦为纯数值堆砌，缺乏操作层面的正反馈
  • Build 同质化——看似丰富的技能树最终收敛到少数最优解，玩家创造力受挫
3 价值与意义

「异世午梦」从立项之初就以"深度与爽感兼得"为设计信条，力求在商业与文化两个维度创造价值。

📈

商业价值

ARPG 品类全球年市场规模超百亿美元，核心用户付费意愿强、黏性极高。通过差异化的"属性容器 × 多级属性 × 状态协同"战斗体系，与市面上主流作品形成显著区隔，有望在细分市场中建立独特竞争力。买断制 + 免费大型更新的商业模式，兼顾收入稳定与玩家口碑。

⚡

体验升级

创新的多级属性系统与状态机驱动战斗，将复杂的数值成长转化为直观的操作反馈。玩家不再需要翻阅 Wiki 理解暗藏公式——每一次加点、每一件装备、每一个技能的选择，都会在战斗中产生清晰可感的差异化体验。
同时提供清晰的属性面板与实时战斗数据可视化，降低理解成本，让玩家将精力聚焦于"如何打得更好看、更聪明"。
