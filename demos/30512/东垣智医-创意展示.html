— 01 痛点洞察

经典传承之困

中医学术流派的传承千百年来依赖师徒带教，学习者在浩如烟海的古籍中 难以形成系统的临证思维。东垣之学，得其书易，得其神难。

📜

古籍庞大，检索困难

李东垣的代表作《脾胃论》《内外伤辨惑论》《兰室秘藏》《医学发明》等数万条文散落各处，交叉引用，初学者难以快速定位到所需信息。

🧠

理法方药，难以融通

"补土派"的核心思想贯穿全部著作，但学习者往往只见树木不见森林，缺乏能在临床中灵活运用东垣辨证体系的训练工具。

🤖

现有中医AI缺乏学派深度

市面上的中医AI多采用"大而全"路线，综合百家却缺乏学派定见，无法真正体现某一流派的辨证论治特色和学术个性。

👨‍⚕️

临床辅助，需求迫切

临床中医师面对复杂病例时，希望获得东垣学派视角的辨证参考，但目前缺乏能够"像东垣一样思考"的数字化辅助工具。

— 03 产品介绍

东垣智医是什么？

一个基于大语言模型的「学术流派传承智能体」—— 将李东垣的全部著作与学术思想 转化为AI可理解的思维框架与知识库，使学习者能够直接"对话"金元大家。

  • 01
    Skill 思维框架注入
    将东垣的辨内伤外感、脾胃升降、脏腑补泻等核心辨证方法提炼为可执行的推理框架，约束AI遵循东垣的思辨路径。
  • 02
    RAG 知识库实时检索
    《脾胃论》《内外伤辨惑论》《兰室秘藏》《医学发明》《东垣试效方》等全部原著的原文向量化，随时精准检索。
  • 03
    理法方药一致性校验
    内置"辨证-立法-处方"一致性检查，确保输出方剂严格对应东垣的制方原则，避免AI常见的"方证不符"问题。
  • 04
    透明溯源，引文可查
    每一次辨证结论都标注出处原文，学习者可一键追溯到东垣原著的对应段落，真正做到"有据可查"。

— 05 技术架构

Skill + RAG 双引擎

「东垣智医」采用分层架构设计，上层负责"像东垣一样思考"， 下层负责"在东垣的书中查找"，两者协同实现深度学术传承。

🧩

思维框架层

Skill Layer

将东垣辨内伤外感、脾胃升降、阴阳火辨治、脏腑补泻等核心理论编码为system prompt中的推理约束规则。

📚

知识检索层

RAG Layer

全部东垣著作的原文向量化存储，支持语义检索与精准定位，提供原文溯源能力。

🔗

推理中间层

Reasoning Bridge

协调 Skill 的思维约束与 RAG 的知识检索，执行"先辨证→再检索→后校验"的推理管线。

🎯

输出校验层

Output Guard

方-证-法一致性校验，确保输出的辨证论治逻辑自洽，标注所有引文的原始出处。

⇅
⚡ 底层模型：Claude / GPT 系列大语言模型
