成本核算系统

基于 Django + Neo4j 图数据模型的制造业成本核算平台，覆盖送货暂估、发票匹配、摊销折旧、BOM 成本核算全链路。

Django REST Framework 嵌套集树形结构 图谱数据模型 SQLite / Neo4j

核心业务流程

以"月份"为时间维度节点，实现跨月追溯与对比

① 供应商流程
送货单 → 暂估入账 → 发票匹配 → 运费摊销 → 付款

送货单作为原子单位，暂估与发票挂载其上，支持当月作废 / 跨月冲红

② 员工薪酬流程
应发工资 → 社保 + 公积金 + 个税 → 实发
③ 客户流程
发出商品 → 开票 → 收款
功能模块矩阵

12 个 Django App 协同工作，覆盖成本核算全场景

会计科目

accounts

科目树形结构，支持辅助核算、数量核算、可摊销标记

送货单

delivery

系统原子单位，承载暂估/发票/运费三类凭证状态

摊销管理

amortization

固定资产/无形资产/长期待摊/待摊费用自动计提

BOM 物料清单

bom

产品与原材料多对多关系，支撑成本核算

原材料树

material

品类→自编码→供应商编码三级树形结构

客商树

counterparty

客户与供应商统一管理，含银行账户信息

图谱应用

graph_app

Neo4j 风格的节点/边模型，业务链路可视化

库存商品

inventory_product

产成品管理，对接 BOM 与成本结转

材料余额

material_balance

期末结存与差异调整凭证管理

会计期间

periods

月度结账控制，支持跨期追溯

账套公司

company

单例公司信息，含税号、银行账户、行业

流水线

pipeline_app

业务流程编排与自动化处理

技术亮点

数据结构与业务模型的深度结合

树

嵌套集树形结构

会计科目、客商、原材料均采用 Nested Set 模型，O(1) 查询子树，支持高效层级聚合。

图

Neo4j 图数据模型

以月份为枢纽节点，将主体、凭证、业务串联成图，天然支持链路追溯与异常检测。

原

送货单原子化设计

暂估、发票、运费作为同一送货单的不同凭证状态，避免数据分散与对账难题。

跨

跨月追溯能力

月份节点作为核心维度，轻松实现跨月对比、累计查询与异常状态检测。

技术栈

成熟稳定的技术选型

Python 3.11 Django 后端框架 DRF REST API SQLite 业务数据库 Neo4j 图数据模型 Nested Set 树形结构 JSONField 凭证存储 Signals 业务联动
