/ 02

市场痛点分析

🔴

安全防护真空

市面上无一款 APP 能实现「AI 主动预警 + 语音呼救 + 110 联动」的全链路人身安全防护。女性夜行、老人独居、儿童走失等场景缺乏有效的技术守护手段。

🔴

健康管理碎片化

美柚只管女性、Keep 只管运动、亲宝宝只管育儿——每个家庭成员需要下载 3-5 个 APP，数据孤岛严重，无法形成家庭健康全景图。

🔴

老年人数字鸿沟

现有健康 APP 操作复杂，不适合老年人使用。慢病管理、用药提醒、防走失等刚需功能严重缺失。

🔴

付费意愿断层

单一人群 APP 用户生命周期短（2-4 年），获客成本高。全家庭覆盖才能摊薄成本、提升 LTV。

任意界面呼喊「小事小事，我有危险」，AI 秒级识别并自动启动报警流程，适配慌乱中无法手操作的场景。

一键 SOS 按键

APP 全局悬浮 SOS 按钮，锁屏可点击。一键触发紧急报警、位置共享、紧急联系人推送。

🧠

AI 被动识别预警

结合手机姿态传感器，智能识别老人倒地久卧、女性独处高危环境，主动弹窗问询，无应答自动触发预警。

环节说明
110 精准报警推送自动推送「实时定位 + 用户年龄 + 身体状况 + 风险场景 + 联系方式」，区别普通电话报警
双向联动推送同步推送至所有紧急联系人、子女绑定账号，多人同步救援
AI 语音自动播报求助自动外放语音求助话术，告知周边路人位置与险情
救援进度跟踪支持查看报警反馈与救援进度，险情解除后可一键撤销
隐蔽无声报警静默模式，无铃声无弹窗，后台发送求助信息，避免激怒施暴者

安全预报前置： AI 动态安全评级、高危场景提前预警、出行安全护航。防患于未然，而非等出事再报警。

🎤

AI 语音呼救

可行性：高
基于科大讯飞/阿里云 ASR API。四层误报过滤：关键词 → 声纹 → 二次确认 → 倒计时触发。
API 调用约 ¥0.002-0.005/次，月成本 <¥150。

🚔

110 报警对接

可行性：中
短期：短信/电话代拨 + AI 语音播报。长期：对接各地公安「互联网+报警」平台。全程标注「辅助报警工具」。

🧠

AI 被动识别

可行性：中高
手机加速度计 + 陀螺仪 + LSTM 端侧模型（TensorFlow Lite）。三段确认：初判 → 10秒无操作 → 语音问询 → 无应答触发。
