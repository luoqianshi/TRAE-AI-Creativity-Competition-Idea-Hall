01 / 痛点

机械臂很能干，但大多数人用不上它。

真机摆在那里，门槛却高得离谱——这中间隔着一整条"翻译链"。

代码门槛高

传统方式要写 ROS/Python 脚本、配置 MoveIt、调 IK，一个抓放任务从开发到跑通往往要数小时，普通操作员根本无法临时改任务。

仿真与真机割裂

仿真里跑通的算法迁移到真机常常"水土不服"，串口协议、话题名、坐标系对不上，sim2real 迁移成本极高，换台车要重来一次。

大模型停在聊天框

大模型已经能"听懂"人话，但它的工具调用多停留在对话框里，既看不到真机动作，也无法验证任务到底有没有完成——不可信、不可用。

02 / 方案

用数字孪生 + LangGraph，做大模型与真机之间的桥。

产品形态：一个纯前端的三维数字孪生网站（Vite + Three.js），左屏是机械臂 1:1 三维镜像，右屏是 LLM 智能体面板。无需后端，浏览器即开即用。

用户输入一句自然语言，LangGraph 编排的智能体循环开始：模型决定调用哪个工具 → 执行器在仿真中落地 → 结果回灌给模型 → 继续下一步，直到任务完成或熔断。每一步动作实时镜像到真机并下发给 STM32 下位机。

  • 双模式自动切换：有 API Key 走 LangGraph + OpenAI 兼容大模型；无 Key 自动回退正则 NLU 模式，零门槛演示。
  • 9 个 MCP 工具：perceive / move_base / plan_arm_motion / grasp / release / retract / verify / get_robot_state / get_scene_info，覆盖"看—走—抓—放—验"全链路。
  • 失败恢复：IK 不可达自动换站位、轨迹碰撞自动重规划、retract 卡死先脱离再继续，同目标失败 2 次换同类目标，最多 4 次重试。
  • 真机即插即用：ROS1/ROS2 双协议自适应，配套串口桥接包，帧格式与 STM32 逐字节一致。

04 / 能力

不止"听得懂"，还要"干得完、干得对"。

9 个 MCP 工具

感知、底盘导航、臂运动规划、抓取、放置、收回、验证、状态查询、场景查询，OpenAI function calling 标准格式。

MoveIt2 风格规划

多起始点 IK + 关节限位 + 环境碰撞检测 + 抬升/水平/下降经由点轨迹，一次调用完成规划与执行。

4 级失败恢复

IK 不可达换站位、轨迹碰撞重规划、retract 卡死先脱离、同目标失败 2 次换同类目标，最多 4 次重试。

1:1 数字孪生

直接从 URDF 解析运动学树并加载真实 STL 网格，关节 origin/axis/limit 100% 保真，所见即真机。

ROS1 / ROS2 双协议

下拉框一键切换，前端自动适配消息类型字符串与时间戳字段，配套 ROS2 串口桥接包。

YOLO 数据集生成

多布局 × 8 视角 × 多种子渲染 640×480 图像，3D 包围盒投影生成归一化标注，打包下载直接训练。

guard 防伪报完成

模型中途想偷懒结束？guard 节点检测到已开始作业但未 verify，自动注入"继续"指令最多 3 次。

多模型兼容

OpenAI / DeepSeek / 通义千问 / 智谱 / 本地 Ollama，所有 OpenAI 格式 API 即填即用，面板热改。

双相机实时画面

订阅 CompressedImage / raw Image，支持 rgb8/bgr8/mono8，双画面独立配置话题，真机视角实时回显。
