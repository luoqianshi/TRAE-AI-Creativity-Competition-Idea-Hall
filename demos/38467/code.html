— 01 / OVERVIEW

产品概览 四核驱动

围绕"识别 — 学习 — 激励 — 共建"四条主线，构建可持续运转的分类闭环。

MODULE 01

AI 智能识别

调用摄像头实时取帧，端侧轻量模型推理，毫秒级返回分类结果与置信度，支持多物体同框识别。

MODULE 02

环保知识库

覆盖上海市分类条例与国标 GB/T 19095，提供词条检索、误投案例、处置建议与本地回收点导航。

MODULE 03

用户积分系统

正确识别、连续打卡、社区贡献均可获得生态积分，可兑换实物奖励或捐赠公益项目。

MODULE 04

社区共建

用户可纠错反哺模型训练、提交新词条、参与街区排行榜，形成自循环的数据飞轮。

— 02 / AI PIPELINE

AI 图像识别 从像素到判断

端云协同：本地推理保证隐私与速度，云端校验保证准确率，构建可信赖的分类链路。

INPUT 摄像头取帧
PREPROCESS 尺寸归一化
INFERENCE MobileNetV3 · 端侧
OUTPUT 分类 + 置信度
FEEDBACK 用户纠错回传

毫秒响应，隐私优先

核心模型部署在微信小程序 inference 接口侧，平均推理时延 180ms。低置信度（<75%）结果自动转交云端二次校验，并触发用户确认。

01

图像采集与预处理

压缩至 224×224，HSV 色彩空间归一化，去除 EXIF 旋转信息。

02

端侧模型推理

MobileNetV3-Large 微调，36 类输出，Top-3 准确率 94.2%。

03

规则引擎校验

叠加地域规则（沪 / 京 / 深）、季节性物品映射与禁投清单。

04

结果呈现与反馈闭环

展示分类、处置建议、就近投放点；用户可一键纠错反哺训练集。
