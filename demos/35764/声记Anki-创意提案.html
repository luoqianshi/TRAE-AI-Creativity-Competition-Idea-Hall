💡 创意名称 + 创意介绍

创意名称：声记Anki


想解决什么问题：长时间使用Anki复习导致眼睛疲劳，而通勤、散步等碎片时间因双手和双眼被占用，无法有效利用来复习Anki卡片。


为什么会想到做这个：作为Anki的日常用户，每天需要复习大量卡片，长时间盯屏让眼睛非常疲劳。散步时想利用这段时间复习，但手机拿在手上既不安全也不方便。听觉通道在这些场景下是完全空闲的——如果能让Anki"开口说话"，就能把碎片时间变成高效复习时间。


大概是什么产品：一款Android原生App，与AnkiDroid集成，通过离线语音识别+语音合成实现纯语音交互的Anki卡片复习，支持息屏/锁屏下持续使用。

核心交互流程：自动播报卡片正面 → 用户说"看答案" → 播报卡片背面 → 用户说"简单/良好/困难/重来"评分 → 自动进入下一张卡片。全程无需看屏、无需动手。

🎯 目标用户及痛点

👤 核心用户

使用AnkiDroid进行间隔重复复习的安卓用户，尤其是每天复习量较大、用眼时间长的学习者（语言学习者、医学生、考研党等）

📍 使用场景

散步/通勤路上、做家务时、闭目休息时——任何双手或双眼被占用但听觉空闲的碎片时间

当前痛点

😫

长时间盯屏疲劳

每天复习数百张卡片，眼睛干涩疲劳，但又不敢中断复习节奏影响记忆效果

🚶

碎片时间浪费

散步、通勤时想复习但无法看手机，这些时间本可以用来完成当天的复习任务

🚫

现有方案缺失

市面上没有成熟的Anki语音交互方案，AnkiDroid本身不支持语音控制复习流程

✨ 价值与意义

📈 效率提升

将散步、通勤等碎片时间转化为有效复习时间。以每天散步30分钟计算，可额外完成约30-50张卡片的复习，显著提升间隔重复的执行率。用户不再需要在"保护眼睛"和"坚持复习"之间做取舍。

❤️ 社会价值

降低长时间用眼带来的视力健康风险，帮助用户养成更健康的学习习惯。对于视障用户或有眼部疾病的学习者，语音交互方式更是刚需——让Anki这个强大的记忆工具变得无障碍可访问。

⚙️ 技术方案概览

🗣️ 离线语音识别

Sherpa-ONNX（Paraformer模型），中文识别准确率92-95%，流式识别延迟300-500ms，无需联网

🔊 语音合成

Android内置TTS引擎，支持中文播报，系统级稳定性

📇 AnkiDroid集成

通过FlashCardsContract ContentProvider API读取卡片内容和提交评分

🔋 息屏运行

Foreground Service + WakeLock，支持锁屏下持续语音交互

Kotlin Android Native Sherpa-ONNX Android TTS AnkiDroid API Foreground Service WakeLock

🗺️ MVP开发规划

阶段1 · AnkiDroid API + TTS播报

通过API读取卡片内容并语音播报，验证AnkiDroid集成可行性

阶段2 · 离线语音识别 + 指令状态机

集成Sherpa-ONNX，实现"看答案"和评分语音指令的完整交互

阶段3 · 息屏/锁屏运行

Foreground Service + WakeLock，实现锁屏下正常语音交互

阶段4 · 辅助指令 + 反馈 + 实测优化

暂停/继续/跳过/重听/退出指令，提示音反馈，户外场景实测调优

🛡️ 风险与应对

⚠️ 户外语音识别准确率

风噪干扰下准确率可能下降。应对：MVP采用数字指令（1/2/3/4）替代自然语言评分，提升识别率；后续版本加入唤醒词机制降低误触发

⚠️ 息屏后台麦克风权限

Android 14+对后台麦克风限制严格。应对：使用foregroundServiceType="microphone"并引导用户授权；推荐搭配蓝牙耳机使用
