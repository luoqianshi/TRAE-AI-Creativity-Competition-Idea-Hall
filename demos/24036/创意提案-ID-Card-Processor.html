解决痛点

传统证件复印件制作工具严重依赖云端 API，用户上传身份证面临极大的隐私泄露风险。同时，用户拍摄的证件照片往往存在角度倾斜、背景杂乱、打印尺寸不标准（非 85.6mm × 54mm）的问题。

技术突破

WASM OpenCV.js

利用 findContours 和透视变换算法，自动检测倾斜身份证的四角并进行"视觉扶正"

ONNX Transformers.js + RMBG-1.4

在浏览器端直接运行 ONNX 模型，实现毫秒级的边缘锐利抠图

产品形态

Vue 3 Vite TypeScript Tailwind CSS

基于 Vue 3 + Vite 构建的现代化 Web 极简工具应用，支持 PWA 离线安装

核心价值

  • ◆ 绝对的隐私安全（断网可用）
  • ◆ 傻瓜式一键扶正排版
  • ◆ 物理尺寸 1:1 精确复刻打印（85.6mm × 54mm）
