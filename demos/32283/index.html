FEATURES

核心功能

六大模块，覆盖从输入到交付的完整建模链路

📤

多模态输入

支持自然语言描述、参考图上传（照片/手绘草图/三视图）、语音输入、混合输入（文字+图片）

智能补全缺失参数，自动澄清模糊需求

🔍

智能解析引擎

轮廓提取（从照片提取外形轮廓）、尺寸推断（根据参考物比例推尺寸）、视图重组（三视图→3D）、特征识别（孔/槽/螺纹/倒角）

术语标准化（口语→CAD术语），约束自动推断

⚙️

自动建模生成

双输出路径（直接下载CAD文件 / AI代理操控本地CATIA）、多格式输出（STEP/IGES/STL/F3D）、多版本方案对比（同时生成2-3个方案供选择）

生成过程可视化，实时显示"步骤3/7：正在创建倒角特征"

🎛️

参数化编辑

参数面板调参（修改数字模型同步更新）、特征树浏览（支持回退到任意特征修改）、局部重建模（框选区域修改，其他不变）

版本分支管理（类似Git，任意节点分叉尝试新方案）

🛡️

仿真与校验

快速力学分析（应力/变形估算）、干涉检查（装配体自动检测碰撞）、可制造性分析（深腔/薄壁/刀具可达性预警）

材料推荐（根据受力/重量/成本）与成本估算

🌐

协作与生态

项目制管理（按项目分组）、版本历史与对比（高亮差异）、工程图自动生成（三视图/剖视图）、BOM清单导出（Excel）

模型广场（脱敏分享，一键复制复用）
