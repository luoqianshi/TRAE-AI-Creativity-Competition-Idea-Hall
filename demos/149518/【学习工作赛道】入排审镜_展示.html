Pain Points

入排标准设计的五大顽疾

不合理的入排标准，让临床试验从起点就埋下隐患

01 // ISSUE

标准过于理论化

起草者缺乏临床一线经验，标准设定过于理想化，实际入组困难，导致入组期一拖再拖，试验成本飙升。

02 // ISSUE

入选与排除逻辑矛盾

入选条件要求某指标正常，排除条件又排除该指标正常者，逻辑冲突导致伦理委员会和审评机构质疑方案科学性。

03 // ISSUE

定义模糊缺乏量化

"严重肝肾功能不全""轻度贫血"等定性描述无具体量化值，不同中心执行标准不一，影响数据一致性。

04 // ISSUE

筛选失败率居高不下

国内III期试验平均筛选失败率30-40%，大量筛查资源浪费，受试者时间和精力被白白消耗。

05 // ISSUE

缺少系统化审查工具

入排标准审查全靠人工经验和直觉，缺乏标准化、可量化的审查工具，质量参差不齐。

入选#1 vs 排除#7：逻辑矛盾 — 肝功能条件冲突

入选标准要求ALT/AST≤2.5×ULN即符合"主要器官功能正常"，但排除标准排除"严重肝肾功能不全者"。两者界值不统一，且"严重肝功能不全"缺乏量化定义，可能导致不同中心对同一患者的判定不一致。

严重
🔴

排除#7：定义模糊 — "严重肝肾功能不全"无量值

建议明确量化标准，如"Child-Pugh B级及以上"或"ALT/AST>5×ULN且伴总胆红素>2×ULN"，以确保各中心执行标准一致。

严重
🟠

入选#1：年龄范围过宽 — 75岁上限与排除#6存在冲突

入选至75岁，但排除标准排除了6个月内有心肌梗死或不稳定心绞痛者。75岁高龄人群心血管事件发生率较高，实际入组中两者可能产生重叠，建议评估是否需要设置更低年龄上限或增加心血管风险评估。

中等
🟠

排除#2："活动性自身免疫性疾病"缺乏客观判定标准

建议增加客观判定标准，如"正在接受系统性免疫抑制剂治疗"或"DSQ评分≥X分"，降低主观判断差异。

中等
🟢

入选#3：ECOG 0-1分可能过度限制

IIIA-IIIB期NSCLC患者中ECOG 2分者占一定比例，建议评估是否可纳入ECOG 2分患者以加速入组，同时不影响安全性评估。

轻微
🟢

入选#5："预期生存期≥12周"评估主观性强

预期生存期评估在不同研究者之间差异大，建议增加客观辅助指标（如PS评分、白蛋白水平、肿瘤负荷等）作为参考。

排除#6：6个月心肌梗死窗口期需确认合理性

建议根据试验药物的作用机制和安全性数据，确认6个月窗口期是否适当，或是否需要根据心血管事件严重程度分层处理。

Technology Stack

技术架构与核心亮点

NLP + 医学知识图谱 + 逻辑推理，构建入排标准审查智能底座

01 // NLP

医学语义解析与实体识别

基于医学BERT模型，对入排标准文本进行深度语义解析，提取疾病名称、检验指标、量化阈值、药物名称等医学实体，建立结构化审查模型。

BioBERTNER医学实体
02 // LOGIC

逻辑矛盾检测引擎

基于一阶谓词逻辑和约束满足算法，将入排标准转化为逻辑规则进行自动推理，检测入选与排除条件之间的交叉冲突、循环依赖、语义矛盾。

FOLCSP推理引擎
03 // KNOWLEDGE

临床指南知识图谱

构建包含各疾病领域临床诊疗指南、CSCO/ESMO/NCCN共识、药物说明书的知识图谱，用于比对入排标准中的阈值和标准是否与临床实践一致。

Neo4j临床指南RAG
04 // EPIDEMIOLOGY

流行病学入组预测模型

整合疾病流行病学数据（发病率、人口学分布、合并症率），建立蒙特卡洛仿真模型，预测在当前入排标准下潜在可入组患者比例和入组周期。

Monte Carlo仿真入组预测

内置200+条来自GCP、ICH-GCP E6(R2)、中国药监局指导原则的合规规则，自动检查入排标准是否满足法规要求，标注合规风险点。
