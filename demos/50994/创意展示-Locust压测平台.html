/ 痛点洞察

性能测试，不应该这么麻烦

开发团队在压测环节普遍面临工具碎片化、结果不直观、协作困难等问题。 LocustPlatform 从真实工作流出发，逐一击破。

⚡

命令行操作门槛高

传统 Locust / JMeter 依赖命令行参数和 YAML 配置文件，非资深测试工程师难以快速上手，团队成员协作效率低。

📊

监控指标分散割裂

Web 版 Locust 仅提供基础 QPS 和响应时间，缺少 P95 延迟、失败率趋势、系统资源（CPU/内存）等关键维度的整合视图。

🔌

扩展与集成困难

缺乏插件体系、定时任务调度、多格式报告导出（HTML/PDF/Excel/PNG）等企业级功能，难以融入现有 DevOps 流程。

/ 核心能力

六位一体，全链路压测

从任务创建到报告导出，从单机压测到分布式协同， LocustPlatform 覆盖性能测试全生命周期。

🌐

多协议支持

HTTP/HTTPS（GET/POST/PUT/DELETE/PATCH 全方法）、原生 WebSocket 协议，满足微服务与实时应用压测需求。

📈

12 维实时监控

QPS · TPS · RPS · 平均/最大/最小/P95 响应时间 · 失败率 · 在线用户数 · 成功/失败请求数 · CPU/内存，一目了然。

🔗

分布式协同压测

Master/Worker 多机架构，水平扩展压测规模，支持节点状态管理与动态调度，单机瓶颈不再是限制。

📄

多格式报告导出

一键导出 HTML 交互报告、PDF 文档、Excel 数据表、PNG 趋势图，自由嵌入测试报告或项目管理工具。

🔌

动态插件体系

基于 Hook 系统的插件架构，支持 PRE_REQUEST / POST_REQUEST / ON_START 等扩展点，社区可贡献自定义插件。

⏰

定时任务 & API 导入

APScheduler Cron 定时调度，支持 Swagger / OpenAPI / Postman Collection 一键导入，快速复现已有接口测试。

/ 架构设计

分层清晰，扩展灵活

五层架构解耦设计，每一层职责单一、接口明确，便于团队协作与持续迭代。

UI 层 PySide6 桌面客户端 · 6 大功能页面 · 暗黑/亮色双主题 · 左侧导航 + 顶部状态栏
服务层 任务管理 · 执行队列 · 报告生成（Jinja2/fpdf2/openpyxl） · 定时调度 · API 导入
引擎层 Locust 压测引擎 · 分布式 Master/Worker 管理 · 插件加载器 · 钩子系统（Hook）
数据层 SQLite 持久化 · 5 表 CRUD · 连接池 · 事务管理 · CSV 数据驱动
扩展层 plugins/ 自动扫描加载 · Python 脚本热插拔 · 社区插件市场（规划中）
/ 应用场景

谁在使用它？

面向开发团队、测试工程师、SRE 运维的桌面级压测利器。

🧑‍💻

后端开发工程师

接口开发完成后快速验证性能基线，在本地桌面即可发起万级并发压测，无需部署额外的 Web 服务。

🧪

QA 测试工程师

可视化创建测试任务，实时监控各项指标，生成标准化压测报告，大幅降低非功能测试门槛。

🔧

SRE / 运维工程师

分布式压测 + 定时任务组合，定期执行容量评估与压力巡检，及早发现系统瓶颈与退化风险。
