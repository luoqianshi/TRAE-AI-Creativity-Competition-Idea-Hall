01 / 创意介绍

为什么是 BasePulse

一句话:从中国棒球运动,到俱乐部,到教练,到家长,到孩子——BasePulse 串联起整条成长链路,让每一次挥棒都被记录、被回望、被看见。

想解决什么问题

中国棒球基层(青少年联赛、俱乐部训练、校园比赛)缺少一套顺手又看得懂的记分与数据统计工具。教练用纸笔或 Excel,数据散落、难复盘;家长看不到孩子的成长轨迹。

为什么会想到做这个

陪孩子参加 U8 棒球训练时发现:教练一边抛打一边在纸上画记号,赛后还要手动整理成绩。海外 GameChanger 功能专业,但它面向职业化场景——重战术分析、重高阶数据、重胜负结果;BasePulse 更关注孩子的成长本身:每一次挥棒的进步、一个赛季的坚持、团队里的位置与角色,才是青少年棒球该被记住的东西。同时它全英文、不支持中国棒球术语,也不懂「教练抛打」这种 U8 场景。

大概是什么产品

移动 App(React Native / Expo)+ Web 端 + Express 后端的棒球记分与统计系统。支持实时记分、阵容管理、自动生成球员成长报告、OCR 识别纸质花名册。

02 / 目标用户及痛点

谁会用,什么时候用

核心用户:中国棒球基层生态的三类角色。

USER 01

青少年棒球教练

场景:带队训练、组织友谊赛、参加俱乐部联赛。
痛点:训练中要一边抛打一边记分,纸笔记录易错难复盘;Excel 整理数据耗时长,无法实时给家长反馈。

USER 02

球员家长

场景:周末陪孩子比赛,想了解孩子表现。
痛点:看不懂英文棒球数据;教练口头反馈信息零散;孩子的成长没有可视化档案,几年后想回顾找不到记录。

USER 03

赛事 / 俱乐部组织者

场景:组织淘汰赛、循环赛,需要赛程编排、实时比分发布、赛后报告。
痛点:赛程靠手排,对阵图手画;成绩统计滞后,无法即时发布给参赛家庭;缺乏统一的数据沉淀平台。
