✨ YOLO26 核心改进
  • 端到端 NMS-Free: 原生支持无 NMS 后处理，简化部署流程
  • DFL 移除: 移除 Distribution Focal Loss，简化检测头设计
  • MuSGD 优化器: 融合 SGD 与 Muon，提升训练稳定性
  • Progressive Loss + STAL: 渐进式损失与小目标感知标签分配
  • CPU 推理提速 43%: 针对边缘设备优化
💡 创意介绍
🎯 解决的问题
传统字符检测方法在处理文档图像时，面临着多尺度字符识别困难、小目标检测精度不足、大目标误检率高等痛点。特别是在实际文档处理场景中，字符大小差异可达数十倍，现有模型难以同时兼顾所有尺度的检测效果。
💡 灵感来源
基于 YOLO26 最新架构的高效特征提取能力，结合多尺寸训练样本策略，构建一个能够精准识别文档中不同大小字符的检测系统。灵感来源于实际 OCR 场景中对字符定位的迫切需求。
📦 产品形态
深度学习目标检测模型（YOLO26）+ 文档预处理模块 + 检测后处理引擎，支持图片和批量文档的字符检测，可集成于 OCR 系统、文档分析工具、表单识别等应用场景。
🛠️ 技术方案
🏗️ 模型架构
本项目采用 YOLO26s 模型作为基础架构，其核心组件包括：
Backbone 结构（基于 yolo26.yaml）:
  • 输入 → Conv (64, 3, 2) → P1/2
  • Conv (128, 3, 2) → P2/4
  • C3k2 × 2 → Conv (256, 3, 2) → P3/8
  • C3k2 × 2 → Conv (512, 3, 2) → P4/16
  • C3k2 × 2 → Conv (1024, 3, 2) → P5/32
  • SPPF + C2PSA 瓶颈层
Head 结构: FPN 上采样融合 P3/P4/P5 特征，三层检测头分别处理小/中/大字符。
📊 训练方法
优化器配置: AdamW 优化器，学习率 0.001，余弦学习率策略
参数 值 说明 epochs 200 训练轮数 batch_size 16 (默认) / 2 (1280px) 批次大小 imgsz 640 / 960 / 1280 输入图像尺寸 lr0 0.001 初始学习率 optimizer AdamW 优化器 cos_lr True 余弦学习率衰减 amp True FP16 半精度训练 rect True 保持宽高比训练 patience 10 早停耐心值 grad_ckpt 可选 梯度检查点（节省显存）
数据增强策略: 仅使用 HSV 颜色增强（hsv_h=0.015, hsv_s=0.7, hsv_v=0.4），关闭几何变换和 Mosaic，避免字符变形影响检测精度。
📁 数据生成流程
采用合成数据生成策略，自动生成大规模标注数据集。
数据参数 配置值 字体种类 宋体、仿宋、楷体、黑体、微软雅黑、雅黑粗体 字号范围 22, 24, 29, 32, 35, 48, 56, 72, 96 px 行间距 1.0, 1.5, 2.0 倍行高 字间距 1, 2, 3 像素 背景色 偏白、偏黄、偏黄褐、偏灰 噪声强度 轻(30%)、中(50%)、重(20%) 数据集大小 训练集 1000 张 + 验证集 100 张
⚙️ 关键技术细节
  • 像素级包围盒测量: 对标点符号和窄字符使用 measure_tight_bbox 进行像素级紧贴测量，避免全角字宽导致的大片留白
  • 小字符复制增强: 50% 概率在行尾复制 1~3 个小字符（如 .,;:iIlj1'），提高小目标检测召回率
  • 显存优化策略: FP16 训练减少 50% 显存占用，梯度检查点节省 30-40% 显存
  • 余弦学习率: 配合 AdamW 优化器，实现平滑的学习率衰减
  • 矩形训练: rect=True 保持宽高比，避免字符变形
