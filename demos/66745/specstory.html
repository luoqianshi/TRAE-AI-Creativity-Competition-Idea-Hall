PAIN POINTS · 创作痛点

为什么长篇小说
总是写到一半就崩？

长篇创作缺乏工程化约束，创作者在白板与文档之间孤军奋战，隐性成本高昂。业界统计显示，超 30 万字长篇的弃坑率超过 60%。

PAIN 01
大纲崩坏
写到 20 万字后节奏失控，三幕结构变形，主线被支线淹没，回头已无法收束。
发生率 78%
PAIN 02
人设漂移
主角性格在第 50 章悄悄变了，前文设定的口癖、习惯、价值观无追踪，读者出戏。
读者弃读主因 #2
PAIN 03
伏笔遗忘
第 3 章埋的钩子到第 80 章忘了回收，关键道具、人物动机变成「坑」，读者愤怒。
回收率 < 40%
PAIN 04
资产散落
世界观、人物卡、时间线分散在十几个文档里，无法跨作品复用，每本书都从零开始。
复用率近乎 0

🎯 立项阶段 · Requirements

产出物：题材定位书、目标读者画像、风格基调卡、商业卖点清单
  • 主笔 Agent 与用户对话，挖掘创作意图与目标受众
  • 输出可签核的「立项 spec」，包含类型、基调、字数预期、卖点矩阵
  • 质量门禁：题材定位清晰度评分 ≥ 7.5，目标读者画像完整度 100%
MULTI-AGENT · 多 Agent 协作

4 位专职 AI 编辑
像编辑部一样协作

不同阶段由不同专职 Agent 负责，模拟真实编辑部的角色分工：主笔把控全局、人物师雕琢角色、大纲师搭建结构、写手执笔、编辑审校。Agent 之间通过 spec 文档传递上下文。

主
主笔 Agent
CHIEF WRITER
把控创作全局。负责立项与世界观构建，与用户对齐创作意图，输出题材定位书与设定体系。所有 spec 文档的起点。
负责阶段：P01 立项 · P02 世界观
人
人物师 Agent
CHARACTER DESIGNER
雕琢角色灵魂。生成人物卡（性格、口癖、外貌、动机）、关系图谱、成长弧曲线。每个角色有独立「人设指纹」供后续一致性校验。
负责阶段：P03 人物设计
纲
大纲师 Agent
OUTLINE ARCHITECT
搭建故事骨架。基于世界观与人物，输出三幕结构、分章大纲、伏笔埋设/回收点矩阵。确保节奏曲线与情绪曲线符合类型范式。
负责阶段：P04 大纲 · P05 分章
编
编辑 Agent
EDITOR & PROOFREADER
把关文本质量。在初稿阶段接力写作，在审校阶段执行一致性校验、节奏分析、伏笔回收核查，输出修订清单与终稿。
负责阶段：P06 初稿 · P07 审校 · P08 定稿
QUALITY GATES · 质量门禁

12 项质量门禁
不达标不让进入下一阶段

每个阶段签核前自动跑质量门禁：人设一致性、伏笔回收率、节奏曲线、字数控制……把「写崩风险」前置暴露，而不是等到 30 万字后推倒重来。

阶段 门禁指标 通过阈值 拦截等级 失败动作

世界观设定自洽性评分≥ 8.0 / 10BLOCK回退主笔修订规则

VALUE & SIGNIFICANCE · 价值与意义

把「写崩重来」
变成可控的工程交付

💼
商业价值
瞄准 网络文学 + 剧本创作 百亿市场，SaaS 订阅模式服务创作者。 可向内容工作室、MCN 输出 团队协作版，按席位计费； 沉淀的可复用资产库（世界观/人物卡）可形成 创作组件市场 抽佣。
⚡
效率提升
通过阶段签核 + 质量门禁，把「写崩重来」的隐性成本 前置暴露。 业界统计长篇弃坑率超 60%，预计可将长篇完成率 提升 2 倍以上， 创作者单位时间产出字数提升 40%+。
🎓
教学价值
让写作学习者第一次 看见 一篇好小说是如何分阶段诞生的—— 从立项到定稿的每一步 spec 文档都是教学样本。 可与高校创意写作专业、网文平台训练营 联合培养 新人作者。
TARGET USERS · 目标用户

谁会用到
墨章工坊？

✍️
网文作者
SCENE · 长篇连载创作
痛点：百万字长篇写到中段人设崩坏、伏笔遗忘，读者流失，平台断更。
获得：阶段签核让崩坏前置暴露；伏笔矩阵自动追踪；人物指纹保证一致性。
🎬
编剧 / 剧本作者
SCENE · 剧本开发与改稿
痛点：多线叙事结构难梳理，人物动机网一改全崩，与制片人/导演沟通成本高。
获得：可视化管线展示结构；spec 文档作为沟通语言；版本管理支持多稿对比。
📚
写作学习者
SCENE · 创意写作训练
痛点：只看到成稿，看不到「一篇好小说如何分阶段诞生」，学习方法论无从下手。
获得：每阶段 spec 文档都是教学样本；可在每个节点介入学习与模仿。
🏢
内容工作室
SCENE · 团队批量产出
痛点：多人协作时设定文档散落、风格不统一，新人上手成本高，质量参差。
获得：统一 spec 仓库；可复用资产库；角色化 Agent 协作降低人力依赖。
