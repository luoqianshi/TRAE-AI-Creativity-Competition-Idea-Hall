雪线之上

AI 驱动的本地媒体收藏夹
只收藏链接，不占用内存，随时预览美好

创意介绍

想解决什么问题：各大平台的收藏功能分散且封闭，下载到手机又太占内存，用户缺少一个轻量、统一、可预览的跨平台图集收藏工具。

灵感来源：平时刷抖音、小红书看到喜欢的图集，平台收藏夹越堆越乱，下载下来手机存储告急。想要一个"只存链接、即时预览"的私人收藏空间。

产品形态：纯静态网页，通过接入免费 API 解析抖音/小红书图文链接，提取图片直链进行收藏和预览，数据保存在浏览器本地。

核心功能

链接解析粘贴抖音/小红书链接，AI 自动解析图集
批量收藏支持多行 URL 同时解析为图集
本地存储数据保存在浏览器，隐私安全不泄露
即时预览收藏即预览，无需下载占用内存
分类筛选图片/视频分类，支持关键词搜索
数据备份支持导出/导入 JSON 备份收藏

界面设计

采用玻璃拟态（Glassmorphism）设计风格，深色背景搭配柔和渐变，营造沉浸式的视觉体验。

目标用户与痛点

  • 视觉爱好者 — 喜欢收藏美图、壁纸、摄影作品，但平台收藏夹杂乱无章
  • 内容消费者 — 经常浏览抖音/小红书图集，想要统一管理的收藏入口
  • 轻量工具追求者 — 不想下载 App、不想占用手机存储，希望打开网页就能用

核心痛点：平台收藏夹分散在各 App 中难以统一管理；下载图片占用大量存储；收藏内容被算法淹没难以找回；缺少轻量级跨平台收藏预览方案。

技术实现

  • 前端：纯 HTML + CSS + JavaScript，无框架依赖，轻量高效
  • API 接入：BugPk 免费接口解析抖音、小红书、短视频链接
  • 数据存储：浏览器 localStorage 本地持久化，隐私安全
  • UI 设计：玻璃拟态 + 深色渐变背景 + 自定义滚动条
  • 响应式：适配桌面端和移动端，随时随地管理收藏

未来规划

  • 笔记日记功能 — 用收藏的图片随机插入日记，打造视觉化个人记录
  • 标签系统 — 更细粒度的内容分类管理
  • 云端同步 — 跨设备收藏数据同步
  • AI 智能分类 — 基于图片内容的自动标签与分类
