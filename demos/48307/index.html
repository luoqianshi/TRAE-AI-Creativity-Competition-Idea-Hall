01 / PAIN POINTS

时间，正在破碎。

现代人面对任务碎片化、习惯难坚持、提醒不及时、缺乏复盘四重困境。 工具越多，时间越散。

PAIN 01

工具碎片化

待办、习惯、日历分散在 3 个以上 App，数据无法联动。打开 5 个应用只为规划一个早晨。

PAIN 02

习惯难坚持

打卡应用只记录不思考。21 天养成一个习惯？没有数据洞察，第 7 天就放弃了。

PAIN 03

提醒不及时

系统推送常被 OEM 省电策略杀掉。重要会议提醒丢失，代价是真实的。

PAIN 04

缺乏复盘

工具只记录不分析，看不到时间花在哪。一周过去，复盘时只能凭感觉。

02 / CORE FEATURES

五个模块，一条轨迹。

任务、习惯、日历、AI、推送，五维联动， 从规划到执行到复盘，闭环管理。

FEATURE 01

任务管理 · 三层优先级

支持截止日期、提醒、分类、子任务。三层优先级（高/中/低）配合艾森豪威尔矩阵，让真正重要的事浮出水面。

  • 分类与标签双重组织
  • 软删除与历史回溯
  • Web 后台批量管理
FEATURE 02

习惯追踪 · 21 天可视化

每日打卡、连续天数统计、热力图可视化。看到自己的坚持，比任何鼓励都有力量。

  • 自定义打卡频率（每日/每周）
  • 热力图与连续天数
  • 归档与历史回顾
FEATURE 03

日历视图 · 月周日切换

任务与习惯在同一时间轴上呈现。看到冲突，看到空白，看到一周的全貌。

  • 月/周/日三视图无缝切换
  • 任务与习惯统一渲染
  • 跨天事件与全天事件支持
FEATURE 04

AI 时间助手 · 数据驱动建议

基于历史任务完成数据，AI 给出时间分配建议。从"被动记录"到"主动规划"，让工具会思考。

  • 任务优先级智能排序
  • 时间块智能分配建议
  • 自然语言任务录入
FEATURE 05

智能推送 · FCM 统一通道

Firebase Cloud Messaging 跨平台推送，任务提醒、习惯打卡、AI 通知，准时到达。

  • Android 16 (API 36) 适配
  • 通知点击智能路由
