💡 我们发现了什么问题

当前小学生作业辅导领域的三大痛点

📱

AI直接给答案，学生不经思考

小学生用ChatGPT/DeepSeek问作业，AI直接把答案和解题过程全说出来。孩子照抄完事，根本没有思考——长期下去会丧失独立思考能力。

👨‍👩‍👧

家长辅导有心无力

很多家长工作繁忙，回家还要辅导作业。有的家长自己也不会教，讲不清楚反而让孩子更困惑。教育焦虑普遍存在。

💰

优质辅导资源不均衡

好的一对一辅导价格昂贵，不是所有家庭都能负担。教育资源分布不均，农村和城市差距大。

✅ 不是想法，是成品——我们已经做到的

以下是已经写出来、跑起来的功能，不是规划中的蓝图

🧭

苏格拉底式Prompt引擎（已实现）

自己编写了30条系统角色规则，分"教知识"和"解题目"两种场景。遇到题目AI绝不报答案，反问"题目里有什么数字？""用加法还是减法？"——每次只引一步，做对表扬做错温和纠正，根据1-6年级自动调整语言难度。

📚

小学数学知识库（已录入）

已录入小学1-2年级数学核心知识点——数数、10以内加减法、100以内加减法、乘法口诀、两步应用题等。每个知识点含核心内容、常见错误、引导话术模板和典型例题，支持按学科和年级自动检索匹配。

⚙️

完整后端系统（已搭建）

Node.js + Express + TypeScript 搭建API服务，SQLite数据库管理用户、对话记录、知识库。实现8步对话流水线：消息 → 知识库检索 → 历史拼装 → Prompt注入 → DeepSeek大模型调用 → 流式返回引导性追问，全流程自动化。

🎮

练习模式（已实现）

AI出题后锁定输入框，学生必须作答。提交后自动验证答案——答对了AI表扬并解锁继续，答错了温和提示再来一次。杜绝跳过思考直接要答案。

📱

多端覆盖（已实现）

Taro 4 + Vue 3 框架开发，一套代码同时编译为H5网页和微信小程序。覆盖11个学科分类（小学数学/语文/英语/科学等），支持年级1-6年级、学科切换、虚拟数学符号键盘、暗色模式、PWA离线缓存。

用户系统（已实现）

支持邮箱注册登录，JWT令牌认证，bcrypt密码加密存储。对话记录持久化保存，支持查看历史对话列表。

🎯 核心设计理念

追思AI与其他AI学习工具的本质区别

🚫

绝不直接给答案

ChatGPT、DeepSeek、拍照搜题App都是一键出答案——学生抄完什么都没学会。追思AI的核心规则：遇到具体题目，宁可说自己不会，也绝不能报答案。唯一例外是学生自己答对了才能展示解题过程。

�

分场景智能判断

教知识（概念定义类）可以直接讲解，解题目（有求解目标类）必须引导。AI能区分"什么是三角形"（可答）和"这道三角形面积怎么算"（只能引），不是一刀切地什么都不说。

👦

小学生为同龄人打造

由小学生独立发起和开发。小学生最懂小学生的痛点——什么引导能听懂、什么语气不会反感、什么问题孩子真的不会。成人开发者做不到的这种同理心，是追思AI最核心的差异化壁垒。

🔜

后续规划（Phase 2-3）

语音输入、拍照搜题（OCR）、知识库扩展到小学全年级+语文、错题自动追踪、每周学习报告、向量检索升级知识库匹配精度。

👥 目标用户与使用场景

🧒

核心用户：小学1-6年级学生

遇到不会做的作业题，需要有人引导思路而不是直接给答案。自主复习时不知道从哪下手，需要结构化引导。

👨‍👩‍👧

辅助用户：家长

工作繁忙无法时刻辅导，或自己也不会教某些学科。通过AI陪伴孩子学习，同时查看学习报告了解孩子进展。

📋 核心使用场景

✏️

场景一：作业答疑

放学回家做作业，遇到不会的题。拍照或打字发给追思AI，AI逐步引导思考，学生自己解出答案。

📝

场景二：考前复习

期中期末考试前，AI帮助学生梳理本学期知识点，通过互动问答巩固薄弱环节。

🌙

场景三：睡前自学

家长没空辅导的晚上，孩子自己打开追思AI，选择想学的学科，自主探索和提问。

💎 价值与意义

🎓

教育价值

真正培养学生独立思考能力。不是"授人以鱼"而是"授人以渔"——苏格拉底式引导让学生掌握学习方法本身，受益终身。

❤️

社会价值

免费提供优质AI学习辅导，缩小城乡教育差距。缓解家长辅导焦虑，降低家庭教育支出。让每个孩子都有"AI私教"。

🚀

商业价值

中国K12教育市场规模超5000亿。先通过免费模式积累用户和口碑，后续通过增值服务（深度报告、个性化课程）变现。
