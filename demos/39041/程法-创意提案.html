程法是一款专注于多交通工具组合出行的智能路线规划工具。现有导航软件只能提供单一交通工具的最优路线，而现实中我们常常需要在地铁、公交、打车、飞机、高铁之间灵活组合。程法通过智能算法（多模式路径搜索 + 帕累托最优解集），为用户在时间、金钱、舒适度等多个维度之间寻找最优平衡点，让每一次出行都更加高效、经济。

🎯 真实场景：程法如何解决实际问题

📍 场景一：城市通勤（北京中关村 → 国贸）

  • 现有方案：高德推荐"打车直达"（45元，40分钟）或"地铁直达"（5元，50分钟）
  • 程法方案："打车到知春路地铁站（15元，15分钟）→ 地铁10号线（5元，20分钟）→ 步行5分钟" = 20元，40分钟
  • 节省：比打车省25元，比地铁省10分钟

✈️ 场景二：跨城出差（上海 → 深圳）

  • 现有方案：需分别查去机场交通、航班、深圳机场到酒店交通，手动计算衔接时间
  • 程法方案："地铁2号线到浦东机场（8元，50分钟）→ 航班（680元，2.5小时）→ 机场大巴到福田（25元，40分钟）" = 全程智能衔接，无需手动计算
  • 优势：自动考虑航班起飞时间，推荐最优出发时间，避免误机

👥 场景三：朋友聚餐（5人汇合）

  • 现有方案：A说去三里屯，B说去西单，C说去王府井...大家凭经验选择
  • 程法方案：输入5人位置，算法计算最优汇合点，考虑各人到汇合点的交通时间和费用
  • 结果：推荐最优汇合地点，5人平均到达时间最短，总交通费用最低

🛠️ 技术方案：如何实现？

技术栈

HTML5 CSS3 JavaScript 地图 API 路径规划算法 多目标优化

核心算法

  • 多模式路径搜索：基于改进的Dijkstra算法，实时计算多种交通工具的混合路径，考虑路况、班次、票价等因素
  • 多目标连续优化：采用帕累托最优解集，根据用户偏好权重（而非固定模式）在时间、金钱、舒适度之间寻找最优平衡点
  • 多人汇合算法：基于几何中位数和实时交通状况，计算让所有参与者总到达时间最短的汇合点
  • 时间衔接优化：智能匹配航班/高铁时刻与市内交通，精确计算换乘缓冲时间，避免误机误车
