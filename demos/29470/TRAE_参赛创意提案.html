🎯 生涯规划智能体

Career Planning Agent — 基于大模型五阶闭环的AI生涯规划系统

Python 3.10+ LangChain FAISS RAG DeepSeek API FastAPI
💡 创意介绍
大学生和求职者在考研/考公/就业多条路径前缺乏科学决策工具，信息碎片化、咨询成本高，容易做出不适合自己的选择。
身边大量同学在考研/就业之间反复纠结，网上信息真假难辨，缺少一个能结合「个人画像 + 真实数据 + AI推理」的个性化规划系统。
Web 应用（FastAPI 后端 + HTML/CSS/JS 前端），AI 智能体自动执行五阶闭环分析。
填信息 → AI自动分析 → 3分钟输出完整生涯规划报告+院校推荐
👥 目标用户及痛点

🎓 大三/大四考研党

不知道自己水平能报什么学校，不确定选学硕还是专硕，没有数据支撑决策。

📚 专科升本学生

专升本信息零散，不清楚各省录取率，更不知道升本后如何衔接考研。

💼 纠结型毕业生

在「考研 vs 就业 vs 考公」之间反复摇摆，缺少客观的横向对比数据。

🏳️ 少数民族考生

不了解少干计划的降分政策，不知道哪些院校有少干名额，白白浪费政策优势。

🏗️ 技术架构（七层解耦）

🎨 前端界面层

原生 HTML/CSS/JS 深色科技风页面，粒子动态背景，实时显示Agent运行日志与结果。

🤖 Agent 核心推理层

五阶闭环：Planning → Action → Observation → Reflection → Iteration，全部由 LLM 动态推理。

🔧 工具层（3大工具）

分数线分析工具 · 多路径对比工具 · 院校推荐工具 · 报告导出工具

📚 RAG 知识库层

FAISS 向量检索 + 关键词降级，内置60+条考试/院校/政策知识，杜绝模型幻觉。

💾 记忆层

JSON 文件持久化用户画像、对话历史、规划方案，重启不丢失。

🌐 LLM 调用层

兼容 OpenAI 接口，支持 DeepSeek/豆包/通义千问，延迟初始化避免空配置报错。

📤 文件导出层

一键导出 Markdown 格式生涯规划报告 + 考试分析报告。

🔄 智能体五阶闭环流程图
1

Planning 智能规划

LLM 分析用户输入，拆解任务步骤，识别缺失信息，制定工具调用计划。

2

Action 工具执行

调用 RAG 检索知识库获取真实数据 → ScoreAnalyzer 计算分数线 → PathComparison 对比多路径 → SchoolAnalyzer 匹配院校。

3

Observation 结果观察

校验工具返回数据真实性，分析分差、适配度评分、竞争数据，汇总观察结论。

4

Reflection 自我反思

识别用户短板（英语弱/数学弱/学历低），评估方案风险，推荐保底方案。让AI自己反思自己的方案。

5

Iteration 迭代调整

最多3轮反思→优化循环，输出最终版规划（短期/中期/长期+月度计划），导出Markdown报告。

⭕ 闭环反馈：Iteration 输出可再次进入 Planning，形成持续优化

  • 计算分差 + 院校层次调节

  • 对比维度：周期·成本·薪资·成功率
  • 智能适配度评分
  • 可视化柱状图展示

📋 完整报告导出

  • Markdown 结构化报告
  • 用户画像 + 分析过程 + 最终方案

  • 分月度学习计划
💎 价值与意义

⏱️ 效率提升

过去需要花几天查资料、问学长、咨询机构才能完成的生涯规划，现在 3分钟 即可输出完整方案。

📊 数据驱动

基于 60+ 条知识库真实数据（国家线、报录比、薪资数据），所有分析有据可查，杜绝空口推荐。

🔄 AI 自反思

不是简单的问答机器人，而是具备「执行→观察→反思→迭代」能力的自主智能体，方案越迭代越好。

🎯 社会价值

帮助偏远地区/少数民族/专科学生获得平等的生涯规划咨询服务，降低信息差带来的决策劣势。

🚀 运行方式
# 1. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 配置 .env 文件（DeepSeek API）
LLM_API_BASE=https://api.deepseek.com
LLM_API_KEY=sk-xxxxxxxx
LLM_MODEL_NAME=deepseek-chat

# 3. 启动后端 API（终端1）
python api_server.py

# 4. 启动前端页面（终端2）
python -m http.server 3000 -d frontend

# 5. 打开浏览器访问
http://localhost:3000
