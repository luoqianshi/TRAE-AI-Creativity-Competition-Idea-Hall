Metric Framework

指标体系全景图

点击任意指标查看计算公式，32 个核心指标覆盖研发全生命周期

⚡
交付效率
Delivery Efficiency
部署频率
单位时间内成功部署到生产的次数
= 部署次数 / 统计周期
前置时间
从代码提交到部署生产的总时间
= 部署时间 - 提交时间
周期时间
从任务开始到完成的时间
= 完成时间 - 开始时间
吞吐量
Sprint 内完成的 Story Point
= Σ 完成故事点
WIP 在制品
当前正在开发中的任务数
= 进行中任务数
评审响应时间
PR 从提交到首次评审的时间
= 首评时间 - 提交时间
🛡️
交付质量
Delivery Quality
变更失败率
导致生产故障的部署占比
= 失败部署 / 总部署 × 100%
MTTR 恢复时间
从故障发生到恢复的平均时间
= Σ 恢复时间 / 故障数
缺陷逃逸率
线上发现的缺陷占总缺陷比
= 线上缺陷 / 总缺陷 × 100%
代码覆盖率
单元测试覆盖的代码行占比
= 测试覆盖行 / 总代码行 × 100%
PR 打回率
PR 评审被要求修改的比例
= 打回PR数 / 总PR数 × 100%
技术债比率
技术债任务占总工作量的比
= 债务点数 / 总点数 × 100%
💚
团队健康
Team Health
Sprint 完成率
实际完成 vs 计划完成的比
= 完成点数 / 计划点数 × 100%
Carry Over 率
跨 Sprint 延期任务的比例
= 延期任务 / 总任务 × 100%
加班指数
非工作时间的提交和活跃度
= 非工时提交 / 总提交 × 100%
团队满意度
定期调研的团队满意度评分
= Σ 评分 / 调研人数
知识分享指数
文档/分享/评审的参与度
= 分享活动次数 / 人数
Bus Factor
最少几人离开即影响项目
= 关键模块独占人数
💰
成本效益
Cost Efficiency
单位交付成本
每个 Story Point 的人力成本
= 人力成本 / 交付点数
缺陷修复成本
修复一个线上缺陷的平均成本
= 修复投入 / 缺陷数
资源利用率
研发资源实际使用率
= 实际工时 / 可用工时 × 100%
需求交付ROI
需求价值与开发投入的比值
= 业务价值 / 开发成本
返工率
因质量问题返工的工时占比
= 返工工时 / 总工时 × 100%
云资源成本
CI/CD + 测试环境云资源费用
= Σ 云服务费用
AI Insight Engine

AI 异常趋势解读

DevMetric AI 持续监控所有指标，自动发现异常趋势并给出改进建议

🤖
AI 效能洞察
最近 7 天检测到 3 条异常趋势
⚠️
前置时间连续 3 周上升
从 2.8 天上升至 4.5 天（+60.7%），主要瓶颈在 PR 评审环节，平均评审响应时间从 4 小时增至 11 小时
💡 改进建议：①设置 PR 评审 SLA（首评 ≤4h）；②大 PR 拆分为小 PR；③引入 CODEOWNERS 自动分配评审人；④每日站会跟进阻塞 PR
🚨
变更失败率突破预警阈值
本周变更失败率 18.3%，超过 15% 预警线。集中在支付模块（占失败 62%），根因分析显示主要来自缺少集成测试覆盖
💡 改进建议：①优先补充支付模块集成测试（目标覆盖 80%）；②引入部署前自动化门禁；③支付相关变更需双人评审；④增加灰度发布比例至 30%
📊
加班指数持续偏高
近 4 周加班指数维持在 23%-28%（健康值 <15%），集中在周二/周四晚间。Sprint 完成率 92% 但 Carry Over 率上升至 18%
💡 改进建议：①Sprint 容量规划下调 15%；②检查是否存在外部依赖阻塞；③考虑增加 1 名后端开发；④周四设为"无会议日"保障专注时间
