Data Pipeline

六阶段记忆采集流水线

从原始数据到可检索记忆，全自动、全加密、全本地

Phase 1

数据源自动识别

智能检测导入目录下的文件类型——微信 txt、QQ mht、邮件 eml/mbox、笔记 md、日历 ics——自动路由到对应解析器。

Phase 2

格式解析与清洗

聊天特殊格式清洗、邮件签名剥离、HTML 标签去除、URL/手机号脱敏标记，输出统一的 RawMessage 中间格式。

Phase 3

中文预处理

jieba 分词 + 停用词过滤 + 智能切块，处理速度达 20,000 字/秒（2 核 CPU 基准），专为个人语料优化的预处理管线。

Phase 4

实体抽取与重要性评分

人名/地名/事件自动识别（F1 ≥ 85%），五维度重要性评分——交互频率、决策标记、情感强度、时间新鲜度、信息密度。

Phase 5

向量化与三维索引

Skip-Gram 128 维语义向量 + 时间线索引 + 实体索引 + 向量索引，构建 MemoryUnit 统一记忆单元模型。

Phase 6

AES-256-GCM 加密持久化

自定义 .mem 二进制格式，128 位密钥指纹验证，所有数据加密落盘。支持增量追加与完整性校验。

按人物、话题、时间范围或来源物理删除记忆，不可逆、不可恢复，你的遗忘权由你掌控。

用完即焚模式

开启后，系统退出时自动安全擦除所有记忆索引——随机数据覆盖后删除，不留痕迹。

加密导出迁移

记忆库支持 AES-256 加密导出（.mem.enc），设置独立密码，安全迁移至新设备。
