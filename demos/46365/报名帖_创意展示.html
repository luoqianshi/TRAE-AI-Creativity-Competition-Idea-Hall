💡 创意介绍

客户跟进提醒系统 · SmartCRM

想解决什么问题：外贸业务员每天面对几十上百个客户，跟进节奏混乱、到期不记得跟进、客户信息分散在 Excel 表格和邮件中，导致商机流失。需要一个轻量、智能的客户管理系统，自动提醒跟进、智能分析客户。

为什么会想到做这个：团队自身做外贸业务，深刻体会到一个业务员同时跟进 50+ 客户的痛苦——"今天该跟进谁"这个问题每天都要反复查 Excel，且不同业务员的跟进方式参差不齐，缺乏统一标准和智能辅助。

大概是什么产品：一个桌面端 + 浏览器端双模式的本地化 CRM 系统（Desktop App / Web App），支持 Excel 双向同步、AI 智能分析、邮件提醒、飞书机器人通知。

📊

仪表盘总览

客户总数、待跟进数、逾期提醒一目了然，快速掌握全局状态。

🔄

Excel 双向同步

直接导入现有 Excel 表格，修改后自动写回，零学习成本过渡。

🔔

智能跟进提醒

根据客户等级自动计算下次跟进日期，每天定时邮件提醒待办事项。

🤖

AI 深度调研

📧

邮件通知

💬

飞书机器人

接入飞书，团队内实时推送提醒，支持 AI 对话查询客户信息。

👥 目标用户及痛点

👩‍💼

外贸业务员

核心用户 · 一线客户跟进人员

使用场景：每天上班第一件事——查看今天有哪些客户需要跟进，打开系统查看仪表盘，按优先级逐一完成跟进并记录。

  • ❌ 客户太多记不住跟进周期，经常遗漏重要客户
  • ❌ 每次查 Excel 翻几十行找今天该跟进的客户，效率极低
  • ❌ 跟进记录分散在微信、邮件、本子上，无法追溯
  • ❌ 无法快速了解客户背景，每次跟进前要重新翻资料
👨‍💼

外贸团队主管 / 小企业主

决策者 · 关注团队效率和客户转化

使用场景：每天查看团队客户跟进整体情况，识别推进缓慢的客户，分配跟进任务。

  • ❌ 无法从宏观上知道团队有多少客户正在跟进、多少逾期
  • ❌ 业务员离职后客户信息散落丢失，交接困难
  • ❌ 专业 CRM 太贵（Salesforce 等每年数万），小企业用不起
🌐

SOHO 外贸个人 / 自由开发者

个人使用者 · 追求轻量和免费

使用场景：个人接外贸订单，自己管理客户资源，需要低成本解决方案。

  • ❌ 市面上 CRM 非重即贵，个人根本不需要那么复杂的功能
  • ❌ 数据云端存储担心隐私泄露，希望本地保管

💎 价值与意义

💰

商业价值

显著提升客户转化率。通过智能提醒确保每个客户在最佳时机被跟进，减少商机流失。以一家 500 客户的贸易公司为例，跟进效率提升 30% 意味着每年至少多转化 20-30 个订单。完全免费开源，相比 SaaS CRM 每年节省数万元支出。

⚡

效率提升

告别每天手动翻 Excel 的繁琐操作。系统自动计算跟进日期、生成待办清单，一键查看今日跟进任务。Excel 双向同步让老员工无需改变工作习惯，零学习成本上手。AI 深度调研将客户背景分析时间从 30 分钟缩短到 1 分钟。

🌍

社会价值

帮助中小外贸企业和个人创业者以零成本获得专业的客户管理能力，缩小与大型企业的数字化鸿沟。数据完全本地存储，不依赖云服务，保护商业隐私安全。飞书机器人的接入让团队协作更加高效透明。

🔧 技术架构

🐍 Python 3.9+ 🌐 Flask 🖥️ pywebview 🗄️ SQLite 📊 Pandas 📧 SMTP 🤖 LM Studio 🦙 Ollama 💬 飞书 API 📦 PyInstaller 🎨 HTML/CSS/JS ⏰ APScheduler
  • ✅ 纯本地运行 — 所有数据存储在本地 SQLite，无需联网，隐私安全
  • ✅ 自动跟进周期 — A 级客户每 3 天提醒，B 级每周，C 级每两周，智能排程
  • ✅ AI 多后端支持 — 自动检测 LM Studio → Ollama → OpenAI，按序降级
  • ✅ 一键打包分享 — 双击「构建 EXE」即可生成独立软件，发给同事免安装
  • ✅ Excel 智能双向同步 — 支持周列式表格结构，CRM 修改实时回写
  • ✅ 桌面 + 浏览器双模式 — 可当 Windows 软件运行，也可在浏览器中打开
