BioQuest

生物竞赛与高考智能学习平台 —— 让每一位高中生都能高效备考

💡创意来源

想解决的问题：全国每年有超过10万名高中生参加生物学联赛，同时数百万普通高中生备战高考生物。但备考资源分散、缺乏系统性学习工具，学生往往需要翻阅大量教材和习题册，学习效率低下。

灵感来源：作为生物竞赛爱好者，深知备考的艰辛——知识点庞杂、复习难以系统化。借鉴 Anki 的间隔重复算法（SM-2），结合竞赛和高考特点，打造覆盖竞赛生与普通高中生的通用学习平台。

产品形态：Web 应用（SPA），支持 PC 和移动端，无需安装，随时随地学习。

🎯目标用户及痛点

👨‍🎓
典型用户一：竞赛选手
小明是一名高二学生，目标是冲击 CNBO 国家集训队。他每天需要复习大量知识点，但传统笔记方式效率低，经常"记了就忘"。错题散落在各处，难以系统回顾。
👩‍🎓
典型用户二：普通高中生
小红是高三学生，正在备战高考生物。她希望用科学的方法巩固知识点，但市面上缺乏针对高考生物的系统化学习工具，复习效率不高。
痛点一：资源分散

竞赛生需翻阅20-30本教材；高考生知识点散落在课本、习题册中，缺乏统一入口。

痛点二：复习无序

没有科学的复习机制，被动刷题，遗忘率高，学习效果难以持久。

痛点三：缺乏反馈

不知道自己的薄弱环节，无法针对性提升，备考方向模糊。

⚡产品方案

BioQuest 集成五大核心模块，覆盖竞赛与高考双场景：

🃏
知识卡片
Anki 风格翻转卡片，SM-2 算法智能安排复习
📝
竞赛题库
联赛真题、模拟卷、逻辑推理专项训练
📖
高考题库
历年高考真题、知识点专项练习、智能组卷
📊
学习分析
正确率趋势、知识点雷达图、每日打卡
💬
社区讨论
发帖交流、Markdown 支持、经验分享
原生 JavaScript Python Flask Supabase JWT 认证 SM-2 算法
