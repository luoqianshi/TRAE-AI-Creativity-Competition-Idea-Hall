01 / CREATIVE INTRO

创意介绍

从一线科研痛点出发，用 AI 重构申报文书的生产方式

!

想解决什么问题

职务创新成果申报涉及专利、软著两类知识产权，配套附件多达 17 种，格式要求极严（字体、字号、勾选框、表格嵌套层层嵌套），手工填写易错、耗时长、反复核对仍难达标。

?

为什么会想到做这个

接触到油田科研一线后发现，工程师把大量精力耗费在文书整理而非技术创新上。一套完整申报材料往往要花两三天反复改格式，而这本该是机器最擅长的事——于是决定用 AI 把它自动化掉。

▢

大概是什么产品

Windows 桌面应用，内置 LLM 智能体 + Python 文档引擎。用户上传技术交底书，系统自动完成查新检索、文书撰写、格式填充、勾选框标记，一键导出符合规范的完整申报材料包。

05 / NOVELTY SEARCH

查新功能

AI 驱动的专利新颖性检索，让授权前景判断有据可依

查新检索四步流程

01

提取技术要素

LLM 从交底书提取技术领域、技术问题、必要/附加技术特征、技术效果

02

构建检索式

基于 IPC 分类自动构建检索式，调用专利检索 API 获取相关文献

03

特征对比

逐篇对比相关专利的技术特征，生成特征对比表

04

新颖性结论

综合对比结果输出新颖性结论，辅助判断授权前景
