"它不怕了"
宠物医院双用户体验设计

将不会说话的宠物纳入独立用户角色，通过软件·硬件·空间三触点协同，重构宠物医院就诊体验——让每一次就诊都从"恐惧经历"变为"被温柔对待的安心旅程"。

🎯 服务设计 + 交互设计 👥 双用户（宠物·主人） 📅 2026 🛠️ 含可交互原型
01 · THE WHY

背景与痛点

宠物就诊的"恐惧黑洞"远比想象中严重——这不是"不听话"，而是真实的身心应激反应。而主人的焦虑与无助，让这个过程雪上加霜。核心矛盾：医疗效率 vs 动物福利 + 主人情感需求。

⚠️

三大核心痛点

环境恐惧：陌生气味+刺眼光线+尖锐声响 → 本能应激

信息黑箱：主人不知何时轮到、进展如何 → 焦虑累积

空间粗暴：以医疗效率为中心，完全忽视动物福利

🔄

双重用户困境

宠物（隐性用户）：无法用语言表达恐惧，行为信号（抓咬/躲藏）常被误解为"不乖"

主人（显性用户）：在"为了健康"与"不忍心看它受罪"之间反复挣扎，缺乏可控感

02 · USER RESEARCH

用户调研与洞见

03 · SYSTEM ARCHITECTURE

系统架构与状态设计

从"人本位医疗效率"重构为"宠物+主人双中心"的服务系统。核心逻辑：引入预诊缓冲机制打破"恐惧累积曲线"，通过状态机管理就诊全流程的每个节点。

✨ 渐进适应型

  • 1预约填应激等级 → 系统推荐低敏时段
  • 2到店取号 → 花朵引导 → 分区候诊
  • 3低敏候诊区（隔间/安抚舱）→ 逐渐适应
  • 4预诊缓冲室过渡（10-15分钟）
  • 5可视化诊疗 → 正向反馈 → 离院

❌ 恐惧累积型

  • 1预约（无应激信息）→ 焦虑出门
  • 2到店 → 冰冷前台登记 → 紧张加剧
  • 3候诊区（嘈杂）→ 恐惧累积至峰值
  • 4直接进入诊室 → 恐惧爆发 → 诊疗受阻
  • 5离院（无后续关怀）→ 负面记忆强化

📌 场景 01 · 预约准备
林女士打开App，选择"阳光宠物医院·王医生"，填写年糕应激等级（高）。系统推荐上午10点低敏时段，生成准备清单：航空箱铺熟悉毯子、准备零食、提前15分钟到5号隔间。

🌺 花朵进度·反馈回路

交互装置根据候诊人数动态变化——花苞→半开→绽放的视觉隐喻，将"被动排队"转化为"可参与的互动体验"。每次更新伴随轻柔触觉反馈，减少了用户对"等待"的线性感知。研究表明，自然意象的进度反馈比数字倒计时能降低约32%的焦虑感。

🎯 透明度机制：用户实时看到排队位置和等待时间，消除"黑箱焦虑"。

🔄 双重用户·反馈闭环

宠物应激行为通过App推送和硬件联动形成闭环：App监测主人输入的宠物状态 → 推荐安抚方案（音轨/安抚舱）→ 宠物状态改善 → App正向反馈强化。

🎯 人在回路：宠物不会说话，但系统让它们的"沉默反馈"被看见、被响应——主人始终是干预链条中的主动决策者，而非被动旁观者。

SUMMARY

设计总结

"它不怕了"是一个典型的服务设计 + 交互设计项目。通过"痛点发现→用户调研→系统重构→交互落地→场景展示"的完整设计链，展示了如何从具体社会议题出发，通过数字化交互手段重构物理空间体验。

项目的核心创新在于双用户设计方法论——将不会说话的宠物作为独立用户纳入设计范畴，通过行为观察和应激指征建立设计准则，同时关注主人的信息需求与情感支持。

三个触点层（软件 · 硬件 · 空间）的协同设计，将一次充满不确定性的恐慌经历，转变为可预测、有缓冲、被支持的安心旅程。
