购物决策助手

基于大模型的多轮决策分析 Agent · 3 分钟给出推荐，10 分钟出完整报告

1创意名称 + 创意介绍

购物决策助手 —— 一个基于大模型的多轮决策分析 Agent，帮助用户在不熟悉的商品领域中，3 分钟内获得产品推荐，10 分钟内完成深度决策分析。

想解决什么问题

当用户面对一个不熟悉的品类（如音箱、降噪耳机）产生购买意向时，往往面临三重困境：

  • 参数看不懂：功率、频响、单元材质、蓝牙版本等技术细节多，普通人缺乏快速理解的框架
  • 型号分不清：同一产品线的 Pro / Max / Ultra 版本多达十余种，逐一对比耗时巨大
  • 评论信不过：电商刷单控评严重，通用大模型直接提问容易产生幻觉且上下文丢失

核心定位：不是追求 100% 可信，而是为不了解该领域的用户快速建立一个"80 分"的决策参照系——让他们知道该看什么维度、该怎么比较、哪些产品适合自己。

产品流程
🔍

→
📋

👈

左滑 dislike / 右滑 like 快速表达偏好，缩小候选范围

对偏好产品做多维度客观比较：性能、场景适配、性价比、售后

📄
报告输出
生成决策报告，支持 JSON 上下文沉淀和产品收藏复用
技术方案
  • 数据来源：Demo 阶段依赖大模型知识（保证信息近半年内有效），高时效敏感参数标注置信度提醒用户核实；后续接入电商 API 获取实时商品参数，再逐步引入专业评测媒体结构化数据
  • 上下文管理：通过多个 Skill 链式调用，将五步流程拆解为子 Skill，强制 JSON 格式上下文输入输出，解决多轮对话中的上下文丢失问题
  • 幻觉控制 · 推理链显式化：在深度分析环节，要求大模型对每个推荐产品输出三段式推理链（用户需求 → 产品维度表现 → 推荐结论），强制引用需求挖掘阶段的结构化输出。不限制推荐范围，但要求模型"说清楚为什么推荐"，使编造内容难以自圆其说，用户也更容易发现破绽
  • 幻觉控制 · 用户纠偏机制：报告输出后每个推荐产品旁设"信息有误？"反馈入口，用户可标注产品不存在、参数有误、价格过时等问题，纠偏记录写入决策沉淀的 JSON 上下文，下次同类品类决策时作为历史经验注入 prompt，实现越用越准
  • 长期规划：自研/微调刷单检测模型，构建可信评测库，提升信息可信度

核心使用场景

用户临时有购买意向但不了解该品类，希望在 3-10 分钟内获得一份相对客观、结构化的购买参考，明确自己需要什么、哪些产品适合自己。适用商品为具备可比较客观维度的产品，如数码家电、家居硬件、运动户外等。

3价值与意义
用户价值
⚡ 效率提升

将原本 2-3 小时的对比调研缩短至 10 分钟以内，节约 85%+ 决策时间；避免错误购买带来的退换货沉没成本。

🧭 认知降维

为不了解该领域的用户快速建立知识框架和评价参照物，知道"该看什么维度"，从"价格-销量"单一维度引导至多维度综合考量。

💾 决策沉淀

决策过程的 JSON 上下文和产品收藏可保存复用，避免每次决策从零开始，把"一次性劳动"变成"可迭代的决策资产"。

商业价值
🎯 精准流量入口

购物决策本身带有极强购买意愿和消费能力，产品若能影响用户"买什么"，即掌握高价值的电商导购入口。

💰 变现路径

通过电商平台优惠券、广告等方式变现，不干预推荐排序，保证客观中立——信任是唯一壁垒，佣金模式不牺牲中立性。

🔄 数据飞轮

积累的品类参数库、用户偏好、决策路径可反哺品牌方选品和新品预测，开辟 ToB 数据服务第二增长曲线。

社会价值
⚖️ 降低信息不对称

通过聚合分析帮助消费者不被虚假评论和营销话术绑架，促进健康透明的消费环境。

🌱 减少资源浪费

帮助用户"一次买对"，从源头减少因错买、闲置、退货造成的物流与资源浪费，契合绿色消费趋势。

🤝 辅助弱势群体

对信息搜索能力较弱的人群（如老年人、不熟悉数码产品者）提供友好引导，减少数字鸿沟带来的购物损失。
