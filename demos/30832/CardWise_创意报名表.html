赛道：学习工作
产品形态：基于 Web 的智能学习工具

一、创意名称与介绍

1.1 创意名称

CardWise · 智卡 —— 让每一篇长文，都长成可复习的知识卡片。

1.2 想解决什么问题

在学习和研究中，我们经常阅读大量论文、教材章节和长文章。读完后，核心要点往往被埋没在海量文字里，复习时只能重新翻阅，既低效又容易遗漏关键信息。我们需要一种方式，能把深度内容自动"压扁"成可检索、可练习、可分享的知识单元。

1.3 为什么会想到做这个

自己在备考和做技术调研时，经常要从几十上百页资料里手工整理笔记，费时且容易断更。试过市面上的 AI 笔记产品，但大多只做摘要，不支持"问答式复习"。既然会写程序，就想做一个能真正帮自己、也能帮别人学习的工具。

1.4 大概是什么产品

基于 Web 的智能学习工具。用户上传 PDF / 粘贴长文，系统自动生成结构化知识卡片（问答、概念、公式、关键证据），并支持复习模式和卡片导出分享。

二、目标用户及痛点

2.1 面向哪些用户

  • 学生群体：需要大量阅读文献的高年级学生、研究生——尤其是备考研究生、留学考试的学生
  • 技术研究者：需要快速吸收新领域论文的工程师、研究员
  • 知识工作者：产品经理、内容创作者、分析师——需要高效整理资料

2.2 在什么场景下使用

场景 用户目标 使用方式
读论文 快速抓住核心贡献和实验结果 上传 PDF，生成问答卡，用于复试/答辩前复习
备考 把厚教材一章一章地吃透 逐章上传，逐步积累个人复习卡片库
项目调研 系统化整理多篇竞品分析 统一整理为卡片，方便团队互相问答

2.3 当前痛点 —— 没有这个产品时会怎样

痛点 具体描述 CardWise 的解决方案
AI 摘要"不够用" 只给结论，不给可练习的知识单元 生成问答式卡片，用户可主动练习
手工做卡片太累 Anki/Quizlet 一条条输入，学习成本高 一键生成，用户只需确认和编辑
跨资料检索困难 想对比多篇文献中的同一概念，只能分别翻找 卡片可按关键词聚合，一键对比
复习体验割裂 笔记、卡片、练习、分享要在 3-4 个工具间切换 一站式流程：上传→生成→复习→分享

三、价值与意义

3.1 效率提升

CardWise 把"阅读 → 提炼 → 复习"的流程从小时级压缩到分钟级。一份 30 页的论文，传统方式可能需要 1-2 小时做笔记，使用本工具后可以在 5-10 分钟内得到一份可直接进入复习循环的卡片集。对于高频学习者来说，每个月能"多出来"几十个小时的高质量学习时间。

3.2 社会价值

知识的吸收和传播是每个人的刚需，但高质量的学习辅助工具对非技术用户并不友好。CardWise 的设计目标是"零门槛"——不需要懂 AI、不需要写 Prompt，只要会上传文件就能得到有价值的学习成果。我们希望通过降低知识消费的技术门槛，让更多人获得高质量的学习体验。

四、可行性检查（自问自答）

Q1：用户真的会用它吗？
有风险，但可通过 MVP 设计化解。
✅ 高匹配用户：论文党和电子材料党（PDF 课件、电子教材、在线长文）——他们本来就有电子版，上传零成本
❌ 暂不覆盖：纸质书用户——不会为了"生成卡片"而去扫描整本书
结论：可行。MVP 锁定"已有电子材料"的用户，不试图解决"纸质书"问题。
Q2：AI 生成的卡片质量够吗？
LLM 可能出错（张冠李戴、概念不准确）。对于"备考用户"来说，错误卡片是致命的。

三大解决方案：
  1️⃣ 原文引用：每张卡片带 PDF 原文位置跳转——用户可以自行验证
  2️⃣ 状态标签："待验证 / 已确认 / 错误"三档，用户掌握最终判断权
  3️⃣ 保守生成：只基于原文内容生成，不做推理和扩展

结论：风险存在，但有明确的解决路径。核心定位是"学习辅助"而非"学习替代"。
Q3：和 ChatGPT + Notion + Anki 三件套有区别吗？
核心差异在于"端到端体验"。三件套的每个工具都很强，但它们之间没有被打通——一个用户如果读完一篇论文要在三个工具里走一遍流程，TA 会放弃。CardWise 的核心价值就是把这三步变成一步。
能力 ChatGPT + Notion + Anki CardWise
上手成本 高——3 个工具反复切换 低——一条线：上传→生成→复习
卡片格式 用户手动输入，格式不一致 自动生成标准化卡片
原文关联 弱——卡片和原文无链接 强——每张卡片可跳转原文
跨资料检索 几乎做不到 天然支持——同概念卡片可聚合
Q4：用户用完一次后，为什么会回来？
两大留存机制：
  1️⃣ 卡片资产：用户生成的卡片是个人知识资产——用得越久，卡片库越大，迁移成本越高
  2️⃣ 复习循环：内置间隔重复算法，根据用户"记住/忘记"反馈自动推送复习卡片——让产品从"工具"变成"学习伴侣"

⚠️ 风险提示：如果 MVP 只做"上传→生成卡片"，那它就是一次性工具。MVP 至少要包含简化版复习推送功能。
Q5：成本和合规能撑住吗？
MVP 阶段完全可控。

💰 成本控制：
  • MVP 限定每次上传不超过 50 页，每页生成不超过 3 张卡片——单次成本可控在几毛钱
  • 大赛阶段全部免费（用于收集用户数据），赛后考虑"免费额度 + 付费升级"模型

⚖️ 合规风险：
  • 明确声明"用户上传内容仅供个人学习使用"
  • 产品不存储和分享原始文件，只存储处理后的卡片数据
  • 引导使用"论文、公开文章、用户自己写的笔记"三类安全内容

结论：核心是做好用量上限和内容边界声明。

五、MVP 功能优先级

优先级 功能 说明 是否 MVP 必需
★★★ PDF / 文本上传解析 核心输入能力，支持中英文文档 ✅ 必需
★★★ AI 问答卡片生成 把内容拆解为问答式卡片，带原文引用 ✅ 必需
★★★ 卡片跳转原文位置 差异化核心——三件套做不到 ✅ 必需
★★☆ 简化版复习推送 "记住/忘记"二选一，基于间隔重复算法 ✅ 必需——保障留存
★★☆ 卡片状态标签 "待验证/已确认/错误"三档，降低 AI 风险 ⭐ 强烈建议
★☆☆ 卡片导出/分享 Markdown 导出，生成分享链接 可延后至 v2
★☆☆ 跨资料卡片检索 按关键词聚合不同资料的卡片 可延后至 v2

🌟 关键洞察

如果 MVP 只有"上传 PDF → 生成卡片"这一个功能，它就是个用完即走的 AI Demo，缺乏记忆点和留存。

但只要再加「每张卡片可跳转原文位置」这一个功能，它就变成了一个三件套做不到的差异化学习工具——

这个功能实现成本极低（只需记录 PDF 页码/行号），但用户感知价值巨大。
