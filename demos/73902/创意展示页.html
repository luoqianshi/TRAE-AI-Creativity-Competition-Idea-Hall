一、创意介绍

想解决什么问题

电气专业学生在学习 EPLAN 电气设计软件时，面临两大痛点：一是 EPLAN 操作复杂、学习曲线陡峭，初学者画一张简单的电机控制电路图需要花费大量时间在符号查找、放置和连线操作上；二是手绘或纸质电路原理图转换为 EPLAN 格式耗时费力，学生课上学习的电路知识难以快速转化为规范的电气图纸。

为什么会想到做这个

作为电气专业学生，在课程设计和实验中频繁使用 EPLAN 绘制电气原理图。每次画图都需要反复切换菜单、搜索符号、调整位置，一个简单的三相电机控制电路可能需要半小时以上。如果有一个 AI Agent，能像 CAD 的辅助绘图工具一样，"你描述、它画图"，学习效率将大幅提升。

产品形态

一个基于 TRAE Work 的 AI Agent。用户通过自然语言描述电气原理图，Agent 自动解析电路结构，调用本机 EPLAN Electric P8 的 COM API 接口，在 EPLAN 中自动生成完整的电气原理图。

二、目标用户及痛点

面向用户

  • 电气工程及其自动化专业在校学生（本科/高职）
  • 正在学习 EPLAN 电气设计课程的初学者
  • 需要快速将电路知识转化为 EPLAN 图纸的实训场景

使用场景

  • 课上学习：老师讲解电机控制电路原理后，学生通过 Agent 快速生成对应 EPLAN 图纸，加深理解
  • 课程设计：根据设计任务书描述，自动生成初始图纸，在此基础上修改完善
  • 课后复习：通过文字描述回顾电路知识，同步生成规范图纸辅助记忆

当前痛点

  1. EPLAN 符号库庞大，初学者查找一个符号需要翻找多层菜单，效率极低
  2. 手动放置符号、调整位置、连线对齐耗时费力，一张简单图纸可能需要 30 分钟以上
  3. 手绘原理图或教材上的电路图，转换为 EPLAN 格式需要重复劳动，容易出错
  4. 学生容易在繁琐的操作中分散注意力，无法专注于电路原理本身的学习

三、价值与意义

学习效率提升 — 将"画一张原理图"的时间从 30 分钟以上缩短到 1 分钟以内。学生可以把更多时间花在理解电路原理、分析控制逻辑上。

降低学习门槛 — 初学者不需要先花大量时间学习 EPLAN 的操作细节，就能快速生成规范的电气图纸。Agent 生成的图纸本身就是最好的"标准范例"。

连接知识与实践 — 学生课上学习的电路理论知识，可以通过自然语言描述直接转化为可编辑的工程图纸，打通"理论-图纸"的转化链路。

技术栈

层级技术理由
AI 层TRAE Agent + 内置大模型大赛要求使用 TRAE，零成本使用 AI 能力
中间层Python 3.10+语法简单，适合非编程专业学生上手
API 层Python win32com.client通过 COM 调用 EPLAN，无需编译 DLL
目标软件EPLAN Electric P8专业电气设计软件，行业标准工具

核心流程

  1. 用户在 TRAE Agent 中输入自然语言电路描述
  2. Agent 解析用户意图，匹配预设电路模板或生成结构化 JSON
  3. Python 脚本读取 JSON，调用 EPLAN COM API 执行绘图
  4. EPLAN 中自动生成完整电气原理图，用户可直接查看和编辑

五、初赛 MVP 功能

初赛阶段目标：实现"文字输入 → AI 理解 → EPLAN 自动出图"的完整链路。

必做功能

  • 自然语言输入：用户通过文字描述电路结构和元件
  • AI 解析引擎：将自然语言解析为结构化电路 JSON
  • EPLAN 自动绘图：创建页面、放置符号、自动连线、设置命名
  • 预设电路模板库：内置 5 个典型教学电路模板，确保 Demo 稳定
  • TRAE Agent 对话界面：在 TRAE 中实现交互式对话体验

预设电路模板（初赛）

  1. 三相电机直接启动控制电路
  2. 电机正反转控制电路
  3. 星三角降压启动控制电路
  4. 简单照明控制电路
  5. 自定义简单电路（用户自由描述）

六、复赛扩展计划

  • 图片/手绘草图识别：使用多模态大模型识别手绘电路图
  • 智能布局算法：自动计算元件位置，支持多页自动分页
  • 交互式修正：自然语言修改已生成结果
  • 电路模板库扩展：支持 PLC 控制、变频器、伺服驱动等更多电路
  • 元件选型建议：根据负载功率自动推荐元件规格
  • 用户界面优化：Web 界面展示绘图进度和结果预览

七、Demo 演示计划

由于 EPLAN 是专业桌面软件，评审环境可能未安装。Demo 采用预录演示视频 + TRAE Agent 交互展示的组合方式：

  1. 视频展示：从用户输入到 EPLAN 自动生成原理图的完整过程
  2. Agent 交互：在 TRAE 中展示 Agent 对话界面和 JSON 解析结果的可视化
