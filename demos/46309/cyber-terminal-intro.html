✦ Pain Points

传统终端让你抓狂的时刻

那些日常开发中反复遇到、但又懒得解决的痛点，Cyber Terminal 一一击破。

⚠

总要多个窗口来回切换

查个 API 文档切换到浏览器，搜个报错切到 ChatGPT，切回终端写命令…… 一天下来光 Alt+Tab 就能按到手指酸。

✅ 内置 WebView2 预览面板，查文档/搜 AI 不用出终端
⚡

相同的命令重复敲

git push、npm run dev、docker compose up…… 每天几十遍的肌肉记忆，偶尔手误就翻车。

✅ 快捷命令栏一键插入，支持自动执行 & 拖拽排序
📂

项目目录来回 cd

同时维护三四个项目，每次都要 cd 到对应目录，Tab 补全再快也是多一步操作。

✅ 目录书签栏，点击即切换，支持自动初始化命令
🧠

终端报错手动复制去百度

跑崩了 → 鼠标选中报错 → Ctrl+C → 切浏览器 → Ctrl+V → 回车。拜托，2026 年了。

✦ Features

不只是终端，是数智工作台

每一个细节都为开发者和效率工程师精心打磨，从界面到交互，从功能到性能。

⊞

嵌入式 WebView2 预览

内置原生 WebView2 浏览器面板，支持多标签页。查文档、看页面、调接口，全程不离开终端。关闭后 5 分钟内可恢复缓存。

多标签5min 缓存WebView2
⟐

右键 AI 搜索

选中终端中的报错或代码，右键一键直达 7 大 AI 平台：豆包、通义千问、元宝、DeepSeek、智谱清言、Kimi、讯飞星火。自动复制选中文本到剪贴板。

豆包DeepSeekQwenKimi
☰

浏览器式多标签管理

每个标签独立 PTY 会话 + 独立工作目录 + 独立预览实例。Ctrl+T 新建、Ctrl+W 关闭、Ctrl+Tab 切换，标签间互不干扰。

Ctrl+TCtrl+W独立会话
⌘

快捷命令栏

预设你最常用的命令，一键发送到终端。支持自动追加回车执行、拖拽排序、行内编辑，彻底告别反复敲相同命令。

一键执行自动运行拖拽排序
✦

目录书签 + 自动命令

收藏项目目录，点击即创建新标签并自动 cd。支持设置自动初始化命令，每个目录打开后自动运行（如 npm install、git pull）。

一键导航自动命令目录收藏
↔

可拖拽分屏

终端和预览面板之间的分隔条支持拖拽调整宽度比例，30%~80% 自由调节，大小比例自动持久化到本地存储。

拖拽调节自动保存
◷

终端功能增强

滚动到顶部/底部一键切换、中断命令（◼ 按钮发送 Ctrl+C + y）、最小化恢复无变形、URL 点击自动在预览面板打开。

滚动控制中断命令URL 跳转
▣

赛博科技主题

深色底色 + 霓虹蓝紫渐变，Orbitron + JetBrains Mono 双字体组合，自定义滚动条 + 毛玻璃效果。颜值即生产力。

暗色主题霓虹渐变毛玻璃
