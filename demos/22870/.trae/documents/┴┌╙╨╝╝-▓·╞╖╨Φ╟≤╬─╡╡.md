# 邻有技 - 产品需求文档 (PRD)

## 1. 产品概述

"邻有技"是一款基于小区LBS的社区技能互换互助微信小程序，旨在解决居民日常小需求找专人太贵、找邻居不好意思开口的痛点，同时为有手艺的居民提供利用闲时赚零花钱或换服务的渠道。

核心价值：整合社区内分散的技能资源，实现邻里资源高效匹配，降低居民生活成本，搭建邻里互助的信任纽带。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 服务提供者 | 微信授权登录 | 发布技能、接单、管理订单、查看收益 |
| 服务需求者 | 微信授权登录 | 发布需求、浏览技能、下单、评价 |
| 双角色用户 | 微信授权登录 | 同时具备服务提供和需求发布能力 |

### 2.2 功能模块

1. **首页**: 技能分类展示、附近技能推荐、搜索功能、轮播公告
2. **技能市场**: 技能列表、分类筛选、距离排序、价格区间筛选
3. **发布页**: 技能发布表单、需求发布表单、图片上传
4. **订单中心**: 订单列表、订单状态管理、订单详情
5. **个人中心**: 用户信息、我的技能、我的订单、评价管理、钱包

## 3. 核心流程

### 3.1 服务需求者流程

用户打开小程序 → 浏览/搜索技能 → 查看技能详情 → 发起预约 → 等待接单 → 服务进行中 → 确认完成 → 评价

```mermaid
flowchart TD
    "A[打开小程序]" --> "B[浏览/搜索技能]"
    "B" --> "C[查看技能详情]"
    "C" --> "D[发起预约]"
    "D" --> "E{等待接单}"
    "E" -->|接单成功| "F[服务进行中]"
    "E" -->|超时无人接单| "G[重新发布或取消]"
    "F" --> "H[确认完成]"
    "H" --> "I[评价服务]"
    "I" --> "J[订单结束]"
```

### 3.2 服务提供者流程

用户注册/登录 → 完善个人信息 → 发布技能 → 收到订单通知 → 确认接单 → 提供服务 → 等待确认 → 收到评价

```mermaid
flowchart TD
    "A[注册/登录]" --> "B[完善个人信息]"
    "B" --> "C[发布技能]"
    "C" --> "D[收到订单通知]"
    "D" --> "E{确认接单}"
    "E" -->|接受| "F[提供服务]"
    "E" -->|拒绝| "G[订单流转他人]"
    "F" --> "H[等待确认完成]"
    "H" --> "I[收到评价]"
    "I" --> "J[收益到账]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 温暖橙 (#FF6B35) - 代表社区温暖、邻里互助
- **辅助色**: 清新绿 (#2ECC71) - 代表环保、可持续的生活方式
- **中性色**: 暖灰系列 (#F5F5F5, #E0E0E0, #9E9E9E, #424242)
- **按钮风格**: 圆角胶囊按钮，带轻微阴影，hover时上浮效果
- **字体**: 
  - 标题: PingFang SC Medium, 18-24px
  - 正文: PingFang SC Regular, 14-16px
  - 辅助文字: PingFang SC Light, 12px
- **布局风格**: 卡片式布局，顶部固定导航，底部TabBar
- **图标风格**: 圆角线性图标，配合品牌色

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 搜索栏 | 白色背景，圆角输入框，搜索图标，语音按钮 |
| 首页 | 分类导航 | 横向滚动，圆形图标+文字，6-8个分类 |
| 首页 | 技能卡片 | 白色卡片，左侧图片，右侧信息，底部价格和距离 |
| 首页 | 轮播图 | 全宽，圆角，自动轮播，指示器 |
| 技能市场 | 筛选栏 | 固定顶部，下拉筛选器，标签式选择 |
| 技能市场 | 列表项 | 卡片式，头像+技能名+评分+价格+距离+标签 |
| 技能详情 | 头部 | 大图展示，技能名称，评分，服务次数 |
| 技能详情 | 预约按钮 | 底部固定，橙色主按钮，白色文字 |
| 发布页 | 表单 | 分组卡片，输入框，选择器，图片上传区 |
| 订单中心 | Tab栏 | 固定顶部，状态分类Tab |
| 订单中心 | 订单卡片 | 服务名+时间+状态+操作按钮 |
| 个人中心 | 头像区 | 大头像，昵称，认证标签，信用分展示 |
| 个人中心 | 功能列表 | 图标+文字+箭头，分组卡片 |

### 4.3 响应式设计

- 采用移动优先设计，适配微信小程序环境
- 支持不同屏幕尺寸的iPhone和Android设备
- 触摸优化：按钮最小点击区域44x44px，适当增加触摸反馈

### 4.4 动效设计

- 页面切换：右滑返回，淡入淡出
- 卡片加载：骨架屏占位
- 按钮交互：点击缩放+颜色变化
- 下拉刷新：自定义动画
- 订单状态：进度条动画
