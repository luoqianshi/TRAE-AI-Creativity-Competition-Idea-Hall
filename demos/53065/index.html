理念起源

始于重庆的创新思考

化妆师这份工作的尽头是"培训"——把技术传承下去，既是对个人职业生涯的延续，也是对行业的一点贡献。

2017至2018年间，我们的化妆工作室在重庆同行中率先提出了"Travel Class"理念。我们深知，传统的美妆培训受限于时间和空间，许多热爱美妆的朋友因为地域原因无法获得优质的学习资源。

于是，我们开始思考：学习，是否可以有另一种可能？

"让每一个热爱美妆的人，无论身处何地，都能轻松参与到高质量的学习中来。"

关于创始人

用热爱传递美好

资深化妆师 / Travel Class 理念创始人

从一名职业化妆师，到化妆工作室的创始人，再到 Travel Class 理念的提出者，一路走来，始终坚信技术的价值在于分享与传承。

2017年，在重庆的工作室里，我们首次提出了"Travel Class"的概念——这不仅是一种教学模式的创新，更是对"学习"这个词的重新定义。我们相信，真正的学习不应该被教室的四面墙所限制，它可以发生在旅途中，发生在不同的城市文化里，发生在与不同背景的人们交流碰撞的每一个瞬间。

我们希望 Travel Class 能成为一座桥梁，让每一个热爱美妆的人都能跨越地域的阻隔，与美好的技术、美好的人、美好的风景相遇。
