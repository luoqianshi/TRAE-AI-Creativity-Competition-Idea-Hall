一、创意介绍

1.1 想解决什么问题

问题一：播客创作者的配音困境

一集30分钟节目真人配音成本1500元以上，现有AI配音工具声音机械、缺乏个性，无法建立主播声音品牌。75%的创作者被"高效产出优质配音"困扰。

问题二：声音永久丧失的不可逆性

渐冻症、喉癌、甲状腺术后等患者面临声音永久消失，却没有任何低成本的预防性备份方案。普通人也从未意识到：自己的声音，也是值得保存的数字资产。

1.2 为什么会想到做这个

看到韩国母亲通过VR与去世女儿"重逢"的新闻，想到：如果声音也能被永久保存，让一个人即使离开了，他的声音还能陪伴家人，那该多有意义。而VoxCPM2开源模型的出现，让个人开发者也能构建专业级语音服务，这是技术赋予我们的机会。

1.3 大概是什么产品

声师是一款基于开源AI语音克隆技术的Web平台

为播客创作者提供专属音色定制服务——克隆主播本人声音，保持风格统一，成本降低92%。同时为所有可能失去声音的人群提供免费"声音备份"公益服务——在声音消失前，永久保存这份独特的数字资产。

三、价值与意义

3.1 社会价值

"声音备份"计划让每个人都有机会在声音消失前保存自己的声音资产。对于渐冻症患者，这是他们在完全失去交流能力后，仍能用"自己的声音"与家人沟通的最后机会。对于普通人，这是一份可以提前准备的"声音遗嘱"。

3.2 商业价值

中文播客市场超50亿元，AI配音可将单期成本从1500元降至120元（降低92%），让中小创作者也能产出专业级音频内容。播客赛道目前涉足AI配音的竞品极少，存在明确的蓝海机会。

3.3 技术价值

基于VoxCPM2开源模型（Apache-2.0协议），48kHz录音室级音质，8GB显存即可本地部署，让个人开发者也能构建专业语音服务。开源底座意味着低成本、可深度定制、无版权风险。

3.4 安全价值

声音克隆安全防护体系

声音克隆是一把双刃剑，声师建立完整的安全防护机制：

  • 声纹验证：用户上传录音前需朗读随机验证码，证明是本人声音
  • 授权机制：签署电子授权协议，禁止克隆未经授权的他人声音
  • 数字水印：所有生成音频嵌入不可听水印，可追溯来源
  • 内容审核：关键词过滤+人工抽检，防止用于诈骗、虚假信息传播
  • 数据加密：用户音频加密存储，不出境、不共享第三方
  • 合规运营：符合《个人信息保护法》，生成内容明确标注"AI合成"

4.3 技术架构

核心技术：VoxCPM2

由 OpenBMB（清华大学）开源，Apache-2.0 协议，可商用。

  • 20亿参数，8GB显存即可运行
  • 48kHz录音室级音质输出
  • 30种语言 + 9种中文方言支持
  • 零样本声音克隆（3秒音频即可）
  • 文本描述生成新音色（Voice Design）
  • 情感/语速/风格可控

部署方案：Python 3.10+ + FastAPI + PyTorch 2.5+ + Docker

服务器需求：NVIDIA GPU 8GB显存（RTX 3060/4060级别）
