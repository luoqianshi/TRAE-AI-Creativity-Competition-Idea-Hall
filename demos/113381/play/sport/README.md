# FitLife 运动健身主题网站

## 项目简介

FitLife是一个专业的运动健身主题网站，致力于为用户提供全面的健身服务和资讯。

## 项目结构

```
sport/
├── index.html          # 首页
├── about.html          # 关于我们
├── programs.html       # 健身项目
├── trainers.html       # 教练团队
├── schedule.html       # 课程表
├── membership.html     # 会员中心
├── nutrition.html      # 营养指导
├── gallery.html        # 精彩瞬间
├── contact.html        # 联系我们
├── css/
│   └── style.css       # 样式文件
├── js/
│   └── main.js         # JavaScript文件
├── images/
│   └── placeholder.txt # 图片说明
└── README.md           # 项目说明
```

## 功能特点

1. **首页** - 展示网站特色、热门项目和会员心声
2. **关于我们** - 介绍网站故事、使命和成就
3. **健身项目** - 展示各类健身课程及价格
4. **教练团队** - 展示专业教练信息
5. **课程表** - 工作日/周末课程安排及预约
6. **会员中心** - 会员套餐选择和注册表单
7. **营养指导** - 健康饮食建议和营养计算器
8. **精彩瞬间** - 健身照片画廊（支持灯箱效果）
9. **联系我们** - 联系方式和留言表单

## 技术实现

- **HTML5** - 语义化标签构建页面结构
- **CSS3** - 样式美化，包含渐变、动画、响应式布局
- **JavaScript** - 实现交互功能（课程表切换、营养计算、灯箱效果等）

## 设计要求

- 主题明确：运动健身
- 风格统一：绿色为主色调，金色点缀
- 布局合理：清晰的导航和内容分区
- 交互友好：表单验证、按钮反馈等

## 使用方法

1. 克隆或下载项目
2. 将图片放入images文件夹
3. 在浏览器中打开index.html即可浏览
