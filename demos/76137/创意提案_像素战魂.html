🎮 项目概述

《像素战魂》是一款以极致打击感为核心目标的 2D 横版像素动作 RPG。我们深信"手感"是动作游戏的灵魂，因此从冻结帧、屏幕震动、受击闪白到击退反馈，每一个细节都经过精心调校。

项目采用组件化架构与信号驱动设计，不仅实现了流畅的战斗体验，更为独立游戏开发者提供了一套可复用、可扩展的技术框架。

Godot 4.x GDScript 组件化架构 状态机 FSM 信号驱动 EventBus

⚔️ 战斗系统

伤害流程链路

玩家攻击输入 → ComboComponent → 状态机切换 Attack
→ HitboxComponent.activate() → 碰撞检测
→ CombatSystem.apply_hit() → HurtboxComponent.receive_damage()
→ HealthComponent.take_damage() → EventBus 分发事件
→ FXManager: 冻结/震动/粒子 → AudioManager: 打击音效 → UI: 伤害数字 / HUD 更新

打击感参数调校

参数 数值 效果
命中冻结 (Hitlag) 80-120ms 命中瞬间时间暂停，产生"顿挫感"
屏幕震动 3-6 像素 / 0.15-0.25s 轻攻击小震，重攻击大震
敌人闪白 0.1s Shader 白色闪烁，视觉命中确认
击退力度 200-400 根据攻击强度产生位移
连击窗口 0.3s 窗口期内按键续招
翻滚无敌帧 0.25s 短暂无敌，可穿越攻击

🏗️ 技术架构

项目采用六层架构设计，模块间通过 EventBus 信号通信，实现零耦合：

  • Autoloads 层：EventBus + GameManager + AudioManager + FXManager + InputManager 全局单例
  • Core 层：GameConfig（物理层/常量）+ StateMachine（通用状态机）+ HitData（伤害数据）+ EntityBase（实体基类）
  • Components 层：Health / Hitbox / Hurtbox / Movement / Combo 等可复用组件，挂载即用
  • Systems 层：CombatSystem（伤害计算/暴击/减伤扩展点）+ CameraSystem
  • Entities 层：PlayerEntity（组合组件 + 输入处理）+ EnemyBase + SlimeAI
  • UI / Levels 层：HUD、伤害浮动数字、测试关卡

💡 价值与意义

娱乐价值

为玩家提供纯粹、爽快的动作游戏体验。通过精心调校的打击感参数（冻结帧 80-120ms、震动 3-6 像素、击退 200-400 力度），让每一次攻击都有"重量"，营造心流状态。

技术价值

项目采用组件化 + 信号驱动 + 状态机的现代化架构设计，所有参数通过 @export 导出，可在 Godot Inspector 中实时调试。可作为独立游戏开发的优质参考框架。

创作价值

全程借助 TRAE IDE 与 TRAE Work 辅助开发——从架构设计、代码实现到设计文档撰写，展现了 AI 辅助游戏开发的完整工作流，践行"人人都可以创造"的理念。
