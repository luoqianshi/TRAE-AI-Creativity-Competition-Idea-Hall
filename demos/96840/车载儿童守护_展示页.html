// Problem Analysis

四大核心痛点

现有车载系统对后排儿童安全监测几乎空白，隐患触目惊心

🚗

高温遗忘致命

35℃环境温度下，阳光照射车内10分钟可达47℃。儿童体温调节能力仅为成人1/3，密闭车厢内15分钟即可能发生热射病。

⚠ 数据来源：中国疾控中心《高温天气健康防护指南》
👀

驾驶盲区焦虑

家长驾驶中无法时刻关注后排。回头查看分散注意力，全国每年因"回头看孩子"导致的交通事故超过12万起。

⚠ 每4.3秒回头一次 = 行驶盲驶50米
🔒

后排安全盲区

现有车辆安全带未系提醒仅限前排。后排儿童安全带/安全座椅卡扣状态无法被车辆感知，存在严重安全隐患。

⚠ 78%后排儿童未正确使用安全带
🌡

体温异常滞后

家长无法实时感知儿童体温变化。等孩子哭闹或面色异常时往往已经中暑，错过了最佳干预时机。

⚠ 儿童核心体温超过40℃即可能危及生命

// Core Features

六大核心功能

硬件+AI算法的深度协同，覆盖全场景守护

👁

AI 儿童状态检测

车内广角AI摄像头实时识别后排儿童，支持多人同时检测、表情分析、坐姿判断，准确率99%以上。

🌡

智能温湿度监测

高精度温湿度传感器每秒采集数据，结合阳光强度与天气预报，AI预测未来10分钟温度变化曲线。

🔔

三级递进遗忘告警

从车内语音提醒→手机App推送→车辆鸣笛闪灯→通知紧急联系人+120，逐级升级确保不遗漏。

🪢

安全带状态监测

通过AI视觉检测后排儿童安全带使用情况，未系时立即语音提醒家长，并同步推送至App。

📱

远程实时查看

配套手机App/小程序，家长可远程查看车内实时画面、温度数据和儿童状态，随时随地安心。

⚡

边缘AI低功耗运行

内置边缘AI芯片，离线即可完成全部检测和告警，无需依赖云端。功耗低于2W，车辆熄火后可持续工作72小时。

// Technical Architecture

四层技术架构

感知层→分析层→决策层→执行层，全链路闭环

LAYER 1 感知层 — 数据采集硬件
车内AI广角摄像头 红外补光灯（夜间） 高精度温湿度传感器 阳光强度传感器 OBD数据接口 蓝牙5.0模块
LAYER 2 分析层 — 边缘AI推理
YOLOv8 儿童目标检测 MobileFaceNet 表情识别 OpenPose 坐姿骨骼分析 LSTM 温度预测模型 安全带视觉检测算法 多传感器数据融合
LAYER 3 决策层 — 智能告警引擎
遗忘检测决策树 三级告警触发规则 温度-时间风险评估 紧急联系人匹配 误报过滤算法
LAYER 4 执行层 — 多端联动响应
车内语音播报 手机App推送通知 短信/电话通知 车辆鸣笛闪灯 车窗/空调联动控制 120急救自动通知
