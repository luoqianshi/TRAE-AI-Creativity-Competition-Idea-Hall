项目简介

财报快捷系统面向投资者、研究员和财经从业者，解决传统 PDF 财报阅读中“检索慢、目录乱、对比难”的痛点。系统支持通过股票代码 / 名称 / 拼音首字母快速定位上市公司，自动抓取并解析年度报告、半年度报告等公开披露文件，提供精准目录导航、行业对比、关键词搜索与批注截图等能力。

核心价值：将动辄数百页的非结构化 PDF 财报，转化为可快速定位、可对比分析、可批注沉淀的结构化阅读体验。

核心功能

智能股票搜索

支持 6 位股票代码、公司全称、拼音首字母（如 600519 / 贵州茅台 / GZMT）三种方式快速定位。

PDF 目录精准导航

基于 pdfjs-dist 内置大纲生成目录，逐页渲染为图片，点击目录毫秒级滚动到对应页面，无页码偏移。

独立悬浮阅读器

目录与 PDF 各为独立悬浮卡片，各自拥有金色滚动条，互不影响，鼠标悬停即可分别控制。

财报自动下载

通过东方财富接口按股票代码聚合近五年财报，支持 PDF 下载与本地缓存。

行业对比

支持多家公司财务指标并排对比，辅助快速发现行业龙头与异常值。

批注与截图

在阅读器内直接圈画批注、截取关键页面，沉淀研究证据。

技术创新点

  • 逐页懒加载渲染：使用 IntersectionObserver + 缓冲页策略，scale 3 高清渲染同时保持滚动流畅。
  • 目录结构多源融合：优先使用 PDF 内置 outline，失败时回退到文本切分与财报常见标题正则。
  • 精准页码定位：通过 id="pdf-page-N" 物理页码 DOM 锚点，彻底避免浏览器内置阅读器的页码偏移。
  • 稳定的滚动体验：目录与 PDF 滚动解耦，PDF 滚动不再触发目录高亮抖动；targetPageRef 范围校验过滤远距离干扰页码。
  • 金色金融主题 UI：毛玻璃面板、圆角阴影、自定义金色滚动条，营造专业研报阅读氛围。

使用方式

  1. 在项目根目录执行 npm install 安装依赖。
  2. 执行 npm run dev 同时启动前端（默认 5174）与后端 API（3001）。
  3. 浏览器访问 http://localhost:5174/。
  4. 在首页搜索框输入股票代码 / 名称 / 拼音首字母，选择目标公司。
  5. 选择报告年度与类型，点击下载或在线阅读，进入阅读器体验目录导航与批注。
