Python 学习路径

五级学习体系，从零基础到专家

L1 L2 L3 L4 L5
L1

完全新手

编程零基础，刚接触 Python

应该掌握

  • • 安装 Python 环境和 VS Code
  • • 变量、数据类型（int, float, str, bool）
  • • 基本输入输出（print, input）
  • • 数学运算和字符串操作
  • • 编写第一个程序（Hello World）

常见错误

  • • 中英文标点符号混淆
  • • 缩进错误（Python 对缩进敏感）
  • • 变量名使用中文或特殊字符
  • • 忘记安装必要的库

晋级标准

能够独立编写简单计算器程序，正确使用变量和基本运算。

# L1 示例：简单计算器
num1 = float(input("输入第一个数: "))
num2 = float(input("输入第二个数: "))
result = num1 + num2
print(f"结果: {result}")
L2

入门开发者

掌握基础语法，能写简单程序

应该掌握

  • • 条件语句（if-elif-else）
  • • 循环结构（for, while）
  • • 列表（list）和字典（dict）操作
  • • 函数定义和调用
  • • 基本异常处理（try-except）

常见错误

  • • 列表索引越界（IndexError）
  • • 循环中修改正在迭代的列表
  • • 函数参数传递方式不理解
  • • 忘记在循环中更新计数器

晋级标准

能够编写待办事项管理程序，使用函数封装逻辑。

# L2 示例：待办事项管理
todo_list = ["学习Python", "完成作业"]
def add_todo(item):
todo_list.append(item)
print(f"已添加: {item}")
add_todo("买菜")
print(todo_list)
L3

进阶开发者

掌握面向对象和常用库

应该掌握

  • • 面向对象编程（类、对象、继承）
  • • 文件读写操作
  • • 使用 pip 安装第三方库
  • • 正则表达式
  • • 模块和包的概念

常见错误

  • • 类的 self 参数遗漏
  • • 文件路径处理不当
  • • 导入顺序导致循环依赖
  • • 正则表达式过于复杂

晋级标准

能够使用类和对象开发图书管理系统，读写文件保存数据。

# L3 示例：面向对象
class Book:
def __init__(self, title, author):
self.title = title
self.author = author
def info(self):
return f"{self.title} - {self.author}"
book = Book("Python入门", "张三")
print(book.info())

  • • 数据库操作（SQL/ORM）
  • • RESTful API 设计
  • • 异步编程（async/await）

专家开发者

能够独立完成复杂项目

应该掌握

  • • 微服务和分布式系统
  • • 性能优化和调优
  • • 容器化（Docker/K8s）
