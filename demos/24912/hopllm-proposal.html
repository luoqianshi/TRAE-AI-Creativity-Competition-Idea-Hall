HopLLM

智能 LLM 路由 API 代理

创意介绍

想解决什么问题：开发者调用 AI API 时，永远在"贵但强"和"便宜但弱"之间纠结。GPT-4 一个请求 $0.03，同样任务 DeepSeek 只要 $0.0001，但手动切换模型太麻烦，大部分开发者干脆全用贵的。

为什么会想到做这个：我自己是独立开发者，月 API 账单从 $200 涨到 $800，发现 70% 的请求根本不需要 GPT-4 级别的能力——翻译、闲聊、简单代码完全可以用便宜 100 倍的模型搞定，只是缺少一个自动判断和路由的工具。

大概是什么产品：一个 OpenAI 兼容的 API 代理服务（网站），开发者只需把 base_url 从 api.openai.com 换成 hopllm.com，系统自动识别请求意图，路由到最便宜且胜任的模型。5 分钟接入，零代码改动。

目标用户及痛点

面向中小团队和独立开发者——那些每月 AI API 支出在 $50-$2000 之间、对成本敏感但又不想牺牲质量的团队。

使用场景

团队用 GPT-4 处理所有请求，其中编码和复杂推理确实需要强模型，但翻译、简单问答、格式化等任务占 60%+ 的调用量，完全可以用 DeepSeek/Qwen 等低成本模型完成。

当前痛点

  • 手动选择模型——每个请求都要想"这个用哪个模型合适"，心智负担大
  • 锁定单一 Provider——切模型要改代码、换 Key、调参数，迁移成本高
  • 成本不透明——月底才看到账单，不知道哪些请求本可以更便宜
  • 没有统一入口——多 Provider 的 Key、配额、计费方式各不相同
