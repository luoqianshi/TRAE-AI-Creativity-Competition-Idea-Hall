// PROBLEM STATEMENT

你的数字生活有多混乱？

在信息爆炸的时代，每个人都面临着数据碎片化管理的真实困境

密码记忆过载

数十个账号密码散落在不同浏览器、笔记应用中，要么重复使用弱密码，要么频繁忘记需要重置，安全与便捷难以兼得。

文件管理混乱

桌面堆积如山，重复文件占据大量空间，重要文档藏在层层目录深处，搜索耗时久，分类整理更是无从下手。

照片散落各处

手机相册、云盘、本地文件夹、聊天记录中的图片分散存储，重要回忆照片难以集中管理和回顾，安全备份也成问题。

日程安排零散

工作任务、个人待办、约会提醒分散在日历应用、待办清单、便签中，缺少统一的任务管理和番茄钟专注计时工具。

纪念日常被遗忘

家人生日、重要纪念日、节日庆典常常需要反复确认日历，缺少主动提醒和倒计时功能，错过重要时刻的遗憾时有发生。

隐私安全隐忧

云端存储的数据面临泄露风险，第三方服务的数据收集政策不透明，个人敏感信息难以做到真正的"本地优先"保护。

// THE SOLUTION

贾维斯·一站式解决方案

一个桌面应用，解决你所有的个人数据管理问题

个人数字指挥中心

贾维斯（NexusGuard） 是一款基于 Electron 构建的桌面端全场景个人管理软件。它以「个人数据中枢」为核心理念， 将密码管理、文件归档、图片相册、日程计划、纪念日提醒、信息卡片、快捷链接、AI 对话助手等分散功能，统一整合于赛博朋克科幻级可视化界面中。

所有数据均存储在你的本地设备上，不经过任何云端服务器，辅以路径白名单、文件魔数验证等多层安全机制， 为你打造沉浸式、高效率、强隐私保护的个人数字管理体验。

  • 本地优先的数据存储方案，完全掌控你的数据主权
  • 科幻级非对称网格布局，一屏掌握所有核心数据指标
  • 模块化功能架构，按需使用，灵活扩展
  • 多层安全防护，防御路径遍历与恶意文件上传攻击

// CORE MODULES

八大核心功能模块

从数据仪表盘到AI助手，全方位覆盖你的个人数字生活管理需求

数据仪表盘

非对称网格布局的科幻级大屏，展示安全评分、存储分布、任务完成率、专注时长、纪念日倒计时等核心指标

密码保险箱

本地加密存储所有密码，支持分类筛选和关键词搜索，内置安全强度检查、密码生成器和重复密码检测

文件管理器

双栏布局 + 列表/网格视图切换，文件分类导航，智能重复文件检测，批量重命名功能，标签管理系统

图片相册

支持批量上传与管理，集成魔数验证确保图片安全，提供缩略图浏览、分类管理和本地存储方案

每日计划

任务清单管理，支持优先级、截止时间、重复规则，搭配日程时间轴和番茄钟专注计时器，提升工作效率

特殊日期

生日、纪念日、重要节日提醒管理，自动倒计时计算，仪表盘可视化展示，重要日期不再遗漏

AI 对话助手

集成自然语言交互，支持多轮会话和历史记录，用户可配置自定义 API Key，获得智能化的个人助理体验

安全架构

路径白名单机制，文件类型魔数验证，symlink 检测防御，三层安全保护确保你的本地数据安全无忧
