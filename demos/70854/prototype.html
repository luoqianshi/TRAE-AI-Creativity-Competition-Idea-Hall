01 / CREATIVE INTRODUCTION

创意介绍 · 从怀旧到重制

腾讯《电子宠物大作战》曾刷屏朋友圈，但只在微信内可用、无独立对战机制。我们把它搬到开放的 Web 端，并加上 P2P 二维码对战这个核心创新。

01

痛点 / PAIN POINT

原 H5 仅在微信生态可用，玩法以单机养成为主，缺少真正意义上的玩家对战；电脑端无法游玩；停服后无法再体验。

// 想玩的人找不到入口 · 想对战的人无对手
02

动机 / MOTIVATION

致敬童年拓麻歌子情怀，同时探索 WebRTC P2P 在轻量小游戏中的应用——好友扫码即开战，无需注册账号、无需后端服务器。

// 让怀旧 IP 在开放 Web 上复活
03

产品形态 / FORMAT

纯前端 Web 应用（React + Vite），桌面/移动浏览器皆可访问。养成 + 大厅 + 对战 三段式架构，二维码作为社交分享媒介。

// 一个 HTML 链接 · 扫码即玩 · 关闭即走

05 / TECH HIGHLIGHTS

技术亮点 · 零后端 P2P 对战

用纯前端技术栈实现完整实时对战，无需自建服务器。

P2P
PeerJS
WebRTC · v1.5

基于 WebRTC 的 P2P 数据通道，房主扫码生成 PeerID，好友扫码直连，无需后端中转。

QR
qrcode.react
+ html5-qrcode

生成端将 PeerID 编码为二维码，扫描端调用摄像头识别，配套 6 位房间码作为备用方案。

RX
React 18
+ Vite + TS

组件化三段式架构，Zustand 管理全局状态，localStorage 持久化宠物存档。

8B
Canvas + WebAudio
8-BIT ENGINE

Canvas 自绘像素宠物（无图片资源），Web Audio API 合成 8-bit 音效，零外部资源依赖。
