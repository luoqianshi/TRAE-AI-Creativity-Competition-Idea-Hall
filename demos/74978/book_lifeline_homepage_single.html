01 · 产品定位

不做知识库，做关系层

短期 Demo 不是完整产品，而是一个 9 天内可执行的最小验证文档。核心目标：验证“旧节点回声”是否成立。

把一段新的读书感受，变成 ReadingNode，并找回最多 3 条相关旧节点。

不是这些

  • AI 笔记
  • 第二大脑
  • 知识库工作台
  • 学习平台
阅读型第二大脑的
关系层

02 · 核心目标

验证旧节点回声

唯一核心目标

  1. 1系统成功生成一个结构化 ReadingNode
  2. 2系统给出最多 3 条旧节点候选
  3. 3每条候选都能给出一句人类可读的关联理由
  4. 4用户愿意对其中至少 1 条关系执行“保留”动作
  5. 5用户主观感受到“原来这两条真的能连起来”

03 · 本期边界

不做什么，比做什么更重要

不验证

  • 社区价值
  • 星图美学
  • 大规模知识库
  • 内容分发
  • 公共书摘广场
  • 完整导入系统

不做

  • 书城 / 公开社区 / 排行榜
  • 推荐流 / 多用户协作
  • 复杂账号系统
  • 完整向量数据库
  • 图数据库

04 · 目标用户

记得自己想过，却找不到在哪

已经有读书摘录、日记、想法碎片，但经常“记得自己想过，却找不到在哪”的人。

重度读书者 知识工作者 内容创作者 研究型个人 长期日记写作者

05 · 使用场景

三种输入方式

读纸质书

拍下一页，或手动粘贴摘录，再补一句此刻想法。

读电子书

从微信读书复制一段文字，再补一句此刻想法。

突然想起

“今天想到《世界简史》里关于苏美尔的那段。”

06 · 核心流程

七步闭环

输入感受→ 生成 Node→ 召回候选→ 重排筛出→ 解释关联→ 用户确认→ 保存关系

不要让用户填写复杂字段；让用户自然表达，让机器长出结构。

07 · 核心页面

四个关键页面

PAGE 01

首页 / 输入页

输入框 + 示例按钮 + 最近节点预览

PAGE 02

ReadingNode 确认页

书名 / 摘录 / 想法 / 标签，可编辑

PAGE 03

关联推荐页

最多 3 条旧节点回声，每条有理由

PAGE 04

生命线回看页

新节点 + 已确认关系 + 时间顺序

09 · 关系类型

六种关系，固定不扩张

echo回声同向共振
contrast反差对照
source来源上游
example案例样本
question共同问题同一个追问
correction修正纠偏

类型数量固定，不扩张。用户看得懂比分类更重要。

10 · 技术方案

轻量优先

单文件 HTML 或本地可运行网页

前端本地 JSON 数据，样例内置

关系召回先用轻量规则 + 手工模拟

解释理由可由 LLM 辅助生成

embedding 本期不是没有价值，而是不是第一优先级。

《心安》如何进入真实生活

书中观点
《心安：致焦虑的时代》 · 前言 · 位置 1536-1647
“我一直对反向效应深深着迷，有时候我称之为‘反过来法则’。”
“当你屏住呼吸，你就没了气……”
生活片段 · 游泳
6/7 晚上原本想去皇冠假日游泳，先在闲鱼找票被拒，到现场又发现泳池很挤，于是临时加钱换去万豪。进水后看见旁边有小姑娘学游泳，突然想起白天写过的一句：“你要浮起来，你得先沉下去。” 于是开始练习降心率、放慢动作，结果发现：越放松，身体越能自然浮起来。
书中观点
《心安：致焦虑的时代》 · 第九章
“这是一朵玫瑰……不，一朵玫瑰就是一朵玫瑰……”
生活片段 · 玫瑰
7/1 前一晚一点多才睡，早上八点多先醒了一次又睡回去，十点才真正起身。下午去浙江美术馆看《彩墨星辰》，傍晚在地铁上读到“玫瑰”这一段。那天前面刚看完画展，脑子里一直在想“抽象”到底是什么；读到这里后，直接把它迁移成一句现实判断：“看画、看病、看关系都一样——先别急着贴标签，让它‘就是它’地撞我一下。”
书中观点
《心安：致焦虑的时代》 · 第一章 · 位置 8774-8920
“你无法抓住生命，正像你无法用一只水桶带走一条河流。”
“要‘拥有’流动的水，你必须放手任其自流。”
生活片段 · 场所判断
7/5 去奥体附近皇冠假日酒店游泳，现场发现泳道拥挤、水偏浅，和自己想要的“放松 + 练习下潜”完全不匹配。当天留下的现实判断是：“先问清楚一个场所是否匹配当下的具体目标，再决定要不要留在原地凑合。” 同一天晚上读完《心安》，又把这本书总结成：“它更适合当成一个场所来读，而不是知识容器。”
同一本书不只产生一个想法。它会进入身体、睡眠、看画、场所判断这些真实生活场景。
书 → 书

《世界简史》如何发散到不同的书

输入节点
《世界简史》 · 威廉·麦克尼尔 · 第一部分 · 位置 949-1038
“只有在需要灌溉的地方，大量人力才有必要合作挖掘沟渠、修筑堤坝。”
文明不是只靠粮食长出来的，而是靠必须协作的基础设施长出来的。
echo
《枪炮、病菌与钢铁》 · 贾雷德·戴蒙德 · 第5章
“我们必须想法子找出食物生产的发源地、起源时间，以及特定作物或牲畜被驯化的时间与地点。”
关联原因
《世界简史》在讲“文明为什么会长出来”，这本书继续追问“农业为什么会最早在那里长出来”。
关联原因
《世界简史》强调灌溉与协作；《大历史》把它进一步拉到更大尺度：农耕文明的核心，是复杂度提升和资源控制能力扩大。
source
《大历史：虚无与万物之间》 · 大卫·克里斯蒂安 · 6.1
“我们以农耕文明来指称庞大的国家和帝国制度……不过，它们更复杂，控制着更多的人力和物质资源。”
example
《文明》 · 肯尼斯·克拉克 · 第1章
“伟大的民族在三种手稿中写下它们的自传，这就是行为之书、语言之书和艺术之书。”
关联原因
《世界简史》偏向文明的形成机制；《文明》把视角转向文明如何通过行为、语言、艺术被理解。这让“文明”从制度结构，又发散到文化表现。
一本书不会只连到一本相似的书。它可能同时发散到：文明形成机制书、文明起源追问书、文明文化观看书。
想法 → 书

一个今天的想法，如何被追溯回几本书

输入想法
6/2 日记《用进废退：全身运动×“息”作为中式武术的计数单位》
“到了现在，生产工具变了。不再只是人和牲畜，而是 AI、Agent、算力、Token。所以竞争的关键变成了：谁能调动更多的 AI，更多的 Agent，更多的算力，更多的 Token。”
source
《世界简史》 · 威廉·麦克尼尔 · 第一部分 · 位置 949-1038
“只有在需要灌溉的地方，大量人力才有必要合作挖掘沟渠、修筑堤坝。”
关联原因
这条 AI 想法的底层结构，不是来自 AI 新闻，而是来自更早的文明史判断：复杂社会 = 更大规模的协作与调动。
关联原因
《世界简史》给的是协作基础；《大历史》补的是：当资源、人口、安全问题叠加，组织结构会继续长出权力、城市、防卫与国家形态。
echo
《大历史：虚无与万物之间》 · 大卫·克里斯蒂安 · 6.3
“随着难民从干旱地区涌入苏美尔……安全感要求领导阶层承担防卫；军事领袖应运而生。”
example
《枪炮、病菌与钢铁》 · 贾雷德·戴蒙德 · 第5章
“我们必须想法子找出食物生产的发源地、起源时间，以及特定作物或牲畜被驯化的时间与地点。”
关联原因
这本书补的是“生产系统”如何具体展开：农业从哪里开始、怎样扩散、怎样塑造不平等和优势。它把这个 AI 想法从抽象判断，再往前推到“生产能力如何形成”的问题。
一个今天关于 AI 的判断，可以被追溯回：文明协作的源头、城市与组织的长成、生产能力的形成路径。而不是只像一句“突然冒出来的灵感”。
