为什么需要期末粥？

大学生期末复习阶段面临的四大核心困境，每一个都让人抓狂

[1]

资料零散，格式混乱

PPT、Word、PDF、图片、录音...资料散落在各处，格式不统一，手动整理耗时巨大，还没开始复习就已经精疲力尽。

[2]

重点不清，方向迷茫

老师课件里的重点标注无法自动识别，不知道哪些是核心考点，复习没有针对性，效率极低。

[3]

题型不明，练习盲目

不清楚考试具体题型分布，练习题与真实考试脱节，做了很多无用功，上了考场才发现练错了方向。

[4]

时间紧迫，计划混乱

距离考试只剩几天，知识点太多不知从哪开始，没有科学的复习计划，熬夜通宵效果却很差。

  • PPT / Word / PDF 自动提取内容

[1] 多格式资料解析

支持 PPT、Word、PDF、图片、视频、音频、纯文本等全格式导入。系统自动提取内容，并通过格式标注智能识别重点。

  • [★] 颜色高亮内容自动识别为"老师重点"
  • [★] 加粗文字自动标记为"核心概念"
  • [★] 视频音频自动语音转文字并分段
  • [★] 图片通过 OCR 提取文字内容
02 考试适配

考试信息确认 + 题型跟随

  • 确认科目与考试类型
  • 设置剩余复习天数
  • 录入题型分布
  • 【!!注意!!】只出老师给的题型

[2] 考试信息确认 + 题型跟随

复习开始前，系统确认科目、考试类型、剩余天数、题型分布等关键信息。

【!!注意!!】 核心规则：老师给了题型（如"单选30分+简答30分+综合40分"）→ 只出老师给的题型，不擅自增加；老师没给 → 全部题型覆盖。

[4] 知识点详细讲解

每个知识点包含 7 个完整板块，从定义到易错点全方位覆盖。

  • [1] 定义：准确清晰的概念描述

05 实战训练

题型训练（按实际题型）

  • 选择题 >= 20 道，每题带解析
  • 填空题 >= 15 道
  • 简答题背诵版 >= 章节数 x 2
  • 计算题/综合题：3题/类型

[5] 题型训练（按考试实际题型）

严格按照老师给定的题型出题，不擅自增加题型。

  • [▼] 选择题 >= 20 道，每题带解析（对在哪 + 错在哪）
  • [▼] 填空题 >= 15 道
  • [▼] 简答题背诵版 >= 章节数 x 2，答案精炼条目化，可直接背诵，附关键词
  • [▼] 计算题：每种类型 3 题（理解型 + 巩固型 + 自练型）
  • [▼] 综合题：按专题分，3 题/专题
