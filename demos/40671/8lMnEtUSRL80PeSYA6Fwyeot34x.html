AI任务流自生系统
让每个需求自动变成可执行的工作流（AI Project Execution Engine）

🔥 项目简介

本项目旨在解决“AI只能回答，不能执行”的问题。 用户只需输入一句话需求，系统即可自动生成结构化任务流 + 可执行项目计划。

⚡ 核心痛点

❌ 需求无法拆解
❌ 项目执行依赖经验
❌ 工具割裂（文档/设计/开发）
❌ AI只会回答不会做事

💡 解决方案

① 一句话输入 → 自动生成任务树
② AI自动拆解需求为可执行步骤
③ 多AI角色协同（策略/设计/开发/数据）
④ 可视化任务流（类似项目管理系统）
⑤ 一键导出 PRD / 开发任务 / UI结构

🧠 AI执行角色系统

策略AI 产品AI 设计AI 数据AI 文案AI

每个AI像一个虚拟团队成员，共同完成项目交付。

📊 示例：输入 → 输出

输入：做一个换电柜小程序推广方案

用户分析 → 目标人群定义
竞品调研 → 市场对标分析
活动策略 → 增长方案设计
页面结构 → 小程序UI规划
推广渠道 → 投放策略拆解

✔ 提升需求拆解效率 80%

✔ AI从“回答工具”升级为“执行系统”
✔ 可落地企业研发 / 运营 / SaaS场景
