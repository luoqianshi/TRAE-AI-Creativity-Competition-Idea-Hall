PART 01 · THE MOVEMENT

这是一场运动，不只是一个产品

无罪之罪不是"AI辩论玩具"——它是一项真实推进中的社会运动。产品是运动的基础设施，AI 是运动的加速器。

运动核心主张

"不回避'安乐死'三个字，但用'无痛的死亡'替代'杀死'；不否认这是'罪'，但强调这是'无罪之罪'——在法律框架内的罪，是为了逼出更大立法的罪。"

运动不煽动仇恨，但揭露商业利益集团（繁殖场、宠物店、后院繁殖者）的阻力；不鼓励个人英雄主义，强调 SOP 和签字锚定的集体保护；绝不教用户如何私自处死动物，必须走合法 SOP。

PART 02 · THE PAIN

运动推不动，因为五道墙挡在前面

这不是"做个 AI 聊天机器人"的需求，是真实运动里支持者每天都在撞的墙。每一道墙都在让运动倒退。

01
👾
支持者被网暴
在 10 万+ 的反对帖下公开支持安乐死代替弃养，几十条评论瞬间围攻。被骂"杀人犯""冷血"，被扒个人信息，被群体极化压到沉默。
影响：支持者不敢发声，运动失去公开场域
02
🎭
被 2000+ 种话术变体压制
反对者用挖陷阱、稻草人、莫顿之叉、滑坡论证、封口句式把你按在地上。你明明有道理，却被带进对方框架，越辩越被动。
影响：论点失真，运动主张被扭曲成"杀猫运动"
03
📺
传播被断章取义
媒体主持人明显偏向反对立场，每句话都在设陷阱，一句话被截出来就是"支持杀猫"。运动的复杂主张被压缩成符号，传播即失真。
影响：运动无法获得公共理解，被标签化
04
🏜️
教练稀缺，无人陪练
真实运动里没有 5 位专家随时陪你演练。苏姐（数据）、大刘（传播）、老钱（法律）、陈默（伦理）、老周（执行）——这些角色在现实里可遇不可求。
影响：支持者各自为战，经验无法沉淀
05
🕳️
运动自身的知识盲区
运动不知道自己的论点哪里有漏洞。哪些数据站不住脚？哪些法律依据会被反将一军？哪些反对角度从未被预演过？盲区在真实对抗中才暴露，代价惨重。
影响：运动在关键辩论中失利，公信力受损
∑
🧱
五墙叠加的结局
支持者沉默 → 主张失真 → 传播失败 → 经验无法沉淀 → 盲区持续存在 → 支持者更沉默。运动陷入负循环，推进举步维艰。
影响：运动停留在小圈子，无法形成社会共识
PART 03 · THE BREAKTHROUGH

无罪之罪模拟器：AI 如何为运动破局

每一道墙，对应一个 AI 破局点。这不是"用 AI 做个聊天框"，是用 AI 重构运动的训练、传播、沉淀闭环。

破局 · 01
🛡️
模拟战场：把真实失误成本降为 0
支持者上场前先在 AI 模拟器里被键盘侠围攻 100 次。所有会让人社死的失误，都在模拟器里犯完。真实开口时，已经身经百战。
破局 · 02
⚔️

从真实微信群聊提取反击模式做 few-shot 训练，AI 反对者会说"你急了你急了"、会冷暴力回一个"？"、会假装示弱再绝杀。2000+ 种攻击变体按难度递进，比真实喷子更系统。
破局 · 03
🤝

破局 · 04
🗂️
辩论档案卡：每场对局沉淀为运动资产
每场对局自动生成结构化档案卡：正反观点、关键数据、法律依据、教练建议、用户立场判断。个人经验不再流失，沉淀为运动公共知识库。

破局 · ∑
🔄

支持者被训练 → 主张清晰 → 传播有效 → 经验沉淀 → 盲区收窄 → 段位晋升。围观者 → 发声者 → 辩手 → 说服者 → 倡导者 → 守望者，运动进入正循环。

PART 07 · ARCHITECTURE

技术架构 · 安全可维护

基于 TRAE Work + 原生 Web 技术栈。安全合规是底线，不是事后补丁。

前端
原生 JavaScript + Tailwind CSS，零框架依赖，单文件可部署。三屏状态机驱动，SSE 流式渲染实时响应。所有用户输入经 escapeHtml 转义防 XSS。
后端
Python Flask + SQLite。所有 SQL 使用参数化查询（? 占位符），禁止 f-string 拼接 WHERE 子句。管理员接口 @require_admin 装饰器鉴权。
AI 引擎
大模型 API + 分层提示词工程（人格 / 议题 / 战术 / 安全）。AI 调用失败直接抛错，不静默降级。内容安全过滤器拦截违规输出。
知识库
5 大议题领域结构化知识库。真实群聊 few-shot 训练数据按战术类型均匀采样，控制 token 消耗。
数据持久化
会话状态、辩论档案卡、段位积分、向上反馈记录均落 SQLite。新表 IF NOT EXISTS 幂等创建，UTF-8 编码。
安全合规
参数化查询、HTML 转义、管理员鉴权、内容安全过滤、API 密钥环境变量读取、服务器 IP 走 os.getenv。用户数据严格隔离。
