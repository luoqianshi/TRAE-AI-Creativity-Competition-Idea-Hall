💡 代码审查模式
👤

帮我看看这段 Python 代码有什么问题：

def find_max(arr):
    max_val = 0
    for num in arr:
        if num > max_val:
            max_val = num
    return max_val
🤖

发现 1 个逻辑缺陷 和 1 个改进建议：

🔴 严重：当数组全为负数时返回 0，而非实际最大值

🟡 建议：使用 max() 内置函数更 Pythonic

# 修复方案
def find_max(arr):
    if not arr: return None
    return max(arr)
