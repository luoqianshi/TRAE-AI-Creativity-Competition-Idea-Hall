使用指南

三步找回你的说说

按照以下步骤操作，即可从QQ空间互动消息中恢复已删除的说说

1

打开QQ空间网页版并登录

在浏览器中访问 user.qzone.qq.com 并登录你的QQ账号。确保登录的是发表说说时使用的账号。

💡 推荐使用 Chrome / Edge 浏览器，兼容性最佳
2

进入「互动消息」页面

登录后，点击页面上的「消息」或「互动」标签，进入互动消息列表。这里会显示所有互动通知，每条通知都包含了原说说的预览内容。

💡 如果看不到互动消息，试试点击左侧菜单中的「消息中心」→「互动」
3

运行爬取脚本

按 F12 打开开发者工具，切换到 Console 面板，将下方的脚本粘贴进去并按回车运行。脚本会自动滚动并收集数据。

💡 脚本运行期间请不要操作该页面，耐心等待滚动完成。运行结束后会自动下载 JSON 文件。

点击上方「下载扩展文件包」按钮，将 zip 文件解压到任意文件夹（解压后不要删除文件夹）。

常见问题

    
遇到问题？

  

  

    

      

        网页版翻不到太久以前的消息怎么办？
        ▼
      

      

        这是QQ空间网页版的限制！请使用移动版（h5.qzone.qq.com）抓取。操作方法：在 Chrome 中按 Ctrl+Shift+M 切换到手机模拟模式，然后访问 h5.qzone.qq.com 登录。移动版的消息列表可以翻到很久很久以前，远比桌面版深。v2.0 扩展已自动支持移动版。
      

    

    

      

        脚本运行后没有反应，怎么办？
        ▼
      

      

        请确保：1) 你已经在QQ空间网页版登录；2) 已经进入互动消息页面；3) 在 Console 面板（不是 Elements 面板）粘贴脚本。如果页面结构发生变化，请尝试「高级自定义」模式手动指定选择器。
      

    

    

      

        为什么有些说说的文字不完整？
        ▼
      

      

        互动消息中只显示说说的文字预览，长文本会被截断。这是QQ空间的限制，预览内容最多只展示部分文字。但图片通常是完整的。
      

    

    

      

        脚本运行很长时间怎么办？
        ▼
      

      

        如果你的互动消息非常多，脚本可能需要运行较长时间。脚本会持续滚动直到到达页面底部（滚动高度不再变化为止），确保不遗漏任何内容。你可以在脚本开头的 CONFIG 中调整参数：减小 scrollDelay（滚动间隔）加快速度。运行期间可以在控制台看到进度日志。
      

    

    

      

        恢复的说说图片无法显示？
        ▼
      

      

        图片链接可能因为QQ空间的防盗链机制而失效。建议：1) 尽快在QQ空间页面内保存图片；2) 将图片链接复制到新标签页直接访问；3) 导出后尽快下载图片。部分图片可能已经从服务器删除，无法恢复。
      

    

    

      

        数据安全吗？会不会泄露？
        ▼
      

      

        完全安全。脚本仅在你本地浏览器运行，所有数据只保存在你的电脑上，不会上传到任何服务器。导出的文件也是保存在本地。本工具网站本身也是纯静态页面，没有任何后端服务。
      

    

    

      

        能不能直接恢复已删除的说说到QQ空间？
        ▼
      

      

        不能。本工具只能从互动消息中提取说说的预览信息（可能不完整），无法恢复原始说说到QQ空间。恢复的数据仅限于消息中可见的文字片段和图片链接。
