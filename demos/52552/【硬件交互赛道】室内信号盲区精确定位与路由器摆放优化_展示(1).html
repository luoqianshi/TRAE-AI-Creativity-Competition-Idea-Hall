TECH STACK

从信号采集到热力图生成，三层技术架构

📡

信号采集层

利用 Android/iOS 系统API读取 WiFi RSSI（接收信号强度指示）和蜂窝信号 dBm 值，配合手机加速度计和陀螺仪实现步态检测，将信号数据与空间位置关联。

WiFiManager.startScan()
CoreLocation.RSSI
Accelerometer.stepDetect()
🗺️

热力图生成

基于采集的稀疏信号点，使用 IDW（反距离加权插值）算法生成连续的信号强度热力图。同时识别墙体位置，在插值时加入墙体衰减因子，使热力图更贴合实际信号分布。

IDW Interpolation
Wall Attenuation Model
Canvas2D Heatmap Render
🤖

摆放优化引擎

基于信号传播模型（Free-Space Path Loss + 墙体衰减），在户型图上遍历可行的路由器摆放候选位置，计算每个位置的预期覆盖率，推荐全局最优摆放方案。

FSPL Model: P(d)=P0-20log(d)
Candidate Grid Search
Coverage Optimization
