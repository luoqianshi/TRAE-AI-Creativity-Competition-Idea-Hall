- 五虎遁：甲己之年丙作首，乙庚之年戊为头...

### 深度命理分析引擎（2026-06-13）
在 `bazi-engine.js` 中新增三个模块，`paipan()` 返回值新增 `pillarRelations`、`yongShen`、`geJu` 字段：

**用神判定 `getYongShen()`**
- 扶抑用神：根据日主旺衰（4级）自动推算喜用/忌神/闲神
- 调候用神：冬喜火、夏喜水、春喜金、秋喜木
- 病药用神：识别命局最旺忌神，推算克制/化解之法
- 通关用神：冲战关系的调解五行
- 输出：喜用神列表、忌神列表、五行行业/方位/颜色指导、综合描述

**干支关系 `getPillarRelations()`**
- 天干五合、地支六合/三合、六冲、相刑、相害
- 四柱间全量配对计算，返回结构化关系列表 + 综合概述
- 合冲并存等特殊组合的自动解读

**格局判定 `getGeJu()`**
- 以月令本气十神定主格（正官格/七杀格/财格等8种）
- 检测月支藏干在其他天干的透出情况，判定兼格
- 格局高低评价 + 各格局专属性格描述

专属解读页 (`exclusive.*`) 已接入上述三个模块的完整展示：
- 用神之道（金边高亮卡片）：喜用/忌神标签 + 详解 + 调候/病药 + 行业方位指引网格
- 格局判定：主格标签 + 兼格标签 + 格局评述
- 干支感应：综合概述 + 按合/冲/刑/害分组展示
