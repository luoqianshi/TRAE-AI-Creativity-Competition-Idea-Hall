01 设计哲学

MySence 的核心理念是让用户几乎感受不到它的存在，直到你需要它的那一刻。

◉

纯净

无广告、无弹窗、无冗余界面。只保留最核心的交互，让工具回归工具的本质。

◈

静默

后台智能运行，不打扰用户当前工作。全屏检测与免打扰模式确保专注时刻不受干扰。

◆

按需

Win+Q 快速唤起、通知中心面板、CLI 三种入口，在你需要时以最短路径提供服务。

02 核心功能模块

五大模块协同工作，构建完整的个人知识管理与自动化工作流。

◎

智能工作流引擎

将重复性工作编排为自动化流程，越用越省心。既支持简单的脚本级自动化，也支持多步骤的智能编排。

  • 常用操作自动记忆为模板，下次直接复用，不必重复指示
  • 跨步骤智能协调：Git 采集 → 生成报告 → 写入笔记 → 通知，自动串联
  • 习惯自适应：系统默默学习你的使用模式，常见操作渐入佳境
  • 代码化执行：确定性的操作本地执行，智能层只在需要理解场景时才介入
自动编排 习惯学习 跨步骤协调 渐进式效率
◉

知识联想网络

帮你把零散的信息自动关联起来——文件改了什么、做了哪些任务、写了哪些笔记，系统能理解它们之间的联系。

  • 智能联想：查一个文件时，自动关联相关的任务、笔记和 Git 提交
  • 模式发现：系统能察觉你不同工作之间的关联规律
  • 渐进调优：常用的关联路径被强化，冷门线索自然淡出
  • 工作流与知识网络双向联动，每次操作都丰富你的知识体系
智能联想 模式发现 渐进式知识
◈

文件影子系统

不依赖 Git 的用户级文件版本守护——没开 Git 的文件夹、被 ignore 的文件、未提交的修改，通通有历史可查。

  • Copy-on-Modify 写前快照：文件变更前自动保存前一个版本
  • Git 智能交叉：已提交的跳过用 Git 历史，未提交和非 Git 区域由影子系统接管
  • 多窗口存储策略：6h 全量 → 7天每小时 → 30天每天 → 超期按遗忘核衰减
  • 5GB 默认配额 + 竞争淘汰：按"版本价值分"自动清理低价值快照
  • 统一查询：Git 历史 + 影子历史 + 超图关联合并呈现
版本回溯 增量记录 多维检索 写前快照 配额管理
◆

笔记生态集成

深度连接 Obsidian Vault，让笔记成为知识网络中的活跃节点。

  • Vault 双向读写，笔记与知识节点实时同步
  • Wiki 链接自动映射为网络关联关系
  • 工作事件自动注入笔记时间线
双向同步 链接映射 事件注入
