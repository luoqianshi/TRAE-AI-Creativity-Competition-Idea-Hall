痛点与创意

想解决什么问题

AI Agent 自主写代码时，用户启动任务后进入"黑盒等待"——不知道 AI 在做什么、是否卡住、方向是否正确。等了十几分钟回来，发现 AI 一直在死循环或做无用功，时间白白浪费。

核心创意

给 AI 配一个"监工"：每隔 N 分钟自动打断 AI 的执行，注入反思提示词（"汇报卡点"、"检查进度"、"换思路"），迫使 AI 停下来审视方向，从"放任自流"变成"定时巡检"。

启动 AI → 倒计时 180s → 打断 → 注入提示词 → AI 汇报 → 重新计时

核心功能

自动巡检打断

  • 两阶段注入：先点停止按钮中断任务，再粘贴反思提示词并发送
  • 冷却期保护：打断后等待 10 秒让 AI 响应，再重新计时
  • 自定义间隔：10~3600 秒可调，默认 3 分钟

视觉驱动自动化

  • 纯视觉方案：OpenCV 模板匹配 + pyautogui 模拟操作，不依赖任何 API Hook
  • 多尺度匹配：0.5x~2.0x 共 16 个缩放尺度，应对 DPI 缩放和窗口大小变化
  • 窗口实时跟随：50ms 轮询目标窗口坐标，悬浮条自动吸附，最小化自动隐藏

可视化工作流编辑器

  • 类节点编辑器，支持 7 种步骤：等待、视觉检测、点击、输入、截图、条件判断、发送提示词
  • 支持条件分支跳转，YAML 持久化，编排任意 GUI 自动化序列

提示词模板系统

  • SQLite 持久化，内置 4 条预设反思模板：汇报卡点、检查进度、换思路、总结输出
  • 支持自定义模板、JSON 导入导出、使用计数、队列批量发送

技术亮点

  • 零侵入：不修改目标应用，纯视觉+模拟操作，天然跨应用
  • 三窗口协同：透明悬浮条 + 控制面板 + 工作流编辑器，各司其职
  • 中文路径兼容：使用 `cv2.imdecode` 替代 `imread` 解决中文路径问题
  • 剪贴板安全恢复：粘贴前保存原内容，操作后自动恢复
  • 单实例保护：Win32 Mutex 防止多开冲突

谁需要它

目标用户

  • 使用 QoderWork / WorkBuddy / Cursor 等 AI IDE 进行长时编程任务的开发者
  • 需要 AI 自动跑任务但无法全程盯屏的独立开发者
  • 需要编排 GUI 自动化流程的效率工具爱好者

典型场景

  • 启动 AI 修 bug 后去开会，3 分钟后自动让 AI 汇报进度，防止卡死
  • 下班前让 AI 写一个模块，监工定时打断引导方向，第二天早上看结果
  • AI 陷入死循环反复尝试同一种方案时，自动注入"换个思路"提示词
  • 用工作流编辑器编排跨应用自动化（如：读取邮件 → 打开 IDE → 输入代码 → 截图）

多 Profile 支持

YAML 驱动的配置系统，每个 Profile 独立配置目标进程名、模板图片、匹配阈值，一键切换监控不同的 AI 应用。
