The Problem

不是资料太少，而是缺少一张认知地图

初次接触陌生行业时，人们真正缺少的不是更多链接，而是对“该看什么、先看什么、它们如何关联”的清晰判断。

信息碎片化

报告、新闻、百科、课程和技术文档散落在不同平台，用户需要不断切换、复制和整理，难以形成连续理解。

重点难判断

专业术语与细节扑面而来，新手无法区分基础概念、核心变量和边缘信息，容易把时间花在低价值内容上。

全貌难建立

即使阅读了大量资料，也可能只理解局部。产业链、核心技术、代表企业与商业模式之间仍然缺少连接。

理解行业利润分布、产品成本和竞争差异的基础。

政策与市场数据建议进阶

用于判断行业周期、成长空间与区域机会。

单一车型参数暂时忽略

初次建立全景认知时，不必过早陷入产品细节。

Core Features

围绕“快速、全面、抓重点”设计

01 / 全景框架

自动搭建行业骨架

覆盖定义、发展历程、产业链、商业模式、市场格局、代表企业和关键岗位。

02 / 重点提炼

帮用户做信息减法

根据使用目标，区分必学知识、进阶知识和暂时可忽略的次要信息。

03 / 图谱生成

关系不再藏在段落里

输出可编辑 Mermaid 代码，支持继续扩展、分享和沉淀到个人知识库。

04 / 路径规划

从全貌走向行动

面向求职、学习、创业或研究，生成不同深度和顺序的个性化学习路线。

05 / 术语解释

降低专业阅读门槛

用通俗语言解释核心术语，并展示概念之间的因果、依赖与上下游关系。

06 / 来源追溯

让结论可以被验证

标注关键观点的资料来源、发布日期和可信度，方便进一步核实与深挖。

Target Users

为每一次“进入陌生领域”服务

同一个行业，不同用户关注的问题并不相同。系统根据目标改变信息权重与输出路径。

USER 01

学生与转行者

快速理解行业结构、岗位分工和面试必备知识，减少盲目学习。

场景：求职 / 面试
USER 02

产品与技术人员

进入新项目时掌握上下文、核心术语和关键技术之间的依赖关系。

场景：项目启动
USER 03

创业者与管理者

发现价值链位置、竞争格局和潜在机会，为业务判断建立共同语言。

场景：机会研究
USER 04

研究与投资人员

快速完成行业初筛，定位需要深入验证的指标、企业与风险变量。

场景：行业调研
