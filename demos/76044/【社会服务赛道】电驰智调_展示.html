TECH 01

时序需求预测模型

基于历史充电数据、天气、工作日/节假日特征，采用 LSTM + Attention 模型预测未来2小时各点位充电需求，准确率达 92%。

# 需求预测核心逻辑 def predict_demand(zone_id, horizon=120): features = extract(time, weather, holiday) model = LSTMAttention(input_dim=24) return model.predict(features, horizon)
TECH 02

多目标最优调度算法

综合考虑距离、等待时间、充电功率、价格四个维度，使用多目标优化算法为用户推荐 Pareto 最优解，而非仅看距离最近。

# 多目标评分函数 score = w1*distance + w2*wait_time \ + w3*power_match + w4*price return pareto_optimal(score_list)
TECH 03

动态定价削峰填谷

高峰时段自动上浮电价、低谷时段给予折扣，引导用户错峰充电。结合调度推荐，可将峰值负载降低 35%。

# 动态定价策略 if load_ratio > 0.8: price *= 1.15 # 高峰上浮 elif load_ratio < 0.3: price *= 0.85 # 低谷折扣
TECH 04

低延迟 MQTT 消息总线

充电桩状态变化通过 MQTT over WebSocket 实时推送，端到端延迟 < 200ms，确保用户看到的永远是最新空位信息。
