Core Features

核心功能

从记录到封存，从解压到回忆，每一个功能都温暖人心

📷

多媒体记忆录入

每天可记录30秒视频、不限量文字、照片、语音转文字。支持心情标签和事件标签，让每一天都有迹可循。

✓ 30秒视频 ✓ 语音转文字 ✓ 心情标签
💡

每日一问 · 降低门槛

每天首次打开弹出一个小问题，回答即自动保存。3秒快录按钮，长按直接录制视频，零操作成本。

✓ 每日一问 ✓ 3秒快录 ✓ 模板提醒
💎

年度最重要一天

每年可手动设置或智能推荐"最重要的一天"。该天在年度格子上有金色星标，封存回忆时自动定格。

✓ 手动/智能设置 ✓ 金色星标 ✓ 高光时间线
📦

记忆封存 · 时光胶囊

除当前年份外，过往年份自动压缩为记忆胶囊。封存时播放回忆流，定格最重要一天，格子收缩汇聚成金色胶囊。

✓ 自动封存 ✓ 回忆流播放 ✓ 释放存储
🔓

记忆解封 · 拆开时光胶囊

点击琥珀色格子，胶囊碎裂、格子散开恢复、记忆涌入。从1月1日开始，有记录的格子依次亮起，文字弹幕飘出。

✓ 碎裂动画 ✓ 记忆涌入 ✓ 完整恢复
🔃

数据导出与迁移

一键将所有数据打包成ZIP记忆胶囊，下载到本地。换手机时导入ZIP即可完整恢复。支持选择性导出。

✓ ZIP打包 ✓ 导入恢复 ✓ 选择性导出
🎨

格子亮起与祝福

每过一天格子自然亮起，有记录的格子更亮。生日、新年、整百天自动弹出祝福，播放去年同日的记录。

✓ 自然亮起 ✓ 生日祝福 ✓ 那年今天

封存与解封

封存不是删除，是把一年的记忆封进琥珀。解压不是恢复，是拆开时光胶囊，让回忆重新涌来

📦 封存回忆

  • 年度回顾预告：显示该年记录数据摘要
  • 沉浸式回忆流：全屏播放全年记录，配背景音乐
  • 定格最重要一天：自动跳转到年度最重要一天
  • 封存动画：格子收缩汇聚成金色记忆胶囊
  • 存入保险箱：胶囊飘入屏幕角落的记忆保险箱
  • 释放存储：完整数据从日常存储中移出，仅保留索引
  • 年度格子变为琥珀金色，hover显示"已封存"

🔓 解压回忆

  • 选择胶囊：点击琥珀色格子或导入ZIP文件
  • 拆封动画：胶囊旋转、裂纹扩大、金色光芒溢出
  • 胶囊碎裂：格子像烟花一样散开，重新铺满屏幕
  • 记忆涌入：格子从金色恢复为原色，文字弹幕飘出
  • 欢迎回来：显示"X年的记忆已恢复"，定格最重要一天
  • 完整恢复：所有视频、文字、图片、标签全部还原
  • 年度格子恢复亮色状态，可继续添加新记录

Memory Review

回忆与回顾

让过去的记忆主动来找你，每一次打开都是一次惊喜

📅

那年今天

每天打开自动展示N年前今天的记录。"3年前的今天，你在毕业典礼上哭了。"点击即可查看完整记录。

🎬

年度回顾电影

每年结束时，自动将该年所有视频片段按时间线拼接成一段"年度回忆短片"，配背景音乐。

🎲

随机回忆

摇一摇或点击按钮，随机跳到过去某一天有记录的格子。给你一个意外的回忆，也许是你早已忘记的美好瞬间。

📈

情绪曲线

基于每天的心情标签，生成年度情绪变化曲线图。看到自己情绪的起伏，发现生活的规律。

📷

沉浸式回顾

全屏播放某段时间的记录流，自动翻页，像翻相册一样浏览。支持对比模式：10年前的今天 vs 今天。

⭐

人生高光时间线

所有年份的"年度最重要一天"自动汇集成一条时间线。每个节点显示年份、日期、一句话摘要。
