Stage Map

把育儿路拆成看得懂的阶段

新手父母最怕“现在应该做什么”。萌芽手册用阶段地图把复杂准备转化成清晰的下一步。

01

备孕准备

体检、营养、作息、心理预期和家庭分工，用清单帮家庭从第一步开始准备。

02

孕期陪伴

按孕周整理产检提醒、身体变化、风险信号和生活注意事项。

03

待产生产

待产包、证件、入院流程、生产选择和家属陪护重点一页看清。

04

月子护理

围绕妈妈恢复、宝宝喂养、睡眠、黄疸和护理误区提供真实经验。

05

0-1 岁成长

疫苗、辅食、翻身、坐立、爬行、语言启蒙和家庭记录持续跟进。

Pain Points

新手父母真正需要的不是更多信息

他们需要可信、分阶段、能互相验证的经验，以及一个能保存家庭记忆的地方。

?

信息太分散

短视频、群聊、文章、亲友建议各说各话，新手父母难以快速判断。

!

经验难辨真伪

很多经验缺少阶段和场景说明，照搬后反而增加焦虑。

···

缺少同伴支持

相同阶段的问题反复出现，却没有被结构化沉淀和复用。

☆

记录容易散落

成长瞬间分散在相册、备忘录和聊天记录里，难以长期回顾。

Core Features

一本手册，串起准备、经验、互助和记录

萌芽手册不是单一知识库，而是围绕家庭阶段流转的育儿协作平台。

清单

阶段任务清单

按备孕、孕期、待产、月子、宝宝月龄自动整理待办事项和准备重点。

经验

避坑经验库

沉淀真实家庭的注意事项、常见误区和可复用心得，按阶段检索。

互助

同阶段社区

让同月龄、同孕周、同问题的父母快速找到彼此，减少孤立感。

记录

成长节点档案

记录出生、满月、第一次翻身、第一次坐立、第一次叫爸爸妈妈。

提醒

个性化提醒

根据家庭阶段和宝宝月龄推送检查、疫苗、辅食和护理提醒。

User Flow

使用路径足够简单，才适合疲惫的新手父母

用户不需要学习复杂系统，只需要告诉平台“我现在在哪个阶段”。

01

选择阶段

从备孕、孕期、待产、月子或宝宝月龄开始。

02

查看清单

获得当前阶段最需要准备和关注的事项。

03

阅读经验

用真实案例理解容易忽略的细节和误区。

04

社区互助

向同阶段父母提问，也分享自己的心得。

05

记录成长

把宝宝的重要节点保存成家庭成长手册。

“原来不止我一个人会在半夜搜索宝宝为什么哭。有人在同一个阶段，真的会安心很多。”

孕 32 周：待产包到底哪些东西真的会用上？
宝宝 2 个月：白天小睡短，是不是每个家庭都会遇到？
新手爸爸：第一次打疫苗前，需要提前准备什么？

Social Value

把个体经验变成可被更多家庭使用的社会支持

萌芽手册希望减少育儿初期的信息不平等和情绪孤岛，让新手父母更从容。

更高效

减少反复搜索

用阶段化清单聚合关键事项，让父母把精力放回照顾自己和宝宝。

更安心

降低新手焦虑

真实经验和同伴回应让家庭知道“这个问题有人遇到过，也有办法处理”。

更长久

保存成长记忆

将宝宝的重要节点沉淀为可回顾的家庭手册，陪伴孩子和父母共同成长。

Vision

让每个新手家庭，都有一本属于自己的萌芽手册

它记录准备，连接经验，托住焦虑，也收藏宝宝从来到世界第一天起的每一次成长。萌芽手册希望成为新手父母身边温柔、可靠、可以一起长大的育儿伙伴。
