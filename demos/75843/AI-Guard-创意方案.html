01 · 创意名称 + 创意介绍

一套“ invisible but always there ”的居家养老守护方案

以非侵入式感知与 AI 决策为核心，打通家庭、子女、社区三方闭环。

创意名称

AI-Guard 智慧社区居家养老智能系统

“AI”代表智能决策与语音交互，“Guard”代表全天候守护。我们想做的是老人身边的隐形守护者。

想解决什么问题

中国 90% 的老人选择居家养老，但独居老人面临意外无法及时发现、子女远程关心困难、社区服务响应滞后三大痛点。很多老人“不想麻烦子女”，导致摔倒、突发疾病、忘记服药等问题被延误处理。

为什么会想到做这个

灵感来自一次真实的社区走访：一位独居奶奶摔倒两小时后仍无人发现。我们参观了深圳作为科技等智慧养老企业后意识到，现有方案往往设备孤立、交互复杂。我们想把“科技的温度”真正落地到老人家里。

大概是什么产品

一个由智能传感器 + 家庭网关 + 三端应用组成的全栈系统。老人通过语音/一键按钮交互；子女通过鸿蒙 App 查看状态、接收报警；社区通过 Vue 数据大屏做服务联动与权限管理。

产品形态：三端一体 + 边缘感知

端侧采用 ESP32-S3、涂鸦传感器、树莓派网关；云端采用 Java / Spring Boot / openGauss；应用层覆盖老人端、子女端、社区端。

老人端

语音交互、一键 SOS、服药提醒、环境感知报警，低门槛使用。

子女端

实时查看父母状态、接收异常报警、远程设置守护规则。

社区端

数据大屏、报警处理、服务调度、权限与档案管理。

02 · 目标用户及痛点

三方用户，一个共同目标：让老人安全、安心、不孤单

我们不只是服务老人，更连接子女与社区，形成可持续的居家养老守护网络。

核心用户：老年人

典型使用场景

独居在家日常起居、夜间起夜、服药时间、突发身体不适或意外摔倒时。

当前痛点

  • 摔倒、突发疾病无法及时呼救
  • 忘记服药或重复服药
  • 智能设备操作复杂，不会用
  • 不愿频繁打扰子女，报喜不报忧

关切群体：子女 / 家属

典型使用场景

在外工作、出差或异地居住时，想远程了解父母健康与安全状态。

当前痛点

  • 电话/视频无法掌握老人实时状态
  • 接到邻居通知才知道出事
  • 担心父母被诈骗或忘记关水电气
  • 工作与尽孝之间时间冲突大

服务主体：社区 / 机构

典型使用场景

社区日间照料中心、网格员巡检、紧急上门援助、健康档案与服务派单。

当前痛点

  • 老人信息分散，难以精准服务
  • 报警来源多，响应流程不清晰
  • 服务资源调配缺乏数据支撑
  • 家属授权与隐私边界难管理

从家庭温情到社会效率，创造可量化的价值

我们选择在社会价值与效率提升两个维度重点发力，同时保持清晰的商业延展路径。

01

社会价值：让养老更有尊严

响应国家“9073”养老格局与积极应对人口老龄化战略，让 90% 选择居家养老的老人拥有“ invisible guardian ”。通过跌倒检测、危险环境感知、一键求救，显著降低独居老人意外死亡率；通过语音陪伴与用药提醒，缓解老人孤独感与认知衰退。

02

效率提升：三方协同，分钟级响应

打破老人、子女、社区之间的信息孤岛。传感器自动上报 → 边缘网关初步研判 → 云端 AI 决策 → 子女与社区同步接收 → 服务工单自动派发。从“事后补救”变为“事前预警”，从“人找服务”变为“服务找人”。

03

商业价值：可复制的社区级方案

以“硬件 + SaaS + 服务”模式面向街道/社区/物业/保险公司输出。基础版硬件套件降低部署门槛，社区数据大屏提供订阅式服务，AI 语音与健康管理可延伸至慢病管理、居家康复等高附加值场景，具备良好的规模复制潜力。
