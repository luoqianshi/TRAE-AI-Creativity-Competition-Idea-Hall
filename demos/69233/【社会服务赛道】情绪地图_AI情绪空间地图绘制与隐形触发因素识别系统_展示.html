Tech Stack

技术原理与AI分析引擎

让情绪分析既有心理学的严谨，又有数据科学的精准

🧠 多模态情绪识别引擎

综合语音语调分析（语速/停顿/音量变化）、文本情感分析（基于BERT的中文情感模型）、表情符号语义映射，将用户的30秒输入转化为五维情绪向量（愤怒/悲伤/焦虑/平静/快乐）与强度值（-5到+5）。

# 情绪向量编码 emotion_vector = { "anger": (0.2, -3), # (概率, 强度) "sadness": (0.6, -4), "anxiety": (0.1, -2), "calm": (0.05, +1), "joy": (0.05, +2) } primary = max(emotion_vector, key=lambda x: x[1])

📈 时序情绪聚类与模式挖掘

使用DTW（动态时间规整）算法对齐跨周的情绪时序数据，通过K-Shape聚类发现重复出现的情绪模式。当某个场景（如"周一例会"）在多个周期中对应相似的情绪低谷时，系统将其标记为"隐形开关"。

# 隐形开关检测 for scene in all_scenes: if cross_week_correlation(scene) > 0.75: if avg_emotion(scene) < -2: mark_as_trigger(scene, "负面开关") elif avg_emotion(scene) > +2: mark_as_trigger(scene, "充电站")

📍 空间化情绪地形渲染

将抽象的情绪时序数据映射为二维地形图：情绪强度映射为海拔高度，时间映射为水平坐标。使用高斯核密度估计生成平滑的"情绪等高线"，让用户的情绪波动呈现出类似地形起伏的直观视觉效果。

# 情绪海拔映射 altitude(x, t) = sum( intensity[i] * exp(-((t - time[i])**2) / (2 * sigma**2)) for i in emotions ) # 绘制等高线 = 情绪等值线

🔒 隐私优先的本地计算架构

情绪数据极度敏感，所有原始记录和AI分析均在设备端完成（端侧LLM + 本地SQLite）。用户可选择性地将匿名化的模式统计上传至云端用于算法优化，原始内容永远不会离开手机。支持密码锁与生物识别双重保护。

# 隐私架构 raw_data -> [本地加密存储] -> [端侧AI分析] patterns -> [匿名聚合] -> [可选上传] insights -> [用户可见] -> [导出PDF报告]
