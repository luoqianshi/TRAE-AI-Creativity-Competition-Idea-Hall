01 / PROBLEM

三个被忽视的老问题

群里人多,互相不认识

50-500 人社群,半年后真正互相认识的不超过 5%。主理人拉群容易,激活关系极难。

精华对话被刷屏

一条有价值的对话,24 小时后就被淹没。手工整理耗时 2-3 小时/天,主理人靠爱发电。

人才之间找不到彼此

群里有现成专家能解决你的问题,但你不知道 ta 在群里。资源错配,效率最低。

02 / PRODUCT

四大核心模块

M1

成员图谱

把 211 人渲染成可缩放、可筛选的关系网络。点击节点查看个人画像,左右侧玻璃面板联动。

  • 社交链 / 思维链 / 双链叠加 三种模式
  • 城市 / 角色 / 场景 多维筛选
  • 9 字段详情抽屉 + 思维指纹 + 共鸣成员
M2

群聊精华日报

每日 02:40 自动跑批,产出 7-8 条自包含的语义卡片,可双向链接、可被引用、可导出。

  • 原子化语义卡片(每条独立可读)
  • 精华二级图谱(以卡片为中心的相关网络)
  • 主题网络视图 + Obsidian/Notion 导出
M3

入群 SOP

群主配置欢迎语 + 模板化自我介绍表单,新人入群 5 字段自动采集,沉淀为可用画像。

  • 模板编辑器 + 实时预览(微信对话风)
  • 字段:昵称 / 城市 / 职业 / 工具 / 场景
  • 一键生成群公告
M4

按问题找人

7 大场景入口(AI 编程/产品原型/金融量化...),3 秒出推荐 + 评分 + 思维匹配依据。

  • L1 标签匹配 + L2 思维匹配 + L3 立场匹配
  • 每条推荐展示"为什么推荐 ta"
  • 匹配报告可导出 PDF
03 / METHODOLOGY

双链范式 + 原子化笔记 + 思维建模

— 01

双链结构

把"谁和谁聊过"(社交链)和"谁和谁想的是同一件事"(思维链)拆成两层图谱,叠加显示。

— 02

原子化笔记

每条精华必须自包含——读完一条就能 get 一个点。可双向链接,不被粗暴压缩。

— 03

个人思维建模

从"是谁"升级为"怎么想":表达偏好 / 关注议题 / 立场倾向,基于发言 embedding 提炼。

— 04

个人知识库导出

支持导出双向链接 Markdown(Obsidian vault 格式)/ Notion / 标准 Markdown,知识归个人。

05 / BUSINESS

商业路径与目标用户

目标用户

  • AI / 技术 / 知识付费社群主理人
  • 国内估测 500-2000 个,客单价 ¥199-999/月
  • 典型场景:50-500 人规模的微信群
  • 需要内容沉淀 + 关系激活 + 会员留存

核心壁垒

  • 全 AI 跑批降低运营成本(主理人日均 2-3h → 5min)
  • 可调频(日 1-3 次)控制 API 费用
  • 数据隔离的多租户 SaaS 后台
  • 本地缓存解密,降低账号封禁风险
