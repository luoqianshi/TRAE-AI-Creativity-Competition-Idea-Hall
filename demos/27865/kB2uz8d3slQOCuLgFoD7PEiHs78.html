AI 图表翻译器
Chart Translator

人工绘制图表，后台自动产出 Python 脚本，让 AI 实现对复杂图表的 100% 精准复刻

项目概述

在大语言模型（LLM）和视觉语言模型（VLM）快速发展的今天，AI 已经能够理解和生成大量文本内容。然而，当面对复杂的专业图表时——例如德尔菲法预测结果的截角楔形图、多维雷达对比图、嵌套桑基图等——VLM 的识别准确率仍然极低，LLM 更是无法从零开始准确复刻这些图表。

AI 图表翻译器（Chart Translator）正是为解决这一核心痛点而设计的本地化工具。用户在前端界面人工绘制所需图表，系统后台自动生成对应的 Python 绘图脚本（.py）。随后，通过 VLM 对原图进行语义理解生成 JSON 描述，再由 LLM 将 JSON 与 Python 脚本串联，形成完整的图表复刻工作流。未来，LLM 只需调用这套工作流，即可 100% 精准复刻任意复杂图表。

核心理念：将人类对图表的精确控制力与 AI 的代码生成能力结合，构建"人画图 → 机器出代码 → AI 学会复刻"的闭环。

痛点分析

问题一：VLM 无法准确识别复杂图表

视觉语言模型在处理简单柱状图、折线图时尚可胜任，但面对专业领域中的非标准图表（截角楔形图、三角图、平行坐标图、和弦图等）时，识别准确率急剧下降。图表中的细微标注、精确比例、特殊布局往往被完全忽略或严重扭曲。

问题二：LLM 无法从描述中准确还原图表

即使通过人工修正为 VLM 提供了正确的图表描述，LLM 在尝试生成对应图表代码时，仍然面临巨大困难。原因在于：缺乏精确的坐标、比例和布局信息。自然语言描述天然存在模糊性，无法传达图表中像素级的精确位置关系。

问题三：现有工具仅能导出 SVG，LLM 无法理解

市面上的绘图工具（如 Figma、Draw.io、Excel）大多只能导出 SVG 或 PNG 格式。SVG 虽然是矢量格式，但其代码结构面向渲染而非语义理解，LLM 难以从中提取有意义的绘图逻辑。PNG 更是完全丢失了结构信息。这导致AI 无法从已有图表中学习绘图方法。

解决方案

核心架构：三阶段流水线

AI 图表翻译器采用三阶段流水线架构，将人类绘图意图精确转化为 AI 可执行的代码：

✎

阶段一：人工绘制

用户在前端画布上通过可视化操作绘制目标图表，支持拖拽、缩放、精确坐标调整等交互方式，确保图表的每个细节都符合预期。

⚙

阶段二：自动生成 PY

后台引擎将用户的绘图操作实时翻译为 Python 绘图脚本（基于 Matplotlib / Plotly），包含精确的坐标、颜色、标注等参数。

🤖

阶段三：AI 复刻

VLM 理解原图语义生成 JSON 描述，LLM 将 JSON 与 PY 脚本串联，形成可复用的图表生成工作流，实现 100% 精准复刻。

技术方案

前端：交互式画布

前端采用 Electron + Fabric.js 构建交互式画布，支持丰富的绘图操作：拖拽图形元素、调整坐标与尺寸、设置颜色与样式、添加文字标注等。所有操作事件被实时捕获并序列化为结构化数据，传输至后端引擎。

后端：代码生成引擎

后端引擎接收前端传来的结构化绘图数据，通过模板映射 + AST 构建的方式生成 Python 绘图脚本。支持 Matplotlib 和 Plotly 两种输出后端，覆盖静态图表和交互式图表的需求。生成的代码包含完整的导入语句、数据定义、绘图参数和样式配置。

AI 集成：VLM + LLM 协作

系统集成本地或 API 调用的 VLM 和 LLM 模型。VLM 负责对原始图表进行语义理解，输出结构化 JSON 描述（包含图表类型、数据关系、视觉语义等）。LLM 负责将 JSON 描述与 Python 脚本进行语义对齐，理解"这段代码画的是什么"、"如何修改参数来适应新数据"，最终形成完整的复刻能力。

价值与意义

对 AI 行业的价值

当前 LLM 在图表生成领域最大的瓶颈不是"不会写代码"，而是"不知道该写什么样的代码"。AI 图表翻译器通过人工绘制→代码生成的路径，为 LLM 提供了精确的图表-代码配对样本，填补了这一关键空白。这将直接推动 AI 在专业可视化领域的能力提升。

对科研工作的价值

科研论文中的复杂图表往往需要数小时甚至数天来制作。通过 AI 图表翻译器，研究者可以一次绘制、永久复用。生成的 Python 脚本可以轻松修改数据源、调整参数，实现图表的快速迭代。同时，脚本化的图表也提高了科研的可重复性。

对知识管理的价值

在知识库整理过程中，大量有价值的图表因为无法被 AI 理解而变成了"信息孤岛"。AI 图表翻译器能够将这些图表转化为 AI 可读、可理解、可复刻的代码资产，极大地提升了知识库的可用性和价值密度。

愿景：让每一张人类制作的复杂图表，都成为 AI 可以精确理解和复刻的高价值数字资产。构建"人类画图 → AI 学会 → AI 独立复刻"的正向循环。

发展路线图

Phase 1：核心功能 MVP

实现基础的画布绘图功能和 Python 代码生成引擎，支持常见图表类型（柱状图、折线图、饼图、散点图），输出 Matplotlib 脚本。打包为 Windows EXE。

Phase 2：专业图表支持

扩展支持截角楔形图、三角图、和弦图、桑基图、雷达图等专业图表类型。增加 Plotly 输出后端，支持交互式图表。

Phase 3：AI 集成

集成 VLM + LLM，实现"原图 → JSON 描述 → PY 脚本 → 复刻工作流"的完整闭环。支持本地模型和云端 API 两种模式。

Phase 4：生态扩展

构建图表代码库与复刻工作流市场，支持社区分享。增加 R（ggplot2）、JavaScript（D3.js）等多语言代码输出。

总结

AI 图表翻译器瞄准了一个被长期忽视的关键痛点：AI 无法准确理解和复刻复杂图表。通过"人工绘制 + 自动代码生成 + AI 学习复刻"的创新路径，本项目不仅提供了一个实用的本地工具，更重要的是构建了一套让 AI 从人类图表中学习的系统化方法。

这不是简单的"画图工具"，而是一座连接人类可视化能力与AI 代码生成能力的桥梁。随着 LLM 在各领域的深入应用，对精确图表生成的需求只会越来越大。AI 图表翻译器正是这一趋势下的关键基础设施。
