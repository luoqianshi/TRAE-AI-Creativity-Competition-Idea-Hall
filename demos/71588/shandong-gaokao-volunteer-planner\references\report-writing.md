# HTML 报告写作规范

## 一、输出文件

- 文件名：`山东高考志愿100方案.html`（默认放 `E:\qq wenjian\` 下，可让用户指定）。
- 单文件：CSS / JS / 数据全部内嵌，不依赖外部资源，不依赖联网。
- 用户双击即可打开，不需要启动服务器。
- **不输出 Excel / Word / PDF**。

## 二、首屏结构

```
┌─────────────────────────────────────────────┐
│  山东高考志愿 100 方案                        │
│  考生：xxx  分数：xxx  位次：xxx  选科：xxx   │
├─────────────────────────────────────────────┤
│  总览：冲 X | 稳 Y | 保底 Z | 新增 W         │
│  必读风险提醒：[民办 X 条] [高收费 X 条] ...  │
├─────────────────────────────────────────────┤
│  [冲档分析]  [稳档分析]  [保底分析]  ← 三个入口按钮 │
├─────────────────────────────────────────────┤
│  最值得保留的 10 个志愿（卡片）              │
├─────────────────────────────────────────────┤
│  主表（100 个志愿，支持筛选/搜索）           │
└─────────────────────────────────────────────┘
```

### 2.1 考生画像区

显示：考生姓名/代号、年份、省份、总分、位次、选科、单科成绩、偏好（priorities）、学费上限、可接受办学性质、偏好专业方向、偏好城市、体检限制。

### 2.2 总览区

显示四档数量（冲/稳/保底/新增）。

### 2.3 必读风险提醒区

用红/橙色醒目标注：

- 民办志愿数量。
- 中外合作志愿数量。
- 高收费志愿数量（学费 ≥ 50000）。
- 体检限制相关志愿数量。
- 无往年数据（新增）志愿数量。
- 校区偏远志愿数量。

### 2.4 三个入口按钮（强制要求）

```html
<nav class="top-nav">
  <a href="#section-chong" class="nav-btn nav-chong">冲档分析</a>
  <a href="#section-wen"   class="nav-btn nav-wen">稳档分析</a>
  <a href="#section-bao"   class="nav-btn nav-bao">保底分析</a>
</nav>
```

- 点击 `冲档分析` → 滚动到 `<section id="section-chong">`。
- 点击 `稳档分析` → 滚动到 `<section id="section-wen">`。
- 点击 `保底分析` → 滚动到 `<section id="section-bao">`。
- 使用 `scroll-behavior: smooth` 实现平滑滚动。
- 按钮固定在首屏可见位置，移动端也能点击。

### 2.5 最值得保留的 10 个志愿

从 100 个中按 `score` + `keep_priority` 选出前 10 个，用卡片形式展示，每张卡片包含：学校、专业、城市、档位、入选理由、风险提醒。

### 2.6 主表

支持以下筛选/搜索（用内嵌 JS 实现，纯前端，不联网）：

- 按档位筛选：全部 / 冲 / 稳 / 保底 / 新增。
- 按城市筛选：从结果中提取去重城市列表。
- 按办学性质筛选：公办 / 民办 / 中外合作 / 高收费。
- 按专业方向筛选：从结果中提取去重 `discipline` 列表。
- 搜索框：输入关键字匹配学校名或专业名。

每行显示 12 列：

| 列 | 说明 |
|---|---|
| 序号 | 1-100 |
| 档位 | 冲/稳/保底/新增（用颜色区分） |
| 学校 | school_name |
| 专业 | major_full_name |
| 城市 | city |
| 公私性质 | ownership |
| 学费 | tuition（元/年） |
| 2026 预估位次 | estimated_rank_2026 |
| 历年最低位次 | min_rank_1 / min_rank_2 / min_rank_3 |
| 位次差 | ref_rank - R（负数表示冲，正数表示保底） |
| 推荐理由 | reason |
| 风险提醒 | risk_note（用红/橙色标注） |

民办、中外合作、高收费、新增专业的行用特殊背景色：

- 民办：浅黄背景。
- 中外合作：浅橙背景。
- 高收费：浅红背景 + 红色文字标注"高收费"。
- 新增专业：浅紫背景 + 紫色标签"新增"。
- 体检限制相关：红色边框 + "体检"标签。

## 三、下方分析区（强制要求三个）

### 3.1 冲档分析 `<section id="section-chong">`

内容要点：

- 冲档的核心：录取位次显著优于考生位次，存在落榜风险，但学校/专业价值值得尝试。
- 冲档建议数量：25-30 个，排在 96 个志愿的前部。
- 哪些值得冲：学校层次明显提升（如双一流）、专业方向匹配、城市意向匹配。
- 哪些只是看起来好但不适合：冲档专业与排斥方向冲突、冲档中外合作但学费超限、冲档校区偏远、冲档体检受限。
- 风险提示：冲档过多易滑档，建议控制在 30 个以内。
- **老师建议小结**：1-2 段话，结合本考生的冲档候选给出具体建议。

### 3.2 稳档分析 `<section id="section-wen">`

内容要点：

- 稳档是主体区间，位次接近考生，录取概率较高。
- 稳档建议数量：35-45 个，是 96 个志愿的中坚。
- 稳档应优先保证：专业满意度、城市意向、公办属性、考研考公适配度。
- 重点考察：学科评估、硕士点博士点、保研率、专业水平（国家级/省级一流）。
- 注意录取规则：分数优先 / 专业优先 / 专业级差，影响志愿排序策略。
- **老师建议小结**：1-2 段话，结合本考生的稳档候选给出具体建议。

### 3.3 保底分析 `<section id="section-bao">`

内容要点：

- 保底的核心：保证本科和底线可接受，避免滑档。
- 保底建议数量：25-30 个，排在 96 个志愿的后部。
- 公办保底优先，民办/中外合作/高收费作为补充保底。
- **民办、中外合作、高收费必须强备注**：学费、性质、风险，不得伪装成优先推荐。
- 保底不能太少：建议至少 5-10 个公办本科兜底。
- **老师建议小结**：1-2 段话，结合本考生的保底候选给出具体建议，明确指出哪些是"经济压力较大"的备选。

## 四、入选理由（reason）写作模板

每条志愿的 `reason` 必须具体、可解释，**避免空话**。

### 4.1 模板

```
[档位标签] 学校名 + 专业名 + 城市 + 性质 + 学费。
位次匹配：考生位次 R，本专业参考位次 ref_rank，位次差 Δ，[冲/稳/保底]。
匹配点：[专业方向命中 / 城市命中 / 学科评估 A / 保研率 X% / 公办学费低 / 硕士点博士点齐全]。
```

### 4.2 示例

```
[稳] 青岛大学 + 计算机科学与技术 + 青岛 + 公办 + 5100元/年。
位次匹配：考生位次 150000，本专业参考位次 148000，位次差 -2000，稳档核心。
匹配点：专业方向命中"计算机"，城市命中"青岛"，有硕士点，公办性价比高。
```

```
[保底] 烟台大学 + 软件工程 + 烟台 + 公办 + 6600元/年。
位次匹配：考生位次 150000，本专业参考位次 175000，位次差 +25000，保底区间。
匹配点：公办兜底，专业方向相关，城市可接受。
```

```
[新增] 山东建筑大学 + 人工智能 + 济南 + 公办 + 5500元/年。
位次匹配：新增专业无往年数据，参考位次缺失。
匹配点：专业方向命中，公办学费合理，城市命中"济南"。
风险：无往年录取数据参考，实际录取位次可能大幅波动。
```

## 五、风险提醒（risk_note）写作模板

`risk_note` 必须明确指出具体风险，**不得写"无明显风险"敷衍**。如果没有显著风险，写"暂无明显风险，建议核实当年招生章程"。

### 5.1 常见风险类型与话术

| 风险类型 | 话术示例 |
|---|---|
| 民办 | "民办院校，学费 X 元/年，社会认可度低于公办，建议家庭确认经济承受能力。" |
| 中外合作 | "中外合作办学，学费 X 元/年，培养模式特殊，出国衔接与学位授予方式需核实当年招生章程。" |
| 高收费 | "高收费专业，学费 X 元/年，超出常规公办学费 X 倍，家庭经济压力较大。" |
| 体检限制 | "本专业对色觉/视力有要求，考生体检结论为 X，需确认是否符合录取条件。" |
| 新增专业 | "新增专业，无往年录取数据参考，实际录取位次可能大幅波动。" |
| 校区偏远 | "校区位于 X（四线/五线城市），区位偏远，实习就业资源相对有限。" |
| 招生计划少 | "2026 计划招生 X 人，计划数过少，录取位次波动风险高。" |
| 位次波动大 | "近三年最低位次分别为 X/Y/Z，波动幅度 ≥ 30%，稳定性较差。" |
| 录取规则 | "录取规则为专业级差，志愿排序需谨慎，建议放在前部位置。" |
| 无往年数据 | "无任何往年录取数据，参考价值低，建议谨慎填报。" |

### 5.2 keep_priority 取值

- `建议优先保留`：稳档核心、公办、专业匹配、综合评分高。
- `可备选`：稳档边缘、保底公办、综合评分中等。
- `慎重考虑`：民办、中外合作、高收费、新增、体检限制、校区偏远。

## 七、技术要求

- HTML5 + 内嵌 CSS + 内嵌 JS，不依赖任何外部 CDN。
- 表格支持响应式，移动端可横向滚动。
- 颜色规范：
  - 冲档：红色系 `#e74c3c`。
  - 稳档：绿色系 `#27ae60`。
  - 保底：蓝色系 `#3498db`。
  - 新增：紫色系 `#9b59b6`。
  - 民办/高收费：橙黄色系 `#f39c12` / `#e67e22`。
- 字体：系统默认中文字体栈，避免使用 Web Font。
- 数据内嵌为 `<script type="application/json" id="volunteers-data">...</script>`，由 JS 读取后渲染表格。
- 不使用任何外部图片，所有图标用 emoji 或纯 CSS 实现。

## 八、模板复用

`assets/report-template.html` 提供基础模板，`render_html_report.py` 通过字符串替换以下占位符生成最终 HTML：

- `{{STUDENT_INFO}}`：考生画像 JSON。
- `{{VOLUNTEERS_DATA}}`：100 个志愿 JSON。
- `{{OVERVIEW}}`：总览数据 JSON。
- `{{ANALYSIS_CHONG}}`：冲档分析 HTML 片段。
- `{{ANALYSIS_WEN}}`：稳档分析 HTML 片段。
- `{{ANALYSIS_BAO}}`：保底分析 HTML 片段。
- `{{TOP10}}`：最值得保留 10 个的 HTML 片段。
- `{{GENERATED_AT}}`：生成时间。

分析区 HTML 由 `render_html_report.py` 根据考生实际情况动态生成（不能是空模板）。
