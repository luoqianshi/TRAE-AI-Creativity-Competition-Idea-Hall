# 老师式访谈流程

Skill 拿到学生信息后**不许直接筛选**，必须先像认真负责的升学规划老师一样，按三轮把情况问清楚。如果学生一次性把信息给全，也要逐项复述确认（"我帮你复述一遍，请确认无误"），再进入筛选。

## 第一轮：硬信息（必问）

| 项 | 说明 | 是否必填 |
|---|---|---|
| `year` | 考生年份（2026 届即 2026） | 必填 |
| `province` | 省份，本 Skill 只处理山东 | 必填，必须为"山东" |
| `score` | 总分（满分 750） | 必填 |
| `rank` | 全省位次（夏季高考普通类一分一段表） | 必填 |
| `elective` | 选科组合，3 门，如 "物理+化学+生物" | 必填 |
| `single_subjects` | 单科成绩，至少含数学、英语；如选物理/化学/生物则也填 | 必填 |
| `batch` | 批次，本 Skill 默认普通类常规批（一段） | 必填，默认"常规批一段" |
| `subject_type` | 科类，山东新高考为"综合" | 必填，默认"综合" |

注意：

- 山东新高考是 "3+3" 模式，不分文理，`subject_type` 固定为"综合"。
- 位次比分数更重要，是分档的主要依据。
- 单科成绩用于判断专业适配（如数学差慎选计算机、电子；物理差慎选机械、自动化）。

## 第二轮：偏好信息（必问）

| 项 | 说明 | 默认 |
|---|---|---|
| `priorities` | 看重哪几项：学校 / 专业 / 城市 / 考研 / 考公 / 就业（可多选） | 必填 |
| `prefer_in_province` | 是否优先山东省内 | 必填 |
| `acceptable_provinces` | 能接受的省份/城市列表 | 必填 |
| `unacceptable_provinces` | 绝对不能接受的省份/城市列表 | 必填 |
| `acceptable_ownership` | 能接受的办学性质：公办 / 民办 / 中外合作 / 高收费 | 必填 |
| `tuition_limit` | 每年学费上限（元），家庭可承受的总额 | 必填 |
| `preferred_majors` | 喜欢的专业方向（如计算机、电子、电气、师范、医学、法学、会计等） | 必填 |
| `excluded_majors` | 明确排斥的专业方向 | 必填 |
| `preferred_cities` | 偏好的城市（如济南、青岛、北京、上海、南京、武汉、成都等） | 可空 |
| `preferred_disciplines` | 偏好的门类（如工学、理学、医学、法学、经济学、管理学） | 可空 |

注意：

- 学费上限必须真实反映家庭承受能力。中外合作、高收费专业常见 5 万-19 万/年。
- 如果家长说"民办也可以但要便宜"，要把学费上限降到 2 万以下。
- "高收费"指学费显著高于同校普通专业（通常 ≥ 5 万/年或 major_note 含"高收费"）。

## 第三轮：风险与限制（必问）

| 项 | 说明 | 默认 |
|---|---|---|
| `health_limits` | 体检限制：色盲 / 色弱 / 高度近视（>800度）/ 晕血 / 左利手 / 其他 | 必填，没有则填"无" |
| `exclude_controversial` | 是否排除争议方向：医学 / 护理 / 动物医学 / 化工 / 土木 / 师范 / 生物 / 环境 / 材料 | 必填 |
| `must_bachelor` | 是否必须保本科（不接受专科） | 必填，默认 true |
| `accept_adjust` | 是否愿意服从调剂 | 必填 |
| `parent_student_agree` | 家长与学生意见是否一致；不一致需说明分歧点 | 必填 |
| `special_notes` | 其他特殊说明（如家庭背景、定向招生、地方专项、军校警校意向等） | 可空 |

风险红线详见 `shandong-rules.md`。

## 访谈话术示例（参考）

- 第一轮开场：「您好，我先帮您把基本情况核对一遍，麻烦您确认分数、位次、选科这几项……」
- 第二轮：「再问几个偏好，您更看重学校牌子、专业方向，还是城市、考研、考公、就业？学费上限大概多少？民办、中外合作、高收费能不能接受？」
- 第三轮：「最后几个风险问题：孩子有没有色盲色弱、高度近视、晕血？有没有明确不想读的方向？必须保本科吗？家长和孩子意见一致吗？」

访谈没完成，**不允许**进入数据库查询。
