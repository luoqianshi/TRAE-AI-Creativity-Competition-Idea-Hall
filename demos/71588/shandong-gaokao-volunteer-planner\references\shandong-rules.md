# 山东新高考规则与风险红线

## 一、山东新高考基本规则

- 模式："3+3"（语文、数学、外语 3 门统一高考 + 3 门等级考选科）。
- 不分文理，`subject_type` 固定为"综合"。
- 总分 750：语文 150 + 数学 150 + 外语 150 + 选科 3 门各 100。
- 等级考赋分：选科 3 门按等级赋分，原始分不直接用。
- 志愿单位："专业(类)+院校"，一个专业+一个学校 = 一个志愿单位。
- 平行志愿数量：普通类常规批一段 96 个。
- 录取依据：**位次**（同分按语数外总分 → 数学 → 语文 → 外语 → 选科最高分 → 选科次高分 依次比较）。
- 批次：提前批 → 特殊类型批 → 常规批一段 → 常规批二段。
- 本 Skill 默认处理"常规批一段"。

## 二、位次为何比分数重要

- 高考试卷难度年度波动大，分数年度可比性差。
- 位次是全省排名，稳定性高，是录取的核心依据。
- `estimated_rank_2026` 是数据库给出的 2026 届预估位次，`min_rank_1/2/3` 是历年实际最低位次。
- 筛选与分档**必须以位次为主**，分数仅作辅助参考。

## 三、选科匹配红线

山东新高考选科要求从 2024 年起大幅调整：

- **理工农医类大多数专业要求"物理+化学"**。只选物理不选化学能报的理工专业大幅减少。
- 医学类专业（临床、口腔、麻醉、影像等）几乎全部要求"物理+化学"。
- 部分高校的计算机、电子、电气也要求"物理+化学"。
- 师范类、文法类、经济管理类多数"不限"或要求单科。
- 选科匹配必须严格执行，**不允许把选科不符的志愿放进候选**。

匹配规则见 `references/database.md` 的"选科匹配规则"表，由 `query_candidates.py` 的 `elective_match()` 函数实现。

## 四、体检限制红线

体检结论分三类：

1. **学校可以不予录取**（最严重）。
2. **学校有关专业可不予录取**（如色盲不能报美术、医学、化工；色弱不能报化学、生物等）。
3. **学校有关专业不宜就读**（建议但不强制）。

常见硬限制：

| 限制 | 不能报的方向 |
|---|---|
| 色盲 | 美术、医学类、化工、生物、地质、农学、公安、航海、医学影像 |
| 色弱 | 化学类、生物类、医学类、药学、食品、心理学、体育 |
| 高度近视（>800度） | 海洋科学、海洋技术、测控、化工、医学、材料 |
| 晕血 | 医学、护理、动物医学、检验 |
| 左利手 | 口腔医学（部分院校） |
| 听力/语言障碍 | 师范、外语、法学、新闻、播音 |

`query_candidates.py` 会查 `major_note` / `admission_rule` 中含"色"、"体检"、"不予录取"的项，结合学生 `health_limits` 二次判断。**体检冲突的志愿必须在硬过滤阶段排除**，不得放入候选。

## 五、民办 / 中外合作 / 高收费处理红线

- 可作为保底候选（用户在 `acceptable_ownership` 中允许时）。
- **必须强备注**：
  - 民办：学费高、社会认可度低于公办。
  - 中外合作：学费高、培养模式特殊、出国衔接、学位授予方式需核实。
  - 高收费（`tuition >= 50000` 或 `major_note` 含"高收费"）：家庭经济压力。
- **不得伪装成优先推荐**：在排序时排在同档位末尾，`keep_priority` 标"谨慎考虑"。
- 报告中必须用醒目颜色（红/橙）标注。

## 六、新增专业红线

- `is_new = '新增'` 的专业没有稳定历史数据（`min_rank_1/2/3` 多为 NULL）。
- **必须单独标记**为"新增/特殊"档，**不得当作稳妥保底**。
- 在报告中用特殊颜色（紫/蓝）标注，并提醒"无往年录取数据参考，风险较高"。

## 七、必须保本科时的处理

- 学生 `must_bachelor = true` 时，硬过滤排除 `degree_level` 含"专科"的项。
- `degree_level = '职业本科'` 算本科，可保留，但报告中提醒"职业本科"属性。
- 保底档必须保证至少 5-10 个公办本科兜底，避免全部依赖民办。

## 八、地方专项 / 定向招生

- `plan_type` 含"地方专项"、"定向"等特殊计划时，必须确认学生是否符合资格（户籍、学籍等）。
- 不符合资格的应排除。
- 这类计划通常分数要求低，但不能简单当保底，报告中需说明资格要求。

## 九、96 个平行志愿的填报策略（供老师建议参考）

- 山东常规批一段 96 个平行志愿按"分数优先，遵循志愿"投档。
- 每个志愿都是"专业(类)+院校"，没有"服从调剂"概念（专业已确定）。
- 推荐排布：前 20-25 个冲、中间 40-50 个稳、后 20-25 个保底。
- 保底必须真正能兜住，不要全部填冲的导致滑档。
- 本 Skill 输出 100 个候选，留 4 个家庭讨论余地，最终填报 96 个由家庭确认。

## 十、不承诺录取声明

报告底部必须包含：
