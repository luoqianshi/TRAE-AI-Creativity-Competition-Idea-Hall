表现层 (Electron UI)

基于 React + Vite 构建的桌面渲染层。通过严格白名单 Preload API 与主进程进行 IPC 通信，保障系统安全。

编排层 (Agent Service)

基于 Node.js 与 LangGraph 驱动，负责 Context Assemble、计划生成、风控确认 (ConfirmIfNeeded) 及工具调度闭环。

基础设施 (Infrastructure)

包含 Ollama 大模型引擎、本地文件系统沙箱、Vector Store 向量库索引，以及外部 CLI 自动化引擎 (Automation Runner)。
