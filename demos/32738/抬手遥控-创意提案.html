01 / IDEA创意介绍

想解决什么:电视遥控器易丢、按键反人类、打字折磨人;用手机当遥控又总遇到「手机不在手边、双手占着、老人小孩不会用」。我们想让大家连遥控器都不用,抬抬手就能遥控电视——而且不用额外买任何新硬件。

WHY · 为什么做
现有产品「土拨鼠大屏助手」已能手机远程触控电视,还发现一个事实:电视本就是安卓系统,但芯片性能落后手机好几代——一台 8 年前的锤子手机 R1,芯片都比现在很多高端电视还强,大量存量电视停在老版本、32 位,根本跑不动新东西。
TURN · 拐点
新一代 64 位 + 高性能 CPU 的电视盒子正在出现,大屏终于能装手机版软件、跑得动 AI,而这块新市场的交互升级几乎没人做。
HOW · 怎么做
在土拨鼠已成熟的控制能力上,加一层摄像头手势识别(也就是「无遥控空间交互」),让新一代高性能盒子装个软件就能抬手遥控,正好填这个空白。

📦大概是什么产品

一款装在电视大屏 / 电视盒子(安卓系统)上的软件,用大屏自带或外接的摄像头看懂你的手势,手一挥电视就跟着动——实现不用遥控器、不用手机、空手就能遥控的大屏交互。

纯软件 · 无额外硬件 · 存量卡位 · 空手隔空

03 / VALUE价值与意义

📈商业价值

大屏交互升级是代际趋势,但方案都被厂商锁死在新机型里。电视芯片落后手机数代(锤子 R1 都比高端电视强),存量设备跑不动 AI。但拐点已至:新一代 64 位 + 高性能 CPU 盒子出现,大屏能装手机版软件、跑得动 AI,而这块新市场交互升级几乎空白。

本方案以「纯软件 + ADB」提前卡位窗口期,瞄准新一代高性能盒子,装个软件即可旗舰级隔空手势。谁先做出标杆,谁吃下大屏交互升级红利。复用土拨鼠已验证控制链路,感知层是增量投入,投入产出比高。

🌍社会价值

降低大屏交互门槛,让不擅长手机操作的老人和儿童也能「抬手即控」,弥合数字鸿沟;在双手占用场景(做饭、育儿、健身)下提供无障碍交互,提升家庭便利。

全本地处理、不上云、不存帧,大屏摄像头可控可关,不成为客厅的隐私负担。

04 / TECH技术方案

交互闭环

摄像头采集 → 端侧感知(手势/动作) → 意图理解 → ADB 指令 → 大屏响应 → 视觉反馈

四层架构

感知层
摄像头 → 端侧推理引擎
MediaPipe Hands/Pose 或蒸馏小模型,ONNX/TFLite 端侧部署,降分辨率控算力
理解层
手势分类 + 动作时序 + 激活态判定
状态机 + 轻量分类器,抑制误触;待机/激活双态,显式唤醒
控制层
ADB 指令映射(复用土拨鼠)
input swipe / tap / keyevent,手势→指令可配置,基建已验证
反馈层
屏幕指针 / 状态指示 / 提示
屏幕角常驻图标:灰=待机 / 亮=激活,一眼可知「它在不在听」
