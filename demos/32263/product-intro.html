Pain Points

核心痛点

1

多平台订单分散

拼多多进货、淘宝进货、得物出售、闲鱼出售……订单散落在多个 App，需要在之间反复切换，极易漏记。

2

隐性成本容易被忽略

只看买入价和卖出价，容易忽略发货运费、退回运费、平台扣费等隐性支出，导致利润计算失真。

3

行情变化快，手动查价累

商品价格波动频繁，用户需要反复打开得物等平台查看实时成交价，手动比价效率极低。

4

订单状态容易混乱

待发货、待取货、平台鉴别中、待结算、已结算、退回……状态一多就记不清哪笔单子卡在哪一步。

5

轻量工具缺失

个人卖家不需要复杂 ERP，但 Excel 记账又太原始，缺少一个轻量、直观、隐私友好的利润账本。

Core Features

当前核心功能

📝

完整交易记录

记录商品名称、进货渠道、出货渠道、入手成本、发货运费、退回运费、出售收入和订单状态，一笔不漏。

💰

自动利润计算

自动计算单笔净利润、总净利润、在途成本、待回款金额，隐性支出全部纳入，利润数据真实可靠。

📊

渠道筛选统计

支持按拼多多系、淘宝系、京东系、其他渠道筛选，快速对比不同进货/出货渠道的赚钱效率。

🏷️

财务状态标记

支持待结算、已结算等财务状态标记，一眼看清哪些钱已到账、哪些还在路上。

🔒

本地隐私存储

所有数据存储在浏览器本地，不上传任何云端，保护个人交易隐私安全。

💾

导出/导入数据

支持一键导出 JSON 备份和导入恢复，实现手动备份和多端迁移，数据永远在自己手中。

Roadmap

未来迭代方向

1
Phase 1 · 订单自动化

接入平台订单 API

自动同步购买订单、发货状态、退款状态和结算状态，减少手动录入，订单状态实时更新。

2
Phase 2 · 行情监控

接入商品行情数据

自动检测目标商品在得物等平台的实时成交价格或近期成交区间，无需手动查价。

3
Phase 2 · 预估利润

实时利润预估

根据买入成本、运费、平台扣费和当前行情，自动计算预估利润，帮助用户快速决策。

4
Phase 3 · 智能提醒

风险预警与经营建议

当商品行情跌破成本线、订单长时间未结算、退货导致利润变负时，自动提醒用户，并给出需要优先处理的订单列表。

5
Phase 3 · 交易监控台

从记账本到监控台

把工具从手动记账本升级为多平台商品交易状态监控台，实现订单、行情、利润、风险一站式管理。

Why ProfitLens

价值说明

✓ 减少手动输入

当前通过结构化表单快速录入，未来接入 API 后自动同步订单，大幅降低记账成本。

✓ 提高记账准确性

运费、退回运费、平台扣费全部纳入计算，告别"只看买卖价"的粗放记账方式。

✓ 保护交易隐私

数据存储在浏览器本地，不上传任何服务器，你的交易信息只属于你自己。

✓ 轻量即开即用

单个 HTML 文件，无需安装、无需注册、无需服务器，打开浏览器即可使用。

✓ 数据自主可控

支持导出/导入 JSON 数据，备份和迁移完全由用户掌控，不依赖任何第三方平台。

✓ 面向未来扩展

从手动记账到自动同步、行情监控、智能提醒，工具随用户需求逐步进化。
