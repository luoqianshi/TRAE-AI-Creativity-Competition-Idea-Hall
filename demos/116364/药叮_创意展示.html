痛点 · Pain Points

老人记不住，子女管不到

服药管理不是「设个闹钟」那么简单。真正难的是：药品种类多易混淆、方案会随疗程变化、库存与效期无人盯、异地子女只能靠电话反复确认。

记忆衰退，漏服错服频发

降压药、降糖药、钙片、护胃药……一天五六个时间点，老人记不清「哪种吃了几粒、上次什么时候吃的」，重复服、漏服、错服时有发生。

「降压药刚吃过，又拿起来要吃第二遍……」

子女异地，只能靠电话追问

成年子女普遍异地工作，每天打电话问「吃药了吗」既低效，又让老人觉得被唠叨。老人常报喜不报忧，漏了也不说。

「电话里说吃了，其实又忘了……」

药箱散乱，过期药还在吃

药盒散落抽屉，没人记录剩余量与有效期。药快吃完无人补，过期半年的药还在吃——这是当前所有「轻量代管」产品刻意回避的问题。

「整理药箱才发现，三盒药都过期了。」
体验设计 · Dual Protagonist

双主角，不是单向代管

子女与老人都是主角：子女负责配置，老人负责打卡，双方各自看到自己关心的。同一小程序，按角色自适应界面。

功能架构 · Architecture

五大模块，专注服药与药箱

严格限定在服药管理与药箱管理范畴，不涉医疗建议。每一个模块都为「双主角协作 + 适老」而生。

01

药品信息管理

结构化记录每一盒药，支持通俗称呼与颜色标签。

  • 扫码 / 拍照 / 手动三种录入
  • 名称 + 通俗称呼 + 规格 + 照片
  • 有效期 + 颜色标签
  • 按家庭药箱分组
02

多阶段服药方案

按疗程与时段灵活配置，匹配真实用药节奏。

  • 起止日期疗程设置
  • 早 / 中 / 晚 / 睡前时段
  • 每日 n 次 / 隔天 / 周指定日
  • 剂量备注（如「饭后半小时」）
03

智能提醒系统

纯微信订阅消息，零成本，靠机制保证不断链。

  • 方案自动派生提醒
  • 手动补充一次性提醒
  • 「打卡即续期」防断裂
  • 漏服宽限 + 二次提醒
04

多账号共享协作

三级权限防误改，代管标识有温度。

  • 管理员 / 编辑者 / 查看者
  • 小程序码 / 6 位码邀请
  • 操作日志可追溯
  • 「由女儿小萱为您管理」标识
05

库存与效期预警

自动扣减、阈值预警，填补同类产品空白。

  • 打卡自动扣减库存
  • 低库存阈值提醒补货
  • 近效期 / 已过期预警
  • 补货一键记录
∞

清晰的产品边界

只做记录、提醒、协作，绝不越界。

  • 不解读药品说明书
  • 不给处方或用药建议
  • 不做药物相互作用医学判断
  • 不监测健康指标 / 不问诊
风险与边界 · Boundary

知道不做什么，比做什么更重要

服药管理触及健康与医疗，边界必须清晰。药叮只做「记录 + 提醒 + 协作」，所有需医疗资质的能力一律不做，规避风险、保持聚焦。

做 · 服药与药箱管理

  • ✓ 药品信息结构化记录（名称/规格/有效期/照片）
  • ✓ 多阶段服药方案配置
  • ✓ 微信订阅消息提醒与打卡
  • ✓ 三级权限家庭协作
  • ✓ 库存与效期预警
  • ✓ 服药记录与依从性统计

不做 · 需医疗资质的内容

  • ✕ 药品说明书解读 / 用法用量医学解释
  • ✕ 处方建议 / 用药指导 / 剂量推荐
  • ✕ 药物相互作用医学判断（仅提示咨询医生）
  • ✕ 健康指标监测（血压/血糖/体重）
  • ✕ 在线问诊 / 药店导购 / 药品电商
  • ✕ 自动电话 / 短信兜底通道

关键风险：订阅消息「一次性」授权会断链

微信小程序订阅消息每次授权仅推送一条，老人若长期不进小程序，提醒链会断裂——这是纯订阅消息方案的最大技术风险。

化解：打卡即续期 + 子女端可见「授权余量」+ 余量不足优先通知子女引导
典型案例 · Use Cases

三个真实场景，看见药叮的价值

从独居老人到多子女协作，药叮把监督变成关怀，把焦虑变成安心。

场景一

异地独居母亲的降压药

王女士在外地工作，母亲独居服三种降压药。过去每天打电话确认，母亲常嫌烦、有时还报喜不报忧。

用药叮后，母亲按早/晚大按钮打卡，王女士仅漏服时收到提醒。一周省下 14 通电话，母亲也觉得「被牵挂而非被管」。
场景二

术后多疗程父亲的复杂用药

李父心脏支架术后，需服抗凝药 3 个月、降脂药长期、护胃药 2 周。三个疗程时段不同，家人记不清。

子女用多阶段方案分别配置，到期自动停。抗凝药剩 5 天时收到低库存预警，提前购药不断档。
场景三

兄妹三人协作照护奶奶

奶奶 78 岁，子女分散三地。谁来管药、谁来看状态，过去全靠微信群接力，信息常错乱。

大哥任管理员配方案，妹妹任编辑者补库存，弟弟任查看者只看状态。操作日志可追溯，再无「谁改错了」的扯皮。
价值与意义 · Value

把家庭沟通从监督，变回关怀

从效率提升与社会价值两个角度，药叮让普通家庭都能用上专业的服药协作工具。

效率提升

把服药确认从「电话三分钟」压缩到「一秒打卡」，把子女从「每日追问」解放为「异常才管」。

  • 老人侧 时段大按钮打卡，操作从记药名变为一键确认
  • 子女侧 仅异常触发通知，日均沟通成本下降 80%+
  • 库存侧 自动扣减与预警，告别「翻抽屉盘点」
  • 协作侧 三级权限 + 操作日志，多子女协作零扯皮

社会价值

以零门槛的小程序形态与纯订阅消息零成本方案，守护独居老人用药安全，缓解代际照护焦虑。

  • 适老普惠 免下载、零成本，老人扫码即用
  • 用药安全 降低漏服错服，减少由此引发的健康风险
  • 代际缓和 关怀替代唠叨，改善老人心理体验
  • 家庭韧性 异地子女也能稳定参与照护，缓解照护资源不足
