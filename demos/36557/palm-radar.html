1 创意名称 + 创意介绍

🎯

想解决什么问题

基于开源的 WiFi 信道状态感知技术（参考 ESPectre / RuView 项目思路），使用 ESP32-S3 开发板构建一台掌上生命探测仪。只要室内存在 WiFi 信号，无需摄像头、无需穿戴设备，就能让子女和社区工作人员远程知晓独居老人是否在家中活动、是否存在异常长时间静止。同时可扩展为公共场所的社交密度探测器，辅助空间管理和人群疏导。

💡

为什么会想到做这个

目前社区工作人员需要定期上门走访慰问老年人，老小区没有电梯，逐户爬楼梯效率低、强度大。独居老人一旦发生意外（跌倒、昏迷），可能在数小时内无人知晓。最关键的是 ——WiFi 信号探测完全不需要摄像头和麦克风，不采集任何音视频信息，从根本上保护老年人隐私权，让技术关怀不再以牺牲尊严为代价。

📱

大概是什么产品

一台圆形触控屏硬件设备（1.85 英寸、360×360 分辨率、CNC 铝合金外壳）。版型小巧可挂墙/放桌面，内置 WiFi 感知模组、六轴传感器、扬声器和锂电池。探测数据可推送到手机 App 或接入社区平台，子女和工作人员通过手机即可查看老人的活动状态。

2 目标用户及痛点

👥 面向用户

与父母分开居住的年轻人 —— 想知道独居父母今天是否正常活动，又不想频繁打电话打扰。

社区工作人员 / 养老机构护工 —— 面对数十户独居老人，需要高效掌握每户的基本安全状态。

📍 使用场景

独居老人的住宅（客厅/卧室/卫生间）、养老院房间、老旧小区。
设备贴在墙上或放在角落，连上家中 WiFi 即可工作，无需老人任何操作。

💔 当前痛点

• 只能打电话确认 —— 如果老人没接，焦虑和无助感会瞬间涌上来。
• 社区人员只能上门走访 —— 人力有限，老小区爬楼一趟就是半天。
• 摄像头上门侵犯隐私 —— 没有人愿意被24小时监视。
• 跌倒/昏迷后的"黄金窗口"很短 —— 但传统手段发现异常可能需要数小时甚至数天。

3 价值与意义

🔒

隐私优先的关怀

全程不使用摄像头和麦克风，仅分析室内 WiFi 信号变化来判断是否有人活动。不采集任何图像、声音或可识别个人身份的信息。技术关怀和隐私保护不是二选一。

⏱️

缩短意外发现时间

设备检测到老人长时间静止（超过日常活动模式阈值）时自动推送提醒。将意外发现窗口从"可能数天"压缩到"分钟级"，大幅提升急救成功率。

🏛️

社区工作减负

一台几十元的设备替代每周数次上门。社区人员可在后台统一查看辖区内独居老人活动概览，将有限的人力精准分配到真正需要上门关注的住户。

🌐

技术普惠

基于开源社区的 WiFi 感知研究成果（ESPectre / RuView），将学术论文和 GitHub 项目转化为普通人都能用得起的民生设备。技术门槛向下走，社会价值向上走。

核心算法（仅 3 步）

① 每秒采集周围 WiFi 信道的 RSSI 值，形成时间序列
② 对最近 3 秒的 RSSI 数据计算滑动方差
③ 方差 > 校准基线 + 阈值 → 判定环境中有活动物体

与 ESPectre 的 CSI 方案不同，这里使用更轻量的 RSSI 方差法，
足以检测室内人员走动（2–5 米范围），且完全跑在单块 ESP32-S3 上。

Get Started
三步上手掌上雷达
1

安装 Arduino IDE

下载安装后，添加 ESP32 开发板支持 URL：
https://espressif.github.io/arduino-esp32/package_esp32_index.json

2

安装依赖库

在 Arduino 库管理器中搜索安装：
TFT_eSPI（LCD驱动）、CST816S（触摸）、QMI8658（IMU）

3

烧录 & 开机

USB 连接板子 → 选择 ESP32S3 Dev Module → 点击上传
上电自动校准 10 秒，随后雷达扫描线开始旋转 —— 完成。
