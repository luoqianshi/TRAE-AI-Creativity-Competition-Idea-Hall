PROJECT OVERVIEW

什么是情绪星球？

情绪星球是一款 AI 驱动的交互式情绪可视化 Web 应用。用户每天用一句话或一段文字描述自己的心情，AI 会实时生成一颗独一无二的「情绪星球」——它拥有专属的地貌、大气颜色、天气系统和微小生命。

随着时间推移，你的星球会因为每天的情绪积累而不断演化：快乐让星球开花，焦虑掀起风暴，平静催生湖泊，悲伤带来雨季。30 天后，你将拥有一颗完全由你的情绪历史塑造的星球。

💡 核心理念：情绪不是需要被"管理"的问题，而是值得被"看见"的风景。当我们把抽象的感受变成具象的画面，理解自己就变成了一件自然而然的事。

CORE FEATURES

核心功能

✍️

情绪输入

用一句话、一段文字甚至一个 emoji 描述今天的心情，AI 自动解析情绪维度

🪐

星球生成

实时 3D 星球渲染：地表颜色、地形起伏、大气光晕全部由情绪数据驱动

🌦️

天气系统

快乐=晴天花开、愤怒=火山喷发、平静=湖泊微风、悲伤=连绵细雨

🧬

星球演化

连续记录越久，星球越丰富。历史情绪叠加塑造独一无二的地貌生态

📊

情绪图谱

时间轴回顾：查看 7 天 / 30 天情绪变化曲线，发现自己的情绪规律

💌

星球明信片

把今天的星球生成为精美明信片，一键分享给朋友或保存为壁纸

TECH STACK

技术实现

🎨 前端框架React + Three.js（3D 星球渲染）
🧠 AI 能力TRAE Work 生成代码 + GLM / DeepSeek 做情绪分析
🌈 视觉引擎Three.js 粒子系统 + Shader 自定义大气效果
💾 数据存储LocalStorage（纯前端，无需后端，零成本部署）
🚀 部署方式静态 HTML 文件 / Vercel / GitHub Pages
DEVELOPMENT PLAN

开发路线

Phase 1 · 情绪解析引擎

用 TRAE Work 搭建情绪关键词 → 多维情绪向量（快乐/悲伤/愤怒/平静/焦虑/爱意）的映射系统

Phase 2 · 3D 星球渲染

Three.js 搭建基础星球，实现情绪数据驱动的颜色、地形、大气效果

Phase 3 · 天气与生命系统

粒子系统实现雨/雪/花/火山等天气效果，添加微小生命体（飘浮的水母、行走的光点）

Phase 4 · 演化与历史

实现连续记录机制，历史情绪叠加影响星球地貌，添加情绪时间轴图谱

Phase 5 · 分享与打磨

星球明信片导出、响应式适配、动画流畅度优化、整体 UI 打磨

VALUE & IMPACT

为什么值得做？

🌱 解决真实问题

年轻人越来越关注心理健康，但传统情绪日记"写完就忘"。把情绪变成可视化的星球，让记录本身变得有期待感——你会想看看今天的星球长什么样。

🎨 技术与艺术的结合

3D 渲染 + AI 情绪分析 + 数据可视化，技术栈丰富但不堆砌，每一项都为核心体验服务。

📱 低门槛、高传播

纯前端实现，一个 HTML 文件即可体验。星球明信片天然适合社交分享，具备自传播潜力。

🔮 可扩展性

  • 多人星球碰撞（情侣/好友情绪互动）
  • 接入可穿戴设备的心率数据作为情绪输入
  • 星球音乐：根据情绪生成环境音效
  • AI 情绪教练：在星球上给出温和的建议
