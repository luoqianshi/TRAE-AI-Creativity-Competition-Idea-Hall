🚀 4 大技术创新点

1. Agentic RAG 迭代检索（2026 前沿架构）

不再一次检索定生死。系统自动评估结果充分性，不足时自适应改写查询、换角度再搜，最多 3 轮迭代。前端实时展示"思考-检索-评估-再检索"全过程。

2. 检索规划器 + 多查询并行

DeepSeek JSON mode 意图识别，闲聊跳过检索省 2s，知识问题自动改写为 1~3 条子查询并行检索。

3. 双模式回答路由

高相关度 → 直接引用（严格基于原文）；低相关度 → R1 推断（基于博主思维框架推理）。两种模式自动切换。

4. 端到端视频知识管线（市场空白）

Dify/FastGPT/RAGFlow 只接受文本，飞书/ima 不支持视频。我们是唯一原生支持视频端到端入库 + 跨视频 RAG 问答的方案。
