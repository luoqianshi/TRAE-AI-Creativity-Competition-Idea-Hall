实现一个 HTTP 接口，
就拥有一个完整产品

SlashX 把前端、鉴权、后台、计费打包成开放协议。按 slashx.request.v1 / response.v1 接入即可。

echo-bot.js · slashx.response.v1 
// SlashX 发来请求，你只需返回标准 JSON
const response = {
  schemaVersion: 'slashx.response.v1',
  runStatus: 'success',
  messages: [{
    id: request.runId,
    role: 'assistant',
    status: 'success',
    content: { text: replyText },
  }],
}
res.end(JSON.stringify(response))
