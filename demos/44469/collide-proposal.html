碰撞

多视角 AI 学习讨论室 —— 不是听 AI 讲，而是和 AI 辩

1 创意概述

碰撞是一个多角色 AI 学习讨论室。

传统的学习工具是一个 AI 讲给你听，你是听众。碰撞反了过来：你和对一个问题持有不同思考视角的多个 AI 角色，同时亮出观点、交叉对比、互相质疑。

它像一个苏格拉底式的讨论小组：有人严谨推理、有人直觉跳跃、有人专门挑刺。你不是旁观者，你是这场思辨的圆心。系统用一张可交互的知识画布把讨论过程可视化——谁说了什么、哪里矛盾、哪里共识——一目了然。讨论结束后，画布自动保存为一幅完整的"思维碰撞地图"，方便复盘。

一句话：把"一个人看书"变成"一群人辩书"。用社交压力逼你做认知努力，用可视化的画布帮你看见自己的思维盲区。
2 目标用户及痛点

核心用户：大学生、考研/考证备考者、自学编程或跨专业知识的技术人群。场景：独自学习时，需要检验自己是否"真懂了"。

📖

以为自己懂了

看书看视频都很顺，合上书大脑一片空白。缺乏外部追问来检验真实理解水平。

🔄

思维容易固化

一个人学久了，看问题的角度越来越窄。没人从不同角度挑战你的推理，容易形成认知盲区。

📊

学完没法复盘

学完一章不知道自己到底哪里会、哪里不会。缺乏结构化的自我认知记录。

4 价值与意义
🧠

学习效果提升

基于认知科学的提取练习和精细加工理论。被追问、被质疑的过程本质上是高强度的记忆提取和知识重组，远优于被动阅读。讨论中的跨章节联想自动实现交错学习效果。

🪞

看见自己的思维

画布把讨论过程空间化——哪些概念你反复卡壳、哪些推理链路你习惯性忽略。讨论结束后的复盘面板按章节聚合，让你纵向看到自己的成长轨迹和思维模式变化。

📚

有据可依的讨论

支持上传教材、笔记构建个人知识库。AI 角色在讨论中引用教材原文——"教材第三章第 2 节说…你这里的理解有偏差"。学完一章后可以对照教材发现自己的理解盲区。

🚀

降低学习启动门槛

比起"打开书硬啃"，一个有趣的问题 + 一群等你的 AI 讨论伙伴，更有动力开始。系统自动记录进展，每次打开都知道上次学到哪、接下来学什么。支持轻量模式（精力不好时也能聊两句）。

差异化创新点：
① 不是 AI 讲，是 AI 辩——市场上已有大量"AI 讲解"类学习工具，但"多角色 AI 讨论"是空白。把学习从被动接收变成主动思辨。
② 画布做外部记忆——解决了多轮 AI 讨论中"上下文越长越失真"的问题。画布上的卡片连线图是结构化记忆，不依赖 AI 内部上下文。
③ 质疑者独立隔离——质疑者角色不看不听其他 AI 的发言，只看用户的观点然后必须挑刺。这是防止群体附和的关键设计。

5 技术可行性简述

前端：React + TypeScript + Tailwind CSS。画布使用 React Flow 库（节点+连线+自动布局）。讨论流使用标准聊天 UI 组件。
后端：Node.js + Express 或 Next.js API Routes。轻量 API 层调度 LLM 调用 + 知识库检索。
AI：DeepSeek API（免费额度可用）。3 个角色通过不同 system prompt 实现人格分化。质疑者采用独立上下文隔离策略。
知识库：MVP 阶段使用关键词匹配 + LLM 上下文注入。后续可引入向量数据库（如 Milvus Lite）做语义检索。
存储：SQLite 本地存储（零部署依赖），后续可按需迁移至 PostgreSQL。
部署：初赛阶段支持本地运行。复赛可部署至云服务器或使用 Vercel/Netlify 等免费平台。
