// 01 / INTRODUCTION

创意介绍

想解决什么问题 / PROBLEM
在快节奏的现代生活中，人们面临着日益加剧的焦虑与孤独。市面上音乐类应用大多停留在"听觉享受"层面，缺乏真正的情感陪伴与心灵共鸣。繁忙工作与学习之余，用户渴望一个既能享受音乐，又能倾诉心事的温暖角落。
为什么会想到做这个 / MOTIVATION
观察到一个普遍现象：深夜里，人们戴着耳机，听着音乐，却依然感到孤独。音乐能抚慰听觉，却无法回应情感的空缺。我们希望创造一个"懂你"的伴侣——在音乐的律动中，加入温暖的 AI 对话，让每一次聆听都成为一次心灵的对话。
大概是什么产品 / PRODUCT
一款基于 Electron 桌面端应用，融合氛围感音乐播放器与 AI 情感伴侣聊天功能，为用户打造沉浸式的放松空间。赛博朋克终端美学风格，带来独特的视觉与情感体验。

目标用户

> USER PERSONA // 用户画像

  • 都市白领 — 工作压力大，需要下班独处时光放松身心
  • 学生群体 — 学业繁重，希望在学习间隙获得片刻宁静
  • 情感敏感者 — 渴望被理解，需要一个安全的倾诉对象
  • 赛博朋克爱好者 — 追求独特的视觉与交互体验

当前痛点 / PAIN POINTS
传统音乐软件功能单一，仅有听觉放松，缺乏情感互动；社交平台又过于喧嚣，难以找到纯粹的陪伴空间。用户在音乐与情感之间被迫二选一，无法兼得。
核心需求 / CORE NEEDS
一个私密、温暖、无需设防的空间——在这里，音乐是背景，陪伴是核心。用户可以一边享受音乐的律动，一边与 AI 伴侣畅聊心事，释放压力，获得情感共鸣。
