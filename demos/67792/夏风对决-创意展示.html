夏风对决

NATSUKAZE · DUEL

一款 Lo-fi 治愈系风格的 3D 网页端 FPS 竞技游戏，参考 CSGO 与瓦罗兰特的核心玩法，在浏览器中即可体验完整的爆破模式对战。

1. 创意名称 + 创意介绍

想解决什么问题：传统 FPS 游戏需要下载安装、占用大量存储空间，且对硬件配置有较高要求。很多轻量级玩家想体验竞技射击的乐趣，却被安装门槛劝退。

为什么会想到做这个：受到 Krunker.io 等 WebGL FPS 游戏启发，结合自己对 CSGO/瓦罗兰特爆破模式的理解，希望打造一款"零安装、秒开即玩"的网页端射击游戏，同时融入 Lo-fi 治愈系美学，让紧张的对枪体验也能有放松的氛围。

大概是什么产品：基于 React + Three.js 的 3D 网页游戏，无需安装，打开浏览器即可游玩，支持练习模式、生存 PvE、混乱 PvP（5v5 Bot 对战）。

2. 目标用户及痛点

  • 面向哪些用户：喜欢 FPS 但不想下载大型游戏的休闲玩家、学生群体、办公间隙想快速放松的用户，以及前端/WebGL 技术爱好者。
  • 在什么场景下使用：课间 10 分钟休息、午休时快速打一局、通勤路上用手机浏览器体验、技术分享时展示 WebGL 能力。
  • 当前痛点：传统 FPS 游戏下载慢、安装复杂、占用几十 GB 空间；网页 FPS 游戏大多手感差、玩法浅，缺乏完整的竞技体验（经济系统、回合制、爆头判定等）。

3. 价值与意义

效率提升：零安装门槛，从打开链接到进入游戏仅需 3 秒，大幅降低用户尝试成本，让更多人能轻松体验竞技射击的乐趣。

技术示范价值：完整展示了 React + Three.js 结合的最佳实践、WebGL 性能优化（零分配主循环）、程序化音频合成、spec-driven 开发流程等，可作为 WebGL 游戏开发的参考案例。

4. 核心功能亮点

  • 完整的爆破模式：参考 CSGO 的经济系统（$800 起始、击杀奖励、买枪商店）、回合制（可选 1/3/5/7/9 回合）、A/B 包点下包拆包机制。
  • 沉浸式打击感：Camera Shake（开火/爆炸/受击震动）、Weapon Sway（呼吸摇摆）、Hit Decals（弹孔贴花）、爆头音效反馈。
  • 三线式战术地图：警家/匪家/中路/A 包点/B 包点，高箱掩体形成对枪位，支持蹲下（Shift）降低暴露。
  • 军衔等级系统：30 级成长体系（新兵→大地球），根据击杀/爆头/胜负累计 EXP，解锁黄金/红色准星。
  • 多武器战术：冲锋枪/狙击枪/战术刀（左键轻击两次杀敌、右键重击一刀毙命、持刀移速 +60%）、手雷投掷。
  • 全栈架构：前端 React + Three.js + Vite，后端 Node.js + Express + SQLite，排行榜/管理员面板完整。

5. 技术栈

React 19 + TypeScript
Three.js 0.170
Vite 6
Tailwind CSS v4
Node.js + Express
SQLite (better-sqlite3)

6. 工程亮点

  • 零分配主循环：15 个模块级临时对象复用，彻底消除 WebGL GC 蓝屏问题。
  • WebGL 上下文防护：contextLost 检测 + 渲染前拦截 + 错误提示。
  • 程序化音频合成：无外部音效文件，纯 Web Audio API 分层合成枪声（瞬态冲击 + 噪声体 + 低频嗡 + 衰减尾音）。
  • Spec-driven 开发：12 个 spec 文档驱动迭代，每个功能有明确的 spec.md/tasks.md/checklist.md。
