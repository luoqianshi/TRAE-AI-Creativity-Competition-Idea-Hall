局域网资产管家

员工自助式计算机信息采集与管理系统

学习工作赛道
创意介绍

创意名称：局域网资产管家

想解决什么问题：解决企事业单位计算机资产信息收集困难、数据不准确的痛点，通过员工自助参与的方式，实现资产信息的高效采集与统一管理。

为什么会想到做这个：在实际工作中发现，很多单位的IT资产管理依赖管理员逐个收集信息，不仅效率低，还容易打扰员工工作。让员工主动参与信息上报，既能减轻管理员负担，又能确保数据的准确性和完整性。

大概是什么产品：一款员工自助式计算机信息采集系统，员工在本机运行客户端程序，填写个人信息后自动采集计算机配置数据并上传至服务端。

核心功能

👤 员工信息录入

员工填写姓名、办公室门牌号等个人信息，建立资产归属关系

💻 硬件信息采集

自动采集CPU、内存、硬盘、网卡、操作系统等详细硬件配置信息

🌐 网络配置记录

记录IP地址、MAC地址、网关、DNS等网络配置信息

☁️ 数据上传服务端

将采集的信息加密上传至服务端，实现集中管理和数据汇总

📊 数据统计报表

管理员端生成资产统计报表，支持Excel导出，方便资产盘点和审计

🔒 权限管理

支持管理员权限管理，确保资产信息的安全性和数据隐私

目标用户及使用场景
  • 核心用户：企事业单位全体员工（信息上报端）、IT管理员、行政管理人员（数据管理端）
  • 资产盘点场景：单位组织资产盘点时，员工在本机运行程序，一键完成信息上报
  • 新员工入职场景：新员工入职领取电脑后，运行程序完成资产登记
  • 设备变更场景：硬件更换或网络配置变更后，员工重新上报更新信息
  • 日常管理场景：管理员通过服务端查看全网资产信息，进行运维和规划
当前痛点

管理员负担重：传统方式需要管理员逐个部门、逐个员工收集信息，工作量大且效率低下

打扰员工工作：管理员上门收集信息会打扰员工正常工作，影响办公效率

信息不准确：人工记录容易出现错误，员工自己上报能确保信息的准确性

信息更新滞后：硬件更换后信息无法及时更新，导致资产台账与实际不符

价值与意义

⚡ 效率提升

员工自助上报替代管理员上门收集，大幅减轻IT部门工作负担，提升资产信息收集效率

💰 商业价值

帮助企业实现精细化资产管理，避免资产流失和重复采购，降低运营成本

技术方案

技术栈

  • Python
  • PyQt5
  • SQLite
  • WMI
  • HTTP API

系统采用客户端-服务端架构，客户端运行在员工计算机上，通过WMI协议采集本地硬件信息，员工填写姓名和办公室门牌号后，通过HTTP API将数据加密上传至服务端数据库存储。管理员通过管理界面查看和导出资产数据。
