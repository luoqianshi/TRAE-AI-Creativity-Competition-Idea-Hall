## 决策格式

每个决策条目应包含以下信息：

- **日期**: 决策日期
- **决策者**: 做出决策的人
- **状态**: 提议 / 已接受 / 已弃用 / 已替代
- **背景**: 为什么需要做这个决策
- **方案对比**: 考虑过的其他方案
- **决策**: 最终选择的方案
- **理由**: 选择此方案的原因
- **影响**: 此决策对项目的影响
- **关联事件**: 相关的事件 ID
