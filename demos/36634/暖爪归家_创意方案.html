02

暖爪归家 —— 微信小程序 · 公益服务平台

供给侧连接救助站/救助者/志愿者，需求侧服务潜在领养人。围绕信息透明、匹配精准、流程标准、长期陪伴四大关键词设计。

让每一次救助，都有一条可信任的路径。

我们将小程序的轻量触达能力，与公益场景的信任需求结合，打造「发布 → 浏览 → 申请 → 审核 → 回访」的完整闭环。基于位置、基于标签、基于信用分，让信息与信任一起流动。

信息透明

标准化档案：来源、健康、性格、位置信息一目了然。

匹配精准

结构化条件 + 权重推荐，减少凭经验的错配。

流程标准

问卷 · 视频沟通 · 电子协议自动归档，流程可追溯。

长期陪伴

7/30/90/365 天回访提醒，累计信用分，形成长期责任链。

03

为谁而做 —— 三类核心用户

救助者与志愿者是供给侧核心，潜在领养人是产品最终转化方，关注者组成早期传播与社区生态。

USER A · 供给侧

救助站 / 救助者

长期承担经济与照护压力

工具使用能力中等偏下，需要一键发布、批量管理、自动回访与可视化数据看板。节省时间就是拯救更多生命。

一键发布协议归档自动回访数据面板
USER B · 需求侧

潜在领养人

都市青年 / 小家庭 / 退休老人

有爱心但信息不对称、养宠经验不足，期待按条件筛选、档案清晰、喂养建议与长期陪伴社区。安心领养，不再孤军作战。

条件筛选透明档案喂养建议陪伴社区
USER C · 传播侧

关注者 / 志愿者

学生 / 上班族 · 关注公益但暂无条件

愿意参与传播与公益活动，产品提供便捷分享、活动通知与信用分成长体系，未来想领养时可优先匹配。

一键分享活动订阅信用分社区互动
04

关键场景 —— 五步走完一次领养

从刷到心动、到遇到流浪、到提交申请、到长期回访、到后台管理，五个场景串起一条完整的责任链。

01
刷到心动

朋友圈分享卡片 → 进入小程序 → 浏览附近待领养信息 → 收藏心动 → 提交申请

02
遇到流浪

下班路遇小生命 → 拍照上传基本信息 → 位置自动标记 → 救助站审核补充详细 → 纳入正式领养列表

03
申请与审核

填写结构化问卷 → 条件匹配 → 视频沟通 → 签署电子协议 → 可存档下载

04
长期回访

7/30/90/365 天自动提醒 → 上传近况照片与文字 → 累计领养信用分

05
后台管理

救助站登录后台 → 批量发布/编辑 → 审核申请 → 生成协议 → 可视化数据报表

05

我们期待 —— 让每一次善意都能落地

第一年关键指标：信息供给侧、领养转化侧与责任闭环侧三方可衡量，用以验证产品假设并驱动下一轮迭代。

我们相信，每一次善意都值得被记录。

围绕「发布 → 匹配 → 审核 → 回访」闭环，关注信息量、审核率与回访完成度三个核心指标。
