About the Project

重新定义 JLPT 备考体验

YukiTest 是一个面向日语学习者的在线真题练习平台，覆盖 JLPT N1 到 N5 全部等级。 系统采用前后端分离架构，集成 DeepSeek AI 流式解析，帮助考生高效备考。

从试卷导入到模拟考试，从智能评分到错题复盘， YukiTest 打造了完整的日语能力测评闭环。独特的「和紙文具風」UI 设计，让备考也能成为一种美学体验。

Core Features

六大核心功能

每一项功能都围绕"真实考试体验"精心设计

核心
📝

真题练习

按 JLPT 等级（N1-N5）分类，涵盖文字·词汇、语法、阅读、听力四大板块，完整还原真实考试结构。

核心
⏱

官方计时

按照 JLPT 官方考试时长自动倒计时，支持暂停/继续。最后 10 分钟红色闪烁预警，超时自动交卷。

核心
📊

即时评分

交卷后瞬间出分，按四大板块分别展示正确率，可视化进度条。点击任意题号跳转 AI 深度解析。

体验
📕

智能错题本

自动收集错题并按试卷/板块分组，支持筛选"未掌握/已掌握"状态，记录错误次数，一键回到原题复习。

AI
🤖

AI 流式解析

集成 DeepSeek V4 大模型，SSE 流式输出逐字呈现。对每道题目进行多角度深度分析：语法解释、词汇辨析、解题技巧。

体验
💾

进度保存

考试中途自动保存答题进度到后端草稿，下次打开智能恢复。支持本地 + 云端双重保障，不怕意外中断。

Creative Highlights

创意亮点

技术与设计的巧妙融合

🎨 和紙文具風 UI 设计

独创「Washi Stationery Aesthetic」设计语言，采用日式传统配色（朱色 × 藍色），和纸纹理背景叠加，Noto Serif JP 书法字体标题。每个 JLPT 等级都有专属色彩标识，从视觉到交互传递日式美学。

🧠 SSE 流式 AI 深度解析

基于 DeepSeek V4 的 SSE 流式传输，实现"逐字输出"的 AI 解析体验。支持 OpenAI 兼容 API 格式，用户可自定义 API Key 和服务地址。Markdown 实时渲染让解析内容结构清晰、易于阅读。

⌨️ 沉浸式考试交互

键盘快捷键支持（方向键切题、数字键选答案），阅读/听力双栏分屏布局，答题进度可视化导航，最后 10 分钟计时器闪烁预警。全方位还原真实考场体验，帮助考生培养考试节奏感。

🔒 安全与工程化实践

JWT 无状态认证 + AES 密码加密双重保障；MyBatis-Plus 自动化分页与时间戳；全局异常处理统一响应格式；H2 内存数据库支持零配置开发环境；完善的单元测试覆盖核心业务逻辑。
