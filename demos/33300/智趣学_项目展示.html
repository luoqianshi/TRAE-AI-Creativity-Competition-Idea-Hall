Problem

想解决什么问题

儿童编程学习普遍存在"学得快、忘得快、不会用"的困境。传统视频教程缺乏互动性，游戏化产品又过于娱乐化缺乏系统性。

📺

被动学习效率低

视频教程只能看不能练，孩子被动接收信息，无法主动思考和实践，知识留存率不足 30%。

🎮

游戏 vs 系统性

纯游戏化学编程产品趣味性强但缺乏知识系统性，没有清晰的学习路径和进度评估。

👨‍👩‍👧

家长难以参与

家长想了解孩子学了什么、掌握程度如何，但现有产品缺乏学习数据反馈和家长端界面。

Solution

为什么会想到做这个

作为开发者，深感编程思维对儿童教育的价值。市面上缺乏将系统性知识与趣味性体验完美结合的产品。借助 AI 和互动视频技术，让每个孩子拥有"一对一私人编程教练"。

目标用户

主要面向 8-14 岁儿童及其家长，次要用户是编程教育机构和兴趣班。

1

课后自学

完成作业后，通过互动视频自主学习编程基础

2

周末亲子

家长与孩子一起观看互动教程，完成亲子练习

3

课外辅助

配合编程兴趣班，课后复习和拓展练习

Value

价值与意义

📚

教育价值

将循环、条件、类与对象等抽象概念转化为"魔法学院"情境的沉浸式体验，提升学习留存率 3 倍以上。

⚡

技术价值

验证 hyperframes + GSAP + Web Audio 技术组合可行性，形成可复用的互动教程制作流水线。

🚀

效率提升

AI 配音 + 自动化构建，将互动教程制作周期从数周缩短至数天，大幅降低内容生产成本。

Product

产品形态

基于 Web 的儿童编程互动学习平台，支持浏览器直接访问，无需安装任何软件。

🎬 互动视频教程

  • AI 配音 + GSAP 动画同步
  • 手动/自动双模式切换
  • 键盘/鼠标多种交互方式
  • 章节进度条 + 学习数据追踪

🎮 游戏化练习

  • 10 款益智游戏（围棋、2048、扫雷等）
  • 统一战绩统计页面
  • 学习成果即时反馈

📝 博客笔记

  • Markdown/HTML 双格式支持
  • 分类标签管理
  • 书签与搜索功能

💰 亲子记账

  • 可视化财务管理
  • 多维度统计图表
  • 培养理财意识
