===============================================
《诗境漫游》参赛作品
===============================================

【作品名称】诗境漫游——AI大模型驱动的古诗词沉浸式解谜游戏

【作品简介】
《诗境漫游》是一款基于智谱GLM-4-Flash大语言模型的古诗词沉浸式文字解谜Web游戏。
玩家穿越至诗词幻境，与李白、杜甫、苏轼等十位大诗人AI自由对话，通过对诗、解谜
触发通关。项目融合Web Speech API语音朗读技术，为每位诗人配置独特声线；采用
数据驱动架构，覆盖100首经典诗词场景。以"AI+传统文化"创新模式，让古诗词学习
从背诵变为"与古人对话"的沉浸体验。

【运行方式】
1. 直接双击打开 index.html 即可在浏览器中运行
2. 或部署到任意Web服务器（Nginx/Apache等）
3. 推荐使用Chrome/Edge浏览器以获得最佳语音朗读体验

【技术栈】
- React 18 + TypeScript + Vite
- Tailwind CSS + Zustand
- 智谱GLM-4-Flash大模型API
- Web Speech API语音合成

【核心特色】
- 10位大诗人 x 10首经典 = 100个沉浸式场景
- AI驱动的自由对话，非固定选项
- 每位诗人独特声线（pitch/rate差异化）
- 国风水墨UI设计
- 纯前端实现，无需后端服务器

【项目结构】
index.html          入口页面
favicon.svg         网站图标
assets/             静态资源
  index-*.js        主程序代码
  index-*.css       样式文件
