经典游戏机收藏

🎮

FC 红白机

1983年发售的经典游戏机，开启了无数人的游戏生涯。Super Mario、Battle City等经典作品至今仍让人回味无穷。

🕹️

街机

1980年代的街机黄金时代，Pac-Man、Space Invaders、Street Fighter等经典街机游戏定义了电子游戏的最初形态。

📺

Game Boy

1989年问世的掌机先驱，Tetris、精灵宝可梦等游戏陪伴了一代人的童年，让游戏真正随行。

🎯

SFC 超任

1990年发售的超级家用机，16位画质带来更细腻的游戏体验，Final Fantasy、萨尔达传说等大作云集。

👾
1978

太空侵略者

街机射击游戏的鼻祖，像素外星人的经典形象影响了整整一代游戏设计。

🍄
1985

超级马里奥兄弟

FC平台的护航大作，定义了平台跳跃游戏的标准，影响力延续至今。

🧩
1989

俄罗斯方块

Game Boy上的经典益智游戏，简单易上手的特性让它成为史上销量最高的游戏之一。

⚔️
1991

街头霸王II

格斗游戏的里程碑，独特的招式系统和角色设定，至今仍在全球拥有大量粉丝。

🐉
1996

精灵宝可梦

Game Boy上的RPG大作，收集与对战的理念开创了全新的游戏类型，成为全球现象级IP。
