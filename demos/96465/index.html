核心功能

🤖
AI Agent 智能解题
基于大语言模型的智能解题助手，自动分析题目类型，加载相关技能，提供逐步推理和解答。支持多种难度级别：基础、常规、进阶、竞赛、奥赛级。
🔧
多工具链集成
集成 CAS 符号计算、Python/Julia 代码执行、Lean 4 形式化验证、语义搜索等工具，形成"分析→计算→验证"的完整闭环。
📊
五闸门验证引擎
通过逻辑一致性检查、数值验证、特殊化检验、边界测试、反例搜索五层验证机制，确保解题过程的正确性。
🎯
技能注入系统
自动识别题型并加载对应的解题技能（Skill），包括不等式技巧、数列方法、组合恒等式等，提升解题质量和效率。
🖼️
多模态支持
支持上传图片和文件进行分析，图片自动进行 OCR 识别，提取数学公式和文字内容，便于处理纸质题目或截图。
💻
终端用户界面
基于 Ink 框架的 TUI 界面，支持鼠标滚轮滚动、文件上传按钮、快捷键操作，提供流畅的终端交互体验。

证明不等式：a² + b² + c² ≥ ab + bc + ca
● openmath
这是一个经典的不等式问题，可以使用基本不等式或配方法来证明。
📐 题型=不等式 · 注入 3 个 Skill
🔧 CAS: simplify(a² + b² + c² - ab - bc - ca)
**证明过程：**
考虑将不等式两边同时乘以 2：
2(a² + b² + c²) ≥ 2(ab + bc + ca)
移项得：
2a² + 2b² + 2c² - 2ab - 2bc - 2ca ≥ 0
可以重新排列为完全平方形式：
(a-b)² + (b-c)² + (c-a)² ≥ 0
✓ 验证通过：对于任意实数 a,b,c，平方和恒非负
