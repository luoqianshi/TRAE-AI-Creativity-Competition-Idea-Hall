Philosophy

设计哲学

甜遇不是一个「更快更强」的产品，它应该是一个「更温柔」的产品。

甜遇的角色们记得用户的一切，
但甜遇自己什么都不记。
🛡️

隐私不妥协

聊天记录、角色记忆、API Key 全部本地存储。客户端直连用户自填 API，不经任何服务器中转。

🧠

记忆即灵魂

每个角色拥有独立记忆库。自动提取事实、偏好、事件，在对话中自然调用，让 AI 真正「记得你」。

✨

体验不将就

从 6 步引导到悬浮桌宠，从丝滑动效到骨架屏加载，每一帧交互都打磨到自然舒适。

Features

核心功能

从角色创建到深度陪伴，每一个功能都围绕「记得」这个核心命题展开。

🧑‍❤️‍💋
多角色引擎

多角色心动人设库

创建任意数量的独立 AI 角色，每个角色拥有独特的人设、性格、场景和记忆。

名称唯一校验 + 20 个预设二次元头像
人设导入/导出，JSON 格式跨设备共享
批量多选操作 + 实时搜索排序
🧠
核心引擎

独立记忆系统

每次对话后异步提取三类记忆：事实、偏好、事件，写入角色独有数据库。

FACT / PREF / EVENT 三类记忆提取
上下文组装引擎，自动拼接记忆到 prompt
Token 超限时按优先级丢弃最老记忆
🐾
桌宠

悬浮桌宠随身陪伴

Android 悬浮窗，迷你浮球可拖动吸附。展开即见迷你对话框。

浮球态 / 展开态双模式切换
无障碍读屏服务，屏幕内容直接带入对话
前台服务保活 + 边缘自动吸附
💬
聊天

沉浸聊天体验

流式 SSE 渲染逐字输出，完整消息状态机，输入态指示器，键盘完美适配。

消息三态 + 15s 超时提示「走神了」
截图分享：隐私提示 + 角色名隐藏 + 水印
下拉加载历史 + 置顶/删除会话
🔍
社区

发现社区

用户分享与 AI 角色的暖心日常。敏感词过滤 + 图片审核。

信息流 + 九宫格图片 + 点赞互动
内容合规校验（敏感词 + 图片审核）
发布弹窗：可见范围 + 表情 + 图片
🔐
红线

隐私安全体系

不上传聊天记录、角色记忆、API Key、手机号/通讯录/位置。

客户端直连，不经过甜遇任何服务器
本地数据库：每个角色独立 Room 实例
读屏数据仅暂存内存，不记录不上传
Architecture

技术架构

Kotlin + Jetpack Compose + Room，重度依赖 Android 系统级能力，隐私不妥协。

UI
  • Jetpack Compose
  • ViewModel + StateFlow
  • Material3 主题系统
  • Coil 图片加载
Data
  • Room 数据库
  • MMKV 高频KV
  • EncryptedSharedPrefs
  • 独立角色 DB 文件
Network
  • OkHttp + Retrofit
  • SSE 流式请求
  • 直连用户自有 API
  • 不经过中转服务器
Service
  • 悬浮窗 WindowManager
  • 无障碍 Accessibility
  • 前台服务保活
  • 记忆提取引擎
Tech Stack
  • Kotlin (语言)
  • Jetpack Compose (UI)
  • Room (本地数据库)
  • MMKV (KV 存储)
  • Coil (图片加载)
  • OkHttp + Retrofit (网络)
Storage
  • 全局设置 → MMKV
  • API 密钥 → EncryptedSP
  • 角色配置 → Room (全局 DB)
  • 独立记忆 → Room (独立 DB)
  • 聊天记录 → Room (独立 DB)
Privacy Rules
  • 不上传聊天记录
  • 不上传角色记忆
  • 不上传 API Key
  • 不上传手机号/位置
  • 读屏数据不落盘

Privacy First

隐私至上

甜遇的全部技术承诺只有一句话。

🔒

不上传

聊天记录、角色记忆、API Key、手机号、通讯录、位置——全部不上传。

🔄

直连

客户端直接连接用户自填的 API 地址，请求不经过甜遇任何服务器中转。

💾

本地加密

API Key 使用 Android Keystore + EncryptedSharedPreferences 加密存储。

🏠

独立隔离

每个角色拥有独立 Room 数据库，角色间数据物理隔离，互不干扰。

🔍

透明可控

Token 消耗统计展示给用户，所有存储内容用户可随时查看和清除。

🛡️

读屏安全

无障碍服务读取的屏幕数据仅暂存内存，不记录不存储不上传。
