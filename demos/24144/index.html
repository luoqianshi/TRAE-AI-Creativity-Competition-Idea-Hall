安装与使用指南

1

克隆项目

从 GitHub 克隆项目到本地

git clone https://github.com/geek2author/PinForge.git
2

安装依赖

进入项目目录并安装依赖

cd PinForge
npm install
3

启动开发服务器

运行开发命令启动本地服务器

npm run dev
4

构建部署

构建生产版本并部署

npm run deploy

常见问题解答

在项目根目录创建新的芯片配置文件（JSON 格式），参考现有的 pin_config.1.0.json 格式，包含引脚编号、功能列表、复用信息等。然后在 sysconfig.jsx 中导入并注册新的芯片配置即可。

引脚冲突通常发生在同一引脚被配置为多个功能时。例如，一个 GPIO 引脚同时被配置为 UART TX 和 SPI MOSI。系统会自动检测这种冲突并给出警告提示。

目前支持导出 C/C++ 代码格式，适用于 ESP-IDF 和 STM32 HAL 等主流开发框架。后续版本将支持更多编程语言和框架。

点击导出按钮可以将当前配置保存为 JSON 文件，分享给团队成员。导入时只需上传 JSON 文件即可恢复配置。
