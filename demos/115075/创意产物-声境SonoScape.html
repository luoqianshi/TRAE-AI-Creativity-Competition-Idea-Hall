01 · 创意名称 + 介绍

想解决什么问题

音乐直播、线上演出、短视频配乐越来越多，但大多数视觉呈现还停留在静态封面或简单频谱条。创作者和观众都希望声音能被“看见”，却缺少低门槛、高颜值的实时声音可视化工具。

为什么会想到做这个

团队成员喜欢在听音乐、看 live 时观察节奏与画面之间的联系。我们发现，现有的可视化工具要么太专业（需要 DAW、着色器编程），要么效果千篇一律，普通人很难做出属于自己的视觉风格。

产品形态

声境 SonoScape 是一款基于 Web Audio API 的浏览器端声音可视化应用。用户可通过麦克风、本地音频文件或内置测试音，实时生成波形、频谱和动态粒子视觉，并一键保存为视频或 GIF 用于直播、短视频和演出背景。

02 · 目标用户及痛点

面向哪些用户

  • 音乐主播 / 线上 DJ / 虚拟演出创作者
  • 短视频配乐 UP 主，需要视觉化背景
  • 音乐教育者和学生，用于理解节奏、频率、音色
  • 普通音乐爱好者，想“看见”自己喜欢的歌

使用场景

  • 直播时把麦克风声音变成实时背景动画；
  • 上传一段音乐，导出 15 秒可视化视频发朋友圈；
  • 课堂上播放不同乐器音频，直观展示频谱差异。

当前痛点

  • 专业音频可视化软件学习成本高，且多为桌面端；
  • 常见播放器频谱单调，无法自定义色彩和粒子效果；
  • 视频创作者需要反复在多个工具间切换，流程繁琐。

04 · 价值与意义

娱乐价值

让听音乐从“听觉体验”升级为“视听联觉体验”，用户可以在直播间、派对、个人视频中展示独一无二的动态视觉。

效率价值

原本需要 AE + 音频插件 + 渲染工具才能完成的可视化视频，现在打开浏览器即可实时生成，制作周期从小时级缩短到分钟级。

社会价值

为听障群体提供一种“看音乐”的可能性；为音乐教育提供低成本、可互动的频谱与波形演示工具。
