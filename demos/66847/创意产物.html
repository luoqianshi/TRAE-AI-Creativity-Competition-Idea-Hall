题管家

个人题库数字化 + 智能刷题一体化平台

把你的纸质 / 文档题库，变成可练习、可统计、可追踪的学习资产

产品形态：Web 应用 多端：PC + H5 技术栈：Vue3 + Python 核心能力：OCR · 文档解析 · 智能练习
PROBLEM

我们想解决的痛点

备考与学习过程中，资料整理与练习反馈的三个真实困境

📑

资料碎片化

题库散落在论坛、网盘、社交、付费平台等多渠道，格式各异（Excel / PDF / Word / 图片），整理转换耗费大量时间，难以统一管理。

📄

静态资料无反馈

PDF 与纸质资料只能「看题—对答案—理解」，无法即时反馈对错、无法记录进度、无法生成错题本，学习链路长且低效。

💸

付费循环与盲区

付费题库常陷入「购买后发现不适用 → 再寻找 → 再购买」的循环；且无法统计知识点正确率，难以识别薄弱点，学习没有方向感。

VALUE

核心价值主张

把零散资料转化为可练习、可统计、可追踪的学习资产

🔄

资料结构化

格式各异的题库文档统一转为标准化 JSON，解决信息碎片化与格式割裂

⚡

即时反馈

从静态阅读到动态答题 + 实时评分，缩短「看题—对答案—理解」链路

📊

数据驱动

通过作答记录、错题本、知识点正确率识别薄弱点，智能推荐针对性提升

📱

多端无缝

PC 与移动端共享同一套后端数据，学习进度跨设备接续

FEATURES

三大核心功能模块

从文档导入到智能练习的完整闭环

🔍

智能文档识别与转换

多格式自动识别 · OCR · 结构化解析
  • 支持 Excel / PDF（文字型 + 扫描件）/ Word / 图片 / JSON / Markdown 六大格式
  • 系统自动识别格式并选择对应解析器，扫描件与图片调用 PaddleOCR 提取文字
  • 保留题目编号、选项、答案、解析等结构语义，输出统一 JSON 数据
  • 左图右文校对工作台，低置信度自动高亮，机器智能 + 人工校对接近 100% 准确率
PaddleOCR 版面分析 置信度评估 人工校对
✍️

在线刷题与模拟考试

四种模式 · 即时反馈 · 自动评分
  • 顺序练习 / 随机抽题 / 专项练习 / 模拟考试四种模式
  • 模拟考试支持倒计时、答题卡、题目与选项随机，还原真实考场
  • 提交后即时反馈对错、正确答案与解析，客观题自动评分
  • 主观题支持自评或接入 AI 评分（v2 规划）
  • 断点续答：切设备或断网后从中断处继续，作答数据不丢失
答题卡 倒计时 断点续答 跨端同步
📈

错题本与薄弱知识点分析

数据驱动 · 智能推荐 · 个性化提升
  • 答错题目自动进入错题本，支持分类筛选、标记与重做
  • 按知识点统计正确率，识别薄弱知识点与高频错题
  • 智能推荐相关题目针对性提升，告别盲目刷题
  • 成绩走势可视化（雷达图 / 折线图），学习进步一目了然
知识点正确率 薄弱点分析 智能推荐 成绩走势 ECharts 可视化
