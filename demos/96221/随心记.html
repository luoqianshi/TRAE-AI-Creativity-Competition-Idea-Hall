01 · INDUSTRY PAIN

信息过载时代的记录困境

⏱️

记录阻力大

传统笔记软件层级深、启动慢，等建好文档灵感早没了。记录过程中的摩擦力导致灵感流失。

心流被打断
🧱

信息孤岛

复制粘贴的内容丢失了来源上下文（哪个网页、哪个软件发出的），事后溯源极其困难。

来源丢失
📚

收藏即埋葬

记录下来的碎片信息缺乏状态流转机制，越积越多，最终变成再也不看的“数字垃圾”。

信息积压焦虑
🔍

整理耗时耗力

手动归类、打标签、提炼摘要需要花费大量时间，违背了“速记”的初衷。

手动整理成本高
02 · SOLUTION

极速捕获到智能沉淀的闭环架构

① 极速捕获层

桌面悬浮球 / 全局快捷键 / 安卓分享菜单 / 剪贴板监控 / 截屏监控

目标：将记录摩擦力降至零
▼

② 仓库暂存层 (GTD 收件箱)

所有新记录默认进入“未处理”状态 · 自动附带来源上下文（App名/URL/窗口标题）

目标：清空大脑，暂存一切
▼

③ AI 辅助处理层

AI 自动提取标签 / 错别字修正 / 选中内容润色 / 多记录聚合问答归纳

目标：秒级完成人工数十分钟的整理
▼

④ 沉淀与导出层

标记“已处理” · 自定义项目分类 · 导出 Markdown/JSON · 本地 SQLCipher 加密 / 云端同步

目标：构建个人知识资产
03 · CORE FUNCTIONS

为效率而生的核心功能

⚡

无感极速捕获

桌面端全局悬浮球 + 快捷键唤出极速面板；安卓端系统分享直送。支持剪切板与截屏自动监控。

Alt+Space
🧠

上下文感知

自动记录捕获时的来源信息（进程名/URL/App包名），生成隐形标签，无需手动溯源。

自动溯源
📥

GTD 收件箱模式

明确的“未处理”/“已处理”状态流转。先记录，后整理，告别信息积压焦虑。

状态流转
🤖

AI 智能助手

开启后台自动整理；或手动选中内容润色扩写；支持勾选多条记录让 AI 综合归纳总结。

多记录问答
📂

灵活组织管理

按日期时间线自动聚合，支持自定义项目分类文件夹，基于 SQLite FTS5 毫秒级全文检索。

全文搜索
📤

数据自由导出

支持单条、多条或全量导出为 Markdown、纯文本或 JSON 格式，数据完全掌握在自己手中。

无锁定
04 · TECH STRATEGY

双轨架构与极致性能

🛡️

离线版：本地优先

桌面端基于 Tauri + Rust，体积小、内存低。数据存储在本地 SQLCipher 加密数据库。支持 WebDAV 自主同步。

一次性买断
☁️

在线版：云端无缝

基于 Supabase 构建云端实时双向同步，提供开箱即用的 AI 算力支持。安卓端基于 Flutter 打造丝滑体验。

SaaS 订阅
05 · ROADMAP

产品演进路线

🚀

Phase 1 · MVP 核心闭环

桌面端悬浮球/快捷键速记、安卓端分享接收。上下文来源自动捕获。本地 SQLite 存储，剪切板与截屏监控。未处理/已处理状态切换。数据导出。

✨

Phase 2 · 体验深化

自定义项目分类功能。接入 AI 接口，实现手动润色和选中问答。WebDAV 同步配置跑通。安卓端桌面小组件。

🌐

Phase 3 · 商业化与云端

AI 自动整理开关功能。多记录聚合问答 UI 及逻辑。接入 Supabase，开发在线版账号体系与云同步。上线订阅制。

🧠

Phase 4 · 知识图谱 (远期)

跨笔记关联与可视化图谱。基于笔记库的 RAG 深度问答。构建真正的“第二大脑”。
