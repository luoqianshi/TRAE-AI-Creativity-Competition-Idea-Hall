How It Works

预警全流程

从地震发生到预警送达，全程不超过 5 秒。

T+0.0s 地震发生
震源破裂，P 波开始向外传播
地震波从震源向四周扩散。P 波速度约 6 km/s，S 波约 3.5 km/s——这个速度差就是预警的时间窗口。
T+1.5s 传感器触发
最近 3 个传感器检测到 P 波
MEMS 加速度计检测到超过阈值的振动信号，触发数据上报。至少 3 个节点触发后，系统启动分析流程。
T+3.0s AI 分析完成
震级估算 + 震中定位 + 影响预测
AI 算法基于 P 波前 2 秒的特征（振幅、频率、波形），预测完整震级和影响范围。生成目标区域的 S 波到达时间和预估烈度。
T+3.5s 预警推送
用户收到预警，S 波尚未到达
App 推送 + 社区广播 + 学校联动警报同步发出。用户看到倒计时："X 秒后地震波到达，请立即避险"。

Core Features

核心技术能力

从传感采集到 AI 分析到联动推送，QuakeAlert 构建了端到端的地震预警能力。

01 // DENSE SENSOR

高密度 IoT 传感网络

低成本 MEMS 加速度计（单价 <¥200），平均 15-30km 间距密集部署。县乡级覆盖成本仅为传统地震仪的 1/500。

02 // AI P-WAVE ANALYSIS

AI P 波特征分析

深度学习模型从 P 波前 2 秒数据中预测完整震级，准确率达 92%。相比传统阈值触发法，误报率降低 60%。

03 // EDGE COMPUTING

边缘计算快速响应

传感器节点内置边缘计算芯片，本地完成 P 波检测和初步分析，上报延迟 <0.5 秒。无需等待云端响应，争分夺秒。

04 // MULTI-CHANNEL ALERT

多通道预警推送

App 推送 + 短信 + 社区广播 + 学校警报 + 电梯联动，多通道同步发出。确保不同场景下的用户都能及时收到预警。

05 // AUTO LINKAGE

自动化联动接口

标准 API 对接学校广播、PLC 控制器、电梯系统、燃气阀门。预警到达后自动执行预设保护动作，无需人工干预。

06 // BLOCKCHAIN LOG

预警记录上链存证

每条预警记录（时间/震级/推送状态）上链存证，不可篡改。为震后评估和保险理赔提供可信数据支撑。
