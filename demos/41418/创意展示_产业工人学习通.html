💡 产品简介

产业工人学习通是一款专为一线产业工人打造的 Android 学习辅助应用，集题库管理、多模式练习、智能搜题、TTS语音朗读于一体，支持完全离线使用。

🎯 核心用户

养护工、桥梁工、隧道工、施工员、安全员等需要安全生产知识学习和职业技能考核的产业工人。

⚡ 核心功能

  • 多模式练习：随机练习 / 专项练习 / 模拟考试 / 错题强化
  • 断点续做：退出自动保存进度，重新进入无缝恢复
  • 多引擎TTS语音朗读：适配8种语音引擎，支持离线朗读
  • 自研离线OCR搜题：基于像素分析，完全离线运行
  • 三重数据安全：SQLCipher加密 + AES加密 + 时间防篡改

🏗️ 技术栈

Kotlin + Jetpack Compose + MVVM + Room + SQLCipher + Apache POI + eSpeak-NG + 讯飞AIKit

📋 开发历程

v1.0：基础架构搭建（MVVM + Room）
v1.2.5：TTS语音朗读、拍照搜题、学习统计
v2.0.0：迁移Jetpack Compose，加密数据库
v2.3.0：断点续做、进度持久化、评分优化（2026-06-18）
v2.3.1：统一AnswerJudge答案判定（2026-06-18）
