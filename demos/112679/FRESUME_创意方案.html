SEC · 04

核心
能力

Feature · matrix · 6 cells
01// DECOMPOSE
🧠
两阶段 LLM 拆解

Section Decomposer 先按 8 类语义切片，Point Extractor 再逐句提炼亮点、技能与指标。

02// RENDER
📄
PDF 多页可视化

pdf.js 把每一页 raster 成 2x 缩略图，并提供页码切换条与悬浮粒子动画。

03// SECURITY
🔒
JWT + 配额限流

FastAPI + Redis 做 token 鉴权与每用户配额，LLM 成本始终可控。

04// STORAGE
☁️
阿里云 OSS 直传

前端拿到 STS 临时凭证后 PUT 文件到 OSS，不走服务器带宽，省钱且快。

05// COCKPIT UI
🎨
驾驶舱 UI

Vue 3 + Pinia 打造的“驾驶舱”，配色荧光绿 #00FFCC，赛博感十足。

06// PLUGGABLE
🔌
多 LLM 可切换

默认 DeepSeek，按 .env 一键切到 OpenAI / 通义千问，本地支持 MOCK。
