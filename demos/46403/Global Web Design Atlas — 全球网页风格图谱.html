创意名称 + 创意介绍

创意名称

Global Web Design Atlas（全球网页风格图谱）

想解决什么问题

现有设计灵感站（如 Awwwards、SiteInspire）只能提供网站截图，设计师和开发者在学习优秀网站时，无法深入理解设计决策背后的逻辑，更无法看到同一个品牌的设计语言如何随时代演化。

为什么会想到做这个

在帮客户做网站 redesign 时，我发现自己花了大量时间手动拆解参考网站的排版、色彩和组件逻辑。市面上没有一款工具能同时做到"拆解设计 DNA + 记录风格演化 + 提供可复现代码"。

大概是什么产品

一个基于 Web 的 AI 驱动网站设计研究、学习与复现平台，用弧形拨动卡片选择网站，以仪表盘形式拆解设计，用时间线记录风格演化。

价值与意义

⚡

效率提升价值

将"看设计"升级为"拆设计 + 学设计 + 复现设计"。

2h → 2min

原本需要 2 小时手动拆解一个网站，现在 2 分钟获得完整的设计 DNA 报告、历史演化对比和可运行代码 Demo。

🌍

社会价值

降低设计学习门槛。让非设计师（如独立开发者、AI 编程用户）也能理解优秀设计的底层逻辑，推动设计知识的民主化。

设计民主化

打破专业壁垒，让每个人都能学会"为什么好看"和"怎么做到好看"。
