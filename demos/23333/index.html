PART 01

创意名称与介绍

想解决什么问题

在信息科技学科教学中，教师普遍面临「出题难、批改累、学情看不见、学生兴趣低」四大难题。一堂课下来，老师要花费数倍于课堂的时间准备试题、手工批改并整理成绩；学生面对枯燥的纸质练习，学习热情难以持续。平台希望通过一套在线工具，让试题设计 → 学生答题 → 自动批改 → 学习分析的全流程数字化、智能化。

为什么会想到做这个

本创意来源于一线信息科技教师的真实反馈与长期观察。作为通用技术与信息技术融合的新兴学科，信息科技课程资源相对匮乏，商用系统又价格昂贵、操作复杂。我们希望打造一款"老师用起来简单，学生学起来有趣"的轻量平台，既能满足日常教学刚需，又具备趣味化激励（如智能学伴）让课堂活起来。

大概是什么产品

一个基于 Web 的 信息科技学习平台（B/S 架构，支持 PC 浏览器访问，亦可在平板上使用）。核心包含教师端（试题设计、发布检测、自动批改、学情分析、学生管理、智能学伴管理）与学生端（在线答题、积分激励、虚拟学伴养成、作品长廊）。技术上使用 FastAPI + SQLite 后端，Vue 3 + Tailwind CSS 前端，无需安装大型客户端即可使用。

PART 02

目标用户及痛点

教师（信息科技学科）

授课对象：小学 3-6 年级 / 初中 7-9 年级

出卷耗时：一套综合试题需要手工整理 Word、排版、打印，平均 2+ 小时。

批改低效：多个班级 200+ 份答卷手工批改 + 登分，经常挤占备课时间。

学情盲区：缺少直观数据可视化，难以精确知道"哪个知识点、哪个学生"薄弱。

资源匮乏：信息科技题库与共享资源少，跨班级协作难度高。

学生（在校学习用户）

使用场景：课堂练习 / 课后检测 / 自主学习

反馈延迟：提交答卷后通常需 1-2 天才能知道对错，学习热度过期。

激励不足：缺乏持续性、可积累的成就系统，练习如同"任务"而非"挑战"。

协作薄弱：小组学习缺少量化贡献度，组长制效果不明显。

学习无感：学过即忘，缺少"作品长廊"等自我回顾与展示渠道。

PART 03

核心功能 · 六大模块

① 智能试题设计

支持单选 / 多选 / 判断 / 单填 / 多填 / 简答 6 种题型；支持图片上传、Word 导入导出、拖拽排序、随机打乱选项等高级能力。

教师 5 分钟即可组装一份规范化试卷

② 在线学习检测

学生在浏览器中完成答题，支持时间限制、防作弊（切屏检测）、允许多次重考、考试结束后自动展示答案解析与得分。

支持跨班级批量发布 + 成绩自动同步

③ 自动批改引擎

客观题自动判分；填空题支持"多参考答案 + 模糊匹配（包含即得分）"；简答题给出参考答案辅助教师人工复核。

批改效率提升 80%+，教师只需关注开放性题目

④ 学习分析看板

从班级、小组、学生、知识点四维展示数据：平均分 / 得分分布 / 高频错题 / 知识点掌握度，帮助教师精准定位薄弱环节。

自动生成图表，学情分析会上可直接投屏展示

⑤ 智能学伴养成

学生通过答题、课堂表现积累积分，领养并进化专属虚拟学伴（共 8 级进化）；图鉴展示全部学伴品种，形成趣味化激励。

游戏化设计 + 学科激励，让"刷题"变成"养宠物"

⑥ 学生/小组管理

支持多班级、小组、组长机制；Excel 批量导入；教师权限分级审核；学习积分与密码修改可视化看板。

一次配置，全学期可用
PART 04

目标用户画像

信息科技教师

每周 10-15 节信息科技课，负责多个平行班。迫切需要降低事务性工作负担，快速出题与批改，并获得可视化学情数据。

使用场景：备课 → 课堂检测 → 课后分析

中小学生

喜欢有趣、有成就感的学习体验。希望答题过程能像玩游戏，并看到自己的努力在持续被记录与奖励。

使用场景：课堂练习 / 单元测验 / 自主挑战

学校教研管理员

希望了解全校信息科技学科的整体学习情况，能够在教研会上直接引用真实学情数据，并跨班级共享高质量试题。

使用场景：教研分析 / 题库共享 / 数据统计
