Problem

为什么需要 NetScan？

在日常网络管理和运维中，我们经常面临以下困扰

🔍

设备发现困难

公司或家庭网络中有多少设备在线？传统方式需要逐个 ping，耗时且容易遗漏，缺乏直观的全局视图。

🚪

端口安全隐患

不知道哪些设备暴露了高风险端口？SSH、RDP、数据库等关键服务是否对外开放？缺乏快速检测手段。

📊

工具门槛过高

Nmap 等专业工具命令行复杂，普通用户难以使用。市面上的 GUI 工具要么收费，要么功能简陋、体验差。

Solution

NetScan 的核心能力

用 Go 语言打造的高性能桌面应用，让网络扫描变得简单高效

⚡

极速 IP 扫描

100 个并发 Goroutine 同时扫描整个 C 类网段（254 个地址），秒级完成设备发现，自动检测本机网段。

🚪

智能端口扫描

支持自定义端口范围和 25+ 常见服务自动识别（SSH、HTTP、MySQL、Redis 等），每 IP 20 并发探测。

🎨

现代化 GUI

基于 Fyne 框架的跨平台桌面界面，左右分栏展示 IP 列表与端口详情，实时进度条与状态反馈。

🔧

高度可配置

自定义网段、端口范围、超时时间等参数。支持单端口、多端口、端口范围（如 8080-8090）灵活配置。

🖥️

跨平台支持

一套代码编译即可在 Windows、macOS、Linux 上运行，自动适配各平台的 ping 命令差异。

🛡️

安全可控

纯本地运行，无需联网上传数据。支持随时停止扫描，800ms 端口连接超时保护，避免对网络造成压力。
