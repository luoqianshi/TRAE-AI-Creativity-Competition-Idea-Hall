# 喵域图鉴 Meowdex — 产品需求文档（PRD）

## 1. 产品概述

**产品名称**：喵域图鉴 (Meowdex)
**一句话定位**：用 AI 识别身边的流浪猫，像收集宝可梦一样建立你和它们的亲密度。
**Demo 形态**：单页 HTML 移动端 App 风格可交互 Demo（以 iPhone 14 Pro 比例 390×844 为目标），所有数据为前端 mock，可点可玩。
**目标用户**：云吸猫人群、社区爱心喂养者、好奇路人、社区志愿者。

## 2. 核心叙事

> 下班路过楼下花坛，一只熟悉的橘猫正眯着眼晒太阳。打开喵域图鉴，镜头对准它，屏幕飘出小星星、一只猫粮罐头"啪"地落在它脚边，弹出"CAT FOUND — Fluffyfur"的明信片式解锁卡。这只猫的身份档案，从此属于你。

## 3. 信息架构 / 屏幕清单

| # | 屏幕 | 路由 | 核心作用 |
|---|------|------|----------|
| S0 | 启动屏 / Logo | `#/` 首次进入 | 品牌识别 + 入口引导 |
| S1 | 图鉴 Collection | `#/collection` | 主屏：已收集猫咪的明信片墙 |
| S2 | 拍照识别 Camera | `#/camera` | 模拟取景框 + 罐头投喂 + 星星动画 + READY TO CATCH |
| S3 | CAT FOUND 弹层 | 浮层 | 仿宝可梦"捕获"反馈卡 |
| S4 | 猫咪档案 Detail | `#/cat/:id` | 单只猫的身份证 / 亲密度 / 照片 / 目击地图 |
| S5 | 地图 Map | `#/map` | 附近猫咪出没点位（mock） |
| S6 | 个人 Profile | `#/profile` | 玩家等级、罐头数、亲密度排行 |
| S7 | 新猫命名 | `#/name` | 第一次拍到未知猫时弹出的命名流程 |

底部 Tab：Collection / Map / Camera（大圆按钮，居中凸起）/ Store / Profile

## 4. 关键交互流程

### 4.1 主流程：发现 → 拍照 → 解锁

1. 用户在 Collection 或 Map 看到一只猫，点击"📷 拍猫"进入 Camera
2. Camera 屏显示模拟取景框（带橙色 L 形角标、3/3 tries 罐头数、"READY TO CATCH!" 按钮）
3. 点击"READY TO CATCH!"：
   - 罐头从屏幕顶部飞入并"砸"到猫咪位置
   - 屏幕飘出多颗小星星（CSS 动画）
   - 800ms 后弹层升起 CAT FOUND 明信片
4. 弹层包含：猫咪扣像 + 名字 + XP +130 / 金币 +11 / 编号 #000014 + "加入图鉴" 按钮
5. 点击"加入图鉴"回到 Collection，新卡片以高亮翻转入场

### 4.2 亲密度（Affection）系统

- 每次成功"拍到"同一只猫，亲密度 +10
- 亲密度 0~30：路人，名字显示为"???", 档案大部分信息锁定
- 亲密度 30~60：熟人，可看毛色、性格
- 亲密度 60~90：老朋友，可看常出没区域
- 亲密度 90+：守护者，获得命名权（已命名猫可改一次）

## 5. 视觉风格

- **关键词**：暖色明信片、纸纹质感、贴纸风、奶油 + 焦糖 + 暖橘
- **主色板**：
  - `--paper: #f4ecdb`（奶油纸张）
  - `--ink: #2a1f17`（深咖墨水）
  - `--orange: #ff7a3d`（焦糖橘）
  - `--mint: #4ec9a0`（薄荷点缀）
  - `--cream-2: #f9e9c8`（明信片卡片底）
- **字体**：英文/数字手写感 `Caveat` / `Patrick Hand`；中文 `ZCOOL KuaiLe` 或系统回退
- **质感细节**：
  - 背景为极淡的牛皮纸纹理（CSS 多层 radial-gradient + noise）
  - 猫咪照片用 `mask-image` 扣像后落到奶油色卡片上，带轻微投影
  - 名字贴纸用 SVG 撕边效果 + 旋转 1~3°
  - 罐头 emoji 🥫 + 星星 ⭐ 用作收集货币的拟物 icon
