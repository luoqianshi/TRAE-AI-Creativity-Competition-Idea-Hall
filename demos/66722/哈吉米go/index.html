原型导览

点击手机屏幕中央的 🐾 大圆按钮 进入拍照模式；从相册选一只猫投喂罐头，触发识别 → 解锁 → 入图鉴的全流程。

  • Collection：已收集的猫咪
  • Camera：拍照 + 投喂 + 识别
  • Map：附近出没点位
  • Store：罐头补给
  • Profile：等级 + 亲密度

核心动效

  1. 罐头从顶部飞入猫身边
  2. 星星以 60ms 间隔飘散
  3. CAT FOUND 明信片升起
  4. 返回图鉴后新卡翻入
