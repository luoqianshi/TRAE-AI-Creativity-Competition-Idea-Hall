农村老人办事，为什么这么难？

不是政策不够透明，而是「实操层面的门道」从来没人告诉过他们。

01

信息只到省市

官方平台告诉你「可以办」，但没告诉你窗口在几楼、几点人少、照片要白底。

02

老人不会搜索

60 岁以上农村老人多数不会打字，不会用搜索引擎，只能问邻居、跑三趟。

03

经验只在人脑中

「周三上午人少」「银行卡要信用社」这些信息只存在办过的人脑子里，随时间流失。

办高龄津贴，三趟才办成。不是政策难，是没人提前说一句：照片要白底，银行卡要本地的。
—— 村里不缺经验，缺的是把经验留下来的方式。

我们的解决方案

把「办过的人脑子里的经验」变成老人听得懂、看得清、能转发的信息。

方言模糊搜索

说「老人钱」自动匹配「高龄津贴申请」，说「看病报销」自动找到医保报销。

本村经验墙

同村王桂兰告诉你：照片要白底，周三上午人少，别月底去。

大字版清单

一键生成超大字体清单，带什么、去哪、找谁、注意什么，截图直接发给子女。

村情关系图

可视化展示你们村谁办过这个、你可以问谁，熟人信任一目了然。

项目开发书

产品、技术、运营、审核与盈利的完整设计。

一、项目定位

「村头万事通」是一个基于熟人信任的乡土办事经验 Wiki。不是政务办事系统，不是官方政策发布平台，而是村民自助 + 村民互助的信息连接器。

二、核心功能

  • 方言模糊搜索：说「老人钱」自动匹配「高龄津贴申请」
  • 本村经验墙：同村/邻村人的真实办事经历，带踩坑提醒
  • 大字版清单：一键生成超大字体清单，可截图转发
  • 村情关系图：可视化展示「你们村谁办过、你可以问谁」
  • 我的查询记录：本地保存老人查过的办事信息

三、技术实现

  • 前端：微信小程序 / HTML5 + CSS3 + JavaScript
  • 存储：localStorage（Demo 阶段）/ 云开发数据库
  • 图标：内联 SVG Symbol
  • 关系图：HTML5 Canvas
  • 开发工具：TRAE Work / TRAE IDE

四、内容治理

  • 机器先筛：敏感词、图片 OCR、重复内容检测
  • 实名身份绑定 + 地域围栏
  • 村民举报 + 信用分体系
  • 村干部不参与日常审核，只在例外情况介入

五、商业模式

  • 县域政府轻量采购数字乡村便民服务
  • 企业 CSR 公益赞助
  • 匿名化基层办事痛点数据服务
  • 核心原则：不向老人收费、不依赖政府长期拨款

六、社会价值

  • 智慧助老：帮助农村老人跨越数字鸿沟
  • 信息平权：把只存在「办过的人脑子里」的经验公开化
  • 基层减负：减少老人因信息不对称而反复跑腿
  • 熟人信任：依托乡土熟人网络，降低信息验证成本

七、运营规划

  • 短期：以一个县为试点，验证产品价值
  • 中期：复制到 10-30 个县，形成可复制的运营模板
  • 长期：覆盖更多乡镇，成为农村办事经验基础设施
