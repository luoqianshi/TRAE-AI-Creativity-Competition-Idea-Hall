银龄反诈陪练

社会服务赛道（可加选“社会公益”标签）

用“情景对话 + 解释纠错 + 家属联动”的方式，把反诈知识变成每天 3 分钟的可练习小任务。 目标不是讲大道理，而是让老人真正“遇到类似信息会停一下、问一下、查一下”。

创意介绍

这是一个面向老年人及其家属的轻量 Web 应用/小程序：每天推送 1 个“真实常见”的诈骗/骚扰场景（快递丢件、医保升级、熟人借钱、客服退款、刷单返利等）， 以对话形式让用户选择回复。系统给出“风险点拆解 + 正确做法 + 一句话提醒”，并沉淀到个人的“易中招点”画像。

  • 场景化：每道题都像聊天记录，降低学习门槛。
  • 可纠错：做错不扣分，重点解释“为什么这句话危险”。
  • 可联动：家属端可以看到学习记录，并一键生成“提醒话术”。

目标用户及痛点

  • 老年用户：看不懂“套路语言”，又怕麻烦子女；遇到“紧急、权威、限时”信息容易慌。
  • 家属：知道风险但难以持续提醒；讲多了像说教，老人反而抵触。
  • 社区/志愿者：反诈宣讲覆盖面有限，难以针对个人薄弱点反复训练。

价值与意义

  • 效率：把一次性宣讲变成可持续的日常练习。
  • 社会价值：降低受骗风险，减少家庭财产损失与心理创伤。
  • 可扩展：可接入社区活动、运营商短信识别、政务反诈素材库等。

用户流程（示意）

  • 打开应用 → 看到“今天 1 题”（大字模式可选）
  • 阅读/收听场景（短信/电话/微信聊天）→ 选择你的回复
  • 立即看到：风险点拆解 + 正确做法 + 一句话提醒
  • 生成个人画像：我最容易中招的 Top 类型（例如“限时恐吓”“加微信下载 App”）
  • （可选）家属端：查看学习记录 → 一键生成温和提醒话术 → 约定“遇到不确定先问我”

设计原则：不追求“学会所有反诈知识”，而是训练一个能执行的动作链：停一下 → 反向核实 → 再处理。

功能清单（MVP → 可扩展）

  • MVP（报名/初赛最适合）：题库（10-20条）+ 做题 + 解释 + 学习记录（本地或账号）
  • 增强：家属端提醒话术生成；“我做错过的题”复训；一键拨打官方热线/子女电话（提示用）
  • 无障碍：大字模式、语音播报、方言版本（先做普通话即可）
  • 安全与隐私：默认不收集敏感信息；如果上传截图/录音，需明确“本地处理/可随时删除”

Demo 打磨重点：题目“像真的”、解释“讲人话”、按钮“够大够清楚”。这些比复杂技术更能打动评审。
