01 / IDEA

创意名称与创意介绍

把“地点”从记录的背景，变成串联个人数字记忆的主索引。

创意名称
Pocket Earth · 口袋地球

想解决什么问题

我们的阅读、观影、音乐、照片和旅行记录分散在不同平台中，彼此割裂，难以形成完整的个人记忆。传统记录大多按照时间或类别整理，但人们往往记不清具体日期和名称，却仍记得一件事“发生在哪里”。这些被记录下来的内容因此很容易沉底，无法再次被发现和回想。

为什么想做这个

地点不仅是生活发生的背景，也是唤起记忆的重要线索。Pocket Earth 希望把“在哪里”变成个人记忆的主索引，让原本散落的数字碎片重新产生联系，也让记录从简单的存放，变成可以持续回望和理解自己的过程。

大概是什么产品

一款以可交互数字地球为核心的个人空间知识库应用。用户可以将书籍、电影、音乐、照片、行程和随手记录与相应地点关联，并在同一张地图上进行浏览、整理和回顾。随着内容不断积累，地球也会逐渐成长为一幅只属于用户自己的生活与兴趣地图。

02 / USERS

目标用户及痛点

服务于记录丰富、重视回顾体验，同时关注个人数据与隐私安全的用户。

TARGET USERS

面向哪些用户

有阅读、观影、听歌、旅行或摄影习惯，长期积累了大量个人记录，希望更好地整理和回顾生活，同时重视个人数据与隐私安全的用户。

USE SCENARIOS

在什么场景下使用

读完一本书、看完一部电影、听到一首喜欢的歌、结束一次旅行或整理照片时，用户可以随手记下一笔，并将内容关联到相应地点；当想回忆某段经历或寻找过去的兴趣记录时，也可以从地图出发，按照“在哪里”重新发现它们。

当前痛点

01

记录分散

个人记录散落在多个应用中，无法统一整理。

02

查找困难

单纯依靠时间线查找，记忆成本较高。

03

内容沉底

内容记录后容易沉底，缺乏再次回顾的契机。

04

偏好理解不足

现有工具难以真正理解用户长期形成的兴趣偏好。

05

隐私顾虑

照片、票据等资料可能包含敏感信息，用户不愿直接上传云端。

06

整理成本高

人工分类和补充信息步骤繁琐，难以长期坚持。

03 / VALUE

价值与意义

让记录更容易被整理、重新发现，并持续沉淀为由用户自己掌握的个人记忆体系。

VALUE 01

整理效率

以地理位置作为统一索引，将不同类型的个人记录转化为地图上的空间节点，降低跨平台整理和查找的成本，让分散的信息能够在同一视角下被看见。

VALUE 02

记忆唤醒

地图不仅用于存放内容，也为用户提供一种更符合直觉的回顾方式。通过地点重新连接书籍、影像、音乐与真实经历，使沉底的记录获得再次被发现的机会。

VALUE 03

隐私自持

对包含人脸、证件、定位等敏感信息的内容，优先在用户设备本地完成必要处理，尽可能减少原始隐私数据的外传，让用户保有对个人数字记忆的控制权。

VALUE 04

长远价值

随着使用时间增长，Pocket Earth 将逐渐沉淀出用户独有的生活轨迹、兴趣偏好和情感记忆，成为一颗越用越完整、越用越懂用户，同时由用户自己掌握的“口袋地球”。

让每个人都拥有一颗越用越完整、越用越懂自己，并由自己掌握的“口袋地球”。
