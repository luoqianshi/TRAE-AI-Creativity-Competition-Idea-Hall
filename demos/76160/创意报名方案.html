# 学习工作

1创意名称 + 创意介绍

创意名称
知识拼图 —— 一款把零散知识自动整理成可复习卡片的轻量学习系统
想解决什么问题
学生在听课、阅读、看视频时会产生大量零散笔记，但事后难以系统化、也很容易忘记；现有笔记工具偏「记录」而非「消化」。
为什么会想到做这个
灵感来自自身备考经历：同一主题的知识点散落在不同 App 里，复习时要反复翻找。希望有一个工具能像「拼图」一样把碎片自动拼成知识全景。
大概是什么产品
一款小程序 + Web 端的轻量学习系统，支持语音/文字/截图导入，自动生成结构化复习卡片与知识图谱。

2目标用户及痛点

面向哪些用户
核心用户为中学生、大学生及职场考证人群（如考研、考公、学语言者），也适用于需要持续学习的职场人。
在什么场景下使用
课堂听讲、看书划重点、刷网课、通勤碎片时间复习，以及考前集中回顾时使用。
当前痛点
没有该产品时，用户只能手动整理笔记，费时且容易半途而废；知识点孤立、缺乏关联，复习效率低，考前容易「看了像没看」。

3价值与意义

效率提升
通过 AI 自动归类与间隔复习提醒，把「记笔记」到「记住」的链路从数小时压缩到几分钟，复习效率预计提升 40% 以上。
商业价值
面向 2 亿+ 在校与考证人群，可采用「免费基础 + 会员进阶」模式，并对接教培机构 B 端合作，具备清晰的变现路径与规模空间。
