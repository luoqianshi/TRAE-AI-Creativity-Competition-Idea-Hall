# 繁星之火

**TRAE AI 创造力大赛参赛 Demo**

## 项目简介

"繁星之火"是一个"知识统摄 + 学习闭环"系统的静态原型 Demo。核心理念：知识不是一堆散点，而是一张大网。每个知识点都必须被放进地图里，经过本体理解、实例理解、题目训练、通关验收、定期复习和学习留痕，形成完整的学习闭环。

## 文件结构

```
星火-demo1/
├── index.html    # 主页面（7 个板块）
├── style.css     # 样式表（明亮大气风格）
├── app.js        # 交互脚本
└── README.md     # 项目说明
```

## 如何预览

直接双击 `index.html` 即可在浏览器中打开。无需安装任何依赖，无需启动服务器。

## 板块说明

| 板块 | 说明 | 位置 |
|------|------|------|
| 首页 Hero | 品牌展示、数字卡片、跳转按钮 | `#hero` |
| 知识地图 | 8 个知识节点，点击查看详情 | `#map` |
| 知识点本体 | 集合知识点的本体解释和深度理解 | `#ontology` |
| 现实实例 | 5 个真实场景实例卡片 | `#examples` |
| 题目训练 | 10 道训练题，可标记掌握，进度条变化 | `#training` |
| 复习循环 | 学习记录 + 6 节点时间轴 + 模拟提醒弹窗 | `#review` |
| 学习留痕与项目价值 | 留痕字段 + 四类用户价值 | `#traces` |

## 交互功能

1. **顶部导航** — 点击 / 滚动切换板块，自动高亮
2. **首页按钮** — "进入知识地图"和"查看学习闭环"按钮跳转
3. **知识地图节点** — 点击节点后底部显示详情
4. **题目训练** — 点击"标记掌握"后状态变为"已掌握"，进度条更新
5. **复习提醒** — 点击"模拟复习提醒"弹出提醒弹窗，支持 ESC 和点击遮罩关闭

## 学习流程展示

```
知识点本体 → 现实实例 → 题目训练 → 通关验收 → 定期复习 → 学习留痕 → 回到知识地图
```
