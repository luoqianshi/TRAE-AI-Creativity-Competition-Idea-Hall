01 · 创意介绍

想解决什么问题

中国有 2.8 亿老人，却有一半以上不会用智能手机。智能时代，不该把最需要被照顾的人留在桥的那一头。

🎯

痛点

老人用智能手机像走迷宫：字小看不清、按钮易误触、找功能要七八步、普通话不标准语音助手听不懂，学会又忘。独居老人想子女、突发不适，更是无门可求。

💡

灵感来源

爷爷想给我打视频电话，却要点开微信、找通讯录、翻到我、点视频——他学了一周还是学不会。那一刻我想：为什么不能"说一句话"就打通？于是有了银龄桥。

📱

产品形态

一款交互式网页应用（HTML 单文件）。老人打开网页，对着手机说话，就能查天气、提醒吃药、一键联系家人、听戏曲、紧急求助。双击即用，无需下载。

05 · 技术方案

怎么落地

纯前端单文件实现，浏览器原生能力驱动，双击即用，核心功能离线可用，完全符合初赛"交互式 HTML Demo"提交要求。

Web Speech API

浏览器原生语音识别 + 语音合成，无需音频文件、无需后端、无需 API Key。

单文件交付

HTML/CSS/JS 集成在一个文件，零安装、零依赖，老人双击即用。

离线可用

核心功能不依赖网络，农村、无网环境同样流畅。

响应式布局

一套代码适配手机/平板/电脑浏览器，自动适配屏幕。

长按防误触

关键操作长按 3 秒确认，防止老人手抖误触引发误操作。

WCAG 高对比配色

达到 WCAG AAA 级对比度标准，老花眼也能清晰辨认。
