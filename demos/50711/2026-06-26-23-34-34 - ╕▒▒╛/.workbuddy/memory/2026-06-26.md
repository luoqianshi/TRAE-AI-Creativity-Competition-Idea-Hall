## 感情急诊事务所 Web 应用开发

构建了完整的纯前端情感调解应用，三个文件：
- `index.html` - 页面结构（首页、单人调解、双人PK三个页面）
- `style.css` - 暖色调综艺风格样式，卡片式布局，移动端适配
- `app.js` - 全部业务逻辑

### 核心功能
1. **单人调解模式**：性别/年龄选择 → AI引导式对话收集信息 → 四位导师点评（按钮切换，同一时间只显示一位）→ 语音朗读（董情女声，其余男声）→ 综合建议
2. **双人PK模式**：甲方填写 → 生成分享链接（URL hash编码数据）→ 乙方通过链接填写 → 双方陈述整合 → 导师点评 → 综合建议
3. **四位导师**：董情(心理学家/女)、涂雷(社会学家/男)、罗桑(律师/男)、付杭(搞笑担当/男)，各有独立系统提示词
4. **技术**：Web Speech API语音合成，OpenAI兼容API调用，localStorage存储API配置，URL hash编码实现纯前端分享

### 使用说明
- 需要在设置中配置 OpenAI 兼容 API（地址、密钥、模型名）
- 支持 DeepSeek、智谱、通义千问等国内API

## 2026-06-29 API连接问题排查与修复

### 问题
用户使用智谱API（bigmodel.cn）时报"网络连接失败"

### 排查过程
1. 测试智谱API CORS预检（OPTIONS）→ 返回200，CORS头正常
2. 测试实际POST请求（带Origin头）→ 返回200，响应正常
3. 测试 file:// 协议（Origin: null）→ 返回200，`Access-Control-Allow-Origin: null`
4. 发现本地HTTP服务器已停止运行 → 用户很可能通过 `file://` 协议直接打开HTML文件

### 根因
Chrome等浏览器会阻止 `file://` 协议页面的所有 `fetch()` 请求（浏览器安全策略），即使API服务器支持CORS也会报 "Failed to fetch"

### 修复
1. 设置弹窗新增「测试连接」按钮，可诊断API连接问题
2. 改进错误提示：检测到 file:// 协议时提示用户通过 http://localhost:8080 访问
3. API地址/模型名称placeholder改为智谱示例
4. 404错误增加模型名称检查提示
5. 重启本地HTTP服务器（Python http.server 端口8080）

### 智谱API配置参考
- API地址：https://open.bigmodel.cn/api/paas/v4
- 模型名称：glm-4-flash（免费）/ glm-4 / glm-4-air
- 认证方式：Bearer token（直接用API密钥，格式 id.secret）
