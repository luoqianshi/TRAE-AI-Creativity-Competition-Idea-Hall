## 感情急诊事务所 - 修复流式输出闪烁问题

### 问题描述
用户反馈：在导师输出建议的时候屏幕一直在闪。

### 根本原因
1. `callLLMStream` 的 `onToken` 回调在每个 token 到达时都触发 DOM 更新
2. 高频 DOM 操作（每秒多次 `innerHTML` 赋值）导致浏览器频繁重绘/重排
3. 每次 token 都调用 `scrollTo`，导致滚动跳动

### 修复方案
1. **添加节流机制**（app.js ~第298行）：
   - 新增 `scheduleUpdate()` 函数，每 150ms 最多更新一次 DOM
   - 使用 `setTimeout` 确保最后一次更新一定会执行
   - 减少对 `onToken` 回调的调用频率

2. **优化 `renderMentorStreamContent` 函数**（app.js ~第859行）：
   - 首次渲染时创建完整卡片结构，并给 body 元素设置唯一 ID
   - 后续流式更新时，只更新 `.stream-text` 元素的 `innerHTML`
   - 避免每次 token 都重建整个卡片 DOM

3. **改进滚动逻辑**：
   - 只在用户已滚动到底部（距离底部小于 150px）时才自动滚动
   - 避免强制跳到底部导致滚动跳动

### 文件修改
- `app.js`：添加节流机制，优化流式渲染函数

### 状态
- 服务器运行正常：http://localhost:8080 可访问（返回200）
- JS 语法检查通过
- 等待用户测试确认闪烁问题是否解决
