Pain Points

你的空调，浪费了多少？

中国家庭空调空转率高达 35%，每年因"人走了空调没关"浪费数百亿度电。三大核心痛点，凉感知逐一解决。

空调空转浪费电

每天2-3小时空转却不自知，卧室开着空调去客厅看电视、出门忘记关空调……这些场景每天都在上演。

月浪费 45-72 度电 ≈ ¥30-48

定时器一刀切

设了2小时自动关闭，结果中途出去一趟回来空调已关，重新制冷比持续运行更费电。定时器解决不了动态需求。

反复启停额外耗电增加 15%

传统PIR传感器把宠物、风扇摆动、阳光变化误判为"有人"，导致空调无法进入节能模式，形同虚设。

传统方案误判率高达 30%

Workflow

四步智能决策流程

从探测到行动，全链路 0.5 秒完成。感知 → 融合 → 判断 → 执行，每一步都经过精密算法优化。

01
雷达探测人体
60GHz毫米波持续扫描空间，微多普勒效应区分人体与静态物体，即使呼吸微动也能捕捉。
→
02
双传感融合判断
毫米波 + PIR + 环境温度三源数据融合，AI算法交叉验证，误判率从30%降至不足2%。
→
03
无人倒计时
人离开后启动5分钟倒计时，期间持续复检。短暂离开不触发，真正离开才动作，避免频繁切换。
→
04
自动调温/恢复
无人则温度上调2°C进入节能，红外发码控制空调。人回来自动恢复舒适温度，无感切换。

Core Features

六大核心功能

每一项功能都经过真实场景打磨，不是堆砌参数，而是解决真实痛点。

毫米波精准感应

60GHz FMCW毫米波雷达，5米半径内精准识别人体存在，不受光线、温度、遮挡影响。可穿透玻璃和薄墙。

FMCW60GHz5m穿透探测

双传感融合防误判

毫米波与PIR双源交叉验证，配合环境温湿度数据，AI融合算法将误判率从30%压缩至不足2%。

PIRAI融合2%误判率三源数据

智能调温策略

无人自动上调2°C，但不会关机，保持基础温度避免重新制冷的额外能耗。支持自定义节能温度偏移。

+2°C节能策略自定义避免重启

夜间宽容模式

入睡后延长倒计时至15分钟，避免翻身等微动触发频繁切换。凌晨自动切换至静音模式，不影响睡眠。

15min夜间模式静音智能延时

多房间管理

蓝牙Mesh组网支持全屋多设备联动，一个App管理所有房间。支持场景联动：客厅有人则餐厅不关空调。

Mesh全屋联动场景模式远程控制

节能报告

每日/周/月节能数据可视化，精确记录每次触发节能的时段与节省电量。支持碳足迹追踪，环保量化可见。
