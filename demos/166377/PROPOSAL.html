挑战

网络流量的真相，
藏在碎片的海洋里

当安全事件发生，运维人员面对的是分散在多份 CSV、多张 Excel、多个网段之间的海量记录。 IP 归属不清、跨区域流向难辨、人工关联耗时——每一次溯源都是一场与时间的赛跑。

  • 01
    资产边界模糊 IP 资产、Web 资产、网络区域分散管理，缺少统一的归属关系视图，难以快速定位责任主体。
  • 02
    跨网段流向失真 传统工具只能呈现单点流量，跨区域的真实通信路径被掩盖，异常横向移动难以被识别。
  • 03
    分析门槛高 需要熟练掌握查询语言与可视化工具，普通运维人员难以独立完成从数据到结论的全流程分析。
  • 04
    合规审计断层 操作行为缺少完整记录，安全事件发生后无法回溯"谁在何时做了什么"，合规风险居高不下。

AI 智能

不止是聊天，
是会思考的网络分析智能体

Traffic Traceback 的 AI 不是装饰。它能调用工具读取真实流量数据，能记住上下文跨轮推理，能在思考过程中自动压缩记忆——这是一个真正嵌入业务的工作伙伴。

  • 工具调用与数据访问

    AI 通过工具调用实时查询流量、资产、区域数据，数据源状态实时指示，仅授予只读权限，安全可控。

  • 上下文记忆与自动压缩

    滑动窗口 + 递归摘要混合策略，Token 预算智能分配。上下文使用率达 100% 时，Agent 在推理过程中自动挂起并执行压缩，告知用户后再继续输出。

  • 多模型管理与 Auto 选择

    API Key AES-256-GCM 加密存储，支持 OpenAI/Anthropic 多协议。Auto 模式智能评分选择最佳模型，模型能力细分（推理/图片/视频/语音）。

  • 用户偏好双层模型

    显式偏好 + 隐式习惯双层记录，80% 自动合并、100% LRU 淘汰，AI 越用越懂你。会话记忆按用户 + 项目维度隔离，多用户数据互不干扰。

  • 安全栅栏 L2 审批

    Agent 模式下 AI 扩展为可写权限（生成文档、导出数据），但必须通过安全栅栏 L2 审批。输入输出双向过滤，敏感内容自动清洗，docx 报告中文文件名规范编码。

安全合规

每一行操作，
都有迹可循

从认证到授权，从输入过滤到输出清洗，从审计日志到密钥轮换——安全不是附加项，是平台的底座。

RBAC 权限模型

admin / analyst / operator / viewer 四角色十六权限，按钮级前端控制，AI 数据访问五维开关。

认证与暴力破解防护

JWT 自动生成 64 字节随机密钥持久化，5 次失败锁定 30 分钟，初始密码仅输出到 stdout 登录后清理。

AI 安全栅栏

输入端 SQL 注入 / XSS / 敏感词过滤，输出端跨 chunk 累积清洗。高风险操作触发 L2 审批工作流。

全操作审计日志

GET / POST / PUT / DELETE 全方法记录，24 种操作类型，15 种资源类型，时间 + 关键词筛选，自动清理。

国密算法支持

SM2 / SM3 / SM4 国密算法，密钥轮换周期可配。轮换时所有 JWT 立即失效，强制重新登录。

数据隔离与资产过滤

Web 资产访问过滤 10 种内网地址段，DNS 重绑定防护。多用户记忆 / 偏好完全隔离，A 用户数据 B 用户不可见。
