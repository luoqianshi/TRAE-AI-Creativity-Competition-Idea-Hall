01 / 创意介绍

为什么做一款「反潮流」的本地音乐播放器？

当音乐 APP 越来越像社交、直播、电商的混合体，我们想回到听歌这件事本身。LinkPlayer 不做算法推荐、不做流量生意，只做一件事：把你已经拥有的音乐，用最好的方式播放出来。

一句话产品形态

LinkPlayer 是基于 Vue 3 + Electron + Capacitor 的跨平台本地音乐播放器，已支持 Windows / macOS / Linux / Android，并配套官网与会员体系。

灵感来源

创始团队硬盘里存了大量本地音乐，却找不到一个界面干净、功能完整、能自动整理曲库的播放器，于是决定用 TRAE 自己做一个。

核心解决的问题

终结会员套娃、广告打扰、本地音乐被忽视、设备不互通的糟糕体验，让音乐回归纯粹。

02 / 目标用户与痛点

谁需要 LinkPlayer？他们正在经历什么？

核心用户不是追逐热歌榜的泛娱乐用户，而是对音乐有真实收藏、真实情感、真实音质需求的人群。

01

本地音乐收藏家

硬盘、网盘、CD 转录里存了大量 FLAC / WAV / MP3，却没有一个播放器能自动整理封面、歌词与专辑信息。

02

厌倦了订阅制的用户

每年在多个平台花费几百元会员费，换了设备还要重新买，歌单里的歌曲还会因为版权下架突然变灰。

03

追求专注体验的职场人与学生

只想在工作、学习时安静听歌，却被开屏广告、直播弹窗、社交动态不断打断，播放器变成了噪音源。

04

跨设备音乐爱好者

电脑、手机、平板之间音乐无法同步，车载音响不支持流媒体账号，想在自己的所有设备上听同一套曲库非常麻烦。

03 / 价值与意义

一次性投入，终身自由；个人数据，完全自主

LinkPlayer 从效率提升、用户价值与商业价值三个维度，重新回答「音乐播放器应该是什么样子」。

效率价值：3 步构建私人曲库

自动扫描文件夹 → 智能识别歌手/专辑/封面/歌词 → 即刻播放。配合桌面歌词、全局快捷键、远程控制，把听歌这件事做到极致顺手。

用户价值：数据隐私回归本地

所有音乐文件与播放记录保存在本地，不上传云端、不收集行为数据，让用户重新拥有对自己音乐资产的掌控权。

商业价值：完整商业闭环

官网 + 会员中心 + 支付订单 + 优惠券 + 设备授权，已形成可落地的商业模式，不是单纯的工具 Demo。

04 / 实现路径

从创意到可体验产品，我们是怎么做的？

基于现有 Electron + Capacitor + Vue 3 全平台架构，我们已经完成核心体验闭环，并持续向更精致的产品形态迭代。

第一阶段：本地曲库智能整理
完善文件夹扫描、音频元数据解析、歌手/专辑自动归类、封面与歌词自动匹配，让用户的本地音乐「一秒变整洁」。
第二阶段：极致播放体验
基于 Howler.js 的跨平台音频引擎，支持 FLAC/WAV 无损解码、10 段参数均衡器、ReplayGain、桌面歌词、睡眠定时与全局快捷键。
第三阶段：系统级整合与跨端协同
实现托盘菜单、文件关联、最小化迷你播放器、远程控制页面，并继续打磨 Android 沉浸式体验与多端同步。
第四阶段：商业化与可持续运营
通过官网会员中心、SVIP 体系、支付订单、优惠券与设备授权，建立健康的产品商业模式。
