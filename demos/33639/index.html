01 · 痛点

一个摄影师的一天

3,000+ 一场婚礼的平均出片量。手工初筛 3–5 小时，双眼疲劳导致漏选错选。

婚礼摄影师拍完一场活动后，面对数千张照片的手工选片、逐张修图和反复调色， 耗费大量时间在机械重复劳动上。中小摄影工作室根本没有专职后期团队。

  • 选片 — 从 3,000+ 张中手工剔除闭眼、模糊、表情不佳的照片，耗时 3–5 小时
  • 精修 — 每张照片逐颗瑕疵修复、皮肤柔化、五官增强，熟练修图师每天极限修 150 张
  • 追色 — 客户拿一张「小红书网图」要求同款色调，调色师反复试错，一张图调半小时
  • 批量 — 选片→精修→追色环节串联，中间大量文件搬运、格式转换，易出错且极度枯燥
02 · 产品

AI PHOTO STUDIO

一个模块化的 AI 图像处理工作台。本地运行、数据安全、可离线使用。 Gradio 图形界面，摄影师无需技术背景即可上手。

01

智能选片 · Culling

7 阶段漏斗式流水线：画质预筛 → 人脸/表情检测 → 深度质量评分 → 感知哈希去重 → 美学评分 → 综合排序。支持手动覆盖和 checkpoint 重放。

MediaPipe · pHash · 多阶段淘汰
效率提升 90%
02

AI 人像精修 · Retouching

11 步顺序流水线：瑕疵检测修补 → 频率分离磨皮 → LAB 美白 → Unsharp+CLAHE 人脸增强 → 白平衡 → 分色调色。每步独立开关，异常自动降级。

OpenCV · Guided Filter · 自动降级
每张 30–60 秒
03

AI 追色 · Color Transfer

5 种算法可选：Reinhard / 3D 直方图 / Optimal Transport / MKL。MediaPipe ROI 保护肤色，多尺度导向滤波保持空间一致性，可导出 .cube 3D LUT。

PyTorch · 5 算法 · LUT 导出
一键模仿色调
04

批量工作流 · Workflow

一键串联选片 → 精修 → 追色 → 渲染 → LUT 导出。OOM 自动降级，进度 checkpoint 支持打断恢复，单图失败不影响批处理。

05 · 架构

技术规格

模块化流水线架构，引擎与 UI 解耦。审计事件异步 JSONL 日志全程可追溯。

智能选片引擎

  • P1 文件解码与元数据提取
  • P2 画质预筛（模糊/曝光/尺寸）
  • P3 人脸检测与表情评分
  • P4 深度学习质量评分
  • P5 感知哈希去重
  • P6 美学评分
  • P7 综合排序与挑选

人像精修流水线

  • MediaPipe FaceMesh 人脸检测
  • YCbCr 肤色 + 人脸椭圆掩码
  • 局部瑕疵检测 + OpenCV inpaint
  • 频率分离 + 导向滤波磨皮
  • LAB L/A 通道美白
  • Unsharp + CLAHE 人脸增强
  • 白平衡与分色调色

AI 追色系统

  • P0 人脸/皮肤 ROI 提取
  • P1 Reinhard / OT1D 颜色迁移
  • P2 3D 直方图 / MKL 匹配
  • P3 多尺度导向滤波空间融合
  • P4 肤色/中性色/高光保护
  • P5 渲染输出
  • P6 3D LUT .cube 导出

批量工作流

  • 多图顺序流水线编排
  • OOM 自动降级与重试
  • 进度 checkpoint 持久化
  • 单图失败不影响批处理
  • 共享 3D LUT 批量色彩统一
  • 异步 JSONL 审计日志
