Claude · 导师模式
好，我们来聊聊 Python 里一个很优雅的概念——多态（Polymorphism）。

你可以把它理解为：同一个"动作"，不同的对象有各自不同的表现。

想象你发出指令「叫一声」，狗会"汪汪"，猫会"喵喵"，鸭子会"嘎嘎"——接收同一指令，各自执行各自的版本，这就是多态。
在代码里，我们通过方法重写（Method Override）来实现： 
class Animal:
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "汪汪！"

class Cat(Animal):
    def speak(self):
        return "喵喵～"

# 多态的魔力在这里
animals = [Dog(), Cat(), Dog()]
for a in animals:
    print(a.speak())  # 每个对象各说各的
你觉得这和你在 JavaScript 里见过的原型继承，有什么感觉上的相似或不同？

这个问题问到点上了！Python 里有个重要的思想叫做 鸭子类型（Duck Typing）：

"如果它走路像鸭子，叫声也像鸭子，那它就是鸭子。" ——Python 的哲学
也就是说，Python 不要求你显式继承同一父类，只要对象"有这个行为"就行： 
class Duck:
    def speak(self):
        return "嘎嘎！"

class Robot:           # 没有继承 Animal
    def speak(self):
        return "哔哔~"

def make_noise(thing):  # 不在乎类型，只在乎"会不会叫"
    print(thing.speak())

make_noise(Duck())   # → 嘎嘎！
make_noise(Robot())  # → 哔哔~
这比 Java 的接口强制实现更灵活，也是 Python 代码可以如此简洁的原因之一。
