项目背景与定位

直击现有文件管理工具的痛点，打造刚刚好的轻量化替代方案

系统工具效率低下

Windows 资源管理器单窗口操作繁琐，跨文件夹复制需反复跳转；批量重命名功能孱弱，大目录加载卡顿，无法满足高频文件整理需求。

专业工具门槛过高

Directory Opus、Total Commander 等专业软件功能庞杂，学习曲线陡峭，普通用户仅用到 20% 功能，却要承担高昂的授权成本与臃肿体积。

跨端中转体验割裂

多设备间传小文件依赖社交软件，存在压缩、大小限制、留痕等问题；通用网盘登录繁琐，缺少「即用即走、自动过期」的临时中转方案。

核心定位

以「轻量化双栏文件管理」为核心，保留 Directory Opus 最常用的核心操作，剔除冗余功能；融入 AI 智能整理能力降低操作门槛；搭配自研临时云盘实现跨端文件中转， 面向办公人群、设计师、开发者等高频文件处理用户，提供「比系统好用、比专业工具简单」的文件管理体验。

核心功能矩阵

5 项基础能力 + 2 项 AI 创新功能，覆盖文件管理全流程

双栏分栏显示

左右双栏独立展示不同文件夹，支持拖拽复制/移动文件，跨目录操作无需反复跳转窗口，大幅提升文件整理效率。

左侧目录树导航

侧边栏完整展示磁盘目录层级结构，支持一键展开/折叠，快速定位目标文件夹，全局视角掌控文件分布。

批量文件操作

支持批量新建、删除文件与文件夹；提供前缀/后缀/序号替换等多种批量重命名规则，一键完成百级文件规范化命名。

一键压缩解压

内置 ZIP 格式压缩与解压能力，支持多文件/文件夹直接打包，右键快捷操作，无需依赖第三方压缩软件。

临时云盘同步

单文件限 20MB，保存 7 天自动过期；上传生成分享链接，多终端浏览器即可下载，适配跨设备临时文件中转场景。

AI 自然语言重命名

AI创新

输入自然语言指令（如「按修改日期+序号重命名」），AI 自动解析生成命名规则并批量执行，无需手动配置复杂规则。

AI 智能分类整理

AI创新

一键识别文件夹内文件类型与内容特征，自动按「文档/图片/视频/压缩包」等类别归档到子文件夹，专治杂乱的下载目录。

技术实现方案

成熟技术栈 + 模块化设计，实施难度可控，大赛周期内可完整落地

前端客户端架构

  • 技术栈：Electron + Vue3 + Tailwind CSS，基于 TRAE IDE 快速开发，跨平台兼容 Windows 系统
  • 文件系统交互：调用 Node.js fs 模块实现目录读取、文件增删改、批量重命名等核心操作
  • 压缩解压：集成 JSZip 开源库，支持 ZIP 格式的打包与解包，轻量无额外依赖
  • UI 组件：目录树、双栏布局、拖拽交互均采用成熟开源组件，快速搭建核心界面

后端与云服务

  • 技术栈：Node.js + Express 轻量后端，部署于个人云服务器，提供文件上传下载接口
  • 权限与限制：接口层校验单文件大小（≤20MB），生成唯一文件标识与分享链接
  • 自动过期清理：定时任务每日扫描文件，自动删除超过 7 天的文件，释放存储空间
  • 数据存储：本地磁盘存储文件，极简架构无需数据库，运维成本极低

AI 能力集成

AI 自然语言重命名

调用大语言模型 API，传入用户自然语言指令与文件列表，由大模型输出标准化重命名规则，本地执行批量改名操作。仅做规则解析，不上传文件内容，安全高效。

AI 智能分类整理

基于文件名、后缀、大小等特征，通过大模型判断文件类别，生成分类目录与移动方案，本地执行归档操作。支持自定义分类规则，适配不同使用场景。
