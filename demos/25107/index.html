痛点
传统图表工具，对 AI 不友好
Mermaid、PlantUML、Graphviz 都是为人类手写设计的，AI Agent 生成图表时面临重重困难。
🔀

语法变体太多

Mermaid 有十几种箭头样式和隐式规则，LLM 极易混淆，生成的代码经常无法解析。

📐

布局需手动指定

Agent 必须表达坐标或方向提示，无法让引擎自动推断最佳布局，输出经常混乱。

🐛

报错模糊难调试

传统工具出错时只给模糊提示，Agent 无法自行定位和修复，只能反复重试。

🔄

无法增量修改

缺乏语义级 Diff/Patch 能力，每次修改都需重新生成完整图表，效率低下。

引擎自动布局 · 语义实体自动选型

核心能力
为 AI Agent 量身打造
🧩

固定语法，3种箭头

仅 -> --> <-> 三种箭头，消除语法歧义，LLM 生成准确率大幅提升。

🎯

语义实体声明

声明 type: database、type: service，引擎自动选择形状和图标，无需手动配置样式。

📐

自动布局引擎

内置 Sugiyama、力导向、环形、思维导图等多种布局算法，引擎自动推断最佳布局。

🔍

结构化诊断

错误信息包含精确位置和修复建议，Agent 可自行定位问题并修复，无需人工介入。

🔄

AST级 Diff & Patch

AST 是一等公民，支持 JSON 导出、语义级 Diff 比较和增量 Patch，实现图表的版本化管理。

�

图表动画能力

内置动画引擎，支持节点逐帧出现、连线流动、状态切换过渡等动画效果，让静态图表变为动态演示，适合教学演示和产品展示场景。

��

跨平台部署

Rust 核心共享 CLI、HTTP Server、WASM 三种前端，浏览器端也能实时渲染。
