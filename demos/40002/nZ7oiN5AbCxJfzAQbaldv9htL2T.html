The Core Innovation

他不需要你替他做决定。
他有自己的需求，自己的偏好，自己学到的喜欢。

「分一点一秒，他活得像我们一样。」

每个微动作（吃饭 / 睡觉 / 刷手机 / 加班）由 6 维需求 × 性格 × 时段 × 偏好权重共同决定； 完成后基于需求恢复量计算 selfReward，
用 Hebbian EMA 更新 41 维偏好权重——他真的"知道"自己现在该做什么。

▎ 自主活着引擎 · 实时观察 · 1× = 1秒 = 1分钟

真实需求

6-D Needs

体力 / 饱腹 / 陪伴 / 充实 / 整洁 / 专注。每秒衰减，每个动作有 delta 压力。人物真的会因为"饿了"而去找吃的。

自主强化

Self-RL

完成动作后算 selfReward（满足度 - 之前 / - 之后），用 α=0.10 EMA 更新偏好权重。slowly forget 防止漂移。

纯观察

Observer Mode

用户没有任何「替他做决定」的入口。只有暂停、调整速度（3 档时间倍率）、翻看历史。1 秒 = 1 秒 / 1 分 / 10 分。

Multimodal Output

4 种模态的产物

不是"一篇文章"，是 4 件你可以拿走的作品。

生命之书

LIFE BOOK

按人生阶段（童年/少年/青年/中年/老年）展开 10-20 个关键事件 + 终章。DeepSeek 流式生成，可一键重写。

平行世界的我

PARALLEL PORTRAIT

豆包·Seedream 文生图。一张属于"那个我"的脸：年龄 / 城市 / 性格 / 价值观 / 人生轨迹全部写进 prompt。

自传语音

AUTO-BIO TTS

Web Speech API 用他的人生轨迹 + 关键事件 + 性格独白生成一段自传朗读。中英混合、男声女声可调。

AI 分身主页

SHAREABLE PROFILE

把 Life 序列化成 gzip+base64url token。/u/:token 公开只读：头图、状态徽章、性格/价值观条形图、二维码。

足迹地图

FOOTPRINT MAP

SVG 世界地图：他走过的城市连线、当前位置高亮。点开看每个城市的居住时长、关键事件。

习惯偏好表

SELF-LEARNED

41 维偏好权重 Top/Bottom 5：他自己学到的"喜欢什么、不喜欢什么"。每条生命都不一样。
