Industry Pain Points

工厂工程师的 6 大真实痛点

基于一线工程师长期实践，归纳出最影响工作效率的"工科人写文档"难题

📁

记录散乱难检索

Word/记事本/微信文件助手到处存放，几个月后想找一份记录都找不到，宝贵经验石沉大海。

🔁

经验无法复用

处理过的"电机轴承异响"案例，过半年再遇同类问题又得从头排查，历史经验没有结构化沉淀。

⏰

周报月报痛苦

月底交月报要花 2-3 小时从几十篇日记里挑内容、复制粘贴、调整格式，深夜加班成常态。

✍️

会干不会写

老师傅技术过硬但写不出规范文档，年轻工程师能写但写不出技术深度，"干与写"严重脱节。

📐

格式五花八门

班组多人协作时，Word 字体、行距、标题样式、模板不统一，文档专业度大打折扣。

🔒

工厂内网受限

化工厂、电厂等场景网络隔离，云端 AI 工具无法使用，离线可用、数据本地化是硬刚需。

Core Features

七大核心功能模块

一个软件，工程师"记录→整理→复用→汇报"全流程搞定

📝

智能日记管理

按日期编写 Markdown 日记，标题三级分层管理，多维度标签分类，结构化沉淀每一条工作经验。

  • 三级/四级标题双层结构
  • 标题库引用追踪 + 标签筛选
  • WebView/Textbox 双模式实时预览
  • 自动保存 + 多版本备份
🤖
★ 核心亮点

AI 帮写 + AI 问答

选中文字一键改写/润色/续写，未选中时 AI 根据提示词在光标处插入内容；AI 问答支持一阶/二阶穿透，自动加载 MD 引用文档。

  • 流式输出，文本框自适应高度
  • 引用保护：AI 处理中保留 MD 链接/图片
  • 每篇文档独立对话历史持久化
  • 支持 10+ LLM 提供商（DeepSeek/Kimi/通义等）
📄

AI 文档助手

DOCX → MD → AI 润色 → DOCX 全流程自动化，三步搞定专业报告，5 级润色等级（轻度/中度/深度/放飞）。

  • 7 套专业模板（周报/月报/会议纪要/技术方案）
  • 智能图片路径处理（relative_path 模式）
  • 支持独立 exe 打包，无需 Python 环境
  • 多文件合并 + 输出续写 + 一级标题改名
📊

周报/月报自动生成

选日期范围一键聚合所有日记 → AI 润色 → 输出标准 DOCX，告别"手写月报熬通宵"。

  • 周记：周一到周日聚合
  • 月记：基于周报汇总或直接选日记
  • 专题报告：关键词搜索 + AI 总结
  • 批量重新生成脚本（regenerate_reports.py）
✅

待办闭环管理

日记中的 `- [ ] 待办:` 自动提取归档，待办面板集中销项，完成/取消后自动回写源日记。

  • 仅提取三级标题下的待办（避免误提取）
  • 白名单格式：- [ ] 待办: xxx (TD0001)
  • 四风格新建对话框（极简/暖纸/深邃/晨光）
  • 全局校正按钮：以 .md 为准修复 JSON
🔍

聚合搜索 + 智能搜索

关键词/标题双模式搜索，跨日记聚合同一标题下的所有内容；AI 智能搜索让 LLM 帮你总结搜索结果。

  • 聚合浏览模式（可编辑、可保存）
  • 标签浏览：按标签 AND 关系筛选
  • 多标签 Tab 浏览 + 滚动位置记忆
  • 浏览历史前进/后退（精准滚动恢复）

Tech Stack

技术架构与实现

基于 Python + CustomTkinter 的现代化桌面应用，支持完全离线运行

UI Layer
CustomTkinter + tkinterdnd2 + tkinterweb
现代化 Tkinter UI、文件拖拽、Markdown WebView 渲染
Business Logic
JournalLogic + 16 个 Mixin 模块
日记 CRUD / 报告生成 / 搜索聚合 / 标题标签管理
AI Engine
ai_polisher + llm_client
多 LLM 适配（DeepSeek/Kimi/通义/Gemini 等）+ 5 级润色
Document Engine
pandoc + python-docx + markitdown
DOCX↔MD 转换、智能图片路径处理、Word 模板套用
Data Layer
Markdown 文件 + JSON 索引 + SQLite
日记文件 + 标题管理 + 标签管理 + 待办 + AI 聊天历史
🏗️

Mixin 拆分架构（万行级主程序）

JournalApp 继承 16 个 Mixin 模块，单文件曾达 21151 行，现主体精简到 ~6000 行

📦

PyInstaller 独立打包

主程序 + AI 文档助手分别打包为 exe，双击即用，不依赖外部 Python 环境

🔌

启动器层解耦设计

launch_ai_tool.py 作为稳定中间层，gui.py 可随时更新替换，零维护成本

🎨

主题与显示设置

暗色/亮色双主题、8 种中文字体、6 级标题颜色、命名配置文件持久化

🔒

本地优先 · 数据安全

所有日记、配置、AI 历史都存本地，支持完全离线运行，工厂内网合规
