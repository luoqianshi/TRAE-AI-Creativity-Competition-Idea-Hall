First Principles

追问到底，发现同一个底层问题

🔍

表面问题各不相同

被比较、被冤枉、被冷落、失恋、等审判——五个完全不同的场景

💡

真正的问题只有一个

所有负面情绪都停在同一个点上：不知道怎么开口

🎯

根因比想象更具体

不是"情商低"或"性格内向"，是因为从来没有地方练习过

🎭

排练是唯一可行的解法

数学有习题册，体育有训练场。但"跟妈妈说你的比较让我很难受"——这句话怎么练？

· · ·

如果没有排练场：五种结局

每一次沉默、逃避、不开口——都让下一次更难开口

🧧 被比较 → 沉默 → 沉默变成习惯 → "我就是这性格"
📝 被冤枉 → 不解释 → 不解释变成默认 → "说了也没用"
👥 被冷落 → 不问 → 不问变成逃避 → "他们讨厌我"
💔 失恋 → 不说 → 不说变成压抑 → "我不擅长表达"
🚪 等审判 → 躲着 → 躲着变成常态 → "我们没话说"

排练场要拦住的，就是这条向下的螺旋线。

Technology

技术架构

直连斯坦福学术前沿的多智能体模拟架构

场景分析 + 角色匹配

TRAE AI API

用户输入困境文本 → AI提取关键信息 → 在关系图谱中自动匹配相关角色 → 呼吸高亮提示

关系图谱可视化

D3.js / Cytoscape.js

中心是"我"，角色节点+关系连线，支持拖拽缩放。排练过的角色有标记，关系线随互动变化

角色扮演对话

TRAE AI API + Prompt

AI基于用户自定义的角色描述 + 行为特征 + 历史排练记忆，模拟真实对话风格

长期记忆系统

Transformers.js + IndexedDB

浏览器端向量嵌入（all-MiniLM-L6-v2），每次排练生成摘要向量，下次排练注入上下文

多智能体联动

Generative Agents 架构

基于斯坦福2023论文的记忆-反思-计划架构，角色间信息可传播，模拟真实人际关系网络

隐私安全

本地存储 + 内容过滤

全部数据存储在浏览器localStorage/IndexedDB，无用户注册，无数据上传，端到端隐私保护
