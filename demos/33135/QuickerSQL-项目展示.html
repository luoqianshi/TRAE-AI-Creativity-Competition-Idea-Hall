1️⃣ 创意名称 + 创意介绍

解决什么问题 · 为什么想到做这个 · 产品形态

🎯
想解决什么问题
日常工作中，我们常常需要快速分析一份本地 CSV 或 Excel 数据——销售报表、问卷统计、考勤记录、库存清单。

然而：用 Excel 效率低、用 Python 门槛高、用在线工具担心数据泄露、用 BI 工具太重。

痛点一句话：有没有一款零配置、开箱即用、数据不出本地的数据分析工具？
💡
为什么会想到做这个
在日常学习与工作中，我反复遇到同一个困境：

① 拿到一份 CSV 数据，想做个快速统计表，Excel 公式繁琐
② 想画个图表，却要在多个工具间来回切换
③ 数据里有敏感信息，不敢上传到任何在线工具

于是萌生了用 TRAE Work 做一个 "本地版 Tableau Lite" 的想法。
⚡
产品形态
一款基于 Tauri + React + SQLite 架构的 桌面应用。

用户只需三步：① 拖拽导入数据文件（CSV/Excel/SQLite） → ② 编写或点击生成 SQL 查询 → ③ 一键生成可视化图表并保存为仪表盘。

所有数据处理在 100% 本地 完成，无需网络连接，零数据泄露风险。 安装包仅 ~10MB，启动速度 < 2秒，支持 Windows / macOS / Linux。

💻 代码演示：销售数据分析（示例 SQL）
一条查询，自动生成多种图表
-- 2025年各月份销售总额 & 订单数量统计 SELECT strftime('%Y-%m', order_date) AS 月份, SUM(amount) AS 销售总额, COUNT(*) AS 订单数量 FROM sales_orders WHERE strftime('%Y', order_date) = '2025' GROUP BY strftime('%Y-%m', order_date) ORDER BY 月份;

🔑 为什么选择 Tauri 而不是 Electron？

📦 更小的体积

Electron 应用通常 >100MB，Tauri 仅 <10MB。用户下载成本降低 10 倍以上。

🚀 更快的启动

Tauri 使用系统原生 WebView，启动时间 <2秒，对比 Electron 的 5-10秒。

🔒 更安全的架构

Rust 内存安全语言 + 严格的权限模型。默认禁止网络访问，数据天然隔离。

💪 更低的内存占用

运行时内存占用为 Electron 的 1/3，节省用户的系统资源。
