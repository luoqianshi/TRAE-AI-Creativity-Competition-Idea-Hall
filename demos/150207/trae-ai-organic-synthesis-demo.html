🚀 核心功能

从分子输入到可行性报告的全链路设计

⚡

双引擎推理

基于 RDKit.js 子结构匹配的现代引擎优先检索，失败时自动回退至规则映射引擎，确保任意分子均有返回结果。

🧬

规则驱动逆合成

不依赖预设模板，通过 200+ 条 SMARTS 规则对目标分子递归切断。就像化学家一样：识别官能团 → 选择切断策略 → 评估前体。

🎨

分子绘制 + 多种输入

支持 SMILES 直接输入、107 种常用分子名称联想、结构绘制器，以及 IUPAC 命名自动识别，覆盖主流输入需求。

🔬

键线式可视化

自研 Canvas/SVG 分子渲染引擎，专业级键线式展示，支持缩放、旋转、平移等交互操作。

📊

多维度评分系统

综合步骤数、原料可得性、反应条件温和度、总产率四大维度评分排序，附带难度等级、绿色化学评分。

💡

推理链 + 可行性报告

每条路径展示完整的"思考过程"：官能团分析 → 切断位点选择 → 反应条件考量 → 副反应风险规避 → 优化建议。

🏗️ 双引擎架构详解

混合推理策略：RDKit 子结构匹配 × 规则映射引擎

🧪 RDKit 引擎 PREFERRED

  • 通过 rdkit.js WebAssembly 进行 SMARTS 子结构匹配
  • BFS/DFS 递归搜索 + node signature 去重
  • 完整立体化学 (CIP 标记 + E/Z 几何分析)
  • 环系断键策略 (retro-DA、芳环取代逆向)
  • 5s 全局超时 · 预排序分批处理 (每 20 条检查)
  • 200 条规则匹配缓存

📐 规则映射引擎 FALLBACK

  • 基于官能团模式识别 + 反应活性优先级排序
  • 命名切断映射 + 碳数拆分 + 多选一规则
  • 分步骤展示切断策略与化学逻辑
  • 根据反应类型动态推荐试剂、条件与产率
  • 多路径合并、去重、评分、过滤
  • FeasibilityReport：总产率/难度/绿色评分/优化建议
🎯 目标分子 SMILES → 官能团识别 15+ 模式 → RDKit 规则匹配 优先 → DFS 递归逆推 MAX 500 节点 → 4 维评分排序 步骤/原料/条件/产率 → 📋 结果 + 推理链展示

📅 开发历程

从基础应用到规则引擎重构，逐步打磨

第 1 轮 · 基础架构搭建

Vite + React + TS 项目初始化，Tailwind 主题配置，响应式主布局（Header/输入区/结果区）。集成分子绘制器 & SMILES 输入系统，实现约束条件设置面板（碳数/试剂/条件）。

Task 1-3

第 2 轮 · 合成路径生成引擎 + 键线式可视化

构建基于官能团转化的逆向合成算法，路径评分排序系统。自研 Canvas/SVG 键线式渲染器，支持缩放/旋转/平移。添加反应标注系统（试剂/条件/类型/机理）。

Task 4-6

第 3 轮 · 交互优化 + 响应式设计

路径列表快速切换、步骤放大弹窗、路径比较视图（2-3 条并排）。完成桌面/平板/移动端三端适配，统一组件动效与微交互。深色主题系统。

Task 7-9

第 4 轮 · RDKit 引擎集成

引入 rdkit.js WebAssembly，构建基于 SMARTS 子结构匹配的新引擎。实现 moleculeSmiles 映射库、full molecular analysis（分子式/分子量/官能团/环系/立体化学）。

Round 4

第 5-6 轮 · 环系断键 + 立体化学

retro-DA、芳环取代逆向等环系断键策略。完整立体化学处理（CIP 优先级 R/S 标记、E/Z 双键几何、去立体 SMILES 生成）。

Round 5-6

第 7 轮 · 规则扩展 + 路线对比增强

杂环合成、过渡金属催化、立体选择性反应、生化转化等规则扩展。PathNavigator 滚动按钮、路线对比与评分增强。

Round 7

🎯 规则引擎重构 — 迈向泛化推理

移除固定模板依赖，改为基于 200+ SMARTS 规则的动态推理。重构官能团识别模块，新增推理记录数据结构、可行性评估报告、试剂知识库，重塑 UI 展示。
