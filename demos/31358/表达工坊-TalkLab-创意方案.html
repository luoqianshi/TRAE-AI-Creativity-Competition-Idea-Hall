1. 产品定位

🎯

一句话定位

把"表达练习"变成像学英语一样可拆解、可重复、可追踪的日常训练：先有方法，再有反馈，最后才有进步。

🧭

解决的核心痛点

表达力偏弱的人最需要的不是"被指出问题"，而是"被给一个能照着做的结构"，再加上低压力的练习环境。

💡

灵感来源

从"面试说不出话、汇报逻辑混乱、当众发言紧张"这些真实困境出发，用系统化训练补齐表达的"基本功"。

📱

产品形态

以微信小程序为主入口，提供"剧本 → 脚本 → 录音 → 复盘 → 再练"的完整闭环训练。

2. 产品核心理念（方法优先，智能藏在背后）

📐

① 先给"结构"

所有表达都可以被结构化：STAR / PREP / 金字塔原理 / 问题-方案-证据。先给用户一套能照抄的框架。

✏️

② 再给"脚本"

不是让用户"随便说"，而是让用户"先照脚本说，再逐步脱稿说"。降低启动门槛。

🔁

③ 反复"迭代"

同样一个话题，鼓励用户反复录，直到达到自己满意的版本；保存最佳版本做纵向对比。

4. 核心功能

🗂️

情景剧本库

按行业、岗位、场景（面试问答 / 项目汇报 / 即兴演讲 / 会议发言 / 日常沟通）分类的结构化剧本。

✍️

表达脚本模板

每一个话题都有可填写的结构模板，用户照模板填好自己的脚本，降低"说什么"的焦虑。

🎙️

录音式练习

照着脚本录音，再脱稿录音，支持倒计时、提示卡、重录，过程零压力。

🧭

结构化反馈

语音转文字后，提供结构是否完整、逻辑是否清晰、是否有关键证据、语气是否合适等方向的结构化点评。

📈

个人成长曲线

记录每一次练习，看自己在结构、简洁、证据、节奏等维度的长期走势，进步可视化。

🏆

任务与打卡

每日一题、30 天坚持、主题周（面试周 / 汇报周），游戏化维持长期使用。

📝 脚本反馈示例

原文（片段）："嗯……我就是一个比较有责任心的人，做事情还行，应该能胜任。" 结构分析：缺少"情境 / 任务 / 行动 / 结果"任一要素，证据缺失，说服力弱 重写建议："在上一份工作（情境），我负责新功能上线后的用户留存任务（任务）；我用数据分析找出流失节点并设计了召回机制（行动）；两个月内留存从 62% 提升到 78%（结果）。" 可操作建议：下次练习前先把这四个要素写清楚再录音，并刻意放慢前 20 秒开头的内容，再重录对比听感。

9. 价值与意义

⚡

效率提升

过去"想练表达却不知道怎么练"的人，现在 5 分钟就能完成一次"选情景 → 填脚本 → 录音 → 看反馈"的完整训练。

🌍

社会价值

为表达力偏弱、缺少练习机会的群体提供低门槛练习空间；可作为高校就业指导和企业内训的素材。

💰

商业价值

C 端：付费剧本库、高级分析和会员订阅。B 端：高校、企业批量训练授权、情景定制与数据报告。

♿

包容性

文字 + 语音 + 图表多种信息呈现方式，适合不同学习习惯的用户；对社恐、表达焦虑群体尤其友好。

扩展：视频表达训练、行业定制剧本、跨端 App / H5

11. 为什么现在要做这件事

需求真实且普遍

"不会表达、当众紧张"是年轻人普遍的困扰，学校没有系统课程教这件事。

方法可被系统化

表达有成熟的结构方法（STAR、PREP、金字塔原理），只是缺少把它们产品化。

产品具有长尾价值

一次练完"表达"之后，可以自然延展到写作、谈判、销售等软技能。

与教育 / 企业双通道

C 端提供高频练习，B 端提供批量训练与数据洞察，双向协同。
