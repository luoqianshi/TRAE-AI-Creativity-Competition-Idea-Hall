创意名称：宠物数字星球

Pet Digital Planet — 让每一只宠物拥有属于自己的3D数字星球和AI生成的沉浸式专属小屋

🔥

想解决什么问题

宠物主人缺乏一种有温度、有仪式感的方式将宠物的数字记忆具象化。照片和视频只是平面的记录，无法呈现宠物独特的"世界"和"家"的感觉。更痛的是，宠物离世后，主人缺少一种沉浸式的纪念方式——如果能为去世的宠物创建一个数字分身，让它以3D形态永久陪伴，这份爱与记忆就不会随时间消散。

💡

为什么会想到做这个

灵感来自两个交汇点：一是宠物经济爆发式增长，"毛孩子"已成为家庭成员，但数字产品远远跟不上情感需求；二是 World Labs Marble 等 AI 3D 生成技术的突破，让"为宠物创造一个世界"从想象变为现实。而最触动我们的，是看到无数宠物主人在宠物离世后的悲伤——如果能给去世的宠物一个数字分身，让它永远住在自己的星球上、自己的小屋里，这份陪伴就能跨越生死。

💻

大概是什么产品

一个 Web 应用 + 小程序：用户上传宠物照片/视频，AI 自动生成宠物专属3D数字星球和沉浸式3D小屋，支持社交互动、虚拟装饰和永久纪念。对于去世的宠物，系统可生成数字分身——一个以3D形态永久居住在专属星球上的AI宠物，让主人随时可以"走进去"陪伴。

🌟

核心愿景

让每一只宠物都拥有一颗星球，让每一份爱都能跨越生死。不只是数字纪念，而是一个可以"走进去"的、充满宠物个性的3D世界——你的狗狗有壁炉和网球的小屋，你的猫咪有樱花和攀爬架的雅致空间。即使宠物已经离开，它的数字分身依然在星球上等你回家。

👥 TARGET USERS

目标用户及痛点

三类核心用户群体，共同的渴望：让宠物的存在被看见、被记住

🐾

宠物主人

日常记录 / 生日纪念 / 离世缅怀

手机里存了上千张宠物照片，却没有一个地方能让这些记忆"活起来"。想要给宠物一个有仪式感的数字家园，而不是冰冷的相册文件夹。

🧑

宠物社区爱好者

社交分享 / 宠物交友 / 社区互动

现有的宠物社交只是发图点赞，缺少沉浸感和互动深度。想要一个能让宠物"住"进去的3D空间，和其他宠物主人的星球产生连接。

🙏

宠物缅怀者

宠物离世 / 数字分身 / 永久陪伴

宠物离开后，只有照片和视频可以回顾。缺少一个可以"走进去"的空间，去感受宠物曾经的存在。更渴望给宠物一个数字分身，让它以3D形态永远住在自己的小屋里，随时可以回去陪伴——这份爱不会随时间消散。

🚀 TECH ADVANTAGES

技术优势

六大核心技术壁垒，构建宠物3D数字世界的护城河

🌍

World Labs Marble 3DGS 引擎

全球首批接入 World Labs Marble API 的应用，通过文字/图片/视频直接生成3D高斯泼溅（3DGS）世界。相比传统3D建模，生成速度提升100倍，真实感远超多边形渲染，支持 Web 端实时浏览。

🦾

AI 数字分身技术

基于宠物照片生成3D数字分身，支持动作捕捉和AI行为模拟。去世的宠物可以数字形态永久"活"在自己的星球上，保留生前习惯动作和性格特征，实现跨越生死的陪伴。

⚡

Spark 2.0 实时渲染

集成开源 Spark 2.0 渲染器，基于 Three.js + WebGL2 实现浏览器端3DGS流式加载与渲染。无需安装任何插件，用户打开网页即可沉浸式浏览3D世界，零门槛体验。

🔗

WebSocket 实时社交

Socket.io 驱动的实时通信系统，支持星球间即时聊天、宠物互动、访客通知。宠物主人可以邀请朋友参观自己的星球，实现真正的3D社交体验，而非简单的图文社区。

🏠

8物种专属3D小屋预设

针对犬、猫、鱼、鸟、兔、爬行、仓鼠等8种宠物物种，精心设计专属室内3D场景 prompt。每种小屋从配色、家具到氛围都贴合物种特征，一键生成即可获得高度个性化的3D空间。

🌀

Monorepo 全栈工程化

pnpm workspace + 共享包架构，前后端代码统一管理。TypeScript 全栈类型安全，API 自动降级机制（真实API → 模拟模式），确保服务稳定性。可快速扩展为小程序和 App。
