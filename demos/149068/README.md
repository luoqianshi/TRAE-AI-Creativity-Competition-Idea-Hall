## 一、产品简介

**灵犀阁·灵感合璧录** 是一款让普通日常多一点点新鲜感和温度的小工具。

你随手记下的每一件"改天再去做"的小事，都可以被重新打捞起来。它会把你的两三个念头，结合此刻的时间、预算、天气、心情和同行的人，融合成一份具体、好玩、今天就能开始的生活方案。

- **不是推荐更多选择**，而是把你自己的念头重新组合；
- **不是抽象的灵感清单**，而是一份带有"为什么此刻适合""准备哪些小物""下一步做什么"的具体方案；
- **不是大模型生成**，而是一套不依赖网络的本地规则引擎，确保任何时候都能用。

**目标用户**：会在咖啡馆发呆时想起一件事、又把它遗忘的人；想要把恋人关系、家中周末、独处时间变得更有记忆点的人；喜欢用小仪式感对抗重复日常的人。

## 二、如何打开

### 1. 直接双击 index.html（推荐）

```bash
# macOS
open index.html
# Windows
start index.html
# 或在文件管理器中双击 index.html
```

**完全离线运行**：第一次打开也不需要联网；断网后双击 `index.html` 同样可以正常体验。

### 2. 本地起一个静态服务器（如需）

```bash
# Python 3
python3 -m http.server 8765
# 然后访问
open http://localhost:8765/index.html
```

> 因为脚本里使用了 `localStorage`，浏览器对本地文件的权限通常也会放行；如遇限制，用第 2 种方式起静态服务即可。

## 三、零外部依赖说明

- **不使用任何外部 CDN** —— 全部 CSS / JS 写在同一个 `index.html` 中。
- **不调用任何外部网络资源** —— 页面不发起任何网络请求。
- **不使用外部字体** —— 字体栈只引用系统字体（PingFang SC / 思源宋体 / 苹方 / 宋体等）。
- **不依赖任何第三方库** —— 分享卡由浏览器原生 Canvas 在本地生成。
- **Favicon 内嵌** —— 用 `data:` URI 内嵌 SVG 图标，浏览器不会请求外部 favicon.ico。

> 因此：**完全离线运行**。双击 `index.html` 即可在断网状态下完整体验所有功能。

## 五、数据保存方式

- **本地存储**：所有灵感、藏阁、状态、备注统一保存在 `localStorage` 键 `lingxi_state_v1`。
- **不上传任何内容**：页面无任何后端调用、无埋点、无第三方依赖，离线也能用。
- **首次使用引导** 状态保存在 `lingxi_onboarded`；**主题模式** 保存在 `lingxi_theme`。
- **导入 / 导出**：底部"导出全部数据 (JSON)"会下载一个带时间戳的 JSON 备份；"导入 JSON 备份"可恢复。
- **清空**："清空全部本地数据"会弹窗二次确认，建议先导出。

> 切换设备、清除浏览器数据、使用无痕模式都可能导致本地内容丢失，请提前导出。

## 九、已知限制

- **方案生成是本地规则引擎**，不是 LLM 生成，因此方案风格更稳定可控，但不会无限惊喜。同一组条件下，多次"再变化一次"能给出 2—3 个差异较大的版本。
- **单设备本地存储**：没有云同步。换设备请用"导出 → 导入"做迁移。
- **多语言**：当前仅中文 UI。
- **PWA / 安装到桌面**：未做 manifest.json；可作为后续迭代方向。
- **分享图导出** 使用浏览器原生 Canvas，不支持嵌入字体（系统字体），在不同操作系统上排版略有差异。
