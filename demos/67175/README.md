## ✨ 核心玩法

1. **输入发射** — 在输入框中输入你想说的话，按 `Enter` 发射
2. **气球膨胀** — 文字像子弹一样飞向气球，气球逐渐变大、发光、摇晃
3. **自动模式** — 点击"😤 骂不动了，你替我骂"开启自动连发
4. **目标锁定** — 在右侧输入名字，所有发射自动带上目标
5. **大爆炸** — 30 秒后气球爆炸，碎片飞溅 + 彩带飘落
6. **重新开始** — 点击屏幕重置，循环释放

## 🎨 创意背景

现代人压力越来越大，但很多人没有合适的情绪宣泄渠道：
- 社交媒体不敢发，怕影响形象
- 找人倾诉，对方不一定有空
- 压抑情绪对身心健康有害

**「骂了么」** 提供了一个即时、零成本、有趣的情绪出口。通过游戏化的交互设计，让情绪宣泄变得可视化、可感知，给用户带来即时的爽感释放。

名字致敬"饿了么"，一听就知道是干嘛的，自带梗属性，传播性极强。
