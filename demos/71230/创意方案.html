我们想解决的问题

据统计，中国家庭每年浪费的药品价值超过 1500 亿元，其中因过期而丢弃的占绝大多数。 多数家庭药箱常年无人整理，"找不到药"和"不敢吃"成为日常烦恼。

📦

翻箱倒柜找药，浪费宝贵时间
🔁
重复购药
忘记家里有，又买了一盒
⚠️
安全隐患

3

解决方案：四大核心功能

一站式家庭药品管理体验：拍一下就识别，临期主动提醒，从此告别"过期药"。

📷
AI 智能扫描
对准药盒一拍，自动识别
  • 药品名称自动填充
  • 有效期精准识别
  • 支持 12 种日期格式
  • 无需手动输入
⏰
过期智能提醒
3 档状态分级，主动告知
  • 绿色：正常 (90天以上)
  • 橙色：临期 (30天内)
  • 红色：已过期
  • 首页/微信多渠道触达
📋
家庭药箱
一站式药品清单管理
  • 分类筛选与搜索
  • 智能排序：过期优先
  • 扫码快速查看
  • 数据本地存储
📊
用药统计
看清家中药品全景
  • 总数 / 临期 / 过期
  • 按分类统计
  • 采购时间线
  • 避免重复购药

技术实现方案

Taro 4.x 跨端框架 React 18 TypeScript SCSS Modules Context API 状态管理 dayjs 日期处理 本地存储 (Storage) OCR 文字识别 (可扩展) 云函数药品数据库
