01 / 目标用户及痛点

竞品分析正在被 不可辩护的结论 拖累。

PAIN · 01

LLM 幻觉无法追溯

大模型生成的竞品分析常常编造价格、功能、用户评价。决策者拿到一份漂亮报告，却无法验证任何一条结论的来源。

"这个结论从哪来的？"——没人能回答。
PAIN · 02

信息碎片化无结构

官网、搜索结果、用户评论散落各处。产品经理手工拼凑证据，维度遗漏、来源冲突难以发现，决策依据脆弱。

同一竞品三个价格，信哪个？
PAIN · 03

决策无法自我修正

传统工具一次性输出，错了就错了。没有复核机制，没有记忆回流，同类错误在下一份报告里重复出现。

生成完就结束，没有第二次机会。
面向谁
  • A产品经理与创业者——新品立项前需要快速、可辩护的竞品扫描
  • B投资分析师——尽职调查时需要结构化整理竞品情报
  • C市场与战略团队——营销战役前生成 Battlecard，明确对位策略
  • D研发负责人——产品迭代中基于最新证据调整功能优先级
在什么场景下用
  • 立项前· 扫描竞品功能、定价、用户反馈，找到差异化机会点
  • 迭代中· 基于最新市场证据，调整产品定位和功能优先级
  • 投资前· 结构化整理竞品情报，生成可辩护的决策建议
  • 战役前· 生成 Battlecard，明确己方优势和对位策略
02 / 创意方案 · 七节点闭环

一条 证据闸门 串联的流水线，每一步都可观测。

01

Planner 规划器

拆解竞品范围与输入来源，生成可执行的 ResearchPlan。有 URL 映射到对应竞品，无 URL 为每个竞品生成搜索任务，评论生成聚类任务，图片生成识别任务。

输入 · 产品目标 + 竞品 + URL + 评论
输出 · ResearchPlan
02

Research 并行调研器

基于 ResearchPlan 并行执行 URL 抓取、搜索引擎补搜、评论聚类、图片识别等多源采集任务。单任务失败不阻塞整体，记录 warning 事件。

并发 · ThreadPoolExecutor · 4 workers
适配器 · URL / Search / Comment / Image
03

Evidence Scorer 证据评分器

对采集到的证据进行三维评分并转换为结构化 Claim。所有评分收敛到 [0,1]，标记不可信来源，为下游决策提供可量化的证据质量。

维度 · credibility / relevance / quality
阈值 · quality ≥ 0.5 · credibility ≥ 0.4
04

Coverage Gate 覆盖闸门 · 质量关卡

检查证据是否覆盖所有必达维度。未达标且预算允许时，用 gap_queries 触发补搜回环（最多一轮），research_round 防止无限循环。

通过条件 · 加权覆盖率 ≥ 0.7
回环 · research_round < 1 时补搜
05

Conflict Resolver 冲突裁决器

检测同竞品同维度的证据冲突——价格不一致、功能有/无对立、抓取成功/失败对立。按 credibility_score 排序，保留高可信度证据。

检测类型 · 价格 / 功能 / 抓取状态
裁决策略 · 按可信度排序保留
06

Writer 决策包写作器

基于证据和策略生成结构化决策包：定位建议、MVP 优先级、定价洞察、Battlecard。强校验所有 evidence_ids 必须真实存在，无证据不编造。写入决策记忆块。

产物 · positioning / mvp / pricing / battlecard
校验 · evidence_ids 强校验
07

Reviewer 复核器 · 收口节点

规则校验 + LLM 智能复核。校验引用合法性、维度匹配、空值检查。低分自动触发 Writer 重写（Reflexion），高分自动发布。最多 1 轮修复，保证任务可收敛。

发布 · score ≥ 0.8 & risk=low
重写 · score < 0.6 → Writer 回流
03 / 核心能力

让决策 可追溯、可修正、可复用 的四个机制。

EVIDENCE

三维证据评分

每条证据从可信度、相关性、质量三个维度量化打分，收敛到 [0,1]。来源类型、域名可信度、HTTPS、新鲜度、关键词命中都参与计算。

credibility relevance quality
MEMORY

决策记忆回流

决策包拆分为记忆块写入索引，新一轮生成时召回历史决策、冲突记录、Reviewer 反馈。实现"越用越准"——同类错误不在下一份报告重复。

recall = lexical·0.58 + direct·0.24 × boost
RAG

混合检索融合

采用 RRF（Reciprocal Rank Fusion）融合向量语义检索与词面检索。通过排名而非分数融合，无需归一化，天然偏好既有关键词匹配又有语义相关的结果。

RRF(d) = Σ [1 / (k + rank_i(d))] · k=60
REFLEXION

受控重写闭环

Reviewer 低分时自动触发 Writer 重写，prompt 注入复核意见和幻觉风险提示。最多 1 轮修复避免死循环，旧版本标记 superseded，完整历史可追溯。

score < 0.6 → rewrite max 1 round
