# 完整演示功能说明

## 功能概述
点击"一键演示完整过程"按钮，系统将自动演示从清晨到深夜的大气受热完整过程，包括：

### 演示时间轴（40秒）

1. **清晨日出（0-4秒）**
   - 太阳高度角：15° → 45°
   - 时段：白天
   - 模式：太阳暖大地
   - 说明：太阳高度角低，短波辐射穿过大气路径长，削弱多，地面获得能量少

2. **上午升温（4-8秒）**
   - 太阳高度角：45° → 80°
   - 时段：白天
   - 模式：太阳暖大地
   - 说明：太阳升高，短波辐射增强，地面吸收能量增多，温度开始上升

3. **正午最强（8-12秒）**
   - 太阳高度角：80° → 75°
   - 时段：白天
   - 模式：太阳暖大地
   - 说明：太阳高度角最大，短波辐射最强，地面吸收大量能量，温度快速升高

4. **地面辐射增强（12-16秒）**
   - 太阳高度角：75° → 70°
   - 时段：白天
   - 模式：大地暖大气
   - 说明：地面升温后，以长波辐射形式向大气传递热量

5. **大气逆辐射（16-20秒）**
   - 太阳高度角：70° → 45°
   - 时段：白天
   - 模式：大气还大地
   - 说明：大气吸收地面长波辐射后升温，向下发射大气逆辐射

6. **下午太阳降低（20-24秒）**
   - 太阳高度角：45° → 20°
   - 时段：白天
   - 模式：综合展示
   - 说明：太阳高度角降低，短波辐射减弱，地面获得能量减少

7. **傍晚过渡（24-28秒）**
   - 太阳高度角：20° → 5°
   - 时段：傍晚
   - 模式：削弱作用实验
   - 说明：太阳接近地平线，短波辐射急剧减弱，地面长波辐射成为主要热源

8. **夜晚开始（28-32秒）**
   - 太阳高度角：5°
   - 时段：夜晚
   - 模式：保温作用实验
   - 说明：无太阳短波辐射，地面持续向外发射长波辐射，温度下降

9. **深夜保温效应（32-36秒）**
   - 太阳高度角：5°
   - 时段：夜晚
   - 模式：保温作用实验
   - 说明：大气逆辐射将部分热量返还地面，减缓地面降温速度

10. **综合总结（36-40秒）**
    - 太阳高度角：5°
    - 时段：夜晚
    - 模式：综合展示
    - 说明：完整过程：太阳暖大地→大地暖大气→大气还大地，三环耦合形成地球温度系统

## 动态响应效果

### 1. 太阳动态变化
- **位置变化**：太阳高度角从15°升到80°再降到5°，太阳位置实时升降
- **亮度变化**：辐射强度S影响光晕大小和透明度
- **颜色变化**：傍晚自动偏红（0xff8844）
- **可见性**：夜晚自动隐藏

### 2. 地表温度变化
- **颜色偏移**：地面温度升高时偏红/橙，温度降低时偏蓝
- **时段亮度**：夜晚地表自动变暗
- **热辐射可视化**：温度越高，地表颜色越暖

### 3. 辐射箭头动态
- **太阳箭头（黄色）**：groundSolar↑ → 箭头越大越亮
- **地面箭头（橙色）**：groundLW↑ → 箭头越大越亮
- **大气箭头（紫色）**：atmoIR↑ → 箭头越大越亮

### 4. 物理数据实时更新
- **太阳辐射强度 S**：随时段和高度角变化
- **到达地面比例**：随云量、尘埃、高度角变化
- **地面长波辐射**：随温度变化
- **大气逆辐射**：随水汽、CO₂、云量变化
- **地表温度 T地**：动态计算
- **近地面气温 T气**：动态计算
- **昼夜温差**：实时显示

### 5. 大气层可视化
- **颜色变化**：水汽/CO₂↑ → 从淡蓝变深紫（温室效应）
- **透明度变化**：温室气体↑ → 大气层越明显
- **时段变化**：夜晚自动变暗

### 6. 云层动态
- **数量变化**：云量滑块变化时自动重建云层
- **透明度变化**：云量越大越不透明，夜晚自动变暗

### 7. 尘埃粒子
- **透明度变化**：尘埃浓度↑ → 粒子越明显
- **大小变化**：浓度↑ → 粒子越大
- **动画效果**：粒子缓慢飘动

## 物理原理体现

### 科学口诀
- **太阳定入口**：太阳高度角和云尘决定输入多少热量
- **地面定调性**：反照率+热容量决定热量如何转化释放
- **大气定存留**：水汽+CO₂决定热量能留存多久

### 三阶段过程
1. **太阳暖大地**：短波辐射穿过大气，大部分到达地面
2. **大地暖大气**：地面升温后以长波辐射加热大气
3. **大气还大地**：大气逆辐射将部分热量返还地面

### 瓶颈分析
- **沙漠**：锁不住（白天R地↑强，但R逆↓弱）
- **冰雪**：吃不进（反照率高，吸收少）
- **湖泊/森林**：三环通畅（热容量大，缓冲剧烈波动）
- **城市夜晚**：额外热源（蓄热释放）
