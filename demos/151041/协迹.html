产品定位

「协迹」是一款面向中小团队与个人办公场景的轻量化协作助手，融合任务管理、团队协作、数据统计与创意孵化四大能力。 以四象限法则组织任务，以番茄钟驱动专注，以共享链接打通协作，以创意工坊激发灵感——让每一份工作都有迹可循。

✨创新功能亮点

  • 🐈四象限+番茄钟融合：将艾森豪威尔矩阵与番茄工作法原生结合，专注与优先级双驱动。
  • 🐾猫咪成就体系：完成任务触发猫咪庆祝动画，连续打卡解锁猫咪徽章，让效率有温度。
  • 🌸智能建议引擎：基于任务负载与完成率，AI实时给出排程建议与专注提示。
  • 🎯创意提案闭环：从灵感→头脑风暴→结构化提案→投票→落地，一条龙创意孵化。
  • 🤝无感协作：短链分享+权限矩阵+版本差异，协作如呼吸般自然。

🛠️技术架构说明

前端层

Tailwind CSS 原子化样式 + 原生 JavaScript 交互，CSS conic-gradient 自绘图表，无外部图表库依赖。

数据层

localStorage 本地持久化，任务、便利贴、提案等数据自动同步保存。

交互层

原生 Drag API 实现便利贴拖拽，setInterval 驱动番茄钟，display 切换模块。

设计层

低饱和度清新配色（薄荷绿/天空蓝/暖珊瑚），圆角卡片+猫咪元素，响应式自适应。
