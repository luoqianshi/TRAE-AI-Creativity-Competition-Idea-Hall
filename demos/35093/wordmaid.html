THE PROBLEM

写文档时
AI 总是健忘

你刚在对话里告诉它张三的手机号，5 分钟后写合同时又得重查一遍。对话框式 AI 打断你的写作心流，传统 RAG 方案又要烧钱又要配服务器。

$ rag_setup --vector-db pinecone --embeddings openai
$ monthly_bill: $129.00 # 太贵了

割裂的对话框交互

在文档和对话框间反复复制粘贴，AI 还总是忘记前文背景。写一句话要切三次窗口。

RAG 成本与技术门槛

传统方案要接入大模型 API 并自建向量数据库，海量 Token 消耗，普通用户根本玩不转。

上下文失明

传统 AI 无法感知光标所在位置的上下文，补全内容常常破坏文档结构，需要大量手动修改。

CORE FEATURES

三个动作
让记忆浮现

光标在哪里，记忆就在哪里。无需对话框，无需复制粘贴。

01 · INFO RECALL

信息自动回填

基于 Trae 此前记忆的用户信息，在文档表格中输入"张三"，按 Tab 键，自动补全张三的手机号、邮箱、职位——只要 Trae 见过。

// 输入
张三 → 138****5678 / zhangsan@...
02 · FLOW CONTINUE

长文连贯续写

撰写项目周报时，输入"本周进度"，插件根据 Trae 记忆中本周的代码提交记录或之前的对话内容，自动补全工作总结。

// 输入
本周进度 → 完成 API 重构, 12 commits...
03 · STYLE ALIGN

格式与风格对齐

续写一段话时，插件读取光标前文的语气、用词习惯和排版结构，直接给出符合当前文档语境的补全建议，不会破坏既有风格。

// 检测
tone: 正式 · format: 列表 → 对齐输出
