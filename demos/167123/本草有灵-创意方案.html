创意名称 + 创意介绍

本草有灵 —— 让年轻人愿意主动亲近的中医古籍
想解决什么问题
《本草纲目》等中医古籍以文言文与专业术语为主，大众读不懂；现有传播多为静态图文，缺少适合社交分享与年轻人参与的载体。
为什么会想到做这个
国风审美与非遗内容正在年轻群体中回潮，但「看得懂 + 愿意传播 + 能互动」的中医科普产品几乎空白，文化传播机构也缺可复用的内容底座。
大概是什么产品
一款微信小程序（兼容 H5/Web）：以本草详情为核心，配套国风卡片/短片工坊、抓药配伍小游戏、AR 针灸铜人与运营审校后台，形成「内容活化 + 社交传播 + 互动体验」的完整闭环。

目标用户及痛点

谁在用 · 什么场景 · 现在有多不方便

国风 / 传统文化爱好者

18–35 岁年轻人，喜欢中式审美与非遗内容，愿意分享有质感的图文，但缺少「既好看又有知识含量」的中医内容来源。

泛健康求知用户

想轻松了解本草与养生常识，却被古籍的文言门槛和真伪难辨的碎片信息劝退，需要可追溯、有审校的可信内容。

文化传播 / 文旅机构

学校社团、博物馆、文旅展馆、非遗活动组织者，需要可落地、可复用的互动内容底座，而非一次性的「看展式」体验。

在什么场景使用
碎片时间刷手机、课堂/展馆互动教学、节气节点做文化传播、社交平台分享打卡。
当前痛点
古籍读不懂、内容不敢信、体验不好玩、机构没抓手——四道墙把年轻人挡在中医文化之外。
我们如何破墙
白话解读拆懂门槛、来源审校建立信任、游戏与 AR 提供参与感、后台让机构可自主运营。
叁

价值与意义

社会价值 · 效率提升 · 商业价值
🌿

社会价值

降低中医古籍的理解门槛，推动《本草纲目》等非遗内容在年轻群体中的传播与传承，让传统文化「活」在日常。

⚡

效率提升

「理解→分享→体验」链路目标让用户 30 秒看懂一味草、60 秒完成首次分享或体验，模板化生成大幅降低优质内容产出成本。

🏛️

商业价值

为学校、文旅、博物馆、非遗活动提供可扩展的内容与互动底座，形成 B 端合作与品牌记忆点，具备可持续运营空间。

⚕️ 合规边界：本产品定位为「古籍知识整理与文化科普」，不提供在线问诊、个体化诊断、处方或用药建议。所有对外内容均可追溯到古籍出处与审校状态，并附带风险提示。

目前已实现的内容

四端已跑通，核心功能可体验
一期

首页与节气推荐

节气专题、今日本草、热门卡片流与快捷入口。

一期

本草检索与详情

109 味结构化词条；原文摘录、白话解读、性味归经知识卡、典故推荐。

一期

国风卡片工坊

选模板 + 编辑文案，一键生成适合朋友圈分享的图文卡片。

二期

国风短片工坊

按脚本模板生成分镜 storyboard 与短片，适合短视频传播。

二期

抓药配伍小游戏

3 类关卡（按归经 / 配伍 / 场景），拖拽药材入屉，服务端判定配伍。

二期

个人中心

收藏、最近浏览、作品记录跨页数据回流。

三期

AR 针灸铜人

14 条经络，可旋转缩放 3D 铜人，点击热点弹「经络+本草+知识卡」。

三期

归经可视化入口

详情页归经标签可点击，透传经络与本草进入 AR 铜人，形成闭环。

运营

内容审校后台

词条导入、白话审校、模板管理、发布状态门控与数据分析。

伍

技术实现

小程序优先、Web 兼容的解耦架构

客户端 · Taro 4 + React 18

小程序 / H5 双端；SCSS Modules + Zustand + TanStack Query。

运营后台 · Vite + React + Ant Design 5

词条导入、审校任务台、模板管理。

AR 子应用 · three + R3F + drei

H5 3D 铜人，进场预取经络热点，点击本地命中知识卡。

服务端 · NestJS 10 + Prisma

MVP 采用 SQLite 快速跑通；目标形态 PostgreSQL 16 + pg_trgm 全文检索。

pnpm workspace 单仓 统一 /api/v1 接口 发布状态门控（reviewStatus + isPublished） 游戏判定在服务端（不下发答案标记） 全链路来源与风险提示字段 H5 分包预加载 · 首屏 < 1.5MB
