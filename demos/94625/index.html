核心功能

全方位语音交互能力

从呼入到呼出，从语音识别到语音合成，打造完整的 AI 语音交互体验

呼入通话

用户可通过普通电话拨打配置的中继号，自动连接到 AI Agent，实现智能语音交互。

  • 支持 PSTN 电话接入
  • 智能路由分配
  • 来电显示

呼出通话

AI Agent 可主动拨打用户电话，实现通知、提醒、回访等业务场景。

  • 批量外呼支持
  • 智能拨号策略
  • 通话记录追踪

语音识别 (ASR)

实时将用户语音转换为文本，支持多种语言和方言，准确率高达 99%。

  • 实时流式识别
  • 多语言支持
  • 降噪处理

语音合成 (TTS)

将 AI Agent 的文本响应转换为自然流畅的语音，支持多种音色和语速。

  • 多种音色选择
  • 情感语音
  • 实时合成

全模态模型支持

支持多模态输入输出，结合视觉、语音、文本等多种信息进行智能交互。

  • 视觉理解
  • 多轮对话
  • 工具调用

灵活部署方案

支持本地私有部署和云服务部署，满足不同场景的安全和性能需求。

  • 本地 Docker 部署
  • 云服务 API
  • 混合部署
