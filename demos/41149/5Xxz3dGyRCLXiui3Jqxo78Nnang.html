消费者在购买服装时面临的四大核心痛点

品牌贴标溢价

同样质量的衣服，贴上知名品牌标签后价格翻倍，消费者为品牌溢价买单而非产品本身。

∞

图案同质化

市面上的印花设计千篇一律，难以找到符合个人审美的独特图案，缺乏个性表达。

?

文化误解

许多服装上的外文印花含义不明，可能造成尴尬或文化误解，穿者无意识中传递错误信息。

!

撞衫焦虑

快时尚批量生产导致同款泛滥，走在街上很容易"撞衫"，失去独特性和自我表达。

// 用户故事

来自真实用户的场景与需求

USER_STORY_01
小明的大学生身份认同

开学第一天，想穿出独特风格给新同学留下深刻印象

// 需求

设计一件印有自己原创插画或喜欢的歌词的T恤

// 痛点

淘宝上的印花T恤要么烂大街，要么价格虚高

// 期望

用自己的审美定义穿着，不再"泯然众人"

USER_STORY_02
阿杰的情侣装创意

纪念日想给女友一个特别的礼物

// 需求

设计一套情侣装，有两人的专属暗号或图案

// 痛点

网上情侣装太俗套，定制网站操作复杂价格高

// 期望

用最小的成本创造最有心意的礼物

USER_STORY_03
旅游聚会小分队

聚会旅行，想要有统一的"仪式感"，拍照出圈有意思

// 需求

设计一件印有共同元素的卫衣（梗、图案、口号）

// 痛点

网上买的一致款太普通，手工定制又太贵太麻烦

// 期望

用一件衣服承载友情记忆，成为独特纪念

USER_STORY_04
Tony的社群身份标签

参加音乐节，想要一身吸睛的装备

// 需求

设计一件融合街头文化和音乐元素的限定款T恤

// 痛点

市面上买不到符合亚文化审美的服装

// 期望

通过穿着找到同好，建立社群身份认同
