一、创意概览

创意名称：VibeVoice — Agent 全程语音化协作插件

想解决什么问题：在 VibeCoding 场景下，开发者与 AI Agent 的协作多以"盯屏+鼠标点击"为主，Agent 完成阶段性任务或需要决策时，用户必须主动回头查看屏幕才能继续；长时间盯着 IDE 容易疲劳，也打断了心流。

为什么会想到做这个：在使用 TRAE 等 AI IDE 编程时，我经常遇到 Agent 完成一个长任务后我不在屏幕前，导致下一个环节被推迟。灵感来源于车载导航和智能音箱在用户视线离开时仍能主动汇报的体验。

大概是什么产品：一款运行在 IDE / Agent 平台上的浏览器/桌面插件，Agent 阶段性工作结束或需要决策时通过语音主动播报，用户通过语音回复或选择方案，Agent 接收后继续，全程无需手离开键盘、视线离开屏幕。

三、产品形态与核心流程

产品形态

浏览器插件 + 桌面客户端（Electron）+ 可选硬件按键，支持与主流 AI IDE（TRAE、Cursor、Copilot）以及自定义 Agent 平台对接。

核心交互流程

1. Agent 完成任务 → 2. 触发语音播报 → 3. 用户语音回复 → 4. Agent 继续执行

对话示例

🎙️ VibeVoice：已完成用户登录模块的开发，共改动 6 个文件，需要您做一次确认：是采用 JWT 还是 Session 方案？
用 JWT，记得加 refresh token
🎙️ VibeVoice：好的，已切换至 JWT 方案并补充 refresh token，接下来执行接口联调，预计 1 分钟。
