小氢 Ballo

小 氢 · 会 飞 的 家 里 小 管 家

一颗轻飘飘的"小气球"，飘到家里每个角落看你想看的地方。它会默默记住全家空间，帮你照看老人小孩、找钥匙、看煤气灶，像家里一个会飞的温柔小管家。

认识小氢 看看小氢会什么
THE PROBLEM

为什么装了摄像头，还是不放心？

固定摄像头有死角，多个设备各管各的，真的要看一眼时永远差一个角度。

📷

固定摄像头有死角

装在客厅看不到卧室，装在走廊看不到厨房。想看某个角落得手动转云台，转了也未必看得到。全屋无死角覆盖要装五六个摄像头，成本高还侵犯隐私。

👴

老人小孩独自在家

父母上班，家里只剩老人和小孩。老人摔倒了、小孩爬到危险地方了，固定摄像头拍不到，等发现时已经晚了。每周都有"早知道就好了"的瞬间。

🔌

智能家居各自为政

门锁是门锁，扫地机是扫地机，煤气灶报警器是另一个 App。设备之间不联动，出了事要一个个查，家里像一盘散沙，谈不上"智能"。

🔍

找东西全靠翻

钥匙放哪了？遥控器呢？老人的药盒呢？翻箱倒柜半小时找不到。没有一个系统能帮你"看一眼"家里，定位物品位置。

THE SOLUTION

让摄像头变成家里的小可爱

小氢是什么？

小氢是一颗粉嘟嘟、圆乎乎的"会飞的小管家气球"。它头上戴着一顶轻盈的安全小气囊，里面装着氦气，让它能像氢气球一样温柔地浮在空中；小尾巴装着小小的矢量推进器，可以让它轻巧地飞到客厅、卧室、厨房、玄关……家里的每个角落。

它没有冷冰冰的金属棱角，机身是柔软的抗静电材质，碰一下也不会伤到老人小孩和小宠物。它会默默记住家里每个房间的样子，认得出爷爷、奶奶、宝宝、还有家里的狗狗，会说"客厅的窗没关哦"、"奶奶在厨房站了 20 分钟啦"……它不只是摄像头，它是家里一个会飞的、贴心的、暖呼呼的小伙伴。

轻盈充气升力 圆萌外型 全屋三维建模 家人识别 语音小贴士 智能家居联动 安静省电 自动回充
CORE FEATURES

小氢的六个小本领

从认路找家到守护安全，从省电回窝到联动家电，全方位照顾你和家人。

1

空间感知与三维建模

SPATIAL PERCEPTION & 3D MAPPING
✓

全屋自动扫描建模：小氢轻轻飞一圈，悄悄在脑袋里画出家里每个房间的立体地图——客厅多大、卧室在哪、家具怎么摆，全记得清清楚楚。

✓

可移动区域划分：会自动避开障碍物和家人，规划安全的飞行路线，不会撞到家具和人，安安静静地飘。

✓

房间与家具识别：认得出卧室、客厅、厨房、卫生间，认得出床、沙发、餐桌、橱柜，让你说"客厅窗边"它就知道去哪。

2

智能语音交互定位

VOICE & SPATIAL POSITIONING
✓

听声辨位：你说"去客厅看看"，小氢就乖乖飞到客厅上方；你说"看看宝宝"，它知道宝宝在哪个房间。

✓

指令精准执行：结合位置理解指令意图，"关灯"自动关联当前所在区域的灯，不用一个个房间说。

✓

模糊位置秒懂：支持"客厅窗边""卧室床头柜"等模糊描述，结合三维地图自动定位准确位置。

3

异常检测与安全守护

ANOMALY DETECTION & SAFETY
✓

自动小巡检：按设定路线轻轻飘过每个房间，智能发现异常情况，不用你盯着屏幕看。

✓

多场景贴心识别：陌生人闯入、宠物异常、垃圾堆积、爷爷奶奶不小心摔倒，都能第一时间发现。

✓

分级小提醒：分提醒/警告/紧急三级，通过 App、短信、电话多通道告诉你，让关心不延迟。

4

自主续航与回充

AUTONOMOUS CHARGING & ENERGY
✓

自动回小窝充电：电量低时自己规划最短路线，乖乖飞回充电座，全程不用你操心。

✓

省电小算法：根据任务优先级智能分配电量，待机时低功耗模式，氦气升力 + 极小推力 = 长续航。

✓

智能补能规划：结合三维地图找最快充电路线，任务中断也能快速补能、继续守护。

5

智能家居小联动

SMART HOME INTEGRATION
✓

门锁小助手：听到门开声，自动飘到玄关看看，陌生人来敲门立刻提醒你。

✓

天气 + 窗户小贴士：结合天气预报和窗户开关状态，温柔提醒"快下雨啦，要关窗哦"。

✓

垃圾小哨兵 + 扫地机：看到地上有脏东西，自动喊扫地机器人来打扫，地面一直干干净净。

✓

煤气灶小管家：发现煤气灶开太久没关人，温柔提醒奶奶"汤好像煮好啦"，守护厨房安全。

6

更多贴心小功能

CUTE EXTENSIONS
✓

小环境监测：实时采集温湿度、空气质量、光照，告诉你"今天有点干，要加湿啦"。

✓

老人小孩看护：爷爷久坐不动、宝宝夜里异常起身，自动预警，让你不在家也安心。

✓

家电小账本：监控家电使用情况，告诉你哪个电器待机最耗电，帮你省电省钱。

✓

✓

找东西小能手：说"我的钥匙呢？"，小氢会飞到可能的位置扫一圈，帮你找到它。

✓

家庭小警卫：漏水、烟雾、异常声响，第一时间发现并告警，全天候守护你的家。

如果成功，10 颗星的小氢是什么样？

小氢会成为每个家庭的"暖心小守护"——它不需要你打开 App 去找它，它会在你需要的时候轻轻飘过来：奶奶起夜时默默跟过去看一眼，宝宝哭闹时飞过去瞧瞧再小声告诉你"没事，只是翻身"；出门前温温柔柔地提醒"窗户没关、煤气灶关了"。

它不是冷冰冰的监控设备，而是家里那个永远在的、轻飘飘的、有大眼睛有暖心的小可爱。当每个家庭都有一颗小氢，"出门不放心"这件事，就不存在啦。
