Pain Points

空气质量信息服务的三大短板

📌

预报时间粒度太粗

环保部门发布的AQI预报以24小时为单位，且是全市平均数。市民无法获知自己所住街道未来几小时的空气质量变化，更无法提前2-3天做规划。

👤

敏感人群被动暴露

哮喘患者、儿童、老人等敏感人群常常在出门后才发现AQI爆表，口罩没带、药没备。每年秋冬雾霾季，呼吸系统急诊量激增40%以上。

🏫

学校临时应对打乱安排

学校决定取消户外活动往往是在当天早上，家长措手不及、学生失望、老师也需临时调整课程。缺少提前2-3天的预警机制。

Solution

四步构建空气质量预测服务

01

数据采集

对接气象API（风速、温度、湿度、气压）和环保监测站实时数据，同步排放源清单信息

02

AI预测

LSTM+Transformer时序模型融合气象与排放特征，预测未来72小时逐小时AQI和6项污染物浓度

03

分级预警

AQI超阈值自动触发三级预警（蓝→黄→橙→红），推送健康建议和防护提醒至用户微信

04

主动防护

敏感人群提前3天收到空气质量趋势，学校提前规划室内外活动，环保部门提前发布应对措施

Core Features

六大核心功能

🌎

72小时逐小时预测

基于LSTM+Transformer模型，融合气象数据和排放源信息，预测未来72小时逐小时AQI和PM2.5、PM10、O3等6项污染物浓度。

📍

街道级精细化预报

突破传统全市平均预报模式，结合GIS空间插值和微尺度气象模型，实现街道/社区级别的空气质量精细化预报。

🔔

智能分级预警推送

AQI超阈值自动触发四级预警（蓝黄橙红），通过微信推送至订阅用户。支持按人群定制：儿童/老人/哮喘患者接收不同阈值提醒。

📚

个性化健康建议

根据用户健康状况档案（哮喘/过敏/心血管），自动生成差异化健康建议：是否适合户外运动、开窗通风建议、口罩佩戴等级。

📈

污染源追踪分析

结合排放源清单和风向轨迹，识别当前空气质量的主要贡献源（工业/交通/扬尘/区域传输），帮助环保部门精准施策。

📦

学校/机构专用看板

为学校、幼儿园、养老院等机构提供专用管理后台，提前3天规划室内外活动安排，一键生成应对通知模板。

Technical Architecture

技术架构与亮点

▶ 前端层（小程序 + Web）

  • 微信小程序 市民端，定位获取街道级预报
  • Vue3 Web管理后台，ECharts热力图
  • Leaflet GIS地图，街道级AQI色斑图

▶ 后端层（微服务）

  • Python FastAPI数据接口，异步I/O
  • Celery 定时任务：每小时拉取气象数据
  • Redis 预报结果缓存，热点数据加速

▶ AI层（时序预测）

  • LSTM 多变量时序预测核心模型
  • Transformer 注意力机制捕捉长程依赖
  • XGBoost 排放源贡献分解模型

▶ 数据层（多源融合）

  • MySQL 监测站历史数据存储
  • InfluxDB 时序气象数据，高效查询
  • API 对接气象局、环保局开放数据
