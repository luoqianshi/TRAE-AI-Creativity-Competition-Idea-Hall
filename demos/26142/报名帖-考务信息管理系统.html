💡 创意介绍

想解决什么问题？
在各类考试、开放日、招聘会、培训活动等场景中，考务人员经常需要为大量考生制作和发放体验证或参会证。传统的手动填写、逐个打印方式不仅效率低下，还容易出现信息错误、格式不统一、遗漏考生等问题，给考务工作带来极大的负担。

为什么会想到做这个？
在实际工作中，我亲眼目睹了考务老师在考试前几天通宵加班制作证件的场景——几百甚至上千个考生的信息需要手工录入、排版、打印，稍有不慎就会出错。这不仅效率低下，还容易引发考生不满。因此我希望用技术的力量，让考务工作变得更轻松、更精准。

大概是什么产品？
这是一个基于 React + Node.js 的 Web 应用系统，集成了考生信息录入、Excel批量导入、证件模板配置、照片自动裁剪、一键打印体验证/参会证、数据统计分析等完整功能，让考务管理从繁琐走向高效。

📝
Excel批量导入
支持三种导入方式，一键上传考生信息表，自动去重、身份证校验、性别推导
🖼️
智能照片裁剪
自动识别并裁剪为标准2寸证件照（135×189px），支持拖拽上传
🎨

体验证与参会证独立配置，可自定义字号、水印、字段显示顺序
🖨️
一键打印
A4排版自动适配，支持单个打印和批量打印，另存为PDF也没问题
📊
数据看板
考生统计、性别比例、场次分布、打印状态一目了然，数据可视化
🔧
动态字段
支持自定义字段，灵活适配不同考试/活动的信息录入需求

⚙️ 技术实现

本系统采用现代化的前后端分离架构，前端使用 React 构建响应式 SPA，后端使用 Node.js 提供 RESTful API，数据库使用轻量级 SQLite，支持一键部署。以下是主要技术栈：

⚛️ React 18 ⚡ Vite 5 📘 TypeScript 🎨 Tailwind CSS 🟢 Node.js 🚂 Express 🗃️ SQL.js (SQLite) 📊 ECharts 📝 SheetJS (xlsx) ✂️ react-easy-crop 🚀 Zustand 🔄 React Router
