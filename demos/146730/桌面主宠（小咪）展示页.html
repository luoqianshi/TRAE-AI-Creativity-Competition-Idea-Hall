万物皆可流程化

不只是点鼠标。自己训练的视觉模型、AI 写的脚本、流程逻辑与桌面操作，都能编进可复用的自动化。

视觉

自训视觉模型

用自己框选训练的定位 / 分类 / 分割模型，在流程里匹配图标、点击控件、等待界面出现。

脚本

AI 写的脚本

自然语言生成 Python 脚本，语法校验后入库；流程步骤可直接调用，复杂计算交给代码。

逻辑

流程逻辑

顺序、分支、循环、异常处理：OCR 命中再输入、窗口未出现则等待——像写程序一样编排桌面。

桌面

桌面操作

键鼠、窗口聚焦、OCR 识字、UIA 找控件、启动程序——真正在你的 Windows 桌面上动手。

无限可能

MCP、Skill、脚本与视觉模型，都能让 AI 自动开发生成——一次创造，处处复用。

MCP

AI 写扩展工具

描述新能力，AI 生成 MCP 服务代码并登记；下次创造流程时自动带上，避免重复造轮子。

Skill

AI 写技能包

把岗位经验写成 Skill，Agent 通过 read_skill 随时调用；可测试、可开关、可绑定。

脚本

AI 写 Python

自然语言生成脚本，语法校验后入库；流程步骤直接调用，复杂逻辑交给代码。

模型

自训视觉模型

框选训练定位 / 分类 / 分割模型，保存为可复用资产，在流程与 Agent 里反复匹配点击。

开发一次 → 入库绑定 → 流程与 Agent 随时调用，能力会越攒越多。

随意移植

自己做的流程、MCP、Skill 与 Agent，一键打包；换一台电脑导入就能接着用。
