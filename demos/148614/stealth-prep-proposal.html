§ 05

风险与边界

RISK & SCOPE
R-01

企业监控软件

很多公司装了屏幕录制 / 上网行为管理,纯界面伪装绕不过去。
// 边界

产品定位明确为"防瞥见"而非"防监控",避免过度承诺。

R-02

题库版权与时效

省考 / 教资真题有版权敏感性,直接收录存在法律风险。
// 边界

走官方授权路线,或开放用户自导入(UGC)通道规避版权。

R-03

程序员皮肤反向风险

伪装成代码时,懂行同事一眼能看出"这段代码不对劲"。
// 边界

这类皮肤做成"半成品草稿 / TODO 注释"风格,反而更安全。
