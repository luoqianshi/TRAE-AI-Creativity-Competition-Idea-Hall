Innovations
六大核心创新
不只是搜索，而是以工程化的逻辑，让 AI 像资深研究员一样规划、分工、反思与收敛。
🧠

自适应路由决策

系统自动判断问题复杂度：简单问题直接回答，复杂问题自动拆解为多维度子问题。无需人工干预，路由决策由 LLM 语义理解驱动，精准匹配研究深度。

⚡

专业化 Agent 协作

四种专家角色各司其职：搜索专家高效定位信息、阅读专家深度提取内容、分析专家交叉验证逻辑、事实核查员追溯原始来源。不同问题匹配不同策略，而非一刀切。

🔄

迭代收敛机制

研究不是一次性的。Reflector 每轮评估覆盖度，自动发现遗漏角度并补充调查。补充限额逐轮递减 [2,1,0]，确保研究在充分与效率之间找到最优平衡点。

🧊

长期记忆 + RAG 知识库

基于向量数据库的长期记忆让 Agent 记住过往研究；RAG 知识库支持用户上传专属文档，让研究基于你的领域知识，而非泛泛的互联网信息。

🔒

线程安全并行执行

多子问题真正并行执行，线程安全的状态管理确保 URL 去重、搜索配额等共享资源不会冲突。速度提升的同时保证结果一致性。

📐

工程级代码规范

Pydantic 强类型数据模型、分层异常体系、结构化日志、Ruff 代码检查。不是原型，是可维护、可扩展的生产级代码。

Architecture
自适应研究工作流
从问题到报告，六步完成深度研究。简单问题直出，复杂问题自动进入完整流水线。
01

路由判断 (Router)

LLM 语义理解问题复杂度，简单问题直接 ReAct 回答，复杂问题进入深度研究流程。自适应决策，无需人工指定模式。

02

智能规划 (Planner)

将复杂问题拆解为多个子问题，并为每个子问题分配最合适的专家类型（搜索/阅读/分析/核查），附带推荐搜索关键词。

03

并行执行 (Parallel Execute)

多子问题同时派发给专业化 Agent，ThreadPoolExecutor 并行调度，线程安全的状态管理确保 URL 去重和配额控制。

04

迭代反思 (Iterative Reflect)

Reflector 评估研究充分度，发现遗漏角度，补充新子问题。补充限额逐轮递减 [2→1→0]，4 重收敛条件确保不会无限循环。

05

知识沉淀 (Memory Store)

研究结果存入 Qdrant 向量数据库的长期记忆，同时检索 RAG 知识库中的用户专属文档。越用越聪明，研究不重复。

06

报告生成 (Writer)

Writer 综合所有子研究结果，生成结构清晰、引用完整的研究报告，自动保存为 Markdown 文件。
