PROBLEM · 痛点发现

塔防游戏，只能点点点吗？

植物大战僵尸是无数人的童年经典，但传统版本只支持鼠标点击操作——选植物、放格子、收集阳光，全程"点点点"。这种交互方式虽然简单，却缺少身体参与感和沉浸感。当体感游戏逐渐流行，我们不禁思考：能不能用手势来玩塔防？

01

操作单一，缺乏沉浸

传统塔防游戏只有鼠标点击，没有身体参与感，玩久了容易疲劳

02

体感游戏品类单一

现有体感游戏多为动作类（切水果、拳击），缺少策略塔防品类

03

经典IP缺少新玩法

植物大战僵尸的经典玩法多年未变，玩家期待全新的交互体验

04

硬件门槛高

体感游戏通常需要VR设备或专用传感器，普通用户难以接触

塔防引擎渲染
全链路在浏览器本地运行 · 视频流不上传 · 延迟 < 50ms

核心技术思路：MediaPipe Hands 模型以约 30fps 检测手部 21 个关键点，系统根据关键点之间的角度和距离关系，实时识别握拳、张掌、剪刀手、捏合等手势类型。食指指尖坐标映射为游戏内光标位置，握拳动作触发种植确认。Phaser 3 引擎负责草坪网格管理、植物 AI（自动攻击）、僵尸寻路、子弹碰撞和经济系统。整个流程在浏览器主线程完成，无需任何后端服务。

VALUE · 价值与意义

经典玩法 × 体感交互

🌍 社会价值

让体感游戏从"动作类"扩展到"策略类"，证明手势交互不仅能切水果，还能玩深度策略游戏。降低科技体验门槛——一台普通电脑就能感受 AI 手势识别的魅力。

⚡ 技术价值

验证了 Web 端手势识别在复杂策略游戏中的可用性。多手势状态机 + 游戏引擎的结合，为 Web 体感游戏提供了一种可扩展的技术架构范式。

📚 教育价值

塔防游戏天然包含资源管理、空间规划和策略思维，结合手势交互后更具沉浸感。适合用作 AI 手势识别技术的教学案例，激发学生兴趣。

🎉 娱乐价值

经典 IP + 全新玩法 = 话题性极强的展示项目。线下展示时，围观者能看到玩家对着空气"指挥"植物军团，极具观赏性和传播力。
