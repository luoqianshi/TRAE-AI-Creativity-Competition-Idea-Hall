💡 灵感来源

最初大家对 LLM 幻觉问题——即"一本正经胡说八道"——高度不信任。 但模型的这个能力是否也可以有用？我们想到：脱口秀的本质，不就是带着善意的"胡说八道"吗？ 随着模型持续迭代，幻觉问题有了很大改善，我们对语言模型的要求也会更高。 从"信"到"达"再到"雅"，模型还有提升空间——而以脱口秀这种形式，恰好能检验模型在语言表达上的进化程度。

痛点洞察

每个人心里都有段子，但没人会讲

生活中的槽点无处不在，但把经历变成好笑的脱口秀需要天赋、练习和结构感——大多数人卡在第二步。

有故事，没结构

每个人都有想吐槽的经历：加班、相亲、早高峰……但写成段子往往变成流水账，缺少「铺垫→反转→爆梗」的喜剧结构。

🎙️

写了没法听

常见问题

FAQ

需要什么 API Key？
默认用 DeepSeek（兼容 OpenAI SDK），也可以换成其他 OpenAI 兼容的 LLM。语音合成使用 Index-TTS，支持多种情绪表达。
生成的段子真的搞笑吗？
我们有一套四层验收体系来量化「好不好笑」，包括喜剧理论结构和真实弹幕数据校准。虽然不是每段都能让你笑出声，但比随机生成的强多了。欢迎自己试试！
Index-TTS 和普通 TTS 有什么区别？
普通 TTS 是"念稿"，Index-TTS 能理解文本情绪并做出相应语调变化——自嘲时语气下沉、调侃时语速加快。脱口秀不是朗读，是有表演的。
我可以贡献代码吗？
当然！项目已在 GitHub 开源。无论是修 bug、加新功能、优化验收标准，还是分享你的 persona，都欢迎 PR。
