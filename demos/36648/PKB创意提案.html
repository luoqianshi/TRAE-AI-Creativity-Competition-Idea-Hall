PKB
编译式个人知识库

AI 驱动的编译式个人知识库，不是检索工具，是知识的编译器。

产品形态：AI IDE / 本地终端 非 SaaS，非 Web 应用

三层编译架构

raw/

不可变原始层

网页采集、论文下载、文档转换。只增不删。

wiki/

结构化知识层

AI 自动分析内容，生成 Markdown 笔记（YAML frontmatter + wikilink 双链）

rules/

自动化规则层

Agent 行为规则，frontmatter 校验、健康检查、自动 Git 提交

核心工作流

1

用户丢入任何东西

网页链接、论文 PDF、文档

2

AI 自动采集原始内容

四级正文提取 + 多源论文下载

3

AI 编译为结构化笔记

分析内容 → 提取概念 → 写 Markdown → 建立双链

4

健康检查 + Git 提交

知识库持续生长

与同类方案的区别

传统笔记工具 RAG 检索方案 AI 摘要工具 PKB
整理方式 手动整理 手动整理 一次性输出 AI 全自动
理解能力 — 只匹配关键词 单次摘要 AI 真正理解
知识积累 依赖用户主动 检索而非积累 一次性 持续积累结构化知识库
