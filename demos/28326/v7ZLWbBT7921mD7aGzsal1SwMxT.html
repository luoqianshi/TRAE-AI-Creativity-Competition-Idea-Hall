AI Agent 笔试刷题系统

系统化 AI Agent 面试与笔试刷题平台，覆盖 RAG、Prompt Engineering、LangGraph、MCP 等核心知识点，助你备战大厂。

创意介绍

随着 AI Agent 技术爆发，越来越多的开发者需要系统学习 RAG、Prompt Engineering、LangGraph、MCP 等核心技术。然而，目前市面上缺乏专门针对 AI Agent 岗位的刷题工具——零散的文章、不系统的视频教程，让求职者难以高效备考。

核心痛点：AI Agent 岗位面试/笔试缺乏系统化、可交互的刷题平台，求职者无法精准评估自己的知识盲区。

产品形态：一个纯前端 Web 应用（HTML + CSS + JS），无需后端即可运行，支持分类筛选、模拟考试、错题本、收藏等功能。

目标用户与使用场景

核心用户群体：

  • 准备 AI Agent 相关岗位面试的开发者（初级到中级）
  • 希望系统学习 AI Agent 技术栈的在校学生
  • 需要评估团队 AI Agent 技术能力的面试官/管理者

使用场景：

  • 日常练习：利用碎片时间刷题，巩固知识点
  • 考前冲刺：模拟考试模式，检测综合水平
  • 查漏补缺：通过错题本定位薄弱环节，针对性复习
当前痛点：求职者只能零散地阅读技术文章或观看视频，缺乏一个可以即时反馈、系统追踪学习进度的刷题工具。

价值与意义

效率提升：将零散的知识点整合为结构化题库，配合即时反馈和错题追踪，学习效率提升 3-5 倍。

社会价值：降低 AI Agent 技术学习门槛，帮助更多开发者快速掌握核心技术，推动 AI Agent 生态的人才培养。

商业价值：可扩展为付费订阅产品，加入更多题库、AI 智能解析、面试模拟对话等增值功能。

技术亮点

  • 纯前端实现：无需后端服务器，直接打开 HTML 即可使用，部署零成本
  • 本地数据持久化：使用 localStorage 保存答题记录和错题本，刷新不丢失
  • 响应式设计：适配桌面端和移动端，随时随地刷题
  • 键盘快捷键：支持方向键切换题目、Enter 提交、R 随机抽题
  • 精选题库：覆盖基础认知、Prompt 工程、RAG、LangGraph、MCP 等核心领域
