创意介绍

想解决什么问题

我们每天阅读大量文章、记笔记、学课程，但知识都是零散的"碎片"，学了就忘、难以串联， 想复习时找不到脉络，想应用时提取不出来。很多人花了大量时间学习，却始终建不起自己的知识体系。

为什么会想到做这个

我自己就是一个"收藏癖"——微信收藏夹里存了几百篇文章，笔记软件里记了上千条笔记， 但真正能内化的没多少。每次想写东西或解决问题时，总觉得"我好像看过相关内容"但就是找不到、想不起。 我希望有一个工具能自动帮我把这些零散的知识"织成网"，让学习事半功倍。

大概是什么产品

一个基于大语言模型的 Web 应用 + 浏览器插件。用户导入笔记、文章、电子书等内容后， AI 自动分析知识点、识别关联关系，生成交互式的可视化知识图谱。 用户可以在图谱上探索、补充、复习，逐步构建个人知识体系。

技术实现思路

核心技术栈

大语言模型 (LLM) 向量数据库 知识图谱 (KG) Embedding React / Vue D3.js / ECharts Node.js 浏览器扩展 API

实现逻辑简述

1. 用户导入内容后，先通过 Embedding 模型向量化，存入向量数据库；
2. 调用大模型对每段内容进行结构化提取：识别核心概念、属性、关系；
3. 基于语义相似度和关系提取结果，构建知识点之间的连接，生成图谱数据；
4. 前端用可视化库渲染交互式图谱，支持搜索、筛选、路径探索等操作；
5. 问答功能结合向量检索 + LLM 生成，回答附带来源定位。
