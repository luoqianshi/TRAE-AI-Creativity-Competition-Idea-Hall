PROBLEM

开发者参加比赛有多难？

信息分散、筛选成本高、缺乏社区经验——每一个环节都在消耗开发者的热情

🔍

信息分散，容易错过

黑客松、AI 大赛、硬件创新赛等信息散落在各官网、公众号、社区中。开发者经常在比赛结束后才从朋友圈得知消息，错过报名截止日期。

📋

筛选成本极高

每个比赛的参赛资格、技术栈要求、难度等级各不相同。用户需要逐个点开详情页阅读，才能判断"我能不能参加""适不适合我"，花费数小时。

🔇

缺乏经验沉淀

比赛结束后，获奖方案和复盘经验散落在各处，新选手很难找到系统的备赛指南。不像 Game Jam 有 itch.io 社区，编程比赛领域缺少垂直社区。

👥

组队渠道缺失

很多比赛需要组队参加，但开发者缺少专门的组队平台。只能在朋友圈、微信群发消息，效率低且难以找到技术互补的队友。

FEATURES

核心功能

MVP 已实现核心信息聚合，后续迭代 AI 推荐和社区生态

🗂️

比赛信息聚合

自动爬取多来源比赛信息，统一展示。支持黑客松、AI 大赛、硬件创新、开源贡献等多种类型。

🔎

多维度筛选

按状态、类型、难度、参赛资格筛选，支持关键词搜索和多种排序方式，快速找到目标比赛。

🤖

AI 智能匹配

用户填写身份、技能、经验等资料，AI 自动匹配推荐"可以直接报名"的比赛，省去筛选时间。

📄

比赛详情页

完整展示比赛介绍、参赛资格、技术栈要求、奖项设置、时间安排，一键跳转官网报名。

💬

社区经验分享

像龙空一样的垂直社区，获奖选手分享经验、评委视角解读、备赛指南，构建技术比赛知识库。

🤝

组队 & 招募

专门的组队板块，按技术栈匹配队友。主办方也可发布招募信息，连接优秀开发者。

VALUE

为什么值得做？

效率提升 + 社会价值，双重驱动

⚡ 效率提升

通过 AI 智能匹配，将"找比赛 → 判断资格 → 筛选适合 → 报名"的流程从数小时缩短到几分钟。用户填写一次个人资料，平台持续推送完全匹配的比赛，省去反复筛选的时间成本。对标 itch.io 在 Game Jam 领域的效率提升，HackHub 将为编程比赛领域带来同样的体验。

🌍 社会价值

降低开发者参与技术比赛的门槛，让更多学生和从业者有机会通过比赛提升技能、拓展人脉、获得职业发展机会。形成垂直技术社区，沉淀比赛经验和行业知识，构建像龙空在网文领域那样的技术比赛生态——通用平台上找不到的深度内容和圈内文化。

ROADMAP

迭代规划

从 MVP 到生态平台，一步一步来

Phase 1 ✅ 已完成

MVP - 比赛信息聚合

FastAPI 后端 + SQLite 数据库 + 前端列表页/详情页。10 条种子数据，支持多维度筛选和搜索。已跑通完整链路。

Phase 2

真实爬虫 + 用户系统

接入真实比赛信息源爬虫，自动更新。用户注册登录、收藏比赛、报名提醒，为 AI 推荐积累用户数据。

Phase 3

AI 智能匹配推荐

用户填写个人资料（身份/技能/经验/设备），AI 自动匹配并推送"可以直接报名"的比赛。核心差异化功能。

Phase 4

社区生态

经验分享论坛、组队招募、比赛复盘。像龙空一样形成垂直社区护城河——通用平台找不到的深度内容和圈内文化。
