1创意名称与创意介绍

一款让每一分公益资金都能被看见、被追溯、被信任的互助平台

🔒

资金流向不透明

传统公益捐款后，捐赠人很难追踪资金去向，不知道自己的钱最终帮助了谁

⚖️

审核流程欠规范

受助者的真实身份与需求缺乏多维度验证，存在冒领、滥用的风险

👥

公众参与度低

普通捐助者只能被动"捐钱"，无法参与审核与决策过程，归属感弱

💡 产品定位

基于微信小程序的资金互助系统，连接资助者与受助者，提供从身份验证、申请提交、多人审核、资金分配到全链追溯的完整公益闭环。 让捐赠真正看得见，让信任重建于透明。

📱 技术形态

以微信小程序为主入口（无需下载安装、即点即用），配合 Node.js 后端服务、SQLite 数据存储、Python 人脸识别微服务、 WebSocket 实时审核群聊、腾讯云 IM 群通讯，构建"多角色 · 多验证 · 全透明"的公益互助生态。

3七大核心功能亮点

覆盖公益资金全生命周期，打造端到端的透明互助体验

🧑‍🎤

AI 人脸识别登录

调用 dlib 1:N 人脸比对算法，支持活体检测，身份验证安全可靠。Python 微服务提供独立的 AI 算力支持。

dlib · 1:N 比对 · 活体检测
📝

电子承诺书/宣誓书

资助者签署《资金来源承诺书》，受助者签署《信息真实宣誓书》，手写签名组件记录承诺瞬间。

Canvas 签名 · 法律效应
💬

实时审核群聊

多位审核员在群聊中讨论申请材料，共享证据与意见。基于 WebSocket + 腾讯云 IM 实现实时通讯。

WebSocket · IM SDK · 实时通讯
📊

全链资金追溯

每一笔资金从充值到分配的去向可视化追踪。提供资金池、流水、追溯报表、BI 统计、捐助人员清单。

SQLite 关联 · BI 报表
🏘️

社区代办代收

专门为不会操作智能手机的老人、乡村居民设计，支持社区居委会工作人员代办申请，不让数字鸿沟成为受助障碍。

包容性设计 · 数字平权
🎯

公众参与审核

资深捐助者可作为公众审核员参与决策过程，让公益从"少数人管理"变成"多数人监督"，培育社区自治。

角色多选 · 任务队列
💰

月捐与资金池管理

支持一次性充值与月度自动捐赠。定时任务 cron service 自动执行月度资金分配，减少人工操作。

Cron Jobs · 定时任务
📰

资讯与公告系统

首页展示平台资金池总览、爱心排行榜、精选资讯与公告。支持文章管理、封面自动生成，营造活跃社区氛围。

CMS · 封面自动生成

4典型业务流程

两条并行的业务主线，最终汇聚于透明的资金分配

A
👨‍💼 资助者主线
微信登录 / 人脸登录 → 选择角色 → 签署《资金来源承诺书》 → 扫码充值 / 设置月捐 → 查看资金池与分配明细 → 可选：参与审核任务
↓
B
🙋‍♂️ 受助者主线
微信登录 / 人脸登录 → 选择角色 → 实名认证 → 人脸信息注册 → 提交资助申请 → 签署《信息真实宣誓书》 → 等待审核
↓
C
👁️ 审核员决策
审核员查看任务 → 进入审核群聊讨论 → 多人沟通与证据核对 → 电子签名确认 → 通过 / 驳回申请
↓
D
⚙️ 管理员执行
管理中心 → 资金发放模块 → 系统自动计算分配方案 → 资金到账通知 → 全链追溯记录永久保存
↓
E
📊 全平台透明
任何人可查看：资金池总览 · 资金流水 · 资金追溯链 · BI 月度报表 · 捐助人员清单 → 重建社会对公益的信任

5与传统公益模式对比

从人工到智能，从黑盒到透明，从被动到参与

对比维度 传统公益模式 互帮互助平台 提升效果
身份核验 线下人工核对身份证 ✓ AI 人脸识别 + 实名验证 1 天 → 5 分钟
申请提交 纸质表格填写、邮寄或面交 ✓ 小程序在线上传材料 1 小时 → 10 分钟
审核流程 邮件/线下传阅、多人签字 ✓ WebSocket 审核群聊 + 电子签名 1–2 周 → 2–3 天
资金发放 人工打款 + 线下通知 ✓ 系统自动计算分配 + 到账通知 1 月 → 周度/月度
资金追溯 无 ✓ 完整资金流向链 + BI 可视化 不可追溯 → 全链透明
公众参与 仅捐款，无决策参与 ✓ 公众审核员、多人讨论 被动 → 主动参与
困难群体覆盖 操作门槛高，数字化障碍 ✓ 社区代办、线下协助 数字鸿沟 → 人人可及
数据透明度 年度报告、延迟披露 ✓ 实时资金池、流水、BI 报表 年度 → 实时

8价值与意义

从效率提升到社会信任重建，产品的双重价值

⚡ 效率提升

每一份申请的处理周期从传统的 1–2 周缩短到 2–3 天，身份核验时间从 1 天缩短到 5 分钟。通过系统自动化资金分配与定时任务，管理员每月工作量节省 60%+。

受助者从"不知道进度"到"实时查看审核状态"，捐赠者从"捐款即失联"到"每一笔资金都能被看到去向"，整个公益流程效率提升数倍。

🌱 社会价值

📖 重建公益信任 —— 全链资金追溯、BI 报表公开、捐助人员清单透明，让每一分钱都能被看见，重建社会对公益事业的信心。

🛡️ 多维身份验证 —— 微信登录 + 手机号实名 + 活体人脸识别三重验证，有效防范冒领虚假申请，让资金真正到达需要帮助的人。

👨‍👩‍👧‍👦 人人可参与 —— 公众审核员模式让捐助者不仅能捐款，还能参与决策，让公益从"少数人管理"变成"多数人共同监督"。

🌾 关怀技术弱势群体 —— 社区代办与代收功能，让不会使用智能手机的老人、乡村居民也能平等享受公益资助，不让数字鸿沟成为受助障碍。

🔔 培育社区自治 —— 审核群聊机制让社区成员参与讨论与决策，培育社区自治精神与公益意识的良性循环。
