青少年心理健康陪伴平台

在你的心里，建一座温暖的小岛

项目简介

心岛是一款专为高中生和大学生设计的心理健康陪伴小程序。我们通过AI虚拟同伴、心理评估、习惯养成、放松游戏等功能，帮助青少年应对学习压力、情感困扰、未来规划等问题，陪伴他们健康成长。

目标用户与痛点

目标用户

  • 高中生：15-18岁，面临高考压力、学业焦虑、青春期情感困惑
  • 大学生：18-25岁，面临就业压力、人际困扰、情感挫折、未来迷茫

高中生痛点

  • 每天重复的高强度学习，身心俱疲
  • 遇到学不会的知识时，容易产生挫败感
  • 青春期的懵懂情感，不知道如何处理
  • 高考的巨大压力，担心自己考不好
  • 对未来要读什么专业、做什么工作感到迷茫

大学生痛点

  • 即将步入社会，对未知感到焦虑和不安
  • 找工作时面临激烈竞争，压力很大
  • 恋爱中的甜蜜与失恋后的痛苦，不知道如何应对
  • 对未来的职业发展和人生方向感到迷茫
  • 难以平衡学业、兼职、恋爱、社交等各方面的关系

核心功能

🤖

心岛AI聊天

虚拟同伴"心岛"24小时在线，倾听你的烦恼，给予专业的心理支持和建议。内置专题指南，如高考减压、失恋疗愈等。

📋

心理评估

专业的心理测评问卷，帮助你了解自己的心理状态，包括压力评估、人格测试等。

🕳️

小树洞

匿名留下你的心事和语音，未来可以回看回忆。AI会分析你的情绪，但不会回复，保护你的隐私。

📝

情绪日记

记录每天的心情，生成情绪曲线，了解自己的情绪变化规律。

✅

习惯打卡

培养良好习惯，学习、运动、早睡、阅读等，记录每一天的进步。

🏆

成就系统

打卡、完成测试获得徽章和奖励，增加成就感和动力。

🧘

正念呼吸

可视化的呼吸训练，帮助你快速放松，缓解焦虑和压力。

🎮

放松小游戏

猜数字、词语接龙等轻松小游戏，在压力大的时候放松一下。

产品亮点

创新点

  • AI+专业心理支持：结合AI技术和心理学知识，提供专业但温暖的陪伴
  • 隐私安全：小树洞功能让用户可以放心倾诉，AI只分析不回复
  • 游戏化设计：成就系统、打卡奖励，让心理健康变得有趣
  • 全场景覆盖：从日常陪伴到考前减压，从习惯养成到情感疗愈

技术栈（拟采用）

微信小程序 React / Vue Node.js Python DeepSeek / OpenAI API MongoDB / PostgreSQL

开发计划

第一阶段：MVP核心功能

AI聊天、心理评估、小树洞、情绪日记、习惯打卡

第二阶段：完善体验

成就系统、正念呼吸、放松小游戏

第三阶段：优化迭代

UI优化、性能优化、用户反馈迭代

愿景与目标

我们希望心岛能成为每一个青少年心里的一座温暖小岛，在他们迷茫、压力大、不开心的时候，能在这里找到安慰和支持。

我们的目标是：让心理健康不再难以启齿，让每一个青少年都能被温柔以待。
