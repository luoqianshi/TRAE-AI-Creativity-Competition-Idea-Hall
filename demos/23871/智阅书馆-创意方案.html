01 / 创意介绍

传统图书馆管理，
正在浪费每个人的时间

每到选课季或考试周，高校图书馆总是人满为患——学生排长队借还书、管理员手工录入借阅信息、逾期提醒全靠人工…… 我们发现，大多数高校图书馆仍停留在"纸质登记+人工催还"的原始阶段，信息孤岛严重，效率极低。

😫

借还书排队久

学生需要在柜台排队等待人工办理借还手续，高峰期等待时间超过30分钟，严重影响学习效率。

📋

逾期管理混乱

逾期图书缺乏自动提醒机制，管理员只能逐条核查，催还效率低下，大量图书长期滞留。

🔍

图书查询困难

学生无法在线检索馆藏，只能到馆后逐架翻找，找一本书往往耗费大量时间，体验极差。

📊

数据统计缺失

管理者无法实时掌握借阅趋势、热门图书、逾期率等关键数据，决策全凭经验，缺乏数据支撑。

02 / 产品方案

双端协同，让图书馆真正"智慧"起来

智阅书馆是一款面向高校的智慧图书馆管理系统（Web端），分为管理员端与读者端双入口， 覆盖图书管理、在线借阅、逾期追踪、数据看板全流程，让借阅像点外卖一样简单。

🛡️
管理员端
全馆管控，一屏掌握

图书与分类管理

增删改查图书信息，支持按分类、关键词快速检索，馆藏状态一目了然

读者信息管理

管理读者账号、借阅额度、启用/禁用状态，精准管控借阅权限

借阅记录管理

查看全馆借阅流水，支持代借代还、逾期标记，一键处理异常

数据统计看板

实时展示馆藏总量、借阅率、逾期率等核心指标，辅助管理决策

📖
读者端
自助借阅，随时查询

在线图书查询

支持按书名、作者、ISBN检索，分类筛选，实时查看库存状态

一键借阅与归还

在线完成借阅操作，到期一键归还，借阅额度实时提醒

智能续借

支持在线续借，系统自动校验60天上限，逾期图书也可续借恢复

个人借阅中心

查看借阅记录、当前借阅量、可借额度，首页智能提醒借阅状态

03 / 技术架构

前后端分离，JWT鉴权护航

基于 Vue3 + Spring Boot + MyBatis 的前后端分离架构，JWT Token 实现双端独立鉴权。

🟢

Vue 3 + Element Plus

Composition API + 组件库，双端独立路由与状态管理

🍃

Spring Boot + MyBatis

RESTful API + 动态SQL，灵活高效的业务逻辑实现

🔑

JWT + 拦截器

双端独立Token鉴权，接口级权限控制，安全可靠

🗄️

MySQL

关系型数据存储，事务保障借阅归还的数据一致性

04 / 核心亮点

不只是管理，更是智慧

从借阅上限校验到逾期自动标记，每一个细节都在为效率和安全服务。

🔐 双端独立鉴权

管理员与读者使用独立Token，路由守卫自动分流，互不干扰，安全性更高

📊 ECharts 数据看板

馆藏总量、借阅率、逾期率等核心指标可视化呈现，辅助管理者科学决策

⏰ 借阅智能校验

借阅上限实时判断、续借60天硬限制、逾期自动标记，前后端双重校验保障数据准确

🔄 在线续借归还

读者可在线完成续借与归还操作，逾期图书续借后自动恢复为正常状态

🔔 借阅额度提醒

用户首页实时展示借阅量与可借额度，达到上限自动预警，避免超限

📱 自助注册登录

读者可自主注册账号，自动生成借书证号，无需管理员手动录入
