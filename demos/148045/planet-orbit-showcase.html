创意概述

让天文教育从平面走向沉浸

⚠

发现的痛点

天文教育长期依赖书本插图、2D动画或静态星图，学生难以直观理解行星轨道、公转速度差异和天体物理关系。现有的3D天文软件要么过于专业复杂，要么缺少交互调试能力，无法满足学习和实验的双重需求。

🚀

解决方案

基于 Three.js 构建全栈沉浸式3D太阳系模拟平台，用户可以在深邃的星空中自由旋转缩放，观察8大行星以不同速度绕太阳公转。更重要的是，它提供了参数调试功能，让用户调整引力常数、时间倍率、行星质量等物理参数并实时预览效果。

产品形态

网站 + 后端服务

基于 React + Three.js + Express.js + SQLite 的全栈 Web 应用。前端负责 3D 场景渲染与交互界面，后端提供用户认证和调试数据持久化能力。支持访客浏览体验和注册用户数据管理两种模式。

核心功能

四大模块，层层深入

🌌

3D 太阳系场景

全屏沉浸式 Three.js 渲染，5000粒子星场背景，Bloom辉光后处理，每颗行星独立公转/自转

🪐

行星详情探索

每颗行星有独立详情页，展示3D模型、质量/半径/轨道等物理参数，土星带环效果

🎛

参数调试面板

实时调整时间速度、引力常数、单颗行星质量/轨道半径/公转速度，即时生效

💾

调试数据持久化

注册用户可保存当前参数组合，随时加载历史记录进行对比分析，支持增删改查

👤

用户认证系统

邮箱注册登录，JWT令牌认证，7天免登录。访客可浏览，注册用户享数据管理权限

🎯

交互探索体验

鼠标拖拽旋转视角、滚轮缩放、悬停显示信息、点击选中高亮行星轨道，极低交互门槛

目标用户

谁需要星球之路

🎯 核心用户群体

天文爱好者 — 希望直观观察行星运动的业余天文爱好者

📍 使用场景

• 课堂上教师打开应用，展示行星公转轨迹
• 学生在家自主探索太阳系结构
• 天文爱好者调试物理参数，"如果引力变成两倍会怎样"
• 课前预习/课后复习天体运动知识
• 科普展览中的交互展示终端

🔴 没有它，用户面临什么

天文科普资源要么是静态图文不够直观，要么是专业模拟软件门槛高、安装复杂。学生难以将抽象的物理参数（引力常数、轨道速度）与可视化的天体运动建立联系。教师缺少一个开箱即用、可交互的天文教学工具。

价值意义

创造三重价值

✦

教育价值

将抽象的天体物理概念转化为可视化3D体验。学生可以"看到"引力变化如何影响行星轨道，直观理解开普勒定律和牛顿引力。降低天文教育门槛，激发探索兴趣。

✦

效率价值

教师无需在多款软件间切换——在同一平台完成展示、交互、调试、保存全流程。调试数据的保存/回溯功能让实验教学变得可重复、可对比、可追踪。

✦

社会价值

普及天文科学知识，缩小教育资源差距。作为开源/开源借鉴的精神产物，任何人都可以免费使用和改进，让优质天文教育资源触手可及。

技术架构

全栈技术栈

前端层
  • React 18 + TypeScript
  • Three.js + @react-three/fiber
  • @react-three/drei + postprocessing
  • Tailwind CSS 3
  • Zustand 状态管理
  • Vite 构建工具
后端层
  • Express.js 4 + TypeScript
  • JWT 认证 (jsonwebtoken)
  • 密码加密 (bcryptjs)
  • Nodemon 热重载
  • Tsx 运行时
数据层
  • SQLite (better-sqlite3)
  • users 用户表
  • debug_records 调试记录表
  • WAL 日志模式
  • 外键级联删除
