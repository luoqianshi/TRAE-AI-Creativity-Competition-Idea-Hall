Three Tabs

三个入口，分别解决三个学习问题

像游戏关卡一样轻量开始，但每一次点击都指向真正的理解和沉淀。

Trip：我如何系统进入一个领域？

用户选择或创建一个 Field，生成一条清晰路线。它可以是平台已有课程、自定义资料课程，也可以是用户资料 + 平台资料的混合生成。

系统学习入口

Feed：这个领域现在有什么值得理解？

Feed 不是普通信息流。它会解释新内容为什么重要、和用户已学知识有什么关系，并提供提问、对比、小测和收藏。

持续探索入口

Me：我学到了什么，沉淀了什么？

Me 承载用户的知识松果、学习记录、成就、收藏内容和个人反思，让一次次学习变成可回顾、可生长的个人知识资产。

个人知识资产
Create a Trip

新增 Trip 不是输入一个主题，而是选择一种学习方式

FieldTrip 支持从平台课程快速开始，也支持用户上传自己的资料，或者由平台补充资料生成更完整的学习路线。

1选择平台已有课程：适合想马上开始学习的用户。
2用户自定义课程：上传 PDF、网页、视频、播客、文章或文档。
3混合生成课程：自己的资料 + 平台高质量资料，生成更完整 Trip。
学习站点

每一站，都是一次主动理解

一个学习站点围绕明确主题展开，把资料、讲解、互动题和个人表达组织在一起，帮助用户真正理解一个关键问题。

Claude Code 的 memory / context management

从一个真实主题进入：先补前置概念，再理解材料和案例，最后用互动题和个人表达完成理解。

1前置概念context window、tool use、agent loop、memory。
2多层材料官方文档、builder 观点、GitHub issue、产品 release note。
3互动理解判断题、案例题、挑战题、用户理解输入和小松鼠问答。
4沉淀资产概念卡、观点卡、产品卡、案例卡和“我的理解”。
Learning Engine

学习引擎把资料变成任务，而不是变成摘要

用户看到的是轻量、清爽的 App 界面；背后是一套从资料源到知识库的生成链路。

A

资料源系统

官方源、Builder 源、工程实践源、长内容源和高质量二级解释源被打上可信度、领域、观点类型等标签。

B

学习站生成

系统识别主题，生成必要背景、关键片段、解释、案例、互动题和挑战，让用户完成主动理解。

C

知识更新

每次学习都进入知识松果；Feed 中的新内容也能反哺 Trip 和个人知识库，持续更新认知。

Mascot

小松鼠不是 Chatbot，
而是学习陪伴者和知识收藏引导者

当用户在学习站点中卡住，它负责解释；当用户在 Feed 中看到新内容，它帮助理解；当用户回到 Me，它展示已经收集到的知识松果。

FieldTrip Vision

让用户不是“看过很多”，而是“真的理解，并形成自己的知识资产”

FieldTrip 的完整闭环是：选择 Field，生成或选择 Trip，完成一个个学习站点，互动理解，收藏知识松果，进入 Me 沉淀，再通过 Feed 持续更新。
