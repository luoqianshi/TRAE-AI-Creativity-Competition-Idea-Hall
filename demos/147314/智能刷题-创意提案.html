解决了什么问题

传统刷题工具的四大痛点

❌

离线即瘫痪

现有刷题App大多需要联网登录，在工厂车间、偏远考场等无网络环境下功能受限甚至无法打开。

⏳

题库导入困难

企业/个人的自有题库（Excel、Word、纸质材料）难以快速导入到第三方平台，手工录入耗时数小时。

📋

错题复盘流于形式

错题本只能记录文字，缺乏针对性的解析和知识回溯，考生难以定位薄弱环节。

👁

隐私与速度隐患

拍照搜题依赖云端API，识别速度慢、有隐私泄露风险，且未联网时完全不可用。

核心功能

八大模块，覆盖题库全生命周期

📊

首页仪表盘

实时展示题库数量、题目总数、考试次数、最近正确率。提供快捷操作入口，一键开始考试或导入题库。

数据可视化
📚

题库管理

卡片网格展示所有题库，支持搜索过滤。每道题库显示题型分布标签和题数，一目了然。

卡片式浏览
📥

四种导入方式

粘贴文本自动解析、Excel 批量上传、拍照 OCR 识别、教材 AI 自动生成题目。几分钟完成原本数小时的手工录入。

AI 驱动
📝

模拟考试

从题库随机抽题，支持判断/单选/多选混合组卷。倒计时提醒，自动交卷，单人即可完成全流程自测。

智能组卷
💯

考试结果分析

成绩大卡展示分数与用时，题型统计定位薄弱环节。错题可调用本地 Ollama AI 实时生成针对性解析。

AI 解析
🔍

拍照搜题

上传图片 → Ollama VL 模型 OCR 识别 → Levenshtein 模糊匹配题库 → 按相似度排序返回 Top 5 最相似题目。

视觉 + 文本
🔧

AI 设置中心

配置 Ollama API 地址、文本模型和视觉模型名称。一键测试连接状态，实时显示可用模型列表。

模型管理
🔒

隐私与安全

所有数据本地 SQLite 存储，AI 推理本地 Ollama 运行。CSP 安全策略、单实例锁、全局错误捕获。
