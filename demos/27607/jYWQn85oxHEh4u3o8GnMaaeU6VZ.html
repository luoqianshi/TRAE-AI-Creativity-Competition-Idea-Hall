Core Features

Built for developers who need precision, not flash.

🧩

Request Breakdown

Input a one-line requirement and AI automatically decomposes it into structured user story cards with acceptance criteria and priority ordering. Supports clarification plans and continuation queries.

AI-Powered
🎨

Live Canvas

Select a user story and an AI agent generates an implementation in an isolated git worktree. Preview code changes in real time, review diffs, accept or decline file changes, and merge into main.

Core
🕸️

Context DAG

A three-level hierarchical DAG (project → story → subtask) that serves as a lossless context memory system. Persists raw Markdown logs, structured JSONL records, and a DAG manifest.

Local-First
⚡

Hermes Gateway

JSON-RPC-over-stdio bridge to external AI providers. Manages session creation, model selection, provider switching, streaming responses, and rate-limit retry with exponential backoff.

AI-Powered
🔌

Dual-Transport Runtime

Hermes stdio (primary) + ACP fallback. Automatically discovers available providers, checks authentication, and falls back across transports and providers. Switch in the UI, not in code.

Core
📁

Admin Catalog

Scans and catalogs the .claude/ directory across 7 categories: agents, skills, context, tools, plugins, commands, hooks. Local and workspace-scoped roots with metadata extraction.

Local-First

Architecture

Designed for reliability, offline capability, and extensibility.

📐 Next.js 16 + React 19

App Router with TypeScript strict mode. Server components for data-heavy operations, client components for interactive workspaces.

🎨 Tailwind CSS v4 + shadcn/ui

Light-first workbench design with restrained cobalt accents, soft elevation shadows, and compact status language. No neon, no gradients.

💾 Per-Project Store

Each project stores its workspace data at <projectRoot>/workspace-store.json. No central dependency. Co-located with code.

🔗 Context DAG Persistence

Raw logs in .apex-agent/context-dag/raw/, structured records in records/, manifest in context-dag.json. Best-effort Postgres sync optional.

🤖 ACP + Hermes

Dual transport: @agentclientprotocol/sdk for direct integration, Hermes gateway for stdio-based provider routing. Automatic fallback.

🔒 Local-First Assets

All skills, plugins, and tool registries live in .claude/. No cloud dependency. Works offline. Version-controllable with git.

4 AI Client Providers, Zero Lock-In

Switch providers with a UI toggle. Automatic fallback across transports.
