Problem · 痛点

健身房新手不是没毅力
是没人教

观察身边10个去过健身房的朋友,8个说过同样的话。新手流失的真正原因,藏在器械前那个低头玩手机的尴尬瞬间里。

01 🤷

不会用器械

面对琳琅满目的器材,不知从何下手。每个器械都像一道解不开的谜题,新手只能凭直觉硬试。

02 😳

怕丢人

站在器械前装作玩手机,其实是在偷偷看别人怎么用。一次尴尬,可能就再也没去过健身房。

03 📉

流失率高

去几次就放弃,健身房留不住新手。会员卡办了不用,续费率持续走低,运营者也很头疼。

04 🙅

私教难转化

想找教练不知道找谁,被推销又反感。真正的需求与合适的服务之间,缺一座不尴尬的桥。

  • 底部出现"找教练指导"转化入口

TRAE · 创作

全程使用 TRAE 创作

从行业分析到代码实现,从方案文档到 Web Demo,每一个阶段都借助 TRAE IDE 完成。

PHASE 01

📊 行业分析

用 TRAE 分析健身房行业痛点,整合身边10位朋友的访谈数据与行业公开数据,评估"扫码学器械"方案的可行性与市场空间,确认这是一个真实存在且未被满足的需求。

PHASE 02

📝 方案设计

基于个人观察与 AI 分析,设计包含扫码学习、安全要点、学习路径、教练预约在内的14模块完整方案。TRAE 辅助生成 Markdown、HTML、PPT 三种格式的方案文档,逻辑严密可执行。

PHASE 03

💻 MVP 开发

后端用 TRAE 生成 Node.js + Express 的26个 API,调试 SQLite 编译问题后重写为 JSON 存储;前端用 TRAE 生成微信小程序6个页面与扫码逻辑;管理后台用 TRAE 生成完整 CRUD + 二维码生成功能。

PHASE 04

🌐 Web Demo

为参赛专门制作 H5 版本,复用现有后端 API 与设计语言。让评审无需下载小程序即可体验完整流程,降低评价门槛。Demo 部署于 Vercel,全球可访问。
