九层自动化流水线

从 PPT 解析到视频交付，每一步都经过精心设计

01

PPT 解析引擎

使用 python-pptx 深度解析演示文稿，提取文字、图片、表格、动画等全部元素，还原页面结构与层级关系。

python-pptx · XML 解析
02

知识增强层

对提取的原始知识点进行语义扩展与上下文补充，联网搜索权威资料，自动生成知识背景与延伸阅读。

GPT-4 · 联网搜索 · RAG
03

分镜脚本生成

将知识点拆解为标准化分镜 JSON，包含画面描述、旁白文本、时间估算、转场方式等结构化字段。

GPT-4 · 结构化 Prompt
04

⚡ 人工干预节点（Human-in-the-Loop）

教师可在分镜编辑器中修改旁白、调整顺序、替换素材、补充知识点。系统保留教师主导权，AI 仅辅助。

Web 编辑器 · 实时预览
05

TTS 语音合成

根据教师选择的人格风格（严谨/幽默/冲刺），调用高质量 TTS 引擎生成自然语音，并返回精确时长数据。

Edge TTS · Azure Speech
06

时间轴对齐引擎

基于 TTS 实测时长动态调整分镜时间轴，确保画面切换、字幕出现与语音节奏精确对齐，消除声画不同步。

动态时间轴 · 实时反馈
07

双层图像系统

优先从内置素材库匹配高清图片，未命中时调用 AI 生图作为兜底，确保每个分镜都有高质量视觉内容。

素材库 · DALL·E 3 · 降级策略
08

视频合成引擎

使用 FFmpeg 将图像序列、语音轨道、字幕层、转场效果合成为最终视频，支持多种分辨率输出。

FFmpeg · MoviePy · 字幕渲染
09

AI 质量检测

自动检查声画同步、字幕准确性、画面清晰度、音频响度等指标，不合格则自动重试或降级处理。

自动检测 · 重试机制

六大核心功能

每一项功能都围绕教师实际需求设计

01

教师人格系统

支持严谨学术风、轻松幽默风、考前冲刺风三种教学风格，AI 自动调整语言风格、语速节奏和表达方式，匹配不同教学场景。

02

时间轴对齐引擎

基于 TTS 实测时长进行动态反馈调整，确保每段旁白与画面精确同步。自动处理语速差异，消除声画不同步问题。

03

双层图像系统

优先从内置高质量素材库精确匹配，未命中时自动调用 AI 生图作为兜底。保证视觉质量的同时最大化生成成功率。

04

全链路降级兜底

任意环节失败都不会导致整体崩溃。联网搜索失败用缓存数据、AI 生图失败用占位图、TTS 失败用备选引擎，确保视频一定能生成。

05

人工干预分镜编辑器

Human-in-the-Loop 设计，教师可在 AI 生成后自由修改旁白、调整分镜顺序、替换素材，保持教学主导权。

06

三种输出格式

支持 16:9 横屏（课堂投影）、9:16 竖屏（手机观看）、压缩版（快速分享）三种格式，一键切换适配不同场景。

降级兜底策略

全链路容错设计，任意环节失败都有对应的降级方案

失败环节 一级降级 二级降级 状态
联网搜索失败 使用本地 RAG 缓存的知识库数据 跳过知识增强，保留 PPT 原始内容 可用
AI 生图失败 调用备用图像生成模型（DALL·E → Stability） 使用预置占位图 + 关键词文字叠加 可用
TTS 配音失败 自动切换备选 TTS 引擎（Edge TTS → Azure Speech） 使用系统默认语音或生成无声视频 + 字幕 可用
视频合成失败 降低输出分辨率 / 帧率后重试 输出 PPT + 音频包，教师可用本地软件合成 可用
整体流程崩溃 保存已完成的中间产物（分镜 JSON + 已生成素材） 提供断点续传接口，教师可从上次失败处继续 可用
