数据源分离架构

热梗库与情感台词库彻底分离，各自独立管理、独立更新，互不依赖。

📦 hotwords.json · 网络热梗库

仅用于生成商店限时商品和任务名称。

"trending_words": [ "尊嘟假嘟", "哈基米", "搭子", ... ]
管理器：HotwordManager（单例）
更新频率：每小时自动拉取一次，失败用本地缓存兜底
消费方：shop.py（生成热梗商品）、task_manager.py（生成热梗任务）、memory_archives.py（归档）

💬 sweet_talk.json · 情感台词库

仅用于桌宠左键点击、定时互动弹出的撒娇/情话内容。

"cute_lines": [ ... ]
"love_words": [ ... ]
"coquettish_lines": [ ... ]
管理器：SweetTalkManager（单例）
更新频率：每两周自动拉取一次，失败用本地缓存兜底
消费方：pet_window.py（互动台词弹出）

模块职责一览

核心模块

main.py核心
class NuanBanApp
程序入口与主窗口。集成所有模块，构建菜单栏、聊天区、状态栏，协调热词更新与网络监控。
pet_window.py核心
class PetWindow
桌宠悬浮窗口。无标题栏置顶半透明，支持漫游/拖拽/鼠标跟随三种移动模式。从 config.json 读取 pet_image_path 加载图片，仅读取 sweet_talk.json 获取互动台词。
hotword_manager.py数据源
class HotwordManager (单例)
网络热梗库管理器。仅负责 hotwords.json 的加载、保存、联网更新。提供 get_trending_words() 接口供消费方调用。每小时更新。
sweet_talk_manager.py数据源
class SweetTalkManager (单例)
情感台词库管理器。仅负责 sweet_talk.json 的加载、保存、联网更新。提供 get_random_interaction_line() 接口。每两周更新。

业务模块

shop.py业务
class ShopWindow
商店窗口。常驻商品 + 季节限定 + 热梗限时商品。热梗商品由 HotwordManager.get_trending_words() 自动选取 2-3 个生成，有效期绑定当前季节。
task_manager.py业务
class TaskManager
任务管理器。常驻（固定2个，奖励基础金币）、热梗（1-2个/小时，奖励热梗币）、季节（1-2个/季，奖励季节币）三类任务。接取后等待5秒模拟完成。
task_window.pyUI
class TaskWindow
任务面板界面。展示三类任务标签页，显示三种货币余额，接取任务与奖励结算。
backpack.pyUI
class BackpackWindow
背包窗口。道具背包与纪念品两个标签页，支持使用道具。

养成系统

save_manager.py养成
class SaveManager (单例)
存档与配置管理器。读写 config.json 和 save.json，支持回调订阅，重启自动加载所有养成数据与设置。
tics_engine.py养成
class TicsEngine
口癖引擎。多形态口癖（默认/开心/困倦/撒娇）随桌宠状态切换，学习模式自动记录用户高频语气词，持久化到 tics_config.json。
name_engine.py养成
class NameEngine
称呼引擎。多形态称呼随状态切换，学习用户偏好称呼，持久化到 name_config.json。
personality_config.py养成
class PersonalityConfig
人设配置管理器。读写 personality_config.json，提供人设信息（名字/身份/语气/简介/问候语）给对话引擎。

辅助模块

network_manager.py辅助
class NetworkManager (单例)
网络状态管理器。每30秒检测连通性，区分 WiFi/移动/离线，状态切换时通知订阅者，离线时降级使用本地缓存。
answer_provider.py辅助
get_default_provider()
搜索问答端口。请求公共搜索 API 返回网页摘要，预留接口允许替换为 AI 对话模型，离线时自动降级。
memory_archives.py辅助
class MemoryArchives (单例)
记忆库核心。自动归档热词按日期存储，6个月期限自动清理，已收藏为纪念品的热词永久保留。
memory_ui.pyUI
class MemoryArchivesWindow
记忆库界面。左侧月份列表，右侧热词详情，支持搜索/导出/收藏标记。
live2d_driver.py辅助
class Live2DDriver (单例)
Live2D 模型驱动。管理模型目录，检测可用模型文件。

核心特性

桌宠独立悬浮窗

无标题栏、置顶、半透明，与主窗口互不冲突。透明色 #ff00ff 实现穿透。

图片路径配置化

pet_image_path 字段读取，用户改配置文件即可换形象，无需改代码。

数据源彻底分离

热梗库与台词库独立管理器、独立更新频率，互不依赖。

透明度独立控制

main_alpha 与 pet_alpha 分离，主窗口与桌宠透明度互不影响。

三种移动模式

自由随机漫游、手动拖拽、鼠标跟随，可独立切换。

本地持久化

config.json + save.json，重启自动加载养成数据与设置。

记忆归档系统

热词按月归档，6个月自动清理，收藏纪念品永久保留。

口癖与称呼学习

自动记录用户高频语气词与偏好称呼，融入后续对话。

网络降级机制

离线时自动降级使用本地缓存，保证核心功能可用。
