赛道：学习工作

一、创意名称 + 创意介绍

创意名称

PaperMind - 科研文献智能工作台

想解决什么问题

科研工作者每天阅读大量文献，却面临笔记碎片化、标注分散、文献管理繁琐的难题。论文的关键观点难以快速回顾，AI辅助写作的潜力尚未被充分利用，知识沉淀效率低下。

为什么会想到做这个

作为科研人员，深知文献管理和知识整理的痛点。市面上的工具要么功能单一，要么过于复杂，缺少一个将阅读、笔记、AI辅助融为一体的一站式平台。

大概是什么产品

一个面向科研工作者的全栈Web平台，集成PDF阅读标注、知识笔记、AI写作辅助于一体，所有数据本地化存储。

二、目标用户及痛点

面向哪些用户

高校研究生、科研机构研究员、企业研发人员等需要大量阅读和整理学术文献的人群。

在什么场景下使用
  • • 精读论文时添加高亮标注和旁注
  • • 撰写文献综述时快速回顾已读论文
  • • 写作论文时调用AI进行润色和翻译
  • • 日常科研记录和灵感捕获
当前痛点
  • ✗ PDF阅读和笔记分离，来回切换效率低
  • ✗ 文献标注分散在不同工具中，难以统一管理
  • ✗ DOI元数据需要手动录入，费时费力
  • ✗ AI写作辅助与文献知识库脱节，生成内容缺乏针对性

三、价值与意义

效率提升

通过双栏阅读模式，科研人员可在阅读PDF的同时直接记录笔记，标注内容与文献自动关联。DOI一键导入功能将文献录入时间从分钟级缩短到秒级，AI辅助的摘要生成、论文推荐等功能大幅提升知识获取效率。

知识沉淀

块级引用和双向链接功能让笔记之间形成知识网络，配合图谱可视化，帮助用户发现文献间的关联，促进知识整合和创新。

四、核心差异化优势

对比维度 PaperMind 传统工具（Zotero/EndNote）
使用门槛 ✓ 无需下载插件，直接使用 ✗ 需要安装客户端，配置复杂
成本 ✓ 完全免费 ✗ 高级功能需付费订阅
AI能力 ✓ 内置AI记忆系统，自动建立知识关联 ✗ 无AI功能或需额外配置
数据存储 ✓ 全本地化，隐私安全 ✗ 依赖云端或本地文件
知识图谱 ✓ 自动生成文献关联图谱 ✗ 无图谱功能

五、功能特色

📄

PDF智能阅读标注

  • 支持高亮、下划线、旁注三种标注类型
  • 双栏阅读模式：左PDF右笔记，同步滚动
  • 标注位置精确定位，支持点击跳转
🔍

DOI一键导入

  • 输入DOI自动查询CrossRef获取元数据
  • 支持从综述参考文献批量导入文献
  • 自动去重，避免重复录入
🧠

AI记忆系统

  • 标注内容自动关联到笔记
  • 笔记间自动建立知识图谱
  • AI辅助生成论文摘要和推荐相关论文
🌐

知识图谱可视化

  • 文献间引用关系图谱
  • 笔记与文献的关联图谱
  • 支持图谱导航和快速跳转
✍️

写作辅助

  • 多种引用格式支持（APA、MLA、Chicago等）
  • AI文本润色和翻译
  • 块级引用，笔记内容复用
💾

数据安全

  • 全本地化存储，隐私安全
  • 支持一键备份和恢复
  • 所有数据可导出为标准Markdown文件

六、技术方案

架构设计
Vue 3 + TypeScript Node.js + Express Tailwind CSS PDF.js 本地文件系统
核心技术亮点
  • • 全本地化存储：所有数据存储在用户本地目录，支持随时导出
  • • 实时同步：数据变更实时通知，无需手动刷新
  • • 安全防护：路径遍历防护、API密钥后端存储

七、可行性分析

合规性

使用自行撰写的示例论文进行功能演示，用户上传的文献仅在本地处理，不涉及版权问题。

冷启动策略

从综述参考文献自动导入：一篇综述通常引用几十上百篇文献，用户导入一篇综述就能获得初始知识网络，快速感受到图谱功能的价值。

功能分层
  • • 有API密钥：享受完整AI功能（摘要生成、论文推荐、写作辅助）
  • • 无API密钥：核心价值仍在（文献提取、图谱建立、笔记跳转）
数据安全

全本地化存储，用户数据完全可控。支持一键备份和恢复，所有数据可导出为标准Markdown文件。
