问题背景

三代人的情感纽带，正在被屏幕隔断

年轻人学业工作繁忙缺少陪伴祖辈的渠道，老年人独居孤单、不会使用复杂数码产品，祖孙之间存在数字鸿沟与情感沟通断层。

👴

老人的困境

不会操作普通视频软件，打字、调画面操作复杂；独自在家缺少倾诉对象，长期独居产生深度孤独感。

👦

孙辈的缺位

学业繁忙，普通通话枯燥乏味，缺少轻松有趣的和祖辈互动方式，容易在忙碌中忽略老人的感受。

💔

两代人的断层

缺少共同娱乐载体，通话仅简单寒暄，很难产生深度情感交流，隔代亲情在时间中逐渐变淡。

P0 必做

语音明信片

"想到你了，但不用即时响应"

解决老人不会打字、打电话怕打扰的痛点。一种"异步情感表达"方式——长按录音，松手即送， 即使孙辈只点一个"抱一下"，老人也能收到回应。

祖辈端操作
打开首页，点击超大按钮"给孙孙说句话"
长按录音（最长60秒），松手自动发送
可选：加一张照片，调起摄像头直接拍照
发送后显示信封动画："已送到，等孙孙回信哦"
孙辈端操作
收到微信推送："爷爷给你寄了一张明信片"
打开信封，播放语音 + 查看照片
可回复语音/文字，或直接点"抱一下"

设计要点

  • 祖辈端零文字输入，全程语音操作
  • 异步通信，不要求即时响应
  • "抱一下"即完成情感反馈闭环
  • 技术难度：低，小程序录音API + 消息推送

P0 必做

今日合拍

"同一个主题，两个视角的生活"

每天发布一个拍摄主题，祖孙各自拍一张，拼在一起看。把"今天你的窗外是什么样"变成轻量日常互动， 低成本高频率，每天都有理由打开。

祖辈端操作
首页出现今日主题卡片，大字显示主题
点击"拍一张" → 调起相机 → 拍完自动上传
自动匹配孙辈照片，左右拼成一张合拍卡片
孙辈端操作
收到推送："爷爷已经拍好了，就等你了"
拍完后生成合拍卡片，可分享到朋友圈

设计要点

  • 拼图自动生成，不需要任何编辑操作
  • 预设30天主题库自动轮换，降低运营负担
  • 让老人觉得自己的日常被关注和看见
  • 技术难度：低，图片拼接 + 每日主题配置

P1 重要

家味菜谱

"想念奶奶做的菜，那就亲手学着做"

把最普遍的隔代情感符号——"想念奶奶做的菜"——变成可操作的互动。祖辈分步录制菜谱， 孙辈跟着做、打卡拍照，成品发给爷爷点评。不只是菜谱，是家庭味道的数字化传承。

祖辈端：录制菜谱
选择"教一道菜" → 语音说菜名
分步骤录制：每步一段语音 + 一张过程照
自动生成菜谱卡片，推送给孙辈
孙辈端：跟着做
收到菜谱，分步图文 + 语音讲解
跟着做，每步拍照"打卡"
成品发给爷爷 → 爷爷语音点评

设计要点

  • 菜谱可被家庭成员共享，沉淀家族味道
  • 打卡照片自动归档成"家味菜谱册"
  • 情感锚点最强，有天然传播性
  • 技术难度：中，分步骤卡片 + 打卡 + 评论

P1 重要

陪伴日历

"把'想起来才联系'变成'自然的习惯'"

陪伴容易三天热度。陪伴日历通过可视化互动记录、轻度游戏化徽章驱动习惯养成， 孙辈端有成就激励，祖辈端是纯粹的"照片墙"情感收获。

孙辈端
日历视图记录每日互动：语音、合拍、菜谱、通话
连续7天互动解锁陪伴徽章
每月生成陪伴报告卡片，可分享
祖辈端
一面自动归档的"照片墙"
每收到一次互动，墙上多一张照片
不需要主动操作，纯粹的情感收获

设计要点

  • 轻度游戏化驱动习惯，但目标是"自然"非"任务"
  • 祖辈端无任何考核感，只有"充实感"
  • 年底可生成"年度陪伴相册"纪念品
  • 技术难度：中，日历逻辑 + 统计 + 徽章 + 报告

P3 远期

亲情智能相框

"不用操作，也能看见你"

老人不会翻手机相册，需要一种"被动陪伴"方式。相框绑定小程序后， 照片和明信片自动推送展示，收到新消息时柔光提示。零操作的陪伴体验。

核心功能
孙辈点"发到相框" → 照片自动推送到相框
相框默认循环展示家庭照片，无需操作
收到语音明信片 → 相框边缘亮灯 → 点击播放
"隔空拥抱"：点抱一下 → 相框出现温暖动效
进阶功能
日常拍照可选"家里的也能看"，自动同步
白天显示生活照，晚上显示合影照
节假日自动优先显示节日照片

设计要点

  • 核心价值：零操作陪伴
  • 初期与现有智能相框厂商合作定制固件
  • 建议小程序验证需求后再推进硬件
  • 技术难度：中高，需硬件联网 + 推送协议
