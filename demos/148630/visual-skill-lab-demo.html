🔄 执行步骤

  1. 解析用户请求 — 路由到对应风格模板
  2. 组装结构化提示词 — 含风格锚点、场景主题、UI模式
  3. 调用图像生成工具 — 按指定比例出图
  4. 风格与质量自检 — 不达标自动重绘一次
  5. 返回最终结果 — 附带提示词与元信息

✅ 必过检查项

  • ✓主体清晰可识别，符合主题描述
  • ✓风格特征明显，对应游戏视觉锚点到位
  • ✓UI 元素与游戏类型匹配
  • ✓画面无明显畸形、错字、穿模
  • ✓色彩与光影符合风格基调

⚠️ 风险与约束

  • ⚠复杂文字场景可能出现文字错乱
  • ⚠多人物互动场景可能出现比例失调
  • ⚠首次生成可能需要调整提示词迭代

WORKFLOWS

六条输出工作流

每条工作流都有明确的输入输出契约、关键约束与质检标准，确保输出稳定可预期。

🖼️

普通图片生成

基础文生图工作流，支持 7 种风格路由与 3 种 UI 模式。

  • 支持 16:9 / 1:1 / 9:16 三种比例
  • 风格自动路由到对应提示词模板
  • UI 元素按游戏类型自动匹配
  • 自动重绘最多 1 次
  • 可切换「只写提示词」模式
👤

人物照片风格化

上传真人照片，统一重绘为目标画风，保留身份可识别度。

  • 身份锚点：脸型、眉眼、发型轮廓
  • 重设计：衣着、道具、动作、光照
  • 禁止：照片脸贴背景、绿幕抠图感
  • 像素风降级为轮廓+主色+表情
  • 支持多人场景统一画风
🔮

空间景深预览

生成图片 + 深度图，WebGL 实现苹果空间照片式视差效果。

  • displacement 模式：Shader 位移（推荐）
  • mesh 模式：细分网格透视
  • 无深度图时自动启发式生成
  • 单文件 HTML，离线可看
  • 鼠标 / 触摸平滑跟随
🎬

5 秒 / 10 秒视频

文生视频 / 图生视频，基于 CogVideoX API。

  • 仅支持 5 秒（默认）或 10 秒
  • 默认 1920×1080 / 30fps
  • 支持文生视频 + 图生视频
  • macOS Keychain 安全存储密钥
  • 异步轮询，900 秒超时
🌐

360° 全景图

等距柱状投影全景图，WebGL 可拖拽预览，支持动态增强。

  • 严格 2:1 宽高比，左右无缝衔接
  • 非 2:1 自动规格化（stretch/crop/pad）
  • 静态 WebGL 查看器：拖拽、缩放、复位
  • 动态增强：云雾、粒子、巡游、呼吸
  • 单文件 HTML 内嵌 base64 图片
🎥

360° 全景视频

全景图生视频 + 360° 全景视频预览器。

  • 先生成 2:1 全景底图
  • 调用 CogVideoX 图生视频
  • 输出 360° 全景视频预览 HTML
  • 支持帧序列预览模式
  • 视频纹理 WebGL 采样

QUALITY

技术与质量保障

每条工作流都有明确的技术规格与质检标准，输出可预期、可复现、可验证。

📐 2:1 全景比例

360° 全景图严格遵循等距柱状投影 2:1 宽高比。非 2:1 图片自动通过 normalize_equirectangular_aspect.py 规格化，支持 stretch / crop / pad 三种模式。

🎯 身份锚点

人物照片风格化时，明确定义保留项（脸型、眉眼、发型轮廓、气质）与重绘项（衣着、道具、动作、光照），像素风自动降级为轮廓+主色+表情符号，确保身份可识别。

🪟 WebGL 预览

全景与空间预览均采用原生 WebGL + GLSL Shader 实现，不依赖任何第三方库。图片以 base64 内嵌，生成单文件 HTML，离线可打开、可分享。

⏱️ 5/10 秒时长

视频生成严格遵循 CogVideoX 能力边界，仅支持 5 秒（默认）或 10 秒两种时长，1920×1080 分辨率，30fps。不承诺做不到的事。

🔐 密钥不落盘

视频生成 API Key 通过 macOS 钥匙串（Keychain）安全存储，首次使用弹出系统对话框隐藏输入。支持环境变量覆盖，密钥从不写入 Skill 目录。

🛡️ 自动依赖引导

需要 Pillow/NumPy 的脚本通过 run_with_deps.py 启动，自动创建 .venv 安装依赖。白名单机制仅允许执行指定脚本，保障安全。

📦 技术栈

  • Skill 框架 Codex Skill System
  • 后端脚本 Python 3.9+
  • 前端预览 原生 WebGL + Canvas
  • 视频生成 BigModel / CogVideoX
  • 图像依赖 Pillow + NumPy（可选）
  • 密钥管理 macOS Keychain
