归位 Guiwei

本地优先的家庭物品定位应用。
五级层级结构化管理，QR / NFC 扫码即查，让每一件物品都有迹可循。

核心功能特性

🏘️

五级层级结构

House → Floor → Room → Container → Item 完整映射真实家居收纳结构，层级导航清晰直观

📱

多种物理输入

支持 QR 码扫码、1D 条形码识别和 NFC 近场通信，Android / iOS / Windows 全平台覆盖

🔍

智能搜索

关键词搜索覆盖名称、标签、备注，实时响应快速定位，v1.2 将升级 FTS5 全文索引

🔒

本地优先 · 零隐私妥协

所有数据存储在设备本地 SQLite，无账号、无网络、无上传，家庭物品隐私完全自主掌控

📷

物理码生成

为任意层级生成 QR / NFC 码，截图保存或打印贴在实体位置，扫码直达目标

🗑️

软删与级联

支持软删除和级联软删，删除层级时自动处理下属数据，保留历史支持未来恢复

数据层级模型

7 张表 + 16 个索引 + XOR 约束，结构性表达家居收纳空间

House 房子
↓
Floor 楼层
↓
Room 房间
↓
Container 容器
↓
Item 物品
层级中文核心字段关系
House房子id / code / name / address1:N Floor
Floor楼层id / code / houseId / level / nameN:1 House; 1:N Room
Room房间id / code / floorId / nameN:1 Floor; 1:N Container/Item
Container容器id / code / roomId / name / typeN:1 Room; 1:N Item
Item物品id / code / name / tags / noteN:1 Container 或 N:1 Room

码标识系统

统一 payload 格式，扫码即可反查层级或物品，O(log n) 命中

📱
QR 码
最通用格式，相机即扫，支持导出分享
guiwei://room/3f9b1c4e-7a82-4d1f-9e3a-2c5b8e6f1a4d
🏷️
1D 条形码
兼容现有条码体系，仓储场景友好
guiwei://item/1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d
📡
NFC 标签
靠近即识别，适合贴在抽屉/柜门外侧
guiwei://container/5f4d3c2b-1a09-8b7c-6d5e-4f3a2b1c0d9e

核心使用流程

STEP 01
建立层级库
从创建房子开始，逐层建立收纳结构：House → Floor → Room → Container
STEP 02
生成物理码
为房间、容器生成 QR / NFC 码，截图保存或打印贴在实体位置
STEP 03
添加物品
手动选择位置、扫码选位置或 NFC tap，三种方式添加物品并记录详情
STEP 04
查找物品
关键词搜索、导航式浏览或扫码 / NFC，三种方式快速定位物品
STEP 05
管理与维护
修改物品信息、移动位置、软删操作，支持级联删除和位置变更

项目特色

1

本地优先，隐私零妥协

无账号、无登录、无网络请求、无会员付费，家庭物品数据永不上传

House → Floor → Room → Container → Item，贴合真实家居收纳逻辑
