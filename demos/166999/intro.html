核心特性

把现实画面，
炼成流动的玻璃。

从摄像头采集到最终成帧，每一帧都流经一条模块化的 GPU Pass 管线。新增 Shader 只需新增 Pass，无需改动既有代码。

01 · CAPTURE

实时摄像头后处理

getUserMedia 采集 MediaStream，作为 Video Texture 直接进入 GPU 管线，零 CPU 拷贝。

02 · PIPELINE

9-Pass Frame Graph

Frame Graph 思路串联 9 个独立 Pass，双缓冲 RenderTarget ping-pong，与 Unreal / URP 同构。

03 · RIPPLE

交互式水波涟漪

点击产生涟漪、拖动绘出连续波纹、双指缩放玻璃，多指触摸与鼠标皆可驱动。

04 · GLASS

液体玻璃 Shader

Blur + Refraction + Fresnel + Specular + Bevel + Thickness + Edge，复刻 Apple Liquid Glass 质感。

05 · PRESETS

四种艺术预设

Original / Dreamy / Cyber / Subtle 一键切换，参数通过 localStorage 持久化保存。

06 · MONITOR

实时性能监控

FPS、分辨率、当前激活 Pass 列表、GPU 后端类型一览，桌面 1080P 稳定 60 帧。

渲染管线

从摄像头到屏幕，
一条 Frame Graph。

每帧画面依次流经 9 个独立 Pass，模块解耦、顺序可循。这正是高端实时图形引擎的通行结构。
