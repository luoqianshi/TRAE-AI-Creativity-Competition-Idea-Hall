1. 创意名称 + 创意介绍

创意名称：心语树洞 - AI心理陪伴助手

想解决什么问题： 青少年在成长过程中面临学业压力、人际关系困扰、自我认同迷茫等心理问题，但很多人不愿向家长或老师倾诉，导致情绪积压。传统心理咨询资源有限且门槛高，无法满足大量青少年的即时需求。希望用AI技术为青少年提供一个安全、私密、随时可用的心理陪伴空间。

为什么会想到做这个： 去年暑假，我参加了社区志愿者活动，接触到一些初中生。有个女孩告诉我，她经常失眠但不敢跟父母说，怕被骂"矫情"。还有个男孩说，他因为成绩下滑感到很焦虑，但不知道该跟谁说。这些经历让我意识到，很多青少年需要一个能安心倾诉的地方，而AI可以成为很好的倾听者和陪伴者。

大概是什么产品： 一个Web端的AI心理陪伴平台，包含情绪日记、AI陪伴聊天、正念冥想引导、情绪分析报告等功能，用温暖的视觉设计和亲切的交互体验，为青少年提供安全的心理倾诉空间。

2. 目标用户及痛点

面向哪些用户：

  • 12-18岁青少年（初中、高中生）
  • 面临学业压力、人际关系困扰的学生
  • 性格内向、不愿向他人倾诉的青少年
  • 需要情绪管理指导的年轻人

在什么场景下使用：

  • 学习压力大、感到焦虑时
  • 和同学/朋友发生矛盾后
  • 深夜失眠、情绪低落时
  • 考试前后感到紧张时
  • 需要找人倾诉但身边没人时

当前痛点：

  • 不愿向家长/老师倾诉，怕被误解或批评
  • 心理咨询资源有限，预约困难且费用高
  • 缺乏即时性，情绪上来时无法立刻获得帮助
  • 没有安全、私密的倾诉空间

3. 价值与意义

社会价值： 为青少年提供一个无偏见、无条件接纳的心理陪伴空间，帮助他们释放情绪、缓解压力，促进心理健康成长。通过AI技术降低心理支持的门槛，让更多有需要的青少年能够获得帮助，减少因心理问题导致的不良后果。

效率提升： AI可以24小时随时响应，提供即时的情绪支持和心理疏导。通过情绪日记和分析功能，帮助青少年更好地了解自己的情绪变化规律，培养自我调节能力。冥想引导功能可以快速帮助用户放松身心，提高学习和生活效率。

四

技术实现方案 Web + AI 服务

核心 Prompt 设计思路

你是一位温暖、耐心的心理陪伴助手"小树"，擅长倾听青少年的烦恼，给予无条件的接纳和支持。

请按照以下原则与用户交流：
1. 始终保持温和、亲切、不评判的态度
2. 多倾听，少说教，用开放式问题引导用户表达
3. 当用户情绪低落时，先共情再给予建议
4. 如果用户有伤害自己的倾向，引导他们寻求专业帮助
5. 语言简洁易懂，避免使用专业术语

常用回应方式：
- 共情："我能感受到你现在很难过..."
- 鼓励："谢谢你愿意和我分享这些..."
- 引导："你愿意多说一点吗？"
- 支持："无论发生什么，你都不是一个人"
