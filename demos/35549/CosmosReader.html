01 — 创意概览

重塑人类与长文本的交互方式

🌌

创意名称

Cosmos Smart Reader · 星图知识重构白板
Canvas-Based Knowledge Engine

🎯

核心解法

将传统的“从上往下读文档”，转化为“在一张无限画布上逛地图”。利用大语言模型（LLM）实时提取长文本中的概念实体，并在右侧直接渲染为动态连接的知识图谱，打破线性阅读瓶颈。

💡

灵感来源

现代人每天面临海量论文、API 文档、架构设计图。我们发现，最顶尖的工程师和学者在阅读时，脑海中浮现的不是“文字段落”，而是“网状概念”。为什么不让 AI 直接帮你把这张网画出来？

💻

产品形态

这是一个典型的 AI 原生 Web 应用。左侧是原文档阅读区，右侧是无限 Canvas 画布。鼠标悬停左侧任意专业词汇，右侧画布会瞬间点亮该节点及其上下游知识脉络。完全符合 Trae 大赛倡导的“极致体验与效率提升”。

02 — 痛点分析

传统阅读工具的三个“硬伤”

当下主流的 AI 阅读助手（如 ChatPDF、侧边栏 AI）依然停留在“你问我答”或“总结全文”的维度，没有从根本上改变信息的组织和视觉呈现方式。

01

全局观缺失

面对长篇架构文档或论文，读者极易陷入细节而迷失宏观逻辑。AI 的单段翻译无法还原作者的思想骨架。

02

注意力碎片化

遇到不懂的概念，需要开新标签页去 Google，查完切回来已经忘了上下文，知识链条被频繁打断。

03

沉淀成本极高

看完了长文，如果想做笔记，需要手动复制粘贴到 Notion 或 Obsidian，过程枯燥且不易维护图谱关系。

04 — 产品设计

重构阅读体验的 4 大杀器

  • ✓

    非线性“星图”生成 (Semantic Canvas Extraction)

    导入 PDF、网页 URL 或 Markdown，AI 后台进行分块处理，提取出核心实体和层级关系，并在右侧画布瞬间生成一张拓扑脑图。文章结构一目了然。

  • ✓

    左滑右亮：双向语义锚点

    鼠标在左侧文档的某个概念上悬停（如“分布式锁”），右侧画布对应的节点瞬间发光放大；反之，点击右侧图谱上的节点，左侧文档自动平滑滚动到对应出处。

  • ✓

    语义缩放 (Semantic Zooming)

    在画布上，滚轮缩小看到的是宏观目录脉络；滚轮放大节点，节点会自动展开出 AI 翻译的“大白话解释”、“关键公式”或“核心代码段”，无需回到原文。

  • ✓

    积木式知识库沉淀 (Drag & Drop Memo)

    阅读中遇到有价值的卡片，直接拖拽到自己的“私人工作台”。支持多个文档生成的卡片互相连线组合，最终一键导出为 Markdown、Anki 卡牌或 Obsidian 兼容格式。

05 — 技术实现

AI 原生的现代技术架构

前端：极致交互

Next.js 14 App Router ReactFlow / D3.js Tailwind CSS Zustand 状态管理 Framer Motion (动画) Radix UI

后端：大模型与数据处理

Trae IDE (极速开发) DeepSeek/Claude API LangChain (文档拆分) Pinecone (向量检索) FastAPI (Python)

核心机制：图谱映射与 RAG 融合

EdgeWeight(A, B) = α * CosineSim(Emb(A), Emb(B)) + β * Co-occurrence(A, B)

文档导入后，首先进行智能 Chunking，利用 LLM 提取 `[Entity 1, Relationship, Entity 2]` 三元组，存入图数据库。随后通过向量化（Embedding），计算实体间的语义相似度和共现频次，动态计算图中边缘（Edge）的权重，确保渲染的连线逻辑严密、无冗余。

06 — 商业与社会价值

重塑生产力的护城河

🚀

10x 学习效率提升

将阅读一篇 30 页英文文献的时间从 2 小时压缩至 15 分钟。通过视觉化降维，极大降低了认知负载，让人类大脑专注于“思考结构”，而非“死记硬背”。

🔗

破除数据孤岛

对于企业而言，大量的历史文档、架构设计往往无人问津。Cosmos Reader 可以作为一个企业级中间件，将死寂的文档库转化为活性的、可交互的企业知识图谱。
