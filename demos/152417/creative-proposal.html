1. 创意介绍

RA 是一个 AI 原生的长期 Research Space，不是搜索引擎、不是文献管理器，也不是聊天机器人。它围绕一个研究方向（Research Direction）持续运行：自动扫描学术来源（当前 MVP 以 arXiv / OpenAlex 等 AI/ML 源为验证），发现相关论文与代码/模型/数据集 artifact，按相关性与新颖性排序，提取任务、方法、数据集、指标、基线、局限等结构化信息，并生成带有证据链的周度研究简报。研究者通过结构化反馈（保存、忽略、待跟进、缺 artifact 等）让下一次扫描更贴合自己的方向。

虽然当前 MVP 优先验证 AI/ML 方向（论文 API 成熟、研究对象数字化程度高、 early adopter 接受度好），但底层循环——方向 → 情报 → 结构化证据 → 实验/声明 → 简报 → 反馈——对所有需要长期跟踪文献、实验和证据的研究者都适用。

一句话定位：把“搜索→读论文→记笔记→跑实验→写文档”的复制粘贴循环，替换成“方向→情报→结构化证据→实验/声明→简报→反馈”的闭环系统。

2. 我们发现了什么痛点？

信息过载 以 AI/ML 为例，arXiv 每日新增数百篇论文，任何领域的研究者都难以持续跟进自己真正关心的方向。
工具碎片化 搜索、文献管理、代码/数据集发现、实验跟踪、写作评审分散在不同工具中，反复复制粘贴。
证据易丢失 读完论文后的判断、为什么重要、哪些声明可信，往往只留在个人笔记里，难以复盘和共享。
模型输出不可信 通用大模型容易把摘要内容当成全文结论，缺少来源、范围和审核边界。

3. 核心产品循环

研究者只需创建一个方向，其余环节由 Agent 自动推进，关键决策保留人工 gate。

创建方向 → 配置来源/主题 → Source Run 扫描 → 候选排序 → 结构化提取 → 证据链检查 → 生成简报 → 反馈更新方向

关键设计原则

  • 来源可审计：每次 source run、每个候选、每条声明都保留来源与检查记录。
  • 范围可见：摘要级、元数据级、全文级的证据范围在 UI 中明确标注，不会把摘要当全文结论。
  • 证据先于断言：Agent 不能发布无证据引用的声明；检查器会拦截 unsupported claim。
  • 反馈即数据：研究者的一次“保存/忽略/待跟进”会被持久化为结构化反馈，用于下一次排序与方向画像更新。

4. 目标用户与使用场景

核心用户：所有需要长期跟踪文献、实验和证据的研究者。首发验证人群为 AI/ML 方向的研究型硕士/博士生、AI 实验室应用研究工程师、研究小组负责人。

典型场景：

  • 周一早上打开 Workspace，查看“本周我的方向有什么变化”。
  • 在 Inbox 中用键盘批量 triage 候选文献（j/k 移动，s 保存，d 忽略，n 标记待跟进）。
  • 进入 Candidate Detail，先看“为什么被推荐”“证据范围”“不确定项”，再看原始元数据。
  • 周五阅读 Briefing，检查被拦截的声明、来源失败和推荐清单，提交反馈。

6. 价值与意义

效率价值：把研究者从“每天刷 arXiv + 手动整理笔记”的重复劳动中解放出来，把有限时间投入到高价值的科学判断和实验设计。

质量价值：通过证据链、范围标注和检查器，降低大模型幻觉导致的误判风险，让研究决策更可追溯。

长期价值：方向级别的持续记忆和结构化反馈，让 Agent 越用越懂研究者的真实偏好，逐步形成“研究记忆库”。

7. 初赛 Demo 计划

报名通过后，初赛将交付一个可运行的 Demo：用户可以在浏览器中创建一个研究方向（当前演示以 AI/ML 为例），触发 source scan，查看排序后的候选 inbox，进行结构化 triage，查看带证据链的候选详情，并提交反馈。所有关键路径均通过 Playwright smoke test 覆盖，确保“5 分钟完成第一次研究闭环”。
