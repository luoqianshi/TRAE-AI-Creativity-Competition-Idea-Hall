创意介绍

想解决什么问题
瑜伽初学者在家练习时缺乏专业指导，姿势不正确不仅达不到效果，还可能导致运动损伤。传统视频教学无法实时反馈纠正，用户难以判断自己的动作是否标准。
为什么会想到做这个
在疫情期间，居家运动成为常态，但很多人因缺乏专业指导而放弃。我们希望借助AI技术，将专业瑜伽教练"搬"到用户家中，让每个人都能以低成本获得个性化指导。灵感来源于看到身边朋友因姿势不当导致腰部受伤的经历。
大概是什么产品
一款基于Web的AI瑜伽学习应用，通过摄像头实时捕捉用户动作，利用AI视觉模型分析姿势准确度，并通过语音即时给出纠正指导，帮助用户掌握正确的瑜伽练习方法。

目标用户及痛点

面向哪些用户
瑜伽初学者 上班族 居家运动爱好者 中老年人群

核心用户是希望在家练习瑜伽但缺乏专业指导的人群，包括工作繁忙的都市白领、想要改善体态的学生、以及关注健康的中老年人。
在什么场景下使用
  • 🏠 居家练习：下班后在家进行15-30分钟的瑜伽放松
  • 🌞 晨间唤醒：早晨起床后进行简单的拉伸唤醒身体

当前痛点
  1. 缺乏实时反馈：观看视频无法知道自己动作是否正确
  2. 教练费用高昂：私教课费用让很多人望而却步
  3. 练习时间受限：无法随时找到合适的课程和教练
  4. 动作不当风险：错误姿势可能导致肌肉拉伤或关节损伤
  5. 缺乏坚持动力：独自练习容易半途而废

技术方案

核心技术
前端技术栈： React 18 + TypeScript + TailwindCSS + WebRTC摄像头采集
后端技术栈： Node.js + Express + TypeScript (ESM)
AI模型： MiniMax-3 abab6.5s-chat视觉分析 + T2A v2语音合成
关键能力： 实时视频帧捕获、AI姿势分析、语音指导反馈、二维码移动端访问
工作原理
  1. 用户通过浏览器授权摄像头访问
  2. 系统每秒截取一帧画面发送至AI模型
  3. AI分析人体骨骼关键点与标准姿势对比
  4. 生成针对性的语音纠正指导
  5. 通过Web Speech API实时播放指导语音
