Core Features

四个核心模块，覆盖养宠全场景

从健康管理到社交互动，一站式解决养宠人的高频需求。

01

宠物健康档案

一只或多只宠物的疫苗记录、驱虫记录、体重变化曲线、健康日志，全部数字化存储。疫苗接种自动计算下次到期时间，体重趋势一目了然。

02

智能提醒系统

疫苗到期前 7 天/3 天/1 天微信服务通知推送，驱虫、洗澡、剪指甲自定义提醒。再也不用担心忘记重要日期，系统帮你记住一切。

03

宠物身份证

每只宠物生成专属微信小程序码，贴狗牌上。路人一扫即可看到宠物信息 + 主人联系方式。走丢时这是最直接的寻回通道。

04

附近宠友社交

地图上发现附近宠物，发起遛狗邀请、组织宠物聚会、分享日常动态。让养宠不再孤单，狗狗也有自己的朋友圈。

新手铲屎官

User Scenarios

四个典型使用场景

A

新手引导

用户打开小程序 → 微信授权登录 → 添加第一只宠物 → 引导录入第一针疫苗 → 自动计算下次接种时间 → 开启提醒。

B

日常健康管理

收到疫苗到期推送 → 带宠物接种 → 录入新记录 → 系统自动计算下一针时间 → 体重有变化随时记录看趋势。

C

寻找遛狗搭子

开启位置共享 → 查看附近宠物 → 筛选同品种 → 发起遛狗邀请 → 对方接受 → 约定时间地点 → 遛狗后打卡。

D

宠物走失应急

打开宠物身份证 → 保存二维码 → 路人微信扫码 → 看到宠物信息 + 主人联系方式（脱敏）→ 一键拨打电话。

📈
