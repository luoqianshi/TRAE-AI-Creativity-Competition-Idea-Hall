银狐木马每年盗走数亿，
传统杀软为什么防不住？

银狐（SilverFox）是针对中国用户的顶级窃密木马家族，专门窃取网银、微信支付、企业财务系统等账户凭证。传统特征码查杀模式对新变种反应滞后，普通用户防护手段有限。

痛点：银狐为什么难防？

  • 每天多个变种，传统特征码跟不上
  • 使用合法的代码签名证书绕过白名单
  • 钓鱼域名全是 .com.cn，普通用户难辨别
  • DLL 侧加载手法隐蔽，静默窃取凭证
  • 针对财务人员的社工攻击精准高效

方案：XIGUA 如何解决？

  • ONNX 深度学习推理引擎，识别未知变种
  • 云端哈希库联动，毫秒级黑/白名单判定
  • Edge 浏览器扩展实时拦截钓鱼网站
  • MiniFilter 驱动层拦截，进程终止 + 文件隔离
  • EDR 行为监控，检测异常进程行为

核心功能

四大引擎联动，多层防护

每一层防护都针对银狐木马的不同攻击面，层层递进、相互补充。

Melix 深度学习引擎

基于 ONNX Runtime，提取 283 维特征向量，推理准确率 90%+。无需网络、毫秒级判定。

云端哈希库

与云端恶意/白名单哈希库同步，黑名单命中即时拦截，白名单跳过免误报。

MiniFilter 驱动防护

Windows 内核层文件系统过滤驱动，在进程访问文件时实时检测和拦截。

EDR 行为监控

通过 ETW 监控系统进程行为，检测异常操作（注册表修改、进程注入、横向移动等）。

Edge 浏览器扩展

基于 declarativeNetRequest 拦截银狐钓鱼域名，支持自定义黑名单规则。
