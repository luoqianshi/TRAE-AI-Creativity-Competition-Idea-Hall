Problem

为什么游戏美术资产生产这么痛？

无论是独立开发者还是小型工作室，角色动画资产的生产始终是项目瓶颈。

01
流程冗长，人力密集

传统流程需要概念设计、建模/绘图、骨骼绑定、逐帧动画、抠图导出等多个环节， 单个角色从设计到可用资产通常需要 3 ~ 7 天，涉及至少 2 ~ 3 个专业角色协作。

02
重复劳动，效率低下

抠图、裁剪、格式转换、序列帧导出——这些机械性工作占据了约 60% 的资产制作时间。 美术师的时间被低价值劳动吞噬，无法专注于创意本身。

03
门槛高，成本昂贵

独立开发者、Game Jam 参赛者、非美术背景的策划，即使脑海中有完美的角色构想， 也难以快速获得可用的动画素材，好想法被卡死在资产瓶颈上。

Solution

一句话输入，一整套资产输出

SpriteForge 将多模态 AI 模型编排为一条全自动生产线——从文字到可用资产，中间零人工干预。

01
文字即输入

自然语言描述角色外观，或上传一张参考图。无需专业美术技能，任何人都能启动生产。

02
预置动作模板

内置行走、奔跑、攻击、待机、受击、跳跃等标准动作模板，精心调优的提示词确保生成质量。

03
自动抠图合成

AI 语义分割自动移除背景，输出透明 PNG。告别 Photoshop 逐帧手动抠图的噩梦。

04
引擎级交付

输出 PNG 序列、GIF 动画、Sprite Sheet，直接拖入 Unity / Unreal / Cocos / Godot。

STEP 01 用户输入

用一段自然语言描述你想要的角色——"一个穿着破旧斗篷的精灵游侠，翠绿色眼睛，银色长发"。 或者，直接上传一张参考图片。系统接受文本与图像双通道输入，自动识别意图并进入下一步。 也支持选择资产类型：角色、武器、怪物、道具，系统自动匹配对应的生成策略。

STEP 02 角色标准化

AI 将你的输入解析并扩展为一份完整的角色规格文档：精确的外观描述、配色方案、身体比例、 风格标签（像素 / 卡通 / 写实）。这份标准化文档确保后续所有动作生成的视觉一致性—— 无论生成多少个动作，角色始终"长一个样"。用户可以在此步微调确认细节，或选择自动通过。

STEP 03 动作视频生成

系统根据预置动作模板（行走、奔跑、攻击、待机等）自动组装文生图 / 文生视频的提示词， 调用多模态生成模型（支持 Gemini、Stable Video Diffusion、用户自定义 API 等） 为每个动作独立生成一段流畅的角色动画视频。每个动作的提示词经过反复调优，确保 帧率稳定、运动自然、角色不变形。

GEMINI / SVDe CUSTOM API PROMPT ENGINEERED
STEP 04 脚本自动裁剪

用户指定需要的帧数（如"8帧行走循环"或"12帧攻击动作"），系统自动从生成的视频中 均匀采样裁剪。支持自定义起止区间、循环模式（loop / ping-pong）、帧率调整。 批量裁剪所有动作，一步到位。可视化预览让用户在裁剪前就能对比不同方案的效果。

FRAME SAMPLE LOOP / PING-PONG BATCH CROP
STEP 05 自动抠图

使用高精度语义分割模型（RMBG / SAM）自动移除每一帧的背景，输出透明 PNG。 边缘抗锯齿处理确保角色轮廓干净锐利，无需人工修边。支持自定义背景色或棋盘格预览， 批量处理所有帧——彻底消灭手动抠图。

RMBG / SAM ANTI-ALIAS BATCH PROCESS
STEP 06 资产交付

最终输出一套标准化的游戏美术资产包：PNG 序列帧（透明背景）、GIF 动画预览、 Sprite Sheet（横向拼接）、以及包含帧率和偏移量配置的 JSON 元数据文件。 所有格式直接兼容 Unity、Unreal Engine、Cocos2d、Godot 等主流游戏引擎， 解压即用，零额外配置。

标准化交付，引擎级兼容

每个资产包包含三种输出格式，覆盖从快速预览到引擎集成的全部需求。

{ PNG }
透明 PNG 序列

逐帧独立文件，带编号命名。直接拖入引擎的 Animation Controller，逐帧控制完全自主。

{ GIF }
GIF 动画预览

循环播放的动画预览文件。适合快速查看效果、团队沟通、文档嵌入，无需打开引擎即可验收。

{ SHEET }
Sprite Sheet + JSON

横向拼接的精灵表，附带帧率、偏移量、碰撞框等元数据。Cocos / Godot / Phaser 一键导入。
