中译中

把看不懂的中文，翻译成人话
一个面向普通用户的「中文语境翻译器」。先识别关键词和语境，再结合结构化词条库、示例解释、风险标签，最后由 AI 生成人话翻译。不是简单的聊天问答套壳。

一句话介绍

不是外语翻译，而是把满是圈层梗、术语、黑话和废话文学的中文句子，拆解成普通人能直接理解的人话。

📘 词典模式

词条库 + 关键词匹配，展示基础解释、示例句、所属圈层、风险标签。

✨ 中译中模式

AI 增强。整句人话翻译 + 潜台词 + 行动建议 + 风险提示。

痛点

每个字都认识，但整句话不知道在说什么。
  • 刷到一条带圈层梗的评论，别人都在笑，只有你没 get 到，只能默默划走。
  • 看直播时"家人们、闭眼上车、包的"一整段说完，你不确定主播是在营销还是真推荐。
  • 职场会议上"对齐打法、拉通、闭环"一堆词，新人不知道到底要做什么。
  • 传统搜索只能查单个词，没法解释整句含义、语气和风险。
  • 部分冒犯和低俗话术披着"网感"外衣传播，难以被及时识别。

它是怎么工作的

本项目由 AI 驱动，但不是简单的聊天问答套壳。每一次翻译都有明确的处理流程，输出结果可解释、可追溯。
STEP 1
关键词识别
对用户输入做分词和关键词匹配，找出句子里包含的梗、黑话、术语。
›
STEP 2
语境判断
根据关键词组合，判断所属语境——职场/直播/游戏/梗文化/专业领域等。
›
STEP 3
词条库查询
取出每个关键词的词条解释、示例句、所属圈层、风险标签。
›
STEP 4
AI 人话生成
在词条基础上，调用 AI 生成自然的整句翻译、潜台词和行动建议。

基础层 · 词条库驱动（无需 AI）

查词条、搜索关键词、展示基础解释、示例句、所属圈层、风险标签、相关词条。

增强层 · AI 补位（调用 API）

组合词条生成整句翻译、解释潜台词、判断语气、生成行动建议、处理新词。

目标用户

USER 01
普通用户 / 圈层梗读者
刷内容碰到看不懂的梗，想快速理解意思和风险。
USER 02
职场新人 / 实习生
开会听不懂术语，跨部门沟通被黑话绕晕。
USER 03
研发 / 测试 / 产品
面对"颗粒度/抓手/闭环/赋能"类表达，想快速落地。
USER 04
学习者与内容创作者
想理解行业术语、避免误用有风险的表达。

核心功能

01
词典模式
词条库 + 关键词匹配，无 AI 也可用。
02
中译中模式
整句人话翻译 + 潜台词 + 行动建议。
03
关键词识别
自动拆解句子中的黑话/术语/梗。
04
语境判断
识别职场、直播、游戏、梗文化等场景。
05
潜台词解释
解释字面之下真正想表达的意思。
06
风险提示
识别营销诱导/冒犯/低俗/攻击等风险。
07
每日热词
用户主动随机抽梗看，左滑右滑分辨 good/bad。
08
用户补充与纠错
审核制的词条共建，不做社交互动。

初赛 Demo 计划

  • 基础词条库：先定几个大类（职场/开发/直播电商/游戏电竞/互联网梗/专业术语/废话文学/影视台词梗），然后往里面逐条补充，约 200-300 条，手动维护。
  • 词典模式：关键词匹配、展示词条解释、示例句、所属圈层、风险标签。
  • 中译中模式：调用 AI API，演示整句人话翻译、潜台词、行动建议。
  • 每日热词 / 随机抽梗：卡片式交互，用户可随机抽词查看，并标记 good/bad。
  • 示例切换 + 交互页面（即本页所展示的流程）。
  • 不做社区 / 热帖 / 评论区 / 用户互关，聚焦翻译本身。

产品边界

它不是聊天社区，也不是吐槽平台。
  • 不做大广场、热帖、私信、用户互关、大型评论区。
  • 不做吵架排行、黑称榜、地域梗榜、社交关系链。
  • 不做规避平台审核的话术生成。
  • 用户可补充词条与纠错，但评论仅用于词条维护，不做社交互动。
  • 目标不是制造更多黑话，而是帮助用户看懂黑话、降低沟通成本。

项目价值

⚡ 效率提升

把一次"看不懂 → 追问 → 再解释"的沟通，缩短成一次翻译。

🤝 跨圈层理解

让不同圈层的梗、术语、黑话可以被彼此理解。

📚 学习价值

帮助新人快速理解行业术语与圈层表达，降低入门门槛。

🛡️ 内容安全

识别营销诱导 / 冒犯性表达，提示使用风险，不鼓励传播。
