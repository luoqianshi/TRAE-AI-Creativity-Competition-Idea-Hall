玩法概述
玩家与 3 位节气守灵（AI）共坐一桌，依 春夏秋冬 四时流转，
完成叫气、定气、追加、弃牌四式抉择，争夺最终筹码。

卡牌规则
牌组 (28张)
24张节气牌 + 4张季节王牌(春王/夏王/秋王/冬王)。节气按1-24排列，每季6张。季节王气值=12。
筹码
天时(x1) · 月令(x2) · 岁首(x4)。每人开局：10天时 + 5月令 + 3岁首。
一岁流程
1. 抽命格(随机能力) -> 2. 各发2张手牌 -> 3. 盲注(1天时) -> 4. 翻3张公共牌(春候) -> 5. 第一轮行动 -> 6. 翻第4张(夏候) -> 7. 第二轮行动 -> 8. 翻第5张(秋候)+藏候牌(暗) -> 9. 最终轮行动 -> 10. 摊牌
牌型 (由高到低)
四季归一(5张同季) -> 四候(4张同季) -> 节气顺(5连号) -> 三候(3张同季) -> 两气(2对同季) -> 单气最大。得分 = 牌型等级x10000 + 最佳5张气值之和。
气散 (爆牌)
所有手牌(7或8张)气值总和 > 96 则立即淘汰。持有2+季节王时阈值降为82(反噬)。
追加
声明追加等级(月令x2或岁首x4)，筹码暗置。其他玩家必须匹配或弃牌。追加过的玩家可偷看藏候牌。
定气
每轮一次，锁定状态不再追加，但保留赢牌资格。追加后定气仍可偷看藏候牌。
藏候牌
1张暗置公共牌，仅追加者可偷看。可选纳入手牌评估(共8张，但气散风险增加)。
隐藏规则 (游戏中发现)
· 公共牌可弃：气值>=85时可排除1张公共牌不计入气散检查 · 季节王反噬：2+季节王爆牌阈值降至82 · 相生暗涌：公共牌3连同季->该季玩家气值-3 · 冬至回光：手持冬至(22)爆牌时可保留1天时
