暖音 - 独居老人AI语音陪伴与异常预警系统

用声音温暖每一天，让陪伴永不缺席

智慧助老 社会公益
创意名称 + 创意介绍
想解决什么问题：

随着老龄化加剧，中国60岁以上独居老人数量已超5000万。这些老人面临着情感孤独、健康管理困难、操作复杂、安全风险、家人担忧和娱乐匮乏六大核心痛点，急需一款专为老年人设计的智能陪伴系统。

为什么会想到做这个：

我们团队成员都有父母在老家独居，深知子女在外工作时对父母的牵挂。看到身边老人因不会使用智能手机而无法享受科技便利，因缺乏陪伴而感到孤独，我们希望用技术手段为老人带来温暖和安全保障。

大概是什么产品：

这是一款面向60岁以上独居老人的全栈智能陪伴Web应用，采用React 18 + TypeScript + Node.js技术栈，通过语音优先交互和老人友好界面设计，提供全方位的生活陪伴、健康管理和安全保障服务。

目标用户及痛点
面向哪些用户：
  • 核心用户：60岁以上独居老人、空巢老人，子女在外地工作，日常无人陪伴
  • 间接用户：关心老人的子女和家人，希望随时了解老人状态
在什么场景下使用：
  • 日常陪伴：早上起床后与暖音对话，获取天气和问候
  • 健康管理：测量血压/心率后录入系统，查看健康状态
  • 定时提醒：设定吃药、运动、复查等提醒，按时收到通知
  • 紧急求助：突发疾病或摔倒时，点击SOS按钮联系家人
  • 休闲娱乐：想听故事、音乐、新闻时随时调用
  • 联系家人：想打电话给子女时一键拨号
当前痛点：
  • 情感孤独：子女不在身边，日常无人陪伴交流，容易产生孤独感和心理健康问题
  • 健康隐患：健康数据记录繁琐，异常难以及时发现，可能延误治疗
  • 操作困难：传统手机和APP界面复杂，字体小，老人难以使用，存在数字鸿沟
  • 安全风险：紧急情况下无法快速联系到家人或急救，生命安全缺乏保障
  • 家人担忧：子女无法实时了解老人的生活状态，产生焦虑和牵挂
  • 娱乐匮乏：缺乏适合老人的娱乐内容和认知训练工具，精神生活单调
核心功能

🏠 首页仪表盘

智能问候语（根据时间变化）、实时天气、快捷服务入口、健康提示、使用统计（对话次数/打卡天数/待处理提醒）

💬 智能聊天

语音录音和文字输入双模式，AI实时回复并语音播报，可播放/暂停语音消息，聊天历史自动保存

❤️ 健康监测

支持血压、心率、血糖、体温四种数据记录，系统自动判断状态（正常/偏高/异常），提供健康建议

⏰ 智能提醒

吃药、运动、复查、自定义四种提醒类型，每天/每周/仅一次三种重复模式，今日待办状态清晰展示

👨‍👩‍👧 家人联系

紧急联系人管理，一键拨号，发送短信，家人列表支持添加多个家人并显示关系标签

🎵 休闲娱乐

故事模块（四大名著）、音乐模块（经典老歌）、新闻模块（养老政策）、认知游戏（记忆翻牌等）

🚨 SOS紧急求助

10秒倒计时防止误触，语音播报提示，立即拨打和取消操作，优先拨打紧急联系人

⚙️ 设置中心

字体大小调节（标准/大/特大）、语音音量控制、夜间模式、消息提醒开关、隐私设置

价值与意义
社会价值：
  • 关爱老人：通过AI语音陪伴缓解独居老人孤独感，提升生活幸福感。老人可以随时与暖音对话，获取问候、故事、音乐等内容，不再感到孤单。
  • 保障安全：SOS紧急求助功能为老人提供生命安全保障。10秒倒计时+语音播报机制防止误触，在紧急情况下老人只需点击一个按钮就能联系到家人。
  • 健康管理：智能健康监测帮助老人及时发现健康异常。系统自动判断血压/心率/血糖/体温状态，用三色标识清晰展示，提供个性化健康建议。
  • 数字包容：帮助老人跨越数字鸿沟。大字体界面、语音优先交互、简洁布局设计，让老人能够轻松使用智能设备，享受科技带来的便利。
  • 减轻负担：让子女更放心，减少家庭焦虑。家人联系功能和健康监测数据，让子女能够随时了解老人的生活状态。
  • 认知训练：认知游戏帮助延缓认知衰退。记忆翻牌、数字认知等游戏保持老人大脑活跃。
技术创新价值：
  • 语音优先交互：专为老人设计，支持语音录音发送和语音播报回复，减少文字输入操作
  • Web Speech API集成：实现全功能语音合成与识别，无需额外硬件设备
  • 实时通信：通过Socket.io实现实时消息推送和状态更新
  • 智能健康判断：根据医学标准自动判断健康状态，提供个性化建议
技术架构
前端技术栈：

React 18 + TypeScript + Vite + Lucide React + Axios + Socket.io-client + Web Speech API + MediaRecorder API

后端技术栈：

Node.js + Express + Socket.io + JWT + Multer + Dotenv + JSON文件持久化

核心服务：
  • storageService.js（readJSON/writeJSON/appendJSON/deleteFromJSON）
  • conversationService.js（处理语音/文字消息）
  • monitoringService.js（状态统计和异常监测）
创新亮点
设计创新：大字体界面（支持三档调节）、高对比度配色（紫色渐变）、大按钮设计、简洁布局（底部固定导航）、全功能语音播报
技术创新：语音优先交互、Web Speech API集成、实时通信、JSON文件持久化、智能健康判断
安全保障：SOS紧急求助（10秒倒计时+语音播报）、紧急联系人管理、异常预警机制
