古法编程 AncientCode

AI 时代的手写代码训练场

先用 AI 学，再靠手写练 —— 让代码肌肉记忆不退化

创意介绍

临帖式编程训练：看 AI 写的代码，自己手敲一遍

发现的问题

AI 代码生成工具普及后，开发者手写代码能力严重退化。新人"AI 生成 → 复制粘贴"成常态，离开 AI 就手忙脚乱——面试写不出、现场调不通、弱网下无法工作。

灵感来源

古人学书法要"临帖"——先看名家字帖，再一笔一划临写。编程也该有临帖训练：先看 AI 生成的规范代码，再逐字手敲一遍，在"看→敲→查"中重建肌肉记忆。

产品形态

Web 在线练习平台 — 用户输入需求让 AI 生成参考代码（或直接粘贴代码），然后在双编辑器界面中逐字手敲，系统实时比对正确率和速度，记录成长曲线。

目标用户及痛点

面向所有想提升手写代码能力的开发者

👨‍💻

AI 依赖型程序员

习惯 Copilot/ChatGPT 生成代码，手敲速度和准确度明显下降，面试时无法白板编码。

🌱

职场新人

刚毕业 1-3 年，从学校就依赖 AI，缺乏代码语感和肌肉记忆，遇到线上问题不敢手写修复。

📚

语言学习者

正在学新语言的开发者，需要通过手敲加深语法记忆，从"看懂"过渡到"能写"。

当前痛点

✗
打字练习软件不针对代码 — 练的是中文/英文输入，不涉及代码语法、缩进、符号
✗
刷题平台重在算法 — LeetCode 关注思路和结果，不关注手写过程和输入速度
✗
IDE 自动补全反向削弱手写意愿 — 越补全越不会手写，形成恶性循环
✗
缺少"有参考、有反馈、有记录"的训练场 — 独自练习无标准可对照，无数据可衡量进步

核心功能模块

6 大模块支撑完整训练闭环

⌨

双编辑器比对引擎

Myers diff 逐字符比对，实时映射为 Monaco Editor 装饰器（绿/红/灰），防抖 50ms 保证流畅。

🤖

AI 代码生成

用户配置 OpenAI 兼容 API，输入需求+语言即可生成。SSE 流式返回，打字机效果展示。

📊

练习统计引擎

实时采集按键事件，计算 CPM、正确率、连续正确长度、错误类型分布。自动分类标签。

📈

成长曲线 & 分类统计

ECharts 折线图展示速度/正确率趋势；按语言、代码类型分组统计，发现薄弱环节。

💾

IndexedDB 本地持久化

全部练习数据本地存储，无需后端。支持导出/清除，API Key 遮蔽显示仅末 4 位。

🧠

理解检查（可选）

手敲完成后 AI 针对代码逻辑提问 2-3 个问题，防止无脑照抄，确保理解代码含义。

interface Practice { id: string; source: 'ai' | 'paste'; // 代码来源：AI生成 或 用户粘贴 requirement: string; // 需求描述 / 粘贴摘要 language: string; // 编程语言 referenceCode: string; // 参考代码 userCode: string; // 用户手敲的最终代码 keyEvents: KeyEvent[]; // 按键事件序列 stats: PracticeStats; // 练习统计 category: string; // 代码分类 completedAt: Date; // 完成时间 } interface PracticeStats { duration: number; // 总用时(ms) cpm: number; // 字符/分钟 accuracy: number; // 正确率(0-1) totalKeystrokes: number; // 总按键次数 errorCount: number; // 错误次数 maxConsecutiveCorrect: number; // 最长连续正确 errorTypes: Record<string, number>; // 错误类型分布 }

价值与意义

效率提升 + 社会价值

⚡

效率提升

持续"对照手敲"训练后，开发者代码输入速度和准确度显著提升。日常开发减少对 AI 补全的依赖；面试白板编程、线上调试等场景从容应对。成长曲线和分类统计让进步可量化，形成正反馈激励持续练习。

🌍

社会价值

在 AI 全面辅助编程的趋势下，"古法编程"倡导的不是拒绝 AI，而是 "先用 AI 学，再靠手写练"——让开发者既能享受 AI 提效，又不丧失独立编码能力，避免整个行业陷入"离不开 AI"的技能退化陷阱。
