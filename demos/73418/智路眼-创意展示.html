01 / 问题洞察

道路问题
总是"被发现"
而非"主动发现"

城市道路异常事件的治理，长期困在"发现慢、取证难、处置慢"的循环里。与此同时，自动驾驶车辆每天采集的海量路侧感知数据，仅服务于单车决策，高价值数据被白白浪费。

发现滞后 —— 人工巡查覆盖有限，夜间井盖缺失、快速路抛洒物等高危事件发现滞后数小时。

取证不全 —— 依赖人工录入工单，事件分类标准不一、证据链不完整，跨部门协同反复流转。

数据闲置 —— 自动驾驶的视觉、激光雷达、毫米波雷达多模态数据采集后即丢弃，未发挥社会价值。

行业普遍在"卷"车辆本身的驾驶技术，却很少有人挖掘这些"移动感知节点"对城市公共价值的贡献。

02 / 产品概览

移动感知节点 + AI 治理中枢

一款纯 Web 端的路网事件协同治理系统，浏览器即可访问。由三大模块构成，实现"发现—研判—派单"全自动闭环。

MODULE 01

公众上报入口

面向市民与司机的轻量化上报通道，支持图文 / 短视频一键提交，自动定位并生成标准化工单，全程可视处置进度。

  • 图文 / 视频一键上报
  • 自动定位 · 标准化工单
  • 处置进度全程可视
MODULE 02

AI 智能研判中枢

接入自动驾驶实时路侧感知数据，利用多模态大模型自动识别道路异常，完成事件分类、风险分级、证据链提取与标准化工单生成。

  • 多模态事件自动识别
  • 风险分级 · 证据链提取
  • 发现—研判—派单全自动
MODULE 03

治理管理后台

面向交管、路政、市政的统一工单台，支持智能分级派单、跨部门协同流转、处置追踪与效果回溯，并提供路网风险热力图。

  • 智能分级派单 · 跨部门协同
  • 路网风险热力图
  • 前置治理 · 资源调度

04 / 用户与场景

三类角色 · 一个闭环

面向治理部门、市民与自动驾驶企业三类用户，覆盖日常处置、便捷上报与数据反哺三大场景。

CORE · 治理部门

交管 / 路政 / 市政

通过 AI 研判中枢自动接收事件工单，按风险等级智能派单至处置单元；基于路网风险热力图对高频隐患路段进行前置巡查与重点治理，管理人员通过后台完成工单全流程追踪与跨部门协同。

PUBLIC · 市民司机

便捷上报 · 进度可视

路遇道路异常（井盖缺失、路面破损、违停占道）时，通过 Web 入口快速上报，提交后实时查看处置进度与责任部门，形成"上报—处置—反馈"完整闭环，参与感显著提升。

FLEET · 自动驾驶企业

数据反哺 · 一路巡查

自动驾驶车辆在常态化运营中，同步将路侧感知数据回传至智路眼平台，由 AI 自动识别并上报道路事件。在不影响驾驶决策的前提下，辅助城市治理，实现"一路行驶、一路巡查"。

06 / 技术架构

感知 → 研判 → 派单 → 闭环

四步全自动闭环，从数据采集到治理完成，全程无需人工介入。

01

感知采集

自动驾驶车辆在运营过程中实时采集路侧多模态感知数据（视觉 / 激光雷达 / 毫米波雷达），同步回传至平台。

02

AI 研判

多模态大模型自动识别道路异常事件，完成事件分类、风险分级与证据链提取。

03

智能派单

系统按风险等级与责任部门自动生成标准化工单并路由派发，跨部门协同零摩擦。

04

闭环回溯

处置进度全程追踪，结果回溯沉淀为路网风险热力图，支撑前置治理与持续优化。
