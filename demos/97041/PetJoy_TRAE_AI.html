PAIN POINTS

当前萌宠平台的烦恼

萌宠激励很吸引学生，但真正用起来，老师和课堂都在"忍"

🐌

操作太慢，打断课堂

课堂上一个一个学生找着加分，光翻列表就要十几秒；分组加分操作更绕，老师讲着课还要分心操作平台，严重影响教学节奏。

单次操作 10~30秒
😐

形象固定，新鲜感退

宠物形象千篇一律，学生刚拿到时很兴奋，但过了两周就没什么感觉了。无法持续激发参与课堂、好好写作业的内在动力。

使用率低于 30%
SOLUTION

两大创新，让萌宠激励真正落地

不只是"更好看"，而是"更好用" —— 让老师愿意用，让学生持续喜欢

01 🎨🐣

学生自创萌宠

不再使用平台预设的固定宠物形象，而是让学生自己动手"创造"专属萌宠。因为宠物是自己创造的，学生会有更强的归属感和喜爱度，激励效果更持久。

  • 自定义宠物外观、颜色、配饰
  • 宠物随加分成长、进化形态
  • 每只萌宠独一无二，学生更有感情
  • 可展示在个人主页，增强荣誉感
02 ⚡👆

3秒快捷加减分

在界面右侧设计悬浮快捷面板，加加分键和减分键触手可及。支持按单人加分或按组加分两种模式，无需翻找列表，每一个操作都能在3秒内完成。

  • 右侧悬浮面板，永远在手边
  • 单人/分组一键切换
  • 快捷分值按钮（+1/+2/+5）
  • 可联动互动游戏，游戏得分同步宠物

TECH STACK

技术框架与实现思路

轻量前端优先，AI赋能宠物生成，实时同步课堂互动

FE ⚛️🎨

前端：Vue 3 + Canvas/SVG

采用 Vue 3 构建响应式界面，课堂积分页面使用组件化开发。宠物创建器基于 Canvas 或 SVG 实现拖拽式自定义，学生选择基础形态后可调整颜色、配饰、表情等属性，生成独一无二的宠物形象。

  • Vue 3 + Vite，开发体验好，打包体积小
  • Canvas/SVG 宠物编辑器，支持实时预览
  • PWA 支持离线使用，课堂网络不稳定也能用
  • 响应式布局，适配电脑、平板、手机
BE 🤖☁️

后端：Node.js + AI 宠物生成

后端使用 Node.js + Express 提供轻量 API 服务，数据存储采用 SQLite（轻量部署）或 MongoDB（多校协作场景）。宠物生成可接入 AI 绘图接口，学生输入文字描述即可生成宠物形象；也可使用预设的组件化拼装方案，零门槛创建。

  • Node.js + Express，轻量高效，部署简单
  • AI 接口生成宠物形象（可选方案）
  • WebSocket 实时同步，加分即时反馈到全班
  • SQLite 单机部署 / MongoDB 多校云端协作
01 🕹️🔗

互动游戏联动

设计简单的课堂互动小游戏（如答题闯关、快速抢答），游戏得分可直接同步为宠物经验值。老师一键发起游戏，学生参与后自动获得对应积分，宠物同步成长，让激励融入趣味互动。

  • 答题小游戏模块，支持自定义题库
  • 游戏得分自动映射为宠物经验值
  • 排行榜激发良性竞争
  • 可与现有课堂互动工具对接
02 📱🚀

部署与扩展

支持两种部署方式：单机版（老师自己电脑运行，零成本零门槛）和云端版（学校统一部署，多班级数据互通）。初期以单机版快速验证，后续可扩展为微信小程序或接入学校现有教学平台。

  • 单机版：一键安装包，开箱即用
  • 云端版：Docker 容器化部署，运维简单
  • 数据导出/导入，学期数据无缝迁移
  • 预留 API 接口，可对接学校教务系统
