创意背景与痛点

在 3D 动画和特效制作中，传统的物理风场模拟往往缺乏“艺术可控性”。艺术家很难精准控制风的轨迹、范围和动态变化，且解算和预览极其耗时。为了一个特定的风吹效果（如角色披风特定方向飘动、树叶随风起舞的特定节奏），动画师需要反复调整复杂的物理参数，缺乏直观、艺术化且可预测的控制手段。

CPS 旨在解决这一痛点：为 Blender 提供艺术可控、可缓存、可验证的环境场工具。第一阶段优先解决风场动画工作流，第二阶段增加 CPU 离线网格求解，第三阶段提供多物理场、声学和天气等实验能力。

核心功能与技术亮点

  • 艺术导向风源：支持全局、点、面、曲线风源，参数支持关键帧动画，允许风力沿着特定曲线路径吹拂。
  • 空间扭曲场：支持曲线扭曲、曲面扭曲、体积扭曲，直接修改风场速度方向，实现极具创意的风场动效。
  • 确定性时空采样：预览和烘焙共享相同的单位、参数含义和边界定义，确保动画效果的确定性与一致性。
  • 流线与矢量实时预览：在 Blender 视口中直观显示风的走向、流线和速度颜色，实现“所见即所得”的艺术化引导。
  • 主线程隔离架构：计算核心与 Blender bpy 彻底解耦，后台计算进程不访问 bpy，确保 Blender UI 交互流畅不卡顿。

系统架构设计

CPS 采用“Blender 主线程适配层 + 纯数据计算核心 + 版本化缓存”的解耦结构：

Blender Main Thread (主线程) ├── Host Adapter (适配器 - 唯一访问 bpy 的层) │ ├── Operators & Panels (操作器与面板) │ ├── Scene Snapshot Builder (场景快照构建器) │ ├── Undo / Persistence (撤销与持久化) │ └── Geometry Nodes Bridge (几何节点桥接) ├── Runtime Coordinator (运行时协调器) │ ├── Field Model Registry (场模型注册表) │ ├── Cache Manager (缓存管理器) │ └── Preview Scheduler (预览调度器) └── Viewport Renderer (视口渲染器 - 矢量/流线) Pure-data Core (纯数据计算核心 - 不依赖 bpy) ├── Analytic Field Solver (分析式风场求解器 - P1) ├── Uniform-grid CPU Solver (均匀网格求解器 - P2) ├── Sampling & Interpolation (采样与插值) └── Cache Codec (缓存编解码器)

开发路线图

第一期：可运行 MVP
分析式风源、有限影响域、单向 Blender 力场集成、基础缓存、流线/矢量预览、UI 和 Python API。
第二期：生产 Beta
CPU 离线 Stable Fluids、障碍物、被动温度标量、独立进程 Bake、Geometry Nodes 桥接。
第三期：高级实验版
稀疏网格、GPU 计算原型、程序化天气视觉、离线声学、启发式循环。

价值与意义

⚡ 效率提升
将原本需要数小时的“调整-烘焙-预览”循环缩短至秒级，极大提升了 3D 动画的创作效率。

💎 商业价值
降低高质量环境特效的制作门槛，帮助中小型工作室和独立创作者以极低的成本产出电影级的动态物理效果。
