创意介绍

🎯 想解决什么问题

当前 AI Agent 研究面临语义漂移与逻辑死锁瓶颈——纯文本 Agent 缺乏物理世界的因果约束，导致行为不可预测、难以对齐人类价值观。学术界和工业界急需一个包含物理惩罚底线的仿真环境，用于 AI 安全对齐与人机共生推演。

💡 为什么会想到做这个

灵感来源于对现有 Agent 框架的深入观察：大多数系统只关注"认知层"而忽略"具身性"，导致 Agent 会说出"我可以飞"这类物理幻觉。我们相信，真正的智能必须扎根于物理世界的因果律——只有让 AI 体验饥饿、疲劳、碰撞等物理约束，才能培养出符合人类预期的行为模式。

🚀 大概是什么产品

OmniSim 是一个三位一体的社会模拟系统，将物理具身层（肉身）、生理/心理层（内分泌）与认知叙事层（灵魂）彻底解耦又紧密耦合，为研究者提供一个可编程的"虚拟社会学具身沙盘"。系统完全在 Headless 纯数值模式下运行，无 3D 渲染、无 GPU 负载，纯 CPU 计算物理动力学。

目标用户及痛点

核心用户

AI 安全研究者

从事 AI 对齐、价值对齐、可解释性研究的学者与工程师，需要在受控环境中测试 Agent 的长期行为演化。

核心用户

多智能体系统开发者

开发协作/竞争型 Agent 系统的团队，需要高保真仿真环境验证算法的鲁棒性与涌现行为。

核心用户

计算社会科学家

研究经济分层、文化传播、群体决策的学者，需要可重复、可干预的"数字社会实验室"。

😰 使用场景

  • 算法验证：在部署到真实世界前，测试 Agent 在极端条件（资源匮乏、信息不对称）下的决策质量
  • 政策推演：模拟不同经济政策（税收、福利）对虚拟社会 Gini 系数的长期影响
  • 教育训练：为 AI 伦理课程提供可交互的案例沙盒，让学生观察"无约束 Agent"的危害

💔 当前痛点

  • 纯文本 Agent 的语义漂移：现有框架（如 AutoGPT、LangChain Agent）缺乏物理 grounding，Agent 会生成"我要飞到月球"等不可执行意图，导致逻辑死锁
  • 缺乏生理约束建模：大多数系统假设 Agent 是"永动机"，无法模拟饥饿、疲劳对决策的影响，涌现行为单一
  • 评估指标碎片化：学术界缺乏统一的 benchmark，不同论文使用不同指标，难以横向对比
  • 计算资源门槛高：传统社会仿真（如 Agent-Based Modeling）依赖 Unity/Unreal 引擎，需要 GPU 渲染，研究成本高昂

价值与意义

核心技术亮点

物理层

60Hz 固定时间步

严格遵循游戏引擎最佳实践，禁用弹性 delta time，确保物理模拟的确定性与可重复性。AABB/OBB 碰撞检测 + 冲量响应，防止穿模。

生理层

代谢动力学方程

离散时间动力学建模能量 E、水分 H、体力 S、创伤 P，引入意图-能力过滤器 (ICF) 拦截物理幻觉意图。

认知层

生成式记忆流

三级记忆漏斗（工作/情景/语义）+ 联想检索三维评分 Score(m,q)，支持睡眠归纳压缩与外源记忆注入。

核心机制

物理媒介绑定 (PMB)

物品全局 GUID 绑定 + 两阶段检测，从源头杜绝"凭空造物"幻觉。Twin Register 实现物理↔语义双向 Hook。

工程约束

单侧权威结算

物理层为唯一事实源 (Source of Truth)，认知/生理层只接收状态、不重推演，彻底解决多层冲突。

可视化

B/S 驾驶舱架构

前后端分离：FastAPI + WebSocket 后端，React + Three.js + D3.js 前端。四面板布局（空间/叙事/Inspector/控制）。

E_{t+dt} = E_t - (k_basal + k_motion·‖v‖²)·dt

Score(m,q) = w_rec·exp(-λ_rec·Δt) + w_imp·Imp(m) + w_sim·cos(V_m, V_q)
边际效用（资源分配）:
U_i(x,t) = w_x·(1 + Σ_m λ_m·(M_crit - m)²·𝟙(m<M_crit))
