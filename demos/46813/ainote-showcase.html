2. 自注意力机制详解

自注意力机制是Transformer的核心组件，它允许模型在处理序列中的每个位置时，动态地关注序列中其他位置的信息。这种机制使得模型能够捕捉长距离依赖关系，同时保持并行计算的优势。

2.1 注意力公式推导

给定查询向量Q、键向量K和值向量V，注意力的计算过程如下：

Attention(Q, K, V) = softmax(QKᵀ / √dₖ)V

其中：

  • Q ∈ ℝ^(n×dₖ)：查询矩阵，n为序列长度
  • K ∈ ℝ^(m×dₖ)：键矩阵，m为键值对数量
  • V ∈ ℝ^(m×dᵥ)：值矩阵
  • dₖ：键向量的维度

2.2 缩放因子的作用

当dₖ较大时，QKᵀ的元素值会变得很大，导致softmax函数的梯度变得非常小，即梯度消失问题。引入缩放因子√dₖ可以缓解这个问题。

2.2.1 代码实现

import torch import torch.nn.functional as F def scaled_dot_product_attention(Q, K, V, mask=None): d_k = Q.size(-1) scores = torch.matmul(Q, K.transpose(-2, -1)) / torch.sqrt(torch.tensor(d_k, dtype=torch.float32)) if mask is not None: scores = scores.masked_fill(mask == 0, -1e9) attention_weights = F.softmax(scores, dim=-1) output = torch.matmul(attention_weights, V) return output, attention_weights

缩放因子√dₖ是如何解决梯度消失问题的？
好问题！当dₖ较大时，QKᵀ的元素值会趋于很大，导致softmax输出趋近于one-hot分布，此时梯度会变得非常小。通过除以√dₖ，可以将QKᵀ的方差缩放到1附近，保持softmax的梯度在合理范围内。这一技巧在原论文中有详细的数学分析。

Multi-Head Attention的多头是如何合并的？
Multi-Head Attention将输入分别通过h个不同的线性变换得到h组Q、K、V，每组独立计算注意力后得到h个输出。最后将这些输出在最后一个维度上拼接，再通过一个线性层进行降维，得到最终输出。
