创意介绍

MxTraffic 的诞生源于开发者日常调试中的真实痛点

💡 灵感来源

在前后端联调、接口测试、问题排查的日常工作中，开发者需要频繁查看网络请求。现有的抓包工具要么过于笨重（如 Fiddler、Charles），要么功能受限（如浏览器 DevTools）。MxTraffic 希望做一个轻量、专注、对开发者友好的本地代理工具。

🎯 解决的问题

• 传统抓包工具启动慢、配置复杂
• 浏览器 DevTools 无法捕获跨应用请求
• 缺乏灵活的请求篡改和重发能力
• 难以从响应中提取自定义字段进行分析

📦 产品形态

基于 Electron + React + TypeScript 构建的桌面端应用。支持 Windows / macOS / Linux 跨平台运行，提供本地 HTTP/HTTPS 代理服务，自动配置系统代理，开箱即用。

🚀 核心定位

面向前端开发者、后端工程师、测试人员、安全研究员的轻量级网络调试助手。强调易用性、可扩展性和与 AI 工具的集成能力。

核心功能

基于真实开发场景设计，覆盖抓包调试的完整工作流

📡

HTTP/HTTPS 抓包

自动配置系统代理，一键启动即可捕获所有 HTTP/HTTPS 流量。支持 WebSocket 连接捕获与帧数据查看。

🔍

高级过滤系统

支持多条件组合过滤（方法、URL、路径、状态码、主机名、协议），AND/OR 逻辑组合，支持取反和正则匹配。

📋

请求/响应篡改规则

对匹配请求自动执行篡改动作：URL 重写、Header 增删改、Body 替换/注入、状态码修改、请求延迟模拟。

✏️

请求编辑器

右键任意请求即可编辑并重发。支持修改方法、URL、参数、请求头、请求体，实时查看响应结果。

📊

自定义列

通过 JSON Path 从响应体中提取字段作为表格列。支持列的显示/隐藏、拖动排序、列宽调整。

🤖

MCP Server 集成

内置 MCP Server，让 AI 助手（如 TRAE、Claude）直接读取和分析抓包数据，实现 AI 辅助调试。

📥

HAR 导入/导出

支持标准 HAR 格式导入和导出，方便与 Chrome DevTools、Charles 等工具互通数据。

🎨

主题与个性化

支持亮色/暗色主题切换，可自定义表格列、字体大小、代码折叠、 minimap 等编辑器偏好。

⌨️

快捷键支持

完整的键盘快捷键体系，支持快速启动/停止代理、清空会话、复制 cURL、重发请求等高频操作。

目标用户与痛点

谁需要 MxTraffic？他们在日常工作中遇到了什么问题？

👨‍💻

前端开发者

调试接口响应、排查跨域问题、分析页面加载性能

🖥️

后端工程师

🧪

🔐

分析请求链路、检查 Header 安全性、验证加密传输

📌 当前痛点

1

传统工具太笨重

Fiddler、Charles 功能强大但启动慢、界面复杂，很多功能日常用不到，学习成本高。

2

浏览器工具有局限

Chrome DevTools 只能捕获浏览器内请求，无法抓取小程序、桌面应用、命令行工具的流量。

3

篡改和重发不方便

修改请求参数、模拟错误响应、重发特定请求等操作，在现有工具中步骤繁琐。

4

数据难以与 AI 协作

抓包数据无法直接输入给 AI 助手分析，需要手动复制粘贴，效率低下。

价值与意义

MxTraffic 为开发者带来的实际价值

⏱️ 效率提升

一键启动代理，自动配置系统代理，无需手动设置。请求列表实时刷新，右键即可复制 cURL 或重发请求，将调试时间从分钟级缩短到秒级。

🎯 降低门槛

界面简洁直观，核心功能一目了然。非专业开发者也能快速上手进行基本的接口调试和问题排查。

🔧 增强可控性

规则系统让开发者可以精确控制请求行为：模拟超时、替换响应、注入错误，轻松测试各种边界场景。

🤖 AI 就绪

MCP Server 让抓包数据直接成为 AI 的上下文，开发者可以用自然语言让 AI 分析请求链路、定位问题根因。

技术实现

基于现代技术栈构建，兼顾性能与可维护性

⚡ Electron ⚛️ React 18 📘 TypeScript 🎨 Ant Design 🗂️ Zustand 📦 Vite 🔌 Node.js HTTP Proxy 🔐 HTTPS MITM 🌐 WebSocket 🤖 MCP Protocol

架构亮点

• 主进程：Node.js HTTP/HTTPS 代理服务器，证书管理，系统代理自动配置
• 渲染进程：React + Ant Design 构建的现代化 UI，支持主题切换
• 状态管理：Zustand 实现跨组件状态共享，简洁高效
• MCP 集成：基于 Model Context Protocol 的 AI 工具服务
• 规则引擎：条件匹配 + 动作执行的灵活规则系统
• Body 解析：支持 JSON/XML/HTML/文本/二进制多种格式自动识别
