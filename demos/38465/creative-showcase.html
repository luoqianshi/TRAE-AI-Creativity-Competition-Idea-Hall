⚽ 江苏城市足球联赛管理系统

专业的赛事管理平台，让城市足球更精彩

📋 项目概述

江苏城市足球联赛管理系统是一个面向城市足球联赛组织者的专业Web管理平台。系统采用前后端分离架构，提供赛程管理、积分榜计算、淘汰赛编排等核心功能，帮助联赛组织者高效管理赛事数据，提升赛事组织水平。

🎯 核心功能

📅

赛程管理

灵活的赛程编排，支持小组赛和淘汰赛两种赛制，可视化展示每场比赛信息

📊

积分统计

自动计算积分榜，支持足球联赛标准积分规则，实时更新排名和净胜球

🏆

淘汰赛编排

可视化的淘汰赛树状图，自动追踪晋级关系，清晰展示对阵路线

👥

团队管理

完整的球队和赛季管理，支持队徽上传，打造专业的赛事形象

🛠️ 技术栈

Vue3 Element Plus Spring Boot MyBatis MySQL Vite Axios SVG
