群面模拟 与 证据化复盘 工具

先模拟一场群面，
再把它整理成可回放的证据。

EqualTalk 话轮镜把群面训练分成两步闭环：先用 AI 模拟一场多角色群面，再把这场讨论整理为多人发言时间线、带证据的互动图谱、观点演化思路流，以及经教练审核的下一轮练习目标——让学员看见自己在哪个时刻做了什么，并在下一次模拟中验证是否改变。

高校就业中心 群面教练 求职训练学员 沟通培训机构
01

真实问题

一场 15—30 分钟的模拟群面结束后，复盘往往停留在主观印象。

使用场景

模拟群面训练

4—8 名学员、1 名教练、一道明确题目、15—30 分钟。所有人授权录音，训练后逐人复盘，并在下一次训练中验证行为是否改变。

现实角色

四方诉求

组织者要可重复的训练；教练要快速定位关键互动；学员要知道自己哪个时刻做了什么；付费方要更一致、更低成本的反馈。

● 当前方式为何不足
  • 教练靠记忆与零散笔记复盘，不同教练反馈不一致
  • 录音回放逐字听，一场 20 分钟讨论要花数倍时间定位
  • “你刚才打断别人了”——没有原始片段可回看
  • 学员拿到模糊评语，看不到具体时刻与证据
  • 两次训练之间，无法对照同一目标行为是否出现
● 话轮镜的回应
  • 互动事件全部关联转写证据，可点击回看原始片段
  • 图谱按阶段/关系筛选，几秒定位关键互动
  • 候选事件经教练确认或驳回，人在回路
  • 报告只写可观察行为，附带证据片段
  • 两次训练对照同一目标行为，用证据判断是否改变

04

两大创新点

一面把模拟群面成本降到接近为零，一面让复盘的每条判断都带时间戳证据。

SIMULATE-AT-ZERO-COST

AI 模拟群面：成本归零，队友无限

真人群面要凑人、约场地、排时间，一次成本高、难以重复。话轮镜用同一可控模型扮演不同队友——激进型、保守型、强势型、冷场型——代码控制发言顺序与阶段切换。学员可在短时间内连续体验数十种队友组合，积累远超真人训练的群面样本量，再带着具体问题进入真人复盘。

选队友组合 → AI 群面 → 一键复盘 → 换组合再练
EVIDENCE-ANCHORED

证据链路：判断 → 转写 → 可回放时刻

多数沟通分析工具止步于“谁说了多少”。话轮镜要求：每一条互动边都必须关联至少一段原始转写证据，并带有起止时间戳。教练不是在看一个结论，而是在看一个可回放的瞬间。确认或驳回，都基于证据，而非印象。

互动事件 → 证据引用 → 转写片段 → 时间戳 → 可回放
07

数据来源与边界

明确数据从哪来、存在哪、不碰什么。

数据来源与隐私边界

  • 本地种子数据驱动 示例会话为预置演示数据，非真实录音运营数据。
  • 用户上传数据仅存于浏览器本地 审核状态、会话记录保存在 localStorage，不上传服务器。
  • LLM 仅用于事件检测（可选） 需用户自行配置 API Key；不配置时使用本地种子数据完整可体验。
  • 录音授权前置 示例数据标注授权完成状态；真实使用须获得所有参与者授权。
  • 断网可用 核心复盘功能不依赖网络；刷新后示例 Demo 可重新开始。

产品不会做什么

  • 不做企业自动招聘筛选 训练复盘用途，不用于招聘决策。
  • 不做候选人能力排名 不生成“领导力第一”“沟通能力 85 分”这类排序。
  • 不做综合能力总分 报告只描述可观察行为与证据，不给总分。
  • 不推断人格、情绪、性格、性别或健康 不使用任何刻板标签。
  • 不做录用建议 不输出“建议录用 / 不录用”。
  • 不把多人同时说话直接定义为恶意打断 以“候选事件”呈现，由教练判定。
