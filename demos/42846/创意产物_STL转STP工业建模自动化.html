02 / SOLUTION

产品：一个UG插件，解决一个核心问题

我们没有做一个复杂的平台，而是做了一个简单但精准的工具——直接在UG内部安装， 在你每天工作的软件里完成转换。

01

UG NX插件

基于NX Open .NET API开发，支持UG NX 12.0及以上版本，安装即用，无需额外软件。

STL → STEP 智能转换

自动识别STL中的平面、圆柱、圆角等特征，拟合为曲面，再缝合成可编辑的B-rep实体。

03

输出UG原生实体

// 步骤1：导入STL为小平面体
FacetedBodyCollection fbc = workPart.FacetedBodies;
STLImportBuilder builder = fbc.CreateSTLImportBuilder();
builder.File = stlFilePath;
builder.FacetBodyType = STLImportBuilder.FacetBodyTypes.Nx;
builder.Commit();

// 步骤2：识别几何特征，拟合曲面
FacetedBody[] facets = fbc.ToArray();
foreach (var fb in facets)
{
    fbc.Convert(fb, FacetedBodyCollection.Type.Nx);
}

// 步骤3：导出STEP文件（AP214标准）
StepCreator stepCreator = theSession.DexManager.CreateStepCreator();
stepCreator.OutputFile = outputPath;
stepCreator.ExportSolidsAndSurfacesAs =
    StepCreator.ExportSolidsAndSurfacesAsOption.Precise;
stepCreator.Commit();

06 / WORKFLOW

使用场景：设计师的一天

从接到客户需求，到输出可分模的STEP文件，看看插件如何融入日常工作。

09:30 · 接收客户需求 图片 / STL样件 / 手绘草图
客户发来产品外观概念图，或一个扫描得到的STL样件。设计师需要基于此完成模具设计，输出可分模文件。
10:00 · AI生成3D模型 图生3D / 文本生3D
使用AI图生3D工具（如Tripo、Meshy等），将图片或描述生成3D模型，导出为STL格式。耗时约3-5分钟。
10:10 · 在UG中启动插件 菜单 → STL转STP工具
打开UG NX，新建或打开当前工作的部件文件。在菜单栏点击"STL转STP工具"，或按F12快捷键。
10:12 · 选择STL，一键转换 文件选择 → 自动处理
在弹出的对话框中选择AI生成的STL文件，设置输出路径。插件自动完成导入、特征识别、实体拟合全过程。
10:15 · 得到STEP文件 3分钟完成转换
输出UG原生实体的STEP文件。直接在UG中打开，可以进行分模、抽壳、布尔运算等所有工业操作，无缝进入后续工作。
10:20 · 开始分模设计 真正的创造性工作
设计师的时间花在真正有价值的工作——分模策略、结构设计、出工程图，而不是格式转换。
