WordLayer

把“背单词”变成“顺手发生的阅读副作用”

WordLayer 是一个 Chrome 浏览器插件加控制台网页系统。它不要求用户专门进入“学习模式”， 而是在用户日常浏览中文网页时，将少量目标词汇自然嵌入内容流中，让学习发生在真实语境里、 发生在最容易坚持的高频场景里。

降低学习启动阻力
产品形态
插件 + 控制台网页
目标结果
长期、低打扰、可持续积累

01 / Problem & Insight

用户真正卡住的，不是方法，是启动

大多数词汇学习产品默认用户愿意“拨出一段专门时间来学习”，但现实恰恰相反。 用户真正高频、稳定、可持续的输入场景，是日常网页阅读，而不是背词 App。

现有产品问题

打开背词 App 是一个重动作，需要切换心态、抽离当下任务、进入专门学习模式。

查词与记忆常常发生在脱离真实语境的列表或卡片里，无法与真实阅读建立稳定联结。

学习变成“今天要不要完成任务”，而不是“信息摄入的一部分”。

用户行为洞察

用户并没有放弃英语，只是高频场景不在学习 App，而在资讯、博客、技术文章、行业内容。

如果词汇能以低干扰方式嵌入这些真实场景，学习就会从刻意训练变成自然渗透。

真正需要被优化的是“开始学”的门槛，而不是背词法本身。

机会窗口

浏览器插件天然贴近日常信息流，拥有更高频、更轻量、更接近真实工作的触点。

只要渗透比例和展示方式足够克制，用户不会感到被“教学”，却会持续形成词汇暴露。

长期来看，这是一种更容易坚持的词汇积累机制。

02 / Target Users

谁最需要 WordLayer

目标用户的共同点不是“想学英语”，而是“知道英语重要，但很难长期维持系统性背词行为”。

备考人群

四六级、考研、雅思、托福用户，需要持续词汇暴露与阅读敏感度提升。

碎片化学习 需要坚持

技术从业者

程序员、产品经理、设计师经常看英文术语和技术文章，但缺少低阻力积累工具。

高频阅读 术语敏感

行业信息用户

关注商业、科技、海外资讯的人，需要阅读能力提升，但不愿单独投入背词时间。

信息驱动 长期输入

轻学习型用户

目标不是考试，而是把英语维持在不生疏的状态，希望学习像习惯而不是任务。

低压学习 日常渗透
03 / Product Strategy

产品核心不是替换单词，而是嵌入场景

WordLayer 不是传统的“翻译插件”，也不是“网页背单词器”。它的价值在于把目标词汇控制在少量、可理解、可点击的层级， 让用户继续阅读，同时轻微暴露在真实语境中的英文词上。

默认展示方式

这个事情很 important（重要）
  • 中文主语境保持完整，用户不会被强制切换语言。
  • 英文词只占少量位置，既能感知又不会造成阅读挫败。
  • 陌生词点击后才展开更多信息，默认不打断阅读节奏。

四条核心原则

  • 低阻力：学习不需要额外启动动作。
  • 真语境：词汇出现在真实内容而不是孤立卡片中。
  • 可控干扰：用户对频率、词难度、展示密度拥有控制权。
  • 长期适应：系统根据熟悉度、点击率、掌握状态调整曝光。
04 / Architecture

插件与控制台网页如何协同工作

插件负责“词汇渗透与阅读内交互”，控制台网页负责“词库管理、学习状态、策略配置与效果反馈”。 两者组成一个轻前台、重后台的闭环系统。

Chrome 插件

  • 识别用户正在浏览的中文网页内容
  • 按策略抽取目标词并进行低比例嵌入
  • 支持点击词汇弹出释义、发音、例句
  • 记录曝光、点击、跳过、熟知标记

控制台网页

  • 设置考试词库、行业词库、自定义词库
  • 配置展示频率、难度层级、网页白名单
  • 查看掌握状态、曝光热词、复现频率
  • 输出个性化学习节奏与策略建议

数据与策略引擎

  • 维护词汇熟悉度分层与频率规则
  • 根据点击行为更新用户掌握状态
  • 判断继续出现、减少出现、几乎不出现
  • 逐步建立“词汇渗透型学习画像”
前台职责：在阅读流中做最少量、最自然的语言渗透。
后台职责：把零散暴露沉淀为可追踪、可优化的学习系统。
05 / User Flow

一次完整体验如何发生

用户不是来“完成今天的学习任务”，而是在本来就要做的阅读过程中，顺手完成一次轻学习闭环。

1

打开网页

用户照常浏览中文资讯、技术文章、博客或行业内容。

2

词汇嵌入

少量目标词以自然方式出现在中文句子中，不破坏整体阅读。

3

点击查看

遇到不熟悉词汇时，用户点开小预览框，获取释义、发音、例句。

4

主动反馈

用户可以选择继续出现、减少出现、几乎不出现或完全熟知。

5

系统调频

系统根据反馈动态调整曝光策略，让学习越来越贴合个人状态。

06 / Core Value

WordLayer 的核心价值不是“更努力”，而是“更容易坚持”

它不是一款要求用户更自律的产品，而是一款通过降低阻力，让学习更容易持续发生的产品。

降低启动成本

不需要专门打开学习 App，不需要安排整块时间，不需要进入任务模式。

嵌入真实信息流

学习发生在资讯、工作、技术阅读等真实语境中，帮助用户建立长期语感。

长期积累更稳

因为打扰更小、入口更轻、路径更顺，用户更容易坚持，产品更容易形成复利。

07 / Differentiation

与传统背词产品的差异

WordLayer 的差异并不在于词库本身，而在于“发生位置”和“用户心理负担”的重构。

传统背词产品

  • 用户需要主动开始学习。
  • 学习发生在脱离真实阅读的独立场景中。
  • 坚持靠意志力，容易中断。
  • 查词和记忆常打断任务主线。

WordLayer

  • 用户正常阅读时自动进入轻学习状态。
  • 词汇出现在真实内容语境里，更贴近使用场景。
  • 坚持靠低阻力设计，而不是靠纪律。
  • 学习作为阅读副作用发生，几乎不额外占用注意力。
08 / Roadmap

建议的 MVP 演进路线

如果下一步要启动开发，建议先做最能验证价值的闭环，而不是一开始堆满所有学习功能。

Goal 0
信息架构与数据流确认 明确插件侧、网页侧、策略侧的职责边界，画清楚词汇嵌入、点击、反馈、调频之间的流转关系。
MVP
最小可验证闭环 完成中文网页中的基础词汇嵌入、点击弹层、小范围词库选择、熟悉度反馈与后台统计展示。
V1
个性化策略与体验打磨 增加词汇难度调节、网页白名单、行业词库、自定义词库、曝光频率优化和复习策略建议。
V2
增长与商业化准备 探索考试词库订阅、职业英语包、团队版学习面板，以及与阅读工具、知识管理工具的联动。
09 / Business Potential

可延展的商业空间

WordLayer 可以从单点工具切入，但长期不只是插件，它有机会成为“阅读场景里的语言学习操作系统”。

付费词库

考研、雅思、托福、职场、技术、金融等专项词库可形成内容型订阅。

个性化策略服务

根据阅读领域与学习目标给出节奏建议、频率策略和阶段性复盘。

B2B 场景

可延伸至企业英语培训、校园学习支持、国际化岗位语言提升工具。

Final Statement

WordLayer 不是让用户更努力，而是让学习更自然。

这份创意提案的核心判断是：英语学习最大的敌人不是词汇难度，而是启动阻力。 如果能把学习从“专门任务”改写为“阅读中的轻微副作用”，那么坚持就不再依赖意志力， 产品也更有机会进入用户真正高频、长期的生活流和工作流。
