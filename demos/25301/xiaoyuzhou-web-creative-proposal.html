小宇宙 Web 端

随时随地，在浏览器里订阅、发现、畅听你爱的播客

💡 创意介绍

想解决什么问题：

小宇宙作为国内最优质的播客平台之一，目前仅有 iOS / Android 移动端 App。对于常在电脑前工作、学习的用户，想听播客只能要么用手机播放（与工作流割裂），要么忍受网页版第三方转存工具体验差、无法同步订阅和进度。一个官方级的 Web 端能完美弥合这个缺口。

为什么会想到做这个：

日常开发和学习时习惯戴耳机听播客，但每次切歌、查看 shownotes、订阅新节目都需要拿起手机。如果浏览器里就能完成全部操作，工作效率和收听体验都能提升一个台阶。

大概是什么产品：

一个 PWA 响应式 Web 应用，核心功能对标移动端 App：播客搜索与订阅、播放器控制（倍速/定时/进度记忆）、shownotes 浏览、下载管理、个性化推荐。
形态：桌面端 Web App（渐进式 Web 应用，可安装到 Dock / 任务栏）。

👥 目标用户及痛点

  • 知识工作者 / 白领 — 每天在电脑前 6h+，午休、做机械性工作时想听播客，不想频繁掏手机
  • 学生 / 研究人员 — 查资料、写论文时习惯用播客作为背景音，需要快速查看 shownotes 跳转引用
  • 开发者 / 设计师 — 技术播客重度用户，希望在浏览器中一键收藏、片段收藏、复制 shownotes 中的代码片段
  • 多设备用户 — Mac + iPad + Windows 混合使用，需要跨平台进度同步

当前痛点：

  • ❌ 手机小宇宙无法与桌面工作流无缝衔接
  • ❌ 第三方网页版要么功能残缺，要么无法登录/同步订阅
  • ❌ 想分享某段 shownotes 或时间戳，在手机上操作极不方便
  • ❌ 没有大屏沉浸式浏览体验，shownotes 中的图文内容展示受限

⚡ 核心功能设计

🎧 播放器面板 🔍 播客搜索 📋 订阅管理 📝 Shownotes ⏱ 倍速/定时 💾 下载管理 📊 收听统计 🔄 进度同步 🎯 个性化推荐 🔖 片段收藏

特色亮点：

  • 双栏布局 — 左侧播客列表 + 右侧详情/播放器，类似 Spotify Web 的沉浸体验
  • 一键复制 — 支持一键复制 shownotes 中的链接、时间戳、代码块
  • 无缝同步 — 通过小宇宙 API 实现收藏/订阅/播放进度三端同步
  • 深色模式 — 原生支持深色主题，与桌面系统主题联动
  • PWA 安装 — 支持添加到桌面，像原生应用一样独立窗口运行

🎯 价值与意义

效率提升：

用户无需离开浏览器即可完成播客的所有操作——搜索、订阅、播放、查看笔记、收藏片段。据统计，知识工作者平均每天切换手机/电脑 30+ 次，Web 端能显著减少这种上下文切换损耗。

商业价值：

Web 端能覆盖 Mac / Windows / Linux / Chromebook 全平台，拓展小宇宙的用户使用场景和使用时长，提升 DAU 和广告/会员曝光机会。同时可作为播客创作者的内容展示窗口，吸引更多内容创作者入驻。

社会价值：

降低播客收听门槛——对于不方便安装 App 的设备（如学校/公司电脑、Linux 用户），Web 端让每个人都有平等的播客访问权，推动知识普惠。

🛠 技术方案

React + TypeScript Next.js Tailwind CSS Web Audio API Service Worker IndexedDB 小宇宙 Open API

前端使用 React + Next.js 构建 SSR 页面，保证首屏加载速度和 SEO；音频播放基于 Web Audio API 实现高精度倍速控制；利用 Service Worker 缓存音频资源实现离线播放；IndexedDB 存储本地收听记录和下载数据；接入小宇宙开放 API 实现账号同步。
