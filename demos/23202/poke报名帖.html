# 生活娱乐

1创意名称 + 创意介绍

想解决什么问题
想做点正事、又不知道此刻该做什么，于是顺手刷起了手机——决策瘫痪比懒更消耗人。Poke 想替你把"现在做什么"这个决定做掉。
为什么会想到做这个
我自己常在通勤、午休、睡前这些零碎时间里"既不想躺平又懒得规划"，待办清单又长又吓人，反而一件都没动。我想要的不是清单，而是一个"现在，就这件，做就行"的轻推。
大概是什么产品
一个 iOS App。打开就推荐一件真实可做的小事，你用 4 个按钮反馈，它越用越懂你此刻想做什么：
✓完成
✗不喜欢
⏱稍后
↻换一个

2目标用户及痛点

面向哪些用户
有轻度拖延、想利用碎片时间却容易陷入"决策瘫痪"的人——尤其是想养成微习惯、但被庞大待办清单劝退的年轻上班族和学生。
在什么场景下使用
通勤路上、午休、排队、睡前——任何"有几分钟空、又不知道做啥"的零碎时刻，打开就用。
当前痛点
没有 Poke 时，用户面对的是一长串待办清单（看着就累、不知从哪下手）或干脆放空刷手机。清单工具只负责"记录"，不负责"此刻该挑哪件"——于是最后那一步，挑一件去做，总是落空。

3价值与意义

⚡ 效率提升
把"现在做什么"从一道选择题变成一次轻点。推荐在本地设备即时完成、零延迟、断网也能用，让决策成本降到最低，碎片时间真正被利用起来。
🌱 社会价值
用"一次只推一件"对抗信息过载与无限滑动信息流。不抢注意力、不做时长留存，推一件、做完就走——一款"反沉迷"的工具型产品，把时间还给生活。

4创意产物

本 HTML 即由 TRAE Work（Auto 模式）生成的创意产物，完整展示 Poke 的方案与界面构想。以下为产品已落地的核心设计，佐证可行性：
两段式推荐架构
模型（DeepSeek）异步"写出懂你、应时的事"入库；本地排序器即时"在对的时刻挑对的那一件"——结合时段匹配、新鲜度、完成/不喜欢历史打分，纯本地零延迟。
能量日历
做完一件事后用三色记录体感，信号反哺生成端，让推荐越来越贴近"做了真的让你变好"的事：
🟢 提升能量 🟡 中性 🔴 消耗能量
隐私优先
推荐全部在本地完成，个人数据不上云。
技术栈：Expo SDK 54 + TypeScript（strict）+ expo-sqlite + @tanstack/react-query
