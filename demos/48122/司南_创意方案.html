让方向·先于脚步。

一个让"过来人"为"后来者"铺路的学习平台。输入你想学的东西，平台交付一条经过验证的闭环路径——前置知识、主学习、配套工具、实践检验，一步不漏。

Sinan — The Path Before the Step. 向下探索
The Problem · 痛点

没有"师傅"领进门，
每个人都从零摸黑。

01

无从下手

面对全新任务，不知道该先学什么、后学什么。直接上手主任务卡壳，回过头才发现缺了前置知识。

02

路径碎片化

教程、视频、文档散落在 B 站、CSDN、GitHub 各处。要自己拼凑顺序，花在"找资料"上的时间比"学"还多。

03

工具难寻

哪个 API 中转站可用？哪个 IDE 适合新手？工具靠口口相传，新人只能一次次踩坑验证，重复前人的弯路。

04

缺乏闭环

学完理论没有实践项目检验，"看了等于会了"。没有反馈，就无法判断自己到底掌握到了哪一步。

The Solution · 解决方案

一条闭环，
而非一堆资料。

平台把"过来人"验证过的路径结构化为四个阶段，环环相扣，最终回到检验——形成完整的认知闭环。

STAGE 01
壹

前置知识

识别学习目标背后的依赖项。告诉你"先学什么"，避免直接撞墙。如学 LangChain 前必先掌握 Python。

STAGE 02
贰

主学习

给出主任务的参考学习路径，配经过筛选的视频清单与文档序列。不再纠结"看哪个教程"，直接进入学习。

STAGE 03
叁

配套工具

提前整理好这条路径上会用到的所有工具——官方 API、可靠中转、IDE、调试器。每个工具配独立使用教程。

STAGE 04
肆

实践检验

给出可实践的练习与项目，检测学习成果。通过则闭环完成；未通过则回到对应阶段——这就是"闭环"。

检验未通过 · 回到对应阶段
A Case Study · 案例

当一位零基础用户
输入"LangChain"。

User Input 我想学 LangChain，但毫无基础。
Stage 01 · 前置

先学 Python

LangChain 是 Python 生态的 LLM 编排框架，跳过 Python 直接学会反复卡壳。平台给出 Python 的最小必要子集：基础语法、虚拟环境、pip 包管理、面向对象，约 5–7 天可掌握。

基础语法venvpip视频清单 ×3
Stage 02 · 主学习

进入 LangChain

前置通过后，进入 LangChain 主体。平台按"核心概念 → 链式调用 → Agent → Memory → RAG"递进，每个节点配 1–2 个精选视频与官方文档段落，告别"不知道下一个该学什么"。

ChainsAgentsMemoryRAG视频清单 ×8
Stage 03 · 工具

配套工具集

这条路径上会用到的一切工具，提前为你整理好。每个工具配单独使用教程，不用再边学边四处搜罗。

OpenAI 官方 API可靠中转 APILangSmithJupyter每个工具独立教程
Stage 04 · 检验

实战项目闭环

给出三个递进难度的项目：①做一个单链问答 bot；②加 Memory 实现多轮对话；③搭一个 RAG 文档问答系统。完成即闭环；卡住则回到对应阶段查漏补缺。

单链 QA多轮对话RAG 系统检测通过 → 闭环
The Value · 价值

少走的每一步弯路，
都是赢回的时间。

01

效率提升

把"找资料—理顺序—选工具—做练习"这套原本需要数天甚至数周的零散工作，压缩为一次输入即可获得的现成方案。让学习者把时间花在"学"上，而不是"找"上。

"学习的启动成本，应当趋近于零。"
02

社会价值

打破"经验私有化"。让过来人的踩坑经验结构化沉淀，传递给后来者，缩小信息差。让没有"师傅"的人，也能被"领进门"——这是知识平等的一次小小推进。

"让经验，找到下一个人。"
