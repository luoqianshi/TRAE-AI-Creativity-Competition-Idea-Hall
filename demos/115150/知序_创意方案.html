知序

个人知识库智能管理系统 — 让知识回归秩序

创意介绍

一句话概括：知序是一款基于 AI 驱动的个人知识库文件管理系统，通过智能扫描、自动归类、命名规范化和知识索引，将混乱的电脑文件转化为可检索、可关联、可生长的知识资产。

想解决什么问题：每个人的电脑工作盘上都积累了大量文件——文档、代码、截图、下载物、参考资料——但大多数人缺乏一套系统化的文件管理体系。文件命名混乱、目录层级失控、重复文件泛滥、找东西全靠记忆，"存了等于扔了"是普遍困境。

产品形态：一套包含智能扫描程序 + 目录架构规范 + 自动化管理脚本 + 知识索引工具的完整解决方案，用户通过简单的命令行操作即可实现文件级别的"总工管理"。

四大核心功能

01

智能文件扫描

7大维度全面体检：类型分布、目录深度、大小分布、重复检测、命名规范、活跃度、空目录清理

02

PARA 目录架构

基于 PARA 方法论改良：Projects / Areas / Resources / Archive / Inbox，让文件各归其位

03

自动归类引擎

按文件类型、命名规则、内容特征自动将文件归类到对应目录，告别手动整理

04

知识索引生成

一键生成完整知识库索引——目录树、文件统计、标签交叉索引、近期变动清单

├── 04_Archive/           # 已完成归档
├── 05_Inbox/             # 临时收件箱
└── _system/              # 管理系统
    ├── scripts/          # 自动化脚本
    ├── devlog/           # 开发日志
    └── config.yaml       # 配置文件

痛点 → 解决方案

文件堆积 → PARA 架构 + 自动归类

每个文件都有唯一归属位置，新文件自动进入 Inbox，定期归类归位。

命名混乱 → 规范化命名引擎

日期前缀 + 版本标记 + 状态标签，文件名就是元数据，一目了然。

重复泛滥 → 哈希比对去重

基于 SHA256 哈希的重复文件检测，精确识别重复，释放存储空间。

知识无法沉淀 → 知识索引 + 开发日志

一键生成知识库全景索引，开发日志体系记录每一次创作和决策过程。

价值与意义

效率价值：每周节省 4+ 小时找文件的时间，一年约 200 小时——相当于多出 25 个工作日。

知识价值：将"沉睡"的文件激活为可检索、可关联的知识资产，让过去的积累为未来的决策服务。

社会价值：在信息爆炸时代，帮助每个人建立属于自己的"数字秩序"，提升全社会的数字素养。
