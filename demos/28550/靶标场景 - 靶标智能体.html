```yaml
apiVersion: apps/v1

kubernetes.io/os: linux
kubernetes.io/arch: amd64
---
apiVersion: v1
kind: Service
metadata:
name: ubuntu-dvwa
spec:
type: NodePort
ports:
- port: 80
targetPort: 80
nodePort: 30001
selector:
app: ubuntu-dvwa
```

**访问方式**：
`http://:30001`
**漏洞点**：
- SQL 注入 (Login 页面)

`http://:30003`

- 文件上传漏洞 (Image Upload)

### 重要说明
1. **Windows 部署要求**：
- 需要集群中有 **Windows 节点**（已启用 Windows 容器支持）
- 需要提前构建 Windows 镜像：
```bash
# 构建 ASP.NET 漏洞应用镜像
docker build -t k8s-security-training/windows-vuln-app:1.0 -f Dockerfile.windows .
```
- Dockerfile 示例（包含 SQL 注入漏洞）：
```Dockerfile
FROM mcr.microsoft.com/windows/servercore:1909
COPY app /app
CMD ["c:\\app\\vuln-app.exe"]
```

2. **安全提示**：
- 仅限 **训练环境** 使用
- 所有应用使用 **弱密码**（如 `admin:123456`）
- 请勿在生产环境部署
- 部署后立即删除（`kubectl delete -f all-scene.yaml`）

3. **验证部署**：
```bash
kubectl get pods -A
# 应看到三个 Pod 分别运行在不同 OS 节点
kubectl get svc
# 检查 NodePort 30001/30002/30003
```
