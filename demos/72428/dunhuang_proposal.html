敦煌

一个关于飞天、天穹与声音的新时代文化展示场景。 第一版只完成“飞天初现”：进入数字石窟，抬头看见一座被画出来的天空。

SCENE 01 / 飞天初现

低头进入洞窟。
抬头，看见一座天空。

飞天不是写实人物，而是身体、长巾、流云和风共同构成的飞行想象。 本 Demo 将传统壁画元素转译为可进入、可听见、可分享的数字文化场景。

创意介绍

不是做百科，
而是做一次进入。

《敦煌》不把传统文化做成静态展板，而是先聚焦一个完整场景： 飞天女从藻井天穹中被光唤醒。通过画面、音乐、音效、短句叙事和 动态光影，让普通用户先被吸引，再理解飞天、藻井和伎乐背后的文化含义。

入窟 黑场、尘埃、风声和光束，建立“进入石窟”的空间感。
点亮 莲花藻井从暗处浮现，中心发光，暗示“天空被画在洞窟顶部”。
飞天 飞天女以壁画线描与数字光影出现，长巾飘带成为主视觉。
听见 琵琶、箜篌、腰鼓、横笛等伎乐元素被转成空间音效。
用户痛点

很多人看见敦煌，
但没有真正看懂。

普通用户面对传统文化资料时，常常会被专业名词和大段说明挡住。 他们知道飞天很美，却不清楚飞天为什么能“飞”；知道藻井很复杂， 却不知道它其实是洞窟顶部的天空结构。

资料太专业 学术资料准确，但不适合普通用户快速理解和传播。
展示太平面 许多线上展示仍是图片加文字，缺少“进入感”。
审美容易俗化 传统文化常被做成大红大金或古风写真，缺少克制和现代性。
传播记忆点弱 用户看完后只觉得“好看”，但难以记住文化结构。
Demo 核心

一个场景，
四段镜头。

初赛 Demo 不做大而全。第一版只做“飞天初现”一个完整场景， 但把它做出清晰节奏：入窟、点亮、飞天、听见。每一段镜头都对应 一个文化解释，避免把所有信息塞进一个静态界面。

视觉素材 藻井天穹、飞天女主体、飘带循环、金粉尘埃、矿物颜料纹理。
声音素材 洞窟环境音、莲花点亮音、飘带风声、伎乐飞天音效。
技术实现 纯前端 HTML / React Demo，可后续加入 Three.js 与 Web Audio API。
分享结果 生成一张“我的敦煌记忆卡”，适合传播和作品帖展示。
