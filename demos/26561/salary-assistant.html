Overview

产品介绍：把工资从「月底一次性公布」变成「每天都能看到」。

很多打工人都有一个熟悉的场景：月底前两天疯狂刷新工资短信；请假时犹豫半天，因为不知道到底会少多少钱。 「打工助手」尝试做一件小但温柔的事——帮你把这份不确定感，拆成每天可见的数字和颜色。

Core Features

把「怎么算」和「怎么看」都做到打工人友好。

功能不是为了堆参数，而是为了回答几个简单的问题： 我今天值多少钱？请这次假要花掉几杯奶茶？这个月是怎么一点点累积到这份工资的？

📏

薪资规则一站式配置

入职时间、发薪日、截止日、日薪 / 月薪、几薪制、房补、餐补……这些零散的信息被统一收进一块规则面板里。

适配不同公司制度，不再靠脑补记规则。

📈

本月工资实时估算

根据出勤、请假与补贴规则，动态计算「已经赚到的金额」和整体进度条，让等工资的过程不再是黑盒。

越接近发薪日，进度越接近 100%，成就感也越高。

⏰

上下班打卡 · 打工节奏记录器

早上点一下「上班啦」，晚上点一下「下班溜」，顺手就能记下今日节奏，也为日结模拟提供真实依据。

记录成本够低，才有机会变成习惯。

🚫

请假标记联动工资

每一次请假都会在日历上留下一个明显的「缺口」，同时影响本月工资估算，让「请假要花掉多少钱」一眼可见。

不是为了劝你别休息，而是让选择更有信息。

🗓️

日历视图 + 本月统计

把出勤、请假和工资进度铺在同一张日历上，方便用户在月底回顾「这一整个月到底是怎么过的」。

视觉上更像一张「打工生活轨迹图」。

☁️

云端同步 · 跨设备使用

数据支持云端同步，手机和电脑都能接着用同一份记录，不会因为换设备就断档。

打工的路可以换车坐，但工资记录要是一条线。

Value

价值亮点：不仅算钱，也在安抚等钱的心情。

打工助手试图在「严肃的薪资计算」和「轻松的情绪表达」之间找到一个平衡点： 一边用规则和数据保证准确，一边用有趣的语言和视觉，告诉你——你真的在慢慢赚到这笔钱。

👀

把「月底惊喜 / 惊吓」变成「日常可见」。

每一天上班之后，工资进度条都会往前走一点点。用户不再需要等短信，而是随时打开就能看到自己离发薪日有多近。

🧮

从「只看总数」升级到「看过程」。

请假、加班、补贴这些细节，都在模拟中一一起作用。月底回看日历，就像在看一篇「这个月是怎么赚到这笔钱」的故事。

💗

情绪共鸣： 「知道今天值多少钱，就更想好好过完今天。」

当「请假 = 少赚 XX 元」被直观地看到时，很多人会更珍惜自己的出勤，也更愿意为自己真正想要的休息负责任。
