## 报名信息

- **创意名称**：探字星球（Hanzi Planet）
- **主赛道**：学习工作
- **附加赛道**：社会公益
- **一句话介绍**：一款基于 TRAE Work Auto 模式开发的微信小程序，用 AI 把每一个汉字都变成一颗会讲故事的星球，让孩子在星际探险中自然认字、会写、懂源、爱上汉字。
- **核心标签**：AI 教育、幼儿启蒙、汉字识字、微信小程序、TRAE Work、教育普惠

## AI 创意亮点

1. **AI 笔顺识别引擎**：基于 Canvas 实时采集书写轨迹，结合 DTW 动态时间规整算法与标准笔顺库进行即时纠正。
2. **AI 自适应学习路径**：基于艾宾浩斯遗忘曲线与用户答题数据，动态生成个性化复习计划。
3. **AI 字源演义动画**：把甲骨文、金文、小篆到现代汉字的演变过程转化为可交互故事。
4. **AI 童声伴读 + 故事生成**：用 TTS 讲解汉字故事，降低家长陪读压力。
5. **AI 加速研发**：基于 TRAE Work Auto 模式完成从需求拆解、UI 生成、Canvas 算法实现到文档治理的全流程协作。

## 评审重点

- **学习工作**：解决幼儿识字、笔顺纠正、幼小衔接与家庭陪读效率问题。
- **社会公益**：所有汉字内容完全免费、永久零广告，面向低收入家庭、留守儿童家庭和乡村幼儿园开放。
- **文化传承**：用 AI 重新讲述《说文解字》《千字文》《易经·蒙卦》等蒙学与字源文化。
- **TRAE Work 价值**：展示独立开发者如何借助 TRAE Work 把教育创意快速沉淀为可评审、可迭代、可落地的产品方案。
