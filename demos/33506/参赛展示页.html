AI 在终端里跑，人却切到了别处

用 Claude Code、Codex 跑长任务时，你切去查资料、写文档，AI 到底写完没？出错没？每次都得切回窗口确认，注意力被反复打断。

● 没有 Light

  • 不停切回终端盯进度，频繁打断手头工作
  • 没及时发现 AI 已停下 / 报错，白白浪费十几分钟
  • 多个会话并行时，分不清是哪个卡住了
→

● 有了 Light

  • 余光一瞥：蓝光=工作中、绿勾=完成、红抖=出错
  • 完成 / 报错的一瞬间就被你看见，立刻接手
  • 多 Agent 自动分栏，谁在干什么一目了然
大概是什么产品

一颗会发光的桌面状态胶囊

基于 Electron 的桌面应用，常驻屏幕顶端、不抢焦点。把手机顶部「低打扰状态提示」的体验，搬到了电脑上。

状态一目了然

工作中泛蓝光呼吸、完成变绿打勾、出错变红抖动，还显示当前工具与已用时长。

多会话 / 多 Agent

Claude Code 与 Codex 同时跑也能分栏显示，各自独立状态，互不打架。

磨砂玻璃 UI

玻璃拟态质感，任何壁纸下白字都清晰；鼠标移上去展开详情面板。

顺手的小工具

桌面备忘录 + 当前播放的音乐（可上一首 / 下一首 / 暂停），随手就用。

纯本地、隐私安全

只监听 127.0.0.1，不联网、不上传任何数据，外部机器无法访问。

一行 hook 接入

通过本地 HTTP 接收事件，任何能上报状态的 Agent 都能接，扩展性强。

目标用户及场景

给「让 AI 帮自己写代码」的人

使用 AI 编程助手的开发者、独立开发者与 AI 编程重度用户。

场景 01

单 Agent 跑长任务

启动 Claude Code 后切到浏览器查资料，胶囊保持蓝光呼吸；任务完成的一瞬间变绿打勾，你立刻知道该回去了。

场景 02

双 Agent 并行

Claude Code 与 Codex 同时干活，胶囊分裂成左右两栏，分别显示状态——谁卡住、谁完成，一眼分清。

场景 03

工具调用瞬时反馈

AI 调用 Bash / Edit 时，胶囊显示当前工具名，让你确认它「在做事」而不是卡死。

价值与意义

把「主动查」变成「被动感知」

效率提升

消除「切窗口查状态」的上下文切换成本，让开发者敢于放心地把长任务交给 AI 并行处理，真正实现「人机并行、互不打断」——这正是 AI 编程时代最稀缺的专注力。

社会 / 生态价值

随着 AI 编程 Agent 普及，「人如何低打扰地同时监督多个 AI 任务」会成为通用需求。Light 提供一种轻量、隐私安全（纯本地 + 开源 MIT）的范式，可推广到任意通过 HTTP 上报状态的 Agent。

技术实现

轻量、原生、可扩展

主进程跑本地 HTTP server + 状态机，渲染层用 React 画胶囊，动画交给 Framer Motion / CSS 合成层，纯 transform 驱动、不卡顿。

Electron Vite React 18 TypeScript Framer Motion 本地 HTTP · 127.0.0.1
隐私与安全
  • 🔒 HTTP 服务只绑定 127.0.0.1，外部机器无法访问
  • 🔒 没有任何遥测 / 上报，备忘录只存在本机
  • 🔒 渲染层隔离，页面拿不到 Node 能力
  • 🔒 不执行任意命令，事件字段仅用于显示
