# Bravream · 静态可交互页面（用户端）

这是 Bravream（AI 求职教练）用户端的 **1:1 高保真静态可交互页面**。
所有数据均为前端 mock，**不调用任何后端、不暴露业务源码**，
可放心用于产品演示、投资人讲解或用户体验走查。

## 文件结构

```
.
├── index.html          # 页面结构（首页 + 聊天页）
├── assets/
│   ├── styles.css      # 全部样式（Material Design 3 + 自研深色星夜风）
│   └── app.js          # 全部交互（导航、消息 mock、粒子动画、面板、拖拽）
└── README.md
```

## 打开方式

### 方式一：直接双击 `index.html`
最简单的方式，浏览器即可打开。

> 提示：首次加载需要联网拉取 Google Fonts（Material Symbols Rounded / Roboto Flex / Sigmar One）。
> 如果你处于离线环境，可以提前把这三种字体下载到 `assets/fonts/` 再引用。

### 方式二：本地起一个静态服务器（推荐）
部分浏览器对本地 `file://` 协议有限制，建议起一个静态服务器：

```bash
# 进入本目录
cd "Bravream_Trae_静态页面/2"

# Python 3
python3 -m http.server 8765

# 或者 Node.js
npx http-server -p 8765
```

然后在浏览器打开：<http://127.0.0.1:8765/>

## 体验动线

1. **首页**：星空背景 + 鼠标光柱 + 输入框粒子动画
   - 鼠标在页面内移动 → 观察环境光跟随
   - 点击 4 个 AI 顾问（职业规划 / 简历优化 / 职位分析 / 职位比对）→ 自动填充问题并进入聊天
   - 在输入框敲字 → 发送 → 粒子飞散动画 + 自动跳转聊天页

2. **聊天页**：三栏布局
   - **左侧栏**：会话列表（今天 / 昨天 / 7 天内），支持收起 / 切换 / 删除
   - **中间**：消息区（mock 智能回复：简历优化、职位匹配、通用回答）
   - **右侧**：内容面板（点击 AI 回复中的卡片即可打开，可拖动中间分隔条调整宽度）
   - 工具栏：消息 / 岗位 / 文件 三个 Tab

3. **核心交互**
   - 简历优化问题 → 触发简历详情面板（含完整简历结构）
   - 职位匹配问题 → 触发推荐职位面板（带匹配度进度条）
   - 联网搜索按钮：可切换高亮状态（mock）
   - 拖动中间分隔条：自由调整三栏宽度
