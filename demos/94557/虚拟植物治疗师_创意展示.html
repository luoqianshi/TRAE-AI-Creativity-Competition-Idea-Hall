// Core Concept

养植物 = 养自己

将抽象的自我关怀行为转化为可感知的植物生长，让"对自己好"变得看得见、摸得着

🌱

行为即养分

早睡产生"睡眠之水"、运动产生"活力阳光"、冥想产生"宁静露珠"——每种自我关怀行为对应一种独特的植物养分

🌿

状态即镜像

植物的每一片叶子、每一朵花，都映射着你最近的生活状态。它茂盛，说明你最近对自己很好；它枯萎，是温柔的提醒

💜

陪伴即疗愈

不是冰冷的打卡数据，而是一个"被你需要"的生命。你照顾它的过程，其实是在学习照顾自己

// Pain Points

为什么我们需要它

道理都懂，但就是做不到——这是自我关怀最大的困境

😮‍💨

打卡App冷冰冰

习惯打卡只有数字和勾，没有情感连接。坚持了没有成就感，放弃了没有愧疚感——因为那只是一个数字。

🤔

不知道什么算"对自己好"

自我关怀太抽象了。喝一杯水算吗？早睡半小时算吗？需要一个具体的、可视化的方式让自己感受到"我在照顾自己"。

🏠

独居缺少"被需要感"

一个人住的时候，很容易凑合——外卖对付、熬夜无感、周末躺两天。没有人在等你回家，没有生命需要你照顾。

// Features

核心功能

不只是养成游戏，更是一套完整的自我关怀系统

01

行为识别引擎

对接手机传感器和健康数据，自动识别早睡、运动、步数等行为，无需手动打卡

02

AI 关怀建议

根据植物状态分析你的薄弱环节，推送个性化的自我关怀建议："你的植物缺水了，今晚试试早睡？"

03

情绪天气系统

每天记录心情，形成专属"情绪天气"。连续晴天，植物会开出稀有的彩虹花

04

植物图鉴收集

超过 50 种植物品种等待解锁——薰衣草代表平静、向日葵代表活力、昙花代表深度放松

05

好友花园互访

参观朋友的植物花园，互相"浇水"——送出一个关怀行为，双方的植物都会获得加成

06

成长时间胶囊

每月生成一份"自我关怀报告"，记录你这个月对自己做了多少好事，见证成长轨迹

// Use Cases

抑郁或焦虑的时候，连照顾自己都很难。但植物需要你——这个"被需要"的感觉，可能就是拉你一把的力量。

// Value

价值与意义

💚 社会价值：让自我关怀成为习惯

将心理健康领域"自我关怀"的抽象概念，转化为每天可操作、可感知的具体行为。通过情感化的养成机制，帮助年轻人在"照顾另一个生命"的过程中，不知不觉地学会照顾自己。对于独居青年、高压职场人、情绪低落期的人群，这棵植物不只是一个游戏，而是一个"被你需要"的温暖存在。

💰 商业价值：天然收集 + 社交裂变

植物养成具有天然的收集属性——50+ 品种、稀有花朵、季节限定，驱动持续活跃。好友花园互访、互相浇水带来社交裂变。商业化路径包括：付费植物品种、联名主题花盆、企业员工关怀版本（B2B）、与心理健康机构合作推广。
