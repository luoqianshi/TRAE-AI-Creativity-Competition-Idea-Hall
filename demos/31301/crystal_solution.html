AI 对话代理服务

Technical Features

技术特性

Go 后端 + 嵌入式前端，轻量高效的本地智能体架构

🏗️ Go 嵌入式单文件部署
  • 前端资源通过 go:embed 编译进二进制文件
  • 零依赖部署，单可执行文件即可运行
  • 随机端口分配（10000-40000），避免冲突
  • WebView 嵌入式窗口 + 浏览器双模式
🔄 智能反向代理
  • 自动识别 /v1/、/tts/、/ltpx/ 等路径并代理至核心服务
  • 非代理路径由嵌入式文件系统直接响应
  • 统一入口，前端无感知的请求路由
  • 优雅关停：SIGINT/SIGTERM 信号处理
🎨 玻璃拟态设计体系
  • 半透明毛玻璃面板 + backdrop-filter 模糊
  • 亮色/暗色双主题 CSS 变量覆盖
  • 标准依赖库统一管理（Font Awesome / highlight.js / KaTeX / ECharts / Mermaid / Live2D）
  • 三断点响应式（1024px / 768px / 480px）
🧩 扩展包自动发现机制
  • 扫描 package 目录，自动识别含 metadata.json 的子文件夹
  • 图标/URL 路径自动解析为完整访问地址
  • 支持拖拽安装 .ltpx/.ltp2 格式扩展包
  • LTPX 工具包支持运行时动态加载/卸载
🤖 AI 工具调用集成
  • OpenAI Function Calling 格式工具定义
  • 内置 open_page / get_config / modify_config 三大工具
  • 多模态输入：文本 + 图片附件混合发送
  • 配置变更自动弹出三栏预览确认对话框
⚡ 异步图像生成引擎
  • 异步任务处理器，提交即返回，轮询获取结果
  • 支持 Stable Diffusion / RealESRGAN 超分辨率
  • Go 原生 GGUF 二进制解析器（13 种值类型）
  • 图片格式批量转换（PNG / JPEG / WebP 互转）
