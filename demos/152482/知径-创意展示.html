一、创意介绍

想解决什么问题

很多人想学一个新领域（比如 AI、摄影、烘焙），却不知道从哪开始、学什么、按什么顺序学。网上的攻略越看越焦虑，信息碎片化严重，缺乏一条清晰的学习路径。

为什么会想到做这个

团队在自学过程中反复遇到这个问题：搜"人工智能怎么入门"，结果出来 100 篇文章、50 个视频，说法各不相同。我们想要一个工具，能像导航仪一样，输入目的地就规划好路线——于是做了知径。

大概是什么产品

知径是一个 Web 应用（网站）：用户输入学习目标，AI 自动拆解方向、生成比喻可视化知识体系、推荐真实学习资源、规划学习路线。前端 React + 后端 Python FastAPI + DeepSeek AI。

五、价值与意义

维度价值说明
效率提升 用户从"搜索 → 筛选 → 整理 → 规划"数小时的流程，缩短到输入一句话、10 秒内获得完整知识体系。三层缓存机制让重复查询秒级返回。AI 追问功能让用户遇到疑问时不用另开窗口搜索，直接在知识点页面提问。
社会价值 降低学习门槛——不是每个人都有信息检索和路径规划能力。知径把"知道怎么学"这件事本身平民化，让任何有学习意愿的人都能快速获得一条清晰路径。尤其帮助教育资源不发达地区的学生，一部手机就能获得 AI 生成的个性化学习路线。

七、技术实现

技术栈

React 18 TypeScript Vite Tailwind CSS Framer Motion react-i18next Python FastAPI SQLAlchemy SQLite DeepSeek API JWT Prometheus Docker

架构亮点

  • 三层缓存去重：内存缓存（0ms）→ 数据库存档（5ms）→ AI 生成（5-10s），相同目标不重复调 AI
  • AI 降级策略：无 DeepSeek Key 时自动降级到 23 个预置模板 + mock 比喻库
  • 代码分割：React.lazy 拆分 9 个页面，按需加载
  • 限流保护：IP 级别 Rate Limiting，防止 AI 接口被刷
  • Prometheus 监控：152 条自定义指标，实时监控系统健康
TRAE Work 开发过程：整个项目使用 TRAE Work 的 AI 辅助编程完成。从 v1.0 基础功能到 v7.1 持久化档案，经历了 8 个版本的迭代演进。AI 负责生成代码骨架、重构组件、编写测试、修复 Bug、生成文档，人类负责需求定义、架构决策和方案审核。
