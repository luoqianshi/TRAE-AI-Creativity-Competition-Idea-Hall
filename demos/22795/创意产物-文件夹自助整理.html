💡 创意介绍

想解决什么问题

电脑里散落着成千上万的文件——下载目录堆积如山、桌面密密麻麻、文档文件夹毫无章法。手动整理耗时费力，现有工具要么只按扩展名机械分类，要么需要写复杂规则，普通人根本用不起来。

为什么会想到做这个

每次想找一份文档都要翻半天，下载文件夹永远是一团乱麻。市面上的文件整理工具要么不懂中文文件名的语义，要么会误操作系统文件夹导致软件崩溃。我们需要一个"懂你"的智能助手。

大概是什么产品

一款 Tauri 跨平台桌面应用，用户选择目录后，AI 自动识别文件语义、生成整理方案，用户审批确认后一键执行。同时为每个文件夹生成用途标注，下次打开就知道里面是什么。智能避让系统/软件文件夹，绝不误操作。

✨ 三大差异化亮点

🏷️

文件夹用途标注

为每个文件夹自动生成用途说明，类似 macOS 的 .DS_Store 但可开关。下次打开就知道"这个文件夹是干嘛的"，告别迷路。

🛡️

智能避让系统文件夹

三层黑名单 + AI 辅助识别，自动跳过 Windows/macOS 系统目录、软件安装目录、开发工具结构化文件夹，绝不误操作。

🤖

LLM 深度语义理解

不只是按扩展名分类，AI 理解文件名和内容的语义，"季度报告.pdf"和"Q3财报.xlsx"会被归到同一类，而非分散到不同扩展名文件夹。

💎 价值与意义

  • 📈

    效率提升：从数小时到数分钟

    传统手动整理一个混乱的下载文件夹可能需要 2-3 小时，使用本工具只需 5 分钟审批确认。AI 理解中文文件语义，分类准确率远超按扩展名机械归类。

  • 🏢

    商业价值：填补市场空白

    现有 AI 文件整理工具（LlamaFS、AI File Sorter 等）均未实现文件夹标注和系统避让，本产品在功能上形成明确差异化，可面向个人用户免费 + 高级功能订阅模式。

  • 🔒

    隐私安全：本地优先架构

    默认使用本地 Ollama 运行 LLM，文件内容不出本机。云端 API 仅作为可选备选，用户数据始终在本地。标注文件支持 AES-256-GCM 加密，审计日志链式防篡改。
