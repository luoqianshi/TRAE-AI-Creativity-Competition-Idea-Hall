广州中考志愿填报助手

AI 驱动的智能志愿填报与录取风险评估系统

💡 创意介绍

广州中考志愿填报助手是一款面向广州中考考生和家长的智能志愿填报辅助工具。系统内置50 所广州高中真实招生数据，通过 AI 算法综合成绩梯度、名额分配、末尾志愿序号、外区投档分等多维度数据，一键生成"冲-稳-保"个性化志愿方案，帮助考生科学填报、降低滑档风险。

50+广州高中数据
4招生批次支持
12万年服务考生规模
3分钟完成志愿方案

🎯 目标用户及痛点

核心用户群体

广州中考考生及家长，每年约 12 万考生，覆盖 11 个行政区。

使用场景

中考成绩公布后，考生需要在 3-5 天内完成志愿填报。用户打开 H5 页面，输入成绩和所在区域，系统自动分析并推荐最优志愿方案。

四大核心痛点

📚

信息分散，收集成本高

招生数据分散在官网、公众号、学校通知等多个渠道，家长需要花费数天甚至数周收集和整理信息。

🤯

规则复杂，难以理解

四个批次、名额分配、末尾志愿序号、外区投档分差异……普通家长难以在短时间内消化这些复杂规则。

⚠️

凭感觉填报，滑档风险高

缺乏科学的个性化推荐工具，只能凭经验和感觉填报，每年都有大量考生因填报不当而滑档。

⏰

决策时间紧迫

成绩公布到志愿截止通常只有 3-5 天，家长需要在极度焦虑中做出影响孩子未来的重大决策。

⚡ 核心功能

🤖

智能推荐引擎

综合成绩梯度、本区/外区录取分差异、名额分配、末尾志愿序号，一键生成"冲-稳-保"六级志愿方案。

🔍

学校查询系统

50 所广州高中详细信息，支持按区域、类型、等级、批次多维度筛选，查看历年分数线和招生计划。

📋

四批次志愿填报

支持第一批自主招生、第二批名额分配、第三批统一招生、第四批民办学校，总计最多 15 个志愿。

🎯

名额分配精确匹配

选择初中学校后，精确展示该初中在目标高中的名额分配数量，让第二批志愿填报有据可依。

📊

录取概率分析

实时显示每所志愿学校的录取概率（把握大/有机会/可冲刺/搏一搏），帮助考生理性决策。

📱

扫码即用 H5

H5 移动端设计，无需下载安装，扫码即可使用。内置二维码生成，方便分享给其他家长。

🏗️ 技术架构

Vue 3 TypeScript Tailwind CSS Vite Node.js Express SQLite RESTful API 响应式设计 反爬虫安全

前后端分离架构，前端构建 H5 移动端界面，后端提供 RESTful API，数据库存储 50 所广州高中真实招生数据。

🌟 价值与意义

🏛️ 促进教育公平

教育公平是最大的民生。该系统让每个考生无论家庭背景如何，都能获得科学、精准的志愿填报建议，降低因信息不对称导致的滑档风险，让教育机会更加公平可及。

⚡ 提升效率（从数天到数分钟）

将传统需要数天甚至数周的信息收集和决策过程缩短到几分钟。智能推荐算法一键生成"冲-稳-保"方案，家长无需再在多个渠道间反复查找和对比数据。

📊 数据驱动决策

内置 50 所广州高中真实招生数据，涵盖历年分数线、名额分配、末尾志愿序号等关键指标。志愿填报从"凭感觉"变为"靠数据"，让决策更加科学理性。

🌐 零门槛普惠使用

H5 移动端设计，无需下载安装，无需注册登录，扫码即可使用。支持局域网和互联网访问，让更多家庭受益。
