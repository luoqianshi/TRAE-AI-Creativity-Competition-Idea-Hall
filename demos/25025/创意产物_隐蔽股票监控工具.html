📊 隐蔽股票监控工具

上班也能安心看盘的终极解决方案 —— 伪装成Excel的A股实时监控神器

💡 创意介绍

这是一款专为上班族设计的隐蔽式A股实时监控工具。它最大的创新点在于：从外观到交互，完全伪装成Microsoft Excel电子表格，即使被同事或领导从背后看到屏幕，也绝不会引起任何怀疑。

🎯 想解决什么问题

对于关注股市的白领来说，上班期间看盘是个巨大痛点：券商APP界面太显眼、同花顺/东方财富一眼就能被认出、手机看盘又小又不方便。一旦被领导或同事发现，轻则尴尬，重则影响职业形象。

💡 解决方案

将股票监控工具完美伪装成Excel表格：窗口标题显示"Book1 - Excel"、界面采用白底黑字的表格样式、数据以行列形式展示、支持双击查看走势图（伪装成"数据分析"）。真正做到大隐隐于市。

📱 产品形态

Windows桌面端应用程序，基于Python + PyQt5开发。单文件可执行，无需安装，即开即用。源码约2900行，包含9个核心类，功能完整成熟。

🔧 更多功能细节（从源码提取）

双击编辑持仓数据

在表格中双击"成本/现价"列或"持有数"列，弹出编辑对话框，可直接修改持仓数量或成本价。修改后自动重新计算市值、盈亏、当日盈亏。

混合数据策略

系统采用智能混合数据模式：优先从positions.json读取预存数据（确保导入后立即可见），再尝试从腾讯财经API获取实时价格覆盖。API失败时自动回退到预存数据，不会出现全"--"的情况。

交易日智能判断

自动判断当前是否在A股交易时间内（上午9:15-11:30，下午13:00-15:00，排除周末）。交易时间内动态计算当日盈亏，休市时保留导入值不变。每个新交易日自动清除"当日买入"和"已卖出"标记。

卖出标记与自动清理

全部卖出后标记is_sold=True，当日仍保留盈亏数据用于统计。次日程序启动时自动清除已卖出股票，保持列表整洁。

表格排序

点击任意表头可按该列排序，使用NumericTableWidgetItem自定义类实现数值排序（而非字符串排序），确保盈亏、市值等数值列排序正确。

多选操作

支持Ctrl/Shift多选股票行，Delete键批量删除，移除前弹出确认对话框。

港股支持

自动识别港股代码（HK前缀），腾讯API自动补零为5位数字获取行情数据。

同步功能

记住上次导入的文件路径（config.json），一键"同步"按钮重新读取该文件并覆盖更新已有持仓数据。

技术栈

数据流

StockDataFetcher (后台线程, 每10秒) → requests.get('https://qt.gtimg.cn/q=sh600519,...') → 解析gbk编码的返回数据 → emit data_updated(dict) 信号 → StealthStockMonitor.on_data_updated() → 更新 stock_data → 判断交易日/交易时间 → 动态计算盈亏或保留预存值 → refresh_table() → 更新ExcelStyleTable → update_minimalist_panel() → 更新极简面板 → 更新走势图（如果在走势标签页）

🚀 使用方式

  1. 下载程序，双击 start.bat 启动
  2. 程序自动加载预设持仓，显示为Excel表格样式
  3. 点击"买入"输入股票代码，自动获取名称，输入数量和价格
  4. 点击"导入"选择券商导出的CSV/XLS/XLSX文件
  5. 双击股票行查看分时走势图
  6. 双击"成本/现价"或"持有数"列可直接编辑
  7. 点击"极简"切换为悬浮面板，最小化为"股"字圆按钮
  8. 按Delete键快速删除选中股票（支持多选）
  9. 关闭窗口自动最小化到托盘，后台静默监控
