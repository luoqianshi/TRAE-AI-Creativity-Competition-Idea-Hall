TECHNOLOGY

技术原理与亮点

从"听懂"到"执行"，每一步都有技术支撑，每一步都清晰可见。

01

多层级意图分类模型

采用 BERT-based 分类器进行三级意图识别：一级（场景类/设备类/情绪类）→ 二级（睡眠/观影/通风等12个场景）→ 三级（具体设备参数）。模糊指令通过情感分析模块补充语义信息。

"我有点闷" → sentiment: negative + topic: environment → intent: VENTILATE
02

设备动作编排引擎

基于规则+学习的混合编排策略。预定义 30+ 场景模板，同时通过用户反馈数据持续优化动作时序（如先关窗帘再调暗灯光，避免视觉突变造成不适）。

sleep_scene = [curtain.close(), light.dim(10%), ac.mode(SLEEP, 26°C), tv.off()]
03

CSS 3D 实时渲染管线

纯 CSS transform 构建 3D 客厅场景，通过 CSS 变量和 class 切换实现设备状态过渡动画。无需 WebGL 即可在小程序环境中流畅运行，兼顾视觉效果与性能。

transform: rotateX(-8deg) rotateY(25deg); transition: all 0.8s ease;
04

决策链路可视化

将后台的意图分类、策略生成、指令编码过程以步骤条形式实时呈现，每个阶段展示关键数据结构，消除 AI 黑盒焦虑，帮助用户理解和信任系统决策。

Pipeline: Input → NLU → Strategy → JSON → Hardware
