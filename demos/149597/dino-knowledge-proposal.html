01 / 创意介绍

当恐龙百科"活"了过来

把一本厚厚的恐龙百科 PDF 交给 AI，让每个人都能用自然语言提问、看图、探索知识图谱。

🦕

想解决什么问题

传统恐龙百科读物是静态的——你只能按页码逐页阅读，无法通过提问获取信息，图片和文字脱节，知识之间的关系更是一团迷雾。当你想知道"霸王龙和棘龙谁更大"时，只能靠人肉翻阅、手动比对，效率极低。

💡

为什么想到做这个

RAG（检索增强生成）技术在医疗、法律等领域大放异彩，但很少有人把它用在知识科普上。一本恐龙百科图书包含了文本、图片、表格、图谱等丰富内容，正是展示 RAG + 多模态 AI 能力的最佳场景。

🌐

大概是什么产品

Web 应用（网站/系统），前端 Vue 3 + Element Plus，后端 FastAPI+Python。支持上传 PDF 文档自动解析、语义搜索、AI 问答（6 种查询模式）、知识图谱可视化。浏览器访问即可使用，无需安装。

🏗️

技术源头

基于开源 RAG-Anything 框架深度定制，整合 MinerU 文档解析、LightRAG 检索引擎、Ollama 本地 VLM、DeepSeek 大模型、PostgreSQL + pgvector 向量存储，形成从文档到问答的完整技术链路。

当前痛点

📖 静态阅读体验差

PDF 百科只能逐页翻阅，无法按需检索。想对比两种恐龙的数据，需要来回翻几十页进行人肉比对。

🖼️ 图文割裂

文档中的图片、表格、公式散落各处，与文字描述缺乏关联。AI 无法"看见"图片中的内容来辅助问答。

🕸️ 知识孤立

恐龙之间的演化关系、分类关系、时空分布关系隐藏在文字之中，没有结构化呈现，无法直观探索。

❓ 难以验证

用通用 AI 问专业知识，得到的回答无法追溯来源，存在"幻觉"风险。需要一种能精准定位原文的机制。

03 / 使用场景

从上传文档到对话式探索

一条完整链路：上传 PDF → 智能解析 → 多模态处理 → 语义检索 → 智能问答。

01

上传恐龙百科 PDF，AI 自动解析

用户将恐龙百科 PDF 拖入系统，MinerU 引擎自动解析文档结构——正文、图片、表格、公式全部分离提取。大文档支持按 50 页自动拆分，子文档自动关联。整个过程带有实时的 SSE 进度推送，前端进度条可视反馈。

02

多模态内容理解——让 AI 看懂每一张图

文档中的恐龙复原图、骨骼化石照片、地理分布表格被提取后，由本地 VLM 模型（qwen3-vl）生成文字描述。描述内容参与向量检索和知识图谱构建，让图片也能被"搜到"。

03

知识图谱可视化——恐龙之间的"关系网"

LightRAG 引擎自动抽取恐龙实体（霸王龙、三角龙、梁龙等）及其关系（掠食、共存、演化等），构建交互式知识图谱。用户点击节点展开详情，直观探索恐龙世界的关系网络。

04

对话式问答——像聊天一样学恐龙知识

用户输入"霸王龙的咬合力有多大？"，系统通过向量检索 + 知识图谱联合召回相关文本和图片，VLM 增强理解图片内容后，由 DeepSeek 生成精准回答。每条回答标注引用来源——文档名、页码、相关图片，确保知识可追溯。

07 / 核心技术流程

两大核心数据流

知识入库流和智能问答流构成了完整的 RAG 闭环。

📥 知识入库流（上传→解析→入库）

1
用户上传 PDF → 计算 MD5 → 保存到本地 → 写入 documents 表
2
触发解析 → MinerU 子进程调用 vLLM 引擎 → 提取文本/图片/表格/公式
3
文本分离 → LightRAG 向量化入库 → 图片资产存入 image_assets 表
4
多模态 VLM 描述 → 知识图谱实体/关系抽取 → GraphML 持久化

🔍 智能问答流（提问→检索→生成）

1
用户输入问题 → 第一步检索获取上下文 + 提取图片路径
2
查 PG image_assets → 图片按关键词匹配度排序 → 最多取 5 张
3
VLM 增强（可选）→ qwen3-vl 看图生成描述 → 拼接入查询上下文
4
DeepSeek 生成回答 → 组装引用标注 → 保存到 query_history 表
08 / 功能特性总览

不止是问答，是一整套知识管理方案

五大功能模块覆盖知识库建设的完整生命周期。

📤

智能文档解析

支持 PDF 上传、文件夹批量导入、大文档自动拆分（每 50 页）。MinerU 2.0 + vLLM 引擎精准提取文本、图片、表格、公式。带实时 SSE 进度反馈。

💬

六种查询模式

local（本地向量）、global（全局图谱）、hybrid（混合）、mix（混合+知识图谱）、naive（纯关键词）、bypass（直连 LLM）。一键切换，适配不同查询场景。

🖼️

VLM 增强问答

检索到的相关图片由本地 Ollama qwen3-vl 模型"看图理解"，生成文字描述后参与问答上下文。让 AI 真正"看见"恐龙复原图、化石照片等视觉信息。

🕸️

知识图谱可视化

自动抽取恐龙实体及其关系（掠食、共存、演化），使用 vis-network 交互式力导向图呈现。支持实体搜索、热度排行、展开深度控制、节点详情面板。

📊

仪表盘与监控

系统状态总览：文档数量、查询统计、索引状态、PostgreSQL 和 Ollama 健康检查。ECharts 图表可视化展示系统运行状态。

📋

查询历史记录

所有问答自动保存，支持随时回顾历史对话。每条记录包含问题、答案、引用来源、相关图片、查询模式、VLM 增强标记等完整上下文。

10 / 部署方案

一键启动，本地运行

完整的启动脚本和环境配置，降低使用门槛。

🐳

Docker 容器化

PostgreSQL 17 通过 Docker 运行，pgvector 扩展预装，数据卷持久化。一条 docker run 命令即可启动数据库服务。

🦙

Ollama 本地推理

VLM 模型 qwen3-vl 在本地运行，无需联网。与 MinerU 通过显存时分复用机制共享 GPU，最大化硬件利用率。

⚡

一键启动脚本

PowerShell 脚本自动完成：① 检查/启动 PostgreSQL Docker ② 检查/启动 Ollama ③ 启动 FastAPI 后端。前端单独 pnpm dev 启动。
