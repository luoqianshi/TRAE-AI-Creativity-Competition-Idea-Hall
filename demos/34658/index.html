D · 01Web 应用 / 无限画布

无限画布

把灵感、参考图、生成结果与项目节点放进同一张画布里，边生成边整理。

1新建画布项目，确定主题与目标。
2写清主体、风格、构图与限制条件。
3对比不同模型，沉淀为节点与分支。
4同一方向持续放大、延展或复用。
D · 02Web 应用 / 漫剧梦工厂

漫剧梦工厂

剧本 → 分镜 → 图片 → 视频的完整管线，适合系列化短剧与角色出场片段。

1确定主题：人物、世界观与情绪基调。
2补充剧本与镜头节奏，便于拆分。
3分镜生成关键帧，固定角色与景别。
4图生视频动作化，串成动态镜头。
D · 03Web 应用 / 创作 Agent

创作 Agent

提示词整理、文案生成、图像/视频任务与素材仓库，成为持续协作的助手。

1把目标、语气、受众写清楚再发送。
2参考素材越多，结果越贴合要求。
3把成功的提示词与素材存入仓库。
4回看创作历史，从已有成果继续。

一个长期维护的创作平台。

这里不只是作品展示页，也是真实可运行的工作台主页。三个 Web 应用与背后的 API 网关，由同一套入口承载，云端部署后同样可用。

我希望它保持干净：没有廉价渐变、没有过度装饰、没有多余色彩。重要的是作品本身，以及让创作过程可被复盘。

如果你也喜欢这种工作方式，欢迎从这里开始。
