项目介绍

金陵邻里通是一款面向住宅小区居民的智慧社区微信小程序，旨在解决传统社区信息不透明、邻里互动少、活动组织难等痛点，通过数字化手段提升社区治理效率和居民生活品质。

在现代城市生活中，小区居民往往"同住一栋楼，相见不相识"。社区通知靠张贴、活动报名靠微信群接龙、日程安排靠口口相传——这些传统方式效率低下，信息容易遗漏。金陵邻里通应运而生，以微信小程序为载体，无需下载安装，打开即用，让社区生活更智能、更温暖。

核心功能

📅

智能日程

年/月/周三视图日历，社区活动一目了然，支持活动管理与提醒

🎉

活动发现

首页聚合社区精彩活动，卡片式浏览，快速了解活动详情

🔐

业主认证

严格的身份审核机制，区分访客、待审核、业主、管理员角色

⚙️

管理后台

管理员可便捷管理活动卡片、轮播图、用户审核与数据导出

目标用户与痛点

核心用户：住宅小区居民、业主委员会、物业管理人员

使用场景：业主想查看本月社区有哪些活动；业委会要组织业主大会需要发布通知和日程；物业需要管理居民信息和活动安排。

当前痛点：

  • 社区通知层层转发，信息衰减严重，很多居民错过重要活动
  • 活动报名依赖微信群接龙，统计困难，容易遗漏
  • 缺乏统一的社区活动日历，居民无法提前规划时间
  • 新住户难以融入社区，邻里之间缺少互动渠道

价值与意义

📈

效率提升

活动发布从"贴海报+微信群"简化为一次后台编辑，信息触达率提升80%以上

🤝

社会价值

增强邻里互动，提升社区归属感，助力构建和谐社区文化

🔒

信息安全

业主认证机制保障社区信息安全，仅认证用户可查看敏感内容

技术架构

微信小程序 TDesign UI Node.js Express MySQL Vercel

前端采用微信小程序原生框架搭配 TDesign 组件库，保证流畅的用户体验和一致的视觉风格。后端使用 Node.js + Express 构建 RESTful API，数据持久化采用 MySQL 关系型数据库，整体部署于 Vercel 云平台，实现低成本、高可用的服务架构。

项目亮点

1. 多视图日历系统：独创的年/月/周三视图切换，满足不同维度的日程查看需求，活动分布一目了然。
2. 角色分级体系：访客/待审核/业主/管理员四级角色，配合严格的审核流程，兼顾开放性与安全性。
3. 轻量无负担：微信小程序形态，无需下载安装，即用即走，降低用户使用门槛。
4. 管理端一体化：管理员可在小程序内完成内容管理、用户审核、数据导出等全部操作。
