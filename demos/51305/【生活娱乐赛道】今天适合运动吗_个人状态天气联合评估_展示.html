技术原理
天气 API + 身体状态问卷 + AI 多维评估模型，三步科学决策
01

数据采集层

实时获取地理位置天气数据（温度、湿度、AQI、风速、紫外线指数），同时通过身体状态问卷采集用户的主观指标（睡眠时长、疲劳度、心情、不适症状）。支持接入 Apple Health / 华为运动健康 / 小米手环等穿戴设备数据，自动同步心率、血氧、步数等客观数据。

天气 API问卷引擎穿戴设备健康数据同步
02

AI 评估引擎

多维加权评分模型：天气维度（温度舒适度 0-2.5、AQI 0-2.5、风速 0-2.5、紫外线 0-2.5、湿度 0-2.5）+ 身体维度（睡眠质量 0-2.5、疲劳度 0-2.5、心情 0-2.5、疾病风险 -3 至 2.5），两维度按 6:4 加权计算综合运动指数。内置症状交叉检测规则引擎。

加权评分交叉计算风险检测症状规则引擎
03

智能建议输出

根据综合评分匹配运动类型、运动强度和推荐时长。高分 → 户外中高强度；中分 → 低强度或室内运动；低分 → 休息 + 恢复方案。所有建议附带运动医学依据（引用 ACSM/AHA 指南），并支持一周趋势预测和历史对比功能。
