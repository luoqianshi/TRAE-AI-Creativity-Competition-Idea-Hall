The Solution · 产品方案

一座架在医生与患者之间的"翻译桥"

无声诊室是一款部署在医院诊室的 Web 双屏应用:医生端语音问诊实时转译为患者能"看懂"的图文手语;患者端通过可视化身体选择器描述症状,转译为医生能"听懂"的结构化语音报告。

医生端 · Doctor Side

语音 → 视觉

  • 🎤 医生正常语音问诊
  • 📝 实时转写为大字文字
  • 🔑 关键词高亮 + 图标化
  • 🙌 简化手语示意动画
🌉
AI 沟通桥
患者端 · Patient Side

视觉 → 语音

  • 👤 点击身体部位图定位
  • 🌡 选择症状与严重程度
  • 📋 生成结构化症状报告
  • 🔊 语音播报给医生
🗣️

医生问诊实时转译

医生正常说话,Web Speech API 实时识别,关键词自动提取并用大字 + 图标 + 手势动画呈现给患者,听障者"看"得懂问诊。

🧍

可视化症状描述器

患者无需打字,点击人体部位图、选择症状图标和疼痛等级,AI 自动生成结构化症状描述并语音播报给医生。

⚡

就医常用语快捷板

预置"哪里疼 / 多久了 / 药物过敏 / 既往病史"等高频问诊话术,一键双向发送,缓解紧张、提速问诊。

🛡️

沟通记录与导出

本次就诊的医患沟通要点自动整理,患者可导出留存,复诊时不再"从零讲起",医生也可追溯问诊过程。

🚨

紧急情况识别

当患者症状提示胸痛、呼吸困难、剧烈腹痛等急症信号时,系统高亮预警,提示医生优先处置。

♿

无障碍设计

大字号、高对比、图标先行、振动反馈、慢速模式,贴合不同听障程度和老年患者的视觉习惯。
