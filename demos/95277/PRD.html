产品概述

「记忆之森」是一款私密语音日记应用，通过树洞语音记录、AI智能整理、记忆树可视化成长等核心功能， 为用户打造安静、治愈、私密的个人记录空间。用户只需对着树洞说出心声，即可收获一片属于自己的回忆森林。

💎

核心价值

降低记录门槛，用语音捕捉真实情绪，用视觉化的记忆树见证成长

👥

目标用户

喜欢记录生活、注重隐私、追求治愈感的年轻人群

🌙

产品定位

私密 · 治愈 · 沉浸式的语音日记工具

核心流程

3.1 主流程：语音记录到生成日记

用户打开应用 → 点击树洞开始录音 → 水波纹随音量波动 → 语音实时转文字 → 说完后点击停止 → AI自动整理日记（拟标题、加标点、分段、生成标签） → 生成记忆树新叶片 → 日记保存到本地

🔊 回声体验流程

  • → 用户打开日记 → 长按/选中文本
  • → 绑定语音片段 → 保存后文本高亮
  • → 点击高亮文本 → 播放对应语音

🍃 记忆树探索流程

  • → 用户进入记忆树页 → 观察榕树形态
  • → 点击随机叶片 → 打开对应旧日记
  • → 重温回忆 → 返回继续探索

性能要求

  • • 页面加载时间 < 3秒
  • • 语音转文字延迟 < 1秒

  • • 默认本地存储，不上传云端
  • • 音频数据仅临时缓存

可用性

  • • 移动端优先优化

数据模型

6.1 日记 (Diary)

{
  id: string;           // 唯一标识
  title: string;        // 标题(AI生成或手动编辑)
  content: string;      // 正文内容
  tags: Tag[];          // 标签列表
  createdAt: number;    // 创建时间戳
  updatedAt: number;    // 更新时间戳
  audioBlob?: string;   // 语音Blob URL(临时)
  echoes: Echo[];       // 回声绑定列表
  template: string;     // 手账模板类型
}

6.2 标签 (Tag)

{
  id: string;           // 唯一标识
  name: string;         // 标签名称
  color: string;        // 标签颜色
}

6.3 回声 (Echo)

{
  id: string;           // 唯一标识
  text: string;         // 绑定的文本内容
  start: number;        // 语音起始时间(ms)
  end: number;          // 语音结束时间(ms)
}

6.4 用户设置 (Settings)

{
  nickname: string;     // 昵称
  avatar: string;       // 头像URL
  bgMusicVolume: number;// 背景音乐音量(0-1)
  speechEngine: string; // 语音引擎('vosk'|'iflytek'|'sensevoice')
  autoOrganize: boolean;// 是否自动AI整理
}
