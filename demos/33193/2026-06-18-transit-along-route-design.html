产品概念设计

沿线路径换乘方案

"你在线上，目的地在你的沿途" — 基于沿线路径的最优换乘推荐

📅 2026-06-18 🎯 产品概念展示型 HTML 👥 普通通勤市民 + 游客/外地人

1. 产品概述

传统地图App的路线规划方式：用户输入 A点 → B点，系统给出方案。

本产品的核心创新：用户说 "我在 XX 路线上，在 YY 站到 ZZ 站之间"，系统分析沿途每一站到目的地的最优方案，从而找到最省时省力的换乘方式。

覆盖交通方式：地铁 公交 步行

目标用户：普通通勤市民（日常灵活选择上车位置） + 游客/外地人（利用已知线路探索未知目的地）

2. 核心差异化优势

"沿线路径"维度出发

传统方式要求用户知道精确的起点和终点。但现实场景中，用户常常只知道 "我在 2 号线上，江苏路到南京东路这一段"，并不确定具体从哪一站上车最方便。

本产品给出：沿途每一站 → 目的地 的多组换乘方案，让用户选择自己最方便的上车站点。

  • 场景示例：我在上海地铁 2 号线上（江苏路→南京东路段），想去外滩
  • 结果：分析每站的换乘方案，推荐最优（如南京东路站步行 200m 即达）

3. 页面架构与叙事流程

采用滚动驱动叙事的单页结构，从上到下 6 个章节：

章节内容目的
① Hero 区 全屏大标题 + 动态线路图背景，核心文案"你在线上，目的地在线下" 秒懂产品定位
② 传统痛点 模拟地图App换乘页面的繁琐体验 建立共鸣
③ 解决思路 可视化"沿线路径"思维——输入所在线路→沿途各站到目的地最优解 讲透核心创新
④ 运作演示 以上海 2 号线为例，动态展示查询→匹配→推荐的过程 让概念可感知
⑤ 场景对比 与传统地图 App 的换乘模式对比 建立说服力
⑥ 价值主张 核心卖点总结 + CTA 收尾转化

交互机制：滚动触发动画、视差滚动、SVG 线路图脉冲动画

4. 视觉风格与配色方案

风格：现代、精致、深色模式优先（Apple 产品页风格）

字体：无衬线体系，标题粗重大字号，正文清晰可读

动效：平滑滚动触发动画、SVG 线路脉冲、渐变过渡

配色方案

#0a0e1a 深色背景
#3b82f6 主色
#06b6d4 辅色
#f59e0b 强调色
#e2e8f0 文字

关键视觉元素

  • 动态线路图：SVG + CSS animation 绘制发光线路，车站节点脉冲光效
  • 换乘路径卡片：横向时间轴卡片展示，站与站之间线条连接
  • 对比滑块：左右拖动展示传统方式 vs 本产品

5. Demo 场景与数据内容

场景设定（上海）

起点：上海地铁 2 号线，从江苏路到南京东路这一段之间

目的地：外滩

沿线各站最优方案

出发站推荐方案换乘方式预估时间
江苏路2号线→人民广场换乘1号线→步行600m地铁+步行~18min
静安寺2号线→南京东路站→步行800m地铁+步行~12min
南京西路2号线→南京东路站→步行800m地铁+步行~10min
人民广场步行出站→穿过人民广场步行直达~8min
⭐最优 南京东路出站步行200m→外滩步行最优~3min

呈现方式

  • 横向卡片组展示同一路线上不同站点的换乘方案差异
  • 最优方案高亮标出
  • 每个卡片含：线路名称、换乘点、步行距离、总耗时
  • 线路图上同步高亮对应车站节点

6. 技术实现

  • 技术栈：纯 HTML + CSS + JavaScript（无需外部依赖）
  • CSS：CSS Variables、Flexbox/Grid、CSS Animations、Intersection Observer API
  • SVG：内联 SVG 绘制地铁线路拓扑图，CSS 驱动脉冲动画
  • 滚动：Intersection Observer 触发各章节入场动画
  • 文件：单 HTML 文件，自包含所有样式和脚本
