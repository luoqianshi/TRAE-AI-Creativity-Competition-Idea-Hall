# 暖邻帮 - AI驱动的社区互助养老平台

## 项目概述
暖邻帮是一款基于AI技术驱动的社区互助养老平台，通过智能匹配算法将社区志愿者与需要帮助的老人精准对接。

## 目标用户
1. **老年用户端** - 大字版极简界面，语音输入为主
2. **志愿者端** - 任务接单、积分查看、信用评价
3. **管理端** - 居委会/物业审核、数据看板、社区公告

## 核心功能
- AI智能派单匹配引擎
- 邻里信用积分体系
- 紧急情况一键呼叫
- 社区公告与活动组织
- 任务全流程管理

## 技术栈
- HTML5 + CSS3 + JavaScript (原生)
- LocalStorage 本地数据持久化
- 响应式设计，支持移动端

## 页面结构
```
/
├── index.html          # 入口/首页
├── css/
│   └── style.css       # 统一样式
├── js/
│   ├── app.js          # 主应用逻辑
│   ├── ai-matching.js  # AI匹配引擎
│   └── data.js         # 模拟数据
└── README.md
```

## 设计理念
- 温暖友好的视觉风格（橙色/暖色调为主）
- 极简交互，降低老年人使用门槛
- 清晰的信用积分可视化
- 紧急呼叫功能突出显示
