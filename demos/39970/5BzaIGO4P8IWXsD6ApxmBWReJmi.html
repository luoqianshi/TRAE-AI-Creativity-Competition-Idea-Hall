核心功能特性

全方位覆盖 AI 基础设施监控需求

🎮

GPU 硬件监控

实时追踪 NVIDIA GPU 的显存使用率、GPU 利用率、温度、功耗和风扇转速。支持多 GPU 并行监控，nvidia-smi 优先，CPU 后备方案。

⚡

系统资源监控

CPU 使用率、内存占用、磁盘 I/O、网络流量全维度监控。支持自定义阈值告警，实时数据刷新率可达 3 秒。

🔄

吞吐量统计

客户端级别和模型级别的请求追踪。统计请求数、Token 数、延迟分布、错误率，支持数据导出功能。

🐋

Ollama 实例管理

支持本地进程和 Docker 容器部署的 Ollama 实例管理。模型列表、拉取、删除、加载、卸载全生命周期管理。

📦

多类型实例管理

支持本地进程、Docker 容器、Windows 服务等多种实例类型的 CRUD 操作。SSH 远程管理和命令执行。

📁

文件管理系统

完整的文件浏览、上传、下载、删除、重命名功能。支持路径导航、文件预览、拖放上传，内置路径安全检查。

🧠

Unsloth Studio 集成

与 Unsloth Studio API 深度集成，实时同步模型加载状态、MTP 多卡并行状态，支持模型推理请求。

🔐

安全认证系统

JWT 令牌认证、用户注册登录、密码加密存储、SMTP 邮件验证。支持多用户权限管理和会话控制。

API 使用示例

简洁优雅的 RESTful API 设计

📊 获取系统指标

curl -X GET http://localhost:9876/api/system/metrics \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

# 响应示例
{
  "cpu_percent": 45.2,
  "memory": {
    "total": 32768,
    "used": 18432,
    "percent": 56.3
  },
  "gpu": {
    "memory_total": 24576,
    "memory_used": 8192,
    "memory_percent": 33.3,
    "gpu_percent": 67.5,
    "temperature": 72
  },
  "timestamp": "2026-06-22T10:30:00Z"
}

🤖 模型推理请求

curl -X POST http://localhost:9876/api/chat \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama-3.1-8b",
    "messages": [
      {"role": "user", "content": "解释量子计算的基本原理"}
    ],
    "stream": false
  }'

# 响应示例
{
  "model": "llama-3.1-8b",
  "response": "量子计算是一种利用量子力学现象进行计算的技术...",
  "usage": {
    "prompt_tokens": 15,
    "completion_tokens": 128,
    "total_tokens": 143
  },
  "latency_ms": 1250
}

🐋 Ollama 模型管理

# 拉取模型
curl -X POST http://localhost:9876/api/ollama/pull \
  -H "Content-Type: application/json" \
  -d '{"model": "llama-3.1-8b"}'

# 删除模型
curl -X DELETE "http://localhost:9876/api/ollama/models/llama-3.1-8b"

# 查看模型列表
curl -X GET http://localhost:9876/api/ollama/models
