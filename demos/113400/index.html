为什么是 HomeNest

克制，但足够好用

不为炫技而生。它把"家庭小工具"重新想象成一块可以自由拼贴的画布，每一个能力都干净利落地独立存在。

卡片化画布

实时持久化

每次变更 PUT 后端 + localStorage 兜底，刷新、重启都不会丢配置。

毛玻璃导航

backdrop-filter 毛玻璃底栏，长按底部徽章 500ms 设置小红点。

卡片级登录守卫

单文件部署

挑你顺手的

无论双击二进制、从源码构建，还是丢进 Docker，启动后访问 http://localhost:8082 即可。

01 / 下载预编译

二进制直跑

按平台下载对应二进制（Win / macOS Intel / Apple Silicon / Linux），双击或加权限运行，无需任何依赖。

# macOS Apple Silicon
chmod +x HomeNest-arm64
./HomeNest-arm64
02 / 源码构建

从源码编译

克隆仓库，拉取依赖后一条命令构建。修改 embed/ui 下的前端后需重新 go build 打包。

go mod tidy
go build -o HomeNest .
# 自定义端口
./HomeNest -port 8082
03 / Docker

容器部署

多阶段构建 + named volume 持久化数据，后台运行，生产环境推荐此方式。

docker compose up -d --build
docker compose logs -f
# 停止
docker compose down
