核心功能模块

一站式解决旅行规划的全部痛点，让您的行程安排更智能、更高效

目的地 & 偏好录入

  • 城市、天数、预算区间输入
  • 偏好标签：自然风光/古迹人文/美食探店
  • 自然语言解析："厦门3天2晚，想吃海鲜"

智能 POI 搜索 + 筛选

  • 调用高德/腾讯地图 POI API
  • 返回：名称、坐标、封面图、评分、标签
  • 筛选：类型/评分/门票/距离

行程日历 + 地理聚类

  • K-means 聚类自动分配每日行程
  • Day 1~Day N 卡片视图，含停留时长
  • 拖拽调整顺序，自动重算交通

地图可视化标点 + 路线

  • 不同颜色 Pin 标记景点/美食/酒店
  • 按天切换，彩色折线连路线
  • 导出 KML/GPX 或跳转导航

美食 & 特色店推荐

  • 基于景点聚类中心搜周边餐厅
  • 展示：招牌菜、人均、步行时间
  • 直接 Pin 到行程 + 地图标点

交通 & 住宿参考

  • 城际交通：高铁/飞机班次查询
  • 市内交通：公交/地铁/打车预估
  • 住宿推荐：近核心景点 + 预算区间
创意名称 + 创意介绍

智游 · 行程规划助手

想解决什么问题

解决旅游前"跨平台搜攻略—人工筛选景点—手动标点地图—分散查交通酒店"的低效痛点，把碎片化的规划流程一站式整合。

为什么会想到做这个

每次旅行前，我都要在小红书翻大量笔记找路线，再逐个搜索景点照片判断是否感兴趣，接着在地图上手动标点、安排每日行程，还要分开查高铁票、机票和酒店价格，过程繁琐且极易遗漏关键信息，于是萌生了做一个"懂我偏好、自动排线"的工具的想法。

大概是什么产品

一款 Web 端 + 移动端的智能行程规划系统，基于地图 SDK 与 POI 数据，支持 AI 推荐、可视化排程与导出分享。

目标用户及痛点

谁是我们的用户

面向哪些用户

自由行游客、周末短途出行人群、大学生背包客以及有轻度定制需求的家庭用户。

在什么场景下使用

在出发前 1–2 周制定旅行计划时，或临时决定短途出行、需要快速生成可行路线时使用。

当前痛点

用户需在多个平台间反复切换，手动记录景点位置、比对交通时间与住宿价格，既费时又容易因为信息割裂导致路线绕路、错过性价比高的车票与酒店，整体决策成本高、体验差。

价值与意义

创造什么价值

效率提升

  • 通过 POI 聚合检索、地理聚类算法自动分配每日行程，将原本数小时的规划工作压缩至十几分钟

  • 地图可视化与一键导出功能，显著降低用户对第三方工具（文档、备忘录、截图）的依赖

商业价值

  • 可作为 OTA（在线旅行社）平台的流量入口，通过景点门票、酒店预订、当地玩乐产品的嵌入实现转化

  • 沉淀的用户偏好与行程数据，可为个性化推荐与精准营销提供高价值基础
