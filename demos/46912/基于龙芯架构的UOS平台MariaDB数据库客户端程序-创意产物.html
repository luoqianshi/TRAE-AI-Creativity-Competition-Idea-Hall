PART 01 创意名称 & 创意介绍
💡 想解决什么问题
在统信 UOS 龙芯（loongarch64）国产化平台上，长期缺乏原生的 MariaDB/MySQL 图形化客户端工具，数据库管理员只能依赖命令行操作，效率低、门槛高；且旧版本第三方库（pandas、openpyxl 等）兼容性差，导致数据导入导出频频报错。
🎯 为什么会想到做这个
在国产 CPU 和操作系统生态建设过程中，数据库是核心基础设施之一。但市面上主流工具（如 Navicat、MySQL Workbench）均未适配龙芯架构，亟需一款专为国产化平台量身打造的轻量级、离线可用、功能完善的数据库管理工具。
🏗️ 大概是什么产品
一款基于 Python 3 + PyQt5 开发的桌面系统级应用程序（约 4300 行单文件），提供数据库连接管理、可视化 SQL 编辑器、数据导入导出、表结构浏览等全栈功能，支持国产化运行环境与离线场景。

PART 02 目标用户 & 核心痛点
🎯 面向哪些用户
统信 UOS 龙芯平台的数据库管理员、软件开发人员、系统运维工程师，以及使用国产 CPU 架构（龙芯、鲲鹏、飞腾等）的政府/企事业单位 IT 团队。
📍 在什么场景下使用
① 日常数据库连接与多库切换管理；② 复杂 SQL 查询编写、调试与执行；③ 批量业务数据（CSV/Excel）的导入与导出；④ 表结构、索引、字段注释的查看与分析。
⚠️ 当前痛点（没有这套系统的不便）
❌ 无原生图形化客户端：命令行操作繁琐易错，数据库管理门槛极高，新手难以快速上手。
❌ 跨平台工具兼容性差：Navicat、MySQL Workbench 等工具在龙芯架构上无法运行或频繁崩溃。
❌ 第三方库版本不匹配：国产系统 pip 源中的 pandas、openpyxl 等库版本陈旧，与最新 MySQL 驱动不兼容。
❌ 中文与多字节字符处理缺陷：SQL 解析时中文分号、Unicode 段落分隔符处理不当，导致脚本执行异常。
❌ 离线场景无法使用：现有工具依赖在线激活或云端服务，纯内网环境无法部署。

PART 04 系统架构 & 核心模型
🏛️ 软件分层架构
界面层（View）— QMainWindow + QSplitter + QTabWidget
⬇
业务层（Service）— 连接管理 / SQL 解析 / 导入导出调度
⬇
数据层（DAO）— pymysql 封装，屏蔽数据库细节
⬇
线程层（Worker）— QThread 异步执行，界面不卡顿
📊 核心功能模块
① 连接管理 — 多套连接配置持久化（JSON），Fernet 加密存储密码，支持连接/断开/刷新/库切换
② 数据库浏览器 — 树形结构展示库/表/列/索引，双击表自动生成 SELECT * LIMIT 100
③ SQL 编辑器 — 语法高亮、3 位行号自适应、Ctrl+Enter 执行、选中执行、智能注释剥离
④ 数据查看器 — 分页表格、自定义 LIMIT/WHERE、字段排序
⑤ 表结构查看器 — 字段名、类型、是否为空、键、默认值、注释（COMMENT）、索引信息
⑥ 导入数据 — CSV/TXT/XLS/XLSX 自动识别分隔符、首行标题映射、预览前 10 行、后台线程批量插入
⑦ 导出数据 — 查询结果或全表导出为 CSV/TXT/XLS/XLSX，支持 UTF-8 BOM 便于 Excel 打开中文
⑧ 辅助功能 — 自动 USE 库、DDL 自动创建缺失库、文件菜单（新建/打开/保存 SQL）、右键复制表名/列名
🚀 部署方式
项目提供 一键安装脚本（install.sh）（自动使用清华镜像源安装 PyQt5、PyMySQL、pandas、openpyxl、xlrd、cryptography 等依赖）、启动脚本（run.sh）（依赖检查 + 启动入口），以及 Linux 桌面快捷方式（.desktop）。运维人员零经验也能快速上线，真正做到 "上传即解压，一键即安装，双击即运行"。
