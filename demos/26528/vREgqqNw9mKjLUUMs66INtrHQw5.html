创意介绍与产品形态

一套软硬一体化的智能仓储解决方案

🎯 一句话概述

域感智能是一套基于 无人机自动巡航 与 RFID 射频识别 的仓库智能巡检一体化系统，通过无人机挂载 RFID 读写器对高货架货物进行自动化扫描，实时上传库存数据到后端系统，实现无人化盘点、异常预警与可视化管理。

🏗️ 系统架构（四大子系统 + API 网关）

🚁

无人机数据系统

负责无人机管理、GPS 定位、视频流推送、图像采集、飞行参数记录（8000 端口）。

📦

仓库巡检系统

货架与 SKU 管理、巡检任务派发、库存实时快照、入库流水记录（8001 端口）。

🔗

API 网关

核心工作流程

从起飞到入库的自动化闭环

1

任务下发

管理员在 Web 面板创建巡检任务，指定货架区域、巡检时间和无人机编号。

2

无人机起飞巡航

无人机按预设航点自动飞行，挂载 RFID 读写器对货架上的电子标签进行连续扫描。

3

RFID 实时采集

PRE 系列 UHF 模块以 900MHz 频段远距离读取 EPC 码，RSSI 信号强度辅助定位。

4

数据上传与解析

数据经网关路由转发至仓库巡检系统，通过 EPC → 商品映射表自动匹配 SKU。

5

库存更新与异常告警

事务更新 Inventory 库存快照，写入 InboundRecord 入库流水，数量异常自动触发告警。

6

可视化展示

前端通过 WebSocket 实时接收巡检状态，面板展示库存热力图、历史趋势与异常清单。
