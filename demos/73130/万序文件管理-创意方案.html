01

整理，与工作流冲突

打标签、写说明、归对文件夹——这些动作每次都要打断当前的工作节奏。没有人坚持得下来，不是意志力问题，是反人性。

「所以，必须自动化。」

02

搜索，只认文件名

系统搜索只能匹配文件名，而人脑记住的是"内容大概是什么"。两者对不上，于是关键词来回试，文件夹一层层翻。

「记的是意思，找的却是字符串。」

03

版本，混在一片里

同一份材料五六个版本，分不清哪个是最新、差异在哪。误用旧版文件，不是尴尬，是真实的工作事故来源。

「'终版2' 永远不是终版。」

— 02 / 解法
THE SOLUTION

让秩序，在文件落地的瞬间就位。

一个 Windows 本地后台工具。文件保存进工作目录的瞬间，自动按你的标签库打标、生成一句话摘要和版本定位说明， 写入 Windows 原生文件属性（不绑架数据）和本地索引库。配一个热键唤起的极简搜索小窗， AI 理解你的意图，秒级定位文件。全程零打扰，本地优先。

为长期产出大量办公文件的

企业职能岗

Training / Report / Proposal

培训、方案、汇报的高产人群。每周产出多份文档，版本迭代频繁，是"终版2"现象的重灾区。

咨询顾问

Consultant

Product Manager

PRD、评审、原型、复盘——同一件事从不同角度产出多份材料，需要快速回溯决策脉络。

— 05 / 价值
VALUE & MEANING

把「翻找」，
变成一句话直达。

效率提升是表层，更深的价值在于：它在个人知识管理（PKM）与企业知识管理（KM）之间，填补了一块长期空白的中间地带。

— 效率价值

从源头消灭
"重做已有材料"的浪费

知识工作者平均每天花可观时间在找文件上。万序把"翻找"变成"一句话直达"，找回的不只是时间，更是注意力本身——不再被中断、不再被挫败感侵蚀。

版本定位能力直接降低误用旧版文件的工作风险。一次"误用终版2"的汇报事故，成本远高于这个工具本身。

0.3s 从一句话输入到文件命中——
比翻文件夹快两个数量级

DESIGN PRINCIPLES

四条不可妥协的底线。

— 原则 01
零打扰
整理动作全程静默，不弹窗、不询问、不要求确认。用户感觉不到它的存在，直到主动唤起。
SILENT BY DEFAULT
— 原则 02
本地优先
索引、摘要、标签全部存本地。可离线工作，可断网使用。云端是可选项，不是必需项。
LOCAL FIRST
— 原则 03
不绑架数据
所有元数据写入 Windows 原生文件属性。即使卸载万序，文件依然带着标签和摘要——秩序属于文件本身。
NO VENDOR LOCK-IN
— 原则 04
叠加，而非替代
不要求你迁移到新生态，不改变你的文件夹结构。万序叠加在你现有的工作流之上，让原生文件系统变聪明。
AUGMENT, NOT REPLACE
万序。
— 项目概述

万序 Wànxù 是一个 Windows 本地后台工具，文件保存即自动打标、生成摘要与版本定位，热键唤起自然语言检索。全程零打扰，本地优先，数据永远属于用户。
