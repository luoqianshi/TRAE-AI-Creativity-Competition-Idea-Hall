核心创新点

可解释AI推荐
多因子评分模型，每个推荐都有4因子分解和文字解释，不是黑盒推荐。

Score = 0.4×兴趣 + 0.3×距离 + 0.2×时间 + 0.1×活跃度
公益信用体系
4级等级体系（新手→成长→资深→贡献者），成长系数机制，信用分可用于综测加分、招聘背书。
动态调度系统
紧急任务优先推送，基于地理位置和信用分智能调度，类似"公益版滴滴调度系统"。
GIS可视化
活动热力图、公益活跃区域、个人贡献轨迹，支持地图找活动和区域数据分析。

AI服务：Python + Flask + FastAPI

系统架构

微服务架构
  • 网关服务 (port: 8080) - 路由转发 + JWT认证 + 限流
  • 用户服务 (port: 8081) - 用户管理 + 认证 + 个人资料
  • 活动服务 (port: 8082) - 活动CRUD + 搜索
  • 报名服务 (port: 8083) - 报名流程 + 签到签退
  • 推荐服务 (port: 8084) - 推荐算法 + 可解释输出
  • 信用服务 (port: 8085) - 信用分计算 + 积分流水
  • 通知服务 (port: 8086) - WebSocket推送 + 短信/邮件
  • 组织服务 (port: 8087) - 组织管理 + 统计分析
  • 区块链服务 (port: 8088) - 志愿记录存证
前端模块
  • 用户端H5 (Vue3 + Vant)
  • 组织端PC (Vue3 + Element Plus)
  • 管理后台 (Vue3 + Element Plus)
  • 可视化大屏 (ECharts + DataV)
数据存储
  • MySQL 8.0 - 主数据库（18张表）
  • Redis 7 - 缓存 + 会话 + 推荐缓存
  • Elasticsearch 8 - 全文搜索
  • RabbitMQ - 消息队列 + 异步任务
AI服务
  • 推荐引擎 - 多因子评分 + Haversine距离
  • 信用评估 - 信用分计算 + 等级判定
  • 智能问答 - NLP对话助手
