Solution

解决方案

  • react.py — ReAct 决策闭环

    观察飞控反馈，分析传感器数据，推理最优指令，行动执行 CLI 命令。全自动调参循环，实时响应飞行状态变化。

  • blackbox_react.py — 黑匣子智能解析

    读取 MSP/SD 卡原始日志，多轮 AI 分析将陀螺仪噪声转化为调参建议，生成 HTML 教育报告与飞手个性画像。

  • memory.py — Mem0 双层记忆

    短期对话记忆（最近 6 条交互）+ 长期语义向量索引，自然语言搜索历史 PID 配置与滤波参数，数据永不丢失。
