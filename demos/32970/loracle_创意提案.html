loracle

一款面向 AI 角色创作者的智能数据清洗工具 —— 从海量文本中精准提取人物语料， 一键生成 LoRA 微调数据集，让每个角色都拥有栩栩如生的 AI 灵魂。

创意背景与用户痛点

为什么需要 loracle？当前 AI 角色创作面临的核心困境。

🧩

数据收集难

创作者手中有大量小说、剧本、对话录等文本素材，但人物相关内容散落在数万行文字中，人工筛选耗时巨大，动辄数天甚至数周。

🧹

清洗门槛高

原始文本充满噪音：旁白叙述、无关角色对话、格式乱码……清洗需要编程能力，大多数创作者被技术门槛挡在门外。

📊

格式不统一

不同训练平台（OpenAI / ShareGPT / SillyTavern）要求不同数据格式，手动转换极易出错，缺乏一站式解决方案。

🔄

迭代效率低

数据集制作→训练→效果不佳→返工修改，循环中缺乏版本管理和去重能力，创作者在重复劳动中消耗热情。

核心理念：人机协作，而非全自动

loracle 不追求"一键全自动"，而是把机械重复的工作交给算法（切块/去重/编码检测）， 把需要判断力的工作留给人（审阅/编辑/最终选择），并让 LLM 在二者之间提供智能辅助。 这种设计哲学确保了数据集的质量上限由人的审美决定，而非算法。

核心功能亮点

每一项设计都直击 LoRA 数据集制作的真实痛点。

🔤

六级关键词体系

主名 → 别名 → 代称 → 相关词 → 排除词 → 正则。最长非重叠匹配，多级过滤精准定位人物相关内容，误召回率极低。

✂️

三种灵活切块规则

句子级（含上下文窗口）、段落级、窗口合并级，适配不同文本类型与训练需求。支持重切块并保留版本 lineage。

🔍

SimHash 近似去重

64-bit SimHash + 8 bands bucket 索引，Hamming distance ≤3，O(n) 复杂度。在保留语义相似度感知的同时高效剔除重复内容。

🤖

9 种内置 LLM Prompt

相关性判定、信息提取、去噪、性格模板分析（含 MBTI/ACGN 原型/深层心理 JSON Schema）、人格提示词、角色卡、SillyTavern 格式等。

📦

多格式导出 + 严格校验

原始 JSON / OpenAI JSONL / ShareGPT+system JSON，内置严格格式校验（role 检查、长度阈值、结构完整性），杜绝"训练时报错"。

🔐

API Key 安全存储

基于 Windows DPAPI 加密存储，不落地明文，不写入 project.json，确保 LLM 凭据安全。

技术架构

桌面端 GUI 应用，离线可用，数据完全本地化。

Python 3.11+ PySide6 (Qt 6) Pydantic v2 SQLite (WAL) httpx AsyncClient tiktoken charset-normalizer SimHash 64-bit opencc Windows DPAPI pytest + ruff + mypy

GUI 层

三栏 QSplitter 布局：左栏工作流导航 + 中栏 Chunk 卡片列表（搜索/筛选/快捷键审阅）+ 右栏源文定位高亮。QThread 后台导入，UI 不卡顿。

数据层

11 张 SQLite 表的 Repository 模式，WAL + 5s busy_timeout，游标分页，additive migration。project.json 原子写入防损坏。

LLM 层

httpx 异步客户端 + 指数退避重试。asyncio.Semaphore 并发控制（默认 max_concurrent=2），支持暂停/继续/取消，版本 stale 检测。

目标用户与使用场景

loracle 为谁而做？

🎭

AI 角色扮演创作者

为 SillyTavern / Character.AI 等平台的角色制作 LoRA 数据集，从小说/剧本中提取角色语料，赋予 AI 角色一致的人格与口吻。

✍️

网文作者 / 同人创作者

将自己笔下的原创角色或同人角色转化为可交互的 AI 角色，拓展创作边界，让读者能与角色"对话"。

🏢

AI 创业团队

快速构建垂直领域的角色型 AI 助手（虚拟客服、IP 角色、数字人），以标准化流水线替代手工数据清洗，降低人力成本。

🎓

NLP / LoRA 学习者

开源工具 + 完整测试覆盖（15 个测试文件），可作为学习 LoRA 数据工程和 PySide6 GUI 开发的参考项目。

创新点与差异化优势

相比现有方案，loracle 的独特价值在哪里？

人机协作审阅流

市面上多数工具是"全自动黑箱"，产出质量不可控。loracle 设计了完整的三栏审阅界面 + 快捷键操作，让人的判断力贯穿全流程。

六级关键词 + 正则

常见方案仅支持单一关键词匹配，loracle 的多级关键词体系可精确区分"主角说话"和"别人提到主角"，大幅降低误召回。

完整 LLM Prompt 生态

不仅是数据清洗工具，更内置了角色画像分析（MBTI / ACGN 原型 / 深层心理）、角色卡生成、人格提示词等全链路 Prompt 模板。

桌面端离线优先

无需云端服务，数据完全本地化。API Key 通过 DPAPI 加密存储，隐私安全可控。即使断网也能完成清洗和审阅。
