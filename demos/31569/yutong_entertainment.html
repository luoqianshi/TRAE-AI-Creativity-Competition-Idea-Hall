01 · CORE PLAY

为 温暖陪伴 而生的核心玩法

基于 Go 框架的可扩展聊天机器人，以下是语瞳作为陪伴型机器人的创意方向。玩法不固定，功能可自定义。

01
💬

闲聊陪聊

通过大模型对话实现自然流畅的日常对话。人设和语气可自由配置，让群里多一个可以聊天的伙伴。

02
🌞

情感化问候

通过定时任务 + LLM 插件实现。早晨问好、深夜提醒休息，语瞳的问候由你自己的模型与模板定义。

03
📅

每日一句

一个典型的 COMMAND 插件示例：定时推送一句温暖话语。框架提供定时任务和消息推送的基础设施。

04
🧊

冷群救星

框架内置群聊活跃度检测与沉默计时。可通过 HOOK 插件配置触发条件与响应策略，让群聊保持温度。

05
🎭

人设自定义

通过 YAML 配置定义语瞳的名字、性格、语气、角色背景。也支持完全自定义的人设 prompt，让每个群的语瞳独一无二。

06
🌸

节日与节气

HOOK 插件的典型应用：在特定日期/节气触发特定内容。框架提供日历识别与时间触发的基础设施。

02 · MEMORY & COMPANION

让她 记得你，而不是做个陌生人

语瞳的记忆系统是框架的核心能力。以下是记忆系统的六层架构设计 —— 框架层已就位，数据层随使用逐步增长。

L1 · 当下
💭

对话上下文

保留最近 N 轮对话的上下文窗口。N 可配置，让同一轮对话中的问答自然连贯。

L2 · 短期
📝

群友画像

为活跃成员建立可持久化的档案：昵称、常用称呼、话题偏好。数据结构已设计，写入随插件调用触发。

L3 · 长期
🎂

日期与事件型记忆：生日、纪念日、入群时间。框架提供日期匹配 + 定时提醒的基础设施，可按需扩展"每年生日祝福"等功能。

CHAR
🎭

人设与性格

语瞳的人设由 YAML 配置定义：名字、语气、风格、口癖。可随时替换，让不同群的语瞳有不同性格。

TIME
⏰

时段感知

框架向插件暴露当前时段（早晨/下午/晚上/深夜）信息。可据此调整问候风格，让回应更"刚刚好"。

SYNC
☁️

多群记忆隔离

每个群的数据按群 ID 独立隔离存储。同一语瞳实例可服务多个群，互不干扰。

05 · PLUGIN ECOSYSTEM

开发者可以 写新玩法

语瞳的框架设计了 5 种插件插槽，开发者可以通过编写小插件为语瞳添加新指令、新玩法、新工具。玩法不固定，创意由你定义。

⌨️
COMMAND 插件

命令扩展

通过 manifest 声明一个斜杠命令，框架自动处理参数、帮助信息和触发条件。想做一个"成语接龙"？一个 COMMAND 插件就可以搞定。

/weather · /translate · /music
🛠️
TOOL 插件

工具调用

向语瞳暴露函数能力，让框架可以在响应流程中决定是否调用工具。比如查天气、搜歌词、查询状态等能力，可通过 TOOL 插件添加。

web_search · code_eval · music_lookup
🪝
HOOK 插件

钩子注入

在语瞳的"思考-决策-回应"流程中插入自定义逻辑。比如对特定用户追加专属回应，或在每日一句后附加天气预报。

on_before_reply · on_after_response
📢
EVENT 插件

事件订阅

订阅定时任务、入群欢迎、退群提醒、自定义事件。想让语瞳每天固定时间推送内容？通过 HOOK 插件可以实现定时触发的逻辑。

cron:0 8 * * * · member_join
🌐
API 插件

接口扩展

向语瞳的服务注册 REST 接口，让第三方系统也能与群聊互动。想把自家服务的通知推送到群？一个 API 插件就能搞定。

POST /api/notify · GET /api/rank
🤖
LLM 插件

大模型代理

接入自定义大模型或自定义 Agent 工作流。支持多步推理、函数调用、知识库 RAG，让语瞳拥有你想要的专属能力。

custom_model · rag_kb · agent_workflow
