📁 微信默认文件路径 (Windows)

  • 📤 接收文件目录%USERPROFILE%\Documents\WeChat Files\\FileStorage\File
  • 🖼 图片目录%USERPROFILE%\Documents\WeChat Files\\FileStorage\Image
  • 🎬 视频目录%USERPROFILE%\Documents\WeChat Files\\FileStorage\Video
  • 🎵 语音消息%USERPROFILE%\Documents\WeChat Files\\FileStorage\MsgAttach
  • 💾 缓存目录%USERPROFILE%\Documents\WeChat Files\All Users\config\cache
    • 快速查看当前用户路径： echo %USERPROFILE%\Documents\WeChat Files

    💻 PowerShell 自动分类脚本

    将以下内容保存为 organize-wechat.ps1，放在微信 FileStorage 目录或你需要整理的文件夹中，然后右键运行。

    # ======================================== # 微信文件自动分类整理脚本 (Windows PowerShell) # 作者: AI Assistant | 使用方法: 右键 → 使用 PowerShell 运行 # ======================================== $sourceDir = ".\File" $destDir = ".\_Organized_" $logFile = ".\_organize_log_$(Get-Date -Format 'yyyyMMdd_HHmmss').txt" if (-not (Test-Path $sourceDir)) { Write-Host "❌ 源目录不存在: $sourceDir" -ForegroundColor Red exit } $categories = @{ "文档" = @(".doc",".docx",".pdf",".txt",".rtf",".xls",".xlsx",".ppt",".pptx",".csv",".md") "图片" = @(".jpg",".jpeg",".png",".gif",".bmp",".webp",".tiff",".svg") "视频" = @(".mp4",".mov",".avi",".mkv",".flv",".wmv",".rmvb") "音频" = @(".mp3",".wav",".flac",".aac",".ogg",".amr",".m4a") "压缩包" = @(".zip",".rar",".7z",".tar",".gz",".bz2") "安装包" = @(".exe",".msi",".apk",".dmg") "代码" = @(".html",".js",".css",".json",".py",".java",".c",".cpp",".ts",".vue") } function Get-Category($ext) { foreach ($cat in $categories.Keys) { if ($categories[$cat] -contains $ext) { return $cat } } return "其他" } New-Item -ItemType Directory -Path $destDir -Force | Out-Null $files = Get-ChildItem -Path $sourceDir -File -Recurse $count = 0 foreach ($file in $files) { $ext = $file.Extension.ToLower() $cat = Get-Category $ext $ym = $file.LastWriteTime.ToString("yyyy-MM") $size = if ($file.Length -gt 50MB) { "大文件" } else { "普通" } $targetDir = Join-Path $destDir "$cat\$ym\$size" New-Item -ItemType Directory -Path $targetDir -Force | Out-Null $destFile = Join-Path $targetDir $file.Name $i = 1 while (Test-Path $destFile) { $destFile = Join-Path $targetDir "$($file.BaseName)_$i$($file.Extension)" $i++ } Copy-Item -Path $file.FullName -Destination $destFile "[$((Get-Date).ToString('HH:mm:ss'))] $($file.Name) → $targetDir" | Out-File -Append -FilePath $logFile -Encoding UTF8 $count++ } Write-Host "✅ 整理完成！共处理 $count 个文件" -ForegroundColor Green Write-Host "📂 输出目录: $destDir" -ForegroundColor Cyan Write-Host "📝 日志文件: $logFile" -ForegroundColor Gray Start-Sleep -Seconds 5

    🛠 辅助工具与进阶操作

    🔍 查找大文件
    在 PowerShell 中执行：
    Get-ChildItem -Recurse -File | Sort-Object Length -Descending | Select-Object -First 20 Name, @{N='Size(MB)';E={[math]::Round($_.Length/1MB,2)}}
    🧹 清理重复文件
    按 MD5 比较，相同文件仅保留一份。推荐配合 Duplicate Cleaner 或 Total Commander 的同步功能使用。
    ⏰ 定时自动整理
    在"任务计划程序"中创建基本任务 → 每日凌晨执行 organize-wechat.ps1，实现无人值守自动归档。
    ☁️ 云盘同步
    _Organized_ 文件夹可加入 OneDrive / 百度网盘同步目录，重要文档自动云端备份。
    🖼 图片重命名
    按拍摄时间批量重命名：
    Get-ChildItem *.jpg | ForEach-Object { Rename-Item $_.FullName ("IMG_{0:yyyyMMdd_HHmmss}.jpg" -f $_.LastWriteTime) }
    📊 容量统计
    查看各分类占用空间：
    Get-ChildItem -Directory | ForEach-Object { "{0:N2} MB → {1}" -f ((Get-ChildItem $_.FullName -Recurse | Measure-Object -Property Length -Sum).Sum/1MB), $_.Name }
