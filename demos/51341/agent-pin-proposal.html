02 / 概念

它是给 AI 用的
桌面贴纸机。

Agent Pin 不是新的聊天工具，也不是复杂的项目管理软件。它更像一个给 AI 用的桌面贴纸机：AI 负责干活，Agent Pin 负责把结果、提醒、灵感和待办贴出来。

每张 Pin 像 PixPin 一样浮在桌面上，可以置顶、拖动、缩放、关闭。它不需要用户打开一堆窗口去找信息，而是让 AI 主动把重要信息递到桌面上。

重要的就贴出来，暂时不做的也可以先贴着。桌面不只是放文件和窗口的地方，也可以变成 AI 和我协作的地方。

03 / 工作流

AI 干完活，
一行命令贴到桌面。

任何 Agent 都可以通过 CLI 或本地 HTTP API 把内容推送成桌面 Pin。本地优先，只监听 127.0.0.1，不上云、不联网。

STEP 01
Agent 干活
Codex / TRAE / Claude Code / ChatGPT 完成一次任务
→
STEP 02
调用入口
agent-pin CLI
或 POST /api/pins
→
STEP 03
桌面出现 Pin
独立悬浮窗口
可拖动 / 缩放 / 置顶 / 关闭
# Codex 审查完 PR，把结论贴到桌面 agent-pin markdown --title "PR 审查结论" --text "发现 2 个问题，建议先修第一个。" # Claude Code 改完一半，留一张提醒 agent-pin status --title "明日待办" --level warning --text "记得补上 auth 测试。" # TRAE 生成效果图，直接贴图 agent-pin image --title "页面预览" --path ./preview.png # HTTP 直推，跨 Agent 通用 curl -X POST http://127.0.0.1:4317/api/pins -d '{"title":"灵感","blocks":[{"type":"markdown","content":"这个点以后可以做成产品。"}]}'

06 / 价值

桌面，变成
AI 和我协作的地方。

我一抬眼就能看到：哪些事完成了，哪些事还要做，哪些灵感值得以后继续。
效率提升
把"找结论"从分钟级降到秒级。Agent 输出的关键信息直接落桌，用户不用切换上下文、不用翻聊天记录。
协作新范式
Agent 生态正在扩张（Codex、Claude Code、Cursor、TRAE CLI），但 Agent 与桌面操作系统的衔接仍是空白。Agent Pin 提供一个轻量、本地优先、跨 Agent 通用的"最后一公里"交付层。
长期想象
像AI 时代的桌面贴纸板。不同 AI 小助手干完活以后，不是只在自己的窗口里说一句"完成了"，而是把真正重要的结果贴到我的桌面上。

AI 负责干活，
Agent Pin 负责贴出来。
