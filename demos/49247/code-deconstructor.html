my-todo-app React + Vite 单页应用

项目类型

这是一个基于 React 18 + Vite 5 的单页应用（SPA），实现了一个待办事项管理工具。项目采用组件化开发模式，使用 JSX 语法和 React Hooks 管理状态，通过 Vite 进行开发构建与热更新。

整体架构

项目采用 三层架构 设计：入口层（main.jsx）负责将 React 应用挂载到 DOM；组件层（App.jsx 及 components/）负责 UI 渲染与交互；工具层（utils/api.js）封装数据请求逻辑。各层职责清晰，互不耦合。

核心模块

UI组件 Header.jsx / Footer.jsx — 页面头部与底部组件，负责布局结构和静态内容展示。
状态管理 App.jsx — 根组件，通过 useState 和 useEffect 管理待办数据与加载状态。
数据通信 api.js — 封装 fetch 请求，统一管理 API 调用与错误处理。
构建配置 vite.config.js / package.json — 定义开发服务器端口、React 插件及项目依赖。

设计思路

项目遵循 关注点分离 原则：UI 渲染与数据获取解耦，组件只负责展示，数据请求集中在工具函数中。组件设计遵循 单一职责，每个文件只做一件事。入口文件极简，核心逻辑上提至 App 组件统一调度，使得项目结构清晰、易于维护和扩展。
