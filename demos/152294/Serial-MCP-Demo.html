Features
核心功能
提供完整的串口通信能力，覆盖嵌入式调试的各个环节。
工具功能模式
list_ports列出系统可用串口（含 VID:PID、序列号）-
open_port打开串口连接，完整参数配置直接模式
close_port关闭串口连接，释放资源直接模式
connect_bridge连接 TCP-Serial Bridge桥接模式
disconnect_bridge断开桥接连接桥接模式
send_data发送数据（文本 / HEX 格式）双模式
read_data读取接收缓冲区数据双模式
get_status获取连接状态和通信统计双模式
🔌

双工作模式

直接模式独占串口，桥接模式支持多程序共享。按需选择，灵活应对不同调试场景。

📡

HEX + 文本双格式

同时支持文本和十六进制数据收发，完美适配 Modbus RTU、自定义二进制协议。

🌐

Web 实时监控

通过 SSE 实时推送数据流到浏览器，无需安装任何软件，打开网页即可查看。

🔌

MCP 标准协议

基于 Model Context Protocol 开放标准，可被任何兼容 MCP 的 AI 工具调用。

🔄

透明数据转发

TCP-Serial Bridge 实现数据双向透明转发，AI 和串口助手看到完全相同的数据。

📊

通信统计

实时追踪收发字节数、连接时长、最近错误，调试过程全程可追溯。
