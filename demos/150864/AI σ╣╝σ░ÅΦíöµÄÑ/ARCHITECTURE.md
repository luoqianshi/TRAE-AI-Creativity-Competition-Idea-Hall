# 芽芽星 · AI 幼小衔接小程序 — 架构设计文档

> 版本 v1.0 · 2026-07 · 面向快速上线 + 用户增长的 MVP 架构

---

## 一、产品定位与目标

### 1.1 一句话定位
面向 **5-7 岁准小学生**的 AI 个性化幼小衔接成长平台，以"发现→完成→表达→反思"探究式学习闭环为核心，**家长付费决策、儿童实际使用、教师协同反馈**三方联动。

### 1.2 核心目标
| 维度 | 目标 | 衡量指标 |
|------|------|----------|
| 快速上线 | MVP 4 周可提审 | 主包 < 1.5MB，首屏 < 1.5s |
| 用户增长 | 社交裂变驱动获客 | 分享打开率 > 15%，7 日留存 > 25% |
| AI 价值 | 个性化学习路径 | 出题准确率 > 90%，周报打开率 > 60% |
| 商业转化 | 体验课→付费 | 体验转付费 > 12% |

### 1.3 四视角设计（源自现有设计稿）
- **儿童视角**：探究小岛 + 今日任务 + 心情打卡（沉浸式游戏化）
- **数据看板**：成长雷达 + 六维能力 + 同期群对比（可视化）
- **教师视角**：班级成长树 + 小组协作 + 教学反馈（管理工具）
- **家长视角**：成长家园 + 本周周报 + 快捷任务（轻量看护）

## 二、技术选型

### 2.1 整体方案：微信云开发（CloudBase）
**选型理由**：MVP 阶段最快路径，免服务器运维、免域名备案、天然鉴权。

| 能力 | 选型 | 说明 |
|------|------|------|
| 前端框架 | 原生小程序 + 自定义 tabBar | 不引入 Taro/uni-app，减少包体积与学习成本 |
| 后端 | 云函数 + 云数据库 + 云存储 | 免运维，自动扩缩容 |
| AI 能力 | 云函数代理调用大模型 API | 敏感 key 不落地客户端 |
| 组件库 | 自研轻量组件 + TDesign 按需引入 | 儿童向定制，非通用 UI |
| 状态管理 | MobX-miniprogram | 多角色全局状态共享 |
| 图表 | ec-canvas（ECharts 小程序版） | 成长雷达、同期群曲线 |
| 支付 | 微信支付（云函数统一下单） | v1.1 接入 |

### 2.2 基础库要求
- 最低基础库 **2.27.0**（支持自定义 tabBar 稳定版 + 按需注入）
- 开启「按需注入」`"lazyCodeLoading": "requiredComponents"` 降低启动耗时

## 四、分包策略详解

### 4.1 体积预算
| 包 | 预算 | 内容 |
|----|------|------|
| 主包 | ≤ 1.5MB | 首页/登录/家长简版 + 公共组件 + tabBar + 主题图 |
| 学习核心 | ≤ 2MB | 探究任务 + 语音 + 作品表达 |
| 成长看板 | ≤ 1MB | 雷达图 + 周报（图表库重，独立分包） |
| 教师中心 | ≤ 1.5MB | 班级管理 + 成长树 |
| 营销裂变 | ≤ 0.8MB | 落地页 + 海报生成 |
| **合计** | **≤ 7.8MB** | 远低于 20MB 上限 |

### 4.2 预加载规则（`preloadRule`）
```json
{
  "preloadRule": {
    "pages/index/index": {
      "network": "all",
      "packages": ["learning"]
    },
    "pages/parent/parent": {
      "network": "wifi",
      "packages": ["dashboard"]
    }
  }
}
```
- 首页加载即预取「学习核心」——儿童最高频路径零等待
- 家长页（通常 WiFi 环境）预取「成长看板」

### 4.3 独立分包（可选）
营销裂变分包可设 `"independent": true`，作为独立分包用于**分享落地页**——用户未登录也能秒开，提升拉新转化。

## 五、AI 集成方案

### 5.1 调用链路
```
小程序 → wx.cloud.callFunction('ai-generate') → 云函数
  → 组装 prompt + 注入儿童画像上下文
  → 调用大模型 API（DeepSeek/通义/智谱）
  → 结构化解析返回 → 写入学习记录 → 返回前端
```
**关键点**：API Key 只存云函数环境变量，绝不落地客户端；云函数做 prompt 模板管理与内容安全校验。

### 5.2 AI 能力清单
| 能力 | 云函数 | 输入 | 输出 | 触发时机 |
|------|--------|------|------|----------|
| 智能出题 | ai-generate | 年龄+能力维度+历史 | 题目+选项+解析 | 进入任务页 |
| 成长评估 | ai-generate | 学习记录集合 | 六维雷达分值 | 每完成 5 个任务 |
| 周报生成 | ai-weekly | 本周行为数据 | 自然语言总结 | 每周日晚自动 |
| 语音评测 | ai-generate | 录音文件 | 发音得分+纠音 | 语音跟读后 |
| 路径推荐 | ai-generate | 画像+薄弱点 | 下一步任务推荐 | 任务完成后 |

### 5.3 内容安全
- 大模型输出经 `msgSecCheck` 云函数二次校验（儿童内容零容忍）
- 题库预审机制：AI 生成题目进入「待审池」，人工抽检后转正

## 六、数据模型（云数据库集合）

### 6.1 核心集合
```
users          用户：openid、角色(parent/child/teacher)、昵称、头像
children       儿童档案：出生年月、年级、能力基线、兴趣标签
tasks          任务：类型、难度、AI生成标记、题目内容、答案
records        学习记录：childId、taskId、耗时、得分、作品URL
growth_radar   成长雷达：childId、六维分值、更新时间、AI评估ID
weekly_reports 周报：childId、周区间、AI总结文本、阅读状态
classes        班级：教师Id、学生列表、班级成长树数据
shares         分享记录：分享人、被分享人、渠道、转化状态
coupons        优惠券：用户、类型、有效期、状态
```

### 6.2 索引建议
- `records`：`childId + createdAt` 复合索引（周报查询高频）
- `growth_radar`：`childId` 唯一索引（upsert 场景）
- `shares`：`sharerId + createdAt`（裂变统计）

## 七、性能优化清单

| 优化项 | 措施 | 目标 |
|--------|------|------|
| 启动耗时 | 按需注入 + 主包瘦身 + 首屏骨架屏 | < 1.5s |
| setData | 合并调用 + 纯数据字段 + 路径更新 | 单次 < 256KB |
| 图片 | WebP + CDN + lazy-load + 尺寸裁剪 | 单图 < 50KB |
| 网络 | 请求缓存 + 预加载 + 失败重试 | 弱网可用 |
| 列表 | 虚拟列表（scroll-view type=list） | 千条流畅 |
| 雷达图 | ec-canvas 懒渲染 + 数据降采样 | 首帧 < 500ms |

## 八、快速上线 MVP 分期

### Phase 1 · MVP（第 1-4 周）— 提审上架
**只做家长 + 儿童学习核心**，砍掉教师端和支付。
- 主包：首页探究岛 + 登录 + 家长简版
- 学习分包：探究任务 + 作品表达 + 成长币
- AI：智能出题 + 成长评估
- 营销分包：分享落地页 + 体验课入口

### Phase 2 · 增长（第 5-8 周）— 留存与转化
- 成长看板分包：雷达图 + AI 周报 + 同期群
- 微信支付接入：体验课→月卡/季卡
- 订阅消息：周报推送 + 任务提醒
- 营销增强：拼团 + 优惠券

### Phase 3 · 生态（第 9-12 周）— B 端协同
- 教师中心分包：班级 + 小组 + 成长树
- 家校互通：教师布置任务 → 家长查看
- 数据看板进阶：LTV 同期群分析

## 九、增长与获客策略

### 9.1 社交裂变（核心引擎）
| 场景 | 机制 | 触发点 |
|------|------|--------|
| 成长作品分享 | onShareAppMessage 生成作品海报 | 完成作品后自动引导 |
| 周报分享 | 家长分享周报到群/朋友圈 | 每周日晚 |
| 拼团体验课 | 3 人成团享 7 天免费 | 体验课落地页 |
| 邀请有礼 | 邀请 1 人得成长币/优惠券 | 家长页常驻入口 |

### 9.2 订阅消息（留存利器）
关键触达节点（务必在用户最愿意授权时请求）：
- **下单/体验后**：立即请求「任务提醒」订阅（转化最高）
- **完成任务后**：请求「周报生成」订阅
- 模板：`任务提醒` / `周报生成完成` / `优惠活动`

### 9.3 流量入口
- 小程序码印入线下体验物料
- 公众号文章挂载小程序卡片（内容→工具转化）
- 视频号直播挂载（育儿干货 → 体验课）

## 十、审核合规要点

| 风险点 | 应对 |
|--------|------|
| 未成年人信息 | 隐私协议明示收集范围，家长授权后再采集儿童数据 |
| 教育类目 | 选择「教育-在线教育」类目，避免超纲教学承诺 |
| 用户头像昵称 | 用 wx.getUserProfile（已废弃需改 button open-type） |
| 内容安全 | UGC 作品（图片/语音）必须 imgSecCheck / msgSecCheck |
| 支付合规 | 虚拟商品需走 iOS 限制策略，会员类需明确权益 |
| 诱导分享 | 分享按钮文案避免"分享后解锁"等强制话术 |

## 十一、关键代码约定

### 11.1 请求层（`utils/request.js`）
统一封装 `wx.cloud.callFunction`，处理鉴权、重试、错误码、loading。

### 11.2 角色路由（`utils/auth.js`）
登录后按角色写入 `globalData.role`，自定义 tabBar 据此渲染不同标签页。

### 11.3 设计令牌（`theme/tokens.wxss`）
沿用设计稿色板（奶油/珊瑚/鼠尾草绿/天蓝），统一 `--yy-*` 变量命名。
