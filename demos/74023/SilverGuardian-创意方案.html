CREATIVE INTRODUCTION

创意名称与介绍

一个为长者而生的智能 Agent，温柔守护每一个独处的黄昏

「银发守护者」HarmonyOS 智能陪伴 Agent

这是一款基于 HarmonyOS Stage 模型开发的适老化智能应用。它不是冰冷的工具，而是具备感知-记忆-规划-行动完整认知能力的 Agent 系统，能够理解长者的诉求、记住他们的习惯、规划合适的服务，并在紧急时刻主动行动。

应用集成了端侧大模型语音交互、健康数据监测与一键紧急求助三大核心能力，并借助鸿蒙分布式特性与子女的手机、手表、家庭智慧屏无缝协同。

  • 🎙️
    离线语音优先 端侧轻量化模型，断网也能听懂指令
  • 🧠
    ReAct 思维链可解释 子女可查看长者与 Agent 的全部思考过程
  • 🚨
    主动呼救 检测到异常自动通知家人与社区

这大概是一款什么样的产品？

极简界面 + 强大 AI 能力 + 鸿蒙分布式协同

01
极简适老化 UI

02
端侧 AI 大模型

USE CASES

目标用户与典型场景

60+ 独居或半独居长者，以及无法时刻陪伴的父母子女

💊
SCENE 01 · 日常提醒

奶奶忘记吃药

早晨 8 点，手表震动 + 语音播报：奶奶，降压药该吃啦，饭后半小时后还要吃钙片。点一下手表中"已吃药"就行。

✅ 端侧模型识别意图 → 调用提醒服务 → 多设备协同反馈
💬
SCENE 02 · 情感陪伴

爷爷想聊天了

"小银啊，我今天有点闷"。Agent 主动切换为陪伴模式，调用方言识别，聊起孙子上周的照片，让爷爷乐开了花。

✅ 情感识别 → 主动关怀策略 → 分布式拉取家庭相册
🆘
SCENE 03 · 紧急呼救

奶奶卫生间跌倒

手表检测到异常姿态 + 3 分钟无活动。Agent 自动联系子女、拨打 120，并向社区网格员推送定位。

✅ 风险评估：HIGH → 紧急预警 → 多通道同步通知
👨‍👩‍👧
SCENE 04 · 子女关怀

异地女儿查看父母

女儿在外地打开子女端 App，看到妈妈今天吃药✓✓、心情😊、心率正常。Agent 主动汇报"妈妈今天状态不错"。

✅ 健康数据汇总 → 自然语言生成日报 → 推送子女端
