创意介绍

Core Idea

痛点：企业内网、保密项目、离线出差、涉密代码等场景下，公网大模型无法使用；开发者要么退回"手写代码"时代，要么冒着代码泄露风险通过网页端把代码片段上传给 ChatGPT / Copilot，效率与合规两难。

灵感：在折腾 Qwen-uncensored 等开源大模型本地部署时发现，单卡 4090 即可流畅跑 7B/14B 模型，但"本地模型 + IDE 体验"之间缺一座桥梁。市面上同类项目要么必须联网，要么体积臃肿。

产品形态：轻量级桌面应用 + VS Code / JetBrains 插件，对接本地 Ollama / vLLM 部署的 Qwen 模型，提供代码补全、整段生成、Bug 定位、单元测试生成、代码评审、Git Commit 总结等能力，全程不联网。

🔥 现有方案的三大痛点

① 数据外泄：Copilot / Cursor / ChatGPT 必须把代码片段上传到云端，敏感业务代码（合同、风控、用户数据处理逻辑）有合规风险。
② 网络与账号强依赖：出差/内网/涉密机环境无网，海外服务在国内访问不稳；商业产品按月付费，团队使用成本高。
③ 工具链碎裂：本地已有 Qwen + Ollama + IDE，但缺少把它们串起来的统一 UI 与上下文管理；想要"无审查"代码生成又担心云端审计。
