📄 文档上传

支持多种格式文档上传，通过 REST API 将文件存储至服务器，文件信息记录在 MySQL 数据库中，原始文件保存至 backend/data/uploads/ 目录。

支持的格式：PDF、DOCX、TXT、MD、XLSX、PPTX、CSV

⚙️ 文档解析

根据文件类型自动选择解析引擎，将文档内容提取为纯文本：

PDF → PyMuPDF (fitz) · DOCX → python-docx · XLSX → openpyxl · PPTX → python-pptx

🧩 文本分块

将解析后的文本按配置参数切分成语义完整的文本块（chunks），默认块大小 512 tokens，重叠 128 tokens，确保上下文连贯性。

🔢 向量化

使用 Embedding 模型将文本块转换为向量表示（1536维），存入 ChromaDB 向量数据库。支持双模式：

Ollama: qwen3-embedding:8b · DashScope: text-embedding-v3

🎯 混合检索

用户提问后，同时执行三种检索策略，从不同维度召回相关文档片段：

🔍 BM25权重 0.4
基于词频-逆文档频率的经典全文检索，召回率 85%
🧠 向量检索权重 0.4
余弦相似度计算语义相似度，召回率 78%
📌 关键词匹配权重 0.2
正则表达式精确匹配关键词，召回率 92%

⚡ RRF 融合排序

使用 Reciprocal Rank Fusion 算法将三种检索结果融合，通过倒数排名加权实现对不同检索策略的公平排序：

RRF(d) = 1/(k + rank₁(d)) × 0.4 + 1/(k + rank₂(d)) × 0.4 + 1/(k + rank₃(d)) × 0.2

🤖 LLM 生成

将检索到的文档片段作为上下文，拼接系统提示词后发送至大语言模型，通过 SSE 流式返回生成结果，首 Token 延迟 <500ms。

支持双模式切换：

本地: Ollama(qwen2.5:7b) · 云端: DashScope(qwen-plus)
CORE FEATURES

核心功能

企业级 RAG 系统的完整功能矩阵

🔍

BM25 全文检索

基于词频-逆文档频率的经典检索算法，配合 jieba 中文分词，实现高精度关键词匹配。自定义 BM25 实现，参数 k₁=1.5, b=0.75。

jieba 分词TF-IDF全文搜索
🧠

向量语义检索

通过 Embedding 模型将文本转为高维向量，使用余弦相似度计算语义相似度。支持 Ollama 与 DashScope 双 Embedding 模式。

1536 维余弦相似度ChromaDB
📌

关键词精确匹配

基于正则表达式的关键词提取与匹配引擎，高精度命中特定术语、编号、日期等结构化信息，召回率高达 92%。

正则表达式精确匹配高召回
⚡

RRF 融合排序

Reciprocal Rank Fusion 算法，以倒数排名加权融合三种检索结果，权重配比 BM25:0.4 + Vector:0.4 + Keyword:0.2，实现最优排序。

RRF加权融合排序优化
🤖

双模式 LLM

同时支持本地 Ollama 与云端 DashScope 两种推理模式，通过 .env 配置一键切换，适配不同部署场景与性能需求。

OllamaDashScope通义千问
