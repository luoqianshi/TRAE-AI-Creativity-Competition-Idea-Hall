🧼 挖皂泥

一款治愈系宝石收集休闲小游戏

🏷️ 项目标签

生活娱乐

💡 创意介绍

想解决什么问题：现代人生活压力大，需要简单轻松的休闲方式来解压放松，同时满足收集控的成就感。

为什么会想到做这个：受到现实中"考古挖掘玩具"和"皂泥挖宝"网红玩具的启发，将这种解压又有趣的玩法搬到小程序上，让用户随时随地都能享受挖宝的乐趣。

大概是什么产品：一款基于 Taro 框架开发的跨端小程序游戏，用户通过"挖"皂泥获得各种稀有度的宝石，体验收集和开盲盒的乐趣。

🎯 目标用户及痛点

面向哪些用户：18-35岁年轻群体，尤其是喜欢收集类游戏、休闲解压游戏的用户，以及对盲盒、开箱子等玩法感兴趣的玩家。

在什么场景下使用：通勤路上、午休时间、睡前放松、工作间隙摸鱼等碎片化时间，用户希望快速获得快乐和满足感。

当前痛点：现实中的皂泥挖宝玩具需要购买、占地、弄得到处都是碎屑，而且价格不便宜，无法反复体验；而手机上的休闲游戏要么太复杂、要么广告太多，缺乏纯粹的解压和收集乐趣。

💫 价值与意义

  • 😊

    情绪价值与解压

    挖皂泥和开盲盒的过程能有效缓解焦虑和压力，为用户提供简单纯粹的快乐体验。每一次挖掘都是一次小惊喜，收集宝石带来的成就感能持续刺激多巴胺分泌。

  • 💰

    商业价值

    通过游戏内金币系统和高级皂泥付费购买，可形成稳定的变现模式。同时宝石收集系统具有强留存特性，用户为了收集齐全会持续游玩，提升日活和时长。

  • 🎮

    轻游戏趋势

    顺应休闲轻游戏的市场趋势，玩法简单易上手，适合碎片化时间娱乐。小程序形态无需下载，即点即玩，降低用户门槛，便于社交分享传播。

⚙️ 技术实现

技术栈：Taro 4.x + React 18 + TypeScript

支持平台：微信小程序、抖音小程序、支付宝小程序、H5

状态管理：React Context + localStorage 本地持久化

样式方案：CSS Modules + SCSS + 设计系统

项目特色：一次编写，多端运行；模块化组件设计；流畅的动画效果；温暖可爱的视觉风格
