# 家庭点菜系统 - 部署指南

## 环境要求

| 组件 | 版本要求 |
|------|---------|
| Node.js | 16+ |
| npm | 8+ |
| PHP | 7.4+（推荐 8.0+） |
| MySQL | 5.7+ |


打开 phpstudy 自带的 **phpMyAdmin**（或使用 Navicat 等工具）：

1. 登录账号：`root`，密码：`14285703a`
2. 导入 `database.sql` 文件
3. 执行成功后会创建 `family_ordering` 数据库，包含 7 张表和初始数据

编辑 `api/config/database.php`，确认数据库连接信息：

```php

    'host' => '127.0.0.1',
    'port' => 3306,
```

## 二、前端部署

### 方式一：开发模式（推荐调试用）

1. 编辑 `src/api.js`，修改 API 地址为你的实际地址：

```javascript
export const API_BASE = 'http://localhost/family-ordering/api'
```

2. 启动开发服务器：

```bash
cd "E:\visual studio code\web前端\家庭点菜系统"
npm install
npm run dev
```

3. 打开浏览器访问 `http://localhost:5173`

### 方式二：生产构建（推荐部署用）

1. 修改 `src/api.js` 中的 API 地址

2. 执行构建：

```bash
npm run build
```

3. 将 `dist` 文件夹中的所有文件复制到 phpstudy 网站根目录：

```
D:\Program Files (x86)\phpstudy_pro\WWW\family-ordering\
├── api\
├── uploads\
├── index.html              # dist/index.html
├── assets\                 # dist/assets/
└── favicon.svg             # dist/favicon.svg
```

4. 访问 `http://localhost/family-ordering` 即可使用

## 四、API 接口文档

| 接口 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `/api/users` | GET | `id`（可选） | 获取用户列表 |
| `/api/users` | POST | `nickname`, `role_name` | 创建用户 |
| `/api/users` | PUT | `id`, `nickname`/`role_name`/`avatar` | 更新用户 |
| `/api/dishes` | GET | `category`（可选） | 获取菜品列表 |
| `/api/dishes` | POST | `name`, `description`, `category`, `emoji` | 创建菜品 |
| `/api/orders` | GET | `date`, `user_id`（可选） | 获取点菜记录 |
| `/api/orders` | POST | `user_id`, `dish_id`, `quantity`, `order_date` | 提交点菜 |
| `/api/cooking` | GET | `date`（可选） | 获取做菜记录 |
| `/api/cooking` | POST | `user_id`, `dish_id`, `cooking_date` | 记录做菜 |
| `/api/announcements` | GET | - | 获取公告列表 |
| `/api/announcements` | POST | `title`, `content`, `author_id` | 发布公告 |
| `/api/dates` | GET | `month`（可选） | 获取重要日期 |
| `/api/photos` | GET | `album`（可选） | 获取照片列表 |
| `/api/upload` | POST | `file`（FormData） | 上传照片 |

## 五、常见问题

### Q: API 返回 500 错误？

检查 `api/config/database.php` 中的数据库密码是否正确，以及 phpstudy 的 MySQL 服务是否启动。

### Q: 前端页面空白？

1. 打开浏览器开发者工具（F12）查看 Console 报错
2. 确认 `src/api.js` 中的 API 地址是否正确
3. 确认 phpstudy 的 Apache 服务已启动

### Q: 照片上传失败？

1. 检查 `uploads` 文件夹是否存在
2. 确保 `uploads` 文件夹有写入权限
3. 检查上传文件大小是否超过 5MB 限制

### Q: 数据库导入报错？

1. 确认 phpMyAdmin 登录账号密码正确
2. 如果提示表已存在，先执行 `DROP DATABASE family_ordering;` 再重新导入
3. 确保 MySQL 版本为 5.7+

### Q: 跨域问题（CORS）？

API 已配置 `Access-Control-Allow-Origin: *`，如果仍有问题，检查是否有其他中间件拦截。
