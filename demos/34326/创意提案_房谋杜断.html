🔧技术架构

采用前后端分离架构，注重高可用、可扩展和安全性：

React 18 TypeScript Tailwind CSS Express.js Drizzle ORM SQLite JWT认证 熔断降级 指数退避 AES-256加密
高可用保障
  • 熔断机制：5次失败 → 30秒熔断 → 半开探测
  • 降级方案：AI不可用时自动切换本地规则引擎
  • 健康检查：K8s就绪/存活探针 + 优雅关闭
  • 数据备份：每日自动备份 + 一键恢复

🔄决策反馈闭环

系统不是"一次性建议"，而是持续迭代的决策教练：

决策创建 → AI分析 → 方案推荐
首次决策分析，多维度框架评估
1天后：初始反馈
决策执行后第一感受，是否遇到意外
7天后：短期效果
初步结果评估，量化对比预期vs实际
1月 / 3月 / 6月 / 1年：长期追踪
持续评估决策质量，偏差分析驱动模型校准
知识沉淀：偏差分析 → 自动校准
