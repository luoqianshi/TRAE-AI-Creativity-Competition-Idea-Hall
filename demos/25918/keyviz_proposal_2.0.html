PART 01

💡 创意名称与创意介绍

创意名称：KeyViz 键盘可视化（Keyboard Visualizer）

想解决什么问题：游戏录屏、教学视频、直播展示时，观众/读者看不到操作者按下了什么键，学习成本高。很多游戏连招、软件快捷键只能靠口头描述或后期字幕来补充，无法做到实时、直观、沉浸式地展示键盘操作。

为什么会想到做这个：作为一名开发者，我经常看编程教程视频，作者按下快捷键完成了一系列操作，但我完全看不清是哪个键，需要反复暂停、倒回去观察。同样地，看游戏主播时，想学习连招手法却看不清按键节奏。市面上已有一些工具（如 KeyCastOW、carnac、NohBoard），但它们要么界面丑陋、要么功能单一、要么跨平台支持差。于是我想做一款现代化、高颜值、可高度定制的键盘可视化工具。

大概是什么产品：一款基于 Tauri + Rust + TypeScript + Vue 3 的跨平台桌面应用，底层用 Rust 监听全局键盘事件，通过 Tauri 的事件系统实时传递到前端，由 Vue 组件以多种酷炫的动画效果展示按键、组合键、按键热力图等信息。用户可自定义主题、布局、透明度、窗口置顶、OBS 虚拟摄像头适配等。

  • 录屏时 按键不可见，观众/读者只能靠猜测或反复观察来学习
  • 现有工具 界面丑陋、动画单一，与现代化桌面风格格格不入
  • 部分工具 仅支持 Windows，Mac/Linux 用户没有好的选择

PART 05

🎮 核心功能清单

可视化展示模式

  • 🎹 键盘布局模式 —— 在屏幕上显示完整键盘，按下的键高亮发光，支持多种键盘布局（60%、75%、TKL、全尺寸）
  • 💫 浮起显示模式 —— 按键以动画形式从屏幕底部浮起并消散，适合直播、教程录制场景
  • 🔥 按键热力图模式 —— 根据按键频率用颜色渐变显示键盘热力图，了解自己的按键习惯
  • 📏 条纹模式 —— 横条/竖条形式滚动显示按键序列，类似音乐节奏游戏
  • 📝 历史记录模式 —— 显示最近按键序列，可调节记录数量、显示时长、字体大小

技术与交互特性

  • 毫秒级响应 —— Rust 事件监听 + Tauri 事件通道，从物理按键到屏幕显示延迟 < 10ms
  • 组合键智能识别 —— Ctrl+C、Alt+Tab、Cmd+Shift+4 等组合键作为整体展示
  • 鼠标事件支持 —— 鼠标点击、滚轮、X1/X2 侧键同样可视化（可开关）
  • 数据统计面板 —— 按键总数、CPS（每秒按键数）、连击计数、最常用按键排行
  • 窗口置顶/透明/无边框 —— 支持 always-on-top、透明背景、无边框窗口
  • 多主题/多语言 —— 内置深色/浅色/彩虹/霓虹多种主题，支持中文/英文
  • 自定义布局 —— QWERTY、Dvorak、Colemak、自定义布局文件导入
  • OBS / 直播友好 —— 透明背景模式、窗口捕获源支持、绿色屏幕背景色
  • 隐私保护 —— 可选密码模式（在密码输入框时自动暂停可视化），纯本地运行，无任何数据上传
