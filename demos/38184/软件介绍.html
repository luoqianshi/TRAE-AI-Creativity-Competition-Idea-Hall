CORE FEATURES

核心功能特性

从智能识别到结果审核，打造完整的档案著录工作流

🤖

智能提取

调用本地 Ollama 大模型自动识别档案图片，智能提取字段信息，准确率高，适应复杂档案格式。

⚙️

三种提取模式

OCR 快速模式、视觉模型模式、混合模式自由切换，应对不同场景，兼顾速度与精度。

📑

前后页模式

可选择档案的前 N 页和后 N 页作为参考，提供更丰富的上下文信息，显著提高识别准确率。

🧩

自定义档案类型

支持创建和管理多种档案类型的著录规则，文书、工程图纸、照片、声像等灵活配置。

🎯

字段要求设置

为每个字段设置具体的提取要求和提示词，让 AI 提取更贴合业务需求。

🖱️

拉框 OCR

在图片上拉框选择文字区域进行 OCR 识别录入，精准定位关键字段。

✅

结果审核

支持对提取结果进行人工审核和修改，可标记已审核，完整保留人机协作流程。

📊

多格式导出

支持导出 Excel 和 CSV 格式的著录结果，带格式化样式与颜色标记，方便后续处理。

🔍

实时诊断

Ollama 连接状态实时监控和诊断，模型可用性自动检测，问题早发现。

🎨

多主题支持

深色 / 浅色多种主题自由切换，匹配不同工作环境，护眼更专业。

🚀

一键优化

根据电脑配置自动优化批处理大小、图片压缩等参数，新手也能获得最佳性能。

🔒

本地化运行

完全本地化部署，数据不出本地，敏感档案信息得到充分保护，符合档案安全规范。

EXTRACT MODES

三种提取模式

根据档案复杂度与性能需求，自由选择最合适的提取方式

RECOMMENDED · 推荐

👁️ 视觉模型模式

直接使用 Ollama 视觉大模型进行字段提取，准确率高，适合复杂档案。推荐使用 qwen2.5vl:7b。

FAST · 快速

⚡ OCR 快速模式

使用本地 OCR 进行文字识别，速度快，适合简单文档。处理大批量数据时优势明显。

HYBRID · 混合

🔀 混合模式

先尝试 OCR，如果提取字段不足，自动回退到视觉模型。兼顾速度与准确率的最佳实践。

QUICK START

快速开始

三步启动你的档案著录工作流

# 1. 安装 Ollama 与视觉模型
$ ollama pull qwen2.5vl:7b
✓ 模型下载完成
 
# 2. 启动 Ollama 服务
$ ollama serve
✓ 服务运行于 http://localhost:11434
 
# 3. 启动档案著录系统
$ python main.py
✓ 主窗口已显示 · 准备就绪
CONFIGURATION

核心配置参数

灵活配置，匹配你的工作环境

配置项 默认值 说明
Ollama 地址 http://localhost:11434 Ollama 服务地址
默认模型 qwen2.5vl:7b 使用的视觉语言模型
连接超时 30 秒 Ollama 连接超时时间
请求超时 300 秒 单次请求超时时间

Temperature 0.1 生成随机性（0=确定，2=随机）
上下文长度 8192 模型上下文窗口大小

USE CASES

适用场景

覆盖多种档案类型的智能著录需求

📄

文书档案

公文、合同、协议等文书类档案，自动提取题名、责任者、日期、页数等核心元数据。

📐

工程图纸

建筑图纸、机械图纸等工程档案的智能识别与字段著录，支持图号、比例等专项字段。

📷

照片档案

历史照片、活动照片的元数据著录，包括时间、地点、人物、事件描述等。

🎬

声像档案

录音、录像等声像类档案的著录管理，提取时长、格式、主题等关键信息。

📊

会计档案

凭证、账簿、报表等会计档案的批量处理，符合财务档案管理规范。

🔬

科技档案

科研项目、专利、技术报告等科技档案的智能著录与归档。
