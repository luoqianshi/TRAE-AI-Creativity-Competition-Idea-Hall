产品介绍

为 AI 创作 而生的监控工具

在 AI 绘画工作流中，硬件状态的可视化是提升创作效率的关键一环。

💻

ComfyUI 原生集成

作为 ComfyUI 插件无缝嵌入工作流界面， 无需切换窗口即可查看 GPU 占用、显存使用、温度等关键指标。 不干扰创作流程，时刻守护你的 AI 绘图任务。

🎨

翡翠胶囊美学

独创的 3D 圆柱渐变效果 + 霓虹发光边框设计， 将冰冷的硬件数据转化为具有科技美感的视觉体验。 监控也可以很优雅。

⚙️

解决真实痛点

直观呈现显存占用趋势，提前预警 OOM 风险； 实时追踪 GPU 利用率，帮助判断推理瓶颈； 让每一次 AI 生成都更加可控、高效。

用户洞察

目标用户与 核心痛点

我们深入理解 AI 创作者的日常挑战，每一项功能都源于真实需求

👤

目标用户

  • 🎨

    ComfyUI / Stable Diffusion 用户

    使用节点式工作流进行 AI 图像生成的创作者，需要实时了解硬件负载状态。

  • 💻

    AMD / NVIDIA 双显卡用户

    使用 AMD 或 NVIDIA 显卡进行 AI 推理的用户，希望获得跨平台的统一监控体验。

  • 🧠

    开发者与研究者

    需要监控工作流硬件负载的开发者/研究者，用于性能调优和资源规划。

⚠️

核心痛点

  • 🔴

    GPU 状态不可见

    AI 绘图时 GPU 占用率高但无法直观看到实时状态，只能靠猜测判断是否正常运行。

  • 🔴

    显存 OOM 风险

    不知道显存何时接近爆满，经常遭遇 Out of Memory 崩溃，导致长时间渲染前功尽弃。

  • 🔴

    瓶颈难以定位

    无法判断是 GPU 瓶颈还是其他瓶颈（如 CPU、内存、磁盘 I/O），优化无从下手。

  • 🔴

    缺少美观工具

    现有监控工具要么功能简陋要么界面丑陋，缺乏一款既美观又不干扰工作的监控工具。

技术架构

技术 亮点 深度解析

每一项技术选型都经过深思熟虑，追求极致的性能与用户体验

📞

WebSocket 实时推送

采用 WebSocket 协议实现服务端到客户端的低延迟数据推送， 相比轮询方案大幅降低网络开销和服务器压力。

协议类型 WS/WSS
端到端延迟 < 100ms
更新频率 2Hz
🖥️

跨平台 GPU 检测

自研 GPU 抽象层，统一封装 NVIDIA 和 AMD 的检测接口。 自动检测运行环境并选择最优的数据采集策略。

NVIDIA 方案 pynvml
AMD Linux amdsmi
AMD Windows WMI/ADLX
📊

EMA 平滑算法

采用指数移动平均（Exponential Moving Average）算法平滑数值跳动， 在保持响应速度的同时消除高频抖动，带来丝滑的视觉体验。

算法类型 EMA
平滑系数 alpha=0.3
视觉效果 无闪烁
🎨

CSS 变量主题引擎

基于 CSS Custom Properties 构建的主题系统， 支持运行时动态切换，零 JavaScript 样式计算开销， 所有颜色、阴影、光效均可通过变量控制。

主题数量 5 Colors
风格预设 5 Styles
组合总数 25 Themes
🚀

线程安全架构

数据采集线程与 WebSocket 推送线程完全解耦， 通过线程安全队列进行通信，确保高并发场景下的数据一致性。

采集线程 独立
推送线程 独立
同步机制 Queue
⚙️

性能优化策略

采用惰性采集、缓存复用、增量更新等多种优化手段， 确保监控系统本身对系统资源的消耗降至最低。

CPU 开销 < 1%
内存占用 < 50MB
