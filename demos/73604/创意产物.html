01 痛点 / Pain Points

写论文的最后一公里，从不是写作本身。

每一位交大 MBA 学员都经历过同样的至暗时刻：内容写完，却被格式打回。

章标题要黑体三号居中，节标题却要四号左对齐；图编号要"图 3-1"按章重置，公式要"(2-3)"右对齐；三线表不能有一根竖线，页眉左边"上海交通大学 MBA 学位论文"右边是题目——50 多条规则，散落在 12 页 PDF 格式说明里。
i.

逐条手改

52 个样式要一个一个点，10 分钟起步，错一处就得重来。

ii.

编号连锁

图 1-1、表 2-3、公式 (3-5)，一改章节全乱，全文要重排。

iii.

三线表玄学

顶线 1.5pt、表头线 0.75pt、无线框竖线——Word 找不到这个预设。

iv.

目录永远对不上

F9 更新键按到手酸，页码还是错位，导师批注"目录再调一下"。

v.

中英图题同步

"图 3-1"和"Figure 3-1"必须同号，一个一个手抄是噩梦。

vi.

答辩前夜的崩溃

截止日期前夜还在改页眉字号，整栋宿舍楼都听得到你的叹气。

' 入口宏 — Alt+F8 选择"导入上海交大MBA论文样式"运行
Public Sub 导入上海交大MBA论文样式()
    Dim doc As Document
    Set doc = ActiveDocument

    On Error GoTo MainHandler
    Application.ScreenUpdating = False

    ' Step 1: 页面设置（A4 + 交大边距）
    SetupPage doc
    SetDefaultFont doc

    ' Step 2: 52 个 MBA 自定义样式
    CreateAllStyles doc

    ' Step 3: 9 级多级编号 + 4 个 ListTemplate
    ClearOldBindings doc
    BindAllNumbering doc

    ' Step 4: CaptionLabel 题注系统
    SetupCaptionLabels doc
    SetupCaptionStyles doc

    Application.ScreenUpdating = True
    ValidateAll doc

    MsgBox "上海交通大学MBA学位论文样式导入完成！" _
           & vbCrLf & "[样式] 52 个 MBA 格式样式" _
           & vbCrLf & "[编号] 第X章 / X.X / X.X.X / (X) / 圈号" _
           & vbCrLf & "[题注] 图X-X / 表X-X · CaptionLabel 自动编号", _
           vbInformation, "MBA 论文样式 v6.0"
    Exit Sub

MainHandler:
    Application.ScreenUpdating = True
    MsgBox "运行出错：" & Err.Description
End Sub

' 编号模板示例：第 X 章 / 1.1 / 1.1.1
Dim lt As ListTemplate
Set lt = doc.ListTemplates.Add(OutlineNumbered:=True)

With lt.ListLevels(1)
    .NumberFormat = ChrW(31532) & " " & "%1" & " " & ChrW(31456)
    .TrailingCharacter = wdTrailingSpace
    .NumberStyle = wdListNumberStyleArabic
    .ResetOnHigher = 0
    .StartAt = 1
    .Font.NameFarEast = "黑体"
    .Font.Size = 16
    .Font.Bold = True
End With

' 三线表格式化（一键 顶/表头/底 三线）
Public Sub MBA格式三线表()
    If Selection.Tables.Count = 0 Then Exit Sub
    With Selection.Tables(1).Borders
        .OutsideLineStyle = wdLineStyleNone
        .InsideLineStyle = wdLineStyleNone
    End With
    ' 顶线 1.5pt · 表头底线 0.75pt · 底线 1.5pt
    Selection.Tables(1).Rows(1).Borders(wdBorderTop) = wdLineWidth150pt
    ' ... 详见 modUtility.bas
End Sub
05 架构 / Architecture

9 个模块，9 个 Bug 教训，
9 个工程化纪律。

从 v5 的单文件巨型模块，重构为分层架构。每层单一职责、彼此解耦、便于单测。

01
modConfig.bas
配置层

87 个 Public Const 常量：字体、字号、样式名、页面参数——所有魔数集中。

02
modStyleEngine.bas
通用样式引擎

EnsureStyle / GetOrCreate——幂等创建，断网也能跑通。

03
modPageSetup.bas
页面设置

A4 + 3.5/4.0/2.8 边距，CLng 包裹防 4608 错。

04
modStyleGroups.bas
样式分组

52 个样式分 9 组批量创建，调用引擎不重复造轮子。

05
modNumberEngine.bas

4 个 ListTemplate 模板，9 级 OutlineNumbered。

06
modCaption.bas

07

08
modValidator.bas
验证器

52×13=676 项格式校验，输出 Pass/Fail 报告。

09
modMain.bas
入口与引导

07 历程 / Lessons

让 AI 真正 写生产代码，
需要的不是 Prompt，是 纪律。

整个 v5→v6 的迭代，是用 30 个真实 Bug 喂出来的：Python 写 GBK 文件乱码、wdOddRows 在 Word 2016 不存在、删除 %2 占位符导致级联编号全断、CentimetersToPoints() 在某些版本要 CLng() 包裹……每修一个，就写一条规则写进 SKILL.md，下次再调用时作为不可跳过的强制步骤。

最终沉淀为 9 条工程铁律：编码前调用 karpathy 编码指南 / 修改前 4 项影响分析 / Option Explicit / On Error Resume Next 成对 / 编号占位符不可删 / CLng 包裹度量单位 / 修改后 git commit + tag……
