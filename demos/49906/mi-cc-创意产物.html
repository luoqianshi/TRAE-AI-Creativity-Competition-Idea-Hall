🎯发现的问题

现有 AI 编程工具在实际开发中反复出现的五大痛点

🔄 上下文反复交代

每次新开对话都要重新介绍项目技术栈、架构和约束，大量时间浪费在重复沟通上。

⚠️ 单模型依赖

API 遇到 429/5xx 错误或 Key 失效时，工作流直接中断，需手动切换和排查。

📉 长对话截断

超过 Token 上限后，前面的关键需求和设计决策被丢弃，导致输出偏离目标。

🧩 经验无法沉淀

团队里的高频工作流、最佳实践和个人 trick 无法被系统化积累和复用。

🔧 仅支持原子操作

普通 MCP 工具只能执行读/写/执行单条命令，无法自主规划完成完整编程任务。

🚀核心解决方案

mi-cc 用 11 大核心能力系统性解决上述痛点

🧠

四层记忆系统

checkpoint（会话）/ MEMORY（项目）/ notes（草稿）/ history（日志），启动自动恢复，跨会话持久化。

💾

任务级 Checkpoint

每次工具调用自动记录目标、步骤、已修改文件和阻塞问题，崩溃后可无缝续跑。

🔄

多 Provider 故障转移

配置多组 API Key，401/429/5xx 错误时自动切换，保证对话和任务不中断。

📦

分层摘要压缩

60%/80%/95% 三档触发，滚动窗口自动维护最近 N 轮，超长对话不丢上下文。

🎯

完整任务执行

agent_execute 自主规划 + 多轮工具调用，完成完整编程任务，而非仅原子操作。

📚

技能库自动蒸馏

/distill 从历史对话挖掘高频工作流，top-2 匹配技能自动注入 System Prompt。

🔍

项目索引与问答

/index 扫描代码提取函数/导入/导出；/ask 基于索引进行代码问答，支持 TF-IDF 检索。

🔗

MCP Server 模式

--mcp 启动，暴露完整 Agent 能力给 OpenClaw、Cursor、Claude，开箱即用。

🌐

联网搜索

内置 webFetch 工具，LLM 可自主抓取网页内容，实时获取最新文档和信息。

🧠四层记忆系统架构

从会话级到项目级的立体记忆，告别反复交代背景

L1

checkpoint.md — 会话检查点

当前会话状态快照，启动时自动恢复，任务断点续跑

L2

MEMORY.md — 项目记忆

跨会话持久化的项目上下文，自动注入每条 System Prompt

L3

notes.md — 临时笔记

草稿、待办、调试记录，随时查阅和更新

L4

history.json — 完整日志

全量对话历史，可检索、可审计、可分析

🎬典型使用场景

覆盖从个人开发到团队协作的完整工作流

1

大型项目持续开发

跨多天的复杂功能开发中，四层记忆自动保持项目上下文，无需每次重新交代架构。

2

长对话完整重构

对一个模块进行完整重构时，自动压缩保留关键决策，不因 Token 上限而丢失需求。

3

模型故障无缝切换

遇到 429 限速或 5xx 服务异常时，0 人工干预自动切换到备用 Provider，任务不中断。

4

团队知识沉淀

通过 /distill 将高频工作流自动提炼为技能库，新成员接入即可获得团队最佳实践。

5

接入 Cursor / Claude

通过 MCP Server 模式，让现有 IDE 获得多模型切换、记忆持久化、任务自主执行能力。

6

联网实时辅助

询问最新 API 文档或框架版本时，LLM 主动联网获取，回答不再受训练数据截止时间限制。
