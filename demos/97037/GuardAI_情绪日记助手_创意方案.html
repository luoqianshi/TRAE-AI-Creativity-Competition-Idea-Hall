GuardAI 情绪日记助手

一个有安全护栏的 AI 情绪记录与反思工具

让每一次倾诉都安全、被理解、有价值

💡 创意介绍

想解决的问题：当代年轻人普遍面临情绪压力，但专业心理咨询门槛高、费用贵；而现有通用AI聊天工具缺乏安全边界，可能在情绪脆弱时输出有害内容或错误建议，反而加重焦虑。
我们的方案：GuardAI 是一个带有多层安全护栏的AI情绪日记助手。用户通过文字或语音记录每日情绪，AI基于心理学知识库生成温和的反思问题，帮助用户梳理思绪；同时系统在检测到风险内容时自动提供专业资源转介，确保用户安全。

产品形态

基于 Web 的全栈 AI 应用，支持语音输入、流式对话、情绪趋势可视化，以及管理员面板展示任务队列设计。

⚛️ React + TypeScript 🐍 FastAPI 🧠 大模型 API 🔍 RAG 检索 🛡️ 内容安全过滤 📊 PostgreSQL ⚡ Redis 🐳 Docker

👥 目标用户与痛点

🧑‍💻

职场新人（22-30岁）

工作压力大，经常加班，情绪波动频繁。不好意思频繁向朋友倾诉，担心成为"情绪负担"。

📚

高校学生（18-25岁）

面临学业、就业、人际关系多重压力。学校心理咨询资源紧张，预约往往需要等待1-2周。

🏠

独居青年（25-35岁）

独居生活缺乏日常倾诉对象，深夜情绪低谷时无人可聊，通用AI聊天又担心隐私和安全。

核心使用场景

🌙 睡前情绪复盘

记录一天的情绪起伏，AI帮助梳理引发情绪波动的事件和思维模式。

😤 冲突后的冷静

与同事/朋友发生争执后，通过日记和AI反思，避免情绪化决策。

😔 低落时的倾诉

感到孤独或焦虑时，有一个随时在线、不会评判的倾听对象。

📈 情绪趋势追踪

长期记录后查看情绪变化曲线，发现潜在的情绪周期和触发因素。

当前痛点

  • 向朋友倾诉怕打扰对方，且朋友未必具备倾听技巧
  • 通用AI聊天（如ChatGPT）缺乏边界，可能在情绪脆弱时给出不恰当建议
  • 专业心理咨询费用高（300-800元/次），且预约周期长
  • 现有情绪记录App多为纯工具，缺少AI智能分析和反馈

🛡️ 安全护栏设计

GuardAI 的核心差异在于"安全优先"的设计理念。我们不追求AI万能，而是明确划定能力边界：

📝 用户输入语音/文字日记 ↓ 🛡️ [第一层] 内容安全过滤 — 关键词规则 + 大模型自评估 ↓ 🛡️ [第二层] 意图识别 — 普通记录 / 需关注 ↓ 📚 [第三层] RAG检索 — 从心理学知识库获取相关知识 ↓ 🤖 [第四层] Agent生成反思问题（CBT框架） ↓ 🛡️ [第五层] 自我评估 — 检查回复是否可能加重焦虑 ↓ 💬 流式输出到前端

🚫 不做什么

不提供医疗诊断、不开具药物建议、不替代专业心理咨询、不承诺"治愈"效果。

✅ 做什么

提供情绪记录空间、生成反思问题、识别风险并转介专业资源、长期情绪趋势追踪。

🔄 兜底机制

检测到高风险内容时，自动提供24小时心理援助热线和本地专业资源链接。

💎 价值与意义

🌍

社会价值

降低情绪管理门槛，为轻度情绪困扰人群提供安全、私密、随时可用的支持出口。中国心理咨询师缺口超100万，AI可以在非危机场景中有效填补供需缺口。

⚡

效率提升

用AI即时响应替代"等朋友有空"或"等咨询预约"，让用户在情绪发生的当下就能获得支持。从"数天后"缩短到"数秒内"。

📊

商业价值

企业EAP（员工心理援助）市场是成熟付费场景；高校学生心理服务有政策预算；个人用户可通过增值服务（深度报告、语音输入等）变现。

🔧 技术架构亮点

全栈技术栈

前端 Next.js + TypeScript 实现 SSE 流式交互；后端 FastAPI 提供异步API；PostgreSQL 存储用户数据与对话历史；Redis 缓存与任务队列；ChromaDB 作为向量数据库。

Agent 工作流

多步骤任务编排：内容安全检测 → 意图识别 → RAG知识检索 → 反思问题生成 → 输出自评估。每个环节可观测、可追踪。

RAG 体系

语义分块 + BGE-M3 Embedding + 向量检索 + BM25混合检索 + Cross-encoder重排序 + 上下文压缩，确保回复有据可依、减少幻觉。
