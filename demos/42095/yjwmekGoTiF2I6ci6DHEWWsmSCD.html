📖 如何配置 GitHub Gist 同步

  1. 登录 GitHub（如没有账号请先注册）
  2. 前往 Personal Access Tokens 页面
  3. 点击 "Generate new token (classic)"
  4. 填写 Note: "Purselog Sync"，勾选 "gist" 权限
  5. 点击 "Generate token"，复制生成的 Token
  6. 在 GitHub 任意页面点击右上角 "+" → "New gist"
  7. Filename: purselog.json，内容随便填（如 {"test": true}）
  8. 点击 "Create public gist" 或 "Create secret gist"
  9. 复制 URL 中的 Gist ID（长串字符）
  10. 填入上方表单，测试并保存配置
⚠️ 重要提示：
  • 请勿将 Token 分享给他人
  • 建议使用单独的 Token 用于此应用
  • Secret Gist 不会被搜索引擎索引
  • 数据以 JSON 格式存储在 Gist 中
