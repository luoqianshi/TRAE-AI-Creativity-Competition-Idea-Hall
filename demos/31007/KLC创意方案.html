01 / 痛点

为什么世界需要
另一门语言

主流语言复杂度高、原理晦涩，新手难以触达编译器内核；轻量脚本又多依赖庞大运行时。

LEARNING
PAIN · 01

编译器原理
高不可攀

主流编程语言动辄百万行代码，新手在 GCC、LLVM 面前无从下手。编译原理课程停留在纸面，缺少可读、可改、可跑的完整实践案例。

PRACTICE
PAIN · 02

缺少可二次开发的
自研语言样本

市面上的"教学语言"要么过于简化（只有解释器），要么过于庞大（无法通读）。青少年学习者很难找到一个从词法到原生 EXE 全链路自主可控的参考实现。

RUNTIME
PAIN · 03

轻量脚本
运行时臃肿

Python、Node.js、Lua 等脚本语言依赖庞大的运行时与解释器，部署体积大、启动慢、原生性能差，难以胜任嵌入式脚本与小型工具的轻量场景。

05 / 语法

读起来像自然语言

"Let it flow" —— 代码应当流畅如自然语言，同时保留现代语言的表达力。

examples/fibonacci.klc KLC
1-- 迭代版斐波那契
2fn fib_iter(n: i64) -> i64 {
3  if n <= 1 { return n }
4  let mut prev = 0
5  let mut curr = 1
6  let mut i = 2
7  while i <= n {
8    let next = prev + curr
9    prev = curr
10    curr = next
11    i = i + 1
12  }
13  return curr
14}

15fn main() {
16  io.println("fib(10) = " ++ fib_iter(10).to_str())
17}
