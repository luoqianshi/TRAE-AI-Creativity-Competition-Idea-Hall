核心功能

从硬件提醒到 AI 问答，覆盖服药管理全流程

⏰

智能服药提醒

定时风扇转动 + 蜂鸣器提醒。每个药仓独立配置服药时间，支持每日多次。到点自动提醒，60秒后自动关闭。

✅

时间窗口策略

计划时间 ±30 分钟为有效窗口。窗口内取药 = 按时服药；超时未取 = 自动标记漏服。防误触，精准记录。

📊

服药记录追踪

自动记录每次服药时间，统计周/月依从率。可视化图表展示，一目了然。漏服一目了然，方便子女远程关怀。

🤖

AI 药品知识问答

基于 RAG（检索增强生成）技术，内置药品知识库。用户用自然语言提问，AI 即时回答药品功效、副作用、禁忌等。

📱

设备远程管理

Web 平台实时查看药盒在线状态、传感器数据。远程配置药仓、下发指令（开风扇/关风扇/出药测试）。

🔔

漏服自动告警

定时任务每5分钟扫描一次，窗口过期未服药的记录自动标记为"漏服"。子女可通过平台实时查看漏服情况。

服药管理流程

从计划生成到服药确认，全自动闭环

🌅

每日 00:05 自动生成计划

系统根据药仓配置，自动生成今日所有服药记录（pending 状态）

🔔

到点自动提醒

到达服药时间，网关下发指令 → 药盒风扇转动 + 蜂鸣器响起，持续提醒

👆

用户一键取药

按下药盒物理按钮 → 电机转动出药 → Zigbee 上报 → 云端记录服药时间（completed）

⚠️

超时自动标记漏服

窗口（±30分钟）过后仍未取药 → 状态变为 missed → 子女可在平台查看到漏服记录

药品问答
阿莫西林能和阿奇霉素一起吃吗？

不建议同时服用阿莫西林和阿奇霉素，原因如下：

1. 两者作用机制不同

阿莫西林（青霉素类）抑制细菌细胞壁合成；阿奇霉素（大环内酯类）抑制细菌蛋白质合成。

2. 联合使用无协同增效

两者联用可能产生拮抗作用，降低彼此药效。
