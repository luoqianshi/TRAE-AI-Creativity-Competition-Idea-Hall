一、项目概述

🎯 项目定位

LeetSpace 是一个专为算法面试准备者设计的 Chrome 侧边栏插件，致力于将 LeetCode 从简单的刷题网站升级为完整的学习工作台。我们不替用户刷题，而是帮助用户建立高效、系统的刷题工作流。

核心价值主张

  • 系统化规划: 从题单导入到进度追踪，让刷题计划清晰可见
  • 知识沉淀: Markdown 笔记系统帮助构建个人算法知识库
  • 智能辅助: AI 自动识别题目并提供简洁实用的解题提示
  • 隐私优先: 100% 本地数据存储，无服务器成本，用户完全掌控
  • 开源透明: MIT 协议，代码完全开源，可二次开发

目标用户

  • 正在准备技术面试的求职者
  • 系统学习算法的在校学生
  • 需要长期维护刷题笔记的工程师
  • 希望提升刷题效率的编程爱好者

二、痛点分析

🔍 当前用户面临的核心问题

  1. 计划难以坚持: 刷题缺乏系统性规划，容易半途而废
  2. 笔记分散混乱: 笔记散落在多个平台（本地文件、语雀、Notion），复习时难以查找
  3. 知识难以沉淀: 做过的题容易遗忘，没有形成自己的知识体系
  4. 思路缺乏引导: 遇到难题不知从何下手，缺少有效的思路提示
  5. 进度不可视化: 不清楚自己的刷题进度、完成率和薄弱环节
  6. 效率无法追踪: 不知道每道题花费的时间，无法量化学习效率

现有解决方案的不足

方案类型 代表产品 主要问题
力扣原生功能 LeetCode 收藏夹 功能简陋，无笔记系统，无进度可视化
通用笔记软件 Notion、语雀 需要手动维护链接，与刷题页面割裂
现有力扣插件 各类浏览器插件 功能过重、体验复杂、强行 AI 化但价值低

三、核心功能

📚 题单计划管理

从力扣页面一键导入题单（Hot100、代码随想录、灵茶题单等），自动分组管理，支持折叠展示。

  • 题单自动分组
  • 重复题单防导入
  • 大题单折叠展示
  • 按全部或单个题单查看进度

✅ 进度自动同步

读取力扣账号中的题目 AC 状态，自动同步已完成题目到本地计划。

  • 同步 LeetCode/力扣已 AC 状态
  • 提交通过后自动标记完成
  • 减少手动维护成本
  • 适合长期刷题追踪

📝 Markdown 笔记系统

每道题都可以关联笔记，支持源码和渲染预览切换，按题单分类沉淀。

  • 最近笔记快速查看
  • 完整笔记库独立窗口
  • Markdown 源码/预览切换
  • 按题单分类管理题解

🤖 AI 自动识题辅助

进入题目页后，AI 自动识别当前题目信息，生成简洁有效的算法提示。

  • 自动读取当前题目信息
  • 多种解法思路对比
  • 标记推荐企业级方案
  • 输出复杂度和避坑点

⏱️ 悬浮做题计时器

在力扣页面显示轻量悬浮窗，记录每道题的真实思考时间。

  • 播放/暂停/重置
  • 页面内轻量悬浮
  • 可拖拽调整位置
  • 辅助复盘做题效率

⚙️ 简洁设置配置

基础设置保持清爽，高级功能收纳在高级设置中，避免界面臃肿。

  • 基础设置页
  • 高级设置弹窗
  • 自定义 AI Provider
  • 本地保存敏感配置

架构特点

🏗️ 纯前端架构 - 零服务器成本

  • 无后端依赖: 所有功能在浏览器端完成，无需服务器
  • 本地存储: 使用 chrome.storage.local 存储数据，隐私安全
  • 用户自带 API: AI 功能由用户配置自己的 API Key，支持 OpenAI、Claude、DeepSeek 等
  • 开源免费: MIT 协议，完全开源，可自由部署和修改

核心模块

模块 技术实现 说明
Side Panel Chrome Side Panel API 主工作台界面，不占用页面空间
Content Script DOM 解析 + 消息通信 提取力扣题目信息，监听提交状态
Background Service Worker 消息路由 + 存储管理 处理跨模块通信和数据同步
存储层 chrome.storage.local 计划、笔记、设置的持久化存储
AI 服务 OpenAI-compatible API 支持多家 AI 服务商，用户自带 Key
