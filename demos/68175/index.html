拍照修图 MVP 原型

不会摆姿势也能快速出片

这个单文件页面演示了拍照修图产品的 MVP 框架：先看姿势建议，再上传照片自动调色，最后加趣味边框并导出。

拍前

通过姿势模板快速找到适合自拍、半身照、全身照的动作。

拍后

上传照片后一键套用自然、清透、氛围三种自动调色风格。

分享感

叠加拍立得、胶片、生日、旅行边框，提高成片趣味性。

MVP 范围

用纯 HTML、CSS、JavaScript 即可运行，适合先验证产品流程。

姿势指导

首版先用模板引导替代复杂姿态识别，降低开发成本。

A

侧身回头

身体微侧 30 度，眼睛看镜头，肩颈线条会更明显。

适合自拍 / 半身照
B

手扶脸颊

一只手轻放脸侧，另一只手自然下垂，画面更松弛。

适合近景 / 可爱风
C

走路抓拍

往前走半步，头微低，镜头连拍更容易抓到自然瞬间。

适合全身照 / 街拍
D

双手抱臂

双手自然交叉，身体重心偏一侧，适合酷感人像。

适合站姿 / 氛围照
