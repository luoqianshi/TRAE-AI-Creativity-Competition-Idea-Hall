CREATIVE PROPOSAL

创意名称：万物皆有其歌

Every Object Has Its Own Song — A Cross-Modal Translation System from 3D Printing to Music

想解决什么问题

3D 打印的制造过程中蕴含着丰富的运动、决策与随机信息，但这些信息在最终产品中完全消失——物体只留下结果，过程被遗忘。目前没有任何系统能将物体的制造过程编码为可感知的声音表达，让沉默的物体讲述自己的诞生。

为什么会想到做这个

灵感来自老式 CRT 电视的逐行扫描——如果把物体当作电视画面来扫描，每一行黑白像素都可以翻译成一个音符。人类有声纹、指纹、DNA 来定义"我是谁"，但物体没有。如果物体也有 DNA，它不应该只是一串编号，而应该是一种关于它如何诞生的声音记忆。

大概是什么产品

一套软硬件结合的跨媒介翻译系统：通过读取 3D 打印的 G-code 文件和 CCD 相机扫描实物，将制造过程编码为 Object DNA，再解码为个性化音乐。包含扫描硬件模块和音乐生成软件（已实现完整可运行的 Python 程序）。

01 — OBSERVATION

我们看见物体，
却听不见它

在工业社会中，产品 = 结果。一只杯子、一个雕塑、一个 3D 打印件——人们只能看见最终形态。但它们都经历过运动、时间、决策、错误、随机性。这些全部消失了。

👁️

可见的：最终形态

我们只能看到物体长什么样——颜色、形状、大小。这是产品留给世界的全部信息。

🔇

不可见的：制造过程

运动轨迹、速度变化、路径决策、意外偏移——这些信息被彻底抹去，仿佛从未存在。

🧬

缺位的：物体身份

人拥有声纹、指纹、DNA 来定义"我是谁"。但物体没有任何东西来诉说"我是怎么来的"。

02 — RESEARCH QUESTION

如果物体有 DNA，
它应该是什么？

本项目的研究问题不是"如何把 3D 打印变成音乐"，而是：

"一个物体是否能够拥有自己的声音记忆？"

Can an object possess its own acoustic memory of creation?

03 — SYSTEM PIPELINE

从物体到音乐：
编码 → 解码

Step 01

用户提交作品

用户提交一份 3D 打印作品，同时提供 G-code 文件（制造指令，23,720 条移动指令 / 321 层）和 CCD 相机图像（实物俯视照片）。

Step 02

G-code 特征提取

从 G-code 中提取 Chaos（路径混乱度 = 30）、Flow（流动度 = 100）、Density（路径密度 = 37）、Height（重心高度 = 39），构成"制造基因"。

Step 03

CCD 扫描线分析

图像裁切后分成 100 条扫描线（如同老式 CRT 电视），每条提取 Density、Smoothness、Symmetry、Complexity，得到 100×4 的特征矩阵。

Step 04

计算 Object DNA

综合 G-code 和 CCD 特征，计算作品的音乐 DNA：

Energy = 30Complexity = 34Stability = 91Emotion = 69
Step 05

歌曲检索与匹配

将 Object DNA 与 28 首经典曲目的歌曲库进行欧式距离匹配，找到情感空间最接近的基准歌曲。匹配结果：River Flows in You — Yiruma（距离 = 13，BPM 68，三和弦+七和弦，固定音型）。

Step 06

逐行扫描音乐改编

不是"一个作品→一首歌"，而是"一条扫描线→歌曲的 1%"。100 条扫描线逐段修改和弦、演奏方式、乐器编制和音区。每行内含 2 拍×4 细分 = 8 个音符位置，包含和弦+旋律+低音+弦乐垫音+对位，最终生成 144.9 秒的完整作品。

07 — VISUAL ↔ AUDITORY

花瓶的形状，
你听得见

将花瓶从底到顶分为五段，每段的形态特征直接对应不同的声音表现——宽处声音厚，窄处声音薄；圆润处连奏，粗糙处断奏。

口沿（顶部 5%）
形状：窄，微微外翻
密度低 → 钢琴独奏，声音单薄透明；外翻对称度下降 → 音区略有偏移，产生轻微的不稳定感
收颈（70%–88%）
形状：急速收窄，直径骤降
密度骤降 → 乐器从三重奏退为二重奏；平滑度仍高 → 连奏延续；对称度高 → 和声干净稳定，如同收紧的颈部
腹部（12%–50%）
形状：最宽处，正弦曲线鼓出
密度最高 → 弦乐垫音+对位旋律全开，声音最厚最满；平滑度极高 → Legato+Reverb，圆润绵延；对称度 = 100 → 和声极度稳定
过渡区（5%–12%）
形状：从底座快速展开
密度快速增加 → 乐器从独奏渐入二重奏；平滑度上升 → 断奏变连奏；和声从简单逐渐丰富
底座（0%–5%）
形状：窄，平稳起点
密度低 → 低音提琴独奏，声音单薄；平滑度中等 → Normal 演奏；对称度高 → 音区居中，和声简洁
08 — TARGET USERS & PAIN POINTS

目标用户
与痛点

🎨 艺术创作者与设计师

面向哪些用户：从事 3D 打印、数字雕塑、参数化设计的创作者。

在什么场景下使用：完成 3D 打印作品后，希望在展览中让观众不仅能看到实物，还能"听见"作品诞生过程。

当前痛点：作品只能以静态实物呈现，创作过程中的运动、决策、随机性完全无法被感知和传达。

🏫 艺术与科技教育场景

面向哪些用户：STEAM 教育教师、艺术科技工作坊导师。

在什么场景下使用：课堂教学中，需要用直观体验帮助学生理解编码/解码、跨媒介转换等抽象概念。

当前痛点：现有工具缺乏从"造物"到"声音"的完整体验链路，学生只能通过公式理解信息编码，无法获得可听、可感的体验。

👥 展览与公共空间观众

面向哪些用户：艺术展览、科技馆的参观者。

在什么场景下使用：在展览中走近 3D 打印展品，通过本系统实时"听见"作品的诞生音乐。

当前痛点：面对展品只能被动观看，无法与作品建立情感连接，缺乏从"旁观者"变为"参与者"的体验。

09 — VALUE & SIGNIFICANCE

价值与意义

🎭

社会价值：让沉默的物体发声

本项目提出了一种全新的艺术语言——不是为物体作曲，而是让物体通过自己的制造过程演奏出属于自己的音乐。这是对"产品即结果"这一工业逻辑的根本性质疑，提醒公众：过程本身也是一种表达。

📈

效率提升：跨媒介教育工具

现有 STEAM 教育中，信息编码、跨媒介转换等概念只能通过公式讲授。本系统将抽象的信息论概念转化为可听、可感的直观体验，学生可以在完整链路中"动手"理解编码与解码，大幅降低认知门槛。

10 — INNOVATION

项目创新点

01

双源编码：G-code + CCD

同时采集"制造过程"和"最终形态"两个维度的数据，共同构成 Object DNA，对物体身份的完整定义。

02

逐行扫描音乐改编

不是"一个作品→一首歌"，而是"一条扫描线→歌曲的 1%"的细粒度控制。每行内含和弦+旋律+低音+弦乐垫音+对位，总计约 1000–1500 个独立音符。

03

CRT 扫描线隐喻

受老式 CRT 电视逐行扫描启发，将二维图像降维为一维时间序列，天然与音乐的时间维度对齐。

04

乐理驱动的歌曲库

28 首经典曲目的 E/C/S/Em 值均基于严格乐理分析（BPM+力度→Energy，和声复杂度→Complexity，重复性→Stability，表现力→Emotion），而非随意标注。

05

闭环叙事：字 → 音乐 → 字

系统支持反向编码：从音乐参数反推抽象视觉形态，形成跨媒介语言系统的完整闭环。

11 — RUNNING SYSTEM

这不是概念，
是可运行的程序

本项目已实现完整的 Python 可运行程序 every_object_sings.py，包含 G-code 解析器、CCD 图片扫描器、28 首歌曲库、numpy 音乐合成引擎（ADSR + 多振荡器 + 卷积混响）和 WAV 输出。

# 安装依赖
$ pip3 install numpy Pillow

# 生成示例 CCD 图片
$ python3 every_object_sings.py --generate-sample-ccd vase_top.png
Sample CCD image saved: vase_top.png

# 完整流程：G-code + CCD → 歌曲
$ python3 every_object_sings.py --gcode vase.gcode --ccd vase_top.png --output 花瓶的歌.wav
