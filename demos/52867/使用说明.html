科室月计划管理系统

使用说明  |  版本 3.0

一、系统概述

科室月计划管理系统用于管理各部门月度工作计划的导入、跟踪、统计和导出。支持多科室、多月份的数据汇总分析，提供可视化图表和进度追踪。新增周计划管理模块，支持周计划导入、编辑、统计图表以及与月计划的双向关联。

核心工作流程：

  1. 1 上传各科室月计划 Excel 文件，系统自动识别表头并提取数据
  2. 2 各科室成员在线填写：周数、实际完成日期、验收方、验收结论、备注，并更新任务状态
  3. 3 通过仪表盘查看统计图表和完成率趋势，或导出汇总数据
  4. 4 通过左侧目录树导航月计划和周计划，支持双向关联和独立管理
单机部署：本工具是一个独立的 HTML 文件，无需服务器，直接双击即可在浏览器中使用。将 科室月计划管理.html 文件发送给同事即可本地使用。

二、数据导入

2.1 批量智能导入（推荐）

  1. 点击「批量智能导入」按钮，选择多个 Excel 文件
  2. 系统从文件名自动识别年月和科室信息
  3. 从 Excel 表头自动识别列映射，支持不同月份格式差异
查重保护：如果对应年月科室的数据已存在，系统会提示"请先删除后重新上传"，不会覆盖已有数据。需要先通过「清除数据」删除旧数据，再重新导入。

2.2 手动导入

  1. 在顶部下拉框中选择年份、月份、科室
  2. 点击「手动导入」按钮，选择单个 Excel 文件
  3. 适用于文件名不符合自动识别规则的情况

2.3 文件命名规范

批量导入时，系统从文件名中自动提取年份、月份、科室信息：

文件名识别结果
2026年六月计划-综合科.xlsx2026年6月 综合科
五月总结-企管科.xlsx（取年份下拉值）年5月 企管科
6月计划-综合科.xlsx（取年份下拉值）年6月 综合科
2026-06-企管科.xlsx2026年6月 企管科
提示：文件名中需包含月份关键词和科室名称（用短横线分隔），年份可选。

2.4 Excel 表头要求

系统自动匹配以下列名关键词，表头可以在 Excel 的前 15 行任意位置：

系统字段匹配的关键词
工作名称包含"工作名称"
完成状态包含"完成状态"、"推进状态"、"工作执行状态"
责任人包含"责任人"、"执行人"
计划开始包含"计划开始"、"工作计划开始"
计划完成包含"计划完成"、"计划结束"
实际完成包含"实际完成"、"实际完成日期"
周数包含"周数"、"计划周"
验收方包含"验收方"、"验收人"、"验收部门"
验收结论包含"验收结论"
备注包含"备注"（不含"验收结论"）
智能匹配：只要 Excel 表头包含上述关键词（无需完全匹配），系统即可自动识别对应列。例如"责任执行人"会匹配到责任人列，"工作计划开始时间"会匹配到计划开始列。日期列（如 Excel 序列号 46174）会自动转换为 "YYYY/MM/DD" 可读格式。

2.5 支持的状态值

  • 按计划完成
  • 延期完成
  • 未完成
  • 进行中
  • 暂停取消

三、目录树导航

3.1 左侧目录结构

系统左侧提供树状目录导航，按"月份 > 功能/周次"两级组织：

  • 计划总览 — 始终在目录顶部，点击后显示全部月份全部科室的汇总数据，页面回到顶部
  • 年份月份节点 — 可折叠，展开后显示该月的功能入口和周次列表
  • 编制月计划 — 点击后切换到该月的任务列表编辑视图
  • X月第X周 — 点击后切换到对应周的计划视图（统计图表 + 任务表格）

3.2 目录自动生成

目录中的月份节点根据已导入的月计划数据自动生成。每月默认生成四周（第一周至第四周），无需手动创建。周次节点后面如果有数据会显示任务数量 badge。

四、周计划管理

4.1 导入周计划

  1. 点击左侧目录树底部的「上传周计划」按钮，选择一个或多个 Excel 文件
  2. 系统从文件名自动识别年月和周次信息
  3. 导入后自动显示在对应月份的周次节点下

4.2 周计划文件命名规范

文件名识别结果
6月第四周（6.22-6.30）.xlsx2026年6月 第四周 W04
7月第一周（7.1-7.10）.xlsx2026年7月 第一周 W01
2026-07-W02.xlsx2026年7月 W02

4.3 周计划表格编辑

周计划视图中，任务列表的所有字段均可直接编辑（点击单元格即可修改）：

  • 任务标题 — 可编辑文本框
  • 负责人 — 可编辑文本框
  • 计划目标 — 可编辑文本框
  • 完成进度 — 下拉选择（未开始 / 进行中 / 已完成）
  • 关键任务简述 — 可编辑文本框
  • 关联计划 — 可编辑文本框
  • 来源部门 / 来源人员 — 可编辑文本框
  • 备注 — 可编辑文本框
新增和删除：周计划表格底部有「+ 新增任务」按钮可添加空白任务行。每行末尾有红色 × 按钮可删除该任务。

4.4 周计划统计图表

周计划视图上方自动显示三种统计图表：

  • 完成进度 — 环形图显示完成率百分比，左侧显示已完成/进行中/未开始的具体数量
  • 人员任务 — 横向堆叠柱状图，按负责人分组显示任务完成情况
  • 来源部门分布 — 环形图显示各部门的任务占比

4.5 关联月计划

周计划中的「关联月计划」列支持两种方式：

  • 自动关联 — 导入周计划时，系统自动匹配月计划中同名任务
  • 手动关联 — 点击每行的「+ 关联」按钮，从弹窗中勾选要关联的月计划任务
  • 查看月计划 — 点击已关联的蓝色链接，跳转到月计划视图并高亮对应任务行
  • 取消关联 — 点击关联名旁边的 × 移除关联
状态独立：周计划的完成进度与月计划的完成状态互相独立，修改一方不会影响另一方。如需关闭月计划任务，请在月计划视图中操作。

五、科室管理

  1. 点击导航栏「科室管理」按钮打开管理面板
  2. 查看已有科室及其成员列表
  3. 输入新科室名称后点击「添加科室」
  4. 每个科室可添加多个成员，成员从导入数据中自动提取
  5. 修改后自动保存

六、数据浏览与筛选

6.1 仪表盘概览

  • 统计卡片 — 显示总任务数、各状态数量和完成率，点击可查看对应状态的任务明细
  • 人员任务卡片 — 显示各成员任务完成情况，点击可查看个人任务列表
  • 饼图 — 汇总视图显示整体完成状态分布；单月视图按科室拆分显示
  • 折线图（汇总时）— 月度完成率趋势，每个数据点标注完成率百分比
  • 柱状图（单月时）— 周数任务数量统计，按状态堆叠着色，点击柱子可弹窗查看该周数的所有任务

6.2 筛选功能

  • 年份筛选 — 下拉框选择年份
  • 月份筛选 — 下拉框选择特定月份，或查看全部
  • 科室筛选 — 下拉框选择特定科室
  • 状态筛选 — 点击状态标签过滤（全部 / 按计划完成 / 延期完成 / 未完成 / 暂停取消）
  • 搜索 — 输入框实时搜索工作名称

筛选条件可叠加使用，如「2026年 + 6月 + 综合科」。

6.3 展开记录

月计划和周计划的任务列表中，每行最后一列有「展开」按钮。点击后在该行下方展开卡片，显示该任务的完整字段内容，可直接编辑。再次点击或展开其他行时自动收起。

6.4 月计划关联周

月计划任务列表中新增了「关联周」列，显示该任务被哪些周计划引用。点击周次标签（如 W01）可直接跳转到对应周计划视图。

6.5 数据目录

点击「选择数据目录」可关联本地文件夹，支持目录模式的批量导入和数据持久化存储。

七、数据编辑

7.1 修改状态

在任务列表的「状态」列使用下拉框修改任务状态，修改后统计数据和图表自动刷新。

7.2 编辑字段

以下字段支持直接在表格中点击编辑（多行文本，支持换行）：

  • 周数 — 填写所属周数
  • 实际完成日期 — 填写实际完成时间
  • 验收方 — 填写验收人 / 验收部门
  • 验收结论 — 填写验收结论
  • 备注 — 填写补充说明
自动保存：修改后约 1 秒自动保存并刷新统计数据和图表。任务列表和所有弹窗中的周数、实际完成日期、验收方、验收结论、备注字段均可直接编辑。任务列表支持横向和纵向滚动，可拖拽文本框右下角调整高度。

八、数据导出

8.1 导出 Excel

点击「导出 Excel」按钮，将当前筛选结果导出为 .xlsx 文件，包含所有任务字段和统计汇总。导出的文件可直接当作模板修改后重新上传。

8.2 导出只读报告

点击「导出只读报告」按钮，生成独立的 HTML 报告文件（含数据和图表），适合分享和归档。

九、数据管理

9.1 清除数据

点击「清除数据」按钮，需连续点击两次确认，清除所有已导入的任务数据。

9.2 数据存储

📁
优先方案：目录存储 选择数据目录后，数据以 JSON 文件保存在指定目录中
🗃
备选方案：浏览器存储 如未选择目录，数据保存在浏览器 IndexedDB 中（清除浏览器数据会丢失）

十、注意事项

  1. 数据安全：修改操作自动保存，建议定期使用「导出只读报告」或「导出 Excel」备份数据
  2. 浏览器兼容：推荐使用 Chrome、Edge 等现代浏览器
  3. 文件分发：将 科室月计划管理.html 直接复制发给同事，双击打开即可使用
  4. 首次使用：需先点击「科室管理」配置科室和成员信息
  5. 批量导入建议：文件名尽量包含年份，避免依赖页面下拉框的默认值
  6. 列映射异常：如导入后字段错位，请检查 Excel 表头是否包含上述关键词
  7. 支持的格式：.xlsx、.xls
  8. 周计划独立管理：周计划的状态（完成进度）与月计划状态独立，不会自动同步
  9. 双向关联：在周计划中关联月计划任务后，月计划列表会显示对应周次标签；删除关联后同步移除
  10. 展开编辑：点击任务行的「展开」按钮可在卡片中编辑完整字段，与表格内编辑效果一致

十一、常见问题

Q：上传文件后没有识别到数据？

A：请检查 Excel 表头是否包含"工作名称"和"完成状态"（或"推进状态"等）关键词。系统需要识别到这两列才能提取数据。表头可以在前 15 行的任意位置。

Q：批量导入提示"无法识别"？

A：请确保文件名中包含月份关键词（如"6月"或"六月"）和科室名称（用短横线分隔，如"-综合科"）。

Q：导入后字段错位（如工作名称显示在了别的列）？

A：这通常是因为 Excel 表头行不在第一行。系统支持前 15 行内任意位置的表头，但如果表头列名中包含可能被误匹配的关键词（如"完成状态（未完成 按计划完成 延期完成 暂停取消）"中包含"计划完成"），可能导致列偏移。请检查表头列名是否清晰。

Q：如何分享给同事使用？

A：直接将 科室月计划管理.html 文件复制或发送给同事，用浏览器打开即可。每位用户的数据独立存储在各自的浏览器中。

Q：导出的 Excel 能否重新导入？

A：可以。导出的 Excel 使用标准格式（第一行是表头），系统可自动识别并重新导入。

Q：修改状态后统计数据没有更新？

A：修改后约 1 秒会自动保存并刷新统计数据和图表。如长时间未刷新，请手动刷新页面。

Q：周计划如何关联月计划？

A：导入周计划时系统会自动匹配同名月计划任务。也可以手动点击周计划表格中的「+ 关联」按钮，从弹窗中选择要关联的月计划任务。关联后可在月计划列表的「关联周」列看到引用关系。

Q：周计划和月计划的完成状态为什么不同步？

A：周计划和月计划的完成状态设计为互相独立。周计划关注本周任务的执行情况（未开始/进行中/已完成），月计划关注月度整体完成状态（按计划完成/延期完成/未完成等）。如需统一管理，请在两个视图中分别更新。
