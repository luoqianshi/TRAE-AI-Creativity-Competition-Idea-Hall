04 原则 PRINCIPLES
  • 01 关键少数不扫所有平台，只盯与你利益相关的 10-20 个实体 × 3-5 个平台 × 特定信号类型。 // focus > coverage · 信号噪声比优先
  • 02 域间隔离每个域独立部署、独立故障。一个域挂了不影响其他，整体可用性 ≠ 单点可用性。 // blast radius · 隔离即韧性
  • 03 共享实体库所有域抽取的实体进入同一个 Neo4j，一条 query 看到跨域全貌，让关联自己浮现。 // single source of truth · 实体为中心
  • 04 人是回路的一部分Human Pass 不是瓶颈，是飞轮的燃料。你修正的每一次，都在让系统变准。 // human-in-the-loop · 反馈即训练
  • 05 终端美学朴素数字美学，CLI 优先，无花哨仪表盘。查询即力量，输出即决策。 // CLI-first · 文本是最稳定的 UI
  • 06 先有数据，再有模型不从 ML 开始。先跑规则积累标注数据，数据够了再加模型，顺序不能反。 // data > model · 规则兜底，模型增益
  • 07 贴地飞行跑在中文互联网上，就面向中文平台的现实设计。境外站超时 → proxy 解决或压根不依赖。 // localize-first · 不为不可达的资源设计
