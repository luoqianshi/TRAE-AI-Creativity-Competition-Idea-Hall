CORE MODULES

五维交叉验证，秒级辨真假

从信息来源到内容一致性，AI 多维度分析每一条灾害信息的可信度。

MODULE 01

来源可信度分析

追溯信息发布者身份，比对官方认证账号、权威媒体和历史可信度记录，评估来源可靠性。

MODULE 02

官方数据交叉验证

实时比对应急管理部、地震局、气象局等官方数据源，核实灾害等级、影响范围等关键数据。

MODULE 03

内容一致性检测

NLP 分析信息内部逻辑是否自洽，关键数据（时间/地点/数字）是否与已知事实矛盾。

MODULE 04

历史谣言库匹配

比对过去 10 年灾害谣言数据库，识别"老谣新传"——很多灾害谣言只是换了地名和时间。

MODULE 05

传播模式异常检测

分析信息传播速度和路径，识别水军批量转发、机器人扩散等异常模式，标记疑似有组织造谣。
