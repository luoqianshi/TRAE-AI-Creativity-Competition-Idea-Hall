[ 01 / CREATIVE INTRO ]

创意 intro

重新定义 AI 与代码的关系——不是辅助，而是原生协作。

01
PROBLEM

想解决什么问题

现有 AI 编程工具依赖 LSP 事后提示、需用户复制粘贴日志、AI 自由发挥导致代码臃肿。 错误从写入到运行时层层漏网，AI 始终在"事后补救"而非"源头拦截"。

02
MOTIVATION

为什么会想到

观察 Cursor / Copilot 的痛点：AI 找文件靠扫描、错误靠用户转述、代码无规模约束。 既然 AI 是主要消费者，就该让所有信息以结构化数据主动喂给它，而不是让它去"看"。

03
PRODUCT

大概是什么产品

一套面向 AI 原生的智能开发环境底层协议， 由智能编辑器、文件图谱、运行时监控三大模块组成， 作为 AI 编程软件的透明底层运行，可独立集成或组合使用。

[ 02 / PAIN POINTS ]

痛点 contrast

没有 aidev 的世界 vs 有 aidev 的世界。

BEFORE 现有 AI 编程工具的困境
  • 语法错误依赖 LSP 事后提示，AI 写完才发现问题，反复修改消耗 token
  • AI 找文件靠全局扫描，理解项目结构需阅读大量文件，耗时耗上下文
  • 后端日志需用户手动复制粘贴给 AI，沟通成本高、信息易丢失
  • 浏览器错误需用户 F12 截图转述，AI 难以获取完整堆栈信息
  • 代码规模无限制，AI 自由发挥导致单文件膨胀，项目难以维护
  • 前后端错误无法关联分析，定位根因需要多轮对话推理
→
AFTER aidev 协议下的新范式
  • 写入时即拦截语法错误，结构化 JSON 返回 AI，当场修复不留到运行时
  • MetaGraph 元数据图谱，AI 毫秒级定位相关文件，无需扫描整个项目
  • RuntimeWatch 包裹进程，stdout/stderr 实时流入 AI，零人工干预
  • 浏览器注入监控脚本，console.error / 网络错误自动捕获推送
  • 2000 行硬性拦截，物理层面强制模块化，AI 无法绕过
  • 前后端错误 + 文件图谱三向关联，一次性定位根本原因

[ 05 / CORE MODULES ]

模块 architecture

三大核心模块，统一向 AI 核心输送结构化数据。

// MODULE_01

SyntaxPad

智能编辑器
→ 写入时拦截错误
  • 三层检查：语法 / 静态逻辑 / AI 深度审查
  • 400ms 延迟同步语法检查，错误当场修复
  • 1500 行提醒，2000 行硬性拦截
  • 支持 Python / JS / HTML / CSS
  • 记事本文件一键导入 + 自动扫描
  • 所有错误以 JSON 结构化返回 AI
LAYER: 3 STATUS: ACTIVE
// MODULE_02

MetaGraph

文件图谱系统
→ 项目结构语义化
  • 文件顶部 @id @desc @links 元数据声明
  • .aimap.json 自动汇总项目级关系图谱
  • AI 查询 API：find / file / affects / graph
  • 毫秒级定位相关文件，无需扫描全项目
  • 元数据由 AI 自动维护，零人工负担
  • dependency_graph + tag_index 双索引
LAYER: 2 STATUS: ACTIVE
// MODULE_03

RuntimeWatch

运行时监控
→ 实时捕获运行错误
  • aidev run 包裹进程，拦截 stdout/stderr
  • 浏览器注入脚本捕获 console / onerror
  • fetch / XHR 4xx 5xx 网络错误自动捕获
  • 前后端错误联动分析，识别同一事件
  • 结合 MetaGraph 定位根本原因
  • 结构化 JSON 实时流入 AI
LAYER: 3 STATUS: ACTIVE

[ 08 / PRINCIPLES ]

原则 doctrine

六条核心设计原则，贯穿整个协议。

PRINCIPLE_01

AI 原生

所有信息以结构化数据返回，不依赖视觉显示，AI 是第一消费者。

PRINCIPLE_02

主动推送

错误主动推送给 AI，不等 AI 来问，从被动响应转为主动喂养。

PRINCIPLE_03

从源拦截

能在写入时解决的，不留到运行时，错误消灭在产生之前。

PRINCIPLE_04

强制约束

关键规则物理执行，AI 无法绕过，2000 行硬限制根治臃肿。

PRINCIPLE_05

轻量集成

不改变现有开发习惯，作为底层透明运行，零侵入接入。

PRINCIPLE_06

自维护

元数据由 AI 自动维护，零人工负担，开发即建档。
