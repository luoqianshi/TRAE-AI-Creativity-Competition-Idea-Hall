Problem

当前爱好者面对的 5 大痛点

如果你也在这些场景中感到疲惫，那么"胡桃木社区"就是为你而建。

01

内容分散 · 来回切换心累

想找同人图要去 LOFTER，想讨论剧情要去贴吧，想追官方消息要去微博……一个晚上切换 5 个 App。

02

算法干扰 · 找好内容很难

各大平台的推荐系统常常塞入低质量、不相关的内容，想找到真正感兴趣的高质量帖子成本越来越高。

03

氛围混杂 · 缺少纯粹圈子

公共社区的评论区鱼龙混杂，缺少一个同好之间可以放松交流、不被"出圈"打扰的纯净角落。

04

功能不完整 · 体验割裂

有些平台只有图片、有些只有短视频，缺少一个能同时承载图文、长文、Wiki、社区互动的综合站点。

05

广告打扰 · 隐私难保障

部分平台强制实名、广告弹窗层出不穷，用户只是想安静地刷个帖子，却被各种打扰搞得疲惫。

Features

完整而克制的功能体系

从账号到互动，从内容到管理，每一个模块都服务于"干净好用"这一核心。

👤

账号与用户体系

完整的注册、登录、个人资料管理，让每个用户都有属于自己的社区身份。

  • 邮箱/手机号注册登录
  • 头像、昵称、个人简介
  • 自定义背景图与主题色
  • 隐私设置与黑名单
✍️

内容发布系统

发帖、上传图片、选择板块、编辑删除——一切都应该是直觉式的操作。

  • 富文本编辑器
  • 多图上传与排版
  • 板块/标签分类
  • 草稿保存与定时发布
💬

互动与社交

点赞、评论、转发、收藏、关注——让同好之间的连接变得自然而轻松。

  • 多级回复评论系统
  • 点赞/转发/收藏/举报
  • 关注作者 & 粉丝列表
  • 动态时间线
🎨

个性化体验

背景图、主题色、夜间模式，随心定制属于自己的社区界面。

  • 自定义背景图（壁纸库）
  • 明亮 / 暗黑主题切换
  • 字体大小与间距调节
  • 内容偏好与推荐设置
🔍

搜索与发现

关键词搜索、板块筛选、热门排序——用最短的路径找到想看的内容。

  • 全站关键词搜索
  • 按板块/时间/热度筛选
  • 热门标签与话题聚合
  • 相关内容智能推荐
🛡️

后台与治理

社区健康离不开完善的管理工具——版主、管理员、内容审核一应俱全。

  • 用户 / 内容 / 板块管理面板
  • 用户-版主-管理员分级权限
  • 删帖、禁言、封停、举报处理
  • 访问量、发帖量等数据统计
💻

Web 端（主）

响应式网页设计，桌面与移动端浏览器都有良好体验，无需下载即可访问。

  • 桌面 / 平板 / 手机三端适配
  • SPA 单页应用，流畅切换
  • 图片懒加载与性能优化
  • PWA 支持，可添加到主屏
📱

Android APK（后续）

在 Web 端功能稳定后，同步开发原生 Android 应用，提供更极致的移动体验。

  • 与 Web 端数据完全互通
  • 原生流畅的滑动体验
  • 消息推送与通知提醒
  • 系统级深色模式适配
Value

为什么要做这件事

一个好的社区不仅是内容的容器，更是文化生长的土壤。

⚡

效率提升

一个入口解决所有二次元内容需求——不再需要在多个 App 之间反复跳转。普通用户省时间，创作者减少多平台维护的成本，集中精力在自己擅长的事情上。

🌱

社区价值

二次元文化仍有被误解、被标签化的倾向。一个积极、友好、有管理的中文社区，能让爱好者们获得更健康的交流空间，促进圈层内部的正向互动。

🎯

差异化定位

与大而全的综合社区不同，胡桃木走"小而美、深而专"的路线。不追求所有用户，而是把真正热爱 ACG 的那一群人服务好。

Roadmap

开发路线图

从创意提案到可运行的 Demo，再到真正的社区产品——一步一步来。

PHASE 1 · 当前

报名 & 创意提案

确定产品方向与核心功能，完成创意提案与报名材料。

PHASE 2

Web 端 MVP

核心板块、注册登录、发帖、点赞评论等基础功能，跑通最小可用版本。

PHASE 3

Web 端完善

加入关注系统、收藏、搜索、后台管理、个性化设置，打磨产品细节。

PHASE 4

Android APK 开发

在 Web 端功能稳定后，同步开发 Android 原生应用，提供更好的移动体验。

PHASE 5

上线与迭代

小范围内测 → 公测 → 根据真实用户反馈持续优化，让产品真正"活"起来。
