✦ 创意概述

"千载同频 · 时空邮局"是一款融合 AI 情感计算与中华古典诗词文化的 Web 应用。用户写下当下的心境，AI 智能识别情绪类型，匹配历史上同频共振的诗人，生成一封穿越时空的"回信"——让李白的豪情、苏轼的豁达、李清照的婉约，成为当代年轻人情绪疗愈的知己。

核心创新点：古籍活化 × 现代心理学 × AI 情感计算
让冰冷的 AI 成为有温度的"跨时空笔友"

✦ 目标用户与痛点

目标用户

  • 18-35 岁都市青年，面临学业、职场、情感压力
  • 对传统文化有兴趣但缺乏深度接触渠道的用户
  • 需要低门槛情绪出口的心理亚健康人群

核心痛点

  • 心理咨询门槛高、费用贵，且存在病耻感
  • 向亲友倾诉有心理负担，担心被评判
  • 短视频/游戏等消遣方式无法真正疏导情绪
  • 传统文化产品形式陈旧，难以触达年轻群体

✦ 产品价值

社会价值

让古籍"活"起来，用 AI 连接古今情感，传承中华优秀传统文化。每一位用户与古人的"对话"，都是一次文化基因的传递。

情绪价值

为零门槛用户提供有温度的情感共鸣与心理慰藉。当用户发现"原来李白也失意过""原来苏轼也迷茫过"，孤独感便消散了。

文化价值

打破"传统文化 = 枯燥"的刻板印象，让古诗词以个性化、互动化的方式走进年轻人生活，实现真正的"古籍活化"。

✦ 技术方案

前端

  • 新中式 UI 设计：宣纸纹理、毛笔字体、朱砂印章、卷轴动效
  • 情绪动态皮肤：5 种情绪对应 5 套视觉主题与音效
  • Canvas 手写模拟：墨汁洇染效果、书写沙沙声

后端

  • 轻量级 API：POST /api/v1/generate_echo
  • 大模型情感分析：System Prompt 精准控制诗人匹配与信件生成
  • 零数据库架构：纯 API 驱动，降低部署成本

AI 核心能力

  • 情绪分类：JOY / LOVE / GRIEF / ZEN / ANGER 五维标签
  • 诗人匹配：基于历史事实的精准人物-情绪映射
  • 信件生成：250-400 字文学化回信，含历史叙事与诗词引用
