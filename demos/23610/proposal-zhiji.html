🎯 解决的问题

你是否也有这样的困扰：

痛点一：手动记账太麻烦

每次消费后都要特意打开 App 手动输入，坚持几天就放弃了

痛点二：账单不知道花在哪

月底看账单只知道花了多少钱，不知道钱花去哪了，也不知道怎么省

✨ 产品介绍

智记是一款面向学生群体的智能记账 + AI 分析工具，主打混合输入 + AI 自动分析，让记账变得简单又有用。

和传统记账 App 不同，智记支持：

💬

聊天式记账

像聊天一样输入"午饭 25"，AI 自动解析分类

🎤

语音记账

说话就能记，不用动手打字

📝

表单记账

传统方式也保留，满足不同习惯

📄

自动导入账单

自动读取微信/支付宝导出的 CSV 账单

📊

AI 分析看板

消费趋势、分类占比可视化一目了然

💡

省钱建议

AI 帮你找出可以优化的消费，告诉你能省多少钱

🎯

智能预算

根据历史数据自动建议预算，超支实时提醒

🚨

异常检测

自动识别异常大额支出，避免冲动消费

❤️

财务健康评分

综合消费习惯打分，给出改进方向

🛠 技术方案

采用纯前端本地存储方案，数据全部存在用户浏览器里，保护隐私，Demo 可直接在线体验：

React 18 + TypeScript Vite TailwindCSS Zustand 状态管理 Chart.js 可视化 IndexedDB 本地存储 Web Speech API 语音识别 纯前端离线运行

技术创新点

  • 纯前端实现，不需要后端服务器，降低部署成本
  • 数据本地化，用户隐私完全可控
  • 多种输入方式混合，适配不同使用场景
  • AI 分析全部在前端完成，即时出结果

🎁 目标用户和价值

目标用户

  • 学生群体，刚开始独立管理生活费
  • 有记账意愿但觉得手动输入太麻烦的人
  • 想知道钱花在哪、想学习理性消费的人
  • 经常用微信支付宝付款，需要批量导入账单

产品价值

  • 降低记账门槛，三种输入方式总有一种适合你
  • 不仅仅是记录，更能给出有用的 AI 分析和建议
  • 培养理性消费习惯，帮助学生攒钱和理财
  • 完全免费、离线可用、隐私保护
