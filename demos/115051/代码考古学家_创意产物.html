router — 路由入口

  • 文件：routes/user.js
  • 职责：定义用户模块的所有 API 端点
  • 导出：Express Router 实例

POST /register — 用户注册

  • 中间件：validateInput (入参校验)
  • 逻辑：检查邮箱是否已存在 → 创建用户 → 哈希密码 → 保存 → 签发 Token
  • 返回：201 + 用户安全信息 + JWT Token

GET /profile — 获取用户信息

  • 中间件：authenticate (身份验证)
  • 逻辑：生成缓存 Key → 查缓存 → 未命中查数据库 → 写入缓存
  • 缓存策略：Cache-Aside，TTL 3600秒

  • 来源：middleware/auth.js
  • 职责：验证 JWT Token，将用户信息挂载到 req.user

Level 1

一句话概括

这是一个基于 Express 的用户服务路由模块，提供用户注册和获取个人信息两个 API，使用了 JWT 身份验证、入参校验和 Redis 缓存策略。

Level 2

关键步骤拆解

注册流程 (POST /register)：
1. validateInput 中间件先校验请求参数格式
2. 调用 User.findByEmail 检查邮箱是否已被注册
3. 如果邮箱已存在，返回 409 冲突
4. 创建 User 实例，调用 hashPassword() 加密密码
5. 保存到数据库，生成 JWT Token，返回 201

查询个人信息流程 (GET /profile)：
1. authenticate 中间件验证 JWT，提取用户 ID
2. 生成缓存 Key：user:{id}:profile
3. 先查 Redis 缓存，命中则直接返回
4. 未命中则查数据库，将结果写入缓存（TTL 1小时）
5. 这是一种典型的 Cache-Aside 缓存策略
