# HiYa! 嗨呀！

HiYa! 是一款无需联网、纯本地存储的正念日记 App。它帮助用户每天记录一件开心的事，用三档“嗨呀”心情等级、四周日历、历史记录、主题换装和随机音效，把记录变成一个轻松的小仪式。

## 用 TRAE 预览


## 产品重点

- 不需要注册、不需要联网、不依赖后端数据库
- 日记默认保存在本机 `localStorage`
- 支持 JSON 导入导出，用户自己管理备份
- 支持日记修改与修改历史
- 支持 10 套疯狂宇宙主题
- 点击按钮随机播放 `hai.mp3`、`ya.mp3`、`haiya.mp3`
