# HiYa! 嗨呀！TRAE 预览说明

推荐使用 TRAE 直接预览 `HiYa_Full_Source/`，这是最接近真实产品的体验方式。

## 预览方式

1. 打开 TRAE。
2. 新建一个本地任务。
3. 选择本提交包中的 `HiYa_Full_Source/` 文件夹。
4. 向 TRAE 输入：

```txt
请帮我预览这个 React/Vite 项目。请先检查 package.json，安装依赖，启动本地开发服务器，并给出可点击的预览入口。请不要修改源码。

如果开发服务器无法启动，请尝试运行生产构建并用本地 HTTP 服务预览 dist 目录。
```

5. TRAE 给出预览入口后，点击打开即可体验。

## 推荐体验内容

- 首次进入欢迎页
- 首页四周日历
- 长按“嗨呀”进入记录页
- 选择三档心情等级
- 写一条日记并保存
- 进入历史页查看记录
- 进入详情页修改日记
- 展开修改历史
- 切换 10 套主题
- 进入设置页体验静音、本地备份和关于信息
- 点击按钮时听随机播放的 `hai.mp3` / `ya.mp3` / `haiya.mp3`

## 产品说明

HiYa! 是一款纯本地正念日记 App。它不需要注册、不需要联网、不依赖后端数据库，日记默认只保存在本机。用户可以通过导出 / 导入 JSON 文件自行管理备份。

## 其他打开方式

如果无法使用 TRAE，可以使用 `Full_App_HTTP_Version/`，让比赛平台在线托管预览，或在本地用 HTTP 服务打开。

`HiYa_Standalone_Demo.html` 仅用于兜底展示，适合快速理解产品概念，但它不是完整产品。
