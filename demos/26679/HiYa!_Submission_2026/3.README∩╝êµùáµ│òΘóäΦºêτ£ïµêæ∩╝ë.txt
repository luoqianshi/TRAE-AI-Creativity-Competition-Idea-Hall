如果不用 TRAE

如果比赛平台支持上传 zip 后在线预览，可以使用 Full_App_HTTP_Version/。

如果评委只想快速看产品概念，可以直接双击：

HiYa_Standalone_Demo.html

【请注意：HiYa_Standalone_Demo.html 是兜底展示版，不是完整 App。】


本地 HTTP 方式预览完整构建版

进入 Full_App_HTTP_Version/ 后启动本地服务：

macOS / Linux：
python3 -m http.server 8080

Windows：
python -m http.server 8080

然后在浏览器打开：
http://localhost:8080
