大赛创意提案详情

1. 创意名称与介绍

创意名称：手绘声图音乐合成器 (Canvas Synth)

想解决什么问题：降低音乐创作的门槛，解决传统电子音乐合成器和编曲软件界面复杂、学习曲线陡峭的问题，让普通人能无障碍地进行音画交互创作。

为什么会想到做这个：源于心理学和艺术中的“联觉”（Synesthesia）现象。人们在听音乐时脑海中常有视觉联想，在作画时也渴望听到线条的律动，这个项目将这两者结合，实现“以画作乐”。

大概是什么产品：这是一款基于 Web Audio API 实现的纯网页端交互式图形化声学乐器网站。

2. 目标用户及痛点

面向哪些用户：非音乐专业的艺术爱好者、音乐与物理声学启蒙教学的师生、以及喜爱新颖交互体验的大众用户。

在什么场景下使用：用户可在工作学习闲暇进行放松性的涂鸦音乐创作，或在中小学科学课堂上作为声学波形与频率的直观教学工具。

当前痛点：如果不用这款产品，用户想把脑海中的画面转化为乐曲，需要经过数月甚至数年的数字音频工作站（DAW）与乐理知识训练；现有的简易音乐网页大多局限于点击固定的虚拟键盘，无法支持用户以涂鸦这种极具自由度的艺术形式进行个性化表达。

3. 价值与意义

效率提升与科普价值：应用全部计算、图像扫描与音频合成均在浏览器本地运行，免去了数据上传服务器的延迟与带宽消耗，实现毫秒级超低延迟反馈。同时以直观的色彩和画线形式将抽象的声学物理波形具象化，大幅度提高了物理与声学跨学科教学的效率与趣味度。
