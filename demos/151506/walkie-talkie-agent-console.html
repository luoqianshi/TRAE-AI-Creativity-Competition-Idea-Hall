WHY · 痛点

Agent 越来越强，
手和眼睛越来越忙。

SPEC · 规格

浏览器原生，
三段链路，只播最有用的声音。

前端 0 依赖即可跑 Demo；后端 Server 把 Agent 事件流翻译成"对讲机语气"。复赛可接 TRAE Agent SDK，再升级语音模型。

VALUE · 价值

快一点、稳一点，
也走得更远一点。

从效率、社会价值、差异化三个角度，WalkieConsole 都不是又一个聊天机器人。

⚡

效率价值

把每天 1–2 小时"被动等待 / 切换碎片"折算成 Agent 协作时间。PTT + 可打断让"边开车边把周报写了"成为日常。

🌍

社会价值

纯语音天然无障碍——视障程序员、手部不便的老人、长时间驾驶的司机，本就应该享有 Agent 协作的红利。

★

差异化定位

填补 voice × Agent console 的明显空白。它是 Agent 时代的"语音终端"，也是 vibe coding 的延伸外设。
