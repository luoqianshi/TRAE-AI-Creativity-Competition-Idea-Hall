Core Features

三端协同，拍摄即归档

ChromaLens 不是一台新硬件，而是一套软件定义的系统。它让退役 Android 手机摇身一变， 成为可远程控制的专业产品拍摄终端。

📱
Android 采集端
Camera2 API 驱动，支持变焦 / 对焦 / 曝光 / 白平衡手动控制。 YUV→JPEG 实时编码，WebSocket 二进制推流至服务端。 兼容 Android 6.0+ 的退役手机。
🖥️
Spring Boot 中枢
WebSocket 帧转发中枢 + REST API。线程安全帧缓冲， 自动照片存储、设备状态广播、摄像头控制指令下发。 轻量部署，不到 50MB 内存占用。
🎨
Vue 管理看板
实时预览 + 远程快门 + 色彩自动提取 + 产品档案管理。 色彩量化算法自动识别 Top 5 主色调（HEX/RGB/占比）。 支持手动标注颜色描述，一键保存产品档案。
🔬
智能色彩分析
16 级通道色彩量化 + 相似色合并 + Top N 归一化输出。 自动输出每张照片的 {hex, rgb, percentage, source} 结构化数据。 为 Pantone/RAL 标准色卡匹配预留算法接口。
📡
实时推流 & 远程控制
手机→服务端→浏览器全链路 WebSocket 通信。 二进制帧协议: [8B 时间戳 + 4B 大小 + N 字节 JPEG]。 支持触摸对焦、曝光手动调节、色温预设。
📋
本地产品档案
产品管理（SKU/名称/类别/备注）+ 照片关联 + 色彩档案。 全部基于浏览器 localStorage，离线可用。 标准 JSON 格式，可导出对接外部 ERP/WMS 系统。
