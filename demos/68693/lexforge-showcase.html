Core Features

不止于优化，更在于管理

全局快捷唤起
Ctrl+Alt+L 在任意应用上方唤起，像输入法一样贴近光标，优化完即走，不抢占焦点。
主题分类管理
新建工作、学习、生活等主题容器，历史与收藏自动归类，告别散落各处的混乱。

20+ 主题配色

Tech Stack

技术架构

现代桌面技术栈，跨平台一致体验。

前端

  • React 18 组件化 UI，TypeScript 强类型
  • Vite 极速 HMR 热更新开发
  • Tailwind CSS 变量驱动的 20 套主题系统
  • Zustand 轻量状态管理 + localStorage 持久化

桌面与引擎

  • Electron 无边框透明窗口 + 全局快捷键 + 托盘常驻
  • Ollama 本地大模型推理，OpenAI 兼容 API
  • IPC contextBridge 安全隔离，文件存储本地化
  • Rule Engine 内置规则引擎兜底，无网络也能用
