📄 《认知负荷理论在阅读中的应用》

认知负荷理论：我们为什么读不进去

Journal of Educational Psychology · 2024 · 阅读时长 12min

认知负荷理论由 Sweller 于 1988 年提出，核心观点是：人类工作记忆的容量极其有限，当信息处理需求超过工作记忆容量时，学习效果就会下降。

阅读本质上是一种信息加工活动。读者需要在解码文字的同时，理解语义、建立联系、提取要点——这一系列操作都会占用认知资源。

当文本结构混乱、术语密集、或读者背景知识不足时，外在认知负荷会急剧上升，导致读者"读了很多，但什么也没记住"。

研究还发现，元认知监控——即读者对自己理解程度的觉察——是深度阅读的关键。然而，大多数读者在阅读时并不会主动进行元认知反思。

因此，设计一种能够降低外在负荷、引导内在加工、促进元认知觉察的阅读工具，可能是解决"读不进去"问题的有效路径。

TECH STACK

技术架构与原理

轻量级浏览器插件，本地运行保障隐私，AI 辅助提升效率

01

浏览器内容脚本注入

以 Chrome/Firefox 扩展形式运行，通过 Content Script 在任意网页和 PDF 阅读器上叠加弹幕层，零侵入原生页面。

WebExtensionShadow DOM
02

本地轻量 NLP 分类模型

基于 DistilBERT 微调的情感-意图联合分类模型，仅 66MB，在浏览器端通过 ONNX Runtime 本地推理，不上传用户数据。

ONNXDistilBERTWASM
03

文本锚点定位系统

每条弹幕自动关联触发位置的文本片段，使用 DOM 路径 + 文本指纹双定位，即使页面重排也能准确回溯。

DOM PathSimHash
04

弹幕渲染引擎

自研 Canvas + CSS 混合渲染管线，支持数百条弹幕同时飘动而不掉帧，智能避让算法避免弹幕重叠遮挡。

Canvas 2DCSS Animation
05

结构化笔记生成

对弹幕集合进行主题聚类（HDBSCAN）和关键句提取（TextRank），自动生成层级化笔记大纲。

HDBSCANTextRank
06

数据本地存储与同步

所有弹幕数据存储在浏览器 IndexedDB 中，支持导出 JSON 备份，可选配端到端加密云同步。

IndexedDBE2EE
