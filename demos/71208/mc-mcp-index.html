方案

一个会"听人话"的服务器插件

MC 服主助手 MCP

基于 Model Context Protocol（MCP）的 Minecraft 服务器插件。 服主在游戏内或控制台用自然语言描述需求，AI 自动转换为合法命令、附上解释， 并可一键执行或回滚。遇到报错能直接粘贴日志，AI 定位原因并给出修复命令。

  • ● 自然语言 → 命令转换（中/英文均可）
  • ● 命令执行前预览 + 风险提示
  • ● 控制台日志粘贴诊断
  • ● 权限/经济/世界插件配置生成
  • ● 常用命令收藏 + 历史回放

对话示例

服主 ▸
给所有人 64 个钻石，再 broadcast 通知一下
助手 ▸
/give @a minecraft:diamond 64
/broadcast 服务器发放钻石，请查收背包
⚠ 将对在线 12 名玩家执行，确认执行？ [Y/n]
服主 ▸
报错：LuckPerms 没有 vault 权限钩子
助手 ▸
/lp group default permission set vault.hook true
# 然后重启 LuckPerms: /lp reload
原因：Vault 桥接未授权，常见于首次安装。
