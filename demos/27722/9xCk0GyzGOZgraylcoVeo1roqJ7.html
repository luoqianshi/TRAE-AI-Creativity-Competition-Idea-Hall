Pain Points

解决什么问题？

当前开发流程中的效率瓶颈与信息孤岛

🔗

信息孤岛

微信沟通内容无法直接转化为可执行任务，需要人工转录到Jira/Trello等工具，再切换到开发环境执行。

⏱

效率瓶颈

单线程串行处理任务，无法利用多核计算资源并行加速。从需求提出到代码交付可能需要数小时甚至数天。

👤

技能门槛高

非技术人员无法直接参与软件开发流程，沟通成本极高。每个创意都需要专业开发者才能实现。

📊

知识断层

开发过程中的决策和变更缺乏自动记录，难以追溯。团队经验无法有效沉淀和复用。

Solution

我们的解决方案

Architecture

六大核心架构模块

企业级、生产就绪的系统设计

🎯

角色流水线

12个专业角色清晰划分职责：接收者→分析师→分配器→架构师→编码者→审查员→测试员→构建员→部署员→文档员→通知员

DAG状态机 并行支持 自动编排
🔒

中断自动恢复

三层恢复策略保障高可用：
• L1 进程级快速恢复 (<100ms)
• L2 检查点持久化 (1-5秒)
• L3 历史记忆重建 (分钟级)

Watchdog守护 Redis+PG双写
🧠

双层记忆系统

STM短期记忆: 环形缓冲区，实时上下文窗口
LTM长期记忆: PostgreSQL+向量数据库，语义检索
自动整合: 高价值事件自动迁移到LTM

遗忘曲线 向量搜索 知识图谱
⚖

全局规则引擎

四层规则体系：
L0 系统级硬规则（安全/资源/合规）
L1 项目级规则（风格/技术栈）
L2 用户级偏好
L3 会话级临时约束

Hook拦截 自动脱敏 危险检测
🔧

技能系统

可插拔能力扩展框架：
内置技能（代码生成/文件操作/搜索/Shell执行）
插件技能（GitHub/Docker/K8s/Jira）
自定义技能（企业内部API封装）

热加载 权限控制 缓存优化
🔗

MCP工具链集成

Model Context Protocol 标准化集成：
GitHub MCP / Database MCP / Browser MCP / Filesystem MCP
跨Server工具编排 + 自动发现 + 权限管理

JSON-RPC 多Server 无限扩展

Features

核心功能特性

💬 微信原生接入

  • ✓支持微信群聊、私聊、公众号多通道
  • ✓iLink Webhook实时消息推送
  • ✓AES-CBC加密解密，安全通信
  • ✓文本/图片/语音/文件多格式识别

⚡ 智能任务调度

  • ✓NLP意图识别 + 参数提取
  • ✓复杂任务自动拆分子任务
  • ✓优先级队列（URGENT/HIGH/NORMAL/LOW）
  • ✓动态扩缩容Worker进程池（3-10个）

💻 多Agent并行协作

  • ✓5-10个Agent进程同时工作
  • ✓专业化分工（Coder/Tester/Reviewer/Deployer）
  • ✓Docker沙箱隔离执行环境
  • ✓自动编译 + 测试 + 打包流水线

🔍 安全防护体系

  • ✓危险命令检测（rm -rf / 等）
  • ✓敏感信息自动脱敏（密码/密钥/手机号）
  • ✓Docker容器隔离（--cap-drop=ALL）
  • ✓频率限制 + 黑名单机制

📊 可观测性

  • ✓Prometheus + Grafana监控面板
  • ✓实时任务进度微信推送
  • ✓AlertManager智能告警
  • ✓Token消耗追踪与成本控制

🚀 一键部署

  • ✓Docker Compose一键启动全部服务
  • ✓systemd开机自启配置
  • ✓Nginx反向代理 + Let's Encrypt SSL
  • ✓完整的部署脚本和文档
