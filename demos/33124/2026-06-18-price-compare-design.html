🛒 多平台比价工具 — 设计文档

日期: 2026-06-18  |  状态: ✓ 已定稿  |  类型: 概念演示 HTML

一、项目概述

生成一个极简现代风格的交互式 HTML 页面，模拟展示"多平台比价工具"的核心功能。使用模拟数据（Mock Data）演示完整的比价流程。

核心理念: "优价雷达" — 一键扫描全网，找到同品牌同规格的最优价格。

二、覆盖范围

平台 (9大平台):

拼多多 抖音 淘宝 京东 速卖通 1688 得物 苏宁易购 本地生活

商品品类: 3C数码、食品生鲜

功能模块 (5项):

  1. 一键搜索比价 — 输入商品自动匹配各平台同款
  2. 历史价格走势 — 30天/90天价格曲线图
  3. 降价提醒 — 关注商品降价徽章和通知
  4. 规格维度对比 — 品牌、颜色、存储、赠品逐项对比
  5. 综合性价比推荐 — 多维度评分排名

三、页面布局结构

F型视觉流，从上到下 6 个区域:

  1. 导航栏 — Logo + 标题 + 设置图标（极简）
  2. 搜索区 — 搜索框 + 自动解析的品牌·规格标签 + 比价按钮
  3. 比价概览 — 9平台价格卡片行（横向滚动），最低价高亮 + 降价徽章
  4. 历史走势 — SVG/Canvas 折线图，支持多平台切换叠加
  5. 规格对比表 — 表格形式，不一致项红色高亮
  6. 性价比排行榜 — 1-3名星级评分 + 推荐理由

四、交互与视觉

视觉风格: 极简现代风

  • 主色: #4a6cf7 (靛蓝) | 辅色: #10b981 (翡翠绿) | 背景: #f8f9fa
  • 大量留白、圆角卡片、柔和投影
  • Inter / -apple-system 无衬线字体

交互行为:

  • 搜索框输入联想 + 回车触发比价
  • 价格卡片行支持水平滚动（拖拽/点按箭头）
  • 点击卡片弹出平台详情浮层
  • 走势图支持多平台折线叠加/隐藏切换
  • 降价格标签带动画闪烁效果

五、数据模拟策略

所有数据在 HTML 中硬编码 Mock 数据集:

  • 预设 3 个演示商品（iPhone 16 Pro Max、AirPods Pro 2、良品铺子坚果礼盒）
  • 每个商品对应9平台的价格、规格、评分数据
  • 历史价格: 30天随机生成数据点，模拟真实涨跌趋势
  • 降价百分比基于"原价-现价"动态计算

六、输出产物

单个 HTML 文件，自包含（无外部依赖）。使用:

  • 原生 JavaScript (ES6+) 实现所有交互
  • CSS 自定义属性实现主题/配色
  • Canvas 或纯 CSS/SVG 实现走势图（无第三方图表库，保持自包含）
