01创意名称 + 创意介绍

东西明明都在，
只是不知道在哪一格。

创意名称：FindItem 寻物。一套让储物盒"被叫到时会亮起来"的软硬件系统。

想解决什么问题

找东西，全靠人脑记

战队赛季箱、电子元件柜、车间工具墙、家里的杂物抽屉——东西都在，可"具体在哪一格"全靠记忆和翻找。越赶时间（比赛 pit 里、deadline 前），越翻不到。

为什么想到做

来自 FRC 6941 战队

一个赛季几百个零件分装在几十个编号箱里。每次比赛维修，"那零件在哪个箱"都要喊一圈、翻一轮。我想做最朴素的东西：你说出要找什么，那个盒子自己亮起来叫你。

大概是什么产品

硬件 + 网页/手机端

一套去中心化零件定位系统。每盒一块 ESP32-C3 接 WS2812 灯带 + 蜂鸣器 + 停止按钮；网页/手机搜索 → 对应盒子亮灯 + 响铃 → 循光找到，按一下熄灭。

02目标用户及痛点

谁会用它，
在什么场景下用。

凡是"东西多、盒子多、还要多人共享"的地方，都缺一个一搜就指给你看的方案。

FRC / VEX 机器人战队

赛季箱零件多，pit 里争分夺秒——本项目正源于此。

学校创客空间 / 电子实验室

元件柜、工具墙共享使用，没人记得别人放哪了。

车间 / 维修站 / 仓库

高频取放、人员流动，靠记忆找物效率低。

家庭重度收纳人群

螺丝、配件、线材分装在几十个透明盒里。

✕没有它时，现在的不方便

  • 在哪一格全靠人记——物品一多记忆就崩，翻找极耗时间，最金贵的比赛/deadline 时间被吃掉。
  • 共享场景尤其乱——别人放的东西自己根本无从找起，相互打断。
  • 贴纸 / Excel 台账——还得人去逐条对照查找，并没省下"走到那一格"的功夫。
  • RFID / 扫码货架——又贵又重，小团队、学校、家庭装不起也用不动。

中间缺一个便宜、能自己装、一搜就指给你看的方案。

03价值与意义

省下的，是你最金贵的时间。

从效率提升与社会价值两个角度。

效率提升

把"翻箱倒柜"变成"看哪个在发光"

<30 秒完成定位，救的是比赛 pit、deadline 前最金贵的时间。多人可同时搜不同零件，每人分到不同颜色的灯，谁找谁一目了然、互不干扰；目录就是一个 items.json，改完即生效，不重启、不重烧固件。

社会价值

几十元就能装，还是一堂 IoT 公开课

单盒物料只要几十元、软硬件全 MIT 开源，小团队、学校、创客空间都装得起、改得动。它本身就是一套完整又好懂的物联网实战——ESP32 固件 / MQTT 通信 / REST 后端 / 前端 / HTTPS + 密码鉴权安全，可直接当作嵌入式与 IoT 入门的真实教学样本。

接地气的去中心化——
让每个最普通的储物盒，
多一点被叫到时会亮起来的能力。
