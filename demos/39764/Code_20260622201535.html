创意名称 & 创意介绍

🎯 想解决什么问题

现代家庭在食材采购后常常忘记及时食用，导致大量食物过期浪费；同时，用户难以科学平衡每日营养摄入，做饭时往往"不知道吃什么"或"不知道怎么做"。

灵感来源于一次大扫除冰箱时发现大量过期食材，心疼之余意识到这是千万家庭的普遍困扰。结合 AI 图像识别与营养学知识，完全可以用技术让"吃饭"这件事变得更智能、更省心。

技术架构概览

🛠️ 技术选型

Flutter / React Native YOLO v8 目标检测 GPT-4 / 文心一言 Firebase / 云开发 Python FastAPI Redis 缓存 MySQL / MongoDB 微信支付 / 支付宝

🏗️ 系统架构

前端层：跨平台移动端（Flutter），支持 iOS / Android，响应式 UI 设计
AI 服务层：图像识别微服务（YOLO v8） + LLM 菜谱推荐引擎（GPT-4 API）
业务服务层：用户管理、食材库存、菜谱匹配、营养计算、购物清单（FastAPI）
数据层：MySQL（结构化数据）+ MongoDB（食谱知识库）+ Redis（缓存热点数据）
第三方集成：生鲜电商 API、营养数据库 API、推送通知服务
