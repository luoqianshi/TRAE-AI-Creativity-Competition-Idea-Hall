// Core Capabilities

核心能力矩阵

六大业务模块 + Agent 智能中枢，覆盖制造企业生产与办公全场景

📋

工单管理

订单→排产→派工→报工→质检→入库，全生命周期闭环。看板 + 甘特图双视图，扫码即达。

📊

排程管理

产能日历 + 产线负载热力图。拖拽调整排期，冲突自动检测高亮，资源利用率一目了然。

✅

质量管理

来料检验 → 过程巡检 → 终检判定。不良品追溯、缺陷帕累托分析，质检标准可配置。

📦

仓储管理

库存台账实时更新，出入库 + 领料退料全追踪。安全库存预警，物料 BOM 关联追溯。

⚙️

设备管理

设备台账 + 点检保养计划 + 故障报修。OEE 综合效率实时统计，异常自动预警。

📝

办公自动化

审批流引擎 + 公告通知 + 文档管理 + 日程协同。请假报销采购，自定义审批链。

// Workshop-First Design

车间友好设计

为不同知识水平的工人打造，降低使用门槛，提升操作效率

🔍

扫码驱动

扫工单/物料/设备二维码，自动跳转操作界面，无需打字搜索

🎤

语音交互

"帮我报工 WO-001，50件" — 说话就能操作，双手不离开产线

👆

触屏大字

一键切换车间模式，≥48px 触控区，大字号 + 颜色状态可视化

🛡️

防错机制

数量超限拦截、物料 BOM 校验、不可逆操作二次确认、离线容错
