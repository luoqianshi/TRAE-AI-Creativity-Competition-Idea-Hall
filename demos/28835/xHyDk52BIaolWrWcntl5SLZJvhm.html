Core Features

核心功能模块

四大模块构建完整的时间交易生态

核心功能

时间拍卖

卖家发布自己的「时间商品」，设置起拍条件。买家以货币、技能、体验、资源或情感进行出价。卖家选择最有意义的出价成交——不一定是价最高的。

发布拍品：时间范围 + 技能标签 + 起拍条件
五种出价类型：货币 / 技能交换 / 体验 / 资源 / 情感
出价可见性：卖家全可见，其他买家仅见类型匿名

即时功能

奇遇匹配

不想等拍卖？即时发布需求，30秒匹配在线卖家。适合"现在就想找人聊聊"的即时场景。基于时间可用性、技能匹配度、地理位置、信用分等多维算法推荐。

即时发布："我有1小时，想找人聊AI产品"
AI智能匹配：3-5个候选卖家推荐
快速履约：卖家30秒内响应，即时开始

时间账本

记录每一段被交易的时间，可视化你的时间价值。累计卖出/买入小时数、帮助人数、学习技能、收入统计。

已卖出48小时
已买入12小时
帮助人数23人
成就徽章5枚

信用体系

基础分60分，实名认证、完成交易、获得好评均可加分。信用等级从青铜到钻石，直接影响匹配优先级与交易权限。

黄金80-89分 · 正常匹配
白银70-79分 · 部分限制
青铜60-69分 · 保护期
