01项目背景与痛点

日常前端项目开发维护中，经常遇到 Git 仓库臃肿、Vite 构建报错、代码合并冲突、线上偶发兼容性异常等问题。

新手排查耗时久、老手重复排障效率低，零散的排障笔记难以复用，遇到同类问题每次都要重新检索资料，严重挤占开发迭代时间。

缺少一个能自动分析报错、给出分步修复方案的 AI 辅助工具。

✨

02解决方案与核心功能

本项目打造前端工程化智能问题排查助手，粘贴报错日志、Git 异常信息、构建报错内容后，AI 自动解析问题根源。

  • 报错一键解析，精准定位代码/配置问题
  • 给出可直接复制的修复命令与修改步骤
  • 留存排障案例库，后续同类问题快速检索复用
  • 大幅降低调试排错成本，提升开发效率
🛠️

03技术框架或实现思路

前端：基于 Vue3 + Vite 搭建交互页面，负责日志粘贴、结果展示、案例管理。

后端：调用 TRAE 大模型能力做自然语言语义解析，匹配前端工程化知识库。

存储：本地采用简单 JSON 持久化保存历史排障记录。

部署：整体轻量化部署，开箱即用，无需复杂环境配置。
