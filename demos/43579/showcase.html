💔 真实故事

有一天我点开自己的粉丝列表，一个一个数——16 个！心里还挺美滋滋的。

后来我拿录屏用程序一跑：OCR 识别 → 去重 → 只剩 13 个了。有些人在不同页码出现了好几次，还有人重复关注。

再仔细看那个被干掉的——「该用户已注销」……原来我连 16 个都没有 😭

这个从 惊喜 → 扎心 的瞬间让我想：干脆做一个工具，让所有人上传粉丝录屏，一键看清自己到底有多少真爱粉。然后生成一面酷炫的感谢墙——谢谢你，还在。

🔄 产品流程

① 上传录屏 → ② 自动抽帧 → ③ OCR 识别 → ④ 智能去重 → ⑤ 手动编辑 → ⑥ 3D 感谢墙
🎬

视频上传 + 抽帧

上传粉丝列表录屏，自动按帧率抽取画面，最多 200 帧，全程浏览器端处理。

🔍

RapidOCR 离线识别

基于 PaddleOCR v4 模型，中文识别精准，置信度可调（50%~99%），自动过滤 UI 噪声。

🧹

智能去重合并

相似名字自动合并（如"崽崽崽"与"崽崽"），按视频帧出现顺序排列，不丢不漏。

✂️

裁剪去噪

可自由裁剪识别区域，排除"关注""回关""作品数"等干扰文字，只留下粉丝名。

✏️

手动修正

识别结果可自由增删改，确认无误后再生成感谢墙，给你最大的掌控感。

🎠

3D 环形感谢墙

所有粉丝卡片环绕成 3D 光环，拖拽旋转、惯性滑动、高亮动效——酷炫且感人。

🖼️

照片墙模式

一键切换为网格照片墙，粉丝名字整齐排列，适合截图分享到朋友圈。

🍿

Demo 视频体验

无需自己录屏，点一下 Demo 按钮即可完整体验全流程，零门槛上手。
