1. 创意名称 + 创意介绍
想解决什么问题？
解决企业中两大核心痛点：① 组织内沟通低效 —— 会议无结构、讨论散、结论散、后续无跟进；② 上下级信息不对称 —— 管理层看不到真实问题，员工不敢说真话。
为什么会想到做这个？
灵感来源于观察到很多企业老板看不清公司的真实问题，上下级欺骗瞒报现象严重。核心逻辑是：收集真实数据 → AI 分析数据 → 得出解决方案。希望让每个员工的声音被听见，让真实问题浮出水面。
大概是什么产品？
一个面向企业端的 数字化转型论坛与组织诊断平台（Web + 小程序），包含结构化讨论、匿名反馈、AI 智能分析三大核心模块。
💬
结构化讨论
问题-观点-证据三层结构，会议时间缩短 70%
🕵️
匿名反馈
可控匿名机制，让真话敢于被说出口
🤖
AI 诊断
大模型生成根因图谱、解决方案与技术指导
👥
2. 目标用户及痛点
面向哪些用户？
核心用户群体：
· 企业决策者（老板、CEO） — 想看清公司真问题，做决策时有客观数据依据
· 部门负责人 — 想组织团队高效讨论，快速形成共识
· 普通员工 — 希望被倾听，希望匿名反馈有安全感
· HR / 组织发展（OD） — 希望做组织诊断与改进
在什么场景下使用？
· 话题讨论场景：公司需要就某个话题（如"如何降低客户投诉率"）组织员工讨论，达成共识并沉淀结论
· 匿名反馈场景：员工对公司/部门有不满、建议，不方便实名说，但希望问题能被看到
· AI 诊断场景：收集到大量讨论内容/匿名反馈后，由 AI 自动生成结构化洞察与解决方案
当前痛点：如果没有你的产品，用户现在会遇到什么不方便？
· 讨论无结构：传统群聊/会议是线性时间线，观点分散，难以梳理和沉淀
· 真话不敢说：担心"枪打出头鸟"，真实问题被掩盖，组织陷入"皇帝的新衣"困境
· 决策无依据：管理者仅凭经验和片面信息做决策，容易误判
· 会议效率低：2小时会议可能毫无结论，问题反复讨论却无法落地
💎
3. 价值与意义
🎯 核心价值主张
✓ 让每个员工的声音被听见 —— 匿名机制让真话敢于说出口，打破上下级信息壁垒
✓ 让真实问题浮出水面 —— AI 自动分析，从海量反馈中识别真正的痛点和根因
✓ 让会议从 2 小时变 20 分钟 —— 结构化讨论+AI 总结，快速达成共识
✓ 让解决方案可落地 —— AI 不仅给结论，还给出执行步骤、责任人建议、里程碑
📊 预期指标
• 月活跃话题数 ≥ 50 • 匿名反馈量 ≥ 200 / 月 • AI 方案采纳率 ≥ 60%
🛠️
4. 技术方案
技术架构
后端：Spring Boot 3.2 + Java 21 + MyBatis-Plus + JWT
前端：Vue 3 + Vite + UniApp（一套代码多端运行）
数据库：MySQL 8.0（结构化数据）+ MongoDB 7（AI 报告/长文本）+ Redis 7（缓存/队列）
AI 接入：豆包 / DeepSeek / OpenAI API
核心数据流
用户发起讨论/提交反馈 → 数据存入数据库 → AI 异步分析（调用大模型） → 生成结构化报告 → 用户查看报告并转为执行任务
安全性设计
· 匿名性保护：`encrypted_user_id` 使用 AES-256-GCM 加密，管理员溯源需审计流程
· 权限控制：基于角色的 RBAC（超级管理员/管理员/员工）
· 输入校验：Bean Validation + 全局 XSS 过滤
· 审计日志：所有敏感操作（如溯源）均写入 audit_log 表
