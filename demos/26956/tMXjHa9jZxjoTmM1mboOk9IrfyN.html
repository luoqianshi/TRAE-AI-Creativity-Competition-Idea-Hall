当前痛点

没有 SwiftCull 之前

摄影师与内容创作者面对海量照片时，长期被困在低效、易错、信息孤岛的工作流中。

🐌

效率极低

Finder 中逐张双击预览，无法批量操作，筛选 1000 张照片可能需要 2-3 小时。

🗂

容易遗漏

RAW 和 JPG 成对存在，手动删除经常漏删配套文件，存储空间无法真正释放。

😵

缺乏智能判断

人眼疲劳后判断标准漂移，好片和废片混在一起难以区分。

🔌

标签不互通

第三方软件的评分和标签无法同步到 Finder，团队协作时信息断层。

🐘

软件臃肿

Lightroom、Capture One 功能全面但启动慢、学习曲线陡峭，对"只想快速筛片"过于沉重。

💸

门槛高昂

专业工具订阅费用高，独立摄影师与爱好者难以承担长期成本。

核心功能

为快筛而生

从极速浏览到智能识别，从原生标签到配对清理，每一个功能都直击真实痛点。

🚀

极速筛选，告别低效

网格视图 + 方向键导航 + 空格键 Quick Look 预览，浏览速度媲美 Finder。拖拽框选、⌘ 点击、⇧ 点击多选，网格大小可调。

🏷️

原生标签，无缝协作

深度集成 macOS Finder 标签系统，自动发现自定义标签名称和颜色。SwiftCull 中标记的标签在 Finder 中同样可见，反之亦然。

🗑️

一键清理，释放空间

自动识别 RAW+JPG+MOV 配对文件，一键删除同时清理所有格式，彻底释放存储空间。筛选结果可一键导出到指定目录。

📷

EXIF 信息，一目了然

自动提取相机型号、镜头、焦距、光圈、快门速度、ISO、拍摄时间等 EXIF 数据，基于 ImageIO 框架纯原生实现。

🛡️

自适应限流

LLM 模式下内置熔断和退避机制，高并发下稳定运行，避免 API 调用失败导致的批量中断。

🧩

三级容错解析

AI 返回结果支持精确 JSON、正则提取、关键字兜底三级解析，最大化兼容大模型输出的不确定性。

AI 能力

双模式 AI 智能筛选

本地 Vision 与云端 LLM 各擅胜场，按场景自由切换，兼顾速度与精度。

本地 · 离线

Apple Vision 分析

无需联网，零成本，秒级响应。基于 Apple 原生 Vision 框架在设备本地完成所有计算。

  • 模糊检测：拉普拉斯方差 + FFT
  • 曝光分析：直方图过曝 / 欠曝检测
  • 人脸质量：Vision 闭眼 / 人脸模糊
  • 构图评分：显著区 + 三分法
  • 相似分组：FeaturePrint 视觉距离
云端 · 精准

LLM 远程分析

调用远程视觉大模型逐张判定，精度最高，返回中文废片理由，便于用户理解与复核。

  • 极速模式：小图 + 精简 prompt + 高并发
  • 标准模式：速度与精度平衡
  • 严格模式：大图 + 完整 prompt + 高精度
  • 自适应限流：熔断 + 退避机制
  • 三级容错：JSON / 正则 / 关键字兜底
