CUDOS 守门人

五维专家评估

创新性、方法有效性、证据置信度、产业应用前景、学术规范 — 五个子智能体并行评审，全面覆盖论文质量维度。

🎯

DEA 期刊匹配

数据包络分析（DEA）定量评估论文与目标期刊的匹配度，Bootstrap 置信区间让推荐更有底气。

🧠

检索-评估耦合

RAG 不是简单引用，而是评审判断的核心触发机制。语义 + 关键词混合检索，让证据支撑更扎实。

🔄

🚀 快速安装

5 分钟上手，零配置烦恼

支持 pip 安装、Docker 部署、源码安装三种方式，总有一种适合你

🎯 最简单的方式 — 一行命令搞定

安装核心包 + 所有可选依赖（LLM、Server、RAG）

$ pip install wuya-agents[all]

或者按需安装：

# 仅核心功能
$ pip install wuya-agents
# 核心 + LLM 支持
$ pip install wuya-agents[llm]
# 核心 + API 服务
$ pip install wuya-agents[server]

配置环境变量后直接使用：

$ export OPENAI_API_KEY=sk-xxx
$ wuya evaluate paper.pdf -o report.md

🐳 容器化部署 — 一键启动完整服务

包含 WuYa + ChromaDB 向量数据库的完整环境

# 克隆仓库
$ git clone https://github.com/yuyang-rgb094/wuya.git
$ cd wuya
# 启动所有服务
$ docker compose up -d

在容器内运行评审：

$ docker compose exec wuya wuya evaluate /app/data/paper.pdf

💻 源码安装 — 开发者首选

适合需要修改源码或参与贡献的开发者

$ git clone https://github.com/yuyang-rgb094/wuya.git
$ cd wuya
$ pip install -e ".[all]"
# 运行测试
$ pytest tests/ -v
