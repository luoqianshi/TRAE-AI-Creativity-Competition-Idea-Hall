双模式设计

🎬

剧情模式

每个角色都有独立的世界线，剧情倒计时营造紧张氛围。AI会主动向你发起话题，汇报潜伏进展，根据你的引导改变行动。你们互有好感，你是TA唯一透露过真实身份的人类。

💝

聊天模式

满好感的温馨日常，彻底卸下剧情负担。角色会毫无保留地撒娇、捉弄，也会袒露内心真实的温柔与守护欲。不主动提及末日、宿命等沉重话题，永远把你放在第一位。

技术架构

K

Kotlin + Jetpack Compose

现代Android开发框架，声明式UI，代码简洁高效

R

Room Database

本地数据持久化，聊天记录、角色信息、剧情状态实时存储

D

DeepSeek API

强大的AI对话模型，支持角色扮演和剧情创作

N

Navigation Compose

现代化导航组件，实现流畅的页面切换

交互流程

1

选择模式与角色

用户在首页选择剧情模式或聊天模式，然后挑选心仪的角色

2

进入聊天界面

加载角色专属背景和历史聊天记录，剧情模式显示倒计时面板

3

发送消息

用户输入消息，系统构建包含角色设定和历史上下文的Prompt

4

AI回复

调用DeepSeek API获取角色风格的回复，保存到本地数据库

5

主动推送

每30秒轮询检查，AI根据剧情进度主动发送消息
