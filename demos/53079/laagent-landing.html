行业痛点

工具割裂、隐私担忧、
AI 只能说不能做

现有设计工具的三大顽疾，LAagent 逐一击破

🔄

工具割裂

聊天用 ChatGPT、画图用 Figma、生图用 Midjourney。三个工具来回切换，上下文反复丢失，复制粘贴到手酸。创作流程被工具打断，灵感转瞬即逝。

🔒

隐私担忧

创作内容、提示词、企业方案全部上传云端。敏感设计稿不敢用 AI 辅助，生怕泄露给第三方。隐私顾虑成了使用 AI 的最大障碍。

🤲

AI 不落地

AI 只能返回文字描述或图片链接，无法直接在你的画布上操作元素。生成结果还要手动拖到画板里，调整位置、大小，费时费力。

核心功能

一个工作台，三件事全搞定

白板、对话、生图 — 不再切换工具，不再丢失上下文

🎨

无限白板画布

基于 Konva 的无限画布，支持矩形、椭圆、文字、便签、图片、箭头六种节点。自由缩放、拖拽平移、图层管理，像 Figma 一样顺滑。

react-konva 无限画布 图层管理
💬

AI 对话 + 工具调用

Agent 通过 WebSocket 流式输出，支持 function calling 和 JSON 文本双模式工具调用。多步推理循环，自动判断是否需要继续执行。

WebSocket function calling 多步推理
✨

ComfyUI 图像生成

文生图 + 图生图双模式，Agent 直接调用本机 ComfyUI 生成图片并自动落盘。支持自定义工作流 JSON，景观平面图、效果图一键生成。

txt2img img2img 自定义工作流
📦

本地资产管理

上传图片和生成图片统一归档，Agent 可通过 asset_list 工具查询资产。项目以 JSON 格式持久化保存，随时重新打开继续创作。

资产归档 JSON 持久化 项目复用
创意亮点

不只是集成，而是重构

四个让 LAagent 不同于其他设计工具的核心设计

01

Agent 直接操作画布

whiteboard_patch
Agent 通过 whiteboard_patch 工具直接在白板上增删改节点 — 添加文字、绘制形状、放置图片，不需要人工搬运。AI 说了就做，做完全自动落到画布上。
02

完全本地化，零云端依赖

100% localhost
LM Studio 做推理，ComfyUI 做生图，所有流量仅在 localhost 流动。文件 IO 限定在 ./data/ 目录，pathlib 防越权。提示词、作品、对话历史完全不离开你的电脑。
03

流式输出 + 工具可视化

WebSocket streaming
delta 增量文本、tool_call 工具调用、tool_result 执行结果、canvas_patch 画布变更 — 每一步都实时推送到前端，工具调用过程可折叠查看输入输出 JSON。
04

双模式工具调用兼容

fallback parsing
优先使用 OpenAI 标准 function calling；当本地模型不支持时，自动从文本中解析 ```json 代码块或 <tool_call> 标签里的工具调用指令。兼容所有本地模型。
工作流程

从一句话到画布落地

Agent 自主完成多步工具调用，用户只需描述需求

💬

用户输入需求

在右侧 AI 对话面板用自然语言描述创作需求，比如"生成一张现代风格庭院的景观平面图"。

WS → { "type": "user_message", "text": "生成景观平面图" }
🧠

Agent 理解 + 规划

LM Studio 流式返回推理文本和 tool_calls。Agent 注入项目上下文（画布尺寸、已有节点），决定调用哪些工具。

WS ← { "type": "delta", "content": "正在为你生成..." }
WS ← { "type": "tool_call", "name": "comfyui_generate" }
✨

执行工具调用

调用本机 ComfyUI 文生图，图片落盘到 generated 目录。然后自动调用 whiteboard_patch 把图片添加到白板画布。

WS ← { "type": "tool_result", "name": "comfyui_generate", "result": { "filename": "img_20260701.png" } }
WS ← { "type": "canvas_patch", "op": "add", "node": { "type": "image", "src": "/api/assets/img_..." } }
🎯

结果回投白板

图片自动出现在白板上，Agent 根据工具结果判断是否成功，继续下一步或返回说明。用户可继续对话微调，如"植物再丰富点"。

WS ← { "type": "done" }
WS ← { "type": "delta", "content": "图片已添加到白板，需要调整吗？" }
