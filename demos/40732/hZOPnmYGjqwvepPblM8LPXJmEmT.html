// 零碎抽屉 v1.0.0
零碎先扔进来，正事再抽出去

每个人的手机里都有个"数字杂物间"——收藏夹里一堆再也没打开过的链接、备忘录里一堆"以后再说"的念头、截图相册里一堆不知道当时为什么存的东西。JunkDrawer 就是一个专门装这些零碎的抽屉，但它不止于装——当你真的想把某件"零碎"变成正事时，抽上桌面，它帮你排进日程。

想解决什么问题：看到有用的东西就存，存完就忘；脑子里冒出"改天要做"的念头，等想起来了已经想不起来了。

为什么会想到做这个：刷到一个健身视频，顺手扔进收藏夹，两周后翻到，第一反应不是"太好了"，而是"早干嘛去了"。我发现我缺的不是"存东西的地方"，而是有人跟我说一句："喂，你之前不是说要练这个吗？"

大概是什么产品：Web 应用（移动端适配），核心交互就两个动作："扔进去"和"抽出来"。

class JunkDrawer {
  constructor() {
    this.drawer = [];
    this.desktop = [];
  }
  
  throwIn(item) {
    this.drawer.push({
      content: item,
      time: new Date().toISOString()
    });
    return "Item stored in drawer";
  }
  
  pullOut(id) {
    const item = this.drawer.find(i => i.id === id);
    if (item) {
      this.desktop.push({
        ...item,
        schedule: aiEstimateTime(item)
      });
      return "Item pulled to desktop";
    }
  }
}

价值与意义 //

⚡ EFFICIENCY
效率提升
把"看到好东西"和"真正去做"中间那截断掉的路接上。不再需要手动整理、复制粘贴、切来切去排计划。从"先存着"到"到时候做"，中间只隔一个手势。
❤️ PERSONAL
个人价值
它不替你决定什么该做，它只做一件事：帮你记住你自己想做的事。对那些"脑子里塞满东西、又什么都没记住"的人来说，这不是效率工具，是给自己少添点堵。每个人的生活都有个乱糟糟的零碎抽屉。JunkDrawer 帮你把它打开，也帮你把它清空。
