技术实现思路

技术架构（创意方案）

以下为产品原型的技术选型思路，用于创意展示，不代表已实现。

前

前端

HTML + CSS + JavaScript，构建用户拍照上传、报告展示等交互界面

后

后端

FastAPI，处理图片上传、调用 AI 模型、生成评估结果并返回前端

数

数据存储

MySQL 存储用户数据和评估记录，支持历史对比查询

缓

缓存与异步

Redis 缓存热点数据，Celery 处理耗时的 AI 分析任务

姿

人体姿态识别

MediaPipe Pose 提取人体关键点坐标，计算关节角度

智

智能分析

基于关键点角度和规则进行体态判断，LLM 生成通俗易懂的分析说明和训练建议
