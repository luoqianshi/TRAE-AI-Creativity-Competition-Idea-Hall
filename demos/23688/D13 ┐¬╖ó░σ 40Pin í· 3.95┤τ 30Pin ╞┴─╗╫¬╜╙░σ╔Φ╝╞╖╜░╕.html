3.3 RY3730 输出电压校验

OVP电压校验:
RY3730 OVP阈值 ≈ 18V ~ 20V
目标屏 Vf = 13.2V
裕量 = 18V - 13.2V = 4.8V (> 3V, 安全)

升压比校验:
输入: VCC_5V = 5V
输出: LED_Vf = 13.2V
升压比 = 13.2 / 5 = 2.64 (RY3730支持最大升压比 ~4x, OK)

输入电流估算:
P_out = 13.2V × 40mA = 0.528W
P_in = P_out / η ≈ 0.528W / 0.85 = 0.621W
I_in = 0.621W / 5V = 124mA (远小于0.5A保险丝, OK)

3.4 电流检测电阻计算 (关键修改!)

原理: RY3730 通过检测电阻(R23)上的压降来恒定LED电流
    VFB = ILED × Rsense
    RY3730 VFB(ref) ≈ 0.3V (典型值，请查阅数据手册确认)

原设计 (110mA):
    R23 = VFB / ILED = 0.3V / 0.11A = 2.7Ω → 实际使用 2.2Ω (约136mA，有裕量)

目标设计 (40mA):
    R_sense = VFB / ILED = 0.3V / 0.04A = 7.5Ω

推荐值:
    使用 6.8Ω (E24标准值) → 实际电流 = 0.3V / 6.8Ω = 44mA
    或使用 8.2Ω (E24标准值) → 实际电流 = 0.3V / 8.2Ω = 37mA
    或使用 7.5Ω (E96精密值) → 实际电流 = 0.3V / 7.5Ω = 40mA (精确)

推荐方案: 使用 7.5Ω / 0805 / 1%精度 电阻
    功率校验: P = I²R = 0.04² × 7.5 = 0.012W (0805额定0.125W, 充裕)
重要: 更换D13板上的R23电阻!
D13开发板原装 R23 = 2.2Ω (对应110mA)。接入30Pin屏幕前，必须将R23更换为 7.5Ω。
如果不更换，背光电流将达到 ~136mA，超过屏幕额定40mA的 3.4倍，会立即烧毁LED!

3.5 OVP分压电阻校验

RY3730 OVP引脚阈值 ≈ 1.2V (典型值)
OVP分压网络: Vout × R_bottom / (R_top + R_bottom) = 1.2V

设定OVP触发点为 17V (略高于13.2V，留足裕量):
    17V × R_bottom / (R_top + R_bottom) = 1.2V
    R_top / R_bottom = (17 - 1.2) / 1.2 = 13.17

推荐值: R_bottom = 10kΩ, R_top = 130kΩ (或 120kΩ + 10kΩ串联 = 130kΩ)
    实际OVP触发: 1.2V × (130k + 10k) / 10k = 16.8V

注意: D13原装OVP分压电阻需根据实际输出电压重新计算。
若原装OVP已设定为18V以上，则可以保持原样不改(13.2V < 18V, 不会触发OVP)。

六、PCB 设计要点

MIPI高速信号布线规则:
1. 所有差分对 (D0+/-, D1+/-, CLK+/-) 必须 100Ω 差分阻抗 控制
2. 差分对内等长匹配: < 5mil (对内skew)
3. 差分对间等长匹配: < 200mil (CLK vs Data)
4. 差分对两侧 0.2mm 净空区，不放置任何其他走线
5. GND参考层必须完整连续，不在MIPI走线下方开槽
6. 过孔数量最小化，MIPI走线尽量在同一层
电源和背光布线规则:
1. LED+/LED- 走线宽度 ≥ 0.3mm (承载40mA以上)
2. 电源走线宽度 ≥ 0.2mm
3. 背光LED-的7.5Ω检测电阻 尽量靠近30Pin FPC连接器
4. 去耦电容 就近放置 在对应电源引脚旁边
5. GND使用大面积铺铜，确保低阻抗回路
转接板外形建议:
1. 板厚: 0.8mm 或 1.0mm (便于弯折安装)
2. 尺寸: 约 30mm x 15mm (紧凑型设计)
3. 40Pin FPC和30Pin FPC连接器分别放在板的两端
4. 触摸FPC连接器放在侧面
5. 四角留安装孔 (M2, 2.2mm)

七、上电调试步骤

步骤操作预期结果异常处理
1确认R23已更换为7.5Ω万用表测量阻值正确若仍为2.2Ω, 禁止上电!
2测量各路电源对地阻值无短路 (阻值>100Ω)检查焊接和连接器接触
3上电，测量IOVCC1.8V ± 5%检查VDDIO连接
4测量VCI, VCC3.3V ± 5%检查VDD1连接
5测量RESET引脚高电平 (~1.8V)检查R1上拉电阻
6使能背光PWMLED+输出 ~13.2V检查升压电路和OVP
7测量LED电流~40mA调整Rsense阻值
8MIPI初始化屏幕显示正常检查差分对连接和阻抗
9触摸功能测试I2C通讯正常检查I2C上拉和电平

八、设计总结

设计项方案风险等级
电源 (1.8V/3.3V)从D13 40Pin VDDIO/VDD1直连，加去耦电容低风险
MIPI信号 (2-Lane)D0/D1/CLK直连，D2/D3不接，100Ω差分走线低风险
背光驱动 (40mA/13.2V)更换D13 R23为7.5Ω，复用RY3730升压电路中风险 - 需验证OVP裕量
触摸面板通过独立FPC连接D13 I2C2，1.8V电平低风险
LCD复位直连MIPI_RESET，加上拉和去耦低风险
