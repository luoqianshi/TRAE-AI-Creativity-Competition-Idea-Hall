小组作业分工侠

AI 自动拆解任务、智能分配组员、追踪进度、一键合并——终结"谁做多少"的世纪难题

💡 创意介绍

想解决什么问题：大学小组作业中，任务分配不透明、进度不同步、成果合并混乱，导致"搭便车"现象严重，认真做的同学吃亏，最终质量参差不齐。


为什么会想到做这个：每次小组作业都是"灾难现场"——有人全程消失最后Copy一份，有人做到凌晨三点还在改格式。一个5000字的报告，光合并排版就要花2小时。这种痛苦每个大学生都懂。


大概是什么产品：一个 Web 端 + 小程序的智能项目协作平台，核心是 AI 驱动的任务拆解与进度管理。

🎯 目标用户及痛点

面向哪些用户：大学生（本科 + 研究生），尤其是需要频繁完成小组作业、课程项目、毕业设计协作的学生群体。


使用场景：

  • 课程小组报告：3-6人协作完成一份调研报告或PPT
  • 编程项目：多人协作开发一个软件/网站
  • 毕业设计：跨专业组队完成综合项目
  • 竞赛团队：数学建模、创新创业大赛等

⚙️ 核心功能

🤖

AI 智能拆解

输入作业要求，AI 自动拆解为可执行的子任务，估算每个任务的工作量和依赖关系。

👥

智能分配

根据组员的擅长领域、历史表现、当前负载，AI 推荐最优任务分配方案。

📊

进度看板

可视化任务看板，实时同步每个人的进度，自动识别延期风险并预警。

📄

一键合并

统一格式模板，各成员在线编辑，最终一键合并为完整文档，自动排版。

⏰

智能催促

根据 Deadline 自动发送提醒，对拖延的组员升级催促频率，不用你当"恶人"。

📈

贡献度评分

基于提交时间、质量、修改次数等维度，自动生成贡献度报告，支持老师查看。

🔧 技术方案

  • 前端：React + TypeScript，响应式设计，支持 Web + 小程序
  • 后端：Node.js + Express，RESTful API + WebSocket 实时同步
  • AI 引擎：大语言模型 API（任务拆解、智能分配、文档合并）
  • 数据库：PostgreSQL（用户/项目数据）+ Redis（实时状态缓存）
  • 文档处理：Pandoc + 自研排版引擎，支持 Word/PPT/PDF 输出
