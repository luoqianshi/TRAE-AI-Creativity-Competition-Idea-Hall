真实痛点

长辈用手机，难在哪里？

不是不想学，而是不敢点。每一个弹窗、每一次支付，都可能成为他们心中的坎。

不敢点，怕点错

手机界面复杂，按钮太小，长辈担心点错后找不到返回的路，甚至造成不可挽回的后果。

怕扣钱，怕被骗

扫码支付、网上挂号涉及金钱和个人信息，长辈担心误操作导致财产损失。

没人教，教了忘

子女工作忙碌，社区资源有限，长辈学了一遍很快又忘记，缺乏反复练习的机会。

字太小，看不清

普通 App 字体小、对比度低，对视力退化的长辈极不友好，操作困难重重。

解决方案

我们的核心设计

从长辈的真实需求出发，打造低压力、高安全、易上手的学习环境。

零风险练习

所有操作均为模拟，不会真的转账、下单或预约，长辈可以放心大胆地点。

大字友好

默认 20px 以上大字体，按钮足够大，支持一键放大和高对比度模式。

一步一教

每一步都有明确提示和箭头引导，像有人在身边手把手教一样。

错了不怕

点错时温柔提醒，告诉用户为什么错、应该点哪里，绝不打击信心。

可反复练习

同一个场景可以无限重来，直到完全掌握，进度自动保存在本地。

技术亮点

纯前端实现，零成本落地

无需服务器、无需接口、无需付费，一个网页就能运行，随时随地帮助长辈。

纯前端架构

HTML + CSS + JavaScript 构建的单页应用，无需后端服务器，无需任何安装步骤，在浏览器中打开即可开始练习。

本地数据存储

练习进度、个人设置和徽章成就都保存在浏览器的 localStorage 中，不上传云端、不登录账号，充分保护长辈隐私。

智能语音播报

基于浏览器原生 SpeechSynthesis API，每步操作都有温柔语音朗读提示，视力不好的长辈也能轻松跟上节奏。

家属自定义设置

子女或志愿者可提前设置姓名、字体大小、高对比度、常用联系人、WiFi 名称和医院名称，让练习更贴近真实生活。

场景可扩展设计

采用 JSON 数据驱动场景配置，每个练习场景都可独立定义步骤和目标，后续可快速添加扫码乘车、在线挂号等更多内容。

全终端响应适配

从电脑到大屏手机、小屏手机都做了响应式优化，按钮和文字自动调整大小，确保长辈在任何设备上都能看清、点准。

零风险安全练习

所有支付、挂号、聊天场景均为模拟环境，不会产生真实扣款、真实预约或真实信息发送，长辈可以放心大胆地点按。

零成本落地部署

无需购买服务器、无需申请接口、无需支付任何费用，单个 HTML 文件即可运行，也支持一键部署到 GitHub Pages。
