Skill 规则纠偏

领域知识 · 内生校准

通过 TRAE Skill 机制注入领域专业规则，对AI生成的知识进行逻辑一致性和合规性校验：

  • API版本兼容规则：自动识别和标注版本冲突
  • 领域术语规范：统一专业术语表述，消除歧义
  • 逻辑一致性检查：发现知识条目间的矛盾
  • 最佳实践规则：基于社区共识标注推荐方案
  • 过时检测规则：标记已废弃的技术和方案

MCP 源头校验

外部数据 · 实时验证

通过 MCP 协议对接权威外部数据源，实时验证知识条目的准确性和时效性：

  • 官方文档MCP：对接官方API文档，实时校验接口
  • 学术数据库MCP：交叉验证论文引用和数据
  • 版本信息MCP：检测依赖包版本和变更日志
  • 权威标准MCP：对照行业标准验证合规性
  • 可信度评分：综合多源验证结果给出0-100评分

产品特性
知衡的四大核心能力
01

智能采集引擎

AI Agent 自动识别领域关键词，从文档、网页、API文档等多源收集知识，自动摘要、分类、结构化存储。支持用户自定义采集源和优先级。

02

Skill 规则引擎

每个领域对应一套 Skill 规则集，内置版本兼容、术语规范、逻辑一致性等校验逻辑。知识入库前必须通过规则引擎审查，不合规条目自动标记或拦截。

03

MCP 验证网络

通过 MCP 协议对接官方文档、学术库、标准库等权威数据源，对知识条目进行实时交叉验证，输出可信度评分和验证溯源链接。

04

知识保鲜巡检

已入库知识定期自动重验，发现过期或冲突信息及时预警并触发更新流程，确保知识库"始终可信，永不过时"。
