01 // Problem

三个核心缺口

01
更低的记录摩擦
对于碎片化的灵感和随记场景，UI 层面仍然具备交互突破口。头部产品如 flomo、闪念贝壳等，语音录入都需要"点击按钮 → 开始录音"的交互路径。而在真实场景中，灵感往往在产生后 5 秒内就会消失，任何多出来的半步操作都是致命的摩擦。"按住说话"比"点击后录音"更快、更符合直觉，也更贴合人类产生灵感时的本能反应——但这个交互在现有主流产品中几乎不存在。
02
灵感的"生长"
国内头部产品聚焦于记录本身，这和备忘录或记录于纸笔没有本质上的区别。当前同赛道产品缺少基于科学方法论的灵感发散与衍生等功能，APP 容易成为灵感的"坟墓"。灵感不是笔记，灵感是一颗种子，它需要被延伸、被融合、被连接到意想不到的领域。我们需要一种工具，不只是帮"存"灵感，更能帮灵感生长——让灵感与灵感之间产生化学反应，让人类与 AI 相互协同，越积越多，相辅相成。
03
认知"地图"
现有工具中的灵感组织方式长期局限于列表、文件夹或标签体系，使用者只能以线性或层级化的方式浏览自己的知识，无法直观感知灵感之间的远近关系与连接密度。而人类的大脑天然是空间化的——我们更容易记住"某座岛在地图的东北角"，而不是"某条笔记在第三个文件夹里"。通过将灵感库投影为一张可生长的认知世界地图，灵感之间的语义关联被转化为物理空间距离，使用者可以像探索真实地图一样浏览自己的思想疆域，在视觉化的空间中主动发现跨域连接、寻找思维盲区，这是传统笔记工具无法提供的认知维度。
02 // Origin

为什么想做灵感胶囊

Personal
一名设计师与发散者的困境

我曾是一名工作了一段时间的设计师，也是一名设计类的在读硕士。需要灵感与选题的场景在我的工作学习中十分常见。同时我也是一个注意力天然难以集中、容易产生思维跳跃的人，这在通常观念中被认为是不适宜的。然而，随着工作中设计选题场景逐渐增多，一款足以跟上思维跳跃甚至能与使用者相互协作的灵感工具显得尤为重要。

Insight
人类无法想象完全没见过的东西

在我们大多数的科幻作品中，外星人的外形设定通常也是"人"——就如同大多数鬼神电影一般，造物主、妖魔、鬼怪，通常为我们熟悉的认知事物的变体。新灵感往往诞生于旧灵感、旧事物的相互连接之中。市面上没有一款工具真正理解"灵感"的特殊性：它来得快、去得更快；它往往不是完整的句子，而是一个碎片；它真正的价值不在于单独存在，而在于与其他灵感的碰撞。

04 // Differentiation

核心差异化

按住说话，快人 0.5 步

比点击录音更快的交互路径。灵感产生后 5 秒内不记录就会消失，0.5 步的摩擦降低足以决定一个想法的存亡。

02

灵感生长，而非静态存储

AI 多智能体引擎驱动的灵感延伸、融合与跨域连接。记录不是终点，而是生长的起点。灵感生灵感，相辅相成。

03

认知地图，空间化思维

将灵感库投影为可生长的认知世界地图。像探索真实地图一样浏览自己的思想疆域，在视觉空间中发现隐藏的跨域连接。

05 // Features

特色功能

Chat

灵感群聊 · 碰撞产生新视角

把几个相关灵感同时拉入群聊，让它们在 AI 调解下互相碰撞、辩论。支持多种控制模式：自动分发、单人聚焦、多方碰撞、主控收束、主控直答。让灵感像真人一样对话，产生意想不到的化学反应。

Synthesis

综合思考 · 多模型取长补短

开启综合思考模式，让多个 AI 模型从不同或相同角度同时分析一个问题。不是选一个模型，而是集众智之长，输出比任何单一模型更全面的洞见。

Tuning

跨域调频 · 打破信息茧房

从现有知识库出发，主动寻找认知圈外的新鲜连接。不是"更懂你"的投喂，而是"带你离开舒适区"的探索。对抗算法时代的信息窄化。

Map

认知地图 · 视觉化思想疆域

灵感之间的语义关联被转化为物理空间距离。岛屿、航道、信号点、灯塔——像探索真实地图一样探索自己的认知版图，发现思维盲区与跨域机会。
