产品概述

先诊断，再画像，后导航

「家投智图」定位为面向 25-45 岁城市家庭的 Web 端智能投资学习 SaaS 平台。产品核心理念是：通过 LLM 帮用户看清自己的财务底子和能力短板，再为其量身定制一条可执行的学习路径，形成"诊断 → 画像 → 导航 → 学习 → 跟踪"的完整闭环。

目标用户

痛点与方案

面向 25-45 岁城市家庭，有投资需求但金融素养薄弱；有稳定收入、具备基础理财意识但缺乏系统投资方法论。

用户核心痛点

  • !

    信息过载

    面对海量金融资讯、理财课程、投资产品，不知道从哪里开始，容易陷入选择瘫痪。

  • !

    学习路径缺失

    碎片化学习零散知识，缺乏从入门到进阶的体系化路径指引，学了不会用。

  • !

    缺乏能力诊断

    不清楚自己的财务健康度、风险承受力、投资认知水平，无法判断该学什么。

家投智图解决方案

  • ✓

    智能诊断先行

    5-8 分钟场景化问卷，自动生成财务健康度评分 + 风险承受力档位 + 认知等级，精准定位起点。

  • ✓

    个性化学习地图

    LLM 基于你的能力缺口，从 200+ 知识节点中自动编排 3-5 条渐进式学习路线，每步清晰可执行。

  • ✓

    自适应动态调整

    学习过程中实时检测薄弱点，自动降级难度或补充前置知识，确保不走弯路。

技术亮点

架构与算法

React + FastAPI + PostgreSQL + LLM 分层模型，构建"评估→画像→地图"核心算法闭环。

⚙

技术栈选型

前端 React 18 + TypeScript + Vite + Ant Design 5 + ECharts 5。后端 Python FastAPI + SQLAlchemy 2.0 + Celery + Redis。数据库 PostgreSQL 15 + pgvector 向量检索。

◉

LLM 分层模型策略

评估解析用 GPT-4o-mini(低延迟低成本)，画像分析用 GPT-4o(深度推理)，学习地图生成为核心场景(GPT-4o/Claude 3.5)，AI问答用轻量模型。按场景分层控制成本与质量。

◈

RAG 知识增强

结构化投资知识文档切分 Chunk 存入 pgvector，混合检索(BM25 + 语义向量) + RRF 融合排序 + Cross-Encoder 重排序，生成内容标注知识来源，降低 LLM 幻觉。

◆

学习地图生成算法

四阶段流程：候选节点筛选(规则引擎) → 混合评分排序(加权公式 w1×GapAlign + w2×DAGPosition + w3×UserPreference + w4×Difficulty) → LLM 路径编排 → 拓扑校验入库。

◇

双信号自适应调整

测验退化(同标签连续3次<60%) + 学习停滞(停留>预估3倍)联合触发。LLM分析根因后自动降级/补前置/替代路线，全程自动化。

◎

LLM 输出校验层

所有面向用户的 LLM 输出经过双重校验：JSON Schema 结构化校验 + Python 规则引擎业务校验，拦截投资建议类表述，确保合规安全。

核心壁垒："评估→画像→地图→自适应"的算法闭环是竞品难以快速复制的差异化能力。通用 AI 可以回答问题但不能诊断、不能规划路径；传统投教平台有内容但无个性化；泛理财平台有课程但无系统评估。家投智图将三者整合为数据驱动的闭环，并具备数据飞轮效应——用户越多，画像模型越精准，地图质量越高，吸引更多用户。
