痛点

多平台时代，小卖家正在被工具割裂

数据在 5 个后台、话术要写 5 遍、客服不会"我的货"、月费 5 个工具叠加超预算——这些问题我们一个一个都遇到过。

⌘

数据孤岛

抖音卡片点击在 A 系统，线索在 B 系统，订单在 C 系统，运营每天要在 3 个后台手动搬运数据。

⧉

重复劳动

同一套"商品 + 链接 + 卖点 + 价格"话术要在 5 个平台分别写 5 遍，每次改价都要 5 个后台逐一修改。

⌬

AI 难落地

通用 SaaS 客服不会"我的货"；自己写 AI 又得懂 RAG、向量库、Embedding、Prompt 工程，对中小卖家极不友好。

$

预算受限

单点工具累计月费动辄 500–1500 元，5 个工具叠加后远超中小卖家承受范围。

⏱

夜间断流

21:00–次日 9:00 客户咨询不能直接断流，但小团队无人值守，订单白白流失。

⚙

复盘低效

想做月度跨平台 ROI 复盘？得手动 Excel 拼接 5 个后台的导出数据，半天起步。

方案

三级降级 + 全链路串联

一条消息从进来到出去，依次经过「关键词规则 → RAG 语义检索 → SystemPrompt 兜底 → 默认话术」四道闸门，确保永远有合理回复。

TIER · 01

关键词规则匹配

正则 + 模糊匹配 + 优先级排序，0 延迟响应"价格、尺码、发货"等高频问。

  • 支持精确/模糊/正则多模式
  • 多关键词组合 + 优先级
  • 时间段 / 频率限制 / 防刷
TIER · 02

RAG 语义检索

商品文档 → 分片 → Embedding → Milvus 入索引 → 命中即答，准确率可量化、可观测。

  • TopK=5 · ScoreThreshold=0.7
  • 知识库命中可视化回灌
  • 低分文档自动提醒补充
TIER · 03

SystemPrompt 兜底

RAG 失败时拼接产品 SystemPrompt 调 LLM；再失败则回退到默认话术，永远不让会话掉地上。

  • 多 LLM 适配（OpenAI / 国产大模型）
  • 参数可调 + 调用日志可审计
  • 成本 / 延迟 / 成功率三指标
