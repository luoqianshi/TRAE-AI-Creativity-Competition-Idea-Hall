Product Vision

让每个 OC 都有自己的故事

我们相信，每个原创角色都值得被认真对待。OC Garden 不只是管理工具，更是你与角色共同成长的花园。

档案管理 — 系统化管理角色的每一个细节，从基础设定到复杂关系网，一目了然。

轻度养成 — 通过日常互动让 OC "活"起来，解锁成长阶段，收获专属剧情。

社区分享 — 在安全的隐私控制下，向世界展示你最骄傲的创作，找到志同道合的伙伴。

Core Features

四大核心模块

从创作到养成，从管理到分享，覆盖 OC 生命周期的每一个环节。

📚

角色档案

全方位记录 OC 的设定：基础信息、外观、性格标签、MBTI、关系图谱、时间线。支持多媒体附件，让档案立体丰满。

🌱

养成系统

每日互动、心情系统、成长阶段解锁。完成任务获得养成道具，看着你的 OC 从幼年一步步成长。

🌎

社区广场

OC 展示主页、话题广场、活动赛事。精细的隐私分级控制，让你自由决定每个角色的可见范围。

✍

创作工具

设定书编辑器、关系图谱可视化、随机生成器、模板市场。从灵感捕捉到成品输出，一站式创作支持。

🔐

隐私优先

本地优先存储，数据完全属于你。可选云同步，端到端加密。支持 JSON/PNG 导出，随时带走全部数据。

🔄

多端同步

Web 端先行，后续扩展至 iOS 与 Android。无论在家还是外出，你的 OC 花园始终随行。

Roadmap

产品路线图

从 MVP 到完整生态，分五个阶段稳步推进，每一步都聚焦真实用户价值。

Phase 1

MVP 验证

第 0-2 个月

  • 角色档案创建与编辑
  • 基础外观与性格设定
  • 本地数据存储
  • 简易导出功能

Phase 2

养成上线

第 2-4 个月

  • 每日互动与心情系统
  • 成长阶段与解锁机制
  • 任务与成就系统
  • 基础统计面板

Phase 3

社区初版

第 4-6 个月

  • OC 公开主页
  • 话题广场与基础互动
  • 隐私分级控制
  • 关注/粉丝系统

Phase 4

工具深化

第 6-9 个月

  • 关系图谱可视化
  • 设定书编辑器
  • 随机生成器
  • 模板市场

Phase 5

多端扩展

第 9-12 个月

  • 移动端 App（iOS/Android）
  • 云同步与多端协同
  • 实时协作功能
  • 创作者变现支持
