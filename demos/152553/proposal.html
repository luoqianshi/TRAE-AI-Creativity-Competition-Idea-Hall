创意介绍

想解决什么问题

AI Agent（如 Claude Code、Cursor）在大型代码库中面临三大困境：找不到符号——Grep 只能文本匹配，无法理解代码结构；看不懂依赖——调用关系、影响范围完全不可见；改了不知道影响谁——修改一个函数可能引入未知的回归缺陷。

为什么会想到做这个

随着 AI Agent 编码能力爆发式增长，它们急需一种基础设施来理解代码库的结构化关系，而不仅仅是读取文件内容。Call Warden 的灵感来自"代码知识图谱"——将符号、调用关系、变更历史、安全漏洞持久化存储，为 Agent 提供精确的符号级查询能力。

产品形态

CLI 工具 + MCP Server。基于 tree-sitter 多语言解析引擎 + SQLite 结构化存储 + Rust PyO3 性能加速构建。通过 MCP 协议与任何支持 MCP 的 AI Agent 集成，无需绑定特定 IDE 或 Agent。

[02]

目标用户及痛点

面向用户

所有支持 MCP 协议的 AI Agent（Claude Code、Cursor、Kimi Code、Gemini CLI）及 AI 辅助开发者。不绑定特定 IDE 或 Agent，通用适配。

使用场景

大型代码库重构、安全审计、代码理解、变更影响分析、多步骤任务编排。适用于 10 万行+的企业级代码库。

当前痛点

Token 浪费（读取整个文件理解一个函数）、盲目修改（不知道影响范围）、无结构化理解（Grep 无法理解调用链）、无安全审计、无任务追踪、无风险感知（不知道哪些代码变更最频繁最易出 bug）。
