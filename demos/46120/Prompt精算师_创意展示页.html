Prompt 精算师

一个帮你在发给 AI 之前自动精简输入内容、实时统计 Token 消耗、并管理对话历史复用的效率工具，让每一分钱都花在刀刃上。

🎯 想解决什么问题

当下使用 ChatGPT、Claude、TRAE 等 AI 工具时，用户往往将整段代码、长日志或重复上下文直接发给模型，导致单次对话消耗大量 Token。对于免费用户，这意味着更快触达每日上限；对于付费用户，这意味着账单膨胀。

当前市场上缺乏一款轻量、直观的工具，能在发送前帮用户预估消耗、精简冗余输入，同时沉淀高频问题的答案，减少重复调用。

📦 产品形态与核心功能

初版形态：独立网页工具

用户将待发送给 AI 的长文本粘贴到工具中，系统自动分析 Token 消耗，提供一键精简和预算预警。精简后的内容可直接复制回 AI 对话页面使用。

后续迭代：浏览器插件 / IDE 插件

在 TRAE、ChatGPT、Claude 等网页版 AI 工具的输入框旁嵌入精简按钮，实现无缝省 Token 体验，减少复制粘贴步骤。

核心功能（MVP）

Token 实时计数

输入内容时实时显示 Token 消耗量，可设预算上限，超限时自动提醒

一键精简 规则引擎

去除冗余停用词、合并重复表述、提取关键代码片段，支持预览和编辑

历史问答库

本地存储高频提问与答案，关键词匹配快速检索，减少重复调用

远期规划

  • 智能精简模型：引入轻量模型，实现更精准的语义压缩
  • 语义检索历史库：基于向量检索实现更智能的历史问答匹配
  • 多平台插件：覆盖 TRAE IDE、VS Code、浏览器等主流场景

👥 目标用户与使用场景

目标用户 核心场景 当前痛点
学生 / 独立开发者 使用免费额度进行编程辅助、论文润色 Token 消耗快，每日上限频繁触顶
程序员 / 技术工作者 粘贴长代码、报错日志给 AI 分析 冗长输入导致单次对话消耗过高
内容创作者 / 研究人员 上传长文档、调研材料进行摘要或改写 缺乏用量感知，月底账单不可控
小型团队负责人 管理团队成员的 AI 工具预算 无法追踪成员用量，预算超支

💡 价值与意义

省

省钱

通过规则精简减少 10%-30% 冗余输入，免费用户延长可用时长，付费用户压缩月度成本

时

省时

历史问答库快速匹配重复问题，避免重复调用模型等待

心

省心

实时 Token 计数 + 预算预警，用量透明可控

社会价值

  • 降低 AI 工具使用门槛，帮助更多学生和独立开发者以更低成本享受 AI 辅助
  • 减少无意义的模型计算资源浪费，推动更可持续的 AI 使用方式

🏪 商业模式

免费版：基础 Token 计数 + 规则精简 + 本地历史库（个人使用，无数量限制）

高级版（订阅制）：智能语义精简 + 云端历史库同步 + 团队用量管理看板

推广策略：联合技术社区、开源活动提供免费高级版体验期，以使用量驱动模型训练和数据积累，再向高频用户转化付费。

⭐ 差异化优势

  • 专注输入端优化：市面上大多数工具聚焦模型侧（换更便宜的模型），我们是少数专注输入端减量的产品
  • 透明可控：所有精简操作可预览、可编辑，用户始终掌握最终发送的内容
  • 渐进式体验：从网页工具到插件的演进路径清晰，每一版都有独立可用的价值
  • 数据沉淀：历史问答库让省下的不只是 Token，还有反复等待模型回复的时间

🚀 大赛 MVP 交付目标

在赛事周期内，交付一个可独立运行的网页版工具，包含：

  • Token 实时计数（支持主流模型 tokenizer）

  • 本地历史问答库（关键词匹配，支持增删查）
  • 用量统计看板（今日/本周消耗趋势）
