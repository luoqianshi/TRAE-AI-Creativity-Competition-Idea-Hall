用户登录模块改造

1. 支持手机号 + 验证码登录，验证码有效期 5 分钟，每日发送上限 10 次
2. 新增微信一键登录，需绑定已有账号或自动注册
3. 登录失败 5 次后锁定账号 30 分钟，支持邮箱解锁
4. 登录态采用 JWT，Access Token 有效期 2 小时，Refresh Token 有效期 7 天

AI 解析结果

功能点 1：手机号验证码登录 — 需实现发送/校验接口，含频率限制与过期机制
功能点 2：微信登录 — OAuth2.0 授权流程 + 账号绑定/注册逻辑
安全规则：错误锁定策略（5次/30分钟）+ 邮箱解锁通道
Token 策略：双 Token 机制，Access 2h / Refresh 7d，需考虑续期与失效
非功能性：三端兼容，接口 RT < 200ms，建议缓存验证码状态
