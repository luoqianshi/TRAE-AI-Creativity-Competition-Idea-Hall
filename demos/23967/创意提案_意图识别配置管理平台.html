创意介绍

Part 01

想解决什么问题：在企业客服、智能助手、语音交互等场景中，用户的自然语言输入千变万化。传统的意图识别系统配置繁琐，依赖工程师硬编码规则，业务人员无法自主维护；同时缺乏对低置信度样本的有效反馈机制，导致系统上线后难以持续优化，识别准确率随时间停滞不前。

为什么会想到做这个：在参与多个智能对话系统项目的过程中，我发现意图配置和维护占据了整个项目 40% 以上的人力成本。业务人员常常抱怨"我想加一个关键词为什么还要找研发排期"，而运维团队则被大量的误识别工单淹没。现有的配置工具要么过于简陋（只有关键词列表），要么过于昂贵（商业产品年费数十万）。我希望用一个可视化的配置平台，让业务人员也能像"发微博一样"管理意图。

大概是什么产品：一个基于 Web 的意图配置管理平台（SaaS 化管理后台），采用 Vue 3 + TypeScript + Ant Design Vue 构建，提供四层漏斗匹配引擎、可视化配置面板、实时测试沙箱、版本历史回溯、以及基于聚类和 LLM 的自学习看板五大核心能力。

😫

核心功能

Part 02

平台提供 6 大功能模块，覆盖意图配置的完整生命周期 —— 从创建、配置、测试到上线后的持续学习与版本管理。

📋

意图管理中心

统一的意图列表视图，支持按优先级、状态、匹配层筛选。每个意图可配置关键词、正则规则、示例语句、同义词组、槽位和否定条件，实现意图的"六维立体化"配置。

🔑

关键词 / 同义词库

全局同义词组管理，实现"退款=退钱=退货"等语义等价映射。配合可视化的关键词命中统计，帮助运营人员快速发现高频表达并优化配置。

📐

正则规则引擎

支持灵活的正则表达式规则配置，带有规则命中次数统计和在线测试工具，让高级用户可以精确控制复杂句式的匹配逻辑。

🧪

四层漏斗测试沙箱

L1关键词 → L2正则规则 → L3向量匹配 → L4大模型的分层匹配，实时展示每层的命中结果与置信度。命中即终止，在保证准确率的同时降低 LLM 调用成本。

🧠

自学习看板

自动采集低置信度样本，通过聚类分析发现潜在新意图，结合 LLM 自动提取关键词建议。从"日志采集 → 聚类分析 → LLM 辅助标注 → 人工审核 → 回灌意图库"形成完整闭环。

📜

版本历史与回滚

每次配置变更自动生成版本快照，支持 Diff 对比查看变更内容，一键回滚到历史版本。让意图配置也能像代码一样被版本化管理。

价值与意义

Part 04

⚡ 效率提升

从 3 天 → 3 分钟

传统的意图配置需要"业务方提需求 → 研发排期 → 修改代码 → 测试上线"的长链路，平均响应周期 3 天以上。使用本平台后，业务人员可在可视化界面中自主完成意图配置，配合实时测试沙箱验证效果，整个过程可在 3 分钟内完成上线，效率提升超过 100 倍。

同时，四层漏斗架构让 80% 以上的高频请求在 L1/L2 层快速返回，无需调用 LLM，单次识别成本降低 90%，为企业节省大量大模型 API 调用费用。

🌱 社会价值

让 AI 对话更懂人

智能客服是企业与用户沟通的重要窗口，但现有系统常常"答非所问"，让用户在机器客服中兜圈后不得不转人工。本平台通过降低意图配置门槛和提供持续自学习能力，让更多中小企业也能拥有高质量的智能对话系统。

同时，平台的自学习看板让系统可以从用户真实输入中不断"进化"，让智能客服真正"理解"用户意图，减少用户 frustration，提升整体服务体验。核心功能将提供 免费开源版本，降低中小企业使用 AI 对话系统的技术门槛。
