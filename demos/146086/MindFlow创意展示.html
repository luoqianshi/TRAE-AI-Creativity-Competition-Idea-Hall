核心功能

六大核心能力

从知识图谱生成到测验巩固，一站式学习辅助工具

AI 知识图谱生成

输入主题，自动生成三层结构脉络图，每个节点标注难度等级、前置知识和预计学习时长，支持缩放拖拽交互

学习路径规划

按难度排序（入门→中级→进阶→实战）生成推荐学习路线，以时间线形式清晰展示，让学习有方向

智能测验

针对选中节点实时生成 5 道单选题，逐题作答、自动批改并显示解析，支持答题历史记录与回看

学习笔记生成

为每个节点生成 Markdown 格式学习笔记，支持一键复制，AI 首次生成后自动缓存

导出中心

支持导出 JSON 数据结构和 PNG 高清图片，方便分享和存档，所有历史图谱自动保存

双引擎 + 智能缓存

内置 Mock 引擎，无需配置即可离线运行；节点讲解、学习路径首次生成后缓存到 SQLite，大幅节省 API 调用成本
