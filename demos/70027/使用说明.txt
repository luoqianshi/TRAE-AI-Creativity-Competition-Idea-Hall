PhotoSelect v1.0.0 — 轻量级图片筛选工具
=============================================

【如何运行】
  双击 PhotoSelect.exe 即可启动。

【操作说明】

  快捷键          功能                    适用模式
  ─────────────────────────────────────────────────
  F / 工具栏      选择文件夹              全局
  Space / 工具栏  切换大图/网格视图       全局
  Esc             退出大图回到网格         大图
  ← →             切换选中 / 翻页         网格=切换, 大图=翻页
  ↓               标记移除                全局
  ↑               恢复                    全局
  0 1 2 3 4 5    评分 (主键盘+小键盘)     全局
  R / 工具栏      按星级排序              全局
  S / 工具栏      保存到文件夹(弹窗选择)    全局
  工具栏          清空(二次确认)           全局
  鼠标滚轮        网格=滚动, 大图=翻页     全局
  鼠标点击左右半区 翻页                    大图

【评分说明】
  0 = ☆☆☆☆☆ (无星)
  5 = ★★★★★ (满星)

【编译（如需从源码编译）】
  cd src
  cargo build --release
  编译产物在 src\target\release\photoselect.exe

【支持格式】
  jpg / jpeg / png / webp / bmp / gif / tiff

【限制】
  - 单文件最大 100MB
  - 最多 10,000 张图片
  - 扫描深度最大 5 层
