01. 创意名称 + 创意介绍

创意名称

食余剧场

想解决什么问题

  • 每天打开冰箱盯着零散食材发呆，陷入「今晚吃什么」的决策瘫痪。
  • 独居 / 加班人群把做饭变成「生存任务」，丢失了生活仪式感。
  • 传统菜谱 App 需要用户主动想「我想吃什么」，反而让零散食材更焦虑。

为什么会想到做这个

我自己就是典型的「冰箱里有啥吃啥」选手。越是疲惫，越希望吃饭这件事能好玩一点。于是想象：如果冰箱是个嘴硬心软的毒舌室友，食材们会吵架、会争宠，最后还能像开盲盒一样变出一道有故事的菜——那么「今晚吃什么」就不再是负担，而是一场小剧场。

大概是什么产品

一个纯前端、单文件 HTML 的互动创意 Demo。用户打开冰箱、选择食材，看食材以第一人称「吵架 / 吐槽」，点击「开盲盒」后由冰箱管家「冰冰」调解，生成一道带稀有度、故事、做法、氛围方案的「和解料理」。

核心差异点：我们不是在做「根据食材推荐菜谱」的工具，而是在做一套「剩菜小剧场」的情绪算法——冰箱有人格、食材有台词、搭配有故事、吃饭有仪式感。

02. 核心体验流程

1 打开页面：傲娇冰箱根据时间段说风凉话
2 打开冰箱：食材按门架 / 冷藏 / 冷冻三层陈列
3 选择 2-5 样食材：食材开始第一人称「吵架 / 吐槽」
4 冰箱调解：盲盒动画，开出带稀有度的「和解料理」
5 菜品卡片：正面故事 / 灵魂解读，背面做法 / 氛围方案
6 收藏 / 分享 / 敲打冰箱换一道

03. 与同类创意的差异性

目前常见的「剩菜盲盒」类创意多停留在「输入食材 → 随机/AI 推荐菜谱」。我们在以下维度做了差异化：

🧊

冰箱人格化

冰箱不是容器，而是有情绪、有记忆、会吐槽的毒舌室友。

🥬

食材角色化

20 种食材各有性格，霸道、卑微、社牛、懒癌，会互动吐槽。

🎭

吵架小剧场

选中食材后触发第一人称弹幕，营造「冰箱里的修罗场」。

⏰

时间感知

根据早/中/晚/深夜推荐不同类型的料理和台词。

🎴

稀有度叙事

离谱搭配不再被否定，而是包装成史诗 / 传说 / 神话级体验。

🕯️

氛围方案

不仅给做法，还给配剧、音乐、灯光、仪式感动作。

04. 目标用户及痛点

面向哪些用户

  • 独居青年、租房党、加班族
  • 喜欢新奇互动、对做饭缺乏灵感但愿意尝试的用户
  • 想降低决策成本、给日常加点趣味的人

在什么场景下使用

下班 / 深夜打开冰箱，不知道如何处理剩余食材时；或是周末想整点花活、用现有食材「开盲盒」找灵感时。

当前痛点

  • 冰箱里有菜，但脑子里没菜——不知道能组合出什么。
  • 做饭变成「生存任务」，毫无期待感，很容易直接点外卖。
  • 菜谱 App 是「人找菜」，面对零散食材反而更焦虑。

05. 价值与意义

效率提升

把「看菜下饭」的决策交给趣味算法，降低「今晚吃什么」的思考成本，让用户更快进入动手阶段，减少决策瘫痪带来的内耗。

情绪价值（核心）

通过傲娇冰箱、食材角色化、稀有度特效和氛围方案，把做饭变成一场有剧本、有惊喜的互动体验。让用户重新与日常食物建立情感连接——哪怕只是煮一碗面，也能变成一天里值得期待的小剧场。

社会价值

用趣味方式鼓励用户消耗冰箱现有食材，减少因「不知道怎么做」而造成的食物浪费，同时缓解独居人群的生活孤独感。

06. 产品亮点细节

冰箱人设：冰冰

大清早的……你确定不是来拿饮料的？
又是你。行吧，今天陪你糊弄一顿。
臣妾肚子里真的没货了，您看着办吧。

稀有度体系

普通 稀有 史诗 传说 神话

离谱搭配不会被嫌弃，反而可能开出传说级卡片。例如西瓜皮 + 老干妈 + 燕麦 + 鸡蛋 → 《西瓜皮老干妈燕麦饼》。

氛围方案（不仅做菜，更做仪式）

  • 配剧：根据菜品气质推荐影视
  • 音乐：推荐吃饭时的氛围音
  • 灯光：给出光线建议
  • 仪式感动作：比如「掀开锅盖深吸一口气」

07. 技术说明

  • 形态：单文件 HTML5 互动 Demo

  • 存储：localStorage 本地持久化食材与收藏册
  • 运行：双击即可离线运行，无需网络
