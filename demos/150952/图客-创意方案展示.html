01 / PROBLEM

我们发现了什么问题

建筑设计协作长期处于割裂状态，图纸、沟通、会议分散在不同工具中，效率低下且难以追溯

📐
PROBLEM 01

图纸沟通脱节

修改意见散落在微信群、邮件和口头传达中，与图纸完全脱节。设计师需要反复对照聊天记录确认修改位置，事后难以追溯决策过程，版本混乱成常态。

🗣️
PROBLEM 02

会议与图纸割裂

开会需要单独使用会议软件，屏幕共享时图纸清晰度差，无法实时标注。会议结论与图纸位置无法关联，会后整理纪要耗时且容易遗漏关键信息。

📱
PROBLEM 03

移动办公受限

外出勘察、出差途中无法查看 DWG 图纸、GLB 模型、PDF 施工图等设计文件，项目动态全靠同事截图转发。紧急修改意见无法及时查看，响应速度慢，影响项目整体进度。

03
异步沟通

03 / CORE FEATURES

核心功能

四大核心能力构成图客的产品骨架，覆盖设计协作全流程

FEATURE 01

图纸在线预览

支持 DWG 建筑平面图、GLB 三维模型、PDF 施工图纸、图片等设计师日常使用的全部格式，无需安装专业软件即可在浏览器中查看。支持图层管理、尺寸测量、比例缩放，移动端流畅浏览不设限。

DWG GLB PDF 图片 图层管理 尺寸测量 比例缩放
FEATURE 02

实时批注与协作

团队成员可直接在图纸上标注问题、绘制箭头、添加文字备注，所有批注实时同步到每位协作者。支持语音批注，让复杂修改意图传达更精准。

实时同步 箭头绘制 文字备注 语音批注
FEATURE 03

项目会议

共享图纸屏幕的远程会议，参会人员可同时查看和标注图纸，讨论过程实时呈现。会议结论自动关联到图纸位置，会后可随时回溯定位。

屏幕共享 同屏标注 结论关联 会议回溯
FEATURE 04

设备选型对比

多方案参数对比表格，自动生成比选报告，支持推荐方案标注和 PDF 导出。帮助工程师和甲方快速做出决策，不再为方案对比耗费大量时间。

参数对比 自动报告 方案标注 PDF 导出

06 / VALUE

价值与意义

从效率提升到商业空间，图客为建筑产业链带来数字化协作新范式

⚡

效率提升

将图纸预览（DWG/GLB/PDF/图片）、坐标锚固标注、异步语音沟通、会议四个环节整合到一个平台，消除工具切换成本。设计师不再需要在微信、邮件、CAD 软件之间反复跳转，所有协作上下文集中在图纸本身的精确坐标上。

8-10h 中型项目每周节省沟通协调时间
📈

商业价值

建筑业总产值约 32 万亿元，设计从业人员超 100 万人。图客定位为"建筑产业链的精准沟通枢纽"，切入图纸沟通这一高频刚需场景。设计师免费使用沉淀协作数据，未来通过 SaaS 订阅和厂家精准触达服务实现商业化，可延伸至施工管理、运维阶段，构建全生命周期协作平台。

万亿+ 建筑产业链年产值 · 数字化渗透空间广阔
06.5 / COMPARISON

为何现有工具不够用

没有任何产品，在设计师图纸讨论的瞬间"精准在场"

工具 关键缺陷 图纸坐标锚固 异步沟通
微信 / 钉钉 以对话为锚点，不涉及图纸坐标，信息错位率高 ✕ ✓
腾讯会议 需全员同时在线，复杂图纸实时共享体验差 ✕ ✕
广联达 · 构件坞 面向 BIM 建模，选型场景错位，沟通非核心功能 部分 ✕
飞书文档 图文分离，无法与 CAD 图纸深度绑定交互 ✕ ✓
图客 图纸坐标精准锚固 + 语音文字同步留痕 + 多格式全覆盖 ✓ ✓
