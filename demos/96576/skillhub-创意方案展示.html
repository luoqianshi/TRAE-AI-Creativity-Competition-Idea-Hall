发现的痛点与需求
学习路径分散
AI时代学习者需要在多个平台跳转：课程平台学理论、论坛社区找资源、招聘网站投简历、面试题库做练习，时间碎片化严重，学习效率低下。
职业转型缺乏系统性工具
转行者从职业测评、技能学习、简历优化到面试准备，每个环节都要找不同工具，流程割裂，无法形成完整的学习-实践-就业闭环。
求职流程碎片化
求职者简历优化用 Word、面试准备刷题库、投递简历在 BOSS 直聘、跟进进度在笔记本，工具分散导致信息丢失和效率低下。
智能体资源获取困难
AI技能包、MCP工具、智能体服务等新兴资源缺乏统一市场,开发者难以变现,学习者难以发现和获取优质资源。
💡 创意灵感来源

在运营 AI 学习社区过程中,我发现大量学习者在不同平台之间来回跳转,浪费时间且效果不佳。同时,求职者在简历优化、面试准备、岗位投递等环节分散在不同工具中,流程割裂严重。这让我萌生了打造一个"一站式平台"的想法——将 AI 学习、职业测评、简历优化、模拟面试、智能体资源市场、社区运营等能力整合到一个系统中,帮助用户完成从学习到就业的完整闭环。

产品形态

SkillHub 是一个全栈 Web 平台,包含前端 Web 应用、后端 API 服务、AI 网关中继服务、智能体资源市场、社区系统和移动端适配。采用 Next.js + Express + Prisma 技术栈,支持企业微信集成、微信支付、支付宝支付等企业级能力。

Next.js 15.5 React 18 TypeScript Tailwind CSS Express Prisma ORM SQLite/PostgreSQL Redis 企业微信集成 微信支付 V3 支付宝支付 阿里云 OSS 百度内容审核
