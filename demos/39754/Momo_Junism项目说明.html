01

现实痛点

当前行业存在三大核心空白，Junism框架正是为填补这些空白而生。

⬡

底层逻辑痛点

当前大模型语义向量工具、文本分析均依赖原生高维Embedding向量，仅能完成文本相似度匹配、简单分类检索，不存在面向人类主观意识、情感、认知逻辑的标准量化体系。

◇

人文理论落地痛点

阴阳、二元、身心、情感矛盾等人文认知理论长期停留在文字思辨层面，缺少可计算、可视化、可数字化的数学转化模型，哲学、心理学研究者无法直观量化文本承载的内在意识倾向。

△

技术工具痛点

现有向量可视化工具无自定义认知维度投影规则，无法区分存在、认知、运动三类核心意识维度，不能解析文本背后隐藏的冲突、融合、化解等深层意识状态。

02

创意介绍

本项目以原创Junism理论体系为底层框架，结合自研Momo·Junism双脑交互架构，通过Trae编程落地，构建一套完整离线文本意识量化解析系统。


平台接收任意中文文本作为输入，由jieba分词预处理、大模型生成基础Embedding向量作为原始素材，通过自主编写的语义正交分解、三轴向量映射、向量缩放翻转等核心算法，将通用无差别语义投影至X/Y/Z三维坐标系，最终通过2D六边形雷达图呈现。


实现人文理论数字化、人类意识可视化、全离线本地部署三大核心目标。

04

核心模块

左脑：语义锚定

  • 锚点提取：jieba分词 → 同义词映射 → 子串匹配，三层递进
  • 多锚点融合：6轴独立加权，正负不抵消
  • 坐标翻译：6方向坐标 → 面向/忽视语义 → 约束prompt

右脑：模糊生成

  • 流式调用：Ollama/Qwen2 流式调用，SSE输出
  • 批量坐标估算：新词自动定标XYZ
  • Jun Core思维种子：三条Core映射驱动回复方向

三层存储架构

  • 内层 junism_sem.db：54词确定性坐标
  • 中层 momo_sem.db：Momo自主积累的记忆
  • 外层 session_sem.db：EWMA缓存（α=0.3，六轴独立）

缓存式加权平均（EWMA）

  • 只更新有值方向，无值保持
  • 跨轮次趋势累积，刷新清零
  • 六轴独立，正负不抵消

外在交互模块

  • 聊天界面
  • 雷达图
  • 意识状态维度表
  • 语义库管理

06

理论设计逻辑

基于Junism双包结构理论基础，将情感意识映射到三维坐标系。

轴向 维度 正向（+） 负向（-）
X轴 自我 直觉 反直觉
Y轴 认知 确定 未知
Z轴 校准 欲望 恐惧

临在原点O = 当下这一刻 = 一切情感与判断的起点。
意识：主动的选择，呈现的结果。
潜意识：放弃的选项，忽视的前提。
（例如：向前以放弃向后为前提，起跳以预备为前提）

数学框架

维度 情感状态 数学表达 表现
自我（X） 合一 S⁺ + S⁻ = 0 张力T / 压力P
认知（Y） 闭合 C已知 + C未知 = C全 引力A / 斥力R
行动（Z） 对齐 A欲望 + A恐惧 = 0 趋力D / 阻力F

三维情感向量 E = S + C + A

1. 表征个人情感的状态
2. 分析二人情感的关系
3. 预测多人情感场的演化
