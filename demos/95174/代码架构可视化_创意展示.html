// Pain Points

开发者为什么需要它

每个接手过别人代码的人，都懂这种痛

😵

新人 Onboarding 地狱

入职第一天面对 50 万行代码，文档过时、同事也说不清。花一周才勉强搞清楚模块之间的关系——而这一周本可以产出价值。

🕗

// Features

核心功能

01

多语言 AST 解析

基于 Tree-sitter 统一语法解析器，支持 Java / Python / TS / Go / Rust / C# 等 10+ 语言的精确依赖分析

02

力导向交互图

基于 D3.js 力导向布局，支持缩放/拖拽/搜索/筛选，百万级节点流畅渲染

03

循环依赖检测

自动识别环形依赖链，高亮标出并给出解耦建议，防止架构腐化

04

架构健康评分

综合耦合度、内聚性、复杂度等维度，输出 0-100 分的架构健康度报告

05

变更影响分析

选择任意模块，一键查看"如果我修改它，会影响哪些下游模块"，辅助重构决策

06

CI/CD 集成

每次 PR 自动生成架构 Diff，检测是否引入不良依赖，守护架构质量底线

// Use Cases

谁在用它

👨‍💻

新入职开发者

入职第一天打开工具，30 秒看到项目全貌。点击任意模块查看职责说明和上下游关系，onboarding 时间从一周缩短到一天。

🏗

架构师 / Tech Lead

月度架构评审时，打开健康度报告，循环依赖、过度耦合一目了然。用变更影响分析评估每次重构的风险范围。

开源项目维护者

// Value

价值与意义

⚡ 效率提升：从"盲人摸象"到"一图全览"

将理解一个陌生代码库的时间从数天缩短到数十分钟。新人 onboarding 效率提升 5-10 倍，重构影响分析从"凭经验猜"变成"看图说话"。每次代码评审都有架构 Diff 辅助，减少引入不良依赖的风险。

💰 商业价值：开发者工具的 SaaS 蓝海

面向开发团队的 SaaS 订阅（按仓库规模计费），同时提供免费开源版本获取社区口碑。CI/CD 集成的架构守护服务可作为企业版核心卖点。目标市场：全球数千万开发者和数百万个代码仓库。
