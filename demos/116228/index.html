东莞中考志愿助手 - 创意方案

1. 创意介绍

项目名称：东莞中考志愿助手

报名赛道：社会服务赛道

项目简介：本项目是一个旨在利用 AI 技术，为东莞市中考学生、家长及升学规划老师提供一站式、智能化、个性化志愿填报辅助的 Web 应用。我们致力于将复杂难懂的中考政策与海量历史数据，转化为清晰直观的决策建议，有效解决信息不对称问题，缓解升学焦虑，让每个家庭都能科学、高效地完成志愿填报。

2. 目标用户及核心痛点

目标用户

  • 东莞市应届中考学生
  • 学生家长
  • 初中升学规划指导老师

核心痛点

  • 规则复杂难懂：中考志愿填报规则、批次设置繁多，不同身份（如户籍生、随迁子女）政策差异大。
  • 信息壁垒高：官方发布的招生计划、历史录取分数线等数据，普通家长难以有效获取和解读。
    • -
  • “冲稳保”难判断：缺乏科学方法论，家长凭感觉填报，容易导致“高分低录”或“滑档”的风险。
  • 决策压力大：志愿填报关乎孩子的未来，家长在信息过载和信息不足的矛盾中备感焦虑。

3. 价值与意义

“东莞中考志愿助手”不仅是一个工具，更是一项具有社会公益价值的服务。它通过 AI 技术赋能教育，旨在实现以下价值：

  • 促进教育公平：打破信息壁垒，让每个家庭，无论背景如何，都能获取专业、对等的志愿填报指导。
  • 提升决策效率：将家长从繁杂的信息搜集和分析工作中解放出来，显著降低时间和精力成本。
  • 降低升学焦虑：提供数据驱动的科学决策依据，减少盲目和恐慌，以理性的分析代替感性的猜测。
  • 赋能一线教师：为升学规划老师提供高效的辅助工具，使其能更好地服务于广大学生。

4. 核心功能

我们计划通过以下四大核心功能，构建智能志愿填报的完整闭环：

  1. 智能学校推荐：用户输入预估中考成绩和关键信息（如户籍类型），AI 模型将结合历史录取数据，推荐“冲刺”、“稳妥”、“保底”三个梯度的学校列表。
  2. 个性化规则匹配：系统内置东莞市最新的中考政策，能根据用户的户籍类型（如户籍生、随迁子女、特定人才子女等）自动筛选和匹配符合资格的学校和批次。
  3. “冲稳保”概率分析：基于机器学习算法，分析历年录取数据波动、招生计划变化等因素，为用户提供每个推荐学校的录取概率预测，让“冲稳保”更科学。
  4. 一键辅助填报：用户在系统中确定志愿顺序后，可生成清晰的志愿填报草稿，包含学校代码、专业代码等关键信息，方便最终在官方系统上进行填报。

5. 初赛 Demo 计划

为在初赛阶段展示项目的核心价值，我们计划开发一个具备核心功能的最小可行产品（MVP），具体包括：

  • 前端界面：一个简洁、友好的 Web 页面，用户可以在此输入自己的预估分数、全市排名以及户籍类型。
  • 核心算法：实现一个基础版的学校推荐模型，能够根据用户输入，从内置的东莞市部分重点高中的历史数据中，给出一个初步的“冲稳保”学校推荐列表。
  • 结果展示：以清晰的卡片形式展示推荐的学校列表，并标注出“冲刺”、“稳妥”、“保底”建议。

该 Demo 将直观地向评委和用户展示我们如何通过技术手段，将复杂的志愿填报问题变得简单化、智能化。
