核心工作流

从模糊想法到任务验收闭环

完整的"先发散、后收敛"任务创建链路，双层验收机制确保每个环节都有明确的质量标准。

1

头脑风暴构思

只有模糊想法时，和 AI 一起发散补充、对比方案、确认边界。支持拓展细化、多方案对比、风险补全三种模式。需求明确时可直接跳过。

拓展细化 多方案对比 风险补全 可选前置
入口：项目级（新建项目时） · 任务级（详情页按钮） · 对话级（模式切换）
输出：点子卡片 → 勾选筛选 → 一键生成任务树
映射：方案目标→描述 · 功能模块→子任务 · 验收条件→验收标准 · 风险点→备注
2

项目拆解为任务树

将大型项目自动拆分为结构化的无限层级任务树，每个任务有明确的验收标准。支持 AI 对话生成、API 调用创建、手动新增等多种方式。

无限层级 验收标准 依赖关系
创建方式：头脑风暴生成 · 手动新增 · API 调用 · AI 对话 · MCP 触发 · 自动拆解
节点属性：标题 · 描述 · 优先级 · 状态 · 验收标准 · 问题清单 · 标签 · 依赖
进度计算：子任务按预估耗时加权平均，父任务自动汇总
3

Vibe Coding 逐项执行

Vibe Coding 通过 API 获取当前任务详情，按序逐一执行，每次只关注一个任务，避免上下文过载。不被长流程淹没。

API 调度 逐项执行 上下文隔离
调度流程：获取任务 → 执行 → 提交验收结果 → 通过/未通过判定
安全限制：仅可调用白名单接口 · 每接口每分钟 30 次 · 操作前自动快照
兼容 IDE：TRAE · Cursor · Windsurf · 任意支持 API 调用的 AI IDE
4

任务级验收

执行完成后，对照验收标准判定通过/未通过。通过则标记完成，自动推进下一任务；未通过则触发问题清单生成。

✓ 通过 → 推进 ✕ 未通过 → 问题清单
验收示例："所有 API 接口返回 200" · "单元测试覆盖率 > 80%" · "列表含分页和搜索"
通过：标记完成 → 自动推进下一任务
未通过：触发问题清单生成 → 进入问题级修复阶段
5

问题级验收闭环

问题清单中每个问题附带独立的验收标准。Vibe Coding 进入修复模式，逐个获取问题、修复、验证。全部验证通过后重新验收任务，形成双层闭环。

结构化问题清单 增量修复 上下文累积 双层验收闭环
问题属性：标题 · 详细描述 · 严重级别(致命/严重/一般/建议) · 状态 · 问题验收标准 · 关联任务
状态流转：待修复 → 修复中 → 已验证 → 完成
闭环：全部问题已验证 → 任务重新验收 → 通过则完成
核心功能

11 项核心能力

从头脑风暴到任务验收，覆盖 Vibe Coding 全流程的任务调度与安全防护。

01
🌳

无限层级任务树

项目 → 阶段 → 任务 → 子任务，无限层级嵌套。每个节点支持基础属性、验收标准、问题清单、时间管理、分类标签、依赖关系。

02
✅

任务级验收

每个任务预设通过条件，如"所有 API 返回 200"、"单元测试覆盖率 > 80%"。执行后自动对照判定，验收覆盖率 100%。

03
📋

问题清单与问题验收

验收未通过时自动生成结构化问题清单，每个问题附带独立验收标准。支持增量修复，修复完验证通过后再处理下一个。

04
💡

头脑风暴构思

三入口覆盖全场景：项目级、任务级、对话级。三种内置模式：拓展细化、多方案对比、风险补全。点子卡片化管理，一键映射任务属性。

05
🤖

AI 对话式管理

类似 ChatGPT 的对话框，直接说"帮我创建一个项目"。支持 Agnes AI 等多模型，AI 拆解先生成预览，用户可编辑调整后再确认。

06
📦

批量操作

批量修改优先级、批量删除（含二次确认）、批量调整标签、批量移动任务、批量状态变更。任务再多也高效管理。

07
🔗

多渠道任务创建

头脑风暴生成、手动新增、Vibe Coding API 调用、AI 对话生成、MCP 接口触发、主任务自动拆解——六种方式覆盖所有场景。

08
🛡️

四层调度安全

接口白名单 + 调用次数上限 + 操作日志 + 快照回滚。Vibe Coding 仅可调用白名单内低风险接口，数据永远可控。

09
🖥️

桌面端双模式

本地模式：内嵌 NestJS + SQLite，离线完整运行。在线模式：公网 NestJS + PostgreSQL，多设备同步。随时切换。

10
📊

多项目进度监控

桌面悬浮窗始终置顶显示当前项目进度。多项目卡片概览，滞后自动高亮。进度加权计算，真实反映整体进展。

11
🔒

本地优先架构

代码和任务数据完全本地存储，不经过任何第三方。零网络依赖，离线也能完整运行。通过 API 对接任意 AI IDE。

+
🚀

远期规划

双验收模式（AI 自验 + 客观校验）、拆解粒度配置、并行任务调度、上下文快照注入、问题知识库、关联任务回归校验。

调度安全机制

Vibe Coding 调用 FlowTask 接口时遵循严格安全限制，确保数据永远在用户手中。

🔐

接口白名单

Vibe Coding 仅可调用白名单内的低风险接口，阻止删除主任务、修改核心配置等高危操作

⏱️

调用次数上限

每个接口设置单位时间内调用次数限制，防止 AI 异常循环调用导致系统过载

📋

操作日志

所有 Vibe Coding 操作自动记录时间、类型、对象、前后数据对比，完整可追溯

⏪

快照与回滚

每次 AI 操作前自动保存快照，用户可一键回滚，数据永远可控，不满意随时撤销
