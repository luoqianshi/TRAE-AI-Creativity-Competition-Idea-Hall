光影集

一站式摄影作品展示与约拍服务平台

Next.js 网站 微信小程序 完整管理后台

一、创意名称 & 项目介绍

想解决什么问题

摄影创作者缺少作品展示、粉丝互动、线上接单一体化专属平台；普通用户找摄影师渠道零散，无法直观查看真实成片、快速预约档期。

创意灵感来源

深耕摄影行业观察到，摄影师分散在社交平台发图流量不稳定、接单流程繁琐，客户筛选摄影师信息杂乱，缺少垂直摄影服务平台，因此开发本项目。

产品形态

PC端Next.js摄影展示网站 + 配套微信小程序 + 全功能后台管理系统综合摄影服务平台。

二、目标用户及使用痛点

用户群体1：摄影师/摄影工作室

  • 使用场景：上传作品、分类图集、上架拍摄套餐、处理客户预约订单
  • 现有痛点：社交平台压缩画质，无专业图库管理；接单、沟通、收款分散多软件，管理效率极低

用户群体2：拍照消费用户

  • 使用场景：浏览摄影作品、挑选摄影师、线上预约拍摄、收藏图集点赞评论
  • 现有痛点：摄影师信息碎片化，无统一对比渠道；线下沟通预约耗时，无平台服务保障

三、项目价值与意义

效率提升价值

平台整合高清图库、AI智能图片标签、评论审核、线上预约全套功能，AI自动识别画面完成分类，摄影师无需切换多款软件；用户瀑布流浏览原图，一键预约，大幅减少双方沟通与整理时间。

商业价值

为摄影师搭建专属私域展示阵地，支持付费拍摄套餐线上售卖，平台可通过服务分成、云存储增值服务实现稳定营收；聚集摄影供需流量，可拓展商拍广告、摄影器材合作等多元变现渠道。

四、功能特性

作品瀑布流展示

支持原图查看、图片EXIF参数展示

树形分类管理

图集自定义排序、多级分类

AI智能标签

自动识别画面生成图片标签

多渠道登录

邮箱账号 + 微信小程序快捷登录

在线预约拍摄

套餐上架、档期预约、订单管理

双存储方案

本地存储 / 腾讯云COS云端存储

五、技术栈

前端：Next.js 15 + React 19 + Tailwind CSS + shadcn/ui
后端：Next.js API Routes + Express + Prisma ORM
数据库：MySQL
存储：本地存储 / 腾讯云COS
部署：PM2 + Nginx
客户端：配套微信小程序

六、快速部署流程
