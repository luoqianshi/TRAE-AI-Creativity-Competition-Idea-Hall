硬件知识库 RAG Agent

像聊天一样查芯片手册——让嵌入式开发者告别翻几百页 PDF 的烦恼

💡 创意介绍

硬件知识库 RAG Agent 是一个面向嵌入式开发者的 AI 助手。它让工程师用自然语言提问，就能从 STM32、ESP32 等芯片手册中找到答案，并且每句回答都标注了原始出处。

[用户]
ESP32-S3 的 strapping 引脚有哪些？
[助手]
根据手册[src1][src2]，ESP32-S3 的 strapping 引脚为：GPIO0、GPIO3、GPIO45、GPIO46。其中 GPIO0 决定启动模式（高电平=正常运行，低电平=下载模式）。

现在有什么痛点？

  • 翻阅低效：芯片手册平均 500-3000 页，找一段话要翻半天
  • 技术门槛高：新手看不懂官方手册的术语，官网示例缺少工程细节
  • 来源不可靠：AI 会编造寄存器名和电压值，出错直接烧硬件
  • 经验难复制：老工程师的踩坑经验踩完就忘，团队知识没有沉淀

核心功能

  • 多格式支持：PDF / Markdown / TXT / XLSX / CSV 文档一键上传
  • 智能分块引擎：按标题结构自动切分 + 代码块保护，确保不把表格和代码拦腰切断
  • 混合搜索：关键词精确搜索 + 语义向量搜索双重保障
  • 引用溯源：每句回答标注手册原文出处 [srcN]，点击即可查看原始段落
  • 多知识库：STM32 手册库、ESP32 手册库、个人笔记库可独立管理
  • 对话管理：多轮对话分支、书签收藏、导出分享

📈 价值与意义

⏱️ 效率提升

查手册时间从 30 分钟缩短到 30 秒。不再需要在几百页的 PDF 里搜索关键词再逐条验证。

🛡️ 安全可靠

每句回答强制引用手册原文，避免 AI 乱编参数导致的硬件损坏。

📚 团队知识沉淀

团队上传的芯片手册 + 踩坑笔记构成共享知识库，新人上手从 3 个月缩短到 1 周。

🔓 开源开放

完全本地部署，数据不出电脑。用户自配 API Key + 自选模型，不受厂商绑定。

⚡ 技术亮点

small-to-big 分块

小块检索保精度，大块生成保上下文。代码块独立提取，短块自动合并减少 84%。

四阶检索管线

向量语义召回 + BM25 关键词 + RRF 融合排序 + reranker 交叉编码精排，四层逐步收窄。

LLM Agent 分块

复杂 PDF 用 AI 三路投票切分章节边界，自动补漏页，temperature=0 保证稳定输出。

量化评测体系

30 道 golden 测试题 + DeepEval 四指标评分，每次优化后跑一遍防回归。
