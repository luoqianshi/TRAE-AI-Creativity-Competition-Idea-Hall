Part 01

创意名称与介绍

SmartHome AI — 让所有设备接入智能家居生态

想解决什么问题：当前智能家居存在设备生态割裂、协议不统一、旧设备难接入、自动化场景受限、语音控制依赖云端、家庭感知依赖摄像头等问题。不同品牌设备往往需要多个 App 分别管理，用户很难将米家设备、自研 ESP32 设备、BLE 设备、红外/RF 传统设备和其他第三方设备统一到一个平台中。

同时，大量已装修家庭中的空调、电视、投影仪、风扇等设备仍依赖传统遥控器，本身并不支持智能家居协议。如果全部更换为智能设备，不仅成本高，还可能破坏原有装修和使用习惯。SmartHome AI 希望解决的核心问题是：不更换旧设备，也能让它们接入智能家居系统，并与不同厂家设备统一联动。

此外，传统智能家居中的人体存在检测和房间定位通常依赖摄像头、毫米波雷达或人体传感器。摄像头存在隐私顾虑，毫米波雷达成本较高，普通人体传感器又只能判断“有人/无人”。因此，系统进一步引入 WiFi CSI 空间感知能力，在不采集图像的前提下，实现房间定位、区域检测和无感感知。

为什么会想到做这个：智能家居真正的价值，不只是让单个设备可以远程开关，而是让不同设备围绕真实生活场景协同工作。例如，“回家模式”不应该只打开一盏灯，而应同时联动门锁、灯光、窗帘、空调、安防和传统遥控设备；“观影模式”也不应只关闭灯光，而应同时拉上窗帘、打开投影仪、调节空调和切换氛围灯。

随着本地大模型、ESP32 低成本硬件、MQTT 通信、LocalBridge 设备桥接和 WiFi CSI 感知技术逐渐成熟，我们看到了一个新的机会：通过软件平台和低成本硬件，把不同品牌设备、自研智能设备和传统非智能设备统一接入同一个智能家居生态，让用户不换家电、不重新装修，也能拥有真正的全屋智能。

产品形态：SmartHome AI 是一个端边云一体化智能家居控制与无感感知平台。系统由云端服务、边缘 AI 网关、iOS 客户端、Watch 客户端、ESP32 硬件模块、LocalBridge 设备桥接模块、场景自动化引擎和 WiFi CSI 空间感知模块组成。

云端服务负责用户认证、设备管理、状态同步、指令下发和自动化规则管理；边缘 AI 网关基于本地大模型实现自然语言意图解析，减少对云端语音服务的依赖；iOS 和 Watch 客户端提供设备控制、场景执行和快捷操作入口；ESP32 红外/RF 模块支持遥控器信号学习与转发，可将传统空调、电视、投影仪、风扇等非智能设备改造成可控制、可联动的智能设备；LocalBridge 支持 Miio、BLE、路由器、门铃、窗帘、晾衣架等本地设备接入；WiFi CSI 模块通过六个 ESP32-S3 节点采集 30 条有向链路的信道状态信息，实现房间定位、区域检测和无摄像头空间感知。

🧑‍💻

智能家居开发者

需要可扩展平台接入新设备、编排场景、开放 API 并验证自研硬件。

典型使用场景

用户可以通过 iOS App、Apple Watch 或语音控制灯光、窗帘、空调、电视、晾衣架等设备；也可以将多个设备组合成统一场景。点击“回家模式”后，系统可自动打开客厅灯光、拉开窗帘、开启空调并关闭安防提醒；点击“睡眠模式”后，系统可关闭电视和客厅灯、拉上窗帘、调整空调温度并启用夜间安防。

对于传统空调、电视、投影仪、风扇等非智能设备，系统可通过 ESP32 红外/RF 学习模块记录遥控器信号，并将其虚拟化为智能家居设备。这样，旧设备也可以和智能灯光、窗帘、门锁、传感器一起参与场景联动。

在空间感知方面，系统可通过 ESP32-S3 六节点 CSI 采集网络，分析人在不同房间或不同区域活动时对 WiFi 信道的影响，实现房间级定位、区域检测和纸箱区域识别等功能。相比摄像头方案，该方式不采集图像，更适合卧室、客厅、办公室等对隐私要求较高的空间。

Part 04

技术方案

端边云架构

  • iOS App 与 Watch 快捷控制入口
  • ASP.NET Core Web API 云端服务
  • SQLite、JWT、SSE 与设备状态同步
  • MQTT Bridge 指令下发与 shadow 状态管理
  • 边缘 AI 网关进行本地意图解析

多协议设备接入

  • LocalBridge 接入 Miio、BLE、路由器、门铃等设备
  • ESP32 自研设备与传感器节点
  • 红外 / RF 学习模块改造旧设备
  • 统一设备能力模型：开关、温度、模式、位置等
  • 开放 API 支持第三方设备扩展

场景与自动化

  • 支持触发条件—判断条件—执行动作的规则结构
  • 支持回家、离家、睡眠、观影、晾晒等家庭场景
  • 支持开店、打烊等商铺自动化场景
  • 支持跨品牌、跨协议、跨设备类型联动
  • 高风险设备自动化触发前进行权限校验

WiFi CSI 空间感知

  • 六个 ESP32-S3 节点构建多链路感知网络
  • 6×5 共 30 条有向 CSI 链路
  • 基于 ESP-NOW 探测帧采集信道状态信息
  • 用于房间定位、区域检测、纸箱区域识别
  • 不采集图像，更适合隐私敏感空间

Part 05

价值与意义

效率提升

多品牌设备、自研设备、传统红外/RF 设备统一接入一个平台，用户无需切换多个 App；通过“观影模式”“离家模式”等场景，一次操作即可完成多设备联动。

隐私保护

核心 AI 推理可在本地边缘网关完成；WiFi CSI 空间感知不采集图像，不记录面部和画面，更适合卧室、客厅、办公室等隐私敏感场景。

商业价值

为已装修家庭和小型商铺提供低成本改造方案，无需更换现有家电，仅需 ESP32 模块即可让传统设备接入智能家居生态。

安全保障

对门锁、摄像头、燃气阀等高风险设备设置权限校验和二次确认；自动化规则触发时也可进行安全判断，避免误操作。

社会价值

  • ✓
    环保节能通过 CSI 空间感知与自动化规则结合，自动关闭无人区域的灯光、空调和电视，提高能源利用效率。
  • ✓
    老龄化友好语音控制、Watch 快捷控制和自动化场景降低使用门槛，无摄像头感知也可辅助老人居家状态提醒。
  • ✓
    减少电子垃圾通过改造而非淘汰旧设备，延长传统家电使用寿命，减少因更换智能设备产生的电子废弃物。
