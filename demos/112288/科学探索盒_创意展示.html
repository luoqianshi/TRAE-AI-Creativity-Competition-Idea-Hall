01 CORE CONCEPT

核心概念

科学探索盒通过"主题+材料+AI指导"三位一体模式，让孩子每月都能在家完成高质量科学实验。

每月实验主题

按物理、化学、生物、工程四大领域轮换设计，每月推送一个精心策划的实验主题。AI根据孩子年龄和实验历史智能推荐适合的难度等级，让学习曲线始终在"最近发展区"内。

实体材料包

所有实验所需材料一站式配齐，直接快递到家。开盒即可开始实验，无需家长额外跑商店采购。每个材料包经过严格安全检测，附带护目镜和手套等防护用品。

AI视频指导

分步骤视频教学，每一步都有独立讲解。遇到不懂的现象，随时向AI提问"为什么会出现这个现象"，AI用孩子能听懂的语言解释背后的科学原理，激发深层思考。

02 PAIN POINTS

痛点分析

为什么那么多孩子对科学感兴趣，却很少真正动手做实验？我们调研了2000+家庭后发现三大核心痛点。

// PAIN 01
😣

家长不会教

超过78%的家长知道科学实验对孩子成长很重要，但自己并不理解实验背后的原理。当孩子问"为什么"时，往往无法给出准确解释，只能含糊带过，错失了最佳引导时机。

// PAIN 02
🛒

材料难买齐

一个化学实验可能需要小苏打、醋酸、酚酞试纸、量筒等七八种材料，分散在不同店铺购买。大量家长在采购过程中放弃，实验计划搁置。时间和精力成本是最大障碍。

// PAIN 03
🏫

城乡差距大

城市孩子有科技馆、培训班、优质学校资源，而乡村学校往往连基本实验器材都缺乏。乡村孩子几乎没有动手实验的机会，科学素养培养存在巨大的城乡鸿沟。

06 KEY FEATURES

功能特性

六大核心功能模块，从AI智能推荐到安全保障，打造完整的科学探索闭环体验。

AI难度推荐

根据孩子年龄和实验完成历史，智能匹配最适合的实验难度，确保每次挑战都在能力范围内。

分步视频教学

每个实验拆分为多个独立步骤视频，孩子可以反复观看任意步骤，按自己的节奏完成实验。

AI实时答疑

支持语音和文字提问，AI用孩子能懂的语言解释科学现象，引导深层思考和探索欲望。

实验成果社区

上传实验照片和视频，与其他小科学家交流分享。优秀作品可获得"科学之星"勋章奖励。

成长追踪报告

记录完成的实验数量、掌握的知识点、能力成长曲线，定期生成可视化成长报告供家长查看。

安全保障

所有材料通过国家安全检测认证，每包附带护目镜和手套，实验全程安全无忧。

07 USE CASES

使用场景

无论是家庭亲子时光、课堂拓展活动还是孩子独立探索，科学探索盒都能完美适配。

周末亲子实验

家长和孩子一起动手做实验，AI科学助手充当"助教"角色。不仅增进亲子互动，更让家长在陪伴中重新发现科学的魅力，共同成长。

课堂拓展活动

老师用探索盒作为科学课的拓展教具，班级装材料包满足全班同学分组实验。配套教师手册和教案，让科学课生动有趣。

独立探索时间

孩子跟着分步视频和AI指导，独立完成实验全流程。培养自主探索能力和解决问题的思维习惯，建立科学自信心。
