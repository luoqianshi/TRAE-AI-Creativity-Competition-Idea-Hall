PROJECT BACKGROUND

开发者的日志困境

面对 Spring Boot 项目动辄数千行的运行日志，人工阅读排查既耗时又容易遗漏关键信息。

⚠️

传统排查流程

  • ✗手动滚动日志，反复阅读查找关键字
  • ✗依赖个人经验判断错误根因
  • ✗切换到搜索引擎 / Stack Overflow 查找解决方案
  • ✗反复试错，平均耗时 15~30 分钟
  • ✗新人学习成本高，难快速上手
⚡

AI 分析流程

  • ✓自动识别 ERROR / FATAL 级别日志
  • ✓智能提取异常堆栈与关键上下文
  • ✓一键调用 DeepSeek AI 生成分析与修复建议
  • ✓结果本地缓存，重复问题秒级响应
  • ✓IDEA 内原生集成，零上下文切换
PRODUCT FEATURES

六大核心功能

围绕 Java 开发者日常日志排查场景打造的全方位 AI 辅助工具链。

🧠

智能日志提取

基于规则引擎自动识别 Spring Boot 项目中的关键错误堆栈，过滤冗余信息。

🤖

AI 错误分析

集成 DeepSeek API，将错误信息与上下文发送给大模型生成专业诊断报告。

📚

错误历史管理

记录每次分析结果，支持按时间/级别筛选，方便回顾与团队知识沉淀。

💾

缓存分析结果

相同错误哈希匹配本地缓存，秒级返回结果，节省 API 调用成本。

🚨

自动检测严重错误

识别 NPE / SQL / Timeout / OOM 等常见严重错误，并高亮标记优先处理。

🧩

IDEA 原生集成

基于 IntelliJ Plugin SDK + Swing UI 开发，完美融入 IDE 工作流，无需离开编辑器。
