Pro-Career Copilot

端云协同智能求职分身

一款基于「无状态架构」与「多智能体协同」的端侧自动化求职插件。
在保障用户绝对隐私的前提下，实现网页级 JD 解析、简历靶向重写与沟通话术的极速生成，
打破传统对话框体验，重塑求职工作流。

The Workflow

核心工作流

三个无缝衔接的人机协同步骤，打造极致求职体验

01

端侧感知与提取

Agentic Extraction

用户在 Boss 直聘等任意招聘页面点击插件。插件不依赖脆弱的网页 HTML 结构，直接暴力抓取当前页面的全量纯文本，云端解析 Agent 剔除广告与冗余信息，精准抽离出 JD 中的硬性技能需求。

02

简历靶向重构

The Optimizer Agent

云端大模型提取本地简历数据，生成匹配度雷达图。对齐 Agent 开启结构化输出模式，将用户的过往经历翻译成符合该岗位黑话的专业描述。界面强制弹出 Diff 对比，以红绿差异高亮展示修改内容。

03

合规化极速投递

Human-in-the-loop

用户确认简历无误后，点击「一键打招呼」。插件通过 DOM 注入，将 AI 生成的定制化打招呼话术填入第三方平台聊天框，并自动上传特调版 PDF 简历。最后一步发送按钮由用户本人物理点击，彻底规避反爬虫风控。

Engineering Defense

三大工程级防御机制

面试绝杀亮点，拉开与玩具 Demo 的差距

🔒

零数据留存

Zero Retention

彻底砍掉云端数据库。用户的隐私简历仅保存在浏览器本地 LocalStorage。每次调用时作为 Payload 传给云端接口，模型处理完毕即刻销毁，实现 100% 隐私安全闭环。

🛡️

抗脆弱视觉解析

Anti-Fragile

不写死任何网页抓取规则，不依赖 XPath 或 CSS Selector，依靠大模型的语义理解能力在乱码纯文本中精准提取 JD。就算招聘网站每天改版，系统依然稳如泰山。

⚖️

安全护栏与人机对齐

Guardrails & Diff

通过强硬的 System Prompt 约束限制模型发散，强制要求输出结构化数据；并在 UI 层强制加入 Diff 对比视觉卡片，完美解决大模型在求职场景下最致命的「幻觉」问题。
