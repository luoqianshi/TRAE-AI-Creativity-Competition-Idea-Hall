// 算法说明 · How it decides

每个候选菜品会得到一个综合分：
偏好分（你打的喜好）＋ 时段分（早餐吃粥不吃烧烤）＋ 口碑分（附近评分）＋ 鲜度分（最近没吃过有加分）。 最后用加权随机抽出，既偏向高分，又保留惊喜。

score = w1·pref + w2·time + w3·rating + w4·fresh
pick ∝ exp(score / τ)
