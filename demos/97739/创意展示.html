家办智投

家庭资产穿透式AI诊断与财商陪伴Agent

基于基金E账户导出的Excel持仓数据，AI穿透分析底层股票、债券与行业分布，生成家办级诊断报告，并提供个性化财商教育陪伴。

01 创意介绍

想解决什么问题

中国基民平均持有7-10只基金，但基金名称无法反映底层资产，多只基金可能重仓同一行业或个股，表面上分散了，实际风险高度集中。同时，传统家族办公室服务门槛千万起步，普通中产家庭无法享受专业的资产配置诊断与长期陪伴。

灵感来源

我自己也是基金E账户的用户，持仓十几只基金，每次复盘时只看基金名称和收益率，直到有一次发现3只不同名字的基金都重仓茅台和五粮液，才真正意识到「伪分散」的风险。我希望有一个工具，能像家族办公室的专业投顾一样，帮普通家庭穿透看清真实风险，并陪伴提升财商。

产品形态

Web应用（Streamlit）+ AI Agent：用户上传基金E账户Excel，系统自动完成穿透分析、生成诊断报告、提供调仓建议，并基于持仓短板推送个性化财商教育内容与AI对话陪伴。

02 目标用户及痛点

核心用户

  • 30-45岁中产家庭，有5-100万基金持仓
  • 使用「基金E账户」App管理资产，但缺乏专业分析工具
  • 希望提升家庭资产配置能力，但无暇深入研究每只基金底层

使用场景

  • 月度/季度复盘：定期查看家庭资产真实风险暴露
  • 调仓决策前：买入新基金前，检查与现有持仓的相关性和重叠度
  • 财商学习：利用碎片时间，学习与自身持仓相关的投教知识

当前痛点

  • 没有工具能自动穿透基金到底层股票和债券
  • 券商/银行投顾往往推荐产品而非客观诊断
  • 投教App内容泛泛，无法结合用户真实持仓进行针对性教育
  • 家办服务门槛高，中产家庭够不着

03 价值与意义

社会价值

在中国，公募基金投资者已超过7亿人，但大多数普通投资者缺乏专业的资产配置能力和风险识别能力。家办智投用AI将千万门槛的家族办公室服务平民化，帮助中产家庭看清真实风险、避免伪分散陷阱、系统提升财商，具有显著的普惠金融价值。

效率提升

传统方式下，用户需要手动查询每只基金的季报持仓、汇总Excel计算行业分布和重叠度，耗时数小时。家办智投一键上传、秒级穿透、自动生成报告，将复盘效率提升数十倍。

05 技术方案

Streamlit Python Pandas Plotly OpenPyXL NumPy

前端/UI：Streamlit + Plotly 实现交互式数据可视化

数据解析：Python + Pandas + OpenPyXL 解析基金E账户Excel

分析引擎：自定义穿透式分析、HHI集中度、相关性矩阵、健康度评分模型

AI能力：规则引擎驱动的报告生成与对话Agent（Demo阶段），复赛可扩展大模型API

06 创新点

  • 穿透式而非表层分析：不停留在基金层面，直抵底层资产，让风险无处隐藏
  • 家办服务平民化：用AI将千万门槛的家族办公室服务降到零门槛
  • 诊断即教育：基于用户真实持仓的「临床教学」，而非泛泛投教
  • 陪伴式Agent：从一次性工具升级为长期财富管家，伴随用户财商成长

07 Demo运行方式

git clone <仓库地址>
cd family-cfo-agent
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
