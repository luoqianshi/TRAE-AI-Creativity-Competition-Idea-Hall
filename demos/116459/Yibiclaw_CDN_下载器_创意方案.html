Yibiclaw CDN 下载器

一款面向中国网络环境优化的多源加速下载器：纯 Go 开发、单文件零依赖、支持 GUI / CLI / 浏览器插件三模式运行。

版本 v1.0.0 单文件 exe · 约 7MB 零第三方依赖

一、创意介绍

在国内下载 GitHub Releases、HuggingFace 模型和开源数据集时，开发者常遇到速度慢、连接不稳定、中断后需重新下载等问题。Yibiclaw CDN 下载器通过内置国内镜像加速、智能多线程、断点续传和分段降级机制，让大文件下载变得稳定可控。

一句话总结：一个 exe 文件，三种使用模式，覆盖从普通用户到开发者的全场景下载需求。

三种运行模式

模式启动方式目标用户特点
GUI 模式双击 exe（无参数）普通用户自动打开浏览器 Web UI，可视化操作
CLI 模式-url "https://..."开发者 / 运维命令行进度条，支持 JSON 机器可读输出
Native Messaging--native-messaging浏览器插件stdin/stdout JSON 协议，供 Chrome/Edge 扩展调用

二、核心功能

01

多源镜像加速

自动为 GitHub、HuggingFace 等常见源匹配 ghproxy、hf-mirror 等国内镜像，并发 HEAD 测速选最快源。

02

智能下载策略

根据文件大小自动选择单线程、16 线程、断点续传或分段降级策略，兼顾速度与时效。

03

断点续传

每 2 秒持久化下载进度元数据，中断后可从断点继续，避免重复下载已完成的部分。

04

分段降级

chunk 失败后可递归细分为最多 16 个子段独立重试，子段成功即保留，不稳定网络也能下完。

05

SHA256 完整性校验

流式计算文件哈希，支持传入期望值自动比对，确保模型和安装包完整无损。

06

原生 Windows 体验

纯 Go 实现图标嵌入，调用 SHBrowseForFolderW 目录选择器，双击无黑框，命令行输出正常。

三、目标用户与使用场景

个人开发者

下载 GitHub Release（Node.js、Go、Python 安装包）、开源工具源码压缩包。

AI 从业者

企业运维

通过 CLI + JSON 输出集成到自动化脚本，批量下载部署包并自动校验完整性。

普通用户

替代浏览器自带下载和迅雷/IDM，免费、无广告、双击即用。

四、价值与意义

效率提升

通过国内镜像自动切换、16 线程并发和智能分段策略，Yibiclaw CDN 下载器能把原本几十分钟甚至数小时的下载任务压缩到几分钟。断点续传和分段降级进一步减少了失败重试的时间浪费。

社会价值

降低国内开发者获取全球开源资源和 AI 模型的门槛。当 GitHub、HuggingFace 等站点访问不畅时，这款工具能成为连接国内开发者与全球开源生态的可靠桥梁，促进技术共享与创新。

商业价值

作为 YibiClaw AI 智能插座生态的基础设施组件，下载器既是独立工具，也可为后续 AI 驱动的自动安装、模型拉取等功能提供底层能力，形成产品矩阵协同。

五、技术亮点

零依赖单文件架构

纯 Go 标准库开发，go:embed 嵌入 HTML 前端，最终产物仅一个 exe，复制即用。

Windows GUI + CLI 双模式兼容

独创 attachParentConsole 函数，双击不弹黑框，命令行输出正常，管道重定向也能正确捕获。

纯 Go 图标嵌入

自研 addicon 工具直接调用 Windows UpdateResource API，无需 rsrc 或 windres 外部工具。

Native Messaging 浏览器集成

实现 Chrome Native Messaging 协议，浏览器扩展可通过 stdin/stdout 驱动下载并实时获取进度。

大文件内存管理

预分配文件空间，线程直接 WriteAt 写偏移，64KB 读取缓冲，GB 级文件也不占额外内存。
