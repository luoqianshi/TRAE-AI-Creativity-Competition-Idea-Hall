04 // Core Features

五大核心能力

从空间共享到技能学习，构建完整的社区厨房生态。

FEATURE 01

社区厨房地图

AI自动识别社区内可共享的厨房资源，生成可视化地图。标注厨房设备、可用时段、步行距离，一键导航到达。

FEATURE 02

家庭烹饪课预约

社区厨艺达人发布"小灶教学"课程，AI根据你的口味偏好和学习进度推荐课程，从入门到进阶自动生成学习路径。

FEATURE 03

智能时段匹配

AI分析厨房主人的生活作息和申请人的空闲时间，自动推荐最佳预约时段，将厨房闲置利用率从0提升到60%以上。

FEATURE 04

食材共享池

冰箱多余食材一键发布，邻居按需领取。AI提醒即将过期的食材优先共享，减少食物浪费，降低做菜成本。

FEATURE 05

信任与安全体系

实名认证+信用评分+保险覆盖。厨房主和学员双向评价，AI识别异常行为，确保共享过程安全放心。

FEATURE 06

厨艺成长档案

记录每道学会的菜、每位教过你的邻居。生成个人厨艺成长时间线，从"只会煮泡面"到"能做一桌年夜饭"。
