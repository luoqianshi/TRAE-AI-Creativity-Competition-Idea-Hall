Present Simple
一般现在时
A1 已掌握
一般现在时用来描述经常发生的动作或客观事实。主语是第三人称单数（he/she/it）时，动词要加 -s 或 -es。
📚 来自《小猪佩奇》EP01 Muddy Puddles
Peppa loves jumping in muddy puddles. 佩奇喜欢在泥坑里跳。（第三人称单数加 -s）
George wants to jump too. 乔治也想跳。（want → wants）
⏳
Present Continuous
现在进行时
A2 学习中
现在进行时表示正在发生的动作。结构：be (am/is/are) + 动词-ing。常搭配 now, today, look, listen 等提示词。
📚 来自《小猪佩奇》EP01 Muddy Puddles
It is raining today. 今天正在下雨。（is + raining）
Now the rain has stopped. 现在雨停了。（现在完成时，表示刚结束）
⚠️
Modal Verb: must
情态动词 must（必须）
A2 学习中
must 表示"必须"，后面接动词原形。用于表达规则、要求或强烈的义务。否定形式 must not (mustn't) 表示"禁止"。
📚 来自《小猪佩奇》EP01 Muddy Puddles
If you jump in muddy puddles, you must wear your boots. 如果你要在泥坑里跳，你必须穿雨靴。（must + 动词原形 wear）
🔤
Articles: a / an / the
冠词 a / an / the
A1 已掌握
a 用于辅音开头的单数可数名词前；an 用于元音开头的名词前；the 表示特指。KET 考试常考 a/an 的区分。
📚 来自《小猪佩奇》EP01 Muddy Puddles
There is a big muddy puddle! 有一个大泥坑！（a + 辅音开头 big）
Daddy Pig found the biggest muddy puddle of all! 猪爸爸找到了最大的泥坑！（the 表特指"那个最大的"）
🏆
Superlatives
最高级
A2 新语法点
形容词最高级用于比较三个或以上的人或物。短词加 -est（the + 形容词-est），长词用 the most + 形容词。前面通常加 the。
📚 来自《小猪佩奇》EP01 Muddy Puddles
Daddy Pig found the biggest muddy puddle of all! 猪爸爸找到了最大的泥坑！（big → bigger → the biggest）
📢
Imperatives
祈使句
A1 已掌握
祈使句用于发出命令、请求或邀请，以动词原形开头。否定形式在前面加 Don't。KET 听力中常出现。
📚 来自《小猪佩奇》EP01 Muddy Puddles
Look! There is a big muddy puddle! 看！有一个大泥坑！（Look 表引起注意）
Let us go outside! 我们出去玩吧！（Let's + 动词原形，表建议）
