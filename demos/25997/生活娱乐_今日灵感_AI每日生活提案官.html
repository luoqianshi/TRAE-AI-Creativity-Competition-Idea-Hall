Part 01 — 创意介绍

把每一天过成一部值得期待的短片

「今日灵感」是一款 AI 驱动的每日生活提案工具。它不是日历，不是待办清单，而是一个懂你此刻状态的「生活编剧」——每天为你生成一份个性化的生活剧本，从早餐建议到下班后的放松方式，从穿搭参考到一句话心情寄语。

想象一下：周一早上醒来，打开手机，看到一份为你量身定制的「今日剧本」——因为今天降温了，它建议你穿暖色系外套、中午去那家新开的牛肉面馆、下午三点安排最难的工作（因为你的精力曲线在这个时段最高峰）、晚上推荐一部适合雨天看的电影。

这不是简单的推荐算法。它会结合你的心情输入、当地天气、日程安排、甚至最近的生活事件，用 AI 生成有温度、有创意、有执行力的生活方案。每天都不一样，每天都有惊喜。

💡 核心理念

  • 生活不需要完美规划，需要的是「恰到好处的灵感」
  • AI 不替代你的决定，而是帮你打开「今天可以这样过」的想象力
  • 每个人的生活都值得被认真对待，哪怕只是一个普通的周二
Part 02 — 目标用户与痛点

谁需要「今日灵感」？

核心用户：18-35 岁的都市年轻人，尤其是——

01
「每天醒来不知道今天要干嘛」的迷茫党
工作日重复循环，周末躺平刷手机。不是没有时间，而是缺少一个「开始做点什么」的触发点。
02
「选择困难症晚期」的纠结星人
午饭吃什么？周末去哪玩？晚上看什么剧？每个小决定都在消耗意志力，最后选择了「算了随便吧」。
03
「想让生活有点仪式感但懒得策划」的打工人
知道生活需要点缀，但下班后只想瘫着。需要一个「推一把」的力量，把好想法变成现实。

使用场景：早晨起床后查看今日提案、午休时浏览下午建议、下班前规划晚间活动、周末前获取两天计划灵感。轻量、无压力、打开即用。

Part 04 — 技术方案

用 TRAE 实现的完整技术栈

全程使用 TRAE IDE 进行开发，充分利用 AI 辅助编程能力完成从架构设计到代码实现的全流程。

TRAE IDE React 18 TypeScript Tailwind CSS Framer Motion OpenAI API Weather API Local Storage PWA

🔧 关键技术点

  • Prompt Engineering：精心设计的系统提示词，让 AI 生成有温度、有创意、不模板化的生活提案
  • 多源数据融合：心情输入 + 天气 API + 时间上下文 + 用户历史偏好，多维度生成个性化内容
  • 动效设计：提案以「翻页剧本」的形式呈现，每一页是一个生活场景，配合微动画提升仪式感
  • PWA 支持：可添加到手机桌面，支持离线查看历史提案，体验接近原生 App
