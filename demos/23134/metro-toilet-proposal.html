项目概述

「地铁找厕所」是一款专为城市出行人群打造的微信小程序，致力于解决地铁出行中最迫切的需求之一——快速找到卫生间。 我们提供全国一线城市地铁网络的卫生间、无障碍设施、母婴室及ATM机的精准位置查询服务，并新增首末班车查询、线路图浏览、用户留言墙等功能，让您的出行更加便捷、舒适、安心。

数据结构设计

集合名称 字段名称 类型 说明
cities（城市） city_id string 城市唯一标识
city_name string 城市名称
city_code string 城市拼音/缩写
metro_count number 地铁线路数
lines（线路） line_id string 线路唯一标识
line_name string 线路名称（如1号线）
line_color string 线路颜色（十六进制）
city_id string 所属城市
schedule object 首末班车时间
stations（站点） station_id string 站点唯一标识
station_name string 站点名称
line_ids array 所属线路列表
city_id string 所属城市
facilities array 设施列表
facilities（设施） facility_id string 设施唯一标识
type string 设施类型（toilet/accessible/baby/atm）
location string 具体位置描述
status string 状态（正常/维护中）
messages（留言） message_id string 留言唯一标识
content string 留言内容
author string 留言者昵称
city_id string 所属城市
created_at timestamp 发布时间
