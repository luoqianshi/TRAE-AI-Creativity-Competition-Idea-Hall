开放 API

简洁强大的 RESTful API，轻松集成到任何系统

api_example.py
# 知识检索 API 示例 import requests # 初始化客户端 client = KnowledgePocket( api_key="your-api-key", base_url="https://api.example.com/v1" ) # 发起知识检索 response = client.search( query="公司报销流程是什么", knowledge_base="hr-policies", top_k=5, include_sources=True ) # 返回结果 print(response.answer) # => "报销流程如下：1. 填写报销单..." print(response.sources) # => ["财务报销管理制度v3.2.pdf"] # Webhook 回调配置 client.set_webhook( url="https://your-server.com/callback", events=["document.updated", "search.logged"] )

API 特性

RESTful 设计

标准 REST 接口，支持 JSON 请求/响应，易于集成任何语言和平台。

OAuth 2.0 认证

标准 OAuth 2.0 + API Key 双重认证，支持企业 SSO 集成。

Webhook 事件

支持文档更新、检索日志等事件回调，实时同步企业业务系统。

流式响应

支持 SSE 流式输出，实现打字机效果的实时回答体验。
