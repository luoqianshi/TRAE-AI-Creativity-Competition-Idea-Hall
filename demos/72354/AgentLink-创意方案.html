P2P端到端加密AI Agent通信与资源共享工具包

🎯 创意介绍

项目名称：AgentLink - 让每个人的AI助手安全互联

解决的问题：现在每个人都有自己的AI助手，但不同用户的AI之间是孤立的——无法交流、无法共享工具、无法传文件、无法共享知识。现有方案要么是同进程多Agent（如AutoGen），要么依赖中心化服务器（如Google A2A），既无法跨用户，又有隐私风险。

产品形态：Python开源工具包/SDK，3行代码集成到现有AI Agent项目，实现跨用户P2P安全通信。

一句话描述：让不同用户的AI助手，就像微信好友一样，在用户授权范围内安全地聊天、调用工具、传文件、共享知识，所有通信端到端加密，中继服务器也无法解密。

👥 目标用户及痛点

目标用户：

  • AI Agent开发者（LangChain/AutoGen/自研框架）—— 需要跨用户Agent通信能力
  • 注重隐私的AI用户—— 不希望自己的数据经过第三方服务器
  • 学生/教育场景—— AI学习助手之间安全协作、共享资料
  • 研究机构—— 多Agent系统研究、分布式AI实验

核心痛点：

  • ❌ 现有框架只支持同一用户的Agent协作，无法跨用户
  • ❌ 中心化方案有数据泄露风险，用户不能掌控权限
  • ❌ 缺乏AI Agent场景的安全防御（提示词注入、数据泄露）
  • ❌ 国外方案在国内网络环境下使用困难

🏗️ 技术架构

采用四层架构，P2P直连优先、中继兜底：

┌─────────┐ 🔒E2EE🔒 ┌─────────┐
│ 用户A │◄──────────────►│ 用户B │
│ Agent A │ AES-256-GCM │ Agent B │
└────┬────┘ └────┬────┘
│ ┌─────────┐ │
└────────►│ 中继服务器│◄─────┘
│(仅转发不解密)│
└─────────┘

🔐 安全层

DID身份 · UCAN令牌 · E2EE加密 · 注入防御 · DLP脱敏

🌐 网络层

WebSocket直连 · STUN穿透 · 轻量中继 · 自动重连

📋 协议层

消息协议 · 握手心跳 · 分块传输 · 错误处理

💬 应用层

加密聊天 · 工具调用 · 文件传输 · 内存共享

✨ 核心功能

  • DID去中心化身份：W3C标准，Ed25519签名+X25519密钥交换，无需注册中心
  • UCAN能力令牌：细粒度权限控制（action:resource），支持授予、撤销、过期
  • 端到端加密：AES-256-GCM加密所有通信，中继服务器无法解密
  • 跨Agent工具调用：授权后可调用对方Agent注册的工具，支持同步/异步函数
  • 文件分块传输：64KB分块传输大文件，传输前双向用户授权，敏感文件自动拦截
  • 共享内存/知识库：授权式读取对方共享的数据，key级别权限控制
  • AI安全防御：20+种提示词注入检测模式，DLP自动脱敏手机号/身份证/密钥等
  • 连接码+二维码：扫码/复制即可连接，类似微信的使用体验
  • 多框架兼容：原生支持LangChain，零依赖支持自定义Agent

💎 价值与意义

效率价值：让AI Agent从孤立的个人助手变成协作网络节点，3行代码即可集成，开发者无需从零构建通信和安全层，极大扩展了单个AI的能力边界。

社会价值：

  • 隐私保护：用户完全掌控数据和权限，端到端加密保护通信内容
  • AI安全：专门针对Agent通信场景设计了提示词注入防御和数据脱敏
  • 开源开放：核心代码开源，任何人可以审计、部署自己的中继节点
  • 国内友好：优先国内STUN服务器，中继可部署国内，月成本30-50元
  • 教育价值：适合教学，帮助理解P2P网络、加密通信、授权机制

🚀 快速集成示例

from agentlink import AgentLinkTool, AgentCard

# 1. 初始化
tool = AgentLinkTool(
    agent_card=AgentCard(name="我的AI助手"),
)
await tool.start()

# 2. 注册工具（对方可授权后调用）
@tool.register_tool
def calculate(expression):
    return {"result": eval(expression)}

# 3. 生成连接码，开始通信
print("连接码:", tool.generate_connection_code())
