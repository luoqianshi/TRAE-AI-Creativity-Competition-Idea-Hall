— how

Three steps. Zero code.

You don't need Godot, you don't need GDScript, you don't need a dev environment. Open the app, type, wait, play.

step 01

Type a vibe.

Plain English. "A cyberpunk snake, neon green on midnight blue." "A pixel-art frog hopping traffic." Whatever you want.

> a cyberpunk snake, neon green on midnight blue_
step 02

Watch it build.

Six stages run on your machine: plan, code, review, fix, screenshot, export. The panel shows each one in real time, with the actual file it just wrote.

step 03

Press play.

A real Godot 4 build opens in your browser. 1280×720, no install, no sign-in. Arrow keys, space, mouse — whatever the game needs.

— pipeline

One request. Six stages. No UI flash.

Every prompt is a job. A job walks a fixed state machine. Each stage writes a file to disk; the next stage reads it. If a stage fails, the job stops and the error is written to the log — nothing is faked to look successful.

  1. PlanParse the prompt into a brief: genre, mechanics, controls, art direction. Output as JSON next to the job's log.
  2. CodeEmit scripts/games/<name>.gd — a single GDScript with _draw(), _process(), input handling and a HUD.
  3. ReviewStatic pass over the script: missing handlers, unreachable branches, Godot 3 → 4 API drift. Emits a review report.
  4. FixApply minimal patches when the review finds something fixable. Skip the stage when the report is clean.
  5. ScreenshotHeadless Chromium loads the wasm, waits for the splash to hide, captures the canvas as PNG to builds/screenshots/.
  6. ExportRun godot --export-release "Web". Copy the html, wasm and pck into builds/play/. Stamp the build timestamp.

— stack

Things the build is made of.

No marketing, just the dependencies you'd find if you cat'd the project.

engine
Godot 4.5 — HTML5 export, single-thread
language
GDScript, vanilla Node2D._draw()
backend
Python 3.12 + FastAPI + Uvicorn
frontend
Static HTML, no framework, ~14 KB
model
Local open-weights 30–35B param LLM, no external API
tooling
MCP over stdio (JSON-RPC), one process per build
art
All hand-drawn SVG, no AI image generation
license
MIT, source in game/ + backend/
