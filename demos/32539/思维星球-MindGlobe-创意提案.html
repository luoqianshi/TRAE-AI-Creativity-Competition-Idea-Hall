The Solution

2D 球面投影 + 游戏式导航

不是 3D 应用，而是"球面展开的 2D 游戏地图"。整个思维网络存在数学球面上，但始终以 2D 投影渲染——像在开放世界游戏里探索地图，永远不会撞到"画布边缘"。

🖱️

点击即传送

点击任意节点，球面平滑旋转，该节点移动到屏幕正中央并刷新视野——和游戏地图点击移动主角一个手感。

🌐

无边缘画布

球面没有"正确方向"，任何点都能成为中心。思想可向任意方向无限延伸，告别"画布不够用"。

⚡

视野懒加载

只渲染视野内节点，进入视野才加载、离开即卸载。配合 Neo4j，轻松承载百万级节点不卡顿。

🧠

空间记忆

人会记住"这个概念在球体左上方"。把回忆变成空间定位，找东西不再靠翻找。

📖

文字不变形

所有节点始终正面朝向观察者，彻底解决 3D 球形导图文字透视变形难读的硬伤。

🔗

天然图结构

思维导图本质就是图。用 Neo4j 存储节点与关系，原生支持最短路径、多跳关联等复杂查询。

Tech Stack

Neo4j + Canvas 2D 投影引擎

前端用 Canvas 做球面坐标↔屏幕坐标转换与游戏式交互，后端用 Neo4j 图数据库，API 层提供节点 CRUD、空间范围查询与路径查询。

01

前端渲染层 · Canvas 2D

球面投影引擎（四元数旋转）+ 游戏式导航（点击/拖拽/滚轮）+ 视野懒加载。纯 Canvas，无需 WebGL。

▲
02

API 服务层 · GraphQL / REST

节点与关系 CRUD、基于球面坐标的空间范围查询、节点间最短路径查询。

▲
03

数据存储层 · Neo4j 图数据库

节点（Node）存储标题/内容/球面坐标，关系（CONNECTED_TO）存储类型/权重。天生处理百万节点。

// Neo4j 数据模型 —— 极简而强大
CREATE (n:Node {
  id: "uuid", title: "节点标题",
  content: "支持 Markdown", color: "#7c5cff",
  x: 0.5, y: 0.0, z: 0.5    // 单位球面向量坐标
})

// 视野范围内的节点（懒加载核心查询）
MATCH (n:Node)
WHERE distance(point({x:n.x,y:n.y,z:n.z}), point({x:$vx,y:$vy,z:$vz})) < $radius
RETURN n
