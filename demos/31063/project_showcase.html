ESP32-S3 智能物料管理系统

基于 ESP32-S3 开发的物联网智能物料管理解决方案，集成 Web 管理界面、LED 库位指示、相机拍照绑定、数据持久化等功能，实现仓库物料的智能化管理。

核心功能特性

🌐

Web 管理界面

内置 Web 服务器，支持 WiFi AP 模式，手机/电脑直接访问管理界面，无需安装额外软件。

💡

LED 库位指示

集成 WS2812 LED 灯带，支持库位搜索定位、空闲库位指示、低库存预警等功能，快速找到目标物料。

📷

相机拍照绑定

支持外接摄像头，拍照绑定物料照片，入库时直接拍照存档，便于物料识别和追溯。

💾

数据持久化

物料数据、操作日志、用户信息自动保存到 Flash 和 SD 卡，双重备份确保数据安全。

📊

数据导入导出

支持 CSV 格式导入导出物料数据，方便与 Excel 等工具对接，批量管理物料信息。

🔐

用户权限管理

支持多用户管理，区分管理员和普通用户，操作日志记录操作人信息，便于审计追溯。

🔄

OTA 远程升级

支持通过 Web 界面远程升级固件，无需拆机即可更新系统功能。

📱

移动端适配

管理界面采用响应式设计，完美适配手机、平板、电脑等多种设备。

🔍

智能搜索定位

支持按物料号、名称、规格、库位等多维度搜索，一键定位物料所在库位。

核心代码展示

📄 main.ino - 系统初始化

void setup() {
    Serial.begin(115200);
    
    // 1. 启动 Web 服务器和 WiFi
    webServer.init("MaterialManager", "12345678", true);
    
    // 2. 初始化 SD 卡
    sd_mmc_init();
    
    // 3. 初始化物料存储
    materialStorage.init();
    
    // 4. 初始化 WS2812 LED 控制器
    ledController.init();
    
    // 5. 初始化相机
    camera_init();
    
    Serial.println("\n✅ System ready!");
}

📄 material_storage.h - 物料数据结构

typedef struct {
    uint16_t id;           // 物料ID
    String code;           // 物料号
    String name;           // 名称
    String spec;           // 规格
    String unit;           // 单位
    uint16_t location;     // 库位号
    uint32_t quantity;     // 库存数量
    uint32_t minStock;     // 最低库存
    uint32_t maxStock;     // 最高库存
    MaterialType type;     // 物料分类
    String photoPath;      // 照片路径
    bool locked;           // 是否锁定
    uint32_t lastUsed;     // 最后使用时间
    uint32_t createdAt;    // 创建时间
} Material;
