🛒 简易电子商务系统
1. 创意名称 + 创意介绍
想解决什么问题：
为初学者提供完整的电商系统学习案例，为小型商家提供简单易用的线上销售工具，解决学习资源匮乏和入门门槛高的痛点。
为什么会想到做这个：
在学习数据库和编程课程时，发现缺少完整的电商系统实战案例，于是结合课程设计需求，开发了这个项目，将理论知识转化为实际应用。
大概是什么产品：
基于Python + SQL Server开发的轻量级电子商务系统，采用控制台交互方式，支持完整的电商业务流程。
2. 目标用户及痛点
面向哪些用户：
买家用户（普通消费者）、卖家用户（小商家）、管理员（运营人员）、学习者（学生和开发者）
在什么场景下使用：
买家浏览商品下单、卖家发布管理商品、管理员维护平台、学习者研究代码结构
当前痛点：
初学者缺乏完整学习案例，小型商家缺少轻量级工具，现有系统复杂度高、部署困难、学习成本高。
3. 价值与意义
教育价值：
提供完整的电商系统学习案例，帮助初学者理解数据库设计、业务逻辑和系统架构。
效率提升：
简化电商系统开发流程，降低入门门槛，让开发者快速搭建可用的电商平台。
技术栈：
Python 3.14 SQL Server 2022 pyodbc 分层架构
4. 核心功能
商品管理：
商品浏览、分类检索、关键词搜索、卖家发布/修改/删除商品
购物车系统：
添加商品到购物车、修改数量、删除商品、一键结算下单
订单管理：
订单创建、状态流转（待支付→待发货→待收货→已完成）、订单查询管理
用户管理：
用户注册、登录、个人信息修改、角色权限区分（BUYER/SELLER/ADMIN）
