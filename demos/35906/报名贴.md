# 【学习工作赛道】智课 AI Scheduler —— AI智能中小学排课工具

## 一、项目背景与痛点

中小学排课是一项高度复杂的资源协调任务。一所普通中学每周需要安排数百个班级、数十位教师、多类教室（普通教室、实验室、体育馆、音乐室）的交叉使用，同时满足课程均衡、教师连续授课限制、学生劳逸结合等隐性规则。

传统手工排课或基于简单规则的软件，存在以下核心痛点：

- **冲突频发**：教师分身乏术、教室重复占用、课程时间重叠，人工检查难以穷尽所有组合
- **效率低下**：一所学校排课平均耗时7-14天，调课响应以小时计，无法适应临时变动
- **规则繁杂**：主科优先上午、体育不连排、教师课时均衡、教研活动时间锁定——规则多达数十条
- **体验缺失**：教师偏好、学生选科意愿、课程连贯性等软性需求在手工排课中几乎被忽略
- **数据孤岛**：课表与人事、学籍、考勤系统割裂，信息重复录入，错误率高
- **应变僵化**：临时调课、代课、换教室需要重新计算全局，手工调整牵一发而动全身

## 二、解决方案与核心功能

**智课 AI Scheduler** 是一款面向中小学的AI智能排课系统，以"约束求解 + 大模型交互 + 实时协同"为核心技术栈，将传统数天的排课工作压缩至分钟级，同时让课表更懂师生需求。

三大核心功能：

1. **自然语言排课**：用户无需学习复杂界面，直接输入"把张老师的数学课都排在上午，周三下午留给教研活动"，系统通过大模型解析意图，自动转化为约束条件并重新求解。对话式交互大幅降低使用门槛，让教务主任像聊天一样完成排课。

2. **多目标智能优化**：系统内置遗传算法 + 模拟退火混合求解器，在硬约束（不冲突）必须满足的前提下，对软约束进行多目标优化——教师时间偏好满足率、学生课程节奏合理性、教室利用率、课程均匀分布等。生成多个Pareto最优解供用户选择，而非单一结果。

3. **实时协同与冲突预警**：任何调课操作在云端实时重算全局影响，冲突在发生前即被拦截。教师手机端可随时查看课表、申请调课、接收变动通知。系统与学校现有人事、考勤、教室门禁系统打通，形成数据闭环。

## 三、技术框架或实现思路

- **约束引擎层**：基于 Google OR-Tools 构建约束规划（CP-SAT）求解器，将排课问题建模为变量（课程单元）、域（时间槽位）、约束（硬约束 + 软约束）的三元组。对于超大规模实例采用分解策略：先按年级分区求解，再跨区协调。

- **AI交互层**：接入大语言模型（LLM）进行意图解析和约束抽取。通过 RAG（检索增强生成）注入学校私有规则库，确保模型理解"校本化"术语。对话历史作为上下文，支持多轮渐进式精化排课需求。

- **数据层**：采用多租户 SaaS 架构，支持公有云部署和私有化部署两种模式。核心数据模型包括：学校组织架构、教师档案与偏好、教室资源池、课程计划、排课规则库、课表版本历史。提供标准 API 与第三方教务系统对接。

- **前端体验层**：课表可视化采用时间轴 + 矩阵双视图：周视图呈现全校宏观排布，日视图聚焦细节冲突。拖拽调课操作即时反馈可行性（绿色可行 / 红色冲突）。教师端小程序支持语音查询。

## 四、应用场景与价值

**目标用户**：教务主任（核心决策者）、班主任（日常管理）、任课教师（课表查看与偏好设置）、校长/管理层（资源决策支持）、教育局（区域统筹）。

**应用场景**：
- 学期初大规模排课：将传统7-14天的工作压缩至分钟级
- 期中临时调课：实时重算全局影响，冲突即时预警
- 教师请假代课：一键生成替代方案，自动通知相关人员
- 区域多校统筹：教育局统一协调跨校资源（如共享实验室、走班教室）

**核心价值**：排课是学校教育运行的"操作系统"，一张好的课表不仅影响教学秩序，更关乎教师职业幸福感和学生学习效率。智课的长期愿景是成为教育时间管理的基础设施——让每一所学校都能用AI生成最优课表，让每一位教师都能拥有合理的工作节奏，让每一个学生都能在科学的课程安排中成长。

当技术真正理解教育的复杂性，冰冷的算法也能传递人文温度。这不是关于机器取代人的故事，而是关于如何将人的智慧从重复劳动中释放，投入到更有创造力的教育工作中去。
