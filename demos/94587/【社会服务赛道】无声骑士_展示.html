CORE FEATURES

四大核心能力

接听、转写、回复、通知——让每一次电话沟通都不再是障碍。

📞

来电自动接听

顾客来电时，系统自动接听并播放提示语"您好，骑手正在为您配送，请说您的需求"。顾客说话内容实时转为文字显示在骑手手机屏幕上，骑手无需手动接听。

自动接听 + 实时语音转文字(STT)
💬

一键话术回复

内置外卖场景专属话术库，骑手点击"马上到，预计3分钟""已放门口""请下楼取餐"等常用话术，系统自动合成为语音播报给顾客，全程不超过3秒。

话术库 + 文字转语音(TTS) + 一键发送
🔊

主动语音通知

骑手到达楼下无需打电话，系统自动合成语音拨打给顾客"您的外卖已到达，请下楼取餐"。骑手也可自定义通知内容，文字一键转语音拨出。

TTS合成 + 自动外呼 + 自定义内容
📊

差评智能申诉

系统自动记录每次沟通的完整文字聊天记录。当听障骑手收到因"电话打不通"导致的差评时，可一键导出沟通记录作为申诉证据，自动提交平台申诉。

沟通记录 + 自动申诉 + 差评防护

TECHNOLOGY

技术原理与亮点

从电话接听到语音播报，AI在背后完成了语音识别、场景理解和语音合成的完整链路。

01

实时语音转文字(STT)

采用流式语音识别技术，顾客说话的同时逐字转写，延迟低于500ms。针对外卖场景优化识别模型，准确识别"放前台""下楼取餐""门禁"等配送术语，识别准确率达95%以上。

streaming ASR → text (latency < 500ms)
02

自然语音合成(TTS)

将骑手选择的文字话术合成为自然流畅的语音播报给顾客。支持多种音色选择，语速可调，合成语音自然度高，顾客几乎听不出是AI合成，避免"机器感"带来的不信任。

text → neural TTS → natural voice
03

外卖场景话术推荐

基于骑手当前配送状态（取餐中/配送中/已到达）和顾客消息内容，AI智能推荐最合适的回复话术。当顾客说"到哪了"，系统自动将"马上到，预计3分钟"置顶推荐。

context + intent → recommend(phrase)
04

沟通记录与差评申诉

每次通话的完整文字记录自动云端存档。收到差评时，系统自动匹配对应订单的沟通记录，生成申诉材料（包含时间线、沟通内容、骑手响应时间），一键提交平台申诉。

record → match(order) → autoAppeal()
SCENARIOS

六大使用场景

从接单到送达，每一个沟通节点都不再是障碍。

📞

顾客来电催单

顾客打电话问"到哪了"，AI自动接听转文字，骑手看到后一键回复"马上到，预计3分钟"，语音播报给顾客。

🏠

到达楼下通知

骑手到楼下，系统自动合成语音拨打给顾客"已到楼下，请下楼取餐"，骑手无需手动打电话。

🗺️

找不到地址

骑手找不到顾客地址，一键发送"找不到地址，能发个定位吗"，语音播报后顾客回复定位，文字显示给骑手。

🏪

商家出餐慢

商家出餐慢导致超时风险，骑手一键通知顾客"商家出餐慢，请稍等"，提前沟通避免差评。

📦

放门口/前台

顾客要求放门口，骑手放置后一键回复"已放门口，请查收"，语音通知顾客，完成无接触配送。

📝

差评自动申诉

收到"电话打不通"差评时，系统自动调取沟通记录生成申诉材料，证明骑手已通过AI完成沟通，一键申诉。
