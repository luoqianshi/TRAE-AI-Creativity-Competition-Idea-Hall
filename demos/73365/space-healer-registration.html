空间治愈师

拍一张照片，还你一个会呼吸的空间

01 · 创意介绍

收纳是每个人日常生活中的刚需，尤其是住宿生、租房族和小户型居民。打开衣柜发现衣服堆成山、书桌上找不到笔、宿舍角落塞不下任何东西——"不会收纳"不只是懒，而是缺乏一套针对自己空间的组织方法。

小红书上的收纳教程都是"别人家的"，看着很厉害但不知道怎么用在自己的空间上。我们希望做一个工具，能像"收纳好友"一样，针对每个人的真实空间给出个性化建议。

产品形态：基于 AI 对话式交互的 Web App / 小程序。

核心流程

📷 拍照 → 🤖 AI 追问 → 📋 收纳方案 → 📤 分享对比

02 · 目标用户与痛点

核心用户

住宿生 租房族 小户型居民

使用场景

  • 周末整理衣柜时
  • 搬家后重新布置空间时
  • 学期初收拾宿舍时
  • 网购收纳用品前规划时

当前痛点

  • 搜小红书教程 → "别人家的收纳"，跟自己的空间无关
  • 买收纳用品 → 不知道怎么搭配自己的实际空间
  • 收纳完又乱了 → 没有持续的收纳习惯和回访机制
  • 想找人帮忙 → 专业收纳师费用高，学生负担不起

效率提升

AI 3 分钟生成个性化收纳方案，从"看完教程还是不会"变成"拍张照片就知道怎么整"。方案附带购买清单和量化效果预估，让用户真正落地执行。

社会价值

帮助千万住宿生和租房族用更低成本获得更高品质的生活空间，降低"空间焦虑"。让"人人都可以拥有整洁的空间"不再是一句口号。

04 · 产品亮点

  • 对话式交互：AI 像"收纳好友"一样温暖追问，不是冷冰冰的表单
  • 空间数据采集：基于真实尺寸和物品数量计算方案，不是"猜"的
  • 量化效果：空间利用率 65% → 90%，效果看得见
  • 购买清单直达：从建议到执行只差一步
  • 效果对比分享：收纳前/后对比卡片，社交裂变自然发生

05 · 技术方案

  • 前端：React / Vue + Tailwind CSS，Camera API 拍照上传
  • AI 对话：TRAE Work 搭建对话流程，接入大模型 API
  • 规则引擎：收纳知识库（衣柜/桌面/厨房规则），每场景 10-15 条黄金法则
  • 存储：用户记录、方案记录、投稿图片
