痛点分析

当前人机交互的困境

在众多场景中，传统交互方式存在明显局限，亟需更自然、更高效的替代方案。

  • 🏭

    工业车间 — 双手被占用

    工厂产线工人操作设备时双手佩戴手套或沾满油污，无法触碰触摸屏或键盘，导致设备控制中断，影响生产效率。

  • 🏥

    医疗手术 — 无菌要求严格

    手术室中医护人员需要在无菌环境下翻阅影像资料或控制设备，触碰屏幕会带来交叉感染风险，目前缺乏有效的免接触交互方案。

  • 🏠

    智能家居 — 操作碎片化

    智能家居设备分散在不同 App 中，用户需要频繁解锁手机、打开应用才能完成简单控制，体验碎片化且低效。

  • ♿

    无障碍场景 — 交互门槛高

    行动不便的用户（如残障人士、老年人）使用传统输入设备存在困难，缺乏低门槛的替代交互方式。

技术栈

核心技术选型

轻量化模型 + 成熟框架，兼顾精度与部署成本。

🧠 模型层

YOLOv8-nano Ultralytics ONNX Runtime OpenCV

基于 YOLOv8-nano 定制训练手势检测模型，通过 ONNX 导出实现跨平台推理，OpenCV 处理视频流。

⚙️ 工程层

Python 3.11 FastAPI MQTT WebSocket

Python 主控逻辑，FastAPI 提供 REST/WebSocket 接口，MQTT 桥接 IoT 设备通信。

🖥️ 部署层

Raspberry Pi 5 Jetson Nano Docker Edge TPU

支持树莓派、Jetson 等边缘设备部署，Docker 容器化一键启动，可选 Edge TPU 加速。

📊 数据层

自采集数据集 Roboflow 数据增强 YOLO 格式标注

自采集 + 公开数据集混合训练，Roboflow 标注与增强，YOLO 格式统一管理。

开发计划

项目里程碑

Phase 1 — 模型训练

手势数据集构建 + YOLO 模型训练

采集 12 种手势图像数据，使用 Roboflow 标注增强，训练 YOLOv8-nano 模型，达到 mAP50 > 0.92。

Phase 2 — 桌面应用

PC 端手势控制 MVP

实现摄像头实时检测 → 手势分类 → 系统指令映射（音量、媒体、截屏等），完成桌面端 MVP。

Phase 3 — IoT 集成

智能家居 & 边缘设备部署

对接 MQTT 协议，实现手势控制智能灯、窗帘等 IoT 设备；树莓派 5 部署优化，推理延迟 < 30ms。

Phase 4 — 产品化

可视化配置界面 + 开源发布

开发 Web 配置面板，支持用户自定义手势-动作映射；完善文档，发布开源社区。
