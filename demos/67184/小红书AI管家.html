创意介绍

用技术创新解决真实痛点

想解决什么问题

小红书创作者、MCN 机构和矩阵号运营者每天要在 App 上重复操作"登录、切号、发笔记、看数据、回评论"，效率极低且无法程序化；而市面工具要么依赖黑盒云服务、要么使用易风控的模拟点击，缺乏安全可控的本地化方案。

为什么会想到做这个

灵感来源于一个真实场景：帮朋友运营 3 个美妆垂类账号时，发现每发一篇笔记要重复切换 4–5 次 App，而 MCP（Model Context Protocol）正在成为 AI 工具与本地服务对话的新标准。我们用 MCP 把"小红书能力"封装成本地 REST 服务，再让 AI Agent 和 CLI 直接调用，从此"发小红书"可以像写 SQL 一样一句话完成。

大概是什么产品

一款本地化、CLI 优先、MCP 兼容的 Python 命令行工具（同时也是 AI Agent 工具箱），把"账号管理—登录—发布—搜索—互动—用户数据"全部串成可脚本化的原子能力。

使用场景

  • 凌晨/午休时段，用一行命令批量发笔记给自己所有账号
  • 用 AI Agent 写完文案，直接 xhs publish 一键发布，不离开终端
  • 跑数据脚本时，自动搜索关键词并拉取 Top 100 笔记的详情 + 评论
  • 多个账号轮换操作时，一条 xhs account switch 5 秒切换身份

创造真实价值，推动行业进步

账号管理

内容发布

Feed 检索

关键词搜索、推荐内容列表、笔记详情获取

xhs feed search xhs feed detail

互动操作

点赞、收藏、评论、回复，全流程自动化

登录管理

一键下载、启动、管理 MCP 服务器，AI 接入就绪
