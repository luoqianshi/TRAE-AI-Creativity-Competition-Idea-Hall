01

创意介绍

Problem / 问题

任务太多，规划太累

很多人每天脑子里塞满"要做的事"，但随手记在便利贴上丢三落四，或在多个 App 间反复切换，真正花在"规划"上的时间比"做事"还多。我们缺的不是记录工具，而是一个能"听懂人话"并自动完成整理的智能助手。

Inspiration / 灵感

从"想不起来先做哪个"说起

自己在学习和工作中最头疼的不是事情多，而是"想不起来该先做哪个"。现有工具要么太重（Notion、飞书），要么太轻（备忘录），缺一个"说出来就能自动归类、自动排优先级"的中间态。

Product / 产品

Web 端智能任务管理工具

支持文字输入、语音录入、截图识别三种方式快速创建任务，AI 自动提取任务名称、截止时间、优先级，并生成每日工作计划。无需复杂配置，开箱即用。

02

目标用户及痛点

Target / 目标用户

上班族、自由职业者、在校学生

特别是每天需要处理 5 个以上零散任务、但没时间精细管理的人。

Scenarios / 使用场景
  • 开会/上课时突然想到一件事，掏出手机说一句就能记下
  • 每天早上打开工具，AI 已根据任务优先级排好今天的顺序
  • 下班前快速回顾，一眼看到哪些完成了、哪些延后了
  • 收到老板微信截图列了 5 件事，直接贴进工具，AI 自动拆成任务
Pain Points / 当前痛点
痛点 具体表现
记不住 记在脑子里忙起来就忘；记在备忘录里找不到
排不开 10 个任务堆在一起，不知道先做哪个，陷入选择焦虑
理不清 待办和工作日历是分开的，看不到任务和时间的对应关系
03

核心机制

智能优先级判定

AI 从用户描述中自动提取信号，综合评估后给出智能排序，并以简短标签说明原因。用户可一键手动调整，系统会记住偏好，越用越懂你。

Priority Signals / 优先级信号
信号类型 示例 推断结果
时间词 "明天交"、"下周一前" 截止时间越近 → 优先级越高
紧急词 "紧急"、"赶紧"、"马上" 直接标记为高优先级
任务依赖 "等张总回复后再做" 有前置依赖 → 链条上游优先
影响/后果 "不交会扣钱"、"影响演示" 后果越严重 → 优先级越高
Input Methods / 三种输入方式
方式 说明 技术实现
文字输入 (P0) 核心体验，所有用户都能用 前端输入框 + LLM API 解析
语音输入 (P1) 锦上添花，MVP 阶段先用系统语音输入法 浏览器录音 API 或系统语音输入法
截图识别 (P1) 差异化亮点，解决聊天记录/邮件截图提取任务 OCR 提取文字 + LLM 识别任务
04

价值与意义

Efficiency / 效率提升

每天省下 15-30 分钟

把"记任务 + 排优先级 + 做计划"三步从手动操作变成 AI 自动完成。用户只需要开口说（或打字、截图），省下每天繁琐的任务整理时间，把精力集中在真正重要的事情上。

Business / 商业价值

高频刚需，口碑传播

个人任务管理是高频刚需场景，工具型产品天然适合口碑传播。未来可扩展至团队协作（共享任务看板 + AI 分配建议），具有清晰的商业化路径。

05

技术实现思路

  • 前端：React/Vue Web 应用，适配桌面端和移动端
  • AI 能力：调用大语言模型 API（GPT-4 / 通义千问 / 豆包）进行任务信息提取和优先级判定
  • 数据存储：本地 localStorage 或简单后端数据库（如需多端同步）
  • 截图识别：先用 GPT-4V 做 MVP，后续可切换专用 OCR + 文字 LLM 组合方案
