核心功能

从 AI 智能问答到知识库全生命周期管理，覆盖健康宣教完整链路

AI 智能问答

基于 RAG 技术，SSE 流式响应逐字呈现。回答标注引用文章、科室、审核人，100% 可溯源，杜绝医疗幻觉。

知识库管理

宣教文章全生命周期管理：草稿 → 审核 → 发布 → 归档。知识自动切片与向量化，一次建设持续复用。

语音输入

支持 Web Speech API 语音提问，方便老年患者和行动不便的患者使用，降低数字门槛。

三端分离架构

管理端、医护端、患者端独立工作流，RBAC 权限粒度到科室级别，JWT 认证 + 科室数据隔离。

运营数据统计

知识覆盖率、患者提问热力图、用户活跃度、问答满意度统计，为医院优化宣教策略提供数据支撑。

安全合规

系统定位为健康宣教工具，无诊断权无处方权。字段加密、日志脱敏、PII 保护，严格遵守医疗合规边界。

目标用户及使用场景

三端分离设计，服务患者、医护、管理者三类核心用户

住院 / 出院患者

术后护理、用药指导、饮食禁忌等健康知识需求。打开手机浏览器即可 7x24 随时提问，AI 基于医院审核过的知识库给出可溯源回答。

医护人员

医生、护士、科室管理员。通过医护端高效管理宣教内容，发布文章自动向量化入库，减少 60%+ 重复答疑工作量。

医院管理者

通过数据看板了解科室健康宣教覆盖率、患者提问热点，优化宣教策略，提升医院服务质量与患者满意度。

价值与意义

从社会价值、效率提升、安全保障三个维度，让健康宣教更高效、更安全、更普惠
