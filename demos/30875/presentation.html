1

创意名称与介绍

💡 想解决什么问题

青少年学业压力大、情绪波动频繁，却缺少一个安全、低压力的情绪出口。传统心理咨询门槛高、预约周期长，且带有"病耻感"——很多孩子不是不想求助，而是害怕被贴上"心理有问题"的标签。他们需要的是一个轻松的、不像"看病"的地方。

🌱 为什么想到做这个

身边的同学把烦恼憋在心里，要么深夜刷短视频麻痹自己，要么在社交平台发"仅自己可见"的动态。我们意识到：青少年需要的不是另一个"心理咨询 App"，而是一个像朋友一样、随时在、不评判的陪伴空间。

📱 产品形态

移动端 Web 应用（小程序风格），主打"无压力陪伴 + 游戏化疗愈"。无需注册、全程匿名、打开即用，包含 AI 情绪树洞、呼吸正念、涂鸦宣泄、白噪音助眠、习惯打卡五大模块。

2

目标用户及痛点

👥 面向哪些用户

12-18 岁初高中学生，尤其是学业压力大、情绪波动频繁但不愿主动寻求帮助的青少年群体。他们熟悉智能手机操作，习惯轻量级应用，对"说教式"内容天然抵触。

📚

考试焦虑型

大考前失眠、紧张，需要快速放松的方法

😶

情绪压抑型

有烦恼但不愿跟家人朋友说，需要一个匿名出口

🌙

失眠困扰型

晚上睡不着，思绪乱飞，需要助眠工具

习惯养成型

想建立好的生活节奏但缺乏动力和追踪

使用场景

  • 晚自习后心情低落，不想跟家人说，打开 App 匿名倾诉
  • 考试前焦虑失眠，用白噪音 + 呼吸练习放松入眠
  • 心情烦躁时打开涂鸦画布随意画画宣泄情绪
  • 每天打卡一个小习惯，积累成就感和掌控感
  • 课间 5 分钟做一次呼吸练习，快速调整状态

当前痛点

  • 心理咨询预约周期长、费用高，青少年难以独立承担
  • 跟朋友说怕被传开，跟家长说怕被说"矫情"
  • 市面上的心理类 App 大多偏"诊疗"风格，打开就有压力
  • 没有持续的情绪追踪和自我觉察工具，情绪来了不知道怎么办
3

价值与意义

社会价值：精准回应青少年心理健康这一社会热点。不是替代专业心理咨询，而是在"无感觉"和"看医生"之间补上一个轻量级的情绪缓冲带。三级健康引导机制在不过度干预的前提下，为真正需要的用户提供专业求助通道，兼顾了社会责任与用户自主性。

效率价值：零后端架构 + localStorage 本地存储，无需服务器即可运行，部署成本趋近于零。AI 混合方案（离线关键词引擎 + 可选大模型 API）兼顾了离线可用性与在线升级能力，关键词引擎基于 CBT/ACT 循证心理方法设计，80+ 条共情话术确保回复质量。

4

核心功能

🌳

AI 情绪树洞

匿名全天候倾听，基于循证心理方法给出共情回复，不做说教，识别高风险情绪时温和推送求助渠道

🌬️

呼吸正念

4-7-8 呼吸法动画引导，圆形跟随节奏缩放变色，4 轮完成给予鼓励反馈

涂鸦宣泄

Canvas 全屏画布，8 种柔和色彩 + 3 档笔刷，支持保存为图片，用色彩释放情绪

🌙

白噪音助眠

6 种自然场景程序化音频生成，支持混合播放与独立音量控制，定时自动关闭

情绪日记

每日选择情绪 emoji + 文字记录，按日期排列回顾，培养情绪觉察习惯

习惯打卡

预设 5 项健康习惯 + 自定义，打卡触发彩纸动画，7 日可视化日历追踪

🛡️ 三级健康引导机制

级别 触发条件 响应方式
L1 关注 检测到压力/焦虑关键词 聊天中穿插温和科普小贴士
L2 提醒 多次出现负面情绪 / 自贬词汇 弹出「你需要休息一下」卡片
L3 引导 检测到自伤/绝望关键词 展示专业求助热线（非强制弹窗）

🔑 核心亮点

  • 混合 AI 方案：默认离线关键词引擎零延迟响应，配置 API Key 后无缝切换大模型，比赛演示不依赖网络
  • 游戏化疗愈：打卡彩纸动画、涂鸦保存分享、呼吸球变色引导——用游戏化体验替代严肃干预
  • 零门槛隐私保护：无需注册，localStorage 本地存储，不收集任何个人信息
  • 循证心理方法：回复话术基于 CBT（认知行为疗法）和 ACT（接纳承诺疗法）设计，不评判不说教
  • 程序化音频：Web Audio API 生成白噪音，无需外部音频文件，支持混合播放
