卡塞尔学院门户

沉浸式龙族世界观互动站

"凡王之血，必以剑终。"

创意介绍

想解决什么问题

龙族粉丝对小说中的卡塞尔学院充满向往，但只能通过文字想象，缺乏沉浸式的体验入口。同人内容分散在各个平台，缺少一个有仪式感、能让粉丝"真正进入"卡塞尔学院的地方。粉丝想扮演"学员"角色，但没有合适的载体。

为什么会想到做这个

从《龙族》小说获得灵感，小说里对卡塞尔学院的描写（学籍编号、言灵、血统评级、任务系统）非常适合游戏化和互动化。结合互动式剧情和炫酷视觉设计，能让粉丝从"读者"变成"学员"，获得更强的代入感和归属感。

大概是什么产品

一个具有炫酷视觉效果的互动网站，模拟卡塞尔学院的内部系统。用户通过"言灵觉醒仪式"获得专属学员身份，体验学院任务、解锁龙文档案、生成专属学员卡片分享，打造沉浸式的龙族世界观体验。

目标用户及痛点

面向哪些用户
  • 核心用户：《龙族》老粉，对卡塞尔学院设定有深厚感情的读者
  • 次核心用户：喜欢沉浸式角色扮演、互动剧情的用户
  • 泛用户：对炫酷视觉效果和游戏化体验感兴趣的爱好者
在什么场景下使用
  • 首次体验：被分享吸引，点开链接体验"言灵觉醒"，获得专属档案
  • 日常回访：闲暇时"回学院看看"，完成新任务，解锁新内容
  • 社交分享：生成精美的学员档案卡片，分享到朋友圈/微博
  • 同好交流：和其他粉丝对比档案、讨论剧情，增加社群话题
当前痛点
  • 只有小说文字，缺少具象化的学院沉浸式体验
  • 同人内容零散，没有统一的世界观互动载体
  • 粉丝想玩"角色扮演"但缺少工具和场景
  • 经典 IP 的互动化、游戏化再创作较少

价值与意义

🎮

娱乐价值

将经典 IP 进行游戏化、互动化再创作，为粉丝提供新的沉浸式体验方式。不只是"看小说"，而是"走进小说"，增强粉丝社群的粘性和活跃度。

💡

创意价值

探索"小说 IP + 互动网站"的结合模式。通过炫酷的视觉设计和游戏化机制，把静态的文字世界变成可交互的数字体验。

核心功能模块

⚡

言灵觉醒仪式

用户首次访问，经历炫酷的觉醒动画，随机抽取言灵（不同稀有度），生成学员档案，提供有限次数重抽机会

📋

学员档案系统

展示个人信息、言灵能力卡、成长数据，生成档案卡片图片，支持社交分享

📜

剧情任务系统

任务大厅列表，互动式剧情体验，选择分支，多结局，任务奖励结算，进度自动存档

🔮

龙文档案馆

龙文图鉴收集，稀有度分级（普通/稀有/传说），详情查看，完成任务/升级解锁

🏠

学院首页

欢迎界面，每日龙族名言，功能入口导航，公告栏，其他学员展示

🗺️

校园地图

学院全景地图，可点击地点进入对应场景（图书馆、竞技场、校董会等）

MVP 版本规划

✅ 必做功能 (P0)

  • 炫酷视觉效果：粒子背景、玻璃拟态
  • 言灵觉醒仪式：随机抽取 + 动画
  • 学员档案页：个人信息 + 言灵卡
  • 新手任务剧情：1个完整任务
  • 本地数据存档：localStorage

⭐ 重要功能 (P1)

  • 档案卡片生成：保存图片分享
  • 龙文档案馆：5-10个龙文示例
  • 学院首页：功能导航 + 公告

💡 点缀功能 (P2)

  • NPC 学员展示：营造氛围
  • 任务大厅界面：展示多个任务

❌ 暂时不做

  • 真实后端和用户系统
  • 查看真实用户档案
  • 剧情编辑器
  • 大量剧情内容

设计风格

整体风格

暗黑学院风 + 金箔奢华感 + 龙族神秘氛围

颜色 预览 色值 用途

视觉效果
  • 金色光晕 / 辉光效果
  • 粒子漂浮（金色尘埃感）
  • 玻璃拟态卡片（backdrop-filter）
  • 龙纹暗纹背景装饰
字体
  • 标题：Cinzel / 思源宋体（庄重典雅的衬线字体）
  • 正文：Noto Sans SC / 系统无衬线（保证可读性）
  • 数字编号：等宽字体（模拟机械/编号感）
动效设计
  • 言灵觉醒：金光扩散 + 粒子汇聚 + 全屏闪光
  • 卡片 hover：上浮 + 金色光晕扩散
  • 按钮交互：涟漪效果 + 微缩放 + 发光
  • 页面切换：淡入淡出 + 轻微位移
  • 剧情文字：打字机效果逐字显示
