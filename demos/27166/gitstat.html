GitStat

本地 Git 仓库提交数据可视化分析平台

🎯 创意介绍

痛点：开发者缺少离线、交互式的多仓库提交数据分析工具。现有方案要么依赖 GitHub API（需联网），要么生成静态 HTML 不可交互，配置繁琐。

形态：单二进制 Web 应用，Go 后端 + Vue 3 前端，内嵌 ECharts，启动即用。

👥 目标用户 & 痛点

  • 个人开发者 — 跨项目追踪编码活跃度
  • 技术管理者 — 团队提交概况一目了然
  • 开源维护者 — 分析贡献者提交模式
  • 内网环境 — 代码不出本机，隐私安全

⚡ 架构流程

  ┌──────────┐   git log --numstat    ┌──────────┐   REST API    ┌──────────┐
  │  Git 仓库 │ ──────────────────→  │  Scanner  │ ───────────→ │  Handler  │
  │  (.git)   │                       │  Parser   │              │  LazyLoad │
  └──────────┘                       └──────────┘              └─────┬────┘
                                                                     │
  ┌──────────┐                       ┌──────────┐                   │
  │  ECharts  │ ←────────────────── │  Store    │ ←─────────────────┘
  │  可视化    │    Response JSON     │  LRU缓存  │
  └──────────┘                       └──────────┘

✨ 核心功能

零配置多仓库扫描 懒加载 日历热力图 作者排行榜 仓库雷达图 多粒度时间聚合 1 键 JSON 导出 双语界面

💎 价值

效率：启动即用，30 秒看懂全项目提交全景

隐私：全离线运行，数据不离本机

团队：辅助研发效能评估，驱动改进决策
