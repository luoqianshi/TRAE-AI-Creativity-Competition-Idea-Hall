我们的星球

一个由 Three.js 构建的 3D 浪漫星球，周围环绕着代表不同功能的漂浮气泡。 点击气泡即可进入对应的功能房间，带来沉浸式的情侣使用体验。

💝 核心功能

每一处都为爱设计

— 根据你的项目源码 —

📖

回忆房间

时间轴记录你们的每一个重要时刻，从第一次约会到每个纪念日。搭配照片墙模块，将甜蜜瞬间一一珍藏，点击即可放大回味。

🎮

游戏房间

内置多款情侣互动游戏：甜蜜转盘（自定义项目 + 惩罚模式）、接住爱心小游戏、情侣飞行棋、MBTI 性格测试。每款游戏都为情侣互动精心设计。

⭐

愿望房间

写下两个人的心愿清单，每次完成一个愿望都会增加进度条。许愿、实现、标记完成——让共同的梦想一步步照进现实。

🌤

双城天气 · 关心彼此

支持设置你和 TA 所在的两个城市，实时显示双方天气温度和状况。即使异地，也能知道对方那边是晴是雨，提醒添衣带伞。

📍

距离测算 · 心在咫尺

利用浏览器定位 + Haversine 公式，实时计算你和伴侣之间的直线距离。每一次刷新都是「此时此刻我们相距 XXX 公里」的浪漫告白。

🎵

环境音乐 · 星空音律

当没有背景音乐文件时，自动用 Web Audio API 生成环境音乐：A minor 温暖无人机和弦 + 随机风铃音效，营造浪漫静谧的星空氛围。

甜蜜转盘

Canvas 绘制的彩色转盘，支持自定义项目和惩罚模式，转到什么做什么，充满惊喜。

接住爱心

键盘 / 触摸控制篮子接住下落的爱心，得分越高掉落越快，考验默契的小游戏。
