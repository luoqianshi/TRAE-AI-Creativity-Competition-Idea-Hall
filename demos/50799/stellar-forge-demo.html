核心理念
🌌

物理驱动，非预设

不依赖预设星球模板，从种子出发通过物理方程递归生成星系、恒星、行星、大气、地质与资源。每一个宇宙都是独一无二的。

⚙️

模拟优先，渲染解耦

数值引擎与渲染层彻底分离。模拟层独立运行，保证物理一致性；渲染层可自由替换，为未来接入 UE5 或其他引擎预留空间。

🔗

整数守恒，精确记账

所有守恒量使用 int64 精确记账，浮点仅用于派生计算。从根源杜绝"凭空造物"，让工业系统拥有物理级别的严谨性。

🤖

AI 做重活

扩散模型与 LLM 承担视觉生成和智能决策，3D 高斯溅射实现高质量场景重建。AI 不只是噱头，而是生产力的一部分。

痛点与解法

现有产品的困境

  • Space Engine：壮丽宇宙但缺乏深度交互和玩法
  • Factorio / 戴森球计划：工业精深但宇宙感不足
  • No Man's Sky：无限星球但交互浅薄
  • 太空建造游戏总在"宇宙感"和"系统深度"间二选一
  • 数值膨胀导致后期体验崩塌

Stellar Forge 的回答

  • 物理真实的宇宙本身成为玩法的一部分
  • Create Mod 风格的多物态工业系统（5 种物态）
  • 跨星际物流网络，排队论驱动的可达性设计
  • 宇宙模拟 × 工业建造深度融合
  • int64 守恒记账保证数值永续精确
核心特性
01

双轨数值系统

int64 精确守恒 + float64 派生计算，Kahan 累加器防止浮点漂移，跨尺度自动传播。

02

多频率仿真调度

三级仿真频率（10Hz 精细 / 1Hz 批量 / 0.01Hz 宏观）并发运行，自适应调度。

03

物理世界生成

种子驱动的全管线生成：星系 → 恒星（光谱/演化/星风）→ 行星（轨道/地质/卫星/环）→ 大气 → 生态 → 资源。

04

工业与物流

配方式生产、多工厂链条、电网与污染模拟；多模式运输（传送带/车辆/管道/铁路/船舶），含寻路系统。

05

沉浸式终端

USS FORGE 飞船终端：传感器扫描、导航计算、AI 助手（LLM 集成）、MUD 式探索、中英双语命令。

06

确定性与可存档

PCG32 确定性随机数、完整 JSON 存档/读档、事件总线跨线程通信、多级日志系统。

核心价值

Stellar Forge 瞄准的是太空建造/自动化这一持续增长的游戏品类。它以"物理真实"作为核心差异化卖点，试图打破"宇宙感"与"系统深度"不可兼得的行业惯例。

技术层面，它探索了一种新的游戏设计范式——数值模拟引擎驱动游戏逻辑，渲染层彻底解耦。AI 辅助的视觉生成（扩散模型 + 3D 高斯溅射）代表了游戏内容生产的前沿方向。

这不仅是一个游戏项目，更是对"如何让程序自主生成可信世界"这一技术命题的一次深度实践。
