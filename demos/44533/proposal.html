01

创意介绍

创意名称

银发守护 AI 伴侣（SilverGuard AI Companion）—— 一款面向独居老人的智能生活助手与情感陪伴系统。

想解决什么问题

中国 60 岁以上独居老人已超过 1.2 亿，他们面临三大核心痛点：

  • 安全风险高：突发疾病、跌倒、火灾、煤气泄漏等意外无法及时发现，黄金救援时间被浪费。
  • 健康管理难：慢性病用药提醒、血压血糖监测、复诊预约等缺乏系统化管理工具。
  • 情感孤独深：子女忙于工作，老人长期缺乏陪伴，心理健康问题被严重忽视。

灵感来源

我的外婆今年 82 岁，独自住在老家。去年冬天她凌晨起夜时不慎在卫生间摔倒，直到早上邻居串门才被发现。这件事让我意识到：技术可以弥合距离，但前提是它必须足够简单、足够温暖、足够可靠。

现有的智能设备对老人来说操作门槛太高——智能手环需要充电、配对、看屏幕，老人不会用、不愿戴，最终沦为抽屉里的摆设。而单纯的监控摄像头又让人有强烈的被监视感，老人心理上难以接受。我们需要一个既智能又有人情味的解决方案。

产品形态

一款以 微信小程序 为核心交互界面、配合 极简智能硬件（语音交互终端 + 环境传感器）的综合服务系统。老人端几乎零学习成本——说话就能用；子女端通过小程序远程掌握老人状态；社区端通过管理后台实现批量化精准关怀。

典型使用场景

场景一

夜间跌倒检测与自动报警

凌晨 2 点，老人起夜时不慎在卫生间跌倒。环境传感器检测到异常震动 + 长时间无移动，AI 语音终端主动询问："您还好吗？" 30 秒内无回应，系统自动拨打 120 并通知子女。从跌倒到报警，全程不超过 90 秒。

场景二

用药智能提醒与记录

老人每天需要服用 3 种药物。AI 伴侣在早中晚固定时间语音提醒："张奶奶，该吃降压药了，记得配温水。" 老人只需说"吃了"，系统自动记录用药时间。若连续两次未确认，通知子女关注。

场景三

情感陪伴与孤独干预

老人独自在家看电视，AI 伴侣感知到长时间沉默后主动发起对话："今天天气不错，要不要聊聊您年轻时的工作？" 通过语音交互提供新闻播报、戏曲点播、回忆录记录等功能，让老人感受到"有人在陪"。

当前痛点

  • 老人跌倒后平均 6 小时 才被发现，错过最佳救治时间
  • 子女每天打电话询问，老人总说"没事"，真实情况难以掌握
  • 市面上智能手环操作复杂，老人不会用、不愿戴，最终沦为摆设
  • 社区养老人力有限，一名网格员要负责数百户老人，无法做到精准关怀

技术实现路径

全程使用 TRAE Work 进行开发，技术栈规划如下：

前端

  • 微信小程序原生框架（WXML + WXSS + JS）
  • TRAE Work 辅助生成 UI 组件与页面逻辑

后端

  • Node.js + Express RESTful API
  • MongoDB 存储用户数据与健康记录
  • WebSocket 实现实时消息推送

AI 能力

  • 语音识别与合成：微信小程序内置能力 + 百度语音 API
  • 自然语言对话：接入大模型 API，由 TRAE Work 封装对话逻辑
  • 异常检测算法：基于传感器数据的规则引擎 + 简单机器学习模型

硬件（初赛阶段可用模拟器替代）

  • 初赛 Demo：使用 Web 端模拟语音终端界面，演示核心交互流程
  • 复赛/决赛：对接真实硬件原型（基于 ESP32 的语音交互终端 + 传感器模组）
