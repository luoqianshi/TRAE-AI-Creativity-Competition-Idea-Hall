01

创意名称 & 创意介绍

当大多数学习软件还在用"题库 + 答案"的方式对待学生时，我们想做点不一样的。

想解决什么问题

初高中生每天要面对语数英、物化地六门学科的大量知识，却普遍面临"没人教、记不住、练不透"的三重困境：课堂上听懂了回家又忘，做过的题换个问法就不会，错题本沦为"抄答案"的形式主义。市面上的学习 App 又往往臃肿、广告满天飞、强行引导付费，且很少真正"懂"这个孩子。

为什么会想到做这个

灵感来自一次陪家中妹妹做物理题的经历——她对着牛顿第二定律的解析反复看了五遍仍不得要领，因为讲解的方式并不匹配她的思维方式。我突然意识到：每个孩子都该有一个"自己的"AI 老师，它记得住她的笔记、看得见她的错题、说得出她能听懂的话。于是有了「翠码学坊」——翠，是品牌色，是清透的水晶质感，更是"青出于蓝"的期待。

大概是什么产品

一款纯前端、零依赖、零安装的 Web 学习应用：双击 index.html 即可在浏览器中打开运行，覆盖笔记、学习计划、AI 陪学、错题本、学情分析、截屏问答、命令面板等全部核心场景。它不是 App，也不是小程序，而是一个"装在 U 盘里就能用"的随身学伴。

02

目标用户 & 痛点

我们先描绘出三个真实的使用者，再来看他们各自的"难"。

🧑‍🎓

小琪 · 初三

主用户：初高中生

课业压力大，自主学习时间零碎，想要一个能随时提问、又能记住自己错题的"小老师"。

👨‍👩‍👧

琪妈 · 家长

次用户：家长

担心孩子沉迷手机、又被广告与游戏分心；希望能清楚看到孩子学了多久、薄弱点在哪里。

🏫

乡村教师

延伸用户：教师

所在学校资源有限，渴望一款不挑设备、装上即用的 AI 助教，能批量生成针对班级共性错题的讲解。

他们在什么场景下使用

  • 课后复习：做完一张卷子，把错题拍照/截图发到翠码学坊，AI 立即给出针对性讲解，并自动收录进错题本。
  • 写作业卡壳：遇到不会的物理大题，按 Ctrl+K 唤出命令面板，输入"陪学"直接和 AI 导师对话。
  • 周末规划：在仪表盘上点"生成计划"，选好下周要攻克的内容，AI 立刻生成 7–10 节课时，每节配套 15+ 道混合题型。
  • 通勤路上：用手机浏览器打开，单页应用无登录即可使用本地数据与已配置的 API Key。

当前痛点（没有翠码学坊时）

"找老师贵、问同学懒、问家长不会、自己看书睡着"——这是绝大多数学生在学习过程中遇到的真实尴尬。题库 App 给的答案千篇一律且无法追溯思路，搜题 App 解一道题要等 30 秒广告，而 AI 对话产品又往往不能"看见"孩子手边的笔记和错题。
  • 缺乏"记住自己"的 AI：现有 AI 大多"无状态"，每次对话都从零开始，无法基于学生过往的薄弱点调整讲解方式。
  • 数据隐私焦虑：把孩子的学习记录托管在第三方服务器，家长普遍不放心。
  • 平台割裂：笔记在一个 App、错题在另一个 App、刷题又在第三个 App，难以形成完整的学习闭环。
  • 视觉疲劳：扁平化卡片堆叠十多年，密密麻麻的列表让孩子一打开 App 就想关掉。
03

价值与意义

从效率提升和社会价值两个角度，看这个创意能带来什么。

效率提升：把"陪学"这件事变得可规模化

⚡

个性化学习闭环

AI 陪学引擎实时读取学生的笔记、错题、用户规则和长期记忆，按"用户规则 > 进化风格 > 默认"优先级拼装提示词，讲解自动贴合孩子的认知水平与表达偏好。

⌨

全键盘命令面板

类似 VS Code 的 Ctrl+K 唤起水晶命令面板，模糊匹配所有功能（支持拼音首字母），熟练后可完全脱离鼠标操作，学习流不被打断。

📸

应用外截屏问答

在做题、看资料时按下 Ctrl+Shift+X，截屏后直接问 AI，多模态模型识别图像内容并给出针对性讲解，再也不用打字描述"第三题那个图"。

📊

学情可视化

3D SVG 图表实时呈现各学科正确率趋势、知识点雷达图与学习时长统计，薄弱点一眼可见，家长也可一同查看。

社会价值：让 AI 教育普惠到每一个角落

  • 零成本、零门槛：整个应用是一个 HTML 文件，双击即可在任意现代浏览器运行，无需安装、无需账号、无需付费。哪怕是一台十年前的旧电脑、哪怕是没有网络的乡村教室，都能用上 AI 陪学。
  • 数据主权归用户：所有笔记、错题、学习记录存放在浏览器本地 IndexedDB，数据不上传任何服务器。API Key 由用户自备、对话内容仅在用户授权时与所选 AI 服务商通信，隐私边界清晰。
  • 降低家庭开支：一个 VIP 题库年费动辄上千元，而翠码学坊以"用户自带 API Key"模式让家庭按使用量付费（OpenAI/Anthropic/MiniMax/Google 等任选），综合成本远低于商业学习 App。
  • 无障碍美学：水晶玻璃 UI 不是炫技，而是为了让孩子愿意打开。动态鼠标光源、悬停 3D 倾斜、卡片翻转动画——让"打开学习 App"这件事本身变得愉悦。

如何使用

下载整个 cuima-crystal-web/ 文件夹

保留所有子目录与文件，不要漏掉 styles/、src/。

双击 index.html

或在终端执行 python -m http.server 后访问 http://localhost:8000。

在设置中填写你的 AI API Key

支持 OpenAI、Anthropic、Google Gemini、MiniMax 以及任意 OpenAI 兼容端点。

按 Ctrl+K 开始探索

试试输入 "xj" 创建笔记、"scjh" 生成学习计划、"px" 开启 AI 陪学。
