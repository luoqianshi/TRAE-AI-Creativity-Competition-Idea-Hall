PROJECT BACKGROUND

项目背景

在复杂多变的训练与推演场景中，传统方法面临效率瓶颈与知识沉淀难题，亟需 AI 技术赋能破局

当前军事训练与战术推演领域正处于深刻变革的关键节点。随着作战形态向智能化、无人化、体系化方向演进， 任务复杂度呈指数级增长，决策窗口持续压缩，对推演效率和质量提出了前所未有的挑战。

传统的人工推演模式依赖专家经验，不仅耗时费力，更面临着人才培养周期长、 知识经验难以传承、重复劳动效率低下等结构性痛点。高质量的战术推演往往需要耗费大量人力物力， 却难以实现规模化、常态化训练。

FlyAgent 应运而生。我们以大语言模型为核心引擎，创新性地提出 三层双循环架构，将 AI 的认知能力与仿真引擎的计算能力深度融合， 构建起一套能够理解自然语言指令、自主进行态势分析、智能生成战术方案、精准执行推演控制的新一代智能推演系统。

USER PAIN POINTS

用户痛点

深入洞察培训推演团队与策略分析人员面临的核心挑战

⏱

推演效率低下

传统人工推演依赖专家操作，单场推演耗时数小时甚至数天，难以满足高频次、大规模训练需求，严重制约训练效益。

🎯

操作门槛过高

专业仿真推演工具学习曲线陡峭，新手需数月培训才能独立操作，人才培养成本高、周期长，团队能力建设缓慢。

🔁

重复执行问题

缺乏智能状态感知与差分机制，指令重复下达、动作重复执行现象频发，既影响推演准确性，又浪费计算资源。

📚

知识难以沉淀

推演经验散落在个人头脑与零散文档中，缺乏系统化的知识管理机制，宝贵战术经验难以传承复用，人才流失即知识流失。

CORE SOLUTION

解决方案

AI 对话驱动 + 双循环架构 + 状态差分 + RAG 知识引擎，四大核心技术重构推演体验

💬

AI 对话驱动任务下达

自然语言交互界面，用户只需用日常语言描述推演目标，系统自动理解意图、解析任务、生成执行方案，彻底打破操作门槛壁垒。

⚡

低频规划 + 中频控制双循环

创新性三层双循环架构：低频规划循环（1-10秒）负责 LLM 战略决策，中频控制循环（100ms-1秒）负责状态差分与精准执行，兼顾智能与效率。

🔍

状态差分避免重复执行

五层防重治理体系：意图解耦、状态差分、执行缓存、冷却机制、冲突检测，从规划到执行全链路杜绝重复指令，确保推演精准高效。

🧠

RAG 知识检索与经验沉淀

基于 FAISS 向量数据库的 RAG 知识引擎，自动从推演结果中提炼战术经验，构建可复用知识库，实现"推演-评分-沉淀-复用"的知识闭环。

CORE ARCHITECTURE

核心流程图

三层双循环架构下的智能推演全流程，从自然语言输入到战术执行的完整链路

① 自然语言任务输入

用户通过对话界面输入推演任务与作战目标，系统基于 LLM 理解意图，解析任务要素，启动推演流程。

01

② 态势感知与 RAG 检索

Snapshot Provider 拉取战场快照，WorldModel 构建态势认知，ThreatAnalyzer 评估威胁等级，RAG 引擎检索战术知识与历史经验。

02

③ 低频规划 · LLM 战术决策

PlanningLoop 基于态势上下文与知识库，由 LLM 生成高层战术计划（PlanPatch），包含作战意图、技能选择与执行参数，写入 PlanStore。

03

④ 中频控制 · 状态差分与防重

ControlLoop 读取计划，CommandBuilder 进行 Observed vs Desired 状态差分，Governor 五层防重审批，仅生成必要的执行指令。

04

⑤ 仿真执行与态势可视化

指令下发至 C++ 仿真引擎执行，实时态势数据通过 WebSocket 推送至前端，三维可视化展示战场全局，支持决策者直观掌握推演进展。

05

⑥ 评分复盘与知识沉淀

推演结束后，ScoreEvaluator 从结果、过程、行为三维度智能评分，KnowledgeUpdater 提炼经验教训，写入知识库形成闭环，赋能下次决策。

06
