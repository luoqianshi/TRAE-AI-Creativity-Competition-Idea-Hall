Time-Controller
一个 Windows 屏幕时间管理 idea

想让 Windows 也有 macOS Screen Time 那样的系统级屏幕时间管理——
不只是统计和提醒，还要防绕过、防篡改、多重保护、跨平台语言。
纯净、克制、开源、用工具替代意志力。

💻 平台：Windows 10/11 🛠 技术：.NET 5 + WinForms 🌐 语言：10 种 🛡 保护：三重机制 📝 状态：创意阶段
💡
这是一个 idea · 项目尚未开发。以下所有功能都是"我们想做"的设想 —— 不是已经实现的特性清单。
如果要做，我们希望它是一个真正"管得住"自己屏幕时间的工具，而不是又一个番茄钟。

1痛点 vs 我们的设想

⚠️ 现状的痛点

  • Windows 没有原生的"每日屏幕时间"
  • 番茄钟响一下就关，根本锁不住
  • 家长控制软件太重，像被监控
  • 屏幕时间工具一退出，限制就没了（异常绕过）
  • 用户直接修改 usage.txt 就能篡改记录
  • 国外软件中文支持差，国内用户看不懂
  • 重启电脑 = 限制清零（无开机自启）
  • 想开机就用，结果软件找不到了（无单实例）

✅ 我们想做的事

  • 🛡 三重保护机制（Windows 服务 + 看门狗 + 计划任务）
  • 🔐 防篡改（加密 + 备份 + 完整性校验）
  • 🕵️ 异常退出检测（谁也别想偷偷关掉）
  • 🌐 10 种语言（运行时切换，全 UI 实时刷新）
  • 🔋 防崩溃恢复（定时器持久化）
  • 📦 便携式（单 .exe 即可运行，配置存 ProgramData）
  • 🖥 单实例（重复启动自动激活原窗口）
  • 🎁 奖励时间（5/10/15/30/60 分钟灵活追加）
屏幕时间管理工具的真正难点不是"计时"，而是"让用户没办法绕过计时"。

2核心架构：三重保护机制

我们认为，一个能"管住"自己的工具，必须有进程级冗余。所以 Time-Controller 想做三个独立进程互相守护。

🖥
ScreenTimeController
主程序 (WinExe)
用户界面 + 计时核心
🛡
ProtectionService
Windows 系统服务
30 秒轮询主进程与看门狗
🐕
WatchdogMonitor
看门狗进程
10 秒轮询，自动拉起服务/主程序
↑ ↓

TaskScheduler · 开机 / 登录 / 每日 三重触发 · 服务具备自愈能力（自动重建被删的计划任务）

3我们想做的 15 项功能

以下是完整功能设想 —— 涵盖计时、限制、保护、可用性、可移植性五个维度。

1
时间追踪

每日屏幕使用时间自动累计；逐应用使用时长统计（基于前台窗口 API）；午夜 0 点自动重置；定时器持久化（带防崩溃恢复与备份文件）。

2
每日时间限制

每周 7 天可独立设置时长限制；进度条实时显示；距离限制 5 分钟时弹出警告；到时自动锁屏。

3
密码保护与锁屏

密码哈希存储（SHA 加密）；LoginAttemptManager 限制登录尝试次数；UnlockForm 锁屏解锁；可启用/禁用密码锁。

4
奖励时间 人性

触发锁屏后可选 5 / 10 / 15 / 30 分钟 / 1 小时奖励；支持密码验证后追加。

5
数据保护 防篡改

配置文件加密存储；备份文件自动生成；DataProtectionManager 完整性校验；防止外部直接修改 usage.txt / settings.txt。

6
异常退出检测

正常退出时写入 clean_exit.txt 标记；非正常关闭会被 AbnormalExitTracker 记录；主界面"保护"Tab 实时显示今日异常退出次数。

7
三重保护机制 核心

ProtectionService（30 秒轮询）+ WatchdogMonitor（10 秒轮询）+ TaskScheduler（BootTrigger + LogonTrigger + DailyTrigger）；服务具备自愈能力。

8
多语言支持（10 种）

英语、简中、繁中、日、韩、西、法、德、俄、葡；支持运行时动态切换，全 UI 实时刷新。

9
系统托盘

最小化到托盘，右键菜单：打开 / 语言切换 / 退出；气球通知（首次最小化提示）；关闭按钮默认最小化到托盘。

10
应用使用排行

抓取前台进程名 → 提取应用图标与友好名；字典缓存优化性能；ListView 详情视图显示。

11
安装向导（首次启动）

自动检测服务/任务是否安装；可勾选安装：ProtectionService、ScheduledTask、Watchdog；自动以管理员权限重启（runas + UAC）。

12
命令行接口

--install-task / --uninstall-task / --check-task / --run-task，方便脚本集成。

13
单实例与焦点恢复

Mutex 单实例锁；重复启动时自动激活已有窗口（ShowWindow + SetForegroundWindow）。

14
UI 自适应

主窗体使用屏幕工作区 70% 比例初始化；TabControl 三页（总览 / 应用 / 保护）；ApplicationHighDpiMode = SystemAware；保护 Tab 进入时强制密码验证。

15
便携性

无需安装，直接运行 ScreenTimeController.exe；配置/数据存于 %ProgramData%\ScreenTimeController\。

4我们的三大亮点

🛡

三重保护，进程级冗余

主程序死了？看门狗拉起。看门狗死了？服务拉起。服务死了？计划任务拉起。任意一个进程想被关掉都难。

🔐

防篡改，让记录可信

配置文件加密 + 备份 + 完整性校验，用户改不了 usage.txt。异常退出直接计数，谁也别想偷偷溜掉。

🌐

10 种语言，运行时切换

不重启就换语言，全 UI 实时刷新。海外用户也能用——这是大多数国内工具忽略的细节。

510 种语言支持

不仅是界面翻译，而是 运行时动态切换 + 全 UI 实时刷新。这是大多数同类工具不做的事。
