// CORE FEATURES

六大核心功能

从即时减压到长期追踪，从工间5分钟到日常心理保养，全链路守护情绪劳动者的心理健康。

01

情绪识别记录

选择当前情绪状态和触发事件，AI记录情绪日志。长期追踪情绪波动规律，发现个人情绪触发模式。

02

即时减压工具箱

根据情绪类型推荐最佳减压方案——呼吸法、EFT敲击、渐进式放松、正念冥想等，3-5分钟快速释放。

04

情绪趋势追踪

生成周/月情绪趋势报告，用数据可视化展示情绪波动曲线，帮助用户和企业管理者了解情绪健康趋势。

05

AI个性化方案

根据用户的情绪数据和偏好，AI自动推荐个性化的减压方案。越用越懂你，效果持续优化。

06

匿名分享减压心得和情绪故事，和同行业的伙伴互相支持。保护隐私的同时建立情感联结，不再独自承受。
