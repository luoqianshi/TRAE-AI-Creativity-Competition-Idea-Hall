捕获层

Tauri Rust 后端通过 WH_KEYBOARD_LL 注册全局热键，按键事件进入事件循环后通过 Tauri Command 推送到 React。

路由层

前端 useAIWindowStore 维护当前平台状态，Alt+1~9 触发平台切换，iframe 重新加载目标 AI 平台 URL。

持久层

用户配置和对话历史进入本地 JSON 文件，API Key 加密存储在系统密钥链中。
