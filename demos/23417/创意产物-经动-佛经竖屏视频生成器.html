经动：佛经竖屏视频生成器

把《金刚经》按“品”切分，一键生成极简、禅意、干净克制的经文动效竖屏视频（不做白话解释）。

第一版：仅《金刚经》 输出：竖屏 9:16 风格：极简 / 禅意 / 醒目

1. 创意名称 + 创意介绍

想解决什么问题：佛经内容经典但呈现形式偏静态，普通人难在短时间内读进去，也不便在短视频平台传播；手工做经文字幕与动效成本高且风格不统一，导致难以稳定产出与持续传播。
为什么会想到做这个：短视频是大众接触传统文化的重要入口。第一版先不做大量解释，只把经文本身做成“能读、好看、可转发”的标准化竖屏视频，让更多人愿意停留阅读原文。
产品形态：网页/小程序的一键生成工具：选择“第 X 品”或“连续多品” → 选择模板 → 生成预览 → 导出/分享。
  • 第一版范围（MVP）：仅支持《金刚经》，按“品”切分生成视频。
  • 内容原则：仅做经文动效可视化，不做白话解释（降低争议与审核成本）。

2. 目标用户及痛点

面向哪些用户

传统文化与佛学爱好者；寺院/公益机构内容运营人员；短视频内容创作者；希望做文化传播的普通用户。

在什么场景下使用

短视频账号日更；节日/纪念日主题传播；讲座/活动预热；将经文片段做成可转发竖屏视频，分享至社群与朋友圈。

当前痛点

手工断句、排版、动效与导出耗时；模板过花会抢字、过素又不醒目，难兼顾阅读性与审美；传播端缺少可重复使用的标准输出。

3. 价值与意义

  • 效率提升：把“选片段 → 断句排版 → 动效制作 → 导出”的流程压缩为一键生成，让非专业用户也能快速产出统一风格内容。
  • 社会价值：用更符合当下传播习惯的竖屏视频形式，让更多人愿意停留阅读经文原文，推动古籍活化从“可获取”走向“可触达、可传播”。

4. 审美与动效规范（第一版承诺）

关键词：极简 / 禅意 / 干净 / 克制 / 好看 / 醒目

视觉风格

  • 版式：大留白、少元素；一屏只承载一段经文，控制信息密度。
  • 配色：黑白灰为底，最多 1 个强调色；强调只用于关键词或进度提示。
  • 背景：纯色或极轻纹理（低对比宣纸/水墨噪点），不抢字。

打字与优雅动效

  • 字一定要打：经文按词/短句逐段打出；遇标点自动停顿，形成可跟读节奏。
  • 动效一定要优雅：只用淡入淡出、轻微位移、关键词高亮渐显；统一缓入缓出曲线，不做弹跳与过度转场。
  • 一致性：字号、行距、边距、强调规则固定，保证批量生成也干净统一。
