// Core Features
从识别到引导，一套完整的品质管控方案
🔬

一芽一叶精准识别

基于YOLOv8-seg实例分割模型，精确到像素级的茶芽形态分析。识别一芽一叶、一芽二叶、单片叶等6种形态，准确率96.8%。

🗺️

智能采摘路径

根据茶芽成熟度热力图，使用TSP+遗传算法为每位采茶工规划最优路径。平均节省行走距离35%，提升采摘效率。

📱

小程序实时引导

采茶工通过手机小程序接收采摘指引——哪棵树、哪根枝条、采几片，语音+箭头双重引导，新手也能秒上手。

📊

品质数据追溯

每批茶叶从采摘到成品的完整质量数据链。扫码即可查看：采摘时间、茶芽合格率、采茶工、产区地块。

🌤️

采摘窗口预测

结合气象数据+茶芽生长模型，预测未来3天最佳采摘窗口。清晨露水干后2小时是黄金时间，系统自动提醒。

👥

远程品质管控

管控员在手机/电脑端远程查看各区块实时采摘质量，异常自动告警。1人可管理原来3人的区域。
