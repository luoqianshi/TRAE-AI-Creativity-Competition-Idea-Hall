# Board Doctor AI

展板识别、诊断与输入驱动生成工作台 Demo。

## 项目定位

这是一个面向设计学生的 AI 工作台 Demo，用于根据用户输入动态生成选题方向、项目诊断、方案逻辑链、分析图清单、评分诊断、下一步任务和答辩表达。

## 核心特点

- 纯前端 HTML / CSS / JavaScript 实现
- 内置关键词识别系统
- 输入驱动生成结果，不同项目会输出不同内容
- 支持 hash seed 和“换一组结果”
- 支持 OpenAI-compatible 真实 AI 接口配置
- 未配置真实 AI 时自动使用本地规则引擎

## 运行方式

直接打开 `index.html` 即可运行。

如果需要本地服务预览，可在本目录运行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```
