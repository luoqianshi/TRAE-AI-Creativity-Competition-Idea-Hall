🎤 全域语音输入助手

让任意输入框都能「动口不动手」—— 对着麦克风说话，文字自动填入当前光标位置

💡 创意介绍

想解决的问题：很多时候我们不方便打字——手在忙、打字速度慢、老年人不会拼音、残障人士操作困难。市面上虽有语音输入产品，但大多只能在自家 App 里使用，无法通用到任意软件的输入框中。

为什么会想到做这个：看到太多场景下用户需要快速输入文字——司机要在导航间隙回消息、厨师要记菜谱、老人想用微信却不会打字、程序员懒得写重复性注释……如果能有一个工具，监听当前输入框，说话即填，将会极大提升效率。

产品形态：一个轻量级桌面小工具（Windows / macOS），运行时在屏幕边缘显示一个悬浮麦克风按钮。点击后说话，AI 语音识别结果自动插入到当前处于焦点的输入框，无需任何手动粘贴操作。

关键技术选型：
• 语音识别：调用云端 AI 语音 API（支持讯飞、百度、OpenAI Whisper 等）
• 焦点检测：系统级全局钩子，实时获取当前光标所在输入框
• 文字注入：通过 Windows API / macOS Accessibility API 模拟键盘输入，兼容任意软件
