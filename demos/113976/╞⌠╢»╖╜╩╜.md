下次开机后启动项目非常简单，有两种方式：

---

## 方式一：开发模式（推荐，有热更新）

**步骤：**

1. 打开 **命令提示符** 或 **PowerShell**
按键盘 Win + R
输入 cmd → 回车（打开命令提示符）
或输入 powershell → 回车（打开 PowerShell）
2. 进入项目目录：

```bash
cd "F:\BaiduSyncdisk\TRAE WORK CN\亲络家谱" （测试人员把这个路径改成你的电脑地址）
```

3. 启动开发服务器：

```bash
npm run dev
```

4. 在浏览器打开：**http://localhost:5173/**

---

## 方式二：直接打开（无需启动服务，离线查看）

直接双击打开以下文件即可：

```
F:\BaiduSyncdisk\TRAE WORK CN\亲络家谱\dist\index.html
```

> ⚠️ 注意：方式二用的是上次构建的版本，如果你修改了代码，需要先运行 `npm run build` 重新构建。

## 常用命令速查表

| 命令 | 作用 |
|------|------|
| `npm run dev` | 启动开发服务器（热更新） |
| `npm run build` | 构建生产版本（生成 `dist/`） |
| `npm run check` | 类型检查（找代码错误） |
