03清灰三大痛点

PAIN · 模糊经验易翻车
★1
NOISE

风扇怒吼不知从哪拆

风扇越转越响，机箱烫得能煎蛋，却不知道该先拆侧板还是先拔电源。买了气罐对着转动的风扇猛吹，反电动势瞬间烧穿主板芯片，三千块的主板清成废铁。

★2
HEAT

高温降频性能被谋杀

散热鳍片塞满灰绒像堵了旧棉絮，CPU 直奔九十度，游戏帧数断崖下跌。不是性能老化，是灰尘慢性谋杀。一次正确清灰能让温度降十到二十度，帧数满血复活。

★3
BROKEN

拆错禁区当场报废

教程写"适当清理""小心操作"，但没人说哪步是禁区。酒精滴电路短路，拆电源外壳触高压电容，徒手摸硅脂留油膜，弯折 PCB 裂铜箔——一个动作失误，硬件当场报废。

04四步清灰工作流

FLOW · SELECT → PREP → CLEAN → CHECK
★1
SELECT

选设备

从台式机、笔记本、显卡、散热器、电源五类中选定设备，并标记灰尘程度（轻/中/重），系统据此匹配清灰步骤库。

★2
PREP

做准备

勾选手头工具（气罐/毛刷/吸尘器/酒精棉/手环），第一步永远是断电拔线与戴防静电手环，把保命动作前置。

★3
CLEAN

照分镜清

逐格照漫画分镜执行：吹鳍片、刷扇叶、擦金手指、吸积灰，每步配拟声词与对话气泡，✓正确动作与✗禁忌一目了然。

★4
CHECK

装回验收

装回侧板与螺丝，通电开机观察温度与噪音，对照禁忌警告条确认没有踩雷，确认风扇转速平稳、温度回落即完成。

05清灰 DustClear 的价值

VALUE · 把运气变成技术
VALUE · 01 · PERFORMANCE

性能满血复活

一次正确清灰能让 CPU 温度下降十到二十度，游戏帧数回升，风扇噪音归零——这是实打实的性能与体验。把散热鳍片间堵住的灰绒吹掉，硬件才能跑出该有的频率。

VALUE · 02 · LIFESPAN

寿命安全延长

把断电、戴手环、固定扇叶这些保命动作前置成第一步，把拆电源外壳、酒精滴电路这些致命操作标红成禁忌，让硬件多活两到三年，不致于把好端端的设备清成废铁。
