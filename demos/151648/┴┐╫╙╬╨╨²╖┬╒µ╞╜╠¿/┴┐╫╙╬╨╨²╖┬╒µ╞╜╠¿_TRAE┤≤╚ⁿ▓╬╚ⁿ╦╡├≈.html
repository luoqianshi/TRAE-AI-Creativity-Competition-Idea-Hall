4GUI 使用指南

4.1 启动

双击 quantumsim-gui.exe 即可启动,需同目录存在 quantum_sim.dll。无需安装、无需联网、无需注册。若 DLL 缺失,程序会用原生 MessageBox 弹窗提示。

4.2 搭建电路

  1. 在左侧"量子门面板"点击门按钮(H / X / CNOT 等)选中该门
  2. 在右侧"电路网格"对应量子比特行 × 时间列单元格点击放置门
  3. 多比特门(CNOT/CZ/SWAP)需先点控制比特,再点目标比特
  4. 可点击"预设"下拉加载 Bell/Grover/Superdense 等经典电路
  5. 点击网格上方"▶ 运行电路"按钮执行计算
  6. 观察右下涡旋场动画 + 概率柱状图
  7. 点击"导入 JSON"/"导出 JSON"与其他工具互通电路

4.3 三种后端切换

后端量子比特上限适用场景
Dense12 (GUI 限制)小规模电路,最快
Sparse20 (GUI 限制)中等规模,省内存
Mps20 (GUI 限制)低纠缠电路,可扩展

4.4 JSON 3.0 电路格式

GUI 支持导入/导出 OpenQASM 3.0 风格 JSON,可与外部工具互通:

{ "version": "3.0", "backend": "Dense", "nQubits": 2, "circuit": [ { "kind": "H", "q1": 0, "q2": -1, "step": 0 }, { "kind": "CNOT", "q1": 0, "q2": 1, "step": 1 } ] }

5.2 核心 API 速览

// ===== 生命周期 ===== QsimStateHandle qsim_state_new(uint32_t n_qubits); // 创建态向量 (≤32q) void qsim_state_free(QsimStateHandle h); // 释放 // ===== 量子门 (逐个应用) ===== int qsim_state_apply_h(QsimStateHandle h, uint32_t q); int qsim_state_apply_cnot(QsimStateHandle h, uint32_t ctrl, uint32_t tgt); int qsim_state_apply_rx(QsimStateHandle h, uint32_t q, double theta); int qsim_state_apply_u(QsimStateHandle h, uint32_t q, double θ, double φ, double λ); // ===== 批量电路执行 (一次 FFI 调用,零开销) ===== int qsim_state_run_circuit(QsimStateHandle h, const QsimGate* gates, size_t n); // ===== 测量与读出 ===== uint64_t qsim_state_measure(QsimStateHandle h); // 确定性测量 (DFL argmax) double qsim_state_prob_one(QsimStateHandle h, uint32_t q); // |1⟩ 概率 int qsim_state_copy_amplitudes(QsimStateHandle h, double* out, size_t len); // 零拷贝读振幅 int qsim_state_sample_top_k(QsimStateHandle h, size_t k, ...); // Top-K 采样 // ===== OpenQASM 2.0 互通 ===== char* qsim_circuit_to_qasm(const QsimGate* gates, size_t n, uint32_t nq); QsimStateHandle qsim_run_openqasm(const char* qasm_src); // ===== 其他后端 ===== QsimSparseHandle qsim_sparse_new(uint32_t n); // ≤64q QsimMpsHandle qsim_mps_new(uint32_t n, uint32_t chi); // ≤100000q QsimStabilizerHandle qsim_stabilizer_new(uint32_t n); // ≤256q QsimHybridHandle qsim_hybrid_new(uint32_t n); // GPU/CPU ≤32q

5.3 Python 调用示例 — Bell 态

from ctypes import * dll = CDLL("./quantum_sim.dll") # 创建 2 量子比特态向量 sv = dll.qsim_state_new(2) # 应用 H 门到 q0, 再 CNOT q0→q1, 制备 Bell 态 dll.qsim_state_apply_h(sv, 0) dll.qsim_state_apply_cnot(sv, 0, 1) # 读取每个量子比特处于 |1⟩ 的概率 p0 = dll.qsim_state_prob_one(sv, 0) p1 = dll.qsim_state_prob_one(sv, 1) print(f"P(q0=1)={p0:.3f} P(q1=1)={p1:.3f}") # 各 0.5 # 确定性测量 (返回最大概率态索引) result = dll.qsim_state_measure(sv) print(f"测量结果: |{result:02b}⟩") # |00⟩ 或 |11⟩ (各 50%) dll.qsim_state_free(sv)

5.4 Python 调用示例 — 批量电路执行

from ctypes import * import numpy as np dll = CDLL("./quantum_sim.dll") # QsimGate 结构体: 8 个字段, 共 64 字节 class QsimGate(Structure): _fields_ = [ ("gate_type", c_int), ("q", c_uint32), ("q2", c_uint32), ("q3", c_uint32), ("theta", c_double), ("phi", c_double), ("lambda", c_double), ] # 构建电路: 3 比特 GHZ 态 gates = (QsimGate * 4)() gates[0] = QsimGate(0, 0, 0, 0, 0, 0, 0) # H on q0 gates[1] = QsimGate(6, 1, 0, 0, 0, 0, 0) # CNOT q0→q1 gates[2] = QsimGate(6, 2, 1, 0, 0, 0, 0) # CNOT q1→q2 sv = dll.qsim_state_new(3) dll.qsim_state_run_circuit(sv, gates, 3) # 零拷贝读取全部振幅 (与 numpy complex128 布局一致) amp = (c_double * (8 * 2))() dll.qsim_state_copy_amplitudes(sv, amp, 16) state = np.frombuffer(amp, dtype=np.complex128) print("GHZ 态:", state) # [1/√2, 0, 0, 0, 0, 0, 0, 1/√2] dll.qsim_state_free(sv)

5.5 Python 调用示例 — OpenQASM 2.0 互通

from ctypes import * dll = CDLL("./quantum_sim.dll") # 从 Qiskit / Cirq 生成的 OpenQASM 2.0 字符串直接执行 qasm_src = """ OPENQASM 2.0; qreg q[2]; h q[0]; cx q[0], q[1]; """.encode("utf-8") sv = dll.qsim_run_openqasm(qasm_src) result = dll.qsim_state_measure(sv) print(f"QASM 执行结果: |{result:02b}⟩") dll.qsim_state_free(sv)

5.6 Rust 调用示例

use libloading::{Library, Symbol}; let lib = Library::new("./quantum_sim.dll")?; let new: Symbol<unsafe extern "C" fn(u32) -> *mut ()> = unsafe { lib.get(b"qsim_state_new\0")? }; let apply_h: Symbol<unsafe extern "C" fn(*mut (), u32) -> i32> = unsafe { lib.get(b"qsim_state_apply_h\0")? }; let sv = unsafe { new(2) }; let _ = unsafe { apply_h(sv, 0) };
设计哲学:DLL 是"量子电路执行引擎",不绑定特定算法。用户可基于此引擎自行实现 VQE / QAOA / Grover / 量子相位估计 / 哈密顿量模拟 等任意量子算法。这是"授人以渔"而非"授人以鱼"。

6第三方算法实现路径

基于 DLL 的 21 种门 + 批量执行 + 振幅读取 + OpenQASM 互通,用户可以实现任意量子算法。以下是常见算法的实现路径:

🧬

VQE 分子基态

1. 哈密顿量分解为 Pauli 门序列
2. 构建 ansatz (Rx+Ry+CNOT)
3. DLL 运行 → 读振幅 → 算能量
4. 经典优化器更新参数

🎯

QAOA 组合优化

1. MaxCut 问题编码为 QUBO
2. 成本哈密顿量 → Rz 门
3. 混合哈密顿量 → Rx 门
4. DLL 批量执行 → 测量

🔍

Grover 搜索

1. Oracle 电路 (Toffoli/CNOT)
2. 扩散算子 (H+X+H+多控Z)
3. DLL 运行 → Top-K 采样
4. 返回搜索结果

📐

量子相位估计

1. 受控酉门 (CRx/CRy/CRz)
2. 逆 QFT (H+CRz 链)
3. DLL 运行 → 测量
4. 读出相位本征值

⚗️

哈密顿量模拟

1. Trotter 分解
2. 每片分解为 Rx/Ry/Rz+CNOT
3. DLL 批量执行
4. 读取演化后态向量

📡

量子通信协议

1. 超密编码 (H+CNOT+X+Z)
2. 隐形传态 (H+CNOT+测量)
3. DLL 运行 → 概率分布
4. 验证协议正确性

6.1 VQE 算法实现示例 (Python 伪代码)

from scipy.optimize import minimize from ctypes import * import numpy as np dll = CDLL("./quantum_sim.dll") def vqe_energy(params): # params = [θ1, θ2, ...] ansatz 参数 sv = dll.qsim_state_new(4) # 构建 ansatz: Ry(θ0) Ry(θ1) CNOT CNOT ... dll.qsim_state_apply_ry(sv, 0, params[0]) dll.qsim_state_apply_ry(sv, 1, params[1]) dll.qsim_state_apply_cnot(sv, 0, 1) # ... 更多 ansatz 层 # 读取振幅, 计算 <ψ|H|ψ> amp = (c_double * 32)() dll.qsim_state_copy_amplitudes(sv, amp, 32) psi = np.frombuffer(amp, dtype=np.complex128) dll.qsim_state_free(sv) # H = Σ h_i P_i (Pauli 分解), 计算 energy return compute_hamiltonian_expectation(psi) # 经典优化器寻找基态能量 result = minimize(vqe_energy, x0=[0.1]*4, method="COBYLA") print(f"H₂ 基态能量: {result.fun:.6f} Hartree")
关键说明:平台不提供"一键算分子能量"的高级算法 API。用户需自行实现算法逻辑(如 VQE 的 ansatz 构造与经典优化器),DLL 只负责"执行电路 + 返回态向量/概率"。这是有意为之 —— 让用户真正掌握量子算法底层。

7高级特性

7.1 OpenQASM 2.0 互通

DLL 支持 OpenQASM 2.0 标准格式导入导出,可与 Qiskit / Cirq / PyQuil 等主流量子框架互通:

  • qsim_run_openqasm(qasm_str) — 直接执行 QASM 字符串,返回态向量
  • qsim_circuit_to_qasm(gates, n) — 门列表序列化为 QASM 字符串
  • qsim_circuit_from_qasm(qasm_str) — QASM 字符串解析为门列表

7.2 GPU 加速 (Hybrid 后端)

Hybrid 后端自动检测 GPU,优先使用 GPU 批量操作,失败自动回退 CPU:

  • GPU 可用且 n ≤ 28:GPU 批量加速
  • GPU 不可用或 n > 28:纯 CPU f64 精度
  • 支持批量门操作 qsim_hybrid_apply_gates_batch
  • 支持 GPU/CPU 后端查询 qsim_hybrid_backend

7.3 纠缠熵计算 (MPS)

MPS 后端提供纠缠熵计算,用于分析量子态纠缠结构:

// 获取指定 bond 位置的纠缠熵 S = -Σ λ² log(λ²) double qsim_mps_entanglement_entropy(QsimMpsHandle h, uint32_t bond); // 获取压缩比 (state_vector / MPS 内存比) double qsim_mps_compression_ratio(QsimMpsHandle h); // 性能统计 JSON (压缩比 + 平均纠缠熵 + 最大键维数) char* qsim_mps_performance_stats(QsimMpsHandle h);

7.4 数论加速接口

DLL 内置数论加速函数,用于涡旋场阵列生成与算法优化:

7.5 柯西涡旋场渲染

DLL 提供柯西留数涡旋场渲染 API,支持 4 种可视化模式:

  • PhaseBrightness (mode=0) — 相位+亮度叠加
  • Probability (mode=1) — 概率密度热图
  • PhaseOnly (mode=2) — 纯相位着色
  • ResidueHeatmap (mode=3) — 留数热图

支持 Fibonacci 黄金角阵列与 Bragg E₈ 共振阵列自动生成。

7.6 硬件资源查询

DLL 提供完整的硬件资源查询 API,便于第三方程序自适应:

  • qsim_system_ram_bytes() — 物理内存总量
  • qsim_available_ram_bytes() — 可用内存
  • qsim_gpu_vram_bytes() — GPU 显存
  • qsim_gpu_name() — GPU 名称
  • qsim_hardware_max_qubits(mode) — 基于真实硬件计算最大比特数
  • qsim_hardware_info_json() — 完整硬件信息 JSON

9常见问题

启动 GUI 提示缺少 quantum_sim.dll 怎么办?
将 quantum_sim.dll 放到 quantumsim-gui.exe 同目录即可。程序会用原生 MessageBox 弹窗提示。
支持多少量子比特?
Dense 后端最多 32 比特(全矩阵),Sparse 最多 64 比特,MPS 最多 10 万比特(低纠缠),Stabilizer 最多 256 比特(Clifford),Hybrid 最多 32 比特(GPU)。GUI 限制 1-20 比特以保证交互流畅。
能否用 DLL 跑 VQE 算分子能量?
可以。用户自行实现 VQE 的 ansatz 构造与经典优化器,DLL 提供 H/Ry/Rz/CNOT 等门操作和振幅读取接口。平台定位是"电路执行引擎"而非"算法黑盒",让用户真正掌握算法底层。
能否与 Qiskit / Cirq 互通?
可以。DLL 支持 OpenQASM 2.0 格式导入导出,Qiskit/Cirq 生成的 QASM 电路字符串可直接用 qsim_run_openqasm() 执行。
涡旋场动画代表什么?
涡旋场是量子态向量的可视化投影 —— 振幅对应亮度,相位对应旋转方向。让抽象复数向量变为可见漩涡,辅助初学者建立直觉。支持 4 种渲染模式。
是否需要联网?
完全本地运行,零联网,零云端往返,零注册。双击 exe 即用,DLL 直接 FFI 调用零网络开销。
DLL 能被哪些语言调用?
任何支持 C ABI FFI 的语言:Python (ctypes)、C/C++、Rust (libloading)、Go (cgo)、C# (DllImport)、Java (JNA) 等。
如何选择后端?
≤12 比特用 Dense(最快);13-64 比特用 Sparse(省内存);低纠缠大电路用 MPS(可上万比特);纯 Clifford 电路用 Stabilizer(最快);有 GPU 用 Hybrid(加速)。
支持哪些量子门?
共 21 种:H/X/Y/Z/S/T/CNOT/CZ/Toffoli/SWAP/Rx/Ry/Rz/U3/iSWAP/XX/YY/CRx/CRy/CRz/Fredkin。GUI 拖拽支持前 9 种常用门,DLL FFI 支持全部 21 种。
