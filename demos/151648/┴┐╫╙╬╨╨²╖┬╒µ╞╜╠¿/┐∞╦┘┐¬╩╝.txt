量子涡旋仿真平台 — 快速开始
================================

【文件清单】
  quantumsim-gui.exe              GUI 客户端 (双击启动)
  quantum_sim.dll                 核心引擎 DLL (GUI 和 Python 都需要)
  quantum_sim.h                   C ABI 头文件 (第三方开发参考)
  test_quantum_sim.py             Python 测试脚本 (8 项功能测试)
  量子涡旋仿真平台_使用说明.html   完整使用说明与第三方集成指南
  快速开始.txt                    本文件

【快速开始】
  1. GUI 使用: 双击 quantumsim-gui.exe (需 quantum_sim.dll 同目录)
  2. Python 调用:
     - 确保已安装 Python 3.8+ 和 numpy (pip install numpy)
     - 运行: python test_quantum_sim.py
     - 查看测试结果 (8 项功能测试)

【第三方集成】
  - Python: 用 ctypes 加载 quantum_sim.dll, 参见 test_quantum_sim.py
  - C/C++: #include "quantum_sim.h", 链接 quantum_sim.dll
  - Rust: 用 libloading 加载, 参见使用说明 HTML §5.6
  - 详见: 量子涡旋仿真平台_使用说明.html §5 DLL 第三方集成指南

【后端选择】
  ≤12 比特: Dense (最快)
  13-64 比特: Sparse (省内存)
  低纠缠大电路: MPS (可上万比特)
  Clifford 电路: Stabilizer (最快)
  有 GPU: Hybrid (GPU 加速)

【量子门支持】
  共 21 种: H X Y Z S T CNOT CZ Toffoli SWAP Rx Ry Rz U3 iSWAP XX YY CRx CRy CRz Fredkin
  GUI 拖拽支持前 9 种, DLL FFI 支持全部 21 种
