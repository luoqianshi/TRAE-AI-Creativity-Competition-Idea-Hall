01 / CREATIVE INTRO

创意介绍

从"设备联网"到"真正智能"，中间只差一个 HomeMind

🎯

想解决的问题

家庭智能家具品牌割裂、App 众多，设备之间无法真正联动，用户需要在多个 App 间反复切换才能完成一次"回家 / 睡眠 / 离家"操作，智能家具"不智能"。

💡

灵感来源

家里同时有小米、华为、涂鸦等不同品牌的智能灯具、空调、窗帘、扫地机，每次回家要打开 3 个 App 分别操作；老人更是完全不会用，只能放弃智能功能。意识到"设备连上网"和"真正智能"之间，缺了一个能理解用户、统一调度的"大脑"。

🏠

产品形态

基于 AI 大模型的智能家居统一管控系统，由硬件中枢（HomeMind Hub）+ 自然语言交互 App 组成，通过语音 / 文字 / 手势多模态交互，实现对跨品牌智能家具的统一接入、场景联动与主动服务。

😞 没有 HomeMind 时

  • 每个品牌一个 App，操作繁琐，体验碎片化
  • 小米灯配华为空调，无法做"一键场景"
  • 老人小孩难以使用复杂 App，智能家具成摆设
  • 必须用户主动发指令，设备不会"主动思考"
  • 固定模式无法随季节、作息、心情自适应
  • 设备数据分散，缺乏统一管控与隐私保障

😊 有 HomeMind 后

  • 一个 App 管全部，跨品牌设备统一接入
  • AI 自动编排联动场景，"一句话"搞定
  • 语音优先交互，老人小孩开口即用
  • AI 主动学习作息，自动调节环境
  • 场景随季节 / 天气 / 心情动态自适应
  • 本地化中枢 + 端侧加密，隐私安全可控
03 / USE CASES

典型使用场景

一句话，让家懂你

🚪

回家场景

推门一句"我回来了"，灯光、空调、窗帘、背景音乐自动就位。

"我回来了" → 灯亮 / 空调 26°C / 窗帘半开 / 音乐播放
🌙

睡眠场景

睡前语音"晚安"，全屋熄灯、空调调至睡眠模式、安防启动。

"晚安" → 全屋熄灯 / 空调睡眠模式 / 安防布防
🏃

离家场景

关门自动关闭电器、启动摄像头、扫地机开始工作。

检测离家 → 断电 / 摄像头开启 / 扫地机启动
👴

适老化场景

老人不熟悉 App，直接说话即可控制家电，零学习成本。

"把客厅灯调亮一点" → 自动识别并调节
❄️

预冷场景

夏天回家前远程让空调预冷，到家即享清凉。

"还有 10 分钟到家" → 空调提前启动
04 / VALUE & MEANING

价值与意义

商业价值

用户数据与场景习惯沉淀形成强壁垒，可向地产精装、酒店、长租公寓等 B 端延伸。

AI 主动学习用户作息与偏好，自动调节空调、照明。
