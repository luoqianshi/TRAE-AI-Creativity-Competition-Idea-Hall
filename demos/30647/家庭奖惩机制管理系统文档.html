家庭奖惩机制管理系统

1. 系统概述

家庭奖惩机制管理系统是一个专为家庭设计的分数管理系统，用于记录和管理孩子的日常表现，通过奖惩机制激励孩子养成良好的行为习惯。

1.1 系统功能

  • 用户管理：支持admin、baobao、beibei三个用户角色
  • 分数管理：记录孩子的日常行为分数
  • 活动管理：预设活动类型及其分数值
  • 分数统计：支持月度、年度和总分数统计
  • 分数兑换：支持用分数兑换物品
  • 数据存储：使用MySQL数据库存储数据

1.2 技术栈

  • 后端：Flask + Python
  • 数据库：MySQL
  • 前端：HTML + CSS
  • 部署：Gunicorn + Nginx

4. 部署指南

4.1 环境准备

  • 操作系统：Ubuntu 20.04 或 CentOS 7/8
  • Python：3.6+
  • MySQL：5.7+
  • Nginx：1.18+

4.2 安装步骤

  1. 更新系统 
    # Ubuntu/Debian
apt update && apt upgrade -y

# CentOS
yum update -y
  2. 安装依赖 
    # Ubuntu/Debian
apt install python3 python3-pip python3-venv nginx mysql-server -y

# CentOS
yum install python3 python3-pip nginx mariadb-server -y
  3. 配置数据库 
    # 启动数据库服务
systemctl start mysql  # 或 systemctl start mariadb
systemctl enable mysql  # 或 systemctl enable mariadb

# 安全配置
mysql_secure_installation

# 创建数据库
mysql -u root -p
CREATE DATABASE family;
GRANT ALL PRIVILEGES ON family.* TO 'root'@'localhost' IDENTIFIED BY 'Aa123456';
FLUSH PRIVILEGES;
EXIT;
  4. 部署应用 
    # 创建应用目录
mkdir -p /var/www/family-score
cd /var/www/family-score

# 上传代码
# 使用SCP或FTP上传项目文件

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install flask pymysql gunicorn cryptography
  5. 配置服务 
    # 创建启动脚本
cat > start.sh << EOF
#!/bin/bash
cd /var/www/family-score
source venv/bin/activate
gunicorn -w 4 -b 127.0.0.1:5000 app:app
EOF

chmod +x start.sh

# 创建Systemd服务
cat > /etc/systemd/system/family-score.service << EOF
[Unit]
Description=Family Score Management System
After=network.target mysql.service

[Service]
User=root
WorkingDirectory=/var/www/family-score
ExecStart=/var/www/family-score/start.sh
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 启动服务
systemctl daemon-reload
systemctl start family-score
systemctl enable family-score
  6. 配置Nginx 
    # 创建Nginx配置
cat > /etc/nginx/sites-available/family-score << EOF
server {
    listen 80;
    server_name your_domain.com; # 或服务器IP
    
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host host;
        proxy_set_header X-Real-IP remote_addr;
        proxy_set_header X-Forwarded-For proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto scheme;
    }
}
EOF

# 启用配置
ln -s /etc/nginx/sites-available/family-score /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
  7. 开放防火墙 
    # Ubuntu/Debian
ufw allow 80
ufw enable

# CentOS
firewall-cmd --permanent --add-service=http
firewall-cmd --reload

5. 运维指南

5.1 日常维护

  1. 查看服务状态 
    systemctl status family-score
systemctl status nginx
  2. 查看日志 
    # 应用日志
journalctl -u family-score

# Nginx日志
tail -f /var/log/nginx/error.log
tail -f /var/log/nginx/access.log
  3. 重启服务 
    # 重启应用
systemctl restart family-score

# 重启Nginx
systemctl restart nginx

5.2 数据库维护

  1. 备份数据库 
    mysqldump -u root -p family > family_backup.sql
  2. 恢复数据库 
    mysql -u root -p family < family_backup.sql
  3. 查看数据库状态 
    mysql -u root -p -e "SHOW DATABASES;"
mysql -u root -p -e "USE family; SHOW TABLES;"

5.3 常见问题排查

  • 服务启动失败
    • 检查启动脚本路径是否正确
    • 检查虚拟环境是否存在
    • 查看服务日志获取详细错误信息
  • 数据库连接失败
    • 检查数据库服务是否运行
    • 检查数据库连接配置是否正确
    • 确保安装了cryptography包
  • Nginx代理问题
    • 检查Nginx配置是否正确
    • 确保应用服务正在运行
    • 检查防火墙设置
  • 分数计算错误
    • 检查数据库中的记录是否正确
    • 验证兑换记录是否正确扣除分数

6. 安全注意事项

  1. 密码安全
    • 定期更改管理员密码
    • 不要使用简单密码
  2. 数据库安全
    • 限制数据库访问权限
    • 定期备份数据库
  3. 服务器安全
    • 定期更新系统和软件
    • 配置防火墙
    • 禁用不必要的服务
  4. 应用安全
    • 定期检查应用代码
    • 确保输入验证
    • 防止SQL注入

  1. 更新依赖 
    source /var/www/family-score/venv/bin/activate
pip install --upgrade flask pymysql gunicorn cryptography
