01 · BACKGROUND

创意背景

傩戏，被称为"中国戏剧活化石"，从商代傩仪至今已有三千余年历史。2006年，贵州傩戏入选首批国家级非物质文化遗产名录。然而：

  • 傩戏的传播仍依赖文字与口述，缺乏沉浸式数字展示
  • 全国30+个傩戏流派分散各地，无统一数字化档案
  • 面具、工艺、音乐等核心文化资产面临失传风险
  • 年轻人对傩戏的认知仅停留在"戴面具跳舞"，不知其深厚的文化底蕴

我出生于贵州，从小耳濡目染傩戏文化。借助 TRAE Work，我希望打造一个沉浸式数字档案，让傩戏从博物馆展柜走进每个人的屏幕，让非遗真正"活"起来。

02 · PROJECT

项目介绍

"乡傩"是一个具有东方暗黑美学的交互式单页 Web 应用，以纯黑为底、朱砂红为魂，融合现代 Web 技术与千年傩戏文化，构建六大核心板块：

01
文化渊源
从远古傩仪到首批国家级非遗，时间轴串联五大历史节点，关联权威参考文献
02
全国溯源图谱
ECharts 中国暗色地图，11省30个分布点，点击热点展开完整流派档案
03
面具制造工艺
8步工艺流程，配真实照片与抖音非遗视频链接
04
硬核微观解剖
高分辨率真实面具照片，逐层拆解木材肌理、刀法、彩绘
05
神谱图鉴档案
24个傩戏角色，5大分类，真实面具照片+配色谱系+精神内核
06
民间故事
18则民间传说，每则标注权威参考文献溯源
🎵 特别功能：环境音

用 WebAudio API 实时合成5层傩戏氛围音（低频嗡鸣 + 远处风声 + 傩鼓节奏 + 法器铃声 + 低吟人声），无需音频文件，点击首页即可沉浸体验。
