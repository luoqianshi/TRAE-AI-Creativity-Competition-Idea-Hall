# 银龄桥：老人数字生活 AI 陪练助手

这是用于 TRAE AI 创造力大赛初赛的社会公益方向 MVP Demo。

## 作品定位

银龄桥面向中老年人，帮助他们更安全、更从容地适应高速发展的数字社会。Demo 聚焦三个典型问题：

- 不会使用手机完成线上挂号、打车、支付等高频事务。
- 面对短信、电话、链接诈骗时缺少判断能力。
- 子女和社区志愿者无法随时反复教学。

## 当前 Demo 功能

- 首页：大字体入口，适合老人快速选择“我要学手机 / 我怕被骗 / 我要问问题”。
- 场景陪练：提供医院挂号、手机打车、扫码支付三个场景的步骤卡片和模拟练习。
- 防诈骗识别：基于关键词规则演示风险识别，输出风险等级、风险点和处理建议。
- 老人问答：把验证码、链接、支付、挂号等问题用通俗语言解释。
- 家属模式：家属可添加给老人的专属教程卡片和提醒。

## 初赛提交建议

- 可直接把 `index.html`、`styles.css`、`app.js` 打包成 Zip 上传，或部署为可公开访问的网页链接。
- 初赛作品帖建议截图：首页、场景陪练、防诈骗识别结果、家属模式。
- 帖子中需要补充用 TRAE 创作 Demo 的关键步骤截图和不少于 3 个 Session ID。

## 复赛可扩展方向

- 接入真实大模型 API，让防诈骗识别和问答从规则演示升级为自然语言理解。
- 接入语音识别和语音播报，支持老人直接说出问题。
- 接入 OCR，让老人上传手机截图，系统自动圈出下一步该点哪里。
- 增加家属端账号系统、紧急联系人、社区志愿者教程库。
- 加入本地化公共服务流程，例如本地医院、社保、公交、社区通知。
