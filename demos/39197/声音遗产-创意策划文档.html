01
项目概述
Project Overview

声忆（VoiceLegacy）是一个以AI语音克隆技术为核心的公益服务平台，致力于为家庭提供长辈声音的数字化保存、智能互动对话与家族记忆传承服务。

通过AI分析录入的语音，不仅高仿声音本身，更模仿语速、停顿、情感等个人特质，支持方言识别与转换。家属可用普通话提问，AI以老人的声音和语气作答，最终输出一本可代代传承的"家族声音遗产"。

02
为什么做这件事？
Project Background & Social Pain Points
👴

人口老龄化加速

中国60岁以上人口超2.8亿，空巢老人持续增长，代际分离成为常态。

🔇

声音记忆的消逝

声音是最能唤起情感的记忆载体，乡音、口头禅、笑声正随时间消逝。

🗣️

方言文化流失

中国130多种方言正快速消失，长辈的乡音成为文化活化石。

💔

亲情陪伴缺失

"子欲养而亲不待"是无数人的遗憾，现有技术无法弥补这种情感空缺。

技术机遇

  • AI语音合成（TTS）已达高保真度，可克隆音色、模仿语速停顿与情感
  • 大语言模型（LLM）具备自然对话能力，可基于语料实现拟人化交流
  • 方言识别与合成技术日趋成熟，支持多方言处理
  • Web端技术发展使复杂音频处理可在浏览器中完成

核心需求分析
User Needs Analysis

用户画像

用户角色年龄段核心需求使用场景
家属（主要使用者）25-50岁保存声音、互动对话、制作遗产提前录制、缅怀亲人、讲述故事
长辈（声音提供者）60-90岁留下声音和故事讲述人生、录制祝福
第三代（孩子）5-20岁听故事、互动对话了解祖辈、学习方言
公益合作方—为老人提供公益服务社区、敬老院、公益组织

五大核心需求

  1. 声音录制与采集 — 简单引导式录音，支持读稿/自由讲述/对话，音频质量检查与方言支持
  2. AI声音克隆 — 高保真音色复刻，模仿语速、停顿、语气，支持情感与方言
  3. 智能对话互动 — 普通话提问，长辈声音回答，基于生平知识库自然交流
  4. 家族声音遗产输出 — 生成声音纪念册、故事集、问答库，可导出分享
  5. 情感化设计 — 温暖庄重的界面，隐私安全，引导式流程降低门槛

Technical Architecture

竞品差异化分析
Competitive Analysis
产品类型现有特点我们的差异化
普通录音App只能录不能互动AI互动对话，可提问可聊天
商业语音克隆技术导向，价格高公益导向，情感化设计，传承场景
数字人产品侧重视频/形象专注声音，更轻量化，更易普及
家谱/纪念网站文字图片为主声音为核心，可交互可对话

"声忆"不是要让AI替代逝去的亲人，而是用科技为家庭留住那些温暖的声音——奶奶喊你回家吃饭的声音、爷爷讲过去故事的声音、父母用方言叮嘱你的声音。

这些声音，承载着爱，承载着记忆，承载着一个家族的根。

我们希望，多年以后，当孩子问起"爷爷是什么样的人"时，你不仅能拿出照片，还能让爷爷"亲口"讲述他自己的故事。
