世界艺术地球仪

用 3D 地球仪 + 联动时间线，把艺术史从“背诵年代”变成“空间漫游”。

把艺术史从纸面搬到可交互的 3D 地球仪上。

01 · 想解决什么问题

艺术史课本通常按年代线性堆叠：年代、流派、人名、作品。学习者很难建立“这幅画为何出现在这里”“那个时期为何选择那样画”的空间与因果直觉。地理、时间、视觉风格三者被割裂，导致艺术史变成死记硬背的学科，而不是一场可见的人类视觉实验。

02 · 这是一个什么样的产品

受 E. H. Gombrich《艺术的故事》启发——艺术史可以是一场连续的视觉故事，而不只是年代与流派的罗列。但传统书籍是线性的、纸面的，读者很难同时看到“何时、何地、为何这样画”。所以我想把这本书的叙事方式升级成可互动、可视化、可探索的交互式体验。

一本“交互式书籍”——不是传统纸质书，而是可互动、可视化的 Web 应用。暗色博物馆氛围中，一颗可自转的 3D 地球仪悬浮中央，关键文明地点以光点标记。左侧是联动时间线，右侧滑出该时期的代表作、Gombrich 式核心问题，以及与上一时期的“得失对比”。

用户既可以从地球仪探索空间分布，也可以沿时间线感受风格演变，点击任意节点后相机会飞行到对应地点，URL 同步保存当前视图，键盘上下键即可切换时期。

产品路线：首条主线从“自然的镜子：写实主义的胜利与危机”展开，用 3D 地球仪 + 联动时间线 + 得失对比的交互方式讲述艺术史。未来会基于同一产品骨架加入“光的历史”“赞助人与艺术”“身体图像”等更多主题，成为覆盖多主线的交互式艺术史平台。

03 · 六个关键节点

古埃及 约公元前 2500 年
为什么放弃真实，选择清晰永恒？
古希腊 约公元前 500 年

当摄影能复制真实，绘画何为？

04 · 目标用户与使用场景

  • 任何热爱艺术的人：不需要专业背景，只要对艺术、审美、视觉文化感兴趣，就能上手。
  • 自学者：不想再翻厚重教材，想用 10 分钟建立从埃及到现代主义的整体脉络。
  • 博物馆与美术馆观众：看展前快速理解“这幅画站在艺术史哪一级台阶上”。
  • 学生与教师：课前预习、复习，或课堂投屏用地球仪讲故事替代 PPT 年代表。

当前痛点：市面上的艺术史 App 多为百科全书式列表，门槛高、缺乏空间叙事；地图类工具又缺少艺术专业的 curated 内容与视觉连续性。普通爱好者很难找到“既好看、又能建立感觉”的入口。

05 · 价值与意义

学习效率：把传统艺术史书籍变成可交互、可视化的学习材料，将抽象的时间线锚定在真实地理与视觉案例上，降低认知负荷，提升记忆留存。

文化价值：公共领域艺术作品（Met、Rijksmuseum、Wikimedia）被重新组织为可交互叙事，让经典视觉知识更易被年轻用户接触。

扩展空间：首条主线聚焦“写实主义的胜利与危机”。未来会复用同一套 3D 地球仪 + 时间线 + 详情面板的产品骨架，扩展“光的历史”“赞助人与艺术”“身体图像”等更多主线，成为一个不局限于单一主题的艺术史叙事平台。

06 · 技术栈与体验亮点

Vite + React + TypeScript + Tailwind CSS 构建界面；原生 Three.js 直接管理 3D 场景，以获得更精细的相机飞行、大气散射 shader 和标记脉冲动画；GSAP 负责过渡动效；URL 参数同步当前时期，支持键盘导航、移动端时间线视图与 WebGL 不可用时自动降级。
