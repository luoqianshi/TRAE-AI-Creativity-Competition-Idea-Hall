PROJECT IDEA

为什么做忆拾光：时光故事集？

在数字时代的浪潮中，我们希望为银发群体留下一个温柔的角落

💭

被遗忘的记忆

每一位长辈心中都藏着无数动人的故事，但随着时间流逝，这些珍贵记忆可能永远尘封。我们希望为他们搭建一座桥梁。

👴

数字时代的鸿沟

大多数老年人被复杂的科技产品拒之门外。我们相信，好的产品不应该让用户适应科技，而应该让科技适应用户。

💝

代际情感连接

很多子女想了解父母的过去，却不知从何问起。一本回忆录，是送给孩子最珍贵的礼物，也是留给自己最好的见证。

✨

AI 的温度

我们不追求冰冷的技术炫技，而是用 AI 做一位耐心的倾听者、一位温暖的整理者，让每个人的故事都被温柔对待。

CORE FEATURES

四大核心功能

从记录到分享，全流程贴心陪伴

01
🎯

引导式问答

按人生阶段智能引导，"童年记忆"、"青春岁月"、"事业征程"、"家庭温情"、"里程碑时刻"——每一步都有温柔的提问，让用户无需思考"写什么"。

  • ✓ 分阶段主题引导
  • ✓ 开放式问题设计
  • ✓ 随时保存草稿
02
🤖

AI 故事整理

零散的问答不再是零散的笔记。AI 将碎片化的回答编织成连贯的章节文字，自动生成目录、章节标题，让记录变成真正的"回忆录"。

  • ✓ 自动生成章节标题
  • ✓ 内容智能润色
  • ✓ 章节结构组织
03
📚

电子书展示

精美的书籍式阅读界面，像翻阅一本真正的回忆录。配有章节导航、原问答记录查看，让阅读变成一种仪式感的体验。

  • ✓ 书籍封面设计
  • ✓ 章节翻页动画
  • ✓ 字号自由调节
04
🎁

分享与传承

一键生成分享卡片与链接，让子女、孙辈可以在任何时间阅读这些故事。让爱与记忆，在代际间温柔流淌。

  • ✓ 精美分享卡片
  • ✓ 链接一键复制
  • ✓ 多平台支持

TECH ARCHITECTURE

技术架构与实现

一次开发，多端运行 · 稳健架构支撑美好体验

📱

前端：Taro 4.x 跨端框架

基于京东出品的 Taro 框架，使用 React 18 + TypeScript 开发。一次开发，同时支持微信小程序、抖音小程序、支付宝小程序、H5 网页等多个平台。

Taro 4.1.9React 18TypeScriptSCSS CSS Modules
🎨

设计系统

自定义温暖主题配色，完整的间距、圆角、字号规范，确保全平台视觉一致。

💾

本地存储

基于 Taro Storage API 的本地持久化方案，用户数据安全存储在设备本地，无需注册登录。

🤖

AI 能力

接入大模型 API，实现智能问答引导、内容润色、章节标题生成、分享文案撰写。

项目文件结构

src/
├── app.config.ts          # 全局配置（页面 + TabBar）
├── app.tsx                # 应用入口
├── app.scss               # 全局样式
├── styles/
│   ├── theme.scss         # 主题配色变量
│   └── variables.scss     # 通用 SCSS 变量
├── types/
│   └── story.ts           # 回忆录章节等类型定义
├── pages/
│   ├── home/              # 首页：回忆录列表
│   ├── record/            # 记录页：引导式问答
│   ├── book/              # 阅读页：章节浏览
│   ├── mine/              # 我的页：设置与统计
│   ├── share/             # 分享页：分享卡片
│   └── story-detail/      # 章节详情页
├── components/
│   ├── StoryCard/         # 回忆录卡片组件
│   ├── QuestionCard/      # 问答卡片组件
│   └── EmptyState/        # 空状态组件
├── data/
│   └── mockData.ts        # 引导问题库 + 示例数据
└── utils/
    └── storage.ts         # 本地存储工具函数
