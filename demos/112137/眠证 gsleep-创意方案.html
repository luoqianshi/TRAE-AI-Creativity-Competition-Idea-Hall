01 / 问题

失眠已经很难熬，不被相信是第二层痛苦

中老年失眠患者常常发现，自己的痛苦一开口就被一句话打发——“老了都这样”“你是不是太敏感了”。失眠是主观的、说不清的，家人没有恶意，但也没有证据可看，于是选择了最省事的解释：正常衰老。

核心判断

眠证服务的不是“睡得更像数据”，而是“失眠的痛苦终于能被家人认真看见”。

02 / 产品是什么

三步，把一句“我没睡好”变成一份说得清的记录

产品被刻意设计得足够轻：不连续佩戴，不自动同步，不要求用户先学会一套睡眠评分。

01

每天一次，几十秒的语音记录

不是打勾评分，而是具体事件——“三点十五醒的，躺了四十分钟才又睡着”。越具体，越难被一句话打发。

02

患者自己选时机，一键生成报告

系统把连续记录整理成可读的睡眠叙事报告。不会自动同步给任何人，想不想出示、什么时候出示，都由患者决定。

03

主动出示，把话说清楚

下次再被说“你是不是太敏感了”，拿出的不是情绪，而是一段连续、具体、可信的记录。

Input / 输入

患者自己的声音

时间、频率、情绪与身体感受，由患者主动留下，而不是由设备替患者下结论。

→
Output / 输出

一份可讲述的证词

既像证据，也像一次对话的开场白；比冰冷的仪表盘更适合家庭沟通。

03 / 交互流程

真正完成的，不是采集，而是从自述到理解的翻译

这条路径的关键不在“记录更多”，而在于把一次主观感受转化成更容易被别人理解的表达。

语音自述患者说出昨夜发生了什么
提取信息几点醒、醒多久、今天状态
生成报告形成连续、可回看的证据链
自主出示患者选择对象与时机
家庭理解对话从质疑转向认真倾听

硬件不必从手环或传感器开始。当前的软件原型已经足以验证核心假设；未来的硬件可以围绕“出示、播放、共读”展开。

04 / 目标用户

不是要说服所有人，是要说服自己最在乎的那个人

面向 45 岁以上、长期失眠，且被家人尤其是子女质疑或轻描淡写过的人。他们与家人保持日常联系，有意愿主动沟通，只是一直缺少一个不必争辩、只需出示的工具。

典型场景 / 03:15

清晨或睡前，几十秒的语音记录，像写一句极简日记。某天又被一句“老了都这样”打发之后，打开手机，一键生成近期记录，直接递过去——“这是我这周的记录，不是我矫情。”

05 / 价值与差异

差异不在功能多少，而在信息究竟掌握在谁手里

多数睡眠产品默认数据应该流向家人或照护者；眠证坚持由患者决定何时、为何、向谁展示。它保护的不是数据完整性，而是表达尊严。

06 / 最小版本

两周，不验证功能多不多，只验证三件事

先保留语音记录、近期整理、报告出示三个最短环节。硬件接入、睡眠评分、家庭协同，都可以后置。

Test 01
记录够不够轻？

用户能否在几十秒内完成一次自述，并愿意连续留下几天记录。

Test 02
报告真能拿出手吗？

报告是否足够清楚、足够具体，让用户愿意真的拿给家人看。

Test 03
沟通真的改变了吗？

家人的回应是否从“你想多了”转向“我明白你为什么难受”。

07 / 价值

把患者从被否定的一方，变成掌握证据的一方

社会价值

直接回应中老年失眠病耻感与家庭代际沟通断裂。让患者从“被动等待被安慰或被否定”，变成“主动出示证据、掌握沟通主动权”。

商业与效率价值

零硬件成本，两周内可出最小版本。报告被出示给子女的那一刻，本身也构成一次自然传播，验证路径明确、边际成本低。

眠证

“眠”是被否定的那部分，“证”是被拿回来的那部分。这份方案要做的，始终只有一件事——让说不清的痛苦，变得说得清。

本方案基于中老年人失眠痛点研究整理。产品构思未经完整市场与用户验证，核心假设——具体化记录能否真正改变家人的信念——有待 MVP 验证。
