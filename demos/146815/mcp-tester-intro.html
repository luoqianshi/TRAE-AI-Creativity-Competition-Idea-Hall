产品简介

mcp-tester 是一款专为 MCP (Model Context Protocol) Server 开发者打造的测试与验证工具。 通过单一 Node 进程统一接入浏览器、AI 客户端、SSE 观察端三类用户，提供完整的 MCP 协议测试能力， 帮助开发者快速验证和调试 MCP Server 的功能与性能。

核心功能

🌐

统一接入端口

一个端口同时支持 Web UI、REST API、MCP Server、SSE 观察流四种协议

⚡

压力测试

支持顺序压测、突发并发、熔断测试三种模式，全面评估服务性能

🔧

协议验证

11 项 MCP 协议合规用例，确保服务符合标准规范

📊

实时监控

SSE 实时流推送，可视化展示所有 MCP 消息交互过程

🤖

AI 工具接入

提供 17 个 AI tools，支持 Claude/Cursor/VS Code Copilot 直接连接

🔍

日志回放

支持历史日志会话重放，便于问题回溯与调试

技术栈

Node.js Express Vue.js MCP Protocol SSE JSON-RPC

快速开始

启动服务：

npm install && npm start

访问地址：

http://localhost:3456

AI 客户端配置：

{ "mcpServers": { "mcp-tester": { "type": "http", "url": "http://localhost:3456/mcp" } } }
