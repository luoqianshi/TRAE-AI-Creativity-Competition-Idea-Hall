✦ 功能模块

六大模块，守护每一刻情绪

从记录到封存，每个模块都是情绪团子世界的一块拼图，拼出你独一无二的内心地图。

🗺️ 1
情绪地图
可视化你的情绪轨迹——每一次记录化身记忆瓶摆放在地图上，形成专属情绪热力图。走过的路、流过的泪、笑过的瞬间，都在地图上发光。
Leaflet地图 情绪热力图 记忆瓶定位
🧚 2
小精灵
你的情绪陪伴者——会变色、会说话、会回信、会记住。四种人设随心切换：温暖治愈、理性陪伴、元气鼓励、安静倾听。它不是工具，是懂你的小家伙。
Lottie动画 人设系统 情绪变色
🎨 3
涂鸦记录
全屏画布，随便涂鸦——笔触自动识别情绪（笔压与速度映射情绪类型和强度），粒子效果随情绪爆发，画完即标注。不用选标签，你的笔迹就是情绪的语言。
Canvas引擎 笔触情绪识别 tsParticles
🎙️ 4
语音记录
随便说——Web Audio API 提取音量与波形特征，Web Speech API 转文字，双通道信号合并传给 LLM 分析情绪。你的声音，比文字更诚实。
Web Audio API Web Speech API 波形情绪
✍️ 5
手写记录 + 回信
长文日记空间，倾诉、复盘、吐槽——LLM 识别情绪后，精灵带着你选定的人设写一封温暖回信。何炅风格的温柔：不翻旧账，只回应当次，过去的记忆封存进瓶子。
长文日记 精灵回信 人设语气
📸 6
记忆相册
拍照或选图，给照片加上情绪标签和涂鸦叠加，时间线回顾每一帧情绪。记忆不只是图片，是那个时刻的你。
拍照/选图 涂鸦叠加 时间线
🫙 7
记忆瓶 + 报告
把记忆封存进瓶子——每一段情绪记录都可以轻轻盖好瓶盖，不再翻看。精灵会定期给你写周报/月报「体检信」，温柔地告诉你：最近辛苦了，辛苦在哪里。
记忆封存 周/月报告 精灵体检信
✦ 核心创新

不一样的地方

情绪团子不是日记工具，不是情绪量表，而是一个「懂你」的精灵朋友。

🎨
涂鸦笔触自动识别情绪
通过 Canvas 笔触引擎捕捉笔压与速度，映射为情绪类型（焦虑/愤怒/平静/喜悦）和强度值。无需手动选标签，你的画笔自己会说话。情绪爆发时触发 tsParticles 粒子效果，让情绪可视化、可发泄。
🧚
精灵人设回信系统
不翻旧账，只回应当次。精灵带着用户选定的人设（温暖治愈/理性陪伴/元气鼓励/安静倾听）用 LLM 生成回信。何炅风格的温柔：不追问、不评价、不说教，只是轻轻说「我听到了」。每段对话记忆封存进瓶子，精灵不会在下次提起。
🔗
MCP 数据接入层
通过 MCP (Model Context Protocol) 接入多维上下文数据——地理位置（情绪与地点关联）、相册（情绪与场景关联）、HRV 心率变异性（Mock 数据模拟生理指标）——喂给 LLM 作为情绪分析的上下文，让精灵不仅听你说，还能感知你在哪、经历了什么。
🎙️
双通道语音情绪识别
Web Audio API 提取音量包络与频谱波形作为声学情绪特征，Web Speech API 将语音转为文字作为语义情绪特征，双通道合并输入 LLM 做综合情绪判断。声音的颤抖、语气的低落，文字说不出的，声音替你表达。
🫙
记忆封存与精灵体检信
独创的「封存」机制：每段记忆可以轻轻盖好瓶盖，放进瓶子，不再翻看。精灵只记住统计层面的趋势，不记住具体内容。每周/月，精灵写一封「体检信」——不说教、不焦虑，只是温柔地告诉你这段时间的情绪变化。保护隐私，也保护你。
