# 拼音打字练习游戏

一款用于练习拼音打字的互动小游戏，帮助用户提升拼音输入速度和准确率。

## ✨ 功能特点

- 🎯 **随机汉字生成**：根据难度级别随机生成常用汉字及其拼音
- 📊 **三个难度级别**：
  - 🌱 **初级**：简单汉字，每字10秒，共20字
  - 🔥 **中级**：中等难度汉字，每字7秒，共30字
  - 💎 **高级**：复杂汉字，每字5秒，共40字
- ⏱️ **实时计时系统**：每个汉字都有独立的倒计时
- 📈 **实时计分系统**：根据输入速度和准确率进行评分，包含时间奖励
- 🔥 **连击系统**：连续答对可获得连击倍率加成（最高10倍）
- 🎉 **五彩纸屑特效**：答对10连击或游戏结束时触发庆祝特效
- 🔊 **音效反馈**：使用Web Audio API生成正确/错误/倒计时音效
- 🎨 **精美动画**：
  - 动态渐变背景
  - 浮动粒子效果
  - 汉字发光脉动
  - 正确弹跳动画
  - 错误抖动动画
  - 分数滚动动画
  - 3-2-1倒计时
- 📱 **响应式设计**：适配不同设备屏幕尺寸

## 🚀 使用方法

### 本地运行

1. 将所有文件下载到本地文件夹
2. 使用浏览器打开 `index.html` 文件即可开始游戏

### 使用步骤

1. **选择难度级别**：点击初级、中级或高级按钮选择难度
2. **开始游戏**：点击"开始游戏"按钮，会有3-2-1倒计时
3. **输入拼音**：在输入框中输入显示汉字对应的拼音
4. **提交答案**：按回车键提交答案或等待倒计时结束
5. **查看结果**：游戏结束后显示最终得分、正确率、平均速度和最高连击

## 🎮 游戏规则

- 正确输入拼音可获得基础分数和时间奖励
- 时间奖励根据剩余时间计算，剩余时间越多奖励越高
- 连续答对可触发连击，连击越高分数倍率越大（最高10倍）
- 答错或超时会中断连击并显示正确答案
- 游戏结束后显示综合评分和鼓励语

## 🎵 音效说明

游戏使用Web Audio API生成音效，无需外部文件：
- 正确答案：欢快的上升音调
- 错误答案：低沉的下降音调
- 倒计时：短促的提示音
- 游戏开始：欢快的启动旋律

## 🛠️ 技术实现

- **前端框架**：原生 HTML5 + CSS3 + JavaScript
- **无需后端**：所有数据在前端本地处理
- **音频**：Web Audio API（无需外部音频文件）
- **动画**：CSS Keyframes + Canvas（粒子特效）
- **响应式布局**：使用 CSS Flexbox 和媒体查询
