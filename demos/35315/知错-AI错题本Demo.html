核心功能

围绕"录入 → 归因 → 讲解 → 复习"四步，打造完整闭环

01 / 录入

📷 拍照 OCR 智能识别

手机拍照或截屏上传，AI 自动识别题目、公式、图示，几何图形、函数图像也能准确还原。

02 / 归因

🧠 错因智能诊断

结合答案和你的答题痕迹，AI 分析错误原因：概念不清 / 计算失误 / 方法不当 / 审题偏差，给出精准归类。

03 / 讲解

🎓 自适应 AI 讲解

根据学生年级和能力等级，用易懂的语言分步讲解；可一键生成同类变式题，举一反三。

04 / 复习

📅 艾宾浩斯复习计划

基于遗忘曲线智能推送复习时间：第 1 / 2 / 4 / 7 / 15 天自动提醒，再也不让错题"躺在本子里吃灰"。

05 / 图谱

🕸 知识点掌握图谱

可视化展示每个章节、每个知识点的掌握度（熟练 / 一般 / 薄弱），薄弱点一目了然。

06 / 报告

📊 学情周报 · 家长可见

每周生成学情报告：错题趋势、薄弱知识点、提分建议，家长也能在 App 端同步查看。

产品演示

以下是「知错」关键界面的原型示意

数学 · 九年级 中等 来源：期中模拟卷 · 第 23 题
题目：已知二次函数 y = ax² + bx + c 的图像开口向下，且经过点 (1, 2) 和 (-1, 0)，对称轴为 x = 1，求 a、b、c 的值。
✓ 正确答案
a = -1/2，b = 1，c = 3/2
⚠ AI 错因诊断
你的错误：对称轴公式记错。应为 x = -b/(2a)，你算成了 x = b/(2a)，导致 b 符号反了。

薄弱点：二次函数对称轴与开口方向的关系。
💡 AI 讲解（自适应难度）
二次函数 y = ax² + bx + c 的对称轴是 x = -b/(2a)，不是 b/(2a)。这是最常错的公式之一，可以用"负 b 除以 2a"的口诀记忆。如果 a>0 开口向上，a<0 开口向下……
📌 知识点：二次函数 📌 章节：函数与图像 ⚠ 错因：公式记忆 🔁 待复习
