核心特性
为速度而生，为简洁而设计

IPKM 的每一个设计决策，都致力于实现最低延迟和最简配置。

⚡

超低延迟

基于 UDP 的事件传输，使用预编译 struct 格式。事件仅占 11-15 字节，零握手开销，即时发送。

UDP 广播
🔐

ChaCha20 加密

可选的端到端加密，采用 ChaCha20-Poly1305 AEAD 密码套件与 PBKDF2 密钥派生。设置密码后默认启用安全传输。

AEAD 密码
🌐

跨平台

客户端通过 pynput 运行于 Windows、Linux 和 macOS。服务端通过 evdev 在 Linux 上捕获输入。一套代码，全平台覆盖。

pynput + evdev
📡

自动发现

基于 UDP 广播的设备发现机制，自动搜索局域网内的对端设备。无需手动配置 IP 地址。

类 mDNS
🖥️

系统托盘代理

客户端以系统托盘形式静默运行，实时显示统计数据。一目了然地查看接收事件数、错误率和连接状态。

pystray
📦

单文件分发

Windows 客户端通过 PyInstaller 打包为独立 .exe 文件。无需安装 Python 运行时。下载、运行、连接，三步完成。

PyInstaller

二进制协议

预编译 struct.Struct 对象。无 JSON、无序列化开销。原始字节直接上线路传输。

事件类型

鼠标移动 (13B) / 鼠标点击 (15B) / 鼠标滚轮 (11B) / 按键按下 (12B) / 按键释放 (12B)

套接字调优

SO_RCVBUF=128KB。启用 SO_REUSEADDR。1s 超时实现优雅关闭。非阻塞设计。

按键映射

以 Windows VK 码作为通用中间格式。完整支持 A-Z、0-9、F1-F12、修饰键及特殊键。

通信协议
每个事件仅 11 到 15 字节，仅此而已

整个协议是一个紧凑的二进制格式，只为一个目标设计：以物理极限速度将输入事件从 A 点传送到 B 点。

# 事件类型定义
class EventType(IntEnum):
  MOUSE_MOVE     = 0x01
  MOUSE_CLICK    = 0x02
  MOUSE_SCROLL    = 0x03
  KEY_PRESS       = 0x04
  KEY_RELEASE     = 0x05

# 预编译 struct 格式
_MOUSE_MOVE_FMT = '<BdHH'  # 13 bytes
_MOUSE_CLICK_FMT = '<BdHHBB' # 15 bytes
_KEY_EVENT_FMT = '<BdHB'   # 12 bytes

# 一次打包，立即发送
def pack_mouse_move(x, y):
  return _MOUSE_MOVE_ST.pack(
    EventType.MOUSE_MOVE,
    time.monotonic(),
    x, y
  )

使用场景
谁需要 IPKM？

从开发者到游戏玩家，任何在同一网络下拥有多台电脑的人。

01

多屏开发者

在 Linux 工作站上写代码，在 Windows 笔记本上测试。一套键盘鼠标，跨操作系统无缝切换上下文。

IT 管理员

从单一控制台管理多台无头服务器或工作站。无需 KVM 硬件 — 只需你的局域网。

03

数字艺术家与设计师

用高性能桌面进行渲染，同时用平板处理参考资料和通讯。统一的创意工作流。

Home Lab 爱好者

从主桌面控制你的家庭实验室机器。监控、配置、交互，无需硬件切换器。
