守护眼

旧手机变 AI 看护摄像头 — 零硬件成本守护独居老人安全

硬件交互赛道 智慧助老 · 公益附加赛题 TRAE AI 创造力大赛

💡创意介绍

想解决的问题：独居老人发生跌倒、长时间静止等意外时，家人往往无法第一时间发现，错过黄金救治时间。而市面上的看护方案要么是昂贵的高清摄像头，要么是需要穿戴的智能手环——老人抗拒穿戴，摄像头又涉及隐私顾虑。

灵感来源：几乎每个家庭都有一部退役的旧手机躺在抽屉里吃灰。这些手机摄像头还能用、能联网，完全可以"变废为宝"改造成 AI 看护眼。结合 TRAE AI 的浏览器端 TensorFlow.js 能力，无需安装 App、无需穿戴设备，就能实现本地化的姿态检测和跌倒告警。

产品形态：一套"看护端 + 家人端"的轻量 Web 系统。看护端用旧手机浏览器打开网页即可调用摄像头 + AI 姿态检测；家人端是 React Web 应用，实时接收告警和画面。零硬件采购、零 App 安装、零学习成本。

⚡核心功能

📹

摄像头实时取流

WebRTC getUserMedia 调用旧手机摄像头，canvas 实时绘制画面 + TF.js MoveNet 17 点骨架标注，本地推理零延迟。

🚨

跌倒智能判定

躯干角度（站立0°→倒地90°）+ 1.5s 内下降速度 >20% 画面高度，双条件判定避免误报。8s 冷却防重复告警。

⏸️

长时间静止检测

躯干位移 <8px 持续 30s 触发静止告警，覆盖老人晕厥、跌倒后无法起身等场景。

🔔

告警即时推送

异常时截图（JPEG 0.7）+ 时间戳通过 WebSocket 推送到家人端，告警列表 + 浏览器通知双通道触达。

🖥️

家人端实时查看

React Web 应用，按需开启实时画面（~5fps）、查看告警历史、回看异常截图，一键关闭随时保护隐私。

🛠️

调试演示模式

?debug=1 开启调试面板，无需真人摔倒即可模拟跌倒/静止/截图告警，走完整真实链路，方便现场演示。

🧠跌倒检测算法

指标计算方式判定阈值
躯干中心 Yavg(shoulders.Y, hips.Y)1.5s 内下降 >20% 画面高度
躯干角度|atan2(hipX-shoulderX, hipY-shoulderY)|>50°（趋于水平）
体态比bodyHeight / bodyWidth<0.85（倒地形态）
静止位移躯干中心帧间位移<8px 持续 30s
告警冷却两次告警最小间隔8s

跌倒判定需同时满足"突然下落"+"趋于水平"两个条件，有效降低坐下去、蹲下等正常动作的误报。

🔒隐私保护设计

🏠
画面本地处理
姿态检测在手机浏览器本地完成，默认不传输任何画面数据。
📸
仅告警上传截图
跌倒/静止异常时才截图上传（JPEG 压缩），平时零数据外传。
👁️
实时查看手动开启
家人端主动请求才传输画面帧，可随时一键关闭。
⏹️
一键关闭看护
看护端「关闭看护」立即停止摄像头和检测，老人/家人完全可控。

💎价值与意义

💚

社会价值

中国有超 1.3 亿独居老人，跌倒致死是 65 岁以上老人意外死亡首要原因。本项目用零成本方案填补"无穿戴、低隐私侵入"的看护空白，让每个普通家庭都能负担 AI 守护。

♻️

资源循环价值

全球每年废弃手机超 15 亿部，本项目让退役旧手机"变废为宝"，延长设备生命周期 3-5 年，减少电子垃圾，契合绿色低碳理念。

💰

商业价值

零硬件成本降低门槛，可作为社区居家养老、保险公司健康服务、智能硬件厂商的轻量化增值方案，未来可扩展语音呼叫、用药提醒等能力。

🚀如何体验

1

启动服务

解压 zip → npm install && npm start → 服务器启动在 3000 端口

2

家人端（电脑）

浏览器打开 http://localhost:3000/family/ → 看到告警列表 + 实时查看按钮

3

看护端（旧手机）

手机访问 https://<电脑IP>:3000/care-end/（需 HTTPS）→ 允许摄像头 → 点「开启看护」

4

调试演示（推荐）

电脑直接打开 http://localhost:3000/care-end/?debug=1 → 点「模拟跌倒」→ 家人端立即收到告警

5

查看闭环

家人端告警列表出现截图卡片 → 点击放大查看 → 浏览器通知弹出 → 完整闭环验证完成
