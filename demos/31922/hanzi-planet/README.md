#### 1. 创意名称 + 创意介绍

**创意名称**：探字星球

**想解决什么问题**：中国3-6岁幼儿约5000万，幼小衔接焦虑困扰着绝大多数家长。现有识字产品两极分化——要么纯游戏化导致"孩子只玩不学"，要么枯燥机械让孩子抵触。家长急需一款"孩子觉得好玩、家长看到效果"的识字工具。

**为什么会想到做这个**：观察到三个真实痛点：（1）家长没时间系统教孩子认字，只能零散指认；（2）孩子写汉字笔顺错误形成习惯后很难纠正；（3）市面上产品广告多、内容杂、收费高。而汉字本身就是最好的"游戏素材"——相传仓颉造字时观察鸟兽足迹，每个字都有象形故事、演变历史、造字智慧。从《易经·蒙卦》的"蒙以养正"到《千字文》的"天地玄黄"，千年蒙学智慧告诉我们：识字不是死记硬背，而是一场探索宇宙般的奇妙旅程。

**大概是什么产品**：微信小程序 — 基于 TRAE Work Auto 模式快速开发，结合 AI 自适应学习算法，为每个孩子定制专属学习路径。无需下载安装，打开即用，每次5-15分钟碎片化学习。**所有汉字内容完全免费、无广告。**

**技术亮点**：
- **TRAE Work Auto 模式**：从创意到原型，AI 辅助生成核心代码和 UI 设计，开发周期缩短 70%
- **AI 笔顺识别引擎**：Canvas 实时追踪书写轨迹，智能判断笔顺正确性，错误即时纠正
- **AI 自适应学习**：根据孩子练习数据动态调整难度和复习节奏，实现"千人千面"
- **AI 语音伴读**：TTS 合成童声讲解汉字故事，替代家长带读

### 2.2 核心功能模块

#### 模块一：仓颉笔迹（AI笔顺互动练习）

- **文化渊源**：相传仓颉造字时观察鸟兽足迹而悟得笔顺之道，我们延续这份智慧
- **AI 笔顺识别引擎**：Canvas 实时追踪书写轨迹，智能判断笔顺正确性
- **分阶难度**：描红 → 临摹 → 独立书写，循序渐进
- **即时反馈**：每写对一笔触发星星动画和语音鼓励
- **错误纠正**：笔顺错误时，AI 用动画演示正确写法

#### 模块二：千字星际（探字星球冒险）

- **文化渊源**：《千字文》开篇"天地玄黄，宇宙洪荒"，古人以宇宙视角认识世界
- **象形配对**：将汉字与对应图片连线，理解字形本源
- **星球闯关**：每个汉字对应一个星球关卡，通关解锁新星球
- **宝藏收集**：通关后获得汉字宝藏卡，激发收集欲
- **亲子对战**：家长与孩子PK识字速度，增进互动

#### 模块三：字源演义（造字故事动画）

- **文化渊源**：东汉许慎《说文解字》首创"六书"理论，系统分析汉字本源
- **演变动画**：从甲骨文 → 金文 → 小篆 → 隶书 → 楷书的完整演变
- **语音讲解**：AI 童声讲述每个汉字的造字故事
- **互动问答**：故事结束后弹出小测验，巩固记忆
- **文化拓展**：关联相关成语、诗词，拓展文化视野

#### 模块四：蒙学进阶（成就与奖励体系）

- **文化渊源**：《易经·蒙卦》"蒙以养正，圣功也"——在启蒙阶段培养端正品性，是圣人之功
- **每日打卡**：连续打卡解锁特殊成就和限定宝藏卡
- **汉字图鉴**：已学汉字以图鉴形式展示，可视化学习成果
- **学习报告**：家长端查看每日学习时长、掌握汉字数、薄弱点分析
- **等级体系**：从"童蒙"到"开蒙"再到"汉字探险家"的蒙学进阶路径

### 2.3 用户旅程地图

```
Step 1: 发现
  家长在微信搜索"幼儿识字"或朋友圈分享 → 看到探字星球小程序

Step 2:  onboarding
  首次进入 → 选择孩子年龄 → 生成专属宇航员头像 → 进入首页

Step 3: 第一堂课
  系统推荐"山"字（最简单的基础字）
  → 观看甲骨文演变动画（30秒）
  → 听AI讲解"山"字故事（30秒）
  → 进入书写练习，描红第一笔

Step 4: 练习与反馈
  孩子用手指描红 → AI判断笔顺正确 → 触发星星奖励动画
  → 继续下一笔 → 完成整个字 → 获得"山字宝藏卡"

Step 5: 巩固与拓展
  进入"探字冒险"游戏 → 将"山"字与山峰图片配对
  → 通关后解锁"水"字星球
  → 家长收到学习报告：今日学会1个字，练习3分钟

Step 6: 持续学习
  每日推送"今日探险任务" → 完成打卡 → 连续7天解锁"探险家徽章"
```

#### Canvas笔顺书写核心逻辑

```javascript
// pages/write/write.js
Page({
  data: {
    currentChar: '山',
    strokes: [], // 笔顺数据
    currentStroke: 0,
    isDrawing: false,
    points: [],
    score: 0
  },

  onLoad() {
    this.loadCharacterData();
    this.initCanvas();
  },

  initCanvas() {
    const query = wx.createSelectorQuery();
    query.select('#writeCanvas')
      .fields({ node: true, size: true })
      .exec((res) => {
        const canvas = res[0].node;
        const ctx = canvas.getContext('2d');
        this.canvas = canvas;
        this.ctx = ctx;
        const dpr = wx.getWindowInfo().pixelRatio;
        canvas.width = res[0].width * dpr;
        canvas.height = res[0].height * dpr;
        ctx.scale(dpr, dpr);
        this.drawGrid();
        this.drawDemoStroke(); // 显示示范笔顺
      });
  },

  drawGrid() {
    const ctx = this.ctx;
    const w = 300, h = 300;
    ctx.strokeStyle = '#E8DFD0';
    ctx.lineWidth = 1;
    ctx.strokeRect(0, 0, w, h);
    ctx.beginPath();
    ctx.moveTo(0, 0); ctx.lineTo(w, h);
    ctx.moveTo(w, 0); ctx.lineTo(0, h);
    ctx.stroke();
    ctx.beginPath();
    ctx.moveTo(w/2, 0); ctx.lineTo(w/2, h);
    ctx.moveTo(0, h/2); ctx.lineTo(w, h/2);
    ctx.stroke();
  },

  onTouchStart(e) {
    this.setData({ isDrawing: true, points: [] });
    this.addPoint(e);
  },

  onTouchMove(e) {
    if (!this.data.isDrawing) return;
    this.addPoint(e);
    this.drawStroke();
  },

  onTouchEnd() {
    this.setData({ isDrawing: false });
    const score = this.evaluateStroke();
    if (score > 80) {
      wx.showToast({ title: '太棒了！', icon: 'success' });
      this.setData({ currentStroke: this.data.currentStroke + 1 });
      if (this.data.currentStroke >= this.data.strokes.length) {
        this.showCompletion();
      }
    } else {
      wx.showToast({ title: '再试一次', icon: 'none' });
      this.redrawGrid();
    }
  },

  addPoint(e) {
    const { x, y } = e.touches[0];
    this.data.points.push({ x, y });
  },

  drawStroke() {
    const ctx = this.ctx;
    const points = this.data.points;
    if (points.length < 2) return;
    ctx.strokeStyle = '#FF6B35';
    ctx.lineWidth = 8;
    ctx.lineCap = 'round';
    ctx.lineJoin = 'round';
    ctx.beginPath();
    ctx.moveTo(points[0].x, points[0].y);
    for (let i = 1; i < points.length; i++) {
      ctx.lineTo(points[i].x, points[i].y);
    }
    ctx.stroke();
  },

  evaluateStroke() {
    // AI笔顺识别：计算用户书写路径与标准笔顺的相似度
    const userPath = this.data.points;
    const standardPath = this.data.strokes[this.data.currentStroke].path;
    return this.calculateSimilarity(userPath, standardPath);
  },

  calculateSimilarity(userPath, standardPath) {
    // 简化版：计算路径的DTW（动态时间规整）距离
    // 实际项目中使用更复杂的算法
    let distance = 0;
    for (let i = 0; i < Math.min(userPath.length, standardPath.length); i++) {
      const dx = userPath[i].x - standardPath[i][0];
      const dy = userPath[i].y - standardPath[i][1];
      distance += Math.sqrt(dx * dx + dy * dy);
    }
    const maxDistance = 300; // 阈值
    const score = Math.max(0, 100 - (distance / maxDistance) * 100);
    return Math.round(score);
  },

  showCompletion() {
    wx.showModal({
      title: '恭喜完成！',
      content: `你学会了「${this.data.currentChar}」字！获得山字宝藏卡！`,
      showCancel: false,
      success: () => {
        // 跳转到成就页或游戏页
        wx.navigateTo({ url: '/pages/achievement/achievement' });
      }
    });
  }
});
```
