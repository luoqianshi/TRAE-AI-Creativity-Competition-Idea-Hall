赛道：学习工作

1. 创意名称 + 创意介绍

创意名称
AI工具雷达（AI Dev Radar）
想解决什么问题
AI开发工具更新迭代极快，GitHub上每天都有新项目爆火，但开发者难以快速发现和筛选真正好用的工具。目前信息分散在各大平台，缺乏一个实时聚合、智能分类的入口。开发者往往错过优质工具，或在海量选择中耗费大量时间试错。
为什么会想到做这个
作为一名学生开发者，我在学习过程中发现很多同学还在用传统方式写代码，而不知道有Cursor、Windsurf这些能大幅提效的工具。我自己也经常在GitHub Trending里"淘金"，但信息太分散、筛选成本高，就想做一个自动聚合的工具箱。
产品形态
一个Web网站，实时追踪GitHub上热门AI开发工具，提供分类筛选、热度趋势、中文解读等功能。

2. 目标用户及痛点

面向哪些用户
  • 学生开发者：想了解最新AI工具但信息渠道有限
  • 初中级程序员：希望提升开发效率，但不知道有哪些工具可用
  • 技术爱好者：喜欢尝鲜、关注AI领域动态
在什么场景下使用
  • 学习新项目时，想找合适的AI辅助工具
  • 日常开发中，想提升编码效率
  • 技术选型时，需要对比不同工具的特点
当前痛点
  • GitHub Trending信息过载，难以快速定位AI工具
  • 缺乏中文解读，很多项目文档只有英文
  • 没有统一入口，需要跨多个平台搜集信息
  • 工具之间难以横向对比

3. 价值与意义

效率提升
帮助开发者节省信息搜集时间，快速找到适合自己的AI工具。据统计，2025年已有84%的程序员在使用AI编程助手，但仍有大量开发者不知道如何选择合适的工具。
社会价值
降低AI工具的使用门槛，让更多学生和初学者能够接触前沿技术，缩小技术鸿沟，推动AI辅助开发的普及。

4. 技术实现方案

数据来源
  • 使用GitHub官方API获取热门项目数据
  • 通过ai、skill等标签筛选AI开发工具
  • 每周定时更新，保证数据时效性
内容生成
  • 用AI（如ChatGPT、Claude）根据项目README自动生成中文解读
  • 生成内容包括：用途说明、适合人群、推荐理由
  • 人工审核后发布，保证内容质量
展示内容
  • 项目名称 + 简介
  • 用途说明 + 适合人群
  • Star数、增长趋势
  • 项目链接
技术栈
前端
Vue2搭建网页界面
后端
Python脚本定时抓取GitHub数据
数据存储
轻量级数据库或JSON文件
搜索功能
前端过滤实现

5. 开发计划

第一阶段：MVP版本
  • 实现GitHub API数据抓取
  • 搭建基础网页框架
  • 展示项目基本信息（名称、简介、Star数、链接）
  • 实现基础搜索过滤功能
第二阶段：功能完善
  • 接入AI生成中文解读
  • 添加用途说明、适合人群展示
  • 优化界面设计
  • 添加热度趋势图表
第三阶段：迭代优化
  • 根据用户反馈持续改进
  • 扩展更多AI工具分类
  • 考虑添加用户评论功能
