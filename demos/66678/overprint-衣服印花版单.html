01 创意介绍

想解决的问题，
是「印花打样」的工具断层。

Overprint 想解决的核心问题是：独立设计师、印花工作室、中小服装卖家在做衣物印花定制时，抠图、套版、合成打样三个环节被切碎在三到五个工具之间——上传到付费抠图网站、用 PS 套模板手动对齐、再拼合导出，单张图样往往要 15–30 分钟，且原图还要离开本地。

想解决什么问题
把印花设计的全流程，从多工具串联压缩进单页应用。
为什么会想到做这个
灵感来自印刷行业的「叠印」工艺——油墨层层叠加形成最终图案。我们希望把印花流程像叠印一样，在一处完成。
大概是什么产品
纯前端 Web 应用，浏览器打开即用，无需安装、无需登录、原图不上传。
02 目标用户及痛点

四类使用者，
同一种被切碎的流程。

01 独立设计师 / 插画师
接单后，
要从插画抠到成衣。
收到客户来图或自己的插画稿，需要快速抠白底、套进衣服模板、出多角度预览给客户确认。
  • 抠图工具付费 / 排队，单张 1–3 元或等待
  • PS 套版手动对齐，改一版要重做一次
  • 多角度预览靠拼图，沟通成本高
02 印花工作室 / 小作坊
客户来图
质量参差不齐。
每天处理十几单客户来图，背景复杂、分辨率不一，需要先快速抠干净再套版打样给客户看效果。
  • 客户原图背景复杂，免费工具抠不干净
  • 原图不能上传云端，担心隐私与版权
  • 多区域印花（前胸+后背+袖口）要分别套版
03 中小服装卖家
上新频繁，
商品图要快。
每周上新多款，每款都要前胸、后背、细节多张商品图，外包慢、自己 PS 不熟练。
  • 外包打样周期长，错过上新窗口
  • 导出尺寸不统一，店铺规范难维护
  • 没有设计基础，专业软件学习成本高
04 同人 / 社团主理人
团服定制，
要套版到多个位置。
社团团服、应援物、同人周边定制，需要把同一图案套到衣服的不同区域，并批量导出给工厂。
  • 多位置套版靠手动复制粘贴
  • 给工厂的图要带印花区域标注
  • 预算有限，请不起专业设计师
03 价值与意义

从15 分钟到
3 分钟的差别。

i.
效率提升EFFICIENCY
把抠图 → 套版 → 合成 → 导出四个串联环节压缩到一个单页应用。单次出图从 15–30 分钟 降到 1–3 分钟，且所有操作实时可见、所见即所得。多印花区域支持多选对齐与批量应用，团服类多位置套版效率提升更显著。
ii.
商业价值COMMERCIAL
降低独立创作者与小团队的印花打样门槛——不用买专业软件、不用外包抠图、不用学复杂工作流。让 一个人 也能像一个小工作室一样响应定制需求，把接单门槛从「会 PS」降到「会拖图」。
iii.
隐私与技术价值PRIVACY · LOCAL AI
三个 ONNX 模型（MODNet / IS-Net / FP16）全部在浏览器本地推理，原图零上传、零 API 调用、零隐私泄露。对客户来图敏感的工作室和涉密周边定制场景，这是云端抠图服务无法提供的底线保障，也意味着零推理成本可无限次重跑。

AI 三模型本地抠图

← BEFORE
AFTER →

内置三个 ONNX 抠图模型，覆盖人像专用、高精度通用、轻量极速三种场景。模型在浏览器内通过 ONNX Runtime Web 直接推理，原图不上传服务器，处理过程带进度反馈与超时保护。

TECH · onnxruntime-web · WASM SIMD · 三模型切换 · 进度回调
F.02

多印花区域管理

前胸 · 240×180
下摆 · 180×120

同一件衣物可定义多个独立印花区域（前胸、后背、袖口、下摆），每个区域可拖拽、缩放、旋转、锁定，支持多选对齐与分布。

FEATURES · 拖拽 · 缩放 · 旋转 · 锁定 · 多选 · 对齐分布
