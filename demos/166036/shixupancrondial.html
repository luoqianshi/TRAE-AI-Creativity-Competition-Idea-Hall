时序盘 CronDial

把 */5 9-18 * * 1-5 翻译成"工作日9点到18点每5分钟跑一次"，并算出下次触发时间。五段齿轮盘随表达式旋转，分时日月周一目了然。

痛点 // PAIN POINTS

PP-001
语法记不住
* */n a-b a,b L W # 七种符号含义每次都要搜，五个字段从左到右到底是分时日月周还是日月时分周都要再查一遍。
PP-002
符号混淆写错
*/5 和 5/* 写反了任务就跑成每小时第5分钟，0 0 * * 1 以为是周一零点其实是周一凌晨，写错一个字符整个调度全乱。
PP-003
执行时间无法预判
表达式写完不知道到底会在几点触发，要等任务真跑起来才发现"凌晨3点不是我要的"，排查一次就是半小时，线上事故往往就出在这。

工作流 // WORKFLOW

01
输入表达式
在解析台输入 5 段 CRON，或点击预设按钮一键填入常见调度模式。
02
字段拆解
分时日月周逐段翻译成人话，符号含义即时显示，错误字段标红提示。
03
计算下次
从当前时间向后扫描，列出未来 5 次触发时刻，下发前即可验证语义。
04
符号速查
L / W / # 等冷门符号摆在手边，不用再翻文档，新手也能写出高级调度。

价值与意义 // VALUE

VALUE-01 · 效率
把"猜表达式"变成"看表达式"
五段齿轮盘随表达式旋转，分齿轮转得最快、周齿轮转得最慢，视觉记忆比纯文字强十倍。下次执行时间实时计算，写出表达式立刻看到未来 5 次触发点，不用等任务真跑就能验证，为线上稳定性省下最宝贵的排查时间。
VALUE-02 · 工程
降低调度配置错误率
符号速查表把 L W # 这些冷门符号摆在手边，预设覆盖每5分钟、工作日9点、每月1号等高频场景。它不替代 crontab，但给开发者一个共同的、可视化的、可验证的参考标准，让每个写定时任务的人都能在下发前就把语义和触发点确认对。
