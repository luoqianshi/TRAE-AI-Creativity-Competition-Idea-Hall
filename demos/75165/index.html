为什么我们做这个？

灵感来源于一次朋友聚会，大家聊起小时候玩的跳房子、丢沙包、踢毽子，眼里都闪着光。

但如今这些游戏要么消失在记忆中，要么被电子设备取代。我们想用最轻量级的方式，把那些简单纯粹的快乐找回来。

让80、90、00后们在快节奏的成人生活中，能有一个情感出口，一键穿越回童年。

经典游戏收录

🏠

跳房子

童年操场的必修课，单脚跳、双脚跳，跳出满满的回忆！

游戏规则

1. 在地上画出8-10个格子，分别写上数字1-10。
2. 玩家站在格子外，将沙包扔进第1格。
3. 单脚跳进第1格，捡起沙包后单脚跳出。
4. 依次完成所有格子，过程中不能踩线或双脚落地。
5. 失误者淘汰，坚持到最后的人获胜。

80后 90后 户外
🪁

丢沙包

课间十分钟最火爆的游戏，躲避沙包，欢乐无限！

游戏规则

1. 选两人当"投手"，站在场地两端。
2. 其余玩家站在中间区域。
3. 投手用沙包投掷中间的玩家。
4. 被沙包击中的玩家下场。
5. 接住沙包的玩家可以复活一名队友或自己。
6. 场上最后一名玩家获胜。

80后 90后 团体
🪶

踢毽子

女生的课间必修课，毽子飞舞，欢声笑语！

游戏规则

1. 一人踢毽子，其余人围观计数。
2. 用脚内侧、外侧或脚尖踢毽子。
3. 毽子落地则计数中断。
4. 可以单人练习或多人轮流踢。
5. 连续踢得最多的人获胜。
6. 高手可以做出各种花式踢法。

80后 90后 技巧
🧵

翻花绳

一根绳子翻出花样，童年课间的手部艺术！

游戏规则

1. 两人合作，一人将绳子套在双手上。
2. 另一人用手指勾住绳子的交叉点。
3. 双手配合翻转，形成各种图案。
4. 常见图案：面条、大桥、降落伞等。
5. 绳子掉地则失败，重新开始。
6. 考验手指灵活性和想象力。

80后 90后 手部
🪨

抓石子

一把石子抛接之间，考验手眼协调能力！

游戏规则

1. 准备5-10颗小石子。
2. 将所有石子抛起，用手背接住。
3. 再抛起，用手掌接住。
4. 依次抓起1颗、2颗...直到全部抓完。
5. 过程中石子落地则重来。
6. 可以玩"一锅端""步步高"等花样。

80后 90后 技巧
⚪

弹玻璃珠

童年男生最爱，瞄准、弹射，赢取更多玻璃珠！

游戏规则

1. 在地上挖一个小坑，玩家站在规定线外。
2. 轮流弹自己的玻璃珠，目标是弹进坑里。
3. 可以用自己的珠子撞击对方的珠子。
4. 将对方珠子撞进坑的玩家获胜。
5. 也可以玩"打老虎"等变体玩法。
6. 谁收集的玻璃珠多谁就是赢家。

80后 90后 竞技
🏃

打沙包/打马

追逐奔跑的快乐，童年操场的集体记忆！

游戏规则

1. 选一人当"鬼"，其他人四散逃跑。
2. "鬼"抓住一人后，被抓者加入"鬼"的队伍。
3. 直到所有人都被抓住为止。
4. 可以约定安全区域或特殊规则。
5. 最后被抓住的人成为下一轮的"鬼"。
6. 升级版："鬼"可以组队围追堵截。

80后 90后 团体
🎯

跳皮筋/双人线

女生最爱，橡皮筋上的花样年华！

游戏规则

1. 两人撑开橡皮筋，高度从脚踝开始。
2. 第三人在橡皮筋上做各种跳跃动作。
3. 常见动作：勾、踩、绕、跳等。
4. 完成动作后升高橡皮筋。
5. 从脚踝→膝盖→腰部→胸部→肩部。
6. 失误者下场，换另一人挑战。

80后 90后 技巧
