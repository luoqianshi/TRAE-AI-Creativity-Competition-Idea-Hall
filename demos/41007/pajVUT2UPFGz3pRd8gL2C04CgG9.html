💡创意背景

ADHD认知现状

ADHD（注意力缺陷多动障碍）是全球最常见的神经发育障碍之一。据《中国注意缺陷多动障碍防治指南》数据，中国儿童ADHD患病率约为6.3%，意味着每20个孩子中就有1个受到ADHD困扰。然而，国内ADHD的就诊率不足10%，大量患者和家庭处于"不知道、不了解、不干预"的状态。

为什么关注ADHD

📊 患病率高，就诊率低
中国儿童ADHD患病率约6.3%，就诊率不足10%，大量患者未被识别和干预
👨‍👩‍👧 家庭负担重
家长缺乏专业知识，不知道如何应对孩子的注意力问题，容易陷入焦虑和自责
🏫 校园关注不足
老师缺乏ADHD相关培训，难以识别和有效管理课堂中的ADHD学生
💊 药品信息不透明
ADHD常用药物（如专注达、择思达）经常缺货，家长四处求药却无从查询库存
🩺 专业资源分散
能确诊ADHD的医院和医生集中在少数三甲医院，患者挂号难、问诊难
🌐 社会偏见严重
公众对ADHD认知不足，常被误解为"不听话""懒""没教养"，患者承受巨大心理压力

政策与社会趋势

  • 国家政策支持：《健康中国行动（2019-2030年）》明确提出加强儿童青少年心理健康服务
  • 教育政策变化："双减"政策后，学生心理健康受到更多关注，学校需要更多专业工具支持
  • 数字健康趋势：互联网医疗市场规模持续增长，用户对在线问诊、健康管理的接受度大幅提升
  • ADHD用药需求增长：随着诊断率提升，ADHD药物市场需求持续扩大，但供应链信息不透明

功能详解

1. ADHD自查量表

  • 基于DSM-5标准设计的筛查量表
  • 分年龄段版本：儿童版（6-12岁）、青少年版（13-17岁）、成人版（18+岁）
  • 测评结果：无风险 / 低风险 / 中风险 / 高风险
  • 生成个性化报告，建议下一步行动（就医/观察/训练）
  • 免费 所有用户可免费使用

2. 药品库存查询

  • 覆盖主流ADHD药物：哌甲酯、托莫西汀、安非他酮等
  • 按城市/医院查询实时库存（对接医院HIS系统或用户上报）
  • 缺药提醒：订阅药品，到货后推送通知
  • 用药指南：剂量说明、副作用、注意事项

3. 注意力训练

  • 儿童版：舒尔特方格、找不同、听觉训练游戏
  • 成人版：番茄工作法、正念冥想、任务拆解工具
  • 训练记录：每日训练时长、完成度、进步曲线
  • 免费 基础训练免费，高级课程会员专享

4. 自律打卡

  • 自定义打卡项目：服药、运动、冥想、早睡等
  • 打卡提醒：定时推送，支持多次提醒
  • 打卡统计：周/月/年视图，连续打卡天数
  • 打卡分享：可分享至社区，获得鼓励

5. 用药记录

  • 记录每日用药情况：药物名称、剂量、时间
  • 生成用药依从性报告（周/月/季度）
  • 复诊时可直接展示给医生

6. 复诊提醒

  • 医生可设置复诊时间（如"2周后复诊"）
  • 到时间自动推送通知给用户
  • 复诊期间聊天记录不删除，复诊结束后重新计时7天
  • 用户可一键预约同一位医生复诊

7. 用户反馈系统

  • 用户可在"我的"页面提交产品反馈和建议
  • 反馈类型：功能建议、Bug反馈、体验优化、内容举报
  • 采纳奖励：首次采纳奖励500积分，第二次1000积分，第三次1500积分，以此类推
  • 被采纳用户会在社区获得"产品贡献者"标识
  • 每月评选"最佳建议奖"，额外奖励京东E卡

医生端工作台

状态分类：

  • 待回复 新问诊请求，需及时响应
  • 进行中 问诊中，可继续沟通
  • 已完成 问诊结束，用户确认

提醒机制：

  • 新问诊请求：铃声+震动+推送通知
  • 用户追问：推送通知
  • 响应时效：图文30分钟内响应，语音/视频需预约时间

聊天记录：

  • 问诊结束后，医生端聊天记录保留7天，自动删除
  • 聊天界面底部半透明小字提示："本聊天记录7天后自动删除"
  • 复诊期间聊天记录不删除，复诊结束后重新计时

匿名分享：医生可将问诊记录匿名发布到社区，供其他用户参考学习

问诊页面UI（患者端）

顶部搜索栏：输入疾病、科室、医生、医院名称

筛选条件：

  • 地区：省 → 市（全国可选）
  • 科室：精神心理科 / 小儿神经内科
  • 疾病：注意力不集中 / 多动 / 冲动 / 走神 / 拖延 / 分心
  • 排序：综合排序 / 好评率 / 接诊量 / 响应速度

医生卡片：头像、姓名、职称、医院、科室、评分、接诊量、价格、"立即问诊"按钮

Tab切换：医生列表 / 医院列表 / 患友问诊（匿名展示历史问诊对话）

🔒数据安全与合规

数据存储策略

📱 用户端

聊天记录本地存储（类似微信）

用户可手动删除单条/全部记录

注销账户时所有数据彻底清除

🩺 医生端

聊天记录云端保留7天

7天后自动永久删除

复诊期间记录不删除

🔐 平台端

不长期存储用户聊天记录

仅保留匿名化统计数据

通过等保三级认证

隐私保护措施

  • 无痕模式：用户可开启无痕模式，浏览和问诊不留记录
  • 匿名社区：社区发帖默认匿名，可选实名
  • 数据最小化：仅收集必要信息，不过度索取权限
  • 加密传输：全站HTTPS，敏感数据AES-256加密
  • 访问控制：医生仅能看到授权的患者信息

合规措施

  • 医疗合规：平台不直接提供诊断，仅提供咨询和信息服务
  • 医生资质：所有入驻医生均需通过三重审核，确保执业资质真实有效
  • 儿童数据保护：13岁以下用户信息需家长同意，平台不主动收集儿童敏感信息
  • 用户协议：明确告知数据使用范围，用户可随时导出或删除个人数据
  • 等保三级：通过国家网络安全等级保护三级认证

账户注销

注销流程：
  1. 用户提交注销申请
  2. 验证身份（短信验证码）
  3. 确认注销后果（数据不可恢复）
  4. 7天冷静期（期间可撤销）
  5. 冷静期后永久删除所有数据

删除范围：注册信息、聊天记录、社区内容、积分记录、ADHD档案等全部数据
