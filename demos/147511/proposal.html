智能解析 · 精准匹配 · 高效协同

项目背景与痛点分析

📝

传统申报流程繁琐

学生需填写复杂的活动申请表单，包含数十项必填字段，操作门槛高，耗时耗力。

🏢

场地资源利用低效

场地信息分散，学生难以获取准确的场地状态，导致场地预约冲突、资源浪费。

⏳

审批流程周期长

纸质审批或多系统流转导致审批效率低下，学生无法实时追踪申请进度。

🔍

需求匹配精准度低

学生与场地之间缺乏智能匹配机制，活动需求与场地设施难以精准对接。

核心创意与解决方案

核心创意：采用自然语言交互方式，让学生通过日常对话描述活动需求，AI自动解析并生成结构化活动信息，结合智能推荐算法匹配最优场地，实现"一句话发起活动"的极致体验。

技术方案

前端技术栈

Vue 3.5.x
TypeScript 5.8.x
Vite 6.3.x
Element Plus 2.14.x
Pinia 3.0.x
Vue Router 4.6.x
Axios 1.18.x
ECharts 6.1.x
Day.js 1.11.x

技术亮点：采用 Vue 3 Composition API + TypeScript 构建类型安全的前端应用，配合 Pinia 实现高效的状态管理。使用 Element Plus 组件库保证UI一致性和开发效率，ECharts 提供丰富的数据可视化能力。

核心数据模型

ActivityDraft（活动草稿）

活动名称、类型、时间、人数、设备、目的、流程、安全方案、风险等级、完整度

Venue（场地）

场地名称、建筑、容量、类型、设备、可用性、状态、推荐评分

ActivityApplication（活动申请）

申请编号、申请人、活动信息、选定场地、状态、审核意见、审核时间

ApprovalRecord（审批记录）

申请ID、审核人、操作类型、审核意见、审核时间

创新亮点

💡

自然语言交互

摒弃传统表单填写方式，学生只需用日常语言描述活动需求，AI自动解析生成结构化信息，降低申报门槛。

🎯

智能场地匹配

基于活动需求（人数、时间、设备、类型）与场地属性进行多维度匹配，智能推荐最优场地方案。

🔄

一站式流程管理

从需求提报到场地确认，全流程在线化管理，支持实时状态追踪，提升活动组织效率。

📊

自动评估活动风险等级，智能生成安全预案建议，帮助组织者提前识别和规避潜在风险。

📈

数据驱动决策

提供活动统计、场地使用情况等可视化数据，帮助管理者优化资源配置和决策制定。

🔒

角色权限管理

完善的学生/管理员角色区分，细粒度的权限控制，确保数据安全和操作合规。

应用场景

🎓

学术讲座申报

学生组织学术讲座时，通过自然语言描述讲座主题、时间、预计人数等信息，系统自动推荐合适的报告厅。

🏀

体育赛事组织

体育社团组织比赛时，系统根据参赛人数和赛事类型，智能匹配体育馆、操场等场地资源。

🎵

文化活动策划

文艺社团策划晚会、音乐节等活动时，系统推荐具备舞台、灯光、音响等设备的场地。

💼

会议研讨安排

学院或部门组织研讨会时，根据参会人数和设备需求，推荐合适的会议室或研讨室。
