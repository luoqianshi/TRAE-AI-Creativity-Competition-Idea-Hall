Open Duck Mini

$ git clone https://github.com/apirrone/Open_Duck_Mini

迪士尼 BDX 机器鸭的开源迷你版 — 42cm 高度、14个伺服舵机、强化学习步态、400美元以内的物料成本。用 AI 和开源的力量，让每个人都能拥有自己的行走机器人。

查看 GitHub 技术文档

项目亮点

用开源与 AI 重新定义个人机器人

仿生行走

基于 MuJoCo 仿真环境，使用强化学习训练的双足步态策略，通过 ONNX 模型实时部署到树莓派

开源硬件

全部 CAD 设计开源，支持 3D 打印自行制作。14 个 STS3215 舵机驱动，树莓派 Zero 2W 作为主控

低成本

完整 BOM 成本控制在 400 美元以内。相比迪士尼原版 BDX（约 15000 美元），降低了 97% 的成本

社区驱动

全球开发者社区贡献，中文文档由同济子豪兄团队翻译维护。Discord 活跃社区支持

技术规格

终端风格的配置一览

硬件配置 
root@openduckmini:~$ cat hardware.yaml
  主控: Raspberry Pi Zero 2W
  舵机: 14x STS3215 (总线串联)
  传感器: IMU + 足底压力传感器
  通信: UART 串口 (USB)
  供电: 锂电池 + 稳压模块
软件栈 
root@openduckmini:~$ cat software.yaml
  仿真: MuJoCo Physics Engine
  训练: Reinforcement Learning (ONNX)
  运行时: Python 3.8+ / ODM Runtime
  控制: 小智AI语音 + Xbox 手柄
  建模: BAM (舵机行为建模)
物理参数 
root@openduckmini:~$ cat params.yaml
  高度: ~42cm (腿伸展时)
  总成本: <$400 USD
  许可证: Apache-2.0

Sim2Real 技术路线

从虚拟到现实，打通仿生机器人的最后一公里

从仿真到现实：Open Duck Mini 采用 sim2real 技术路线，先在 MuJoCo 物理引擎中通过强化学习训练行走策略，再将策略导出为 ONNX 模型部署到实体机器人上。通过舵机辨识（BAM 工具链）精确建模真实硬件特性，大幅缩小仿真与现实的差距。

1

MuJoCo 物理仿真

高精度物理引擎模拟机器人动力学与环境交互

2

强化学习训练

RL 算法自动探索最优步态策略，无需手动编程

3

BAM 舵机辨识

精确建模真实舵机响应特性，缩小 sim-real gap

4

ONNX 模型部署

跨平台推理引擎，在树莓派上实时运行行走策略
