✨ 核心功能

六大模块覆盖从几何导入到流场分析的全链路

🧬AMBER 网格推理

预训练 GNN 模型，对 STEP 几何进行 20 步迭代优化，输出约 43K 高质量三角形网格。支持 VTK + CGNS 双格式同时输出。

📐智能网格编辑

通过尺寸场乘系数实现全场加密/放松。根据计算需求整体调整网格密度，gmsh 自动重新划分网格。

🛩️Fluent CFD 求解

密度基求解器、SST k-omega 湍流模型。支持稳态、瞬态、网格自适应三种求解模式。同一次会话可连续执行多阶段计算。

🤖LLM 智能助手

接入 OpenAI GPT-4o / DeepSeek V3。5 个 function calling 工具。自然语言驱动所有操作，无需手动编写脚本。

🌐3D 可视化

基于 Three.js 的 3D 视口，支持旋转/缩放/平移。实时预览 STEP 几何、VTK/CGNS 网格。多面板布局。

🔗端到端自动化

从 STEP 几何导入 → AMBER 推理 → 交互优化 → Fluent 求解，全流程天然语言驱动，无需任何手动操作。

🔧 LLM 工具集

5 个 function calling 工具，LLM 根据自然语言自动选择调用

工具用途关键参数
modify_sizing_field 全场网格加密/放松 region=all, factor, operation
run_cfd_steady 稳态 CFD 求解 iterations, mach, temperature
run_cfd_transient 瞬态 CFD 求解 time_step_size, num_time_steps, mach
run_cfd_adaptive 带网格自适应的 CFD 求解 mode, adapt_interval, adapt_field, adapt_level
run_cfd_full 【推荐】稳态→瞬态全流程 iterations, enable_adapt, adapt_interval

⚡ 效率对比

传统方式 vs AmberAgent

传统工作流

  • 手动网格划分需数小时
  • 网格优化需反复试错
  • Fluent 脚本手动编写
  • 不同软件间手动切换
  • 经验依赖性强

AmberAgent

  • AI 自动生成网格（~2分钟）
  • 自然语言指令优化
  • LLM 自动调用 Fluent API
  • 统一界面一键完成
  • 降低使用门槛
