PicFlow

极简图片工作流工具链：让「手机拍照」到「文档插入」只需 3 步

项目背景与痛点

在数字花园构建、技术写作或内容创作中，图片是不可或缺的要素。然而，传统的跨端图片传输流程极其低效且碎片化。

传统流程的问题

  • 存储冗余：文件传输助手、本地下载、图床，同一图片产生 3+ 份副本。
  • 手动繁琐：需手动下载、打开 PicGo、点击上传、复制链接、切换窗口粘贴。
  • 仓库膨胀：若直接存入 Git 仓库（如 Obsidian 附件），会导致仓库体积迅速激增，难以维护。
  • 隐私风险：过度依赖第三方社交软件作为中转。

PicFlow 的愿景

通过 Flutter 打造无缝衔接的体验，将 10 个手动步骤 压缩至 3 个自动化动作：

1. 拍照 → 2. 自动处理 → 3. 粘贴链接

全程无本地文件落地，图片直达终点。

技术架构与选型

PicFlow 采用现代化的全栈技术栈，兼顾跨端性能与部署灵活性。

模块 技术选型 关键特性
跨端核心 Flutter 3.x 一套代码运行于 iOS 和 Android，保证 UI 高度一致。
采集与编辑 image_picker + camera 调用原生相机，支持 image_editor_pro_eclix 进行裁剪、打码。
高效传输 Dio (HTTP/2) 支持 FormData 流式上传，内置超时重试与并发控制。
后端服务 FastAPI / Node.js 轻量级 RESTful API，支持自建私有存储或对接云端 OSS。
自动化联动 clipboard 上传成功后自动回传链接并写入剪贴板，实现即插即用。
