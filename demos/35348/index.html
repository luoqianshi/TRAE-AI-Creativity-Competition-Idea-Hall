五阶段交叉质询工作流

调度官全程主持，从问题定义到决策简报，每阶段有明确的执行者和质量门控。

STAGE 0
🎯
问题定义
将原始问题转化为结构化确认书：核心问题+背景+约束+期望输出
🧭 调度官执行
STAGE 1
💬
初始观点
所有选中专家并行给出初始分析（≤300字），调度官做阶段总结
🧠 专家并行 → 🧭 调度官总结
STAGE 2
⚡
交叉质询
专家按配对表两两对抗：A质询→B回应→A反驳→B再反驳，双重QC检测
🧠 专家配对 → 🔍 双重QC
STAGE 3
🔄
观点修正
专家基于质询并行修正观点（≤200字），调度官做阶段总结
🧠 专家并行 → 🧭 调度官总结
STAGE 4
📋
总结输出
调度官整合全部内容，输出结构化决策简报+免责声明
🧭 调度官执行
Dispatcher

调度官 🧭 — 全程主持人

调度官不是专家，不提供专业观点，只负责协调、裁判、质量检测和整合。

🧭
调度官
deepseek-v3
独立主持人角色，与专家严格隔离。不参与专业分析，确保裁判中立性。
阶段0：结构化用户问题为确认书
阶段1/3：汇总专家观点做阶段总结
阶段2：配对调度 + 调度官QC裁判
阶段4：整合输出决策简报
追问模式：判断是否需要补充质询

⚡ 为什么调度官不能是专家？

如果调度官同时提供专业观点，就会在交叉质询中产生利益冲突——既当裁判又当选手。将调度官与专家严格隔离，确保质询配对和质量检测的公正性。调度官的唯一目标是推动高质量决策，而非推销某种立场。

Quality Control

双重质量检测机制

每轮质询后进行双重检测，防止专家"走过场"，确保对抗质量。

🔍
独立QC检测
独立于调度官的质量检测模块，自动检测每轮质询是否存在重复观点、跑题、敷衍回应等问题。
检测项：
· 观点重复率 > 70% → 不通过
· 偏离议题核心 → 不通过
· 回应字数 < 50字 → 不通过
✕ 连续3次不通过 → 强制终止该配对
🧭
调度官QC裁判
调度官基于全局视角判断质询是否产生了实质性新信息，决定是否继续下一轮对话。
判断逻辑：
· 产生了新论点/新证据 → 继续
· 仅在重复已有观点 → 终止
· 双方已无新论据 → 终止
✕ 连续3次检测不通过 → 强制终止该配对
🛡️
双重检测协同
独立QC + 调度官QC形成双重保障：独立QC防止形式化敷衍，调度官QC防止无意义的无限对抗。
协同逻辑：
· 独立QC通过 + 调度官QC通过 → 继续
· 任一不通过 → 计入失败计数
· 连续3次失败 → 强制终止
✕ 终止后进入观点修正阶段

我在大厂工作5年，年薪50万，现在有一个创业机会——做AI教育产品，已有种子用户200人，但需要全职投入且前6个月零收入。我应该辞职创业吗？
📋 决策简报

📌 结论

不建议立即辞职创业。建议采取3个月"双轨并行"验证期，在保住薪资的同时用MVP验证市场，达到量化阈值后再做全职决策。

🔑 核心发现

1. 200种子用户≠付费用户，付费转化率是关键未知数；2. 6个月零收入假设过于乐观，实际烧钱期通常12-18个月；3. 心理洞察揭示可能存在"倦怠驱动逃避"倾向，需区分创业动机；4. AI教育赛道窗口期存在但非赢者通吃，不必恐慌性入场。

✅ 建议行动

1. 申请停薪留职或3个月无薪假试错；2. 周末开发MVP，3个月内验证付费转化率≥10%；3. 储备12个月生活费（约50万）再考虑全职；4. 深度访谈种子用户，确认付费意愿而非兴趣。

⚖️ 未解决分歧

风险质疑官认为应充分准备再行动，跨界创意员担心错过AI教育爆发期——双方在"时机窗口紧迫性"上未达成共识。

🌐 全局统筹者评分

当前辞职创业可行性：4.2 / 10 · 双轨并行验证后可行性预期：7.5 / 10
