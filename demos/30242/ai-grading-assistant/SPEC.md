# AI批卷系统 - 产品规格文档

## 1. 产品概述

**产品名称**：AI批卷助手
**产品类型**：Web应用（离线优先）
**核心功能**：通过拍照上传试卷，利用OCR和AI技术自动批改客观题，帮助教师快速完成作业和试卷批改工作

## 2. 目标用户

- 小学、初中、高中教师
- 培训机构教师
- 需要批量批改作业/试卷的教育工作者

## 3. 核心功能模块

### 3.1 用户认证
- 教师账号注册/登录
- 本地数据存储（LocalStorage）
- 班级和学生数据管理

### 3.2 班级管理
- 创建/编辑/删除班级
- 学生列表管理（增删改查）
- 班级信息设置

### 3.3 作业/试卷管理
- 创建作业/试卷（设置题目和答案）
- 支持题型：选择题、填空题、主观题
- 设置分值

### 3.4 AI批改功能
- **拍照上传**：调用摄像头或上传图片
- **OCR识别**：使用Tesseract.js本地离线识别文字
- **自动批改**：
  - 选择题：自动匹配答案，计算得分
  - 填空题：关键词匹配评分
  - 主观题：标记待手动批改
- **批改预览**：显示识别结果和批改结果
- **人工确认**：教师确认或调整批改结果

### 3.5 成绩统计
- 班级成绩汇总
- 个人成绩明细
- 错题统计（高频错题分析）
- 数据可视化（图表展示）

### 3.6 成绩导出
- 导出为Excel/CSV格式
- 生成成绩单文档
- 分享到班级群

## 4. 技术方案

### 4.1 前端技术
- **框架**：原生HTML5 + CSS3 + JavaScript
- **UI库**：Tailwind CSS（CDN引入）
- **图标**：Lucide Icons

### 4.2 OCR技术
- **引擎**：Tesseract.js v5（本地离线OCR）
- **语言**：中文简体（chi_sim）

### 4.3 数据存储
- **浏览器LocalStorage**：用户数据、班级数据、学生数据、作业数据、成绩数据
- **IndexedDB**（备选）：存储图片缓存

### 4.4 文件结构
```
/
├── index.html          # 主页面
├── css/
│   └── styles.css      # 自定义样式
├── js/
│   ├── app.js          # 主应用逻辑
│   ├── ocr.js          # OCR处理模块
│   ├── grading.js      # 批改逻辑
│   └── storage.js      # 数据存储模块
└── assets/
    └── logo.svg        # 应用图标
```

## 5. 界面设计

### 5.1 页面结构
1. **登录/注册页** - 用户认证
2. **首页** - 工作台概览
3. **班级管理页** - 班级和学生CRUD
4. **作业管理页** - 创建和管理作业/试卷
5. **批改页** - 拍照上传和AI批改
6. **成绩统计页** - 数据分析和导出

### 5.2 设计风格
- **配色**：教育主题蓝色系（#3B82F6主色）
- **布局**：简洁清晰，移动端友好
- **交互**：即时反馈，操作流畅

## 6. 用户流程

```
注册登录 → 创建班级 → 添加学生 → 创建作业/试卷 → 拍照上传 → AI批改 → 确认成绩 → 统计分析 → 导出成绩
```

## 7. 数据模型

### 7.1 用户 (User)
```json
{
  "id": "uuid",
  "username": "教师姓名",
  "password": "密码(加密)",
  "createdAt": "创建时间"
}
```

### 7.2 班级 (Class)
```json
{
  "id": "uuid",
  "userId": "用户ID",
  "name": "班级名称",
  "grade": "年级",
  "students": ["学生ID数组"]
}
```

### 7.3 学生 (Student)
```json
{
  "id": "uuid",
  "name": "学生姓名",
  "classId": "班级ID"
}
```

### 7.4 作业 (Assignment)
```json
{
  "id": "uuid",
  "userId": "用户ID",
  "classId": "班级ID",
  "title": "作业标题",
  "questions": [
    {
      "id": "q1",
      "type": "choice|blank|subjective",
      "content": "题目内容",
      "options": ["A选项", "B选项", "C选项", "D选项"],
      "answer": "正确答案",
      "score": "分值"
    }
  ],
  "totalScore": "总分",
  "createdAt": "创建时间"
}
```

### 7.5 成绩 (Grade)
```json
{
  "id": "uuid",
  "assignmentId": "作业ID",
  "studentId": "学生ID",
  "scores": {
    "q1": { "autoScore": 5, "finalScore": 5 },
    "q2": { "autoScore": 0, "finalScore": 3 }
  },
  "totalScore": "总分",
  "gradedAt": "批改时间"
}
```

### P1 - 重要功能
