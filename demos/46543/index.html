§ 01
产品定位

没有人是一座孤岛，每本教材也是。

200 页的教材，密密麻麻的公式和定义。打开 PDF 看了 3 页就走神，关掉页面刷 B 站，一晚上过去了。这不是能力问题——这是没有人陪你读。

Paper2Galgame（2026）证明了一件事：把 20 页的论文切成几十个小块，用一个角色陪你一段段看，读完率能拉到 60%+。我们把它从「论文」扩到「教材」，从「1 个角色」扩到「5 位学科对位的 ta」——读 Python 有 Py 姐，读高数有顾极限，每门课都有专精的那位陪你。

▍ 一句话定位

它不是

  • 一个恋爱模拟器蹭学习热度
  • 一个套了二次元皮肤的题库
  • 一个语音陪伴 / 心理咨询产品
  • 一个 LLM 论文总结工具

它是

  • 一个「上传教材 → 学科 ta 陪你读完」的阅读工具
  • 核心循环：上传 → 切成小块 → 学科 ta 讲 → 出题测 → 错则重讲 → 读完一本
  • 主线任务 = 读懂这本书，不是谈恋爱
  • 5 位学科对位的 ta，专精 / 专业 / 不卖萌
§ 02
一次完整阅读的四步

上传 → 讲解 → 测 → 重讲，
直到你真懂。

STEP 01 / 04

上传教材 / PDF

把 200 页高数课本、Python 教程、英文文献拖进来。系统自动分章节、识别公式、抽取知识点。

→
STEP 02 / 04

学科 ta开讲

对应学科的「ta」用大白话讲这章。ta 不像老师，更像一个读过这本书的学姐——讲完会留一个停顿，等你反应。

→
STEP 03 / 04

出题 · 测你懂没懂

每讲完一个小块，自动出 1-2 道选择题 / 填空题。答对：ta 点头「嗯，这块你过了」。答错：ta 皱眉，切回讲解。

→
STEP 04 / 04

读完 · 解锁

读完整本书，生成一份核心考点总结 + 错题剧本，下次遇到类似章节可以一键重读。

§ 05
和 Paper2Galgame 差在哪

致敬灵感的同时，
打三处不一样的点。

Paper2Galgame（2026）证明了一件事：把一篇论文切成几十个可玩的小块，能让普通人读得下去。我们的产品定位、核心循环、范式都和它接近——所以我们必须回答：为什么不是它？

维度 Paper2Galgame Code Love Academy
目标载体论文 PDF（1 种）教材 + 论文 + 教程（多源）
学科覆盖通用 galgame 角色5 位学科对位的 ta（专精）
反馈深度选对夸 / 选错换表情答错切回讲解，换一种方式再讲一遍
主线任务读完一篇读懂一本（含考点总结 + 错题剧本）
语音无Lily 姐TTS + 用户音色克隆陪读
核心差异论文 → 玩教材 → 读懂（带学科 ta + 重讲机制）

数据参考：Paper2Galgame 媒体报道（2026 / 04 · 差评），猿题库 / 墨墨 2025 公开数据，本产品内测 50 人估算。

▍ 我们的态度：Paper2Galgame 是个伟大的玩具，让论文变得可读。它证明了这个范式有效。我们把它从「论文 → 玩」扩到「教材 → 读懂」，加上学科对位的角色 + 答错重讲的闭环，把它从「玩具」推向「学习工具」。
