项目简介

CodeGuard AI 是一款基于大语言模型（LLM）的智能代码审查工具，支持多编程语言（Python、JavaScript/TypeScript、Java、Go、Vue、React、C++、Rust等）的全方位代码质量保障。 通过深度理解代码语义和业务逻辑，自动检测代码质量问题、安全漏洞和性能隐患，并提供精准的修复建议。

Python JavaScript Java Go Vue/React C++/Rust LLM CLI AI Agent
🎯

解决的痛点

在现代软件开发中，代码审查面临四大挑战：审查效率低下、审查深度不足、安全漏洞漏检、团队规范难以统一。 CodeGuard AI 通过 AI 自动化审查，将人工审查时间从数小时缩短至分钟级，实现全面、精准、高效的代码质量保障。

核心功能

🔍

代码质量检测

自动检测命名规范、代码复杂度、重复代码、代码风格等问题，确保代码整洁规范。

🛡️

安全漏洞检测

识别 SQL 注入、XSS 攻击、敏感信息泄露、空指针风险等安全隐患。

⚡

性能优化建议

分析循环优化、内存泄漏、数据库查询优化、资源浪费等性能问题。

📊

多格式报告输出

支持文本、HTML、JSON 多种报告格式，满足不同场景的集成需求。

AI审查流程

1

代码输入

读取 Vue/Java 文件，提取代码内容和文件结构信息

2

上下文构建

分析文件依赖关系、代码上下文，构建完整的审查上下文

3

Prompt生成

构建针对代码审查优化的专业 Prompt 模板，引导 LLM 进行深度分析

4

LLM调用

将代码和 Prompt 发送给大语言模型进行智能分析，获取审查结果

5

结果解析

解析 LLM 返回的结构化审查结果，提取问题分类和修复建议

6

报告生成

根据用户选择的格式生成专业的审查报告，支持文本、HTML、JSON 输出

使用方式

CLI 命令示例

$ codeguard review src/App.vue
$ codeguard review src/
$ codeguard review --diff
$ codeguard review src/ --format html --output report.html
$ codeguard review src/ --format json --output report.json
