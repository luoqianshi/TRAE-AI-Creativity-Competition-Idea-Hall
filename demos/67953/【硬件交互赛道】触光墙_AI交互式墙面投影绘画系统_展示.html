💡 超短焦投影+自动梯形校正

采用0.23:1投射比的超短焦镜头，主机距墙30cm即可投射80英寸画面。内置6轴陀螺仪+摄像头，自动识别墙面角度并实时进行梯形校正和曲面贴合，无需人工调试。

# 自动校正流水线 wall_plane = detect_plane(ir_depth_map) # 检测墙面平面 keystone = calculate_keystone(wall_plane) # 计算校正矩阵 output = warp_projection(image, keystone) # 实时扭曲输出

👆 红外ToF深度感知定位

基于940nm红外ToF传感器，以60fps采集墙面深度图。当手指靠近墙面（<5mm）时，深度突变被识别为"触摸事件"。通过标定将深度坐标映射到投影像素坐标，实现±2mm的触摸定位精度。

# 触摸检测 depth_diff = baseline_depth - current_depth touch_mask = depth_diff > 3 # 3mm阈值 touch_points = cluster_centroids(touch_mask) # 聚类提取触点

✨ 边缘AI实时绘画生成

搭载8核ARM+NPU的边缘主机本地运行SDXL-Lightning蒸馏模型，文生图推理耗时<1秒，无需联网。同时集成ControlNet，可将用户手绘草图作为结构引导，AI在此基础上自动上色、细化、补全背景。

# 草图精修流水线 sketch_edge = canny_extract(user_drawing) # 提取草图边缘 image = controlnet_generate( prompt, sketch_edge, strength=0.75 # 保持结构+AI创作 )

👥 多人协作与笔触渲染

支持最多4人同时在墙面上绘画，系统自动区分不同触点（通过触摸区域距离聚类）。采用WebRTC协议实现多设备画面同步，笔触渲染引擎基于OpenGL ES，单帧可渲染500+笔迹点无卡顿。

# 笔触渲染：发光效果 glow = gaussian_blur(stroke, radius=8) final = stroke * 1.0 + glow * 0.4 # 主体+光晕叠加
