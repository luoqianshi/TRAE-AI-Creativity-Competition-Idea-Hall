04

核心功能

❤️
MAX30102

心率血氧监测

手指贴合传感器即可测量，自动过滤异常值，数据稳定后才显示。未佩戴时提示"请放好手指"，不展示虚假数据。

🆘
PWR 长按

SOS 一键求助

长按电源键触发 SOS，手表震动确认并亮屏，通过 PushPlus 向家属推送告警消息，SOS 优先级高于一切其他提醒。

📉
QMI8658C

跌倒 / 异常静止检测

基于六轴 IMU 检测冲击、姿态变化和随后静止，触发 10 秒倒计时，用户可取消，未取消才发送 SOS。先做日志测试模式，不默认自动求助。

👣
计步算法

步数与活动记录

加速度计驱动的步数统计，记录每日活动量，支持久坐提醒（活动量过低时震动提示，夜间不触发）。

⏰
NVS 持久化

定时提醒与闹钟

支持每日、指定日期、星期重复。到点自动亮屏、震动、弹出提醒。重启后数据不丢失。AI 可通过语音直接添加/删除。

🎙️
ES8311 + NS4150

语音播报与对话

短按电源键启动语音会话，AI 回复通过功放扬声器播出。支持中文 TTS，老人无需操作屏幕即可对话。

🤖
MCP 工具

AI 状态解释

老人问"我今天身体怎么样"，AI 读取手表最新心率和步数数据，用通俗语言解释当前健康状态并给出建议。

🌤️
OpenWeather

天气与抬腕亮屏

固定城市天气显示，抬腕自动亮屏（QMI8658C 姿态检测，带冷却时间避免频繁触发），设置页可开关。

使用场景

07:00 · 清晨

起床服药提醒

手表震动亮屏，显示"该吃降压药了"。老人确认后点完成，家属端同步看到已服药记录。

10:30 · 上午

日常健康打卡

老人抬腕亮屏，手指放好测量心率和血氧。数据稳定后显示结果，AI 语音播报"心率 72，血氧 98%，一切正常"。

14:15 · 下午

跌倒紧急求助

老人在卫生间不慎滑倒，手表检测到冲击后静止，10 秒倒计时后自动向家属推送 SOS 告警，附带时间和位置标记。

20:00 · 晚间

语音陪护对话

老人短按电源键说"今天步数多少"，AI 回答"今天走了 3842 步，比昨天多了 500 步，很棒"。孤独时也能聊聊天。

技术实现思路

硬件层
ESP32-S3 主控 ST7789 240×280 LCD FT5x06 电容触摸 MAX30102 心率血氧 QMI8658C 六轴 IMU ES8311 音频编解码 NS4150 功放 震动马达
系统层
ESP-IDF v5.5.4 FreeRTOS 多任务 NVS 提醒/闹钟持久化 FAT 动画资源 SPIFFS 音频资源 OTA 远程升级
UI 层
LVGL 图形框架 表盘 / 蜂窝菜单 / 健康页 SOS 响铃页 提醒覆盖层 语音状态动画 FFAT 帧动画
服务层
WeatherService 天气 HealthService 健康统一服务 WebSocket 云端通信 PushPlus 家属推送 SNTP 时间同步
AI 层
MCP Server 工具注册 reminder.add / list / delete alarm.add / enable / delete STT 语音识别 TTS 语音合成 LLM 对话理解

所有传感器访问通过统一 HealthService 封装，UI 不直接操作 I2C。 提醒/闹钟数据使用定长字符数组 + NVS blob 存储，带版本号便于升级。 MCP 工具回调不直接操作 LVGL，通过原子刷新标志在 UI 线程安全更新页面。

07

AI 参与方式

用户侧 · 语音入口

  • 短按 PWR 启动语音会话
  • 自然语言指令："今天 12 点提醒我吃药"
  • 健康提问："我今天心率正常吗"
  • 日常陪伴：自由对话聊天
  • 无需操作屏幕，老人零门槛
⇄

AI 侧 · 工具与理解

  • MCP 工具调用：自动解析意图并调用对应工具
  • reminder.add：创建提醒，校验时间
  • reminder.list / delete：查询并删除
  • alarm.add / enable：管理闹钟
  • 状态解释：读取健康数据并用通俗语言回复
— 对话示例 1：添加提醒 —
👤 老人：今天中午 12 点提醒我吃药
🤖 AI：→ 调用 reminder.add(hour=12, minute=0, title="吃药")
🤖 AI：← {"success":true,"id":3}
🤖 AI：好的，已经设好今天 12 点的吃药提醒，到时候手表会震动提醒您。
— 对话示例 2：健康状态解释 —
👤 老人：我今天身体怎么样
🤖 AI：→ 读取 HealthService 最新快照
🤖 AI：您最近一次心率是 72 次/分钟，血氧 98%，都在正常范围。今天走了 3842 步，活动量不错。继续保持！
