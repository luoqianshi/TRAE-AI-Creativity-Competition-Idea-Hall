💡 项目简介

Geo-Spider 是一个基于 AI 的智能地理信息采集与分析平台，融合了分布式爬虫技术、大语言模型和自动化工作流。 为企业提供全方位的舆情监测、数据分析和内容生成服务，实现从数据采集到智能分析的完整闭环。

🚀 核心功能

🎯 智能任务调度

  • 基于 Redis 的分布式任务队列
  • 支持多平台、多区域并发采集
  • 自动扩缩容与故障恢复
  • 灵活的定时任务配置

🤖 AI 驱动的内容分析

  • 集成多个 LLM 平台 API
  • 自动提取关键词、生成摘要
  • 智能内容分类与情感分析
  • 企业舆情智能监测

📝 自动化报告生成

  • 基于模板的文章自动生成
  • 数据可视化仪表盘
  • 定时报告推送
  • 多维度数据分析

🔌 开放式架构

  • OpenAPI Worker 支持外部执行器
  • Selenium Hub 集成
  • 模块化设计，易于扩展
  • 完善的 API 接口

🛠️ 技术栈

Spring Boot MyBatis-Plus Redis Redisson Selenium Grid MySQL OSS 存储 多 LLM 集成

🏗️ 系统架构

接入层： geo-spider-api (HTTP Controllers, 前端接口, OpenAPI Worker 接口)
业务层： geo-spider-service-impl (领域实现, CRUD, 聚合查询, 第三方集成)
任务层： geo-spider-task (爬虫实现, Selenium, 平台模型集成)
数据层： geo-spider-dao (MyBatis-Plus, 实体, Mapper, JSON查询)
协调层： Redis + Redisson (队列, 状态, 并发控制, 分布式锁)

💼 应用场景

📊 企业舆情监测

实时监控企业相关新闻、社交媒体动态，智能分析舆情趋势，及时预警负面信息。

🔍 竞品信息追踪

自动追踪竞争对手动态、产品更新、市场活动，为企业决策提供数据支持。

📈 行业数据分析

采集行业相关数据，生成可视化报告，洞察市场趋势和机会。

✍️ 自动化内容生产

基于采集数据和 AI 模型，自动生成文章、报告等内容，提升内容生产效率。
