技术亮点

解决 MUGEN 社区长期存在的工程难题

内存级胜负检测

直接读取 MUGEN 进程内存基址，通过指针偏移定位双方胜场计数器。解决 MUGEN 1.1 原生日志不含胜者字段的根本问题。

中文路径零拷贝

用 Windows mklink /J 创建 junction 联结，将中文路径映射为 ASCII 短路径，资源文件零拷贝直接引用，彻底解决崩溃问题。

6种Worker多线程

BattleWorker / PrefetchWorker / RecalculateWorker / LivePreviewWorker / PortraitQueue + 60s 看门狗，UI 全程不卡顿。

5级缓存体系

以 file_signature (size+mtime) 为核心原语，6 层递进签名校验 + SHA1 内容寻址缓存，源文件变化自动失效。

实力定档闭环

定档结果反向进入战斗编排系统自动播放战斗，战斗后再计算实力定档，实现完全自动化的联赛循环。

UI布局完整持久化

窗口/分割器/表格列序/冻结列/自定义列名/折叠状态全部自动保存恢复，含离屏检测和防抖机制。

版本转换工程规范

三层解耦：扫描只发现、运行才证明、Fatal 才修改。配套自动化脚本 fix_tagout / fix_exploit / fix_binary_st。

AI设计方法论

18 章系统化手册：分层决策（宏观策略/中观距离/微观连段）+ 概率驱动 + 安全优先 + 全招式覆盖，3 个端到端参考角色。

SFF精灵逆向解析

逆向分析 MUGEN 二进制 SFF 精灵文件格式，提取 9000 号大头像和站立姿态精灵。不依赖 Fighter Factory 等第三方工具，纯代码实现精灵解析与渲染。

AIR动画帧逆向渲染

逆向解析 AIR 动画定义文件，提取角色站立动作序列帧，自动选择最佳帧渲染各 P 数（1-12 色表槽位）的实机预览图，无需进入游戏即可查看角色。

战场背景逆向渲染

逆向解析 .def 舞台定义文件格式，提取背景层定义、parallax 视差参数和遮挡关系，独立渲染战场预览图，不启动 MUGEN 即可预览场景全貌。

性能优化与工程深度

23000+ 行代码背后，是反复打磨的工程细节

协作式取消三重保险

threading.Event() 零开销查询取消标志，先设协作标志，再 terminate() 进程，3s 后 kill()，确保战斗任务安全终止不残留。

立绘队列看门狗

PortraitQueue 每 5s 检查 worker 状态，超过 60s 未完成的任务自动踢出，_emitted 标志防止超时与正常完成的竞争条件。

表格批量更新防抖

批量更新战绩表/角色表时 blockSignals(True) 阻止逐行触发信号，20+ 处调用，避免大量无用的 UI 重绘。

战绩内存缓存

StatsService 用 (file_signature, data) 对做内存缓存，读取前先比对文件签名，未变化则跳过 JSON 解析直接返回。SQLite 5 个索引加速查询。

战斗监控效率

WinCountMonitor 100ms 轮询间隔，仅在胜场变化时记录。诊断采样 5s 一次，样本上限 40 条，防止长时间战斗内存无限增长。

日志自动管理闭环

启动时清理 30 天前的 .log 文件，desktop_runtime.log 超 5MB 自动归档为带时间戳文件，归档文件 30 天后自动删除。

布局持久化健壮性

离屏检测恢复时检查窗口矩形与屏幕相交；offscreen 平台保护跳过保存；启动防抖 500ms 防中间状态写入；自动保存防抖 350ms 单发定时器。

内容寻址缓存自动清理

立绘/预览缓存文件名由 SHA1(源文件签名+版本号) 生成，源文件变化产生新路径，旧缓存自动孤立无需手动清理。

03

AI 战斗剧情生成

AI 根据对战双方的招式、伤害、节奏自动生成文字剧情解说，实时显示在界面下方，让每场战斗都有独特的叙事。

04

剧情与战斗双向融合

05

电影化输出

编排剧本 → AI 生成剧情 → 战斗与剧情实时融合 → 玩家可随时干预走向 → 输出可观看的剧情化对战视频。MUGEN 从"格斗模拟器"进化为"格斗电影生成器"。
