## 一、新的分类结构

### 1.1 三种浏览模式

系统重构为"按地域｜按工艺｜按用途"三个切换模式：

#### 按地域（手艺地图）
核心定位："跟着手艺去中国"，从地域维度发现非遗。

8个示范地区：
- 河北廊坊：第什里风筝（直播中）
- 江苏苏州：刺绣与缂丝（可体验）
- 江西景德镇：陶瓷（专题）
- 云南大理：扎染（可体验）
- 北京：景泰蓝与传统泥塑（专题）
- 福建：漆艺（专题）
- 陕西：皮影（专题）
- 甘肃：剪纸和彩陶（专题）

#### 按工艺（统一一级分类）
8个一级分类及二级示例：

| 一级分类 | 二级示例 |
|---------|---------|
| 纸艺与灯彩 | 风筝、剪纸、灯彩、纸扎 |

| 木竹与编结 | 木雕、竹编、木作 |
| 金属与珐琅 | 景泰蓝、铜器、金银器 |
| 雕刻与塑作 | 泥塑、石雕、木雕 |
| 漆艺与文房 | 漆艺、宣纸、笔墨 |
| 表演与器乐 | 皮影、木偶、古琴、地方戏曲 |

#### 按用途（真实消费需求）
8个消费需求入口：
1. 送一份有故事的礼物
2. 日常使用的手工器物
3. 家居陈设
4. 收藏独立作品
5. 亲子手作体验
6. 个性化定制
7. 旅行纪念
8. DIY材料包

### 1.2 首页调整

首页不再直接展示完整分类宫格，调整为：
1. 今晚主题直播（核心入口）
2. 手艺正在发生（横向滑动卡片）
3. "跟着手艺去中国"地图预览卡（显示"6个地区正在直播，12个工坊可预约体验"）
4. 本周地方专题（专题卡片）
5. 按工艺探索（横向标签）
6. 按真实需求选作品（4x2网格）
7. 少量精选市集内容

## 二、地图交互逻辑

### 2.1 地图页面交互

1. **进入方式**：点击首页"跟着手艺去中国"地图预览卡或底部导航"发现"->按地域模式
2. **地图展示**：使用内嵌SVG绘制中国简化地图轮廓，8个点位标注
3. **点位状态**：
   - 红色（直播中）：河北廊坊，带有浮动动画
   - 绿色（可体验）：江苏苏州、云南大理
   - 灰色（专题）：其他地区
4. **点击点位**：弹出底部抽屉，展示该地区详细信息

### 2.2 地区抽屉交互

点击地图点位或发现页地区卡片后，从底部弹出抽屉：

抽屉内容结构：
1. 地区名称 + 代表性手艺 + 状态标签 + 收藏按钮
2. 当前直播模块（仅直播中地区显示）
   - 直播标题
   - 观看人数
   - 进入直播间按钮
3. 推荐作品列表
4. 可预约体验列表
5. 进入地方专题按钮

抽屉操作：
- 点击遮罩层关闭抽屉
- 点击进入直播间/专题按钮，关闭抽屉并跳转对应页面
- 收藏按钮支持切换状态，数据保存至localStorage

### 2.3 浏览模式切换

在发现页面顶部三个标签切换：
- 按地域：展示8个地区卡片网格
- 按工艺：展示工艺分类横向标签 + 对应内容列表
- 按用途：展示用途分类横向标签 + 对应商品列表

切换时平滑显示/隐藏对应区块。

## 三、数据字段结构

### 3.1 地区数据结构

```javascript
regions: {
    [regionId]: {
        id: string,           // 地区ID
        name: string,         // 地区名称
        crafts: string[],     // 代表性手艺列表
        status: string,       // 状态：'live' | 'experience' | 'topic'
        liveTitle?: string,   // 直播标题（仅live状态）
        liveViewer?: string,  // 观看人数（仅live状态）
        geojson: {           // GeoJSON格式坐标
            type: 'Point',
            coordinates: [number, number]  // [经度, 纬度]
        },
        experiences: string[],  // 可预约体验列表
        works: string[],        // 推荐作品列表
        color: string           // 主题色（用于卡片和图标）
    }
}
```

### 3.2 工艺分类数据结构

```javascript
craftCategories: {
    [categoryId]: {
        name: string,       // 分类名称
        items: string[]    // 二级示例列表
    }
}
```

### 3.3 用途数据结构

```javascript
purposes: {
    [purposeId]: {
        name: string,      // 用途名称
        icon: string       // FontAwesome图标名
    }
}
```

### 3.4 过滤数据标记

内容卡片使用 `data-craft` 和 `data-purpose` 属性标记所属分类：

- `data-craft="paper"`：属于纸艺与灯彩分类
- `data-purpose="gift,decor"`：同时属于送礼物和家居陈设

## 四、未来接入GeoJSON方案

### 4.1 当前设计预留

当前数据结构已包含 `geojson` 字段，格式完全符合GeoJSON规范：

```javascript
geojson: {
    type: 'Point',
    coordinates: [116.7, 39.5]  // [经度, 纬度]
}
```

### 4.2 QGIS导出接入流程

当未来需要接入QGIS导出的GeoJSON数据时，可按以下步骤进行：

**步骤1：数据格式转换**

QGIS导出的GeoJSON通常为FeatureCollection格式：

```json
{
    "type": "FeatureCollection",
    "features": [
        {
            "type": "Feature",
            "geometry": {
                "type": "Point",
                "coordinates": [116.7, 39.5]
            },
            "properties": {
                "name": "河北廊坊",
                "crafts": ["第什里风筝"],
                "status": "live"
            }
        }
    ]
}
```

**步骤2：数据加载**

```javascript
// 加载外部GeoJSON文件
fetch('regions.geojson')
    .then(response => response.json())
    .then(data => {
        // 转换为当前appData格式
        const newRegions = {};
        data.features.forEach(feature => {
            const props = feature.properties;
            newRegions[props.id] = {
                ...props,
                geojson: feature.geometry  // 直接使用GeoJSON几何对象
            };
        });
        appData.regions = newRegions;
    });
```

**步骤3：地图渲染升级**

当前使用固定SVG坐标，接入GeoJSON后需实现坐标转换：

```javascript
// 简单的经纬度转SVG坐标函数
function geoToSvg(lon, lat) {
    // 根据实际地图投影参数调整
    const x = ((lon - minLon) / (maxLon - minLon)) * mapWidth;
    const y = ((maxLat - lat) / (maxLat - minLat)) * mapHeight;
    return { x, y };
}
```

**步骤4：功能扩展**

接入GeoJSON后可扩展的功能：
- 支持更多地区点位
- 添加地区边界多边形
- 实现地图缩放和平移
- 支持不同层级的地理信息展示

## 五、已测试的用户路径

### 路径1：首页 -> 主题直播 -> 工艺档案 -> 购买

1. 用户进入首页，看到主题直播卡片
2. 点击进入直播间，观看直播内容
3. 点击"进入工艺档案"按钮
4. 查看作品制作档案详情
5. 点击"购买成品"按钮
6. 选择规格并确认购买

### 路径2：首页 -> 地图预览 -> 地图页面 -> 地区详情 -> 直播间

1. 用户在首页点击地图预览卡片
2. 进入地图页面，看到8个地区点位
3. 点击河北廊坊点位（直播中）
4. 在抽屉中查看地区详情
5. 点击"进入直播间"按钮

### 路径3：发现 -> 按工艺 -> 筛选 -> 查看内容

1. 用户点击底部导航"发现"
2. 选择"按工艺"模式
3. 点击"纸艺与灯彩"标签筛选
4. 页面仅显示纸艺类内容
5. 点击内容卡片查看详情

### 路径4：发现 -> 按用途 -> 筛选 -> 查看商品

1. 用户点击底部导航"发现"
2. 选择"按用途"模式
3. 点击"亲子"标签筛选
4. 页面显示亲子相关商品
5. 点击商品卡片查看详情

1. 用户打开任意地区抽屉
2. 点击心形收藏按钮
3. 收藏状态切换，数据保存至localStorage
4. 再次打开该地区抽屉，收藏状态保持

### 路径6：首页 -> 本周专题 -> 地区详情

1. 用户在首页看到本周专题卡片
2. 点击卡片打开地区抽屉
3. 查看完整专题内容

## 六、技术实现要点

### 6.1 响应式设计

- 最大宽度480px，居中显示
- 地图容器高度300px，适配手机屏幕
- 抽屉最大高度85vh，支持滚动
- 横向滚动区域隐藏滚动条

### 6.2 图标统一规范

- 线宽统一：1.5px
- 尺寸统一：18px（标签）、20px（卡片）、24px（商品）
- 颜色逻辑：工艺分类使用专属颜色
- 视觉中心：图标居中对齐

### 6.3 状态管理

- 使用localStorage存储用户收藏：`jiangjian_favorites`
- 收藏数据格式：`["langfang", "suzhou"]`（地区ID数组）

### 6.4 性能优化

- 单文件开发，减少HTTP请求
- 内嵌SVG，无需外部资源
- CSS动画使用transform，硬件加速
