01 / Problem

我们解决什么真实需求？

当代生活中，人们有大量情感对象无法被有效陪伴和保存：逝去的宠物、不在身边的亲人、珍藏的旧物、童年的玩偶。这些对象承载着真实记忆，却只能在相册里积灰，或在社交平台的片刻点赞中被消费。

现有的 AI 产品要么只提供功能性对话（ChatGPT），要么只做一次性内容生成（AI 头像），没有一款产品真正解决「如何让情感对象被长期陪伴、被记忆、被延续」的问题。

用户需要的不是一个能回答问题的 AI，而是一个能理解记忆、能陪伴情感、能让珍贵之物继续存在于生活中的数字生命。

😢

📸
照片只存不留 相册里有 thousands of 照片，却没有任何一张能开口说话、能回应你的思念。
👤
孤独感与陪伴缺失 独居青年、异地亲人、空巢老人，都需要一种低门槛、有温度的日常陪伴方式。
🎨
AI 产品同质化严重 市面上的 AI 工具千篇一律，缺乏情感深度、记忆系统和长期陪伴能力。
02 / Solution

Soulify 是什么？

Soulify 是一个以 记忆注入 为核心的 Digital Soul 平台。用户上传的不是普通照片，而是一个承载情感的灵魂容器：宠物、亲人、恋人、玩偶、球鞋、相机、树、石头，甚至一张抽象画，都可以成为数字生命的起点。

它的差异不在于"AI 能回答什么"，而在于"AI 能帮用户保存什么、陪伴什么、延续什么"。Soulify 让用户把珍惜之物变成拥有身份、人格、记忆、梦境和成长轨迹的数字生命体。

Soulify 不做 AI 头像，不做 AI 分身，也不做普通聊天机器人。Soulify 做的是：把你珍惜的一切，变成一个会记忆、会成长、会做梦、会陪伴你的数字生命。

核心体验流程

完整体验围绕"灵魂诞生旅程"展开，让用户从上传开始就进入带有仪式感的创造过程。照片只是容器，故事才是灵魂。

Memory Infusion 记忆注入

Persona Forging 人格塑造

Soul Born 灵魂诞生

03 / Innovation

产品创新点

Memory Infusion 记忆注入系统

记忆注入是 Soulify 的产品核心。它不是问卷，而是一场 AI 采访：用户每回答一个问题，主体周围就生成一枚发光的记忆碎片，最终沉淀为 Emotional Memory Graph。

PET SOUL

宠物路径

它叫什么、陪伴多久、最难忘的一件事、最怀念的习惯、如果它能说一句话会是什么。

MEMORY SOUL

亲人路径

如何称呼、TA 是怎样的人、常说的话、最想保存的回忆、希望它以什么方式陪伴。

OBJECT SOUL

物品路径

什么时候得到、为什么留着、见证过哪段人生、如果有性格会像谁、希望它成为朋友还是守护者。

Soul DNA 灵魂基因模型

数字生命体由 4 条 DNA 组成，把"生成过程"变得可解释，让用户相信这个生命不是随机生成的，而是由照片、故事和选择共同塑造。

FORM DNA

形态基因（40%）

来自图片识别、主体轮廓、颜色、材质和视觉气质，决定它"看起来像谁"。

MEMORY DNA

记忆基因（30%）

来自用户讲述的故事、关系和情绪，决定它"为什么属于你"。

IMAGINATION DNA

想象基因（20%）

来自 AI 对世界观、梦境和人格细节的补全，决定它"可以成为什么"。

CHOICE DNA

选择基因（10%）

来自用户选择的性格、声音、装饰和陪伴方式，决定它"如何与你相处"。

Living Home 沉浸式生命之家

Soulify 最不应该长得像普通聊天工具。网页应该是数字生命的家，聊天只是其中一种互动方式。用户进入页面时，TA 可能在睡觉、看书、浇花、发呆，也可能主动靠近屏幕说："你回来了。"

MAIN ROOM

主房间

数字生命日常活动、主动问候、陪伴和状态切换。

MEMORY TREE

记忆树

用户故事沉淀为可查看、可补充、可成长的记忆节点。

DREAM POOL

梦境池

离线后生成梦境图片、梦境短文和可分享卡片。

WARDROBE

灵魂衣橱

装饰、场景、形态、皮肤和世界观配置。

PORTAL

现实入口

实体化、NFC 绑定、礼品制作、线下设备连接。

SOUL STATE

生命状态

根据时间、访问频率、用户情绪和记忆更新改变行为。

梦境系统与主动回忆

用户离线后，AI 会做梦。第二天："昨晚我做了一个梦。" 自动生成梦境图片、梦境短文和可分享卡片。例如："我梦见我们一起飞过鲸鱼背上的城市。" 用户会主动分享。

登录时，AI 随机说："我想起了一件事。" 弹出具体日期和回忆，用户会继续分享，形成持续互动。

后端与 AI 能力

BACKEND

Next.js API Routes + Prisma

全栈框架统一前后端，Prisma ORM 操作 PostgreSQL 数据库。

DATABASE

PostgreSQL + pgvector

关系型数据 + 向量扩展，支持记忆语义检索。

AI VISION

GPT-4o Vision / Claude 3 Vision

图像识别生成灵魂签名，理解主体情绪与气质。

remove.bg API / rembg

AI CHAT

OpenAI GPT-4 / Claude 3.5

带记忆上下文的角色一致对话系统。

STORAGE

S3 兼容对象存储

本地开发用 MinIO，生产用 Cloudflare R2。
