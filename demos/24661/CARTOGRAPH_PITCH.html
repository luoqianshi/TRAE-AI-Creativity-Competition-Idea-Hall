💡 创意简介

想解决什么问题？

创作者（TRPG GM / 小说作者 / 独立游戏设计师）想要为自己的架空世界绘制一张带地形 / 水文 / 气候 / 资源 4 个图层的可缩放地图，并放置城市 / 国家 / 政区等元素。但通用画图工具要么不够"格子化"、要么太贵、要么不开放 JSON 导出与版本化管理，难以承载"地理数据"语义。

为什么会想到做这个？

  • 个人痛点：写小说前需要画世界地图，用 PS 改人口要重画、用 Wonderdraft 无法版本管理
  • 开源生态空白：轻量/格子化/JSON 可读写/多图层的工具几乎没有
  • 架构验证：作为前端架构师，验证命令式渲染器 + Hooks 分层 + JSON schema 版本管理的工程方法论

大概是什么产品？

一款开源、纯前端、JSON 化的 架空世界地图编辑器（Web SPA），用格子（cell）作为最小单位，支持 4 个地理图层 + 地图元素（点状 POI）+ 区域（多格）三类业务对象的创建、编辑、撤销重做、JSON 导入导出。

开源 纯前端 JSON 化 Web SPA 数据主权
