创意介绍

🎯 想解决什么问题

长时间久坐是现代办公人群的隐形健康杀手——颈椎病、腰椎间盘突出、下肢静脉曲张等问题日益低龄化。大多数人并非不愿活动，而是沉浸在工作中忘记了时间，等到身体发出警报时往往为时已晚。而市面上的久坐提醒工具大多是简单的"傻瓜闹钟"，完全不感知实际行为。

💭 为什么会想到做这个

作为一名每天编码超过 8 小时的开发者，我深受现有提醒工具"误报"之苦——刚从茶水间回来就弹提醒，正在赶 deadline 时被强制打断。我想借助 TRAE AI 辅助开发，做一款真正能感知用户行为的智能提醒工具，做到"该提醒时精准触达，不该打扰时绝不干扰"。

📦 产品形态

一款基于 Chrome Manifest V3 的浏览器扩展。无需安装额外软件，打开浏览器即自动生效。计划通过系统空闲检测 API + 多信号融合算法，实现零硬件依赖的智能站立检测。

💬 为什么选择 Chrome 扩展而不是 App？——智能手表不是人人都有，桌面 App 在很多公司的办公电脑上有安装限制，但浏览器人人都有，Chrome 扩展不需要管理员权限，加载即用，是覆盖办公人群最广的方案。

计划实现的核心功能

🔍

多信号融合检测

计划结合系统空闲状态、时间阈值和工作上下文三重校验，精准判断用户是否真正站立。

⏱️

精确计时引擎

基于时间戳差值而非 alarm 触发次数，杜绝锁屏/睡眠后的时间虚增问题。

🔔

双模式提醒

系统通知 + 全屏覆盖弹窗可选，从轻量提示到强制感知，适配不同场景需求。

📊

健康评分体系

设计三维度加权算法（休息频率 60% + 超时惩罚 20% + 久坐惩罚 20%），量化每日健康表现。

🧠

智能免打扰

勿扰时段、工作时段、忙碌模式等多种灵活机制，不在错误的时间打扰你。

🛡️

零隐私风险

全部数据本地存储（chrome.storage），不连接任何服务器，数据只属于用户自己。

关键技术思路

  • Manifest V3 架构 — 采用 Service Worker 替代持久化背景页，所有状态通过 chrome.storage 持久化，适配现代浏览器扩展规范
  • 精确闹钟调度 — 计划使用一次性 chrome.alarms 精确计算到点时间，而非依赖重复闹钟的间接累计
  • 时间戳差值计时 — 通过 Date.now() 差值计算真实经过秒数，解决锁屏/睡眠后时间虚增的行业通病
  • 多信号融合判断 — 结合 idle 状态 + 持续时长 + 工作上下文，三重校验才判定为"有效站立"
  • 边缘场景兜底 — 关机过夜、Service Worker 被挂起等场景的优雅恢复策略

核心痛点

  • 无感知久坐 — 沉浸工作时完全意识不到已坐多久，直到身体的颈椎、腰椎发出警报才反应过来
  • 现有工具误报频繁 — 简单计时器不考虑实际行为：刚从厕所回来就弹提醒，正在开会不方便起身
  • 智能手表不普及 — 不是所有人都有智能手表/手环，工作时也未必习惯戴
  • 桌面 App 装不上 — 很多公司办公电脑有安装限制，第三方软件需要审批，但浏览器扩展加载即用无门槛
  • 缺乏量化反馈 — 没有数据追踪，不知道每天的久坐习惯是好是坏，缺乏改善动力
🎬

设想的使用场景

  • 日常办公 — 设定 45 分钟工作间隔，扩展自动追踪久坐时长，到点智能提醒起身活动
  • 接水/上厕所 — 短暂离开（< 5 分钟）自动识别并过滤，不会错误重置计时器
  • 午餐时段 — 勿扰时段自动静音（如 12:00-14:00），该休息的时候绝不打扰
  • 紧急 deadline — "现在很忙"模式：暂停弹窗但保留超时警示，尊重用户当前状态
  • 下班后/周末 — 工作时段外自动停止、非工作日完全静默，不占用私人时间

价值与意义

💚

社会健康价值

世卫组织数据显示，久坐行为是全球第四大致死风险因素。希望通过技术手段主动干预不良习惯，预防颈椎/腰椎疾病和心血管风险。每一次及时的站立提醒，都是对用户未来健康的一次投资。

⚡

工作效率提升

研究表明，规律休息能显著提升认知表现和创造力。通过科学的"45 分钟工作 + 5 分钟休息"节律，帮助用户维持高效专注，减少因疲劳导致的错误。健康评分机制形成正向激励闭环。

🚀

技术差异化

"多信号融合站立检测"思路解决传统计时器误报率高的痛点。完全基于浏览器 API，零硬件依赖、零服务器成本、零隐私风险，用 AI 辅助开发验证技术可行性。
