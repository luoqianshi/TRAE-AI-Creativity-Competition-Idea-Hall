这个项目解决什么？

📱
相册太多，但没有“意义”手机里有上千张照片，却很难回答“这一年家里发生了什么”。
🧩

👵
家庭变化不可回看老人健康、孩子成长、家庭团聚这些变化，缺少一条可读的家庭叙事。

项目核心逻辑

照片如何变成家庭记忆？

评委最关心的是“这东西有什么用”。所以页面必须明确展示：不是上传图片玩效果，而是把照片转化成家庭长期资产。

1

读取照片元信息

读取拍摄时间、文件时间、GPS 坐标；这是家庭记忆的时间轴和空间轴基础。

2

AI理解照片内容

识别场景、人物共现、事件类型、情绪倾向。Demo 用模拟视觉识别，真实产品可接视觉模型。

3

构建家庭图谱

同一张照片里共同出现的人，会形成关系连接；多次共现会增强关系强度。

4

生成年度叙事

把照片事件按时间组织，输出可以被家庭阅读、分享和长期保存的家庭故事。

技术与落地

真实产品怎么接起来？

Demo 不是假想，它的核心链路可以直接落地：前端读照片，视觉模型解析内容，关系图谱和故事生成由结构化数据驱动。

照片上传浏览器 File API，多图上传、本地缩略图。
EXIF解析读取 DateTimeOriginal、GPS；缺失时降级到文件时间。
视觉识别接入 GPT-4o / Gemini / Qwen-VL，识别人物、场景、情绪。
记忆建模生成事件节点、人物共现边、地点轨迹、情绪曲线。
故事生成把结构化事件编译成家庭年度报告与纪录片旁白。
Family Memory Lens｜一句话收尾：让照片从“存储的图片”变成“可理解、可回看、可传承的家庭记忆”。
