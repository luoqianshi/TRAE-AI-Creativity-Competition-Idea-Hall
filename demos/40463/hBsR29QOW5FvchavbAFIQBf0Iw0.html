帮我解释一下Spring AI是什么？
🤖
Spring AI 是 Spring 生态中的 AI 应用框架，它提供了：

1. 统一的 API 抽象 — 对接 OpenAI、通义千问等多种模型
2. 流式响应支持 — 原生集成 SSE 实现打字机效果
3. RAG 能力 — 文档检索增强生成
4. 函数调用 — 让 AI 调用你的 Java 方法

简单来说，它让 Java 开发者能用 Spring 的方式快速构建 AI 应用。
👤
这个项目的架构是怎样的？
🤖
本项目采用前后端分离架构：

🏠 前端：Vue 3 + Pinia + Vite
⚙️ 后端：Spring Boot 3.5 + Spring AI Alibaba
📊 存储：Redis 持久化会话数据
📦 部署：Docker Compose 一键编排

前后端通过 RESTful API + SSE 流式接口通信，支持实时打字机效果。
