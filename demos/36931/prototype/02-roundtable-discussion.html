见解
阅读 token.ts 后，当前过期逻辑存在 滑动窗口缺失： 
// token.ts:L18
const expiresIn = 3600; // 固定1小时，无滑动
sign(payload, SECRET, { expiresIn })
问题：token 一旦签发，过期时间固定，用户活跃期间无法自动续期，被迫频繁重登。
建议：引入 access + refresh 双 token，access 短期（15min），refresh 长期（7d）。
