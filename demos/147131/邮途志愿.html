邮途志愿

高考志愿智能推荐系统 — 输入分数，秒出冲稳保专业方案

💡创意介绍

?想解决什么问题

北邮历年分数线分散在多个网站，缺乏整合；考生和家长无法快速判断自己的分数/位次能报哪些专业。

!为什么会想到做这个

做过几次招生宣讲后发现，为学生和家长解答报考问题时，手边没有历年分数线的整合参考来给出预判信息，各种专业信息也缺乏统一整理，于是决定做一个专用查询+推荐工具。

★产品形态

手机端 H5 网站，免安装、微信直接点开即用。基于 React + Vite 构建，纯前端无需后端，可部署在 GitHub Pages 免费托管。

👥目标用户及痛点

🎓

高考考生

自己查数据、做决策，需要精准定位

👨‍👩‍👧

考生家长

帮孩子参谋，但不懂位次、选科规则

🏫

中学教师

指导多名学生，需快速查询对比

使用场景

出分后志愿填报前的黄金1-2周。考生拿到分数和位次后，需要在短时间内确定目标院校的可行专业范围。微信里收到链接即可直接打开使用，无需安装任何App。

当前痛点

1. 北邮招生网数据按省按年分散在几十个页面，无法一次看全
2. 官方只公布分数线，不提供位次，而位次才是跨年对比的准绳
3. 没有"冲稳保"推荐功能，考生只能手动对比5年数据估算概率
4. 分数和位次之间的关系需要查各省一分一段表，非常麻烦

⭐价值与意义

⚡

效率提升

将分散的历年分数线数据整合为一体化查询体验，让考生从繁杂的信息搜索中解放出来，快速获得科学报考参考。

🌍

社会价值

降低高考志愿填报的信息差。许多农村和小城市的考生缺乏经验丰富的指导老师，本产品让每个考生都能获得数据驱动的科学推荐，减少因信息不足导致的滑档、误报，促进教育公平。

🔧核心功能

📊

分数线查询

31省5年数据，按位次排序，显示"位次（分数）"格式，支持搜索过滤

📈

历年位次折线图

点击任意专业展开近5年位次趋势图，直观判断分数波动

🎯

智能推荐

输入分数/位次，基于位次算法推荐冲稳保专业，支持分数自动转位次

📱

移动优先

H5网站微信即开即用，无需安装，零门槛分享传播

⚙️技术方案

前端：React 18 + Vite 5，纯静态部署，无需后端服务器

数据：从北邮招生网、掌上高考等官方渠道采集，标注数据来源（官方/参考）

推荐算法：基于近5年位次均值，按位次偏差比例分为冲（+10%~30%）、稳（±10%）、保（-10%以上）三档

部署：GitHub Pages 免费托管，微信链接即开即用
