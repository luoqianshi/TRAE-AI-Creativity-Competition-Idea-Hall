🎯 创意介绍
💡 想解决什么问题

企业和个人在合同管理过程中，常常面临合同文件散乱、质保金到期遗忘、合同查找困难等痛点，导致经济损失和工作效率低下。

🚀 为什么会想到做这个

在日常工作中发现很多朋友和同事都在为合同管理发愁，尤其是质保金到期提醒这一块，经常因为忘记而造成不必要的损失。于是想到做一个简单实用的合同管理系统来解决这些问题。

📦 产品形态

基于 Web 的合同管理系统，支持 Docker 容器化部署，可轻松运行在 NAS 设备上，随时随地访问管理。

✨ 核心功能
📤
合同上传管理

支持上传 PDF 格式合同文件，自动生成合同记录，支持编辑和删除操作。

👁️
在线预览

集成 PDF.js 实现合同在线预览，无需下载即可查看合同内容。

🔔
到期提醒

自动检测 7 天内到期的质保金，通过 PushMe 或 Server 酱发送提醒通知。

📊
数据导出

支持将合同列表导出为 Excel 文件，方便数据备份和报表分析。

🛠️ 技术架构
后端技术
Python 3.9 Flask 2.0 SQLite
前端技术
HTML5 CSS3 Bootstrap 5 PDF.js
部署方案
Docker Docker Compose 飞牛 NAS
🎨 界面预览
📱
登录界面

简洁的登录页面，支持用户名密码登录

📊
仪表盘

展示合同概览、即将到期合同、合同统计等信息

📝
添加合同

表单式合同录入，支持上传 PDF 文件，填写质保金信息

👁️
合同详情

合同详情页，集成 PDF 在线预览功能

🌟 价值与意义

效率提升

系统化管理合同文件，一键搜索、在线预览，大幅提升合同管理效率，节省人力成本。

商业价值

智能到期提醒确保用户不会错过质保金回款时间，避免因遗忘导致的经济损失，保护企业和个人财产安全。

📦 部署方式 
# 1. 将项目文件复制到 NAS 上
cd /volume1/docker/contract-management

# 2. 配置环境变量（docker-compose.yml）
# 设置 PushMe/Server 酱密钥

# 3. 启动服务
docker-compose up -d

# 4. 访问系统
# http://[NAS_IP]:5000

默认账号：admin / 密码：admin123
