📖 创意简介

高考志愿填报 Wide&Deep 模型 录取概率预测 冲稳保推荐

智选志愿 是一款基于 Wide&Deep 深度学习模型的 Web 智能推荐系统，面向全国高考考生。 系统通过采集考生的分数、位次、专业偏好、地区偏好、性格倾向等多维信息， 利用自研的多源概率融合引擎精确计算每个院校专业的录取概率， 自动生成 冲刺 · 稳妥 · 保底 三级梯度推荐方案，帮助考生科学填报志愿，让每一分都不被浪费。

✨ 核心功能

📊 录取概率预测

融合 model_prob（深度学习概率）、diff_prob（分数差概率）、rule_prob（规则概率）、rank_probability（位次概率）四层评分

admission_prob = 0.68 × rank_probability + 0.32 × raw_admission_prob

🎯 综合推荐评分

七维综合排序：录取概率 ×0.50 + 专业匹配度 ×0.30 + 地区偏好 ×0.08 + 院校层次 ×0.08 + 质量分 ×0.04

📈 冲稳保梯度推荐

基于位次比精确划分三档：冲刺池（位次比 0.62~0.98）、稳妥池（0.90~1.10）、保底池（1.06~1.48）

🔄 多样性选择策略

同院校最多 2 个专业、专业类上限约束、省外院校比例 ≥40%，避免推荐方案过于集中

📋 志愿草稿管理

支持多方案编辑、对比、保存，画像修改后可追溯历史推荐版本

🔍 录取概率复核

支持对任一院校专业进行实时录取概率复核，结合最新排名和位次重新计算

🔄 推荐工作流程

考生填写画像 → 构建候选池 → 模型概率预测 → 规则评分融合 → 冲稳保分层 → 多样性选择 → 推荐结果

💡 技术亮点

🔬 合成伪标签训练

基于历史录取数据，通过 8 种场景模拟（高分/低分/不同位次等）自动生成训练样本，无需真实录取结果即可完成模型训练。训练基表 14 万条扩增至 112 万条样本。

🧩 Wide&Deep 混合架构

Wide 侧记忆"分数差 ≥ 线差 → 大概率录取"等显式规则，Deep 侧通过 Embedding + MLP 学习多维特征的深层交互，两者互补实现精准预测。

📉 多阶段概率融合

将深度学习概率与领域规则概率渐进融合，确保极端情况下（如冷门专业、大小年波动）仍有合理的概率输出。

⚡ 轻量级推理引擎

模型仅约 15 万参数，单次推荐在 CPU 上仅需 0.2~0.4 秒，无需 GPU 即可部署，适合大规模并发访问。
