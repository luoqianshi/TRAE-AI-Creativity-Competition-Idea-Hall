>> 07 · 答疑

常见问题

// 如果你心里还有疑问,先扫一眼这里。

问.01可以同时报名多个赛道 / 多个创意吗?
+
可以。你可以同时报名多个赛道,也可以在同一赛道下提交多个创意。但每个创意都要单独发一篇报名帖,且报名通过奖励只发放一次。
问.02报名帖没通过审核,能改原帖再审吗?
+
不建议。官方只审核前一天新发的报名帖,编辑旧帖不会重新进入审核。建议直接重新发一篇新的报名帖。
问.03为什么收到了「报名通过」通知,却没收到速通奖励?
+
报名通过后还需要去 大赛官网「确认领取」,奖励才会发放。两种情况会导致领取失败:
① 你已是速通 Pro / Pro+ / Ultra / 优速通 Express 任一种,速通 Pro 自动发放失败,由运营在 3 个工作日内补发等值奖励(价值 ¥99 / 100 次 / 31 天);
② 被风控判定为异常用户。
问.04为什么强调「社区和 TRAE 中国版用同一手机号」?
+
本次报名没有收集手机号表单,社区账号与 TRAE UID 一一对应。如果两边用了不同手机号,或中途换账号 / 昵称,系统可能无法把你的作品和奖励对应起来。
问.05报名没通过,对应的 Demo 还能参赛吗?
+
不能。报名审核期间可以提前做 Demo,但报名最终未通过的话,对应 Demo 不进入初赛评审。建议先确保报名通过再投入打磨。
问.06怎么知道自己报名通过了?
+
三个途径同步结果:
① 登录大赛官网 trae.cn/ai-creativity/result 查看状态;
② 留意短信通知(保持注册手机号畅通);
③ 关注社区 / 社群的「晋级 & 获奖公示」。
问.07创意方案 HTML 怎么生成?真的不用会代码吗?
+
不用会代码。打开 TRAE Work · 智能模式,把你的创意用一句话告诉它,再贴上报名帖的内容要求(创意介绍 / 目标用户 / 价值意义),3–5 分钟就拿到一份可展示的 HTML 方案。
