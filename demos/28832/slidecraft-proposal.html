痛点分析
AI 能生成，但改不了
当前 AI 生成 HTML 演示文稿的工作流存在一个关键断裂
✍

改代码门槛高

AI 生成的 HTML/CSS 代码往往复杂且冗长，普通用户根本不敢动手改。即使懂代码，在几千行 HTML 里找一个颜色值也极其低效。

🔄

让 AI 改不可控

让 AI 修改意味着重新描述需求、等待生成、检查结果——改一个字号可能要等 30 秒，而且 AI 可能改错地方或引入新问题。

📋

缺少年页管理

HTML 演示文稿本质是多页内容，但浏览器只能整体预览。无法像 PPT 那样快速翻页、排序、插入、删除，管理效率极低。

🎨

样式调整不直观

想微调字体大小、间距、颜色、对齐方式？在代码里改 CSS 值，刷新看效果，不满意再改——完全无法实时预览，反复折腾。

📱

布局拖拽缺失

想把标题往左移一点？把图片换个位置？在 HTML 里这意味着修改 CSS 定位或 Flexbox 属性，完全无法像 PPT 那样直接拖拽。

🚫

传统 PPT 的困境

反过来，传统 PPT 格式 AI 极难生成——二进制格式、复杂嵌套结构，AI 只能通过 SDK 间接操作，效果差且限制多。

解决方案
像编辑 PPT 一样编辑 HTML
SlideCraft = AI 生成的效率 + 可视化编辑的自由

核心理念

AI 负责生成，SlideCraft 负责调整。用户用 AI 快速生成 HTML 演示文稿的初版，然后在 SlideCraft 中像使用 PowerPoint 一样，通过拖拽、点击、面板调整来精修每一页的内容和样式。

技术架构

基于 Electron 构建，利用 Chromium 渲染引擎实现真实的 HTML 预览。左侧页面缩略图栏管理分页，中间画布实时渲染，右侧属性面板精确调整——三栏布局，和 PPT 编辑器一样的直觉操作。

关键创新

不是代码编辑器套壳，而是真正理解 HTML 语义的可视化编辑器。选中元素即可拖拽移动、调整大小、修改样式，所有改动实时反映到 HTML 源码，零延迟双向同步。

分页管理

像 PPT 一样管理页面：缩略图预览、拖拽排序、插入新页、复制删除。每个 section 或 article 标签自动识别为一页。

👆

元素拖拽编辑

点击选中任意元素，直接拖拽移动位置、拖拽边角调整大小。无需碰代码，像操作 PPT 对象一样自然。

🎨

实时样式面板

右侧属性面板实时展示选中元素的样式：字体、颜色、间距、对齐、边框等。修改即时生效，所见即所得。

📝

富文本编辑

双击文字即可原地编辑，支持加粗、斜体、字号、颜色等格式调整。告别在 HTML 标签里找文字内容的痛苦。

💾

多格式导出

编辑完成后导出为独立 HTML 文件（可直接在浏览器演示），或导出为 PDF。保持原始样式和动画效果。
