我们要解决什么问题？

"组织失忆症"——最重要的知识不在系统里，在人脑里。人走了，经验就没了。

📄

知识孤岛

80% 的组织知识散落在会议录音、聊天记录、邮件和数十个文档系统里，彼此割裂，无法统一检索。

🚪

经验流失

员工离职带走约 42% 的隐性经验——判断逻辑、决策权衡、人脉关系。每流失一人，组织损失 5-8 万元。

🔍

找不到了

现有工具只能回答"文档里写了什么"，无法回答"基于组织的全部知识和经验，现在应该怎么做"。

👴

数字鸿沟

老年群体面对复杂公共服务流程，要么靠子女帮忙，要么跑多次冤枉路。政策落地"最后一公里"缺乏智能支撑。

产品核心能力

不是聊天机器人，是一个认知操作系统：感知 → 记忆 → 反思 → 成长 → 执行

🧠

三层记忆系统

短期记忆（会话上下文）+ 长期语义记忆（ChromaDB 向量检索）+ 概念记忆（知识图谱）。自动重要性评分，周期性记忆巩固。

💡

反思引擎

系统定期主动扫描记忆库，自动发现事实矛盾、合并重复信息、识别隐藏关联，生成"你正在形成 XX 认知模型"类洞察。这是从"存储工具"到"认知系统"的质变——不是等人来查，而是主动思考。

🤖

Agent 内部市场

内置知识整理、会议纪要、深度调研等 Agent；开发者可提交自定义 Agent 至内部市场，管理员审核后全组织可用。形成生态飞轮：使用越久，Agent 越精准。

🛡️

安全运行时治理

Kill Switch 紧急熔断 + 事件审计 + 163 项红队逃逸测试 + 沙箱策略默认禁用。所有安全控制面基于元数据驱动、故障关闭、按需授权。

🏛️

组织级架构

RBAC 权限控制 + JWT 认证 + 多租户 Workspace 隔离 + 全本地存储。支持共享数据库与独立数据库两种模式，满足合规要求。
