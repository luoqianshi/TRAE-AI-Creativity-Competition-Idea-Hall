01 / 问题洞察

标签页混乱，
是每一个重度浏览者的日常

作为产品经理，我每天需要同时处理竞品分析、文档协作、数据看板、即时通讯等多个工作流。浏览器标签页常常堆积到几十个甚至上百个，找页面全靠肉眼翻，效率极低。

标签堆积如山

打开的标签页越来越多，Chrome 自带的标签栏被压缩到只剩 favicon，完全看不清内容。

想找某个页面时，需要在几十个标签之间来回扫描，浪费大量时间。

关闭操作繁琐

想关闭同一网站的所有标签，只能一个个点，没有批量操作能力。

工具要么简陋要么臃肿

市面上的标签管理工具要么功能太简单，要么界面丑陋且加载缓慢。

03 / 技术架构

纯原生实现，
零外部依赖

不依赖任何第三方库，全部使用原生 Web 技术栈实现，保证极致的加载速度和稳定性。

Chrome Manifest V3

最新的扩展标准，Service Worker 后台脚本，性能更优、更安全。

Web Audio API

实时合成关闭音效，无需音频文件，纯代码生成声音。

CSS 变量主题系统

4 套主题通过 CSS 自定义属性切换，性能开销几乎为零。

Canvas 粒子动画

requestAnimationFrame 驱动的彩色纸屑效果，60fps 流畅运行。

chrome.storage.local

所有数据本地存储，主题、书签、历史记录均不上传服务器。

XSS 安全防护

所有动态内容通过 escapeHtml() 转义，防止脚本注入攻击。
