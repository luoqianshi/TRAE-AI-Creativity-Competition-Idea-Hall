MVP Features

五大核心功能

建词本 → 学单词 → 心动匹配 → 小组互动 → 看剧巩固，形成完整学习闭环。

P0 核心

自建单词本

完全自由地创建和管理你的单词本。支持手动添加、批量导入（CSV/文本粘贴）、从预置词库一键导入。免费用户最多 5 个单词本，按需付费扩展。

手动添加 批量导入 预置词库 分类管理
P0 核心

AI 短文串联与语法解析

勾选 3-10 个单词，AI 自动生成一段包含所有单词的连贯英文短文，高亮学习词汇。点击即可获得关键句型、从句、时态等语法标注和解释。

AI 生成短文 语法解析 自定义 API Key 难度可控
P0 核心

心动单词匹配

为任意单词匹配包含它的流行歌曲或经典电影台词。30 秒试听片段，一键跳转正版平台收听完整内容。情感共鸣，让记忆更深刻。

歌曲匹配 电影台词 试听片段 用户共创
P1 增强

智能字幕处理

上传 SRT/ASS 字幕文件，自动扫描并高亮生词。支持「完整学习字幕」和「生词句子过滤」两种模式，将看剧场景转化为学习场域。

SRT/ASS 支持 生词高亮 双输出模式 一键学习卡片
P1 增强

学习小组

创建或加入学习小组，分享心动匹配、AI 短文、字幕处理成果。点赞、评论互动，找到志同道合的学伴，让学习不再孤单。

公开/私密小组 动态发布 点赞评论 邀请码加入
