PROJECT OVERVIEW

什么是 AI 时间胶囊？

AI 时间胶囊是一款 AI 驱动的跨时空自我对话 Web 应用。用户用文字、语音或图片记录此刻的心情、想法和画面，设定一个未来送达时间（1年、5年、10年），AI 将自动生成独一无二的「时间胶囊」并封存。

到期那天，你会收到一封「来自过去的信」——更棒的是，AI 还会生成一份「时光对比报告」，对比你与过去的变化：哪些坚持了？哪些放下了？哪些成长了？

💡 核心理念：我们总在忙碌中忽略当下的感受，等到多年后回忆时，才发现记不清当时的心情。AI 时间胶囊帮你把这一刻永远封存，让未来的自己能穿越时光与过去对话。

🎯 核心用户18-40 岁，关注自我成长、有记录习惯的年轻人

CORE FEATURES

核心功能

✍️

多模态记录

文字、语音、图片，三种方式记录此刻。AI 自动整理成完整的时间胶囊

⏰

定时封存

设定 1年/5年/10年后送达，AI 自动封存，到期准时送达

📬

时光信件

到期收到「来自过去的信」，AI 用你当年的语气和风格重新呈现

📊

时光对比

AI 生成对比报告：哪些坚持了？哪些放下了？哪些成长了？

🔐

隐私保护

端到端加密，只有你自己能打开。支持指纹/面容解锁

💝

代际传递

给未来的孩子、伴侣、朋友写一封信，让爱穿越时光

TECH STACK

技术实现

🎨 前端框架React + Framer Motion（流畅动画）
🧠 AI 能力TRAE Work 生成代码 + GLM / DeepSeek 做风格迁移
📬 定时系统Node.js + node-cron（到期自动触发）
🔐 加密方案AES-256 端到端加密，密钥仅存于用户设备
💾 数据存储LocalStorage + 可选云端同步
🚀 部署方式静态 HTML / Vercel / GitHub Pages
DEVELOPMENT PLAN

开发路线

Phase 1 · 胶囊创建引擎

用 TRAE Work 搭建多模态记录系统，文字/语音/图片 → 统一胶囊格式

Phase 2 · 定时封存系统

实现时间设定 + 本地加密存储 + 到期提醒机制

Phase 3 · 时光信件生成

AI 读取历史记录，用用户当年的语气和风格重新呈现

Phase 4 · 时光对比报告

对比用户过去与现在的变化，生成可视化成长报告

Phase 5 · 分享与打磨

胶囊分享功能、响应式适配、动画流畅度优化
