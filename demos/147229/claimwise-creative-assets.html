01 / 痛点

走还是不走？
这笔账没人帮你算。

轻微事故后，车主面临的不是“要不要修”，而是“该谁出钱”。但保费上涨规则藏在合同细则里，销售只说省心的话。

PAIN 01
📊

规则不透明

NCD 系数、出险次数、连续投保年限如何联动影响保费？普通人根本算不清，保险公司也不主动告知。

PAIN 02
🤔

决策信息缺失

销售只说“走险省心”，不告诉你第二年涨多少。自费又怕被宰。两边都模糊，只能凭感觉。

PAIN 03
⏳

缺乏长期视角

一次走险的影响可能持续 3 年（NCD 等级回退）。用户只看眼前维修费，不知道长期总账可能更亏。

PAIN 04
💼

销售利益冲突

4S 店走险有佣金，倾向推荐走险。用户在不知情下被引导，做出对自己不利的决策。

03 / 决策算法

怎么算出“自费更划算”？

核心公式：比较“自费维修一次性成本”与“走险后未来 3 年保费累计上涨金额”，取较小者。

01

输入参数

保险公司、当前 NCD 等级、维修金额、是否本年已出险

input → { insurer, ncd, amount, claimed }
→
02

保费涨幅测算

基于保司规则表，模拟出险后 NCD 回退，计算未来 3 年保费变化

Δ = Σ(premium_t - premium_0), t∈[1,3]
→
03

对比与建议

若 Δ > 维修金额，建议自费；反之建议走险；接近时给出临界值

self_cost < claim_cost ⇒ 自费
说明：保费涨幅系数基于公开的银保监 NCD 规则与各保司商业车险条款手册整理。实际涨幅因保司、地区、车型略有差异，结果仅供参考，最终以保司报价为准。
04 / 目标用户

谁，在什么时候，
需要 ClaimWise？

覆盖三类典型用户，从新手到老司机，从自用决策到代理辅助。

新

新手车主

NEW DRIVER · 1–3 年驾龄

对车险规则几乎一无所知，事故后容易被销售带着走。需要的是“明确告诉我该怎么做”。

  • 地库蹭墙、剐蹭柱子后
  • 4S 店推荐“走险省心”时
  • 第一次面对保费上涨通知
熟

EXPERIENCED · 5+ 年驾龄

开车多年，NCD 等级较高（5 年未出险）。一次走险会让 NCD 大幅回退，更需要精算。

  • 评估是否动用保险
  • 多次轻微事故累积决策
  • 续保前回看历史出险影响
代

AGENT · 工具型用户

不只是省钱，
更是让规则透明。
