Features

三大核心功能

从「入库」到「对话」再到「联动」，构建完整的收藏品拟人化体验闭环。

01
多模态识别 · Agent 构建

拍照入库，一秒拟人

对收藏品拍照或上传图片，多模态模型自动识别物品类型、外观特征与文化背景，一键生成拥有独立人设、口头禅和知识库的专属 NPC Agent。

Vision LLM Agent Profile Persona Engine
02
流式交互 · 实时推理

跨越时空的对话

支持语音和文本两种交互方式。与你收藏的黑胶唱片聊聊七十年代的摇滚现场，让那只景德镇瓷器给你讲讲窑火的故事——每一次对话都是穿越时空的私密漫谈。

Streaming TTS RAG Memory Voice Clone
03
多智能体联动 · 杀手级创新

深夜聊天室

当多个收藏品 NPC 共处一室，它们会自主发起对话——手办吐槽黑胶唱片太老派，古董茶壶和潮牌联名款争论审美。你只需旁观，就能收获意想不到的快乐。

Multi-Agent Auto Dialogue Event Trigger
