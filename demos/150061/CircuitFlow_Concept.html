行业痛点

PCB 设计，新手有三难

传统 EDA 工具门槛极高，新手往往在第一步就放弃。这三个核心痛点，每年劝退无数硬件爱好者。

元器件选型头疼

数万种型号、几十种封装、上百页英文 Datasheet。面对空白画布，不知道选哪个、怎么配、去哪买。

全球超过 2000 万种元器件

原理图不会画

复杂的符号库、连线规则、网络标号……打开专业 EDA 工具，面对几十个面板，新手完全无从下手。

平均学习周期 6 — 12 个月

布线全靠运气

信号完整性、EMC 规范、阻抗匹配、差分等长。每一根走线都有讲究，板子打出来才发现问题。

平均迭代打样 3 — 5 次
解决方案

三步，从想法到电路板

不需要懂电路，不需要学 EDA。像跟工程师对话一样描述需求，Agent 帮你搞定全部。

1

描述需求

用自然语言告诉 Agent 你要做什么电路。支持中文，细节越丰富效果越好。

"我要一个低功耗蓝牙温湿度传感器，CR2032 供电，成本 20 元以内"

2

Agent 自主执行

自动拆解任务：并行搜索元器件、生成原理图、AI 智能布线、实时画布预览。

核心能力

六大核心能力

每一项能力都围绕同一目标设计——让电路设计前所未有的简单。

多模型自由接入

OpenAI、Claude、DeepSeek、豆包、文心……自带 API Key，想用谁就用谁，零厂商锁定。

智能 Token 优化

模型路由 + 上下文压缩 + 响应缓存 + 项目记忆。越用越省，最高降低 90% 成本。

AI 智能布线

不是传统 DRC 自动布线。AI 理解电路语义——信号类型、电源网络、高频要求——寻优决策。

元器件全景搜索

聚合嘉立创、Digi-Key、Mouser。自动比价、查库存、推替代料、拉取封装图纸和引脚数据。

可视化原理图 / PCB

画布实时渲染，拖拽交互，所见即所得。封装预览、3D 模型查看、引脚高亮标注。

全流程 Agent 自主执行

Agent 自主拆解任务、并行执行、自我纠错。投板/下单等关键节点人工确认，其余全自动。
