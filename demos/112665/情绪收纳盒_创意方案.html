创意名称 + 创意介绍

🎯 想解决什么问题

当代年轻人白天戴着社交面具强撑，晚上却陷入情绪内耗，却找不到合适、安全的方式表达或释放。情绪积压久了，轻则影响睡眠质量，重则引发心理健康问题。

💡 为什么想到做这个

我曾长期被深夜焦虑困扰，发现写下情绪比说出来更有效。但日记太耗时，社交平台倾诉又怕被评判。我需要一个"不说话也能被听见"的地方。

📱 产品形态

一款纯软件实现的微信小程序，通过「情绪标签选择 → 呼吸灯光反馈 → 温柔安抚文案/语音」三步闭环，为用户提供即时、私密、零压力的情绪疗愈体验。

🧪 核心交互

  • 选择情绪标签（😠😢😌😔😤）
  • 全屏对应颜色呼吸光效
  • 温柔安抚语音/文案
  • 情绪日历私密归档

�场景二：通勤途中

被领导批评后坐在地铁上，不想让同事看出异样。戴上耳机，打开小程序，选"😢 委屈"，蓝色光波慢慢扩散，耳边传来"你不必时刻坚强，难过也没关系"。

安抚文案示例

😠 愤怒 "你的愤怒是合理的。先深呼吸，让这股火慢慢变成保护自己的铠甲。"
😢 委屈 "被误解的感觉真的很不好受。但你的感受是真实的，不需要任何人批准。"
😔 疲惫 "你已经撑了很久了。今晚不必强迫自己积极，允许自己只是躺着。"
😤 焦虑 "焦虑说明你在乎。但此刻，你什么都不用解决，只需要被温柔对待。"
😌 平静 "这一刻的安宁很珍贵。好好享受它，你已经做得很好了。"
🫠 崩溃 "碎裂也没关系。你不需要时刻完整，裂缝里也会有光照进来。"

价值与意义

🌍 社会价值

据《中国国民心理健康发展报告》显示，18–34 岁青年群体焦虑检出率居高不下。情绪收纳盒以零门槛、零社交压力的方式，为年轻人提供一个安全的情绪出口，有助于降低心理问题隐蔽化风险，推动"情绪健康日常化"的公众意识觉醒。

💰 商业价值

可延伸为情绪管理工具矩阵：企业员工关怀计划（EAP）合作、文创品牌联名、情绪数据匿名化研究等。差异化定位在"不解决问题，只陪伴"，填补了市面上"功利化情绪管理"的空白，具有独特的品牌辨识度和用户黏性。

技术方案概览

🛠️ 前端技术栈

微信小程序原生 WXML / WXSS JavaScript Canvas 动画

🗄️ 数据存储

LocalStorage wx.setStorageSync 不上传云端 完全私密

🎨 核心实现

  • Canvas 绘制全屏呼吸光效动画
  • InnerAudioContext 播放安抚语音
  • wx.createAnimation 实现过渡动效
  • 日历组件实现情绪归档视图

📐 设计原则

  • 极简主义：每个页面只有一个核心操作
  • 无打扰：不使用红点、弹窗、推送
  • 暗色主题：保护深夜使用者的眼睛
  • 用完即走：不强迫停留，不设计日活指标
