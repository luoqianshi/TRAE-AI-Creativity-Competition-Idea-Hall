语法课从术语讲起

主谓宾定状补……学生听不懂、记不住、用不上。术语本身成了学习的门槛，而非工具。

背了很多单词却写不出完整句子。单词量和表达能力之间有一道鸿沟，传统教学无法弥合。

长难句无从下手

遇到长难句不知道怎么拆，写作只能套模板。缺乏系统化的拆解方法，阅读和写作都受困。

核心创新 — 教学方法论
用直觉替代术语，用方法替代死记硬背

"连接词是胶带"教学法

  • 核心理念：把所有语法规则简化为"胶带"概念 — 连接词就是把句子片段粘在一起的胶带
  • 并列胶带（FANBOYS + 标点）：连接并列成分，语序不变
  • 从属胶带（各从句连接词）：连接主从句，可能变序

"三长两短一并列" 长难句拆解法

  • 三长：定语从句 / 名词性从句 / 状语从句 → 加圆括号 ( )
  • 两短：介词短语 / 非谓语动词 → 加方括号 [ ]
  • 一并列：and / but / or → 切断句子分界
  • 去掉所有括号内容 → 剩下句子主干，结构一目了然

词根树 + 介词核心含义发散

  • 一个词根串出一族词：dict → predict / dictionary / dictation
  • 每个介词锁定一个核心空间含义，发散出多个引申义
  • 韵脚词自带记忆法：pool / fool / tool / cool
