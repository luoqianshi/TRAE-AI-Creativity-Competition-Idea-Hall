// 01

看不懂，真的很痛。

当一款工具只有英文界面、文档只有英文版本、报错信息全是英文——普通用户被无声地挡在门外。

PROBLEM 01
🌐

外语软件像天书

专业软件、小众工具、内部系统——99% 没有中文。汉化补丁永远慢一拍，而工作不能等。

PROBLEM 02
📸

截图翻译繁琐

截屏 → 切到翻译 App → 等待 → 切回——一次操作 30 秒，错误率高，思维频繁中断。

PROBLEM 03
🔀

上下文彻底断裂

翻译结果脱离原图，看一句切一句，无法理解"这个按钮在界面哪里""这句对应哪个选项"。

// 02

四个特性，一气呵成。

从识别到翻译，每一步都为了一个目标：让翻译这件事消失在背景里。

🎯
01

即时光学识别

接入 PPOCRv6 引擎，对屏幕任意区域逐帧识别，文字坐标精确到像素级。

30 FPS · 0.3s/帧
🧠
02

端侧大模型翻译

本地 LLM 推理，懂 UI 术语、懂技术 jargon、懂上下文，翻译有"语感"。

03

纯本地，零上传

Offline · 隐私零泄露
⚡
04

几乎无感延迟

识别 + 翻译 + 叠加，整链路控制在 1 秒内。配合屏幕变化自动触发，无需手动。

Δt < 1.0s
