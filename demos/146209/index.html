// 02 · PAIN POINTS

没有它，你正裸奔在密码丛林

现代人平均拥有 80+ 个在线账户，而大多数人仍在用三种方式"管理"密码——每一种都暗藏风险。

01

密码混乱综合症

不同账户必须用不同密码——这早已是安全常识。可现实是：你把它们写在便签、记事本、聊天记录里，每次登录都在大脑里翻箱倒柜。三秒之内找到正确密码，几乎不可能。

02

明文存储的定时炸弹

Excel 表格、TXT 文件、备忘录——这些"明文密码本"一旦被偷看、被同步到公共盘、被恶意软件扫描，你所有账户的钥匙就一次性拱手让人。一次疏忽，全盘崩溃。

03

云端托管的不信任

市面上的密码管家大多托管在云端。一旦服务商被攻破、被 subpoena、被收购改条款，你的全部密码就成了别人服务器上的一行 SQL。主权不在你手里，安全就是空话。

// 03 · CORE MECHANISM

三件事，构建你的主权密码金库

密匣只做三件事——分类、加密、备份。每一件事都做到极致，把密码主权彻底还给你。

/ 01

分类管理 Categorize

按场景自定义分类：工作、个人、财务、社交、开发、家庭……每条密码带标题、用户名、URL、备注、强度评估，结构化沉淀而非散落堆积。

  • 分类层级 无限自定义
  • 字段结构 标题 / 账号 / URL / 备注
  • 强度检测 实时评估
  • 快速检索 全文模糊匹配
/ 02

7z 加密归档 Encrypt

密码库不是数据库文件，而是一个 AES-256 加密的 .7z 压缩包。即使被复制、被上传、被截获，没有主密码也无法解开一字节。

  • 加密算法 AES-256
  • 归档格式 .7z / .zip 兼容
  • 密钥留存 仅本地内存
  • 残留清理 导出后擦除明文
/ 03

多处备份 Replicate

同一个 vault.7z，复制到 U 盘、网盘同步目录、NAS、第二块硬盘——一处损坏，他处还原。备份主权在你手中，不依赖任何单一服务商。

  • 备份目标 任意路径
  • 多端同步 U盘 / 网盘 / NAS
  • 版本命名 时间戳自动
  • 还原方式 选文件 + 主密码
