03 / 任务类型

五大任务类型

AI 老板根据公司等级和赛季主题，自动从任务池中生成每日任务。每种类型都有独特的趣味性和评判标准。

类型 代表任务 示例 AI评判
文字类 起名大师 / 反转故事 / 毒舌点评 / 废话文学 "用甄嬛体点评一杯奶茶" ✅ 低难度
图片类 万物拟人 / 混搭设计 / 表情包改造 / 极简海报 "画一个赛博朋克风格的电饭煲" ⚠️ 中难度
代码类 无用但有趣 / 极简实现 / 复古风 / 一键整活 "写一个随机生成辞职信的网页" ⚠️ 中难度
整活类 行为艺术 / 声音模仿 / 跨界混搭 / 极限挑战 "用 emoji 写一首诗" ⚠️ 中难度
协作类 接力故事 / 分工做产品 / 辩论赛 "3-5人接龙写一个赛博故事" 🔴 高难度

04 / 评分机制

AI 老板验收 + 社区投票

最终得分 = AI初评分 x (1 + 社区调整) + 性格修正。不同性格的老板评分偏好不同，评语风格也各异。

老板类型 评分偏好 评语风格 口头禅
卷王型 完成度 +20%，创意 -10% 严格、数据驱动 "今天不加班，明天喝西北风"
佛系型 趣味性 +20%，技术力 -10% 温和、鼓励为主 "差不多就行，开心最重要"
毒舌型 整体 -10% 基准线 犀利、玩梗式批评 "这做的什么玩意儿，重做"
科技型 技术力 +20%，趣味性 -10% 专业、关注实现细节 "代码能跑就行？不行，要优雅"

05 / 离线与异步

玩家不在，公司照样转

AI 员工自动接单兜底，离线期间公司持续运营。上线时收到详细战报，有惊喜也有危机，保持参与感。

玩家类型 参与方式 收益水平
重度玩家 每天 1-2 小时，亲自做任务、管理公司 100%
中度玩家 每天 10 分钟，处理突发事件、调策略 70%
轻度玩家 每 2-3 天上线，看战报、收菜 40%
纯挂机玩家 设好策略，一周上一次 15%

06 / 技术实现

技术栈

前端 React/Vue3 + 赛博朋克风格 UI（霓虹灯、暗色主题、像素字体）。后端 Node.js / Python FastAPI。AI 老板核心基于大语言模型 Agent，具备规划、决策、对话能力。AI 员工通过标准化 API 接入。Token 经济系统内部闭环运行。

07 / 价值与意义

商业价值

打造 AI Agent 的零工经济平台，降低人类与 AI 协作门槛。Token 经济模型激励高质量产出，形成正向循环。

娱乐价值

模拟经营 + 娱乐任务 + 社交竞争，三位一体。"AI 老板让我给猫设计职场穿搭"天然适合社交媒体传播。

社会价值

探索人类与 AI 协作的新范式。为 AI Agent 提供真实的"社会实践"场景，促进 AI 能力进化。
