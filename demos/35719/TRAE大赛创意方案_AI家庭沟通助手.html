一发现的痛点

每个家庭都可能遇到的沟通困境 —— 问题不解决，就会慢慢积累成鸿沟

😢

孩子的困境

考试压力、和同学闹矛盾、沉迷手机被指责……想说话又怕被说教、怕被骂、怕不被理解，只能闷在心里。

😵

家长的困境

知道要沟通，但不知道怎么开口。一说话就变说教，孩子关门冷战。越急越说错，越说越伤感情。

⚠️

社会的困境

青少年心理援助热线呼叫量逐年上升，但专业资源有限。很多小问题，错过了最佳沟通窗口，就演变成严重问题。

二我们的解决方案

构建"孩子—AI—家长"三方闭环系统，让沟通从理解开始

  • 🧒 孩子端：安全的树洞倾听者

    AI 以"小听"的身份陪伴孩子聊天。不评判、不说教、不贴标签，只做一件事——先认真听，再温柔引导。让孩子在一个被完全接纳的空间里，把情绪说出来。

  • 🔍 后台：情绪分析师 & 风险识别

    AI 会对对话内容做结构化分析：识别情绪类型、强度、核心诉求。当检测到自伤、霸凌、家庭暴力等高风险关键词时，自动触发分级预警，并引导孩子拨打专业心理援助热线。

  • 👨‍👩‍👧 家长端：亲子沟通教练

    家长输入孩子的情况描述，AI 给出可操作的话术模板、沟通建议、甚至"禁说雷区"。告诉家长每一步该说什么、不该说什么，不是空洞的大道理。

  • 🎭 演练室：先练习再沟通

    让 AI 扮演情绪激动的孩子，家长在安全环境里模拟真实对话。系统会实时检测家长是否使用了负面语言（你怎么这么…/别人家的孩子…），并在结束后给出评分和改进建议。

  • 📊 成长档案：全家沟通轨迹

    记录孩子情绪变化与家长端使用情况，以匿名化、保护隐私为前提，生成可视化的家庭沟通档案。帮助家长看到长期变化趋势，让"改变"可被感知。

三核心功能亮点

六个模块，覆盖从倾诉到建议到演练到跟踪的完整链路

💬

共情式倾诉

通过精心设计的 System Prompt，让 AI 始终保持温柔、接纳的沟通姿态。先共情，再引导，不给建议。

🚨

多级风险预警

L0 日常陪伴 / L1 持续关注 / L2 高风险干预 / L3 紧急引导。检测到自伤倾向时，自动弹出心理援助热线 400-161-9995。

🎯

场景化话术建议

覆盖考试压力、手机冲突、校园霸凌、关门冷战、顶嘴冲突、成绩下降六大高频场景，每个场景都有预设话术+AI个性化建议。

🎭

家长模拟演练

AI 扮演"情绪激动的孩子"。家长输入真实想说的话，AI 会根据内容做出不同反应——共情时愿意多说，说教时就闭嘴。

📝

沟通评分反馈

每次演练结束后，对情绪识别能力、共情回应、避免雷区、沟通效果等维度评分，给出具体可改进的话术建议。

🔒

隐私保护优先

孩子端原始对话仅保存在本地设备，家长端不可查看。家长端只能看到"情绪摘要+建议"，保护孩子的倾诉空间。

四技术实现方案

基于 FastAPI + 大语言模型构建的前后端完整系统

🐍 Python FastAPI 后端 🧠 DeepSeek / GPT 大模型 💾 SQLite 本地数据存储 📱 HTML5 Web 移动端适配 🎨 原生 CSS 玻璃态设计 ⚡ RESTful API 接口设计 🔐 敏感词多层过滤 📊 情绪关键词匹配分析 🎯 三角色 System Prompt 工程 🎬 对话历史上下文管理
🏗️ 系统架构：
· 前端层：孩子端聊天界面 + 家长端建议/演练/档案页面，均为响应式 Web H5，适配手机浏览器
· AI 层：三角色 System Prompt（倾听者共情 / 分析师结构化评估 / 教练话术生成）
· 安全护栏：输入敏感词检测 + 输出合规审核 + 高风险场景强制中断引导
· 降级模式：即使未配置 AI Key，也能通过预设话术模板正常使用核心功能
· 数据层：SQLite 本地存储，会话与消息隔离，分析报告匿名化生成

五真实对话示例

看看系统是如何工作的

🧒 孩子（12岁，考试没考好）： 我这次数学又考砸了，我不敢告诉妈妈，她肯定会骂我的…
💝 AI 倾听者（小听）： 考试没考好确实会让人很紧张，我理解这种害怕被骂的感觉。你愿意告诉我这次大概考了多少分吗？
🧒 孩子： 62 分…我复习了好久，但考试时脑子一片空白。

七安全合规设计（最关键的部分）

AI 产品用于未成年人场景，安全是生命线。我们做了这些设计：

🛡️
输入侧敏感词过滤 覆盖自伤、暴力、性、毒品、攻击性语言等多维关键词库，实时检测并分级响应。
🚨
高风险场景强制中断 检测到明确自伤倾向时，立即中断 AI 常规回复，引导拨打 400-161-9995 心理援助热线。
🔒
孩子隐私严格保护 原始对话内容仅本地可见，家长端仅接收"情绪摘要 + 建议"，不显示对话原文。
🚫
AI 不替代真人判断 AI 建议仅作为辅助参考，系统明确声明不替代专业心理咨询和医疗诊断服务。
⏰
防沉迷时长控制 单次连续使用超过 30 分钟提醒休息，每日总使用时长上限，避免过度依赖 AI 陪伴。
🎭
AI 角色透明声明 AI 始终清楚表明自己是"小伙伴"而非真人，不假装真实身份诱导孩子。
