01

创意名称与介绍

PROJECT IDENTIFICATION

创意名称：交通事故现场照片测距小工具（TrafficScene Measure）

解决什么问题：交警使用无人机拍摄交通事故现场俯拍照片后，往往需要在照片上快速测量刹车痕长度、车辆间距、散落物距离等关键尺寸。传统方式需要回到办公室使用 CAD、PhotoModeler 等专业软件进行处理，流程繁琐、门槛高、时效差。

产品形态：一个纯前端、可离线运行的 Web 小工具（单 HTML 文件）。交警只需在电脑或平板上打开网页，导入无人机照片，选取画面中已知实际长度的两个点作为基准，即可在照片上直接测量任意两点之间的距离，并支持标注文字、尺寸、线段、形状及图片旋转裁剪等常用图像处理操作。

核心创新点：将「单张影像比例测距」与「警务现场标绘」整合到一个零安装、零部署的轻量工具中，降低交警使用门槛，提升现场勘查效率。
02

目标用户与痛点

TARGET USERS

一线交通警察、事故勘查民警、保险公司定损员、道路养护与应急救援人员。

OPERATIONAL WORKFLOW

无人机现场取证

事故发生后，交警使用无人机在事故现场正上方拍摄高清俯拍照片，获取完整现场俯视视角。

导入照片标定基准

将照片导入工具，选取画面中已知实际长度的参照物作为基准尺寸。

现场测量与标注

在照片上直接测量刹车痕、碰撞点、车辆位置等关键距离，生成标准化勘查示意图。

CURRENT PAIN POINTS

  • 专业测距软件安装复杂、学习成本高，基层民警难以快速上手。
  • 事后回到办公室处理照片，无法在现场快速完成初步勘查。
  • 现有工具多为国外软件，中文支持差，且需要付费授权。
  • 标注与测距分离，需要切换多个工具完成示意图制作。
03

价值与意义

效率价值

将原本需要 30 分钟以上的现场照片处理流程压缩到 5 分钟以内，显著缩短事故勘查时间，减少道路拥堵。

社会价值

提升交通事故处理的规范性与透明度，为责任认定提供可视化、可量化的辅助依据，助力智慧交管建设。

实用价值

纯前端实现，无需服务器、无需联网、无需安装，可在公安内网或离线环境中直接运行，符合警务数据安全要求。

可扩展价值

核心能力可扩展至保险定损、工程测绘、消防救援等多个需要影像比例测距的社会服务场景。

04

核心功能设计

基准标定测距

选取图片上已知实际距离的两点作为基准，自动计算像素比例尺，测量任意两点距离。

多维标注工具

支持文字标注、尺寸标注、线段、箭头、矩形、圆形及自定义形状绘制。

图像变换

支持图片旋转、裁剪、水平翻转、垂直翻转，适配不同拍摄角度。

导出与存档

一键导出标注后的高清示意图，支持 PNG/JPG 格式，便于存档与上报。

自定义形状

内置简易画板，用户可自行绘制常用交通形状并保存到形状库复用。

本地运行

所有图像处理在浏览器本地完成，不上传任何数据，保障现场照片安全。

IMPLEMENTATION NOTES

  • 比例尺计算：通过基准线段的像素长度与实际长度，建立 pixel ↔ meter 映射关系。
  • 坐标变换：处理图片旋转、翻转、缩放后的坐标映射，确保标注与测距同步。
  • 标注系统：基于 Canvas 的分层绘制架构，实现标注对象的增删改查。
  • 形状库：通过小型画板收集用户绘制路径，序列化为可复用形状数据。
