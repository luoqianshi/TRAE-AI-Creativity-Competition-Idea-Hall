# 产品需求文档 (PRD) — 奇想小剧场

> 文档版本：v1.0 · 适用范围：MVP 阶段 · 文档语言：中文

---

## 1. 产品概述

「奇想小剧场」是一款专为 **1–6 岁儿童** 家庭打造的纯互联网 Web 应用（移动端优先）。孩子通过超大按钮模式独立操作，家长一次性输入关键词或主题，AI 即时生成专属故事并以"父母声音"风格的柔和女声朗读，把"再讲一个"的无限循环从家长身上解放出来。

- **核心问题**：解决家长"被孩子缠着讲故事"的高频刚需与精力枯竭
- **目标用户**：1–6 岁孩子的家长（操作端）+ 1–6 岁孩子（消费端）
- **产品灵魂**：**斯堪的纳维亚童书插画感**。像翻一本安静的北欧绘本——米白底色、淡裸粉与雾蓝点缀、衬线圆角字体、手绘水彩风的细线装饰。没有花哨的糖果配色，没有"AI 智能"营销词，只有克制的温度、留白和故事本身的呼吸感。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 家长 | 邮箱 + 密码 | 配置孩子档案、设定每日听读时长、查看听读报告、输入关键词生成故事 |
| 孩子 | 无登录（由家长代为切换） | 大按钮模式浏览推荐故事、播放/暂停/拖动进度条、点击闪卡彩蛋 |

> 角色切换通过「家长中心」入口 + 4 位 PIN 码隔离；孩子主界面禁止任何文字输入。

### 2.2 功能模块

| 优先级 | 模块 | 描述 |
|--------|------|------|
| P0 | 登录注册 | 家长邮箱+密码；首次登录跳转 onboarding |
| P0 | 引导配置 | 录入孩子昵称/年龄段/喜好主题 |
| P0 | 儿童主界面 | 大按钮模式：推荐故事卡片 + 中央"听故事"巨按钮 |
| P0 | 故事播放 | 音频播放、进度条、闪卡彩蛋、"换一个"+"我要指定" |
| P1 | 家长管控 | PIN 码解锁、今日听读报告、每日时长限额、定时关闭 |
| P1 | 声音复刻 | 预留接口，UI 演示"正在使用妈妈的声音" |
| P0 | 故事生成 API | 根据年龄段+主题生成 300–500 字故事 |
| P0 | 语音合成 API | OpenAI TTS 转 MP3，存到本地 public/audio |
| P0 | 推荐 API | 拉取最近未听/初始预设故事 |

### 2.3 页面详细

| 页面 | 路由 | 模块 | 功能说明 |
|------|------|------|----------|
| 登录 | `/login` | 登录表单 | 邮箱+密码注册/登录切换；首次登录后跳 `/onboarding` |

## 3. 核心流程

### 3.1 家长首次路径
```
打开应用 → /login 注册 → 跳转 /onboarding → 填写昵称+年龄段+主题 
  → 进入 /home → 中央点击"听故事" → /player/[seed_id] 直接播放预设故事
  → 听完后点"换一个"或"我要指定" → /api/generate-story → /api/text-to-speech 
  → 返回新 story_id → 自动跳转新 /player/[story_id]
```

### 3.2 孩子独立路径
```
/home → 看到大 Emoji 封面 → 点击中央"▶ 听故事" → 进入播放 → 听故事 
  → 闪卡弹出 → 点击闪卡放大 → 播放结束 → "换一个"再听
```

### 3.3 家长管控路径
```
/home 底部点击 🔒 → 弹出 PIN 输入 → 输入 0000 → 进入 /parent 
  → 查看今日听读时长 → 调整每日限额 / 定时关闭 
  → 退出后回到 /home
```

## 4. 用户界面设计

### 4.1 设计风格

**斯堪的纳维亚童书插画感**——克制、温柔、有呼吸感

- **底色系统**：奶油白 `#F8F4EC`、淡裸粉 `#F2E2D5`、雾蓝 `#D7E3EC`、米杏 `#EDE3D2`
- **强调色**：暖橙陶土 `#D87B5A`（仅用于核心 CTA"听故事"）、墨绿 `#4F6F5C`（次级按钮）
- **文字色**：墨黑 `#2A2A2A`、铅笔灰 `#7A7268`
- **字体系统**：
  - 衬线圆角（儿童内容）：`Fraunces` / `ZCOOL XiaoWei` / `Noto Serif SC` fallback
  - 商务无衬线（家长/UI）：`Inter` / `Noto Sans SC` fallback
  - 严格禁用 Comic Sans、Arial、system-ui 默认堆栈
- **圆角**：卡片 16px、按钮 24px、PIN 输入 12px；中央"听故事"按钮 9999px（圆形）
- **装饰元素**：手绘风 SVG 细线（云朵、星星、月亮轮廓），1px 浅米色描边，绝不用实色块 emoji 墙
- **图标**：lucide-react；底部导航允许使用 Emoji 🏠 🔒（孩子可识别）

### 4.3 响应式

- **设计基线**：移动端优先（375×667 iPhone SE 起），平板（768×1024 iPad）放大到 1.2 倍
- **断点**：`sm: 640px` / `md: 768px` / `lg: 1024px`
- **触控防误触**：儿童主界面所有可点击元素 `touch-action: manipulation`，禁止双击缩放
- **按钮最小尺寸**：64×64px（PRD 要求严格执行）
- **最大宽度**：移动端 100vw，平板及以上居中 max-width 480px（模拟手机屏幕）

### 4.4 动效细节

| 场景 | 动效 |
|------|------|
| 页面进入 | 整体 fade-in 200ms + 轻微 y:8→0 |
| 听故事按钮 hover | 阴影从 24px 扩散到 32px（200ms ease-out） |
| 听故事按钮点击 | scale 1→0.95→1（100ms） |
| 闪卡出现 | opacity 0→1 + scale 0.8→1（300ms cubic-bezier(0.34, 1.56, 0.64, 1)） |
| 闪卡点击 | scale 1→1.3 → 0（400ms 缓出） |
| 加载动画 | 旋转星星 1.2s linear infinite，配合"小精灵正在编故事..."文字 0.5s 闪动 |
| PIN 错误 | 整个 PIN 组 shake 6px × 3 次 200ms |

## 5. 内容安全与隐私

- **AI 提示词硬性约束**："故事中禁止出现暴力、恐怖、悲伤结局，必须包含积极向上的价值观。语言适合 1-3/3-4/4-6 岁儿童。"
- **PIN 码**：bcryptjs 哈希存储，默认 0000
- **音频缓存**：本地 `public/audio/` 目录（SQLite 模式下），文件名用 `story_<id>.mp3`
- **离线备用**：3 个预置故事文本存 `localStorage.fantasy_theater_offline_stories`
- **家长后台隔离**：`/parent` 路由必须通过 PIN 解锁组件，未解锁时不返回任何 children 设置数据
