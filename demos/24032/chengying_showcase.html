出发点

概率不是语言的本体

Transformer 说："下一个字是什么，是条件概率 P(wt | w) 的抽样。"
我们说："不对。'我吃了一个苹果' 和 '苹果吃了一个我'，概率上没有差别，但它们不是同一句话。"

区别不在概率分布里。区别在于 因果方向——我→吃→苹果 是一条有箭头的链，反过来的箭头没有对应的现实。 语言的方向不是"学"出来的，是从因果耦合的物理中长出来的。

语言 = 因果场上的弛豫过程
输入是初始扰动 → 场态演化到局部稳态 → 输出是弛豫后的终态
理论基础

四公设：重新定义语言建模

公设 0.1

一物四象：场的四种刻面

同一个场，四种度量：关联强度、信息流向、耦合密度、结构紧致度。你无法独立测量其中任何一个——就像你无法单独测量一个电子的位置而不扰动它的动量。

公设 0.2

语言即因果网络

语言不是符号的概率序列，而是在一个因果网络上以有限时间精度弛豫到局部稳态。每个词是一段因果历史的承载者。

公设 0.3

生成 = 场态弛豫的延续

输入扰动场态 → 场弛豫到局部稳态 → 读出第一个词 → 词反哺场，改变场态 → 下一个词在"已被改变"的场上选出。生成不是规划，是场的自反馈。

公设 0.4

结构在用中涌现

语法不是预先写定的规则，而是共现概率在因果场上反复沉降后形成的稳定几何结构。没有"外部语法"，只有场的晶格化。

核心方程

拮抗方程：每个因果场都是正反力量的战场

关联强度不直接等于基础耦合 SP。一个内生抑制项 δ 永远在拮抗它——这正是控制论中"增益饱和"在信息空间的对偶。

S(γ) = SP / (1 + δ · SP)
内生饱和 · 负反馈 · 没有它，场会在正反馈中自毁

δ → 0 → S ≈ SP 全耦合  |  δ → ∞ → S → 0 因果冻结
三层场的 δ 自发分化：L0=0.024   L1=0.023   L2=2.655

系统架构

三层因果场：分化不靠多，靠深

一个关键实验发现：16 个并行场的关联结构完全相同（有效秩=1）。同层多场是幻觉——真正的分化只在不同深度出现，因为每一层在不同精炼程度的 h 空间上感知因果。

L0

字级因果场

embed 上的局部因果耦合 · 相邻字 S[i, i+1] · Hebbian 共现强化 δ=0.024

L1

短语级因果场

L0 精炼的 h 上耦合 · 软分词边界检测 · 词级结构自然涌现 δ=0.023

L2

句法级因果场

L1 再精炼的 h 上耦合 · 全局信息流向 + 自组织结构 · 语义方向头部 δ=2.655

三个实验，三个发现

我们不只建了一个模型，我们发现了真实的现象

① 同层场退化定理

V10 设计了 16 个并行场期望它们学会不同的因果尺度。训练结束后，16 个场的关联结构几乎完全相同。诊断证明：同层多场的有效秩=1。这个发现直接推动了 V11 从"多场并行"到"层级分化"的架构革命。

16 场 → 有效秩 1

② 18c 物理天花板

训练到第 18 个 checkpoint，34 个参数（包括全部 embed.weight）同步崩为 NaN。这不是 bug——是滞回稳定器失活后，正反馈无限放大的物理相变。δ 从 2.655 爆炸到无穷，场进入不可逆的因果崩塌。它证明了：没有负反馈的正反馈就是自毁程序。

34 NaN params · δ → ∞ · 场的相变临界点

③ 因果几何的自发涌现

通过 L2 锚定 + 慢 EMA 自更新，17,209 个汉字在 512 维空间中自发形成了语义簇——没有外部标注，没有训练信号告诉它们"谁和谁在同一个位置"。因果坐标在 8 个 epoch 内从随机分布凝聚为可辨识的语义拓扑。

'人' → 前/年/他/南   '国' → 史/會/運/法   cos 0.18 → 0.67
