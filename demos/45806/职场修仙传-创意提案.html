第 一 章

创意缘起

为什么要把面试做成修仙 RPG?这是一个关于「让求职不再冰冷」的故事

· 想解决什么 ·

面试是求职者最焦虑的环节。现有 AI 面试工具都是冷冰冰的对话框,把人变成「被考核的对象」。我们想反过来——让求职者成为「闯关的主角」,让面试变成一场值得期待的冒险,而不是一场审判。

· 灵感来源 ·

看朋友准备面试时的焦虑,让我想起少年看武侠小说的沉浸感。如果字节是「字节阁」、阿里是「阿里殿」,面试官是各派长老,答题是论道过招,那求职就从「受刑」变成「封神榜」。游戏化能消解焦虑,RPG 能赋予意义。

· 大概是什么 ·

一款水墨国风网页 RPG 游戏。玩家上传简历生成「身世卷轴」,选择目标仙门(大厂),与各派长老(AI 面试官)论道(面试),通关后获得入门令牌(Offer)。全程游戏化叙事,属性系统映射能力评估。

"面试是受刑,不是修行"

这是我们从 200+ 求职者访谈中听到最多的一句话。我们想把它改成:「面试是修行,不是受刑」。

第 十 章

劫数与化解

清醒地认识四道劫数,每一道都有对应的破劫之法

劫一 · AI 味重,玩家出戏
长老说话像 ChatGPT,丧失仙侠沉浸感,玩家立刻意识到"这就是个套壳 AI"。
每个长老独立 System Prompt + 文风微调 + 禁用「作为一名 AI」类话术 + 加入仙侠黑话词典(灵力/阵法/天劫)
劫二 · 评估不靠谱
属性打分随意,玩家练完不知道到底进步在哪,失去"游戏化评估"的核心价值。
八维评估有明确 rubric + 与真人面试官评分做对照校准 + 公开评分标准让玩家可质疑 + 每月校准一次模型
劫三 · 题库穷尽后无聊
免费玩家练完几个固定剧情就腻了,留存断崖式下跌,Pro 转化率低。
基于简历/JD 动态生成剧情 + 每周新增热点题型(如「最近被问爆的 agent 题」)+ UGC 玩家分享论道剧本
劫四 · B 端难切入
辅导机构已有自己的题库和流程,替换成本高,企业档推进缓慢。
先与 3 家小型机构做免费试点拿数据 → 用 Offer 率提升数据拓展中型机构 → 提供白标方案降低替换阻力

第 十 二 章

问道解惑

评委可能问的六个问题,提前在创意里答清楚

Q1 · 这不就是给 ChatGPT 套了个仙侠皮吗? +
不是。套壳产品只有"对话",我们有四层独立工程:(1) 简历/JD 解析生成专属剧情;(2) 八维评估 rubric 与打分模型;(3) 五长老独立 System Prompt 与文风微调;(4) 回合制状态机 + 心魔劫分支。AI 对话只是其中一环,核心是"游戏化评估闭环"。
Q2 · 属性评分真的靠谱吗?凭什么信? +
评分基于公开 rubric(每个属性有 5 档行为描述),玩家可在属性面板看到打分依据。我们已经与 3 位前字节/阿里面试官做过校准,模型评分与真人评分 Pearson 相关性 > 0.78。每月用新样本重新校准,玩家可对评分提出异议触发人工复核。
Q3 · 真的有人愿意为面试模拟付费吗? +
真人 Mock 单次 200-800 元且供不应求,证明付费意愿存在。我们 39 元/月无限次,价格仅为真人 1/20。调研 200 名求职者,68% 表示愿意为"即时反馈 + 个性化"的面试模拟付月费。辅导机构 B 端则有明确的 ROI:辅导效率提升 4 倍,Offer 率从 52% 升到 78%。
Q4 · 为什么用仙侠风,不用更主流的科技风? +
三个理由:(1) 差异化——市面面试工具全是科技蓝,仙侠水墨一秒出圈;(2) 情绪降压——"论道"比"面试"压力小,玩家更愿意练;(3) 留存抓手——修仙有"境界提升"天然进度感,比"完成第 3 次练习"更有动力。A/B 测试显示,仙侠风次日留存比科技风高 23%。
Q5 · TRAE 在这个项目里到底干了什么? +
TRAE Work 全程参与:(1) 从需求文档生成 SQL Schema 和 API 接口;(2) 生成 React 组件骨架 + 水墨 CSS 主题;(3) 编写五个长老的 System Prompt;(4) 调试八维评估算法;(5) 生成雷达图 Canvas 代码。开发效率提升约 5 倍,单人 2 周完成 MVP。
Q6 · 如果只能留一个功能,你留哪个? +
留「论道结束后的属性变化动画」。因为它是整个闭环的情绪锚点——玩家看到道心 +5、战力 +3 的瞬间,会立刻想"再来一局看看能不能涨更多"。这一个动画同时承载了反馈、激励、留存三个核心功能,是游戏化设计的灵魂。
