7 Stage 流水线 · 专业级视频生成引擎

从代码分析到视频合成，像一条工业流水线，每个 Stage 只负责一件事，做到极致。

1
INPUT
Code Analyzer ｜ 代码结构分析
对输入代码做静态分析：AST 语法树、CFG 控制流图、函数调用关系、变量依赖、递归深度、复杂度初步估算。支持 Python/JS/Java/C/C++/Go 六种语言。
ASTCFG6 语言支持

▼

2
CLASSIFY
Code Type Classifier ｜ 算法自动分类
10 大类 · 70+ 子类型自动识别：排序 / 查找 / 递归分治 / 动态规划 / 贪心 / 图论 / 回溯 / 字符串 / 数据结构 / 高级专题。一个代码可命中多个标签。
10 大类70+ 子类型多标签

▼

3
PLAN
Pedagogical Planner ｜ 教学策略规划
根据算法类型 + 用户水平（BEGINNER/INTERMEDIATE/ADVANCED），自动选择最佳教学节奏、生成生活化类比、标注常见误区、生成学习目标。
类比库误区检测难度自适应

▼

4
SCRIPT
Teaching Script Generator ｜ 教学脚本生成
将"代码"翻译成"人话"。逐段生成 narration 文案 + animation_hint 场景提示。避免逐行念代码，改用自然语言解释思想。内置文案优化器。
JSON 脚本文案优化

▼

5
STORYBOARD
Storyboard Generator ｜ 分镜 & 场景调度
选择对应 Manim 场景库：Array / LinkedList / Stack / Queue / Tree / Graph / HashTable / DPTable 等。自动匹配最合适的示例数据、选择镜头运动。
100+ 场景库示例选择引擎镜头调度

▼

6
TIMELINE
Timeline Planner ｜ 音频驱动 · 时间轴规划（核心创新）

🎓 PERSONALIZATION · 个性化教学

3 档难度自适应 ｜ 对谁都能讲到位

同一段代码，对初学者多类比特写，对进阶者聚焦思想，对高手直击优化技巧。不用你选，AUTO 模式自动推断。

● LEVEL 1
🌱 初学者 BEGINNER
适合：零基础 / 入门 / 考研一轮 / 算法小白
  • 多类比、多生活化举例
  • 慢节奏，动画逐帧走
  • 每一步都讲"为什么"
  • 生活化类比：栈=叠盘子、递归=套娃
  • 基础概念不省略，从零讲起
  • 常见误区特别警示动画
● LEVEL 2 ⭐ DEFAULT
🚀 中级 INTERMEDIATE
适合：有基础 / 刷题中 / 课程复习 / 项目代码学习
  • 适度讲解，重点突破
  • 省略基础概念，聚焦核心逻辑
  • 中等节奏，典型步骤详细讲
  • 复杂度分析带过但不省略
  • 1~2 个关键类比 + 典型例子
  • 推荐默认档，适用 80% 用户
● LEVEL 3
🔥 高级 ADVANCED
适合：进阶开发者 / 算法竞赛 / 校招冲刺 / 资深工程师
  • 聚焦核心思想 + 优化技巧
  • 快节奏，基础一笔带过
  • 复杂度下界证明
  • 多种解法横向对比
  • 边界条件 / 最坏情况重点讲
  • 工程实现坑点 & 最佳实践
