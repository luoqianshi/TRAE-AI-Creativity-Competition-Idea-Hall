01 · 痛点

想解决什么问题

3亿人的"哑巴英语"困境

中国超过3亿英语学习者能读能写，但听不懂、说不出。传统背单词、做语法题的方式枯燥低效，难以坚持。

语音现象没人教

市面上几乎没有产品系统教授英文歌中的连读、弱读、爆破音吞音等现象，学习者无法模仿歌手的发音方式。

歌词和发音之间缺少桥梁

歌词网站只给文本，词典App只给标准发音，两者之间缺少一座桥。每次想搞清歌词怎么唱，都要反复倒带、猜测。

传统练习太无聊

口语练习枯燥乏味，缺乏趣味性和激励反馈。明明听歌是兴趣，学英语却变成了负担。

02 · 灵感

为什么会想到做这个

创作动机

我本人就是通过听英文歌学英语的，但每次想搞清楚一句歌词到底怎么唱，都要反复倒带、查词典、猜测哪里连读、哪里吞音，过程非常痛苦。市面上的歌词网站只给文本，词典App只给单个词的标准发音，没有任何产品把"歌曲"和"发音教学"结合起来。这个空白值得被填补。

面向哪些用户

核心用户画像

喜欢听英文歌的中国大学生和高中生，英语水平在初中到四六级之间，想要提升英语口语和听力，但觉得传统学习方式太枯燥。

04 · 功能

核心功能

🎤

卡拉OK模式

歌词逐句同步高亮，每个单词标注IPA音标，连读/弱读/爆破等语音现象用颜色编码标注，点击单词查看详情。

✏️

填空挑战

播放歌曲时隐藏关键词，优先隐藏含语音现象的词。用户听歌填写，即时反馈 + combo计分。

🎯

跟读评分

播放一句歌词后暂停，用户用正常语速朗读，浏览器AI实时对比打分，给出"优秀/良好/再试一次"反馈。

🎵

预置歌曲库

内置3-5首免费版权示例音频，打开即可体验。无需登录、无需上传，30秒内进入学习。

📊

学习进度

XP经验值、连续打卡、歌曲完成度。游戏化设计激励持续学习，让进步看得见。

🔤

语音现象标注

系统化标注连读、弱读、爆破音、闪音T等发音现象，提供教学说明，填补市面产品空白。

05 · 形态

产品形态与技术方案

Web 网站 React + TypeScript FastAPI + SQLite Web Speech API

用户选择一首英文歌后，系统自动分析歌词中的音标和语音现象（连读、弱读、爆破音等），并提供卡拉OK跟唱、填空游戏、AI跟读评分等互动学习模式。前端使用 React + TypeScript + Tailwind CSS，后端使用 Python FastAPI + SQLite。跟读评分使用浏览器原生 Web Speech API，零部署、无需 GPU。预置歌曲打包免费版权音频，规避版权风险。

06 · 价值

价值与意义

社会价值

英文歌曲是大量年轻人接触英语的最自然渠道。SongLingo 把被动听歌变成主动学习，降低口语练习的心理门槛。尤其对教育资源相对匮乏的非一线地区学生有实际帮助 —— 只需一部手机和浏览器，就能获得系统化的发音学习体验。

效率提升

通过歌曲的旋律和节奏作为记忆锚点，语音现象的学习效率显著更高 —— 一个连读规则背10遍，不如在一首喜欢的歌里真实听到1遍。游戏化设计（填空挑战、跟读评分、连续打卡）进一步提升了学习动力和坚持率。
