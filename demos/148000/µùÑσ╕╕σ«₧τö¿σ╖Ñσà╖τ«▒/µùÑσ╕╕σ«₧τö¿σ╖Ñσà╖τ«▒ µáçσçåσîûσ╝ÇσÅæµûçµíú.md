文档总览
文档编号：ToolBox-OfflineHTML-V1.0
开发目标：纯前端离线单页 HTML 工具箱，无后端、无联网依赖，本地打开即用，集成字符、搜索、表格函数、PS 快捷键、生活工具类功能
适用人群：办公文员、设计、运营、技术小白；仅浏览器运行，支持 Windows/Mac/ 手机本地打开
技术栈：原生 HTML5 + Tailwind CSS v3（内嵌无需 CDN）+ 原生 JS（无第三方外部 JS），完全离线，保存 html 文件双击直接打开
一、整体架构说明
1.1 项目架构
单文件单页面架构，仅一个index.html，所有样式、脚本、资源全部内嵌，不引用任何在线资源，保证断网 / 无网络环境可用
分层结构：
HTML 结构层：页面布局、导航栏、各功能模块容器
CSS 样式层：内嵌 Tailwind + 自定义主题，适配电脑 / 手机响应式
JS 逻辑层：全局工具函数 + 各功能独立模块（字符库、快捷键库、计算器、搜索等）
静态数据层：内置 JSON 数据（特殊字符、PS 快捷键、Excel 函数、单位换算等，写死在 JS 内，离线读取）
1.2 文件目录（仅单个文件）
plaintext
离线工具箱/
└── index.html  # 唯一文件，包含全部页面、样式、脚本、内置数据
1.3 运行环境要求
电脑：Chrome、Edge、Firefox、Safari 任意现代浏览器，双击 html 直接打开
手机：微信内置浏览器、手机系统浏览器，本地文件管理器打开 HTML
限制：无需服务器、无需网络、无需安装软件，纯离线
二、业务需求与功能模块（核心业务逻辑）
2.1 顶部全局通用功能（全站共用）
全局搜索框：一键检索全部工具内容（特殊字符、PS 快捷键、Excel 函数、工具名称），实时模糊匹配，高亮关键词
复制通用功能：所有文本块统一「一键复制」按钮，复制成功弹窗提示
暗黑 / 浅色模式切换：本地存储记录用户偏好，刷新页面不重置
侧边导航菜单：分类快速跳转，移动端折叠汉堡菜单
重置按钮：一键清空输入框、搜索内容
2.2 模块 1：特殊字符复制库（高频办公）
业务功能
分类标签分组：
标点符号、方框符号、箭头符号、星星花朵装饰、数学符号、希腊字母、上下标、空白占位符、Emoji 极简符号、版权标识
点击单个字符直接复制，hover 放大预览
支持批量复制：勾选多个字符一键复制组合文本
筛选器：输入关键词过滤对应符号（如输入 “箭头” 只显示箭头符号）
收藏常用字符：本地缓存收藏列表，下次打开保留
数据存储：JS 内置数组 JSON，离线加载，无需联网
2.3 模块 2：Excel 表格函数大全（办公刚需）
业务功能
函数分类：文本函数、逻辑函数、统计函数、日期函数、查找匹配、数学计算
每条函数展示：函数名称、语法模板、示例公式、使用说明
一键复制完整函数模板（直接粘贴 Excel 可用）
搜索过滤：输入函数名快速定位（vlookup/sumif 等）
常用函数置顶，支持收藏
2.4 模块 3：PS 快捷键大全（设计专用）
业务功能
分类分组：基础操作、图层、选区、画笔、文字、变换、视图、导出、Mac/Windows 区分快捷键
表格展示：功能说明 + Windows 快捷键 + Mac 快捷键
单行一键复制对应快捷键文本
搜索：输入 “画布”“合并图层” 快速检索对应快捷键
导出全部快捷键文本（复制纯文本清单）
2.5 模块 4：日常实用小工具合集（多功能集成）
子工具 1：单位换算
长度、重量、面积、体积、时间、人民币数字大小写转换
子工具 2：时间日期工具
时间戳互转、日期计算（间隔天数）、倒计时、农历简易转换
子工具 3：编码转换
URL 编码 / 解码、Base64 加密解密、Unicode 字符转换
子工具 4：随机生成器
随机数字、随机密码、随机字符串、随机颜色色值（复制色值）
子工具 5：文本处理工具
去空格、换行合并、大小写转换、文本去重、字数统计、JSON 格式化
子工具 6：二维码生成（纯 JS 离线生成，不调用在线接口）
输入文字 / 链接，本地生成二维码，支持右键保存图片
2.6 辅助功能
本地存储 localStorage：保存收藏字符、收藏函数、主题模式、常用记录
复制全局统一回调：复制成功轻提示，无需弹窗遮挡
页面锚点跳转：侧边栏点击快速定位对应模块
响应式适配：电脑多栏布局，手机单栏折叠布局

五、核心 JS 逻辑说明（开发可直接落地）
5.1 全局公共函数（通用工具）
copyText(text)：通用复制函数，兼容所有浏览器，复制成功提示
setStorage(key, val) / getStorage(key)：本地缓存读写
debounce(fn, delay)：搜索防抖，减少频繁渲染
switchTheme()：切换深色浅色，写入本地存储
highlightKeyword(text, keyword)：搜索关键词高亮渲染
5.2 数据渲染逻辑
所有静态数据以 JS 数组对象内置，示例结构：
javascript
// 特殊字符数据示例
const symbolList = [
  {type:"箭头", list:["←","→","↑","↓"]},
  {type:"数学", list:["±","×","÷","∞"]}
]
// PS快捷键数据示例
const psShortcut = [
  {cate:"图层", win:"Ctrl+J", mac:"Cmd+J", desc:"复制图层"}
]
// Excel函数数据示例
const excelFunc = [
  {cate:"逻辑", name:"IF", template:"=IF(条件,满足,不满足)", desc:"条件判断函数"}
]
页面加载自动遍历数组渲染卡片，切换分类过滤对应数据。
5.3 搜索逻辑
全局搜索：遍历全部三类数据（字符 / 函数 / 快捷键）匹配关键词
模块内搜索：仅过滤当前分类数据
模糊匹配，不区分大小写
5.4 收藏逻辑
点击收藏按钮，将对应 ID 存入 localStorage，收藏夹页面单独渲染收藏内容
5.5 离线二维码生成
使用纯 JS 二维码生成库（内嵌至 html，无外部 CDN），输入文本实时绘制 canvas 二维码

七、风险与兼容注意事项
7.1 离线核心风险规避
禁止所有外部资源引入（CDN、在线 JS、在线图片接口），所有样式、脚本全部内嵌
二维码 JS、Tailwind CSS 全部压缩嵌入 html，不使用外链
不使用任何 fetch/axios 网络请求，所有数据本地 JS 内置
7.2 浏览器兼容问题
复制功能兼容低版本浏览器，增加备用复制方案
localStorage 本地存储判断，无存储权限给出提示
移动端触摸优化，放大按钮，防止误触
7.3 功能边界限制
Excel 函数仅提供模板复制，不支持在线计算（离线无计算引擎）
二维码仅本地 canvas 绘制，无下载图片以外功能
农历转换为简易算法，仅基础日期参考，不做高精度万年历
