功能演示 1：报错智能解析

粘贴报错信息，AI 快速定位问题并给出完整解决方案

❌ 报错信息
TypeError: Cannot read properties of undefined (reading 'map') at UserList (src/components/UserList.js:15:7) at renderWithHooks (react-dom.development.js:14985:18)
1
问题定位
第 15 行对 users 变量调用了 .map()，但 users 的值为 undefined
2
根本原因
API 请求尚未完成时组件已渲染，或请求失败时未设置默认值。数据为异步加载，渲染时可能为 undefined
3
修复方案
// 方案一：使用可选链 + 空数组兜底 const userList = users?.map(user => ...) ?? []; // 方案二：渲染前判断加载状态 if (!users) return <div>加载中...</div>;
4
为什么会这样
React 组件渲染是同步的，但数据获取是异步的。在数据到达之前，users 为 undefined。这是 React 新手最常见的错误之一。

用户
好的，我们先一起看看你的思路。你打算怎么判断一个数是奇数还是偶数？

很好，这个思路是对的。那你想用什么数据结构来存放奇数和偶数？需要几个容器？

完美！那你现在应该能写出完整的函数了。试着写一下，然后我们一起看看有没有可以优化的地方。
CodeBuddy

功能演示 3：项目导航助手

输入 GitHub 仓库，AI 自动生成项目阅读指南

📦 项目概述
一个基于 React + Node.js 的待办事项应用，使用 MongoDB 存储数据，JWT 做用户认证。适合学习全栈开发入门。
📁 目录结构
📁 todo-app/ 📁 client/ React 前端 📁 src/ 📁 components/ UI 组件 📁 pages/ 页面组件 📁 hooks/ 自定义 Hooks 📁 services/ API 请求封装 📄 App.js 路由配置 📁 server/ Node.js 后端 📁 routes/ API 路由 📁 models/ 数据模型 📁 middleware/ 中间件 📄 server.js 入口文件
🎯 推荐阅读顺序
1
先看入口文件
client/src/App.js 和 server/server.js，了解整体架构
2
再看数据流
services/ 里的 API 请求 → server/routes/ 里的接口实现 → models/ 里的数据模型
3
最后看 UI 层
components/ 和 pages/ 里的组件，了解前端如何展示数据
