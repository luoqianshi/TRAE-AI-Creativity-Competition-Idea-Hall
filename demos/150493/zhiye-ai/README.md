# 智页AI - 基于知识图谱RAG的网页智能问答插件

## 项目简介

智页AI是一款搭载结构化知识图谱增强RAG的通用浏览器插件，支持自动解析单页和整站网页内容生成专属知识库，内置划词提问、代码生成与API合规校验、知识体系梳理等功能，同时开放全维度AI来源自定义配置，在任意网页内为用户提供即开即用的精准智能问答服务。

## 核心功能

### 1. 结构化知识图谱构建
- 自动解析网页标题层级、段落、代码块、表格、列表等内容
- 构建实体-关系-实体的结构化知识图谱
- 自动提取API函数、参数信息
- 建立语义关联，支持子图检索

### 2. 知识图谱增强RAG问答
- 基于查询动态检索最相关的知识子图
- 结构化上下文注入（API、代码、段落、表格分类组织）
- 支持多轮对话，保留聊天历史
- 流式响应，实时输出AI回答

### 3. 划词提问
- 选中页面任意文字，悬浮显示提问按钮
- 支持右键菜单快速操作（提问/解释/生成代码/总结）

### 4. 代码生成与API校验
- 基于文档API自动生成可运行代码（支持Lua/JS等）
- API合规校验：检查代码中的API调用是否符合文档规范
- 参数数量匹配检测
- AI深度代码审查

### 5. 多模型适配
- 支持OpenAI、Claude、Gemini等主流云端模型
- 支持Ollama本地开源模型离线调用
- 支持自定义API端点（兼容OpenAI格式）
- API Key仅本地存储，保障隐私安全

### 6. 多维度交互界面
- 侧边栏问答面板（4个Tab：问答/代码/知识图谱/检索）
- 浏览器右键菜单集成
- Popup快捷操作面板
- SidePanel管理中心

## 安装方法

### 开发模式加载

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目的 `zhiye-ai` 文件夹
5. 扩展图标将出现在浏览器工具栏

### 配置AI模型

1. 点击扩展图标 → 点击「设置」
2. 在设置页面选择AI提供商（OpenAI/Claude/Gemini/Ollama/自定义）
3. 输入API Key和模型名称
4. 点击「测试连接」验证配置
5. 点击「保存配置」

## 使用指南

### 基础问答
1. 打开任意网页，插件自动解析内容
2. 点击页面右下角的「AI」悬浮按钮或浏览器工具栏图标
3. 在侧边栏输入问题，按Enter发送
4. AI基于当前页面知识库回答

### 划词提问
1. 在页面中选中任意文字
2. 点击出现的悬浮「💬 提问」按钮
3. 或右键选择「智页AI：提问选中内容」

### 代码生成
1. 切换到侧边栏「代码」Tab
2. 输入功能需求描述
3. 点击「生成代码」
4. 插件自动基于文档API生成可运行代码

### API校验
1. 在「代码」Tab中点击「校验代码」
2. 粘贴你的代码
3. 插件自动检查API调用是否符合文档规范

### 知识图谱浏览
1. 切换到「知识图谱」Tab
2. 查看当前页面的节点统计（API、代码块、段落等）
3. 点击任意节点可直接针对该节点提问

## 技术特色

| 特性 | 说明 |
|------|------|
| 结构化知识图谱 | 不同于普通文本切块RAG，构建标题-段落-代码-API的图结构 |
| 语义关联 | API与代码块、段落之间自动建立引用关系 |
| 多模式问答 | 支持问答/解释/总结/代码/API校验多种模式 |
| 流式响应 | AI回答实时逐字显示，无需等待完整响应 |
| 本地优先 | API Key、知识库、对话历史均本地存储 |
| 全模型兼容 | 云端+本地+自定义API，灵活适配不同场景 |

## 适用场景

- **开发文档阅读**：快速定位API用法，生成可运行代码示例
- **学术论文学习**：提炼核心观点，梳理知识框架
- **技术博客浏览**：即时解答概念疑问，深入理解技术细节
- **产品文档查阅**：快速获取功能说明，提高信息获取效率

## 隐私说明

- 所有API Key仅存储在浏览器本地 `chrome.storage.local` 中
- 知识图谱和对话历史保存在本地，不上传到任何服务器
- 网页解析在本地完成，内容不会外发
- 仅与配置的AI服务提供商进行必要的API通信

## 技术栈

- Vanilla JavaScript (ES2020+)

- 纯前端实现，零后端依赖
