查看功能 → GitHub 📦

核心功能

📅

饮食记录

按日期追踪每日饮食，支持 AI 查询食物热量，记录三餐摄入情况

📊

数据分析

折线图展示每日热量趋势和体重变化，直观了解减肥进度

🤖

AI 助手

基于豆包 API 的个性化减重分析、餐食推荐、每日鼓励

⚖️

体重追踪

记录每日体重变化，生成体重趋势图，见证减肥成果

🎨

主题定制

8 种预设配色 + 暗色模式，满足个性化需求

🔔

进餐提醒

自定义三餐时间的本地通知，养成规律饮食习惯

价值与意义

⏱️

效率提升

AI 一键识别食物热量，智能计算每日推荐摄入量，省去手动查询的麻烦

❤️

社会价值

推广科学减重理念，减少盲目节食对健康的危害，帮助用户建立健康自信的生活方式

📈

可视化追踪

数据图表让减肥进度一目了然，持续的鼓励和正向反馈，帮助用户坚持到底
