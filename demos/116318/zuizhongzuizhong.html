A痛点 / PAIN

靠修改时间排序不靠谱——有人后保存但内容其实是更早的草稿。靠"最终""定稿"关键词也不靠谱——每个人都标最终。改名的、加括号的、加日期的、加自己缩写的、加"副本"的，规则五花八门。

最后只能挨个打开比对，或在群里 @ 一圈问"这个是不是最新的"。更糟的是用了旧版发出去：合同错版、标书错版、设计稿错版，返工成本极高。

B工作流 / FLOW

  1. 粘贴一组文件名（一行一个）
  2. 解析每个文件的版本号、定稿关键词、日期、序号
  3. 按版本新鲜度评分排序
  4. 最高分唯一 → 蓝戳"最新"
  5. 最高分并列 → 红戳"重复存疑"
  6. 含"副本/copy" → 红戳"疑似副本"
  7. 其余归入历史版本抽屉

C价值 / VALUE

效率提升：把"挨个打开—肉眼比对—群里追问"压缩成"粘贴清单—看排序—复制结果"。五分钟变五秒。

协作价值：给团队一个统一的版本识别口径，减少误用旧版导致的返工、错发、合同错版。让"最终"不再各说各话。

本作品使用 TRAE Work 梳理痛点与拆解模块（输入 → 解析 → 评分 → 归档 → 导出），并用 TRAE IDE 构建老式卡片目录柜风格的交互原型：每个文件名做成借阅卡，三个木抽屉分别归档最新定稿、存疑重复、历史版本，最新版盖蓝色圆形借阅戳，存疑版盖红色警示戳，卡片以归档滑入动效进入抽屉。
