01 · CONCEPT

从感觉还行
到专业量化

传统照片评价停留在"好看"或"感觉还行"的模糊层面。点评相机用 AI 视觉模型，把一张照片拆解为五个可量化的美学维度。

构图、光影、色彩、主题、创意——每一维都有独立的 1-10 分评分，配合雷达图直观呈现照片的美学指纹。

不止打分。AI 会指出具体的优点、缺点，并给出可执行的拍摄参数建议。这不是终点，而是成长的起点。

07 · TECH

技术架构亮点

稳健的后端、流畅的前端、安全的 AI 集成。

FRONTEND

Canvas 2D 雷达图

SelectorQuery 获取 Canvas 节点，原生 2D API 绘制五维雷达图，requestAnimationFrame 平滑动画，500ms 内完成渲染。

AI

腾讯混元视觉模型

三步式 Hunyuan 评估流程：预检（服务端）→ 小程序直连 AI（wx.cloud.extend.AI）→ 提交结果（服务端校验占位记录）。

BACKEND

Node.js + MySQL

Express + mysql2/promise 异步连接池，timezone +08:00，utf8mb4 全字符集。Nginx 反向代理，trust proxy 正确获取 HTTPS。

SHARING

多渠道分享裂变

分享给好友、朋友圈单页模式、海报生成（Canvas 绘制 + canvasToTempFilePath）、贴图广场（wx.shareToOfficialAccount + 小程序短链）。

SECURITY

内容安全校验

微信 security.imgSecCheck 同步版检测违规图片，内存 Buffer 直传不落盘。失败降级放行，平衡安全与体验。

PERFORMANCE

渐进式渲染策略

独立 setData 替代 Promise.all 阻塞，懒加载广告实例，setTimeout 350ms 延迟刷新避免导航动画卡顿。
