Project Background

为什么需要 Hum2Midi

灵感转瞬即逝。当一段旋律在脑海中浮现时，大多数人并没有能力把它准确记录下来。Hum2Midi 的存在，就是为了弥合这道鸿沟——让人人都能用最自然的方式捕捉音乐的灵感。

01

记谱的专业门槛

传统记谱需要长期的视唱练耳训练。普通爱好者面对一段简单的旋律，也需要花费数小时反复聆听与辨别音高，最终结果仍然可能存在明显偏差。

02

灵感记录的滞后性

灵感往往在非预期的时刻闪现——散步、洗澡、通勤。等到你打开专业软件、调出虚拟键盘、调整设置，那段旋律已经消失得无影无踪。

03

专业软件过于复杂

Logic、Cubase、Ableton 等 DAW 软件有陡峭的学习曲线。大多数学习者和业余爱好者并不需要这些工业级工具，却被挡在了数字化创作的门槛之外。

04

音乐教学的效率瓶颈

课堂上老师示范一段旋律后，学生需要手动抄写乐谱才能带回家练习。这一过程占用了宝贵的教学时间，也容易因抄写错误导致练习偏差。

05

儿童启蒙的工具空白

儿童对音乐的表达往往是即兴的哼唱，但他们还不会读谱、不会演奏乐器。市场上缺乏一种能让孩子用自己的声音与音乐进行互动的简单工具。

06

云端方案的隐私顾虑

少数在线音乐识别服务要求上传音频到云端。对于注重隐私的创作者和教育者来说，把尚未公开的原创旋律交由第三方处理，是难以接受的选择。

Core Features

从声音到乐谱的完整管线

Hum2Midi 把复杂的音乐信号处理封装为清晰的处理阶段，从按下录音键到获得 MIDI 文件，中间每一步都在本地设备完成。

一站式音乐数字化方案

我们整合了从音频采集、信号处理、节奏识别到 MIDI 生成与播放的全流程技术，提供简洁、低门槛的交互界面。你不需要任何专业背景，就能把口头上的旋律变为可编辑、可分享、可播放的数字乐谱。

  • 基于开源信号处理库的基频检测
  • 自适应节奏检测，支持不同速度哼唱
  • MIDI 格式输出，兼容主流音乐软件
  • 极简界面设计，降低视觉干扰
  • 本地 CPU 运行，不依赖任何云服务

音频输入模块

支持麦克风实时录音与本地音频文件导入两种模式。采用音频队列缓冲机制，确保录音过程平滑无卡顿。自动将多声道音频统一为单声道信号，便于后续处理。

音高识别引擎

基于开源信号处理库实现的基频检测算法，对哼唱音频进行逐帧音高估计，输出连续的音高曲线。算法针对人声频率范围做了特别优化，提升识别准确度与稳定性。

节奏检测与分割

自动识别音符起始点，将连续的哼唱切割为离散的音符片段。根据能量变化与音高稳定性双重判断，提高起始点识别精度。支持不同速度与节拍模式的旋律输入。

MIDI 生成与导出

将识别出的音符序列写入标准 MIDI 文件。支持多轨道、可调节速度、自定义乐器通道。输出文件可直接导入 Logic、Ableton、FL Studio 等主流数字音乐工作站。

内置 MIDI 播放器

集成 MIDI 播放模块，无需外部播放器即可预览生成的旋律。支持开始、暂停、停止、音量调节等基本播放控制。识别结果即刻可听，便于即时修正与再创作。

乐谱渲染与作品管理

将识别后的音符渲染为标准五线谱，方便读谱与对照查看。提供作品管理功能，可浏览、搜索、回放历史录音与乐谱，支持多次创作与多项目版本管理。

Technical Architecture

技术架构说明

Hum2Midi 是一个以 Python 为开发语言的桌面应用程序，采用模块化的分层架构，将音频采集、信号处理、节奏分析、音符量化、MIDI 生成与图形界面解耦为独立模块。

GUI 框架

基于跨平台的 Qt 框架实现，使用统一的 QSS 样式表保证各平台视觉一致。提供欢迎页、主页面与功能页面的多层页面结构，支持多语言与多显示分辨率。

  • 窗口尺寸 1280 x 800，可自适应
  • 极简风格的界面元素设计
  • 清晰的状态提示与操作反馈

音频信号处理

采用基于 Python 的开源音频处理库实现音频读取、重采样与声道归一化。音高检测使用主流的基频估计算法，在人声哼唱的频率范围内做了针对性的参数优化。

  • 支持 WAV 与其他常见音频格式
  • 逐帧估计音高并输出连续曲线
  • 平滑与去噪处理保证结果稳定

音符分割与量化

基于能量变化与音高稳定性双重判据，自动识别音符起始点，将连续的哼唱信号切分为离散的音符。根据标准音高表做量化，将每个音符映射为最接近的半音音名。

  • 自动音符起始点检测
  • 音高量化到标准半音
  • 时长估计与时间戳对齐

MIDI 文件生成

使用成熟的 MIDI 读写库生成标准 MIDI 文件。支持多轨道输出，每个声部独立保存。生成的 MIDI 文件兼容 Logic、Ableton、FL Studio 等主流数字音乐工作站。

  • 标准 MIDI 1.0 格式
  • 可配置节拍速度与乐器通道
  • 多轨道、多声部结构

本地回放

集成轻量级 MIDI 播放模块，无需外部播放器即可预览生成的旋律。支持播放、暂停、停止、音量调节等基本播放控制，提供即时反馈。

  • 本地合成，不依赖外部设备
  • 支持多种音色选择
  • 播放状态可视化指示

作品库与管理

所有录音与生成结果保存在本地文件系统中，按项目、按日期、按类型组织。作品库支持搜索、过滤、排序、批量导出等操作，便于用户长期维护自己的创作资源。

  • 本地文件系统存储
  • 多维度搜索与过滤
  • 作品版本记录与回溯
