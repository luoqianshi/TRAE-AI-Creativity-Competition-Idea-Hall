AI 知识织网
知识图谱驱动的学习效率优化

自动构建个人知识图谱，在用户提问时结合相关旧知识作答，通过类比加速理解，帮助新知识融入已有知识体系。

01 / Problem

新知识难理解，难融入已有体系

学习新知识时，有时会遇到比较难理解的概念，难以将其融入自己的知识体系。如果系统能自动发现新知识点与已学知识之间的关联，通过类比帮助快速联想，就能显著加速理解过程，让新知识自然地成为知识体系的一部分。

01

旧知识分散

学过的知识点分布在浏览器书签、代码仓库、本地文档中，缺少统一的关联和组织，回忆和调用需要额外花费时间。

02

关联靠手动

学习新内容时，与已有知识之间的关联需要自己主动去想、去建立，错失了通过类比加速理解的机会。

03

整理负担重

现有知识管理工具需要手动导入和整理，门槛较高，多数人难以坚持，知识关联的收益难以体现。

02 / Solution

自动织网，类比加速

AI 知识织网在用户日常学习的过程中，自动采集学习内容、提取知识点、建立新旧知识之间的关联。当用户提问时，系统结合知识图谱中的相关旧知识作答，帮助用户通过类比快速联想，从而优化学习效率。跨平台采集（浏览器 + PC 客户端）是实现这一目标的手段，让用户无需改变学习习惯即可自然积累知识。

03 / Architecture

以 PC 客户端为核心的架构

PC 客户端同时承担文件监视、本地服务和知识图谱可视化三项职责，浏览器插件和 IDE 插件作为轻量扩展通过本地通信与之交互。存储层采用兼容引擎设计，通过统一接口支持本地数据库和远程数据库，切换后端只需更改配置。

文件监视与采集

监控用户打开的 PDF/PPT/Markdown 等文档，自动提取内容作为学习知识。

本地服务（知识图谱 API + AI 调用）

知识图谱管理、内容处理、AI 调用转发（用户自带 API Key）、存储管理，供浏览器插件和 IDE 插件调用。

知识图谱可视化

内嵌交互式图谱界面，支持搜索、拖拽、缩放、筛选和节点详情查看。

04 / Visualization

让知识网络一目了然

知识图谱可视化是产品的核心功能。节点大小反映关联数量，颜色按主题分类，连线粗细反映关联强度。用户可以直观地浏览自己的知识体系，发现隐藏的知识关联。

05 / Users

面向广泛的终身学习者

产品面向有持续学习需求的人群，浏览器插件和 PC 客户端适用于所有用户。

D

技术从业者

开发工程师、架构师等，在浏览器查资料、IDE 写代码、阅读技术文档，需要系统化关联技术知识。

S

在校学生

不限专业，通过浏览器上网课、查资料，通过本地文档学习，需要将课堂知识和课外拓展关联起来。

L

终身学习者

跨行业自学者、考证人群等，通过网页和文档学习新领域知识，需要系统化管理学习内容。

06 / Privacy

隐私安全，用户掌控

作为收集用户行为数据的工具，安全和隐私是产品信任的基石。采用三层防护机制，确保用户数据完全由自己掌控。

🛑

学习模式开关

全局开关控制数据采集。关闭时不采集任何数据，确保非学习操作（聊天、网购等）不会泄露隐私。

💾

默认本地存储

所有数据默认存储在本地设备，不上传到任何服务器。兼容引擎设计支持切换远程数据库。

🔑

用户自带 AI 服务

不自带大模型服务，用户自行提供 API Key，选择心仪的模型，数据不经第三方服务器。

07 / Value

价值与意义

效率提升

通过自动构建知识图谱和 AI 语义关联，帮助用户在学习新知识时快速发现与已学知识的联系，通过类比加速理解和记忆。让新知识自然地融入已有知识体系，学习效率从"够用"提升到"高效"。

商业价值

面向广泛的终身学习市场，差异化在于"AI 知识图谱关联 + 问答时类比作答 + 隐私可控（默认本地存储、用户自带 API Key）"。目前市面上没有产品同时实现这三点，是一个明确的市场空白。
