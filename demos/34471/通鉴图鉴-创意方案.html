01

创意名称 + 创意介绍

想解决什么问题

读《资治通鉴》时，读者无法直接在地图上直观地了解历史事件发生的地理位置、地名变迁、国家疆域变化等前后时空环境。只能一边看书，一边通过地图软件、搜索引擎等工具查询相关地理信息，在多个应用之间来回切换，学习体验割裂、不直观、效率低。

为什么会想到做这个

大脑对图像的记忆远强于纯文字。读史书时，如果能将文字描述与地图上的空间变化对应起来，历史事件的因果关系和发展脉络会变得更加清晰。希望能把《资治通鉴》的文字内容转换成更容易被大脑记忆的可视化地图，降低历史学习的认知门槛。

大概是什么产品

一款可在电脑、手机、平板等终端使用的轻量 Web 应用。以《资治通鉴》熊逸版的内容框架为主线，结合 CHGIS 等开源历史地图数据，用户选择章节即可查看对应的历史地图形势、原文内容和熊逸版辨证解读。

02

目标用户及痛点

面向哪些用户

  • 历史爱好者和文史专业学生
  • 中学及以上阶段学习中国古代史的学生
  • 对《资治通鉴》有兴趣但觉得阅读门槛较高的普通读者

在什么场景下使用

  • 阅读《资治通鉴》原文或相关历史书籍时，对照查看事件发生地的地理形势
  • 备考复习时快速梳理某一时期的国家分布和重大事件空间关系
  • 日常碎片化时间浏览历史地图，建立宏观历史空间认知

当前痛点

没有专门针对《资治通鉴》内容设计的历史地图工具。用户需要同时打开电子书/纸质书、地图 App、搜索引擎等多个工具，手动将文字中的地名与地图位置对应，费时费力，且难以形成连贯的时空认知。

03

价值与意义

效率提升

将"文字阅读 + 手动查地图"的多步骤学习流程，简化为"选章节 → 看地图 + 读内容"的一站式体验，大幅降低学习《资治通鉴》的认知负担和时间成本，让厚重的史书变得更易读、易记。

社会价值

降低经典史书的阅读门槛，帮助更多年轻人以直观的方式接触和理解中国传统文化经典，培养历史空间思维，让古籍中的智慧以更符合现代人认知习惯的方式传承下去。

04

核心交互设计

主流程

用户选择章节/年份 → 左侧展示历史地图（自动标注地名、战役地点、国家疆域与行政区划），右侧展示原文内容。

双向联动

点击文字中的地名，地图自动高亮并定位到对应位置，实现文字与地图的实时交互。

辨证标注

熊逸版的辨证观点以地图弹窗形式标注在相关地点旁，同时设有独立的"辨证笔记"模块，方便集中阅读。

参赛 Demo

选取熊逸版一个完整章节制作可交互 Demo，展示完整产品体验。

05

技术方案概述

数据来源

  • 历史地图数据：CHGIS 等开源历史地理信息系统
  • 内容框架：以《资治通鉴》熊逸版内容目录为主线进行规划和制作
  • 辨证内容：整合熊逸版的辨证解读，与地图位置关联

产品形态

轻量 Web 应用，支持电脑、手机、平板等多终端访问。地图层采用可交互的地图组件，支持缩放、拖拽、点击标注等操作。

MVP 范围

先制作一个完整章节的可交互 Demo，用于参赛展示。后续可根据反馈逐步扩展更多章节和功能。
