TECH STACK

ESP32-C3 技术架构

轻量、低功耗、易部署，一块芯片撑起整个互动场景。

📶

SoftAP 热点层

ESP32-C3 开启 WiFi 热点，参与者连接即可访问本地服务，无需公网。

🌐

本地 Web Server

在芯片内运行轻量 HTTP 服务，直接提供聊天页面与静态资源。

🚪

Captive Portal（可选）

连上 WiFi 后自动弹出页面引导，降低参与门槛。

⚡

WebSocket / 轮询

实时推送新消息，或以低频轮询刷新，兼顾性能与体验。

🗃️

RAM 循环队列

消息仅保存在内存中，采用循环队列限制数量，重启即清空。

🛠️

管理员页面

支持置顶、删除、清空消息，活动结束一键归零。

📱 参与者手机 / 电脑
↓ WiFi 连接
📶 ESP32-C3 SoftAP 热点
↓ HTTP / WebSocket
🌐 本地 Web Server + 聊天页面
↓ 读写
🗃️ RAM 循环队列（临时存储）
活动结束 / 重启 → 数据自动清空
