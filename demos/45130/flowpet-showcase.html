技术架构

FlowPet 长什么样

从前端到 AI 到数据层，都只做一件事：让专注温柔地发生。

Frontend
React 18 · Tailwind CSS · Vite
FocusTimer · PetAvatar（SVG 状态机）· FlowReport · Settings
ReactTailwindVite
Detection
Page Visibility API + TensorFlow.js BlazeFace（可选）
零依赖 API 检测标签切换；TF.js ~10MB gzip 本地人脸检测，不上传视频。
Page VisibilityTF.jslocal only
AI
OpenAI Chat Completions · Web Speech API（可选 TTS）
只发送会话摘要（时长、分心数），不含视频画面。
miniTTSsummary only
Data
Supabase Auth · PostgreSQL · Storage
users / focus_sessions / evolutions；localStorage 离线降级；RLS 行级安全。
SupabasePostgresRLSlocal fallback
Deploy
Vercel · Edge Functions
静态产物 + SSR 混合；OpenAI 代理走 Edge Function，Key 不透给前端。
VercelEdge
