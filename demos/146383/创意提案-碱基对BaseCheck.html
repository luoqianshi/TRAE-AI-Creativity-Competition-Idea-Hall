创意介绍

想解决什么问题

高中生物知识点又多又杂，学生面临"记不住、学不透、错题反复犯"三大困境。现有学习工具要么全科覆盖但生物深度严重不足，要么只有搜题功能没有学习闭环——错题收录了却不复习，知识碎片化不成体系，遗传题和实验题成为持续性失分黑洞。

核心痛点：全科题库"生物太浅"，搜题工具"只搜不学"，错题本"只收不练"，辅导班"价格高昂"。

为什么会想到做这个

生物学科有大量需要深度理解与记忆的概念——从细胞器的功能到遗传信息的传递，从光合作用的暗反应到生态系统的能量流动。这些知识不是"搜一道题"就能学会的，需要系统学习、反复练习、针对性复习。

我们调研发现：市面上没有一个产品专注于"生物单科的极致深度"。全科工具在生物上浅尝辄止，国际工具（Khan Academy、Quizlet）又缺乏中国课标对人教版教材的覆盖。于是我们决定做一个"生物单科深度学习伴侣"——不做全科，只做生物，做到极致。

产品形态

一款面向高中生的生物单科深度学习 App（uni-app 四端覆盖：Android / iOS / 微信小程序 / H5），搭配一个品牌展示网站（Vue 3 + Three.js）。覆盖课程学习、刷题练习、错题闭环复习、AI 答疑、知识图谱可视化、AI 自动生成课程等核心功能，形成完整的"学-练-错-析-复-灭"学习闭环。

价值与意义

效率提升

"学-练-错-析-复-灭" 完整学习闭环

通过艾宾浩斯遗忘曲线复习调度 + 错因五维分析（概念不清/审题失误/计算错误/知识遗忘/方法不对）+ 薄弱点精准定位 + 连续2次正确即归档消灭机制，形成完整闭环。让错题真正被消灭，而非反复犯错。多数竞品有错题本但无闭环，这是本产品相对竞品的核心优势。

社会价值

降低优质生物教育资源获取门槛

通过 AI Function Calling 深度集成（DeepSeek 大模型 + 工具调用查询真实数据库，不编造数据），让偏远地区学生也能获得高质量的个性化生物辅导。AI 答疑 + AI 自动生成课程，相当于为每个学生配备了一位 24 小时在线的生物老师，促进教育公平。

商业价值

填补"中国课标 + 生物学科 + 间隔重复"市场空白

经竞品分析，市面上不存在同时满足"匹配人教版课标 + 生物单科深度 + 间隔重复记忆"三个条件的产品。本项目以 RICE 评分最高的"闪卡 + 间隔重复记忆系统"为首迭代方向，精准填补这一市场空白，具有清晰的商业化路径。
