使用帮助

基本操作

  • 点击"刷新串口"按钮扫描可用串口设备
  • 选择串口号，设置通信参数（波特率、数据位等）
  • 点击"连接串口"按钮建立连接
  • 在发送框输入数据，点击发送按钮或按Enter键发送
  • 接收的数据会显示在上方数据显示区域，带有时间戳

协议解析

  • 选择预设协议模板或配置自定义协议
  • 自定义协议需要设置起始字符、数据长度和校验方式
  • 解析后的协议字段会在数据显示区域高亮显示

数据可视化

  • 选择要可视化的数据字节（可多选）
  • 可以自定义字节名称和颜色
  • 接收数据时会自动更新曲线图
  • 可以调整数据点数量和Y轴范围
  • 鼠标悬停在数据点上可以查看详细信息

关于Web版

  • Web版使用浏览器原生 Web Serial API，无需安装任何软件
  • 支持 Chrome/Edge 等基于 Chromium 的浏览器
  • 需要浏览器支持并启用 Web Serial API
  • 首次使用需要在浏览器弹窗中授权串口访问权限
