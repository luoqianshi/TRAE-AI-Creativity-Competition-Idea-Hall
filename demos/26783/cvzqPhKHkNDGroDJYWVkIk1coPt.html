为什么是 Formdown？

不是"表单工具加了 AI"，而是 AI → DSL → 表单的一体化闭环。

// 01

AI 一句话生成

不用拖拽，不用写 Schema。告诉 AI "我要一个活动报名表"，30 秒拿到完整表单。

// 02

可版本化的 DSL

表单即 Markdown，可进 Git、可在 PR 中 Code Review、可 diff、可回滚。

// 03

一次定义多端发布

同一份 DSL，可发布为网页问卷、企微/钉钉 OA、Notion 嵌入或 PDF。
