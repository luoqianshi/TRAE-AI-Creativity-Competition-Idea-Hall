血压时间线

一个面向家庭 NAS 和自托管环境的本地健康管理应用：把散落在相册里的血压仪照片，整理成可确认、可追踪、可导出的长期血压时间线。

社会服务赛道 Docker / 家庭 NAS 本地优先 血压趋势管理 隐私数据不出家门

创意介绍

很多家庭会长期给老人或慢病管理人群测量血压，但真实记录方式往往很松散：血压仪屏幕照片存在手机相册里，纸质记录容易丢，微信里发过的图片很难回看，去医院复诊时也缺少连续、可信、结构化的数据。

血压时间线希望把这个过程变成一个家庭可持续使用的健康数据工作台。用户上传血压仪照片后，系统通过本地 OCR 或可替换的识别适配器提取收缩压、舒张压、心率和时间信息，再由用户审阅确认，最后保存为正式记录，生成趋势图和时间线。

本地优先

照片、识别结果和健康记录默认保存在 NAS 或本机数据目录，减少敏感健康数据外传。

确认后入库

OCR 可能出错，所以识别结果必须经过用户确认，避免把错误读数写入长期健康档案。

Docker 部署

计划公开为任何 Docker 环境都能运行的应用，特别适合家庭 NAS、软路由和自托管服务器。

目标用户与痛点

  • 家里有高血压、心血管风险或需要长期监测血压成员的家庭。
  • 习惯用手机拍下血压仪读数，但缺少结构化整理工具的照护者。
  • 重视隐私，希望健康数据放在家庭 NAS，而不是上传到陌生云服务的用户。
  • 医生复诊前需要快速整理最近几个月血压趋势的人。

核心流程

1. 上传照片批量上传血压仪屏幕、纸质记录或历史截图。
2. 候选识别系统提取可能的血压、心率和测量时间。
3. 用户审阅用户确认或修正识别结果后再保存。
4. 趋势回看按时间线、图表和导出文件查看长期变化。

价值与意义

社会价值：帮助普通家庭低成本建立长期血压记录，提升慢病自我管理和家庭照护效率。

效率价值：把“翻相册、手抄数字、做表格”的重复劳动变成自动识别加人工确认，复诊前可以快速导出。

隐私价值：健康数据属于高敏感数据，家庭 NAS 部署让用户拥有更强的数据控制权。

当前基础与后续计划

项目已有可运行 MVP：包含前端界面、Fastify 后端、SQLite 数据存储、OCR 适配器、Dockerfile、生产启动脚本和 NAS 应用打包骨架。下一步会把部署方式从特定平台扩展成更通用的 Docker 镜像与 compose 模板，让 Synology、TrueNAS、Unraid、CasaOS、飞牛、懒猫微服等家庭 NAS 用户都能方便运行。

  • 公开源码与 Docker 镜像，补齐 README、环境变量和数据目录说明。
  • 提供 docker compose 示例，支持一条命令启动。
  • 完善血压异常标记、家庭成员区分、CSV 导出和复诊摘要。
  • 明确医疗边界：只做记录、整理和趋势回看，不提供诊断、治疗或用药建议。
