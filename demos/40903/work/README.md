# 毛主席诗词创作足迹图

这是一个面向 `PC 端` 的静态前端原型，使用 `HTML`、`CSS`、`JavaScript` 与 `Canvas` 搭建。

## 已完成内容

- 首页视觉区与双栏信息布局
- 古风手绘全景地图底图
- 58 个诗词节点（含原文、背景、节选）

## 文件说明

- `index.html`：页面结构
- `styles.css`：界面样式
- `data.js`：扩展版诗词节点数据
- `app.js`：Canvas 绘制、底图叠加与交互逻辑
- `assets/ancient-map-clean.jpg`：古风手绘地图底图
- `sources-public.md`：本轮公开来源整理说明

## 使用方式

直接打开 `index.html` 即可浏览。
