1创意介绍

想解决什么问题 · 为什么做 · 是什么产品

痛点：工具分散，流程割裂

独立游戏开发需要美术、音乐、文案、程序多个环节。当前 AI 能力虽强，但散落在不同工具里：画图要开 ComfyUI，写剧情要切对话工具，找素材要翻 Kenney/OpenGameArt，导出要手动整理目录。开发者把大量时间花在"切换工具和搬运文件"上，而非创作本身。

动机：个人独立开发的真实困境

作为想尝试独立游戏的开发者，我深刻体会到：一个人要兼顾所有环节，精力极其有限。AI 能帮上忙，但每次调用都要在多个软件间反复跳转、手动传参、手动归档产物。ComfyUI 工作流虽然效果好，但调用过程依旧复杂，亟需一个统一入口。

产品形态：一个 Web 应用

「游匠工坊」是一个以"游戏项目"为中心组织的 Web 工作台。开发者在一个界面内完成：灵感构思 → 文案生成 → 美术素材生成 → 开源素材检索 → 按 Godot 目录结构导出。AI 能力支持对接各类云端 API 和本地部署的 AI 服务（如 ComfyUI），在 Agent 中可直接调用工作流，实现统一入口管理。

2目标用户及痛点

面向谁 · 什么场景 · 当前的不便

核心用户群体

  • 独立游戏开发者：1-3 人小团队，一人多岗
  • 游戏开发学习者：想入门但被多工具门槛劝退
  • Game Jam 参赛者：限时内需快速产出全套素材
  • 有 AI 工具基础的开发者：已部署 ComfyUI 等本地工具，但苦于调用繁琐

使用场景

  • 项目启动期：构思世界观、角色设定、剧情大纲
  • 素材生产期：批量生成角色立绘、场景图、道具图标
  • 素材补充期：检索免费开源素材填补空白
  • 集成导出期：按引擎目录结构打包，导入 Godot

3价值与意义

效率提升 · 社会价值

效率提升价值

  • 流程整合：4-5 个工具的切换成本归零，单界面完成全流程
  • 本地工具简化：把 ComfyUI 工作流调用从"改 JSON+轮询"简化为"填表单+点按钮"
  • 统一 AI 接入：支持各类云端 API 和本地部署 AI 服务的对接，灵活选择
  • 产物自动归档：按项目/类型自动整理，导出即引擎可用

社会与教育价值

  • 降低独立游戏门槛：让更多有创意但缺资源的人能做出游戏
  • AI 工具平民化：把 ComfyUI 等高门槛本地工具封装为易用界面
  • 开源生态贡献：项目开源，复用并反哺已有方案
  • 学习工作场景：本身就是"用 AI 辅助复杂创作任务"的典型学习工作场景

AI 能力对接设计

☁️ 云端 API 对接
灵活配置

支持对接各类云端 AI API 服务，用户在设置页配置服务地址和密钥后即可使用。密钥存储在浏览器本地，不上传服务器，保障隐私安全。

🖥️ 本地部署 AI 服务对接
核心亮点

支持对接本地部署的 AI 服务（如 ComfyUI），默认连接 localhost 端口。用户在界面中选择工作流模板，上传参考图、设置参数后一键执行，无需手动修改 JSON 和轮询。ComfyUI 工作流可在 Agent 中直接调用，实现更智能的自动化流程。

无需 AI 的基础功能（纯前端实现）

📋 项目管理

多项目隔离，每个游戏项目独立管理素材、文案、进度。

🗂️ 素材管理

按类型（角色/场景/道具/UI）分类，支持标签、搜索、预览。

📊 计划推进

待办清单 + 进度看板，跟踪各环节完成度。

以上功能使用浏览器 IndexedDB/localStorage，完全离线可用，零依赖。

5技术实现方案

基于 TRAE IDE 开发

技术栈

  • 前端：React + Vite + TypeScript
  • 本地服务：Fastify（处理 ComfyUI 代理、素材服务）
  • 存储：IndexedDB（项目数据）+ 文件系统（素材）
  • AI 接入：云端 API / 本地 ComfyUI
  • 开发工具：TRAE IDE

初赛 Demo 范围（1 个月聚焦）

  • 必做：项目管理 + 素材库 + 计划推进
  • 必做：AI 文案生成（API 对接）
  • 必做：AI 美术生成（API 对接 + ComfyUI 连接器）
  • 加分：Godot 目录结构导出
  • 复赛扩展：音乐/音频生成、Godot 实时集成

TRAE 能力运用的独特思路

本项目将"调用本地部署 AI 工具"这一高门槛操作，通过 TRAE 的 Skill 机制封装为可复用能力。ComfyUI 工作流可在 Agent 中直接调用，本提案进一步将其产品化为 Web 界面的"ComfyUI 连接器"模块，让非技术用户也能一键调用本地工作流生成流程。这是对 TRAE 能力的深度运用，实现 AI 工具的统一管理和调用。
