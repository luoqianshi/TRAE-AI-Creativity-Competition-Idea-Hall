// TECH PRINCIPLES

四层匹配引擎

从关键词提取到评分输出，全链路智能化处理。

LAYER 01 — EXTRACT
智能关键词提取
对JD文本进行分词和实体识别，自动提取技能关键词（如"Python""机器学习"）、学历要求（如"本科以上"）、经验年限（如"3年以上"）、行业领域（如"金融""电商"）四大类关键词，构建结构化的岗位画像。
LAYER 02 — MATCH
多维度匹配算法
对每个关键词进行三级匹配判定：精确匹配（关键词完整出现）、模糊匹配（同义词/缩写变体，如"JS"匹配"JavaScript"）、上下文匹配（关键词相关技能出现在上下文中，如"Vue生态"匹配"Vue.js"）。不同匹配等级赋予不同权重分值。
LAYER 03 — WEIGHT
智能权重分配
不是所有关键词都同等重要。系统根据关键词在JD中的出现频率、位置（标题 vs 正文末尾）和强调方式（如"必须""精通"vs"了解"）自动计算权重。标注为"必须"的关键词缺失会大幅扣分，标注为"加分项"的关键词缺失仅轻微影响。
LAYER 04 — REPORT
可视化评分报告
最终生成0-100分的综合评分，并按技能/学历/经验/领域四个维度输出分项得分。关键词以"命中/弱匹配/缺失"三色标签展示，缺失关键词自动生成"建议在简历中补充"的优化提示。
// CORE FEATURES

六大核心能力

从输入到报告，全流程设计让简历筛选变得高效且可量化。

01

一键粘贴分析

JD和简历文本直接粘贴，无需上传文件或填写表单。10秒内输出完整匹配报告，零学习成本。

02

同义词智能识别

"JS"自动匹配"JavaScript"，"MySQL"匹配"SQL数据库"，覆盖200+常见技术名词的别名和缩写。

03

关键词权重计算

"必须""精通"标注的关键词权重3倍于"了解""熟悉"。缺失一个"必须"关键词比缺失三个"加分项"扣分更多。

04

四维度分项评分

技能匹配、学历匹配、经验匹配、领域匹配四个独立维度评分，一眼看出简历在哪方面薄弱。

05

简历优化建议

针对缺失关键词自动生成优化建议，精确告诉求职者"在技能描述中补充Vue.js""增加金融行业项目经验"等具体改进方向。

06

求职者自查模式

求职者在投递前自查简历匹配度，从"盲投50份0回复"变成"投5份拿3个面试"，大幅提升投递效率和信心。
