产品概述

📖
什么是赛博日记本？
赛博日记本是一款命令行工具，专为追求完全自主掌握日记文件的用户设计。 它可以将您存储在 /diary 文件夹中的 Markdown 格式日记文件， 转换为精美的 HTML 预览、查看和统计页面，让您的日记以直观的可视化方式呈现。

核心功能

📅
日历视图展示
以日历形式展示所有日记，有日记的日期会用圆圈标记。日记内容越多，圆圈越大， 让您一眼就能看出写作频率和内容量的变化。点击日期即可查看对应日记的完整内容。
👁️
智能预览
支持日记内容的开头预览，点击后可查看全部内容。预览时会显示日记的字数统计， 让您快速了解每篇日记的篇幅。
🔍
全文搜索
在浏览器中根据日记内容进行全文搜索，快速定位您想要查找的日记条目， 支持关键词匹配和模糊搜索。
📊
数据统计
自动统计日记数据，包括：
  • 每周、每月、每年的日记总数
  • 每周、每月、每年的日记字数
  • 每个日期的字数统计
所有数据以可视化图表形式展示，点击图表可查看对应日期的完整日记内容。

使用方法

1
存放日记文件
将您的日记文件存放在项目的 /diary 文件夹中。
文件格式：markdown (.md)
命名规则：yyyyMMdd.md
示例：20250801.md, 20260122.md
2
运行生成命令
执行命令行工具，将所有 Markdown 格式的日记文件转换为 HTML、CSS 和 JS 文件。
输出目录：/build
3
打开预览页面
在浏览器中打开 /build 文件夹中的 HTML 文件，即可查看日历视图、搜索日记和浏览统计图表。
