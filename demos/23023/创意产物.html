1创意介绍

FeynmanAgent 是一个面向小学英语语法学习的网页端AI伴学系统。它打破了传统"AI当老师、学生被动听"的单向辅导模式，创新性地采用翻转课堂理念——让孩子扮演老师，向一个"有认知盲区的AI学生"讲解知识点。AI不会直接公布答案，而是根据孩子的讲解质量，装作困惑、提出变体错误或生成进阶小题，引导孩子继续解释、修正和举一反三。

"当我要求孩子把知识点反过来讲给我听时，他的专注度和理解深度明显提升——这与费曼学习法‘以教促学’的思想高度契合。"

—— 项目创始人家教实践观察

想解决的问题

  • 小学生遇到不会的题目时，直接依赖搜题软件或大语言模型拿答案，短期效率高，长期却削弱独立思考、表达和纠错能力。
  • 通用大模型在教育对话中容易顺从用户错误说法，甚至产生事实性误导，缺乏严谨的教学流程约束。
  • 现有AI学习机价格较高（2000–5000元），普通家庭存在硬件门槛；而通用聊天机器人又容易变成"答案机器"。

核心技术路径

RAG 知识检索 前置隐式诊断 LangGraph 状态机 Harness 中间件管线 Vue3 前端 FastAPI 网关

4系统架构与核心流程

系统采用"Harness 中间件管线 + LangGraph 状态机"的双层控制架构，将大模型嵌套在严格的教学闭环中，实现对话流的精准控制与抗幻觉保障。

核心创新点

  • 前置隐式诊断（LLM as Judge）：独立轻量级模型 MODEL1 在用户输入到达主生成节点前，强制对比 RAG 检索出的 Ground Truth，输出结构化诊断结果，从架构上切断模型顺从性偏差。
  • LangGraph 状态机编排：将"安全对齐 → 记忆注入 → 知识检索 → 逻辑诊断 → 追问/反问/测试 → 记忆归档"固化为有向图，通过条件边实现精准路由。
  • Harness 中间件管线：将记忆提取、RAG 检索、结构化解析、安全对齐等操作封装为标准化中间件，实现虚拟学生推理过程的沙盒化与白盒化。
  • 双层记忆架构：短期 Checkpointer 保障多轮对话上下文；长期记忆浓缩机制在 Token 达到阈值时异步提炼学情画像，确保人设与认知状态连续。
