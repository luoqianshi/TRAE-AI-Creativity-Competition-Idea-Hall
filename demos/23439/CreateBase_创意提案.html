一、创意名称 + 创意介绍

Q 想解决什么问题

AI创作（图片/视频/提示词）领域存在"经验黑盒"问题：优质创作方法论散落在各平台、更新极快、难以系统化复用。创作者每次都从零摸索，重复造轮子。现有AI工具只解决"生成"，不解决"怎么生成更好"。

W 为什么会想到做这个

在实际商业视频制作中发现：同一个镜头语言规则被反复使用、同一套爆款公式在不同项目中验证有效、但团队每次都要重新沟通。如果把"经过验证的创作知识"结构化沉淀下来，让AI在创作时自动调用，就能把个人经验变成可复用的"创作资产"。

P 大概是什么产品

一套AI驱动的创作知识操作系统：基于Obsidian知识图谱 + RAG混合检索引擎 + 多Skill智能编排，实现「案例输入 → 知识提炼 → 卡片入库 → 智能检索 → 辅助创作 → 效果反馈 → 知识迭代」的完整闭环。不是笔记工具，是创作力的基础设施。

五、创意亮点（差异化竞争）

🔮

RAG 混合检索引擎

BM25 + TF-IDF + Embedding 三层检索，GPU加速向量匹配

vs Notion AI：只有简单关键词搜索，无语义理解能力
🃏

知识卡 6 段式标准结构

YAML元数据 + 场景/规则/可调用内容/示例/避坑/关联，机器可读+人类可用

vs Obsidian模板：无标准化结构，无法被程序自动消费
🤖

视频分析 → 知识自动提炼

拉片完成后自动扫描可复用方法并建议入库，无需人工整理

vs 所有竞品：无任何产品做到"分析即沉淀"这一步
🚦

Prompt Router 规则路由器

4层流水线(R0铁律→R1内容维→R2技巧→R3质检)自动选卡注入

vs ChatGPT/Claude：无领域知识路由能力，通用模型不懂创作规则
🤝

多 Agent 协作协议

Trae/Codex/Qoder/Peter 多智能体共享同一知识库，协同创作

vs 单Agent工具：无法实现多角色分工协作
📡

平台规则实时追踪

抖音算法变→单独更新一张规则卡→全局生效，秒级同步

vs 付费课程/电子书：内容发布即过期，无法动态更新
