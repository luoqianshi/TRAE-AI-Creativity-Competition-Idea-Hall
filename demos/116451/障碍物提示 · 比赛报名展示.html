Pain Points

视障出行的常见痛点

盲杖与导盲犬是成熟的辅助方式，但在特定场景下仍存在感知盲区，持续语音播报又容易造成信息过载。

前方障碍感知不足

盲杖只能探测到触及范围内的地面障碍，对腰部以上、悬空或突然出现的障碍物难以提前感知。

探测范围有限

传统盲杖的探测角度和距离有限，在开阔空间或人流密集处，难以及时判断障碍物的方位和距离。

持续语音有干扰

全程语音播报容易造成听觉疲劳，也会掩盖环境中的重要声音信息，如车流、人声和警示音。

不是替代盲杖或导盲犬

本项目不声称替代成熟的辅助出行工具，而是作为补充设备，提供额外的前方空间感知能力。

聚焦交互体验验证

核心是验证"震动 + 分级语音 + 主动识别"的多模态反馈模式是否自然、有效、低干扰。

低承诺，高可信

Core Features

核心功能

三层反馈机制：常态震动保持连续感知，危险时叠加声音强化提醒，按键后获取详细信息。

常态扫描

ToF / LiDAR 持续测距，通过震动节奏提示障碍物远近。距离越近，震动频率越高。

危险提示

近距离触发蜂鸣或短命令语音，如"正前方很近，请停下"。命令型提示，直接可行动。

强震动 + 蜂鸣 + 语音

按键识别

用户主动按键后，播报方位 + 几步 + 大小等级 + 模拟名称，如"前方偏左，约两步，有中等障碍物，疑似椅子"。

示例：前方偏左，约两步，中等障碍物，疑似椅子

Hardware Architecture

技术与硬件模块

三层架构：感知层获取数据，判断层做决策，反馈层输出多模态提示。

感知层

左 / 中 / 右 三路 ToF

三个 ToF 传感器分别覆盖左前、正前、右前三个方向，持续读取距离数据，为方位判断提供输入。

左 ToF 中 ToF 右 ToF

判断层

ESP32 / Arduino 主控

接收三路距离数据，计算最近障碍物、方位角、空间占用等级和危险等级，并决定反馈策略。

距离计算 方位判断 危险分级

反馈层

震动 · 蜂鸣/语音 · 按键 · 电池

震动马达提供连续距离反馈，蜂鸣/语音模块用于危险提醒和详细播报，实体按键支持用户主动触发识别。

震动马达 蜂鸣器 语音模块 实体按键 锂电池

Application Scenarios

应用场景

室内外多种出行场景下，提供持续、低干扰的前方空间感知。

室内走廊

狭长空间中持续感知前方行人与障碍物，避免正面碰撞。

房间与楼道

识别桌椅、门洞、楼梯口等室内常见障碍与结构变化。

室外人行道

感知行道树、停放车辆、施工围挡等路边障碍物。

路口过街

路口处辅助感知方向和前方障碍物，辅助判断行进路线。

商场入口

人流密集区域感知前方行人与玻璃门等不易察觉的障碍。

公共交通

站台边缘、车厢内扶手和站立乘客的感知与距离提示。

Value & Impact

价值与意义

社会价值

提升视障用户的出行安全感与独立性，减少对他人陪同的依赖。

用低门槛的硬件方案探索辅助出行的新可能，推动无障碍技术的多元发展。

验证无摄像头方案的可行性，为隐私敏感场景下的辅助技术提供新思路。

效率提升

安静连续提示：震动作为默认反馈通道，不干扰环境听觉，也不会造成听觉疲劳。

危险时强化提醒：进入危险距离后叠加声音和命令型语音，确保紧急信息不被忽略。

按需获取详细信息：用户主动按键才触发详细播报，掌控信息获取的节奏和频率。
