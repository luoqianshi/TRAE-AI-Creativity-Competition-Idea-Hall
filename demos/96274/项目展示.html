项目概述

PLC SmartConsole 是一款面向工业自动化领域的桌面级 SCADA（数据采集与监控）控制系统。 采用 WPF/.NET 8 技术栈，集成基恩士（Keyence）PLC 通信协议，支持通过 XML 配置文件 动态构建用户界面，实现零代码调整界面布局。

项目全程使用 TRAE IDE + AI 助手 进行开发，从架构设计到功能实现， AI 辅助编程显著提升了工业软件的开发效率，让工程师能够专注于业务逻辑而非底层细节。

技术架构

技术创新点

🌍 独创双轨翻译机制

针对工业软件国际化难题，设计了"菜单 JSON + XML 配置"双轨翻译系统。 菜单资源通过 Excel 表管理，XML 配置中的中文属性通过 XmlLocalizationService 自动提取并生成翻译表。切换语言时所有页面即时刷新，无需重启软件。

⚡ XML 驱动的动态 UI

所有功能页面（手动操作、运行数据、IO 监控等）的布局均从 XML 配置文件动态加载。 工厂工程师无需编写代码，仅通过修改 XML 即可调整按钮位置、添加监控项、修改显示名称， 极大降低了后期维护成本。

🔒 企业级权限管控

实现超级管理员 / 普通用户双角色体系，敏感模块（PLC 监控、时序曲线）仅限管理员访问。 用户数据采用 HMAC-SHA256 签名防篡改，确保生产环境的安全性。

🎨 现代化视觉设计

采用深蓝科技风渐变配色，自定义无边框窗口，支持深色/浅色主题一键切换。 所有视觉元素通过 XAML 资源字典管理，主题切换时全局资源热替换，无闪烁。
