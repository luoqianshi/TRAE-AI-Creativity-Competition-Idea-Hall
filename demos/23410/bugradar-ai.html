错误类型

TypeError: Cannot read property 'map' of undefined

JavaScript 运行时类型错误，尝试对 undefined 值调用数组方法 map()。

可能原因
  • API 请求尚未完成，list 状态初始值为 undefined
  • API 返回异常，未正确处理空数据或错误状态
  • 组件在数据加载完成前即执行渲染逻辑
相关知识点

可选链操作符 ?.、空值合并 ??、React 条件渲染、useEffect 依赖管理

推荐修复

为列表渲染添加空值保护，使用可选链与默认空数组：

// List.jsx 第 24 行修改 const renderList = () => { return list?.map(item => ( <ListItem key={item.id} data={item} /> )) ?? <p>暂无数据</p>; }; // 或更兼容的写法 const safeList = Array.isArray(list) ? list : []; return safeList.map(item => ...);
预防措施
  • 初始化状态时使用合理的默认值：useState([])
  • API 层统一封装响应处理，确保返回结构一致
  • 为异步数据渲染添加 Loading 状态管理
