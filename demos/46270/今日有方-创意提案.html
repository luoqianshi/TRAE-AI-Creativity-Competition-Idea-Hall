创意介绍
Creative Introduction
想解决什么问题

现代都市人在快节奏生活中经常感到迷茫、疲惫、不知所措——"今天到底该怎么过？"这个看似简单的问题，却很少有人能给出让自己安心的答案。

市面上的工具要么是冷冰冰的效率软件，要么是玄学感厚重的命理应用，要么是千篇一律的情绪记录本。缺少一个把东方生活智慧（黄历、节气、五行）与现代情绪觉察结合、用 AI 把传统文化翻译成"今天可以怎么做"的轻量入口。

为什么会想到做这个

灵感来自一个日常观察：很多人手机里装着黄历 App，但只看"宜忌"两个字就关掉；很多人想做情绪管理，却坚持不过三天。

我们发现：传统的黄历节气本身蕴含着"顺时而为"的生活智慧，只是表达方式老旧、缺乏个人化、无法落到具体行动。如果能用 AI 把它"翻译"成每个人今天可以戴什么、穿什么、吃什么、怎样安顿情绪——传统文化就能真正回到日常生活里。

"不是把玄学讲得更准，而是把'顺时而为'这件事，做得让人愿意每天打开。"
大概是什么产品

今日有方 是一款微信小程序，以"今日"为核心场景，整合黄历节气、五行智慧、情绪觉察与 AI 对话，每天给用户一份"今天可以怎么做"的温柔指南。

产品包含：每日能量签、黄历宜忌、五行穿衣/配饰/食养推荐、节气养护、5 套自我测试、AI 情绪伙伴"小息"、节气生活圈等模块。后端基于 NestJS + Prisma + AI 大模型构建，前端使用 uni-app + Vue3 开发。

微信小程序 NestJS 后端 AI 对话 黄历节气 情绪觉察 五行智慧

3
价值与意义
Value & Significance
📈

商业价值：高粘性的每日打开场景

"今日"是天然的高频入口——每天打开看黄历、读能量签、查推荐，形成稳定的日活习惯。后续可延伸至东方生活美学电商（推荐配饰、食材、穿搭单品）、付费深度报告、品牌联名节气礼盒等。情绪健康 + 东方生活美学是尚未被充分开发的蓝海赛道。

🌿

社会价值：让传统文化回到生活

把黄历、节气、五行这些被年轻人觉得"老土"的传统文化，用 AI 翻译成生活化的行动建议——不是算命，而是"顺时而为"的生活哲学。降低情绪自我照顾的门槛，让"照顾好自己"这件事变得温柔、可执行、有文化温度。

⚡

效率提升：AI 个性化推荐

用 AI 把生辰八字、节气、情绪状态、天气等多维数据融合，自动生成"今天戴什么、穿什么、吃什么、怎么安顿情绪"的个性化方案。用户无需自己翻黄历、查命理、研究节气——AI 帮你把复杂的东方智慧，翻译成一句"今天可以这样做"。

💚

情绪价值：温柔的自我照顾入口

不是冷冰冰的工具，而是一位"不催促的朋友"。AI 伙伴"小息"用东方生活感的语言，给疲惫的都市人一个温柔的出口——"今天也要温柔一点"、"照着自己的节奏往前"。让情绪管理不再是任务，而是一种被看见的陪伴。

技术实现
Technical Architecture
两层推荐架构

产品核心是"两层推荐系统"，把东方智慧变成可执行的建议：

Tier 1 时令基础层：基于黄历干支五行、节气季节属性、当日宜忌，生成所有人可用的基础推荐。

Tier 2 八字校准层：当用户登记生日后，基于八字四柱五行分析（日主元素、旺弱判断、喜用神/忌神），以更高权重覆盖 Tier 1，生成个人化推荐。

AI 能力亮点 · 已实现

1. 情绪对话"小息"：结合五行语境（当日五行、用户八字、节气）构建 Prompt，让 AI 用东方生活感的语言回应情绪，而非通用心理话术。

2. 推荐内容生成：AI 把黄历宜忌、节气食宜、五行脏腑对应等数据，翻译成生活化的行动文案——不是"宜祭祀、忌开市"，而是"适合出门走走、少做消耗大的决定"。

3. 能量签个性化：根据用户完成测试的状态、生辰档案，AI 生成贴合当日状态的签文解读，从基础版到高阶版逐层个性化。

AI 能力亮点 · 进阶规划

在现有 Prompt 工程基础上，规划引入 AI Agent + RAG 架构，让"今日有方"从"内容推荐工具"进化为"东方生活 AI 助理"：

4. 东方知识库 RAG 检索增强：构建中医典籍、节气物候、五行理论、黄历释义的专业知识库（向量化存储），让 AI 回答不再依赖单一 Prompt，而是基于权威典籍检索增强生成。例如用户问"为什么小满要吃苦味"，AI 可引用《黄帝内经》《本草纲目》原文，给出有依据的解读，而非泛泛而谈。

5. 多 Agent 协同推荐：将"戴穿吃"三层推荐拆分为独立 Agent：

• 配饰 Agent：调用电商 API 检索符合五行元素的实物商品，给出可购买链接
• 穿搭 Agent：结合实时天气 API + 用户衣橱档案，生成今日具体穿搭方案
• 食养 Agent：结合节气食材库 + 用户体质，生成可执行的菜谱与采购清单
• 情绪 Agent：跟踪用户 7 日情绪曲线，主动识别低落周期并推送干预建议

6. Function Calling 工具调用：让小息 AI 具备"动手能力"——用户说"帮我订一份今日食养食材"，AI 可调用外部 API（生鲜电商、外卖、日历提醒）完成下单或加入待办。从"给建议"升级到"帮你做"。

7. 长期记忆与用户画像：基于向量数据库构建用户长期记忆：情绪模式、五行偏好、测试历史、推荐反馈。让 AI 记住"你上周说压力大""你对苦味食材接受度低"，实现真正的个性化陪伴，而非每次对话从零开始。

8. 节气日历 Agent：自动监控节气交替、用户生日、能量周期，在关键节点主动推送定制化养护方案。例如"明日立秋，你的金气偏弱，今晚可提前润肺"。
