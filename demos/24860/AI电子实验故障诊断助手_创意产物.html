📋 项目概述

核心理念：电子实验是电子工程师成长的必经之路，但"实验失败→找不到原因→求助无门→放弃"是大多数学生和职场新手的真实写照。我们不做仿真工具，不做硬件套件，只做一件事——当你实验出问题的时候，AI 立刻告诉你为什么，并讲清楚原理。

产品定位

一款纯软件的 AI 助手，面向大学生和职场新手。用户用文字描述实验现象或上传电路图/波形图，AI 即时诊断故障原因、给出排查步骤、讲解背后原理，让用户不仅知道"怎么修"，还知道"为什么"。

问老师/同事不好意思

基础问题反复问，怕被认为"太笨"；论坛提问半天没人回，耽误实验进度。
AI 解决：7x24 在线，任何问题都可以问，没有"蠢问题"，AI 会根据你的水平调整解释深度。
📚

只会照抄不会思考

按实验指导书接好电路，出了故障就懵了，因为根本不理解电路原理。
AI 解决：不仅告诉怎么修，还讲解"为什么会出现这个问题""背后的物理机制是什么"，培养工程思维。
⏰

排查效率低下

没有系统性的排查思路，东试西试，一个下午过去还没找到问题。
AI 解决：提供结构化排查流程（从电源→信号→负载逐步排查），每一步都有明确的判断标准。
📝

实验报告不会分析

实验数据拿到了，但不知道怎么分析、怎么解释异常、怎么写讨论部分。
AI 解决：根据实验数据和现象，自动生成数据分析建议、异常原因解释、讨论部分写作框架。

🎯 核心功能

🔍 故障智能诊断

用户描述实验现象（文字/图片），AI 基于电路知识和经验库，快速定位故障原因，准确率达 85% 以上。

📋 结构化排查指南

不是给一堆可能原因让用户自己试，而是提供步骤化的排查流程，每一步都有明确的判断方法和预期结果。

💡 原理解析

每个故障诊断都附带原理讲解，从"现象→原因→机制→预防"四层递进，培养用户独立分析能力。

📊 波形/数据对比

AI 生成"正常波形 vs 故障波形"对比图，标注关键差异点，让用户直观理解问题所在。

🎯 个性化解释

根据用户知识水平（大一/大四/职场新人）调整解释深度，新手用比喻，老手用公式。

📚 案例库积累

每个解决的问题都沉淀为案例，形成可搜索的"故障百科"，后来者可以快速找到相似问题的解决方案。

💬 产品交互演示

👨‍🎓
老师好，我搭的共射放大电路，输出波形上半部分被削平了，测了一下 Vce 只有 0.3V 左右，请问是什么原因？
🤖
诊断结果：饱和失真

根据你的描述（波形上半部分削平 + Vce ≈ 0.3V），这是典型的饱和失真。

原因分析：
静态工作点 Q 设置过高，三极管进入了饱和区。正常 Vce 应该在 1/2 Vcc 左右（比如 Vcc=12V 时，Vce 应在 5-7V）。

排查步骤：
1️⃣ 测量基极电压 Vb，计算基极电流 Ib = (Vcc - Vb) / Rb
2️⃣ 如果 Ib 过大，说明 Rb 取值太小，需要增大 Rb
3️⃣ 目标：将 Vce 调整到 Vcc/2 附近

原理讲解：
三极管放大需要工作在放大区（发射结正偏、集电结反偏）。当 Ib 过大时，Ic 也增大，Rc 上压降增大，导致 Vce 减小。当 Vce < 0.3V 时，集电结也变成正偏，三极管饱和，失去放大能力。此时信号正半周进入饱和区，导致上半周被削平。

正常波形： 饱和失真波形：

/ \ / \
/ \ / \
/ \ / \
💡 预防措施：设计时预留足够的动态范围，输入信号幅度不宜过大。
👨‍🎓
明白了！我 Rb 用的是 10k，换成 47k 后 Vce 到了 6V，波形也正常了。谢谢老师！
🤖
很好！你找到了正确的方向 🎉

这次经历其实很有价值，建议你记录下来：
• 故障现象：饱和失真（波形削顶 + Vce 过低）
• 根本原因：Q 点过高 → Ib 过大 → Rb 过小
• 解决方法：增大 Rb 从 10k 到 47k
• 关键指标：Vce 应 ≈ Vcc/2

下次遇到类似问题，可以先检查 Vce 是否在合理范围，这是判断 Q 点位置的最快方法。

场景二：职场新人调试产品

刚入职的硬件工程师小李在调试电源模块，输出电压纹波超标，但不知道从哪里入手排查。

场景三：电子设计竞赛备赛

竞赛团队在做信号处理题目，滤波器效果不理想，团队成员对滤波器理论理解不深。
使用方式：团队上传滤波器电路图和实测频响曲线，AI 分析指出 Q 值过高导致带内波动，建议调整反馈电阻比值，并解释"Q 值与带宽、增益的关系"。团队不仅解决了问题，还加深了对滤波器设计的理解。

场景四：自学者的深夜求助

电子爱好者小张周末在家做项目，晚上 11 点 MCU 不工作，论坛发帖没人回，群里也安静了。

⚙️ 技术实现方案

核心架构

🧠 大语言模型（LLM）

基于 GPT-4/Claude 等大模型，通过 Prompt Engineering 和 RAG（检索增强生成）技术，让 AI 具备电子工程专业知识。

📚 知识库（RAG）

构建电子实验故障案例库、电路原理知识库、排查手册库，AI 回答时先检索相关知识，再生成答案，确保准确性。

👁️ 视觉理解（VLM）

集成多模态大模型，支持用户上传电路图、PCB 照片、示波器截图，AI 自动识别电路结构和波形特征。

📊 波形生成

基于电路参数自动生成"正常波形"和"故障波形"对比图，帮助用户直观理解问题。

技术栈

Python / FastAPI OpenAI GPT-4 API LangChain RAG 框架 Pinecone 向量数据库 React 前端 WebSocket 实时通信 Matplotlib 波形绘制 Cloudflare R2 存储

🗓️ 开发路线图

第一阶段：MVP（1-2个月）

聚焦模拟电路实验，支持文字描述故障现象，AI 给出诊断和排查建议。覆盖 10 个最常见实验（共射放大、射随器、差分放大、运放应用等）。

第二阶段：多模态支持（2个月）

增加图片上传功能，支持电路图识别、波形图分析、PCB 照片诊断。扩展至数字电路实验（逻辑门、计数器、时序电路等）。

第三阶段：知识库建设（2个月）

积累 1000+ 真实故障案例，建立可搜索的"故障百科"。引入用户评分机制，优质案例上浮。支持用户贡献案例。

第四阶段：个性化与社区（持续）

根据用户历史提问构建能力画像，推荐针对性学习内容。建立用户社区，支持经验分享、互助答疑。
