💎 价值与意义

不只是又一个效率工具，它是数字时代的工作记忆外挂。

📈

商业价值

面向全球 2 亿+ 知识工作者。付费意愿强——任何需要写日报/周报、需要证明工作产出的职场人都是潜在用户。可扩展至企业版（团队工作可视化）和企业培训场景。

商业模式：基础版免费 + Pro 订阅（高级 AI 分析 + 云端同步）+ 企业版（团队仪表盘 + SSO）

⚡

效率提升

90%

日报撰写时间减少 90%。从 "回忆 20 分钟 + 打字 10 分钟" 变为 "按快捷键 + 复制粘贴"。同时通过时间可视化帮助用户识别效率黑洞，优化工作习惯。

🌍

社会价值

在 AI 生成内容泛滥的时代，提供"真人工作证明"——摄像头出镜 + 屏幕操作记录，为远程办公者、自由职业者、AI 辅助工作者建立信任链条。减少无意义的日报制度带来的精神内耗。

推动"记录而非监控"的健康工作文化——数据属于用户本人，而非管理者。

🎯 目标用户与场景

这些人按下 Ctrl+Shift+Z 的频率会最高。

💻

软件工程师 / 开发者

每天在 IDE、终端、浏览器间切换数十次。需要回溯"刚才那块代码在哪改的"、自动生成 Standup 日报。

场景：下班前按快捷键，输出今日 Coding Log + 关键截图

🎨

设计师 / 创意工作者

灵感稍纵即逝，过程比结果更重要。需要记录设计迭代的全过程，向客户展示"为什么选这个方案"。

场景：设计评审前导出时间线 GIF，展示从初稿到终稿的完整演变

🏠

远程办公者 / 自由职业者

没有同事在旁边见证你的工作。需要向客户证明"这 3 小时我确实在做事"，建立远程信任。

场景：项目结算时附上 AI 生成的工作证据报告

📚

学生 / 研究生

论文写到哪了？今天看了哪些文献？实验参数改过哪些？告别"我在实验室待了一天但不知道干了啥"。

场景：每周组会前一键生成研究进展报告

🔒 隐私设计

"记录"不等于"监控"。我们把数据控制权完全交给你。

🔄

环形缓冲区

只保留最近 N 秒的数据（默认 5 分钟）。旧数据自动覆盖，不会无限积累。你的硬盘和隐私都不会被撑爆。

🏠

全部本地处理

屏幕截图、摄像头画面、活动日志 100% 存储在本地。AI 分析通过你配置的 API Key 直接调用，数据不经过第三方服务器。

🎛️

完全可配置

FPS、缓冲时长、摄像头开关、截图质量、快捷键——所有参数都可以在 config.py 中调整，没有任何隐藏设置。

🔑

你是唯一拥有者

开源代码，可自行审查。报告生成后由你决定分享给谁。没有云端后台，没有遥测上报。
