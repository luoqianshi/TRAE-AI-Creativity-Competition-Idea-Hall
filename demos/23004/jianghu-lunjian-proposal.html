创意介绍 · 想解决什么

「AI 玩游戏」不该只是在旁边看

当下的「AI 玩游戏」大多是 AI 替你打、你被晾在一边，参与感被掏空；而硬核策略对战又因操作门槛把普通人劝退。江湖论剑给出的答案是 「人出脑、AI 出手」——你用自然语言指挥一个 AI 策士写出战斗逻辑，再看它在水墨擂台上真刀真枪地兑现你的谋略。指挥 AI 打架，比亲手操作更有运筹帷幄的爽感。

心诀 · onIdle(me, enemy, game) — AI 策士亲笔 
// 玄甲铁骑：开局提速贴脸，残血则风筝拉扯
function onIdle(me, enemy, game) {
  const dist = cheby(me.character.position, enemy.character.position);
  if (me.skills.gale.ready && dist > 3) return me.cast("gale");      // 绝尘 · 2× 突进
  if (dist <= 1 && me.skills.armorpiercer.ready) return me.cast("armorpiercer");
  if (me.hp < 40) return me.cast("stirrup_shadow");        // 伏鞍 · 脱战闪避
  me.face(toward(enemy)); me.move(toward(enemy));
}

目标用户 · 使用场景 · 痛点

给「想指挥 AI，却没有擂台」的人

面向谁 · 在哪用

  • 策略 / 自走棋玩家：享受运筹，厌倦无脑手操。
  • AI 与 Agent 爱好者：想把 prompt 功力变成可量化的胜负。
  • 想体验「调教 AI」的轻度玩家与开发者：零门槛上手。
  • 场景：创角 → AI 写心诀 → 训练 → 排位 → 复盘改本，碎片时间即可一局。

没有它，你会遇到

  • 市面「AI 对战」AI 固定不变，打几局就没了成长感。
  • 硬核对战纯靠手速与操作，把非硬核玩家挡在门外。
  • 想「指挥 AI 打一场」，却找不到透明、可复盘、能排位的擂台。
  • 调过的 prompt / 脚本好不好，没有真实胜负去校验。
价值与意义

边玩，边把和 AI 协作练成肌肉记忆

玩法 / 效率创新

  • 把「写提示词、调脚本、读复盘」做成游戏核心循环。
  • 玩家在娱乐中自然练习拆解策略、与 AI 协作——一种「边玩边学 AI」的新娱乐形态。
  • 透明 JS 沙盒 + 逐招诊断，让「为什么赢 / 为什么输」看得见、可迭代。

商业与生态价值

  • 天然契合 AI 工具生态，是 Agent 能力的趣味试炼场。
  • 可延展赛季排位、门派 / 招式扩展、观赛与战录分享。
  • 玩家产出脚本与攻略形成 UGC 与社区粘性，复玩驱动持续运营。
