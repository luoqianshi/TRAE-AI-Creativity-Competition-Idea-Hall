攻略信息分散

小红书、马蜂窝、抖音、知乎……碎片化的攻略让你比来比去，耗费大量时间却难以形成完整方案。

节假日人流难判断

六大核心功能

从对话到地图，从知识到推荐，打造完整的智能出游体验

💬

多轮对话规划

用自然语言说出模糊想法，AI 主动追问补全信息，在对话中逐步明确你的理想行程。

🗺️

WebGIS 地图展示

目的地、路线、景点、美食、住宿一图呈现。支持交互点击，空间信息一目了然。

📚

RAG 知识库

基于向量检索的旅游知识库，提供景点介绍、避峰建议、路线经验等深度内容。

🌤️

实时 API 接入

天气、人流热度、交通可达性、餐饮推荐动态获取，确保规划信息真实有效。

🎯

智能推荐排序

综合偏好、距离、人流、天气、预算等多维度评分，动态调整权重，推荐最优方案。

📅

行程可视化

Day 1 · Day 2 · Day 3 每日行程搭配地图路线，文字 + 空间双重呈现，所见即所得。
