真实商业主体对标

本产品不做单纯资料库，而是吸收成熟产品的能力：权威内容库、学习解析、来源锚定 AI、文创传播，再组合成“古籍理解即服务”。

对标 1

识典古籍

参考其“权威古籍资源 + 智能工具 + 公益开放”的信任模型。我们的差异：从专业阅读平台下探到大众理解、课堂学习和内容传播。

对标 2

中华经典古籍库

参考其“出版社版权资源 + 机构数据库订阅”的 B2B 模型。我们的差异：增加 AI 解释、可视化和课程/文旅场景的轻量交付。

对标 3

古诗文网 App

参考其“诗文学习、注释翻译、朗读、检索”的 C 端学习入口。我们的差异：不止查资料，而是生成学习路径、互动题卡和短视频脚本。

对标 4

NotebookLM 类产品

参考“基于用户提供来源回答”的 AI 知识库范式。我们的差异：垂直聚焦古籍，强调出处、异文、典故和现代传播表达。

产品创意内核

高获奖率来自明确冲突：古籍内容很有价值，但普通人看不懂、创作者讲不好、文旅机构难转化。解决方案是“可信解释 + 创意表达 + 可传播输出”。

用户痛点

  • 学生：文言文注释零散，背了但不理解。
  • 创作者：想讲传统文化，但缺少脚本和视觉素材。
  • 文旅/博物馆：馆藏故事难以变成互动体验。

核心方案

  • 原文解析：逐句翻译、字词解释、典故溯源。
  • 图谱理解：人物、地点、情绪、主题可视化。
  • 传播生成：短视频分镜、题卡、海报、讲解词。

商业模型设计

参赛时不要只讲“弘扬传统文化”，要讲清楚谁付费、为什么付费、先做哪个场景。

C

C 端学习会员

面向中学生、大学生、传统文化爱好者，提供每日古文、逐句讲解、背诵题卡、错题本、AI 讲解音频。基础免费，高级学习计划和导出能力会员化。

B

B 端学校/机构版

给学校、图书馆、博物馆、研学机构提供“古籍课程生成器”：教师可生成讲义、题库、课堂互动页，机构可生成展陈讲解与导览脚本。

IP

文旅 IP 共创

与地方文旅、博物馆、非遗馆合作，把地方典籍和人物故事做成互动 H5、短视频脚本、纪念票卡、文创包装，按项目制收费。

API

古籍解释 API

面向阅读 App、教育平台、内容工具开放“文言解释、典故识别、题卡生成、出处校验”接口，形成按量调用收入。

技术方案

正式产品采用“古籍知识库 + RAG 检索 + 多智能体生成 + 人审纠错”的路线，保证不是单纯套壳聊天机器人。

可信来源层

接入公开古籍资源、授权整理本、校勘数据和教师自建素材；所有解释都带来源、篇章位置和置信度。

理解生成层

分为翻译智能体、典故智能体、图谱智能体、创意脚本智能体，避免一个模型同时承担所有任务导致不稳定。

风控纠错层

对人物、年代、出处、译文进行校验；涉及学术争议时展示“多解释并存”，不把 AI 输出伪装成唯一标准答案。

古籍秒懂助手是一款面向学生、传统文化创作者和文旅机构的 AI 古籍活化工具。它解决普通人看不懂古文、教师备课耗时、创作者难以把古籍转化为现代内容的问题。用户输入或选择一段古籍文本后，系统会生成白话解释、字词典故、知识图谱、短视频分镜、互动题卡和文创海报，让古籍从“资料库里的文字”变成“人人能理解、能分享、能再创作的文化内容”。产品初期面向学习工作赛道，同时参加社会公益中的古籍活化工具方向，后续可面向学校、图书馆、博物馆和文旅机构提供课程包与展陈内容生成服务。
