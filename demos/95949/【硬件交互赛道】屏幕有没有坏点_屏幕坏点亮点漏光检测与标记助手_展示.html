HOW IT WORKS · 三步出报告

选卡 → 标记 → 出结论

输入是"你怀疑哪块屏"，处理是"纯色铺满 + 像素放大 + 点击归档"，输出是"亮点暗点漏光各几个、够不够换货、位置在哪"。

01 / SELECT

选测试卡

红绿蓝查亮点暗点，白卡查暗点，黑卡查漏光，灰阶查均匀度。点一张铺满整个舞台。

→
02 / MARK

标记可疑点

看到不对劲的位置直接点。像素放大镜跟着鼠标走，帮你把针尖大的点放大成网格看清。标记时选亮点/暗点/漏光。

→
03 / REPORT

出体检报告

右侧档案实时累计各类数量，对照主流厂商换货阈值，给出"建议换货/可观察/正常"的结论和位置图。

怎么用 TRAE 做出来的

从痛点到原型，一次跑通

我在 TRAE Work 里先把"普通人验屏"这件事拆成四个环节——选测试卡、全屏检测、点击标记可疑点、生成体检报告，确认每一步都有明确的输入和输出。再用 TRAE IDE 搭了一个"屏幕检测工坊"形状的展示页：首屏就是一片暗室里的测试卡舞台，顶部是红绿蓝白黑灰阶六张测试卡的选择条，点一张舞台就切到对应纯色。

梳理痛点→ 拆解模块→ 生成 HTML 展示页→ 调整交互原型

舞台中央可以点击任意位置标记可疑点，旁边悬浮一个像素放大镜显示点击点周围 11×11 的像素网格，右侧实时累计坏点档案、统计亮点暗点漏光数量并对照主流厂商换货阈值给出"建议换货/可观察/正常"的结论。页面重点演示切换测试卡和增减标记点后，档案统计与阈值判定如何联动，还做了测试卡切色过渡和标记点脉冲闪烁的动效，而不是只放一张功能介绍图。
