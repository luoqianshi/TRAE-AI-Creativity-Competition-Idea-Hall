⚠️ 为什么需要沙盒浏览器？

当前主流浏览器存在三大数据主权问题：

强制云端同步

书签、密码、历史记录默认上传厂商服务器，用户无法完全控制数据流向。

隐蔽行为跟踪

浏览习惯、搜索记录、停留时长被采集用于广告推送，用户画像被持续构建。

数据锁定效应

各厂商导出格式互不兼容，用户一旦深度使用某浏览器，迁移成本极高。

💡 核心解决方案

📁

本地 JSON 存储

所有数据以标准 JSON 格式保存在用户设备，随时可用文本编辑器查看、修改、备份。

🔐

密码加密

支持 AES-256 加密整个数据目录，即使设备丢失，数据也无法被他人读取。

🚫

零同步承诺

浏览器本身不包含任何云同步模块，从源头杜绝数据上传可能。

🛡️

零跟踪设计

不收集使用习惯、不推送个性化内容、不建立用户画像，回归工具本质。

✨ 产品功能特性

  • ✓
    标准化数据格式

    书签、历史、密码、下载记录均导出为可读 JSON，支持跨版本兼容

  • ✓
    一键加密/解密

    用户可设置主密码，退出浏览器自动加密，启动时验证密码后解密加载

  • ✓
    便携模式

    整个浏览器与数据可放入 U 盘，在任何电脑上即插即用，不留痕迹

  • ✓
    沙盒隔离

    每个标签页运行在独立进程中，Cookie、缓存、LocalStorage 完全隔离

  • ✓
    数据迁移助手

    支持从 Chrome、Firefox、Edge 一键导入书签与密码，并转换为 JSON 格式

🛠️ 技术实现路径

  • 1
    底层框架：基于 Electron 或 Tauri 构建跨平台桌面应用，内嵌 Chromium 内核保证兼容性
  • 2
    数据层：使用 Node.js fs 模块读写 JSON 文件，通过 crypto 模块实现 AES-256-GCM 加密
  • 3
    沙盒隔离：利用 Chromium 多进程架构，为每个标签页分配独立渲染进程与存储分区
  • 4
    迁移工具：解析 Chrome/Firefox 的 SQLite 数据库，转换为统一的 JSON Schema
