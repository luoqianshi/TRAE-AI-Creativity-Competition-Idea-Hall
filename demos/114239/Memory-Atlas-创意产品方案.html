Memory Atlas
记忆地图

把人生走过的路，变成一张可以探索的地图

Memory Atlas 是一个把个人照片、旅行文字、收藏地点和留言自动整理成「可探索人生地图」的个人记忆网站/小程序。它让普通人的旅行、生活、城市记忆像作品集一样被认真保存。

Problem

回忆没有消失，只是变得很难被找到

很多人拍了大量照片、写过零散文字、收藏过餐厅和地点，但这些内容通常散落在相册、备忘录、社交平台和地图收藏里。时间久了，记忆变得碎片化、不可检索。

照片海量，查找成本极高

手机里存了上万张照片，但想找「去年在京都拍的巷子」时，翻遍相册也找不到。按城市、时间、主题分类几乎不可能手动完成。

内容分散，无法形成完整故事

地图收藏在高德、照片在相册、日记在备忘录、旅行感悟发在社交媒体——它们彼此孤立，无法串联成一个完整的记忆叙事。

普通照片缺少优雅展示方式

很多照片不一定是「摄影作品」，但它们是重要的生活回忆。社交平台只展示精心筛选的瞬间，真实的、粗糙的日常同样值得被看见。

建站门槛高，普通人望而却步

想做一个个人网站来展示旅行和生活，却要面对选域名、搭服务器、学 HTML/CSS、设计排版等一系列门槛，最终往往不了了之。

For Who

为热爱记录生活的人而生

Memory Atlas 服务于每一个认真对待生活的人，无论你是旅行达人、摄影爱好者，还是只是想把日常记录保存下来的普通人。

喜欢旅行、摄影、写生活记录的人 有大量照片和文字但不擅长整理的人 想给朋友展示旅行路线和美食收藏的人 想建立个人档案但不想从零写代码的人
Solution

AI 辅助生成的个人记忆网站

用户导入照片、文字、地图收藏后，系统自动将碎片化的数字记忆，整理成一张可探索的人生地图。

自动生成内容

世界足迹地图 & 国内城市地图
按国家、城市、时间整理的影像相册
每个地点对应的文字记录
美食收藏与路线推荐
可分享给朋友的个人主页
朋友可以在相册下留下评论

Memory Atlas 的核心理念是：让内容导入取代手动排版。用户只需要做两件事——把照片放进对应文件夹、在 Markdown 中写文字。剩下的归类、排版、地图生成、页面构建，全部由系统自动完成。

系统会根据文件夹名称、照片 EXIF 时间信息、文字内容，自动将内容归类到国家、城市、年份和月份。最终生成的是一个视觉精致、结构清晰、可交互探索的个人记忆网站。

它不是一个静态的相册，而是一个可以持续生长的个人记忆系统。每次旅行回来，只需要导入新内容，网站就会自动更新，新的城市会在地图上被点亮，新的故事会自然融入已有的记忆网络中。

Features

六大核心功能

从智能整理到互动分享，每个功能都围绕「降低门槛、提升体验」设计，让记忆的保存和回顾变得自然流畅。

智能内容整理

根据文件夹名称、照片时间戳、文字内容，自动归类到国家、城市、年份和月份。不再需要手动分类和整理。

地图索引

用世界地图和中国地图点亮你去过的每一个地方。点击地图上的光点，直接进入对应城市的影像集。

地点叙事页

每个城市一个完整页面——照片、文字、路线、美食收藏和评论，构成一段完整的城市记忆叙事。

轻量内容更新

把新照片放进文件夹、在 Markdown 中写文字，系统自动识别并更新网站。无需登录后台，无需排版操作。

回忆分层

精选摄影作品和日常记录各有位置。「作品」展示技艺，「回忆」保留温度，两种记忆模式自由切换。

私密管理

站主可通过管理模式管理留言内容。普通访客只能浏览和评论，隐私与开放之间的平衡由你掌控。

Workflow

四步完成，从碎片到地图

把原本需要人工分类、修图、排版、建站、部署的复杂流程，简化成四个直觉化操作。

1

导入内容

将照片拖入文件夹，在 Markdown 文件中写旅行文字和地点信息

2

AI 智能整理

系统自动识别时间、地点和主题，将内容归类到对应城市和年份

3

生成地图

自动生成足迹地图、城市相册和地点叙事页，一键构建完整记忆网站

4

分享主页

将个人记忆链接分享给朋友，他们可以在地图上探索你的旅行故事

Value

不止于工具，更是一种记忆态度

Memory Atlas 在商业效率之外，更关注人与记忆之间被技术忽视的情感连接。

商业价值

降低个人数字资产整理门槛

可发展为面向摄影爱好者、旅行博主、留学生、城市生活记录者的 SaaS 模板服务。从「帮一个人建站」到「为一代人保存记忆」，商业想象空间广阔。

效率价值

五步流程变一步操作

把原本需要人工分类、修图、排版、建站、部署的繁琐流程，简化成「导入内容 → AI 整理 → 自动生成网站」。从数天工作量缩短到数分钟。

情感价值

一个持续生长的记忆系统

它不是单纯的相册，而是一个可以持续生长的个人记忆系统。它承认普通照片也有价值，让用户把人生路径、城市关系和生活片段长期保存下来。

社会价值

鼓励记录真实生活

鼓励人们记录真实生活，而不是只发布社交媒体上高度筛选后的瞬间。它能帮助个人、家庭、小社群建立属于自己的数字档案。
