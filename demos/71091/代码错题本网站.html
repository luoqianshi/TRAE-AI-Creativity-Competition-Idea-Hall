代码错题本网站

记录、分类、复习编程错题，专治"同一类 bug 反复踩"的学习痛点。

01 创意介绍

想解决什么问题： 编程初学者在刷题或做项目时，经常会在同类问题上反复出错，但错误记录散落在各平台，难以系统复习。

为什么会想到做这个： 自己学编程时习惯把错题记在本子上，但纸质笔记检索慢、无法贴代码片段，漏复习导致旧错重犯。

大概是什么产品： 一个面向程序员和计算机专业学生的学习工作类 Web 网站，支持记录错题、添加标签、关联知识点和定期复习提醒。

02 目标用户及痛点

面向哪些用户： 计算机相关专业学生、编程自学者、准备技术面试的求职者。

在什么场景下使用： 刷 LeetCode 时记录错误解法、做课程设计时记录调试经验、面试前按标签集中复习易错点。

当前痛点： 没有该产品时，错题只能记在本地文档或备忘录里，缺乏标签分类和检索，刷过的题很快忘记，遇到同类问题依然卡壳。

Java 空指针异常 集合框架 高频错题
// 错误代码
List<String> list = null;
list.add("hello"); // NullPointerException
// 正确代码
List<String> list = new ArrayList<>();
list.add("hello");

原因分析：使用 List 前未初始化对象，直接调用 add 方法触发空指针异常。

04 价值与意义

  • 效率提升： 将零散的调试经验结构化沉淀，减少在同一类 bug 上反复消耗的时间，加速编程能力提升。
  • 社会价值： 帮助编程初学者建立"从错误中学习"的正向循环，降低自学编程的挫败感。
  • 商业潜力： 可拓展为付费题库订阅、企业内训错题库、面试高频错题包等增值服务。
