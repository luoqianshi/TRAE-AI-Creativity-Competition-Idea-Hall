React 是一个用于构建用户界面的 JavaScript 库。 它由 Facebook 开发和维护，已经成为最流行的前端框架之一。

React 的核心思想是组件化开发， 将 UI 拆分为独立、可复用的组件。每个组件管理自己的状态， 并通过 props 接收外部数据。

虚拟 DOM 是 React 性能优化的关键， 它通过在内存中维护一个轻量级的 DOM 副本， 只更新实际发生变化的部分，从而提高渲染效率。
