核心概念

LIGHTING PREVISUALIZATION FOR EVERYONE

演出类型预设

内置话剧、演唱会、舞蹈、综艺四大演出类型的专业灯光模板，每种类型提供「经典版」与「现代版」两套预设方案，一键加载即可预览。

实时 2D 舞台渲染

基于 Canvas 的实时灯光渲染引擎，精确模拟聚光灯的光束锥形、染色灯的柔化扩散、追光灯的动态光斑，直观呈现明暗层次与色彩氛围。

Cue 单导出

痛点分析

LIGHTING DESIGNERS' DAILY STRUGGLES

设计全靠脑补

没有专业预演软件时，灯光师只能在纸上画草图或全凭经验想象。到了现场才发现光束角度不对、演员站在阴影里、面光不足——返工调试又要数小时。

现场调试成本高

每次调整都要爬上数米高的灯架，反复上下确认效果。一场演出前的灯光调试往往耗时一整天，还存在高空作业的安全隐患。

专业软件天价门槛

Capture、WYSIWYG、Vectorworks 等行业软件价格上万，学习周期长达数月。校园剧团、小型剧场、社区活动根本无力承担。

与导演沟通困难

"这里要一束暖光""那里要有层次感"——抽象的描述很难达成共识。导演想要的和灯光师理解的往往不一致，彩排时争议不断。

学生缺乏实践机会

灯光设计专业的学生很少有足够机会在真实剧场试错。没有预演工具，理论学习难以转化为实操能力，毕业后适应期长。

技术亮点

TECHNICAL ARCHITECTURE

Canvas 光束渲染引擎

自研 2D 光束渲染管线，利用径向渐变和多边形填充模拟真实光锥的衰减与扩散。支持聚光（硬边）、染色（柔边）、成像灯（图案切片）三种光束类型的物理级模拟。

参数化灯具数据库

内置 50+ 真实灯具型号（ETC Source Four、Martin MAC、ROBE 等），每种灯具记录光束角、色温、显色指数、功率、DMX 通道表。支持用户自定义添加新设备。

时间轴 Cue 系统

可视化时间轴编辑界面，支持 Go / Follow / Wait 三种触发模式。Cue 间可设置渐变时间（Fade Time），实时预览 crossfade 过渡效果，生成标准 ASCII 格式的灯光 Cue 表。

WebGL 3D 预览（专业版）

基于 Three.js 的 3D 舞台预览模式，支持导入剧场 CAD 模型，在真实空间坐标中布置灯具。实时光追模拟阴影投射与表面反射，让预演效果更接近真实演出。
