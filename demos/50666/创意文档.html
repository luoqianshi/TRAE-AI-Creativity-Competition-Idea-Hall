时光胶囊 · 家音 Agent

会陪伴、会追问、会记住的家庭记忆陪伴 Agent

1. 创意名称 + 创意介绍

创意名称

时光胶囊 · 家音 Agent

想解决什么问题

独居老人日常孤独，子女无法时刻陪伴；阿尔兹海默症老人容易焦虑、记忆衰退，却缺乏个性化的安抚方式；家庭记忆随着老人年纪增长逐渐流失，缺少有效的记录载体。

为什么会想到做这个

看到身边长辈随着年龄增长，越来越不愿主动开口交流，而子女工作忙碌难以时时陪伴。同时，阿尔兹海默症老人的记忆需要被温柔地呵护和延续，家庭故事不应该随着时间流逝而消失。

大概是什么产品

一个面向老年人的情感陪伴 Web 应用，通过 AI Agent 基于家庭记忆锚点主动陪伴聊天、安抚情绪、补完人生故事。

2. 目标用户及痛点

面向哪些用户

  • 核心用户：65 岁以上的独居或半独居老人，特别是有轻度认知障碍、阿尔兹海默症倾向的老人
  • 次要用户：老人的子女和照护者

在什么场景下使用

  • 老人独自在家感到孤独时
  • 情绪焦虑不安时
  • 想回忆过去却没人倾诉时
  • 子女工作繁忙无法及时陪伴时

当前痛点

  • 孤独时只能默默发呆或反复看电视
  • 焦虑时缺乏即时的安抚和安全感
  • 珍贵的人生记忆随着时间逐渐模糊
  • 子女无法全面了解老人的内心世界和过往故事

3. 价值与意义

社会价值

通过科技手段为老年人提供温暖的情感陪伴，缓解孤独感；帮助阿尔兹海默症老人在安全、不被纠错的环境中表达自我；让家庭记忆得以延续，为后辈留下珍贵的精神财富。

效率提升

为照护者提供可行动的观察摘要，帮助他们更精准地了解老人的情绪变化和潜在需求，减少照护压力；通过结构化的记忆补完，让家庭故事整理不再是沉重的负担。

4. 核心设计

4.1 初始记忆锚点

初始记忆锚点主要由子女或照护者录入，有条件且认知清晰的老人也可以参与补充，但不把老人自己操作作为前提。

三层录入结构：

  • 第一层（必填）：安心锚点，子女 3 分钟完成
    • 老人喜欢被怎么称呼
    • 主要家人是谁
    • 现在住在哪里
    • 子女通常什么时候联系
    • 老人焦虑时适合怎么安抚
    • 哪些话题不要主动提
  • 第二层（可选）：记忆锚点
    • 几个重要人物
    • 几个熟悉地点
    • 几件温暖回忆
    • 几张代表性照片
    • 几句家人的留言
  • 第三层（自然增长）：后续补充
    • 老人与 Agent 聊天时补充的新细节
    • 子女在摘要中确认的新记忆
    • 照护者记录的有效安抚方式

子女先录入最小安心资料，Agent 在陪伴中不断补完，家人再确认沉淀。

4.2 Agent 主动搭话机制

Agent 可以主动搭话，但必须非常克制，基于"照护节律"和"老人状态"触发。

三类触发方式：

  • 固定节律触发：每天上午、下午、睡前各一次，像小广播一样轻轻出现
  • 状态触发：老人打开页面但长时间没有输入，等一段时间后给一个低压力选择
  • 风险或情绪触发：老人连续表达焦虑、想家、找人、害怕时，进入安抚流程

频率控制：

  • 默认每天 2-3 次主动问候
  • 每次只问一个问题
  • 老人可以点"今天不聊"
  • 子女端可以设置免打扰时段
  • 阿尔兹海默症模式下，主动搭话更短、更慢、更重复
  • 如果老人连续拒绝，Agent 当天减少主动触发

Agent 可以主动，但必须像家人轻声问候，而不是像 App 推送骚扰。

4.3 让老人愿意开口的方法

不用"请开始聊天"，而是用"低压力入口"引导。

  • 先听，不先说：入口是"听听家人今天给你留的话"，老人只要点一下听，不需要马上回应
  • 用熟悉物触发：展示熟悉照片、地名、菜名、音乐，而不是问抽象问题
  • 不考试：不问"这是谁、哪一年、发生了什么"，改成"这张照片让你觉得舒服吗？"
  • 允许沉默：老人不回答也算完成一次陪伴
  • 用按钮代替输入：给老人几个大按钮（想听、换一个、我有点着急、今天不聊）
  • 先建立信任：Agent 明确自己不是假装子女

老人愿意开口的前提不是 AI 多聪明，而是交互足够不费力、不冒犯、不像考试。

4.4 记忆确认机制

Agent 从对话中得到的新记忆，默认不能直接变成"事实"，而应进入待确认状态。

记忆三种状态：

  • 已确认：家人明确录入或确认过
  • 待确认：老人聊天中提到的新细节
  • 有争议：不同家人说法不一致，或老人回忆不稳定

确认流程：

  • 1. 系统记录待确认记忆，标注来源、关联锚点、建议确认人
  • 2. 确认人（子女、照护者、家庭资料管理员）轻量确认：点"确认"、"需要修改"、"先保留"或补备注
  • 3. 确认后才进入长期记忆锚点，供 Agent 后续稳定引用

Agent 可以发现记忆，但不能独断定稿；家庭确认后，记忆才真正沉淀。

4.5 子女端设计

子女端不是让子女实时盯着聊天，而是帮子女低负担了解老人状态，并给出可执行的小建议。

三种使用方式：

  • 每日摘要：每天固定时间推送或展示（聊天次数、情绪状态、反复提到的人、让老人平静的话题、待确认记忆、建议子女做的一件小事）
  • 异常提醒：只有出现高风险内容时才实时提醒（自伤表达、身体不适、走失倾向、强烈恐惧、被害妄想、转账/诈骗相关表达）
  • 记忆确认任务：子女不需要看所有原始聊天，只处理少量卡片（确认新记忆、补充人物关系、录安抚话、标记有效话题）

反馈方式：

已联系 稍后联系 这个建议有用 这个话题不适合 补充一句家人留言

子女端不是监控后台，而是一个把陪伴任务降到最低的亲情协作台。

5. 产品闭环

子女录入最小安心锚点
→
Agent 基于锚点陪伴老人
→
老人在低压力互动中说出新细节
→
系统生成摘要和待确认记忆
→
子女轻量确认、补充或反馈
→
长期记忆更新
→
Agent 下一次陪伴更贴近这个家庭

时光胶囊 · 家音 Agent 不是让老人独自使用 AI，也不是让子女实时监控老人，而是用最小家庭锚点启动陪伴，在日常对话中自然补完记忆，再由家人轻量确认，让 Agent 越陪越懂这个家庭。

6. 安全边界

  • AI 不冒充真人子女
  • AI 不替代医生、照护者或紧急救援
  • 所有记忆锚点均需家庭授权录入
  • 阿尔兹海默症友好模式只调整沟通方式，不进行诊断
  • 高风险表达会建议联系真人照护者
  • Demo 使用虚构资料，不上传真实家庭数据

我们不复活任何人，不替代任何家人，只在授权边界内延续真实的关怀与记忆。

7. 视觉与交互要求

整体气质

  • 温暖、克制、留白
  • 不像后台系统、不像医疗仪表盘、不像客服聊天工具

老人端

  • 大字号、大按钮、少选项、高对比
  • 不用密集表格，每次只呈现一个主要问题
  • 支持"再说一遍"、"换一个"、"今天不聊"

子女/摘要端

  • 信息密度可以略高
  • 突出"今天我该做什么"
  • 摘要必须可行动，而不是堆日志

推荐主色

  • 暖白、浅米、柔和琥珀、沉静墨绿或石墨灰
  • 避免过度科技蓝、医疗绿、强紫色渐变
