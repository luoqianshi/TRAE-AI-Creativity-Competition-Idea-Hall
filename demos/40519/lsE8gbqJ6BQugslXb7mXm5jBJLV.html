💡 创意介绍

🎯 想解决什么问题

在质量管理和数据分析工作中，工程师面对海量数据时，往往需要掌握复杂的统计学理论才能完成控制图绘制、过程能力分析、假设检验等专业分析，门槛极高。

能否让工程师只需上传 Excel 数据，就能自动获得专业分析结果和结论意见？

🤔 为什么会想到做这个

在日常质量管理和研究分析工作中，许多工程师和研究人员虽有分析需求，却因统计学基础薄弱而寸步难行。传统的统计分析软件（如 Minitab、SPSS）价格昂贵、操作复杂，而 Excel 自带功能又远不能满足专业需求。

我们希望通过 AI + 专业统计引擎的结合，让数据分析回归本质——解决问题，而非纠结于公式。

🖥️ 产品形态

数决（DataDecide）是一个 Web 端全栈数据分析平台，采用 Vue 3 + FastAPI 技术栈，内置 6 大类 33 种专业统计分析方法与 AI 智能分析引擎。用户上传 Excel 数据后，即可获得可视化图表、专业分析结果和可导出的结论性报告（支持 Markdown / Word 格式）。

⚡ 核心分析能力
📈 控制图分析（9 种） Xbar-R、I-MR、Xbar-S、P、NP、C、U、EWMA、CUSUM
📊 过程能力分析 Cp/Cpk/Pp/Ppk/DPMO 正态能力分析
📋 描述性统计（3 种） 描述统计量、频率分布、正态性检验（AD/SW）
🔬 假设检验（6 种） 单样本 t 检验、双样本 t 检验、配对 t 检验、ANOVA、卡方检验、图形化汇总
📐 回归分析（3 种） 相关分析、简单线性回归、多元线性回归
🎨 数据可视化（11 种） 柱状图、折线图、饼图、环形图、玫瑰图、面积图、散点图等
🤖 AI 智能分析 自动生成专业解读，支持基于分析结果的智能追问
📝 报告生成 支持 Markdown 和 Word（.docx）格式自动导出
📁 上传 Excel → ⚙️ 选择分析方法 → 🤖 自动分析计算 → 📊 图表 + 结论 → 📄 导出报告
💎 价值与意义
⚡

效率提升

将原本需要数小时甚至数天的数据分析工作缩短到几分钟。用户只需上传数据、选择分析类型，系统自动完成计算、绘图、报告全流程。

💰

商业价值

制造型企业通过控制图和过程能力分析实时监控生产质量，及早发现异常，减少不良品率。无需购买 Minitab 等昂贵商业软件，降低工具成本。

🌍

社会价值

让数据分析不再依赖专业知识壁垒，推动数据驱动的决策文化在更广泛的行业和岗位中落地。人人皆可做数据分析，人人皆可做数据决策。
