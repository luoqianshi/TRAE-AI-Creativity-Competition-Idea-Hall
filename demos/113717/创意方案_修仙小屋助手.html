一、创意名称与介绍
🎯 想解决什么问题？
修仙类游戏中大量重复的抽奖、翻卡、天梯赛等操作占用玩家大量时间，且手动选择奖励容易出错，导致玩家错过最优物品，影响游戏体验。
💡 为什么会想到做这个？
在玩修仙游戏的过程中，发现每天需要花费大量时间进行机械重复的抽奖操作，既枯燥又容易选错奖励。于是想到用AI技术来解放双手，让游戏回归娱乐本质。
📦 大概是什么产品？
一款基于PaddleOCR图像识别技术的桌面游戏自动化辅助工具，支持幸运商店抽奖、心悦翻卡、天梯赛、盲盒等多种游戏场景的智能自动化操作。

四、技术方案
🛠️ 核心技术栈
PaddleOCR Python Tkinter GUI SQLite PyAutoGUI OpenCV
🔄 工作流程
  1. 区域选择：用户框选游戏界面中的抽奖区域
  2. 截图识别：系统自动截取区域图像，使用PaddleOCR识别物品名称
  3. 价值计算：根据物品数据库计算每个格子的总价值
  4. 智能选择：自动点击价值最高的格子
  5. 结果记录：记录每次操作的结果到日志文件

五、产品形态
🖥️ 产品形态
桌面应用程序（Windows）

采用PyInstaller打包为独立EXE文件，无需安装Python环境即可运行。用户友好的图形界面，支持一键启动、快捷键控制（F6开始/F7停止）。

  • 物品管理：支持添加/修改/删除物品及其价值
  • 异常处理：遇到未知物品自动暂停，等待人工确认
