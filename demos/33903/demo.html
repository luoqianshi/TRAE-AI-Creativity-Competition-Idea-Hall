📊 WPS 多维表格 · KSDrive 数据读取 Demo

通过 AirScript 脚本调用 KSDrive API，读取多维表格中的全部数据，以结构化的方式展示。

🚀 AirScript + KSDrive 云文档 API
📄 目标文档： https://www.kdocs.cn/l/ctQzvOvixFUo 文档可访问
🎯 快速开始

以下步骤演示如何在 WPS 多维表格中使用 AirScript + KSDrive API 读取数据。只需几分钟即可完成。

1
打开多维表格
在浏览器中打开你的多维表格文档： https://www.kdocs.cn/l/ctQzvOvixFUo
2
打开 AirScript 编辑器
点击顶部菜单栏 「开发工具」 → 「AirScript 编辑器」。 如果找不到开发工具，请先在设置中开启「开发者模式」。
3
添加云文档 API 服务
在 AirScript 编辑器中，点击顶部 「服务」 → 「添加服务」 → 选择 「云文档 API」 → 确认添加。
⚠️ 此步骤必不可少！否则 KSDrive 会报 undefined 错误。
4
粘贴脚本代码
切换到「完整脚本」标签页，复制其中的代码，粘贴到 AirScript 编辑器中， 覆盖默认的 main() 函数。
5
运行脚本
点击编辑器上方的 「运行」 按钮（▶ 图标）。 在底部控制台查看输出结果，你将看到所有数据表和记录数据。
6
查看结果
脚本会依次输出：文档打开状态 → 数据表结构 → 每条记录的字段值 → 数据统计汇总。参考「输出预览」标签了解预期输出格式。
⚠️
重要提示： KSDrive.openFile() 打开文档后必须调用 file.close() 才能再次打开。 每次只能打开一个文件。脚本已正确处理此逻辑。
💡
需要查看特定字段？ 在 GetRecords 的参数中添加 Fields: ["字段名1", "字段名2"] 即可只返回指定字段的数据。
📜 完整 AirScript 代码

以下脚本通过 KSDrive.openFile() 打开文档，使用 Application.Record.GetRecords() 读取所有数据表的数据。

文件：read_multidim_table.gs

JavaScript (AirScript) 
/**
 * ============================================================
 *  WPS AirScript — 读取多维表格数据 (KSDrive API 示例)
 *  文档链接: https://www.kdocs.cn/l/ctQzvOvixFUo
 * ============================================================
 */

function main() {
  try {
    // 1. 通过 KSDrive 打开文档
    console.log('🚀 正在打开文档...');
    const fileUrl = 'https://www.kdocs.cn/l/ctQzvOvixFUo';
    const file = KSDrive.openFile(fileUrl);
    console.log('✅ 文档打开成功！');

    // 2. 获取所有数据表信息
    console.log('\n📋 正在获取数据表结构...');
    const sheetsInfo = Application.Sheet.GetSheets();
    console.log('共发现 ' + sheetsInfo.length + ' 个数据表：');

    for (let i = 0; i < sheetsInfo.length; i++) {
      const sheet = sheetsInfo[i];
      console.log('\n  📊 表 ' + (i + 1) + ': "' + sheet.name + '" (ID: ' + sheet.id + ')');
      console.log('     字段数: ' + (sheet.fields ? sheet.fields.length : 0));

      if (sheet.fields) {
        for (let j = 0; j < sheet.fields.length; j++) {
          const field = sheet.fields[j];
          console.log('     └─ 字段: "' + field.name + '" (类型: ' + field.type + ')');
        }
      }
    }

    // 3. 遍历每个表，读取数据
    console.log('\n📝 正在读取各表数据...\n');

    for (let i = 0; i < sheetsInfo.length; i++) {
      const sheetMeta = sheetsInfo[i];
      console.log('='.repeat(60));
      console.log('📊 数据表: ' + sheetMeta.name);
      console.log('='.repeat(60));

      const result = Application.Record.GetRecords({
        SheetId: sheetMeta.id
      });

      const records = result.records || [];
      console.log('共 ' + records.length + ' 条记录\n');

      for (let k = 0; k < records.length; k++) {
        const record = records[k];
        const fields = record.fields || {};
        const fieldKeys = Object.keys(fields);

        console.log('  📌 记录 ' + (k + 1) + ' (ID: ' + (record.id || 'N/A') + '):');
        for (let f = 0; f < fieldKeys.length; f++) {
          const fieldName = fieldKeys[f];
          const fieldValue = fields[fieldName];
          console.log('    ├─ ' + fieldName + ': ' + JSON.stringify(fieldValue));
        }
        console.log('');
      }
    }

    // 4. 关闭文件
    file.close();
    console.log('\n✅ 脚本执行完毕！');

  } catch (error) {
    console.error('❌ 出错:', error.message);
  }
}

main();

🔧 常用参数说明
参数 类型 说明
SheetId Number 数据表 ID（必填），从 GetSheets() 获取
ViewId String 视图 ID，填写后仅返回该视图可见的记录
PageSize Number 每页条数，默认 100，用于分页
Offset String 分页偏移量，由上次请求返回，用于翻页
MaxRecords Number 最大返回记录数，不填则返回全部
Fields Array 指定返回的字段名数组，如 ["姓名", "日期"]
Filter Object 筛选条件，支持 AND/OR 组合查询

🌐 通过 HTTP API 读取数据

除了 AirScript 脚本方式，还可以通过 WPS 开放平台的 REST API 从外部系统获取多维表格数据。这种方式适合集成到 Web 应用或后端服务中。

⚠️
需要先注册应用： 使用 REST API 前，必须在 WPS 开放平台 创建企业应用，获取 App ID 和 App Secret， 并开通多维表格相关权限。

API 端点一览

接口 方法 说明
POST .../schema/query POST 获取多维表格结构（工作表、字段、视图）
POST .../record/list POST 分页获取记录列表 ⭐ 最常用
POST .../record/retrieve POST 查询单条记录详情
POST .../record/query POST 条件查询记录

获取记录列表 (record/list) 示例

HTTP Request 
POST https://openapi.wps.cn/kopen/office/file/{file_id}/core/execute/record/list
Authorization: Bearer {access_token}
Content-Type: application/json

{
  "param": {
    "sheetId": 1,
    "pageSize": 100,
    "preferId": true,
    "showFieldsInfo": true
  }
}

Node.js 调用示例

JavaScript (Node.js) 
const axios = require('axios');

const FILE_ID = 'ctQzvOvixFUo';  // 文档链接中的 ID
const ACCESS_TOKEN = 'your_access_token';  // OAuth2.0 获取

async function getSheetData(sheetId = 1) {
  const res = await axios.post(
    `https://openapi.wps.cn/kopen/office/file/${FILE_ID}/core/execute/record/list`,
    {
      param: {
        sheetId,
        pageSize: 200,
        preferId: true,
        showFieldsInfo: true
      }
    },
    {
      headers: {
        Authorization: `Bearer ${ACCESS_TOKEN}`,
        'Content-Type': 'application/json'
      }
    }
  );
  return res.data;
}

// 使用示例
getSheetData(1).then(data => {
  console.log('记录数:', data.detail.records.length);
  console.log('字段信息:', data.detail.fieldsSchema);
  console.log('数据:', data.detail.records);
});
🔑
获取 access_token： 通过 OAuth2.0 授权码流程获取，有效期 2 小时。 需要权限：kso.dbsheet.read（读取多维表格数据）。
