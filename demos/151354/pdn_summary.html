关键技术决策: SIwave 2023.1 的 doc.ScrSetRLCValues() 存在静默 bug —— 不论传入任何 C 值, 内存中都会被改写为 1E-20 (≈0), 导致 SIwave 求解器在 log 中打印 Ignoring zero-valued capacitor C1013..., 去耦完全失效。 解决方案: 跳过 ScrSetRLCValues 调用, 只通过文件级 patch 把正确 C 值写进 .siw; open_project 时 SIwave 会把磁盘上的正确值读入内存, 求解器随即使用正确模型。

3.6 频段趋势与物理意义

频段|Z| 范围物理机制合规
100 kHz ~75 mΩ 电源平面直流电阻主导 PASS (余量 ~25%)
1 MHz ~5.5 mΩ 10 µF bulk 电容容抗主导, Zc = 1/(2πfC) ≈ 16 mΩ 与 ESR 串联 PASS (余量充足)
10 MHz ~30 mΩ 10 µF (ESL=0.5 nH) 与 1 µF 形成反谐振峰 WARN (无目标, 但峰值偏大)
100 MHz 270 – 310 mΩ 走线 + 过孔 + 平面分布电感主导, ESL 已达极限 FAIL (3-4× 超 80 mΩ 目标)
设计优化建议: 100 MHz 频段超目标 3-4 倍是典型 PDN 高频问题。改进方向: (a) U1000 BGA 下方 1-2 颗 100 nF / 0402 紧耦合小封装电容; (b) 缩短 BGA-电容回路面积以减小回路电感; (c) 评估改用更先进的 0201 封装, 或在 BGA 球阵列下方的内层增加低电感电容; (d) 检查 VDD_NPU 平面与 GND 平面的介质厚度, 减小 d → 减小 C, 但需结合 SI 权衡。

4.1 自动化的核心优势

  • 效率提升约 15 – 30 倍: 一次完整 PDN 仿真从 30-60 分钟压缩到 2 分钟, 主要节省在 GUI 操作、参数录入、结果整理上。
  • 参数化与可复用: 同一脚本切换网络 (VDD_CPU / VDD_LOGIC / VCC_DDR...) 仅需改 1-2 个常量; 切换扫频范围 / 目标阻抗表 / 电容 RLC 模型, 都是改几行的事。
  • 规避 GUI 不可达的 API bug: 本次关键突破: SIwave COM 的 ScrSetRLCValues 会把 C 值静默写成 1E-20, 自动化通过文件级 patch 绕过, 这是 GUI 模式下完全无法解决 (甚至无法察觉) 的隐蔽 bug。
  • 结果闭环: 仿真 → Touchstone → 阻抗 → 合规报告 → 图 → 文档 全链路自动化, 减少人工抄写错误。
  • 可审计性: 所有参数、操作、log 全部落盘 (pdn_run.log), 可追溯; GUI 模式下操作步骤不留下任何证据。
  • CI / 回归测试基础: 适合嵌入 CI 流程, 每次 PCB 改版自动回归 PDN 仿真, 验证设计变更是否引入新的超 target 频段。

4.2 自动化的局限 / 注意事项

  • 首版调试成本高: 需要摸清 SIwave COM API 行为 (例如 ScrSelectNet 第二个参数含义、ScrSetRLCValues bug), 这些是文档 / GUI 操作里看不见的, 必须靠 log + 试探。
  • 对工程版本 / 安装路径敏感: 本次使用 Siwave.Application.2023.1, 升级到 v24 / v25 后 COM ProgID 可能变化; siwave_ng.exe 路径硬编码, 移植时需更新。
  • 异常处理弱: 几何错误 (disjoint net、obsolete via) 一旦发生, SIwave 会警告但仍求解, 结果可能不可信; 自动化需要额外的 layout_validation 步骤 (本次已通过 disjoint net 清理解决一部分)。
  • 无图形化交互: 调试时难以像 GUI 那样实时查看 port 位置、走线 / via 分布; 需要单独打开 GUI 配合核对。

5总结

本次基于 Ansys SIwave 2023.1 + Python 3 构建的 RV1126B VDD_NPU PDN SYZ 自动化仿真流程, 完整复现了 GUI 模式下的所有操作, 并通过 文件级 patch 绕过了 SIwave COM 的 RLC 注入 bug。 最终在 2 分钟内完成全流程, 输出合规率 82.5%, 定位到 100 MHz 频段超 80 mΩ 目标 3-4 倍 的关键问题, 为后续设计优化 (BGA 紧耦合小封装电容 / 回路电感优化) 提供了精确的量化依据。

自动化方案相比传统 GUI 人工操作, 在效率、可重复性、批量化、可审计性等维度具有显著优势, 特别适合多网络 / 多参数 / 改版回归等工程场景。
