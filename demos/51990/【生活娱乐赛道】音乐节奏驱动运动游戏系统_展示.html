技术原理

五层技术架构

从音频采集到动作编排，每一层都为"音乐驱动运动"而设计。

01

音频采集层

Web Audio API 实时采集音频流，FFT 频谱分析提取频率特征

→
02

节拍检测层

基于 onset detection 算法检测节拍点，计算实时 BPM 和节拍强度

→
03

能量分析层

计算音频能量曲线，识别歌曲结构（主歌/副歌/间奏/高潮段落）

→
04

动作编排层

AI 根据节拍+能量+歌曲结构，从动作库中编排最优运动序列

→
05

游戏渲染层

Canvas/WebGL 实时渲染下落音符、判定反馈、粒子特效和数据 HUD
