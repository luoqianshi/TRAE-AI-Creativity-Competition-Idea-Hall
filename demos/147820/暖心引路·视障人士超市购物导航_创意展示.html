蓝牙信标三角定位

超市内每隔 8-12 米部署低功耗蓝牙信标（iBeacon/Eddystone），手机接收各信标的 RSSI 信号强度，通过路径损耗模型计算距离，结合三角测量算法实现 1-3 米的室内定位精度。

距离估算 (RSSI模型): d = 10^((TxPower - RSSI)/(10×n)) n = 2.0~2.5 (室内衰减因子) 三角定位: (x,y) = argmin Σ||dist_i - √((x-xi)²+(y-yi)²)||²
🗣️

无障碍语音交互引擎

专为视障用户设计的全语音交互流程：支持语音唤醒、自然语言商品搜索（如"帮我找无糖酸奶"）、实时语音导航播报、障碍物紧急语音警报。全程无需看屏幕，通过震动反馈和语音确认完成交互。

语音交互状态机: IDLE → LISTENING → RECOGNIZED → NAVIGATING → ARRIVED → OBSTACLE_ALERT → REROUTE
🧭

动态路径规划与避障

基于超市实时布局数据，采用 A* 算法规划最短路径。当检测到前方有临时障碍物（如促销堆头、购物车）时，系统自动重新计算绕行路线，并通过语音播报"前方有障碍物，请向左绕行2米"。

A* 路径规划: f(n) = g(n) + h(n) g(n) = 从起点到n的实际代价 h(n) = n到目标的欧氏距离估计 避障触发: dist(obstacle) < 1.5m
📱

数字孪生超市地图

为每家合作超市建立厘米级精度的数字孪生地图，包含货架位置、通道宽度、收银台位置、无障碍设施等元数据。地图支持增量更新，当超市调整货架布局时，只需上传新的平面图即可自动重新生成导航路径。

地图数据结构: Supermarket { zones: [冷藏区, 干货区, ...], shelves: [{id, category, pos(x,y), facing}], obstacles: [{type, pos, radius, temporary}], beacons: [{uuid, pos(x,y), txPower}] }
