想解决什么问题

玩游戏、看文章时遇到文言文或古文，逐字理解费时费力，搜索出处还要手动复制→打开浏览器→搜索→甄别结果，流程繁琐。我想让「看到不懂的古文 → 立刻知道意思和出处」这件事一步完成。

💡

为什么会想到做这个

玩国风游戏时频繁遇到文言文对话和典籍引用，每次都要切出去搜索，体验非常割裂。而且同样一句话在不同语境下意思可能完全不同，光看字面容易误解。

🛠️

大概是什么产品

一个桌面端辅助工具，通过 OCR 截图识别或系统文本选中监听两种方式，实时获取屏幕上的文言文，调用大模型 API 进行白话翻译，并匹配对应的经典出处。

目标用户及痛点

谁需要这个工具？他们在什么场景下使用？

🎮

面向哪些用户

  • 喜欢深究剧情的国风 / 古风游戏玩家（如《黑神话：悟空》《原神》《仙剑奇侠传》等）
  • 日常需要阅读文言文的学生、教师、历史文化爱好者
  • 工作中偶尔接触古籍文献的职场人士
📍

在什么场景下使用

  • 🎮 玩游戏时遇到看不懂的游戏内典籍、碑文、诗词对话
  • 🌐 阅读网页或文档中的文言文段落，需要快速理解
  • 📚 学习或备课过程中查阅古文出处
⚠️

当前痛点

  • 逐字翻译耗时费力，一个简单的句子可能在搜索引擎花几分钟
  • 网络搜索结果良莠不齐，翻译质量参差不齐，容易误解原文
  • 缺乏上下文关联的出处信息，难以准确理解文意
叁

价值与意义

⚡

效率价值

将「看到不懂的古文 → 搜索 → 理解」这个链条从几分钟压缩到几秒钟，大幅提升阅读流畅度，让用户不再被语言门槛打断沉浸体验。

🏛️

社会价值

降低古文阅读门槛，让更多人愿意接触和理解中国古代典籍。当查阅变得足够方便，人们对经典文化的兴趣自然会提升，对古籍活化、文化传承有实际的推动作用。

🏆 作品可叠加提报「古籍活化」公益附加赛道，让产品不只是游戏辅助工具，更是传统文化传播的数字化入口。
