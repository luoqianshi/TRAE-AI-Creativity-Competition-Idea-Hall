PART 01 · 创意介绍

你只管写，栀子负责懂你。

一款"被动守护型"AI 日记——不帮你写，只读懂你。

日记是许多人最后的避风港，但传统日记是沉默的——你写完最后一个字，屏幕不语，页面无言。心理咨询虽然专业，但费用昂贵、预约困难、还带着说不清的病耻感。大多数人渴望被理解，却找不到那个既专业又温柔的倾听者。

「栀子日记」由此而生：它不是又一个让你写字的工具，而是一位"被动守护型"AI 伙伴。你只管写下心中所想，AI 会自动从字里行间提取你的情绪状态、人格特质、价值倾向，汇聚成 33 个临床级心理指标的数据画像——不需要你做任何问卷，日记本身就是最真实的答案。

"栀子，知子。花开了，你也知心了。"
栀子花语：一生的守候 · 喜悦

产品形态是一套 Web 应用 + 移动端优先响应式设计 的单页系统，覆盖日记书写、心理指标仪表盘、心灵碎片、心灵对话、心理评估报告、数据导出六大模块。整套产品 100% 可运行，已基于 DeepSeek API 实现完整的 AI 分析管线。

技术栈 & 关键创新。

🤖

AI 心理分析引擎

基于 DeepSeek 大模型，通过精心设计的提示工程实现日记深度心理分析——情绪识别、指标评分、碎片提取一气呵成。AI 回应只做温暖的共情者，不做粗糙的心理诊断。

🗄️

心理指标数据库

33 个临床级指标定义预设在 SQLite 数据库中，每篇日记生成新的指标快照（含置信度+依据）。所有查询通过用户 ID 隔离，确保数据隐私。

🔐

JWT 认证 + 数据隔离

PBKDF2-SHA256 密码哈希，JWT 无状态认证（30 天有效期）。所有业务端点强制 Token 验证，按用户 ID 过滤数据，一人一空间。

📊

Recharts 可视化

心理指标仪表盘使用平滑面积曲线展示历史趋势，含 50 分参考线 + 置信度 Tooltip。评估报告页集成雷达图、情绪趋势面积图、分类解读。

💬

个性化心灵对话

对话 AI 接收用户的完整心理画像（33 个指标最新评分）作为上下文，每次回复都基于对用户的真实了解，消除 AI 幻觉，实现真正个性化的陪伴。

📤

一键数据导出

支持导出全部个人数据为结构化 JSON（日记、指标快照、心灵碎片、对话记录、评估摘要），数据主权完全归属于用户。
