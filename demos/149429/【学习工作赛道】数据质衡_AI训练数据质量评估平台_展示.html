PROBLEM ANALYSIS

数据之痛

80% 的模型失败，根源不在算法，而在数据。

01

标注噪声

大规模标注不可避免地混入错误标签。5% 的标注错误率，在万级数据集上就是数百条"脏数据"，直接拉低模型天花板。

02

分布偏移

训练集与真实场景分布不一致——训练集里全是白天场景，模型上线后面对夜间数据直接崩溃，却很难通过统计指标发现。

03

隐性泄露

测试集样本与训练集高度相似甚至重复，导致模型评估结果虚高 10–30 个百分点，上线后真实表现断崖式下跌。

04

工具缺失

现有工具（pandas Profiling 等）只做统计画像，无法检测语义一致性、标注偏差和分布漂移等深层数据质量问题。

TECHNICAL PRINCIPLES

技术原理

六大核心引擎，构建从统计到语义的全栈质量评估体系。

ENGINE 01

统计画像引擎

对数值特征计算均值、方差、分位数、偏度、峰度；对类别特征计算频率分布和基尼系数，快速发现异常值与分布异常。

profile = StatisticalEngine(df).run()
outliers = profile.detect_iqr(threshold=1.5)
ENGINE 02

标注一致性检测

利用嵌入模型将同标签样本映射到向量空间，计算类内聚合度。低聚合度的类别意味着标注者之间存在分歧。

embeddings = CLIP.encode(samples)
coherence = intra_class_cosine(embeddings)
ENGINE 03

泄露检测器

通过 MinHash LSH 快速检索训练/测试集间的近似重复样本，相似度阈值可调，支持文本、图像和表格数据。

lsh = MinHashLSH(threshold=0.95)
leaks = lsh.query(train_keys, test_keys)
ENGINE 04

类别平衡分析

计算类别的有效样本数（Effective N）和 Shannon 熵，评估数据集的信息丰富度，识别极端不平衡和冗余类别。

effective_n = 1 / sum(p_i ** 2)
entropy = -sum(p_i * log(p_i))
ENGINE 05

语义一致性校验

利用 LLM 对文本样本进行语义理解，检测标签与内容不匹配的样本（如图文不符、情感标注反转等）。

confidence = LLM.verify(label, content)
flag = confidence < 0.7
ENGINE 06

可解释报告生成

为每个检测到的问题生成自然语言解释，包括问题位置、严重程度、影响范围和推荐修复策略。

report = ReportGenerator()
report.add(issue, context).render()
