Trend Copilot
科技新闻智能 Agent

不是新闻 App，不是聊天机器人——自动抓取多源科技资讯、生成日报/周报，并带跨时间记忆的多轮追问 Agent。 把 HN、TechCrunch、36Kr、Readhub 的碎片信息，变成可验证、可对比的趋势叙事。

1 · 创意是什么

痛点：科技从业者每天要在多个英文/中文源之间切换，知道「发生了什么」，却很难回答「这周主线是什么、和上周比变了什么、某条新闻是否可靠」。

动机：通勤路上想听/看科技动态，但拒绝无限滚动信息流；希望有一个会抓新闻、会写播报、会记住上次结论的 Agent，而不是一次性 LLM 摘要。

产品形态：CLI + Web 新闻 Agent 后端——定时 daily/weekly 流水线产出 Markdown 播报；Web 端对已入库新闻做引用可追溯的 trend query；底层 LangGraph 规划工具链，SQLite + 向量记忆跨 run 召回。

2 · 目标用户与场景

谁在用

  • 后端 / AI 工程师（跟进开源、融资、监管）
  • 技术写作者、独立开发者
  • 需要写周报、组会分享的 Team Lead

什么时候用

  • 早晨：自动跑 daily，2 分钟中文科技日报
  • 周末：weekly 趋势解读 + 代表文章
  • 随时：「开源 LLM 最近有什么大事？」多轮追问

没有它时的不便：手动刷 4 个源 30+ 分钟；ChatGPT 不连接你的 RSS 库易幻觉；自建 RAG 缺 Agent 闭环（抓取稀疏要扩窗、引用错了要重合成）。

3 · 价值与意义

效率

抓取 → 去重 → 检索 → 对比上周 → 合成播报，一条命令或定时任务完成；问答路径 15–30 秒流式返回，回答带 [文章 id] 引用。

学习 / 工作

适合技术周报、面试前补课、投资研究扫盲——内容 grounded 在本地记忆库，33 条 Golden Eval 回归 faithfulness，不是空编摘要。

4 · Agent 怎么工作（新闻流水线 + 记忆）

四类任务，共用同一 Harness，不是单次 Prompt：

任务 做什么 产出
daily_briefing 抓取 → 入库 → 检索 → 对比昨日 → 合成 科技日报 Markdown
weekly_trend 检索一周素材 → 对比上周信号 → 趋势解读 周报 + 主题演化
trend_query 混合检索记忆库 → 流式问答 带引用的中文回答
trend_compare 主题跨周期对比 新增 / 持续 / 降温信号

感知 → 决策 → 执行（闭环）

fetch_from_sources→ store_articles→ retrieve_trend_context→ compare_with_previous→ synthesize→ upsert_trend_node→ record_episodic

抓取/检索不足时 adaptive replan 自动扩时间窗；合成引用校验失败会重试——这是新闻 Agent，不是念剧本的 Demo。
