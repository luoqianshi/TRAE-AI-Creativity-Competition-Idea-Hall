I · 创意介绍

让 AI 真正长出记忆与边界

痛点：当前 AI 助手"一次性对话"——不会沉淀经验、不会自我审查、工具调用毫无边界管控。
动机：受 Hermes 自进化理念与 OpenClaw 钩子体系启发，让 Agent 在工作中持续成长。
形态：一套 Python AI Agent 框架 + CLI/HTTP/Web 多渠道接入的开源系统。

H

Hermes · 自进化内核

三层 System Prompt（stable / context / volatile）实现缓存友好的提示词架构；Background Review 在对话结束后自动审查沉淀记忆与技能；Curator 维护技能库，自动归档过期技能。Agent 越用越聪明，而不是越用越糊涂。

C

OpenClaw · 钩子与策略

7 个钩子点（before/after tool_call、agent run/reply、model_call）支持工具级拦截、改写、审批；工具策略引擎提供 profile + allow/deny 精细权限；配置 fail-fast 原则确保不带病运行。让 Agent 既强大又可控。

II · 目标用户及痛点

面向开发者与团队的工作场景

核心用户：需要长期复用 AI 能力的开发者、运维工程师、技术团队。
使用场景：代码助手、自动化运维、知识库问答、多渠道客服、定时任务调度。

01

经验无法沉淀

每次对话都从零开始，昨天教过的知识今天又忘了。团队经验无法共享传承，重复劳动消耗产能。

02

工具调用失控

AI 一旦接入工具就"放飞自我"——删错文件、执行危险命令、调用未授权接口。缺乏可审计的工具边界。

03

上下文爆炸

长对话 token 飙升、成本失控；压缩粗暴导致关键信息丢失；不同对话类型用同一套策略效率低下。

III · 价值与意义

从效率提升到生态价值

ClawHermes 不只是一个 AI 工具，而是可进化的工作伙伴。
从效率提升与生态价值两个维度，重塑人与 AI 的协作关系。

◆ Efficiency / 效率提升

越用越快的
工作伙伴

Background Review 让 Agent 在对话后自动沉淀记忆与技能，下一次直接复用经验而非重新摸索；ACE 自适应压缩检测对话类型（代码 / 问答 / 创意）自动切换压缩策略，token 消耗下降 40%+；子 Agent 并行委派让复杂任务拆解执行，告别串行等待。

◇ Ecosystem / 生态价值

可治理的
Agent 生态

Federated Skill Hub 通过 Git 仓库实现技能的发布、安装、验证（SHA-256 + GPG 签名），让社区沉淀的 Agent 能力可流通、可审计；Channel Adapter SDK 标准化渠道接入（飞书 / 微信 / QQ / Discord），4 个方法即可接入新平台；工具钩子 + 策略引擎为团队 AI 治理提供工程化基座。
