核心能力

三 Skill 协同 · 覆盖投研全链路

📢

Skill A — 公告跟踪员

对接交易所公开数据，按自定义股票池智能跟踪。

  • 按股票池检索当日全部公告
  • 智能区分"重大事项"与"例行披露"
  • 投行项目审核状态自动拉取
  • 审核状态变更即时推送提醒
📊

Skill B — 行业报告生成器

聚合多维行业数据，一键生成结构化行业概览。

  • Wind / Tushare / 公开数据源聚合
  • 生成市场规模 / 竞争格局 / 产业链图谱
  • 近期催化事件与核心指标表
  • 支持 Markdown / HTML / Word 导出
🔍

Skill C — 研究报告拆解员

上传 PDF/HTML 研报，自动拆解核心信息。

  • 支持招股书、年报、卖方深度研报
  • 自动拆解投资逻辑 / 财务预测 / 估值方法
  • 关键财务数据提取并比对历史趋势
  • 一键输出摘要简报
痛点 · 价值

改变前后对比

改造前 · 人工模式

  • 公告跟踪：逐条翻 3 个交易所网站，1–2 小时/日
  • 投行项目：每个项目逐一登录审核系统，30 分钟/周
  • 行业报告：切换 5–8 个工具，4–8 小时/份
  • 研报拆解：人工阅读千页文档，1–2 小时/份
  • 信息零散，无法集中管理

改造后 · Agent 模式

  • 公告跟踪：自动推送摘要，5 分钟/日
  • 投行项目：批量拉取状态变更，即时提醒
  • 行业报告：30–60 分钟/份，自然语言一次交互
  • 研报拆解：3–5 分钟/份，关键数据自动提取
  • 全部信息汇集在一个 Agent 界面
