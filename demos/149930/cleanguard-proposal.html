01

创意介绍

C盘智能管家（CleanGuard）是一款面向普通 Windows 用户的 C 盘智能清理与文件系统监控管理系统。它以系统托盘常驻小工具的形态运行，帮助用户实时监控软件安装过程写入的所有位置——文件、注册表、缓存、日志、账号凭据，在软件卸载时一键清除所有残留文件。

更重要的是，它接入了多家大语言模型 API，让 AI 分析每个文件的安全性，智能判断哪些可以安全删除，大幅降低误删风险。传统工具只能靠规则判断，我们让 AI 理解上下文。

市面上现有的清理工具（如 CCleaner、火绒清理等）要么只做基础的缓存清理，要么操作复杂、缺乏引导，普通用户经常面临"不敢删"的困境。C盘智能管家通过实时监控 + AI 智能分析的双重机制，让用户不再需要懂技术，也能放心清理系统空间。

02

痛点与目标用户

核心痛点

C 盘空间焦虑

系统盘不断被占满，但用户不知道哪些文件能删、哪些不能删

卸载残留严重

软件卸载后大量残留文件、注册表项、缓存数据留在 C 盘各处

现有工具门槛高

专业工具功能复杂，普通用户不会用；简单工具功能太少，治标不治本

误删风险大

担心删错文件导致系统或软件出问题，干脆不敢清理

目标用户

不懂技术的普通 Windows 用户 — 包括白领、学生、中老年用户等。他们日常使用电脑安装各种软件，但缺乏系统管理知识，需要一个"放心好用、一键搞定"的 C 盘清理工具。

03

核心功能

多维度实时文件监控

通过 ReadDirectoryChangesW + RegNotifyChangeKeyValue + ETW 事件追踪，实时监控软件安装过程中写入 C 盘的所有位置：文件、目录、注册表、系统日志。覆盖面远超同类产品。

智能卸载残留清理

卸载软件时，一键清除所有关联的残留文件和注册表项。所有删除默认先移到回收站，确保安全，绝不误删。

AI 智能安全分析

接入用户自带的大模型 API（支持 OpenAI、通义千问、豆包、DeepSeek、智谱 GLM 等），让 AI 分析每个文件的作用和安全性，给出清理建议，降低误删风险。

基础清理 + 浏览器缓存

系统临时文件、软件缓存、缩略图缓存、回收站、Windows 更新缓存、浏览器缓存（Chrome/Edge/Firefox）等常规清理一应俱全。

托盘小工具 + 精美面板

系统托盘常驻，点击弹出精致深色主题面板，毛玻璃效果与科技蓝配色，资源占用极低：CPU 空闲 ≤1%，内存 ≤50MB。

04

技术架构

C盘智能管家采用 Electron + C++ N-API 双层架构：前端用 Electron 实现精美 UI 和系统托盘，后端用 C++ 通过 N-API 编译为 Node.js 原生模块，直接调用 Windows 底层 API 实现高性能文件监控。两者无缝桥接，兼顾性能和美观。

05

全方位监控能力

C盘智能管家不只是监控目录的文件变化，而是通过多路径详细监控软件的所有写入行为，不放过任何一个角落。

文件系统监控

ReadDirectoryChangesW 递归监控 + USN Journal 历史回溯，覆盖 AppData、ProgramData、Temp 等关键目录

注册表监控

RegNotifyChangeKeyValue 实时监控 HKLM/HKCU 下的注册表变化，精准捕获软件安装和卸载事件

系统事件追踪

ETW 内核事件追踪 + Windows Event Log 实时订阅，捕获进程创建和文件 I/O 事件

凭据与缓存

监控 Credential Manager、浏览器登录数据、DPAPI 保护目录、软件临时缓存文件

产品形态与交互

C盘智能管家以系统托盘常驻小工具的形态运行，平时安静地待在右下角托盘区，不占屏幕空间，不影响用户工作。需要时点击托盘图标，弹出一个精美紧凑的深色面板。

1

静默监控

2

3

4

用户查看 AI 建议，勾选要清理的项目，一键执行。所有删除默认移到回收站
