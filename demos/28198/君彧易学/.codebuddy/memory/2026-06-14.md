## V2 命理分析引擎重构

### 背景
用户反馈专属解读内容与现实完全无法对接——旧引擎本质是"模板填空"而非真实分析。

### 完成工作
创建 `bazi-analysis.js`（约900行全新引擎），核心改进：

1. **旺衰判定** `getWangShuai()`：从简单五行计数 → 四维综合评估
   - 得令（月令旺相休囚死）+ 得地（通根检测）+ 得生（印星） + 得助（比劫）
   - 输出身强/偏强/中和/偏弱/身弱 五级

2. **用神判定** `getYongShenV2()`：基于真实旺衰，中和命以调候优先

3. **大运分析** `getDaYunAnalysisV2()`：与四柱的刑冲合害真实交互
   - 天干合/地支六合六冲/相害/三合半会 → 逐一检测并评分
   - 每步大运包含 interactions 数组

4. **流年分析** `analyzeLiuNianV2()`：替换360行模板字典
   - 十神定性 + 用忌判断 + 刑冲合害 + 岁运并临检测
   - `generateAllLiuNianV2()` 批量生成

5. **婚姻分析** `analyzeMarriageV2()`：
   - 修复 getShiShen(riGan, 地支) bug → 改用藏干天干
   - 配偶星追踪扩展到地支藏干

6. **健康/职业/学业** `analyzeHealthV2/CareerV2/AcademicsV2`：
   - 基于五行+十神+格局+旺衰的交叉推导
