03 · Agent Nodes

十一个协作节点

每个 Agent 负责一个明确的子任务，由 Supervisor 决定调用顺序与并发组合。悬停查看其工具栈与触发条件。

Supervisor
总控 / Router
意图分类、任务拆解、并行调度、结果融合、异常仲裁。不做具体计算，只做决策路由；structured output 保证确定性。
意图理解 任务拆解 结果融合 异常处理
Needs Clarification
需求澄清
NLP 提取 → Gap 分析 → 偏好翻译（「带5岁孩子」→ child_friendly=true）。信息齐全才放行到 planning 阶段。
信息抽取 Gap 分析 偏好翻译
Transport Search
交通查询
航班/高铁/联运中转方案。排序策略：价格升序 → 去红眼 → 直飞优先 → 用户偏好加权。
search_flights search_trains multi_modal price_calendar
Hotel Search
住宿推荐
按行程中心点搜索，rating ≥ 4.0。score = rating×0.4 + location×0.3 + price×0.2 + facility×0.1。
位置优先 口碑加权 设施筛选
Weather Check
天气查询
7 天预报 + 极端预警。规划阶段调用一次，行中由 Daemon 每 30 分钟轮询触发重规划。
和风天气 极端预警 Daemon 30min
Attraction Search
景点推荐
基于偏好 + 季节 + 体力筛选。从 OTA 景点库拉取，支持按 POI 类型聚类。
偏好匹配 季节筛选 地理聚类
Verification
反幻觉校验
时效性 (>5min 告警) · 存在性 (二次 CRS / OTA 交叉) · 价格合理性 · 逻辑一致性 (中转≥1h/40min)。
时效性 存在性 价格合理性 逻辑一致性
Itinerary Planner
行程编排
约束建模 (时间/体力/地理/天气) → 聚类排程 → 预约提醒。日体力预算：成人 15 / 老人 8 / 小孩 10 pts。
体力模型 地理聚类 预约提醒
Restaurant Recommend
餐饮推荐
按行程位置 + 用户口味匹配，真实评价交叉验证 (大众点评/美团)。
按位推荐 口味匹配 评价校验
Budget Manager
预算管理
分项汇总 (交通/住宿/餐饮/门票) · 预算约束检查 · 溢出告警 (含 budget_flexibility 容忍度)。
分项汇总 约束检查 溢出告警
Booking Executor
预订执行 · HITL
interrupt() 暂停 → 用户审批 → 事务：先 hold → 全部成功 → 确认支付；任一失败 → 释放 → 告警。
interrupt() 事务一致性 回滚释放

src/graph/workflow.py 
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver
from src.graph.state import TravelState
from src.agents import (supervisor, transport, hotel, weather,
                       attraction, verification, itinerary_planner,
                       restaurant, budget, booking)

def build_travel_graph() -> StateGraph:
    builder = StateGraph(TravelState)

    # 添加全部节点
    builder.add_node("supervisor", supervisor.run)
    builder.add_node("transport_search", transport.run)
    builder.add_node("hotel_search", hotel.run)
    builder.add_node("verification", verification.run)
    builder.add_node("itinerary_planner", itinerary_planner.run)
    builder.add_node("budget_manager", budget.run)
    builder.add_node("booking_executor", booking.run)

    builder.add_edge(START, "supervisor")

    # Supervisor 条件路由
    builder.add_conditional_edges(
        "supervisor", supervisor.router,
        {"transport_search": "transport_search", ...,
         "FINISH": END}
    )
    builder.add_edge("booking_executor", END)

    # interrupt_before 实现 HITL
    return builder.compile(
        checkpointer=MemorySaver(),
        interrupt_before=["booking_executor"]
    )
