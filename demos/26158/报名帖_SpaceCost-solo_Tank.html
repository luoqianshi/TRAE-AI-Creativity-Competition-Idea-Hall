01

创意名称与创意介绍

创意名称　SpaceCost-solo · 职场空间与资产综合管理工具

想解决什么问题

中小企业行政在管职场时面临"三套数据各管各的"的困境：

  • 工位分配靠 Excel 表或墙上贴纸，谁坐哪个工位要靠问
  • 每月成本分摊要手工算面积、算人头，公式一乱就出错
  • 固定资产折旧靠财务出报告才知道该处置
  • 季度盘点时打印清单满楼层跑，异常无法系统记录

为什么会想到做这个

十多年行政管理工作中，每次做成本分摊都要重新核对 Excel 公式；每次盘点都拿着一叠表格满楼层跑；每次等财务出折旧报告才知道哪些资产该处置了。用 AI 编程做出 SpaceCost V1.0 后发现这个方向有真实的效率提升空间，于是把空间管理与资产管理合并为一体化工具。

大概是什么产品

面向中小企业的 Windows 桌面应用（双击 exe 即可运行，数据存本地 SQLite，不依赖云服务器），集成以下核心能力：

◰

点击工位分配员工，直观看到占用情况
◨

◉
资产折旧管理

✓

发起 → 导出清单 → 填完导入 → 自动出报告
⇌
JSON 数据同步
导出 JSON 文件，其他门店可直接导入同步
⚡

内置 60 资产 + 50 员工，开箱即体验
02

目标用户及痛点

面向哪些用户

中小企业行政人员　负责工位分配、职场布置、成本分摊

企业财务或行政部门　负责固定资产折旧计算和盘点管理

部门管理者　想透明了解本部门真实占用成本

在什么场景下使用

场景用户动作替代了什么
新员工入职平面图上点击可用工位，一键分配墙上贴纸条 / 翻 Excel 问人
每月末出成本报告选月份，一键生成各部门分摊报告2 人 × 2 天手工汇总 Excel
折旧到期前系统自动提示"以下资产即将到达折旧年限"被动等财务通知，错过处置时间
季度盘点发起 → 导出清单 → 填完导入 → 自动出异常报告打印 → 满楼层跑 → 手写 → 人工录入
多门店数据同步导出 JSON，发送给其他门店导入U 盘拷贝 / 邮件传 Excel

当前痛点

数据分散　工位在 Excel、资产在另一个表、成本在财务表格里，三个数据永远对不上

计算繁琐　每月成本分摊靠手算，面积比例、人头比例每次都要重做，换人接手就是灾难

折旧被动　资产什么时候该报废全靠财务人工判断，行政没有主动权

盘点原始　打印清单 → 满楼层跑 → 手写记录 → 人工录入，异常项无法系统追踪

03

价值与意义

效率提升

  • 成本分摊从"每月 2 人天手工汇总"变成"一键生成"，每年节省约 20 人天
  • 盘点从 4 步纸质流程变成 4 步在线流程，单次节省 4–6 小时

主动管理取代被动响应

  • 折旧到期前自动提醒，资产处置从被动响应变为主动规划，降低合规风险
  • 工位占用率可视化，识别长期空置"死工位"，为租赁优化提供数据依据

降低中小企业数字化门槛

  • 替代多套 Excel / 孤立系统，无需 IT 支撑，行政自己就能上手维护
  • 双击 exe 即可运行，数据存本地 SQLite，不依赖云服务器，无需担心数据安全
  • JSON 文件导出导入，轻松实现多门店数据同步，无需局域网配置
  • 功能自主可控，未来可低成本对接飞书 / 企微 / 钉钉的智能表格
