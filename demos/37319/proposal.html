Todo Timeline

把任务放进 24 小时时间轴，让计划不再只是清单，而是可执行的一天。

创意介绍

Todo Timeline 是一款以时间轴为核心的跨平台任务管理应用。与传统待办 App 只按列表展示任务不同，它把每条任务钉在一天中的具体时段，让用户一眼看到“几点做什么事、是否冲突、还剩多少时间”。

核心洞察：待办清单解决了“记什么”，但很少解决“什么时候做”。Todo Timeline 让任务从“今天要做”变成“10:00–11:30 做”。

产品形态

基于 Qt6 / QML 开发的桌面应用，支持 Windows、Linux 与 Android。数据以 JSON 本地存储，打开即用，无需等待网络同步。

核心功能

⏱️

24 小时时间轴

直观拖拽安排任务，避免时间冲突，像课程表一样规划一天。

🏷️

分类 + 优先级

自定义分类与颜色，低/中/高优先级，快速聚焦重要事项。

🔔

任务提醒

为关键任务设置提醒时间，到期自动弹窗通知，减少遗漏。

🔍

实时搜索

按标题、描述或分类快速过滤任务，长清单也能秒定位。

🌗

主题切换

支持浅色/深色模式，保护视力，适配不同使用环境。

💾

本地存储 + 导入导出

JSON 文件本地保存，支持导入导出，数据自主可控。

目标用户与痛点

核心用户

  • 学生：安排课程、作业、复习计划
  • 职场人士：管理任务、会议、项目节点
  • 自由职业者：规划每日工作时段与 Deadline

主要痛点

  • 传统 Todo 只有列表，难以感知时间冲突
  • 日历工具太重，创建一条任务步骤繁琐
  • 云端同步依赖网络，离线或快速记录时不方便
