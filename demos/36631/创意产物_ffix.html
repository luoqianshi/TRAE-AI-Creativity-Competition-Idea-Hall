全程不需离开终端，按 Y 一键修复

模式一 · 前缀模式

fx g++ main.cpp

fx 代理执行命令，失败时自动拦截并 AI 分析

fx

混合决策引擎 · 智能修复

编译 C++ 代码时报错，零上下文切换直接在终端获得 AI 修复建议。

分阶段开发计划

第一阶段
最小可用原型 —— 命令劫持 + AI 分析
跑通 fx g++ main.cpp → 报错 → AI 返回修复建议 的完整链路
  • 命令代理层：exec.Command 透传 stdout，捕获 stderr
  • 源码上下文提取：正则解析 GCC/Clang/Rust/Python/Go 报错格式
  • AI 客户端：OpenAI 兼容 SSE 流式 API + Ollama 本地模型
  • 主入口：两种模式路由（有参数 → 前缀模式 / 无参数 → 事后纠错）
  • 配置管理：TOML 配置文件 + 环境变量 fallback
第二阶段
终端渲染与交互体验
让 AI 返回结果在终端里好看、可交互
  • Glamour Markdown 渲染 → 代码块语法高亮 + 自定义配色主题
  • Bubbletea Spinner 加载动画 → "正在分析报错..."
  • 流式输出优化 → 逐 Token 实时刷新，TTFB 监控
  • 错误输出增强 → diff 风格（红删绿增），文件路径下划线
第三阶段
本地规则引擎
常见问题毫秒级出结果，不调 AI
  • 拼写纠错：Levenshtein 编辑距离 ≤2，fx gti → git
  • 权限问题：Permission denied → 建议 sudo / chmod
  • 文件不存在：列出当前目录相似文件名
  • 端口占用：Address already in use → lsof + kill
  • 未找到命令：command not found → 包管理器安装建议
第四阶段
交互式自动修复
AI 分析完成后，用户按 Y 直接修改文件
  • [Y] 应用修复 / [n] 跳过 / [e] 手动编辑 — 默认 Y 回车即应用
  • 修改前自动备份 .bak，diff 预览确认
  • 限制单次最多修改范围，防止 AI 幻觉大范围删代码
第五阶段
多语言报错预处理 + 错误历史
  • C++ 模板报错折叠、Rust ANSI 清理、Python Traceback 截断、Go Panic 过滤
  • SQLite 错误历史：fx --history 查询、搜索、详情查看
第六阶段
构建、分发与打磨
  • 交叉编译：Linux + Windows 单二进制零依赖
  • fx --init 输出 Shell 钩子脚本，一键集成 bash/zsh
  • curl | bash 一键安装体验
