HGroundControl简介

HGC是一款基于HGroundControl开源代码进行二次开发的机器人地面站，该地面站为机器人开发者以及机器人使用者提供了包含基础配置，参数调试，任务规划等在内的服务。该款地面站主要分为四大部分，即应用设置界面，参数调试界面，任务规划界面，任务执行界面。

HGroundControl主要特色

  • ArduPilot和PX4 以及其他机器人固件的完整配置/配置。
  • 为运行PX4和ArduPilot（或其他使用MAVLink协议通信的机器人）的任务执行支持。
  • 自主任务执行的任务规划。
  • 地图显示，显示机器人位置、行动轨迹、任务点和机器人仪表。
  • 3D查看器可视化环境3D地图（.osm文件）、飞行器的3D模型（目前仅为多旋翼）以及任务3D轨迹（包括航点）。
  • 带仪表显示叠加的视频流。
  • 支持管理机器人集群。
  • QGC可在Windows、OS X、Linux平台、iOS和Android设备上运行。

以下内容参考 HGroundControl Stable V5.0 的安装页面整理，可作为 HGroundControl 当前阶段的安装说明基础。

系统要求

HGC理论上可以在现代计算机或移动设备上良好运行，但具体性能会受到系统环境、第三方应用以及可用系统资源影响。硬件性能越强，整体使用体验越好。对于大多数场景，建议至少具备以下配置：

  • 8GB 及以上内存
  • SSD 固态硬盘
  • Nvidia 或 AMD 显卡
  • Intel i5 或同等级以上 CPU

为了获得更好的兼容性与稳定性，建议使用较新的操作系统版本。

Windows 安装

支持版本：

  • Windows 10（1809 及以上）
  • Windows 11

安装步骤：

  1. 下载 Windows 安装包。
  2. 双击可执行文件启动安装程序。

说明：

  • Windows 安装程序通常会创建 3 个快捷方式：HGroundControl、GPU Compatibility Mode、GPU Safe Mode。
  • 一般情况下优先使用标准启动方式。
  • 如果启动异常或视频渲染存在问题，可尝试兼容模式或安全模式。

macOS 安装

支持版本：

  • macOS 12（Monterey）及以上

安装步骤：

  1. 下载 .dmg 安装包。
  2. 双击挂载镜像文件。
  3. 将应用程序拖动到 Applications 文件夹中完成安装。

说明：

  • 当前 QGC 原始安装说明提到应用未完成签名，因此在部分 macOS 版本中，首次安装时可能需要手动授予安装或运行权限。

Ubuntu Linux 安装

支持版本：

  • Ubuntu 22.04
  • Ubuntu 24.04

Ubuntu 默认的串口调制解调器管理服务可能会影响机器人或飞控设备的串口通信。在首次安装前，建议先移除相关服务、配置串口权限，并安装视频流所需组件。

首次安装前执行：

sh 
sudo usermod -a -G dialout $USER
sudo apt-get remove modemmanager -y
sudo apt install gstreamer1.0-plugins-bad gstreamer1.0-libav gstreamer1.0-gl -y
sudo apt install libfuse2 -y
sudo apt install libxcb-xinerama0 libxkbcommon-x11-0 libxcb-cursor-dev -y

执行完成后，退出当前账户并重新登录，以使用户权限变更生效。

安装应用：

  1. 下载 HGroundControl-x86_64.AppImage。
  2. 在终端中执行以下命令安装并运行：
sh 
chmod +x ./HGroundControl-x86_64.AppImage
./HGroundControl-x86_64.AppImage

Android 安装

支持版本：

  • Android 9 到 Android 15
  • ARM 32 位 / 64 位

安装方式：

  • 下载 Android APK 安装包并直接安装。

Windows 崩溃问题上报

如果 HGroundControl 在 Windows 平台发生崩溃，可参考 QGC 的处理方式查找崩溃转储文件。

操作步骤：

  1. 使用 Win + R 打开“运行”窗口。
  2. 输入 %localappdata% 并回车。
  3. 查找崩溃转储目录，QGC 原始说明中对应目录通常为 QGCCrashDumps。
  4. 在该目录中找到最新生成的 .dmp 文件。
  5. 将该文件上传到可访问的位置，并在问题反馈中附上链接。

说明：

  • 如果 HGC 修改了程序名称或崩溃转储目录，实际目录名称可能与 QGCCrashDumps 不同。
  • 后续建议结合 HGC 实际构建产物名称，对该部分进行一次针对性修订。

Windows 卡死问题上报

如果 Windows 提示程序“未响应”，可以通过以下方式导出转储文件：

  1. 打开“任务管理器”。
  2. 切换到“进程”标签页。
  3. 找到 qgroundcontrol.exe 对应进程。
  4. 右键该进程，选择“创建转储文件”。
  5. 将生成的转储文件保存到公开可访问的位置。
  6. 在问题反馈中附上 .dmp 文件链接及问题说明。

说明：

  • 如果 HGC 的可执行文件名称已经变化，请以实际进程名为准。

任务执行界面概述

任务执行界面用于在机器人运行过程中进行状态监控与任务控制，是 HGroundControl 中最核心的在线操作界面之一。通过该界面，用户可以完成以下工作：

  • 查看机器人当前状态、飞行模式与关键告警
  • 执行起飞、降落、返航、暂停、继续任务等常用操作
  • 查看地图、任务轨迹与当前位置
  • 显示姿态、罗盘、遥测和视频信息
  • 控制相机拍照、录像与视频流显示
  • 回放历史遥测日志，复盘任务过程

任务执行界面通常由以下几个主要区域组成：

  • 顶部工具栏
  • 左侧或悬浮任务操作区
  • 地图主视图区
  • 仪表/遥测面板
  • 姿态仪与罗盘部件
  • 相机工具与视频窗口
  • 确认滑块

界面主要组成

顶部工具栏

顶部工具栏位于界面最上方，用于显示机器人核心状态信息，并提供顶层视图切换能力。通常包括：

  • 顶层界面切换入口
  • 飞行准备状态
  • 当前飞行模式
  • 车辆消息
  • GPS 状态
  • 电池状态
  • 其他状态指示器

通过左侧主菜单入口，通常可以在以下界面之间切换：

  • 任务规划界面
  • 分析工具界面
  • 机器人配置界面
  • 应用设置界面

地图主视图区

地图区域用于显示：

  • 当前机器人位置
  • 已加载任务轨迹
  • 航点、返航点及其他任务元素
  • 多机器人位置

地图支持以下常见操作：

  • 拖拽移动地图
  • 通过滚轮、按钮或触控手势缩放地图
  • 在机器人飞行过程中点击地图发起目标位置相关操作

当设备处于运行状态时，地图上的特定位置通常可触发如下动作：

  • 前往指定位置
  • 围绕指定位置盘旋

工具栏状态说明

飞行准备状态

任务执行界面会显示机器人当前是否具备执行任务的条件，常见状态包括：

  • Ready To Fly：已满足运行条件
  • Ready To Fly 且带告警：当前模式下可运行，但仍存在风险提示
  • Not Ready：未满足运行条件，不能起飞或执行任务
  • Armed：已解锁，准备执行
  • Flying：正在运行
  • Landing：正在降落
  • Communication Lost：与机器人通信中断

当状态异常时，展开状态下拉区域通常可以看到：

  • 当前不可执行的原因
  • 更详细的错误说明
  • 可能的处理建议

该区域通常还提供以下操作：

  • 解锁
  • 上锁
  • 紧急停机

说明：

  • 紧急停机属于高风险操作，通常仅限紧急情况使用。

飞行模式

工具栏中的飞行模式区域用于显示当前模式，并可在支持的条件下切换模式。展开后通常还可进一步访问：

  • 着陆相关设置
  • 全局地理围栏设置
  • 模式列表显示配置

车辆消息

车辆消息区域用于显示来自机器人或飞控系统的文本消息。当存在重要消息时，该区域通常会高亮或变红，提醒用户及时查看。

GPS

GPS 区域通常显示：

  • 卫星数量
  • HDOP 等定位质量信息

展开后还可查看更详细的 GPS 状态信息，在支持 RTK 的场景中，还可能提供 RTK 相关设置入口。

电池

电池区域通常支持显示：

  • 剩余电量百分比
  • 电压
  • 图标颜色状态

展开后一般可进一步配置：

  • 工具栏上显示的电池信息项
  • 电池图标着色方式
  • 低电量保护或失效保护策略

其他状态指示器

在特定场景下，界面中还可能显示：

  • 遥测链路信号强度
  • 遥控链路信号强度
  • 云台状态
  • VTOL 转换状态
  • 多机器人切换入口

任务操作区

任务操作区通常用于执行最常见的实时控制动作，包括：

  • 起飞
  • 降落
  • 返航
  • 暂停
  • 恢复或继续任务
  • 高度调整
  • 预飞检查

预飞检查

系统可提供自动化预飞检查列表，用于逐项确认机器人配置正确并满足执行条件。

启用方式通常为：

  1. 打开应用设置。
  2. 进入通用设置中的任务执行界面相关选项。
  3. 启用“使用预飞检查表”。

启用后，任务操作区中会出现预飞检查入口。用户完成每一项检查后，可在界面中将其标记为完成。

起飞

当机器人处于落地状态时，可通过任务操作区执行起飞：

  1. 点击 Takeoff。
  2. 根据需要设置目标起飞高度。
  3. 使用确认滑块确认执行。

说明：

  • 某些任务模式下，系统在启动任务时会自动执行起飞步骤。

降落

在运行过程中，可随时执行当前位置降落：

  1. 点击 Land。
  2. 使用确认滑块确认降落。

返航

返航操作通常用于让机器人返回安全点：

  1. 点击 RTL 或 Return。
  2. 使用确认滑块确认执行。

说明：

  • 返航目标通常为 Home 点，但也可能受任务设置、集结点或着陆策略影响。

暂停

多数运行操作都支持暂停，例如：

  • 起飞过程
  • 降落过程
  • 返航过程
  • 任务执行过程
  • 围绕目标点盘旋

执行方式通常为：

  1. 点击 Pause。
  2. 根据需要调整目标高度。
  3. 使用确认滑块确认。

说明：

  • 前往指定位置这类动作通常不支持暂停。

改变高度

在非任务执行状态下，用户通常可以手动调整当前高度：

  1. 点击 Actions。
  2. 选择 Change Altitude。
  3. 通过垂直滑条设置新高度。
  4. 使用确认滑块确认执行。

任务开始、继续与恢复

开始任务

当机器人处于落地状态时，可通过任务操作区启动已上传任务：

  1. 点击 Actions。
  2. 选择 Start Mission。
  3. 使用确认滑块开始任务。

继续任务

Continue Mission 用于继续一个被暂停的任务，或在已经起飞但尚未进入任务流程时，从任务的下一步继续执行。

基本流程：

  1. 点击 Actions。
  2. 选择 Continue Mission。
  3. 使用确认滑块确认。

恢复任务

Resume Mission 与 Continue Mission 不同。恢复任务通常用于：

  • 在任务执行过程中返航
  • 中途降落后更换电池
  • 之后从原任务中断位置继续

当系统检测到任务中断并允许恢复时，通常会提示用户：

  • 删除机载任务
  • 保留机载任务
  • 从上次执行位置恢复任务

如果选择恢复，系统通常会重新构建任务并上传到机器人，然后再通过开始任务继续执行。

说明：

  • 系统不能总是简单地从“上一个航点”直接继续，因为前序任务项中可能包含速度、相机控制或其他会影响后续行为的命令。
  • 因此，恢复任务时通常需要重新整理并下发一份新的任务序列。

仪表与遥测面板

仪表面板用于显示当前机器人的遥测信息，默认常见内容包括：

  • 相对 Home 点高度
  • 水平速度
  • 垂直速度
  • 总运行时间
  • 机器人与地面站之间的距离

用户通常可以自定义遥测面板：

  • 调整显示位置
  • 增减显示行列
  • 为每个数据显示项选择图标、名称、单位和尺寸
  • 选择不同的数据源
  • 选择具体要展示的遥测变量

这使得任务执行界面可以针对不同机器人类型、不同任务场景进行灵活配置。

姿态仪与罗盘

姿态仪/罗盘部件用于显示：

  • 当前姿态
  • 航向信息
  • 方向参考

用户通常可根据设备平台通过长按或右键方式切换不同样式的姿态仪显示形式，并保存配置结果。

相机工具

相机工具用于完成以下工作：

  • 拍照
  • 录像
  • 切换拍照与视频模式
  • 调整相机相关参数

具体可用功能取决于所连接相机的能力。如果相机支持 MAVLink Camera Protocol，则通常还可获得更完整的控制能力，例如：

  • 切换图像拍摄模式与视频模式
  • 开始/停止录像
  • 调整更丰富的相机设置

部分通用设置通常包括：

  • 单张拍照
  • 延时拍照
  • 拍照间隔
  • 恢复相机默认参数
  • 存储格式化

视频显示

如果系统启用了视频流，任务执行界面通常会在地图区域显示视频切换窗口。用户可以在地图与视频之间切换前景显示。

视频窗口一般支持以下操作：

  • 点击窗口切换地图/视频前景
  • 拖拽调整窗口大小
  • 隐藏视频窗口
  • 将视频窗口分离为独立窗口显示

如果关闭已分离的视频窗口，系统通常会将其重新附着回任务执行界面。

视频录制

系统通常支持两类视频录制：

  • 在地面站本地录制视频流
  • 直接控制相机本体开始/停止录像

本地录制视频流

本地录制一般通过视频页面中的录制按钮控制：

  • 点击红色圆点开始录制
  • 录制中按钮会变为红色方块
  • 每次开始录制通常会生成一个新的视频文件

常见说明：

  • 默认保存格式通常为 .mkv
  • 视频文件一般保存到应用的加载/保存路径下
  • 本地录制通常只保存视频流本身，不包含软件界面元素

如果需要连同软件界面一起录制，通常需要使用独立的屏幕录制软件。

在相机端录制

若相机支持视频模式，可在相机工具中切换到视频模式，并通过录制按钮控制相机端录像。

说明：

  • 相机本体录制的视频质量可能更高
  • 但地面站本地存储空间通常更大，更适合长时间记录

视频遥测叠加

当系统在本地录制视频流时，通常还会同时导出一份字幕文件，其中包含遥测叠加数据，用于在回放视频时显示遥测信息。

其特点通常包括：

  • 叠加内容来源于当前遥测面板中选中的显示项
  • 数据更新频率通常为 1Hz
  • 显示内容会尽量以多列形式排布，以提升画面利用率

回放方式

只要播放器支持 SubStation Alpha 字幕格式，通常就可以在回放时加载该遥测字幕文件。

常见要求：

  • 视频文件与字幕文件位于同一目录
  • 文件名保持一致

永久烧录字幕

如果需要将遥测字幕永久嵌入视频文件，可使用如 HandBrake 等工具，将 .ass 字幕烧录到视频中，生成新的带字幕视频文件。

飞行数据回放

飞行数据回放功能主要用于：

  • 复盘历史任务过程
  • 分析异常行为
  • 协助开发或调试飞控/机器人系统

该功能通常仅在桌面版本中提供，例如：

  • Windows
  • Linux
  • macOS

使用流程通常为：

  1. 断开当前活动连接。
  2. 进入应用设置中的任务执行界面相关选项。
  3. 启用遥测日志回放状态栏。
  4. 在回放栏中选择 Load Telemetry Log。
  5. 选择一个遥测日志文件后立即开始回放。

日志加载后，通常可执行以下操作：

  • 播放/暂停
  • 拖动滑条切换到任意时间点
  • 调整回放速率

若要停止当前回放并切换其他日志，一般需要：

  1. 先暂停回放。
  2. 点击断开连接。
  3. 再重新加载新的日志文件。

说明：

  • 在回放暂停或停止时，地面站可能会显示“通信中断”，这是因为系统会将回放连接视为一种特殊的活动连接。
  • 如需进一步分析回放过程，可结合 MAVLink Inspector 等分析工具使用。

确认滑块

在任务执行界面中，涉及安全风险或状态切换的重要操作，通常都需要通过确认滑块完成二次确认，例如：

  • 起飞
  • 降落
  • 返航
  • 开始任务
  • 继续任务
  • 改变高度

该机制可降低误触风险，提高执行安全性。

HGroundControl自定义动作

以下内容参考 HGroundControl Stable V5.0 的 `Custo...

以下内容参考 HGroundControl Stable V5.0 的 Custom Mavlink Action 页面整理，可作为 HGroundControl 当前阶段“自定义动作”能力的说明基础。

功能概述

HGroundControl 支持向当前活动机器人发送自定义 MAVLink 命令。该能力通常可用于：

  • 在任务执行界面的动作列表中增加自定义命令
  • 将自定义命令绑定到摇杆按键
  • 为特定机器人平台快速扩展专用控制动作

这意味着当标准界面中没有现成按钮时，开发者仍可通过配置方式为 HGC 增加特定操作入口，而不必立即修改主界面逻辑。

使用场景

自定义动作适合以下场景：

  • 机器人需要执行特定 MAVLink 命令
  • 不同机型需要不同的扩展控制入口
  • 需要将某个高频命令快速映射到摇杆按钮
  • 需要为行业场景增加专用动作，如灯光、负载、云台或机构控制

动作文件格式

可用动作通过一个 JSON 文件进行定义，其核心结构如下：

json 
{
  "version": 1,
  "fileType": "MavlinkActions",
  "actions": [
    {
      "label": "First Mavlink Command",
      "description": "This is the first command",
      "mavCmd": 10,
      "compId": 100,
      "param1": 1,
      "param2": 2
    },
    {
      "label": "Second Mavlink Command",
      "description": "This is the second command",
      "mavCmd": 20
    }
  ]
}

字段说明

  • actions：必填，表示动作列表数组
  • label：必填，动作的短名称
  • description：必填，动作的详细说明
  • mavCmd：必填，要发送的 MAVLink 命令 ID
  • compId：可选，命令发送目标组件 ID
  • param1 到 param7：可选，MAVLink 命令参数

字段含义补充

label

label 是用户可见的短名称，通常会用于：

  • 任务执行界面的动作按钮文字
  • 摇杆动作下拉选择项名称

如果该动作也用于摇杆配置，建议避免与系统内置动作名称冲突。

description

description 是更长的文字说明，主要用于帮助用户在动作列表中理解该动作的用途。

mavCmd

mavCmd 是实际发送的 MAVLink 指令编号，是动作定义中最核心的字段。

compId

如果未指定 compId，系统通常默认使用 MAV_COMP_ID_AUTOPILOT1 作为发送目标。

param1-param7

若某些参数未显式配置，通常默认值为 0.0。

文件存放位置

自定义动作文件应放在 HGC 保存目录下的 MavlinkActions 目录中。QGC 原始说明中，该目录位于应用保存路径下，例如：

  • ~/Documents/HGroundControl/MavlinkActions
  • ~/Documents/HGroundControl Daily/MavlinkActions

对于 HGroundControl，实际目录建议根据产品名称、发布版本和保存路径策略进行适配。

加载机制

当 HGC 启动时，如果检测到相应的自定义动作文件，系统通常会自动加载这些定义，并使其在以下位置可用：

  • 任务执行界面的动作列表
  • 摇杆按键映射配置

说明：

  • 任务执行界面和摇杆模块可以分别使用各自的自定义动作文件。
  • 该机制适合为不同机器人类型提供差异化动作集。

使用建议

在 HGroundControl 中引入自定义动作能力时，建议：

  • 为每个动作编写清晰可读的 label
  • 用 description 说明动作用途和执行风险
  • 对高风险命令增加额外确认流程
  • 建立统一的动作命名规则，避免多机型之间混乱
  • 对常用动作配置默认模板，减少重复配置成本

风险提示

自定义动作本质上允许直接发送任意 MAVLink 命令，因此在工程或生产环境中应特别注意：

  • 参数配置错误可能导致机器人异常行为
  • 高风险命令不应暴露给无权限用户
  • 建议结合角色权限、二次确认和日志记录一起使用

HGroundControl 3D 查看器

以下内容参考 HGroundControl Stable V5.0 的 `3D Vi...

以下内容参考 HGroundControl Stable V5.0 的 3D View 页面整理，可作为 HGroundControl 当前阶段“3D 查看器”能力的说明基础。

功能概述

3D 查看器用于在三维场景中显示和监控机器人、周围环境以及已规划任务。它适合在需要更强空间感知的场景中使用，例如：

  • 观察机器人与环境的相对位置
  • 查看建筑物、地形与任务路径关系
  • 辅助理解任务航线的空间结构
  • 在三维环境中监控运行过程

3D 查看器通常保留了任务执行界面中的大部分核心能力，因此不仅是一个展示窗口，也可以作为实际运行监控界面使用。

主要能力

3D 查看器通常支持以下功能：

  • 导入并显示目标区域的 3D 地图
  • 在三维场景中显示机器人模型
  • 在三维场景中显示任务路径
  • 执行与任务执行界面类似的大部分控制操作

这些能力通常包括：

  • 执行预飞检查
  • 解锁或检查为什么无法解锁
  • 启动、继续、暂停和恢复任务
  • 起飞、降落、返航、调整高度
  • 显示视频、遥测和其他运行信息
  • 在多机器人场景中切换当前对象

启用方式

3D 查看器默认通常是关闭状态。要启用该功能，通常需要：

  1. 打开应用设置。
  2. 进入 Fly View 或任务执行界面相关设置页。
  3. 找到 3D View 设置组。
  4. 打开 Enabled 开关。

启用后，用户可在任务执行界面的左侧工具栏或相关入口中打开 3D 查看器。

基本交互

打开 3D 查看器后，用户可以通过鼠标或触摸屏在三维环境中进行浏览。

鼠标操作

  • 左键拖动：水平或垂直移动视角
  • 右键拖动：旋转视角
  • 滚轮：缩放视图

触控操作

  • 单指拖动：水平或垂直移动
  • 双指拖动：旋转视角
  • 双指捏合：缩放视图

3D 地图导入

若要在 3D 查看器中显示某一片区域，通常需要先从 OpenStreetMap 下载该区域的 .osm 文件，再将其导入 HGC 的 3D 视图设置中。

典型流程如下：

  1. 前往 OpenStreetMap 网站。
  2. 下载目标区域的 .osm 文件。
  3. 在 HGC 的 3D View 设置中选择该文件。
  4. 导入后，在 3D 场景中显示该区域地图。

3D 查看器设置项

3D 查看器通常包含以下可配置项：

Enabled

用于启用或关闭 3D 查看器功能。

3D Map File

用于指定要加载的 .osm 地图文件路径。一般会提供以下操作：

  • 选择文件
  • 清除当前已加载文件

Average Building Level Height

用于指定建筑每层的平均高度。在某些 .osm 文件中，建筑物高度可能以楼层数而不是绝对高度表示，因此需要通过该参数换算建筑高度。

Vehicle Altitude Bias

用于设置机器人及任务在 3D 场景中的高度偏移量。该参数适用于以下情况：

  • 飞控估计高度存在系统偏差
  • 相对高度与实际地表高度不完全一致
  • 需要让三维显示效果更贴近真实场景

适用价值

在 HGroundControl 中，3D 查看器特别适合以下应用：

  • 建筑密集区域的任务观察
  • 多层空间作业任务展示
  • 教学演示与任务复盘
  • 向非专业用户展示任务路线和环境关系

使用建议

为获得更好的使用体验，建议：

  • 优先为关键任务区域准备高质量 .osm 数据
  • 根据场景调节建筑层高参数
  • 如发现机器人显示高度与地面不一致，可适当调整高度偏移
  • 在任务监控中将 2D 地图与 3D 视图配合使用

说明

  • 3D 查看器更偏向空间展示和任务监控增强，不一定完全替代 2D 地图界面。
  • 它适合作为任务执行界面的扩展能力，与视频、遥测、任务路径显示结合使用。

HGroundControl任务规划界面

以下内容参考 HGroundControl Stable V5.0 的 Plan View、GeoFence、Rally Points 与各类 Pattern 页面整理，可作为 HGroundControl 当前阶段“任务规划界面”的说明基础。

功能概述

任务规划界面用于规划自主任务，并将规划结果上传到机器人。完成规划并下发后，用户通常会切换到任务执行界面执行任务。

除基础任务点编辑外，任务规划界面通常还承担以下能力：

  • 规划航点任务
  • 配置电子围栏
  • 配置集结点
  • 创建复杂任务模板
  • 保存、加载、上传和下载任务文件

界面组成

任务规划界面的主要区域通常包括：

  • 地图区域
  • 规划工具栏
  • 任务工具区
  • 任务命令列表
  • 地形高度覆盖信息

地图区域

地图用于显示并编辑当前任务中的所有关键对象，包括：

  • 计划 Home 点
  • 航点
  • 起飞点和降落点
  • 电子围栏区域
  • 集结点
  • 各类规划模板生成的轨迹

用户通常可以通过点击选中对象，通过拖拽改变其位置。

规划工具栏

规划工具栏通常显示：

  • 当前选中航点相对于上一个航点的信息
  • 整个任务的统计信息
  • 最远遥测距离
  • 上传按钮

其中，Max telem dist 一般表示计划 Home 点与最远任务点之间的距离。

任务工具区

任务工具区主要用于：

  • 添加航点
  • 启动复杂任务模板
  • 上传/下载任务
  • 从文件保存/恢复任务
  • 地图浏览与缩放

任务命令列表

右侧的任务命令列表用于显示并编辑当前任务中的所有任务项。用户通常可以：

  • 切换编辑任务、电子围栏和集结点
  • 选中某个任务项进行编辑
  • 插入或删除命令
  • 修改命令类型

任务规划基本流程

创建一个典型任务通常包括以下步骤：

  1. 切换到任务规划界面。
  2. 添加航点、任务命令或模板任务。
  3. 根据需要编辑参数。
  4. 将任务上传到机器人。
  5. 切换到任务执行界面执行任务。

计划 Home 点

任务规划中的 Home 点用于在没有连接实际机器人时模拟起点位置，以便：

  • 估算任务时间
  • 计算飞行距离
  • 预览路径走向

说明：

  • 该 Home 点只是规划时使用的“计划 Home 点”。
  • 实际运行中的 Home 点通常由飞控在解锁时设置。
  • 任务规划中可以拖动 Home 点到预计起飞位置。
  • Home 点高度通常可在任务设置面板中修改。

任务工具说明

添加航点

点击 Add Waypoint 后，地图点击位置会新增一个航点。通常：

  • 工具保持激活，便于连续添加多个航点
  • 已创建航点可再次拖动调整位置

文件同步与任务文件

文件工具通常用于在地面站、本地文件与机器人之间同步任务。常见能力包括：

  • 上传任务到机器人
  • 从机器人下载任务
  • 保存任务到文件
  • 另存为文件
  • 导出为 KML
  • 从文件加载任务
  • 删除所有任务项

说明：

  • 当任务发生本地修改但尚未同步到机器人时，文件工具通常会显示提示标记。
  • 在执行任务前，必须先将任务上传到机器人。

Pattern 模板工具

Pattern 工具用于快速生成复杂几何任务。根据机器人类型与飞控支持情况，常见模板包括：

  • Survey
  • Structure Scan
  • Corridor Scan
  • Fixed Wing Landing

任务命令编辑

在任务命令列表中点击某个任务项后，通常可以打开对应编辑器并修改参数。

可编辑内容通常包括：

  • 任务命令类型
  • 坐标与高度
  • 相机动作
  • 飞行速度
  • 重复执行逻辑

命令类型通常可以通过点击任务名称后重新选择，例如：

  • Waypoint
  • Start image capture
  • Jump to item
  • 其他固件支持的命令

说明：

  • 实际可用命令会受到飞控类型和机器人类型影响。

任务设置

任务命令列表中的第一个项目通常是任务设置项，它会影响整个任务的默认行为。

默认航点高度

可为新加入任务的首个航点设定默认高度。后续航点通常会继承前一个任务项的初始高度。

任务飞行速度

可为整条任务指定一个不同于系统默认值的飞行速度。

任务结束行为

通常可配置任务结束后是否自动执行返航。

计划 Home 点设置

任务设置中一般还可进一步配置：

  • Home 点高度
  • 将 Home 点设置为地图中心

相机设置

任务设置中通常可配置相机在任务开始后的默认行为，例如：

  • 不改变当前状态
  • 按时间间隔拍照
  • 按距离间隔拍照
  • 停止拍照
  • 开始录像
  • 停止录像

机器人信息

如果当前未连接机器人，系统通常允许手动指定以下信息，以便生成正确的任务能力与估算结果：

  • 固件类型
  • 机器人类型
  • 飞行速度

电子围栏

电子围栏用于定义机器人允许运动或禁止进入的虚拟区域，也可配置越界后的动作。

创建电子围栏

典型流程如下：

  1. 进入任务规划界面。
  2. 在右侧任务类型切换区域选择 Geofence。
  3. 选择添加圆形围栏或多边形围栏。
  4. 在地图上编辑围栏位置和形状。

电子围栏支持：

  • 圆形围栏
  • 多边形围栏
  • 多区域组合

围栏编辑方式

圆形围栏通常支持：

  • 拖动中心点移动位置
  • 拖动边缘点调整半径
  • 在面板中直接修改半径

多边形围栏通常支持：

  • 拖动顶点修改形状
  • 点击边线中间的控制点新增顶点

包含区与排除区

新建围栏一般默认是“包含区”，即机器人必须在围栏范围内活动。通过切换选项，也可以改为“排除区”，即机器人不能进入该区域。

编辑与删除

在围栏列表中选中某个围栏后，通常可继续编辑；也可以通过对应的删除按钮将其移除。

上传方式

电子围栏一般通过与任务相同的文件/同步工具上传到机器人。

集结点

集结点是返航模式下可选的替代降落点或盘旋点，通常用于：

  • 比 Home 点更安全的降落位置
  • 更靠近当前任务区域的备选落点
  • 特定应急返航策略

创建集结点

一般流程如下：

  1. 进入任务规划界面。
  2. 选择 Rally。
  3. 在地图上点击需要设置集结点的位置。

每个集结点通常会以 R 标记显示。当前激活的集结点通常会以不同颜色显示，并可通过右侧面板继续编辑。

编辑与删除

通常支持：

  • 拖动地图上的集结点修改位置
  • 在面板中编辑坐标
  • 通过面板菜单删除当前激活的集结点

上传方式

集结点通常与任务类似，通过文件/同步工具上传到机器人。

Pattern 模板概览

Pattern 模板用于简化复杂任务的创建。不同模板适合不同业务场景：

  • Survey：多边形区域测绘
  • Structure Scan：结构立面巡检/建模
  • Corridor Scan：走廊/道路/线路测绘
  • Fixed Wing Landing：固定翼着陆模式

Survey 测绘任务

Survey 用于在一个多边形区域上生成网格飞行路线，适合：

  • 地图测绘
  • 正射采集
  • 地表巡检
  • 带地理标记照片采集

创建方式

  1. 打开任务规划界面的 Pattern Tool。
  2. 选择 Survey。
  3. 在地图上编辑多边形区域。
  4. 根据需要调整相机、网格与地形参数。

区域编辑

Survey 区域通常支持：

  • 拖动多边形顶点改变形状
  • 点击边线上的 + 增加新顶点

相机设置

Survey 通常支持三类相机模式：

  • 已知相机
  • 自定义相机
  • 手动相机参数

可配置内容通常包括：

  • 横拍/竖拍
  • 图像重叠率
  • 飞行高度
  • 地面分辨率
  • 传感器尺寸
  • 图像分辨率
  • 焦距
  • 触发距离
  • 航线间距

航线设置

Survey 的航线部分一般可配置：

  • 网格角度
  • 转弯冗余距离
  • 旋转入口点
  • 悬停拍照
  • 90 度偏置复飞
  • 转弯处拍照
  • 高度是否相对 Home

地形跟随

当地形起伏较大时，建议启用地形跟随，以保持机器人相对地面的飞行高度更稳定，并降低贴地风险。

通常可配置：

  • 是否启用地形跟随
  • 高度容差
  • 最大爬升率
  • 最大下降率

统计信息

Survey 通常会显示：

  • 测绘面积
  • 拍照间隔
  • 拍照间距
  • 计划照片数量

Structure Scan 结构扫描

Structure Scan 用于围绕建筑或结构体的立面生成分层扫描航线，适合：

  • 建筑立面巡检
  • 结构外观检查
  • 3D 模型重建

基本特征

该模式通常围绕一个多边形或圆形地面轮廓生成环绕式分层飞行路径。机器人会在不同高度层逐圈飞行，直到完成整个结构表面的采集。

创建方式

  1. 在 Pattern Tool 中选择 Structure Scan。
  2. 在地图上生成初始结构区域。
  3. 调整结构轮廓，使其包围目标物体。
  4. 在右侧编辑器中配置扫描参数。

区域形状

Structure Scan 一般支持：

  • 多边形轮廓
  • 圆形轮廓

并通常可通过点击中心控制点在圆形与多边形之间切换。

主要参数

所有模式下一般都可配置：

  • 从顶部或底部开始扫描
  • 结构高度
  • 扫描距离
  • 出入口高度
  • 底部扫描高度
  • 旋转入口点

相机模式

Structure Scan 常见模式包括：

  • 手动模式
  • 已知相机模式
  • 自定义相机模式

手动模式通常可设置：

  • 层高
  • 触发距离
  • 云台俯仰角

已知/自定义相机模式通常可设置：

  • 相机方向
  • 前向重叠
  • 侧向重叠
  • 扫描距离
  • 地面分辨率

Corridor Scan 走廊扫描

Corridor Scan 用于沿一条折线生成带状测绘任务，适合：

  • 道路测绘
  • 河道巡检
  • 管线/输电线路巡检
  • 铁路或边界带状区域采集

创建方式

  1. 在 Pattern Tool 中选择 Corridor Scan。
  2. 在地图上生成初始走廊。
  3. 拖动起点与终点到目标位置。
  4. 通过边线中点添加新的折线顶点。

相机设置

Corridor Scan 通常支持：

  • 已知相机模式
  • 手动相机模式

相关参数一般包括：

  • 横拍/竖拍
  • 图像重叠率
  • 飞行高度
  • 地面分辨率
  • 触发距离
  • 航线间距

走廊参数

常见可配置项包括：

  • 走廊宽度
  • 转弯延伸距离
  • 转弯处拍照
  • 相对高度
  • 旋转入口点

地形跟随

与 Survey 类似，在高低起伏明显的区域中，Corridor Scan 通常也建议开启地形跟随。

固定翼着陆模式

固定翼着陆模式用于为固定翼任务加入标准化着陆过程，适用于 PX4 和 ArduPilot 的固定翼任务。

工作方式

该模式通常包含两个关键点：

  • 盘旋等待点
  • 着陆点

机器人会先在盘旋点等待到达指定高度，再从该点沿着着陆路径飞向最终着陆点。

创建方式

  1. 在 Pattern Tool 中选择 Fixed Wing Landing Pattern。
  2. 在地图上创建盘旋点与着陆点。
  3. 调整位置并配置相关着陆参数。

盘旋点设置

通常可配置：

  • 盘旋高度
  • 盘旋半径
  • 顺时针或逆时针盘旋

着陆点设置

通常可配置：

  • 航向
  • 着陆点高度
  • 盘旋点到着陆点距离
  • 下滑角
  • 高度是否相对 Home

实现说明

该模式在底层通常会生成多个任务项，例如：

  • DO_LAND_START
  • NAV_LOITER_TO_ALT
  • NAV_LAND

若着陆参数违反飞控的下滑或拉平约束，任务上传后通常会触发飞控报错。

Pattern 预设

Pattern 预设允许用户把一组常用配置保存成命名模板，便于后续重复使用。

说明：

  • 当前该能力通常首先支持 Survey，其他模板支持可能逐步增加。

预设管理

常见预设操作包括：

  • 不使用预设，手动配置所有参数
  • 将当前设置保存为预设
  • 删除当前预设
  • 从已有预设列表中选择

创建或更新预设

当选择保存为预设时，系统通常会要求输入预设名称。若当前已选中某个预设，则可直接用当前设置覆盖更新该预设。

通常还可以选择：

  • 是否将当前相机一并保存进预设

如果同一个任务模板会长期配合同一相机使用，通常建议同时保存相机配置。

查看预设内容

若要查看预设的具体参数，通常可以先切回“自定义配置”模式查看全部字段，再切回命名预设。

计划文件中的预设

当前选中的预设通常也会被写入任务文件中。需要注意：

  • 预设与具体 HGC/QGC 版本有关
  • 如果不同用户本地存在同名但内容不同的预设，分享任务文件时可能出现行为不一致

任务上传/下载故障排查

任务、电子围栏和集结点的上传下载在链路质量较差时可能失败。常见原因包括：

  • 遥测链路丢包较高
  • 通信链路不稳定
  • 飞控或地面站协议处理异常

一般建议：

  • 检查 MAVLink 丢包率
  • 丢包率尽量控制在较低水平
  • 必要时开启控制台日志分析上传下载过程

使用建议

在 HGroundControl 中使用任务规划界面时，建议：

  • 在离线规划时先正确设置计划 Home 点
  • 上传前检查任务结束行为和相机动作
  • 对复杂任务优先使用 Pattern 模板提高效率
  • 山区或高差明显区域尽量启用地形跟随
  • 将电子围栏与集结点作为正式任务的安全补充
  • 固定翼任务重点检查着陆模式参数是否合理

HGroundControl参数调试界面

以下内容参考 HGroundControl Stable V5.0 的 `Setup...

以下内容参考 HGroundControl Stable V5.0 的 Setup View 及其相关页面整理，可作为 HGroundControl 当前阶段“参数调试界面”的说明基础。

功能概述

参数调试界面主要用于机器人首次使用前的基础配置、校准、调参与硬件验证。它通常面向以下阶段：

  • 新设备接入后的初始化配置
  • 固件烧录或升级
  • 机架与传感器校准
  • 飞行模式、失效保护和电源参数设置
  • 电机测试与方向检查
  • 相机、手柄与高级参数调试

如果某一项尚未配置完成，系统通常会在侧边栏或汇总卡片中以红色状态提示，表示该项仍需处理。在正式执行任务前，应尽量消除这些未完成项。

界面组成

参数调试界面通常由以下部分组成：

  • 左侧配置菜单
  • 中央配置页面
  • 顶部工具栏
  • 汇总状态卡片

左侧菜单会根据固件类型和机器人类型动态变化。PX4 与 ArduPilot 在可用页面和页面内容上并不完全一致。

常见配置入口

参数调试界面通常包含以下主要入口：

  • 总览
  • 固件
  • 机架
  • 遥控器
  • 传感器
  • 飞行模式
  • 电源
  • 电机
  • 安全
  • 调参
  • 相机
  • 手柄
  • 参数

推荐配置流程

对于新机器人，建议按如下顺序完成基础配置：

  1. 烧录或升级固件。
  2. 选择机架类型。
  3. 校准遥控器。
  4. 校准传感器。
  5. 配置飞行模式。
  6. 配置电源参数。
  7. 检查电机输出和旋转方向。
  8. 配置失效保护与安全项。
  9. 进行基础调参。
  10. 根据需要配置相机、手柄和高级参数。

总览页

总览页用于集中展示关键配置项的完成状态。每个配置块通常对应一个具体页面，例如：

  • 固件
  • 机架
  • 遥控器
  • 传感器
  • 飞行模式
  • 电源
  • 电机
  • 安全
  • 调参
  • 相机
  • 参数

如果某个配置块仍显示红色，通常意味着还存在未完成配置，不建议直接进入执行阶段。

固件管理

固件页面用于向飞控板、SiK 电台或 PX4 Flow 等设备烧录固件。该能力通常只在桌面版本中提供。

使用前提

  • 升级前应断开所有与机器人相关的 USB 或遥测连接
  • 设备不应由电池供电
  • 建议直接连接计算机主机 USB 口，不通过集线器

基本流程

  1. 进入参数调试界面的 固件 页面。
  2. 通过 USB 连接目标设备。
  3. 选择要安装的固件类型。
  4. 如有需要，打开高级选项选择测试版、每日构建或本地固件文件。
  5. 确认后开始升级。

说明

  • 默认通常安装对应固件的稳定版本。
  • 升级完成后，设备会自动重启。
  • 固件写入后通常还需要继续完成机架、传感器和遥控器等配置。

机架配置

机架配置用于指定机器人结构类型，使飞控知道当前设备的动力布局和控制模型。

ArduPilot 机架配置

ArduPilot 的机架配置主要面向 ArduCopter 和 ArduSub。

  • ArduCopter 通常需要先选择大类机架，再选择具体机型
  • 修改机架大类后，通常需要重启设备使其生效
  • ArduSub 需要选择与实际推进器布局一致的框架类型

对于 ArduSub，还应确认：

  • 所有推进器连接到正确输出口
  • 顺时针和逆时针桨叶安装符合框架要求
  • 必要时加载默认参数集

PX4 机架配置

PX4 的机架配置通常需要：

  1. 连接机器人。
  2. 打开 机架 页面。
  3. 选择大类机型。
  4. 在该大类下选择最接近实际设备的具体布局。
  5. 点击应用并重启。

正确的机架配置通常也是后续自动调参、飞行控制和电机测试的基础。

遥控器校准

遥控器页面用于建立主摇杆与通道之间的映射，并校准各通道的最小值、最大值、中位和反向设置。

校准前提

  • 遥控发射机和接收机已经完成对频或绑定
  • 发射机处于正常工作状态

校准流程

  1. 进入 遥控器 页面。
  2. 打开发射机。
  3. 启动校准。
  4. 选择与发射机一致的模式类型。
  5. 按界面提示依次移动主摇杆。
  6. 再依次拨动其他开关、旋钮和滑块。
  7. 保存结果。

附加功能

遥控器页面还可能提供以下高级能力：

  • Spektrum 接收机绑定
  • 复制发射机微调量到飞控
  • PX4 AUX 透传通道
  • PX4 参数调节通道映射

其中，参数调节通道允许把遥控旋钮映射到某个参数，便于在试飞过程中动态微调。

传感器校准

传感器页面用于校准指南针、陀螺仪、加速度计、空速计、水平线和其他传感器。页面中通常会以颜色区分状态：

  • 绿色：已完成校准
  • 红色：必须校准后再使用
  • 无灯：可选配置项

ArduPilot 传感器校准

ArduPilot 常见传感器项包括：

  • 加速度计
  • 指南针
  • 水平校准
  • 气压计
  • CompassMot
  • 传感器方向设置

加速度计通常要求用户按提示把设备放在多个姿态上逐步采样。

指南针校准通常要求随机绕各轴旋转设备，直到进度完成。完成后还可查看各指南针的校准质量，用于判断是否需要禁用表现较差的指南针。

CompassMot 是可选项，适合存在明显电机磁干扰且具备电流监测的设备。

PX4 传感器校准

PX4 常见传感器项包括：

  • 指南针
  • 陀螺仪
  • 加速度计
  • 水平校准
  • 空速计
  • 安装方向设置

陀螺仪校准通常要求设备静止放置在平面上。

空速计校准通常要求：

  • 在无风状态下读取基线
  • 遮挡探头避免环境气流干扰
  • 按提示吹气完成检测

方向设置

如果飞控或外置指南针不是以前向、正立方式安装，就需要配置安装方向。通常可设置：

  • 飞控方向
  • 外置指南针方向

未正确设置方向会导致姿态和航向异常。

飞行模式配置

飞行模式页面用于把发射机上的一个或多个开关映射到飞行模式选择通道。

基本原理

系统通常允许把多个物理开关的位置编码成单一通道上的不同 PWM 值，从而在一个通道上表示最多 6 个模式。

通用要求

  • 必须先完成遥控器校准
  • 需要先在发射机侧完成模式通道混控

ArduPilot 模式配置

ArduPilot 通常支持：

  • 在单一模式通道上配置最多 6 个飞行模式
  • 在 ArduCopter 中给 7 到 12 通道配置附加功能
  • 在 ArduPlane 中选择模式通道

系统会在切换开关时高亮当前激活模式，便于验证映射是否正确。

PX4 模式配置

PX4 通常需要：

  • 指定模式通道
  • 为最多 6 个位置配置飞行模式
  • 为额外通道分配特定动作，例如起落架或紧急停机

建议至少配置稳定、返航和任务相关模式，以满足基本运行需求。

电源配置

电源页面主要用于设置电池参数、功率模块参数和部分电调相关选项。

电池参数

常见配置包括：

  • 电池串数
  • 满电电压
  • 空电电压
  • 电压分压系数
  • 每伏电流系数

如果具备万用表或电流测量条件，系统通常可以根据实测值自动计算电压分压和电流比例系数。

高级设置

高级设置通常包括：

  • 满载压降补偿
  • ESC PWM 最小/最大值校准
  • UAVCAN 电源相关设置

风险提示

  • 电调校准前必须拆除桨叶
  • 某些不支持标准校准流程的电调，可能在校准时以最大功率运转
  • 满载压降值设置过高可能导致电池过放

电机测试

电机页面用于测试各个电机或舵机的输出，确认其连接顺序和旋转方向是否正确。

通用测试流程

  1. 拆除所有桨叶。
  2. 如为 PX4，必要时打开安全开关。
  3. 滑动安全确认开关以启用测试。
  4. 设定测试功率。
  5. 分别点击各电机按钮进行测试。

说明

  • 电机通常会在短时间后自动停止
  • 如果没有转动，可适当提高推力百分比再测试

ArduSub 电机设置

ArduSub 额外支持：

  • 手动测试单个推进器正反转
  • 自动检测推进器方向

自动检测方向时，系统会对推进器施加脉冲，并根据机器人反应判断是否需要反转。该过程仍要求推进器接线顺序正确。

安全与失效保护

安全页面用于配置不同机器人类型的失效保护策略。ArduPilot 的页面通常按 Copter、Plane、Rover、Sub 分别展示。

常见安全项

  • 电池失效保护
  • 地面站失联保护
  • 油门失效保护
  • 电子围栏保护
  • 返航高度与返航行为
  • 解锁前检查项

Copter 常见配置

多旋翼常见安全配置包括：

  • 低电量和严重低电量动作
  • 电压或剩余容量阈值
  • 地面站失联动作
  • 油门失效保护动作
  • 圆柱围栏和高度围栏
  • 围栏越界动作
  • RTL 返回高度和返航后行为
  • 解锁前安全检查位掩码

Plane、Rover、Sub 差异

  • Plane 更关注返航高度、油门保护和高级失效保护
  • Rover 更关注地面站失联、油门阈值和碰撞检查
  • Sub 更关注漏水、内部压力、内部温度、EKF 和驾驶员输入失效保护

说明

  • 安全页通常只覆盖最重要的失效保护项
  • 更细的安全参数仍需要通过参数编辑器配置

调参

调参页面用于优化机器人控制响应。不同固件和机器人类型的能力差异较大。

ArduCopter 调参

ArduCopter 页面通常提供：

  • 基础调参滑块
  • AutoTune 自动调参
  • 飞行中参数调节

AutoTune 一般流程为：

  1. 选择要调节的轴。
  2. 将 AutoTune 绑定到遥控器开关。
  3. 起飞并进入合适模式。
  4. 打开 AutoTune 开关执行调参。
  5. 调参结束后通过开关测试新旧参数。
  6. 在满足条件时落地并保存结果。

一次只调一个轴通常更稳妥，也更节省电池。

ArduSub 调参

ArduSub 更偏向手动调节多个控制器参数，常见包括：

  • 姿态控制器参数
  • 位置控制器参数
  • 航点导航参数

这些参数可用于在“响应更灵敏”和“运动更平滑”之间做平衡。

PX4 调参

PX4 通常同时支持：

  • 自动调参
  • 手动 PID 调参

自动调参一般要求设备已经具备基本可飞行性，并在安全空域中完成。多旋翼通常悬停于数米高度执行，固定翼或 VTOL 则需要在合适巡航状态下进行。

手动调参通常包含：

  • 选择控制器页签
  • 选择 Roll、Pitch、Yaw 等轴
  • 观察响应曲线
  • 通过滑块调整参数
  • 使用剪贴板保存和恢复当前参数组

相机配置

相机页面用于配置相机和云台相关设置。页面细节会随 PX4 或 ArduPilot 不同而变化。

说明：

  • 某些老旧飞控平台默认可能不启用相机模块
  • 实际可见配置项取决于固件是否启用了对应相机支持

手柄配置

手柄页面允许用户使用摇杆或游戏手柄替代传统遥控器控制机器人。

基本说明

  • 手柄控制依赖高带宽且稳定的遥测链路
  • 手柄输入通常通过 MAVLink 下发
  • 手柄通常在校准流程最后一步才会被真正启用

固件支持

  • ArduPilot 通常默认支持手柄
  • PX4 通常需要把 COM_RC_IN_MODE 设置为 Joystick

配置流程

  1. 连接机器人。
  2. 通过 USB 接入手柄。
  3. 打开 手柄 页面。
  4. 选择当前活动手柄。
  5. 进入校准页签并按提示完成校准。
  6. 在监视区检查各轴和按钮是否正常。
  7. 为按钮分配飞行模式或功能。

高级选项

手柄页面通常还提供：

  • 油门模式选择
  • 负推力支持
  • 中心区 Expo 曲线
  • 云台控制通道
  • 手柄控制模式
  • 轴和按钮发送频率
  • 圆形修正
  • 死区调节

不同控制模式可能对应不同 MAVLink 消息，例如：

  • Normal
  • Attitude
  • Position
  • Force
  • Velocity

使用建议

  • 对实时性要求高的机器人，优先使用质量较好的遥测链路
  • 如果摇杆回中不稳定，应适当增大死区
  • 对细腻控制需求高的场景，可适当增加 Expo

参数编辑器

参数页面用于查找、修改并管理机器人全部参数，是最底层也最灵活的调试入口。

查找参数

参数通常按组分类，也支持搜索参数名或描述中的关键字。

修改参数

点击某个参数后，通常会打开侧边编辑器，可修改数值并查看附加说明，例如：

  • 参数用途
  • 是否需要重启生效

保存后，参数通常会立即写入飞控；若参数属于重启生效项，还需要重启设备。

工具菜单

参数页面通常提供以下工具：

  • 刷新参数
  • 恢复全部默认值
  • 从文件加载参数
  • 保存参数到文件
  • 清除 RC 到参数映射
  • 重启机器人

使用建议

  • 优先通过专门配置页面修改常见参数
  • 只有在明确理解参数含义时再通过参数页修改高级参数
  • 调整前建议先导出当前参数文件备份

使用建议

在 HGroundControl 中使用参数调试界面时，建议：

  • 严格按“固件、机架、遥控器、传感器、电源、电机、安全、调参”的顺序推进
  • 所有涉及电机或电调的测试前，必须拆除桨叶或确认推进器安全
  • 对安装方向、指南针和加速度计校准结果进行二次核对
  • 首次调参优先使用保守配置，不要一次性大幅修改多个参数
  • 在修改高级参数前先导出备份，便于出现异常时快速回滚

HGroundControl应用设置界面

以下内容参考 HGroundControl Stable V5.0 的 Settings View 相关页面整理，可作为 HGroundControl 当前阶段“应用设置界面”的说明基础。

功能概述

应用设置界面用于配置 HGroundControl 应用本身的行为，而不是某一台具体机器人。因此，即使当前没有连接机器人，用户通常也可以修改这些设置。

该界面主要用于：

  • 配置界面显示单位和语言
  • 设置地图、视频和日志行为
  • 管理自动连接设备
  • 设置 RTK 基站和地面站 GPS
  • 配置 MAVLink 通信行为
  • 开启控制台日志和虚拟摇杆

界面结构

应用设置界面通常通过左侧菜单切换不同设置页。常见入口包括：

  • 通用设置
  • 通信链路
  • 离线地图
  • MAVLink
  • 控制台

这些设置大多属于应用级配置，因此修改后会影响整个地面站的默认行为。

通用设置

通用设置是应用级配置的主入口，通常用于集中设置单位、地图、视频、自动连接和界面行为等内容。

单位设置

单位设置用于定义应用内展示数据时所采用的单位制。常见可配置项包括：

  • 距离：米、英尺
  • 面积：平方米、平方千米、公顷、英亩等
  • 速度：米每秒、千米每小时、节、英里每小时等
  • 温度：摄氏度、华氏度

统一单位设置有助于确保任务规划、任务执行和日志分析阶段的数据口径一致。

杂项设置

杂项设置通常包含大量与显示和操作习惯有关的选项，例如：

  • 语言
  • 颜色主题
  • 地图服务提供商
  • 地图类型
  • UI 缩放
  • 音频开关
  • 默认加载/保存路径
  • 电量播报阈值
  • 是否自动加载任务
  • 虚拟摇杆开关

其中比较常用的选项包括：

  • Language：设置界面显示语言
  • Color Scheme：切换深色或浅色主题
  • Map Provider：选择地图源
  • Map Type：选择道路图、混合图或卫星图
  • Application Load/Save Path：定义日志、任务、参数等默认保存路径

自动加载任务

如果启用自动加载任务，系统在连接到机器人时会自动上传预设任务文件。此功能适合固定流程场景，但在多机或多任务环境中应谨慎开启。

数据持久化

数据持久化设置用于控制应用是否允许保存和缓存本地数据。若启用“禁用所有数据持久化”，则系统通常不会保存：

  • 遥测日志
  • 缓存地图瓦片
  • 其他应用运行缓存

该模式适用于对本地落盘数据有严格限制的场景。

遥测日志设置

通用设置中通常包含“来自机器人的遥测日志”相关选项，用于控制 .tlog 日志自动保存行为。

常见项包括：

  • 每次任务后自动保存日志
  • 即使机器人未解锁也保存日志
  • 启用 CSV 日志

说明：

  • .tlog 更完整，适合详细回放和分析
  • CSV 更轻量，适合快速表格处理

CSV 日志

启用 CSV 日志后，系统通常会在保存 .tlog 的同时生成一份 CSV 遥测文件。

其特点通常包括：

  • 记录关键遥测字段
  • 更新频率约为 1 Hz
  • 内容比 .tlog 少，但更易导入表格软件

适合快速处理的数据通常包括：

  • GPS 位置
  • 姿态
  • 电池状态
  • 其他基础遥测指标

CSV 文件通常可以直接用以下工具打开：

  • Microsoft Excel
  • Google Sheets
  • LibreOffice Calc
  • OpenOffice Calc

飞行界面相关设置

通用设置中通常还会包含与任务执行界面有关的应用级选项，例如：

  • 启用预飞检查表
  • 强制完成预飞检查后才允许解锁
  • 始终让地图跟随当前机器人
  • 显示遥测日志回放状态栏
  • 启用虚拟摇杆
  • 仪表面板垂直布局
  • 罗盘额外指示项
  • 引导动作的最小/最大高度
  • Go To 最大距离

这些设置主要用于影响任务执行界面的交互体验和安全边界。

任务规划相关设置

应用设置中通常还提供与任务规划界面相关的默认选项，例如：

  • 默认任务高度

该值通常会作为任务起始高度或首个航点的默认高度基础。

自动连接设备

自动连接设置用于指定应用启动后优先自动连接哪些常见设备。常见类型包括：

  • Pixhawk 系列飞控
  • SiK 遥测电台
  • PX4 Flow
  • UDP 连接
  • RTK GPS
  • 外部 NMEA GPS

地面站位置来源

如果设备支持内部 GPS，应用通常会在地图上显示地面站位置。除此之外，也可连接外部 NMEA GPS 设备，将其作为地面站定位源。

外部 NMEA GPS 一般支持：

  • 串口接入
  • UDP 接入

该能力在以下场景中特别有用：

  • 需要更高精度的地面站位置
  • 需要为 Follow Me 提供位置源
  • 工控机本身没有内置定位能力

RTK GPS 设置

RTK 设置用于配置差分基站的 Survey-In 行为，或者直接使用已知基站坐标。

Survey-In

Survey-In 是 RTK 基站启动时确定基站位置的过程，通常需要同时满足：

  • 位置精度达到设定阈值
  • 观测时长达到最小时长

常见设置包括：

  • 测量精度阈值
  • 最短观测时间

使用指定基站位置

如果已经知道基站准确位置，也可以直接填写固定基站参数，例如：

  • 纬度
  • 经度
  • WGS84 高度
  • 基站位置精度

说明：

  • 一次完成 Survey-In 后，通常可以把结果保存下来，后续直接复用，减少启动等待时间。

ADS-B 相关设置

通用设置中通常也可配置 ADS-B 服务器连接，用于在地图上显示附近合作目标。

常见配置项包括：

  • 启动时自动连接
  • 服务器地址
  • 服务器端口

系统通常可以从远程或本地的 SBS 格式 ADS-B 服务中读取数据，并在地图上显示其他航空器目标。

离线地图

离线地图功能用于缓存地图瓦片，便于在无网络环境下继续使用地图。

使用方式

  1. 创建新的离线地图集。
  2. 为地图集命名。
  3. 选择需要缓存的区域。
  4. 选择最小和最大缩放级别。
  5. 下载对应瓦片。

说明

  • 可以创建多个离线地图集，对应不同区域
  • 缩放级别越高，占用空间通常越大
  • 适合野外部署、弱网作业和演示环境

MAVLink 设置

MAVLink 设置页用于配置地面站在 MAVLink 网络中的行为，以及查看链路状态。

地面站参数

常见可配置项包括：

  • 地面站的 MAVLink System ID
  • 是否发送 Heartbeat
  • 是否只接收相同协议版本的机器人
  • 是否启用 MAVLink 转发

其中：

  • System ID 默认为 255
  • 一般不建议关闭 Heartbeat
  • 如果网络中存在多个地面站或其他 MAVLink 应用，可能需要调整 System ID

链路状态

MAVLink 设置页通常还会显示链路质量信息，例如丢包率。

说明：

  • 丢包率过高会影响参数同步
  • 任务上传和下载也可能因此失败

MAVLink 2 日志流

在 PX4 场景中，系统通常还支持 MAVLink 2 实时日志流及日志自动上传能力。

常见能力包括：

  • 手动启动和停止日志流
  • 自动采集日志
  • 上传日志到 Flight Review
  • 设置上传描述、邮箱、公开性和附加说明

说明：

  • 该功能通常要求高带宽稳定链路
  • 一般不适用于低带宽遥测电台

控制台日志

控制台日志页面用于帮助定位 HGroundControl 应用本身的问题，是排查连接、参数、任务同步和固件升级问题的重要入口。

常见用途

常见日志分类通常包括：

  • 连接问题
  • 串口检测问题
  • 固件升级问题
  • 参数加载问题
  • 参数缓存问题
  • 任务上传下载问题
  • 遥控器校准问题

使用方式

用户通常可以在控制台页面中选择打开或关闭指定日志类别，以便只观察与当前问题相关的输出。

命令行日志

如果应用本身发生崩溃，图形界面中的控制台可能无法保留完整信息，此时可通过命令行参数方式启动并记录日志。

该方式更适合：

  • 启动即崩溃问题
  • 图形界面未完全加载的问题
  • 需要收集早期启动日志的问题

虚拟摇杆

虚拟摇杆允许用户通过屏幕上的双摇杆控件直接控制机器人，主要用于触屏设备或无物理遥控器场景。

特点

  • 控制信息通过 MAVLink 发送
  • 响应性通常不如实体遥控器
  • 更适合轻量测试、演示或备选控制方式

启用方式

一般可在：

  1. 打开应用设置。
  2. 进入通用设置。
  3. 勾选虚拟摇杆选项。

启用后，任务执行界面中会显示对应的屏幕摇杆控件。

使用建议

在 HGroundControl 中使用应用设置界面时，建议：

  • 优先先设置单位、地图源和默认保存路径
  • 野外作业前提前下载离线地图并验证范围
  • 对日志分析需求较强的场景，同时启用 .tlog 和 CSV 记录
  • 在多地面站或复杂网络环境中检查 MAVLink System ID 是否冲突
  • 如遇异常问题，优先使用控制台日志收集信息

以下内容参考 HGroundControl Stable V5.0 的 Analyze View 相关页面整理，可作为 HGroundControl 当前阶段“分析工具界面”的说明基础。

功能概述

分析工具界面用于对日志、图像和 MAVLink 数据进行辅助分析，是开发调试、复盘和问题定位的重要入口。

该界面通常提供以下工具：

  • 日志下载
  • 图像地理标记
  • MAVLink 控制台
  • MAVLink Inspector

入口位置

分析工具界面通常可通过应用主菜单中的工具选择器进入。进入后，用户可以通过左侧栏切换不同分析工具。

日志下载

日志下载工具用于从已连接机器人中列出、下载或清除日志文件。

常见操作包括：

  • 刷新日志列表
  • 下载选中日志
  • 擦除全部日志

该工具适合以下场景：

  • 任务结束后提取飞控日志
  • 复盘异常事件
  • 为开发人员提供原始日志材料

图像地理标记

图像地理标记工具用于根据飞行日志为测绘任务照片添加地理位置信息。

适用范围

  • 该能力通常只支持 PX4 日志
  • ArduPilot 一般不支持该流程

基本流程

  1. 选择飞行日志文件。
  2. 选择原始图像目录。
  3. 按需选择输出目录。
  4. 点击开始标记。

处理完成后，系统会生成带有地理信息的照片，便于后续测绘、建模或归档。

MAVLink 控制台

MAVLink 控制台用于连接到 PX4 的系统控制台，并直接发送命令。

适用范围

  • 仅适用于 PX4 硬件设备
  • PX4 SITL 和 ArduPilot 一般不支持

典型用途

  • 查询系统状态
  • 执行底层命令
  • 调试驱动和模块
  • 远程排查飞行中或飞行后的问题

使用方式

连接机器人后，用户可在输入框中输入命令并执行。控制台通常只在收到命令响应时显示输出。

说明：

  • 输入 ? 通常可查看可用命令列表
  • 该功能更适合开发者和高级调试人员

MAVLink Inspector

MAVLink Inspector 用于实时查看和绘制地面站接收到的 MAVLink 消息，是通信分析和协议调试的重要工具。

适用范围

  • 主要面向飞控开发者、机器人集成者和高级调试人员
  • 通常仅支持桌面版

核心能力

系统通常可以显示：

  • 当前接收到的所有消息类型
  • 消息来源组件 ID
  • 消息更新频率
  • 单个字段当前值
  • 字段实时曲线

基本使用方式

  1. 打开分析工具界面。
  2. 进入 MAVLink Inspector。
  3. 选择某个消息查看其字段。
  4. 勾选需要绘制的字段。
  5. 在图表中观察实时变化。

图表能力

图表通常支持：

  • 同时显示多个字段
  • 同时显示来自不同消息的字段
  • 使用两张图表分别展示不同数据组

这对于以下分析非常有帮助：

  • 姿态与控制量变化趋势
  • 传感器数值抖动
  • 状态机切换时序
  • 通信消息发送频率

使用建议

在 HGroundControl 中使用分析工具界面时，建议：

  • 每次重要任务后及时下载并归档日志
  • 对测绘任务保留原始图像和对应飞行日志，便于后续地理标记
  • 仅让熟悉底层系统的人员使用 MAVLink 控制台
  • 使用 MAVLink Inspector 时优先聚焦少量关键消息，避免图表过载

HGroundControl汉化工作

以下内容用于说明 HGroundControl 当前和后续需要推进的汉化工作方向。整...

以下内容用于说明 HGroundControl 当前和后续需要推进的汉化工作方向。整体汉化工作主要分为两个部分：一是 HGC 操作界面的汉化，二是 HGC 参数系统的汉化。

工作目标

HGroundControl 的汉化不仅是将英文界面文字翻译为中文，更重要的是降低一线操作人员、调试人员和维护人员的使用门槛。通过系统化汉化，可实现以下目标：

  • 让用户更直观地理解各页面功能和操作入口
  • 降低培训成本和误操作风险
  • 提高参数配置、调试与排障效率
  • 提升 HGC 在行业项目、本地化交付和现场部署中的可用性

第一部分：操作界面汉化

操作界面汉化主要面向 HGroundControl 软件本体的可视化界面，覆盖用户在日常使用过程中直接看到的文本内容，例如：

  • 顶部菜单与工具栏
  • 弹窗、按钮和提示语
  • 设置页面与功能分组名称
  • 状态指示器、告警信息和任务操作项
  • 日志、引导语和帮助性说明文本

汉化范围

界面汉化通常需要覆盖 HGC 的主要功能界面，包括但不限于：

  • 应用设置界面
  • 参数调试界面
  • 任务规划界面
  • 任务执行界面
  • 分析工具界面

对于这些界面中的常用文本，汉化工作应尽量做到：

  • 翻译统一
  • 术语一致
  • 符合机器人地面站使用习惯
  • 尽量避免生硬直译

汉化原则

为保证界面可用性，操作界面汉化建议遵循以下原则：

  • 优先保证用户能快速理解功能含义
  • 专业术语尽量采用行业内常见中文表达
  • 对高风险操作使用更明确的中文提示
  • 同一术语在不同页面保持一致
  • 在中文过长可能影响布局时，兼顾可读性与界面显示效果

例如：

  • Fly View 可翻译为“任务执行界面”
  • Plan View 可翻译为“任务规划界面”
  • Settings View 可翻译为“应用设置界面”
  • Takeoff 可翻译为“起飞”
  • Return to Launch 可翻译为“返航”

预期效果

完成操作界面汉化后，用户在使用 HGC 时应能够：

  • 直接以中文理解各功能入口
  • 更快完成设备连接、任务规划和参数调试
  • 在出现异常、告警和确认操作时及时理解系统提示
  • 在培训和项目交付时减少对英文界面的依赖

第二部分：参数系统汉化

参数系统汉化是 HGroundControl 汉化工作的重点之一。该部分不仅涉及参数名称的展示，还涉及参数说明、用途、单位、范围和风险提示的中文化表达。

其核心目标是：在 HGC 读取机器人固件并同步参数后，能够将对应固件参数的说明信息以中文形式展示给用户，帮助用户正确理解参数含义。

能力说明

当 HGC 成功连接机器人并读取当前固件参数后，系统通常会加载参数元数据。参数系统汉化的目标是在这一过程中，为用户提供以下中文能力：

  • 参数名称对应的中文解释
  • 参数功能说明的中文展示
  • 参数取值范围和默认值的辅助说明
  • 参数修改风险与重启要求说明
  • 按参数分类或模块提供更清晰的中文检索体验

这意味着用户在参数页面中查看某个参数时，不仅能看到参数本身，还能看到更易理解的中文说明文本，而不必完全依赖英文文档或外部资料。

应用场景

参数系统汉化特别适用于以下场景：

  • 现场调试人员需要快速理解某个参数用途
  • 项目实施人员需要根据客户需求修改参数
  • 售后维护人员需要排查参数配置问题
  • 培训场景下需要向非英文背景用户解释固件参数

关键实现方向

参数系统汉化建议重点围绕以下方向推进：

  • 建立参数名、参数说明与中文释义之间的映射关系
  • 根据不同固件类型加载对应的参数说明数据
  • 在读取参数后自动匹配并显示中文说明
  • 对高风险参数增加更明确的中文警示
  • 支持后续持续补充和更新参数汉化词库

对于 PX4、ArduPilot 及其他接入固件，参数体系并不完全相同，因此参数汉化能力通常需要按固件类型分别维护。

读取固件后的汉化流程

参数系统汉化在实际使用中的典型流程可理解为：

  1. HGC 连接机器人并识别当前固件类型。
  2. 系统从机器人读取参数列表与参数元数据。
  3. 根据固件类型加载对应的参数汉化说明资源。
  4. 将参数名称、参数描述和相关提示映射为中文文本。
  5. 在参数页面中向用户显示中文说明内容。

如果某些参数暂时没有对应的中文释义，也建议保留原始参数名，并逐步补全其中文说明。

预期价值

完成参数系统汉化后，可显著提升以下能力：

  • 提高参数理解效率
  • 降低高级参数误改风险
  • 减少查阅外部英文文档的频率
  • 提升调参与问题定位效率
  • 增强 HGC 面向中文用户群体的产品完整性

工作建议

为了更稳妥地推进 HGroundControl 汉化工作，建议采用“界面汉化优先、参数汉化持续完善”的方式分阶段实施：

  1. 先完成主流程界面和高频功能入口的中文化。
  2. 再逐步补齐提示语、弹窗和错误信息。
  3. 随后针对 PX4、ArduPilot 等固件建立参数中文说明库。
  4. 在实际项目使用过程中持续修正术语和补充缺失项。

总结

HGroundControl 的汉化工作不仅包括表层界面文本翻译，还应覆盖参数解释层面的深度本地化。其中：

  • 操作界面汉化解决“看得懂、会操作”的问题
  • 参数系统汉化解决“读得懂参数、敢于调参数”的问题

这两部分结合后，才能真正形成适合中文用户使用的 HGC 本地化能力体系。
