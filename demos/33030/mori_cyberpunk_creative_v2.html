01 / CREATIVE POSITION项目当前定位

从“提案文档”升级为“可落地的游戏主视觉方案”：把技术硬约束变成世界观的一部分，让工程可信度也变成玩家感知。

世界不是背景，而是一台会审计的天道机器

玩家不是传统修仙主角，而是被末日倒计时唤醒的救世者核心。每一世宿主只是临时载体，真正成长的是跨轮回保存的命火、记忆、因果与权限。

设计基调：暗色城市废土 + 霓虹灵能阵列 + 操作系统 HUD。所有按钮、卡片、弹窗都像“天道终端”发出的可验证指令，而不是普通网页组件。
✦ 开局方式

不再堆开局选项，首页直接进入轮回殿；玩家只投入六维命盘与轮回点数，宿主由天道生成。

✦ 交互方式

人物、物品、装备、功法都以卡片/姓名入口进入弹窗；普通交互走本地 Action OS，自由行动交给天道裁定。

✦ 状态方式

叙事文本不直接改库，所有结果必须通过工具、补丁、事务、审计日志落入 SQLite。

✦ 战斗方向

左右头像自动回合制：HP、灵能、装备技能、默认出招策略、技能消耗与普通攻击组成轻量战斗层。

把项目的核心可玩循环压缩成玩家一眼能懂的七步；每一步都能对应后端服务与前端组件。

06 / ART DIRECTION美术与组件规范

为后续按钮、头像、卡框、状态图标、战斗 UI 与主界面统一风格，避免素材各做各的。

深空黑#030510
灵能青#5DE9FF
霓虹紫粉#FF4ED8
命火金#FFD58A
按钮

大按钮采用三态素材或 CSS 发光边框：idle 低亮、hover 青色脉冲、pressed 命火金压下，适合“再入轮回 / 轮回星图 / 离开游戏 / 设置”。

卡片

人物、物品、装备、功法统一使用玻璃拟态黑底、青色内发光、左上角系统标签、右下角风险/稀有度标记。

头像

1:1 半身胸像，脸部清晰，背景简洁，霓虹 HUD 不遮挡面部；我方偏青金，敌方偏紫红，Boss 使用破碎机械甲片。

战斗 UI

左右阵营头像 + 中央 VS 灵能阵列；HP、灵能、护盾三条分层显示；装备技能在头像下方显示冷却与消耗。
