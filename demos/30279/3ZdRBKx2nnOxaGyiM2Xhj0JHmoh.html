右键菜单创意

Windows 右键菜单增加「创建双向快捷方式」

在目标目录自动额外创建一个指向起始目录的快捷方式，实现双端可达

创意来源：forum.trae.cn/t/topic/22548

01痛点：原版只创建单向快捷方式

右键菜单固定入口：新建 → 弹出对话框 → 填入目标路径 → 完成创建

原版「快捷方式」

在 C:\工作 右键 → 新建 → 快捷方式 → 填入 D:\素材 → 完成。
只在起始目录创建了一个指向目标的快捷方式。

新版「创建双向快捷方式」

同样右键 → 新建 → 创建双向快捷方式 → 填入目标路径 → 完成。
在目标目录也自动创建一个指回起始目录的快捷方式。

02操作流程

操作：右键 → 新建 → 创建双向快捷方式
1
在起始目录的空白处右键 → 新建 → 创建双向快捷方式，弹出路径选择对话框
2
在对话框中填入目标目录路径（或点击「浏览」选择），确认快捷方式名称
3
系统同时做两件事：在起始目录创建 → 目标的快捷方式（原版逻辑），在目标目录额外创建 → 起始目录的快捷方式（新增逻辑）
起始目录 C:\工作
目标目录 D:\素材

实现路径：注册表 HKCR\Directory\Background\shell + PowerShell 脚本，一条菜单命令即可搞定

03适用场景

📁

素材整理

在「采集目录」和「成品目录」之间来回搬运素材，双向快捷方式省去反复导航。

💻

项目联调

前端代码在 C 盘、后端接口文档在 D 盘，双向快捷方式让两个核心目录互通有无。

📚

学习笔记

「课程资料」与「输出笔记」分离存放，双向快捷方式支持随时对照查阅。

📷

媒体处理

「原片 Raw」和「精修输出」工作流中，双端可达极大减少路径跳转成本。

04未来与 ContextMenuMgr 联动

⚙️

Context Menu Manager Plus

ContextMenuMgr 是一款 .NET 10 + WPF 构建的 Windows 右键菜单管理工具。 它不仅能管理传统菜单和 Win11 新菜单，还提供「先拦截、再审核」机制，防止第三方软件随意往右键菜单里塞东西。

未来「创建双向快捷方式」作为注册表级右键菜单项后，可以接入 ContextMenuMgr 的审核队列： 用户安装后，菜单项将自动出现在 ContextMenuMgr 的待审核页，用户可在其 UI 中可视化地启用 / 禁用该功能， 无需手动翻注册表。通过 ContextMenuMgr 的全局搜索、启用 / 禁用开关、独立删除与恢复能力， 让「双向快捷方式」的安装、管理和卸载像普通软件一样顺手。
