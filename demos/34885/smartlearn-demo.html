项目概述

SmartLearn 是一个基于 W3Schools 教程体系 的智能化编程学习平台，将 AI 问答、在线代码测试、代码优化分析、知识图谱可视化 四大核心能力融为一体，打造"学-练-问-测-优"闭环体验，让编程学习者告别工具分散、效率低下的困境。

四大核心功能

围绕编程学习的完整闭环，提供智能化、一体化的学习体验

AI 智能问答

集成大语言模型，具备上下文感知能力，能结合当前学习内容精准回答问题。支持 Gemini + DeepSeek 多模型切换，响应速度快、回答质量高。

Gemini API DeepSeek API

在线代码测试

内置 Monaco Editor 代码编辑器 + Judge0 CE 安全沙箱，支持 60+ 编程语言的在线编写、运行和测试，无需安装任何本地环境。

Monaco Editor Judge0 CE

代码优化分析

AI 驱动的代码审查引擎，从可读性、性能、安全性、最佳实践等多维度评估代码质量，给出具体优化建议和改进示例。

AI Code Review Multi-dimensional

知识点思维导图

基于 Markmap 的交互式知识图谱，将零散知识点可视化为结构化思维导图，帮助学习者建立系统化的知识框架。
