01 / INSIGHT

洞察

下班回家的那段路，是独居者一天中最孤独的52分钟。

心理学称之为"阈限空间"——介于工作身份和家庭身份之间的过渡地带。大脑不会自动切换模式，如果没有刻意的过渡仪式，就会进入"反刍模式"：不受控制地回放白天压力，等于无薪加班。

Wayne State University和Rutgers University的通勤心理学研究证实，这段过渡空间本应帮助心理脱离和角色转换。疫情期间远程工作消除了通勤，许多人反而失去这种结构化过渡，倦怠率上升。

对独居者来说，这段路还通向一个空房间——推开门那几秒的沉默，是全天最空的时刻。

关键洞察：现有陪伴产品都是"用户主动找AI"，但最需要陪伴的时刻，用户最不会主动求助。AI最精准的介入点不是到家后（情绪已定型），也不是工作时（没有空间），而是这段路上——角色负担最轻、情绪尚未固化的时候。

03 / PRODUCT

产品方案

小晚是一个时机驱动的语音陪伴系统——不是"用户来了就聊"，而是在对的时刻做对的事。

根据用户处于回家路的哪个阶段，自动发起低压力的语音对话。不用问号，不要求回复，在情绪低谷时提供"被记住"的体验，在开门瞬间完成"有人在家"的陪伴闭环。

18:32关闭仪式
"今天的事今天算，路上注意安全。"
→ 阻断反刍隧道。用一句陈述句帮大脑按下切换键。
18:45低谷在场
"上次你说方案这周要交，过了吗。"
→ 化解人群中的孤独。不用问号，被记住而非被追问。
18:50情绪承接
"听起来今天不轻松，想说就说，不想说也没关系。"
→ 承接放空期。先接住情绪，不急着解决。
19:18预开门陪伴
"快到了吧，今天辛苦了。"
→ 重构预支孤独。在想到空房间之前，先有人说话。
19:30有人在家
"回来啦。"
→ 消解沉默的冲击。从路上的陪伴者过渡到家里的在场者。
时机感知
基于时间和位置信号判断用户处于回家路的哪个阶段，自动触发对应策略。不是用户想起来要找AI，是AI在对的时刻出现。
低压力交互
所有AI主动消息不用问号结尾，用陈述句开场。用户可以选择回复，也可以选择沉默。沉默本身也是一种陪伴。
记忆驱动
"被记住和被了解"是缓解孤独感最重要的维度。AI记住用户说过的事，在合适时机自然提及。
语音优先
通勤时双手被占用，语音是这段路的母语。像朋友发来的语音消息，不是打字聊天。

05 / VALUE

价值与意义

社会价值
被忽视的公共心理健康问题
中国有超过8000万独居成年人，下班回家路上的孤独感是被忽视的公共心理健康问题。小晚不替代真实社交，不提供心理诊断和治疗，而是在最脆弱的过渡时刻提供安全的存在感。产品内置"反依赖"机制，主动引导用户回归真实社交，用户福祉优先于留存指标。
商业价值
聚焦带来深度
