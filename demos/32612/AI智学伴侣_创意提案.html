你: 老师，Pandas中loc和iloc有什么区别？什么时候用哪个？
AI助教:

好问题！loc和iloc是Pandas中两种常用的数据选择方法，区别如下:

  • loc: 基于标签索引，使用行/列的名称进行选择
    例: df.loc[0:5, ['姓名', '年龄']] —— 选择第0到5行，'姓名'和'年龄'列
  • iloc: 基于位置索引，使用整数位置进行选择
    例: df.iloc[0:5, 0:2] —— 选择前5行，前2列

使用建议: 当你知道具体的行列名称时用loc；当你知道位置编号时用iloc。推荐优先使用loc，因为代码可读性更好。

技术实现方案

前端技术栈

  • 框架: React 18 + TypeScript —— 提供类型安全和组件化开发
  • UI组件库: Ant Design —— 成熟的企业级UI组件，快速构建美观界面
  • 状态管理: Zustand —— 轻量级状态管理，简化数据流
  • 图表库: ECharts —— 丰富的数据可视化图表，展示学习数据

AI能力集成

  • 学习计划生成: 基于大语言模型分析用户目标和时间，生成个性化学习路径
  • 知识卡片提取: 使用NLP技术从学习内容中自动提取关键知识点
  • 智能问答: 集成RAG技术，基于知识库提供精准的学习辅导
  • 复习推荐: 基于遗忘曲线算法，智能计算最佳复习时间点

数据存储

  • 用户数据: 本地IndexedDB + 云端同步，保障数据安全和跨设备访问
  • 知识卡片: 结构化JSON存储，支持标签系统和全文检索
  • 学习记录: 时序数据存储，支持学习轨迹回溯和数据分析

创新亮点

1. AI驱动的个性化学习路径

不同于传统的固定课程表，AI智学伴侣能根据用户的知识基础、学习目标、时间安排和掌握进度，动态生成和调整学习计划，真正实现"千人千面"的个性化学习体验。

2. 知识卡片 + 遗忘曲线 = 长期记忆

将学习内容转化为结构化知识卡片，结合艾宾浩斯遗忘曲线算法，在最佳时间点提醒复习，将短期记忆转化为长期记忆，解决"学了就忘"的痛点。

3. 上下文感知的AI答疑

AI助教不仅拥有通用知识，更能理解用户的学习进度和已掌握的知识，提供针对性的解答和拓展，就像一位真正了解你的私人教师。

4. 游戏化学习体验

通过积分系统、成就徽章、学习 streak 等游戏化设计，增加学习的趣味性和成就感，帮助用户建立持续学习的习惯。
