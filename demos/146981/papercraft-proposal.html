科研写作的四大痛点

📚 文献读不完

一个研究方向动辄数百篇论文，人工筛选、阅读、做笔记耗时巨大，容易遗漏关键工作。

🤔 选题启动难

面对模糊的研究方向，不知道如何聚焦问题、找到创新点，导致开题反复拖延。

🔬 实验设计没思路

论文写到验证环节卡壳，不清楚该用哪些数据集、指标和 baseline，实验方案难以落地。

✏️ 修改轮次多

成稿后逻辑漏洞、表达不清、格式问题层出不穷，导师和审稿意见往往需要多轮返工。

创意介绍

PaperCraft 是一款面向科研人员的「多智能体论文工坊」。它不再是一个简单的对话式写作工具，而是让四个具备不同专长的 AI 智能体像一个小型研究团队一样协作：有人负责选题与文献、有人设计实验、有人执笔写作、还有人模拟审稿。用户只需输入研究方向和初步想法，PaperCraft 就能自动生成选题报告、文献综述骨架、实验方案、论文初稿和审稿反馈，帮助研究者快速完成从 0 到 1 的突破。

四个 Agent 共享同一个「论文画布」，用户可以像审阅协作文档一样查看、修改、批准每一份中间产物，实现人机共创的科研写作新体验。

核心架构：四智能体协作

> Demo 示例：研究方向「大模型驱动下的网络安全智能体」
[选题文献 Agent] → 识别 5 个候选创新点，推荐「多智能体协同的 SOC 自动化运营框架」 [实验设计 Agent] → 建议采用真实企业告警数据集，对比传统 SOAR 与 Agent 方案的 MTTR [写作润色 Agent] → 生成摘要、引言、方法、实验与结论共 6 章初稿 [审稿反馈 Agent] → 指出实验缺少消融研究，建议补充不同 Agent 数量的性能对比
