01 / 问题洞察

屏幕，正在成为隐私泄露的高频入口

在远程协作、AI 自动化、内容创作日益普及的今天，屏幕上的敏感信息正面临前所未有的暴露风险。

💻

远程会议误共享

共享屏幕时突然弹出私人消息、邮件通知，或不小心切换到含有客户资料的页面。

📺

直播录屏泄露密钥

程序员直播写代码时，不小心展示了 .env 文件、Token 或 API Key，被观众截屏记录。

🎓

教学录课暴露隐私

老师录课时误展示学生名单、聊天窗口或个人文件夹，造成学生信息泄露。

💲

后台演示泄露数据

销售或运营演示后台系统时，屏幕上出现客户手机号、订单信息和财务数据。

🤖

AI Agent 越权访问

授权 AI Agent 操作电脑时，Agent 打开了邮件、聊天、密钥文件或支付页面。

⏰

事后发现为时已晚

很多泄露都是不可逆的——会议已结束、直播已播出、录屏已保存，后悔莫及。

02 / 解决方案

ScreenShield Local 的四大核心能力

运行在 Mac 本地的屏幕隐私与内容安全助手，通过本地捕获、智能识别和实时保护，守护你的屏幕安全。

👁

本地屏幕捕获

完全在本地进行屏幕捕获，无需上传任何画面到云端，从源头确保数据不离开你的设备。

🔍

OCR 智能识别

通过本地 OCR 引擎实时识别屏幕中的文字内容，快速定位潜在的敏感信息区域。

🔒

敏感规则检测

内置 API Key、手机号、银行卡、身份证号等多种敏感信息规则，支持自定义检测规则。

🤖

AI 风险判断

结合本地 AI 模型对屏幕内容进行风险评分，智能判断哪些内容需要遮挡或提醒。

实时保护机制

📣

即时提醒

检测到敏感信息时，第一时间弹出提醒通知，让用户意识到风险。

👁‍🗨

自动模糊

对识别出的敏感区域进行实时模糊处理，观众只能看到被保护的画面。

🛑

智能遮挡

用安全遮罩覆盖高风险内容，可配置白名单和黑名单策略。

⏸

暂停确认

遇到极高风险内容时，自动暂停共享并请求用户确认是否继续。

05 / 价值与意义

三重价值，全面守护

ScreenShield Local 不仅是一款工具，更是一种全新的屏幕安全理念。

01

效率价值

减少会议、录屏和直播前反复检查屏幕的时间，让用户更放心地进行远程协作、演示和内容创作。在高风险信息出现时及时提醒或自动遮挡，降低因误共享造成的返工、事故和沟通成本。

02

商业价值

面向个人创作者、远程办公用户和企业团队，发展为本地化的屏幕数据防泄漏工具。对企业而言，它是轻量级本地 DLP 安全助手；对个人而言，它是会议、录屏、直播和 AI Agent 使用时的安全保护层。

03

社会价值

帮助普通用户降低数字生活中的隐私泄露风险。随着 AI Agent 越来越多地进入电脑桌面操作场景，用户不仅需要更强的自动化能力，也需要更可信、更可控的本地安全机制。

06 / 产品愿景

ScreenShield Local 的目标是让用户在使用 AI 工具和远程协作时更加安心。
