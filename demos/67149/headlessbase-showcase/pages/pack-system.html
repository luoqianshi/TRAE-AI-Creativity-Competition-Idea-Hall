Game Pack — 每款游戏即一个 YAML 文件

新增游戏 = 编写一个 YAML 模板文件，定义启动参数、配置表单、命令映射、版本源，以及社区自治钩子（自动欢迎、新手礼包、投票踢人、实时公告），无需改动任何核心代码。

YAML Pack 文件 定义协议、命令、版本
平台加载解析 zod 校验 + 协议适配
游戏服务器运行 统一命令、自动管理

Minecraft Vanilla Pack 示例 

# packs/minecraft-vanilla.yaml — 社区自治开箱即用

pack:
  id: minecraft-vanilla
  game: minecraft
  display_name: Minecraft Java (Vanilla)

startup:
  binary: java
  args: ["-Xmx{{jvm_xmx}}", "-jar", "server.jar", "nogui"]
  ready_pattern: 'Done \([\d.]+s\)! For help'

protocol:
  type: rcon
  default_port: 25575
  auth: password

commands:
  list_players: 'list'
  broadcast: 'say {{message}}'
  give_item: 'give {{player}} {{item}} {{count}}'
  kick: 'kick {{player}} {{reason}}'

autonomy:
  welcome_message: 'say 欢迎 {{player}} 来到服务器！输入 /kit starter 领取新手礼包'
  starter_kit:
    - 'give {{player}} diamond_pickaxe 1'
    - 'give {{player}} bread 16'
  vote_kick:
    threshold: 0.6
    duration: 300
  announce_events: true

versions:
  source: mojang
  type: server-jar
  eula_required: true

三种协议，统一抽象

RCON

Minecraft, ARK, CS2 — Source RCON 协议，双向通信，有响应。

stdin

Factorio — 写入进程标准输入，单向通信，无响应。

WebRCON

Rust — WebSocket 封装的 RCON，适合 Web 场景。

Pack schema 用 zod discriminatedUnion 区分协议类型，同一套校验逻辑兼容所有协议。
