01 工程师的加班夜 / THE PROBLEM

企业系统的"打印"诉求,
本不该这么痛。

每个团队都在重复造"打印模板引擎"这个轮子 —— 每年因此消耗 30%+ 的迭代工时,却没有任何一个"标准答案"。

01

模板硬编码在代码里

调整一个字段位置要改 3 个文件 + 测试 + 上线发版。业务说"加一列规格"变成跨部门协作的噩梦。

PAIN · 发版成本
02

弹窗打印无法接受

浏览器 window.print() 总是要用户点"确定"。收银、分拣、批量打单场景,用户压根没机会点确认。

PAIN · 用户体验
03

三种结果对不上

设计期看着对、浏览器出纸错、客户端出纸又错。每个端都自造一套渲染逻辑,bug 永远修不完。

PAIN · 一致性
02 四大支柱 / THE SOLUTION

nf-print 的核心设计:
解耦 · 静默 · 沙箱 · 跨端。

不是又一个"打印插件",而是一整套打印系统的基础设施。我们把"设计期"和"运行期"彻底分开,把"静默打印"做成产品。

PILLAR 01

设计 / 预览解耦

设计端与运行期是两个独立组件,共享同一份 PrintTemplate JSON。

  • 设计端带完整 IDE 体验
  • 运行期仅渲染模板,无需设计器代码
  • 模板跨端一致,JSON 即可传输
PILLAR 02

静默打印

silentPrint(template, data, options) —— 一行代码,三种模式。

  • browser: iframe + afterprint
  • local: WebSocket → PrintDot
  • remote: REST → print-gateway
PILLAR 03

沙箱 + 双数据源

customScript 在隔离环境执行,禁止 window/document/eval。

  • 方案 A: 内置测试数据
  • 方案 B: 脚本动态生成表头/表体/表尾
  • 支持列合并、表头嵌套、自动分页
PILLAR 04

Web Components 化

Vue / React / 原生 HTML 都能用,零学习成本。

  • <print-designer> / <print-preview>
  • 支持属性 / 事件完整传递
  • TypeScript 100% 类型覆盖

04 核心能力 / CAPABILITIES

覆盖企业打印的每一个细节。

从元素设计、变量绑定,到多端输出、测试覆盖 —— 一应俱全。

01

9 种内置元素

文本/图片/表格/页码/条码/二维码/直线/矩形/圆形 —— 加上 SVG 复合和自定义元素扩展,几乎覆盖所有企业打印场景。

02

通用空白表格

<BlankTable /> 独立于打印模板,可用于表单设计、字段映射、动态编辑。行/列增删、双向绑定、动画、响应式。

03

多格式导出

PDF / PNG / JPEG / WebP,支持 ZIP 打包。DPI 可调、中文支持好。jsPDF + html-to-image 成熟方案。

04

主题与品牌

setTheme('light' / 'dark' / 'system') + setBranding + setDesignerFont。CSP 友好、CSS Variables 一致。

05

变量绑定

{#orderNo} 与 {#user.name} 嵌套路径。x1000 替换 < 1ms。安全校验防止注入。

06

模板迁移

templateMigration.ts 校验版本号,旧模板无法渲染新代码时自动告警。模板导入导出是纯 JSON。

07

TypeScript 完备

100% 类型覆盖,IDE 智能提示完备。peerDependencies 仅 svelte ^4.0.0,接入零摩擦。

08

安全沙箱

customScript 在 new Function 隔离环境执行,关键字黑名单禁止 window / document / eval / fetch。

09

70+ 单元测试

utils / stores / 组件 / 性能基准 / E2E 完整覆盖。每次 PR 跑 5 维 CI,防止性能回退。

05 开发者体验 / CODE FIRST

5 行代码,
完成一次完整的打印调用。

设计端用 Svelte 组件开发,运行期用一行函数调用。模板就是 JSON,数据就是对象。

// 1. 定义模板SVELTE
<!-- App.svelte -->
<script>
  import {
    PrintPreview,
    silentPrint
  } from '@nf-print/print-designer'

  const template = {
    paperSize: { w: 210, h: 297 },
    pages: [{ elements: [...] }]
  }
</script>

<PrintPreview {template} {data} />
// 2. 静默打印TYPESCRIPT
// 浏览器静默模式
await silentPrint(template, data, {
  mode: 'browser'
});

// 推送本地客户端
await silentPrint(template, data, {
  mode: 'local',
  wsUrl: 'ws://localhost:1122/ws'
});

// 推到云端网关
await silentPrint(template, data, {
  mode: 'remote'
});
// 3. 变量与数据源TYPESCRIPT
// 模板里这样写
{#orderNo} <- "X202606160001"
{#user.name} <- "张三"
{#items[0].price} <- "100"

// 表格双数据源
{
  type: 'table',
  dataMode: 'script',
  customScript: `return data.map(r
    => '<tr><td>'
    + r.label + '</td></tr>'`
}
// 4. Web ComponentsHTML
<!-- 任何框架都能用 -->
<script type="module"
  src="@nf-print/print-designer/wc">
</script>

<print-preview
  auto-print
  print-mode="local"
  ws-url="ws://localhost:1122/ws">
</print-preview>
