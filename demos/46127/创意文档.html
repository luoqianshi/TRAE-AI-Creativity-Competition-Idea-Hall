MoodMove

用 AI 读懂你的心情，推荐恰到好处的运动

赛道：社区公益 — 青少年身心健康

1. 创意名称 + 创意介绍

创意名称

MoodMove（情绪运动助手）

用 AI 读懂你的心情，推荐恰到好处的运动。

想解决什么问题

13-18 岁的青少年在情绪低落时（考试压力、人际矛盾、被家长批评等），最常做的事是躺着刷手机或打游戏，而不是运动。科学研究表明，适度运动能有效改善情绪——问题在于，大多数青少年不知道什么心情该做什么运动，也缺少一个能理解自己、主动引导自己的工具。

为什么会想到做这个

我自己在压力大的时候去跑步，发现跑完确实神清气爽。但情绪不好时"知道该运动"和"真的去运动"之间隔着一堵墙。如果有一个 AI 能"读懂"我的心情，用朋友的口吻推荐合适的运动，迈出第一步会容易很多。

产品形态

一个在 TRAE 平台上构建的 Web 应用，用户用自然语言描述当前心情，AI 完成情绪识别、运动匹配、陪伴鼓励的闭环。

典型使用场景

用户："刚和好朋友吵架了，好烦。"
MoodMove："听起来你现在心里堵堵的。这种时候，试试戴上耳机出门快走 15 分钟？不用跑、不用想，就边走边听喜欢的歌。走到微微出汗就回来，然后告诉我感觉怎么样？"
（15 分钟后）
用户："好像没那么气了。"
MoodMove："看吧，愤怒被你的脚步消化掉了！要不要把今天的情绪转变记录下来？"

2. 目标用户及痛点

面向用户

13-18 岁的初高中学生，尤其是学习压力大、情绪易波动、想运动但缺乏行动力的青少年群体。

使用场景

  • 考试前焦虑失眠，需要释放压力
  • 被批评或遭遇挫折后情绪低落
  • 感到无聊，想找事做但不想刷手机
  • 有运动意愿但不知道做什么、需要有人推一把

核心痛点

痛点说明
情绪与行动脱节心情不好时只想瘫着，没人引导去运动
缺乏匹配知识不知道什么运动适合自己当前的情绪
看不到正反馈运动后没有情绪改善的直观记录，难以坚持
现有工具太冷健身 App 关注数据和目标，缺乏情感温度

3. 价值与意义

对用户的直接帮助

  • 零门槛启动：不需要选课程、定目标，说出心情即可获得建议
  • 情绪正反馈闭环：运动前记录心情，运动后再记录，看到情绪改善曲线，形成"运动真的有用"的认知
  • 学会情绪管理：帮助青少年建立"运动等于调节情绪"的健康应对方式，替代逃避和沉迷手机

社会意义

青少年心理亚健康问题日益突出。《2024 中国青少年心理健康报告》显示，约 24.6% 的青少年存在不同程度的情绪困扰，而运动是成本最低、门槛最低的干预手段之一。MoodMove 免费、易用、有温度，让每个青少年都能获得一个 24 小时在线的 AI 运动伙伴。

与 TRAE 平台的契合

  • 自然语言理解：识别用户情绪表达的细微差别（烦、难过、无聊等不同情绪维度）
  • 个性化对话生成：运动推荐不是冷冰冰的列表，而是带有人情味的鼓励对话
  • 代码生成与部署：利用 TRAE 快速构建从原型到可用的 Web 应用

4. 差异化亮点

对比维度 Keep / 小米运动 潮汐 / 冥想 App MoodMove
核心目标 记录运动数据 放松减压 调节情绪，驱动运动
推荐逻辑 运动目标/身体指标 固定场景分类 AI 实时分析情绪语义
交互方式 数据面板 语音引导 自然对话，像朋友聊天
情感温度 专业、严肃 宁静、独处 温暖、陪伴、鼓励
用户粘性 靠数据/排名 靠内容库 靠情绪改善可见的正反馈
技术路线 传感器 + 数据库 预设内容 TRAE AI 情绪-运动智能匹配

一句话差异化

从"你该运动了"变成"我懂你为什么不想动，试试这个？"

5. MVP 功能规划

功能模块 具体描述 优先级
心情输入 用户用自然语言自由描述当前心情（支持文字与情绪关键词） P0
情绪识别 AI 分析语义，识别情绪类型（焦虑/愤怒/低落/无聊/兴奋等）及强度 P0
运动推荐 根据情绪匹配 2-3 个运动方案（类型、时长、强度、推荐理由） P0
AI 陪伴对话 运动前鼓励与运动后倾听反馈，语气温暖如朋友，非说教式 P0
心情轨迹 记录每次运动前后的心情变化对，自动生成改善记录 P1
情绪趋势 可视化展示 7/14/30 天的情绪改善趋势图 P1
运动收藏 用户可以收藏喜欢的运动方案，下次快速使用 P2

MVP 开发计划（利用 TRAE）

  1. 对话界面：TRAE 生成前端聊天 UI 与对话逻辑
  2. 情绪-运动匹配引擎：TRAE 辅助编写 Prompt 工程与推荐规则
  3. 心情记录与可视化：本地存储与简易图表
  4. 一键部署：通过 TRAE 部署为可公开访问的 Web 应用
