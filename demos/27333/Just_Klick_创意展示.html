4 技术实现亮点

Python 技术栈 · 多线程架构 · 精准回放

⚙️

核心依赖

pyautogui — 模拟鼠标点击和键盘操作
pynput — 全局监听键盘和鼠标事件
tkinter — 构建现代 GUI 界面
threading — 多线程异步执行

🎯

录制回放精度

使用 相对时间戳 记录每个事件的时间偏移量，回放时按时间轴精确还原操作序列。区分字符键与特殊键，使用 typewrite 优化文本输入。

⚡

快速回放机制

勾选「快速回放」后，跳过所有事件间隔延时，并将 pyautogui 内置 PAUSE 降至用户自定义值（默认 0.01s），实现每秒约 100 次操作的高速回放。

🎨

自定义 UI 组件

GlassButton — 玻璃质感悬停变色按钮
ClockWidget — 实时模拟时钟（指针角度算法）
RecordingToast — 脉冲动画录制状态指示

核心代码架构

class AutoClickerApp:
    def __init__(self):
        self.create_ui()      # 构建 tkinter 界面
        self.start_listeners()  # 启动 pynput 监听

    def click_loop(self):      # ⚡ 鼠标连点线程
        while self.clicking:
            pyautogui.click()
            time.sleep(interval)

    def timer_countdown(self):  # ⏰ 定时倒计时线程
        target_dt = datetime.now() + timedelta(seconds=total)
        while now < target_dt and not self.timer_cancelled:
            time.sleep(0.1)       # 支持中途取消

    def play_events(self):      # 🎬 回放线程
        events = sorted(events, key=lambda e: e['time'])
        for event in events:
            pyautogui.click(x=event['x'], y=event['y'])
5 使用场景示例

只需 3 步，搞定自动化

📝 场景一：批量审批表单

设置：定时点击模式 → 间隔 1秒 → 点击 50次
操作：将鼠标移动到审批按钮位置，点击「开始定时」
结果：自动完成 50 个表单审批，节省约 20 分钟

🎮 场景二：游戏日常任务

操作：按 F8 录制 → 执行游戏日常任务操作 → 按 Esc 停止
回放：选择「循环回放」→ 次数设为 0（无限循环）
结果：游戏挂机自动完成任务，解放双手

🧪 场景三：UI 自动化测试

操作：手动执行一次测试流程（录制）→ 停止录制
回放：选择「快速回放 + 0.1秒间隔」→「循环回放」
结果：自动执行回归测试，快速发现 UI 异常
