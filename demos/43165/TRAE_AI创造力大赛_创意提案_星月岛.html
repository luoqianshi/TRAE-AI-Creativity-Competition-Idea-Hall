01
CH. 01 · CREATIVE INTRODUCTION

创意介绍：
让角色自己把故事活出来

痛 点

当前 AI 叙事的「失忆症」

现有的 AI 角色扮演产品大多停留在「一问一答」的脚本体验：角色缺乏持续记忆、目标会在对话间遗忘、性格会随上下文漂移。世界不是被「活着」的角色推动的，而是被用户的每一次输入强行续命的。

动 机

我们想做一个"自发世界"

我们好奇的是：当多个 LLM 驱动的 Agent 被放进同一个世界，给他们真实的记忆、承诺、目标与互相依赖的关系时，他们会自己讲出怎样的故事？

产品形态

StartMoonIsland · 星月岛

一个多智能体 AI 自主叙事世界。在一个名为「星月岛」的奇幻岛屿上，4 位常驻 AI 角色（星月神殿大祭司、护卫队长、占星师、游商领袖）在共享世界时钟的驱动下，自主思考、自主决策、自主对话——你可以旁观、可以介入、可以影响，但永远不会"代写"他们的命运。

"我们不写剧情，我们写角色。然后让世界自己讲故事。"

CH. 02 · TARGET USERS & PAIN POINTS

目标用户 & 未被满足的需求

I
AUDIENCE · 观赏者

互动叙事爱好者

喜欢养成、模拟经营、文字冒险、剧本杀的玩家，希望体验"角色真正活了"的沉浸式世界。

II
CREATOR · 共创者

作家 / 编剧 / 剧情设计

需要持续灵感碰撞的创作者，把世界当作 24 小时不停工的灵感引擎。

III
RESEARCHER · 研究者

AI Agent 研究人员

关注多智能体长程一致性、记忆衰减、目标涌现、社会动力学的学术与工业研究者。

IV
PRODUCER · 二创者

内容生产者

视频、播客、漫画、Vlog 创作者，需要源源不断的真实素材与人物对白。

他们的共同痛点

  • 现有 AI 角色"聊三句就忘了你是谁"，无法形成长程关系
  • 世界是被脚本驱动的，不是被角色驱动的，"玩"起来很被动
  • 多角色互动时上下级、亲属、情感张力混乱，对白漂浮
  • 承诺与目标无法真正落地，"明天做什么"永远只是台词
  • 创作者需要持续输入 prompt 才能维持剧情，缺乏"灵感自动机"
  • 研究者缺乏可观察、可干预、可复现的多智能体长程沙盘

满足"观察一个活的虚拟社会"的纯粹乐趣。不只是玩，更像是看一档永不剧终的、由 AI 共同主演的奇幻连续剧——每一集都是世界自己写出来的。

CH. 04 · SYSTEM ARCHITECTURE

系统架构亮点

星月岛不是单一 LLM 的对话玩具，而是一整套让"角色真正活着"的工程系统。后端基于 Python + FastAPI，前端用原生 JS 渲染实时地图与角色状态，核心是七层协同的智能体运行栈。

L7 叙事观测层
剧情状态机 + 叙事事件检测器：以观察者身份记录世界自发涌现的剧情，不再依赖预定义剧本
L6 决策目标层
长期目标管理器 + 目标层级更新器：每个角色维护 immediate / short / mid / long 四层目标，动态更新
L5 承诺契约层
承诺提取引擎 + 时间表达式解析器 + 全局承诺池：让"明日午时在码头见面"真正成为可追踪的契约
L4 记忆宫殿层
MemPalace 记忆宫殿：向量检索 + 分层记忆 + 自然衰减 + 反思沉淀，让"三个月前的对话"依然能被回忆
L3 资源状态层
资源循环系统 + 角色属性监控：饥饿 / 焦虑 / 幸福 / 体力 / 星力 真实变化，约束角色行为合理性
L2 行动执行层
LLM 行动执行器 + 动作预算控制器：所有角色行动（探索 / 冥想 / 交易 / 战斗）由 LLM 决策，受资源与时间约束
L1 世界时钟层
WorldTimer：统一的奇幻世界时钟，驱动所有 Agent 同步思考、同步行动、同步对话
F · 01
多智能体共生
Multi-Agent Symbiosis

每个角色拥有独立的 LLM 大脑、独立的记忆宫殿、独立的目标层级，通过共享世界时钟与承诺池形成真实的社会网络，而非中心化调度的木偶。

F · 02
承诺驱动的时间线
Commitment-Driven Timeline

角色口中说出的"明天午时""三日后"会被时间表达式解析器转译为真实可追踪的契约，由承诺池统一调度触发，避免对话与行动脱节。

F · 03
记忆衰减与反思
Memory Decay & Reflection

短期对话会自然淡忘，重大事件会被反思系统固化为长期记忆。角色会"成长"，也会"遗忘"，让叙事有时间感与人物弧光。

F · 04
可观测的涌现剧情
Observable Emergent Narrative

叙事状态机不再预设剧情里程碑，而是观察记录世界中自然涌现的事件、转折与冲突，让每一次"奇遇"都是世界自发的产物。
