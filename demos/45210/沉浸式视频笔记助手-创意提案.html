TRAE AI 创造力大赛 · 学习工作赛道

沉浸式视频笔记助手

看视频时一键截图，AI 自动提取内容生成结构化笔记，并同步到 Notion / Obsidian。让每一帧知识都被沉淀，让学习不再手忙脚乱。

产品形态：浏览器扩展插件 版本：v1.5.1 技术栈：Chrome MV3 + 豆包AI + Notion API

一、创意介绍

想解决什么问题、为什么会做、它是什么

🎯

想解决的问题

在线学习、看技术教程、追知识类视频时，关键信息一闪而过。手动暂停截图、再逐字敲进笔记，既打断节奏又容易遗漏，整理成本极高。

💡

灵感动因

作者在学课程时反复「暂停-截图-切窗口-打字」，发现大部分内容其实是 AI 能直接看图理解的视觉信息。为何不让 AI 替我把截图变成笔记？

🧩

产品形态

一款 Chrome / Edge 浏览器扩展插件。侧边栏常驻，快捷键一键截图，后台 AI 自动分析并生成 Markdown，最终落库到 Notion 或 Obsidian。

⚡

核心差异化

不止是截图工具，而是「截图 → AI 理解 → 结构化笔记 → 知识库」的完整闭环，支持代码块、图表、数学公式 LaTeX 自动识别。

二、目标用户及痛点

谁会用、在哪用、没它时会怎样

面向用户群体

  • 📚 在线学习者

    看网课、公开课、技术教程的学生与自学者，需要高效沉淀视频中的知识点。

  • 💻 开发者与产品经理

    观看技术分享、产品拆解视频时，希望快速记录代码片段、架构图、关键结论。

  • 📊 知识工作者

    研究行业分析、数据报告视频，需要把画面中的图表、数据转为可检索文本。

使用场景

  • 🖥️ 场景一：技术教程跟学

    B 站 / YouTube 看编程教学，遇到代码演示一键截图，AI 提取代码并标注语言。

  • 🎓 场景二：在线课程学习

    MOOC 平台看高数/物理课，公式截图自动转 LaTeX，直接渲染成规范数学符号。

  • 📈 场景三：行业研究

    看财报解读、市场分析，截图后图表自动描述，数据点被结构化记录。

当前痛点（没有它时）： 手动暂停 → 截图 → 切到笔记软件 → 重新打字 → 来回切换窗口，5 分钟的知识要花 15 分钟整理，且公式、图表几乎无法还原，学习体验被严重割裂。

四、核心功能

六大能力构成完整闭环

📸

一键视频帧截图

快捷键 Ctrl+Shift+Z 瞬间捕获当前视频画面，无需暂停播放。

🤖

AI 自动内容分析

豆包视觉模型理解截图，自动提取文字、代码、图表、数学公式。

📝

结构化 Markdown

输出标题、要点、代码块、LaTeX 公式，开箱即用的规范笔记。

🔗

Notion / Obsidian 同步

一键配置，笔记自动落库到知识管理工具，形成可检索资产。

📊

任务队列管理

可视化任务列表，支持批量删除、并发处理、失败重试。

🔢

LaTeX 公式渲染

数学公式自动转 LaTeX，在 Notion 中自然显示为数学符号。

五、使用流程

从安装到产出笔记，4 步搞定

安装插件

加载已解压扩展，配置豆包 API Key 与 Notion/Obsidian。

启动监听

打开视频页面，侧边栏点击「启动」开始监听。

一键截图

播放视频，关键时刻按 Ctrl+Shift+Z 捕获画面。

自动成笔记

AI 分析后生成 Markdown 并同步到知识库，任务列表查看进度。
