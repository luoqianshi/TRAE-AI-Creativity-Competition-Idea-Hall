一个完全离线的 HTML 单页应用。输入汉字 → 选字体 → 一键生成描红字帖（田字格 + 拼音 + 组词 + 笔画数）。支持打印/导出矢量 PDF。自带 9 款书法字体 + 可上传自定义字体。所有 JS 库本地化，无需联网。

一、运行环境与快速启动

系统要求INFO
  • 现代浏览器：Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+
  • 推荐 Chrome / Edge（打印 PDF 支持最佳）
  • 无需 Node.js、python、npm 等任何运行时
  • 无需 网络连接（完全离线可用）
快速启动TIP
  1. 打开 dist/ 文件夹
  2. 双击 字帖生成器.html
  3. 输入汉字 → 点击「生成字帖」
  4. 点击右上角 🖨 按钮 → 打印 / 导出 PDF
推荐浏览器NOTE
  • 首选 — Chrome 或 Edge：window.print() 后「另存为 PDF」生成矢量文字
  • 可用 — Firefox：Print → Save to PDF
  • 不推荐 — Safari：PDF 字体嵌入支持较弱

3.3 上传自定义字体

知识产权友好设计IMPORTANT

内置字体仅作为演示提供。为满足版权合规需求，本工具支持你上传自有字体文件：

  1. 点击字体下拉框旁边的 🟢 「添加字体」 按钮
  2. 选择本地的 .ttf / .otf / .woff / .woff2 文件
  3. 字体通过 FontFace API 动态注册到浏览器
  4. 上传的字体自动出现在下拉框，名字带 ★ 前缀
  5. 刷新页面后自定义字体消失（仅当前会话有效，不会泄露到本地存储）
推荐的自带字体方案SUCCESS
  • 开源免费字体（推荐下载后上传）：
  • 霞鹜文楷 — 开源楷体，字形优美

  • 阿里巴巴普惠体 — 阿里免费商用

  • 系统自带字体（直接可用，版权随系统授权）：
  • Windows: C:\Windows\Fonts\ 下的楷体（simkai.ttf）、仿宋（simfang.ttf）
  • macOS: /System/Library/Fonts/ 下的华文系列

四、打印/导出 PDF

打印方案说明IMPORTANT

本工具采用 浏览器原生打印（window.print()）方案，而非 JavaScript 生成 PDF。原因：

  • ✅ 矢量文字（PDF 文字可选、可搜索、可复制）
  • ✅ 任意缩放清晰（300+ dpi 打印无锯齿）
  • ✅ 无需额外库（Puppeteer / jsPDF 等）
  • ❌ 非原生的 PDF.js 方案文字为位图渲染，放大模糊
操作步骤TIP
  1. 生成字帖（点击「生成字帖」按钮）
  2. 点击右上角 🖨 打印按钮
  3. 弹出新窗口，显示「⏳ 正在加载字体，请稍候...」
  4. 字体加载完毕 → 自动弹出浏览器打印对话框
  5. 目标打印机 → 选择「另存为 PDF」
  6. 纸张尺寸 → A4
  7. 边距 → 无（或默认）
  8. 保存 PDF 文件
已知限制WARNING
  • 打印窗口的 @page { size: A4 portrait; margin: 20px } 控制页面参数。部分浏览器（Firefox）对 @page 支持不完整，页眉/页脚位置可能偏移。
  • 如果打印对话框没有自动弹出，请手动按 Ctrl+P（Windows）/ Cmd+P（Mac）。
  • Safari 在打印窗口中对 FontFace API 支持下不佳，可能出现字体未嵌入的警告。

八、常见问题

Q1： 为什么打开 HTML 后字帖没有显示？QUESTION

Q1： 为什么打开 HTML 后字帖没有显示？ A： 检查 fonts/ 和 js/ 文件夹是否与 HTML 在同一目录下。相对路径 ./fonts/ 和 ./js/ 依赖于此。也可以通过 F12 → Console 查看报错。

Q2： 为什么打印预览中的字体不对？ A： 打印窗口需要重新加载字体（FontFace API），在弹出「⏳ 正在加载字体」提示后请等待。可能原因：字体文件路径错误、浏览器弹窗被拦截，或 CSP 策略阻止了 @font-face 加载。

Q3： 可以自定义每页字数吗？ A： 目前固定每页 11 字（22 行 DOM）。可修改 HTML 中 generateGrid() 的 11 和 22 参数。

Q4： 组词数据不准确怎么办？ A： customZuCi 字典优先于 cnchar-words。编辑 HTML 中的同名对象即可覆盖默认值。

Q5： 支持笔顺动画吗？ A： 当前显示静态笔画 SVG 分解。如需逐笔动画，可基于 HanziWriter API 扩展。

Q6： 如何批量生成多页不同内容？ A： 分批输入分别打印，再用 PDF 合并工具（如 PDFsam）汇总；或自行修改 generateGrid() 支持多文本输入。
