🎉 项目简介

大家好！我是「暖暖厨房」团队的成员，很高兴参加这次TRAE创造大赛！

「暖暖厨房」是一款面向所有人群，特别为认知障碍人群和厨房小白设计的智能烹饪助手。我们希望通过技术的力量，让每个人都能享受做饭的乐趣！

✨ 核心功能

🏠
智能食材匹配与菜谱推荐
  • 选择冰箱中的食材，AI自动推荐可做的菜谱
  • 支持70种常用食材，20道精选菜谱
  • 智能匹配算法，精准推荐合适的菜谱
🔍
食材搜索功能
  • 支持打字搜索食材，快速定位
  • 实时搜索结果，提升操作效率
🗣️
语音播报教程
  • 每一步教程都配有语音播报
  • 支持播放/暂停/停止切换
  • 做饭时无需一直看屏幕，解放双手
🥗
热量营养信息展示
  • 显示热量（千卡）、蛋白质、碳水、脂肪
  • 满足减肥健身人群的需求
⚠️
食物相克科普
  • 自动检测食材搭配风险
  • 给出温馨提示，保障饮食安全
💬
美食社区
  • 发帖分享做饭心得
  • 浏览他人帖子，点赞互动
🏆
积分成就系统
  • 8种成就勋章，记录成长
  • 积分奖励，增加使用动力
📸
做饭记录
  • 拍照记录美好时光
  • 保存做饭历史，留下美好回忆

🌟 特色亮点

【无障碍设计】
  • 大字体界面：正文18px，标题24px+，方便阅读
  • 暖色调配色：橙色+米色+暖黄，情绪舒缓
  • 语音播报：解决视觉依赖问题
  • 大按钮设计：按钮尺寸≥44px，易于点击
  • emoji图标：直观的视觉符号，便于理解
【数据统计】
🍽️ 70种常用食材
📖 20道精选菜谱
🏅 8种成就勋章
⚠️ 6组食物相克提醒
【社会价值】
  • 帮助认知障碍人群独立完成烹饪
  • 减少食物浪费（冰箱管理功能）
  • 促进健康饮食（热量营养展示）
  • 增强家庭互动（做饭记录功能）

🏗️ 技术架构

  • 前端框架：原生HTML/CSS/JavaScript（ES6+）
  • 语音合成：Web Speech API
  • 数据存储：localStorage
  • 图片服务：Pexels API
  • 部署方式：GitHub Pages

📱 兼容性

  • 支持浏览器：Chrome、Firefox、Safari、Edge
  • 响应式设计：支持手机、平板、桌面端
  • 无需安装：直接访问即可使用
