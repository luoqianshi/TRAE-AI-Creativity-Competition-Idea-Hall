MODULE BUILDING

用平台搭建业务模块

无需编写代码，通过配置即可搭建完整的业务模块。从业务对象定义到菜单发布，全流程可视化操作

1

定义业务对象

业务对象是ZLink的核心概念，是所有业务能力的载体。创建业务对象后，系统自动生成主实体和基础表结构，包含完整的审计字段（tenant_id、version、create_by等）

业务对象 = 主实体 + 子实体 + 字段 + 业务动作 + 单据转换 + 审批流
2

配置实体与字段

为主实体和子实体添加字段，支持17+字段类型（文本、数字、金额、日期、下拉、树形选择等）。每个字段可配置校验规则、联动规则、字段权限和脱敏策略

字段类型: TEXT | NUMBER | AMOUNT | DATE | SELECT | TREE_SELECT | ADDRESS | RATING ...
3

设计列表与表单

通过可视化设计器配置列表视图（7种视图类型）和表单布局（普通/步骤/电子表格）。拖拽式操作，支持查询条件、列定义、按钮配置、联动规则和子表Tab页

列表设计: 筛选条件 + 列定义 + 按钮配置 + 视图切换 | 表单设计: 字段布局 + 联动规则 + 子表
4

配置业务动作与流程

为业务对象创建业务动作（提交、审批、撤回等），每个动作由DAG步骤流驱动。支持AI_CALL步骤调用AI、审批步骤对接Flowable、条件路由、定时触发等8种步骤类型

步骤类型: UPDATE | APPROVAL | AI_CALL | CONDITION | TIMER | DIALOG | NOTIFICATION | CREATE
5

发布菜单与权限

将业务对象发布为菜单项，配置功能权限（菜单/按钮级）、数据权限（行级过滤）和字段权限（列级/脱敏）。多租户环境下，租户管理员可独立分配菜单和业务对象权限

权限体系: 功能权限(菜单/按钮) + 数据权限(行级) + 字段权限(列级/脱敏)
