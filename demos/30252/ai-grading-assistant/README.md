# AI批卷助手 - 使用说明

## 快速启动

### 方法一：双击启动脚本（推荐）
1. 找到 `启动批卷助手.bat` 文件
2. 双击运行即可自动启动服务并打开浏览器

### 方法二：手动启动
1. 打开命令提示符
2. 进入项目目录：`cd ai-grading-assistant`
3. 启动服务器：`node server.js`
4. 在浏览器访问：`http://localhost:8080`

## 功能介绍

### 登录注册
- 首次使用请注册账号
- 数据保存在浏览器本地，清除浏览器数据会丢失

### 班级管理
- 创建/编辑/删除班级
- 添加/编辑/删除学生

### 作业管理
- 创建作业和试卷
- 支持选择题、填空题、主观题

### AI批改
- 拍照或上传试卷图片
- OCR自动识别文字
- 自动批改选择题和填空题
- 主观题支持手动评分

### 成绩统计
- 查看班级成绩
- 分数分布图表
- 错题统计分析
- 导出CSV成绩单

## 技术说明

- **前端技术**：HTML5 + CSS3 + JavaScript
- **样式框架**：Tailwind CSS
- **OCR引擎**：Tesseract.js（离线中文识别）
- **数据存储**：浏览器LocalStorage
- **本地服务**：Node.js HTTP Server

## 注意事项

1. 首次启动需要下载OCR语言包，可能需要等待几分钟
2. 建议使用Chrome或Edge浏览器
3. 确保网络连接正常（仅首次下载语言包需要）
4. 关闭启动窗口会停止服务

## 问题排查

- **启动失败**：检查是否安装Node.js
- **OCR识别慢**：首次使用需要下载语言包，后续会缓存
- **数据丢失**：清除浏览器缓存会丢失数据，请定期导出成绩
