01 — 创意简介

为爱而生，因需而在

深入洞察家庭教育痛点，打造最懂父母的成绩管理工具

💔

家长痛点

孩子成绩散落在各科试卷、班级群消息、家长会记录中。缺少系统性整理，无法形成完整的学习档案，更无法发现学科间的强弱规律。

💡

创作灵感

每个家长都希望成为孩子学习的助力者，而非焦虑的旁观者。我们希望打造一款工具，让父母能从容地参与孩子成长，用数据说话，用科学方法辅助决策。

📱

产品形态

基于微信生态的小程序，无需下载、即开即用。借助微信云开发，实现数据安全存储与多设备同步，让爱与责任随时在线。

技术驱动，体验至上

采用 Taro 跨端框架，一次开发多端运行，确保在微信小程序中拥有流畅的原生体验。React + TypeScript 构建，Zustand 管理状态，Tailwind CSS 打造精美界面。

微信云开发提供安全可靠的云端存储，让每一次记录都得到妥善保管。

Taro 4.x React 18 TypeScript Tailwind CSS Zustand 微信云开发

01

成绩散落各处

成绩记录分散在试卷、班级群、备忘录中，难以汇总查看。

解决方案：一键录入，云端永久保存，随时查看历史记录
02

缺乏数据洞察

只知道分数高低，不知道哪科薄弱、进步还是退步。

解决方案：多维度统计分析，科目对比图表，直观发现规律
03

多子女管理难

家里有多个孩子，每个孩子的信息交织在一起，查询困难。

解决方案：独立档案管理，一键切换，数据隔离
04

隐私安全担忧

担心孩子成绩数据被泄露或滥用。

解决方案：微信 openid 数据隔离，仅用户本人可访问
🏠

家庭日常

晚饭后，打开微信查看孩子的最近成绩，了解本次考试的得失，与孩子进行有针对性的学习讨论。

📊

期末复盘

学期结束时，查看各科成绩趋势图表，分析偏科情况，为下学期制定针对性辅导计划。

👨‍💼

出差在外

工作繁忙出差时，用手机快速录入新成绩，不遗漏任何一次记录，数据自动同步到云端。
