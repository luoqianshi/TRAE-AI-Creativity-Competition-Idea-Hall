历史背诵辅助软件
产品设计方案

一个帮助用户高效背诵历史知识的浏览器网页应用，支持人物线索与时间线线索两种学习方式， 提供遮挡背诵模式和本地数据管理功能。

项目背景

背景与目标

本项目旨在打造一个辅助背诵历史知识的电脑浏览器网页版应用。用户可以逐步录入自己的历史知识， 并通过两类主体线索进行组织和复习。

人物线索

以人物为主体线索，浏览人物生平、关键事件、功绩与影响

时间线线索

以时间线为主体线索，创建多条时间线，并按时间顺序浏览历史事件

第一版目标

  • 稳定的手动录入与浏览功能
  • 关键词检索功能
  • 遮挡背诵模式
  • 本地保存与导入导出
功能规划

第一版功能范围

包含能力

  • 创建、编辑、删除人物
  • 创建、编辑、删除多条时间线
  • 创建、编辑、删除历史事件或知识点
  • 创建、编辑、删除背诵卡片
  • 历史事件关联到时间线与人物
  • 连续蛇形时间线展示
  • 关键词搜索功能
  • 三种背诵模式与记录
  • 本地保存与 JSON 导入导出

不包含能力

  • 账号系统与云端同步
  • AI 自动提取时间、人物、事件
  • 自动生成知识总结
  • 复杂熟练度算法、错题本和复习计划
  • 多人协作功能
系统设计

信息架构

首页双入口结构

人物主页

浏览、创建、编辑人物信息

时间线主页

创建多条时间线，按时间浏览历史事件

搜索 卡片背诵 导入 导出

顶部提供搜索、卡片背诵、导入和导出入口

设计理念

双入口结构优先保证用户能从"人物"和"时间线"两种学习线索进入知识体系； 卡片背诵作为独立模式存在，不强制归入人物或时间线。

用户旅程

  • 1 用户进入首页选择入口
  • 2 浏览人物或时间线内容
  • 3 进入背诵模式进行学习
  • 4 记录背诵结果并保存
数据设计

核心数据模型

时间线

表示一个可独立浏览和背诵的主题线索

  • id - 唯一标识
  • name - 时间线名称
  • description - 时间线简介
  • tags - 可选标签
  • createdAt / updatedAt

历史事件

时间线上的核心卡片，也是人物详情页中的相关内容

  • id - 唯一标识
  • timelineId - 所属时间线
  • timeLabel - 时间展示文本
  • title / hint / summary / detail
  • keywords / personIds

人物

人物主页中的主体对象

  • id - 唯一标识
  • name - 姓名
  • lifeTime - 生卒时间或所处时代
  • summary / biography / achievements
  • keywords

背诵卡片

用于独立的问答式记忆，可关联人物或历史事件

  • id - 唯一标识
  • front - 卡片正面（问题/提示）
  • back - 卡片背面（答案/解释）
  • keywords - 关键词
  • personIds / eventIds - 可选关联

背诵模式

人物背诵

显示人物名或提示，遮住生平、相关事件、功绩与影响

时间线背诵

显示时间点和提示词，遮住关键事件内容

卡片背诵

显示卡片正面，遮住卡片背面

搜索功能

用户输入关键词后，系统在本地数据中匹配：

  • 人物姓名、简介、生平、功绩、关键词
  • 时间线名称、简介、标签
  • 历史事件时间、标题、提示词、简介
  • 背诵卡片正面、背面、关键词
