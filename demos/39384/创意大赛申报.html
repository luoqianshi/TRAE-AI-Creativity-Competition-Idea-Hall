一个工具，打通有线串口、无线蓝牙与多种工业仪表协议

产品形态：桌面应用（Windows / macOS / Linux）

💡 创意名称 & 创意介绍

想解决什么问题

现场运维和调试人员面对不同品牌、不同协议（Modbus / DL/T 645 / CJ/T 188）的工业仪表时，需要在多个专用软件之间反复切换，且缺乏统一的设备物模型管理，导致调试效率极低、数据无法沉淀。

为什么会想到做这个

团队成员长期从事智慧水务、智慧能源领域现场调试，深受"一表一软件"的困扰——电表用A软件、水表用B软件、Modbus用C软件。更关键的是，新设备上线时，产品属性、寄存器地址、换算公式等配置信息全凭经验口口相传，无结构化存储。我们决定打造一款"全协议+全链路+可管理"的一站式调试平台。

大概是什么产品

基于 Tauri v2 跨平台框架的桌面应用——将串口/蓝牙双物理链路与 Modbus RTU/TCP/UDP、DL/T 645 电表协议、CJ/T 188 水表/热量表协议整合为统一操作界面，并内置产品-属性-寄存器三级物模型管理系统。

当前痛点（如果没有我们的产品）

  • 1

    多软件切换，效率极低

    Modbus 用 ModScan/ModbusPoll，电表用厂家专用软件，水表用另一套，调试一台混合站点可能要打开 4-5 个软件，数据无法对照查看。

  • 2

    连接方式受限，无线场景无工具可用

    现有调试软件几乎只支持串口有线连接。现场很多设备通过蓝牙 BLE 转 RS-485 模块接入，运维人员只能用手机 App 凑合，缺乏专业级桌面调试能力。

  • 3

    设备物模型靠"口口相传"

    新设备上线时，寄存器地址、数据类型、换算公式这些信息没有结构化存储，全凭老员工经验。人员流动导致知识断层，每次新项目都是"从零开始"。

  • 4

    批量配置无工具，人工录入易出错

    一个产品有几十个属性、上百个寄存器，手工逐一录入耗时数小时且极易出错，而现有工具根本不支持 Excel 批量导入导出。

📊 价值与意义

将多协议调试整合为一个工具，现场调试效率预计提升 60% 以上。配合 Excel 批量导入/导出，设备上线配置时间从数小时缩短至数分钟。

🏭

商业价值

填补了"有线 + 无线双链路 + 多工业协议 + 物模型管理"一体化桌面工具的空白。可作为智慧水务、能源管理解决方案的前端入口，与 SaaS 平台联动形成数据闭环。

🌍

社会价值

在碳中和、智慧水务、智慧能源大背景下，降低设备数据采集门槛，加速中小企业数字化改造。开源架构也有助于高校教学，培养工业通信领域人才。

🔧 技术架构亮点

  • 1

    Tauri v2 跨平台架构

    Rust 后端处理原生串口/蓝牙通信，Vue 3 前端负责 UI 交互，性能媲美原生应用，打包体积远小于 Electron。

  • 2

    适配器模式 + 协议层分离

    串口和蓝牙通过统一 BaseAdapter 接口抽象，Modbus 协议在前端 JS 和后端 Rust 双实现，分别覆盖 BLE 透传和串口直连场景。

  • 3

    ASP.NET Core 云端后端

    产品、属性、寄存器数据持久化到云端 MySQL，支持多终端协同。物模型数据可通过 API 与第三方系统（SCADA / MES）对接。
