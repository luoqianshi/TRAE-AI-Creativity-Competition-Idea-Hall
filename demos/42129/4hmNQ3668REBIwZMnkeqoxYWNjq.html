九大模块

每个模块的目标与方法

从透明授权到身份强化，每一个模块都服务于同一个终极目标：训练回归能力。

MODULE 01

透明授权

避免用户产生被监控感。所有数据仅本地记录，不记录内容，不上传云端，可随时删除。

不会记录聊天内容
不会记录输入内容
只记录：开始 / 结束 / 切换 / 停留
MODULE 02

行为观察

只观察事实，不评价。重点记录「离开→回来」，而不是「刷了多久」。

✓ 任务开始 / 结束时间
✓ 离开 / 回来时间
✓ 是否回来
✗ 不统计刷了多少小时
MODULE 03

状态识别

核心创新：区分「恢复型偏离」和「逃避型偏离」。累了需要恢复，不是更强的自律。

恢复型 → 散步 / 闭眼 / 喝水
逃避型 → 最小行动 / 微任务
MODULE 04

规律发现

冷启动：1-3天只观察，4-7天给出推测，第8天起正式输出。每条规律必须配解决方案。

错误：你晚上10点容易分心
正确：晚上10点易离开，最有效的回归方法是「最小行动」
MODULE 05

回归机会

不叫「高风险时段」，叫「回归机会」。把过去容易离开的时间，重新定义为练习回来的时刻。

不是弹窗打扰
仅首页轻提示
「换个更轻的开始方式？」
MODULE 06

回归训练 ⭐

最核心模块。在用户即将分心时，给一次温和选择 + 个人最佳回归动作，同时明确允许继续刷。

传统产品：阻止分心
FocusOS：训练回来
继续刷必须允许（否则逆反）
MODULE 07

回归工具箱

整个系统最大的护城河。用户不知道什么方法适合自己，但系统观察什么方法最常帮他回来。

最小行动（73%）
阅读3页（67%）
散步5分钟（57%）
MODULE 08

回归记录

只保留两个核心指标：回归率和回归延迟。不统计刷了多久，因为那会制造羞耻感。

回归率：离开后回来的比例
回归延迟：回来平均用了多久
不统计：刷了多少小时 ✗
MODULE 09

身份强化

核心身份不是「我是一个从不分心的人」，而是「我是一个能把自己带回来的人」。

开始者 → 回归者 → 坚持者
→ 掌控者 → 创造者
