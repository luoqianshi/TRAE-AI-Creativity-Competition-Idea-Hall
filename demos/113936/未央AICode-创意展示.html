💡 创意介绍

让 AI 真正理解你的代码，而不只是补全

🤔

想解决什么问题

现有 AI 编程助手只停留在补全和对话层面，无法真正理解项目架构。面对遗留代码、复杂项目，开发者仍需要花费大量时间理解上下文、排查 Bug。

💡

为什么会想到做这个

团队在日常开发中发现，AI 生成的代码在小型 Demo 中表现优秀，但在实际项目里缺少对代码库全局的理解。如果有工具能像资深开发者一样理解整个项目的架构和逻辑，开发效率将大幅提升。

🖥️

产品形态

一款基于 Tauri 2.x 的桌面端 AI 代码编辑器，macOS / Windows 双平台原生体验，离线可用，安全可控。

⚡ 核心功能

不止于编辑器，更是一个智能开发工作站

⌨️

Monaco 编辑器

VS Code 同款内核，30+ 语言语法高亮、智能补全、LSP 诊断、内联 AI 聊天、行内代码补全。

🤖

AI Agent 系统

意图检测 → 自动生成计划 → 读写文件/执行终端命令 → 验证结果。不只给建议，直接帮你做完。

🧠

代码知识图谱

基于 tree-sitter 解析 18 种语言，构建代码符号的图数据库。支持调用链查询、影响分析、类型层次。

📊

Office 编辑

直接内嵌编辑 xlsx / docx / pptx，无需切换应用。基于 UniverJS + ProseMirror + Fabric.js 实现。

🔗

项目理解引擎

自动分析项目架构层次，识别框架和技术栈，生成代码指纹，检测文档陈旧度，基于 embedding 的语义搜索。

🔄

Git + 终端

内置 Git 面板（init/clone/commit/push/pull/diff），真实 PTY 终端，多标签页，与 AI Agent 联动。

💎 价值与意义

效率提升 · 商业价值 · 社会价值

🚀 效率提升

AI Agent 自动理解项目架构并执行开发任务，减少 60% 的上下文切换时间。代码知识图谱让开发者能在秒级定位任意符号的定义、引用、调用链，告别"这个函数从哪来的"的困惑。内嵌 Office 编辑避免了切换应用的干扰。

💰 商业价值

对于中小团队，降低了 onboarding 成本——新成员通过项目理解引擎可以快速上手。知识图谱和 DevKG 沉淀了团队的编码规范、设计模式和最佳实践，形成可持续积累的团队资产。支持 Ollama 本地模型，数据不出网，适合对安全敏感的行业。

🌱 社会价值

开源技术栈（Tauri + UniverJS + tree-sitter）降低了桌面应用开发门槛。通过 AI 辅助让更多非专业开发者能参与软件开发。本地优先架构保护用户数据隐私，符合国产化和数据安全趋势。

🎬 快速上手指南

开箱即用的开发工作站

📂

1. 打开项目

点击左侧"打开文件夹"，选择你的项目根目录。文件树自动展开，代码知识图谱自动开始构建。

💬

2. AI 对话

右键面板打开 AI 聊天，选择模型后开始对话。Agent 模式会自动识别你的意图并执行操作。选中代码后可使用内联聊天。

📊

3. 打开 Office 文件

在文件树中双击 .xlsx / .docx / .pptx，即可直接在编辑器内编辑，修改后点"保存"即可。

🔄

4. Git + 终端

底部面板切换至终端使用命令行。Git 面板查看变更、暂存、提交、推送。全程不离开 IDE。
