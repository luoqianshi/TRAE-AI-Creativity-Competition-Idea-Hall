PersonalHub Demo

把昨天的记录，变成今天可执行的建议

这个页面不是静态介绍，而是一个可直接演示的基础样机。你可以切换真实场景，填写晚间结算， 生成候选记忆，手动确认后再得到第二天的 0-3 条建议，并查看每条建议的依据。

3 个 可切换演示场景，覆盖工作推进、学习冲刺、状态恢复。
4 步 从原始记录到今日建议，清晰演示核心产品闭环。
可解释 每条建议都能展开查看来源，不是黑盒输出。
Demo 演示路径

1. 选择一个示例场景

2. 点击“生成候选记忆”

3. 手动晋升或拒绝候选记忆

4. 点击“生成今日建议”查看结果

场景切换

预置三组样例，方便在报名展示时快速切换演示。

晚间结算输入

这是 PersonalHub 的原始来源层，记录进展、决策、卡点和明日一步。
4 原始来源字段
0 候选记忆
0 已晋升记忆
0 今日建议

候选记忆

这里模拟“默认不直接写入长期记忆，必须人工确认”的产品原则。

今日建议

只生成 0-3 条最值得推进的事情，并支持展开查看依据。

系统活动流

用于演示 PersonalHub 如何把动作串成闭环，而不是一次性的建议页。
演示说明：这个 Demo 使用前端内置数据和规则模拟产品主链路，适合报名展示与现场讲解。 如果继续做初赛版本，可以把这里替换为真实后端接口和本地数据读写。
