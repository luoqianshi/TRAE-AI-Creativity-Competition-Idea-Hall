今日心情饭

根据你此刻的情绪，AI 替你决定今天吃什么、怎么做、在哪儿买

产品形态：小程序 / H5 Web App
目标用户：18–35 岁都市年轻人
核心技术：AI 情绪识别 + 食物推荐引擎
创意介绍

一句话能说清楚吗？

"今天吃什么"是中国人每天都要经历的决策困难，但现有的外卖平台和食谱 App 都只关注"我想吃什么"，没有人问过——你今天怎么样？

今日心情饭是一款以情绪为入口的 AI 饮食推荐工具：你只需告诉它你今天的心情（焦虑、疲惫、开心、想犒劳自己……），它会结合你的历史偏好、季节、时段、健康目标，给出一份专属的「今日心情菜单」，并直接对接食谱详情、超市购买或外卖下单。

从「选择困难」到「被温柔照料」，吃饭这件小事，值得被认真对待。

目标用户与痛点

谁需要它？在什么时候？

核心用户是 18–35 岁的都市独居青年、上班族、学生，他们每天面对以下真实困境：

😩
选择困难症 打开外卖 App 滑了 10 分钟还是不知道要什么，最后随便点了一份不满意的
🤕
情绪无人接收 工作压力大的下午，需要的不只是食物，而是一份能带来治愈感的选择
📱
推荐跟情绪脱节 现有 App 按热销、评分推荐，对你今天的状态毫不关心
🥗
健康目标被遗忘 减脂期总是被高热量的诱惑打败，没有工具真正帮你在情绪低谷时坚守目标

价值与意义

为什么值得做这个？

商业价值

餐饮决策是高频刚需，情绪化推荐可显著提升用户粘性，与外卖平台、预制菜品牌合作变现路径清晰

社会价值

通过饮食介入情绪管理，帮助都市人在快节奏生活中获得"被照料"的温度感，减少孤独感与决策疲劳

效率提升

将平均 15 分钟的饮食决策压缩至 30 秒，同时确保推荐质量优于随机浏览，减少不满意下单率

技术实现思路

怎么用 TRAE 做出来？

Demo 阶段将使用 TRAE IDE 生成核心 Web App 原型，主要技术栈为前端 H5（Vue/React）+ 调用大模型 API 实现情绪分析与食物推荐逻辑。

核心 AI 能力：① 情绪标签 → 饮食营养映射规则库（预制知识库）；② 大模型生成个性化推荐理由；③ 用户历史偏好持久化（本地存储）。

后续版本可接入外卖平台 API / 超市商品 API，实现从推荐到下单的完整闭环。
