// PRODUCT

VibeBase 是什么？

三层架构，让基建与业务彻底解耦。AI 在安全区域内自由发挥，基建层锁死不出错。

VibeBase — Project Architecture
Layer 01 — Foundation
锁死的基建层
  • StoreKit 2 内购封装
  • iCloud 同步方案
  • Widget 小组件框架
  • 证书 & Provisioning 自动化
  • 隐私政策 & 审核物料
Layer 02 — Template
可复用的模板层
  • 多套 UI 模板（效率 / 社交 / 工具）
  • 通用业务模块（登录 / 设置 / 分享）
  • App Store 上架 Checklist
  • 配套视频教程
Layer 03 — AI Prompt
安全区提示词库
  • 基建安全区边界定义
  • 场景化 Prompt 模板
  • 常见报错修复 Prompt
  • 业务代码生成最佳实践
