# 产品需求文档（PRD）

## 项目概述

### 项目名称
简历焕新计划

### 项目定位
面向迷茫大学生的简历优化与岗位匹配单页应用（SPA）

### 目标用户
- 在校大学生（大三、大四为主）
- 刚毕业的求职者
- 对简历撰写感到困惑的应届生

### 核心价值
通过 AI 技术帮助大学生优化简历内容、匹配适合岗位，提升求职成功率

---

## 视觉风格

### 设计理念
**学术极简风（Academic Minimalist）**

### 设计原则
- **专业**：传达可靠、权威的感觉
- **冷静**：理性、克制的视觉表达
- **高效**：清晰的信息层级，快速完成任务

### 色彩方案
- **背景色**：低饱和度米白/浅灰（#F8F9FA、#F5F5F5）
- **主色调**：深海蓝（#1A365D、#2C5282）
- **辅助色**：浅蓝、灰色系
- **文字色**：深灰（#2D3748）、中灰（#4A5568）

### 字体规范
- **主字体**：无衬线体（Inter、PingFang SC、Microsoft YaHei）
- **标题**：粗体、大字号
- **正文**：常规字重、适中行高

### 排版特点
- 大量留白，呼吸感强
- 清晰的视觉层级
- 卡片式布局
- 统一的间距系统

---

## 功能需求

### 第一阶段：框架搭建（当前任务）

#### 1. 顶部导航栏
- **左侧**：Logo + 项目名称"简历焕新计划"
- **右侧**：设置按钮（⚙️ 图标）

#### 2. 主体内容区
- 预留大容器区域
- 用于后续渲染不同步骤的卡片

#### 3. 设置功能（核心）
- **触发方式**：点击设置按钮
- **交互形式**：弹出极简模态框（Modal）
- **功能内容**：
  - 输入框：提示文字"请输入您的 AI API Key"
  - 保存按钮：点击后将 Key 存入 localStorage
  - 关闭功能：点击模态框外部或关闭按钮可关闭
- **数据持久化**：
  - 页面加载时自动读取 localStorage 中的 Key
  - 供后续 AI 接口调用使用

---

## 技术栈

### 前端技术
- **HTML5**：语义化标签
- **TailwindCSS**：CDN 引入，快速构建 UI
- **原生 JavaScript**：ES6+ 语法

### 数据存储
- **localStorage**：存储用户 API Key
