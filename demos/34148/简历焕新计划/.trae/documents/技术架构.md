# 技术架构文档

## 项目架构

### 整体架构
```
简历焕新计划/
├── index.html          # 主页面
├── css/
│   └── style.css       # 自定义样式（如需）
├── js/
│   └── app.js          # 主逻辑文件
└── assets/
    └── images/         # 图片资源
```

### 技术选型理由

#### HTML5
- 语义化标签提升可读性
- 良好的 SEO 支持
- 广泛的浏览器兼容性

#### TailwindCSS（CDN）
- 快速构建 UI，无需配置构建工具
- 原子化 CSS，开发效率高
- 内置设计系统，保证一致性

#### 原生 JavaScript（ES6+）
- 无框架依赖，轻量级
- 学习成本低
- 性能优秀

### 3. 设置模态框组件

#### 功能
- 输入并保存 API Key
- 管理用户配置

#### 交互流程
```
用户点击设置按钮
    ↓
显示模态框（淡入动画）
    ↓
用户输入 API Key
    ↓
点击保存按钮
    ↓
验证输入非空
    ↓
保存到 localStorage
    ↓
显示成功提示
    ↓
关闭模态框（淡出动画）
```

#### 样式特点
- 居中显示
- 半透明遮罩层
- 白色卡片背景
- 圆角：8px
- 阴影：中等强度

#### 代码结构
```javascript
// 模态框管理
const SettingsModal = {
    // 打开模态框
    open() {
        const modal = document.getElementById('settings-modal');
        modal.classList.remove('hidden');
        modal.classList.add('fade-in');
    },

    // 关闭模态框
    close() {
        const modal = document.getElementById('settings-modal');
        modal.classList.add('hidden');
        modal.classList.remove('fade-in');
    },

    // 保存 API Key
    saveApiKey(key) {
        localStorage.setItem('ai_api_key', key);
        this.close();
        this.showSuccessMessage();
    },

    // 读取 API Key
    loadApiKey() {
        return localStorage.getItem('ai_api_key');
    },

    // 显示成功提示
    showSuccessMessage() {
        // Toast 提示
    }
};
```

## 开发规范

### 命名规范
- 变量：驼峰命名（camelCase）
- 常量：全大写下划线（UPPER_SNAKE_CASE）
- 函数：动词开头（getUserData）
- ID：连字符命名（settings-modal）

### 代码注释
- 函数前添加功能说明
- 复杂逻辑添加行内注释
- 使用中文注释（与用户语言一致）

### Git 提交规范
- `feat`: 新功能
- `fix`: 修复 bug
- `style`: 样式调整
- `refactor`: 重构代码
- `docs`: 文档更新
