// 什么是粉色俄罗斯方块

经典玩法 + AI 体感 +
粉色治愈，三轴差异化

不是一个新游戏，而是"经典俄罗斯方块的体感升级版"——用 Google MediaPipe 检测手腕位置 + 举手动作，替代键盘操作，纯粉色主题让"打游戏"变成"动动手 + 治愈解压"。

🎮

经典玩法

10x20 网格 + 7 种方块（S/Z/I/O/L/J/T）+ 旋转/移动/消行/计分，40 年经典，0 学习成本

🤖

AI 体感控制

MediaPipe 检测手腕位置 → 方块左右移动；手腕高于肩膀 → 方块快速下降

💗

纯粉色主题

樱花粉 / 玫瑰粉 / 蜜桃粉 + 粉紫渐变背景，治愈系视觉，拍照分享天然友好

📹

直播友好

摄像头预览窗口 + 游戏画面 = 自然"出镜+游戏"分屏，直接生成抖音/小红书短视频

// 技术架构

粉色外观下，
是硬核 AI 体感技术

🎨

HTML5 Canvas

10x20 网格渲染 + 7 种方块 + 旋转/移动/消行/计分核心

🤖

MediaPipe Tasks Vision

Google 开源的关键点检测库，纯前端运行，零后端，3MB 模型

📷

getUserMedia API

浏览器原生摄像头调用，电脑/平板/手机都能用

🔊

Web Audio API

消行音效 + 等级提升音效 + 体感操作反馈音

💾

LocalStorage

最高分本地存储，刷新页面不丢失

✨

纯前端单文件

HTML 单文件，无后端、无服务器、无依赖，3 秒打开即玩
