    GraphRAG 技术原理

    1. 核心思想

    GraphRAG（基于知识图谱的检索增强生成）通过从非结构化文本中自动抽取实体和关系，构建知识图谱，再结合社区检测与层次化摘要，让 LLM 能够回答涉及全局语义和跨文档关系的问题。

    2. 工作流程

    原始文档 ──► 文本分块 ──► LLM 实体/关系抽取 ──► 知识图谱
                                            │
                ┌───────────────────────────┘
                ▼
        社区检测（Leiden）
                │
                ▼
    层次化社区摘要（自底向上）
                │
                ▼
       向量化 + 持久化索引

    3. 关键模块

    模块 作用
    实体抽取 从文本中识别"人/物/概念"等节点
    关系抽取 识别节点之间的语义关系，生成边
    社区检测 按图结构划分主题簇，生成社区
    社区摘要 对每个社区生成自然语言摘要
    Local Search 以实体为锚点，沿图遍历相关上下文
    Global Search 基于社区摘要回答宏观问题
    DRIFT Search 结合 Local 与 Global 的混合检索

    4. 查询模式

    • Local Search：适合"某实体相关 / 某具体事实"问题
    • Global Search：适合"整体趋势 / 跨文档总结"问题
    • DRIFT Search：先宏观定位社区，再深入实体

    5. 优势

    • 能处理跨段落、跨文档的关联问题
    • 通过社区摘要实现全局理解
    • 检索结果可解释（可追溯到具体实体和关系）
