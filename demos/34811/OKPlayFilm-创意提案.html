创意介绍

让互动影游创作像搭积木一样简单

OKPlayFilm 是一款基于浏览器的互动影游创作平台。它用可视化的剧情图谱替代传统线性编剧方式， 让创作者通过拖拽节点、连线分支来搭建复杂的互动叙事结构。无需编程基础，无需安装软件， 打开浏览器就能开始创作你的第一部互动影游。

◈

剧情图谱编辑

用节点和连线搭建分支叙事结构。开始、剧情、选择、结局四种节点类型，拖拽即可创建，连线即建立分支，一目了然。

✎

节点深度编辑

双击节点进入编辑：写剧本、旁白、台词，配置分支条件与目标，管理分镜故事板和媒体素材，自动保存到本地。

⌂

变量与逻辑系统

定义全局变量（角色属性、道具、线索等），在节点中观察和修改变量值，分支可绑定条件表达式，实现真正的互动逻辑。

目标用户与痛点

谁需要 OKPlayFilm？

面向有故事想讲、但缺乏技术手段的创作者群体，以及需要快速原型验证的互动内容团队。

1

独立编剧 / 故事创作者

有好的分支故事创意，但不会编程，现有工具要么太专业（Twine 学习曲线陡），要么太简单（无法表达复杂逻辑），找不到趁手的创作工具。

2

互动影游 / 视觉小说团队

策划用文档写分支逻辑，程序再翻译成代码，沟通成本高、迭代慢。需要一个可视化工具让策划直接搭建可验证的叙事原型。

3

影视 / 游戏专业学生

课程作业需要提交互动叙事作品，但 Unity / Unreal 太重，Ren'Py 需要写 Python，门槛高、耗时长。

4

内容平台 / MCN 运营

想做互动视频或互动图文，但现有平台只支持简单的 A/B 投票，无法实现多分支、多结局的深度互动体验。

🎯 核心使用场景

  • 悬疑推理：收集线索 → 不同选择触发不同真相
  • 恋爱模拟：角色好感度变量驱动多结局
  • 密室逃脱：道具与谜题条件组合解锁路径
  • 教育互动：知识点选择影响学习路径
  • 品牌营销：互动广告让用户参与剧情走向

😤 当前痛点

  • Twine：纯文本标记语言，可视化弱，无变量系统
  • Ren'Py：需写 Python 代码，非程序员劝退
  • Ink / Yarn Spinner：需嵌入游戏引擎，无法独立运行
  • 商业工具（如 articy:draft）：价格昂贵，本地化差
  • 通用笔记软件：无法表达分支逻辑和条件

1. 图谱搭建叙事骨架

在无限画布上拖拽创建节点，用连线建立分支关系。四种节点类型覆盖互动叙事的核心结构：开始、剧情、选择、结局。支持从节点出口直接拖到空白处快速创建并连线，双击进入编辑。MiniMap 全局导航，缩放平移自由探索。

2. 节点内深度创作

双击节点进入编辑器，五个标签页覆盖完整创作流程：剧本（脚本与旁白）、变量（观察与修改）、图片（媒体素材管理）、分镜（故事板排列）、视频（主视频配置）。每个节点可独立管理台词、分支条件和媒体资源。

3. 变量驱动的互动逻辑

项目级全局变量系统，支持数值、布尔、枚举三种类型，按角色/道具/线索/世界/自定义分类管理。节点可观察变量（触发显示）和修改变量（产生效果），分支可绑定条件表达式（如 好感度 ≥ 80），实现真正的互动叙事逻辑。

4. 本地优先，即开即用

基于浏览器 IndexedDB 实现全量本地持久化，自动保存，无需注册账号、无需服务器、无需安装。数据完全掌握在自己手中，随时回来继续迭代。项目支持封面图、标签分类、最近访问排序，多项目管理井井有条。

价值与意义

为什么 OKPlayFilm 值得做？

🚀

商业价值

互动内容是游戏与影视的交叉赛道，市场增速快。OKPlayFilm 可作为互动影游的「Figma」——先做创作工具占领工作流，再延伸到分发与变现。未来可对接 AI 生成剧本、云端协作、发布平台，构建完整生态。

⚡

效率提升

将策划从「写文档 → 程序翻译」的串行流程，变为「可视化搭建 → 即时验证」的并行流程。创作周期从数周缩短到数天，原型验证从数天缩短到数小时。变量系统让逻辑验证无需写代码。

🌍

社会价值

降低互动叙事创作门槛，让更多有故事的人能讲出分支故事。教育领域可用于制作互动课件，文化领域可用于非遗故事互动化，公益领域可用于制作选择式公益宣传片。本地优先保护创作者数据主权。

技术方案

轻量、现代、可扩展

基于 React + TypeScript 构建，React Flow 提供画布能力，Zustand 管理状态，Dexie（IndexedDB）实现本地持久化。零后端依赖，纯前端即可运行。
