===========================================================
                    AI心理树洞系统介绍
===========================================================

一、项目概述
-----------------------------------------------------------
AI心理树洞是一个基于Flask + HTML/CSS/JavaScript开发的
心理支持Web应用，支持手机和电脑端访问。

主要功能：
  1. 心情记录 - 记录每天的心情状态
  2. 树洞聊天 - 与AI心理咨询师对话
  3. 记录管理 - 查看心情和对话历史
  4. 心理知识 - 浏览心理科普文章

二、技术栈
-----------------------------------------------------------
后端：Python 3.x + Flask + Flask-CORS + requests
前端：HTML5 + CSS3 + JavaScript
数据库：本地JSON文件存储
AI服务：DeepSeek API (deepseek-chat)

三、文件结构
-----------------------------------------------------------
AI shudong/
├── app.py              # Flask后端服务
├── index.html          # 前端主页面
├── styles.css          # 响应式样式文件
├── script.js           # 前端交互逻辑
├── requirements.txt    # 项目依赖
├── 系统介绍.txt         # 本文件
└── data/               # 数据存储目录（自动创建）
    ├── mood_records.json      # 心情记录
    └── chat_sessions.json     # 对话记录

四、环境要求
-----------------------------------------------------------
1. Python 3.6+
2. 已安装依赖：Flask、Flask-CORS、requests

五、开启前后端步骤
-----------------------------------------------------------
方法一：使用Python直接运行（推荐）

步骤1：打开命令行（CMD或PowerShell）
       cd "C:\Users\Administrator\Desktop\AI shudong"

步骤2：安装依赖（首次运行）
       pip install -r requirements.txt

步骤3：启动服务
       python app.py

步骤4：访问应用
       在浏览器中打开：http://localhost:5000

方法二：使用虚拟环境

步骤1：创建虚拟环境
       python -m venv venv

步骤2：激活虚拟环境（Windows）
       venv\Scripts\activate

步骤3：安装依赖
       pip install -r requirements.txt

步骤4：启动服务
       python app.py

步骤5：访问应用
       在浏览器中打开：http://localhost:5000

七、注意事项
-----------------------------------------------------------
1. 确保网络连接正常，AI聊天需要联网调用API
2. 数据存储在本地data目录下，请定期备份
3. 服务默认监听5000端口，确保该端口未被占用
4. 开发模式下可使用debug=True，生产环境请关闭

八、功能说明
-----------------------------------------------------------
【首页】
- 根据时间显示不同问候语
- 选择今日心情并记录
- 快捷入口导航
- 最近对话列表

【树洞】
- 与AI心理咨询师实时对话
- 对话记录自动保存
- 支持Enter键发送消息

【记录】
- 心情记录列表（按时间排序）
- 对话记录列表（支持删除）
- Tab切换查看

【知识】
- 心理知识文章列表
- 搜索功能
- 分类筛选
- 文章详情查看

九、响应式适配
-----------------------------------------------------------
- 桌面端：多列布局，适合大屏幕
- 平板端：中等屏幕适配
- 手机端：单列布局，触控友好

===========================================================
                    启动成功后界面说明
===========================================================

启动成功后，命令行显示：
 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
 * Running on http://192.168.xxx.xxx:5000

在浏览器输入以上任一地址即可访问。

如果遇到问题：
1. 检查端口5000是否被占用
2. 检查网络连接
3. 检查API密钥是否有效
