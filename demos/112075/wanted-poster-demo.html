// 这是什么？

AI通缉令生成器是一个娱乐工具——你描述一个"通缉对象"（可以是偷吃外卖的室友、离家出走的水杯、甚至你自己的拖延症），AI会帮你生成一张正经八百的通缉令海报，3秒出结果，截图就能发朋友圈。

// 怎么用？

  • 描述你的通缉对象（越具体越好笑）
  • 选择通缉类型和海报风格
  • 点击生成，3秒出结果
  • 截图保存，发朋友圈/小红书

// 数据隐私

所有输入内容仅在你浏览器本地处理，不会上传到任何服务器。生成的通缉令记录保存在浏览器 localStorage 中，清除浏览器数据即可删除。
