Understanding
知码 AI 开创了一个全新的品类：AI 软件认知。

它不帮开发者写代码，而是帮开发者理解代码——理解架构、理解业务、理解项目的过去与未来。它是开发者的第二大脑。
Core Features
八大核心功能
01
AI 项目认知
自动分析整个项目，生成项目简介、系统架构、技术栈、核心模块、业务流程、难点与风险分析。无需 README，无需询问原作者。
架构分析 自动报告 项目画像
02
项目记忆恢复
针对多年未维护的项目，AI 自动恢复主要功能、开发目的、技术选型、设计思想、已知问题与历史演进，帮助开发者重新找回记忆。
记忆重建 遗留系统 历史回溯
03
AI Logic Graph · 业务逻辑图谱
自动生成业务逻辑图而非传统调用关系图。所有节点可点击查看对应代码、所属模块、设计目的、调用与依赖关系。
业务逻辑 可视化 交互式图谱
04
AI Knowledge Graph · 知识图谱
自动建立代码→模块→接口→数据库→Git→Issue→PR→文档→业务流程的完整知识网络，任意节点可追溯来源、作用与影响范围。
知识网络 全链路追溯 关联分析
05
AI 项目健康诊断
自动发现技术债、死代码、超大类、重复代码、循环依赖、高耦合模块、潜在漏洞与架构异味，一键生成项目健康报告。
技术债 代码质量 安全扫描
06
Impact Analysis · 影响分析
修改任意模块时，AI 自动预测会影响哪些模块、API、数据库、消息队列和业务流程，帮助开发者降低修改风险。
变更预测 风险评估 依赖分析
07
Project Replay · 项目演进回放
结合 Git 历史，自动还原项目从第一天到今天的完整发展过程，帮助理解为什么这样设计、这样修改、这样重构。
Git 分析 时间线 设计决策
08
AI Onboarding · 新人模式
自动生成新人学习路线：第一天读哪些模块，第二天理解哪些业务，第三天可以修改哪些代码，帮助快速接手项目。
学习路线 知识传递 新人引导
用户登录 → 权限校验 → JWT 生成 → Redis 缓存 → 数据库查询 → 返回 Token
