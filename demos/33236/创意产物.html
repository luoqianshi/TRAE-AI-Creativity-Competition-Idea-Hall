角色一致性

锚点系统确保同一角色在所有分镜中外观统一，服装、发型、配饰不会突变

本地 Stable Diffusion 支持

无需联网即可生成高质量漫画。支持多模型切换，每个模型都有专属的提示词结构和反向提示词。分辨率统一为 512x512，适配漫画分镜构图。通过 WebUI API 直连本地 GPU，生成速度取决于硬件性能。
