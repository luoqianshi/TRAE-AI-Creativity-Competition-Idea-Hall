01

创意名称与介绍

CONCEPT
// PROBLEM

想解决什么问题

B端销售线下面对面沟通时，掏出手机记录、翻看客户档案会打断谈话节奏；偶遇客户、展会接待等场景下无法提前调取客户信息，易混淆身份、遗忘沟通细节；同时企业面临客户信息私有化、销售离职导致客户流失的经营风险。

// MOTIVATION

为什么会想到做这个

在B2B销售场景中，线下面对面沟通是核心环节，但现有CRM工具均依赖人工手动录入，无法兼顾「交谈不中断、实时身份识别、即时信息推送、团队信息同步」四大诉求，属于长期未被妥善解决的真实刚需。

// PRODUCT

大概是什么产品

一款基于Rokid智能眼镜的B2B销售辅助应用，集成人脸识别瞬时调取客户档案、语音无感记录沟通内容，并自动同步至企业系统，实现从「销售私域记忆」到「企业公有资产」的转化。

02-1

核心使用场景

USE CASES

商务洽谈 / 上门拜访

销售与客户面对面深度沟通，中途无需掏手机翻看档案、打字记录，全程保持专注，提升专业形象与客户好感度。

一对一深度沟通

展会高密度接待

单日接待数十位潜在客户，自动识别身份、瞬时调取资料，告别手动登记，避免混淆客户身份、丢失洽谈细节。

高效批量识别

销售岗位人员交接

新人接手存量客户时，可直接调取完整线下沟通记录，无需依赖离职销售口头转述，快速掌握客户信任基础与合作细节。

无缝知识传承

多部门团队协同

商务、售后、项目负责人多人对接同一客户时，实时同步全团队历史记录，避免重复提问、承诺冲突，提升企业专业形象。

全员信息共享

S销售侧痛点

  • 沟通中操作手机打断谈话节奏，破坏专业感与客户体验
  • 偶遇客户无法调取资料，仅凭记忆易混淆身份
  • 脸盲遗忘客户需求，事后补记信息丢失率高
  • 客户信息分散在个人手机，形成信息孤岛

E企业侧痛点

  • 人员交接信息断层，新人上手慢，成交周期拉长
  • 销冠离职带走核心客户，客户资源流失风险高
  • 客户资产私有化，隐性沟通信息无法沉淀为企业资产
  • 多部门对接信息不互通，易出现重复提问、承诺冲突
