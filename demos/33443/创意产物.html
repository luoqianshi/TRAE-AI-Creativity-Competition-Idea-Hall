01 / PROBLEM

我们发现的问题

AI 生图工具越来越普及，但普通用户用起来依然有门槛。

  • 1

    不会写提示词

    用户有很好的画面想法，但不知道如何用模型能理解的语言描述，生成结果和想象差距很大。

  • 2

    效果不稳定

    同样的描述每次生成风格都在漂移，像在开盲盒，难以得到可预期的结果。

  • 3

    AI 塑料感重

    普通提示词工具只是做标签翻译，输出像乐高积木一样堆叠关键词，画面缺乏审美统一性。

"不是用户不会描述，而是现有的工具没有帮用户做'审美判断'。"
02 / SOLUTION

我们的解法

基于 VOS-玄造 V3 框架，把"审美路由"封装成产品。

审美先于细节

先判断画面整体审美路线（摄影真实 / 绘画插画 / 史诗概念 / 空间生态 / 氛围壁纸），再生成提示词。

注意力金字塔

确保第一眼有强视觉锚点，第二眼有叙事张力，最后留下情绪记忆，避免元素互相抢戏。

物理真实感

描述光学焦段、空间介质、材质摩擦，让画面更像真实摄影或绘画，消除 AI 塑料感。

03 / PRODUCT

产品形态与功能

一个单页 Web 应用，打开即用，专注于核心体验。

核心功能

  • 输入自然语言描述，一键生成高质量中文提示词
  • 内置 VOS-玄造 V3 审美路由 system prompt
  • 支持 OpenAI 格式 API，用户可接入自己的大模型 key
  • API 连接验证，确保服务可用
  • 历史记录折叠展示、分页管理、一键复制
  • 无需后端，前端直调 API，部署简单

04 / USERS

目标用户与使用场景

AI 绘画小白

想用豆包/即梦做头像、壁纸，但不知道怎么描述。在小红书、朋友圈看到好看的 AI 图，自己也想试试。

内容创作者

需要稳定风格的配图、封面、表情包。希望同一批内容保持视觉一致性，不用反复抽卡。

设计爱好者

对审美有要求，不满意 AI 塑料感。希望通过更好的提示词工程获得有质感的画面。

05 / VALUE

价值与意义

效率提升

把提示词工程的方法论封装成一键工具，小白用户从"反复试错"变成"一次生成可用"。

审美普惠

降低高质量 AI 生图的门槛，让更多人能表达自己的视觉创意，而不需要背诵大量英文标签。
