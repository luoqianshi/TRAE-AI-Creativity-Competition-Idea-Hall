一、产品理念

I. Product Philosophy

1.1 核心价值主张

1.1 Core Value Proposition

Pomodoro 番茄钟是一款基于番茄工作法（Pomodoro Technique）的专注工具，旨在帮助用户建立深度工作习惯，提升时间管理能力。我们相信：就像 Transformer 通过注意力机制捕捉关键信息一样，人的成就也来自于对当下任务的深度关注。注意力是最稀缺的计算资源，把它投入到正确的地方，才能产生最大的价值。

Pomodoro is a focus tool based on the Pomodoro Technique, designed to help users build deep work habits and improve time management skills. We believe: Just as Transformers capture key information through attention mechanisms, human achievement comes from deep focus on the present task. Attention is the most scarce computational resource—invest it wisely where it matters most.

番茄工作法核心原则： Core Principles of Pomodoro Technique:
  • 将工作时间分割为 25 分钟的专注时段（一个"番茄"）
  • Divide work time into 25-minute focused sessions (one "Pomodoro")
  • 每个番茄后休息 5 分钟，恢复精力
  • Take a 5-minute break after each Pomodoro to recharge
  • 每完成 4 个番茄，进行一次长休息（15 分钟）
  • After completing 4 Pomodoros, take a long break (15 minutes)
  • 一旦开始番茄，就要全心全意专注，直到时间结束
  • Once you start a Pomodoro, focus wholeheartedly until time ends

🖥️ 主窗口模式（Main Window）

🖥️ Main Window Mode

功能最全的模式，包含任务管理、设置、统计等所有功能。

The most comprehensive mode with task management, settings, and statistics.

6.2 颜色说明

6.2 Color Guide

Pomodoro 使用颜色直观传达计时器状态：

Pomodoro uses colors to intuitively convey timer status:

颜色 Color 含义 Meaning
● 红色 ● Red 工作计时中 - 番茄红，专注进行中 Work Timer Running - Tomato red, focusing
● 绿色 ● Green 休息计时中 - 恢复放松 Break Timer Running - Relaxing
● 灰色 ● Gray 暂停/停止 - 计时器待命中 Paused/Stopped - Timer idle
● 蓝色 ● Blue 系统时间显示 - 始终蓝色 System Time Display - Always blue

颜色规则：计时器文字、进度条和模式标签均跟随状态变化（工作红/休息绿/暂停灰），三者颜色保持一致。系统时间始终蓝色，不参与颜色变化逻辑。

Rules: Timer text, progress bar, and mode label all change with state (work=red/break=green/paused=gray) and stay in sync. System time is always blue, not part of the color-change logic.
