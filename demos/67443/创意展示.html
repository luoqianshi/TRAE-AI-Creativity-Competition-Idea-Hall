创意介绍

材料价格智能查询系统 是一款专为工业采购和工程师设计的 桌面端智能查询工具（Windows应用程序）， 旨在解决阀门、管件等工业材料价格查询效率低、SAP编码难记忆、多供应商报价对比繁琐的痛点。

核心功能

  • Excel数据源自动加载与多表关联
  • 多条件级联筛选与SAP编码匹配
  • DeepSeek AI智能解析材料描述
  • 一键导出查询结果

技术亮点

  • Python + PyQt6 原生桌面应用
  • AI驱动描述→SAP编码自动转换
  • 向量化数据处理，毫秒级响应
  • 延迟加载架构，启动快

目标用户及痛点

采购人员

每天需要查询数十种材料的供应商报价，手动翻阅Excel表耗时且容易出错，急需一个快速、准确的查询工具。

工程师

面对复杂的SAP编码（14位字母数字组合）难以记忆，需要一种方式用自然语言描述就能自动生成编码。

仓储管理

不同供应商对同一材料报价差异大，需要统一平台对比价格、运费、人工工时等信息。

使用场景： 采购人员收到工程师的材料需求单 → 输入材料描述或SAP编码 → 系统自动匹配所有供应商报价 → 快速比价并导出结果。
