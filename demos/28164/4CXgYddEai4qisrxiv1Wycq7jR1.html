项目概览

想解决
什么问题？

网络管理员在进行IP地址规划和管理时，面临IPv4/IPv6地址管理复杂、子网划分计算繁琐、地址冲突检测困难等痛点。

手动计算子网容易出错

尤其是IPv6地址，手动计算子网掩码、可用IP范围极易出错

缺乏可视化工具

难以直观了解网络拓扑结构和IP地址分布情况

地址冲突检测困难

冲突难以及时发现，容易导致网络故障和业务中断

多语言支持不足

国际化团队缺乏统一的多语言工具，协作效率低下

启动界面 — 星星重力弹弓粒子效果 + 网络拓扑预渲染

地址管理 — 树形网段结构 + IP地址生命周期管理

创意来源

为什么做
这个项目？

作为一名网络工程师，深知IP地址规划和管理的复杂性和容易出错的特点。传统手动计算方式效率低下，尤其是在大规模网络环境中。

技术驱动

利用 Python ipaddress 模块 + AI 智能算法，实现自动化的子网计算和方案评估

专业架构

分层架构设计（UI层 → 服务层 → 数据层），回调接口解耦，工厂模式管理导出器

桌面原生体验

基于 Tkinter/ttk 构建，支持高DPI适配，Nuitka 编译为原生可执行文件

四大功能模块

核心功能，一应俱全

地址管理、子网规划、子网切分、高级工具四大模块，覆盖IP地址管理全生命周期

地址管理 (IPAM)

SQLite 数据库驱动

树形网段结构管理，IP地址全生命周期管控（分配/保留/释放/过期），内置冲突检测、网络扫描、统计分析与网络拓扑可视化。

树形结构 冲突检测 网络扫描 统计分析 拓扑可视化

子网规划

AI + VLSM 优化算法

根据部门需求自动规划最优子网分配方案，支持需求池管理、VLSM优化计算、方案质量评估（0-100分），结果可一键导入IPAM。

VLSM优化 AI评估 需求池 分布图 导入IPAM

子网切分

精确切分 + 剩余网段计算

从父网段中精确切分指定子网，自动计算剩余网段列表，支持切分历史记录和重新切分，可视化分布图直观展示地址空间。

精确切分 剩余计算 历史记录 分布图

高级工具

IPv4/IPv6 双协议栈

IPv4/IPv6 地址信息查询（含多种格式转换、属性分析、RFC参考），子网合并、重叠检测，支持多格式数据导出。

IPv4查询 IPv6查询 子网合并 重叠检测 多格式导出
