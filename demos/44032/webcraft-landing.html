安装门槛高

Minecraft 需要下载数 GB 的客户端，安装 Java 环境，配置繁琐，劝退大量轻度玩家。

💻

原版游戏对显卡和内存要求不低，低配电脑、老旧笔记本、学校机房电脑难以流畅运行。

⏰

联机搭建难

和朋友一起玩需要搭建或购买服务器，配置端口、管理权限，技术门槛让普通玩家望而却步。

WebCraft 解决方案

用 Web 技术重新定义沙盒游戏体验

打开浏览器，就是整个世界

WebCraft 是一个基于现代 Web 技术构建的在线沙盒游戏平台。用户无需安装任何软件，只需打开浏览器访问网址，即可在几秒内进入一个完整的 3D 沙盒世界。

我们利用 WebGL/WebGPU 实现高性能 3D 渲染，通过 WebSocket 实现低延迟多人联机，使用 IndexedDB 实现本地存档，让"随时随地创造"成为现实。

无论是午休时间的 10 分钟，还是课间休息的 5 分钟，打开标签页就能继续你的建造之旅。

webcraft.game/play

多人在线联机

开发路线图

从原型到完整产品的演进计划

P1

原型验证阶段

实现基础 3D 渲染引擎、方块放置/破坏、简单地形生成，验证核心技术可行性。目标：浏览器中流畅运行 60fps。

P2

核心玩法阶段

添加生存模式、合成系统、昼夜循环、生物群系、基础 AI 生物。完善操作体验与 UI 界面。

P3

多人联机阶段

实现 WebSocket 多人同步、房间系统、好友邀请、聊天功能。优化网络延迟与同步策略。

P4

生态完善阶段

上线创意工坊、云端存档、用户系统、地图分享。开放模组 API，构建玩家社区生态。
