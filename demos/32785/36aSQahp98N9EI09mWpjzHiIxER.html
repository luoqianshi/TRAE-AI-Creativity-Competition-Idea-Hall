Problem

桌面效率的困境

日常办公中，我们总是在不同工具间反复切换，效率在无形中被消耗

! 之前的体验

  • 1计算器、翻译、剪贴板分散在不同软件，来回 Alt+Tab
  • 2临时文件堆满桌面，找的时候找不到，删的时候不敢删
  • 3截图后需要打开画图或聊天窗口才能粘贴保存
  • 4日程提醒淹没在浏览器标签和系统通知里
  • 5各种小工具窗口占满桌面，杂乱无章
  • 6微信、QQ 消息弹窗不断打扰，右下角通知混乱
  • 7播放音乐时不知道当前曲目，切歌要打开播放器

✓ 有了 Task Island

  • 1悬浮胶囊常驻桌面，点击展开所有工具，零切换成本
  • 2文件拖到侧岛暂存，生成圆形图标，随时取用
  • 3一键截图直接保存或复制到剪贴板，无需中转
  • 4日程与剪贴板历史集成在同一面板，一目了然
  • 5紧凑胶囊仅占 180 像素宽度，几乎零空间占用
  • 6系统通知全部接管到胶囊，微信 QQ 消息统一收纳
  • 7播放音乐时胶囊中央显示音浪，实时感知音频状态

形态切换

双形态悬浮设计

紧凑胶囊常驻屏幕顶部居中，仅显示当前时间与状态指示灯。点击后以 CubicBezier 缓动曲线流畅展开为多功能面板，所有工具一触即达。

  • 紧凑态 180×36 胶囊，AcrylicBlur 毛玻璃背景
  • 展开态 420×260 面板，8 宫格模块布局
  • 展开动画 CubicBezier(0.32, 0.72, 0.0, 1.0)，0.3s 过渡
  • 收起动画 CubicBezier(0.4, 0.0, 0.2, 1.0)，弹性回弹
  • Topmost 置顶，不被其他窗口遮挡
  • 支持拖拽移动，松手自动吸附顶部居中

文件暂存

文件暂存侧岛

将任意文件拖拽到展开面板区域，侧岛自动生成圆形图标暂存。支持图片、文档、表格等多种格式，点击图标即可打开原始文件。

  • 拖拽文件到面板，自动识别文件类型并提取系统图标
  • 生成 28×28 圆形图标，弹性入场动画
  • 入场曲线 CubicBezier(0.34, 1.56, 0.64, 1.0)，带回弹效果
  • 点击图标直接打开文件，右键菜单可移除
  • 暂存列表通过 ObservableCollection 持久化

内置工具

科学计算器

  • 支持 + - × ÷ 四则运算与括号嵌套
  • 自动计算结果，实时显示在面板顶部
  • 支持小数精度控制，避免浮点误差
  • 计算历史自动保存，可回溯查看
  • 键盘输入支持，效率翻倍

  • 天气小组件：实时温度、湿度、空气质量

  • 待办速览：今日待办事项数量与优先级
  • 小组件支持拖拽排列，自定义布局

文件管理

桌面文件整理区

胶囊展开后可切换至文件整理模式，自动识别桌面文件并按类型分类收纳到虚拟文件夹中。文档、图片、视频、压缩包各归其位，桌面瞬间清爽。

  • 自动扫描桌面文件，按扩展名智能分类
  • 虚拟文件夹：文档、图片、视频、音频、压缩包、其他
  • 一键整理：自动将文件移入对应分类文件夹
  • 快速搜索：输入文件名关键词即时定位
  • 支持自定义分类规则与文件夹名称

媒体联动

音浪可视化

当电脑播放音频或音乐时，紧凑胶囊中央自动显示动态音浪效果。实时感知音频节奏，无需打开播放器即可知道当前播放状态。

  • 实时捕获系统音频输出，生成频谱可视化
  • 紧凑胶囊中央显示动态音浪条，随节奏跳动
  • 支持显示当前播放曲目与艺术家信息
  • 点击胶囊可快速暂停/播放、切换上一首/下一首
  • 兼容主流播放器：网易云、QQ音乐、Spotify 等

隐私守护

设备状态指示

当麦克风、摄像头、屏幕录制等设备被使用时，胶囊侧边自动显示彩色状态指示点。一眼便知哪些设备正在工作，守护你的隐私安全。

  • 麦克风使用时显示橙色呼吸灯，录制中一目了然
  • 摄像头开启时显示青色呼吸灯，防止偷窥
  • 屏幕录制时显示红色呼吸灯，提醒内容被记录
  • 点击状态点可快速关闭对应设备或查看占用进程
  • 支持自定义指示灯颜色与闪烁频率

通知接管

系统通知中心

接管 Windows 右下角所有系统通知，微信、QQ、邮件、日历提醒统一收纳到胶囊通知中心。告别弹窗打扰，消息集中管理，像手机一样优雅。

  • 拦截所有 Windows Toast 通知，统一收纳到胶囊
  • 微信、QQ、钉钉消息按应用分组显示
  • 支持消息预览、快捷回复、一键已读
  • 勿扰模式：工作时间自动静音非紧急通知
  • 消息历史记录，支持搜索与回溯
