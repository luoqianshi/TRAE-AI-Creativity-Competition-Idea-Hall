// Problem Analysis

四大决策困境

站在人生路口，每个大学生都在经历的迷茫

🧩

信息严重碎片化

就业数据在招聘网站、院校报录比在研招网、行业薪资在猎聘、经验贴在知乎...学生需要跑N个平台才能拼凑出一张完整图景，信息搜集耗时耗力。

⚠ 平均每个学生搜集决策信息耗时 120+ 小时
🗣

建议互相矛盾

学长说"必须读研才有出路"，辅导员说"先就业再读在职更现实"，父母说"读研稳妥"，同学说"就业能早赚钱"。每个人的建议都基于个人经验而非客观数据。

⚠ 83% 的学生收到的建议来自"身边1-3个人"
⚖

无法量化比较

考研的机会成本（1-3年时间+学费+错过校招）vs 就业的机会成本（学历天花板+起薪差距），很难直观比较。学生只能凭感觉做决定。

⚠ 超过 60% 的学生承认自己"没有认真算过这笔账"
🔄

缺乏动态调整

跟风考研3个月后发现坚持不下去，但此时秋招已过、春招名额有限；匆忙就业后发现学历不够又回头考研。没有工具能帮你重新评估和及时调整方向。

⚠ 约 35% 的考研学生在备考中途产生过放弃念头

// Core Features

六大核心功能

数据驱动 + AI 分析，让决策从"凭感觉"到"靠数据"

📊

八维度个人画像

采集专业背景、GPA、英语、实习、科研、家庭支持、性格特质、目标院校8个维度，构建完整的个人决策画像。

🧠

AI 四维度评分模型

从"成功概率""机会成本""长期收益""风险等级"四个核心维度分别计算考研和就业的得分，雷达图直观对比。

📈

全国大数据支撑

整合全国各专业就业率、平均薪资、院校报录比、录取分数等多源数据，分析结果基于真实市场数据而非主观臆断。

🔄

动态重新评估

用户可随时更新状态（如"秋招0 offer""备考3个月进度"），AI即时重新计算并调整建议方向，避免"一条路走到黑"。

📋

行动计划生成

不仅告诉你"该考研还是就业"，还生成具体的备考时间线或求职路线图，包括目标院校/公司清单和阶段性任务。

🏫

班级决策看板

辅导员管理后台，一键查看全班学生的决策分布、风险预警名单和高危学生（如"盲目考研成功率<20%"），精准施策。
