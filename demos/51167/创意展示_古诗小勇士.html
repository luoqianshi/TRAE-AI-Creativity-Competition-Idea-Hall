1创意名称 + 创意介绍

🎨 创意名称

古诗小勇士

🤔 想解决什么问题

学龄前儿童（3-6岁）学习古诗和成语主要靠死记硬背，枯燥乏味，注意力最多维持几分钟。家长想让孩子接触传统文化，但找不到既有趣又适龄的学习方式。我们需要一个像玩游戏一样轻松、像看动画一样好看的古诗成语学习工具。

💡 为什么会想到做这个

我观察到很多小朋友对手机游戏很感兴趣，但市面上的儿童教育 App 要么广告太多，要么操作太复杂。古诗和成语是中华文化的根基，如果能把它们变成"闯关游戏"，让孩子觉得"答对了就有星星"，学习就不再是任务，而是一场冒险。

📦 大概是什么产品

一个纯前端网页互动教育小游戏，用浏览器打开即玩，无需安装，内置 300 首古诗，包含古诗连连看和成语小火车两种游戏模式。

2目标用户及痛点

👶 面向哪些用户

3-6岁学龄前儿童，以及希望孩子接触传统文化的家长。核心用户是正在幼儿园或即将进入小学的孩子们。

📍 在什么场景下使用

  • 晚上睡前，家长陪孩子玩 10 分钟古诗闯关
  • 周末闲暇，孩子自己拿着平板玩成语游戏
  • 幼儿园课堂上，老师用大屏投影作为互动教具
  • 长途出行，孩子在车上用家长手机打发时间

😣 当前痛点

市面上的儿童古诗 App 大多是"播放视频+跟读"的单向模式，孩子只是被动接收，没有互动感。成语学习书更是以文字为主，学龄前孩子根本看不懂。家长想要的是"孩子愿意主动玩、玩的过程中自然记住"的产品，而不是另一个需要监督完成的"作业"。

3核心功能

📖 古诗连连看

播放古诗朗读，显示上半句，从 3 个选项中选择正确的下半句。答对获得"文化星"和经验值，答错显示鼓励星和正确答案提示，不惩罚。

🚂 成语小火车

将成语的汉字打乱，孩子按正确顺序点击排列。如"画蛇添足"打乱后变成"添画足蛇"，孩子需要调整顺序还原。操作简单，适合幼儿点击。

🔊 语音朗读

使用 Web Speech API 朗读古诗和成语，孩子可以边听边学。对于识字能力有限的学龄前儿童，语音是极其重要的学习通道。

⭐ 图标收集与升级系统

答对积累"文化星"和经验值，达到一定经验后升级解锁新称号（小诗人、小学士、小状元等）。连续打卡解锁特殊图标，激励孩子坚持每日学习。

🐱 卡通角色陪伴

小猫、小熊、小兔等卡通角色全程陪伴，答对时鼓掌、答错时鼓励。角色可自由切换，增加孩子的归属感和互动乐趣。

4价值与意义

🌈 社会价值

古诗和成语是中华传统文化的重要载体，但低龄化、游戏化的传播方式非常稀缺。"古诗小勇士"用零门槛的网页游戏形式，让孩子在最轻松的互动中建立对古诗成语的第一印象，在娱乐中完成文化启蒙，降低传统文化教育的年龄门槛。

🌱 习惯培养

游戏化的即时反馈（答对得星星、通关有庆祝）符合儿童心理学中的正反馈机制。连续打卡解锁图标的设计，帮助孩子建立"每天学一点"的文化学习习惯，让传统文化学习不再是一次性任务，而是持续的日常习惯。

5技术实现与 AI 参与

🛠️ 技术方案

纯前端实现，单个 HTML 文件即可运行，无需后端服务。使用 HTML5 + CSS3 + Vanilla JavaScript 技术栈，语音通过 Web Speech API 朗读，300 首古诗数据内置在代码中，进度通过 localStorage 本地持久化，响应式设计同时支持 PC 和移动端。

🤖 AI 辅助创作的角色

零基础的参赛者，在 TRAE 的 AI 辅助下完成了完整的游戏开发。从创意落地、题库设计、界面美术到代码实现，全程由 AI 协助编程、调试和优化。展示了 TRAE 降低创作门槛的核心能力——让不懂代码的人也能把教育创意变成现实。
