01

创意介绍

发现问题、寻找灵感、定义产品

🎯

想解决什么问题

传统休息提醒工具使用固定间隔，不管你当前在做什么，到时间就提醒你。但编码45分钟的疲劳程度远高于浏览网页45分钟，现有工具无法区分。

💡

灵感来源

日常开发中同时使用 ActivityWatch 记录时间和 Focust 提醒休息，两个工具数据不互通。一个只记录不干预，一个干预却不关心你在做什么。

🖥️

产品形态

Windows 桌面应用，后台静默采集活动数据，基于实际工作状态智能调度休息提醒，让休息提醒真正"懂你"。

02

核心功能

四大核心模块，打造智能休息体验

📊
自动活动追踪

静默采集，本地存储

后台静默采集活动数据

无需手动记录，系统自动追踪窗口标题、应用名称、AFK状态和浏览器标签页，所有数据仅存储在本地 SQLite 数据库。

  • 窗口活动追踪（每3秒采集）
  • AFK 状态检测（每2秒检测）
  • 浏览器标签追踪（每5秒采集）
  • 本地 SQLite 存储，隐私安全
🧠
智能休息调度

基于活动动态调整

基于活动类型的智能调度

不再是固定25分钟的番茄钟，而是根据你当前的活动类型动态计算最佳休息时间。

  • 编码类活动 ×0.8 系数（更容易疲劳）
  • 浏览类活动 ×1.2 系数（相对轻松）
  • 连续工作超60分钟强制提醒
  • AFK恢复后自动补偿休息时间
⏰
灵活提醒系统

多种模式，贴心提醒

不打扰的提醒体验

短休息20秒不中断工作流，长休息5分钟建议离开屏幕，支持推迟、严格模式和全局热键。

  • 短休息 / 长休息两种模式
  • 根据活动类型推荐休息建议
  • 全局热键快速操作
  • 全屏/演示时自动暂停
📈
可视化报告

数据洞察，持续优化

清晰的数据洞察面板

通过可视化图表了解自己的工作效率和休息习惯，持续优化工作节奏。

  • 应用使用时间饼图
  • 一周专注趋势折线图
  • 休息效率统计分析
  • JSON / CSV 数据导出
03

目标用户与场景

为长时间使用电脑的人群打造

👨‍💻

开发者 / 程序员

连续编码场景

连续编码45分钟后，系统自动提醒站起来走走、做眼保健操。解决写代码太投入忘记休息，导致肩颈酸痛、眼睛干涩的问题。

📖

学生 / 备考人群

长时间学习场景

学习2小时后收到长休息提醒，建议去散步放松。解决长时间刷题效率下降，没有科学学习节奏管理的问题。

✍️

自由职业者 / 创作者

自由工作场景

写作/剪辑过程中智能感知疲劳，推荐合适的休息方式。解决自由工作时间长但不规律，容易过度劳累的问题。

🔴 当前痛点（没有 FocusFlow 的情况下）

• 番茄钟一刀切：不管你在做什么，到25分钟就打断

• ActivityWatch 只管记录不干预

• Focust 会提醒但不知道你在做什么

• 多个工具数据不互通，信息孤岛

04

价值与意义

效率提升与健康守护的双重价值

📈 效率提升价值

基于实际活动数据智能调度休息，避免无效打断。研究表明合理休息可使工作效率提升 15-20%，FocusFlow 让休息变得更聪明——在你真正需要的时候提醒，而不是机械地到点就响。

🏥 健康社会价值

久坐和过度用眼已成为现代职场人的普遍健康问题。FocusFlow 通过"活动感知+智能提醒"帮助使用者建立健康的工作节奏，减少颈椎病、干眼症等职业病的发生概率。
