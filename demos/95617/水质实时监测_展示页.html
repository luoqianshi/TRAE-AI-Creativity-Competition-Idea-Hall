// Problem Analysis

四大饮水盲区

肉眼看不见的水质问题，每天都在发生

💧

水质"盲饮"成常态

绝大多数家庭对自来水水质一无所知。TDS是否超标？余氯是否过量？管道老化是否导致重金属渗漏？全靠"看着清就是干净"的错觉。

⚠ 全国约15%城市供水管网老化，二次污染风险高
🔄

滤芯更换"凭感觉"

净水器滤芯更换提示完全基于倒计时或流量计数，不关心实际水质。导致"净水达标但滤芯已换"浪费钱，或"滤芯失效但提示未到"喝脏水。

⚠ 平均每户每年多花 200-500 元在过早更换滤芯上
🧪

检测手段太原始

市面上TDS检测笔需手动舀水、逐次测量，操作繁琐且数据不连贯。多数产品不支持余氯检测，更无历史数据记录和趋势分析。

⚠ 仅 3% 的家庭拥有水质检测工具，且使用频率极低
🏢

公共饮水巡检难

学校、办公楼、社区公共饮水点数量多分布散，物业巡检依赖人工逐点检测，效率低、成本高、数据滞后，无法做到实时预警。

⚠ 大型社区日均饮水点超 50 个，人工巡检覆盖率不足 30%

// Core Features

六大核心功能

硬件+AI 深度协同，让水质"看得见"

💧

三合一传感器模组

集成 TDS 电导率传感器（精度 0.1ppm）、电化学余氯传感器（精度 0.01mg/L）、NTC 温度传感器，单次水流同步采集三组数据。

💡

环形 LED 直观显示

RGB 可编程 LED 灯环，绿色（优质）→ 黄色（注意）→ 红色（超标）三色直观反馈水质等级，无需打开手机即可了解水质。

🧠

AI 滤芯寿命评估

基于实际水质数据（而非倒计时）评估滤芯真实剩余寿命，既避免过早更换浪费，也防止失效后继续使用。

📱

App 云端数据平台

蓝牙/Wi-Fi 双模连接，水质数据自动同步云端。支持历史趋势图表、水质日报、异常告警推送和滤芯更换提醒。

🔋

水流自发电 + 超低功耗

内置微型水流发电机，利用水流动能自主供电，无需外接电源或频繁换电池。待机功耗低于 0.1mW。

🏢

物业版批量巡检

社区/学校/办公楼多饮水点统一管理，云端地图展示各点水质状态，异常即时预警，巡检效率提升 80% 以上。
