右键收藏

在网页上看到任何内容——一段文字、一张图片、一个链接。右键点击"发送到拾光"，瞬间保存。不打断你正在做的事。

看到喜欢的 → 右键 → "发送到拾光" ✓
🧺

打开口袋

点击浏览器插件图标，所有收藏的东西都在一个口袋里。按时间排列，支持搜索，像翻自己的抽屉。

插件图标 → 弹出面板 → 浏览所有收藏
📦

一键打包

选中需要的内容，一键导出。文字变成 Markdown 文档，图片打包下载。零散的东西，终于变成可用的材料。

批量选择 → 导出 Markdown / 图片 → 下载完成
