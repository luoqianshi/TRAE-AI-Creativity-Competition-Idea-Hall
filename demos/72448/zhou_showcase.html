作品简介

《周》是一款面向青少年的互动叙事游戏。玩家扮演一名高中生，经历从周一到周六的一周校园生活。在一次次看似平常的选择中，逐步看见自己的睡眠、饮食、运动、情绪、社交和自我认同状态。

游戏没有说教，没有正确答案。它只是诚实地呈现：当你习惯性地选择"再看一个视频就睡"、"今天不想吃饭"、"不去运动了"时，一周后会发生什么。

核心玩法

  • 多分支叙事：不同选择导向不同结局，没有标准答案
  • 角色羁绊：与三位同学（陆晨、苏晚、陈一鸣）的互动影响故事走向
  • 数值可视化：六个健康维度实时变化，直观呈现选择后果
  • 多结局系统：好结局 / 普通结局 / 5个特殊结局，结局由你书写
  • 完整游戏系统：存档读档、快进自动、历史回溯、图鉴收集、全屏窗口切换

技术实现

  • 纯前端单文件：一个 HTML 文件，浏览器打开即玩，无需安装部署
  • 原生技术栈：HTML + CSS + JavaScript，零外部依赖
  • 本地存档：localStorage 持久化，40个存档位，图鉴解锁记录
  • 响应式设计：支持全屏/窗口模式切换，适配不同设备
  • 交互优化：快进、自动播放、右键/Esc返回、全屏点击推进

社会价值

游戏的设计初衷不是"教育"青少年，而是让青少年在游戏体验中产生共鸣。

看到自己熬夜刷手机时的内心独白，体会到"假装没事"背后的情绪消耗，理解健康不是"不生病"，而是"有力量去面对每一天"。

这些体悟来自真实的青少年生活观察，而非成人的居高临下。
