PART 01

创意是什么

一个让每个人都能轻松搭建个人空间的开源系统

💡

想解决什么问题

短视频时代，博客似乎已成"落幕时代"。开发者想有一个自己的空间分享技术心得，普通人想记录生活随笔，却被复杂的建站配置、数据库、域名备案、主题选择拦住了脚步。WordPress 太重，Hexo 要折腾，Notion 无法完全自定义——最终很多人选择放弃："算了，我不写了。"

🌟

为什么会想到做这个

从 WordPress 到 Hexo 再到纯手写 React，每一次都在重复"造轮子"。身边有太多朋友说："我也想有个自己的小站，但太麻烦了。"博客时代虽在落幕，但人们记录与表达的渴望从未消失——我想在这黑夜里，点起一盏让每个人都能轻松靠近的灯。

🏠

大概是什么产品

一套开箱即用的个人作品集 + 博客系统（React + Vite + Tailwind CSS 网站模板）。用户只需修改一个配置文件，就能拥有：Markdown 博客、技术栈展示、项目作品、时间线、音乐播放器、3D 地球联系页、多主题切换、炫酷动效——完全无需写一行代码。

核心技术栈

React 19 Vite 8 Tailwind CSS Framer Motion Three.js Markdown SEO Ready Responsive

PART 03

价值与意义

不止是一个技术项目，更是一场"让表达回归简单"的小实验

效率提升

从数周到半天

将原本需要花费数周甚至数月的"从零搭建个人站点"，缩短到"修改配置文件 → 部署上线"的半天过程。开发者无需重复造轮子，非技术用户也能轻松拥有自己的网络空间。项目内置了 SEO 优化、响应式布局、Markdown 内容管理，用户只需专注"写内容"这件事本身。每一位被建站门槛拦住的创作者，都值得拥有一个简单、优雅、自由的起点。

社会价值

黑夜中的一盏灯

在算法推送主导的互联网时代，博客代表着"慢思考"和"独立表达"。当每个人都在刷短视频、被推荐算法推着走的时候，有一个属于自己的小空间，慢慢记录、慢慢思考，本身就是一种抵抗——抵抗碎片化，抵抗被流量绑架。

通过开源这套系统，让更多人能拥有一个不被流量绑架、不被算法裹挟的写作空间。每个人记录的文字，就像黑夜中的一盏灯——微弱但温暖，当无数盏灯亮起时，便是星空。

项目将完全开源免费，用最低门槛，让"记录自己"这件事变得触手可及。不为流量，不为变现，只为让每一个想表达的声音都有处可栖。
