Core Tech / 自研底层架构

ARF 架构：赋予 AI 真正的“灵魂”与“边界”

没有去套壳，而是自研了 Agent 运行时操作系统（ARF）。将 Agent 从“混乱的脚本”升级为“配置驱动、完全白盒化”的现代系统。

ARF Trace & Guardrails

从“黑盒盲盒”到“白盒可控”

ARF 将 Agent 定义为事件驱动的运行时。每一次思考和工具调用都像“飞机黑匣子”般被完整记录。内置安全护栏，在用户极度负面情绪下试图清空文档时触发拦截与“冷静期”，因为绝对安全，才敢真正当助手。

ARF Memory Plugin

长期记忆，深度共情

借助原生长期记忆插件，VibeMate 记住你的考研目标、过去的失败和闪光时刻。当你气馁时，它不说空洞鸡汤，而是说：“你上个月期末考也熬了三个大夜最后拿了 A，这次我们也一定行。”

ARF Eval & LLM Judge

情绪价值可衡量，科学迭代

怎么证明 AI 提供了情绪价值？ARF 内置完整的评估系统，通过“大模型做裁判”自动对回复的“共情度”打分。精准知道哪种干预策略最能降低焦虑指标，让情绪价值的提供也变得科学、可量化。

ARF agent.yaml

配置即灵魂，极简扩展

Agent 的全部行为由一份 YAML 定义。这意味着我们可以一键切换 VibeMate 的人格：今天是“温柔知心学姐”，明天是“严厉项目经理”。具备极强的可扩展性和矩阵化变现能力。
