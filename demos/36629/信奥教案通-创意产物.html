OI-Teach Generator

输入一份题单，AI 自动生成完整专题教学资料——讲义 + 教案。
从四年级零基础到冲刺金牌，说人话、配图示、全路径覆盖。

Core Flow

产品核心流程

01

输入题单 + 专题名称

提供完整题面（题目描述、输入输出格式、样例、数据范围）和专题名称，如 动态规划入门

02

AI 划分子考点，教练确认

AI 根据题面判断每道题隶属的子考点，生成知识点划分方案供教练确认和调整

03

生成讲义

知识点讲解（生活化类比 + 图示）→ 例题精选 → 训练题分配 → 详细题解 → 金牌风格 AC 代码

04

派生教案

从讲义素材自动派生教案：教学目标、课时安排、重难点提示、课堂节奏建议

05

人工验证 + 修正

教练验证代码正确性，发现问题可提供正确代码请求 AI 修正输出

Pain Points

当前痛点

01

备课耗时巨大：教练需要逐题分析知识点归属、编写讲解、写 AC 代码，一份专题教案往往要 2-3 天

02

题单 ≠ 教学资料：现有题单只是题目堆叠，没有知识体系、没有分层讲解、没有详细题解，学生无法直接自学

03

新手教练缺拐杖：很多学校的信息学教练是兼职教师，自身竞赛经验有限，缺乏高质量参考资料支撑教学

04

AC 代码风格参差：网上题解代码质量不一，学生模仿了不好的代码风格，影响后续发展

05

资料不说人话：大多数算法讲解过于学术化，四年级学生根本看不懂，缺少生活化的类比和图示

06

阶段断层：入门资料和竞赛资料之间缺少衔接，学生学完基础后不知道怎么过渡到竞赛水平

07

竞赛技巧缺失：现有资料偏重算法本身，缺少初赛应试技巧、复赛策略、时间分配、骗分方法等实战内容

Standards

讲义生成标准

STD-01

说人话

所有讲解用通俗易懂的语言，避免学术黑话，算法原理用生活化类比讲清楚

图示辅助

算法推演、状态变化、数据结构操作等关键过程必须配图示，让学生"看得见"每一步

STD-03

全路径覆盖

从 C++ 语法零基础到金牌级算法，一个工具覆盖完整学习路径

变量 → 网络流 → 计算几何
STD-04

竞赛实战

包含初赛选择题技巧、复赛答题策略、时间分配、骗分/部分分、对拍调试等竞赛必备能力

骗分技巧 / 对拍脚本

分层友好

3// 想象你在翻一本字典找"苹果"这个词：
4// 你不会从第一页开始翻，而是直接翻到中间——
5// 如果中间页的字母比"A"大，说明"苹果"在前半部分，
6// 否则就在后半部分。每次排除一半，这就是二分！
7
8int binarySearch(int a[], int n, int target) {
9 int lo = 0, hi = n - 1;
10 while (lo <= hi) {
11 int mid = (lo + hi) / 2; // 翻到中间页
12 if (a[mid] == target) return mid; // 找到了！
13 else if (a[mid] < target) lo = mid + 1; // 在后半部分
14 else hi = mid - 1; // 在前半部分
15 }
16 return -1; // 没找到
17}
