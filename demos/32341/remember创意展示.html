1. 创意名称 + 创意介绍

创意名称

Remember - 智能记忆辅助工具

想解决什么问题

备考人群面临海量知识点记忆压力，传统记忆方法效率低下，现有工具存在"界面僵化"与"跨端割裂"问题，无法提供流畅高效的学习体验。

为什么会想到做这个

看到身边很多朋友备考时反复背诵却效果不佳，同时市面上的记忆工具要么操作复杂，要么跨端体验差，于是萌生了打造一款更智能、更稳定、更灵活的记忆工具的想法。

大概是什么产品

一款基于 FSRS 间隔重复算法的跨端记忆辅助工具（Android App + Windows 桌面客户端），帮助用户高效记忆知识点。

什么是 Remember？

想象一下，你正在备考，面对海量知识点：历史年代、法律条文、英语单词... 记了又忘，忘了又记，效率低下。

Remember 就是来帮你解决这个问题的。它是一款基于科学记忆原理打造的智能学习工具，核心采用了目前最先进的 FSRS 间隔重复算法。简单来说，它会根据你的记忆状态，在最合适的时间提醒你复习，让你用最少的时间记住最多的内容。

它能帮你做什么？

📝 创建卡片

支持图文混排、数学公式、代码高亮，轻松记录任何知识点

🧠 智能复习

FSRS 算法自动安排复习时间，每次只需判断"记住了"或"没记住"

📊 学习统计

可视化展示学习数据，热力图记录你的坚持轨迹

🔄 跨端同步

手机和电脑的数据实时同步，一次录入全平台使用

🎨 高度自定义

自由调整界面布局，打造专属学习体验

技术栈

Capacitor Electron React TypeScript FSRS Tailwind CSS

2. 目标用户及痛点

面向哪些用户

考公、考编、考研及各类职业资格考试群体，以及需要系统记忆知识的终身学习者。这类用户面临海量知识点的记忆压力，对提升学习效率有强烈需求。

在什么场景下使用

通勤路上用手机碎片时间复习、自习室用电脑深度制卡、在家休息时轻松巩固、未来支持小组学习分享卡组。

当前痛点

⚠️

效率低下

传统死记硬背效率低，记忆留存率差，浪费大量时间。

💔

体验割裂

许多工具在电脑端常出现闪退、数据丢失，移动端和桌面端数据不同步。

🔧

操作繁琐

界面固定死板，高频功能藏得深，增加学习操作摩擦。

📱

跨端缺失

部分工具仅支持单一平台，无法实现多设备协同学习。

💎

3. 价值与意义

效率提升：重构记忆工作流

Remember 的核心价值在于将"记忆科学"与"工具效率"完美结合。

🧠 算法层面

引入 FSRS 算法，相比传统 SM-2 算法，能以更少的复习次数达到更高的记忆留存率，直接减轻用户的记忆负担。科学研究表明，间隔重复学习法能将记忆效率提升 3-5 倍。

🎯 交互层面

通过"桌面端专注制卡 + 移动端随时复习"的分工，以及"高度自定义界面"，消除工具本身带来的干扰，让用户的注意力只集中在知识点本身。

商业价值：构建双边市场

🎯

精准流量入口

考公/考研群体是高净值、高粘性的用户群体，对提升学习效率有强烈的付费意愿。稳定的跨端体验是打破现有市场格局的关键切入点。

🔄

生态闭环

未来规划的"卡组市场"不仅仅是内容仓库，更是连接"内容生产者"与"内容消费者"的双边平台。通过让优质知识变现，激励更多高质量内容的产生，形成竞争壁垒。
