PAIN POINTS
📋

待办 App 千人一面

清单越来越长，任务越堆越多， 传统日程工具只问"做了没"，从不问"你适合怎么做"。 INTJ 和 ENFP 用同款清单，显然不合理。

# 千人一面# 不懂你# 易放弃
🧠

MBTI 只是聊天话题

你做过 MBTI 测试，知道自己是 INTJ 或 ENFP， 但这些标签除了聊天，无法指导你的日常任务安排—— 你不知道该按什么顺序做、该拆成几步。

# 标签无用# 无法行动# 浪费潜力

通用 AI 能给出漂亮的方案，却不知道你是熬夜型还是早起型， 不知道你压力大时喜欢独处还是社交。 通用 ≠ 适合你，真正有用的 AI 是"你的 AI"。

AI 能力全景

AI ENGINE

🤖 越用越懂你的 AI 引擎

AI 不只是帮你列清单——它是你的"MBTI 策略参谋"。 你每打一次卡、每完成一个任务，AI 都在悄悄更新对你性格的判断， 然后反过来优化你的日程安排。这是一个正向飞轮：记录越多 → AI 越懂你 → 策略越准 → 完成越多。

🧩
智能拆解

大目标一键拆成 5-7 步微步骤，每步 ≤30 分钟，降低启动门槛。

// 例：准备考研 → 收集院校信息 (25min) → 制定复习大纲 (20min) → 英语单词 × 50 (30min) → 数学第一章入门 (28min)
📦
一键整理

混乱清单秒变清晰：去重、合并、归档、AI 推荐"可以放弃的事"。

// 23 个任务 → focus(7) + defer(6) + archive(10) // 今天只做 7 件 // 其他的自动挪位
🎭
性格化排序

基于 MBTI 调整任务顺序，让你用最舒服的节奏进入状态。

// INTJ：难 → 易 // ENFP：易 → 难 → 探索 // ISFJ：紧急 → 重要 → 细节 // ENTP：创意 → 执行 → 复盘
💗
情绪感知调度

心情低落时自动后推难任务、前置轻松事，不硬撑也不躺平。

mood: low → P0社交任务 → 延后 P2整理型任务 → 前置 建议: 先散步20分钟
🔗
跨域因果分析

把待办压力、情绪状态、作息习惯交叉分析，找到"为什么"。

deadline×3 + sleep<4h → mood: low (87%相关) → plan: 今日任务减半 → 建议: 优先睡够
🩹
定制疏导建议

基于性格和情绪给"今天就做一步"的小动作，可执行、不鸡汤。

INFP + sad → ① 去阳台晒5分钟太阳 ② 给自己泡一杯茶 ③ 今天只做1件小事 // 不说"加油"，说"歇会"

以深紫夜色为底，像素荧光绿为点缀，奶黄纸感为内容载体—— 像一家深夜亮着灯的小店，温暖、可靠、治愈。

📐 6 条设计原则

  • 像素粗描边：所有元素 2-3px 深色描边 + 硬阴影
  • 卡片纸感：内容区用奶黄纸色，增加真实感
  • 仪式感动画：出票机、成就解锁都有小动画
  • 轻量 30 秒：打卡只需 30 秒，降低门槛
  • 收集感：小票/徽章/等级，越用越有成就感
  • 越用越懂：AI 建议随数据积累持续优化
