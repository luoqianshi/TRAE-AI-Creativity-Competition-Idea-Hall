Claude 3D Assistant

Android 3D 虚拟助手 · 多模型对话 · 离线语音合成 · 工具调用

项目简介

Claude 3D Assistant 是一款 Android 平台的 3D 虚拟助手应用，使用 Kotlin 与 Jetpack Compose 开发。应用集成了多厂商 AI 对话、3D 角色展示、语音输入输出、离线中文语音合成和工具调用等功能，面向移动端 AI 助手交互场景。

用户可通过文本或语音与 AI 进行多轮对话，3D 角色会根据 AI 回复的情绪倾向实时切换表情与动画状态，同时支持语音播报回复内容，提供沉浸式的交互体验。

核心功能

  • 多模型 AI 对话 — 支持 Anthropic Claude、OpenAI、DeepSeek、硅基流动、Ollama 等多厂商接口，兼容 OpenAI 协议，流式回复实时展示
  • 3D 虚拟角色 — 基于 SceneView (Filament) 渲染 GLB/GLTF 模型，支持情绪状态联动与 Lottie 动画叠加
  • 语音交互 — 集成 Android SpeechRecognizer 实现语音输入，支持系统 TTS 与 Sherpa-ONNX 离线中文 TTS 双引擎
  • 工具调用 — 内置 14 项 Android 原生工具，AI 可主动调用获取设备信息、管理文件、启动应用、读写剪贴板等
  • 情绪识别 — 基于文本分析识别 AI 回复的情绪倾向，实时切换角色表情与动画状态
  • 数据持久化 — 聊天记录与用户设置通过 DataStore 本地存储，支持多轮上下文连续对话
  • Markdown 渲染 — AI 回复支持富文本展示，包含代码高亮、列表、标题等格式
  • 设置管理 — 提供设置页统一管理 API Key、模型选择、Base URL、Temperature、Max Tokens 与系统提示词

对话处理流程

用户通过文本或语音发起对话，应用根据设置的接口协议（Anthropic / OpenAI）构建请求，经 SSE 流式通道传输至 AI 服务端。返回的回复内容实时展示在界面上，若 AI 触发工具调用则在本地执行对应操作后将结果回传继续对话。同时，情绪识别模块分析回复文本，驱动 3D 角色切换表情，语音引擎朗读回复内容。

运行说明

  • 使用 Android Studio 打开项目
  • 确保 app/libs/sherpa-onnx-1.13.3.aar 本地依赖存在
  • 若需离线语音，确保 assets/sherpa-onnx-vits-zh 模型文件完整，或执行 scripts/download_tts_model.ps1 下载
  • 在应用设置页填写 API Key 并选择模型
  • 构建并运行应用（debug 或 release）
