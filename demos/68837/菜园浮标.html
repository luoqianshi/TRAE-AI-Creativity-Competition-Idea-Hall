菜园浮标

【社会服务】用AR眼镜帮老人把菜园“种进”社区闲置角落，让滞销农产品变邻里共享菜箱

标签：社会服务

🌱

1. 创意名称 + 创意介绍

创意名称：菜园浮标

想解决什么问题：

城市老旧小区常有废弃花坛、闲置空地、屋顶边角等资源长期荒废；同时周边农户蔬菜滞销，而社区老人买菜远、不会网购、又舍不得丢剩菜。供需错配导致食物浪费+空间浪费双重问题。老人有种植经验却无地可用，有互助意愿却缺乏组织抓手。

为什么会想到做这个：

走访成都玉林社区时发现：78岁王伯把阳台泡菜坛改成“共享辣酱站”，邻居扫码领酱、留菜换酱——自发协作潜力巨大，缺的是轻量、可视、零学习成本的连接工具。

大概是什么产品：

一款基于轻量AR眼镜（兼容现有Pico/雷鸟）的社区级空间标注系统，配合微信小程序辅助，无需下载App，扫码即启“种菜地图”。

👥

2. 目标用户及痛点

面向哪些用户：

  • 60–85岁有种植经验/生活节俭习惯的城市退休老人
  • 尤其居住在老旧小区、无子女同住或子女不在本地者

在什么场景下使用：

晨练路过废弃花坛时戴AR眼镜，看到地面浮现半透明“可耕种浮标”（标注土壤检测数据+推荐种什么）；或在社区公告栏扫码，用手机镜头扫墙角，立刻看到“本周待认领白菜苗×3株”悬浮提示。

当前痛点（点击展开）
  • 老人发现空地想种菜 → 被物业制止（无备案）
  • 想帮农户买菜 → 找不到可靠渠道
  • 想以物易物 → 记不住谁缺葱谁多蒜
  • 现有助农平台操作复杂，二维码都扫不准
💡

3. 价值与意义

社会价值：

将“闲置空间 + 滞销农产品 + 老年劳动力”三重沉睡资源，在最小干预下激活为社区微循环节点。

  • 单个试点小区预计年减少食物浪费 1.2吨
  • 唤醒 30+ 处“隐形可耕空间”

效率提升：

AR浮标自动对接本地农业合作社库存数据，老人“眼见为实”认领菜苗/共享收成，省去信息匹配与信任建立过程，响应速度从天级压缩至分钟级。

// AR浮标渲染逻辑（简化）
function renderGardenFloaters() {
  const spaces = detectIdleSpaces(); // 扫描空地
  spaces.forEach(space => {
    if (space.soil.isFertile && space.owner === 'community') {
      showFloatingLabel(space, `🌱 可种：小白菜 ×${space.capacity}`);
      attachClickHandler(space, () => claimSeedling(space.id));
    }
  });
}
