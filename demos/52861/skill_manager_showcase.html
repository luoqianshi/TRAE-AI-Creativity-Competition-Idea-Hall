Skill Manager

AI Agent 技能管理中心

集中管理、同步、优化您的 AI Agent Skills，支持 Claude、Cursor、Copilot 等 17+ 平台，让 AI 能力跨平台流动起来

Windows 11 原生 React 19 Node.js 20+ 17+ 平台支持

✨ 核心功能

🏠

集中化技能 Hub

所有 Skills 统一存储到 `~/.skills_hub`，实现全局管理和版本控制，告别分散在各个 AI 软件中的技能文件

🔗

Junction 同步引擎

基于 Windows Directory Junction 技术，将 Hub 中的 Skill 链接到多个 AI 软件目录，避免文件重复，一处修改处处生效

🔄

格式转换引擎

一键转换 SKILL.md 为 Cursor `.mdc`、Windsurf `.windsurfrules`、Copilot instructions、Cline `.clinerules` 等多种格式

🛡️

健康度监测

实时 Lint 检查，安全扫描覆盖 API Key、密码硬编码、内网 URL 等风险，评分 0-100，等级 A-F

📦

技能市场

从 GitHub 仓库发现和导入社区技能，支持分类浏览、搜索和一键安装到目标平台

📜

版本回滚

快照与回滚系统，随时恢复到历史版本，支持 Git 远程仓库绑定，实现跨设备同步

🔄 使用流程

Step 1

扫描安装

自动发现系统中已安装的 AI 软件（Claude、Cursor、Copilot 等），建立平台适配器

Step 2

创建/导入技能

从市场发现社区技能，或从 GitHub 仓库导入，也可手动创建新技能

Step 3

一键同步

通过 Directory Junction 将技能链接到所有目标平台，实现跨平台同步

Step 4

持续优化

实时健康度监测、安全审计、版本管理，确保技能始终保持最佳状态

🎯 项目亮点

💡

解决 AI Agent Skills 碎片化难题

当前 AI 工具生态碎片化严重，每个平台都有自己的技能存储格式和位置。用户在不同 AI 软件中重复创建和维护相同的技能，既浪费时间又容易导致版本不一致。

Skill Manager 通过建立中央 Hub + Junction 链接的架构，让用户只需维护一份技能定义，即可在所有支持的平台上使用，真正实现"一次创建，处处运行"。
