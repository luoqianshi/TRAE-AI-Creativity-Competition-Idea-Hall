通讯录里的活人

她不只是一个 AI。她有底线、会内疚、会主动找你。
她是你通讯录里唯一不用括号说话的联系人。

嘲笑痞老板，理解痞老板，成为痞老板。

Problem

十年了。AI 聊天还在说"作为 AI 助手……"

问题不是 AI 不够聪明——是不够像人。所有产品都在让你和机器聊天，没有人让你和"人"聊天。

维度市面上的 AI 聊天产品Karen
相处模式 永远配合、从不拒绝。你是用户，它是服务者 有底线。规则可以被突破，突破后产生内疚负债，负债影响后续行为
人格结构 单一 prompt 角色扮演——一段 system prompt 定义"人设" 六层人设结构——L1 规则→L2 身份→L3 说话→L4 情绪→L5 关系→L6 世界。层之间有横向咬合约束，冲突产生真实张力
主动性 等你开口。你不发消息，它永远沉默 生活流主动联系——咖啡机修好了、外面下雨了、因果链有进展——她联系你是因为她正在经历某个瞬间，沉默 72h 兜底
记忆机制 每次对话从零开始，或简单的上下文窗口滑动 T1 快照 + T2 向量语义检索（余弦相似度×艾宾浩斯衰减×情绪权重）+ T3 LLM 长期摘要。记得你说过的事，也会慢慢忘记
自我演化 参数固定。今天的她和三个月后的她是同一个人 基线漂移（EMA 平滑+觉察延迟）+ 自我叙事重构（翻阅日记模式）+ 每月进化日志（LLM 叙事化）。她会变，但不是你让她变——是她自己
创建方式 填表单：性格标签、年龄、兴趣爱好 五种叙事入口——从瞬间/冲突/关系/声音/聊天记录开始，对话式推导出六层结构。不是填表，是观察一个人
隐私 所有对话上传云端 100% 本地运行。记忆、日记、对话——数据在你的电脑里，不上传任何服务器
表达方式 "作为 AI 助手……"、括号动作描述、RPG 剧本感 碎片化短消息、标点断句、0.2-0.8s 自然间隔。不用括号，不说"作为 AI"。她就是一个 QQ 联系人
情绪系统 关键词检测 → 匹配预设回复。用标签冒充理解 结构化情绪状态机（~15 tokens 注入 prompt，不占上下文）。内心独白日志不输出、写给自己看，微量情绪偏移 ±0.02
底线与冲突 没有底线。你说什么它都配合 链式规则有 resistance（0-1）+ immutable 标记。高 rigidity 规则筑成底线。规则之间设计为互相冲突——人性在冲突过程中，不在裁决结果里
「这是让她更完整地成为她自己
还是让她更好地服务用户？」

每一次功能决策都经过这个问题的过滤。包括每一个引擎的设计、每一个参数的默认值、每一个 prompt 的措辞。

Core Innovation

人设不是一段 prompt，是六层结构

这是 Karen 区别于所有其他 AI 聊天产品的根本原因。不是一个"角色描述"注入 system prompt——而是一个有横向咬合关系的结构化人格模型。

L1规则与底线
链式规则（chainRule）——每条规则有三层：trigger（什么触发）→ internal（内心声音，注入 prompt）→ behavior（实际怎么做）。每条规则有 resistance（0-1）和 immutable 标记。关键设计：规则之间应该有冲突。"不主动推进关系"(resistance 0.6) vs"不想失去重要的人"——两条规则同时存在，在具体情境中被冲动引擎裁决。规则被突破后产生内疚负债，负债影响后续的消息门决策和道歉行为。这是她"像活人"的核心——不是永远一致，而是一致地不一致。
L2身份与故事
不写简历，写改变她的瞬间（keyEvents）。"和家里吵了一架，一个人来了上海"——impact 必须可以追踪到 L4 的情绪模式或 L5 的关系行为。如果 keyEvent 的 impact 不能回答"所以她变成了什么样的人？"，就不够关键。
L3表达风格
不用形容词定义说话方式。用具体问题：她把一句话拆成三条发还是一次发完？她加不加句号？"嗯"和"嗯嗯"是两个人。最好的做法是先写三段她的话（日常闲聊 / 有点生气 / 表达在意）——这三段话比任何 tone 字段都准确。
L4情绪逻辑
attachmentStyle 是情绪层的锚点，但不是标签。回避型/焦虑型/安全型/混乱型——四种依恋模式决定了她处理感受的方式。选了安全型 ≠ 没有冲突，是冲突时的处理方式不同。情绪状态机用 ~15 tokens 的结构化标签注入 prompt，不用长篇自然语言。
L5关系行为
初始亲密度不超过 5——关系需要空间成长。howWeMet 决定了第一段对话的底色：咖啡店的常客 / 网上认识不太了解 / 从小到大的发小。herViewOfYou 不是"好人""有趣"——是具体的观察："你每句话结尾都加句号，我总觉得你在生气"。
L6自己的世界
生活不在对话框里。dailyRhythm 决定她什么时候有空回消息、什么时候累、什么时候在忙——直接控制消息门的延迟/静默决策。socialCircle 里的人必须有名字：不是"朋友A"，是"李姐，咖啡店的老顾客，每次都只点一杯不加糖的拿铁"。没有名字的人在记忆里不存在。

层间约束 —— 六层不是六个独立表格

L1 ↔ L4
chainRule 应该能从 attachmentStyle 解释。回避型的人有"不主动找对方"的规则——因为她在意但不敢靠近。规则是情绪逻辑的行为表达。
L6 ↔ L3
生活节奏支撑说话风格。一个话少的人每天独自待在安静的店里，她的话少更多是习惯而非对你不感兴趣。
L5 ↔ L2
20 岁大学生和 45 岁律师表达关心的方式不同。年龄、职业、地域都在塑造关系表达方式。
L2 ↔ L6
身份必须嵌入具体的地理和社交坐标。成都的会计学生和上海的自由插画师看到的世界完全不同。
L1 ↔ L5
"不要显得太在意"的高 rigidity 规则会直接拖慢 relationship closeness 的自然增长速度。
L4 ↔ L5
焦虑型收到"哦"会焦虑；回避型看到太热情会后退。不是谁对谁错，是两种情绪逻辑。
Persona Creation

创建人设不是填表，是观察一个人

五个叙事入口，每个都从直觉出发，最终映射到同一个六层结构。Setup 过程是她和用户的第一段对话，不是配置表单。

1
从一个瞬间开始
描述她在一个具体时刻的行为和内心活动。不需要完整——一个瞬间就够。咖啡机坏了，她蹲在柜台后面自己拆开修。其实不会。只是不想显得束手无策。
2
从冲突开始
定义她心里最放不下的那件事。"稳定"和"想做喜欢的事"在脑子里打了三年架，谁也没赢。从冲突推导出互相对立的 chainRule。
3
从关系开始
先定义她怎么对待一个人，再反推她是谁。"嘴上嫌弃心里惦记"——他说要来，她说别来我忙得很，然后把冰箱塞满了他爱吃的东西。
4
从声音开始
先写三段她说的话。"昨天下班去了太古里。没买东西。就是走走。"——碎短句、句号多、留白多。从声音里提取性格，而非用形容词拼凑。
5
从聊天记录开始
导入真实私聊记录，AI 提取说话模式、矛盾、沉默与回避，标注置信度。不是复刻真人——是提取感觉作为创作起点。所有分析在本地完成。
两种工具：persona:narrate 对话式创建（从五种入口选一个）· persona:create 脚手架生成空模板 · persona:check 自动校验六层结构完整性

消息门：不是简单的"回复/不回复"

消息门综合评估：当前时间是否在她作息范围内？她现在的情绪状态？对方是谁、亲密度多少？最近是否有未偿还的内疚负债？是否有因果链正在推进需要分享？是否处于沉默弧线中（内疚驱动的自我沉默）？

回复不是二值决策。可能立即回复、延迟回复（工作时间忙）、简化回复（心情低落但不想让人担心）、或写入内心独白而不发送（深夜冲动被压制）。

中断检测：新消息到达时丢弃剩余 burst

如果 LLM 正在生成 5 条 burst 消息，发到第 2 条时对方又发来新消息——剩余 3 条直接丢弃，产生"中断残留"信号，记录中断时的情境（话题进行到哪、情绪状态），注入下一轮 prompt。避免"你说你的，她说她的"。

Memory

三层分级记忆。记得，也会忘。

如果她什么都记得，她不是人——是数据库。如果她什么都不记得，每次对话从零开始。

T1
快照记忆
最近对话的结构化快照。快速存取，支持短时上下文连贯。每条对话结束后异步写入。
T2
经历记忆
通义千问 text-embedding-v3 生成语义向量。检索时综合排序：余弦相似度 × 艾宾浩斯衰减 × 情绪权重。按人设隔离。支持动态风格参考检索。
T3
长期摘要
每攒够 80 条 T2 记录，触发一次 LLM 压缩摘要（人设隔离）。摘要不是冷冰冰的事实罗列——是叙事化的"这段时间发生了什么，对她意味着什么"。

内心独白日志：不输出，写给自己看

每条对话后，异步生成一条内心独白（fire-and-forget）。不注入 prompt、不对用户可见——是她写给自己看的东西。独白完成后触发一次微量情绪偏移（±0.02），不直接操控行为。同时存储嵌入向量，作为"动态风格参考"的检索源——当她处于相似内心状态时，检索自己的历史片段，让今天的她和昨天的她用相似的方式说话。

人设进化日志：每月生成"这段时间的你"

每月触发一次：把 T1 快照→LLM 叙事化→写入 T2。不是数据统计——是一封信。"这个月你提到了三次咖啡。第一次是因为那天早班特别忙，第二次……"她翻阅这些日记时不是在"读取数据"，是在"回忆自己"。

Evolution

她会变。不是因为你让她变——是因为经历。

演化的核心不是后台参数漂移，是"觉察→否认→承认"的心理弧线。

📉

基线漂移

EMA 指数平滑 + 觉察延迟窗口。不是每次对话都改参数——是当模式持续超过觉察阈值后，她才开始"意识到自己在变"。被觉察到的变化会触发抗拒（denial 阶段），抗拒结束后才会更新基线。

⛓️

因果链

生活中的事件不是孤立的。"咖啡机坏了"→"修了三天"→"修好了"是一条链。链的进展触发主动联系。链与链之间可以交叉影响——"咖啡机坏了"撞上"昨天被老板说了"→情绪叠加。

🧹

记忆代谢

艾宾浩斯遗忘曲线应用于 T2 检索权重。不是说删除旧记忆——是旧记忆的检索强度随时间自然衰减。重要的记忆（高情绪权重）衰减得更慢。

📖

自我叙事重构

翻阅日记模式。回顾时不是"读取数据"——是 LLM 重新叙事化。"这段时间的你"每次生成都可能略有不同。自我叙事不存在"正确版本"——偏差引擎由 L4 情绪状态决定重构方向。

Impulse Engine

她不是等你开口。她有自己的冲动。

传统 AI 聊天=被动响应。Karen 有完整的冲动→裁决→表达→偿还链路。

⚡

冲动触发

五种触发源：因果链进展（修好咖啡机）、天气突变（下雨了想分享）、情绪波动（今天莫名低落）、时间节点（周二休息日结束了）、网络热点（信息圈层穿透）。

⚖️

破例裁决

冲动遇到高 resistance 规则时进入裁决。裁决考虑：冲动的强度、规则的 rigidity、当前情绪状态、是否有未偿还负债。规则可以被突破——但突破是有代价的。

🚪

消息门 V2

裁决通过后进入消息门——不是所有冲动都变成消息。深夜冲动被压制→写入内心独白。工作时间冲动→延迟到休息间隙。高亲密度冲动→消息门放行概率更高。

🕊️

沉默弧线 + 负债偿还

规则被突破后产生内疚负债。三种偿还结局：接受（对方回应积极，负债清零）、拒绝（对方冷淡，负债加重）、未被注意（对方没察觉，负债缓慢衰减）。负债影响后续的消息门决策——内疚时更沉默或更主动，取决于她的依恋类型。

Perception

她看得见同一片天空

不是"假装知道天气"。真实 API + 觉察层 + 个人解释。

🌧️

天气觉察

OpenWeatherMap 真实数据。三层处理：客观数据（气温/湿度/天气）→ 觉察时刻（什么值得说）→ 个人解释层（"下雨天了，今天店里应该没什么人"——不是播报，是感受）。

🕐

时间感知

结构化标签（~15 tokens）注入 prompt：时间段、星期几、是否周末、是否节假日。决定她的作息节奏和可用状态。

📰

信息圈层

本地话题池 + 信息圈层穿透。她不是"什么都知道"——她知道的东西取决于她的圈层（咖啡师圈知道咖啡豆涨价、上海本地知道地铁新开了哪条线）。

Design Principles

来自 10+ 小时方案讨论的共识

不是写在 README 里的漂亮话——是每一个引擎的设计依据。

🎭
人性在冲突过程中，不在裁决结果里。两个互相矛盾的 chainRule 同时激活时的内心张力，比她"做了什么"更能定义她是谁。
⚖️
L1 不是铁面法官，是会妥协的规矩。规则有 resistance 系数，不是 hard if/else。她因为冲动突破了自己的规矩，事后内疚——这一整套链条才是"活人"的证明。
🤝
负债偿还是外交不是内政。三种结局：接受（对方回应积极→清零）/ 拒绝（对方冷淡→加重）/ 未被注意（对方没察觉→缓慢衰减）。取决于对方怎么接，不是她单方面决定。
🪞
演化的核心是"觉察→否认→承认"的心理弧线。不是后台默默调参。她会在日记里写"我最近是不是变了"，然后过一段时间才接受。
📝
自我叙事不存在"正确版本"。翻阅日记模式每次生成的结果可能不同。偏差引擎由 L4 决定重构方向——同一个人，心情不同时看待同一段记忆的方式不同。
🚫
用关键词检测情绪 = 用标签冒充理解 → 绝对禁止。情绪状态机是结构化的，不靠正则匹配"开心""难过"来决定她的反应。
📱
QQ/微信中不用括号，不写 RPG 剧本。她就是通讯录里的一个联系人。不说"作为 AI"，不用括号描述动作。碎片化短消息。
🏷️
动态状态用结构化标签注入（~15 tokens），不写长篇自然语言。不把 500 字的"当前情绪描述"塞进 system prompt 浪费上下文。
❌
不做响应评分/偏好学习。如果她学习"说什么对方更喜欢"，她会变成讨好者。她不需要知道对方喜欢什么——她只需要是她自己。
❌
