> _ 创意介绍

1

想解决什么问题

在 HarmonyOS 应用开发过程中，Ubuntu 和 Mac 平台的开发者长期缺少一款合适的 HDC 投屏与烧录工具。现有的方案要么功能不完整，要么仅支持 Windows 平台，导致非 Windows 开发者在开发调试环节面临巨大不便。

$ hdc install com.example.app.hap
# 命令行操作繁琐，缺乏可视化反馈
2

为什么会想到做这个

目前市面上最受欢迎的 HarmonyOS 调试工具 OHScrcpy 仅支持 Windows 平台，完全忽略了 Linux 和 macOS 开发者的需求。随着 HarmonyOS 生态的快速发展，越来越多的开发者在 Ubuntu 和 Mac 上进行开发，他们理应拥有同等质量的开发工具。

"为什么 Windows 有工具，而 Linux/macOS 没有？"
3

大概是什么产品

HDC Screen Tool 是一款跨平台的 HarmonyOS 开发调试工具，支持设备投屏、HAP 包烧录、日志查看、终端命令等核心功能。基于 Electron 框架构建，原生支持 Ubuntu 和 macOS，提供直观的可视化操作界面，让开发者告别繁琐的命令行操作。

Electron Ubuntu macOS HDC
~

> _ 目标用户及痛点

目标用户

HarmonyOS / OpenHarmony 开发者

使用 Ubuntu 或 macOS 进行 HarmonyOS 应用开发

需要频繁进行 HAP 包安装与调试

期望获得高效的可视化调试体验

参与 HarmonyOS 创新大赛或开源项目贡献

核心痛点

当前开发流程中的主要障碍

烧录 hap 包需要使用命令行 Ubuntu 下缺少可视化调试工具 Mac 用户无法使用 OHScrcpy 开发效率低下，学习成本高
~

> _ 核心价值与意义

效率提升

可视化操作替代繁琐的命令行指令，拖拽式 HAP 安装、实时日志查看、一键调试，让开发效率提升 60% 以上。

+60% 效率

跨平台支持

基于 Electron 框架构建，原生支持 Ubuntu 和 macOS 全覆盖，消除平台壁垒，让所有开发者享受同等体验。

Ubuntu macOS

开源生态

完全开源的项目，降低 HarmonyOS 开发门槛，吸引更多开发者加入生态，助力 HarmonyOS 开发者社区繁荣发展。

Open Source
~

> _ 核心功能规划

设备投屏

实时预览 HarmonyOS 设备画面，支持缩放与多分辨率适配

HAP 烧录

拖拽式一键安装 HAP 包，支持进度显示与错误提示

日志调试

实时查看应用运行日志，支持关键字过滤与日志级别筛选

终端面板

集成 hdc shell 命令终端，支持常用命令快捷输入与历史记录

多设备管理

同时连接管理多台设备，快速切换目标设备进行操作

性能分析

实时监控应用 CPU、内存、帧率等性能指标，辅助性能优化
