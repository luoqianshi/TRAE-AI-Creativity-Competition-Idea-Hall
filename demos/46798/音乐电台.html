01 项目创意概述

解决痛点

传统音乐播放器只能手动切歌、循环固定歌单，无法根据个人听歌偏好、时间段、当下情绪自动编排连贯曲目；缺少电台式拟人DJ氛围感旁白，听歌缺乏沉浸式情绪陪伴，也无法深度联动个人网易云音乐收藏歌单做个性化智能推荐。

创意灵感

参考海外 Claudio AI 私人电台产品思路，依托 Trae IDE 完成全栈从零开发，打造一套全自动AI音乐陪伴系统，实现 24 小时无人值守私人电台，适配居家放松、通勤、睡前、专注工作等各类场景。

产品形态

Node.js 后端调度服务 + PWA电脑网页播放器 + React Native 手机APP三端一体应用，打通大模型LLM、火山TTS语音合成、网易云音乐个人账号曲库，完整闭环AI选歌、语音播报、双向交互、多端同步播放。

02 目标用户 & 使用场景

目标人群

  • • 深度音乐爱好者、长期听歌用户
  • • 上班族，需要氛围感背景音乐
  • • 喜欢独处、睡前助眠人群
  • • 追求个性化、氛围感体验年轻人

典型场景

  • • 晚间居家放松，舒缓氛围电台
  • • 上下班通勤自动匹配曲风
  • • 睡前慢歌助眠模式
  • • 工作专注背景音乐编排

03 整体四层技术架构

第一层｜外部数据源层

用户听歌偏好配置、智谱/豆包LLM大模型、网易云音乐曲库API、天气/日程环境采集输入

第二层｜后端核心调度层

意图路由分发、上下文Prompt组装、LLM适配器、节拍排歌调度、TTS语音管线、SQLite持久化存储六大核心模块

第三层｜上下文推理决策层

聚合6类上下文送入大模型，结构化输出播放队列、DJ串词文案、选歌逻辑，完成歌曲+播音音频生成

第四层｜前后端交互层

WebSocket实时通信，PWA网页端 + React Native手机APP双端播放状态同步、聊天交互、主题切换

04 核心功能亮点

AI智能排歌引擎

读取个人网易云歌单与听歌历史，结合时段自动规划队列，防重复、曲风连贯编排

拟人DJ语音播报

大模型生成氛围感串词，火山TTS合成电台人声，歌曲间隙无缝插播旁白

双向聊天交互点播

文字/语音发消息点歌、切换曲风、闲聊对话，实时修改播放策略

电脑手机双端同步

PWA网页 + RN APP播放进度互通、远程控制、断点续播、明暗主题切换
