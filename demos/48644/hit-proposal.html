核心特性

为开发者日常而造

Hit 解决的是每天都会遇到的问题：装软件卡、Path 被污染、版本冲突没法切——每一个细节都从真实痛点出发。

⚡

交互式 TUI 搜索

hit si 启动全屏搜索界面，实时过滤结果，方向键选择，Enter 一键安装，鼠标键盘均可操作。

🦀

Rust 原生构建

CLI 约 11 MB，Shim 代理仅 214 KB，零运行时依赖，冷启动速度对比 Python/Node 工具提升显著。

🗂️

Scoop 生态兼容

直接读取 Scoop bucket 的 manifest 格式，数千个现有软件包开箱即用，无需重复维护元数据。

🔗

Shim 代理 + 版本管理

每个安装的软件都通过轻量级 .shim sidecar 暴露到 PATH，卸载即删除不留残留；hit reset 在同软件多个版本间自由切换；hit hold 锁住版本防止意外升级。

$ hit reset python 3.12.0
Switched python → 3.12.0 via shim
$ hit hold python
python 3.12.0 locked — will skip on next update
🩺

健康检查自修复

hit doctor 扫描 junction、shim 与目录完整性，发现异常自动修复，保持安装环境始终可信。

🧹

零污染安装

所有软件安装在用户目录 ~/.hit，无需管理员权限，不写系统注册表，删目录即完全卸载。

快速开始

两种方式，分钟级上手

支持在线脚本一键安装，或从源码构建，两条路径都经过测试验证。

在线安装（推荐）

运行官方 PowerShell 脚本，自动拉取最新版本并配置好环境变量，支持指定镜像和版本号。

# 交互式安装
.\scripts\install-hit.ps1

# 指定镜像与版本
.\scripts\install-hit.ps1 -Mirror github -Version 1.0.0

从源码构建

需要 Rust 工具链，构建完成后通过安装脚本 -FromLocal 参数部署到本地。

# 构建 CLI + Shim
cargo build --release -p hit-cli -p hit-shim

# 产物在 target/release/
# hit.exe ~11 MB
# hit-shim.exe ~214 KB

项目架构

关注点分离的 Cargo workspace

五个 crate 各司其职，hit-shim 可独立零依赖部署，hit-core 承载全部业务逻辑。

  • hit-cli
    命令行入口。clap 命令树 + 进度渲染 + TUI 交互搜索界面，所有用户可见的交互层都在这里。
  • hit-core
    核心业务逻辑，包含 manifest 解析、install/uninstall 流程、bucket 管理、store 持久化与 health 检查。
  • hit-common
    公共工具库，提供 config、session、event bus 与统一错误处理。
  • hit-shim
    零外部依赖的 Shim 代理，214 KB，读取 .shim sidecar 后将调用转发到真实可执行文件。
  • hit-test-utils
    跨 crate 共享的测试 fixture，保持集成测试环境一致性。
