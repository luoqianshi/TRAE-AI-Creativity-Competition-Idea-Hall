求极限：lim(x→0) (sin x - x) / x³
正确答案
使用泰勒展开：sin x = x - x³/6 + o(x⁵)

物理 2026-06-13

ε' = (B/2)·L·(2v) = BLv = ε

🤖

解题思路：
1. 直接使用洛必达法则会比较繁琐，需要多次求导
2. 更高效的方法是使用泰勒展开：
   sin x = x - x³/6 + x⁵/120 - ...

计算过程：
sin x - x = -x³/6 + o(x⁵)
原式 = lim(x→0) (-x³/6) / x³ = -1/6

常见错误：
- 泰勒展开记忆错误
- 忽略了高阶无穷小的处理
