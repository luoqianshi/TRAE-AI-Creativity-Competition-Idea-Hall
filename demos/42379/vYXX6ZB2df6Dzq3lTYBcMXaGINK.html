1创意名称 + 创意介绍

创意名称：PeekGuard 智能防窥与健康行为管理助手。 这是一个运行在电脑端的本地 AI 助手，用来同时解决“屏幕隐私暴露”和“长期不健康电脑使用习惯”两个真实问题。

!想解决什么问题

在办公室、图书馆、自习室、咖啡馆、共享工位等场景中，用户经常一边担心别人偷看屏幕，一边又容易出现久坐、 姿势不良、频繁分心、长时间离座后忘记锁屏等问题。现有工具通常只解决其中一部分，缺少一个能够同时保护隐私、 管理行为习惯的桌面产品。

*为什么会想到做这个

这个创意来自真实的电脑使用体验：处理敏感内容时，总要时不时回头确认有没有人靠近；而长时间工作学习时， 又很难持续意识到自己是不是坐姿不良、是不是已经久坐太久、是不是经常无意识趴桌。于是我们希望做一个“既看外部风险， 也看自身状态”的智能助手。

#大概是什么产品

一个基于 Tauri + React + Rust 构建的桌面应用，结合摄像头实时检测、人脸与姿态分析、系统托盘运行、 弹窗提醒和日报统计，形成面向学习与办公场景的“安全 + 健康”双能力产品。

核心定位：PeekGuard 不是单点功能工具，而是一套围绕“电脑前的人”设计的主动式守护系统。
2目标用户及痛点

面向长期在电脑前工作和学习的人群，尤其适合隐私敏感、高频久坐、对专注和健康都敏感的用户。

@核心用户

程序员、设计师、学生、老师、运营、财务、咨询顾问、自媒体从业者、远程办公人群。

[]使用场景

图书馆、自习室、办公室、共享工位、咖啡馆、宿舍、家庭书房，以及处理隐私资料的会议间隙。

?没有产品时

用户需要自己警惕周边环境、频繁回头确认，还经常忽略久坐、离座、姿势不良和专注波动。

+直接痛点

隐私泄露风险高、专注被打断、身体疲劳积累、工作学习节奏无反馈、缺少行为数据复盘。

3双核心能力

项目围绕两个明确方向展开：外部防窥风险检测，以及用户自身行为和健康习惯检测。

方向一：防窥安全

通过摄像头实时检测屏幕前是否出现他人、是否存在陌生人靠近或旁观风险，并触发弹窗、声音或系统提醒。

  • 检测屏幕前是否出现额外人脸或陌生人
  • 支持后台托盘运行，不依赖用户主动查看
  • 告警时自动唤起主窗口，提升提醒触达率
  • 支持隐私模式、勿扰时段与日志追踪

方向二：行为健康检测

通过姿态和行为分析，识别用户的工作学习状态，帮助建立更健康、更自律的电脑使用习惯。

  • 识别坐着、站立、离座、工作中等基础状态
  • 识别喝水、伸展、抬手等积极行为
  • 监测久坐、长时间离座、姿势变化，形成提醒依据
  • 生成完整日报，帮助用户回看一天的行为分布
4行为检测功能介绍

项目当前已经具备行为识别模块，核心思路是通过摄像头画面结合姿态检测模型，对用户在电脑前的行为状态做连续分析， 再配合时间阈值与状态稳定逻辑，避免瞬时动作造成误判。

1

采集视频流

应用启动后获取摄像头画面，在前端持续拿到实时视频帧。

2

识别人和姿态

基于人脸检测和姿态识别判断“是否有人在位”与“身体姿势如何变化”。

3

判断行为状态

把连续结果映射成坐着、站立、离座、喝水、伸展、工作中等可理解状态。

4

生成提醒和日报

把异常或积极行为转成提醒，把全天状态转成时间线和日报数据。

S已覆盖行为

坐着、站立、倾斜/趴伏、喝水、吃东西、抬手、伸展、工作中、离开座位、未知状态。

R如何帮助健康

当用户久坐或行为状态长期单一时，可以在后续扩展中触发喝水提醒、起身活动提醒和专注节奏建议。

D如何帮助自律

通过日报和行为记录，用户能看见自己一天中有多少有效在位时间、离座次数、积极动作和状态分布。

5项目真实功能拆解

以下内容来自当前项目已实现或已接入的功能方向，而不是空想概念。

A防窥检测引擎

检测当前画面中的人员情况，结合“本人/陌生人”逻辑触发风险告警，并支持系统通知与弹窗联动。

B行为状态卡片

主页展示当前行为状态、模型就绪情况、今日行为记录数、监测时长，并支持打开完整日报。

C行为日报

根据当天行为记录生成时间线和统计摘要，让用户看见一天内的节奏变化与行为分布。

D系统托盘与后台运行

关闭窗口后仍可在托盘后台运行，既不打断工作流程，也保证提醒在关键时刻仍然生效。

E快速操作与隐私模式

支持快速启动、暂停、切换隐私模式和勿扰时段，适应不同办公、学习和演示场景。

F日志与可追溯性

监控日志实时展示后端状态、检测流程与告警事件，便于追踪风险和迭代算法体验。

6目标用户价值与意义

效率价值

把“手动警惕”和“靠自觉纠正习惯”转化成系统主动提醒，降低分心成本，让用户把注意力放回真正的工作学习任务。

商业价值

适合个人用户桌面工具、企业办公安全、校园学习空间、远程办公和数字健康辅助等多个市场方向，具备明确产品化潜力。

社会价值

强化公众对数字隐私和电脑使用健康的双重意识，让“保护屏幕内容”和“保护自己状态”成为同等重要的日常习惯。

7技术方案

项目采用轻量桌面端架构，尽量在本地完成分析和展示，兼顾性能、隐私与可扩展性。

React 负责界面展示、状态交互与组件化前端结构
Tauri 提供桌面能力、系统托盘、窗口控制与本地打包
Rust 负责桌面侧能力承接与稳定的本地运行支撑
MediaPipe 承担姿态与视觉分析，为行为识别能力提供基础
技术优势：本地运行、跨平台潜力强、前后端边界清晰、后续可继续扩展更多行为模型与更细粒度健康提醒。
