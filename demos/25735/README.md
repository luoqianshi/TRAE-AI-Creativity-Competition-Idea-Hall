# QRCode Tool Demo

这是一个独立的二维码工具演示版本，可以直接在浏览器中打开运行。

## 使用方法

### 方式一：直接打开
双击 `index.html` 文件，或者用浏览器打开该文件。

### 方式二：本地服务器
```bash
cd demo
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 功能特性

### 1. 生成二维码
- 支持自定义内容
- 可调整尺寸 (100-400px)
- 支持 4 种错误纠正级别 (L/M/Q/H)
- 一键下载为 PNG
- 复制到剪贴板

### 2. 识别二维码
- 支持拖拽或点击上传图片
- 自动识别图片中的二维码
- 支持多种图片格式 (PNG, JPG, BMP 等)

### 3. 样式演示
- 自定义前景色和背景色
- 实时预览样式效果
- 支持在二维码中心嵌入 Logo 图片

## 技术栈

- Vue 3 (CDN)
- qrcode.js - 二维码生成
- jsQR - 二维码识别
- Canvas API

## 注意事项

- 本 demo 为纯前端实现，不调用 Rust 后端
- Logo 功能需要上传图片后才能生成
- 完整功能请使用主程序
