豆子标准化助手

Bean Normalizer

把一颗豆子放进文件夹，它帮你把一切整理得明明白白。

💡这是什么

一个可移动式的单文件小程序。你不需要安装它、配置它、学习它怎么用。只需要把它拖到任意文件夹里，它自动扫描所有文件、用 AI 读懂内容、按规范重命名、统一格式、抽取关键数据、生成一份完整的总览报告。用完了？删掉就好。想用在别处？复制过去就行。

🏗技术架构

🫘 部署层 豆子式投递 — 单文件极小体积，拖入文件夹即运行，不需要安装
🔐 权限层 双重触发机制 — ① 员工自主：整理自己的文件夹   ② 主管统一：处理离职/归档文件夹
🔍 扫描层 文件发现与识别 — 递归遍历 + MIME 检测 + 元数据提取（日期/作者/大小…）
🧠 AI 引擎 多模型智能路由 — 简单任务走本地模型（离线可用），复杂任务走云端大模型，自动升降级
⚙️ 处理管道 五步标准化 — 内容理解 → 智能命名 → 格式转换 → 数据抽取 → 分类归档
📊 输出层 结构化产出 — 统一命名的文件树 + CSV 汇总表 + HTML 总览报告 + 标准化数据集

AI 路由策略

场景模型选择理由
纯文件名模式修改规则引擎确定性任务，不需要 AI
简单文本提取 + 分类本地小模型（Qwen/Llama）成本低、速度快、离线可用
复杂文档语义理解云端 GPT-4o / Claude需要强推理和多模态能力
批量 OCR 识别PaddleOCR / 本地模型高吞吐、成本可控

🏆为什么不一样

对比维度现有工具豆子标准化助手
部署方式需 clone 仓库 + 安装环境拖入即用，无需安装
功能范围只做重命名 / 只做格式转换 / 只做抽取全流程闭环：命名→转换→抽取→报告
权限模型无权限概念，全员无差别双重触发：员工自主 + 主管统一
隐私保护要么全本地 / 要么全云端动态路由：本地优先，按需云端
数据沉淀整理完就走，不留痕迹训练数据飞轮：产出的数据集可复用
开源部分开源MIT 协议完全开源
