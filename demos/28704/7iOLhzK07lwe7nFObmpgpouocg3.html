🌟 价值与意义

从效率提升到社会价值的双重实现

⚡

效率提升

批改时间从20分钟/篇缩短到1-2分钟/篇，效率提升约20倍。百篇作文从一周工作量变为2小时。

💰

商业价值

适用于中小学作文竞赛、培训机构批量评语、在线作文辅导平台，可扩展SaaS模式服务更多学校。

🌏

社会价值

推动教育公平，让西部偏远县域的学生也能享受优质AI评审服务；减轻教师负担，保护身心健康。

🛠️技术架构

# 核心技术栈 开发语言 : Python 3.12 GUI框架 : Tkinter + ttk 数据库 : SQLite3 图像处理 : Pillow (PIL) PDF生成 : ReportLab AI接口 : Requests + REST API 大模型1 : DeepSeek-VL / Chat 大模型2 : 智谱 GLM-4V 大模型3 : 通义千问 Qwen-Plus

📋系统核心模块

  • DatabaseManager：SQLite数据库管理类，负责评审记录的增删查
  • extract_essay_text：GLM-4V图像OCR识别，提取作文原文
  • extract_student_info：智能识别学生姓名和班级信息
  • call_deepseek：DeepSeek综合评审，返回0-100分和四项评语
  • call_zhipu：智谱错别字和语病专项检测
  • call_qwen：通义千问文章结构分析与改进建议
  • create_pdf：生成含原文、AI评审、教师终审的PDF报告
  • EssayReviewApp：Tkinter图形界面，含5个功能标签页
