CORE FEATURES

两大核心能力
深度融入系统

不是又一个独立 App，而是直接长在 Windows 右键菜单里的系统级工具。 安装即用，卸载即净，无感融入日常工作流。

01 / RENAME
⚡

批量重命名引擎

42 种命令覆盖 8 大场景：大小写转换、添加/移除、文本替换、字符清理、 扩展名处理、序号编号、日期时间、哈希/随机。支持正则表达式、 多选文件批量处理、预览确认后再执行。

02 / OCR
👁

屏幕框选 OCR 识别

基于 Tesseract 引擎，支持中英文混合识别。 全屏覆盖层拖拽框选任意区域，识别结果可直接复制。 无论是图片文字、视频字幕、还是不可复制的 PDF，都能一键提取。

03 / SHELL
⊞

系统级深度集成

通过 COM Shell 扩展注入资源管理器，支持多选文件批量处理。 覆盖文件右键、文件夹右键、文件夹背景、桌面背景 4 个位置。 安装包一键部署，卸载自动清理注册表。

VALUE & MEANING

为什么是
右键智囊

01

效率提升

传统批量重命名需要下载专门软件、打开软件、导入文件、设置规则、导出文件， 至少 5 步。右键智囊将其压缩为「右键 → 选择命令 → 确认」3 步， 操作路径缩短 40%，单次任务节省 30 秒以上。

02

商业价值

面向 1.5 亿 Windows 个人用户与中小企业，解决文件管理高频痛点。 可拓展为付费高级版（云端 OCR、AI 智能命名、团队规则同步）， 也可作为效率工具套装的流量入口。

03

社会价值

降低数字工具使用门槛，让非技术用户也能享受批量处理的便利。 OCR 功能帮助视障人群、老年人提取图片文字， 让信息无障碍触达更多人群。
