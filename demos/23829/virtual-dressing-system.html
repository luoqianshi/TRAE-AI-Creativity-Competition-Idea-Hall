项目概述

  • ✓ 行业平均退换货率高达30-40%
  • ✓ 消费者购物决策困难
  • ✓ 商家运营成本增加

创意来源

作为网购爱好者，经常遇到衣服不合身、颜色与图片不符等问题，每次退货都浪费时间和精力。希望能有一个工具让网购像实体店一样可试穿。

  • ✓ 个人网购痛点驱动
  • ✓ 技术可行性验证
  • ✓ 市场需求明确
