Lit-Search · 学术文献智能检索工作台

一条命令并行检索 8 个开源学术数据库，自动去重、自动解析正式出版版本， 一键导出 LaTeX 友好的 references.bib。同时以 MCP Server 形式接入 Trae / Codex， 让 AI 副驾真正"会自己查文献"。

它解决什么

🔍

多源一次性覆盖

Semantic Scholar、OpenAlex、arXiv、CrossRef、CORE、Europe PMC、DBLP、DOAJ 一行命令全部跑完，可选 PubMed / OpenCitations / Unpaywall 增强。

🧹

自动去重 & 合并

按 DOI + 标题相似度合并多批结果，输出干净的 literature_pool.json。

📚

arXiv → 正式出版解析

开启 --resolve-preprint --prefer-published，自动把预印本反查为期刊/会议版本，引用字段优先用正式出版元数据。

📝

LaTeX 友好 BibTeX

字段尽量主流兼容，title / author / journal / booktitle / doi / eprint 等齐全，可直接 \cite{}。

🤖

MCP Server

提供 search_literature / get_paper / merge_pools / enrich_metadata / resolve_citations 五个 MCP 工具，让 Trae / Codex / Claude Code 直接调用。

♻️

可复现检索

每次检索都落盘 search_meta.json：时间、查询词、年份、源、命中数一应俱全，审稿 / 报告可直接引用。

一次命令跑完流程

# 1) 检索：8 源并行
$ lit-search "transformer, attention mechanism" -l 5 -s 2022 \
    --resolve-preprint --prefer-published

# 2) 合并多批结果 + 补全元数据
$ lit-search merge ./batch1 ./batch2 -o ./merged --enrich

# 3) 从参考文献条目反查具体文献
$ lit-search resolve ./citations.txt --output-dir ./resolved

# 输出目录
lit_search_20260625_153012/
├── search_meta.json       # 检索快照，可复现
├── literature_pool.json   # 结构化文献池
└── references.bib        # LaTeX 直接 \cite{}

数据源矩阵

类别数据源默认说明
通用Semantic Scholar / OpenAlex / CrossRef / CORE / Europe PMC / DBLP / DOAJ✅免费开源优先
预印本arXiv✅支持反查正式出版
生命科学PubMed / NCBI可选--with-pubmed 启用
增强Unpaywall / OpenCitations可选OA 元数据 / 引用关系
暂不集成IEEE / Elsevier / WoS / Dimensions / Lens / Springer❌需机构授权，留作付费增强

用 AI 副驾"自己查文献"

把 Lit-Search 接到 Trae / Codex / Claude Code 等 MCP 客户端后，模型可以直接调用：

// search_literature
{
  "query": "knowledge distillation, model compression",
  "limit": 5,
  "yearStart": 2020,
  "queryExpansion": "pairwise",
  "resolvePreprint": true,
  "preferPublished": true
}

// get_paper —— 反查单篇
{ "doi": "10.1145/3411764.3445105" }

所有工具失败时返回结构化错误（含 code / retryable / sources），LLM 可直接消费和重试。
