1创意名称 + 创意介绍

创意名称

小光

想解决什么问题

打工人的工位上什么都有，唯独缺一个「陪着你」的存在。我们被消息追着跑、专注总被打断、久坐一两个小时也没人吭声——而更深一层，一个人对着屏幕工作，其实有点孤独。小光想做的，就是当那个安静待在桌角、陪着你、也悄悄照顾你身体的小家伙。

为什么会想到做这个

灵感来自电子宠物。如果桌上有只小生物，它会因为你久坐而跟着变累、你摸摸它它会回血——那「提醒」和「休息」就不再是冷冰冰的弹窗，而是为了它、也为了你自己愿意去配合的事。它对你的关心，不是来自一个对着你的摄像头，而是来自「它陪你坐了多久」。

大概是什么产品

一个 不带摄像头、有表情、会做小动作的桌面硬件小生物。

✨ 小光的设定（「新物种」得有点来历） 一种以「陪伴」为食的小生物，它的状态是你身体节奏的一面镜子。你专注时，它安静地待在一旁，偶尔转过来看你一眼；你坐得太久，它会跟着蔫下来，提醒你歇会儿；摸摸它的头，它又重新精神起来；你离开工位，它就打个盹。它从不用镜头偷看你——它只是凭着「陪你坐了多久」，懂你。

2目标用户及痛点

面向哪些用户

长时间独自对着屏幕的脑力工作者——居家办公者、自习党、有独立工位的程序员 / 设计师 / 运营，尤其是容易分心、久坐、也容易感到孤独的人。（它个头不大、靠表情而非强光，开放工位也放得下。）

在什么场景下使用

独自在桌前工作、写代码、做方案、自习的整段时间里。它不抢戏，安静待在桌角，需要时才用表情和小动作提醒你。

当前痛点

  • 一个人工作是孤独的，工位上没有任何「陪伴感」；
  • 专注容易被打断，却没有外部抓手帮你守住节奏；
  • 久坐、疲劳全程没人提醒，等身体不舒服了才发现；
  • 现有提醒工具都是 App，弹窗只会让人更烦——没人会想「对一个弹窗好」。

3「新物种」新在哪

桌面陪伴硬件不少，但小光赌的是一个 目前没人拼齐的组合：

01 / NO CAMERA
不用摄像头 —— 它不看你，它感受你
市面上「有表情、又能感知你」的桌宠几乎都装了摄像头。小光只靠 计时 + 摸头 + 在不在工位 来懂你，把「桌面摄像头尴尬」变成它的安全感。
02 / MIRROR
你的久坐 = 它的疲惫
别的桌宠是被冷落了、饿了才不开心；小光是因为「你坐太久了」而蔫——它的情绪，是你身体状态的镜子。
03 / KNOW WHEN
它知道什么时候该闭嘴
你一进入专注模式，它就安静下来、绝不求关注。「懂得安静陪着」是小光的人设。
04 / CREATURE
不是提醒机器人，是你养的一只小生物
健康关怀藏在陪伴里——是「它在乎你」，而不是「又一个 App 在催你」。
你可能会想到车里的蔚来 NOMI，或者陪你专注的 App Focus Friend——它们分别证明了「人会爱上一张会表情的脸」「一个角色绑定你的专注很有效」。小光做的，是把这条 被验证过的情感闭环，拿掉摄像头、放进一个能摸的实体，摆上你的桌子。

4价值与意义

情绪价值（核心）

给独自工作的人一个有温度的陪伴。它不分析你的情绪，但它一直在——会回应你的触摸、记得你的节奏。就像养只猫，它不懂你的心事，但摸摸它你就被治愈了。

健康价值（配角）

陪伴是它的灵魂，「懂事」是它的表现。它把你的久坐变成自己的疲惫、催你起来动一动、专注时安静守着你——把「照顾好自己」这件事，悄悄变成你和它相处的一部分。

这正是「硬件交互 / 造个新物种」想探索的：让 AI 不再是屏幕里的一个功能，也不是又一个对着你的摄像头，而是一个 有性格、懂分寸、能陪你很久的新物种。

5第一步我们先做什么（MVP）

第一版不贪多，只做一条完整的「它有反应」的闭环—— 久坐关怀循环：

你坐下工作
→
它「醒来」，安静陪着（屏幕表情、偶尔看你一眼）
你按一下「专注」
→
进入安静模式，不打扰你，屏上静静计时
久坐 45–60 分钟
→
它跟着「累了」、蔫下来，轻轻提醒你歇会儿
你摸摸它的头
→
它重新精神起来，开始休息倒计时
你离开工位
→
它打个盹睡着

这条闭环就把它的灵魂全展示了：无摄像头地感知你的节奏 → 把你的久坐变成它的疲惫 → 用表情陪你 → 回应你的触摸。

形态：一个巴掌大、带表情屏的小生物，3D 打印外壳，没有摄像头。
进阶（后续）：会议提醒、配套手机小程序、可动作的肢体。
