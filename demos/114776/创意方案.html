产品介绍

自拍 + AI = 你的专属表情包

一个 Web 网站，三步生成表情包

表情包工作室 是一个基于浏览器的 Web 应用，用户无需下载安装任何软件。打开网页，授权摄像头，选择喜欢的艺术风格，摆好表情保持静止，AI 就会在几秒内将你的自拍转化为精美的个性化表情包。

背后由 火山方舟 Seedream 5.0 图生图模型驱动，支持 2048×2048 高清输出。同时，MediaPipe FaceLandmarker 实时识别 52 个 ARKit 表情系数，让 AI 生成的结果更贴合你当下的真实表情。

生成的表情包自动保存到历史记录，支持原图对比、灯箱放大、一键下载，随时发到任何聊天平台使用。

核心功能

六大核心能力

从表情捕捉到风格生成，从静止检测到记录管理，每个环节都经过精心设计。

📷

摄像头实时捕捉

基于浏览器 getUserMedia API，在网页局部框内实时显示摄像头画面，无需安装任何插件，打开即用。

😀

实时表情识别

MediaPipe FaceLandmarker 识别 52 个 ARKit 表情系数，支持笑容、张嘴、眨眼、挑眉、嘟嘴、皱眉等 7 种表情检测，自动融入生成提示词。

⏸️

静止检测自动拍照

自定义像素差分算法实时检测画面静止状态，保持静止 3 秒自动触发 3-2-1 倒计时拍照，无需手动按键。

🎨

19 种艺术风格

卡通可爱、二次元动漫、Q 版萌系、赛博朋克、国风水墨、像素风、黏土动画、美漫、3D 渲染等 19 种风格任你选择。

🤖

Seedream 5.0 图生图

火山方舟 doubao-seedream-5-0 模型，将自拍原图 + 风格提示词 + 表情描述融合生成，2048×2048 高清输出。

🗂️

记录管理与对比

历史记录按时间倒序展示，支持原图与生成图左右对比、灯箱放大查看、一键下载、删除管理。

技术架构

前后端分离 · AI 驱动

前端 React + TypeScript + Tailwind，后端 FastAPI + SQLite，AI 层火山方舟 Seedream 5.0，三层架构各司其职。
