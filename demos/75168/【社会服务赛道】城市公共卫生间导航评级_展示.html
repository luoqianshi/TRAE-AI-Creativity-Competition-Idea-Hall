// CORE FEATURES

核心功能：从找到到反馈的完整闭环

⚲

⚙

友好商户认证

商场、餐厅、酒店可申请"卫生间友好商户"认证，对外开放内部卫生间，获得平台流量扶持。

// TECH STACK

技术原理

LBS 定位 + 实时状态感知 + 用户评分系统 + AI 推荐引擎，构建城市卫生间数字化基础设施。

LBS 实时定位与导航

基于高德/百度地图 SDK，结合 GPS + WiFi + 基站三重定位，室内精度可达 3-5 米。路线规划支持步行导航和室内导引。

实时状态感知系统

通过用户实时反馈 + IoT 传感器（人流量计数器）双重数据源，更新卫生间空闲/排队/维护状态，延迟 <30 秒。

AI 推荐引擎

综合距离、评分、实时状态、个人偏好（如是否需要无障碍设施）多维度加权推荐，不只推荐最近的，更推荐最合适的。
