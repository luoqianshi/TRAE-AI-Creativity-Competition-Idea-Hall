做一个 DeepSeek API 用量监控悬浮球

桌面级 API 消费实时看板 · 悬浮即视

一、创意介绍

想解决什么问题：使用 DeepSeek API 的开发者每次查看余额都要打开网页 → 登录 → 找到余额页面，操作路径长，容易忘记关注消费，导致 API Key 耗尽影响业务。

为什么会想到做这个：团队日常重度使用 DeepSeek API，频繁查余额很烦，于是想做一个小工具「放在那自动刷新」，一次设置后就再也不需要主动去查了。

产品形态：Windows 桌面端应用（单文件 exe，免安装），提供悬浮球 + 系统托盘双入口。

DS

点击悬浮球展开余额面板，右键可刷新/设置/退出

二、目标用户及痛点

面向用户：使用 DeepSeek API 的独立开发者、AI 应用团队、科研人员、企业内部 AI 项目组。

使用场景：开发者在写代码、跑实验、调试 AI Agent 时，API 消费在后台持续进行，需要随时看到余额变化；企业管理者希望团队成员能直观看到 API 预算消耗情况。

当前痛点：

  • 查余额需打开网页 → 登录 → 导航到余额页，至少 3 步操作
  • 没有实时提醒，余额耗尽时才发现，影响线上业务
  • 同时管理多个 API Key 时容易混乱
  • 命令行工具不够直观，非技术成员使用门槛高

三、产品功能亮点

🔄 5 分钟自动刷新

设置一次 API Key 后，每 5 分钟自动查询余额，无需任何手动操作

🎨 桌面悬浮球

半透明渐变圆球常驻桌面，点击展开详情面板，拖拽可随意移动位置

🖱 右键快捷菜单

右键悬浮球快速刷新/修改设置/退出，系统托盘也提供完整菜单

🔒 本地安全存储

API Key 加密保存在用户本地配置文件，不随 exe 传播

四、价值与意义

效率提升：将查余额从「主动操作」变为「被动感知」—— 开发者无需中断工作流去查网页，余光一扫就知道余额状态。按每天查 3 次、每次 30 秒计算，每名开发者每月节省约 45 分钟。

商业价值：帮助企业有效管理 API 预算，避免因余额耗尽导致的业务中断。在 API 经济快速发展的当下，这类轻量级监控工具存在广泛需求，可以拓展支持其他大模型平台（OpenAI、Claude、Gemini 等）的余额监控。

社会价值：降低 AI 开发者的工具使用门槛，让更多人可以专注于创造本身，而不是被基础运维琐事分心。开源共享也能让社区共同迭代，形成良性生态。
