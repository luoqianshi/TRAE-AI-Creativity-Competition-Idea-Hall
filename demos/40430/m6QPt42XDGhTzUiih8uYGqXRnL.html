THE PROBLEM

家长每天都在担心，
却无处可查

过去三年，婴幼儿产品安全事件呈现"高频化、隐蔽化、跨品类化"特征。家长面临三大核心痛点：

⚠️

买前无法判断安全性

面对货架上十几个品牌，家长依赖碎片化测评，小红书、抖音内容质量参差不齐，品牌软文与真实评价难以区分。

68% 的家长表示"越查越迷茫"
🔔

买后不知产品被召回

召回公告散落在各监管机构网站，触达效率极低。超过 60% 的家长在召回发布一个月后仍不知情，继续使用问题产品。

仅 12% 一周内知晓召回
🆘

召回后不知如何处理

即便偶然看到召回新闻，家长也不清楚自己买的是否在召回批次、该如何退换维权、宝宝是否已受影响。信息不对称让维权举步维艰。

超 60% 家长不知如何维权
REAL CASE

三品牌纸尿裤事件
催生了婴查查

2026 年 5 月的真实事件，揭示了召回信息触达的致命短板。婴查查的核心使命是：当召回发生时，第一时间提醒用户停用并维权；同时通过异常信号监测，尽量为家长争取提前避险窗口。

Day 0 · 5月12日

三大电商平台集中下架

天猫、京东、拼多多同日下架 A/B/C 三个品牌纸尿裤。婴查查监测到"多平台同步下架"异常信号（锦上添花的提前预警能力）。

Day 0 · 当日

婴查查推送风险预警

向产品库中含这 3 个品牌的用户推送预警，建议暂停使用。用户比媒体提前 2 天知晓，争取到避险窗口。

Day 2 · 5月14日

媒体爆出质检结果

某财经媒体率先报道，三个品牌纸尿裤质检出甲醛与可迁移性荧光物质超标。多数家长此时才第一次听说。

Day 4 · 5月16日

官方发布召回公告 · 婴查查核心动作

市场监管总局正式发布召回。婴查查立即向所有受影响用户推送召回通知，告知召回批次、退换渠道、维权步骤，指导用户及时处理。

THE SOLUTION

买前查一查，买后自动盯，
召回即提醒

婴查查是面向 0-12 岁儿童家长的全链路婴幼儿产品安全预警工具，以微信小程序为主，覆盖"买前决策—买后监控—召回维权"全生命周期。

01

召回提醒与维权引导

当产品被官方召回时，第一时间向产品库中持有该产品的用户推送召回通知，告知召回批次、退换渠道、维权步骤，指导用户及时停用并维权。核心痛点功能。

召回触达 维权引导 多通道推送
02

买后主动监控

用户将已购产品录入产品库后，平台 7×24 小时持续监控召回、投诉、质检等动态。一旦发现风险立即推送，将召回触达率从 12% 提升至 95%+。

产品库 自动匹配 持续监控
03

买前安全查询

扫码或搜索，3 秒内获得商品安全评分、召回记录、投诉数据、质检信息、代工厂信息等综合安全报告。

扫码即查 五维评分
04

安全比价

价格 + 安全双维度推荐。不仅比价格，更叠加安全评分——"价格↓ + 安全✓"双推送，区别于慢慢买的纯价格比价。

180天价格曲线 降价提醒
05

安全科普 + 每日日签

用精美图片做科普，避免大段文字。每日安全日签打卡提升活跃，7 天 322 激励模型培养打开习惯。

一图读懂 日签打卡
06

召回处理状态机

当产品被召回时，不仅提醒用户，更跟进处理进度。用户按状态机逐步推进（确认批次→联系商家→寄回→维权），直到"已处理"才关闭强提醒。填补官方机构不跟踪个人处理的空白。

状态机跟踪 分级提醒 维权引导
07

订单截图批量录入

一次上传多张电商订单截图，OCR + 大模型自动识别商品信息并批量入库。置信度标注 + 人工校正，隐私脱敏合规，极大降低录入门槛。

OCR识别 多图批量 隐私脱敏
08

早期风险预警（锦上添花）

监测电商异常下架、投诉激增、舆情异常等 7 类信号，通过信号融合算法在官方公告前 2-7 天提前预警，为家长争取额外避险窗口。

信号融合 贝叶斯模型 人工复核

TECH HIGHLIGHTS

技术驱动的
安全守护

两大技术亮点构建产品护城河：液态玻璃设计语言与 AI 知识库。

液态玻璃设计系统 V1.1

  • 借鉴 Apple Liquid Glass（WWDC 2025）与华为沉浸光感设计，打造精美界面，建立第一印象差异化
  • 三层架构：控件层（液态玻璃）+ 内容层（标准材质）+ 背景层，安全信息禁用半透明保证可读性
  • 分级降级策略：高端设备完整液态玻璃，低端 Android 降级为纯色 + 阴影方案
  • 无障碍保障：高对比度模式、WCAG AA 标准对比度、字号可放大 150%
  • 性能约束：单屏 backdrop-filter 元素 ≤2，强制 GPU 加速，滚动帧率 ≥50fps

AI 知识库 + Agent V1.2

  • RAG 架构：BGE-M3 向量模型 + Milvus 向量数据库，支持混合检索（向量 + BM25）
  • GraphRAG 知识图谱：构建"物质-产品-法规-召回"关联图谱，支持风险传导分析
  • 第三方对接：兼容 Dify 外部知识库 API 规范与 MCP 协议，可被外部 Agent 平台挂载
  • 句子级引用溯源：AI 回答每句话可点击查看出处，引用准确率 ≥90%
  • 安全红线：置信度不足转人工，标准空白显式标注，无引用不输出安全判定
