创意介绍

**核心痛点**：AI 编程助手往往只能完成单轮任务，无法持续迭代、自我纠错、独立完成复杂项目。开发者需要反复介入，效率低下。

Claude-Loop 是一个革命性的 AI 自主编程循环系统，实现了六大核心构件的深度集成，让 AI 能够像人类开发者一样持续工作：

  • Automations（自动化心跳）：30分钟伪随机唤醒机制，实现持续自运行
  • Worktrees（工作树隔离）：基于 Git worktree 的物理隔离，解决多 Agent 并发写入冲突
  • Skills（技能资产）：可复用的技能沉淀，避免每轮从零解释项目，大幅降低 Token 浪费
  • Connectors（MCP连接器）：对接外部系统，让 Agent 可操作真实工具链
  • Sub-agents（子代理）：Maker-Checker 架构，独立校验保障无人值守可靠性
  • Memory（记忆管理）：上下文遗忘与持久化，控制运行时上下文体量

核心设计原则

🔍 Maker-Checker 分离原则

单模型自校验存在自宽容问题，必须由第二个独立 Agent 做校验，是无人值守循环可信度的核心保障。

📚 技能沉淀原则

循环本身是管道，真正资产是可复用的 Skill。无 Skill 的循环每轮需重新推导项目约定，Token 效率极低。

🔒 多 Agent 并发隔离原则

禁止多 Agent 直接操作同一份文件，必须通过 worktree 做物理隔离，最终再合并结果。

Token 优化策略

  • 协调者只路由不推理：主协调 Agent 仅做任务分发，不执行具体推理
  • 中间结果存脚本变量而非回传协调者：避免 O(n) 级的上下文膨胀
  • 文件按需下发：每个子 Agent 只接收完成任务必需的文件
  • 短期记忆截断：仅保留最近 3-5 轮交互，更早上下文落盘持久化
  • 心跳+时间抖动替代不间断循环：30分钟 ±20% 伪随机唤醒机制
