把人声，看成 一条会唱歌的曲线

VocalPitch Analyzer 是一套面向中文歌声的音高分析与可视化引擎。它把一段干声拆解为逐帧 F0 曲线、字级歌词时间戳与音符块，在类 MIDI DAW 的钢琴卷轴上重现滑音、颤音与每一次咬字的瞬间。

Capabilities

为歌声而生的每一个细节

不是把语音工具套在歌上，而是针对滑音、拖腔、melisma、连唱与一字多音逐一攻坚。

RMVPE 音高提取

专为歌声训练的 F0 模型，彻底压制 FCPE 偶发的二/三次谐波误锁导致的「高八度」跳变。mel 强制 htk=True。

5ms · 抗八度跳变

识别 / 定时解耦

Qwen3-ASR-1.7B 负责「唱了什么」，FunASR fa-zh 强制对齐负责「何时唱」。各司其职，比单一端到端模型在带腔歌声上稳一档。

Qwen3-ASR + fa-zh

可插拔音符切口

builtin 谱通量 onset、openvpi SOME 与 GAME 三选一。union 模式补出滑音 / 一字多音切口，却不污染歌词位置。

builtin ∪ GAME

声学重锚

全局漂移校正 + 紧容差单调吸附，把对齐器在长段内累积的时机漂移就地拉回真实起音。

reanchor

力度 / 气声曲线

融合 RMS 力度曲线与气声估计，钢琴卷轴上同步呈现强弱与音色变化。

dynamics · breathiness

钢琴卷轴 GUI

C1–C8 键盘、BPM 联动小节线、滚轮缩放、拖拽浏览、点击播放、播放同步高亮——一个真正能用的可视化台。

PySide6
VOCALOID Ecosystem

从真实人声，进入虚拟歌手工作流

分析结果不只用于观察。桌面端可直接导出 VOCALOID6 工程，把音符、中文歌词、音素、原始音高走势和表现力参数带入编辑器继续调声。

VOCALOID6 · .vpr

人声扒谱到 V6 工程，不止 MIDI 音符

导出器生成原生 .vpr 工程：BPM 与音符时值保持一致，中文拼音转换为 VOCALOID 音素，延音符正确保留，并把逐帧 F0 转成 directPitch，尽可能留下原唱的滑音与颤音轮廓。

01 · INPUT干声 / 分轨WAV · FLAC · MP3
02 · ANALYZE音高与字级时机F0 · lyrics · onset
03 · EXPORTVOCALOID6 工程notes · phonemes · directPitch
04 · TUNE歌手与表现力继续调教、混音与渲染

中文音素映射

无声调拼音按 VOCALOID6 中文音素表转换；未知读音保留给编辑器重算，延音使用原生 phoneme="-"。

表现力参数通道

除 directPitch 外，工程还可携带 brightness、air 与 breathiness 等控制曲线，作为后续调声起点。

开放中间数据

SongData JSON 保留音符、字级时间戳、F0、力度和气声，可继续编写 Synthesizer V、OpenUTAU 或其他 DAW 的适配器。

Transcribe Routes

两条转录路线，一键切换

新路线追求字级精度，旧路线完整保留以备多语言与回退。仅由 TRANSCRIBE_ROUTE 一个开关决定。

Post-Alignment

把 fa-zh 的每一处错位掰回原位

强制对齐器面向说话训练，遇到歌声的压扁、拖腔、丢字会系统性错位。这些算法逐一拦截——全部由实测真值反复验证、净负即默认关。

密度驱动两遍对齐
长段前密后疏被压缩 → 在最大字距处二次细切重对齐
压扁展开 spread
多字压到同一时刻 → 按首尾 onset 锚点均匀展开
整链右移 misfill
一个音符被劈成两音节 → 整段后继歌词右移一格
整链左移 dropshift
ASR 丢字 → 识别到强 onset 后整链左移复位 + 插「-」占位
擦音前向吸附 vsnap
x/q/j/ch/s 摩擦段自动跳过，定到元音起点
孤立字扩容差
段首 / 长间隙后字对齐容差扩到 200ms 找回真起音
w 滑音平台吸附
w 声母字音高抵达稳定平台才标起点（只打 w 不碰 y）

合格口径

每个字的起点时间与人工标注真值之差，落在该 BPM 下一个十六分音符的时长之内即为合格。melisma 长音、无 onset 的软起音为剩余误差主因。

Get Started

装一次，浏览器里上传就出谱

首次要跑一遍安装器——它自动建 venv、装 CUDA 版 PyTorch、下载几个 G 的模型，确实得等一会儿。装完之后日常只有两步：启动服务、浏览器拖音频。客户端零依赖，重活全在服务端。命令行只是给批处理/自动化用的可选项。

PowerShell — vocal_pitch_analyzer
# ① 一次性安装（在上级 pp/ 目录，建 venv + CUDA PyTorch + 下载模型，喝杯咖啡）
install_all.bat

# ② 日常：启动网页端，浏览器打开 http://localhost:8000
.\web\run_web.ps1
#    → 拖入音频，服务端跑全精度链路，浏览器实时渲染钢琴卷轴

# 可选：桌面 GUI（PySide6）
python main.py --gui

# 可选：命令行批处理 / 自动化（更轻的 CLI 路径）
python main.py -i audio.wav -o result.json --bpm 120
