Concept Review — 卡片式概念扫盲 Web 应用

想解决什么问题

学习任何新领域的本质，就是不断学习新概念。不管是数学、经济学还是哲学，几乎全是"认识一个新词 → 理解它是什么意思 → 把它和已经知道的词连起来"的过程。但市面上大多数学习工具要么太深（教材级、系统课程），要么太浅（碎片资讯、短视频科普），缺少一个中间层——让你能快速对一个行业的核心概念有一个"一针见血"的粗浅认识。

为什么想到做这个

我们在学习新领域时，最大的障碍不是"没有时间学"，而是"要学的东西太多了，不知从哪下手"。如果能先把一个行业里最核心的概念（黑话）快速过一遍，用卡片式的极简解释让你先大概知道它是什么，再用 AI 深度解读让你稍微深入一点点，再用自由问答解决你想追问的问题——这个过程不是让你精通，而是让你快速消除对这个行业的"陌生感"。

大概是什么产品

一个"卡片式概念扫盲"Web 应用，内置 47 个预置概念覆盖 AI、金融、哲学领域，开箱即用。核心不是复习，而是学习新概念：每张卡片用一段精炼直白的解释让你一针见血明白这个词在说什么；如果还想深入了解，AI 会生成结构化深度解读（前置定义、核心拆解、生活类比、常见误解、自测题）；学完有疑问，直接和 AI 自由问答。此外支持行业黑话自动发现功能——输入一个行业词，AI 自动搜索最新的术语和概念，一键加入你的概念库。

⚡ 核心功能一览

从扫盲到深入，一条完整的学习链路

🃏

卡片扫盲

47 个预置概念，三段式精炼解释（钩子开场 + 核心定义 + 生活类比），一张卡片消灭一个陌生词

🤖

AI 深度解读

点击"深度阅读"，AI 自动生成结构化文章：定义拆解、底层机制、常见误区、自测题

💬

自由问答

对概念还有疑问？直接打字问 AI，不限次数，像有一个老师坐在旁边

🔍

黑话发现

输入任意行业关键词，AI 自动搜索最新术语，一键加入概念库继续学习

🌌

概念星图

可视化展示概念之间的关联网络，帮你建立领域认知地图

📊

学习分析

学习进度、分类统计、每日回顾，让你清晰看到自己的认知扩展轨迹

💎 价值与意义

🧠 认知价值 — 消灭陌生感

这个工具不是让你"精通一个领域"，而是帮你快速消灭对陌生领域的陌生感。当你对一个行业的几十个核心概念都能说出两句，你对这个行业的认知地图就已经建立起来了。

⚡ 效率价值 — 开箱即用

47 个预置概念 + AI 自动深度解读 + 行业黑话自动发现，让你不需要手动录入、不需要自己搜资料、不需要自己做笔记。打开就能用，碎片时间就能学。

❤️ 情感价值 — 了解本身就是一种安慰

这个产品承认一个事实——大部分人学习新领域只是为了"不焦虑"，不是为了成为专家。它不拿"系统学习"、"深度学习"来压你，而是让你在碎片时间里，一点一点地消除对陌生世界的不安全感。"了解"本身，就是一种安慰。

🛠️ 技术实现

基于 TRAE Work + DeepSeek API 构建

Python / Flask HTML / CSS / JavaScript (SPA) DeepSeek API SM-2 间隔重复算法 RESTful API 响应式设计
  • 后端：Flask REST API，复用核心 SM-2 复习算法，匿名 Session 隔离用户数据
  • 前端：纯前端 SPA，统一 API 适配层，支持桌面端（pywebview）和 Web 双模式
  • AI 能力：接入 DeepSeek API，实现深度文章生成、概念问答、黑话自动发现
  • 数据：47 个预置概念覆盖深度学习、机器学习、AI 应用、经济学、金融投资、哲学六大领域
  • 开发过程：全程在 TRAE Work 中完成，完整留痕，支持持续迭代
