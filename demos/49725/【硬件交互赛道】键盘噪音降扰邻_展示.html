Pain Points

为什么我们需要一个硬件解决方案

软件降噪虽然存在，但面对机械键盘的持续敲击仍然力不从心

🎧
软件降噪不彻底
主流软件降噪（如 Krisp、Teams 内置降噪）针对环境噪声效果不错，但键盘敲击频率高、波形复杂，经常出现「漏音」或「声音变闷」的问题。
"降噪开了跟没开一样，键盘声还是噼里啪啦的"
🏢
共享办公/开放式会议
在共享工位、图书馆、咖啡馆办公时，键盘敲击声会严重干扰周围人。尤其是青轴、红轴等机械键盘，敲击声可达 60-70dB，相当于正常对话音量。
"同事说我的键盘声让他无法集中注意力"
🖥
录制/直播场景失控
录制教程、直播编程时，键盘噪音直接进入收音通道。后期降噪处理会带来明显延迟感和音质劣化，严重影响内容质量。
"录完的视频键盘声太大了，降噪后又觉得声音很假"
Core Features

从源头拦截，而非事后补救

夹在键盘和电脑之间，在声音传播前就完成处理

🔌
USB Passthrough 透传
模块同时拥有 USB-A 输入和输出接口，键盘信号完整透传，不影响打字体验。支持全键无冲，延迟增加小于 1ms。
🧠
边缘 AI 音频处理
内置 DSP 芯片 + 轻量化神经网络模型，实时分析键盘声波特征（敲击频率、谐波结构），精准识别并抑制键盘噪音，保留人声完整性。
🎙
虚拟音频通道输出
通过 USB Audio Device 协议向系统注册虚拟麦克风，输出的音频已去除键盘噪音。任何软件（Zoom、腾讯会议、OBS）直接选用即可。
🎨
降噪强度可调
通过顶部触控条或配套小程序调节降噪等级（轻度 / 中度 / 强力），适应不同键盘类型和场景需求。LED 环灯实时显示当前状态。
📱
状态可视化面板
微信小程序可实时查看降噪统计：已过滤噪音时长、噪音峰值记录、日均降噪效率趋势。帮助用户了解使用习惯并优化设置。
🔋
超低功耗待机
采用 ARM Cortex-M4F 低功耗核心，典型功耗仅 0.5W。无需外接电源，由 USB 总线供电，7×24 小时稳定运行。

Technical Architecture

技术原理

五层处理管线，从信号采集到纯净输出

1
MEMS 麦克风阵列采集
内置两颗高灵敏度 MEMS 数字麦克风，形成微型阵列。一颗靠近键盘侧拾取噪音参考信号，一颗拾取混合音频。双通道差分采集为后续分离提供基础。
MEMS 双通道 24bit / 48kHz
2
FFT 频谱分析引擎
使用 256-point FFT 对音频流进行实时频域转换，提取频谱特征。键盘敲击声集中在 2-8kHz 频段，具有明显的短时冲击特征（attack time < 5ms），与人声（300Hz-3.4kHz、较长的元音持续）有本质区别。
FFT 频域分析 STFT
3
轻量化 CNN 分类模型
在 DSP 上运行的定制 CNN 模型（约 120KB 权重），输入为 128×64 频谱图，输出为键盘声/人声/环境噪声三分类概率。模型在 5000+ 条键盘录音数据集上训练，识别准确率 > 96%。推理耗时 < 2ms。
CNN TensorFlow Lite Micro 120KB
4
自适应频域抑制 (AFS)
传统降噪对整个频谱一刀切，AFS 只衰减被识别为键盘声的频段分量。结合自适应滤波器跟踪键盘声的非稳态特征，动态调整抑制深度，避免过度处理导致人声失真。残余噪声控制在 -40dB 以下。
AFS 自适应滤波 < -40dB
5
USB Audio Device 输出
通过 USB UAC 2.0 协议向操作系统注册为虚拟音频设备。无需安装驱动——Windows、macOS、Linux 均原生识别。任何音频软件选择该设备即可获取降噪后的纯净音频，端到端延迟 < 5ms。
UAC 2.0 免驱动 跨平台
Why Hardware

为什么选硬件而非软件降噪

从源头拦截，效果和体验远超软件方案

对比维度 KeySilent 硬件方案 软件降噪 (Krisp/Teams)
处理位置 ✓ 声音传播前拦截（源头） ✗ 声音进入系统后处理（事后）
键盘声过滤 ✓ 专用键盘声纹模型，95% 过滤率 ✗ 通用噪声模型，键盘声容易漏掉
人声保真度 ✓ 只衰减键盘频段，人声几乎无损 ✗ 容易产生闷声、电音感
延迟 ✓ < 5ms 端到端延迟 ✗ 20-50ms，可能有明显回声
兼容性 ✓ 所有软件通用（虚拟麦克风） ✗ 部分软件不兼容或效果不稳定
CPU 占用 ✓ 零 CPU 占用（独立 DSP） ✗ 持续占用 5-15% CPU
使用门槛 ✓ 插上 USB 即用，零配置 ✗ 需安装软件 + 授权 + 配置

Value & Impact

价值与意义

🤝
社会价值：减少噪音污染
开放式办公和共享空间中的键盘噪音是常见的人际摩擦来源。KeySilent 从物理层面消除噪音传播，改善办公环境的声学体验，减少因噪音引发的同事关系紧张。尤其对需要安静环境的听障人士、注意力障碍者更有实际帮助。
⚡
效率价值：零门槛使用
相比软件降噪方案需要安装配置、占用系统资源、效果不稳定，KeySilent 的硬件方案实现了真正的「即插即用」。不改变用户的任何使用习惯，不占用电脑性能，对任何软件都透明兼容。这对不擅长技术设置的用户尤其友好。
