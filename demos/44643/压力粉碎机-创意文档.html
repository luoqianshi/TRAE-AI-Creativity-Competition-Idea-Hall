压力粉碎机

打它不是为了分，是为了听它求饶。

赛道：生活娱乐 / 造点新花样 产品定位：纯前端 H5 互动小游戏 技术栈：HTML5 + CSS3 + Vanilla JS

一产品概述

创意一句话

把生活中的烦恼（老板、甲方、KPI、堵车）变成游戏里的目标，拿起锤子打爆它们，听它们用塑料方言求饶，打完还能生成一张「压力释放证书」发朋友圈。

为什么适合 TRAE 大赛

  • 纯前端，零依赖：HTML + CSS + JS，无需后端、无需模型加载，打开即玩。
  • Vibe Coding 友好：DOM 操作 + CSS 动画 + speechSynthesis，TRAE 生成准确率极高。
  • 传播性强：录屏时目标突然开口「塑料方言求饶」，比静音游戏更有抖音爆点。
  • 情绪价值明确：生活娱乐赛道的核心就是「更便捷、有趣、有温度的生活方式」，「解压」是真实日常需求。

四分步实现指南

建议把下面的每一步单独复制给 TRAE 执行，每步完成后手动测试，再进入下一步。避免一次性给太多需求导致代码混乱。

Step 1：搭建骨架与欢迎页

创建单页 HTML 应用，包含 5 个全屏页面。欢迎页：深蓝色渐变背景 + 大标题「压力粉碎机」+ 打字机效果副标题 + 脉冲动画「开始解压」按钮。

Step 2：情绪体检页

页面标题「今天什么让你最不爽？」。预设 10 个压力源标签（老板、甲方、KPI、加班、工资、堵车、房贷、相亲、早起、快递迟到），可多选最多 3 个，支持自定义输入。已选标签以红色胶囊展示，可删除。选择至少 1 个后，「下一步」按钮亮起。

Step 3：目标设置页

左侧预设 Emoji 目标（👴老板、👹恶魔、📊KPI、🚗堵车、🏠房贷、🐔早起的鸡），右侧支持上传图片（FileReader + 圆形预览）。如果从情绪体检页选择了「老板」，进入本页时默认高亮 👴。

Step 4：武器选择页

4 个武器卡片横向排列：🔨 正义之锤（标准打击）、🏏 狼牙棒（暴击翻倍+震动）、🩴 家长拖鞋（「啪」字飞出）、🪄 魔法棒（随机变形）。点击高亮，底部「进入战场」按钮。

Step 5：游戏主界面（核心）

顶部状态栏（分数 + 60 秒倒计时），中间 3×3 网格游戏区，底部武器/目标预览。目标每 1~2 秒随机冒出，停留 1.5 秒。击中：压扁动画 + 分数 +10/20 + speechSynthesis 求饶语音 + 飘字动画。未击中：缩回 + 嘲讽语音。不同武器对应不同特效。

Step 6：结果页与分享证书

彩纸飘落动画 + 压力释放报告卡片（总分数、击中率、连击最高纪录、评级）。4 个评级等级：初级打工人 → 暴躁老哥 → 解压大师 → 情绪掌控者。底部「再来一局」和「生成证书」按钮，证书支持截图分享。

字体与动画原则

  • 标题：系统默认无衬线字体，font-weight: 700
  • 数字：等宽字体（monospace），强化游戏感
  • 大小层级：标题 32px → 副标题 18px → 正文 16px → 标签 14px
  • 所有状态变化都要有过渡（transition: all 0.3s ease）
  • 目标冒出用 ease-out，缩回用 ease-in
  • 击中反馈要即时（< 100ms），先反馈后动画

七关键实现注意事项

speechSynthesis 兼容性

  • iOS 限制：语音必须在用户交互后触发，游戏开始前必须有「点击开始」覆盖层
  • 中文语音：使用 getVoices() 获取中文语音，无中文语音时默认语音读中文（塑料感反而更搞笑）
  • 避免语音重叠：击中时先 cancel() 再播放新的

图片上传处理

  • 使用 FileReader.readAsDataURL() 读取为 Base64
  • 限制文件大小 < 2MB，过大时提示压缩
  • 统一用 object-fit: cover + border-radius: 50% 做成圆形

移动端适配

  • 游戏网格在手机上保持 3×3，格子尺寸自适应（vmin 单位）
  • 按钮最小点击区域 44×44px

性能优化

  • 游戏循环用 setInterval / setTimeout 即可
  • 飘字动画元素用完后及时 remove()，避免 DOM 堆积
  • 页面切换时暂停游戏逻辑，避免后台计时器继续运行
