Pain Points

看不见的敌人，用不下去的除螨仪

三分之二的家庭拥有除螨仪，但大多数在柜子里吃灰

👀

用了也不知道有没有用

螨虫肉眼不可见，传统除螨仪没有清洁反馈。每次吸完，用户仍然心里没底——"到底吸干净了没有？"没有确定性，就没有坚持的动力。

😏

"买来吃灰"的宿命

室友的除螨仪用了两次就收进柜子。没有可视化反馈和激励机制的硬件，用户使用频率在第三周就会断崖式下降。这不是产品不好，是交互缺失。

🌫

过敏反复却找不到原因

过敏性鼻炎患者反复发作，却不知道症状与床铺清洁频次的关联。缺乏数据记录，无法判断"是不是该清洁了"或"清洁频次够不够"。

Core Features

六大核心功能

看得见的清洁，用得下去的好习惯

💫

253.7nm UVC 杀菌

搭载医疗级 UVC 紫外灯管，波长 253.7nm，破坏螨虫 DNA 结构，杀菌率 99.9%。智能感应——离开被面自动熄灭，保护用户安全。

⚡

8000 次/分高频拍打

内置高速拍打模块，每分钟 8000 次高频振动，将深藏于纤维内部的螨虫和过敏原拍出表面，配合吸力高效清除。

🏠

清洁热力图

APP 通过陀螺仪轨迹实时绘制清洁覆盖区域，生成"床铺热力图"。绿色=已清洁，红色=遗漏。一目了然，再无盲区。

📈

清洁评分系统

综合覆盖率、清洁时长、移动均匀度三个维度，每次清洁给出 0-100 分评分。像智能牙刷一样，让清洁变成有成就感的事。

🤖

AI 智能推荐

根据过敏状况、气候条件（梅雨季螨虫高发）、历史清洁频次，AI 自动推荐清洁周期和重点区域。"本周建议清洁沙发右侧"。

📊

健康趋势报告

每周/月生成清洁报告：覆盖率趋势、过敏发作频次与清洁习惯的关联分析。帮助用户和医生建立"清洁-健康"数据关联。

Hardware

硬件结构

三个核心模块，一个清洁解决方案

手持握把 + 蓝牙模块

人体工学握把，内置 BLE 5.0 蓝牙芯片与六轴陀螺仪，实时传输设备姿态与移动轨迹到 APP

UV-C 紫外杀菌灯

253.7nm 医疗级 UVC 灯管，功率 5W，有效照射面积 30cm²。内置倾倒自动断电保护

高频拍打 + 强力吸尘

8000 次/分高频振动拍打，12000Pa 大吸力。HEPA 滤网拦截 0.3μm 以上微粒，防止二次污染

可更换滤芯设计

HEPA 滤芯 + 粘尘板双层过滤，建议每 3 个月更换。磁吸式设计，一按即换。耗材复购保障持续收入

Use Cases

谁需要它

看不见的螨虫威胁，看得见的清洁守护

🎁

过敏性鼻炎患者

每周清洁床垫，APP 记录清洁趋势与过敏发作频次。几个月后发现：清洁频次从每周一次提升到两次后，夜间打喷嚏减少了 60%。

👶

有婴幼儿的家庭

婴儿皮肤娇嫩，对螨虫过敏原极度敏感。热力图确保婴儿床每个角落都被覆盖，APP 提醒"本周婴儿床清洁评分下降，建议补清洁"。

🐱

养宠家庭

宠物毛发是螨虫的"豪华大巴"。对宠物窝垫、沙发区域重点清洁，APP 标记"宠物区"为高频清洁区域，自动提高推荐频次。

🏨

酒店/民宿自备清洁

入住酒店时用自己的除螨仪快速清洁床铺。轻量化设计仅 800g，塞进行李箱不占空间。出门在外，也要睡得安心。

AI 推荐

频次 + 区域

设备端六轴陀螺仪以 50Hz 采样率记录姿态数据，通过 BLE 5.0 低功耗蓝牙实时传输至手机。APP 使用传感器融合算法将姿态数据映射为二维清洁轨迹，再通过网格化算法生成热力图。云端 AI 模型结合用户过敏标签、当地气象数据（温湿度、降雨量）和历史清洁记录，输出个性化清洁建议。

Value

行为设计价值

💰

商业可持续价值

硬件销售 + HEPA 滤芯耗材复购（每 3 个月一换，类似净水器模式）+ 高级数据分析订阅。耗材复购带来持续收入，用户粘性极强。
