Socialer

社交媒体聚合管家 —— 一站式多平台内容浏览、语音播报与批量发布工具

Electron + Vue + Playwright + Edge TTS

创意介绍

在这个信息爆炸的时代，我们每天需要在多个社交媒体平台之间来回切换——刷微博看热点、上小红书找攻略、逛 V2EX 看技术讨论、去 YouTube 看视频... 频繁切换不仅效率低下，还让眼睛疲惫不堪。

Socialer 应运而生：一个基于 Electron 的桌面应用，将小红书、微博、饭否、X(Twitter)、抖音、YouTube、Threads、V2EX、维基百科等九大平台聚合到一个窗口中。更独特的是，它集成了 Edge TTS 语音播报功能，可以自动为你朗读各平台的文字内容，让你解放双眼、用耳朵"刷"社交媒体。

小红书 微博 饭否 X / Twitter 抖音 YouTube Threads V2EX 维基百科

核心功能

🌐 多平台聚合浏览

Tab 切换浏览 9 大主流平台，每个平台独立 WebView 会话，支持登录状态保持，鼠标移开自动贴边收缩。

🔊 循环语音播报

基于 Edge TTS 技术，自动按顺序切换平台、提取文字内容并用自然语音播报，支持定时启停。

📝 批量内容发布

一键将图文内容同时发布到多个平台，支持小红书、微博、X、抖音等，省去重复编辑的麻烦。

▶️ YouTube 自动播放

自动获取 YouTube 推荐视频列表并顺序播放，支持播放进度跟踪和跳过功能。

💬 Threads 自动阅读

自动获取 Threads 动态帖子队列，用语音播报作者和内容，打造沉浸式社交阅读体验。

⌨️ 全局快捷键

支持自定义全局快捷键，在任何界面都能快速触发循环播报、切换抖音视频等操作。

技术亮点

Electron 29 Vue 3 + Composition API TypeScript Vite Playwright Edge TTS Element Plus Pinia

创新点

  • 首创"用耳朵刷社交媒体"的语音播报模式，支持多平台内容自动提取与朗读
  • 智能页面内容提取引擎，针对不同平台（微博、Twitter、饭否等）定制 DOM 解析策略
  • 基于 Playwright 的自动化浏览器控制，实现 YouTube 和 Threads 的深度交互
  • 贴边悬浮窗口设计，不占用桌面空间，随用随取
  • 定时启停 + 全局快捷键，真正实现"无感"信息获取

适用场景

上班族通勤路上：开启循环语音播报，让 Socialer 自动朗读微博热点、技术社区讨论、维基百科随机知识，充分利用碎片时间。

自媒体创作者：在一个窗口管理多个社交平台账号，写一次内容批量发布到小红书、微博、X、抖音等平台。

视力障碍人士：通过语音播报功能无障碍获取社交媒体信息，降低信息获取门槛，具有积极的社会公益价值。

多屏办公用户：将 Socialer 贴边到屏幕边缘作为信息副屏，不干扰主工作区，随时扫一眼或听一听最新动态。
