人机协同交易操作系统

以 Obsidian 知识库为核心、Trae 驱动的人机协作投研体系
核心理念：人不做机器能做的事，机器不做只有人能做的事

1 核心理念与定位

本系统不是全自动交易软件，而是一个帮助个人投资者建立交易纪律、系统复盘、持续成长的人机协同训练平台。

系统定位：人的交易训练 + AI辅助分析 + AI自动化数据收集 + AI风控预警 + 人把控最终决策的有机互动体系。

系统围绕 Obsidian 知识库构建，利用 Trae Work 的对话能力进行数据整理与分析，Trae IDE 提供量化代码增强，TdxClaw 提供盘中实时行情辅助，形成完整的数据采集 → 知识沉淀 → 研判分析 → 风控执行 → 学习迭代五层架构。

4 两大闭环设计

4.1 模拟训练闭环

在通达信模拟盘中进行主观交易训练，训练数据形成采集 → 分析 → 优化闭环：

人在通达信模拟操作
       ↓
操作记录导出（手动输入 / TdxClaw截图 / CSV导出）
       ↓
Trae Work 自动 ingest 到知识库（结构化写入）
       ↓
Trae Work 基于操作记录+行情数据 生成复盘文档
       ↓
自动计算训练指标（胜率 / 盈亏比 / 纪律执行率 / 最大回撤）
       ↓
生成训练周报，识别薄弱环节
       ↓
形成下一轮训练的改进目标 → 回到起点

4.2 实盘交易数据闭环

实盘交易数据自动结构化、可视化，形成持续迭代的决策优化循环：

实盘交易操作（人在券商APP执行）
       ↓
操作记录录入 Trae Work（对话输入 / 截图）
       ↓
Trae Work 自动补充行情数据（AKShare / 东方财富）
       ↓
自动更新个股实体页（价格 / 仓位 / 浮盈亏）
       ↓
收盘后 Trae Work 生成当日复盘文档
       ↓
盘前 Trae Work 生成次日预案（基于投资者档案约束）
       ↓
Trae Work 定时任务执行风控检查
       ↓
形成持续迭代的决策优化循环

5 风控自动化体系

风控规则来自投资者档案中的硬性约束，由人预先设定：

  • 单票上限 — 单只股票持仓市值 / 总资产 ≤ X%
  • 总仓位上限 — 总持仓市值 / 总资产 ≤ X%
  • 止损线 — 每笔交易的硬性止损价位
  • 最大回撤线 — 周度/月度净值最大回撤警戒线
  • 板块集中度 — 同一板块持仓占比 ≤ X%

风控定时任务

时间 任务内容 输出
盘前 08:50 拉取持仓市值，计算仓位占比，与投资者档案对比 仓位占比报告；超限预警
盘中 每30分钟 监控止损偏离（当前价 vs 止损线） 止损偏离预警
收盘 16:00 汇总当日风控状态 风控日报
核心原则：AI计算+预警，人决策+执行。AI 绝不直接执行交易操作，止损触发时AI发出紧急预警，人决定是否执行。

9 渐进实施路线

Phase 1：跑通闭环（1-2周）

以 Trae Work + Obsidian 为核心，跑通完整的模拟训练闭环和实盘数据闭环。

Phase 2：风控代码化（2-4周）

将风控计算从对话驱动迁移到代码驱动，Trae IDE 开发 Python 风控引擎脚本。

Phase 3：数据管道代码化（4-8周）

开发数据采集脚本（Tushare/AKShare），实现数据自动清洗、校验、入库。

Phase 4：分析与可视化增强（持续）

开发回测引擎、数据可视化模块、训练周报自动生成、策略优化工具。

10 核心原则

  1. 人是决策中枢，AI是辅助工具 — 所有交易决策由人做出，AI提供数据、分析和预警
  2. 止损纪律不可覆盖 — 投资者档案中的止损线是红线，AI发出止损预警后人必须回应
  3. 全过程可追溯 — 每个数据点、每条分析、每笔操作都有完整记录和证据链
  4. 知识沉淀优先 — 所有数据和分析最终沉淀到 Obsidian 知识库，形成可查询、可关联的知识资产
  5. 渐进式工程化 — 先对话驱动跑通闭环，再逐步代码化提升可靠性
  6. 训练与实盘并行 — 通达信模拟训练和实盘交易共享同一套知识库和分析框架
