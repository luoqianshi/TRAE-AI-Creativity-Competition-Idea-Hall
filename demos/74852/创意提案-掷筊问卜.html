掷筊问卜

福建闽南传统民俗 · 数字化交互体验

项目概述

本项目是一个数字化「抛圣杯」交互体验，复刻福建闽南地区寺庙掷筊（圣杯）的民俗仪式。用户可在虚拟神坛前默念心愿、抛掷两片月牙形圣杯，依据落地形态获得圣杯、阴杯、笑杯三种签解，让传统民俗以现代交互的方式被体验与传承。

「掷筊」是闽南地区特有的问卜方式，通过抛掷两片竹制或木制的月牙形圣杯，向神明请示吉凶祸福。这一仪式承载着数百年的民间信仰与文化记忆。

解决的问题

让无法亲临寺庙的用户也能体验闽南「掷筊」文化，并为民俗文化的数字化传承提供新范式

目标用户

对民俗文化感兴趣的年轻群体、文化传承者、想快速了解传统仪式的用户

核心功能

  • 心愿选择：支持自定义输入心愿或选择预设（求财、姻缘、事业、学业、健康、出行）
  • 圣杯抛掷：两片月牙形圣杯以 3D 翻转动画飞起、旋转、落地，模拟真实掷筊过程
  • 签解展示：根据落地结果显示圣杯/阴杯/笑杯的文化释义与指引
  • 连续三圣杯：遵循传统民俗规则，需连续三次圣杯才代表神明明确应允
  • 问卜记录：记录本次问卜的历次掷筊结果，便于用户理解过程
🎲 核心交互：抛掷圣杯动画演示

设计理念

视觉风格

  • 配色：朱红（#8B1A1A）+ 暗金（#D4AF37）+ 墨黑（#1A0F0A）的传统寺庙配色
  • 字体：霞鹜文楷展示书法韵味，思源宋体保证可读性
  • 圣杯设计：真实模拟竹筒切半形态，阳面朱红漆、阴面原木色，配以木纹纹理和凸面光影

氛围营造

  • 背景：寺庙屋檐剪影、飘动烟雾、烛光闪烁、光晕呼吸等环境动效
  • 供桌：檀木色质感，金边装饰，营造神坛仪式感
  • 签卷：卷轴展开效果，毛笔字签文，传统文化韵味
🏯 神坛氛围：寺庙场景设计展示

技术实现

React 18 TypeScript Vite Tailwind CSS 3 Zustand CSS 3D Transform SVG Animation

圣杯动画

使用 requestAnimationFrame 实现抛物线轨迹 + 3D 翻转 + 落地判定，动画时长 1.8 秒，模拟真实掷筊手感

状态管理

Zustand 管理心愿、连续圣杯计数、历史记录等状态，逻辑清晰，易于扩展

判定规则

一阳一阴 = 圣杯（神明应允）
两阴 = 阴杯（神明不应）
两阳 = 笑杯（需要再问）

响应式设计

桌面优先，移动端自适应布局，触控优化，支持长按蓄力效果

文化价值

  • 民俗传承：将数百年的闽南「掷筊」仪式以数字化方式呈现，让年轻一代了解这一独特文化
  • 仪式感保留：神坛场景、圣杯形态、签解内容都严格遵循传统，尊重民俗信仰
  • 可扩展性：未来可接入更多闽南民俗元素（如抽签、解签、祈福等），构建完整的民俗文化数字体验
  • 教育意义：可作为民俗文化教学的互动演示工具，帮助学校、博物馆展示传统仪式
传统民俗不应只是博物馆里的展品，而应成为可触摸、可体验的活态文化。本项目用现代技术让「掷筊」走进每个人的屏幕，让传统活在当下。
