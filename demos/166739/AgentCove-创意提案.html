§ 01 — Problem

多智能体时代的窗口税。

每个智能体跑在自己的终端里。每个权限请求藏在自己的终端里。每个提问等在自己的终端里。成本在累积。

// 01

窗口切换疲劳

三到五个终端窗口散落在桌面上。想知道每个智能体在干什么，必须逐个点过去——每一次都打断你的专注。

// 02

权限请求会丢失

智能体请求审批时，提示只存在于它的终端里。切走就看不见了。任务卡住、你忘了、你重试——浪费循环。

// 03

没有全局视角

没有任何一个地方能告诉你"我所有的智能体现在都在干什么"。你变成了窗口管理员，而不是构建者。

// 04

远程会话不可见

跑在 SSH 或 Docker 容器里的智能体，从本地完全看不见。只有重新连上终端才知道进度。

§ 02 — Solution

从主动巡检，到被动感知。

灵动岛永远可见。智能体的状态永远可见。差别就是一切。

把审批留在岛内

当智能体请求执行高危操作时，岛内弹出审批卡片，带完整代码 diff。按 ⌘Y 允许，⌘N 拒绝——不用离开编辑器。

权限处理从"找到终端 → 读请求 → 输命令"（15 秒）变成"看见岛 → 按一键"（2 秒）。

§ 03 — Features

为多智能体工作流而生。

25 个智能体，20+ 终端，零配置。一切都在本地运行。

→ 01
Zero Config
一次启动，全部就绪。自动为每个支持的智能体配置 hooks。无需 API key，无需云账号，无需手动编辑。
→ 02
25 Agents
Claude Code, Codex, ZCode, Gemini CLI, Cursor, Trae, OpenCode, Droid, Qoder, Qwen, Kimi Code, DeepSeek, Copilot, CodeBuddy 等 25 个智能体，一个岛，一眼看尽。
→ 03
20+ Terminals
iTerm2, Ghostty, Warp, Terminal.app, WezTerm, Kitty, Zellij, VS Code, Cursor——精准跳转到确切的 tab 和分屏。
→ 04
Permission with Diffs
审批前看到确切的改动。完整代码 diff 内联渲染。允许、拒绝或审查——都在岛内完成。
→ 05
Plan Review
审批前预览带完整 Markdown 渲染的计划。不用离开岛就能给出反馈。
→ 06
Pure Swift
原生应用，非 Electron。为 Apple Silicon 构建，内存占用低于 50MB。快、轻、无形。
→ 07
Usage Tracking
一眼看到 Claude、Codex、Kimi、GLM、DeepSeek 的剩余配额。实时重置，无需额外设置。
→ 08
SSH Remote
在远程服务器上跑智能体，从本地监控。一键部署，自动重连，多服务器。
→ 09
Fully Local
一切都在本地。无云、无账号、无遥测。只是你的智能体和岛之间的直接连接。
