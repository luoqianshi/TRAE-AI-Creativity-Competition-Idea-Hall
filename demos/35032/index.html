// 01 · 痛点

切换终端、手动协调、
上下文割裂的时代该结束了

每个 AI 编码 Agent 都很强，但它们彼此孤立。开发者被迫在多个终端窗口之间来回切换， 逐一发指令，再手动汇总输出。DeepFlux 统一派单给所有 Agent，全局可视。

× WITHOUT DEEPFLUX

单体 CLI 的孤岛困境

  • 每个 Agent 独立终端运行，彼此无感知
  • 手动在 N 个窗口之间切换、反复复制粘贴
  • 无法追踪各 Agent 的工作状态和进度
  • 每个 Agent 只擅长某件事，无法互补
  • 复杂项目交付速度受限于单体能力
✓ WITH DEEPFLUX

多 Agent 协同作战

  • 你给 Orchestrator 发指令，它统一派单给所有 Agent，全局可视
  • 一次下达指令、指定派单对象，多 Agent 并行开工
  • 浏览器内实时追踪每个 Agent 的工作流
  • 你决定让谁做什么 —— Codex cli 做 UI、Cursor cli 做后端，各展所长
  • 并行执行让项目交付速度成倍提升

// 03 · 核心特性

为 AI 编码开发者
量身打造的工作台

从指令派单到并行执行，从隐私保护到生态扩展——DeepFlux 的每一个设计决策 都围绕着"让多 Agent 协作更高效"这一目标。

01

指令式派单

你给 Orchestrator 发指令、指定派给谁，它立即把任务转发给对应 Agent，无需手动切换终端。

02

浏览器原生终端

所有 CLI Agent 都在浏览器里真实运行。无需安装额外客户端，打开即用，支持全平台。

03

本地优先架构

数据和 Agent 进程全部跑在你本机，不上传云端，无需账号，无需 key，代码隐私由你自己掌控。

04

灵活角色机制

不只限于写代码。你可以给不同 Agent 起角色名、发不同指令——辩论搭子、研究员、译者、编剧——Orchestrator 统一派单。

05

全局实时可视

每个 Agent 的工作状态、终端输出、任务进度都在一个界面可视化追踪，再也不会迷失在终端窗口海洋。

06

可扩展的生态

支持接入 token 中转站和模板市场机制，为开发者社区提供变现基础，让协作生态可持续生长。

// 04 · 架构设计

// 05 · 使用场景

不止是写代码——
让 Agent 成为你的全能团队

编程只是 DeepFlux 最直接的应用。只要需要多线程协作，就能用 DeepFlux 让 不同专长的 Agent 并行开工。

CASE 01

全栈项目极速开发

你给 Orchestrator 发指令、指定派单对象——前后端实现、测试编写、代码审查、文档生成——一次指令，整个团队并行推进。

产品经理 UI 设计 前端开发 后端开发 测试编写 代码审查
CASE 02

技术调研报告

给擅长查资料的 Agent 发调研指令，给擅长写作的 Agent 发撰写指令，给擅长批判的 Agent 发审稿指令——一份高质量报告几小时内完成。

研究员 编辑 审稿人 排版师
CASE 03

产品设计辩论会

你把几个 Agent 拉进同一个任务里，给它们各自发不同立场的指令——产品经理、技术负责人、用户代表——帮你决策最合理的方案。

产品经理 技术负责人 用户代表 数据分析师
CASE 04

多语种内容本地化

你给擅长不同语言的 Agent 分别发翻译指令，从原文到多语种翻译、风格校对、文化适配——一套内容，多语言版本一键产出。

中文译者 英文译者 日文译者 审校编辑 编剧顾问
