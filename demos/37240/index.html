自由配置 API

不绑定、不锁定、不限制——你的 API Key、你的模型选择、你的创作自由。

DeepSeek、OpenAI、任何 OpenAI 兼容端点 —— 想接什么接什么。 你的 Key，你的创作自由。每个节点独立选择，互不干扰。

🎯

节点级独立配置

画布上的每一个节点都是独立的—— 文本节点用 DeepSeek，图像节点用 Flux，视频节点用可灵， 同一画布上混合调用，互不冲突。

⚡

预设 + 自定义双轨并行

内置常用模型预设，填 Key 就能用。 也支持完全自定义——填个名字、Endpoint 就完事，想接入自家的模型服务也没问题。

🔒

Key 本地持久化，安心创作

所有 API Key 只存在你的浏览器里，不走中间服务器。 你配的 Key，只有你知道。你创作的数据，留在你本地。

🔄

智能轮询，异步生成

🛒

带货短视频流水线

拖一个「产品介绍」模板， 一键生成多风格视频。每个节点可以单独调整——换模型、换描述词。

能力 03

创意画布 · 0 门槛互动影游
把故事变成可以玩的内容

不是写代码、不是做动画——在一张画布上搭出你的互动叙事。 分支选项、角色对话、场景切换——一切都用节点完成。

📝 场景 💬 对话 🔀 分支 🎭 角色 🖼️ 背景 🎵 音效 ▶️ 预览
🏠
场景：迷雾森林入口
主角踏入神秘森林，遇到一位老者
💬
对话：老者开口
「年轻人，你是来寻找传说中的神剑吗？」
🗡️ 选择 A：寻找神剑
💰 选择 B：转身离开
🖼️
场景：神秘洞穴
AI 生成洞穴场景图 + 后续剧情
👆 每一个框都是可点击、可编辑、可连接的节点
🎬

场景节点：讲故事的起点

每个场景节点 = 一个故事节点。填描述、选背景， AI 自动生成场景图，然后连到下一个节点，你的故事线就串起来了。

🔀

分支选择节点：让观众自己选

在剧情走向的关键位置， 右键 → 添加分支选择节点， 自动生成两个选项。观众选 A 走 A 线，选 B 走 B 线。

💬

对话节点：让角色开口

写对话、选语气，AI 自动生成角色对白。 无需任何动画技能，你的角色就能有电影剧本级别的对白。

👁️

一键预览，即时体验

随时点击「▶️ 预览」—— 你的互动影游直接运行。 觉得哪里不对，回到画布随时修改，实时看到效果。

🎮

发布为作品，直接分享

完成后右键 → 发布为作品 → 生成独立链接， 直接分享给朋友玩你的互动影游。你的创作，直接触达观众。
