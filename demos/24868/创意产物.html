每日股票 StockInfo

MiraBox Craft 面板插件 - 实时股票行情，一屏掌握

创意介绍

🎯

想解决什么问题

股民和投资者需要频繁查看股票行情，但频繁切换手机APP或网页会打断工作流。在副屏上实时显示关注的股票信息，可以在不干扰主屏幕工作的前提下随时掌握市场动态。

💬

灵感来源

很多投资者在办公时习惯在副屏放一个行情软件，但传统软件界面复杂、占用空间大。MiraBox Craft 的面板插件形式可以将关键信息精简展示，既美观又实用。

📦

产品形态

基于 MiraBox Craft 平台的面板插件（mPanelPlugin），运行在 9.16"+ 横向副屏设备上，通过新浪财经 API 获取实时股票数据并渲染展示。

目标用户及痛点

1

上班族股民

工作时间无法频繁看手机，希望在电脑副屏上安静地显示关注的股票，不影响正常工作。

2

多屏办公用户

已经使用 MiraBox Craft 副屏设备，希望在现有设备上增加实用的金融信息展示功能。

3

长期投资者

不需要实时盯盘，但希望定时刷新查看持仓股票或大盘指数的走势变化。

4

当前痛点

现有方案要么需要打开完整的行情软件（占用资源大），要么需要频繁切换窗口/手机查看，缺乏轻量级、美观的副屏展示方案。

功能特性

📈

多市场行情

支持 A 股（上证/深证/创业板）、港股、美股，通过股票代码自由配置。

🔄

自动刷新

可配置 10-300 秒自动刷新间隔，交易时间内实时获取最新行情数据。

🎨

涨跌颜色区分

红色表示上涨，绿色表示下跌，符合中国股民习惯，一目了然。

🔍

透明背景

背景透明度 0-100% 可调，100% 时完全透明，完美融入任何桌面壁纸。

⚙

自定义样式

支持自定义字体、颜色、大小，以及是否显示涨跌幅、最高最低价等信息。

📊

常用股票预设

内置上证指数、深证成指、创业板指、贵州茅台等常用股票一键选择。

插件运行效果

  • 股票名称与当前价格醒目显示
  • 涨跌幅百分比实时计算展示
  • 红涨绿跌颜色区分，符合A股习惯
  • 可选显示当日最高/最低价
  • 背景完全透明，融入桌面环境
  • 休市时显示"已休市"提示
  • 支持按键跳转新浪财经页面

价值与意义

效率提升

将股票行情信息精简展示在副屏面板上，用户无需切换窗口或拿起手机，余光即可掌握市场动态，大幅提升工作效率。对于需要同时关注行情的上班族来说，这是一种"无感监控"的最佳方案。

商业价值

中国有超过 2 亿股民，副屏设备用户群体与股民高度重合。该插件可作为 MiraBox Craft 生态的差异化功能，吸引金融用户群体，提升平台活跃度和用户粘性。后续可扩展基金、加密货币等更多金融品类。

技术价值

展示了 MiraBox Craft 插件平台对接外部 API 的能力，为开发者提供了实时数据类插件的开发范例。通过新浪财经免费 API 实现零成本数据获取，降低了开发门槛。

技术架构

MiraBox Craft SDK SecondaryScreen Controller Canvas 2D 渲染 新浪财经 API WebSocket 通信 Web Worker 定时器 HTML/CSS/JS Bootstrap UI

数据流程：插件通过 XMLHttpRequest 请求新浪财经实时行情 API (hq.sinajs.cn)，解析返回的股票数据（名称、价格、涨跌幅、最高最低价等），使用 Canvas 2D 渲染到副屏面板上。通过 Web Worker 实现高精度定时刷新，属性检查器提供完整的用户配置界面。
