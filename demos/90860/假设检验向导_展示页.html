Pain Points

统计分析中的三大困境

📌

方法选择无从下手

面对"我想比较两组数据是否有差异"这个想法，网上搜到的流程图密密麻麻，t检验、Mann-Whitney U、卡方检验、ANOVA……完全不知道怎么选，经常用错方法得出错误结论。

📊

结果解读靠猜

SPSS或Python跑出一堆数字：p=0.032、Cohen's d=0.45、95% CI [-0.12, 1.34]……每个数字都见过，但组合在一起不知道该怎么写进论文里，"显著"还是不"显著"？

📚

统计教材太抽象

教材讲的都是公式推导和理想化例子，但实际数据从来不会那么"完美"——方差齐性不满足、样本量不够大、数据有缺失值，这时应该怎么办？教材没有告诉你。

Solution

四步引导式分析流程

01

明确问题

引导用户描述研究问题：是比较差异、检验相关性，还是验证比例？自动识别分析意图

02

数据诊断

分析数据类型、分布特征、样本量大小、方差齐性，自动检测是否符合检验前提假设

03

推荐方法

基于前两步信息，推荐最合适的统计方法并解释为什么选它、有哪些前提假设

04

解读结果

自动生成"论文级"的中文结果描述，包括p值、效应量、置信区间和实际意义解读

你的研究问题是什么？

选择一个最符合你分析目标的场景，我会根据你的回答推荐合适的统计方法。

⚖
比较两组是否有差异
如：实验组 vs 对照组的成绩、治疗前后的指标变化
📈
比较多组之间是否有差异
如：三种教学方法的效果对比、四个地区的收入差异
🔅
检验两个变量是否相关
如：学习时间与考试成绩是否相关、年龄与购买意愿
🔄
检验比例/分布是否一致
如：男女比例是否符合1:1、不同年级的选课分布

推荐统计方法

根据你提供的信息，以下是适合你分析场景的统计方法：

独立样本t检验
适用于比较两组独立连续数据的均值是否存在显著差异。 该方法检验的是：两组数据来自的总体均值是否相等。
正态分布 方差齐性 独立性
t = (X̅₁ - X̅₂) / √(s²/n₁ + s²/n₂)

结果解读报告

基于假设检验结果，自动生成的"论文级"中文解读：

检验方法 独立样本t检验
t值（统计量） t = 2.84
自由度 (df) 58
p值 p = 0.006**
效应量 (Cohen's d) d = 0.75 (中等)
95%置信区间 [2.3, 12.7]

✍ 结论

独立样本t检验结果显示，实验组（M = 78.5, SD = 8.2）与对照组（M = 71.0, SD = 9.6） 之间的差异具有统计学显著性，t(58) = 2.84, p = 0.006, Cohen's d = 0.75（中等效应量）。 95%置信区间[2.3, 12.7]表明，实验组的平均成绩比对照组高出2.3到12.7分。 这意味着新教学方法比传统方法显著提高了学生的测试成绩。

Core Features

六大核心功能

🔍

智能方法推荐引擎

内置专家决策树，覆盖20+种统计检验方法。根据研究问题类型、数据类型、样本量、分布特征等自动匹配最优检验方法。

⚖

前提假设自动检测

自动检测正态性（Shapiro-Wilk）、方差齐性（Levene检验）、独立性等前提条件是否满足，不满足时推荐替代方案（如非参数检验）。

📝

论文级结果报告

自动生成符合APA格式和中文论文规范的结果描述，包括p值、效应量、置信区间，可直接复制到论文中的"结果分析"部分。

📈

交互式可视化

实时生成箱线图、分布密度图、效应量示意图和置信区间图，让抽象统计概念变得直观可感。

📚

每一步都有"为什么"

每个推荐都有简明的原理说明——"为什么选这个检验""这个前提假设是什么意思""p值到底在说什么"，边用边学。

📦

分析报告导出

一键导出完整分析报告（PDF/Markdown），包含研究问题、数据描述、检验方法、前提验证、统计结果和结论解读。

Technical Architecture

技术架构与亮点

▶ 交互层（前端）

  • React 向导式交互UI，步骤状态管理
  • D3.js 分布图/箱线图/置信区间可视化
  • MathJax 公式渲染：统计量和检验公式

▶ 计算层（后端）

  • Python Scipy + Statsmodels 统计计算引擎
  • FastAPI 轻量API，接收参数返回检验结果
  • Redis 计算任务缓存，结果即时返回

▶ 决策层（AI + 规则引擎）

  • 决策树 基于 Gill/OUP 统计决策树的方法推荐
  • LLM 自然语言结果解读生成
  • 规则库 50+条前提假设判定规则

▶ 知识层（内容）

  • Markdown 方法知识库，每步都有"为什么"
  • LaTeX 公式模板库，覆盖20+检验方法
  • PDF 报告导出引擎（结构化模板）
