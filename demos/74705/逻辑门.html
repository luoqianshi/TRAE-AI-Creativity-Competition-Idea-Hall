Chapter 01

创意名称与介绍

从屏幕到桌面，重新定义逻辑学习方式

逻辑门是一套将数字逻辑从屏幕搬到桌面的实体交互系统。传统逻辑学教学中，学生面对的是纸面上的 p ∧ q 或代码里的 a && b，抽象符号让初学者望而却步。我们的方案是：制作一套实体方块，有的代表变量（A、B、C），有的代表逻辑门（AND、OR、NOT、XOR、NAND），用户不需要敲击键盘，只需用手在桌面上把这些方块像拼图一样摆放在一起，连成一个逻辑链条。

电脑上运行的程序打开摄像头对准桌面，实时识别标记位置并构建逻辑表达式，然后在视频画面上叠加AR 光效 — 发光边框、能量连接线、流动光点、脉冲指示灯 — 让抽象的布尔逻辑变得可触摸、可视、可玩。

产品形态：实体方块（木块/3D打印件 + ArUco标记）+ Python 视觉识别程序 + AR 光效渲染。用户全程不需要键盘即可完成交互。

Chapter 05

技术架构

ArUco + OpenCV + 递归下降解析器的全链路技术方案

Python 3 OpenCV 5.0 ArUco DICT_4X4_100 NumPy 递归下降解析器 位运算（无短路） AR 半透明叠加 itertools 真值表枚举
为什么选择 ArUco 标记：ArUco 是 OpenCV 原生支持的二进制标记，单帧识别 <1ms，天然支持角点检测和姿态估计。相比二维码，ArUco 抗旋转、抗部分遮挡、可同时检测多个标记，是 AR 叠加的行业标准方案。
Layer 1
实体方块层
木块/3D打印件 + ArUco 标记贴纸。18种方块对应18个唯一标记ID，支持多角度识别。
▼
Layer 2
视觉识别层
OpenCV ArUco 检测器实时扫描摄像头画面，提取每个标记的位置、旋转角和ID，单帧处理时间 <1ms。
▼
Layer 3
逻辑解析层
递归下降解析器将标记序列转换为语法树，支持运算符优先级和括号嵌套，位运算实现无短路求值。
▼
Layer 4
AR 渲染层
在摄像头画面上叠加半透明光效：发光边框、连接线、流动光点、脉冲指示灯，以及真值表面板。

    使用 TRAE Work 进行代码审查，发现并修复 4 个逻辑 BUG，新增 3 项功能（赋值方块、真值表、错误诊断），通过 9 项自动化测试。
