## 一、创意名称 + 创意介绍 **创意名称：** 多维伴侣 **想解决什么问题：** 许多企业使用飞书多维表格管理档案元数据（如职称评审材料、项目文档），但表格中的每条记录对应的本地文件散落在各处，缺乏结构化管理。人工整理档案耗时耗力，容易遗漏，且难以与表格数据保持同步。 **为什么会想到做这个：** 在实际工作中观察到，档案管理员需要花费数周时间为上百名员工整理职称评审材料，手动创建文件夹、核对材料完整性、按规范排序，整个过程效率极低且容易出错。 **大概是什么产品：** 一款桌面应用（Python + PySide6），打通飞书多维表格与本地文件系统，实现结构化的档案组卷管理。 ## 二、目标用户及痛点 **面向哪些用户：** - 企业档案管理员 / 行政人员 - HR / 人事部门 - 项目经理 / 团队负责人 - 教育机构管理人员 **在什么场景下使用：** 职称评审材料组卷、项目文档归档、合同档案管理、教学成果汇编等需要批量整理档案的场景。 **当前痛点：** 某企业每年为上百名员工整理职称评审材料，使用飞书多维表格记录信息，但对应的 PDF、Word 文件散落各处。管理员需手动创建文件夹、核对材料、按规范排序，耗时数周且容易遗漏。 ## 三、价值与意义 **商业价值：** 为企业节省大量档案整理人力成本，将数周的工作压缩至数小时。 **效率提升：** 自动化同步飞书数据、模板批量填充、PDF 智能合并，减少 80% 重复性手工操作。 **社会价值：** 推动企业数字化转型，让档案管理工作从「体力活」变为「智能活」，释放人力投入更有价值的创造性工作。 ## 四、核心功能 - 飞书多维表格数据一键同步到本地文件夹结构 - 可视化目录树管理（拖拽排序、备注、标签） - Word/Excel 模板批量填充（{{字段名}} 语法） - PDF 自动合并与预览 - 多档案库切换管理 ## 五、技术架构 Python 3.9 + PySide6 + 飞书 Open API + docxtpl + openpyxl + PyPDF2，自研 structure.json 元数据格式实现文件系统与业务数据解耦。
