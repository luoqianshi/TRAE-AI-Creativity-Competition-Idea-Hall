Demiurge Agent 框架

一个用 Agent Slots 构建的可自进化学习工作智能体框架。它把能力扩展放进可读、可 diff、可测试的 Agent Core 文件中，让 Host Harness 继续负责安全、权限、状态和回滚。

能力通过 Slots 进入 Agent Loop

Bootstrap 注入项目记忆、用户偏好和长期上下文
Input 处理文本、语音、文件和当前任务上下文
Host Loop 模型调用、工具调度、审批和状态由 Host 治理
Output 交付文本、语音、artifact 或结构化结果

想解决的问题

学习和工作里的 AI 助手不应该只是越来越长的提示词。它需要能安全地改变工作流，同时让每一次变化都可检查、可回滚。

自进化不只改提示词

传统 Agent 往往只能在 Skill、memory、prompt 上做增强，难以改变输入处理、输出交付、工具组合和多 Agent 协作。

能力扩展需要边界

Memory、STT、TTS、MCP、Web Search、子 Agent 等能力都应该能接入，但不能把底层 Harness 变成不可控的自修改系统。

长期工作需要可治理

团队和个人都需要知道改动发生在哪里、是否通过验证、能否回滚，以及哪些能力会触发网络、文件或状态变更。

核心设计

Demiurge-agent 把运行时基础设施和可演化 Agent 逻辑拆开。Host 保持稳定，Agent Core 作为文件化表面持续进化。

Host Harness

  • 会话、turn、step 和上下文组装
  • Provider 调用、工具调度和审批
  • 状态、能力边界、发布与回滚
  • Package 安装、版本治理和运行时任务
Slots

Agent Core

  • agent.yaml、SOUL.md 和 pipelines
  • bootstrap、input、output slots
  • tools、skills、MCP、schedules 和 tests
  • 通过文件 diff、验证和 promotion 自我演进

学习工作场景

同一个 Agent Core 可以从简单助手开始，逐步装上工作所需的能力包。

个人学习与研究

记录长期偏好、项目背景和研究资料；用语音或文本输入问题；让 Agent 在新的任务中自动带上合适上下文。

团队工作助手

把团队流程、工具、MCP 服务、文档规范和验证脚本沉淀成 Core 文件或 packages，让助手跟随真实工作流进化。

项目记忆 语音转文字 文字转语音 MCP 工具连接 子 Agent 协作 可预览安装 可验证回滚

Agent Slots 演示方向

下面三类能力都通过 package 和 Agent Slots 接入，展示了“扩展能力但不修改 Host Harness”的思路。

Basic Memory System

Memory package 在 session bootstrap 阶段注入本地文件记忆，让助手带着项目习惯和用户偏好开始工作。

Speech-to-text input

STT package 把音频或视频附件转成当前 turn 上下文，适合会议、口述笔记和移动办公。

Text-to-speech output

TTS package 在 output slot 生成语音结果，让同一个工作智能体可以扩展到音频交互。

Demiurge-agent 的价值不是再做一个聊天机器人，而是提供一套可治理的智能体演进方式：让 Agent Core 能变，让 Host Harness 稳定，让学习工作能力可以持续扩展。
