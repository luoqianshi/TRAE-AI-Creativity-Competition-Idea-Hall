工作原理
三个生命周期钩子，自动完成记忆的读取、写入和归档
1

Session 启动 — 自动注入

SessionStart Hook 自动触发。首次使用时创建记忆目录和文件；已有记忆则直接注入 context，无需任何手动操作。

✓ 已加载项目记忆（1,842 chars）
2

任务完成 — 结构化写入

输入 /memory-loop:save，Agent 回顾本次 session，按 Schema 格式写入对应分区。

+ Completed: "完成 JWT refresh token 逻辑"
+ Gotcha: "[auth] 滑动窗口需设置最大有效期上限"
3

记忆过大 — 冷热归档

Stop Hook 检测文件大小，超过阈值时提示运行 /memory-loop:compress，旧条目归档到冷层。
