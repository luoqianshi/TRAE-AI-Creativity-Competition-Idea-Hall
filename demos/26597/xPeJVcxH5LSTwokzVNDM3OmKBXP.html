项目功能长什么样

这份 HTML 按 PRD 把完整产品形态先补齐成静态演示，官方点开即可理解最终系统的界面、流程和创新点。

01 / 系统底座

3D 主舞台 + 后台账本

公开首页、登录、`/twin` 3D 工作台和 `/admin` 后台面板分层清晰。果园、树木、诊断、任务、用药、预警、推演和巡园日志全部沉淀到数据层。

02 / 已完成核心门面

数字孪生果园

树木按数据库位置实例化渲染，物候期切换外观，健康状态用黄/红光晕表达，支持 FPP/TPP 视角、小地图和树木详情抽屉。

05 / 主动预警

不等果农问，系统先提醒

气象 API 与模拟引擎进入规则引擎，命中花期阴雨、低温冻害、裂果等风险后，右上角铃铛和 3D 场景同步亮红警。

03 / RAG 智能问诊

有来源的荔枝农技问答

围绕荔枝品种、物候、病虫害、保花保果构建垂直知识库，问答支持多轮记忆、SSE 流式输出和来源溯源。

08 / 创新核心

AI 病害空间扩散推演

以病源树为原点，融合风向、湿度、树间距和物候易感系数，推演 72 小时内传播路径，输出高危树、预计损失和防控任务。

09 / AI 巡园员

让 AI 自己飞过去看

系统自动规划巡园路径，相机沿 3D 果园飞行，遇到异常树停留、放大、语音播报，同步追加巡检日志，结束后生成巡园日报并派发任务。

  • 全园 / 异常优先 / 弱势优先三种模式。
  • 异常树前自动停 3 秒并生成结论。
  • 巡完汇总“扫描 N 棵、异常 X 棵、任务 Y 条”。

从发现问题到完成任务

核心不是单点功能，而是把农技建议变成“可定位、可执行、可复查”的闭环。

Step 1

看见异常

3D 场景显示黄/红光晕，或预警规则主动推送风险。

Step 2

诊断原因

拍照识病 + RAG 问诊 + 多智能体会诊形成结构化判断。

Step 3

推演影响

按风向、湿度、树距估算扩散路径和经济损失。

Step 4

派发任务

生成喷药、隔离、复查、用药登记和休药期提醒。
