THE PROBLEM

每一个声音都在发出，
但没有一个得到回声

我们每天都在制造声音——微信语音、电话、备忘录录音——但这些声音发完就消失了。情感表达的媒介严重匮乏，代际之间的理解鸿沟持续扩大。

💬

说不出口的情感

深夜录了一段话想发给某个人，最终没有发送。这段话被删除了，连同它携带的情感一起消失。现有的微信、朋友圈只承载文字图片，缺乏多感官情感载体。

超过 72% 的人曾编辑又删除过想说的话

现有胶囊产品无一提供 AI 创作回应

不是从市场报告里找到的机会，而是从真实生活中看见的空白。三个普通人的瞬间，指向同一个问题——我们缺少一种媒介，让情感以更完整的方式超越时空。

深夜未发送的语音

一个人在深夜录了一段话想发给某个人，最终没有发送。这段话被删除了，连同它携带的情感一起消失——"说不出口的情感"无人承接。

外婆的 6 秒语音

外婆去世后，孙女反复听她的最后一条语音。只有 6 秒，说的是"我很好"。多希望有一首歌、一幅画，能替她说出那些来不及的话——"来不及说的话"需要另一种表达。

十年前的自己

一个人找到了十年前写给自己的信。那时的自己那么焦虑、用力。现在的她想对十年前的自己说一声"谢谢"——"跨越时间的自我对话"不应是单向的。

「回响」诞生

这三个时刻指向同一个答案：让 AI 成为情感的共鸣器——用户投入心声，AI 以音乐、画面、诗三种媒介回应。这不是复读、不是模拟、不是造假，而是把人类情感翻译成更丰富的艺术语言。

THE SOLUTION

录一段心声，
收获三重回应

「回响」是 Web 应用形态的 AI 情感时间胶囊。用户语音或文字输入 → AI 情绪分析 → 生成专属音乐+意境画面+诗意文字 → 时间或暗号封印 → 解锁后以听觉+视觉+文字三种感官接收。

01

录制心声

支持语音录制（最长 120 秒）或文字输入。AI 实时转写语音并分析情绪，界面展示情绪标签与置信度——"怀念 85% / 温暖 72% / 思念 60%"，用户可确认或调整。

语音录制 文字输入 实时情绪分析
02

AI 共鸣创作

AI 以三种媒介回应你的心声：一首 30-60 秒的原创音乐（温暖民谣/思念大提琴/轻快吉他），一幅基于情绪生成的意境画面（花瓣飘落/气泡上升/柔和波浪），一段第二人称的诗意文字。

AI音乐 视觉生成 诗意回应
03

时间封印

两种解锁方式：设定未来某个日期，或设置只有特定人知道的暗号。胶囊进入封印状态后，界面展示缓缓旋转的抽象容器和实时倒计时，营造仪式感。

日期解锁 暗号解锁 仪式感设计
04

开箱共鸣

解锁后四层递进展示：Canvas 粒子动画 → 音乐自动播放 → 诗意文字逐行打字机效果 → 原始心声展示。接收者可以选择"回应"，形成情感的回响链条。

四层递进 回应链条 情感循环
05

分享传播

生成可分享的胶囊预览卡片——展示情绪标签、倒计时或暗号提示、诗意文字前几句。接收者点击链接进入胶囊页，输入暗号或等待时间到达即可开启。

分享卡片 预览链接 社交传播
06

Demo 胶囊体验

预置三颗 Demo 胶囊供评审直接体验：「给妈妈的回响」（怀念型）、「致 2029 年的我」（期待型）、「爸爸，家里一切都好」（爱意型）。覆盖三种核心情感场景。

TECH HIGHLIGHTS

TRAE 全栈驱动
多 AI 服务编排

全程使用 TRAE Work 开发，Demo 本身即是 TRAE 能力的证明。即使评审网络断开，Demo 模式仍可流畅运行。

TRAE 原生能力 SOLO Builder

  • React + TypeScript + Vite：由 TRAE SOLO Builder 从自然语言描述生成完整 Web 应用骨架
  • Tailwind CSS v4：品牌色板（深靛蓝 + 暖金）+ 全套自定义动画（呼吸/浮动/渐现/打字机）
  • Context + useReducer：轻量状态管理，无需引入 Redux 等重型依赖
  • Canvas 2D 粒子引擎：三种视觉模式（花瓣飘落 / 气泡上升 / 柔和波浪），≤60 粒子 + 对象池保证移动端 30fps+
  • localStorage 数据层：纯前端无后端依赖，胶囊数据本地持久化，Demo 模式下完全离线可用

多 AI 服务编排 API Mesh

  • LLM 情绪分析：关键词词典 + 模板匹配算法，从中文文本中检测 6 类情绪（怀念/期待/爱/感恩/勇气/孤独）并输出置信度
  • Suno AI 音乐生成：API 封装 + 异步轮询 + 预置降级方案，Demo 模式下使用 5 首预生成音乐确保零延迟体验
  • Demo 降级架构：所有外部 API 均有预置数据 fallback，按情绪关键词智能匹配最近似的 Demo 内容
  • Web Audio API：MediaRecorder + MIME 类型动态检测（webm/mp4）+ Safari 兼容策略
  • Vercel 一键部署：TRAE 内置部署服务，vercel.json SPA 路由回退 + 音频文件 CDN 长缓存
