创意提案

壹 创意介绍

CREATIVE CONCEPT
痛点 · 古籍之困

古籍是中华文明的根脉，但大众接触古籍的门槛极高——原文晦涩、标点缺失、典故陌生。传统"读古籍"方式以"注释+翻译"为主，枯燥劝退年轻人。古籍沦为博物馆的展品，而非流淌在生活中的活水。

灵感 · 玩中习古

剧本杀 + 互动小说 + 古文知识。玩家不是"读"古籍，而是在故事中"用"古籍——通过解谜推进剧情，在不知不觉中学会断句、翻译、典故。让古籍从"教科书"变成"游戏素材"，从被动接受转为主动探索。

产品形态 · 一卷在手

Web 端互动叙事游戏。打开浏览器即可玩，无需下载。选择朝代 → 进入故事 → 遇到古籍谜题 → 解谜推进 → 多结局。一局15-30分钟，碎片化时间即可沉浸一段古文奇谭。

"古卷奇谭"以七卷古书为骨架，每卷一种玩法：剧本杀推凶、法医勘验、文字冒险、海龟汤谜题、文人雅集、AI 地牢无限生成、古文训练关。第一卷《聊斋诡事录》已完整可玩，玩家化身书生夜宿荒宅，通过搜证、审讯四名嫌疑人、推理指认真凶，在剧情中自然习得《聊斋志异》典故。

肆 技术方案

TECHNICAL APPROACH

本项目全程使用 TRAE Work / TRAE IDE 开发，从项目骨架、故事数据、叙事引擎到AI集成，均在TRAE生态中完成。

一
纯前端单文件部署
HTML + CSS + JavaScript，零依赖，单文件即可离线运行。打开即玩，无需服务器
二
自研轻量叙事引擎
参考 Twine SugarCube 语法，支持场景跳转、分支选择、变量持久化、多结局判定
三
JSON 数据驱动题库
20+ 段古籍原文结构化存储，支持断句/翻译/典故三种题型，易于扩展
四
多模式架构（v2.0）
ModeRouter 路由 7 种玩法引擎：剧本杀、法医、文字冒险、海龟汤、文人游戏、AI地牢、训练关
五
AI 动态生成（P1阶段）
接入大模型实现动态出题、翻译评分、AI-NPC对话、AI-DM主持人、AI推理评判，离线自动回退本地题库
