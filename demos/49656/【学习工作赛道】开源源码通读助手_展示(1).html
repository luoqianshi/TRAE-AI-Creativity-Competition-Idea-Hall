axios - HTTP请求库

Promise based HTTP client for the browser and node.js · 90k+ stars

🎯 项目定位

axios 是一个基于 Promise 的 HTTP 客户端，同时支持浏览器和 Node.js 环境。它是目前最流行的前端请求库之一。

🔌 核心架构（3分钟速览）

入口：lib/axios.js 导出 axios 实例

核心：lib/core/Axios.js 定义 Axios 类，处理请求/响应拦截器

适配：lib/adapters/ 目录包含 http.js（Node）和 xhr.js（浏览器）两套适配器

转换：lib/core/dispatchRequest.js 负责数据转换与请求分发

🧭 请求流程

axios(config)
→
Axios.request()
→
拦截器链
→
dispatchRequest
→
adapter

💡 新手建议

  • 先看 lib/axios.js 了解整体导出结构
  • 重点阅读 lib/core/Axios.js 的 request 方法，这是核心逻辑
  • 拦截器机制在 lib/core/InterceptorManager.js
  • 想支持新平台？看看 lib/adapters/ 的实现方式

express - Web框架

Fast, unopinionated, minimalist web framework for Node.js · 60k+ stars

🎯 项目定位

Express 是 Node.js 最流行的 Web 框架，以极简、灵活著称。整个源码不足 2000 行，是阅读框架源码的绝佳入门选择。

🔌 核心架构（3分钟速览）

入口：lib/express.js 创建应用工厂函数

应用：lib/application.js 定义 app 对象，含 use、get、listen 等方法

路由：lib/router/ 目录包含路由匹配与分发逻辑

中间件：lib/router/layer.js 封装每个中间件层

🧭 请求处理流程

app.listen()
→
app.handle()
→
router.handle()
→
layer.handle()
→
next()

💡 新手建议

  • Express 源码非常精简，适合逐行阅读
  • 重点理解 next() 机制——这是中间件系统的核心
  • 路由匹配逻辑在 lib/router/index.js
  • 看完源码后尝试自己写一个迷你版 Express

lodash - 工具函数库

A modern JavaScript utility library delivering modularity, performance & extras · 55k+ stars

🎯 项目定位

Lodash 是最流行的 JavaScript 工具函数库，提供数组、对象、函数式编程等常用工具方法。其源码以极高的工程化水准著称。

🔌 核心架构（3分钟速览）

入口：lodash.js 将所有方法挂载到 _ 对象

分类：*.js 每个文件一个函数，按功能分类存放

内部：.internal/ 目录包含共享的内部工具函数

构建：webpack + babel 构建多格式产物（ESM/UMD/CommonJS）

💡 新手建议

  • Lodash 采用"一个函数一个文件"的极致模块化设计
  • 从常用函数入手，如 debounce、throttle、cloneDeep
  • 注意学习其参数校验和边缘情况处理的方式
  • .internal/ 中的工具函数是 Lodash 的工程化精髓
