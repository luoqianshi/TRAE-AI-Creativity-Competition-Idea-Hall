01 / PAIN POINTS

为什么需要 LifeGame

生命游戏是元胞自动机的经典范例，但一直没有真正"游戏化"的产品。玩家点几下细胞看演化，几分钟就腻了。

PAIN 01

网页版玩具无目标

打开一个网页版生命游戏，点几下细胞，看几分钟演化就关了。没有目标、没有进度、没有挑战，娱乐性几乎为零。

PAIN 02

理论门槛太高

想深入只能啃 Wikipedia、论文，元胞自动机、涌现、B3/S23 规则这些概念让普通玩家望而却步。

PAIN 03

缺中间态产品

介于"无脑玩具"和"硬核理论"之间，没有一款产品能让人在玩游戏的过程中既体验涌现之美，又有目标驱动的可玩性。

02 / TARGET USERS

谁会玩 LifeGame

三类核心用户，覆盖从休闲到极客的完整谱系。

🎮

休闲解谜玩家

在碎片时间玩，需要简单上手、渐进难度。主玩法（布局+干预）面向该群体，单关 3-10 分钟。

🤓

极客 / 生命游戏爱好者

对元胞自动机有基础认知，追求深度探索。规则设计探索模式面向该群体，可长时间实验不同规则生态。

📚

学生 / 教育场景

用于学习复杂系统、涌现现象。作为附赠教育价值存在，以可玩形式降低理解门槛。

03 / CORE CONCEPT

生命游戏内核 + 三大玩家角色

康威生命游戏（1970）规则极简，却能涌现出滑翔机、振荡子、图灵机等复杂结构。LifeGame 在此基础上扩展出三种玩家角色。

B3/S23

标准规则 B3/S23： 死细胞周围恰好 3 个活邻居则诞生（Birth）； 活细胞周围有 2 或 3 个活邻居则存活（Survival），否则死亡。 规则极简，行为极复杂——这就是涌现。

ROLE 01 · LAYOUT

布局者

回合制布阵。布置初始细胞图案后启动演化，不可干预。慢思考、策略性。

ROLE 02 · INTERVENE

干预者

实时操作。布局后在演化过程中用单细胞增删、注入图案、局部环境修饰等手段干预走向。中节奏。

ROLE 03 · DESIGN

规则调整者

参数调节。修改底层规则参数（B/S 阈值、邻域、状态、网格），观察不同生态。探索式。

FUSION 主玩法 = 布局者 + 干预者 融合；规则调整者作为独立模式存在，是技能树中最大的分支。
04 / GAME MODES

三大模式与核心循环

两种模式组织所有玩法，单棵技能树串联，经验点数解锁推进。

🎯

主玩法：布局 + 干预融合CORE

核心模式。玩家先在网格上布置初始细胞图案，启动演化后可在过程中实时干预。胜利条件多样化，资源约束限制干预强度。该模式覆盖绝大多数关卡。

🔬

独立模式：规则设计探索SANDBOX

玩家可自由调整底层规则参数，在沙盒中观察不同规则下的演化生态。无强制目标，重在实验与发现。该模式是技能树最大分支，本身也含难度递增的引导关卡。

选择模式 / 关卡 → 查看目标与约束 → 布置初始图案 → 启动演化 → 实时干预 → 达成胜利条件 → 获得经验点数 → 解锁技能树
05 / GAMEPLAY MATRIX

胜利条件 · 干预手段 · 资源约束

所有元素均编号入框架，demo 阶段按优先级取舍重组，保证玩法多样性。

① 胜利条件矩阵（VC）

编号胜利条件玩法侧重示例
VC-1匹配目标图案解谜限定代数内让演化结果最接近"十字 / 心形 / 文字"
VC-2保护 / 引导特定细胞挑战让"指定种子细胞"在 N 代内存活或到达指定位置
VC-3达量 / 生成稳定结构资源经营使活细胞数达阈值，或产生滑翔机 / 购子等自维持结构
VC-4多阶段目标叙事先达成 A → 演化进入下阶段 → 达成 B → 通关

② 干预手段（IV）

编号手段粒度说明
IV-1单细胞增删轻量 / 高频暂停后点击网格放置 / 移除单个细胞
IV-2注入预设图案中量 / 策略从图案库选取滑翔机、振荡子等插入指定位置
IV-3局部环境修饰重量 / 经营涂抹"能量 / 养分"区域，加速或抑制该区域细胞生长

③ 资源约束（RC）

编号约束类型机制体验倾向
RC-1能量点数每关固定能量，操作消耗不等（增 1 / 图 3 / 修饰 5）策略经营
RC-2操作次数每关总操作上限（如 20 次），不区分类型简单直接
RC-3冷却时间不同操作有独立冷却，演化不暂停实时压力
RC-4代数限制限定代数内达成，干预无额外限制节奏快
06 / RULE SYSTEM

可调规则维度 + 高维扩展

标准 B3/S23 为基线，玩家可在规则设计探索模式中调节下列维度，长期愿景支持三维乃至更高维环境。

维度可调项说明
出生 / 存活阈值B 集合 / S 集合如 B36/S23（HighLife）、B3678/S34678（Day & Night）
邻域类型与半径摩尔 / 冯诺依曼；半径 R；是否含对角线影响细胞感知范围
多状态 / 多物种细胞状态数；物种数；颜色与交互规则支持年轻 / 老化、多物种竞争等
网格形态与边界方形 / 六边形 / 三角形；环形 / 反射 / 有限改变拓扑结构
VISION / 高维扩展愿景 长期愿景支持三维乃至更高维（4D / 5D+）环境中的生命游戏，通过投影 / 切片在 2D Canvas 上可视化。 demo 阶段以 2D 为主，高维作为"探索"方向的远期目标存在，PRD 框架预留扩展接口。
07 / SKILL TREE

单棵技能树 · 经验点数解锁

所有关卡与模式组织在一棵技能树中，"规则设计探索"为最大分支。不同分支玩法可不同，提供探索乐趣。

[根] LifeGame ├── [主干] 主玩法分支（布局+干预） │ ├── VC-1 匹配图案 → VC-3 达量 → VC-2 保护细胞 → VC-4 多阶段 │ └── 难度递进：20×20 → 40×40 → 60×60+ / 动态 │ ├── [主分支] 规则设计探索（最大） │ ├── 阶段1：B/S 阈值调节 │ ├── 阶段2：邻域类型与半径 │ ├── 阶段3：多状态 / 多物种 │ ├── 阶段4：网格形态与边界 │ └── 阶段5：高维投影（远期） │ └── [支线] 特殊挑战 └── 极限约束关 + 特殊胜利条件组合
解锁机制

经验点数解锁，点数可在分支间通用，鼓励主玩法与规则探索自由切换。

关卡原则

单一聚焦（每关考察一种角色 / 胜利条件）+ 渐进解锁（先体验后命名）+ 可重玩。

难度递增

多维度递进：网格规模 / 目标复杂度 / 规则维度 / 约束强度，避免单一"加量"式难度。

10 / VALUE

三层价值

娱乐、探索、教育三位一体。

🎮

娱乐价值

多样化胜利条件 + 主题切换 + 收集系统，提供长线可玩性。三角色融合 + 资源约束制造挑战。

🔬

探索价值

📚

教育价值

以可玩形式展示涌现、复杂系统、人工生命等概念，降低理解门槛。玩家以为在玩游戏，实际已理解科学命题。

11 / TECH

技术架构

HTML 单文件，原生 JS + Canvas，无构建依赖，双击即玩。与同仓库 ModelLab 项目路线一致。

渲染层

Canvas 2D 逐格绘制；高维用切片 / 投影降维。脏区域刷新 + 离屏 Canvas + rAF。

模拟引擎

TypedArray 存储细胞状态；可插拔规则函数 step(grid, rule)；边界策略可切换。

持久化

localStorage 存进度 / 图鉴 / 成绩 / 设置 / 自定义图案。JSON 导入导出。

性能预算

默认 50×50 @ 60 FPS；最大 200×200 @ 30 FPS；单文件 < 20MB（大赛限制）。
