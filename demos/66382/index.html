📖 分步装机引导

按照步骤一步步来，AI 全程指导你完成装机

步骤 0/8
0

准备工作

在开始装机前，请确保你已准备好以下物品：

  • ✅ 十字螺丝刀（磁性更好）
  • ✅ 防静电手环（或先触摸金属物体释放静电）
  • ✅ 宽敞、干净的工作台面
  • ✅ 所有硬件配件已拆箱并检查完好
💡 小贴士：建议在白天光线充足的环境下操作，方便看清细节。
1

安装 CPU

Intel CPU（LGA1700）安装步骤：

  1. 打开主板 CPU 插槽保护盖，按下拉杆并向外翻开
  2. 找到 CPU 上的金色三角标记，对准插槽上的三角标记
  3. 轻轻放入 CPU，不要用力按压，CPU 会自动归位
  4. 扣回拉杆，保护盖会自动弹开
⚠️ 注意：CPU 有防呆设计，方向不对放不进去，切勿大力出奇迹！
2

安装内存（RAM）

双通道内存安装：

  1. 打开主板内存插槽两侧的卡扣
  2. 对准内存金手指上的缺口与插槽凸起
  3. 双通道请插在第 2、4 槽（从 CPU 方向数）
  4. 两端同时用力按下，听到"咔哒"声即安装到位
💡 小贴士：DDR5 内存缺口位置与 DDR4 不同，注意区分不要混插。
3

安装 M.2 固态硬盘

  1. 找到主板上的 M.2 插槽（通常在 CPU 下方）
  2. 拧下固定螺丝和散热片
  3. 将 SSD 以 30° 角插入接口
  4. 轻轻按下，拧紧固定螺丝
  5. 装回散热片（撕掉导热贴保护膜！）
⚠️ 注意：别忘了撕掉 M.2 散热片上的导热贴保护膜！
4

安装 CPU 散热器

塔式风冷安装：

  1. 在 CPU 表面涂抹黄豆大小的硅脂（或撕掉散热器预涂硅脂保护膜）
  2. 安装扣具（根据 CPU 平台选择对应扣具）
  3. 将散热器对准孔位，对角线交替拧紧螺丝
  4. 将风扇供电线插入主板 CPU_FAN 接口
💡 小贴士：散热器风扇建议朝机箱前方进风方向，形成前进后出风道。
5

主板装入机箱 & 安装显卡

  1. 安装机箱 I/O 挡板（如果主板没有预装一体式挡板）
  2. 安装机箱铜柱（对应主板孔位）
  3. 将主板对准铜柱放入机箱，拧紧固定螺丝
  4. 拆下机箱后方对应显卡的 PCIe 挡板
  5. 打开主板 PCIe 插槽卡扣，插入显卡直到"咔哒"声
  6. 拧紧显卡固定螺丝
6

连接电源 & 跳线

需要连接的线缆：

  • 🔌 24pin 主板供电 — 主板右侧长接口
  • 🔌 8pin CPU 供电 — 主板左上角（别和 PCIe 8pin 搞混！）
  • 🔌 PCIe 供电 — 接显卡（高端卡可能需要 2-3 个）
  • 🔗 前面板跳线 — 开机键、重启键、指示灯
  • 🔗 USB 前置接口 — USB 3.0 / Type-C
  • 🔗 HD Audio — 前置音频
⚠️ 注意：CPU 8pin 和 PCIe 8pin 线序不同，不能混插！仔细看接口标注。
7

首次开机 & BIOS 设置

  1. 检查所有连接是否牢固
  2. 接上显示器（接显卡输出口，别接主板！）
  3. 接通电源，打开电源开关，按下开机键
  4. 开机后按 Del 键进入 BIOS
  5. 开启 XMP/EXPO（让内存跑标称频率）
  6. 检查 CPU 温度是否正常（待机 30-50°C）
  7. 确认所有硬件被正确识别
  8. 保存退出，准备安装系统
💡 小贴士：如果开机没反应，先检查电源开关和前面板跳线是否接好。
