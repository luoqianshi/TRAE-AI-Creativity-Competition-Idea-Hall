捕获层

Tauri Rust 后端持有 Raw Input 注册句柄，按键事件进入事件循环后通过 Tauri Command 推送到 React。

匹配层

前端 useShortcutStore 维护当前键位表，GetForegroundWindow 注入到匹配器，区分全局 / 应用范围。

持久层

用户自定义键位进入 localStorage（key: oniroixs:shortcuts:custom），系统默认键位只读来自 PostgreSQL。
