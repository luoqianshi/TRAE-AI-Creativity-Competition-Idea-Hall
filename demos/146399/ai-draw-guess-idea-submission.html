画猜星球：基于多 Agent 协同的 AI 社交游戏

打破传统题库限制，引入前沿大模型与多智能体（Multi-Agent）技术。 AI 实时动态出题绘图，性格迥异的 Agent 陪你同台竞技，打造永远充满未知与陪伴感的新一代派对体验。

前沿技术：多 Agent 实时协同架构

应用采用模块化 Agent 架构，将复杂的游戏博弈拆解为多个专职大模型智能体，通过 SSE 流式协议与前端实时交互：

Director Agent (导演)

负责把控全局。根据当前主题动态生成符合难度曲线的剧本，并编排绘图路径（Drawing Program 协议）与剧情节奏。

Painter Agent (画师)

解析语义路径（Primitive），引入随机种子生成拟人化的手绘抖动与回笔，将代码流式编译为可平滑播放的 SVG 动画。

Guesser Agents (猜词团)

注入“杠精、小白、学霸”等多样化 Persona。它们会根据画面的实时揭示程度同步发弹幕抢猜、吐槽或给出错误误导。

1 创意介绍

想解决的问题：传统你画我猜依赖固定题库易枯燥，且单人游玩时缺乏陪伴感和互动感。

动机与灵感：大模型的多智能体协同技术能创造出极其逼真的拟人化互动。我们希望将“动态生成”和“Agent陪伴”引入派对游戏，让每一局都是不可预测的小剧场。

产品形态：一款基于大模型协同构建的移动端优先 Web 应用（可拓展至小程序）。

心理学机制设计：沉浸与心流

  • 间歇性奖励（斯金纳箱）： AI 的动态作画过程和 Agent 的不确定性抢答，像“开盲盒”一样提供多巴胺刺激，让玩家保持高度专注。
  • 社会临场感（Social Presence）： 引入多性格 Agent 模拟群聊氛围。通过“学霸的精准”、“杠精的嘲讽”、“小白的搞笑”，显著降低单人游戏的孤独感。
  • 心流理论（Flow Theory）： 导演 Agent 会动态调整题目难度，配合 SVG 画布一笔一画的渐进揭示节奏，使玩家面临的挑战与猜测能力相匹配。

2 目标用户及痛点

面向用户：喜欢轻量小游戏、前沿 AI 玩法、线上娱乐互动的学生、年轻上班族及朋友群。

使用场景：午休摸鱼、睡前放松、单人无聊时的陪伴消遣，以及朋友群的远程破冰。

当前痛点：固定题库更新慢、易失去新鲜感；单人游玩时没有对手和反馈，无法体验派对游戏的“吐槽与围观”乐趣。

3 价值与意义

技术与商业价值：验证了大型语言模型在结构化语义绘图（Drawing Program）与多 Agent 实时博弈上的工程落地可行性，极大降低了内容维护成本，为 AI 原生游戏提供了前沿架构参考。

社会价值：多 Agent 的陪伴式猜测有效降低了独自娱乐的冷清感，缓解年轻人的孤独情绪，同时也是极佳的社交破冰工具。
