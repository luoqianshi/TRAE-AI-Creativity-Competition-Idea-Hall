music_note 音乐日记 (Music Diary)

这是 Melody Diary 的核心心情表达机制。高敏感用户在此不需要背负繁重的文字叙述压力，仅需通过指尖弹奏 7 个低延迟的基础音符（SoundPool）或者挑选特定旋律氛围和弦。

氛围机制：在左侧弹奏琴键，或者直接点按预置和弦，声音合成器会流淌出舒缓的音浪，并映射出极具文学美感的情感隐喻，让不可言说的哀伤或平静在旋律中安全靠岸。

Compose Canvas 按键 情绪映射算法 BPM/和弦结构记录

vpn_key 安全音乐锁开锁仪式

音乐锁并非音乐日记本身，而是一种极富仪式感的进入开锁机制。应用摒弃了生硬死板的传统数字密码，改为使用 4 音符的音阶序列作为进入心房的钥匙。

仪式交互：在左侧沙盒设定解锁密码，然后点击锁定。当密码锁启动后，您的主日记屏幕将自动模糊锁死。在虚拟键盘中弹奏正确的 4 音符即可触发解锁动画重新进入。

仪式感设计 Keystore 密钥隔离 加盐哈希本地比对

brush 莫兰迪视觉情绪映射

为无法用文字甚至声音描述的纠结与压力提供出口。限制在护眼低饱和色板下的自由画布，可追踪笔刷路径并计算线条密度。

色彩分析：在画板随意涂抹。本地分析引擎分析主导颜色与画笔速率，映射成对应的自然场景解说（如『静谧森林』『烟熏幻想』），通过色板记录情感状态。

Morandi 专属色板 无压涂鸦 本地像素特征捕捉

air 让风带走 (Wind Deletion)

专为极敏感、不欲为人知和保留的负面负能量心声设计。这是比“删除”更具温度的倾诉。

粒子动效：输入一段带有负面情绪的文字，点击“让风带走”，扬声器将扫频播放微风掠过的白噪声，编辑器内的文字会裂变散开为数千个微光星芒粒子随风飘散。同时内存数据即时彻底擦除。

粒子系统物理仿真 即时内存擦除 扫频白噪音风声合成

album 月度 OST 专属心情资产

把一个月的所有结构化低敏标签数据（和弦模式、心情分数、主色彩占比）在月末进行聚合。

资产生成：提取当月高频旋律基调，自动拼接为一首专属的月度心境背景和弦。试听中将以 Morandi 渐变模拟出胶片封面，并循环播放该月的音符写照。

System Architecture

Kotlin 原生客户端 + Spring Boot 后端的前后端分离方案

客户端负责沉浸式体验、本地加密、音频播放、脱敏与动画；后端负责业务编排、AI 服务、月度音乐生成、任务系统和 REST/SSE 接口。

Android 客户端

  • Kotlin + Jetpack Compose 构建原生界面
  • Canvas 绘制虚拟钢琴、涂鸦画布与星空背景
  • ViewModel + Coroutines + Flow 管理状态
  • Room + SQLCipher + Keystore 实现本地安全
  • Retrofit + OkHttp 处理 HTTPS 与 SSE 通信
⇄

Spring Boot 后端

  • Auth、Mood、Treehole、Habit、Music 模块拆分
  • 接收 moodScore、keywords、chordPattern 等低敏数据
  • LLM API 编排与 SSE 流式文本返回
  • 月度 OST 生成、MIDI 模板拼接与资产记录
  • JWT 鉴权、Redis 限流、统一异常处理
