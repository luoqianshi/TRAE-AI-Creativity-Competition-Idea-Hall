01 / Concept

创意名称与创意介绍

沿着不断西移的日落线，把音乐、城市故事和当地夜色组织成一段持续流动的世界广播。

创意名称 日落电台 · Earth Calling

想解决什么问题

今天的音乐平台提供了几乎无限的内容，但当人真正需要陪伴时，仍常常不知道此刻该听什么。音乐、城市故事、旅行记忆和地方文化分散在不同媒介中，时间与地点也很少参与内容组织，用户得到的往往是一组彼此独立的歌曲或信息，难以形成一段连贯、有氛围的收听体验。

为什么想做这个

无论此刻身在何处，地球上总有一座城市正在迎来日落。不断西移的黄昏像一枚持续发送的信号，将不同经度、文化和生活方式连接在一起。日落电台希望把这条真实发生的日落线变成节目时钟，让用户跟随夜色抵达不同城市，在声音中感受世界由白昼转入夜晚的过程。

大概是什么产品

一款以可交互数字地球为入口的沉浸式城市声音电台。用户可以主动选择一座城市，也可以跟随日落线自然巡游，收听与当地气质相呼应的音乐、城市故事和声音内容。每座城市都是一个独立频道，节目会随着当地时间和日落顺序自然衔接，形成一段从一座城市流向下一座城市的世界广播。

AXIS 01

地球入口

以交互地球承载城市与路线，让用户从空间关系进入内容，也能直观看见黄昏正在抵达哪里。

AXIS 02

日落时钟

依据城市坐标与当地时间组织节目顺序，让真实世界的昼夜变化成为持续运行的广播节奏。

AXIS 03

城市频道

每座城市汇集音乐、故事与当地氛围，既可单独收听，也能在日落路线中自然衔接。

技术实现路径

技术层围绕地球展示、日落调度、智能编排、城市内容和安全运行展开，让各部分保持清晰分工与独立扩展。

01

交互地球

React、TypeScript 与 WebGL / Three.js 负责数字地球、城市节点和昼夜边界的可视化。

02

日落调度

结合城市坐标、当地时间与日落顺序生成节目路线，把真实黄昏转化为广播时钟。

03

智能编排

理解用户的简单指令，组织城市切换、路线巡游、内容衔接与必要的动作校验。

04

城市内容

城市资料、音乐与声音稿件采用结构化方式管理，媒体资源按需加载。

05

安全运行

模型请求通过服务端代理完成，密钥不进入前端，并支持浏览器、PWA 与容器化部署。

02 / Users & Pain Points

目标用户及痛点

在具体的黄昏里，以地点、节奏与城市氛围共同构成一段可以持续收听的声音体验。

Target Users

面向哪些用户

喜欢音乐、播客、旅行和城市文化，重视氛围与叙事体验，并习惯在通勤、阅读、学习、工作或独处时使用声音陪伴自己的用户。

  • 01傍晚下班或放学时，跟随此刻正在发生的日落进入一座城市。
  • 02阅读、写作或独处时，选择一条城市路线持续收听，减少频繁操作。
  • 03计划旅行、怀念一座城市或想认识远方时，通过声音提前抵达那里。

当前痛点

  1. 选择越来越多，决定“此刻听什么”越来越难

    海量内容把组织与筛选的工作留给用户，声音陪伴也可能变成新的决策负担。

  2. 推荐记录偏好，却很少理解地点与当下

    历史播放数据能够描述口味，但难以表达某座城市、当地时间和此刻环境共同形成的氛围。

  3. 音乐与城市文化分散在不同媒介

    歌曲、播客、旅行内容和城市资料彼此独立，用户需要反复跳转才能拼出完整感受。

  4. 城市内容缺少自然的情绪入口

    攻略和百科侧重信息密度，容易让文化体验停留在“知道”，难以进一步形成感受与记忆。

  5. 内容之间缺少连续的空间叙事

    音乐与故事常以单个条目出现，缺少从一座城市进入下一座城市的路线和节奏。

  6. 频繁操作打断声音陪伴

    选歌、换页面和浏览信息不断切断注意力，用户难以沉浸在一段稳定、完整的收听过程里。

03 / Value & Feasibility

价值与意义

让地理、天文时间、城市内容与智能编排共同构成一条完整体验链路，让用户听见一颗正在入夜的地球。

VALUE 01

全球时空体验

把不断移动的日落线转化为节目调度机制，让每次打开电台都与真实世界正在发生的黄昏建立联系。

VALUE 02

城市文化连接

以城市为内容单元，将音乐、历史、人物与生活气息放进同一段声音叙事，使远方成为可以被聆听和想象的空间。

VALUE 03

沉浸式陪伴

通过连贯编排与自然转场，为通勤、阅读、独处和入夜前提供稳定、克制且具有情绪起伏的声音陪伴。

VALUE 04

主动探索体验

用户可以从地球上选择城市，也可以让节目跟随黄昏自然前行，在每一次收听中发现不同地点与文化。

VALUE 05

技术与内容的持续生长

模块化的地球展示、日落调度、智能编排和城市内容库可以逐步扩展，让电台持续成长为一张世界声音地图。
