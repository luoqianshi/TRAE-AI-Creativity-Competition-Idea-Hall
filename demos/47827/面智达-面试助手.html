🏷️ 生活服务 📱 App 🤖 AI + 硬件交互

1. 创意名称 + 创意介绍

面智达 — AI 智能面试助手

想解决什么问题：求职面试过程中，求职者常因紧张、准备不足或对问题理解偏差而表现不佳；HR 面试官也需要高效筛选和记录面试内容，但缺乏专业工具支持。

为什么会想到做这个：面试是求职的核心环节，但大多数人缺乏实时、私密的面试辅导。随着 AI 大模型的发展，将本地轻量模型与云端顶级模型结合，为每一场面试提供实时智能支持，成为一个极具价值且可行的方向。

产品形态：手机 App（支持录音笔/蓝牙耳机硬件交互），配套云端 Web 管理端。

2. 目标用户及痛点

核心用户：求职者（校招/社招）、企业 HR 面试官

使用场景：

  • 求职者在面试中实时录音 → 本地 AI 优化提问 → 云端获取深度答案 → 耳机语音反馈
  • HR 面试官记录面试内容 → 本地 AI 整理为结构化笔记 → 存档复盘
  • 面试结束后回顾笔记，复盘整个面试过程中的问答表现

当前痛点：

  • 面试时无法有效录音记录，全靠事后回忆
  • 回答问题时缺乏实时指导，错失最佳表达机会
  • 没有工具能根据面试官提问智能优化应答思路
  • HR 面试记录繁琐，难以结构化保存和回溯

3. 价值与意义

效率提升：本地 0.5B 模型毫秒级实时处理问题优化和角色识别，云端顶级大模型提供深度解答，从"事后复盘"升级为"实时辅助"，大幅提升面试表现质量。

商业价值：中国求职培训市场规模超千亿，面智达以"AI + 硬件"差异化定位切入，同时面向 B 端 HR 系统和 C 端求职者，变现路径清晰。

社会价值：降低求职信息差，帮助求职者（尤其是应届生和转行者）在面试中自信表达，提升就业成功率。同时帮助中小企业 HR 专业化面试流程。

4. 技术架构亮点

本地端（App）：

  • 内置 0.5B 量化语言模型，无需联网运行
  • 提示词自动识别求职者/HR 模式，调整回答策略
  • 实时问题优化 + 回答框架生成
  • 问答内容自动保存为 JSON 格式，支持永久本地存储
  • 语音输入 → 本地推理 → 蓝牙耳机语音输出，全链路闭环

云端（Web + API）：

  • 网页端支持 DeepSeek、Qwen 等顶级大模型登录调用
  • 浏览器自动爬取搜索结果增强回答时效性
  • 登录状态浏览器持久化保存，无需重复登录
  • API 模式支持程序化调用，适合高级用户集成
