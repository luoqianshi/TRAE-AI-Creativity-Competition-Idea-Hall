💡创意来源

想解决什么问题

大模型足够聪明，Copilot 人手一份，但"每个人都在和自己的 AI 对话，这些 AI 互不相识"。张三的 AI 写方案，李四的 AI 重新理解一遍；王五的 AI 学会报销，赵六还得从零教起。智能体在个人层面爆发，在组织层面却是一片荒原。

为什么会想到做这个

2024-2025 几乎所有企业都在囤算力、上大模型，但"算力在转，价值没转"。数据显示企业级 GPU 集群平均利用率仅 5%，80% 的 AI 项目未能交付预期价值。企业需要的不是会写诗的 AI，而是能顶岗、能背锅、能产出可被验收成果的数字员工。

更深的痛点是：员工离职了，他积累的岗位经验随之清零；新人入职，一切从零教起。组织知识无法沉淀，每一次离职都是一次能力清零。

大概是什么产品

一款基于 Tauri 的企业级桌面智能体应用——不是给每个人配一个助手，而是给每个岗位配一个分身。员工离职了，分身留下，新人继承即上手；员工优秀了，分身可被复制到整个组织。

🎯 核心洞察

"工具被使用，分身被托付。当一名员工把岗位职责交给 Ava，他托付的不是任务，而是自己的数字存在。"

👥目标用户及痛点

面向哪些用户

企业知识工作者——HR 主管、财务分析师、市场策划、运营专员、销售代表、研发工程师、法务专员、供应链专员等。任何有明确岗位职责、有可沉淀经验的岗位，都是 Ava 的目标用户。

在什么场景下使用

  • 新人入职：继承岗位分身，装载即上手，无需老员工手把手带
  • 日常办公：简历筛选、报表生成、竞品分析、合同审核——分身带着岗位判断执行
  • 跨部门协作：销售要签单需财务审批，分身之间直接对话，无需人类中转
  • 岗位交接：员工离职，分身留下全部经验；新人继承即上手
  • 组织进化：优秀员工的经验蒸馏为技能包，复制到整个组织

当前痛点

  • 经验无法沉淀：每个员工的智能体都是孤岛，A 学到的经验无法传给 B，组织知识无法积累
  • 离职即清零：员工离职带走全部经验，新人从零开始，培训成本高、上手周期长
  • 协作靠人肉：业务流程天然跨部门，但现有智能体无法跨部门自主沟通，仍需人类中转
  • AI 各自为战：每个人和自己的 AI 对话，这些 AI 互不相识，重复劳动严重
  • 资产无保护：企业花重金沉淀的经验以明文 prompt 流通，瞬间可被复制带走

🚀产品方案

产品形态

基于 Tauri 2.0 + React 19 + Rust 的跨平台桌面智能体应用，前端 React + Zustand 状态管理，后端 Rust + SQLite + LanceDB 向量库。每个 Ava 既是客户端也是服务器，通过 A2A 协议实现跨实例协作。

⚙️ 核心功能

  • 岗位化身系统：每个岗位化身 = 业务技能 × 场景技能 × 岗位记忆，装载即化身、卸载即回归
  • Mention 式编排：用一次 @ 召唤子智能体，Explorer / Planner / Verification / GeneralPurpose 四类内置角色，把复杂编排藏进自然交互
  • Harness 工程引擎：完整 ReAct 循环，每次 LLM 调用、工具执行都暴露为可拦截 Hook，思考过程可观测、可治理
  • 技能包加密体系：.avaskill 是 AES-256-GCM 加密压缩包，承载技能脚本、引用文档与资产，Secrets 独立加密
  • 跨实例协作网络：A2A 协议让分身能力可跨实例调用，AgentSquare 让多个分身形成自组织代理社会
  • AvaSquare 飞轮：使用→沉淀→封装→共享，个人经验蒸馏为组织复利资产

✨价值与意义

📈 效率提升

新人上手周期缩短 70%——继承岗位分身即继承全部经验，无需老员工手把手带。跨部门协作从"天"降到"分钟"——销售分身要签单，财务分身 2 分钟内给出方案，无需人类中转、无需反复沟通。每一次使用都是经验沉淀，组织知识像飞轮一样越转越快。

💼 商业价值

数字员工是下一个万亿赛道。中国 AI Agent 市场 2026 年预计规模 449 亿元（CAGR >110%），全球 Agentic AI 市场 2034 年预计 1,391.9 亿美元。Ava 采用三层商业模式：技能包生态（按技能价值定价）、分身订阅（按岗位按月计费）、企业私有化（授权 + 年度服务）。企业按岗位需求弹性扩缩编——淡季减员不裁员，旺季扩编不招聘。

🌍 社会价值

当每一个岗位都拥有自己的化身，组织将第一次实现"能力"与"人数"的解耦。Ava 不替代人，而是让人成为更高级的存在——分身的编排者。员工不再被困在重复性事务中，而是专注于创造性工作；岗位经验不再随离职流失，而是沉淀为可继承的组织资产。让个人经验变成组织能力，让一次性劳动变成复利资产。

🏆 核心差异化

  • 岗位化身概念：现有智能体都是"通用助手"，Ava 是唯一有岗位身份的方案
  • 技能包加密保护：Claude Skills、Coze 插件均无加密，Ava 的 AES-256-GCM 是唯一解
  • 跨实例协作落地：A2A 协议有标准无产品，Ava 是唯一落地的方案
  • 协同进化飞轮：全市场无产品有跨组织 Agent 学习进化机制，Ava 独有飞轮闭环
