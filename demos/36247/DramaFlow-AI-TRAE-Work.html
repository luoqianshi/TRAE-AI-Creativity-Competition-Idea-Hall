DramaFlow AI
AI 短剧生产工作流平台

一个基于 Spring Boot + Vue3 的 AI 短剧自动生成 MVP：从模板或自然语言出发，自动生成旁白、分镜图片、语音、字幕，并通过 FFmpeg 合成最终短视频。

1 条链路从创意到视频结果
5 类能力文本 / 图片 / 语音 / 字幕 / 合成
3 种模式Mock / Demo / Real
可配置管理员动态控制生成规则

1. 创意名称 + 创意介绍

AI 内容生产工作流

创意名称：DramaFlow AI —— AI 短剧自动生成工作流平台。

我想解决的问题不是“再做一个视频生成模型”，而是把短视频生产中分散的步骤串起来：选题、模板、旁白、分镜图片、语音、字幕、视频合成、任务追踪和结果展示。很多 AI 工具可以生成单个素材，但普通创作者要做出一条完整视频，仍然需要在多个平台之间反复切换，效率不高。

DramaFlow AI 的产品形态是一个 Web 应用 MVP。用户可以选择“豪门复仇短剧”“职场反击短剧”“带货口播视频”等模板，也可以输入自然语言主题，系统会自动生成短剧旁白、图片素材、语音音频、字幕文件，并通过 FFmpeg 合成最终视频。

模板/主题输入创意
旁白生成短剧文案
分镜图片视觉素材
语音合成真人音频
字幕生成SRT 同步
视频合成FFmpeg
成果展示播放/下载

2. 目标用户及痛点

短视频创作 / 运营提效
🎬

短视频内容创作者

需要快速验证选题、脚本节奏和视频表达，但缺少从文案到成片的一体化工具。

📈

运营和自媒体从业者

希望用低成本生成视频 Demo，用于测试短剧、口播、带货或知识科普方向。

👨‍💻

AI 应用探索者

不想停留在单模型调用，希望看到一个具备登录、额度、任务、后台配置的完整 AI 应用雏形。

当前痛点

  • AI 工具分散，脚本、图片、配音、字幕、剪辑需要手动流转。
  • 单次素材生成不等于完整视频生产，缺少可追踪的任务链路。
  • 真实 AI 调用存在成本，需要额度、失败退款和生成规模限制。
  • 普通 Demo 往往缺少后台配置、用户隔离和运行时动态调整能力。

3. 价值与意义

工程化落地

单点 AI 生成

  • 只生成一段文本、图片或视频
  • 素材之间需要人工拼接
  • 缺少任务、额度、失败处理
  • 难以从 Demo 变成可演示产品

DramaFlow 工作流

  • 从模板到最终视频形成完整闭环
  • 多模型能力通过 Provider 抽象编排
  • 支持额度冻结、失败退款、任务追踪
  • 管理员可配置生成规则并动态生效

DramaFlow AI 的价值在于把 AI 从“单次生成工具”推进到“内容生产工作流”。它不是替代专业视频生成模型，而是让不同模型能力在一个业务流程里协同工作。

当前版本重点不是训练模型，而是探索：如何用 Java 后端工程化方式，把多个 AI 能力组合成一个可配置、可追踪、可控成本的内容生产 MVP。

5. 技术架构

Spring Boot + Vue3

项目采用前后端分离架构，后端负责用户、任务、额度、AI Provider 编排和视频合成，前端负责生成入口、任务详情、配置中心和成果展示。

Spring Boot Vue3 Element Plus MySQL MyBatis Plus JWT DeepSeek Qwen-Image CosyVoice FFmpeg 异步任务 运行时配置

文本层

通过规则旁白或 DeepSeek 生成适合短剧节奏的解说文案。

视觉层

通过图片 Provider 生成分镜素材，当前支持 Mock 与 Qwen-Image，后续可扩展视频模型。

音频层

通过音频 Provider 生成语音，支持 Mock 与 CosyVoice，并与字幕进行时长同步。

合成层

使用 FFmpeg 将图片、音频、字幕合成为最终短视频。

6. 创新点总结

应用层创新
🔗

完整工作流

不是单点视频生成，而是从创意输入到视频结果的内容生产流水线。

🧱

工程化落地

包含异步任务、用户隔离、额度控制、失败退款、配置中心等产品化能力。

🔌

可插拔 Provider

不同模型能力可作为 Provider 接入，后续可扩展到 Seedance、可灵、即梦等。

对比豆包、Seedance 等强模型，DramaFlow AI 并不尝试在模型画质上竞争，而是把这些能力视为可以接入的组件。它更关注业务流程、工程编排和内容生产闭环。

7. 后续规划

持续迭代
  • 接入 Seedance、可灵、即梦等视频模型作为 Video Provider，提升画面表现。
  • 完善 Demo 模式，使用本地高质量样例素材，不消耗额度也能展示较好效果。
  • 优化真实 AI 体验额度，限制成本并保障用户体验。
  • 支持更多内容模板：带货口播、知识科普、企业宣传、课程短视频。
  • 完善部署文档、线上演示环境、作品展示页和安全策略。
DramaFlow AI 目前还是个人 MVP 项目，但已经跑通了从创意输入到视频结果展示的完整链路。它是一次用 Java 后端工程化思维探索 AI 应用落地的实践。
