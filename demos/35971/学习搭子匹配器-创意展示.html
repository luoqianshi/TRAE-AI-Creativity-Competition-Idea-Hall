1. 创意名称 + 创意介绍

想解决什么问题

一个人学习容易拖延、容易放弃、容易陷入"今天算了明天再说"的恶性循环。市面上的打卡软件只靠"自律"，但自律是稀缺资源；学习博主提倡"找研友"，但茫茫人海找不到合适的，找到了也容易因节奏不合、监督方式冲突而闹掰。学习这件事，需要陪伴，但不需要社交负担。

为什么会想到做这个

身边考研的朋友加了十几个"研友群"，群里要么没人说话，要么变成闲聊水群，真正互相监督的一个都没有。另一个朋友在小红书发了"找学习搭子"的帖子，收到 50 多条评论，聊了一圈发现：有人要凌晨 5 点起，她起不来；有人需要每天视频连线，她觉得压迫感太强；有人三天打鱼两天晒网，反而把她带偏了。找搭子像相亲，靠运气、靠试错，成本太高。我们想用一套匹配机制，让"合适的人"自动相遇。

大概是什么产品

一款微信小程序。用户填写学习目标、每日可用时长、作息偏好、监督风格偏好 → 系统计算契合度 → 推荐 3 位候选搭子 → 双方确认后组成「学习搭子」→ 每日互相可见学习进度、互相提醒打卡 → 连续达标解锁成就徽章，连续缺卡触发约定惩罚（如给对方发小额红包）。

"搭子"是当下年轻人最流行的社交关系——比朋友轻、比陌生人重，刚好够一起做事、互不打扰。我们想把这个概念搬进学习场景：找到那个"刚好合适"的人，互相监督、一起上岸。

2. 目标用户及痛点

面向哪些用户

📚

长期备考者

考研/考证/考公/考编，备考周期 3-12 个月，最需要持续监督

📖

大学生期末突击者

平时放养、考前焦虑，需要短期高强度互相 push

💻

技能自学者

学英语/编程/设计等，缺乏外部反馈，容易半途而废

在什么场景下使用

场景 用户行为 产品作用
开局找伴 刚决定考研/考证，不想一个人孤军奋战 精准匹配作息、目标、风格都合适的搭子，避免"聊完发现不合拍"
日常监督 早上起不来、晚上想刷手机 搭子可见你的"今日进度条"，偷懒有压力；对方打卡了，你收到提醒
危机干预 连续 2 天没打卡，陷入自责想放弃 触发"搭子关心"——对方发来鼓励，或按约定执行惩罚机制，把你拉回正轨
阶段复盘 学了一周，不知道自己的节奏对不对 双方互相评价本周配合度，系统给出"默契度报告"，不合拍可和平解散重新匹配

当前痛点

  • 找搭子靠运气 在群/论坛/小红书发帖，回复者良莠不齐，试错成本高，很多人找了一圈放弃，回到一个人硬撑。
  • 节奏不合拍 你要早起他要熬夜，你想视频他想静默，监督方式冲突导致关系破裂，反而影响心情。
  • 监督没力度 加了微信说好了互相监督，结果两个人一起拖延，从"互相监督"变成"互相安慰"，甚至一起摆烂。
  • 社交负担重 怕欠人情、怕聊太多变成朋友不好意思严格、怕对方放弃了自己也不好意思说，最后不了了之。

3. 价值与意义

📈 效率提升

省去茫茫人海找搭子、反复试错磨合的时间成本，系统基于多维度标签精准匹配，让"合适的人"第一次就相遇。契约化的打卡-监督-惩罚机制，把"靠自律"变成"靠机制"。

  • 找搭子时间：3-7天 → 10分钟
  • 搭子关系维持率：<20% → 60%+
  • 周打卡完成率提升 35%+

🌍 社会价值

用"轻契约关系"替代"重社交负担"，让学习陪伴变得简单、无压力、可持续。帮助更多人找到"刚好合适"的学习伙伴，减少孤军奋战的焦虑与放弃率。

  • 降低学习孤独感与放弃率
  • 建立低门槛、高回报的学习陪伴方式
  • 让"一起学"成为年轻人的生活方式
⭐
4. 产品亮点与差异化

与现有工具的核心差异

维度 打卡软件（番茄钟/Forest） 社交群/论坛找搭子 学习搭子匹配器
核心逻辑 靠自律+工具提醒 靠运气+人工筛选 靠算法匹配+契约机制
陪伴感 无 有，但不稳定 有，且精准、可持续
监督力度 弱（自己对自己） 极弱（不好意思催） 强（互相可见进度+约定惩罚）
社交负担 无 重（怕欠人情、怕闹掰） 轻（契约关系，和平解散无压力）
匹配效率 不涉及 极低（发帖→聊天→试错） 高（10分钟系统推荐）
