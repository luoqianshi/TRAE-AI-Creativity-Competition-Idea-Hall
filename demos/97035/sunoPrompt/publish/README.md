## 3. Overview Description（1000 字符以内 · 至少 50 字符 · 已写好）

**中文版（推荐）**：

> 赋音（FU YIN）是一款专为 AI 音乐创作设计的提示词工作台，
> 帮你在 Suno、Udio 等 AI 音乐平台上用最高效的方式写出风格提示词。
> 7 大模块（流派 / 情绪 / 速度 / 配器 / 人声 / 主题 / 元标签）
> 支持中英双语对照、关键词搜索、按乐器分类筛选，
> 109 种配器涵盖中国民乐、西方管弦、电子合成、世界音乐，
> 内置 24 个精心调校的预设配方（深夜电台 / 城市霓虹 / 古风仙侠 / 赛博战士 …），
> 一键复制即可粘贴到 AI 平台。
> 所有数据本地存储,无需登录,无服务器依赖,纯静态 HTML。

**English version**：

> FU YIN is a dedicated prompt workbench for AI music creation,
> designed to help you craft the most effective style prompts for
> Suno, Udio, and similar AI music platforms. 7 modular sections
> (Genre, Mood, Tempo, Instruments, Vocal, Theme, Metatags) with
> bilingual EN/CN labels, keyword search, and category-based filtering.
> 109 instruments spanning Chinese folk, Western orchestral,
> electronic synthesis, and world music. 24 curated preset recipes
> (Late Night Radio, City Neon, Xianxia, Cyberpunk Warrior…)
> ready to copy-paste. Local storage only, no login, no backend —
> a single self-contained HTML file.

## 4. Key Features & Use Cases（3000 字符以内 · 至少 100 字符 · 已写好）

```markdown
## Key Features

- **7 模块化工作流**:流派 / 情绪 / 速度 / 配器 / 人声与制作 / 主题与场景 / 元标签,逐步构建专业级 Suno 提示词
- **109 种配器分 7 大类**:弦乐、键盘、管乐、弦乐组、打击、电子、世界音乐,支持中英文双语搜索 + 分类筛选
- **40 流派 + 20 情绪**:覆盖 Pop、K-pop、Synthwave、Phonk、Hip-Hop、Trap、Cinematic、古风等全谱系
- **24 个精心调校的预设配方**:深夜电台 / 城市霓虹 / 夏日公路 / 雨中钢琴 / 赛博战士 / 古风仙侠 / 西部黄昏 等
- **实时拼装与字符统计**:右侧实时显示拼装好的提示词,带 200 字符限制的进度条,避免超限
- **歌词工作台**:结构标签按钮一键插入 [Verse 1] [Chorus] [Bridge] [Drop] 等,Suno 兼容
- **元标签控制系统**:用 [Intro] [Pre-Chorus] [Build-up] [Outro] 等精确控制歌曲结构
- **导出 / 分享**:支持 JSON 导出、链接分享(URL hash 携带完整配置)、本地收藏
- **纯静态 + 中英双语**:无服务器依赖,无登录,所有数据本地存储
- **专业录音棚暗黑美学**:Bebas Neue + Major Mono Display + 熔岩橙三色系统,优雅且专注

## Main Use Cases

- **音乐创作者**:为 Suno / Udio 写出更高质量的提示词,快速生成配乐
- **内容创作者**:为视频 / 播客 / 短视频定制专属背景音乐风格
- **AI 爱好者**:学习如何用结构化方式描述音乐风格
- **教学场景**:音乐课堂上讲解不同流派的特征与组合
- **独立音乐人**:在没有乐手的情况下,通过 AI 工具探索新风格
```
