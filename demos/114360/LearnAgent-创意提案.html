1

创意介绍

一个把"学—练—记—复习—坚持"打通的学习闭环工具

痛点

想解决什么问题

年轻人学习时间碎片化、目标驱动却易分心、学完即忘、知识零散难成体系。市面工具要么只做笔记（无 AI 结构化）、要么只做刷题（无知识体系）、要么只做 todo（无学习场景关联），缺少一个把全流程打通的闭环。

动机

为什么会想到做这个

观察到身边备考、转行、求职的年轻人普遍陷入"学了忘、忘了学"的循环。AI 已能做教材级结构化讲解，却没人把它和个人知识图谱、间隔复习、习惯激励绑定。把 12 节模板蒸馏成默认输出，是把"高质量讲解"转化为"长期资产"的最短路径。

产品

大概是什么产品

本地化运行的 Web 应用（FastAPI + 浏览器）。用户提问即生成 12 节结构化笔记并归档，自动构建知识图谱与"虚拟推荐节点"指向下一步学习，需要敲代码的主题弹出引导式代码实操窗口，外加计划/复习/打卡/番茄钟，首页 Dashboard 一屏聚合。

目标用户及痛点

谁会用，什么时候用，没有它会怎样

用户

核心用户群体

想积极提升自我的年轻人 —— 学生（考研 / 期末 / 秋招）、早期职场人（转行 / 技能进阶）、终身学习者。尤其适合有明确目标但自驱力不足的人群。

场景

使用场景

晚上 1 小时学习时段：提问 → 敲代码 → 番茄钟 → 日记；通勤碎片时间：翻卡复习、查看倒计时；周末规划：创建计划、管理待办、回看图谱生长；学习倦怠期：看 streak 与 XP 获得正反馈。

割裂

当前痛点

笔记 / 刷题 / todo / 专注钟分散在 4-5 个 App 里，切换成本高；学完即忘无复习机制；知识零散看不到关联；易分心无专注辅助；目标感弱缺乏倒计时牵引。

✗ 没有 LearnAgent 的现状

  • 学完即忘：看完教程没复习，一周后忘 70%
  • 知识孤岛：笔记散落在 5 个 App，概念间无关联
  • 不知道下一步学什么：学完虚拟内存，不知道该学页面置换
  • 光看不练：教程看懂了，动手就废
  • 三天打鱼：无可见进度，坚持不下来
  • 目标感模糊：离秋招还有几天？没有倒计时压迫感

✓ 有 LearnAgent 之后

  • FSRS-lite 间隔复习：掌握度低的节点自动到期，遗忘曲线变复习日历
  • 个人知识图谱：所有笔记的概念节点与关系一图可见
  • 虚拟推荐节点：基于已学内容自动推荐 1-3 个下一步学习方向
  • 引导式代码实操：弹出窗口，起步代码 + 渐进提示 + 测试沙箱
  • streak + XP + 等级：每次学习都有正反馈，Duolingo 式激励
  • 目标日倒计时：≤7 天红色高亮，时刻盯紧 deadline

4

原创技能：knowledge-architect

把 AI 对话沉淀为教材级文档的原创技能，LearnAgent 的核心引擎

核心理念

对话的价值不应随会话结束而消散

通过将对话中产生的知识沉淀为可复用、可检索、可扩展的教材级文档，让每一次学习都能形成长期资产。本技能蒸馏自 61 本经典计算机科学教材的共性教学法，提炼出 15 项教学范式，凝结为一套 12 节标准输出模板，确保每次讲解都具备教材级的完整性与严谨性。

12 节标准输出模板

01

学习目标

3-5 条"能够……"句式的具体目标，便于自测

05

可运行、带注释的代码，附复杂度分析

06

可视化辅助

07

常见陷阱

反模式及失败原因，配"错误 vs 正确"对比

08

最佳实践

工业界公认做法，配简要理由

09

10

2-3 道渐进难度练习题，附参考答案

11

小结

5 条要点回顾，便于快速复习

12

延伸阅读

精选下一步资源（书 / 论文 / 文档 / 课程）

7

价值与意义

从效率提升与社会价值两个角度

效率提升

把学习压成一条流水线

LearnAgent 把"提问 → 结构化讲解 → 归档 → 图谱串联 → 代码实操 → 复习巩固 → 习惯坚持"压成一条流水线，一次提问产生的不是一次性回答，而是可检索、可复习、可扩展的长期资产。个人知识图谱 + 虚拟推荐节点让学习路径可视化，用户不再"不知道下一步学什么"。FSRS-lite 间隔复习让掌握度低的节点自动到期，把遗忘曲线变成可调度的复习日历。

社会价值

降低高质量学习的门槛

任何能用自然语言提问的人，都能获得教材级 12 节结构化讲解（学习目标 / 前置知识 / 概念地图 / 核心讲解 / 代码示例 / 可视化 / 陷阱 / 最佳实践 / 交叉引用 / 练习 / 小结 / 延伸阅读），而非零散博客或短视频。对教育资源不均衡地区的自学者尤其有意义：一个提问框 + 一份坚持，就能构建属于自己的体系化知识库。
