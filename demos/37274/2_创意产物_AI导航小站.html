1. 作品定位与一句话介绍

AI 导航小站 是一个面向"非程序员"的桌面 AI 工具上手引导站。它不写桌面软件、不搞"一键自动配置"，只做一件事：

🎯 一句话：把"AI 工具怎么用"做成 4 个场景分类 + 每步不超过 3 次点击的浮窗引导，全程中文，5 分钟内必上手。

和市面现有方案的区别：

  • ❌ 不是又一个 AI 工具（不取代 Codex/Claude/Trae）
  • ❌ 不是复杂的一键配置软件（我做不到，也不假装能做到）
  • ✅ 而是 "工具地图 + 浮窗导航 + 国内镜像 + 中文教程" 的集合体

传统路径 vs 小站对比

❌ 传统路径（3-7 天）
  • 知乎搜"DeepSeek 怎么用"翻 1 小时
  • 看官方英文文档（看不懂）
  • 注册、实名搞半天
  • 找不到"API Keys"在哪
  • 生成 Key 后不知道粘到哪
  • 遇到报错又从头搜
✅ AI 导航小站（5 分钟）
  • 首页选"编程 → DeepSeek"
  • 弹窗告诉"先点这、再点那"
  • 每步配中文截图
  • 生成 Key 一键复制
  • 下一步直接跳 IDE 配置页
  • 遇到问题有"问 AI"按钮

6. 国内镜像导航清单

很多人不愿意去 GitHub / HuggingFace —— 要么打不开，要么英文看不懂。小站内置国内镜像导航页：

原站问题国内替代说明
github.com 偶尔抽风 gitclone.com / gitee.com GitClone 提供加速下载，Gitee 是中文代码托管
huggingface.co 经常打不开 hf-mirror.com HF 官方认可的中国镜像
npmjs.com 下载慢 npmmirror.com 淘宝 NPM 镜像，必备
pypi.org 下载慢 清华 pypi 镜像 清华 TUNA 维护
OpenAI 官网 无法访问 通过 SiliconFlow / OpenRouter 中转 用国产 API 替代海外
raw.githubusercontent.com 常被墙 通过 gh-proxy.com 代理 GitHub 原始文件加速
📌 小亮点：用户在站内遇到"GitHub 链接"，会自动检测并提示"点此跳国内镜像"，免去用户自己搜。

7. 云端配置备份（轻量方案）

用户最关心的问题："我配好的东西，换电脑/换软件是不是就丢了？"

我做不到写"自动写本地配置"的程序，但可以做"轻量云端备份"——把用户的 API Key、收藏工具、阅读进度存到云端：

📦 数据结构（极简） 
{
  "user_id": "u_8x2k_demo",
  "providers": [
    {"name":"DeepSeek","key":"sk-***(加密)","base_url":"https://api.deepseek.com/v1"},
    {"name":"Moonshot","key":"sk-***(加密)","base_url":"https://api.moonshot.cn/v1"}
  ],
  "favorites": ["deepseek","trae","kimi","metaso"],
  "progress": {"deepseek-tutorial":"step-4-of-5"},
  "settings": {"language":"zh-CN","theme":"light"}
}
  • 加密存储：API Key 用 AES-256 加密后再上传；
  • 匿名 ID：不强制手机号，微信 / GitHub 第三方登录；
  • 导出 / 导入：用户可下载 JSON 备份到 U 盘；
  • 轻量后端：用 Cloudflare Workers + D1 数据库，几乎零成本。

为什么不做"一键自动配置"？
研究下来发现，每个 IDE 的配置文件位置、格式、权限都不一样，要做"一键"得写底层程序，我一个人做不到。所以我换思路——不做"一键"，做"一步步点下去"，用户跟着浮窗走，每步不超过 3 个点击，全程不超过 5 分钟。
