卡牌评级查询H5项目需求说明书
 
一、项目概述
 
1.项目名称
 
中检鉴真卡牌评级查询H5系统（用户查询端+后台管理端）
 
2.项目目的
 
搭建移动端H5卡牌评级查询平台，用户通过【内部编号】查询对应宝可梦评级卡牌详情；管理后台实现卡牌信息录入、数据管理、页面背景图自定义配置，整体UI大气轻奢、卡牌收藏风，适配手机端全屏浏览。
 
3.项目两端划分
 
- C端用户H5（微信/浏览器打开，核心查询）：2个页面【首页查询页+卡牌详情页】
- B端管理后台（PC端操作）：3个功能菜单【录入卡牌信息、卡牌信息库、背景图管理】
 
二、C端用户H5详细需求（移动端H5）
 
整体风格：蓝金轻奢评级机构风、卡牌潮玩质感，背景支持自定义图片，布局大气不空泛
 
页面1：首页-评级查询页（对标参考图1，精简改版）
 
1.页面整体布局
 
1. 顶部区域- 全屏自定义背景图（后台统一配置全平台首页背景，可随时替换），背景上叠加品牌文案：中检鉴真卡牌评级中心 | 评级查询，搭配盾牌+卡牌矢量装饰元素（UI美化，大气排版）。
- 取消原图扫码查询、去送评按钮、底部导航栏（首页仅保留查询功能）。
2. 中部核心查询区- 圆角大尺寸搜索输入框：左侧提示文字 请输入卡牌内部编号 ，右侧放大镜查询图标；输入框做渐变蓝白样式，增加阴影质感。
- 输入框下方可增加小字辅助文案： 输入卡牌内部编号，一键查询评级档案 。
- 搜索逻辑：用户输入内部编号点击查询→匹配数据库数据，有数据跳转【卡牌详情页】；无数据弹窗提示： 未查询到该编号卡牌信息，请核对编号 。
3. 底部留白美化- 页面空白区域增加淡色卡牌暗纹底纹装饰，避免页面空旷，贴合卡牌行业属性。
 
2.交互规则
 
- 输入为空点击查询：弹窗提示 请填写有效的内部编号 ；
- 编号不存在：弹窗提示无数据；
- 编号匹配成功：无缝跳转到详情页面。
 
页面2：卡牌详情页（对标图2+图3，上下滑动一体式页面）
 
整页分为上下两部分，同页面竖向滚动浏览，无需分页跳转
 
上半区：评级头部卡片区（参考图2）
 
1. 顶部固定背景图（全详情页统一背景，后台单独配置）：整栏大图背景，蓝调暗纹评级底图，后台可自定义上传替换。
2. 左上角评级分数标贴：仿评级壳10分徽章样式（GEM MINT 10分，固定样式）；
3. 卡牌名称大字标题：居中展示【卡牌名称】（如：仙子伊布VMAX）；
4. 卡牌预览缩略图：并排2张圆角缩略图（卡牌正面图+卡牌背面图，后台上传），居中摆放，可点击放大查看原图；
 
下半区：商品基础信息区（参考图3，下滑展示）
 
标题：商品基础信息 BASIC PRODUCT INFORMATION，蓝标点缀美化
列表展示固定5项字段（数据从后台录入读取）：
 
字段名称 备注 
卡牌名称 后台录入内容 
卡牌编号 后台录入内容 
内部编号 唯一查询主键（用户输入的查询码） 
分数 评级分数（如10分） 
卡牌版本 卡牌系列/版本信息（如CS4aC剑&盾 九彩汇聚） 
 
布局：两列式表单排版，图标+文字搭配，圆角卡片分组，大气整洁。
 
详情页额外交互
 
- 页面顶部增加返回箭头：点击返回首页查询页；
- 两张卡牌缩略图点击：弹窗预览大图，支持手指缩放。
 
三、B端管理后台需求（PC网页端，3大顶部导航菜单）
 
顶部导航栏3个Tab：【填入卡牌信息】、【卡牌信息库】、【管理背景图】
 
菜单1：填入卡牌信息（新增单条卡牌数据）
 
表单字段（必填项全部标注*）：
 
1. 卡牌名称*
2. 卡牌编号*
3. 内部编号*【唯一值，不可重复，数据库主键，重复提交弹窗报错】
4. 评级分数*
5. 卡牌版本*
6. 卡牌正面图片上传*
7. 卡牌背面图片上传*
 
功能：表单提交→数据存入数据库；重置按钮清空表单。
 
菜单2：卡牌信息库（全量卡牌数据管理）
 
1. 顶部搜索框：仅支持【内部编号】精准搜索，输入编号筛选对应卡牌；
2. 数据表格列表：展示全部录入卡牌的5项文字信息+缩略小图；
3. 列表操作按钮：【编辑】【删除】- 编辑：弹窗打开表单，修改对应卡牌全部信息；
- 删除：二次确认弹窗后删除本条数据；
4. 分页功能：数据过多自动分页展示。
 
菜单3：管理背景图（双场景背景配置）
 
分为两个独立上传项：
 
1. H5首页背景图上传：上传图片替换用户端首页全屏背景，仅保留1张生效，新图上传自动覆盖旧图；
2. H5详情页顶部背景图上传：上传图片替换用户详情页头部背景，同样单图覆盖；
 
功能：预览当前在用背景图、删除/替换背景图。
 
四、数据库设计（核心数据表：卡牌信息表+系统配置表）
 
1.卡牌信息表（card_info）
 
字段名 字段类型 说明 
id int 自增主键 
card_name varchar 卡牌名称 
card_no varchar 卡牌编号 
inner_no varchar 内部编号（唯一索引，查询关键字） 
score varchar 评级分数 
version varchar 卡牌版本 
img_front varchar 正面图片存储地址 
img_back varchar 背面图片存储地址 
create_time datetime 录入时间 
 
2.系统配置表（sys_config）
 
字段名 说明 
home_bg 首页背景图地址 
detail_bg 详情页头部背景图地址 
 
五、UI设计规范要求
 
1. 主色调：科技深蓝+银白+浅金（对标评级机构蓝盾风格，贴合中检卡牌评级调性）；
2. 整体风格：轻奢商务+潮玩卡牌风，圆角卡片、渐变阴影、质感浮雕元素，杜绝空白简陋页面；
3. C端H5：全页面增加暗纹卡牌底纹、盾牌评级小元素点缀，视觉饱满大气；
4. 管理后台：简洁商务蓝白后台UI，表单卡片化，分区清晰。
 
六、适配与环境要求
 
1. 用户H5：自适应全尺寸手机（IOS/安卓微信浏览器、手机浏览器），H5移动端专属排版；
2. 管理后台：适配PC电脑端（1366px及以上屏幕）；
3. 部署：前后端分离架构，后端提供接口，H5前端调用接口查数据。
 
七、补充边界规则
 
1. 内部编号全局唯一：后台录入重复内部编号无法保存；用户查询仅匹配内部编号，其他字段不作为查询条件；
2. 背景图：首页、详情页各共用一张全局背景，所有卡牌详情页共用同一张详情头部背景，后台统一修改；
3. 图片存储：卡牌正反面图、背景图统一云端存储，H5在线加载展示。
