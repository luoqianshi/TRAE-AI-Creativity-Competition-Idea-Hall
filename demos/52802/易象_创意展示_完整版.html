💡 创意介绍

从真实痛点出发，用现代技术重构古籍学习体验

❓

想解决什么问题

很多对传统文化感兴趣的上班族或大学生，想利用碎片时间了解易经，但面对《周易》原文的古奥文字和复杂体系无从下手；想查卦象含义时，又要在多个网站间跳转，信息零散且质量参差不齐。

💡

为什么会想到做这个

我自己对易经八卦有浓厚兴趣，在学习过程中深感入门不易——翻书查卦象繁琐，优质学习工具稀缺。希望用前端技术和AI能力，把三千年前的古老智慧转化为当代人愿意用、用得懂的产品。

📱

面向哪些用户

  • 对传统文化有好奇心但没系统学过的年轻人
  • 面临择业或人际决策时想获得思考角度的轻度使用者
  • 准备自学易经，需要结构化学习工具的备考/自学者
😣

当前痛点

  • 易经原著厚重晦涩，普通人难以坚持阅读
  • 免费占卜网站充斥广告，解读质量低
  • 没有工具能同时满足「学习+应用+趣味」三重需求

🌟 价值与意义

从社会价值与效率提升两个维度，创造实际帮助

1

降低学习门槛

把六十四卦拆解成可逐步解锁的学习单元，配合交互式卦象图谱，初学者不必啃完整本书也能看懂核心义理。

2

节省查询时间

传统方式查一个卦的含义需要翻书+查多个网站，本平台起卦后从古籍中匹配相关内容并结构化展示，将查询时间从十几分钟缩短到一分钟内。

3

促进古籍传播

通过每日运势、人格测试等轻互动形式，让对易经完全陌生的人也能先产生兴趣，再逐步深入，真正实现古籍活化。

⚙️ 技术方案

纯前端技术栈，无需后端服务器，离线即可运行

⚡

Vue 3 / React

组件化开发三大模块，代码结构清晰，易于维护扩展

🎨

CSS 动画

摇卦动画、爻变动效、卦象图谱交互，纯 CSS 实现

📦

本地数据

卦辞爻辞等古籍内容预置为 JSON，IndexedDB 存储用户数据

🚀

静态部署

GitHub Pages / Vercel 一键部署，免费托管，访问速度快

AI 解读技术方案

不调用外部 API，核心逻辑为「古籍匹配 + 结构化展示」。起卦得出卦象后，系统从预先整理的古籍数据库中，根据卦名、动爻、问题类型（事业/婚姻/运气）匹配对应的卦辞、爻辞、象传，并以现代语言重新组织输出。

完全离线运行 古籍原文支撑 可信度高的结构化输出

风险处理方案

起卦算法复杂度

蓍草占卜采用系统自动运算，铜钱占卜保留用户交互仪式感

64卦内容工作量

MVP 先实现 8 个基础卦（乾、坤、震、巽、坎、离、艮、兑），后续逐步扩展

内容数据来源

引用开源古籍数据，预置为 JSON 格式，确保内容权威准确
