Git blame 只回答"谁改的"

它不能回答"为什么这么改""当时发生了什么事故""这次修改留下了什么结构后果"。

历史上下文散落各处

需求文档、事故复盘、聊天记录、发布记录、commit message 分散存在，新人只能靠问人和猜。

复杂代码不一定天生糟糕

很多模块原本很优雅，是在活动、事故、性能和海外兼容中被逐步侵蚀。

重构缺少证据链

大家都知道某个模块危险，但很难用数据说明为什么现在必须拆、先拆哪里。
