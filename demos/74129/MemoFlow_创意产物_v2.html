学习工作赛道

我们发现了什么痛点

当代人每天在生活、微信、小红书、抖音、网页、邮件、钉钉之间高频切换，产生的信息不仅是文字——还有 PDF 报价单、Excel 表格、Word 合同、PPT 会议材料。这些碎片散落在 5+ 个平台和多种格式中，当你想找回时：

🧠

信息失忆症

上周刷到的搞钱路子、想吃的餐厅，这周想找死活找不到。逐个 App 翻找，翻了十分钟，人直接焦虑爆炸。

📄

文件过期背锅

老板要群里上个月发的 PDF 报价单，弹出"文件已过期或已被清理"。不仅找不到资料，还要背上"工作不细心"的黑锅。

🗣️

琐事遗忘引发家庭大战

老婆说"下周三闺蜜过生日买口红"，老妈说"降压药快吃完了"，一忙转头就忘，过几天被追问直接引发大战。

📊

多格式信息无法统一管理

客户邮件里的 Excel、同事分享的 Word 合同、会议的 PPT 材料——传统备忘录只能存文字，文件型信息无处安放。

核心洞察：传统工具（Notion、备忘录）需要手动分类、打标签、写标题，且只能处理文字。因为"嫌麻烦"，90% 的碎片信息和文件最终散落在各 App 里。用户需要的不是一个备忘录，而是一个能理解、整理、甚至思考的"第二大脑"。

核心创新：借鉴前沿 Agent 记忆架构

MemoFlow 的设计融合了 2026 年 AI Agent 领域最前沿的记忆系统思想，这是我们区别于所有现有笔记工具的核心壁垒：

灵感来源：Hermes Agent

分层记忆架构

借鉴 Hermes Agent 的四级分层设计，按时间和频率管理记忆："热记忆"（近 7 天）首页直接展示，"温记忆"（7-30 天）按分类浏览，"冷记忆"（30 天+）搜索时出现。容量限制驱动精简，只保留高价值信息。

灵感来源：Karpathy LLM Wiki

知识网络而非信息堆砌

借鉴 Karpathy 的 LLM Wiki 层思想，每一条信息都被"编译"为结构化知识。AI 自动提取实体和关系，构建个人知识图谱。信息之间有交叉引用和关联——搜索一条记录时，同时展示关联实体和上下文记忆。

灵感来源：Hermes MEMORY.md

个人事实库

借鉴 Hermes 的 MEMORY.md，AI 自动从多条记录中提取"不变的事实"。例如连续 3 次提到"老婆喜欢 Chanel"，系统提炼为持久事实。搜索"口红"时，不仅找到记录，还直接展示"品牌偏好：Chanel"。

MemoFlow 原创

智能问答而非简单搜索

查询不是关键词匹配，而是基于知识图谱的综合问答。问"我最近有什么待办"，AI 综合所有记录按时间排序回答；问"闺蜜生日送什么"，AI 综合历史送礼偏好给出建议。

灵感来源：Obsidian + Karpathy

Obsidian 原生知识图谱

不是用 D3.js 画一个简陋的图，而是直接生成 Obsidian 标准的 Markdown 笔记，用 [[双链]] 关联实体。用户可以在 Obsidian 里用原生 Graph View 查看知识网络——这是知识管理领域最成熟、最漂亮的可视化方案。

灵感来源：OpenClaw

本地优先架构 + 飞书/企业微信消息交互

所有数据存储在本地 Obsidian Vault，以 Markdown 文件形式存在，解耦存储与计算，保障数字资产绝对主权——即便 MemoFlow 不在了，用户的记忆依然是可以用任何文本编辑器打开的 Markdown。飞书/企业微信消息通过本地网关处理，调用豆包 API 解析后写入本地文件。你的记忆永远属于你自己，不会上传到任何云端。不需要打开任何 App，直接在飞书里给 MemoFlow 机器人发消息就能记录和查询。

目标用户与使用场景

核心用户

20-40 岁的职场人士、知识工作者和多任务管理者，日常工作活跃在微信、钉钉、飞书、邮件等多个平台，信息获取量大但整理能力差。需要管理工作文件（报价单、报表、合同）、生活琐事（家人叮嘱、购物清单）、以及学习知识（技术文章、课程笔记、概念关联）。

价值与意义

为什么这件事值得做

  • 效率革命：多格式输入（文字/图片/PDF/Excel/Word/PPT），一个入口管理一切。从 5-10 分钟翻找降到 5 秒语义检索。
  • 知识复利：借鉴 LLM Wiki 思想，信息不再被消费而是被投资。每条新记录都被 AI 自动"编译"为结构化知识，与已有信息建立关联。这是一次从"数据存储"到"知识编译"的范式转变——用得越多第二大脑越聪明。
  • 真实刚需：每个多平台用户都有信息散落焦虑，工作文件过期更是职场人的集体噩梦。痛点普遍且高频。
  • 商业潜力：用户数据沉淀形成迁移壁垒，天然可拓展到订阅制、团队协作版、企业知识库。AI 时代个人数据资产管理是万亿级市场。
  • 社会价值：帮助轻度 ADHD 用户、多任务管理者减轻信息焦虑，提升生活与工作的掌控感。

技术实现

初赛 Demo 阶段聚焦核心体验，采用简洁技术栈：

Obsidian Vault（本地存储） Markdown + YAML frontmatter Node.js 本地网关 飞书/企业微信机器人 豆包大模型 API（多模态） 本地 SQLite + 向量检索

数据存储在本地 Obsidian Vault，所有记忆以 Markdown 文件形式存在，用 [[双链]] 关联实体，Obsidian Graph View 原生展示知识图谱。AI 层由豆包大模型负责多格式内容解析、实体关系提取、语义 Embedding 和智能问答。飞书/企业微信消息通过本地网关处理，调用 AI 后写入本地文件。检索层用本地 SQLite + 向量检索，所有数据不出本地，隐私绝对安全。

产品愿景

MemoFlow 的终极目标是成为每个人的"第二大脑"——你不需要记住任何事情，只需要负责生活和创造。所有信息的捕获、整理、关联、检索和提醒，全部交给 MemoFlow。信息不再散落在微信、小红书、邮件的各个角落，而是汇聚成一个持续生长、可交叉引用的知识网络。

"你只管过生活，记忆交给 AI。"
