创意介绍

想解决什么问题？

开发者和系统管理员在日常工作中频繁需要连接远程服务器，现有的 SSH 工具要么功能简陋，要么过于复杂，缺乏统一的管理界面和便捷的操作体验。 SSH Connect Pro 旨在打造一款界面美观、功能完善、易于使用的专业级 SSH 连接管理工具。

为什么会想到做这个？

作为开发者，每天都需要连接多台远程服务器进行部署和维护，现有的终端工具在多连接管理、文件传输、会话保存等方面存在诸多不便。 灵感来源于对提升工作效率的追求，希望打造一款集终端连接、文件管理、连接管理于一体的一站式工具。

大概是什么产品？

桌面应用程序（Electron），提供现代化的暗色主题界面，支持多标签页管理多个 SSH 连接，集成 SFTP 文件传输功能， 核心亮点是 MCP API 远程控制能力——通过标准化的 RESTful 接口，允许外部工具、自动化脚本、CI/CD 管道无缝集成 SSH 管理能力， 真正实现服务器管理的自动化和智能化，让服务器管理变得简单高效。

核心特色 — MCP 集成亮点功能

什么是 MCP？

MCP (Message Control Protocol) 是一套标准化的 API 接口协议，允许外部工具和脚本通过 HTTP 请求与 SSH Connect Pro 进行通信。 这意味着您可以将 SSH 连接管理能力集成到自动化工作流、CI/CD 管道、自定义脚本或其他开发工具中。

MCP API 核心能力
GET /mcp/status - 检查服务状态
POST /mcp/command - 执行命令
{"type": "list_connections"} - 列出所有连接
{"type": "execute_command", "connId": "...", "command": "whoami"} - 在指定连接执行命令
{"type": "new_connection", "config": {...}} - 创建新连接
{"type": "close_connection", "connId": "..."} - 关闭连接
GET /mcp/connections - 获取连接列表详情
MCP 的应用场景
1. 自动化脚本集成：编写 Python/Shell/Node.js 脚本，自动部署代码到多台服务器。
2. CI/CD 管道：在 GitHub Actions、GitLab CI 等持续集成工具中调用 SSH 命令。
3. 快捷指令：通过快捷方式一键执行常用运维命令。
4. 自定义工具：基于 MCP API 构建专属的服务器管理面板。
5. 批量操作：同时向多台服务器发送命令，提高运维效率。
MCP 技术优势
• 标准化接口：遵循 RESTful 设计规范，易于理解和使用
• 跨语言支持：任何支持 HTTP 请求的语言都可以调用
• 实时反馈：支持命令执行结果的实时流式返回
• 安全认证：支持 API Key 和请求签名验证
• CORS 支持：允许前端应用直接调用，无需额外代理
• 端口可配置：默认端口 9876，可在设置中修改
使用示例
curl -X POST http://localhost:9876/mcp/command
-H "Content-Type: application/json"
-d '{"type": "execute_command", "connId": "conn-123", "command": "ls -la"}'
