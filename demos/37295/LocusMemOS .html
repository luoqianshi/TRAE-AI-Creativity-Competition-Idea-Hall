Dual Search Engine

快与慢的艺术

两种搜索模式，对应两种思维节奏。 快速搜索满足日常查找，慢搜索解决深度研究。

Fast Mode — LM Wiki

快速搜索

基于 LM Wiki 思路构建的本地索引，支持文件名、标题、关键词的即时检索。 输入过程中实时呈现结果，像翻字典一样自然。

  • 响应速度< 50ms
  • 索引方式全文倒排 + BM25
  • 匹配模式前缀 / 模糊 / 关键词
  • 适用场景日常快速查找
  • 数据来源文件名 + 要素摘要
Deep Mode — Precise

慢搜索

基于语义向量的精确内容匹配。即使你无法回忆起确切关键词， 只需描述模糊印象，系统也能从文件深处找到答案。

  • 响应速度200ms – 2s
  • 索引方式语义向量 + 相似度
  • 匹配模式语义理解 / 上下文
  • 适用场景深度研究 / 模糊记忆
  • 数据来源文件全文内容

实现预览

核心处理逻辑的简化示意 —— 从文件采集到知识索引的完整链路。

knowledge_pipeline.py
# LocusMemOS — 本地知识管理处理管线

from langchain import DocumentLoader, EntityExtractor
from knowledge_graph import LocalGraph
from search_engine import FastIndex, SemanticIndex

class KnowledgePipeline:
    def __init__(self, watch_dir):
        self.graph = LocalGraph()
        self.fast_idx = FastIndex()     # LM Wiki 快速索引
        self.deep_idx = SemanticIndex()  # 语义向量索引
        self.noise_ext = {'.icloud', '.code', '.tmp'}

    def process_file(self, filepath):
        # 1. 噪声过滤
        if self.is_noise(filepath): return
        # 2. 智能去重（保留最新版本）
        self.deduplicate(filepath)
        # 3. LangChain 内容解析 & 要素提取
        doc = DocumentLoader.load(filepath)
        entities = EntityExtractor.extract(doc)
        # 4. 写入知识图谱
        self.graph.add_document(doc, entities)
        # 5. 双引擎索引
        self.fast_idx.index(filepath, doc)
        self.deep_idx.embed(filepath, doc)
        # 6. Git 云端备份
        self.git_backup(filepath)
