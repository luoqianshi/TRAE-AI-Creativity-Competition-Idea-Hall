项目背景与痛点

随着AI辅助编程、流式开发普及，开发者交互方式正在发生变化。键盘负责精准输入、语音负责自然指令，但二者切换频繁，极易打断开发心流。

🔒

商用方案封闭

商用智能笔多面向教育场景，功能固化、协议封闭，无法适配开发者自定义工具链，二次开发无门。

🧩

开源Demo级

开源社区的同类项目多为Demo级玩具方案，缺少量产级的稳定性、低功耗设计与完整结构落地。

📄

功能单一

普通翻页笔仅能实现基础翻页，无法满足AI开发场景下复杂快捷键、语音联动、多设备切换的需求。

核心功能

主打「全开源、可定制、低成本、可落地」四大核心特性，为开发者提供极致的交互体验。

⌨️

全按键可编程映射

5个物理按键支持单击/长按/双击/组合键自由配置，可绑定任意快捷键、宏指令，一键适配VS Code、IDEA等全品类开发工具。

🎤

原声级语音透传

内置PDM数字麦克风，本地做基础数字降噪，完整保留人声特征，完美适配PC端各类AI语音识别、语音输入法。

🖱️

基础六轴空鼠

标准HID鼠标协议全平台免驱，支持灵敏度调节，满足大屏代码评审、架构演示的远程操控需求。

🔋

双模式低功耗连接

支持BLE蓝牙直连 + USB Dongle免驱即插即用，配套多级休眠状态机，兼顾续航与唤醒响应速度。

🔄

通用可换电池设计

采用标准14500（5号外形）3.7V锂电池，用户可自行更换备用电池，实现无缝续航。

📦

全栈开源开放

固件源码、硬件原理图、PCB、通信协议全部开源，预留GPIO扩展接口，支持社区二次开发与功能拓展。

技术框架

基于成熟商用方案重构，整体采用「笔端从机 + Dongle主机 + 上位机配置工具」的三段式架构。

核心数据链路

按键链路 → ADC分压采样 → 状态机解析 → HID/自定义指令上报
姿态链路 → I2C读取陀螺仪 → 卡尔曼滤波平滑 → BLE HID协议上报
音频链路 → PDM麦采集 → 数字滤波降噪 → 蓝牙透传 → Dongle解码
电源链路 → ADC电量采集 → 多级休眠状态机 → 低功耗模式切换

应用场景

从AI流式编程到技术评审，一支笔满足多种开发场景需求。

01

AI流式编程

单手完成快捷键触发、语音输入，减少键鼠切换，维持开发心流。一键触发AI代码补全、生成注释，提升编程效率。

02

技术评审与授课

远程空鼠操控大屏代码、架构图，无需固守电脑前，提升讲解互动感。支持手势翻页、局部放大，演示更自由。

基于成熟量产底座，快速扩展自定义功能、创意硬件项目。预留GPIO扩展接口，支持传感器、LED等外设扩展。

04

多设备协同开发

一支笔配对多台设备，一键切换，适配多主机、开发板的开发场景。支持双连接模式，无缝切换工作环境。
