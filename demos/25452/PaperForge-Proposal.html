Problem

写论文，排版比写作更折磨人

各校各刊格式各一套。学生在 Word 里反复调页边距、标题编号、参考文献，同一套操作每篇论文重来一遍。

😩

手工改样式

重复、易错，改完还不确定是否符合学院 PDF 规范。

📐

LaTeX 门槛高

排版规范但学习成本大，多数学生最终仍交 Word。

🎲

AI 一键排版不可靠

黑盒输出难以验证，标题层级、参考文献格式常常出错。

💸

代排服务不可控

淘宝排版贵、周期长，配置无法复用到下一篇论文。

Solution

像填表一样配格式，像写目录一样填章节

PaperForge 把排版拆成两步：先用表单定义格式参数（页边距、字体、标题编号、参考文献标准），再按章节树填入摘要与正文，服务端一键渲染成 .docx，本地用 WPS / Office 打开即可。

① 配置格式参数 → ② 填写章节内容 → ③ 生成 Word → ④ 格式自检 → ⑤ 下载 / 交稿

Features

四大核心能力

01

格式配置表单

页面、正文、标题 1～3 级、图表题、参考文献、页眉页脚——分组 Tab 一次配齐，支持 JSON 导入导出与「我的预设」复用。

02

章节树 + 内容块

先建结构再填内容：段落、图+题、表+题、参考文献条目。避免边写边改标题层级的混乱。

03

服务端渲染 docx

FastAPI + docxtpl / python-docx，Open XML 确定性输出，无需安装 Office 插件，WPS / Word 直接打开。

04

格式规则检查

对生成或上传的 docx 跑规则引擎：标题样式、边距、摘要字数、参考文献格式等，输出可读的检查报告。

Architecture

CS 架构：浏览器填表，服务端出文档

配置与内容以 JSON 提交，排版服务在云端渲染，用户下载 docx。论文敏感数据 HTTPS 传输，文件定期自动删除。
