核心技术原理

基于CPM关键路径法的实时重算引擎与影响传播算法

01 / CPM ENGINE
关键路径法实时计算引擎
采用改进的CPM（Critical Path Method）算法，将项目任务建模为有向无环图（DAG）。正推计算最早开始/结束时间（ES/EF），逆推计算最晚开始/结束时间（LS/LF），总浮动时间TF=LS-ES。TF=0的任务构成关键路径。当任一任务工期变更时，引擎以O(V+E)复杂度完成全图重算。
DAGCPMO(V+E)
02 / IMPACT PROP
延期影响传播算法
当任务T延期d天时，算法沿DAG的拓扑序正向传播：若T在关键路径上，所有下游关键任务和最终交付日期均推迟d天；若T不在关键路径上且d<=TF(T)，则无全局影响但TF缩减；若d>TF(T)，则T变为关键任务，新的影响路径被计算并高亮。
拓扑排序传播算法路径切换
03 / BUFFER ANALYSIS
浮动时间借用优化
当关键路径上任务延期导致交付推迟时，系统自动扫描所有非关键任务的总浮动时间，计算"如果压缩某非关键任务可以弥补多少延期"。生成压缩建议列表，按"可弥补天数"降序排列，帮助管理者快速决策哪些非关键任务可以"借时间"。
浮动时间压缩建议优化决策
04 / VIZ ENGINE
动态甘特图渲染引擎
基于Canvas的高性能甘特图渲染，支持50+任务流畅动画。任务条的位置、宽度和颜色通过CSS transition平滑过渡，当关键路径变化时用户能看到"路径切换"的动画过程。关键路径用脉冲发光效果突出，延期任务用红色闪烁，受影响任务用金色渐变，形成直观的视觉语言。
CanvasCSS动画视觉编码
05 / DEP GRAPH
依赖关系图编辑器
提供可视化的依赖关系编辑器，用户通过拖拽连线设置任务间的前置依赖（FS/SS/FF/SF四种关系类型）。支持自动检测循环依赖并提示，防止用户创建无效的项目网络。依赖关系变更后自动触发关键路径重算。
拖拽连线循环检测四种关系
06 / SCENARIO SIM
多场景假设模拟
支持"假设分析"模式：用户可以同时模拟多个任务的延期组合（如"A延期2天 + C延期1天"），系统计算组合场景下的新关键路径和交付日期。支持保存多个假设场景进行对比，帮助管理者在"接受延期""压缩工期""调整范围"之间做出最优决策。
假设分析多场景对比决策支持

建模层
用户通过表单或拖拽创建任务，设置工期、前置依赖和里程碑。支持四种依赖关系类型，自动检测循环依赖。
计算层
CPM引擎执行正推（ES/EF）和逆推（LS/LF），计算总浮动时间TF和自由浮动时间FF。关键路径=TF=0的任务链。
分析层
延期传播算法沿拓扑序计算影响范围。缓冲借用优化扫描非关键任务的可压缩空间，生成排序建议。
展示层
Canvas甘特图渲染+CSS动画过渡。关键路径脉冲发光，延期/受影响任务颜色编码。支持PDF导出。
