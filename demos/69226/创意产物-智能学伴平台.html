01. 创意缘起

当前高职院校AI通识课程的配套智能体，基本都集中在技能学习的对话，用户体验不好，有些为做而做的感觉。学生只是"用"别人造好的AI工具，缺乏真正的参与感和自主性。

我们提出了一个核心追问：如果简单的对话不足以启发学生的自主性，那么什么可以？

答案是：创造、归属与意义感。由此，我们构建了平台的三层架构——

🚀 第一层：创造自己的AI学伴

教学生直接在Coze上搭建属于自己的智能学伴，从"用学伴"升级为"造学伴"，获得真正的ownership。

🎯 第二层：职业情境化通用技能训练

面向所有专业的真实岗位场景，每项任务必带情境、必有需求，培养AI时代所有岗位都需要的通用能力。

💡 第三层：全人育人 · 人生规划

先做人生规划，再做职业规划。通过科学测评、健康引导、情感陪伴，建立对生活的热爱。

03. 三层架构详解

第一层：创造属于自己的AI学伴

如果学生只是在平台上"使用"一个别人造的AI，说到底还是在消费。真正的自主性，来自"我的学伴是我造的"这种拥有感和创造感。

注册Coze → 选择学伴模板

零门槛的Coze搭建流程引导，学生跟着步骤即可完成学伴创建

设定人设 & 风格

学长型/导师型/朋友型/助手型？护理专业绑定医疗场景知识，烹饪专业绑定食材知识库

配置知识库 & 调试Prompt

导入课程大纲、教材摘要，调整回答风格，让学伴按期望的方式互动

发布到学伴集市

全班/全校的学伴互相展示、试玩体验、点赞评论，优秀学伴成为下学期"官方推荐配置"

教育意图：搭建学伴本身就是一个完整的AI实践项目。学生需要理解AI能做什么、不能做什么，才能合理设定学伴的能力边界；需要设计Prompt，才能让学伴按期望的方式互动——这个过程本身就是在培养AI素养。

AI通识课程面向所有专业学生，对应的是所有岗位都会用到的AI通用技能：需求分析、问题拆解、流程设计、人机协作。

第三层：全人育人 · 人生规划

技能和素养解决了"会做什么"，但没解决"为什么而做"。

💼 生涯规划助手

不是职业测试，而是深度对话引导："你觉得什么样的工作状态会让你幸福？""把你的人生分成5个阶段，你想在每个阶段获得什么？"

🏃 生活健康教练

作息提醒、运动打卡、饮食建议、睡眠日志——学伴根据学习计划提醒合理作息

💕 成长陪伴者

恋爱话题、兴趣探索、迷茫倾诉、同辈社交——安全的空间表达焦虑，学伴给予温暖陪伴

🧠 就业焦虑疏导

"我学的专业好找工作吗？""AI会取代我们吗？"——理性分析 + 真实案例 + 可行动的小目标

核心育人主张：先做人生规划，再做职业规划。建立对生活的热爱 之前，先建立对自己的了解。

专业生涯规划系统

  • Holland 职业兴趣测验（简化版）：RIASEC六种类型匹配
  • 价值观排序卡片：金钱/自由/创造/稳定/影响力/成长

🌍 世界探索：专业认知

  • 专业全景地图：学什么、做什么、典型岗位的一天
  • 学长学姐故事：真实校友路径
  • AI职业对话：角色扮演式回答"如果我做XX岗位..."

🎯 决策与行动：互通互促

  • 人生→职业：阶段目标自动分解为职业里程碑
  • 职业→人生：职业探索中的发现反馈到人生规划
  • 行动清单：本学期要做的10件事（学习/社交/健康/兴趣）
  • 动态追踪：每学期末回顾，AI辅助调整方向

04. 教育方法论整合

平台将STEM教育理念、OBE（成果导向教育）、PBL（问题导向学习）、布鲁姆认知模型等引入，从"个人学习工具"升级为"教学活动平台"。

方法论核心理念平台落地方式
OBE 成果导向 以终为始，先定义学习成果再设计教学 先定义每项能力的达成指标，反向设计情境任务难度。学习画像实时验证成果达成度。
PBL 问题导向 以真实问题驱动学习 每个情境任务就是真实职业问题。学生不是"学完再做"，而是"在做中学"。
STEM 跨学科 融合科学、技术、工程、数学 造学伴=工程实践 | 情境分析=科学方法 | AI工具=技术 | 数据分析=数学
布鲁姆模型 认知六阶：记忆→理解→应用→分析→评价→创造 情境任务按布鲁姆阶梯分级难度。造学伴对应"创造"层。

教学形式：从"个人"到"团队"

👥 团队协作

情境任务支持2-4人组队：项目经理/数据分析师/方案撰写者/AI操作员，团队学伴拼成"团队智囊团"

🏆 分组竞争

学伴PK赛、情境挑战赛、跨班级联赛——在竞争中激发学习动力

🎤 方案路演

3-5分钟方案陈述，AI辅助Q&A，同学互评 + AI评估形成"多元反馈"

🏅 成就与激励

能力徽章、学伴大师、路演之星、学期成就墙——系统化的激励体系

05. 可评可测：成果评估体系

根据职业教育关键要素改革要求，平台具备清晰的可评可测能力。

📊 四维能力画像

  • AI实操能力（0-100分）：学伴搭建完成度、配置复杂度、迭代次数、集市推荐数
  • 通用职业能力（0-100分）：按能力维度逐个统计情境任务完成质量
  • 生涯认知成熟度（0-100分）：测评完成度、规划完整性、行动清单明确度
  • 生活健康习惯（0-100分）：打卡频率、作息规律性、运动目标达成率

📈 过程性数据采集

  • 对话轮次 → 深度思考程度
  • 问题修改次数 → 迭代优化意识
  • AI使用策略 → 人机协作能力
  • 路演完成情况 → 表达沟通能力
  • 互评深度 → 批判性思维

👥 多元评估主体

  • AI自动评：按预设维度评估格式完整性、逻辑清晰度
  • 同学互评：情境任务产出进行小组互评
  • 教师终评：AI和互评结果作为参考，教师给出最终评分
  • 学生自评：学生对自己的成长过程自评

🎯 育人属性可评价

  • 健康生活习惯：频率追踪 + 目标达成率
  • 生涯认知清晰度：完整度评分 + 时间轴可追溯
  • 工匠精神：迭代次数统计
  • 安全责任意识：情境任务中风险识别完整度
  • 团队协作：贡献度量化 + 队友评价
设计原则：可评可测不等于"唯分数论"。分数只是反馈工具，不是目的。核心价值是：（1）让学生清晰看到自己哪里成长了；（2）让教师掌握班级整体能力达成情况；（3）让育人属性不再"虚"，真正落到可追踪、可评价的实处。

06. 技术实现要点

🔗 与Coze深度整合

通过Coze API管理学伴的创建、配置和发布。Coze的Bot API允许平台自动创建/克隆学伴模板，Knowledge API支持上传课程资料作为知识库。

📋 情境任务引擎

预置50+专业场景模板，覆盖主流职业方向。任务发布时通过LLM动态适配学生专业和已学内容，自动生成四阶段引导。

📊 生涯成长数据模型

画像不用于排名比较，而是用于个性化推荐：推荐下一个最合适的情境任务、建议学伴迭代方向、触发生涯对话节点。

技术栈

React + TypeScript Tailwind CSS Node.js / Next.js Coze API LLM APIs PostgreSQL Vector DB

08. 总结

这个方案回答了一个核心问题：如果对话不足以启发职业院校学生的自主性，那么什么可以？

答案是：一个让学生亲手创造自己的AI学伴、在真实的职业情境中解决实际问题、在科学测评中认识自己、在团队协作与路演中综合成长的平台。

这不是一个"AI教育工具"，这是一个 "用AI帮助大一新生成长为完整的人" 的教学活动平台。

创造AI学伴 → 在职业情境中学会思考 → 在科学测评中认识自己 → 在团队中学会协作 → 在路演中学会表达 → 在规划中找到方向。

我们的信念：这个平台面对的是18岁的年轻人。他们可能在高考中受了挫折，可能对未来充满不安，可能表面满不在乎但内心渴望被认可。我们在培养祖国的未来。每一个设计决策都要问自己：如果我的弟弟妹妹在用这个产品，我会放心吗？
