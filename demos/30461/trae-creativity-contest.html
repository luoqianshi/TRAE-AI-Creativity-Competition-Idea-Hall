JWT RBAC AuditLog

FlowGram 流程图设计器，支持开始、结束、LLM 节点、条件判断、循环、审批端口与子工作流，业务流程可视化与代码解耦。

05 — Workflow Engine

工作流执行

可视化流程编排与声明式工作流定义，支持并行与人工审批

开始
→
任务规划
→
数据分析
→
代码生成
→
审批
→
输出结果
Sequential
节点顺序执行，结果在步骤间传递，支持子工作流嵌套调用。
Fan Out / In
多个智能体并行处理子任务，汇聚后继续下一步，显著提升吞吐。
RequestPort
工作流在关键节点挂起，等待人类审批；通过 Checkpoint 保存状态并恢复执行。
06 — Innovation Highlights

创新亮点

在工程化、可观测性与业务流程自动化方面的差异化设计

Ⅰ

领域知识网络

DKN 与 DRKN 结合，在传统 RAG 之外增加实体与关系层面的知识关联与推理能力。

Ⅱ

Agent 自动循环

AgentLoopExecutor 自动管理 LLM 调用、函数执行与历史消息拼接，并在连续错误时优雅处理。

Ⅲ

统一技能协议

ISkill 接口规范支持技能的热插拔与动态发现，无论是内建能力还是工作流暴露的 MCP Tool 均可被调用。

Ⅳ

声明式工作流

WorkflowBuilder + Executor 模式，将业务流程从代码实现转为图形化声明，降低非开发人员的参与门槛。

Ⅴ

人类介入审批端口

RequestPort 与 Approval 模块深度集成，在关键节点由人工决策后继续执行，确保关键业务场景的可控性。

Ⅵ

思维链与可观测性

工作流事件流 + SSE 推送前端，结合 OpenTelemetry 追踪 Agent 与 Workflow 调用链路，问题排查一目了然。

从基础设施到业务场景的距离

PaulX 提供完整的多智能体开发框架，让团队专注于真正创造价值的业务创新，而非从零搭建基础设施。
