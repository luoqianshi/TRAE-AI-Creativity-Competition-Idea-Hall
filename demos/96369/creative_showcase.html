创意概述

🎯 解决的问题

普通投资者面对海量股票信息时，难以系统化地筛选优质标的、追踪市场变化并做出理性决策，常常陷入信息过载与情绪化交易的困境。

💡 灵感来源

作为个人投资者，深感A股市场信息量大、变化快，仅凭人工分析难以做到全面覆盖和及时响应。因此构建了这个本地量化分析系统，让AI辅助投研。

🔍

AI辅助分析

利用大语言模型对结构化证据进行解读，生成大盘分析、新闻解读和操作建议，让复杂数据变得易懂。

📊

实时监控自选股状态，按趋势、动量、量能等多维度生成综合评分，及时预警风险。

🧪

🛡️

综合评估持仓风险，包括组合VaR、相关性分析和压力测试，全面把控投资风险。

工作流程

数据采集：自动从Tushare、东方财富、AKShare等数据源获取日线行情、实时快照、资金流向、公告新闻等数据
信号生成：基于MA、MACD、RSI、BOLL等技术指标和资金流向，生成趋势突破、回调低吸等交易信号
风险过滤：综合评估20日回撤、波动率、流动性、公告风险等因素，筛选优质机会
AI解读：大模型将结构化证据整理成可读的大盘分析、新闻解读和操作建议
用户决策：用户根据系统提供的建议和证据，结合个人判断做出最终交易决策

Python FastAPI React + TypeScript DuckDB ECharts Tushare Pro AKShare 东方财富API OpenAI / Ollama Vite Lucide React

价值与意义

⚡ 效率提升

系统自动完成数据更新、全市场扫描、信号生成等耗时工作，将投资者从繁琐的信息收集中解放出来，平均每天节省2-3小时投研时间。

🔒 隐私安全

本地部署模式保障用户数据隐私，所有投资数据存储在本地，避免敏感信息泄露，让用户安心使用。
