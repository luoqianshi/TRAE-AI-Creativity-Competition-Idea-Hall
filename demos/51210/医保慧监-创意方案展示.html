01 / 创意介绍

用智能规则引擎，
守护老百姓的"看病钱"

医保基金违规使用问题频发，传统人工审核效率低、覆盖面窄。我们构建了一套集知识库、规则库、统一规则引擎于一体的智能监管系统，将违规发现从"事后抽查"升级为"全量预警+闭环整改"。

🎯

想解决什么问题

医保基金违规使用问题频发，传统人工审核效率低、覆盖面窄，海量结算数据难以实现全量实时监管，违规行为往往事后才被发现，造成基金不可逆损失。

💡

为什么会想到做这个

在医院信息科日常工作中发现，医保基金监管高度依赖人工经验，政策规则分散在各类文件中难以快速检索，违规筛查缺乏系统化工具支撑。同时国家医保局飞行检查常态化，医院急需一套能自动预警、快速响应的监管工具。

🖥️

大概是什么产品

这是一套基于 Web 的医保基金智能监管系统，内置两库（知识库+规则库）和统一规则引擎，可自动筛查结算数据中的违规行为，生成稽核台账并跟踪整改闭环。

🔧

技术亮点

采用 Spring Boot + Vue 3 双端架构，支持 Oracle HIS 数据源实时对接与定时增量同步；规则引擎可灵活配置，支持 ICD 编码匹配、药品目录校验、高频异常查询检测等多种违规模式，无需改代码即可新增规则。

02 / 目标用户及痛点

如果没有它，
监管人员每天在经历什么

面向医院医保管理部门、医保局稽核人员、医院信息科运维人员。以下是当前真实存在的五大痛点。

01

人工审核效率极低

一名审核员每天只能处理有限病例，大量数据无法覆盖。全量结算数据动辄数万条，人工逐条审核根本不现实，违规线索大量遗漏。

02

政策规则分散难检索

规则分散在红头文件、通知公告中，检索困难，更新不及时。不同审核人员理解标准不一，同一违规行为在不同人手中判定结果可能完全不同。

03

违规发现严重滞后

往往到季度结算甚至飞行检查时才暴露问题，错失最佳整改窗口。等到发现时，违规行为已持续数月，基金损失已不可逆。

04

整改缺乏闭环管理

发现问题后通知下发、整改反馈、复核确认全靠线下流转，容易遗漏。缺乏系统化的台账追踪，整改是否到位全凭人工催办。

05

监管经验难以沉淀

缺乏统一的医保监管知识沉淀机制，审核经验存在老员工脑中。人员调动或退休后，积累的违规识别经验随之流失，新人需从头摸索。

06

数据孤岛无法联动

结算数据、药品目录、ICD 编码、患者信息分散在不同系统中，无法交叉比对。诸如"串换药品""高套病种"等违规需要多维度数据关联才能发现。

05 / 应用场景

六大场景，
覆盖监管全生命周期

📊

日常结算数据批量筛查

每日定时对全量医保结算数据执行规则匹配，自动标记疑似违规记录，生成稽核台账供审核人员复核。

🚨

违规风险实时预警

对高频异常查询、重复开药、超量开药等行为实时监控，触发阈值立即预警，支持弹窗文案自定义提醒临床医生。

🔍

飞行检查前自查自纠

在国家医保局飞行检查前，一键启动全量规则扫描，提前发现并整改问题，降低检查风险。

📖

政策法规知识快速查询

知识库沉淀医保政策文件、违规案例、审核要点，支持全文检索，新员工快速上手，经验不再随人员流动流失。

✅

违规整改流程闭环跟踪

从违规发现 → 通知下发 → 整改反馈 → 复核确认，全流程线上流转，整改进度可视化，杜绝遗漏。

🤝

多角色协同监管

支持管理员、审核员、访客等多种角色，细粒度权限控制，医保办、信息科、临床科室协同工作，各司其职。
