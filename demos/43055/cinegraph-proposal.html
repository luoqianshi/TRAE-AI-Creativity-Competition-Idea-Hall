影视立项可视化工作台 —— 让每一张人物关系图与故事结构图，都成为打动投资人的专业提案。

了解创意详情

创意介绍

想解决什么问题：影视从业者在立项汇报时必须提交人物关系图与故事结构图，但现有工具要么过于专业复杂（Visio、OmniGraffle），要么功能简陋（PPT 自带图形），且缺乏影视行业专用模板，导致制图效率低、视觉效果参差不齐。

灵感来源：在参与短片项目时，团队花费大量时间在 PPT 里手动拖拽节点、调整连线。我们意识到：影视制图工作应该被标准化、模板化，让创作者把精力放回内容本身。

产品形态：基于浏览器的可视化编辑器 Web 应用，支持人物关系图绘制与故事结构图编排，内置经典剧本模板，可一键导出高清 PNG/SVG 直接插入 PPT。

核心功能

🎭 人物关系图

自由添加角色节点与关系连线，支持四向连接点、双箭头样式、自由/吸附模式切换，一键自动规整布局，导出高清 PNG。

📜 故事结构图

内置三幕式、救猫咪、英雄之旅等经典剧本模板，一键生成节拍卡片；支持时间轴、流程图、环形、情绪曲线、角色矩阵五种视图。

🎨 视觉定制

节拍卡片支持矩形/圆角/胶囊三种形状、实心/描边/填充三种样式、自由拖拽缩放；情绪曲线实时渲染，角色矩阵自动映射。

📤 一键导出

支持 PNG/SVG 格式、白底/透明背景、2x–4x 高清分辨率导出，直接适配影视立项 PPT 与海报印刷需求。

目标用户与痛点

核心用户：影视制片人、编剧、导演、策划，以及影视院校师生。

使用场景：影视项目立项汇报、剧本研讨会、投资路演、课程作业与毕业设计展示。

当前痛点：

  • PPT / Keynote 中手动绘制节点和连线，布局调整耗时且容易错乱；
  • 故事结构图缺乏行业标准模板，每个人画的格式不统一；
  • 情绪曲线、角色矩阵等高级图表几乎无法在常规工具中快速制作；
  • 导出分辨率不足，放大后模糊，无法满足印刷和投影需求。

价值与意义

效率提升：内置经典剧本结构模板与自动布局算法，用户只需填写内容即可生成专业级图表，制图时间从数小时缩短至数分钟，效率提升 80% 以上。

社会价值：降低影视行业入门门槛，让独立创作者、学生剧组也能制作出高水准的立项材料，促进优质内容孵化与人才成长。

技术实现

基于 React 18 TypeScript Vite Zustand React Flow Tailwind CSS 构建，采用组件化架构与不可变状态管理，支持深色/浅色主题切换，所有数据本地持久化，无需后端即可离线使用。
