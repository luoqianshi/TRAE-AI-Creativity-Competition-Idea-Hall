Core Capability

一个能继续长大的互动影像底座

当前原型已经形成从欢迎页、选剧页、播放页到存档管理的完整闭环，适合继续接入新故事、 新角色、新视频素材与新的分支逻辑，用较低成本持续验证互动内容产品方向。

内容结构

视频节点 + 对白 + 选项

每个场景以视频为核心节点，在指定时机触发对白和选择。内容节奏仍然保留电影感， 但关键推进权交给用户。

体验设计

从单向观看升级为参与式体验

用户不再只是看完离开，而是在剧情关键点做判断、影响路线、比较结局，天然提升停留时长与复玩动力。

工程能力

模块化扩展与本地存档

前端结构清晰，故事内容可 JSON 化配置。后续新增剧情时，不需要重写整套系统，只需补充素材与配置。

Audience

目标用户

喜欢剧情体验、互动叙事、视觉小说、悬疑探索和互动短剧的年轻用户， 以及未来希望做互动内容验证的文娱团队与创作者。
