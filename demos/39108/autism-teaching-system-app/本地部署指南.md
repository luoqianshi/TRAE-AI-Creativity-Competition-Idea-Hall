# 自闭症儿童教学管理系统 - 本地部署指南

## 一、环境要求

- **Node.js**: 18.0 或更高版本
- **npm**: 9.0 或更高版本（随 Node.js 一起安装）
- **浏览器**: Chrome / Edge / Firefox 最新版

## 二、安装 Node.js（如果尚未安装）

1. 访问 https://nodejs.org
2. 下载 **LTS**（长期支持）版本
3. 运行安装程序，一路点击"下一步"即可
4. 安装完成后，打开命令提示符（CMD）或 PowerShell，验证安装：
   ```bash
   node -v
   npm -v
   ```
   如果显示版本号，说明安装成功。

## 三、项目部署步骤

### 步骤 1：解压项目

将下载的 `autism-teaching-system-app.zip` 解压到任意目录，例如：
```
D:\projects\autism-teaching-system-app\
```

### 步骤 2：安装依赖

打开命令提示符（CMD）或 PowerShell，进入项目目录：
```bash
cd D:\projects\autism-teaching-system-app
npm install
```

等待安装完成（约 1-2 分钟）。

### 步骤 3：启动开发服务器

```bash
npm run dev
```

启动成功后，会显示类似如下信息：
```
  VITE v8.0.16  ready in 200 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

### 步骤 4：访问系统

打开浏览器，访问：
```
http://localhost:5173
```

## 四、打包为静态文件（可选）

如果需要部署到内网服务器或分享给同事使用，可以打包为静态文件：

```bash
npm run build
```

打包完成后，会在项目目录下生成 `dist` 文件夹。将 `dist` 文件夹中的内容部署到任何静态 Web 服务器即可。

## 五、常见问题

### 1. 端口被占用

如果提示端口 5173 被占用，可以指定其他端口：
```bash
npm run dev -- --port 3000
```

### 2. 安装依赖失败

如果 `npm install` 失败，尝试使用淘宝镜像：
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### 3. 数据存储说明

- 所有数据保存在浏览器的 **LocalStorage** 中
- 不同浏览器之间的数据不互通
- 清除浏览器缓存会导致数据丢失
- 如需多人协作，需要搭建后端服务器

## 八、技术栈

- **前端框架**: React 19 + React Router 7
- **构建工具**: Vite 8
- **样式**: Tailwind CSS 4
- **图标**: Lucide React
- **图表**: Recharts
- **数据存储**: 浏览器 LocalStorage（当前版本）

## 九、后续升级方向

如需多人协作和云端数据同步，建议：
1. 搭建后端服务（Node.js + Express）
2. 接入数据库（PostgreSQL / MySQL）
3. 添加用户认证和权限管理
4. 将 LocalStorage 替换为 API 调用

推荐使用 **Supabase**（免费）快速搭建后端，无需自己写服务器代码。
