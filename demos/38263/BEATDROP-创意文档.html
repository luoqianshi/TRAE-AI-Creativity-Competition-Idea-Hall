产品概述

BeatDrop 是一款基于 Web Audio API 的赛博朋克风格音乐可视化DJ工具。用户通过点击12个音色采样器模块即可实时创作节拍，系统同步生成与音频频率联动的粒子与几何图形可视化效果。无需音乐基础，点击即可成为DJ。

音频合成原理

使用 Web Audio API 的 OscillatorNode 和 BufferSourceNode 合成所有音色：

// 音频信号流程 OscillatorNode / BufferSourceNode ↓ GainNode (包络控制) ↓ BiquadFilterNode (可选滤波) ↓ AnalyserNode (频谱分析) ↓ Destination (输出)

频率分析

analyser.fftSize = 256 analyser.smoothingTimeConstant = 0.8 // 低频(0-15%): 驱动粒子数量和光晕大小 // 中频(15-50%): 驱动频谱环变化 // 高频(50-100%): 驱动细节点缀
