PAIN POINTS

孤独感为什么难以被觉察？

孤独不像身体疼痛那样明显，它悄无声息地积累。等我们发现时，往往已经深陷其中。

◆

孤独感隐蔽

不像身体疼痛那样有明显信号，很多人意识不到自己正处于高孤独状态，以为是"性格内向"或"最近有点累"。

★

测评像考试

传统心理量表需要专门花时间填写，过程像考试一样让人紧张，结果容易贴标签，不愿频繁使用。

♦

干预门槛高

轻度孤独的人不需要"看心理医生"，但也没有合适的小工具。"多运动""多社交"的建议太空泛，难以执行。

♥

以为"只有我"

孤独的人往往以为"只有我这样"，缺乏"这是很多人都会经历的"正常化视角，越封闭越孤单。

CORE CAPABILITIES

六大核心能力

从日常数据的无感化采集到温和干预建议的精准推送，构建不打扰、不评判的自我关怀陪伴系统。

01

日常行为无感化采集

无需专门填写问卷，通过用户授权的聊天记录频率、作息时间、日记文本等多源数据，自动构建连续的情绪状态画像，降低使用门槛至"零主动操作"。

02

五维孤独指数模型

不输出单一数字，而是从"人际连接、自我关怀、情绪能量、社交主动、语言多样性"五个维度综合评估，让用户看到"哪里需要留意"而非"你有问题"。

03

连续趋势可视化

以7天/30天趋势图呈现指数变化，帮助用户觉察"这周比上周好了一点"的微小进步，建立正向反馈循环，避免单次测评的偶然性。

04

温和干预小行动

基于当前状态生成3条简单可行的"小行动"建议，如"给一位朋友发条消息""记录三件小确幸"，执行门槛极低，避免空泛的"多社交"式建议。

05

孤独感正常化社区

匿名社区展示"本周有xx%的用户和你有相似的波动"，让用户知道"不是只有我这样"。支持匿名分享和互相打气，但不强制社交。

06

学校/企业关怀看板

向学校心理中心和企业HR提供匿名聚合的趋势看板，帮助识别毕业季、考试季等关键节点的群体情绪波动，前置性地组织心理支持活动。

TECHNICAL ARCHITECTURE

五层技术架构

从数据采集到干预建议，每一层都遵循"最小打扰、最大保护"的设计原则，隐私优先，安全至上。

L1

多源数据采集层

在用户授权下，采集聊天记录频率（不含内容）、睡眠时段、App使用时长、日记文本情绪倾向等多维数据。所有原始数据本地加密，不上传服务器。

On-device E2E Encrypt Opt-in
L2

边缘计算与特征层

在手机端完成原始数据的脱敏和特征提取（如"本周日均聊天次数""睡眠质量评分"），只上传匿名化的特征向量，从根源上保护用户隐私。

Federated Feature Extract Privacy Compute
L3

AI评估模型层

基于LSTM时序模型分析五维指数的连续变化趋势，结合BERT情绪分析模型处理日记文本，输出综合评估结果和维度拆解。

PyTorch Mobile LSTM BERT
L4

个性化干预引擎

根据用户画像（学生/职场）、当前状态、地理位置和天气等上下文，从干预方案库中匹配最适合的"小行动"建议，支持A/B测试持续优化。

Rule Engine Context Match A/B Test
L5

应用服务层

微信小程序提供个人仪表盘和社区功能，Web管理后台面向学校心理中心和企业HR提供匿名聚合看板，支持导出趋势报告和预警推送。

WeChat Mini Vue.js ECharts
APPLICATION SCENARIOS

四大应用场景

从个人日常觉察到群体心理支持，覆盖大学生和职场年轻人的核心需求场景。

个人觉察

日常情绪状态追踪

用户每天花10秒查看自己的五维指数和趋势图，像看天气一样自然。当某一项连续下降时，收到一条温和的推送："这周你的社交能量有点低，试试给老朋友发条消息？"

日活: 3分钟 门槛: 极低
关键节点

毕业季/考试季群体关怀

学校心理中心通过匿名聚合看板发现毕业季某学院"人际连接指数"整体下降15%，主动在该院组织" farewell 茶话会"和校友连线活动，前置干预避免群体情绪恶化。

预警提前: 2周 干预精准度: +40%
职场关怀

新人入职适应期支持

企业HR为新入职的异地员工开通关怀通道，发现某新人"社交主动性"连续三周极低，安排mentor主动约饭，帮助其更快融入团队，降低试用期流失率。

流失降低: 25% 融入周期: -30%
社区互助

孤独感正常化互助

用户在匿名社区看到"本周有68%的考研人和你有相似的波动"，意识到自己并不特殊。在社区里读到别人分享的"小行动"体验，获得尝试的勇气和灵感。

参与感: +50% stigma: -35%
