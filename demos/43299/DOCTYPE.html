01
创意名称 + 创意介绍

CodonCraft 是一款面向合成生物学与基因工程领域的智能密码子优化工具，旨在解决科研与工业用户在基因序列设计中的效率瓶颈。

🎯

解决什么问题

当前密码子优化依赖人工经验或国外商业软件（如GeneOptimizer、JCat），存在操作繁琐、不支持自定义密码子表、无法排除特定酶切位点等痛点。CodonCraft 让科研团队一键完成序列优化，同时满足个性化实验约束。

核心痛点
💡

灵感来源

杭州无界智研科技在为客户交付基因合成服务时，发现90%的订单都需要密码子优化，但现有工具要么收费昂贵、要么功能封闭。我们决定基于开源框架 DNA Chisel 和 CoCoPUTs 数据库，打造一款国产、开放、可定制化的密码子优化引擎。

项目背景
🛠️

产品形态

Web 应用（支持微信小程序嵌入），提供序列输入、自定义密码子频率表上传、酶切位点排除、多目标优化（CAI + 密码子对 + GC含量 + mRNA二级结构）等功能，输出可直接下单合成的优化序列。

02
目标用户及痛点

精准定位合成生物学产业链中的三类核心用户，他们在基因序列设计环节面临真实且急迫的痛点。

🏭

工业客户：生物制药/酶工程企业

场景：表达重组蛋白、工业酶改造时，需要将外源基因优化为宿主（如大肠杆菌、酵母、CHO细胞）偏好的密码子。

痛点：商业软件授权费高昂（年费数万元），不支持批量上传自定义密码子表，无法排除内部质粒的酶切位点。

🔬

科研客户：高校/研究所课题组

场景：在论文投稿或基金项目执行中，需要对新克隆的基因进行密码子优化以提高表达量。

痛点：现有在线工具（JCat、OPTIMIZER）功能单一，不支持密码子对优化；国外工具访问不稳定，数据安全存疑。

🏢

CRO/CDMO 服务商

场景：为客户提供基因合成外包服务时，需快速生成优化方案并报价。

痛点：人工优化耗时（每条序列需30-60分钟），效率低且易出错，缺乏可嵌入自有系统的开放API。

❌

工具封闭，无法自定义

主流工具（GeneOptimizer、IDT Codon Optimization）为黑盒，不支持上传实验测得的密码子频率表，也不支持排除特定酶切位点。

❌

单目标优化，忽略翻译流畅度

现有工具大多只优化CAI（密码子适应指数），忽略密码子对偏置（Codon Pair Bias），导致mRNA翻译效率提升有限。

❌

数据安全与合规风险

基因序列涉及企业核心知识产权，上传到国外服务器存在数据泄露风险；国内缺乏同等功能的替代方案。

03
解决方案与核心功能

CodonCraft 基于开源框架 DNA Chisel 构建，整合 CoCoPUTs 密码子数据库，提供"输入-优化-输出"的一站式智能服务。

1

输入序列

粘贴氨基酸序列或DNA序列，选择目标宿主物种

2

设定约束

上传自定义密码子频率表，排除酶切位点，设定GC含量范围

3

多目标优化

同时优化CAI、密码子对偏置、MFE（mRNA自由能）

4

输出结果

生成优化序列、评分报告、可直接导入合成平台的格式

📤

自定义密码子表上传

支持用户上传实验测得的或文献中的密码子频率表（CSV/JSON格式），替代默认物种参考数据，满足特殊宿主或工程菌株的优化需求。

🚫

酶切位点智能排除

内置458种常见限制酶位点库，用户可勾选需排除的酶切位点，系统在优化过程中自动避开，确保后续克隆操作顺畅。

🧮

多目标联合优化

同时优化 CAI（密码子适应指数）、CPB（密码子对偏置）、GC含量、MFE（mRNA二级结构自由能），加权评分生成最优序列。

📊

可视化评分报告

输出优化前后对比图（CAI提升率、密码子对得分、GC分布曲线），支持导出PDF报告用于论文投稿或项目汇报。

🔌

开放 API 接口

提供 RESTful API，支持CRO/CDMO企业嵌入自有LIMS系统或官网，实现客户自助下单、自动报价、批量优化。

🔒

数据本地化部署

支持私有化部署（阿里云/腾讯云服务器），基因序列数据不出境内，满足生物制药企业的数据合规要求。
