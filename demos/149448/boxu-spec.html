三、漏洞修复说明

严重 漏洞修复

V1. 车位预约超卖 → 引入并发锁机制

方案：预约时使用 Redis 原子操作（DECR + Lua 脚本）扣减"车位 × 时段"库存

锁粒度：parking_id + spot_id + time_slot 三元组

流程：

  1. 用户发起预约 → 校验时段可用 → Redis 原子扣减
  2. 锁定期 5 分钟，未支付自动释放（TTL 机制）
  3. 支付成功 → 写入 MySQL 订单，状态置为"已预约"
  4. 支付超时 → 回滚库存，订单置"已取消"

验收：并发测试 100 QPS 同一车位同一时段，仅 1 单成功

V2. 押金资金合规 → 分阶段方案

MVP 阶段（V1）：不收押金，引入信用分机制

  • 初始信用分 100，爽约 -20，按时 +2
  • 信用分 < 60 限制预约权限（需现场签到）
  • 信用分 < 40 拉黑 30 天

V2 阶段：接入微信支付"担保交易"

  • 资金沉淀在微信支付备付金账户，不进平台账户
  • 预留接口 EscrowService，MVP 期实现为信用分的 Stub

合规依据：《非银行支付机构条例》《电子商务法》

V3. 实名认证路径 → 三档认证

第一档（首选）：微信开放平台实名授权（getPhoneNumber + 实名信息）

第二档（回退）：手机号实名（运营商三要素核验）

第三档（兜底）：人工审核（身份证 + 人脸）

未认证边界：仅可浏览地图与停车场静态信息，不可预约、不可评价

V4. 数据准确性责任界定
  • 用户协议：明确"车位信息仅供参考，以停车场实际为准"
  • 数据源协议：与开放平台签署 SLA（数据延迟 ≤ 5s，准确率 ≥ 95%），明确免责
  • UI 标注：实时数据展示更新时间，超 5 分钟未更新显示"数据可能过期"

中等 漏洞修复

V5. 超时爽约边界
  • T0 = 预约开始时刻
  • 宽限期 = 15 分钟
  • T0+15min 未签到 → 触发爽约，信用分 -20，订单置"已爽约"
  • T0 前可免费取消，T0 后取消按规则扣信用分
V6. 状态机补全异常出口
[待支付] → [已预约] → [已签到] → [已停妥] → [待结算] → [已完成]
     ↓         ↓          ↓          ↓
  [已取消]  [已取消/   [已爽约]  [异常处理]
            已爽约]                ↓
                          ┌───────┼───────┐
                          ↓       ↓       ↓
                     [已退款] [人工介入] [已关闭]
  • 异常触发：签到失败、支付对账不平、车辆与车位不匹配
  • 24 小时未解决自动升级至"人工介入"队列
V7. 数据一致性公式补全
空闲 + 已预约 + 已停妥 + 不可用(维修/锁定) = 总车位

增加定时校验任务（每分钟跑一次），不一致告警

V8. 室内导航依赖声明
  • 前提条件：停车场方部署蓝牙信标 + 授权室内地图
  • 降级方案：无信标 → "车位编号 + 文字路径指引 + 楼层图"
  • V2 才做，MVP 不涉及
V9. 多车辆场景
  • 预约时强制选择车牌（从已绑定车牌中选）
  • 核销时车牌必须匹配，不匹配拒绝核销，触发改约流程
  • 改约规则：T0 前 1 小时内可免费改约 1 次
V10. 注销流程合规
  1. 校验无未完结订单
  2. 账号置"已注销"，登录态失效
  3. 个人信息脱敏（姓名→"已注销用户"，手机号→NULL）
  4. 订单与交易记录按《电子商务法》留存 3 年
  5. 注销后 30 天内可恢复，超期彻底清理

七、核心业务流程

7.1 预约主线

  1. 搜索目的地
  2. 系统推荐附近停车场（按距离/价格/空位排序）
  3. 用户选择停车场，查看详情（含实时数据更新时间）
  4. 选择车牌 + 选择车位 + 预约时段
  5. Redis 原子扣减库存（锁 5 分钟）
  6. 生成订单（状态：待确认）
  7. 信用分预授权（不扣分，仅锁定）
  8. 预约成功，推送预约码
  9. 用户驾车导航至停车场
  10. 到场扫码签到 + 车牌匹配核销
  11. 系统锁定车位
  12. 用户停车完成，记录车位位置
  13. 离场结算（停车费走停车场官方通道）
  14. 信用分按时 +2，订单完成
  15. 用户评价

7.2 状态机（完整版）

[待确认] → [已预约] → [已签到] → [已停妥] → [待结算] → [已完成]
     ↓         ↓          ↓          ↓
  [已取消]  [已取消/   [已爽约]  [异常处理]
            已爽约]                ↓
                          ┌───────┼───────┐
                          ↓       ↓       ↓
                     [已退款] [人工介入] [已关闭]

状态迁移规则：

  • 待确认：库存锁定 5 分钟，未确认自动取消
  • 已预约 → 已取消：T0 前免费取消
  • 已预约 → 已爽约：T0+15min 未签到，信用分 -20
  • 已签到 → 异常处理：车牌不匹配、车位被占
  • 异常处理 → 已退款：多扣费用退还
  • 异常处理 → 人工介入：24 小时未解决自动升级
  • 异常处理 → 已关闭：超 7 天未解决
