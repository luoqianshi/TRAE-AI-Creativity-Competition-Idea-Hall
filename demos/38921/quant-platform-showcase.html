⚡ FastAPI + React 🧠 Multi-Agent Orchestration 🔄 LLM Function Calling 📡 WebSocket 实时推送

Three Subsystems

三个 Agent · 各司其职

每个子系统都是独立的 ToolCallingAgent，通过私有 Skills 目录扩展能力，无需重启即可识别新技能

News · 新闻

📰 NewsAgent

负责一切与新闻/事件/资讯相关的任务。带有私有 skills 目录，启动时由 SkillsLoader 自动发现。

  • 东方财富 / 新浪财经 / 财联社 多源抓取
  • akshare 公告/研报采集
  • 事件抽取与利好利空标签
  • 个股、行业关联与归档
  • topnews skill：盘前/盘中/盘后 7 类全时段分析
Sentiment · 舆论

💬 SentimentAgent

聚焦"市场情绪"维度，从雪球、股吧、社交平台量化群众心理。

  • 多平台舆情采集（股票/基金差异化）
  • LLM 驱动的细粒度情感打分
  • 舆情指数计算与趋势追踪
  • 异动预警（情绪突变 / 热度飙升）
  • 输出标准化情绪因子，喂给量化系统
Quant · 量化

📈 QuantAgent

核心闭环：生成 → 校验 → 回测 → 分析 → 优化 → 修复 → 重写。目前 7 个 skill 覆盖完整工作流。

  • backtesting-frameworks：事件驱动 + 向量化回测
  • china-a-share-financials：A 股财务三表
  • technical-indicators：MACD/RSI/KDJ 全套
  • fund-realtime-scraper：基金实时净值
  • westock-data：腾讯自选股 K 线源
  • ths-advanced-analysis：同花顺资金流分析
End-to-End Workflow

一句话 · 跑完全链路

4

5

6
WS 推送

过程事件实时回传前端工作台

Why It's Different

六大工程亮点

不是 demo —— 这是经过 242+ 测试用例验证的可运行系统

🔧

Function Calling 原生

所有 Agent 继承 ToolCallingAgent，标准 OpenAI Tool 协议，支持 LLM 自主选择工具与子系统。

📚

Skills 动态加载

SkillsLoader 兼容 skill.json 与 SKILL.md 双格式。放入新目录即被自动识别，无需重启。

🧮

256K 上下文管理

AgentContext 自动估算 token，80% 阈值触发压缩，避免对话失忆，回退截断兜底。

📊

真实数据落库

结构化数据走确定性采集器（westock + akshare），不让 LLM 编造数字，scheduler 强校验。

📡

事件总线 + 任务日志

每次 agent.run 全过程落盘到 logs/，嵌套调用保留父子链路，前端可查询完整执行轨迹。

⚡

配置即代码

7 个 YAML 完全解耦业务，前端可视化编辑 + 热更新，Pydantic Schema 强校验防错。
