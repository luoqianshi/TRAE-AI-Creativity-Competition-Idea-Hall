AI 代码复盘助手 — CodeReviewMate

让每一个写完的项目，都能沉淀为可复用的成长资产

💡 1. 创意名称 + 创意介绍

一句话定位：CodeReviewMate 是一款 VS Code 插件 + 网页端结合的 AI 代码复盘工具，帮助编程学习者和初级开发者把“做完的项目”自动转化为“看得见的成长”。

想解决什么问题

很多自学编程的学生和初级开发者能跟着教程写出项目，但写完后不知道如何复盘，做过的设计决策、踩过的坑很快就忘，导致能力提升缓慢。

灵感来源

在使用 TRAE 等 AI 编程工具时，AI 能帮我们快速生成代码，但很少有人帮我们“读懂自己刚写完的代码”。我们想补足这个环节：让 AI 从“写代码”延伸到“帮用户学会自己的代码”。

产品形态

VS Code 插件为主入口，自动分析工作区代码；网页端展示复盘报告、知识地图和可复习卡片，形成闭环。

🎯 2. 目标用户及痛点

  • 核心用户：自学编程的学生、转码新人、刚入行的初级开发者，以及需要带新人的技术 mentor。
  • 使用场景：刚完成一个功能模块或独立项目，想沉淀收获、准备面试、写技术博客或给 mentor 汇报时。
  • 当前痛点：传统复盘依赖手动整理笔记，既耗时又容易遗漏关键设计；Git 提交记录太碎片化，无法呈现完整的思考演进过程。

🚀 3. 价值与意义

⏱️
效率提升
把项目复盘时间从 1–2 小时压缩到 10 分钟，AI 自动提炼架构决策、踩坑点和优化方向。
📈
学习价值
帮助学习者建立“写—复盘—复用”的正循环，把每个项目都变成面试可用的素材库。
🌐
社会价值
降低编程学习门槛，让更多人从“代码能跑”进化到“能讲清楚为什么这样写”。

⚙️ 4. 核心功能与交互流程

1
项目扫描
插件读取工作区结构、依赖和 Git 历史
2
AI 分析
提炼模块职责、关键决策与潜在问题
3
复盘报告
生成知识地图、薄弱点与优化建议
4
复习卡片
输出面试问答卡片，支持导出与分享

🛠️ 5. 技术实现思路

  • 前端：VS Code Webview + React 网页端，统一设计语言和组件库。
  • 后端：轻量 Node.js 服务，负责代码解析、Git 分析与 LLM 调用编排。
  • AI 能力：基于大语言模型做代码摘要、架构推演和问答生成，支持接入多种模型。
  • 数据安全：本地优先，代码不上云；可选云端同步用于团队协作。
