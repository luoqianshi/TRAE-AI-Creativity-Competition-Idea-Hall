# 闪念实验室 - 微信小程序

## 项目简介

闪念实验室是一款 AI 驱动的创意想法捕捉、分析与成长管理工具。用户可以随时记录一闪而过的想法，AI 会自动进行分类、评分和分析，帮助用户从日常灵感中发现有价值的创意方向。

## 功能模块

### 1. 捕捉想法（首页）
- 文字输入记录想法
- 语音输入模拟
- 快捷标签填充
- AI 自动分类和评分
- 今日统计概览

### 2. 我的想法
- 想法列表展示
- 搜索功能（按标题/内容/标签）
- 分类筛选（5 大领域）
- 编辑想法
- 置顶/取消置顶
- 删除确认
- 导出为文本
- 去重检测与合并
- 详情弹窗

### 3. 分析报告
- 选择想法进行分析
- AI 生成详细报告
- 综合可行性评分
- 三维评分细分（技术/市场/资源）
- 市场调研
- 竞品分析
- 风险评估
- 行动建议

### 4. 每日报告
- 今日统计（想法数/已分析/最高评分/涉及领域）
- 创意指数（0-100 综合量化）
- TOP 3 推荐想法
- 今日时间轴
- 本周创意趋势图（Canvas 柱状图）

### 5. 个人画像
- 思维热力图（5 大领域分布）
- 能力雷达（5 维能力评分）
- 关联发现（Canvas 思维导图）
- 成长轨迹
- 提升建议（课程/行动/灵感）

## 技术特点

- **纯前端实现**：无需后端服务器，数据存储在本地
- **AI 模拟算法**：基于关键词匹配的自动分类和评分系统
- **Canvas 图表**：手绘柱状图和思维导图
- **暗色主题**：统一的深色 UI 设计
- **响应式布局**：适配不同屏幕尺寸

## 如何运行

1. 下载并安装微信开发者工具
2. 打开微信开发者工具，选择"导入项目"
3. 选择 `idea-lab-miniprogram` 文件夹
4. 填写 AppID（或选择测试号）
5. 点击"编译"即可预览

## 数据存储

使用微信小程序本地存储 API（`wx.getStorageSync` / `wx.setStorageSync`），数据保存在用户设备本地，无需网络请求。

## 开发说明

- 基础库版本要求：2.19.4+
- 支持 iOS / Android 微信客户端
- 不支持 PC 端微信
