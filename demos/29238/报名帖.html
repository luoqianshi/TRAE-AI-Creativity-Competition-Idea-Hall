一、创意名称 + 创意介绍

创意名称：金融显示终端（Financial Display Terminal）

想解决什么问题：
为金融投资者提供便捷的桌面级实时行情显示方案，解决手机查看行情频繁切换 App、电脑端占用屏幕空间的痛点，实现"一眼掌握市场动态"。

为什么会想到做这个：
作为一名投资者，每天需要频繁查看股票和加密货币行情，但手机通知不够直观，电脑端软件又占用宝贵的屏幕空间。希望有一个小巧的桌面设备，能够 24 小时不间断显示实时行情，让投资决策更加高效。

大概是什么产品：
基于 ESP32-S3 的便携金融行情显示终端，配备 1.8 英寸 AMOLED 触摸屏，搭载 QMI8658 六轴姿态传感器，支持 WiFi 联网获取实时数据，支持手机 BLE 远程控制。

二、目标用户及痛点

面向国内以及海外用户：

  • 股票 / 基金投资者
  • 加密货币交易者
  • 金融从业者
  • 美股、港股投资者
  • A 股投资者
  • 需要关注市场动态的上班族

在什么场景下使用：

  • 办公桌面：放置在办公桌一角，随时查看行情
  • 居家环境：客厅 / 书房的信息展示
  • 交易场景：配合交易软件使用，提供独立的行情显示
  • 车载场景：开车时无需分心操作，抬腕亮屏 + 翻腕切页，余光即可掌握行情
  • 佩戴场景：可固定在手腕或支架上，解放双手，用姿态自然交互

当前痛点：

  1. 手机查看：需要解锁、打开 App，操作繁琐
  2. 电脑查看：占用主屏幕空间，影响工作效率
  3. 信息割裂：不同市场（A 股、加密货币）需要不同 App
  4. 缺乏专注：多任务环境下容易错过重要行情变化
  5. 交互低效：传统触屏在小型设备上操作不便，需要更自然的交互方式

三、价值与意义

核心亮点：搭载 QMI8658 六轴姿态传感器，实现业界首创的"手势无接触操控"金融数据终端——抬腕亮屏、翻腕切页，完全免触控操作。

商业价值：

  • 为投资者提供轻量化的行情监控方案，提升决策效率
  • 可扩展支持多种金融产品，形成差异化竞争优势
  • 硬件 + 软件的完整生态，具备商业化潜力

效率提升：

  • 实时数据推送，无需手动刷新
  • 自定义自选股，聚焦关注标的
  • 手势 / 蓝牙远程控制，操作便捷
  • 抬腕亮屏 0.3 秒极速响应，翻腕切页毫秒级识别

社会价值：

  • 降低金融信息获取门槛，提升全民理财意识
  • 促进金融科技与硬件创新的融合
  • 为残障人士提供非接触式的金融数据获取方式

四、技术实现

核心功能：

📊实时行情显示
上证 · 深证 · 个股 · 加密货币
📈分时图展示
5 个自选槽位切换
📱手机 BLE 遥控
屏幕开关 · 页面切换 · 自选同步
💾SD 卡数据缓存
离线查看历史数据
🔋智能省电
自动息屏 · 抬腕唤醒

🛸 姿态传感系统（核心创新）

🖐️ 抬腕唤醒 加速度计 Pitch 检测
30°~75° 抬腕角度识别
300ms 稳定确认 + 低通滤波
3 秒冷却防误触
🔄 翻腕切页 陀螺仪角速度识别
4 方向精准手势（左/右/上/下）
五态机算法（IDLE→检测→峰值→回正→确认）
0.85 低通滤波抗抖动

姿态传感技术参数：QMI8658 6 轴 IMU（加速度计 ±8G / 125Hz + 陀螺仪 ±512°/s / 112Hz），支持低功耗连续采样，手势识别全程无需触摸屏幕，实现真正的"隔空操控"。

技术栈：

ESP32-S3 LVGL 图形库 1.8" AMOLED 触摸屏 WiFi + BLE 双模通信 QMI8658 六轴 IMU Hyperliquid API 沪深交易所 API

项目结构：

ESP32 固件：FinancialDisplay.ino
手机控制端：BLE_Stock_Controller Android App
