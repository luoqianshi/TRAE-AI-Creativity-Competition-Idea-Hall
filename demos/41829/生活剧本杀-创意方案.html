生活剧本杀
在 AI 剧情里，预演你的人生

当朋友来借 5 万、当同事甩锅给你、当父母第七次催婚 —— 你怎么说？

赛道生活娱乐 × 学习工作（跨界） 形式纯前端 Web + LLM API 难度★★★★☆ 周期MVP 5 天 / 完整版 12 天

1产品定位

1.1 一句话定义

「人生预演沙盘」 —— 把生活中"说不出口、不知道怎么开口"的真实困境，做成 5-10 分钟的轻量剧本杀。用户扮演自己，在 AI 驱动的剧情中尝试不同话术，结束后得到一份沟通分析报告。

1.2 解决的问题

真实痛点现有方案我们的差异化
不知道怎么拒绝别人搜公众号文章，看完还是不会在剧情里实际演练一次
职场冲突不会处理看职场课，情境不同用不上剧本就是你的真实场景
亲子/亲密关系紧张心理咨询贵、约不上5 分钟试 3 种说法，看后果
说话总是得罪人凭感觉、事后后悔AI 实时反馈「这句话的影响」

1.3 目标用户

  • 核心：18-35 岁职场新人 + 大学生 + 社恐人群
  • 延伸：35-50 岁父母（亲子沟通）、被催婚/催生人群、初为管理者
  • 公益属性：青少年沟通能力训练、亲子关系修复

2核心玩法

2.1 用户旅程（5 步）

① 选剧本（场景库） ↓ ② 看背景（角色、时间、前情提要） ↓ ③ 进入剧情（AI 扮演对手 / 旁观者，每轮给 3-4 个选项 + 自由输入） ↓ ④ 实时反馈（每轮对话后，HUD 浮窗显示「亲密度 / 压力值 / 信任度」变化） ↓ ⑤ 结束报告（沟通分析 + 最佳路线回放 + 改进建议）

2.2 一个完整剧本示例

剧本名：《朋友来借 5 万块》
角色：你（朋友 A）+ 老同学 B
场景：咖啡馆，下午 3 点
前情：B 之前找你借过 2 次钱，都还了。这次说生意周转，3 个月还。
关系起点：亲密度 70 / 信任度 80 / 压力值 10
目标：维护关系 + 守住自己的钱 + 不内疚

对话轮次（共 5 轮）：

  1. B 开口诉苦 → 你选回应方式
  2. B 提到具体数字 → 你表态
  3. B 加码（能否多借点）→ 你选坚持 / 妥协
  4. B 打感情牌 → 你回应
  5. 结局收尾 → 你怎么收场

结局分支：

  • 完美：借一部分 + 写借据 + 关系不变
  • 一般：借了 / 没借但关系降温
  • 翻车：钱借出去 / 朋友翻脸

3产品亮点

3.1 创新点

🎯

真实感强

剧本都来自真实用户故事改编，不是虚构情境

⚡

实时反馈

每句话都有后果，AI 实时模拟对方反应

📊

双重反馈

剧情内（数值变化）+ 剧情外（分析报告）

🔁

可重玩

同一个剧本，不同选择走不同分支

🌱

公益属性

可拓展为青少年沟通训练营

3.3 传播点

- 「要不要来演一段借钱给你朋友？」
- 「父母催婚剧本杀，5 分钟学会怎么不伤感情地拒绝」
- 「我以为我能拒绝，结果第一轮就破防了」

4演示路径（5 分钟版）

时间内容
00:00 - 00:30开场：「你有说不出的话吗？来预演一下」
00:30 - 01:00剧本选择：展示 3 个剧本
01:00 - 03:00实演《朋友来借 5 万》前 2 轮
03:00 - 04:00报告页：展示沟通评分 + 改进建议
04:00 - 04:30重玩：换个选择，看不同结局
04:30 - 05:00收尾：产品愿景 + 公益方向
