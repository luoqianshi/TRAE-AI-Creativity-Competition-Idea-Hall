适老化记工计时助手

一款专为老年劳动者设计的语音交互记工工具，让每一位劳动者都能轻松记录自己的劳动成果

🏷️ 社会服务 🏷️ 社会公益 📱 Android App

🎯 创意介绍

解决什么问题：大量从事农业采摘、建筑装修、家政服务等行业的老年劳动者，缺乏简单易用的记工工具，常常靠"记性"或纸笔记录工时和产量，月底算账困难、容易遗漏。

为什么会想到做这个：观察发现，农村和城市中的老年零工群体普遍使用功能简单的老年手机，对复杂App操作困难。他们的记工方式要么是"心里记"，要么是"记在烟盒背面"，月底和雇主对账时经常产生纠纷。我们希望通过最简单的交互——大按钮 + 语音播报，让记工变得像打电话一样自然。

产品形态：Android原生应用（已打包APK），也可作为移动端Web应用运行。

👥 目标用户及痛点

🎯 面向哪些用户

  • 农业从业人员：从事水果采摘、茶叶采摘、蔬菜包装等按斤计酬的老年农民
  • 零工劳务人员：建筑工地、装修队、家政服务等按小时计酬的老年零工
  • 手工艺劳动者：编织、加工等按件计酬的居家老年劳动者
  • 适老化关怀机构：关注老年群体数字生活的公益组织

📍 使用场景

  • 采摘工在地头休息时，掏出手机记录今天采了多少斤水果
  • 钟点工做完一户清洁，立即记下本次工作时长
  • 工地散工每天收工后，统一记录当天在哪个工地干了几个小时
  • 月底和雇主对账时，可以直接展示月度汇总让双方确认

❗ 当前痛点

  • 记忆不可靠：老年劳动者普遍不用或不会用复杂App，全靠记性，月底经常忘
  • 对账纠纷多：没有客观记录，雇主说多少就是多少，老人常常吃亏
  • 通用App太复杂：市面上已有记工App功能臃肿、操作流程多、字体小，不适合老年人
  • 不会计算工资：部分老年人对数字计算不敏感，难以快速算出应得报酬

💎 价值与意义

社会价值

  • 保障老年劳动者权益：提供客观可查的劳动记录，在工资结算时有据可依，减少纠纷中被压价的可能性
  • 弥合数字鸿沟：通过极简交互 + 语音反馈的设计理念，让不熟悉智能手机的老年人也能享受数字化工具带来的便利
  • 提升劳动尊严：每一份劳动都值得被准确记录和认可，让老年人感受到自己的劳动被重视

公益价值

  • 面向全国数以亿计的老年劳动者群体，应用完全免费，无广告无商业变现
  • 可被公益组织、社区服务中心推广使用，帮助更多老年人
  • 源码可开放，支持社区贡献和定制化改良

效率提升

  • 录入一条记录仅需3步：打开App → 按数字 → 点保存，耗时不超过10秒
  • 月度汇总自动生成，无需手动计算，减少算错、漏算
  • 支持小时和斤数两种模式，覆盖绝大多数老年零工场景

⚙️ 技术实现

  • 开发工具：TRAE Work + 原生Android WebView
  • 前端技术：纯HTML/CSS/JavaScript，零依赖，轻量高效
  • 数据存储：localStorage本地持久化，无需联网，保护隐私
  • 语音交互：Web Speech API + Android原生TTS双引擎，支持慢语速模式
  • 打包方式：Android APK，无需Google Play即可安装使用
