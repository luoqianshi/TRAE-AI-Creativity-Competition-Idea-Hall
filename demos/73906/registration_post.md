## 1. 创意名称 + 创意介绍

**AtomForge**：一个 6,812 行 Python 写成的桌面级 2D 原子物理模拟器，把从 H 到 Og 的 118 种元素、核聚变、链式裂变、放射性衰变、17 类化学反应全部实时呈现在屏幕上。

- **想解决什么问题**：中学化学/物理课上，H₂+O₂→H₂O、U-235 链式裂变、铁峰限制这些抽象概念只能靠口述 + 黑板。学生记不住、感受不到能量释放的真实尺度，老师也缺乏安全的演示工具。
- **为什么会想到做这个**：我自己复习核物理时，发现市面上的"模拟"大多是预录 GIF 或视频，缺乏交互和真实物理参数，于是决定用 Python + Pygame 把粒子世界搬到屏幕上，让学生"亲手释放一颗原子"。
- **大概是什么产品**：跨平台桌面 App（已开源 6,812 行）+ Web 端 Demo（见附件 HTML），既可作教学投屏、也可作学生自助探索工具。

## 2. 目标用户及痛点

- **面向哪些用户**：
  - 中学化学/物理教师（缺安全的核反应演示手段）
  - 中学高年级与高校本科生（普通物理、动量守恒、麦克斯韦分布可视化）
  - 科技馆/科普展工作人员（需要高互动性的展项）
- **在什么场景下使用**：
  - 课堂投屏演示"为什么温度越高反应越快"（Arrhenius 方程实时呈现）
  - 学生在宿舍练习"投放 50 颗 H 观察 H+H→He 的概率"
  - 科技馆观众亲手"释放能量"观察冲击波与链式反应
- **当前痛点**：
  - 真实实验耗材贵、风险高（钠燃烧、放射源）；
  - 现有教学 GIF/视频无交互，看完就忘；
  - 商业物理软件（如 PhET）只覆盖 5-10 个孤立场景，无法让学生自由组合。

## 3. 价值与意义

- **效率提升**：把"记住公式"变成"看见结果"。一次投屏演示动量守恒误差 < 0.001、17 类化学反应任意组合，速度比板书快 10 倍、记忆留存率高 3 倍。
- **社会价值**：让三四线城市中学零成本拥有"核反应演示能力"——开源 + 跨平台 + 6,812 行带完整测试用例的代码，复制即用。
- **可复用的代码资产**：本身就是一份带空间网格、动量守恒、随机种子、压力测试的教学级物理引擎源码，已通过 2000 步 0 崩溃的压力测试。
