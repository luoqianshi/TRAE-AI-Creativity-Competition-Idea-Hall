场记 LevelNote 怎么做？

01

UE5 场景内 3D 批注

策划在跑关卡时，发现问题的位置直接右键打标记，支持文字、截图和语音反馈。反馈自动带上精确坐标和上下文，美术打开 UE5 就能定位到具体位置。

// 在 UE5 中一键提交反馈
LevelNote::CreatePin(
Location = HitResult.Location,
Comment = "树干底部穿模",
Screenshot = CaptureViewport()
);
🎨
角色模型_v3.fbx
Web 端 3D 预览 · 材质检查 · 版本对比
02

美术资产在线预览与管理

美术把模型、贴图、材质上传到 Web 端，团队无需打开 UE5 就能在线 3D 预览、确认后再导入引擎。支持版本快照，避免用错文件。

03

常用蓝图片段库

技术美术和资深程序把常用蓝图（HUD、拾取、对话、存档等）整理成可搜索的片段库。新人直接搜索、复制、粘贴，减少重复开发。

为谁而做？

🎮

独立游戏团队

5-15 人的小团队，没有专职 PM 和技术支持，需要低成本协作工具。

🎓

高校游戏社团

学生开发者做 Game Jam 或毕业设计，需要快速上手的协作流程。

🏢

中小型工作室

负担不起 Perforce、ShotGrid、Jira 等专业管线，需要轻量替代方案。

价值与意义

效率提升

  • · 把"截图+文字"反馈变成"3D 场景直接标注"，减少沟通往返
  • · 资产统一管理和在线预览，避免版本混乱
  • · 蓝图复用降低重复开发，新人更快融入项目

社会价值

  • · 降低独立开发者和小团队的协作门槛
  • · 帮助学生和独立创作者用更低成本做出更好的游戏
  • · 让没有大公司资源的创作者也能拥有专业管线体验
