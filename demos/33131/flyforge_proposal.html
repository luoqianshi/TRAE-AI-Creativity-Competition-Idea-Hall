💡 创意介绍

我们要解决什么问题？

机械工程师在设计飞轮储能系统时，需要反复手工计算应力分布、安全系数和储能容量。过程繁琐易出错，现有商业仿真软件（如 ANSYS）学习成本高、许可昂贵，个人和小团队难以负担。

为什么会想到做这个？

灵感来源于开源项目 CamForge（凸轮设计工具），发现"专业工程计算 + 轻量桌面应用"的组合在机械设计领域有巨大需求，于是将理念拓展到飞轮设计领域。

产品形态

一款 Windows 桌面应用，基于 Tauri v2（Rust 后端）+ SolidJS（前端），提供参数化飞轮设计、实时应力仿真和图表可视化。全部安装包仅约 5MB。

👥 目标用户及痛点

🎓 机械工程学生

课程设计、毕业设计中需要飞轮计算。当前需要手算公式、Excel 画图，耗时长且容易出错。

🔧 研发工程师

飞轮储能系统初步设计与安全校核。商业软件年费数万、操作门槛高，中小团队无力承担。

🏫 教学人员

课堂上演示飞轮原理。缺乏可视化、交互式的教学工具，学生难以直观理解应力分布。

使用场景

  • 课堂上快速演示飞轮参数变化对应力分布的影响
  • 工程师进行飞轮方案初步设计和安全校核
  • 学生完成飞轮设计作业并导出计算报告

📐 参数化设计

环形轮、实心盘、锥形盘等 5 种飞轮类型，12 种工程材料（合金钢、钛合金、碳纤维等），支持一键加载预设方案。

📊 实时可视化

SVG 飞轮截面预览、von Mises 应力分布图、转速时间曲线、能量柱状图——参数修改后 300ms 自动更新。

🛡️ 安全校核

屈服/疲劳/破裂三重安全系数评估。自动计算安全破裂转速，标注风险等级。

📤 多格式导出

CSV / JSON / SVG / 参数 JSON 四种导出格式，支持自定义保存路径，方便集成到工程报告中。

🌟 价值与意义

⚡ 效率提升

将飞轮设计从"查公式 → 手算 → Excel → 画图"的散乱流程整合为统一交互工具。参数修改后 300ms 自动重算，效率提升 10 倍以上。

📚 教育价值

提供直观的飞轮原理演示工具，拖动参数即可观察应力变化，帮助学生理解离心应力、安全系数等抽象概念。

🌍 社会价值

飞轮储能是清洁能源关键技术。降低设计门槛，有助于推动飞轮储能技术在可再生能源调频、工业节能等场景的普及。
