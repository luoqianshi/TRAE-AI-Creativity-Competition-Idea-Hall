💡 创意介绍

"KET 英语闯关岛"是一款专为小学生设计的剑桥 KET 备考学习网站。我们以游戏化闯关为核心，将枯燥的备考过程变成一场有趣的冒险旅程。

孩子将依次探索阅读岛、听力岛、写作岛、口语岛四大岛屿，在每个岛屿中完成关卡挑战、收集星星、解锁成就，系统掌握 KET 考试所需的知识和技能。

👨‍👩‍👧 目标用户与场景

主要用户

小学 2-6 年级、正在备考或计划备考 KET 的学生，以及希望辅助孩子备考的家长。

使用场景

  • 课后每日 15-20 分钟专项练习
  • 寒暑假集中备考冲刺
  • 考前模拟测评与弱项强化

解决痛点

  • 传统刷题枯燥，孩子难以坚持
  • KET 备考资料分散，缺乏系统性
  • 口语、写作缺少即时反馈
  • 学习进度不透明

🌟 价值与意义

教育价值：将 KET 考纲系统拆解为闯关内容，降低备考门槛，让孩子有针对性地提升听说读写能力。

效率价值：游戏化机制提升学习动力，星级和成就让进步可视化，帮助孩子建立持续学习的习惯。

社会价值：为更多家庭提供免费的 KET 备考工具，让优质教育资源更加普惠。

🛠️ 技术实现

本项目基于 Next.js + TypeScript + Tailwind CSS 构建，使用 Prisma + PostgreSQL 管理学习数据，并采用 NextAuth 实现用户认证。本地开发使用 PostgreSQL，VPS 部署使用 Docker + Nginx。
