① 加权打分分类

每条新闻在 12 个分类下分别累加命中关键词的权重，最高分大于阈值 2 即归类。中英混合、CJK 用 includes、英文用词边界正则。

score = Σ keyword.weight (matched) if (best.score >= 2) → category else → "其他"

② Jaccard 相似度聚类

中文用 bigram + 英文 token 切分，计算两标题 Token 集合交集 / 并集，再加上关键词重叠加分。阈值 0.25 以上合并为同一事件。

sim = |A ∩ B| / |A ∪ B| + 0.15 * keywordOverlap if (sim >= 0.25) → 同一聚类
