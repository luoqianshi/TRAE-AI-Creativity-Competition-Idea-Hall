查询算法

借鉴 Excel 高级函数逻辑，实现高效数据聚合

1 FILTER 批量筛选

根据查询条件（物料编码/型号），从全量数据中筛选出所有匹配记录，等价于 Excel FILTER 函数的数组筛选逻辑。

# Excel FILTER 函数等价逻辑 =FILTER(数组, 包含条件的数组, [未找到时的返回值]) # Python Pandas 等价实现 result = df[df['物料编码'] == query_value]

2 TEXTJOIN 批量聚合

将筛选出的多条记录按指定分隔符聚合为一条结果，实现"一查多返"的核心交互体验。

# Excel TEXTJOIN 函数等价逻辑 =TEXTJOIN(CHAR(10), TRUE, FILTER(数据区域, 条件列=查询值, "")) # Python Pandas 等价实现 records = filtered_df.to_dict('records')

3 UNIQUE 去重展示

对聚合结果进行去重处理，避免重复记录干扰查询结果，确保信息简洁有效。

# Excel UNIQUE 函数等价逻辑 =UNIQUE(区域, [是否区分大小写], [是否提取重复项]) # Python Pandas 等价实现 unique_df = result.drop_duplicates(subset=['物料编码', '型号'])

查询模式

精准与模糊双模式，灵活应对不同场景

精准模式

精确匹配查询

物料编码与型号必须完全一致，确保查询结果的准确性和可靠性。

  • 物料编码严格匹配
  • 物料型号完全一致
  • 返回所有完全匹配的历史记录
  • 适用于已知准确编码的场景
模糊模式

相似度匹配查询

物料编码必须一致，型号支持文本相似度匹配，帮助发现近似物料。

  • 物料编码严格匹配
  • 型号采用 Levenshtein 距离算法
  • 返回匹配结果及相似度评分
  • 适用于型号存在差异的场景
