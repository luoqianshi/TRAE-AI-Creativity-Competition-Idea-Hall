01 / CONCEPT

创意介绍

想解决什么问题？为什么会想到做这个？大概是什么产品？

!

痛点：Build 同质化

当前大多数 Roguelike 在开局就要求选职业、走预设路线，重玩到中后期产生"又走老路"的倦怠感。玩家渴望的是"每一步选择都在塑造独一无二流派"的涌现式体验，而非被系统安排好的通关模板。

*

灵感：杀戮尖塔灾厄流

灵感来源于《杀戮尖塔》灾厄流的极致涌现感——不是开局选了什么职业，而是每一次卡牌选择、遗物获取、事件决策共同涌现出意料之外又情理之中的 Build。我们想把这种"选择即构建"的快感从卡牌移植到动作游戏。

+

产品：像素肉鸽动作游戏

基于 Godot 引擎开发的 2D 像素风动作 Roguelike，玩家扮演全身铠甲的月弧骑士，在程序化关卡中通过战斗选择、装备搭配和事件决策，涌现出独特流派——没有预设职业，每一局都是全新的流派实验。

"好的 Roguelike 不是让你选一条路走到黑，而是让你在路上不断发现新的自己。《裂月骑士》想做的，就是把杀戮尖塔那种'我的 Build 是我一步步选出来的'成就感，放进一个有操作手感的动作游戏里。"

— 设计理念

02 / PAIN VS SOLUTION

痛点与解决方案

现有动作肉鸽的四大痛点，以及《裂月骑士》如何逐一破解

CURRENT PAIN POINTS
  • 1Build 同质化 — 预设职业+技能树，Build 路线高度可预测，三四周目后失去新鲜感
  • 2选择感缺失 — 关键节点缺乏有意义的决策，多数升级只是"攻击力+10%"的数值堆叠
  • 3美术粗糙 — 角色设计潦草，NPC 千篇一律，缺乏"想截图分享"的视觉吸引力
  • 4学习门槛高 — 新手需查攻略才能入门，缺少"玩着玩着就懂了"的渐进式引导
CRESCENT KNIGHT SOLUTIONS
  • A涌现式流派系统 — 无预设职业，每次升级提供 3 个质变性选择（如"剑气可弹射""攻击附加灼烧"），Build 由选择涌现而非预设
  • B质变而非量变 — 升级选项侧重机制质变而非数值堆叠，每个选择都可能改变玩法风格
  • C宝可梦级像素美术 — 精致角色设计，主角铠甲骑士带呼吸待机动画，女性 NPC 特别精心设计，月弧挥剑弧光特效
  • D渐进式引导 — 早期关卡选择少且直观，随进度自然解锁复杂机制，"玩着玩着就懂了"
03 / CORE GAMEPLAY

核心玩法：涌现式流派构建

一局游戏中，你的每一次选择都在塑造一个独一无二的 Build

01
开局：无职业选择
进入游戏就是一个月弧骑士，没有职业面板、没有技能树选择。你的流派从第一场战斗后才开始分化。
02
第一场战斗后：三选一质变
击败首个敌人后，获得三选一的质变性升级——不是"攻击力+10"，而是改变攻击方式的机制选择。
剑气延伸 冰霜附魔 连击加速
03
中期：装备 + 事件交叉涌现
关卡中获取的装备和随机事件进一步与已有质变交叉组合，产生意想不到的化学反应。同一个"冰霜附魔"搭配不同装备，可能走控制流、爆发流或召唤流。
冰霜 + 暴击 = 冰爆流 冰霜 + 召唤 = 冰灵军团 冰霜 + 诅咒 = 寒冬灾厄
04
Boss 战：流派验证时刻
Boss 战是流派的终极验证——你一路涌现出的 Build 能否应对高难度挑战？通关后回看自己的选择路径，每次都是不同的故事。

04 / CHARACTER DESIGN

角色设计

现代像素美术风格，宝可梦级精致角色设计

月弧骑士

PROTAGONIST

全身铠甲的男性主角，待机时有呼吸动画，攻击时挥出月弧形剑光。玩家唯一可控角色，流派由游戏内选择涌现。

神秘女术士

NPC / QUEST GIVER

精心设计的女性 NPC，提供流派分支任务线。外观参考宝可梦级精致像素风格，是玩家在关卡中遇到的关键互动角色。

月之守卫

BOSS

每层关卡的最终 Boss，设计灵感来自月相变化。击败 Boss 后掉落的"月之碎片"是流派质变的关键道具。

流浪商人

NPC / SHOP

关卡中随机出现的神秘商人，出售改变流派走向的稀有装备。与商人的交易选择本身就是 Build 构建的一部分。

05 / TARGET USERS

目标用户及痛点

谁会玩这款游戏？在什么场景下玩？

U

核心用户画像

18-30 岁，喜爱 Roguelike / 动作类游戏的"硬核休闲"玩家。偏好《杀戮尖塔》《空洞骑士》《死亡细胞》等作品——既有挑战高难度的意愿，又希望单局体验可控、碎片化可玩。

S

使用场景

单局 20-40 分钟，适合下班后、午休间隙快速开一局；周末深度挑战高难度关卡、研究流派组合；在社区/直播平台分享自己涌现出的奇葩 Build 和通关录像。

P

当前痛点

现有动作肉鸽 Build 路线可预测、选择缺乏质变、美术粗糙、新手门槛高。玩家渴望"每一局都不同"的体验，但大多数游戏三四周目后就失去新鲜感。

06 / VALUE

价值与意义

商业价值 + 社会价值的双重驱动

$

商业价值

Roguelike 是当前独立游戏市场最热门品类，2024-2025 年 Steam 肉鸽品类持续增长。《杀戮尖塔》《以撒的结合》证明：高重玩性 + 低美术成本 + 口碑传播 = 长尾收益。涌现式 Build 机制大幅提升重玩价值，单玩家留存时长预期远超同类平均。已完成微信小游戏变现调研（激励视频 eCPM 20-80 元，内购分成 60%），具备跨平台混合变现能力。

E

玩家体验价值

涌现式 Build 让每一局都是全新体验，解决肉鸽"后期无聊"的核心痛点。像素美术降低开发成本的同时，通过精致角色设计提升视觉竞争力。月弧挥剑 + 流派组合带来"操作 + 策略"双维度深度，满足不同水平玩家。

S

社会价值

作为独立游戏开发者生态的一环，本作品展示 AI 辅助开发（TRAE）如何帮助个人开发者实现从创意到产品的完整闭环。一个人 + 一个 AI 工具，就能把"涌现式肉鸽"这种原本需要团队协作的复杂设计落地，降低游戏开发门槛，鼓励更多创作者将想法变为现实。

07 / ROADMAP

开发计划

从创意到可体验 Demo 的落地路径

PHASE 01

核心原型

月弧骑士基础移动、挥剑攻击、待机呼吸动画。单关卡 + 3 选 1 升级系统雏形。验证"涌现感"是否成立。

PHASE 02

流派系统

实现 5 大流派方向的质变选项（物理、元素、召唤、诅咒、节奏），装备与事件交叉涌现逻辑。

PHASE 03

内容填充

程序化关卡生成、Boss 设计、NPC 交互、精美像素美术资源制作。目标 100+ 质变选项。

PHASE 04

上线发布

Steam 页面搭建、商店图制作、Demo 试玩版发布。后续评估微信小游戏跨平台移植。

本创意提案使用 TRAE AI 辅助生成。从游戏设计理论（《游戏设计艺术》《游戏设计乐趣理论》）到市场调研（Roguelike 品类分析、微信小游戏变现路径），再到开发计划，全程由 TRAE 协助完成研究与规划，展示了 AI 工具在独立游戏开发全流程中的赋能能力。
