示例 2：数据分析

📝 自然语言输入
分析这份销售数据，找出销售额最高的3个产品，计算平均客单价，并生成可视化图表
💻 生成的伪代码
FUNCTION 分析销售数据(数据文件)
  LOAD 数据 FROM 数据文件
  TOP3产品 = 排序(数据.销售额, "DESC")[0:3]
  平均客单价 = 平均(数据.订单金额)
  生成图表(TOP3产品, "柱状图")
  RETURN 报告
END FUNCTION
