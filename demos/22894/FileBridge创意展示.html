发现了什么问题？

企业在与外部客户交换文件时，传统 FTP 工具存在严重的安全与效率隐患

🔓

权限粗放，数据泄露风险高

传统 FTP 只有目录级权限，无法按项目隔离，客户 A 可能看到客户 B 的机密文件。缺乏文件级细粒度控制，敏感数据暴露风险极高。

🔍

无审计，出事无法追溯

谁下载了合同文件？谁删除了设计稿？FTP 没有操作日志，出了安全事件无法定位责任人，合规审计更是无从谈起。

❌

大文件上传频繁中断

传输几百 MB 的文件，网络稍有波动就前功尽弃。FTP 不支持断点续传，设计、视频行业的客户叫苦不迭。

📋

无审批流程，文件质量失控

客户上传的文件未经审核就对所有成员可见，可能包含错误版本或不合格内容，给项目管理带来隐患。

🗓

文件生命周期不可控

项目结束后文件仍留在服务器上，无人清理。既浪费存储成本，也增加了数据泄露风险，缺乏过期自动管理机制。

🖥

界面简陋，学习成本高

FTP 客户端界面停留在上世纪，非技术出身的客户很难上手。管理员也需要专业知识才能配置权限，使用门槛过高。

核心功能亮点

每一个功能都针对真实痛点精心设计

📁

项目制数据隔离

按项目分组管理文件，不同项目的数据完全隔离。同一项目内成员共享文件，跨项目互不可见，从根本上解决数据泄露风险。

🔐

签名下载链接

文件下载 URL 携带时效签名，过期自动失效。即使链接被转发，也无法被滥用下载，彻底防止直链盗用。

✅

审批工作流

客户上传的文件需经管理员审批后才对其他人可见。支持通过和驳回（附理由），驳回后客户可重新上传修正版本。

📦

大文件分片上传

自动将大文件切分为 5MB 分片逐个上传，支持断点续传。即使网络中断，也只需续传未完成的部分，不再从头来过。

📊

完整审计日志

每一次登录、上传、下载、删除、审批操作都被完整记录，包括操作人、IP 地址和时间戳，满足合规审计要求。

🔔

智能通知系统

文件上传待审批、审批结果通知、文件到期提醒、项目成员变更——所有重要事件都通过站内通知实时触达，不错过任何关键节点。

用户使用流程

从管理员建项目到客户拿到文件，全程安全可控

1

管理员创建项目并分配客户

超级管理员创建项目，设置存储配额，添加客户账号并分配权限（只读 / 读写）和访问有效期。

2

双方在 Web 端或 SFTP 上传文件

管理员上传的文件直接可见；客户上传的文件进入审批队列，支持分片上传和断点续传。

3

管理员审批客户上传的文件

管理员查看文件内容后选择通过或驳回（附理由），结果通过站内通知实时告知上传者。

4

项目成员安全下载和预览文件

通过签名 URL 下载（防直链盗用），支持 PDF / 图片 / 视频 / Office 在线预览和多文件批量 ZIP 打包。

5

文件到期自动清理 + 审计全程在线

文件到期前 3 天发送提醒通知，到期后自动隐藏。所有操作记录可在审计日志中查询，满足合规要求。

价值与意义

效率提升、安全保障、社会价值三重驱动

🚀

效率大幅提升

Web 端开箱即用，客户无需安装 FTP 客户端。分片续传让大文件传输成功率从不足 60% 提升到接近 100%。审批流程线上化，文件流转时间从平均 2 天缩短到几小时。

🛡

商业安全合规

三级权限 + 签名下载 + 全链路审计，帮助企业满足等保、ISO 27001 等合规要求。降低数据泄露带来的商业风险和声誉损失，为企业数字资产保驾护航。

🌐

降低行业门槛

现代化的中文 Web 界面让非技术用户也能轻松操作。Docker 一键部署，中小企业无需专业运维即可搭建专业级文件共享系统，推动传统行业数字化转型。

目标用户画像

三种角色，三种场景，一个平台全覆盖

👨‍💻

IT / 运维管理员

负责公司文件共享系统的搭建和维护。痛点是 FTP 配置复杂、安全漏洞多、缺乏管理抓手。他们需要一站式管理后台、审计日志和简单的部署流程。

💼

业务项目经理

负责与客户对接文件交付。痛点是客户上传的文件质量参差不齐、无法控制谁能看到哪些文件。他们需要审批流程、项目级隔离和精细的权限管理。

🤝

外部合作客户

设计师、供应商、审计方等外部合作方。痛点是 FTP 不会用、大文件传不上去、不知道文件有没有被审核。他们需要简洁的 Web 界面、断点续传和实时通知。
