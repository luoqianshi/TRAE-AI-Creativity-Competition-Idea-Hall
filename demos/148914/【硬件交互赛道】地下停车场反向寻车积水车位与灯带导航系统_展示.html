硬件交互赛道

在地下车库里，让路自己亮起来。

车位感知贴 + 地面灯带 + 柱子指示灯，把反向寻车、积水车位、暗角和占道异常做成现场可见的空间导航。

寻车模式目标车位 B2-C17，沿青色灯带步行 2 分钟
车库状态B2 北侧信号弱，已启用离线灯带导航
异常提示C12 车位轻微积水，系统已避开该路径

不是给车库再做一张地图，而是让车位具备状态感。

地下停车场的问题通常不是“没有标识”，而是标识不会告诉你此刻发生了什么：哪里积水、哪里被临停挡住、哪条通道更适合推购物车、手机没信号时该往哪走。

地磁 / 超声波车位感知

判断车位是否占用，记录车辆所在区域。车主不需要手动记 B2-C17，系统可以通过车牌识别入口记录和车位感知数据反向定位。

水位触点 / 湿度感知

雨季或管道渗水时，低洼车位会被标记为积水风险。导航路线自动避开，物业端收到巡检任务。

灯带 / 柱灯现场指引

在手机信号弱的地下空间，地面灯带比手机地图更可靠。电梯厅扫码后，灯带和柱灯会以分段方式引导。

异常占道 / 暗角提醒

临停车挡住通道、照明异常、摄像头盲区等问题会进入物业巡场列表，减少靠人工肉眼发现的延迟。

B2-C17 已定位

从 6 号电梯厅出发，跟随青色灯带，经过 C 区柱灯后右转。

01电梯厅扫码确认车牌
02灯带分段亮起，避开积水车位
03到达目标区域，柱灯闪烁提醒
无信号也能走

路线不完全依赖手机地图，现场灯带会把路径分段点亮，老人、亲子家庭和推车用户都能直接跟随。

给车主的是路线，给物业的是问题发生的位置。

同一套硬件数据可以服务两类人：车主只需要知道怎么走，物业需要知道哪里出了问题、优先修哪里、是否影响通行。

找车不绕圈

车主在电梯厅输入车牌或扫码，系统反查车位区域，灯带从当前位置亮到目标区域。

入口车牌识别 + 车位占用变化 + 电梯厅定位
积水不踩坑

低洼车位或通道有水时，路径自动绕开，物业收到“积水车位 + 影响路线 + 建议处理”的任务。

水位触点 + 湿度趋势 + 路径避让
巡场有重点

暗角、灯坏、临停占道会按严重程度排序，不再只靠保安整层巡逻和人工记忆。

照度异常 + 通道阻塞 + 维修闭环

地下车库的科技感，应该体现在少一点迷路和狼狈。

这个创意适合商场、医院、会展中心、写字楼和大型小区地下停车场。它不是只做一个反向寻车 App，而是把现场硬件、空间灯光和异常感知结合起来，让复杂地下空间变得更确定。
