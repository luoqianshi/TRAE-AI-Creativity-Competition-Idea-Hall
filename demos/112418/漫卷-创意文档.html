把散落的章节，装订成一卷

漫卷是一款无需安装、无需联网的 EPUB 漫画装订工具——自动识别混乱文件名，合并为一本支持日式/美式翻页的完整 EPUB。

🌐 纯前端 · 零后端 🔒 离线运行 · 不上传 📖 EPUB 3 规范 🀄 中文数字识别

01 · 想解决什么问题

漫画读者的"文件名噩梦"

在网上下载漫画时，你拿到的往往是几十个零散的 EPUB 文件，文件名五花八门——有的叫"第1-10话"，有的叫"Vol.02"，有的干脆是一串数字。阅读器按字母序排列，顺序全乱。

😵

文件名千奇百怪

"第1-10话""Vol.02""Ch.12""卷三"——中文、英文、全角数字混着来，手动排序耗时又容易出错。

💥

简单合并会撞车

直接改后缀名解压再打包？不同章节的图片文件名经常重复（都是 page001.jpg），一合并就互相覆盖。

🔄

翻页方向不对

日式漫画向左翻页，美式漫画向右翻页。合并后如果元数据丢失，阅读器就不知道该往哪边翻。

☁️

在线工具不放心

把漫画上传到第三方网站？谁知道文件会被怎么处理。离线工具又要装软件、跑命令行。

02 · 大概是什么产品

双击 HTML，拖入文件，一键装订

漫卷是一个纯前端网页应用。不需要安装任何软件，不需要联网，不需要注册账号。双击打开 HTML 文件，把散落的 EPUB 拖进去，它会自动识别文件名中的编号并排序，然后合并成一个符合 EPUB 3 规范的完整文件。

每个源 EPUB 的图片、CSS、字体都被放入独立目录，彻底避免同名文件覆盖。合并后的文件写入正确的翻页方向元数据，在任何 EPUB 阅读器里都能正常显示。

04 · 核心功能

不只是拼 ZIP

01

智能文件名解析

识别"卷""册""话""回""章""Vol""Chapter"等标签，支持中文数字（一～九十九）、全角数字、数字区间（第1-10话），并保留人工调整入口。

02

资源路径隔离

每个源 EPUB 放入 sources/book-001、book-002 等独立目录，同名图片不再互相覆盖，原有页面与 CSS/字体的相对路径保持不变。

03

EPUB 3 完整重建

不只拼 ZIP——重建 container.xml、package.opf（manifest + spine）和 nav.xhtml 导航目录，生成符合 IDPF 规范的 EPUB 3 文件。

04

翻页方向控制

通过 page-progression-direction 元数据支持 RTL（日式向左翻页）和 LTR（美式向右翻页），合并后阅读器自动适配。

05

完全离线 · 零上传

所有解析、排序、压缩、下载均在浏览器内完成。没有服务器、没有追踪、没有远程请求。文件不会离开用户设备。

06

完整产品体验

拖放导入、实时解析状态、页数统计、排序校对、上下移动、异常提示、进度条、一键下载——从导入到输出形成闭环。

效率提升：手动排序 + 合并 20 个 EPUB 文件通常需要 15-30 分钟（解压、重命名、处理冲突、重新打包）。漫卷把这个过程缩短到拖放 + 点击，30 秒内完成。

隐私保护：现有在线 EPUB 合并工具均需上传文件到服务器，用户无法确认文件是否被留存。漫卷的纯离线架构从根本上消除了这个顾虑。

07 · 技术方案

怎么做的

漫卷是一个零构建步骤的纯前端项目，技术栈极简：

HTML 5 CSS 3 原生 JavaScript JSZip 3.10.1（本地化） DOMParser ArrayBuffer / Uint8Array Node.js 测试

核心流程：

① JSZip 解压源 EPUB → ② DOMParser 解析 container.xml / package.opf，提取 manifest 和 spine → ③ 正则 + 中文数字转换器解析文件名编号 → ④ 按编号排序，为每个源文件分配独立目录前缀 → ⑤ 重建 EPUB 3 结构（container + opf + nav）→ ⑥ JSZip 压缩输出，浏览器触发下载。

自动化测试覆盖：文件名解析（中文数字、全角数字、数字区间）、排序正确性、路径规范化、EPUB 结构完整性、双向书脊元数据、mimetype 约束。
