一、项目概述

PROJECT OVERVIEW

《我爱摆摊》是一款面向城市社区的手作与摆摊服务展示平台，旨在解决个人摊主、手作人缺乏宣传渠道的问题，同时帮助周边消费者便捷地发现身边的优质好物。

项目核心理念是「让每一份手作都被看见，让每一次摆摊都有温度」。我们不介入交易环节，仅提供信息展示与位置服务，让买卖双方在线下完成真实、有温度的面对面交易。

1.1 项目愿景

成为中国最大的社区级手作与摆摊生态平台，连接千万级手作人与社区居民，让每一个街角都充满创意与生活的烟火气。

1.2 项目 Slogan

  • 主 Slogan：我爱摆摊 · 周边好物分享
  • 副 Slogan：走走停停，遇见附近的好物
  • 传播语：不受地方限制，随意发布自己要卖的东西

二、市场背景与痛点分析

MARKET BACKGROUND & PAIN POINTS

2.1 市场趋势

随着"地摊经济"和"个人创业"理念的兴起，越来越多的人选择通过摆摊或手作来增加收入。据艾瑞咨询数据，2025年中国灵活就业人群已突破2.5亿，其中手作、摆摊类个人经济占比持续攀升。

2.2 核心痛点

  1. 缺乏宣传渠道：个人摊主和手作人没有固定的宣传途径，只能在人流密集的地方摆摊，客源不稳定。
  2. 信息不对称：周边消费者不知道附近有哪些有趣的手作或美食摊位，错过身边的宝藏好物。
  3. 信任成本高：二手商品、手作物品的品质难以判断，缺乏可靠的展示和评价体系。
  4. 地理位置限制：摊主的可见范围受限于物理位置，无法触达更远距离的潜在顾客。
  5. 线上交易复杂：现有电商平台手续费高、流程复杂，不适合小额、即时性的线下交易。

2.3 目标用户

手作人 独立设计师、手工爱好者，制作独一无二的手作商品 展示作品、吸引同好、获得认可

三、产品定位与核心价值

PRODUCT POSITIONING & CORE VALUE

3.1 产品定位

「我爱摆摊」定位为一个轻量级的社区手作与摆摊信息展示平台，以「附近发现」为核心场景，以「商家为展示单位」，不做在线交易，只做信息桥梁。

3.2 核心价值主张

对摊主

零门槛开店，一键发布，周边精准曝光

对消费者

发现附近宝藏摊位，按距离排序，精准导航

对社区

激活社区经济，促进邻里互动，传递生活温度

3.3 产品特色

  1. LBS 附近发现：基于地理位置推荐周边店铺，支持按距离筛选（1km/3km/5km/10km）。
  2. 直播摆摊：商家可开启直播，实时展示摊位实况，增强信任感与互动性。
  3. 新旧皆宜：平台不限商品新旧状态，全新手作和二手好物均可展示。
  4. 无需在线支付：平台仅提供展示与定位，交易在线下面完成，零手续费。
  5. 角色切换：用户可在「个人」与「商家」角色间自由切换，体验完整生态。

四、核心功能模块

CORE FUNCTIONALITY

4.1 用户端功能

APP 采用底部 4 Tab 架构，简洁直观：

经营中商店

展示当前正在经营的商家列表，按距离排序，支持范围筛选。每个店铺显示头像、标题、描述、经营状态、距离、人气值。

热门商店

展示人气 Top 100 商家排行，按访问量/收藏量综合排序，帮助用户发现社区热门摊位。

收藏商店

用户收藏的商家列表，方便快速找到心仪的摊位，支持按关键词搜索。

个人中心

查看/编辑个人资料（昵称、头像、签名）、查看收藏数量、管理我的商店、角色切换、开播入口。

4.2 商家端功能

  • 店铺发布：填写店铺名称、描述、经营类别，自定义可见范围（1-10km）。
  • 定位服务：自动获取当前位置或手动选择摊位地址，消费者可一键导航。
  • 商品管理：每个店铺可添加多个商品，支持商品名称、价格、新旧状态、描述、最多3张图片。
  • 商品编辑：随时修改商品信息、上下架商品。
  • 直播开播：一键开启直播，实时展示摊位商品，与观众互动。
  • 店铺状态切换：随时「收摊」或「开摊」，灵活控制营业状态。

4.3 搜索功能

顶部全局搜索栏支持搜索商家名称、商品名称，实时匹配，结果按人气排序。

4.4 后台管理系统

  • 数据看板：展示店铺总数、用户访问量、商品总数、注册用户数的实时概览。
  • 店铺管理：新增、编辑、搜索、下架店铺，对店铺所有信息进行管理。
  • 商品管理：对商品所有字段进行修改，支持按店铺筛选。
  • 用户管理：管理已注册的商家和个人用户信息。
  • 后台用户管理：新增、删除后台管理员，配置访问权限。

5.3 系统架构设计

面向千万级用户的高并发架构设计，核心组件包括：

  • API 网关：统一入口，负责请求路由、限流、认证鉴权。
  • 微服务拆分：用户服务、店铺服务、商品服务、搜索服务、收藏服务、直播服务独立部署。
  • LBS 附近搜索：Redis GEO 数据结构实现高效的地理位置查询。
  • 人气排行：Redis Sorted Set 实现实时人气排序。
  • 全文搜索：Elasticsearch 支持商家和商品的模糊搜索。
  • 直播服务：独立服务集群，支持 RTMP/WebRTC 推流，CDN 分发。
  • 数据库分库分表：MySQL 主从复制 + 读写分离，按地理位置维度分片。
  • 消息队列：Kafka 异步处理收藏、访问日志、通知等事件。
  • 多级缓存：L1（本地 Caffeine）+ L2（Redis 分布式缓存）+ L3（CDN 静态资源缓存）。

5.4 部署架构

采用容器化部署（Docker + Kubernetes），支持弹性伸缩。前端部署至 CDN，后端部署至云服务器集群，数据库采用云托管服务。

七、运营策略

OPERATION STRATEGY

7.1 冷启动策略

  1. 种子商家招募：在社区集市、创意园区、大学城等地招募首批种子商家，免费提供推广资源。
  2. 地推活动：组织「周末市集」线下活动，邀请平台商家参与，现场引导用户下载APP。
  3. KOL 合作：邀请本地生活博主、探店达人体验平台并分享，快速获取首批用户。
  4. 社区渗透：与社区物业、便利店合作，张贴宣传物料，触达社区居民。

7.2 增长策略

  • 社交裂变：邀请好友注册双方获得积分，积分可兑换推广位。
  • 内容运营：打造「摊主故事」栏目，分享摊主创业故事，增强情感连接。
  • 活动运营：定期举办「主题市集周」「二手交换日」等活动，提升活跃度。
  • 直播扶持：对优质直播商家给予流量扶持，培养平台直播生态。

7.3 用户留存策略

  • 收藏提醒：用户收藏的商家开播或上新时推送通知。
  • 附近动态：推送「附近新开摊位」「常去摊位今日营业」等个性化消息。
  • 会员体系：推出「市集达人」会员体系，累计消费/浏览解锁专属权益。
  • 社区互动：建立摊主交流群、买家评价晒单等社区功能，增强归属感。

9.2 核心竞争壁垒

  1. 社区密度：深耕社区场景，建立高密度的本地商家网络，形成网络效应。
  2. 情感连接：手作与摆摊自带故事属性，容易建立摊主与顾客之间的情感纽带，提高留存。
  3. 数据积累：LBS 数据+用户偏好数据，精准推荐，越用越懂用户。
  4. 直播生态：原生直播能力降低商家使用门槛，形成差异化内容生态。
  5. 零门槛体验：无需营业执照、无需复杂审核，个人即可发布，极大降低供给端门槛。
