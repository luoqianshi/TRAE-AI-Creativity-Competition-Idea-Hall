01
产品概述
Product Overview

产品定位：一款面向投融资领域的合同合规风险智能审查 Web 系统，基于结构化法律规则引擎，实现对投融资合同条款的自动分句、风险识别、分级预警与整改建议输出。

1.1 解决的问题

投融资领域合同条款专业性强、法律风险隐蔽，中小企业和创业团队缺乏专业法务资源，签约前往往无法识别对赌协议、清算优先权、反稀释条款等关键风险点，一旦签约可能承担巨额损失。

1.2 设计动机

在投融资实务中，估值调整、一票否决权、清算优先等条款看似"行业惯例"，实则暗藏对创始人和中小企业极为不利的陷阱。而聘请专业律师逐条审查成本高、周期长，大量创业者只能"盲签"。本系统将法律规则结构化，让合同审查从"人肉逐条看"变成"秒级自动筛查"。

1.3 产品形态

基于 B/S 架构的 Web 应用系统，用户通过浏览器上传投融资合同，系统自动完成条款分句、规则匹配、风险分级，输出结构化审查报告，并支持人工复核与报告导出。

2.1 典型使用场景

投融资签约前的合同审查环节。用户拿到投资方提供的股权协议、增资协议、对赌协议等文件后，上传到系统，几分钟内获得结构化的风险审查报告，识别出违约金失衡、人身免责、抽逃出资、关联交易等隐患条款，再决定是否签署或要求修改。

2.2 当前痛点

痛点描述
效率低一份投融资合同动辄几十页，律师逐条审读需 2–5 个工作日，费用数千至数万元
识别难对赌补偿上限、一票否决权范围、反稀释计算方式等专业条款，非法律人士很难判断合理性
标准乱不同律师审查口径不同，缺乏统一的风险分级和整改建议标准

Technical Architecture

4.1 架构模式

采用前后端分离的 B/S 架构，前端通过 RESTful API 与后端通信，后端负责业务逻辑与数据持久化。

4.3 核心审查引擎

系统核心为 CheckRiskService，采用纯 Java 字符串相似度算法实现，不依赖外部 ML 模型或训练数据，核心流程：

  1. 加载合同全文 → 自动分句（基于句号/分号/换行分割）
  2. 加载全部启用规则 → 逐句关键词匹配 + 句式相似度匹配
  3. 红线/黄线分类：1 级红线 = 违法无效条款；2 级黄线 = 合规瑕疵
  4. 关联 law_article 法条信息，生成风险结论与整改建议
  5. 自动入库 contract_risk + review，返回结构化审查报告

5.2 风险分级标准

红线 — 高风险

违法无效条款，severity ≥ 80 分或命中禁令型规则。如：违约金超过法定上限、人身免责条款、抽逃出资约定等。建议必须修改后方可签署。

黄线 — 中低风险

合规瑕疵，severity < 80 分。如：反稀释条款采用完全棘轮、清算优先权倍数偏高等。建议协商调整，存在谈判空间。

08
价值与意义
Value & Significance
效效率提升

将合同审查从"人肉逐条看"压缩到秒级自动筛查，30 条结构化审查规则覆盖对赌协议、股东协议、增资协议三大核心场景，红线/黄线分级让用户一目了然，审查效率提升 10 倍以上。专业用户还可在自动审查基础上进行人工复核并补充备注，实现人机协同。

益社会价值

降低法律合规门槛，让缺乏法务资源的创业者和中小企业也能在签约前识别关键风险条款，减少因信息不对称导致的"霸王条款"签署，促进投融资交易公平透明。系统内置的 45 条法律法规和可扩展的规则库，使法律知识从"律师独占"走向"普惠可及"。
