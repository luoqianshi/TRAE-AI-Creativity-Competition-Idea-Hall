Tech Stack
技术架构
模式 C 的端云协同架构，对话界面本地渲染，AI 推理和 AR 渲染走云端。
💬

对话界面

本地渲染，类微信聊天体验，卡片式内容展示

  • uniapp + WXML 本地渲染
  • 微信同声传译 ASR/TTS
  • 卡片：妆容推荐 / 步骤指引 / 试妆结果
  • 对话上下文全局状态管理

镜面模式

全屏摄像头 + AR 叠加，独立页面按需加载

  • <camera> 全屏 + <cover-view> 叠加
  • Phase 1：拍照试妆（1-3s 云渲染）
  • Phase 2：Canvas 2D 实时渲染
  • 屏幕补光 + 色号切换 + 截图
🤖

AI 后端

LLM Agent + Function Calling，驱动所有交互

  • 意图识别 → 工具调用 → 结果返回
  • 多轮对话上下文管理
  • 人脸关键点检测 + 肤质分析
  • 美妆知识图谱 + 推荐排序
