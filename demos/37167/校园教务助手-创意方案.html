💡创意概述

产品名称：校园教务助手

产品形态：微信小程序 + 网页端

目标用户：全校本科生和研究生

核心痛点：当前大学生查看课表、考试安排、学习资料等需要登录多个不同平台（教务系统如 https://jwmis.hhtc.edu.cn、班级群、网盘等），信息分散且操作繁琐，手机端体验极差。校园教务助手旨在打造一个统一入口，让学生一站式解决所有教务相关需求。

🚀核心功能模块

📅

智能课表

自动同步教务系统课表，支持周视图/日视图切换，课前提醒，教室导航

📝

考试安排

自动抓取考试信息，倒计时提醒，考场地图，备考计划生成

💬

校园论坛

课程讨论区、学习小组、二手书交易、失物招领

📚

资料库

往届试卷、课程笔记、复习资料分类存储，支持搜索和收藏

🔔

消息通知

成绩发布、选课提醒、教务公告实时推送

📊

学业分析

GPA计算、学分统计、学业进度可视化

⚙️技术实现方案

微信小程序 Vue.js Node.js MySQL Redis 教务系统数据对接 TRAE AI辅助开发

数据对接方案：通过模拟登录方式对接学校教务系统（https://jwmis.hhtc.edu.cn），自动抓取课表、考试安排等数据，经解析后展示在小程序中。同时建立校园资料共享数据库，学生可上传和下载学习资料。

👥目标用户与使用场景

  • 早晨上课前：打开小程序查看当天课表，一键导航到教室
  • 考试周：查看所有考试安排，设置倒计时提醒，下载复习资料
  • 选课前：浏览课程评价，参考学长学姐的建议
  • 课后：在论坛提问或分享笔记，寻找学习伙伴
  • 期末：查看GPA和学分统计，规划下学期课程
