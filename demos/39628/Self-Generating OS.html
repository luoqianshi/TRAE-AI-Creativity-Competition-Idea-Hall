Self-Generating OS

自生成操作系统—不管理行为，管理生成行为的环境

传统工具让你管理任务、习惯、目标。Self-Generating OS 让你管理的是：什么样的环境、状态、身份在「生成」你的行为。
SCROLL
01 / PROBLEM

现有工具解决不了的问题

当你「不想做」的时候，待办清单帮不了你。问题往往不在行为层，而在更底层的状态。

01

任务管理工具的盲区

待办清单、番茄钟、习惯打卡假设你已经知道该做什么、有能量去做。但很多时候，你不是忘了做，而是底层状态出了问题。

02

反复失败的循环

制定了计划却执行不了，归因于「意志力不足」。实际上可能是能量耗尽、身份冲突、环境摩擦——但现有工具无法定位真正的问题在哪一层。

03

缺乏自我理解

你知道自己「不想做」，但不知道为什么。没有系统帮你拆解：是感官过载？假设错误？身份抗拒？还是能量枯竭？

02 / CORE CONCEPT

核心理念

「你不管理行为，你管理的是生成行为的环境。」

系统持续观察用户状态，通过多层推理引擎定位问题出在哪一层，并给出针对性干预。系统构建两个元模型：自我模型（Self Model）与环境模型（Environment Model），并基于愿景生成目标环境设计。

04 / REASONING ENGINE

三层推理引擎

从状态机到概率推断再到 AI 解释，三层协同完成问题定位与干预生成。

底层 · STATE MACHINE

状态机

7 个系统状态：生成中、阻塞、冲突、耗竭、漂移、恢复中、安全模式。实时追踪用户处于哪个状态，驱动后续推理。

中层 · PROBABILISTIC

概率推断

5 个子引擎：问题定位、情境分析、身份归因、假设检测、干预选择。基于各层信号概率推断问题根源。

上层 · AI EXPLANATION

AI 解释

接入 DeepSeek 大语言模型，生成状态镜像、归因分析、干预建议，将底层信号翻译为人可理解的语言。

推理流程 · REASONING FLOW
用户输入→各层状态采集→问题定位→能量评估→Safe Mode 风险检查→状态镜像→归因分析→干预建议→状态转换
05 / META-MODELS

两个元模型

系统持续构建并校准两个元模型，最终输出目标环境设计与迁移方案。

SELF MODEL

自我模型

  • 身份层级与切换模式
  • 能量曲线与恢复节奏
  • 默认假设与认知偏差
  • 行为生成条件模式
ENVIRONMENT MODEL

环境模型

  • 促进 / 阻碍因素
  • 情境行为模式
  • 环境摩擦点
  • 环境与能量 / 身份交互
ULTIMATE OUTPUT · 终极输出

目标环境设计+渐进迁移方案

基于自我模型与环境模型，生成贴合你愿景的目标环境，并规划从当前状态到目标状态的渐进迁移路径。

一日场景演示

11:00

20:00

周末

环境模型生成，分析一周数据，生成环境优化建议。

08 / SAFE MODE

安全模式

当系统检测到能量耗竭或多层阻塞时，主动进入保护模式，停止一切消耗性操作。

⚠

Safe Mode · 安全模式

Safe Mode 是系统的自我保护机制。当能量层触发阈值或多层推理判定用户处于耗竭状态时，系统主动降级，减少一切非必要交互，把空间还给用户用于恢复。

01关闭非必要提醒
02只保留核心功能
03不生成新任务
04推荐恢复性活动
05降低交互频率
06记录触发原因
