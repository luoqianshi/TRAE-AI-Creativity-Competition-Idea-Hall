预设文案（测试配色判定）：
① 输入 · 原文文本 支持纯文本 / Markdown / HTML
强制规则 / Strict Rules
  1. 固定组件顺序：标题头部 → 分隔元素 → 正文 → 尾部分隔 → 结尾 → 空白区
  2. 自动配色判定：喜报/表彰/获奖 → 红色庄重；日常新闻/活动 → 浅蓝色简约
