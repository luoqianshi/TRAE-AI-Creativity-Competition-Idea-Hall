— 01 · Core Features —

四大核心模块，覆盖从查询到决策的完整链路

01
🔍

实时净值查询

通过基金代码一键查询当日估算净值与涨跌幅，内置热门基金快捷入口， 采用非交易时段缓存策略，兼顾响应速度与数据新鲜度。

02
📈

历史走势可视化

基于 Chart.js 构建的近 30 天净值折线图，渐变填充、渐变描边， 配合完整净值表，让历史表现一目了然。

03
⭐

自选管理 & 同步

一键加自选 / 移除，涨跌幅自动排序，二维码 + JSON 文件双模式导入导出， 手机与平板之间无缝同步你的关注清单。

04
🧠

AI 量化调仓建议

基于 DeepSeek API，结合基金真实持仓股票明细与当日行情， 生成结构化建议报告：多因子评分、紧急信号、操作建议与纪律提示。

05
🎨

深色极简视觉

暗色底色 + 红色主色的金融级视觉系统，自定义渐变文字、毛玻璃卡片、 SVG 噪点纹理，移动端优先设计。

06
🧩

可扩展架构

数据源配置化，通过 URL 模板 + 字段映射适配第三方 API； 服务层与视图层分离，便于接入 AkShare、券商接口等更多数据通道。

— 02 · Technology Stack —

轻量、现代、可维护

Vue 3 · Vite
Tailwind · DeepSeek

一套精心打磨的前端组合，在体验与工程化之间找到平衡。

  • Vue 3 Composition 友好的组件开发范式
  • Vite 极速冷启动，毫秒级 HMR 反馈
  • Tailwind CSS 原子化样式 + 自定义主题色板
  • Chart.js 轻量级图表，零依赖负担
  • DeepSeek API 驱动的流式内容生成
  • localStorage 持久化，无需后端即可跑通闭环
