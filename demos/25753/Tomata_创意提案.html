⬆ 左侧牌堆 = 待办任务塔 | 右侧 = 当前专注的牌（番茄钟计时中）

💡 创意介绍

想解决什么问题

现代知识工作者的效率工具严重碎片化：番茄钟 App 只管计时不看任务优先级， 任务管理工具 只管列表不关心专注节奏，燃尽图/进度追踪 则完全是另一套系统。 用户在三个工具之间来回切换，数据割裂、心智负担重，最终导致"工具越多、效率越低"的悖论。

为什么会想到做这个

灵感来自一个简单的画面：把待办事项想象成一摞扑克牌。最紧急重要的在最上面， 你一张张抽走，塔慢慢变矮，桌面渐渐铺满完成的金色卡牌。番茄钟不是独立的计时器， 而是聚焦在"当前这张牌"上的沙漏环；燃尽图不是独立的报表，而是牌堆在地面上的投影——塔有多高，进度就有多远。

产品形态

Web 应用（PWA，支持离线使用），后续可扩展为桌面客户端和移动端。 核心交互极简：PUSH（加牌入塔）→ POP（抽牌专注）→ 番茄完成 → 牌飞入成就区，三步闭环。

📛 名称由来

Tomata = Tomato（番茄工作法）+ Ta（塔 / 中文"她"）

我们所有人的时间，最初都是妈妈在你出生时给予的礼物。但出生之后， 时间并不会自动管理好自己——你需要学会"偷"时间， 从生物意义上的"妈妈时间"或哲学意义上的"上帝时间"中， 抢回属于你自己的每一段专注时刻，让个人获得持续复利的增长。

Tomata 就是你"偷时间"的武器。每一张牌被抽走，每一颗番茄被吃完， 都是在向混沌的日常宣战，夺回属于你的复利时光。

👥 目标用户及痛点

面向哪些用户

知识工作者（程序员、设计师、产品经理）、大学生/研究生、自由职业者、远程办公人群—— 任何需要自主管理时间与任务优先级的个体贡献者。

使用场景

每日开工时 PUSH 今日任务 → 按优先级自动堆叠成塔 → POP 顶牌开始第一个番茄 → 番茄完成牌飞入成就区 → 一天结束，塔消失，桌面铺满金色成就。 也支持 Sprint 周期管理（默认一周），适合敏捷开发团队或个人 OKR 追踪。

当前痛点

🔀

工具碎片化

番茄钟、Todo 列表、进度图表分属三个 App，数据不互通，来回切换打断心流。

📊

进度不可视

做完任务就打勾，缺乏"塔在变矮"的直观成就感，长期坚持动力不足。

😴

枯燥无趣

现有效率工具界面冰冷、交互机械，像在填表而不是玩游戏，用户留存率低。

🎯

优先级模糊

清单式任务管理看不出轻重缓急，用户容易先做简单的、逃避重要的。

⚔️ 与现有产品的差异

现有产品（二合一）

  • 番茄钟 + 任务列表（如 Forest、Focus To-Do）
  • 任务管理 + 进度图（如 Todoist + 看板）
  • 缺乏游戏化体验
  • 数据维度割裂
  • 界面同质化严重
VS

Tomata（三合一）

  • 番茄钟 + 优先级堆栈 + 燃尽图，一个界面搞定
  • 卡牌盖塔的游戏化隐喻，抽牌=专注，塔矮=进度
  • 拖延视觉惩罚（牌会"变质"），温和推动
  • 成就地毯——完成的牌铺满桌面，可视化成长
  • 同一数据三个视角，无需切换

🎮 核心特性（游戏化效率）

🃏

卡牌堆叠塔

任务按优先级堆成塔，P0 在顶 P3 在底，一目了然

⏳

沙漏番茄环

抽牌即启动番茄钟，环状进度条，最后 5 分钟变暖色

📈

塔影燃尽图

牌堆在地面的投影 = 燃尽趋势，塔高逐日降低

✨

成就地毯

完成的牌飘落桌面，越积越多，可视化你的成长

⚠️

拖延视觉惩罚

塔底任务太久不动会"折痕→裂痕→抖动"，温和推动

🎯

Sprint 周期

设置一周目标，塔高=总番茄数，周末看塔是否燃尽

💎 价值与意义

🚀 效率提升

将三个独立工具融合为一个统一体验，消除切换成本。用户不再需要在番茄钟 App、 任务管理工具和进度报表之间反复横跳——一个界面，三种视角，零切换。 优先级堆栈确保用户始终先做最重要的事，燃尽图提供即时反馈，形成"专注→完成→成就感→继续专注"的正向循环。

🌍 社会价值

Tomata 将长期保持免费核心功能，特别面向学生群体和公益组织开放全部功能。 我们相信，高效的时间管理能力不应该被付费墙阻挡。 尤其对于教育资源匮乏地区的学生，一个好的效率工具可能改变他们的学习轨迹—— 这正是 Tomata 选择加挂「社会公益」标签的原因。 未来计划与教育公益机构合作，为偏远地区学校提供定制化的时间管理训练工具。

💰 商业价值

目标市场覆盖全球数亿知识工作者和学生。差异化定位（三合一 + 游戏化）在效率工具红海中开辟蓝海。 商业模式：核心功能免费 + 高级功能订阅（Sprint 分析、团队协作、AI 任务拆解）， 参考 Notion / Todoist 的增长路径，以产品驱动增长（PLG）。
