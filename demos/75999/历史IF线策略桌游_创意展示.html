01 / Core Concept

三条支柱：真实历史 + 策略博弈 + AI推演

历史IF线不是架空幻想，而是基于真实史料和逻辑推演的历史模拟。每一次决策都有据可依，每一条时间线都值得深思。

📜

真实历史剧本

每个剧本基于详实史料编写，关键人物、事件、背景均经过历史顾问审核。玩家面对的是"真实发生过"的困境，而非虚构故事。

♟️

策略博弈玩法

2-6人分饰不同势力，资源有限、利益冲突。联盟与背叛、进攻与防守、短期利益与长期布局——每一步都关乎历史走向。

🤖

AI即时推演

基于大语言模型的AI引擎，在玩家做出选择后即时推演后续发展。没有固定剧本，每一次推演都是独一无二的历史模拟。

07 / Value

让历史"活"起来，让思考"深"下去

历史IF线不仅是一款桌游，更是一次穿越时空的思维训练。

🧠

培养历史思维与批判性思考

玩家不是被动接受历史结论，而是主动分析因果、权衡利弊、预测后果。在博弈中理解"历史为什么是这样"，而非仅仅记住"历史发生了什么"。

🎮

无限重玩，永不重复

AI引擎让每一次推演都独一无二。同一个剧本，不同的玩家组合、不同的决策组合，会生成完全不同的历史走向。没有固定的"正确答案"。

📚

游戏化历史教育

告别死记硬背。学生在推演中自然吸收历史知识，理解决策的复杂性。教育版可直接用于课堂教学，配备知识点解析和评估报告。

🌏

传承历史文化

每个剧本都是一次与历史的对话。从华夏文明到世界史，让年轻人在游戏中建立对历史的兴趣与敬意，成为文化传承的参与者。
