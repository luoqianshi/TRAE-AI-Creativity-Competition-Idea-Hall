问题洞察

自学编程，为什么总是半途而废？

知识零散、缺乏反馈、没有陪伴，是初学者放弃的三大核心原因。

🗺️

没有清晰路径

网上教程繁多，但不知道先学什么、再学什么，知识体系零散。

😔

缺乏持续动力

一个人学习容易孤独和倦怠，遇到问题容易放弃，缺少正向反馈。

📝

学了不会用

看视频会了，写代码就废，缺少针对性的练习和即时的判题反馈。

解决方案

StepUp 学习伙伴是什么？

StepUp 是一个 Web 端闯关式学习平台。新用户首次进入时，会与一个可爱的动画角色对话，回答学习目标、当前水平和每日时间。系统据此生成专属知识阶梯，并把每天的学习拆成可执行的小目标。

完成知识点阅读、选择题、代码练习后，角色会撒花庆祝、解锁新动作；连续打卡能获得皇冠特效和成就徽章，让学习像游戏一样有反馈、有陪伴、有成就感。

  • AI/规则引擎生成专属学习路径
  • Lottie/Rive 动画角色全程陪伴
  • 每日目标 + 连续打卡 + 积分成就
  • Docker 沙箱在线判题，学练结合

核心功能

四大亮点，让学习不再孤单

🎯

个性化知识阶梯

根据目标、水平、时间动态生成学习路径，支持随时调整目标并保留历史进度。

🦊

动画角色陪伴

状态驱动的 Lottie/Rive 角色，在登录、完成任务、连续打卡时给予情感反馈。

📅

每日目标驱动

每日凌晨自动生成任务包，也可手动选择知识点；打卡获得经验值和积分。

💻

在线代码练习

前端用 Monaco Editor 实时预览；Java/Python 用 Docker 沙箱执行并返回测试结果。

技术实现

技术栈与产品形态

StepUp 是一个 Web 应用，采用 Java 全栈技术方案，便于后续扩展为通用学习平台。

Vue 3 / React + TS Vite Element Plus / Ant Design Lottie / Rive Monaco Editor Java 17 + Spring Boot 3 Spring Security + JWT MySQL 8.0 Redis Docker 沙箱 Nginx Docker Compose
开发规划

五阶段落地计划

1

有灵魂的引导

用户注册登录、对话式引导 UI、规则引擎生成专属阶梯并存储。

2

会说话的伙伴

集成动画角色，实现登录、完成任务等关键事件的状态切换与文案显示。

3

动态阶梯与每日目标

完成阶梯实例到每日任务自动生成的闭环，角色给予实时反馈。

4

情感与激励深化

亲密度系统、换装、连续打卡特效、更多角色动画。

5

内容管理与扩展

管理后台知识域配置，平台从单一 Java 学习扩展为通用学习平台。
