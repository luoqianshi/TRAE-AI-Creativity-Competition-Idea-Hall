智能粘贴板 · 12 条记录

桌面端复制粘贴的痛点

系统剪贴板只能保存一条，切换窗口查找信息严重打断工作心流。

切换窗口打断心流

想找三分钟前复制的链接，不得不离开当前应用，打开浏览器或聊天记录翻找，专注状态被打断。

系统剪贴板太弱

Windows / macOS 原生剪贴板只能保存最近一条，重启后清空，没有搜索、没有分类、没有历史。

隐私泄露隐患

复制过的密码、API Key、身份证留在剪贴板里，任何有剪贴板读取权限的应用都能获取，毫无防护。

现有工具太重

笔记软件打开慢、云剪贴板需要注册登录、Ditto 界面过时。缺少一个轻量、现代、本地优先的剪贴板增强工具。

三种唤出方式，随时可达

像原生功能一样自然，不改变你的使用习惯。

全局快捷键

默认 Alt + V 全局唤出，任何应用内都能一键打开。支持自定义快捷键组合。

鼠标边缘触发

将鼠标快速滑向屏幕右侧边缘（或自定义边缘），窗口自动滑出。无需键盘，单手操作。

托盘图标点击

最小化到系统托盘，点击托盘图标即可唤出。右键菜单提供快速设置、退出和数据统计入口。

Electron 驱动的核心能力

借助桌面端能力，实现浏览器做不到的系统级剪贴板增强。

系统剪贴板监听

通过 Electron clipboard 模块持续监听系统剪贴板变化，自动保存每一条复制记录。这是浏览器 Web 页面无法实现的系统级能力。

全局搜索与筛选

唤出窗口后即刻输入关键词搜索。支持按类型（链接/代码/Prompt/文本）、标签、收藏状态筛选，结果实时过滤。

隐私自动打码

本地正则识别手机号、身份证、邮箱、验证码、API Key。默认展示打码版本，查看或复制原文需二次确认。数据不上传，本地处理。

一键回写剪贴板

选中历史记录后按回车，或通过 Electron clipboard.writeText() 将内容直接写回系统剪贴板，无缝粘贴到目标应用。支持复制打码版或原文。

自动分类与标签

基于本地规则引擎自动识别内容类型：链接、代码、Prompt、地址、联系方式等。自动提取关键词标签，无需调用远程 AI API。

跨平台桌面端

基于 Electron 构建，优先适配 Windows，同时保留 macOS 和 Linux 打包能力。一套代码，三端运行。窗口位置、大小、唤出方式均可配置。

紧凑的桌面窗口设计，悬浮于所有应用之上，用完即走。

谁需要这个工具？

高频使用桌面端、追求效率、重视隐私的用户。

开发者

频繁复制代码片段、GitHub 链接、API Key、错误日志。需要系统级监听和安全的本地存储，API Key 绝不能明文暴露在第三方服务中。

产品经理 / 运营

每天处理大量链接、数据、用户反馈。桌面端随时唤出、全局搜索的能力，让信息查找不再依赖切换应用。

内容创作者

积累大量 Prompt、参考链接、素材地址。桌面端常驻后台，复制即保存，素材库随用随取。

效率工具爱好者

用过 Raycast、uTools、Paste，希望有一个更轻量、纯本地、开源友好的替代品。数据完全由自己掌控。

核心价值：不切换、不丢失、不上传

做系统剪贴板的超级增强，而不是另一个笔记应用。

零打断工作流

全局快捷键或鼠标边缘触发，窗口悬浮于当前应用之上。查找历史、复制内容、关闭窗口，全程无需切换应用，心流不被打断。

绝对隐私安全

所有数据保存在本地 SQLite/LevelDB，不上传云端，不依赖第三方服务。敏感信息自动打码，Electron 的本地能力让隐私处理更彻底。

系统级能力

借助 Electron clipboard、globalShortcut、Tray 等模块，实现浏览器完全无法做到的系统剪贴板监听、全局快捷键和托盘常驻。这才是真正的桌面效率工具。

技术方案与差异化定位

Electron + Vite + React，一套代码覆盖 Windows / macOS / Linux。

技术栈

Electron Vite React TypeScript Tailwind CSS SQLite

核心模块：clipboard（剪贴板读写）、globalShortcut（全局快捷键）、Tray（系统托盘）、BrowserWindow（悬浮窗口）、screen（屏幕边缘计算）。不需要后端、不需要登录注册、不需要 AI API。AI 分类和隐私识别由本地规则引擎实现。
