棱镜 Prism

一个决定，折射出无限可能

当你面临人生中纠结的决定，棱镜不替你做选择。它将你的决定如一束光般拆解，折射出多条平行时间线，让你从不同视角、不同时间点，提前活一遍每种可能。

Problem

当局者迷

越重要的决定，越难看清全貌。你困在自己的视角里，只看到自己想看到的，忽略了自己不想面对的。做完决定后才发现关键因素，为时已晚。

现有的 AI 助手试图给你一个"正确答案"，但人生重大决策没有标准答案。模型也不具备替你判断人生的专业能力——它给的答案，可能比你的直觉更不可靠。

Concept

不替你决定，
只展开可能性

棱镜的核心设计哲学：AI 全程不做价值判断，只负责展开可能性。

这恰恰规避了模型判断力不足的问题——不给答案，就不怕胡说；不做专业判断，就不需要法律、医学或金融知识。模型只做它最擅长的事：叙事、角色扮演和信息结构化。

决策权始终在你手中。棱镜只是一面镜子，帮你看见自己看不见的角度。

Features

一个决定，
五重折射

  • 01 — 决策拆解引擎
    将模糊的纠结，拆成明确的选择分支
    用户输入"要不要辞职"，棱镜拆解为"辞职 / 不辞职 / 骑驴找马"等分支，并按人际关系、工作发展、财务状况等维度展开影响面。
  • 02 — 平行时空推演
    每条分支，生成一条未来时间线
    以 3 个月后、1 年后、3 年后为节点，用"未来的你"第一人称叙事，写出每条路径上你会得到的、失去的、和意想不到的。
  • 03 — 蝴蝶效应沙盘
    拨动一个变量，重新推演整条时间线
    在任一时间线上拨动一个小变量——"如果开始健身""如果换城市""如果学了新技能"——棱镜重新推演这个变化如何改变结局，生成新的分支。
  • 04 — 树状图宇宙地图
    所有分支，可视化为可穿梭的决策树
    每个节点是一个时间点，每条线是一个平行宇宙。点击任意节点进入那个宇宙，查看该路径的关键指标：满意度、风险度、意外性。
  • 05 — 视角棱镜
    进入任一宇宙，切换五种视角观察
    当事人（你）、利益相关者（家人 / 伴侣 / 老板）、十年后的你、旁观陌生人、反向视角（你最不愿听的声音）。同一个决定，五个角度，五种判断。

Audience

谁需要棱镜

面临重大人生决策的纠结者。

职场人
考虑跳槽、转行、辞职创业。在"留下"和"离开"之间反复摇摆，需要看清每条路的长期影响。
年轻人
考虑买房、换城市、出国深造。人生第一个重大分叉点，选错成本最高。
情侣与家庭
考虑分手、结婚、生育。情感决策最难理性分析，但影响最深远。
Value

不只是工具，
是一面认知之镜

认知价值
帮助用户跳出思维定势，从多维度、多视角、多时间点审视决策。不是给答案，而是给全景。
情绪价值
用"未来的你"叙事，让用户提前活一遍不同选择的结果。减少"如果当初"的遗憾，增加"我已想过"的笃定。
工具价值
不替用户决定，而是提供决策信息的全景图。用户自己做出更明智的选择——这才是 AI 辅助决策的正确姿态。
