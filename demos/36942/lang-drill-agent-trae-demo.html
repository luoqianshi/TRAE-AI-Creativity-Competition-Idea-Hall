当前题目｜语法辨析

明日の朝八時（　）学校に集合してください。

A. から
B. までに
C. まで
D. には
选择 B 正确。这里强调“八点之前完成集合”，应使用「までに」。这类截止时间表达已写入复习卡片，三天后回流。

核心痛点：背词和刷题像两条平行宇宙

很多备考工具只能解决单点问题：背词软件负责记忆，题库负责刷题，错题本负责记录。真正缺的是一条闭环学习流水线。

传统备考

  • 今天背的词，不一定马上进入题目语境。
  • 语法学完后，需要自己找题验证，成本高、反馈慢。
  • 错题、弱项、复习时间分散在不同工具里。
  • 聊天上下文越堆越长，学习状态容易变成“记忆沼泽”。

Lang Drill Agent

  • 输入今日单词、语法、错题或目标，立刻生成定制练习。
  • 简单题程序判定，复杂题交给判题讲解 Agent。
  • 错题归因、掌握度、复习计划写入数据库。
  • 提示词按任务动态组装，只带必要上下文，避免上下文污染。

学习闭环：从今日输入到错题回流

系统不是“一个大 prompt”，而是前端展示层、后端状态机、动态提示词组装和多 Agent 协作。

输入今日内容用户输入刚背的单词、语法点、错题、目标考试或今日学习请求。
读取学习状态后端读取目标考试、当日会话、到期复习、最近错误摘要。
生成结构化题目出题 Agent 根据考纲范围、真题风格和知识标签生成题目。
判题与讲解系统判定作答结果，复杂题给出诊断、讲解和错因归类。
回写复习计划错题、掌握度、学习摘要和下一次复习时间进入长期学习记录。

三 Agent 协作：别让一个模型同时当校长、老师和判卷人

把职责拆开，才更容易控制质量、追踪错误和节省 token。

Agent 1

Orchestrator（调度器）

识别用户意图，选择学习流程，读取学习状态，组装提示词模块，协调其他 Agent。它不直接生成正式题目，也不绕过数据库校验。

Agent 2

Question Author（出题智能体）

根据今日新学内容、到期复习、考纲规则、真题风格和知识标签生成结构化题目，并交给 Validator 校验后入库。

Agent 3

Evaluator Tutor（判题讲解智能体）

负责复杂题型判分、错误诊断、讲解生成、错题归因和当日总结。简单选择题可由程序直接判定，减少无意义模型调用。

Web 前端和 CLI 共用后端内核，既能做网页交互，也能跑终端工作流。

创意名称：Lang Drill Agent（语言学习训练 Agent）

Lang Drill Agent 面向正在备考英语四级、英语六级、大学日语四级、大学日语六级的大学生。它想解决的核心问题是：背词、学语法、刷题和错题复盘长期割裂，导致学生当天学过的知识不能立刻转化为真实题型能力。

用户可以输入当天背过的单词、刚学的语法点、错题或考试目标，系统通过 Orchestrator、Question Author、Evaluator Tutor 三个 Agent 协作，动态组装任务提示词，生成结构化练习，完成判题讲解、错因归类和复习回流。

这个创意的价值在于把语言备考从“资料堆积”改造成“学习闭环”：今日输入、即时刷题、即时反馈、长期追踪。它既能提升大学生备考效率，也能帮助学习者建立更科学的复习节奏。
