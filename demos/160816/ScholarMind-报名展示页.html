创意介绍

ScholarMind 是面向学生、研究生与科研人员的智能学术研究网站。它回应了研究过程中选题难收敛、资料分散、写作与修改工具割裂的问题，以多 Agent 协作、文献检索增强和论文工作台，把研究者从重复性操作中释放出来，专注于真正的学术判断。

核心功能

多 Agent 协作

研究员、审查员、架构师、综述员、润色员等角色分工协作，帮助厘清研究问题、搭建结构并迭代文本。

RAG 文献增强

连接 CNKI、CrossRef、PubMed 等学术来源，将检索到的相关文献和用户上传材料注入研究对话。

论文工作台

支持论文生成、外审与修改链条，结合研究类型、期刊风格、目标字数等条件完成持续迭代。

研究流程引导

覆盖选题、概念界定、研究问题、检索路径、研究设计与写作等环节，让复杂流程更可执行。

计算社会科学

提供数据处理、统计分析、代码辅助与学术图表生成，服务定量、定性和混合研究场景。

学科化使用体验

按工科、理科、人文社科和交叉学科组织研究入口，匹配不同研究任务的工作方式。

实现方法与提示词框架

用户研究需求 → 学科与研究类型识别 → 角色设定 Agent → 文献检索与 RAG 注入 → 研究问题建构 → 论文生成 / 外审 / 修改 Pipeline → 评分与迭代 → 格式化输出

系统采用 FastAPI 服务架构，结合 LangGraph 工作流、DeepSeek 大模型、向量检索与实时流式对话。关键提示词围绕“研究议题、关键概念、研究问题、检索路径、研究方法、论证结构、期刊风格、审稿意见”组织，使模型输出始终服务于具体研究任务。

数据与来源

产品使用用户在对话中输入的研究议题及自主上传的论文、文本、表格等材料；文献检索面向 CNKI、CrossRef、PubMed 等公开或已接入的学术数据来源。检索结果以题名、作者、年份、摘要、来源等信息构成上下文，用于辅助回答与研究推进，用户仍需对引用和研究结论进行核验。

价值与意义

ScholarMind 将文献发现、研究设计、论文写作、审稿修改和数据可视化串联为连续工作流，减少用户在不同工具间切换和重复整理资料的时间成本。它并不替代研究者的判断，而是以可追溯的资料支持和分角色协作降低学术研究的使用门槛，让更多学习者能够更从容地完成规范、完整的研究实践。
