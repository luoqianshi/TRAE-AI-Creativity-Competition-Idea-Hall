01 / 痛点

为什么我们要做 "电竞经理"？

现有电竞题材产品，要么是即时操作的 MOBA/FPS，要么是抽卡氪金的卡牌养成。我们发现真正想"经营一支队伍"的玩家，没有合适的载体。

1
市面上"真·经理向"产品极度稀缺 大多数电竞游戏重在操作/抽卡，几乎没有"转会谈判、工资帽、伤病管理、合同续约"这种真实经理决策。
2
单机 / 联机 / 网页玩家各有不便 Steam 端游门槛高、移动端切屏体验差、网页版又多为 2D 老 UI，无法承载现代电竞玩家审美。
3
新人入坑成本高、剧情单薄 从丙级到甲级的升级感被大量"开箱即满级"产品抹平，玩家缺乏长期目标与情感投入。
4
现有模拟器数据陈旧、规则僵硬 BP、阵容、战术组合多采用静态规则，缺少动态博弈和"沙盘推演"这类可视化决策辅助。

03 / 产品形态

一句话：打开浏览器就能玩的电竞版《足球经理》

基于 Web 的单页应用（SPA），无客户端安装、无强制氪金，登录即存档，兼容手机 / 平板 / PC，赛季制 + 真实时间推进。

🕹️

前端

原生 HTML/CSS/JS 构建的 SPA，无任何前端框架依赖 — 极轻量、加载快、易维护。设计采用 LoL 主题深色 UI + 霓虹点缀，符合玩家审美。

⚙️

后端

Node.js + Express 5 + MongoDB 7，JWT 鉴权 + 请求限速 + NoSQL 注入防护，RESTful API 设计清晰，可平滑扩展为多人联机。

05 / 价值与意义

这个创意 值在哪？

从用户价值、行业价值、技术价值三个维度出发：

01

用户价值 · 长期可玩性

一个完整赛季约 6 周真实时间（每周 1 场），叠加转会窗、伤病、合同到期等多周期事件，让玩家持续有"明天想回来玩"的钩子。

02

行业价值 · 细分赛道

在"电竞 + 模拟经营"这一尚无明显头部产品的细分赛道，率先做出"Web 原生 + 多端适配 + 深度系统"的标杆方案。

03

技术价值 · 可演进架构

纯前后端分离 + RESTful API，后端服务与游戏逻辑解耦，未来可平滑接入联机对战 / 直播联动 / 移动端封装。
