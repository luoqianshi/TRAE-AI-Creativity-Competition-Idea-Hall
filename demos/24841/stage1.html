📘 第一阶段

🌱 模板语法与响应式入门

认识 Vue 最神奇的"自动感应"机制：数据变，视图自动跟着变！

概念 1

📝 文本插值 {{ }}

最简单也最常用的语法 — 把数据显示在页面上

💡
生活类比：填空题 {{ }} 就像试卷上的"____"，把数据填进模板的空白处
<!-- Vue 模板 --> <div> 你好，{{ name }}！今天也要加油哦～ </div>
🎮 互动演示：改个名字试试
你好，小明！今天也要加油哦～
核心概念

⚡ 响应式系统 — Vue 的灵魂

这是 Vue 最强大的特性：数据变化 → 视图自动更新

🚪
生活类比：自动感应灯 你走过走廊（数据变化），灯（视图）就自动亮了。不用你每次走过去都手动按开关
// 在 Vue 中创建一个"自动感应"的数据 import { ref } from 'vue' const isDark = ref(false) // 当你修改 isDark.value = true // 模板中所有用到 isDark 的地方都会自动更新！
🎮 互动演示：开关灯

📊 数据层（JS）

const brightness = 0
↓ 触发响应
↓ DOM 更新
💡
房间里很暗
概念 2

🖱️ 事件处理 v-on / @

让用户操作（点击、输入）能改变数据

🔔
生活类比：门铃 客人按门铃（@click），主人家（事件处理函数）就出来开门
<!-- 监听按钮点击事件 --> <button @click="count++"> 点了我就 +1 </button> <!-- v-on 的简写是 @ --> <!-- @click === v-on:click -->
🎮 互动演示：点击计数器
0
💡 你每次点击，都会触发 @click 事件，数据 count 改变，视图就自动更新
概念 3

🔗 属性绑定 v-bind / :

让 HTML 元素的属性也能跟着数据变化

<!-- 用 v-bind 绑定属性 --> <img :src="avatarUrl"> <a :href="link">跳转</a>
🎮 互动演示：动态改变图片大小
🐱

数据 size = 150px 自动绑定到 :style 上

概念 4

📋 列表渲染 v-for

用一个数组，自动生成一堆元素

📑
生活类比：复印机 你有一张模板（v-for），给它一份名单（数组），它就自动复印出对应的卡片
<ul> <li v-for="item in fruits" :key="item.id"> {{ item.name }} - {{ item.price }}元 </li> </ul>
🎮 互动演示：购物清单

添加商品

概念 5

🔄 双向绑定 v-model

表单输入 ↔ 数据 双向同步，写一次就够了

🪞
生活类比：对讲机 你说话（输入框）对方能听到（数据变）；对方说话（数据变）你也能听到（视图更新）。两边同时同步
<!-- 双向绑定：输入框 ⇋ 数据 --> <input v-model="message"> <p>你输入了：{{ message }}</p>
🎮 互动演示：实时同步
⇅

数据双向同步

🎯 第一阶段小结

你已经学会了 Vue 最核心的概念：

📝
{{ }}

显示数据

🔗
v-bind (:)

绑定属性

🖱️
v-on (@)

处理事件

📋
v-for

渲染列表

🔄
v-model

双向绑定

💡 关键记忆点：Vue 的核心是响应式 — 数据变了，视图自动跟着变。不用你手动操作 DOM！
