⚡ Vite：下一代前端构建工具

快如闪电的开发和构建体验

🚀
生活类比：火箭 vs 汽车 传统的 webpack 像汽车打包所有行李再出发。Vite 像火箭 — 边飞边加载，按需给你需要的行李。开发体验是火箭级别的
# 用 Vite 创建一个 Vue 项目（极简） npm create vue@latest my-app cd my-app npm install npm run dev # 启动开发服务器 ⚡

核心特性

🔥 HMR：热模块替换（Hot Module Replacement）

改代码 → 浏览器自动更新，不刷新页面、不丢状态

🔄
生活类比：智能换装 你正在玩游戏（当前页面状态），想换个角色皮肤。普通方式：重启游戏（刷新页面）。HMR 方式：瞬间换装，继续玩（状态保留）

核心工具

📘 TypeScript：给 JS 加上类型盔甲

在写代码时就发现错误，而不是上线后

🦺
生活类比：考试 vs 作业 写 JS 像写作业，老师（用户）才发现错误。写 TS 像考试，写的时候就提醒你哪里错了
📜 JavaScript
function greet(user) { return `Hello, ${user.name}` } // 这里写错了，编辑器不会提示 greet({ nam: 'Alice' }) // user.name 是 undefined
❌ user.name 是 undefined，运行时报错
📘 TypeScript
function greet(user: { name: string }) { return `Hello, ${user.name}` } // 写错的瞬间，编辑器就提示 greet({ nam: 'Alice' }) // ⚠️ 属性 'nam' 不存在
✅ 编译时立即提示 'nam' 拼写错误
核心技能

🚀 性能优化：让应用飞快的技巧

避免常见的性能陷阱，让用户体验更流畅

❌ 反面教材（慢）
v-if 和 v-for 用在同一个元素上
直接修改 props 数据
大列表不设 key
所有页面一锅端打包
图片未压缩、未懒加载
不清理 setInterval / 事件监听
✅ 最佳实践（快）
v-if 和 v-for 分开用
通过事件通知父组件改
总是给 v-for 设置 :key
路由懒加载 import()
图片懒加载 + WebP
onUnmounted 清理副作用

📦 路由懒加载：按需加载，用到什么拉什么

把首屏不需要的代码"分块"，提升加载速度

// ❌ 反模式：一锅端 import Home from './views/Home.vue' import About from './views/About.vue' // ✅ 正确做法：动态 import（懒加载） const Home = () => import('./views/Home.vue') const About = () => import('./views/About.vue')
