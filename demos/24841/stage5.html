🚧 路由守卫：导航的"门卫"

• 你有门禁卡吗？（登录状态）
• 你能进这栋楼吗？（权限）

核心概念

🏪 Pinia：组件的"中央仓库"

多个组件共享数据 — 不用一层一层传 props

🏪
生活类比：连锁超市 一个公司（Pinia Store）管理所有分店（组件）的数据。任意分店改数据，所有分店都同步看到。不用每家店单独进货
// stores/counter.js import { defineStore } from 'pinia' export const useCounterStore = defineStore('counter', { state: () => ({ count: 0 }), actions: { increment() { this.count++ } } }) // 在任何组件中使用： const counter = useCounterStore() counter.increment() // 数据更新 counter.count // 读取数据
🎮 互动演示：3 个组件共享一个 Store

修改任意一个组件，所有组件同步更新！这就是 Pinia 的威力

💡 何时用 Pinia？
• 父子组件简单传值 → 用 props
• 跨多层组件共享 → 用 provide/inject
• 整个应用共享（用户信息、购物车、主题）→ 用 Pinia
