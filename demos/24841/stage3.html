⏱️ 生命周期与侦听

组件从"出生"到"死亡"的关键时刻，以及"守望者"模式

核心概念

👶 生命周期：一个组件的一生

从创建、挂载、更新到销毁，每个阶段都有"关键时刻"可以拦截

🌳
生活类比：一棵树的成长 种子（创建）→ 幼苗（挂载到 DOM）→ 长大开花（数据更新）→ 落叶归根（销毁）。每个阶段都有特殊的"仪式"
// Composition API 生命周期钩子 import { onMounted, onUpdated, onUnmounted } from 'vue' onMounted(() => console.log('组件挂载完成')) onUpdated(() => console.log('组件更新完成')) onUnmounted(() => console.log('组件被销毁'))

核心概念

🧮 计算属性 computed

根据已有数据"算出"新数据 — 自动缓存，只在依赖变化时重算

🧮
生活类比：自动算盘 你告诉算盘"苹果5元买了3个"（原始数据），它自动算"总价15元"（computed）。价格或数量变了，它才重算
const price = ref(10) const quantity = ref(2) // computed 会自动跟踪 price 和 quantity const total = computed(() => price.value * quantity.value)

🧠 computed 优势
  • 自动缓存：依赖不变就不重算
  • 自动追踪：依赖的数据变了才更新
  • 像普通变量一样使用：{{ total }}
  • 复杂的派生数据用 computed 写
  • 不要在 computed 里改数据！
💡 满减规则：总价 ≥ 50 减 10，≥ 100 减 25
核心概念

👀 侦听器 watch / watchEffect

"守望者" — 当某个数据变化时，做一些副作用操作

🚨
生活类比：监控摄像头 摄像头盯着门口（watch 一个数据），有人来了（数据变化）→ 自动拍照（执行副作用）。computed 是计算，watch 是反应
// watch: 显式指定要侦听谁 const count = ref(0) watch(count, (newVal, oldVal) => { console.log(`count 从 ${oldVal} 变成 ${newVal}`) }) // watchEffect: 自动追踪用到的所有响应式数据 watchEffect(() => { console.log(`count 当前是 ${count.value}`) })

🖱️ watchEffect：自动追踪所有用到的数据

你不需要告诉它追踪谁，它会自动发现你用到了哪些响应式数据

🎮 互动演示：实时鼠标坐标跟踪器

// 神奇的 watchEffect — 自动追踪所有响应式数据 import { ref, watchEffect } from 'vue' const x = ref(0) const y = ref(0) watchEffect(() => { // 这里用到了 x.value 和 y.value // watchEffect 自动建立依赖关系 marker.style.transform = `translate(${x.value}px, ${y.value}px)` })

🎯 第三阶段小结

👶
生命周期

组件的关键时刻

onMounted / onUnmounted
🧮
computed

从已有数据算出新数据

const total = computed(...)
👀
watch

显式侦听某个数据

watch(source, callback)
🪄
watchEffect

自动追踪所有依赖

watchEffect(fn)
💡 选择指南：
• 想"算出"新值 → computed（同步、有缓存）
• 想"做点事"（如请求接口、改 DOM）→ watch（明确知道侦听谁）
• 想让 Vue 自动发现依赖 → watchEffect（懒人模式）
• 组件销毁前要清理 → onUnmounted + clearInterval
