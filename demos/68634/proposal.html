01

第一阶段：亲戚计算器

核心功能

功能概述

实现最基础的亲戚关系计算功能，用户输入亲戚与自己的关系链，系统自动计算出正确的称呼。支持最多十层、四代的亲戚关系计算，覆盖日常生活中绝大多数亲戚关系场景。

核心特性

  • 关系链输入 支持逐级选择关系，如：父亲 → 兄弟 → 妻子 → 孩子
  • 十层计算深度 支持最多十层关系推导，满足复杂亲戚关系计算需求
  • 四代覆盖 涵盖曾祖辈、祖辈、父辈、同辈四个辈分的亲戚关系
  • 双向计算 支持从用户到亲戚，以及从亲戚到用户的双向称呼计算

技术栈

Vue 3 TypeScript Tailwind CSS 关系算法引擎
关键里程碑

完成关系数据库构建

收录常见亲戚关系及称呼规则

实现关系推导算法

支持多层关系链式推导

UI界面开发

简洁直观的关系输入界面

02

第二阶段：亲戚档案管理

数据存储

功能概述

在计算器基础上增加亲戚档案管理功能，用户可以为已计算出的亲戚关系添加姓名或代号，并将其保存到本地数据库中，方便后续快速查询和使用。

核心特性

  • 亲戚档案创建 为计算出的亲戚添加姓名、照片、备注等信息
  • 智能匹配 自动识别已存在的亲戚档案，避免重复添加
  • 快速搜索 支持按姓名、称呼、关系链等多维度搜索
  • 数据持久化 使用本地数据库存储，数据安全可靠

技术栈

IndexedDB LocalForage 搜索算法 数据同步
关键里程碑

设计数据库schema

定义亲戚档案数据结构

实现CRUD操作

完成档案的增删改查功能

搜索功能实现

支持模糊搜索和精确匹配

第三阶段：家谱树可视化

可视化

功能概述

将已存储的亲戚档案以家谱树的形式可视化展示，用户可以直观地看到整个家族的关系结构。新增亲戚时，系统会根据称呼自动定位到家谱树中的正确位置，同时支持手动拖拽调整。

核心特性

  • 自动家谱构建 根据亲戚关系自动生成家谱树结构
  • 交互式家谱树 支持缩放、平移、展开/折叠等交互操作
  • 手动拖拽调整 支持用户手动调整亲戚在树上的位置
  • 节点详情展示 点击节点查看亲戚详细信息

技术栈

D3.js SVG渲染 力导向布局 拖拽交互
关键里程碑

家谱数据模型设计

构建树状数据结构

可视化渲染实现

使用D3.js绘制家谱树

交互功能开发

实现拖拽、缩放、点击等交互

第四阶段：方言适配

地域化

功能概述

中国地域辽阔，不同省份对同一亲戚的叫法存在差异。此阶段将为软件添加方言适配功能，用户可以选择自己所在的省份，系统将使用当地的方言称呼进行计算和展示。

核心特性

  • 多省份方言库 收录全国各省的亲戚称呼方言
  • 智能方言匹配 根据用户定位自动推荐方言
  • 方言对比展示 支持查看同一亲戚在不同省份的称呼差异
  • 用户自定义方言 支持用户添加和修改本地特有的称呼

技术栈

方言数据库 i18n国际化 地理定位API 用户偏好存储
关键里程碑

方言数据收集整理

收集全国主要省份的亲戚称呼

方言切换功能实现

支持用户切换不同省份的称呼

智能推荐优化

根据用户位置自动推荐方言

第五阶段：民俗场景适配

文化特色

功能概述

在基础功能上增加民俗文化内容，特别是针对过年期间的使用场景，如拜年祝福语推荐、红包金额建议、传统习俗介绍等，让软件成为春节期间不可或缺的家庭助手。

核心特性

  • 智能拜年祝福 根据亲戚辈分和关系推荐合适的拜年祝福语
  • 红包金额建议 根据亲戚关系和当地习俗推荐红包金额
  • 民俗知识介绍 展示不同地区的春节传统习俗
  • 节日提醒 重要节日和纪念日提醒功能

技术栈

民俗数据库 智能推荐引擎 日历API 通知推送
关键里程碑

民俗数据收集
