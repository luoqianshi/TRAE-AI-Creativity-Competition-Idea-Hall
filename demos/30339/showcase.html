普通用户

数媒创作者

3D 建模、剪辑、影视后期、自媒体、摄影师。海量素材精准管理，AI 懂你的创作语言。

游戏开发者

贴图、概念图、参考图一站式管理，快速定位所需资源，加速开发流程。

基础，但不简单

不只是分类，而是让图库真正理解你的意图。

高精度 AI 分类

识图模型 + LLM 模型协同，一键创建智能图库分类。多模型并行推理，自动取最优结果。支持 MobileNet、WD14 等主流模型，统一类别映射与回退策略。

一键 AI 整理

AI 一键将散落在各处的图片移动到指定文件夹并自动整理。支持全盘扫描、增量监听、进度持久化，随时暂停、恢复或中断，无需从头再来。

创作，从素材开始

以下功能专注于数媒创作领域，但不仅限于数媒人群使用。

联网下载

配置好 LLM API 或本地模型，在图库输入需求，AI 精准寻找并安全下载相关图片素材，直接入库管理。

AI 生图

配置生图模型（本地或 API 或 ComfyUI URL），描述内容即可生成图片。可引用图库内图片作为参考图，支持画笔在参考图上注释，让 AI 生成更高质量图片，可直接下载到图库。

自动寻找图片

图片过多？只需描述想找的内容，AI 自动在图库中搜寻。如需立刻投入工作，可让 AI 使用图片帮你构建工作流。

美化直出

AI 分析图片信息，根据用户要求自动调整图像参数（对比度、高光、滤镜等），或使用 AI 生图重绘修图，一键出片。

更多可能

持续迭代中。AI 能力不断扩展，更多创作辅助功能即将上线。

技术架构亮点

双版本并行、高性能原生扩展、企业级数据持久化。

Python/PySide6 + C#/WPF

双版本策略：Python 原型版快速迭代验证，C# WPF 商业版打造精致桌面体验，共享核心设计规范。

C++ 高性能扩展

WIC 缩略图生成、IOCP 文件监听、高性能目录遍历三大原生模块，零外部依赖，失败自动回退。

SQLite WAL 缓存

分类结果持久化采用 SQLite WAL 模式，读写并发无阻塞。参数化查询、索引优化、旧缓存自动迁移。
