1. 产品概述

1.1 产品背景

英语学习者普遍面临"背了忘、忘了背"的低效循环。市面上背单词软件（百词斩、墨墨背单词、不背单词等）的核心逻辑都是"展示单词 + 释义 → 强制记忆"，属于被动接受式学习。

但英语作为拉丁语系语言，60% 以上的词汇由前缀、词根、后缀构成，理解构词法才是高效扩大词汇量的底层方法。目前市场上没有一款产品能对单词进行多层前后缀深度拆解——即逐层剥离前缀和后缀，最终揭露最底层词根。

1.2 产品定位

一款基于 Web 的交互式单词构词拆解工具 + 智能学习系统，填补"交互式词根词缀深度拆解 + 科学复习"的市场空白。

1.3 核心价值主张

输入一个单词 → 逐层剥离前后缀 → 可视化展示拆解过程 → 揭露底层词根 → 科学复习巩固

2. 目标用户

用户群体 核心需求 使用场景
高考/四六级/考研学生 高效扩大词汇量 课间、睡前碎片时间，查单词的同时理解构词逻辑
英语专业学生 / 语言爱好者 深入理解单词构造 研究单词词源，通过词根串联相关词汇
英语教师 课堂构词法教学工具 投屏展示单词拆解过程，辅助讲解前缀/后缀/词根

3. 用户痛点

  1. 机械记忆效率低 — 只背"单词→意思"，不理解构词逻辑，忘得快
  2. 派生词看不懂 — 遇到 unconditionally、irresponsible 等多层派生词，无法判断词根在哪
  3. 缺乏拆解工具 — 市面 App 只查意思不拆结构，没有"先去掉这个前缀、再去掉那个后缀、最后剩什么"的交互体验
  4. 词根词缀知识碎片化 — 缺乏系统梳理的交互式学习工具
  5. 学完就忘 — 拆解完没有配套的复习机制，知识无法长期巩固

4. 功能需求

4.1 MVP 核心功能（v1.0，已实现）

功能 描述 优先级
单词搜索 输入单词，自动匹配内置词库 P0
多层拆解可视化 逐层显示剥离前缀/后缀的过程，每一层标注当前剥离的是什么 P0
词根高亮 剥离所有前后缀后，金色高亮显示底层词根 P0
发音 Web Speech API 美式发音 P1
词根词缀百科 44 个前缀 + 36 个后缀的含义、来源、例词 P1
词汇海洋学习 翻卡学习模式 + 闯关选择题模式，配套科学复习 P1
推荐词快速入口 一键点击演示推荐词 P2

4.2 扩展功能（v2.0 规划）

功能 描述
自定义单词添加 用户可手动输入任意单词并标注拆解
收藏 / 生词本 将拆解过的单词加入个人词库
AI 自动拆解 调用 LLM 对任意单词自动分析词根词缀（不限于内置词库）
词根关联网络 同一词根的单词聚合展示（如 dict → predict, dictionary, dictator）
学习进度追踪 记录已拆解单词数、掌握率，FSRS 间隔重复算法
PWA / 离线使用 Service Worker 缓存，支持离线查看已拆解词
多词库支持 高考词库（9000+词）、COCA 词频分桶、自定义词库

6. 交互流程

6.1 词根拆解流程

启动页面 → 搜索框输入单词
              ↓
        匹配内置词库
              ↓
     展示单词基本信息（拼写、音标、词性、释义）
              ↓
     逐层展示拆解过程（动画逐个出现）:
        Layer 1: 剥离前缀 un-     → 剩余: conditionally
        Layer 2: 剥离后缀 -ly     → 剩余: conditional
        Layer 3: 剥离后缀 -al     → 剩余: condition
        Layer 4: 剥离后缀 -ion    → 剩余: condit
        ★ 最终词根: condit（金色高亮）
              ↓
     展示关联的前缀/后缀含义说明卡片
              ↓
     展示同根词关联（condition, conditional, unconditional）

6.2 词汇海洋学习流程

选择学习模式 → 展示单词卡片（正面: 单词）
              ↓
        点击翻转 → 展示释义
              ↓
     标记"认识"或"不认识"
              ↓
        进入下一个单词
              ↓
        完成一轮 → 闯关测验

9. 竞品分析

产品 优势 劣势（词根侦探的切入点）
百词斩 用户量大，图片记忆有趣 无词根词缀拆解功能
墨墨背单词 艾宾浩斯遗忘曲线 无多层词缀拆解
不背单词 语境记忆，例句丰富 无构词法分析
欧路词典 词库可扩展 词根信息展示浅，无逐层拆解
词根侦探 唯一支持多层前后缀逐层拆解 词库量小，社区生态未建立

核心差异化优势：

  • 唯一支持"逐层剥离前后缀→揭露词根"的交互式可视化工具
  • 配套词汇海洋学习模式，拆解完即学即练
  • 词根词缀百科系统梳理，44 前缀 + 36 后缀全覆盖
  • 底层数据积累深厚，基于高考英语 3500 词精校数据库
