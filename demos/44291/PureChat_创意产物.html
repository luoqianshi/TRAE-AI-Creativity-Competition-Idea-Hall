PureChat 是一款完全私有的跨平台聊天应用。消息不经过任何第三方，Agent 直接住进聊天室，为你处理一切琐事。

为什么需要 PureChat？

现有聊天工具要么把你的数据交给别人，要么把 AI 挡在门外。

数据不在自己手里

微信群聊、企业飞书，所有消息都存储在第三方服务器，隐私泄露风险始终存在。

Agent 体验割裂

AI 助手只能以小程序或链接形式嵌入，无法真正参与群聊、接收实时消息。

私有化部署太重

Matrix、Rocket.Chat 等开源方案架构复杂，移动端体验参差不齐，小团队难以承受。

没有轻量+Agent 的方案

市面上没有任何一款产品，能同时做到零配置部署和原生 Agent 接入。

消息只存在你的服务器上

PureChat 采用 SQLite 单文件存储，零 Docker 依赖，一台最基础的云服务器即可运行。没有第三方审查、没有算法干预、没有数据挖掘。你和谁聊了什么，只有你知道。

Agent 是一等公民

AI 助手不是外挂，而是聊天室的正式成员。它通过 WebSocket 实时收发消息，自动整理会议摘要、记录待办事项、回答常见问题。无需 Webhook，无需 API 桥接，部署一个 Agent，它就能 24 小时在线服务。

一套代码，三端覆盖

iOS、Android、Web，同一个代码库，同一套交互逻辑。Flutter 自绘引擎确保每个平台的体验都接近原生。出门在外用手机，坐在电脑前打开浏览器，消息实时同步，离线也能浏览已缓存的历史记录。

谁在用 PureChat？

从家庭群聊到企业协作，从个人极客到小型团队。

家庭与亲友

建立完全私密的家族群，分享照片、安排聚会、记录家庭账单。没有平台算法推荐，没有广告打扰，聊天内容只属于家人。

10 人以内团队的项目沟通，部署成本几乎为零。Agent 自动整理每日站会摘要、跟踪任务进度、提醒截止日期。

开发者社区

技术爱好者自建服务器，部署专属 Agent 处理代码审查、Bug 跟踪、文档问答。社区数据完全自治，不受平台政策变动影响。
