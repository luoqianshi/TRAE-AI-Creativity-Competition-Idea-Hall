📌 涉及知识点

一元二次方程求根公式、判别式应用

💡 解题思路

首先将方程整理为标准形式 ax² + bx + c = 0，然后计算判别式 Δ = b² - 4ac，根据判别式的值判断根的情况，最后代入求根公式求解。

📝 步骤详解

1. 移项整理：2x² - 8x + 6 = 0
2. 化简：x² - 4x + 3 = 0
3. 计算判别式：Δ = 16 - 12 = 4 > 0
4. 代入公式：x = (4 ± √4) / 2 = 3 或 1

⚠️ 易错点分析

容易在移项时符号出错，或者忘记将方程化为标准形式就直接代入公式。另外，判别式的计算也是常见出错点。

🔄 举一反三

建议练习：解方程 3x² - 6x + 2 = 0，注意判别式小于0时的处理方法。
