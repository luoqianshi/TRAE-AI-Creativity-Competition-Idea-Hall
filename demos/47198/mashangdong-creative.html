请帮我解释一下这段递归代码：
def factorial(n):
  if n == 0:
    return 1
  return n * factorial(n-1)
🤖
这段代码计算阶乘，我来为你拆解：
  • 函数定义：接收一个参数 n
  • 基准条件：n==0 时返回 1，这是递归的终止条件
  • 递归调用：n * factorial(n-1)，不断将问题拆分为更小的子问题
  • 举例：factorial(3) = 3 * 2 * 1 = 6

运行报错了，请帮我看看：
TypeError: 'int' object is not callable
  result = sum(1, 2)
🤖
找到问题了！
  • 错误原因：你之前把 sum 赋值为整数，覆盖了内置函数
  • 检查代码：查找 sum = xxx 这样的赋值语句
  • 解决方法：重命名变量，避免覆盖内置函数
  • 建议：变量名不要用内置函数名如 sum、list、str 等
