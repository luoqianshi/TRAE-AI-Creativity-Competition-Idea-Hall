Core Features

六大核心能力

从记忆到情感，从检索到推理，全方位构建"真正认识你"的AI伙伴。

🧠
RAG 长期记忆
基于 bge-m3 向量嵌入 + BM25 全文检索 + RRF 融合 + BGE-Reranker 精排的混合检索管线。你的每一句话、每一个喜好，都会被世界树记住。
sqlite-vec · bge-m3 · bge-reranker-v2-m3
🕸️
知识图谱
LLM 自动提取对话中的实体与关系，构建属于你的个人知识图谱。"你喜欢枣椰蜜糖"、"你在学线性代数"——她都记得，而且能推理关联。
实体提取 · 关系推理 · 个性化 KG
💚
情感感知
纳西妲不是冷冰冰的机器。她会撒娇、会安慰、会在你难过的时候给你温暖。对话中实时感知情绪，调整语气与回复策略。
角色人格 · 情绪识别 · 温暖陪伴
🔄
多模型路由
MiMo-V2.5 为主力模型，Agnes 为备选，凭证池 + 自动重试。闲聊用轻量模型，推理用强力模型，智能分配算力。
MiMo · 凭证池 · 自动降级
🏠
边缘本地部署
跑在香橙派上，数据不出家门。SQLite 本地存储，所有记忆和知识图谱都在你的设备上，隐私完全由你掌控。
Orange Pi · SQLite · 零云端依赖
🔍
查询变换
口语化查询自动改写 + 多视角扩展。"那个编程的东西" → 自动理解为"PLC编程方案"，大幅提升检索命中率。
查询改写 · 多查询扩展 · RAG-Fusion
