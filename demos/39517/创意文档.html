⚠️ 病害上报系统
📤 数据上传渠道
📡 蓝牙设备上传
支持蓝牙巡检设备数据自动采集上传，实现检测数据实时同步
📝 手动录入上报
支持现场人员手动录入检查数据，附带照片、定位等信息
📁 文件批量导入
支持Excel、CSV文件批量导入历史数据，提高数据录入效率
🚨 紧急病害直报
紧急病害一键直报至调度中心，优先处理，保障行车安全
📊 报表导出功能
📅 每日检查报表
汇总当日检查数据，生成日报表，支持打印和导出
📆 周度巡检报告
统计一周巡检情况，分析病害趋势，生成周报告
📈 月度病害统计
月度病害统计分析，生成统计图表和趋势报告
🔧 维修保养报告
维修保养工作汇总，记录维修情况和成本分析
🛡️ 安全加密模块
🔐 AES-GCM 加密
采用 Web Crypto API 实现 AES-GCM 加密，保障数据传输安全
✓ SHA-256 签名
使用 SHA-256 算法生成数据签名，确保数据完整性
📡 安全传输
数据传输前进行加密处理，防止数据泄露
💾 离线存储
支持离线数据本地存储，限额5MB/100条，联网后自动同步
