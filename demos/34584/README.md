# AI资产GitHub - 交互式Demo

## 项目概述

本项目是「AI资产的GitHub」创意方案的交互式演示Demo，展示了一个面向AI创作者的开源协作平台。

## 核心功能

1. **资产库浏览** - 浏览和搜索AI资产（提示词、智能体）
2. **即时体验** - 点击「体验」按钮即可运行提示词
3. **贡献者展示** - 查看顶级贡献者和他们的成就徽章
4. **评分系统** - 展示资产评分、Fork数、Commit数

## 体验方式

### 方式一：直接打开HTML文件
双击 `AI资产GitHub_交互式Demo.html` 即可在浏览器中体验。

### 方式二：本地服务器运行
```bash
# 使用Python启动简易服务器
python -m http.server 8000
# 访问 http://localhost:8000/AI资产GitHub_交互式Demo.html
```

## 技术特点

- **纯前端实现** - 无需后端服务器
- **响应式设计** - 支持桌面和移动端
- **交互式体验** - 模拟AI提示词运行效果
- **GitHub风格UI** - 深色主题，专业简洁

## 核心机制展示

1. **Git式协作** - 通过Fork/Star按钮展示协作流程
2. **AI裁判评分** - 星级评分和质量评估
3. **贡献证明链** - 贡献者徽章和统计数据

## 创意亮点

- 将提示词、智能体视为"一等公民"资产
- 完整的Fork-Commit-Pull Request-Merge协作流程
- AI自动分析修改价值，辅助审核
- 浏览器插件寄生式冷启动策略
