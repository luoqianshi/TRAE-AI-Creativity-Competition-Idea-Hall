01 / Overview

不只是桌面
是一个有温度的数字伙伴

趣味桌面是一款趣味桌面模拟器，将桌面宠物、任务管理、运势抽签、小游戏融为一体。一只头戴小花的黄色奶龙(ai不知道奶龙长啥样尽力了，发给他图片说看不了)趴在你的桌面中央，眼睛实时跟随鼠标，陪你工作、学习和放松。所有功能集成在一个网页中，打开浏览器即用，无需安装任何软件。

02 / Features

核心功能

🐉

AI 桌面宠物

Canvas 手绘的可爱奶龙（想象他是）趴在桌面中央，眼睛实时跟随鼠标转动。包含耳朵、腮红、肚腩纹、头顶小花等精致细节，带呼吸动画和阴影效果，让桌面充满生命力。

📝

智能备忘录

任务管理 + 计时器 + 目标日期设置三合一。设定目标日期自动显示剩余天数，启动计时后右下角小组件实时显示倒计时。删除的任务进入回收站，可随时恢复。

🔮

每日运势

每日自动抽取运势签，大部分为吉/大吉/中吉。运势卡片常驻桌面右下角，给用户积极的情绪价值。点击可重新抽签，享受开盲盒般的惊喜感。

🎮

内置小游戏

减肥蛇（越吃越短，到零胜利）和银山打字通（类金山打字通，实时显示 WPM 速度），工作间隙快速放松，还能练打字。

🖥️

完整桌面模拟

仿 Windows 11 风格的任务栏、开始菜单、可拖拽窗口系统、搜索功能、文件管理器（文件可预览）、计算器、天气、音乐播放器、画板、终端等一应俱全。

💾

本地持久存储

所有数据通过 localStorage 存储在浏览器本地，刷新不丢失。桌面图标可自由拖拽排列，位置自动记忆。支持背景音乐播放和独立音量调节。

04 / Journey

项目迭代历程

v1.0 · 桌面雏形

实现基础桌面环境、任务栏、开始菜单、可拖拽窗口系统。完成此电脑、回收站、浏览器、文件管理器基础功能。

v2.0 · 奶龙（依旧想象）登场

Canvas 手绘奶龙宠物上线，眼珠跟随鼠标。增加桌面壁纸、备忘录本地存储、应用商店等。整体 UI 向 Windows 11 风格靠拢。

v2.5 · 交互深化

桌面图标支持自由拖拽。增加计算器、天气、音乐播放器、画板、终端。搜索功能完善，支持按应用/文件/任务多维度检索。

v3.0 · 功能完善

备忘录增加任务计时、目标日期、回收站恢复机制。新增减肥蛇和银山打字两款小游戏。桌面右下角小组件实时显示运势和倒计时。增加关机动画和抖因应用。
