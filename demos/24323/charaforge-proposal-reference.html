创意介绍

我想解决的，不是出图，而是“角色真正动起来”

现在很多创作者已经能用 AI 快速生成角色静态图，但一到“让角色动起来并接进产品”这一步， 就会卡在拆部件、矢量化、关键帧、导出代码等一长串流程里。做一个简单桌宠， 往往要在 AI 出图、抠图、SVG、动画工具和前端代码之间来回切换，修改成本高，也很难快速验证创意。

为什么做

想把“静态角色图”推进到“可运行角色原型”

我发现“生成一张图”已经越来越容易，但“把一张图变成一个可交互、可运行、可接入应用的动画角色”仍然很麻烦。 尤其是桌宠、直播陪伴形象、互动网页角色、产品吉祥物这类场景，很多创意不是输在想法，而是输在制作门槛太高。

目标用户

谁会需要 CharaForge

独立开发者 / 前端工程师

想在产品里快速接入桌宠、品牌角色或互动角色，但不想手工跨多个软件反复折腾。

AIGC 创作者 / 设计师

已经会出图，但缺一条更顺滑的路径，把图变成可编辑、可展示、可导出的动画结果。

小团队 / 原型项目

需要在桌宠、陪伴产品、IP 动效方向上更快做出可验证 Demo，而不是停留在概念图阶段。

当前痛点

如果没有这个工具，大家现在怎么做

工具链很散

AI 出图、拆图、SVG、动画、导出代码常常分散在多个软件和平台，创作上下文不断被打断。

修改成本高

改一个角色姿态、锚点或状态，经常需要回退到前面步骤重新处理，效率很低。

难以快速验证

很多人能做出角色图，却很难在短时间内做出“真正能动、能接入产品”的角色原型。

工作流

从文字 / 图片到桌宠动画的完整链路

1

输入创意

输入一句话，或者上传已有角色图，作为桌宠角色的起点。
2

选择候选图

快速生成候选结果，挑出更接近预期的角色方向。
3

部件拆分 + SVG

通过 AI 分割与矢量化，把角色拆成可编辑部件。
4

动画编辑 + 导出

在时间轴中做关键帧动画，再导出为 React 或 Lottie。
当前 MVP

我已经做到了哪些能力

Input

文字 / 图片输入

支持文字生成候选图，也支持上传图片进入后续桌宠动画制作流程。

Parts

部件拆分与矢量化

支持用 AI 做局部分割，并转成 SVG 部件，降低角色二次编辑门槛。

Editor

画布 + 时间轴编辑

支持部件层级、锚点、变换调整，以及关键帧时间轴和多状态动画编辑。

Export

React / Lottie 导出

支持导出为 React SVG 动画组件与 Lottie JSON，方便落地接入宿主项目。

桌宠模板

当前聚焦 pet 场景

默认支持 4 个桌宠状态

idle / happy / hungry / sleepy

这让角色不只是“动一下”，而是具备更接近真实产品场景的可切换状态。
