# 词汇配对游戏 - 服务器使用说明

## 📱 手机访问方式（两种方案）

### 方案一：使用 localtunnel（推荐，无需注册）

1. **双击运行** `启动公网访问.bat`
2. 首次运行会自动安装依赖
3. 等待出现公网地址（类似：`https://xxx.loca.lt`）
4. 将该地址发送到手机即可访问

### 方案二：使用 ngrok（更稳定）

1. 访问 https://ngrok.com 下载并安装 ngrok
2. 注册账号并获取 authtoken
3. 先启动本地服务器：运行 `启动服务器.bat`
4. 新开一个命令行窗口，运行：`ngrok http 3000`
5. 将显示的公网地址发送到手机访问

## 🏠 局域网访问（同一WiFi下）

1. 运行 `启动服务器.bat`
2. 手机连接同一WiFi
3. 访问显示的局域网地址（如 `http://192.168.x.x:3000`）

## 💻 本地访问

直接访问：`http://localhost:3000`

## ⚠️ 注意事项

- **免费隧道限制**：公网地址可能会定期断开，重新运行脚本即可
- **网络要求**：电脑需要保持联网状态
- **安全性**：公网访问时请注意保护隐私，不要在公共网络长时间运行

## 📂 文件说明

- `server.js` - 本地服务器
- `tunnel.js` - 内网穿透脚本
- `package.json` - 项目配置
- `启动服务器.bat` - 仅启动本地服务器
- `启动公网访问.bat` - 启动服务器+公网隧道
- `词汇配对游戏.html` - 游戏网页
