答案解析

(1) 小球到达最高点的时间

公式：t = v₀sinθ / g

计算：t = 10 × sin(45°) / 10 = 10 × 0.707 / 10

答案：t ≈ 0.71 s

(2) 小球的最大高度

公式：H = (v₀sinθ)² / (2g)

计算：H = (10 × 0.707)² / (2 × 10) = 50 / 20

答案：H ≈ 2.5 m

(3) 小球的水平射程

公式：R = v₀²sin(2θ) / g

计算：R = 10² × sin(90°) / 10 = 100 × 1 / 10

答案：R = 10 m

(1) 单摆的周期

公式：T = 2π√(L/g)

计算：T = 2π × √(1.0 / 9.8) = 2π × 0.319

答案：T ≈ 2.01 s

(2) 摆球通过最低点时的最大速度

公式：v_max = √(2gL(1-cosθ₀))

计算：v_max = √(2 × 9.8 × 1.0 × (1-cos(30°))) = √(19.6 × 0.134)

答案：v_max ≈ 1.62 m/s

(3) 最大摆角处绳子的张力

公式：T = mgcosθ₀ (设 m = 1 kg)

计算：T = 1 × 9.8 × cos(30°) = 9.8 × 0.866

答案：T ≈ 8.49 N

(1) 碰撞后两球的速度

公式：v₁' = (m₁-em₂)v₁/(m₁+m₂)，v₂' = (1+e)m₁v₁/(m₁+m₂)

计算：v₁' = (1.0-1.0×1.0)×2.0/(1.0+1.0) = 0

计算：v₂' = (1+1.0)×1.0×2.0/(1.0+1.0) = 4/2

答案：v₁' = 0.00 m/s，v₂' = 2.00 m/s

(2) 验证动量守恒

公式：p = m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'

计算(碰前)：p = 1.0×2.0 + 1.0×0 = 2.0 kg·m/s

计算(碰后)：p' = 1.0×0.00 + 1.0×2.00 = 2.0 kg·m/s

结论：p = p'，动量守恒成立

(3) 计算碰撞前后系统动能

公式：Eₖ = ½m₁v₁² + ½m₂v₂²

计算(碰前)：Eₖ = ½×1.0×2.0² + 0 = 2.0 J

计算(碰后)：Eₖ' = ½×1.0×0.00² + ½×1.0×2.00² = 2.0 J

结论：Eₖ = Eₖ'，弹性碰撞动能守恒

(1) 振动的周期

公式：T = 2π√(m/k)

计算：T = 2π × √(1.0 / 100) = 2π × 0.1

答案：T ≈ 0.63 s

(2) 物体通过平衡位置时的最大速度

公式：v_max = A√(k/m) （由机械能守恒 ½kA² = ½mv²）

计算：v_max = 0.2 × √(100 / 1.0) = 0.2 × 10

答案：v_max = 2.00 m/s

(3) 最大回复力的大小

公式：F_max = kA （胡克定律）

计算：F_max = 100 × 0.2 = 20

答案：F_max = 20.0 N

(1) 小球能到达最高点的最小速度

公式：v_min = √(gR) （最高点临界条件：N=0，仅重力提供向心力）

计算：v_min = √(10 × 1.0) = √10

答案：v_min ≈ 3.16 m/s

(2) 小球在最低点时轨道对小球的支持力

公式：N = m(g + v₀²/R) （向心力方程：N - mg = mv₀²/R）

计算：N = 0.5 × (10 + 3.0²/1.0) = 0.5 × 19

答案：N = 35.0 N

(3) 小球在最高点和最低点的向心力

公式：F = mv₀²/R

计算(最低点)：F = 0.5 × 3.0² / 1.0 = 4.5 N

计算(最高点)：F = 0.5 × (3.16)² / 1.0 ≈ 5.0 N（仅重力）

答案：F_最低 = 4.5 N，F_最高 ≈ 5.0 N

(1) 行星公转周期

公式：T = √(a³/M) （开普勒第三定律：T² ∝ a³/M）

计算：T = √(1.0³ / 1.0) = √1 = 1

答案：T ≈ 1.00 年

(2) 行星在近恒星点和远恒星点的速度大小关系

公式：v = √(GM/r) （由 GMm/r² = mv²/r）

计算(近恒星点)：v_max = √(1.0/(1.0×(1-0.0))) ≈ 1.00 AU/年

计算(远恒星点)：v_min = √(1.0/(1.0×(1+0.0))) ≈ 1.00 AU/年

结论：v_max > v_min，近恒星点速度大

(3) 验证开普勒第二定律

定律内容：行星与恒星连线在相等时间内扫过相等面积

数学表达：dA/dt = L/(2m) = 常量（角动量守恒 L = mrv）

验证：近恒星点 r 小则 v 大，远恒星点 r 大则 v 小，rv = 常量

(1) 两列波的波长

公式：λ = v/f

计算：λ₁ = 1.0 / 2.0 = 0.5 m

计算：λ₂ = 1.0 / 2.0 = 0.5 m

答案：λ₁ = 0.50 m，λ₂ = 0.50 m

(2) 在波源连线的垂直平分线上某点是加强还是减弱

分析：垂直平分线上波程差 Δr = 0

判断：Δr = 0 = 0×λ，满足相长干涉条件

结论：该点为加强点（振幅最大）

(3) 产生相长干涉和相消干涉的条件

相长干涉条件：Δr = nλ (n = 0, 1, 2, ...)

说明：波程差等于波长的整数倍时，振动加强，振幅最大

相消干涉条件：Δr = (2n+1)λ/2 (n = 0, 1, 2, ...)

说明：波程差等于半波长的奇数倍时，振动减弱，振幅最小

知识点总结

运动的分解

斜抛运动分解为水平匀速和竖直上抛两个分运动

最高点特征

最高点竖直速度为零，只有水平速度

对称性

上升时间等于下降时间，轨迹关于最高点对称
