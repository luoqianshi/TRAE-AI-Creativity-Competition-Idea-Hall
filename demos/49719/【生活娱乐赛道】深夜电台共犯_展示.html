核心概念

今夜，电台为你一人直播

传统电台播给千万人，而"深夜电台共犯"只为你一人生成内容—— 你的每一次停顿、每一次呼吸，都会改变主播的语调、故事的走向。

⌨️
打字节奏感知
实时分析你的输入速度、停顿间隔、删除频率，判断当下的专注度与情绪状态——是思如泉涌，还是疲惫迟缓。
🫁
呼吸频率同步
通过手机麦克风捕捉呼吸节奏，AI感知你是紧张急促还是平稳放松，并据此调整电台的语速与氛围强度。
🎙️
专属内容生成
基于实时状态，AI主播即兴讲述故事、朗读诗歌或低声絮语，配合动态氛围音乐，生成只存在于此刻的电台节目。

技术原理

从信号到声音的五步旅程

多种前端技术的协同，让浏览器也能成为一台"有感知"的电台。

1
信号采集
键盘事件监听捕获打字节奏，Web Audio API 分析麦克风音频获取呼吸频率。
→
2
状态推断
综合 WPM、停顿时长、删除率、呼吸 BPM，推断用户当前专注度与情绪区间。
→
3
内容生成
根据状态标签从叙事模板库匹配剧本，或使用 LLM API 实时生成低语故事与诗歌。
→
4
语音合成
Web Speech API 或云端 TTS 将文本转为语音，根据状态动态调整语速、音高与停顿。
→
5
混音输出
Web Audio API 将语音、氛围音乐、环境音效实时混音，通过 Canvas 可视化频谱。
使用场景

哪些深夜需要一位"共犯"

不是每次打开都需要对话，有时候只需要一个"懂你此刻"的声音。

📝
创作瓶颈
写稿到深夜，需要陪伴感
自由撰稿人凌晨两点还在改稿，打字时快时慢。电台感知到频繁的删除和停顿，自动切换到"陪伴写作"模式——AI主播低声朗读与主题相关的参考故事，音乐保持低频不打扰思路。
🌙
失眠陪伴
大脑停不下来，需要被安抚
失眠用户躺在床上，呼吸逐渐平缓但思绪纷乱。电台捕捉呼吸节奏后，生成越来越慢的冥想引导语音，配合白噪音，在20分钟内将叙事密度降至最低，帮助平稳过渡到睡眠。
💻
夜班工作
独自值班，需要打破寂静
夜班客服/运维人员在安静的办公室独自工作。电台提供"深夜值班"模式，保持轻快的背景叙事和适度的音乐，在用户打字停止超过5分钟后主动问候，确认状态并调整内容。
