发现问题

Pixiv CN 官方客户端在收藏管理方面存在明显短板，重度用户面临诸多不便。

⭐

没有评分体系

收藏就是收藏，无法区分"还行"和"神作"。数千张收藏混在一起，找不到真正喜欢的作品。

📦

无法批量操作

想给 100 张作品打分或取消收藏？只能一张一张手动操作，效率极低。

📊

零数据分析

不知道自己的收藏趋势、偏好变化，没有热力图、没有标签分析、没有年度总结。

📱

体验碎片化

没有离线能力、没有 PWA、网络差时无法浏览。桌面和手机体验不一致。

解决方案

一个完整的自托管 Web 应用，覆盖收藏管理的全生命周期。

核心

画廊浏览

瀑布流布局 + HTMX 无限滚动，按时间/热度/随机排序。渐进式图片加载，模糊到清晰的流畅体验。

核心

星级评分

1-5 星本地评分系统，后台 Worker 自动同步至 Pixiv CN。支持悬停预览和一键评分。

核心

批量操作

画廊页和收藏夹详情页均支持多选模式，浮动操作栏一键批量评分（1-5星）或批量取消收藏。

智能

收藏分析

热力图、星级分布、标签偏好、画师排行、画师忠诚度、收藏时间线、标签演变——7 大分析面板。

智能

定时同步

后台调度器自动执行增量更新。可配置执行时间和间隔，支持手动触发和进度查看。

智能

增强搜索

支持文本搜索、ID 精确查找、#标签语法。实时下拉建议，300ms 防抖自动补全。

基础

数据备份

一键创建/下载/上传/恢复 SQLite 备份。恢复前自动安全备份，使用 SQLite Backup API 处理 WAL。

基础

PWA 安装

支持安装到手机主屏幕，Service Worker 离线缓存。桌面端和移动端一致的沉浸式体验。

基础

收藏夹对比

选择两个收藏夹查看重叠和差异，三卡片维恩图展示 + 共享作品缩略图网格。

核心

小说管理

同步小说收藏和全文内容，内置阅读器。支持本地评分和取消收藏（Pixiv CN API 限制）。

基础

四套主题

经典蓝、暖白、薰衣草、深色四种配色。日间/夜间模式切换，CSS 变量驱动的完整设计系统。

基础

安全防护

JWT 认证、登录限速、安全请求头、请求大小限制、输入验证。单用户私有部署，数据完全自主。
