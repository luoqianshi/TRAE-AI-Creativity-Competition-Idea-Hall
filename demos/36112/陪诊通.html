Project Introduction

创意介绍

陪诊通是一款 AI 驱动的异地就医智能陪诊助手。它不解决「挂不上号」，而是解决「挂上了号之后，当天怎么活下来的问题」。

01

想解决什么问题

很多普通人最无力的时刻，不是病本身，而是站在陌生医院门口，不知道下一步往哪走。挂号、签到、缴费、排队、检查、等报告……每一步都可能多耗一两个小时。

02

为什么会想到

一次带父亲跨省就医的真实经历：几栋楼之间来回跑，自助机前反复试错，手机里同时开着三个 App、两个病友群。流程上的难，有时比病上的难更让人崩溃。

03

大概是什么产品

用户输入城市、医院、科室和就诊类型，系统生成「当日就医一页通关指南」，结合语音识别与合成，让老人也能说一句话就拿到指南。

04

产品形态与链路

Web 网站 / 小程序。核心链路：输入信息 → 生成当日流程 → 步骤打卡 → 家属同步。Demo 基于 TRAE Work + TRAE Code 开发。

A True Story

为什么想到它：一个真实的跨省就医夜晚

陪诊通不是凭空设想出来的产品，而是从一个父亲说出口的、让人心碎的瞬间里长出来的。

真实经历｜跨省专科就诊

那天我们在几栋楼之间来回跑，父亲只说了一句话

去年我带父亲跨省看专科，提前在网上查了攻略、挂了号，以为准备充分。到了医院才发现：要先签到再排队、某项检查必须空腹且要单独预约、报告不是当场出、复诊号要提前抢。

那天我们在几栋楼之间来回跑，父亲走不动，我在自助机前反复试错，手机里同时开着三个 App、两个病友群和一堆截屏笔记。

那一刻我意识到：医院 App 解决的是「挂不上号」，却没有解决「挂上了号之后，当天怎么活下来的问题」。那些散落在短视频、论坛、病友群里的经验，对第一次来的人来说，仍然像一团雾。

要是我一个人来，今天可能就放弃了。

—— 晚上回到酒店，父亲只说了这一句。

这句话成了陪诊通的起点。我们想做的，不是又一个挂号工具，而是让每一个独自走进陌生医院的人，都能有一页「可以跟着走」的指南，和一份远方家人能看见的安心。

Users & Pain Points

目标用户及痛点

三类核心用户，共同的困境是：不是不想配合治疗，而是在就医流程里「迷路」了。

🧓

独自/首次异地就医的患者

尤其是中老年人

  • 不擅长智能手机、自助机、线上流程
  • 医院广播快、指示牌复杂，一步走错可能白排两小时
  • 痛点：不是不想配合治疗，而是在流程里「迷路」
👨‍👩‍👧

远在外地的子女与家属

无法全程陪同

  • 焦虑的不是「不知道得了什么病」，而是「今天进行到哪一步、有没有漏检查」
  • 电话问，老人说不清楚；请假陪诊，又未必次次成行
  • 需要的是可远程看见、可共同确认的就医进度入口
🤝

社区志愿者与陪诊员

养老机构、基层卫生服务

  • 陪诊依赖个人经验，难以标准化、复制和沉淀
  • 传统方式效率低，难形成可持续的数字服务资产
  • 需要可复用、可培训、可传承的流程模板

没有陪诊通时，用户的不便

🔍
信息分散且矛盾
短视频、论坛、病友群、各类 App 里搜到的答案彼此矛盾，不知道该信哪个。
🤖
通用 AI 给出泛泛建议
看似完整，实则缺少具体到某医院某科室的当日流程，落地不下去。
📱
缺少统一的「今日作战图」
家属与患者沟通成本高、情绪消耗大，电话里说不清「现在该去哪」。
📖
数字弱势老人读攻略吃力
真正需要的不是长篇文字，而是「下一步做什么」的即时提示。
🔁
经验无法复用
一次陪诊的经验，难变成下一次、下一个人能直接用的工具。
Value & Meaning

价值与意义

在最难自理的时刻，少跑冤枉路、少耗冤枉力气、少承担本可避免的焦虑。

社会价值

让流程上的难，不再压垮最脆弱的人

帮助普通人——尤其是老人、慢性病患者和远在他乡的家属——在最难自理的时刻，少跑冤枉路、少耗冤枉力气、少承担本可避免的焦虑。

基于真实就医场景，把分散经验整理成可执行、可核对、可传承的步骤。未来可用于社区公益陪诊、养老机构就医协助、异地就医志愿者培训；优先服务数字弱势老人、异地就医困难家庭与基层陪诊志愿者。

效率与商业价值

从个人工具到机构服务的可持续延展

把数小时搜索、核对、打电话确认的信息，压缩为几分钟内可执行的当日方案，降低无效跑动与重复排队。

对陪诊机构、养老社区、健康管理平台，可作为 ToB 工具嵌入：标准化陪诊流程、沉淀机构知识库、提升一线效率。可延展为个人/家庭订阅、机构服务、远程协同等可持续形态。

Typical Scenarios

三个典型使用场景

不是抽象的功能描述，而是真实发生在就医路上的一天。

📍 场景 A｜就诊前 3 天

子女提前为父母规划跨省就诊路线

小李在上海上班，父母在县城。下周父亲要去省城三甲医院看心内科，小李提前 3 天打开陪诊通，输入医院、科室和初诊类型，系统生成了一页通关指南：哪栋楼签到、空腹项目要早到、报告下午才出、复诊号要现在就抢。

他把指南发到家庭群，父亲看不太懂文字，点了一下语音播报，听完只说：「这次心里有底了。」

🔊 场景 B｜就诊当天

老人在自助机前卡住，语音指引「下一步」

就诊当天，王阿姨一个人来到医院。签到后，她在自助机前卡住了——屏幕上的字太小，按钮太多。她打开陪诊通，按住语音说了一句：「我签完到了，接下来干嘛？」

系统回复：「现在去 3 号楼 2 层抽血窗口，记得把缴费单带上。抽完血去隔壁心电图室取号。」王阿姨跟着走，一步没错。中午前，她已完成全部检查。

📊 场景 C｜就诊进行中

家属在外地上班，通过摘要知道进度

同一天，小李在公司开会。手机弹出陪诊通的进度摘要：「父亲已完成抽血和心电图，当前在 3 号楼 1 层等待 CT 叫号，预计还需 40 分钟。报告将于下午 3 点后出。」

小李不用打电话打断父亲，也不用反复追问。下午报告出来，系统提示：「报告已出，建议预约下周三复诊。」他直接在线帮父亲抢了复诊号。

Interaction Flow

交互流程

从输入到沉淀，五步走完一次完整的就医陪诊，每一次都变成下一次能用的模板。

用户输入

输入城市、医院、科室和就诊类型（初诊/复诊/检查）。老人也可用语音说出，系统自动识别。

AI 生成一页通关指南

系统生成当日就医流程：步骤顺序、楼层位置、携带物品、踩坑提醒、预计耗时，一页看全。

当日按步骤执行 / 打卡

跟着走，完成一项勾一项。每步都有「下一步」提示，语音播报让老人也能跟着走。

家属查看同步摘要

远方子女实时看到进度：已完成、进行中、等待中。不用打电话追问，也能知道进行到哪了。

就诊后沉淀为可复用模板

本次就医流程自动沉淀为模板，下一次本人复诊或同科室其他用户，都能直接复用。

Product Boundary

产品边界说明

这是陪诊通最重要的一条线：AI 只做就医流程指引与陪伴，绝不越界。

⚕️

不提供医疗诊断，不替代医生意见

陪诊通仅提供就医流程与信息整理辅助：告诉你先去哪、后去哪、带什么、怎么沟通。它不会解读检查报告、不会给出用药建议、不会替代任何医疗判断。所有与健康相关的决策，请始终以医生意见为准。AI 在这里扮演的角色，是一个懂流程的「陪诊向导」，而不是一个懂看病的「医生」。
