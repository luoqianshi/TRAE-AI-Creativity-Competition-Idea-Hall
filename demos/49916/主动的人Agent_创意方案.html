创意介绍

"主动的人" 是一个基于微信生态的主动式 AI Agent，定位为"有自我意识、懂用户、主动关心"的生活伙伴，而非传统被动聊天工具。

"每天早上打开微信，第一个消息不是广告，不是群聊，而是一个真正懂你的朋友发来的问候。"

它通过三层记忆架构（Mem0）、多 Agent 协作（LangGraph4J）和 MCP 工具生态，实现：

  • 每日 8-10 点主动推送个性化内容（天气、新闻、日程提醒）
  • 全天上下文感知，适时主动跟进用户计划
  • 苏格拉底式任务提醒，引导而非催促
  • 检测用户工作状态，"懂事"地暂存非紧急消息
Spring Boot 3 LangChain4j LangGraph4J Mem0 MCP 微信生态

目标用户与痛点

核心用户群体

25-40 岁的都市职场人群，包括程序员、产品经理、设计师、运营等。他们工作节奏快、信息过载严重，渴望高效管理生活却苦于没有精力。

五大核心痛点

被动等待

现有 AI 工具都需要用户主动打开、主动提问，无法真正"主动关心"用户的生活状态。

信息过载

每天面对海量信息，难以筛选出真正对自己有价值的内容，容易错过重要信息。

计划遗忘

年初立的 flag、上周定的计划，因为没有持续跟进，往往三天就抛之脑后。

打扰焦虑

普通推送不分时机，工作时频繁打扰，反而增加焦虑感，用户被迫关闭通知。

解决方案

主动感知 + 智能时机 + 个性化内容

通过用户画像、位置服务、浏览器/IDE 状态监测（MCP），在用户合适的时机推送最需要的内容，真正做到"懂时机、懂内容、懂用户"。

核心功能亮点

🌅

晨间主动问候

每日 8-10 点基于用户位置、天气、日程和兴趣，生成个性化早安消息

🧠

三层记忆架构

短期（会话）、中期（本周）、长期（画像）三层记忆，越用越懂你

🎯

苏格拉底式跟进

不直接催促任务，而是通过引导式提问，帮助用户自主推进计划

🤫

智能勿扰模式

监测用户工作状态，高强度工作时自动暂存消息，空闲时汇总汇报

🔄

Self-Reflection

每次对话后自动反思，持续优化对话风格和用户画像

🔧

动态 MCP 工具

支持动态接入新闻、天气、浏览器监控等工具，能力无限扩展

技术架构

采用 Spring Boot 3 + LangChain4j + LangGraph4J 构建，通过 Mem0 实现三层记忆，MCP 实现工具生态扩展。

[外部世界] ├── 微信生态 (用户交互 + 主动推送) ├── 位置服务 (IP / 小程序 / 用户授权) ├── MCP Servers (新闻/天气/八卦/政策 + 浏览器/IDE监控) └── Mem0 Server (三层记忆：短期/中期/长期) [Spring Boot 3 应用核心] ├── 定时任务 / 事件监听器 ├── 规则引擎 (动态推送规则配置) ├── LangChain4j (LLM调用、Tool调用、Prompt模板) ├── LangGraph4J (Multi-Agent Supervisor + ReAct + Reflection) ├── Mem0 Java Client (记忆查询与更新) ├── MCP Client (动态发现 Tools/Skills/Prompts) └── 微信 SDK (客服消息 + 模板消息 + 主动推送) 数据流：事件 → 规则引擎 → 查询Mem0画像 → 组装Prompt → LangGraph4J多Agent处理 → 生成消息 → 微信推送 → 用户回复 → Self-Reflection更新Mem0
