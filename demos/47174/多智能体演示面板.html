针对您在链表操作中的薄弱点，本章重点讲解单链表、双链表的增删改查操作，以及环形链表检测、链表反转等高频考点。

// 链表反转 - 迭代法 ListNode reverseList(ListNode head) { ListNode prev = null; ListNode curr = head; while (curr != null) { ListNode next = curr.next; curr.next = prev; prev = curr; curr = next; } return prev; }
