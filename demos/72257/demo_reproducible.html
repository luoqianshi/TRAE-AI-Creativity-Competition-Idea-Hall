🔄 完整可复现流程
从零开始，一行一行来，每一步都可以在你自己机器上跑通。
1

环境安装

Python 3.10~3.12，NVIDIA GPU + CUDA（8GB+ VRAM，RTX 3060 测试通过），推荐 Linux/WSL2。

bash
# 克隆仓库
git clone https://github.com/lululudj/trihelix-mamba.git
cd trihelix-mamba

# 安装依赖
pip install torch numpy pyyaml matplotlib
pip install triton mamba_ssm causal_conv1d
2

生成数据

OOD 测试数据（T=150）已包含在 data/ood_T150/ 目录中。训练数据需生成。

bash
# 生成 GridWorld 训练数据 (N=6/8/12, K=4/8/12, T=30/60/100)
python data/gen_grid_world.py

# OOD 数据（可选，已包含在仓库中）
python data/gen_ood.py
3

训练主力模型

ThreeChainMamba2（3.26M 参数），2000 步快速验证。

bash
# 快速训练 (2000 步)
python train.py --config configs/matched_mamba2.yaml --model three_chain_mamba2 --seed 42 --max_steps 2000

# 完整训练 (50000 步)
python train.py --config configs/matched_mamba2.yaml --model three_chain_mamba2 --seed 42

# 30M 参数扩展训练 (500 步快速验证)
python train.py --config configs/matched_mamba2_30m.yaml --model three_chain_mamba2 --seed 42 --max_steps 500
4

OOD 长程外推评估

用训练 T=100 的模型，在 T=150 测试集上做 1.5× 外推评估。

bash
# 用下载的预训练权重直接评估（秒级）
python eval_ood.py --checkpoint best.pt \
                  --config configs/matched_mamba2.yaml \
                  --data_root ./data/ood_T150

# 用自己训练的权重评估
python eval_ood.py --checkpoint results/run_three_chain_mamba2_seed42/best.pt \
                  --config configs/matched_mamba2.yaml \
                  --data_root ./data/ood_T150

# 期望输出: OOD changed_acc ≈ 0.59, ood_decay_pct ≈ 0% (不退化)

# 主力模型 5 种子完整基准 (需 WSL2/Linux/macOS)
for SEED in 42 123 456 789 1024; do

        --model three_chain_mamba2 --seed $SEED --max_steps 2000

        --config configs/matched_mamba2.yaml --data_root ./data/ood_T150
done
