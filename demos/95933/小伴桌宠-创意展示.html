1为什么需要它

我们发现的痛点

桌面太安静了

独居年轻人每天面对电脑超过 8 小时，桌上摆满了不会动的小物件。它们看着可爱，却没法给你任何回应。

手机成了焦虑源

每次通知响起都要拿起手机看一眼，结果刷了半天才发现只是广告。重要消息淹没在信息洪流里。

想要陪伴，但没条件养宠物

租房、加班、出差，养一只猫或狗对很多人来说是不现实的。但人天生需要"身边有个活物"的感觉。

3什么时候用它

一天中的陪伴时刻

09:00 刚到工位，它用屏幕显示今天的日程和天气，顺便眨眨眼跟你打招呼。
14:30 专注工作中，快递到了。它轻轻亮一下，告诉你"快递来了"，不用解锁手机。
18:00 下班前问你"今天过得怎么样？"，你可以随口吐槽两句，它听着，偶尔回应。
22:00 睡前喊它关灯，它把屏幕调成暖光夜灯模式，安静陪着你入睡。

4价值与意义

这个创意能带来什么

💛 情感价值

为独居年轻人提供一个低维护成本的陪伴入口。不是替代真实社交，而是在独处时让桌面有一个"积极的情感锚点"。

⚡ 效率价值

用物理设备的"轻提醒"替代手机推送轰炸，减少无意识刷手机的次数，帮助用户保持专注。

5技术方案

从想法到原型的路径

3D打印外壳 → ESP32主控 → LCD屏幕 → 麦克风阵列 → WiFi联网 → TRAE Agent

为什么选择这条路

ESP32 成本低、功耗低、WiFi/蓝牙原生支持，适合长期插电运行的桌面设备。3D打印外壳让每个人都可以定制自己喜欢的外形。最终接入 TRAE 的 Agent 能力，让它不只是"执行指令"，而是真正"理解语境"的智能伙伴。
