📋 项目概览

AI BodyPilot 是一款基于人工智能推理能力的个人健康决策系统。它不仅记录身体数据，更像一位全天候健康教练，根据用户身体状态、生活安排和健康目标，持续分析、预测并动态调整计划。

🚀 快速开始

1 安装 Node.js

请从 nodejs.org 下载并安装 Node.js（推荐 LTS 版本）。

node --version # 验证安装，应显示 v16.x 或更高
2 安装后端依赖
cd backend
npm install
3 配置豆包API Key

编辑 backend/.env 文件，配置您的豆包大模型 API Key：

# 服务配置
PORT=3000
HOST=0.0.0.0

# 豆包大模型配置
DOUBAO_API_KEY=your_actual_api_key_here
DOUBAO_API_URL=https://api.doubao.com/v1/chat/completions
DOUBAO_MODEL=doubao-3.5-pro

# CORS配置
CORS_ORIGIN=*

获取API Key： 前往 豆包开放平台 注册账号，创建应用并获取 API Key。

4 启动后端服务
# 开发模式（自动重启）
npm run dev

# 或生产模式
npm start

启动成功后访问：http://localhost:3000/api/v1/health

5 运行接口测试
npm test
6 打开微信小程序

使用 微信开发者工具 导入 miniprogram 目录，点击编译即可预览。

注意： 在开发者工具中勾选"不校验合法域名"，并在"服务器域名"中添加 http://localhost:3000。

🧠 提示工程设计

系统提示词精心设计，确保豆包大模型返回结构化JSON格式：

你是一个专业的营养师和健康顾问。请分析用户的饮食描述，提取食物成分并计算营养信息。

要求：
1. 识别所有食物和饮料
2. 估算每种食物的重量（使用常见的中国餐饮分量单位）
3. 计算总热量（kcal）、蛋白质（g）、碳水化合物（g）、脂肪（g）、膳食纤维（g）、糖分（g）
4. 分析饮食结构是否均衡
5. 给出具体的改进建议

输出格式必须是JSON格式，包含以下字段：
{
"food_items": [...],
"nutrition": {...},
"analysis": {...},
"suggestions": [...],
"reasoning": "解释分析依据"
}

关键技术点： 使用 response_format: { type: 'json_object' } 参数强制模型返回JSON格式。

✅ 测试指南

测试用例1：基本饮食分析
# 请求
curl -X POST http://localhost:3000/api/v1/diet/analyze \
-H "Content-Type: application/json" \
-d '{"description":"一碗米饭、一份番茄炒蛋","mealType":"lunch"}'

预期结果：返回营养分析数据，包含热量、蛋白质、碳水等信息。

测试用例2：火锅等高热量饮食
# 请求
curl -X POST http://localhost:3000/api/v1/diet/analyze \
-H "Content-Type: application/json" \
-d '{"description":"麻辣火锅，肥牛卷、蔬菜、可乐","mealType":"lunch"}'

预期结果：识别出高热量，给出晚餐控制建议。

测试用例3：饮食建议
# 请求
curl -X POST http://localhost:3000/api/v1/diet/suggest \
-H "Content-Type: application/json" \
-d '{"currentIntake":1500,"targetDeficit":500,"mealType":"dinner"}'

预期结果：根据已摄入热量，推荐合适的晚餐方案。

⚠️ 注意事项

  • API Key安全： 不要在前端直接调用AI API，必须通过后端代理转发。API Key应存储在环境变量中，不要提交到代码仓库。
  • 小程序域名配置： 生产环境需要配置合法域名，必须使用HTTPS协议，并在微信公众平台配置服务器域名。
  • 数据安全： 用户健康数据应加密存储，传输过程使用TLS/SSL，遵守相关隐私法规。
  • 模拟数据： 未配置API Key时，系统会自动使用模拟数据进行演示，方便开发调试。
