解决的核心痛点

市场上现有听书产品普遍存在格式支持单一、本地文件无法朗读等问题

格式受限

主流平台仅支持自有格式的书籍，用户购买的 PDF、EPUB 等格式电子书无法直接朗读，需要繁琐的格式转换。

必须联网

大多数听书应用强制要求上传云端或在线阅读，无法处理用户本地的私密文档和已下载的电子书资源。

无法同步阅读

传统朗读软件没有文本同步滚动功能，用户无法边听边看，难以在关键处停留或快速定位内容。

核心功能

专为深度阅读者设计的智能朗读体验

多格式支持

原生支持 PDF、EPUB、TXT、DOCX 等主流电子书格式，无需转换直接朗读

自动滚动

智能识别朗读进度，文本自动高亮并平滑滚动，实现听读同步

自然语音

集成高质量 TTS 引擎，支持多种语音风格，语速音调自由调节

本地运行

完全本地化处理，书籍无需上传云端，保护隐私，离线也能使用

技术实现

基于 Python + PyQt6 构建的跨平台桌面应用

Python 3

核心开发语言，丰富的生态支持
