PART 01 · CREATIVE INTRO

创意介绍

解决什么问题 · 为什么做 · 是什么产品

痛点与需求

当下城市交通的根本症结是："人车混行导致事故、信号灯导致拥堵、人工驾驶导致低效"。

行人横穿马路与车辆冲突频发，信号灯强制路口轮流通行造成巨大时间浪费，人工驾驶的不可靠性导致事故、违章与拥堵反复发生。非机动车骑行者行为不可预测，城市大量土地被停车和宽阔车道占据，空中交通更是完全缺乏管理。

灵感来源

当所有车辆都由系统自动驾驶，信号灯和驾驶员都变得不必要。路口无需轮流通行，车辆可以像血流一样连续穿越；行人走天桥或地下通道，彻底消除人车冲突；没有方向盘的车辆内部可以变成生活空间；虚拟车道替代实体车道线，系统动态分配让道路利用率倍增；低空航路让飞行器成为城市交通的新维度。

产品形态

一套智能出行城市系统——由云端系统 CSS + 道路系统 RSS + 车辆系统 VSS 三方核心协同运行，配套独立模拟系统 MSS 做仿真测试。覆盖机动车、非机动车与飞行器的全场景全自动协同，实现零人工驾驶、零信号灯、零人车冲突。

PART 05 · TYPICAL SCENARIOS

典型业务场景

六大典型场景，智能出行城市系统如何发挥价值

1

🔄 无信号灯路口协同通行

  1. CSS 下发全城出行调度策略与虚拟车道分配
  2. RSS 感知路口全向车流，实时协同调度
  3. RSS 向各方向车辆广播通行时序与虚拟车道
  4. VSS 间 V2V 协商穿越顺序，连续通过路口
  5. 无需轮流通行，像血流一样连续穿越，零停车等待
  6. MSS 上线前对该路口场景回归测试
2

🌧 恶劣天气 + 虚拟车道动态调整

  1. CSS 汇集城市天气（暴雨/结冰），重新规划虚拟车道
  2. CSS 将天气与虚拟车道策略下发受影响区域 RSS
  3. RSS 结合自身气象感知，更新虚拟车道并广播给车辆
  4. VSS 接收新虚拟车道与天气信息，自动调整路线与车速
  5. 非机动车自动降速编队，飞行器切换备选航路
  6. MSS 仿真不同天气与虚拟车道组合场景
3

🛸 飞行器低空穿越城市

  1. CSS 管理低空空域态势，规划航路与高度层
  2. RSS 低空感知飞行器位置，监控航路执行情况
  3. VSS 飞行器模式运行，跟随虚拟航路穿越城市
  4. 飞行器间 V2V 协商避让，与地面车辆 RSS 协同
  5. 起降场 RSS 专门调度飞行器排队与着陆
  6. MSS 仿真飞行器与地面交通混合场景
4

🚲 非机动车自动编队

  1. CSS 统一调度全城非机动车出行需求
  2. RSS 为非机动车分配专用虚拟车道，监控编队状态
  3. VSS 非机动车轻量模式运行，自动编队与保持车距
  4. 编队内车辆同步加减速，路口自动让行机动车
  5. 无人骑行，统一调度，消除骑行者行为不可预测风险
  6. MSS 仿真不同编队规模与路口交互场景
5

⚠️ 前方事故避让

  1. RSS 识别前方事故，生成告警并上报 CSS
  2. CSS 重新规划虚拟车道，将事故影响范围下发相关区域 RSS
  3. RSS 更新虚拟车道并向后方车辆广播告警与新路线
  4. VSS 接收告警与虚拟车道更新，自动减速与变道
  5. 全车自动协同避让，无需人工判断，零二次事故风险
  6. MSS 复现事故场景，验证避让与虚拟车道重分配策略
6

🛣 高速编队行驶

  1. CSS 汇集高速路况，下发虚拟车道与编队策略
  2. VSS 通过 V2V 协商编队组成，含机动车与非机动车
  3. 领航车将感知数据共享给跟随车，RSS 提供超视距信息
  4. 编队内所有车辆同步加减速，虚拟车道保持稳定车距
  5. 飞行器沿平行低空航路编队，与地面编队 RSS 协同
  6. MSS 仿真不同编队规模、混合车型与干扰场景
