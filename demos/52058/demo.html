项目背景

在这个数据驱动的时代，我们渴望AI带来的便捷，却也担忧隐私的泄露。当你向云端AI倾诉心事时，是否曾担心这些秘密会被存储、分析甚至滥用？


萤宝诞生于这样的思考：能否让AI陪伴真正属于你？所有对话、记忆、知识，都安静地躺在你的硬盘里，不经过任何云端服务器。就像夏夜的萤火虫，只照亮你一个人的夜空。

萤宝不是一个普通的聊天机器人，而是一个具备记忆系统、知识检索、自主规划能力的 AI Agent——她能主动记住你的喜好与经历，调用本地知识库精准回答，在你需要时给予恰到好处的陪伴。

核心功能

🧠
本地记忆
所有对话历史存储在本地SQLite数据库，即便离线也能回顾过往，记忆永不消失。
📚
知识库问答
上传文档构建私人知识库，ChromaDB本地向量检索，让AI成为你的专属知识助手。
✨
流萤人设陪伴
以《崩坏：星穹铁道》流萤为原型的治愈系人设，温柔细腻，像夏夜萤火虫般温暖。
🔐
隐私保护
完全本地部署，数据不经过任何第三方服务器，你的秘密只属于你自己。

技术架构

采用轻量级技术栈，确保快速部署和流畅运行：

Python Flask SQLite ChromaDB DeepSeek API HTML5 CSS3 JavaScript

🔄 数据流向
用户输入 → Flask后端 → SQLite存储对话 → 检索本地知识库 → 调用大模型API → 返回响应 → 存储记忆

📖
考研学习陪伴
深夜复习时，流萤陪你背书、解答疑惑，记录你的学习进度和心得。
💬
深夜情感倾诉
学习压力或考研焦虑时，向流萤倾诉烦恼，她会温柔倾听，给你治愈的力量。
🌙
每日进度回顾
晚上睡前，萤宝陪你回顾今天学了什么、背了多少单词、哪些地方需要巩固，像朋友一样见证你的每一步成长。

项目亮点

  • 数据本地存储 — 所有对话、记忆、知识库均存储在用户本地设备，零云端依赖，真正做到隐私保护。
  • 人格持续稳定 — 基于流萤人设的系统提示词，确保AI始终保持温柔治愈的角色设定，不会"人设崩塌"。
  • 陪伴感强 — 通过记忆机制让AI记住用户的喜好和经历，每次对话都有连续感，如同真正的朋友。
  • 轻量级部署 — 只需Python环境即可运行，无需复杂配置，普通用户也能轻松部署。
  • 可扩展性强 — 模块化设计，支持接入不同大模型API，方便后续扩展功能。
