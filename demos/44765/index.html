// SECTION_02

运维人员的 现实困境

传统安全运维模式在人机比失衡下的结构性矛盾
[01]

多控制台切换，上下文割裂

SIEM、EDR、防火墙、AD 域控日志分散于异构平台， 分析师需在多个终端间手动关联，威胁溯源链路断裂。

[02]

日志噪音过大，有效告警被淹没

海量重复告警与误报形成"告警疲劳"， 真正的横向移动与权限滥用信号被低优先级事件掩盖。

[03]

响应链路过长，MTTR 居高不下

从告警触发到处置闭环需经多级人工流转， 平均响应时间以小时计，错失黄金遏制窗口。

[04]

专家经验难复制，研判标准不一

高级威胁识别依赖资深工程师个人经验， 知识沉淀不足导致团队整体能力难以规模化提升。

// SECTION_03 · CORE

Agent 工作流 引擎

模仿资深安全专家的研判思路，四阶段串联完成从原始日志到处置建议的全链路自动化
01
STEP_01

日志接入

Log Ingestion

统一接入 SIEM、EDR、AD、流量探针等多源异构日志， 通过 Syslog/API/Kafka 完成标准化清洗与时序对齐， 构建全量可观测数据底座。

02
STEP_02

智能降噪

AI De-noising

基于聚类算法与历史基线识别重复告警， 剔除已知良性触发与误报模式， 将万级原始告警收敛为百级有效事件。

03
STEP_03

情报关联

Threat Correlation

融合 ATT&CK 矩阵、威胁情报源与内网资产图谱， 跨时间窗关联 IoC 与行为链， 还原完整攻击 kill chain 与受影响面。

04
STEP_04

报告生成

Report Generation

自动输出结构化研判报告，包含 IOC 清单、 攻击时序图、处置建议与复测脚本， 一键交付运营并触发工单闭环。
