CORE GAMEPLAY

核心玩法与进阶系统

从基础交易到风险应对，循序渐进构建金融知识体系

Lv.1 入门

基础交易系统

股票买卖、仓位管理、止盈止损设置。价格由随机波动、均值回归与新闻事件共同驱动，真实还原"信息影响股价"的市场逻辑。

K线图买卖操作仓位管理
Lv.2 进阶

配资与杠杆

随着资产增长，逐步解锁配资借款玩法。亲身体验"杠杆放大收益也放大风险"的双刃剑效应，在爆仓中学会敬畏市场。

配资借款杠杆风险爆仓体验
Lv.3 进阶

公司与财报

公司上市、财报季应对、机构做空等进阶玩法。理解基本面分析，学习解读财报数据，识别做空机制的运作原理。

IPO上市财报解读做空机制
⚠️ 警示线

风险警示剧情

特设"风险警示"剧情线，模拟高息理财陷阱、内幕交易查处、流动性危机等典型金融风险场景。所有剧情以"爆雷案例"形式呈现。

资金盘崩盘内幕交易流动性危机
VALUE & SIGNIFICANCE

价值与社会意义

🌍

社会价值

近年来，非法集资、场外配资、虚拟盘诈骗等金融犯罪屡禁不止，受害者多为缺乏金融常识的普通民众。

本游戏以寓教于乐的方式普及金融风险教育，帮助玩家在安全环境中建立正确的投资观念——不贪高息、不盲目加杠杆、敬畏市场规律。

这不仅是一款游戏，更是一堂人人都能上的"金融风险防范公开课"。

TECH STACK

技术实现方案

前端架构

纯前端单页应用

HTML + CSS + JavaScript，无需后端服务，打开即玩。代码完全开源，便于教育工作者二次开发与教学适配。

核心引擎

双向交易引擎

支持做多做空、限价市价、止盈止损。价格由随机波动+均值回归+新闻事件三因子模型驱动。

数据可视化

动态K线绘制

Canvas实时绘制K线图、成交量、MACD、KDJ等技术指标，支持缩放与历史回溯。

风控系统

自动风控系统

实时监控仓位风险、杠杆率、流动性。触发风险阈值时自动预警，强平机制模拟真实券商风控。
