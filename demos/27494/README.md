# 黑白棋（奥赛罗棋）游戏

## 项目介绍

这是一个基于Web技术开发的黑白棋（奥赛罗棋）游戏，支持双人对战和人机对战模式。游戏实现了标准的黑白棋规则，包括棋子翻转机制、合法落子判断、游戏结束判定等核心功能。同时，提供了不同难度级别的AI对手，让玩家可以根据自己的水平选择合适的挑战。

## 游戏规则

### 基础规则
- **棋盘**：8×8方格棋盘（共64格）
- **棋子**：黑白两色圆形棋子
- **玩家**：黑方先行，之后双方轮流落子

### 开局设置
游戏开始前，棋盘中心4格固定放置4颗棋子：
- 黑棋放在 (D4)、(E5)
- 白棋放在 (D5)、(E4)

### 核心行棋规则
- **落子要求**：新落的棋子需与棋盘上已有的己方棋子在水平、垂直或对角线方向上形成"两端夹击"，中间连续排列的全是对方棋子
- **翻面规则**：落子后，所有被"夹住"的对方棋子会立即翻面变为己方颜色
- **无子可走时**：若某方没有符合"夹住对方"条件的落子点，需跳过该回合，由对方继续下棋

### 胜负判定
- 游戏结束条件：棋盘被摆满或双方连续都无子可走
- 胜负规则：统计棋盘上黑白棋子的数量，棋子多的一方获胜；若数量相等，则为平局

## 功能特性

### 游戏模式
- **双人对战**：两名玩家轮流落子
- **人机对战**：玩家可选择与AI对战，可选难度级别

### AI难度级别
- **简单**：随机选择有效落子位置
- **中等**：优先选择角落和边缘位置，有基本的策略性
- **困难**：使用极小极大算法（含Alpha-Beta剪枝），考虑多步之后的最佳走法

### 游戏功能
- **悔棋**：支持撤销上一步操作
- **重新开始**：随时重置游戏状态
- **状态保存**：自动保存游戏进度，刷新页面不会丢失
- **合法落子点高亮**：提示当前玩家可落子的位置
- **游戏信息显示**：显示当前玩家、剩余可落子位置等信息

## 技术栈

### 前端
- HTML5
- CSS3
- JavaScript
- 响应式设计，支持不同设备

### 核心组件
- `GameLogic.js`：游戏核心逻辑，包括规则验证、状态管理等
- `AIPlayer.js`：AI玩家实现，包含不同难度的落子策略
- `testGame.js`：测试脚本，用于验证游戏功能的正确性

## 安装与部署

### 本地开发
1. 克隆或下载本项目到本地
2. 在浏览器中打开 `index.html` 文件即可开始游戏

### 服务器部署
1. 将项目文件上传到Web服务器
2. 确保服务器配置正确（静态文件服务即可）
3. 通过服务器域名或IP访问游戏页面

## 游戏操作

### 开始游戏
1. 访问游戏页面
2. 选择游戏模式（双人对战/人机对战）
3. 若选择人机对战，设置AI难度
4. 点击"开始游戏"按钮开始新游戏

### 行棋操作
1. 轮到自己回合时，点击高亮显示的合法落子位置
2. 系统会自动翻转被夹住的对方棋子
3. 如果没有合法落子位置，系统会自动跳过您的回合

### 游戏控制
- **悔棋**：点击"悔棋"按钮撤销上一步操作
- **重新开始**：点击"重新开始"按钮重置游戏
- **更改设置**：点击"设置"按钮调整游戏参数

## 代码结构

### 核心文件
- `src/js/gameLogic.js`：游戏逻辑核心实现
- `src/js/aiPlayer.js`：AI玩家算法实现
- `src/js/testGame.js`：游戏功能测试脚本
- `index.html`：游戏主页面
- `src/css/styles.css`：游戏样式文件

### 主要类和方法

#### GameLogic 类
- `constructor()`：初始化游戏状态
- `placePiece(row, col)`：放置棋子并翻转被夹住的棋子
- `getValidMoves(player)`：获取当前玩家的所有合法落子位置
- `isGameOver()`：检查游戏是否结束
- `getGameResult()`：获取游戏结果
- `undoMove()`：悔棋功能

#### AIPlayer 类
- `constructor(difficulty)`：初始化AI玩家，设置难度级别
- `getMove(gameLogic, playerColor)`：获取AI的最佳落子位置
- `getMoveDelay()`：根据难度获取AI思考延迟时间

## 性能优化

- 使用数组展开代替JSON序列化进行深拷贝
- 优化棋盘遍历逻辑，减少不必要的计算
- 改进AI算法，实现搜索顺序优化和强剪枝
- 根据游戏阶段动态调整评估函数权重
- 内联实现常用方法提高执行效率
