01

创意名称 + 创意介绍

想解决什么问题

人们有很多"想做但没做"的事，常常卡在"第一步"上。但不同的人卡在第一步的原因完全不同：拖延型是因为目标太大无从下手，完美主义型是因为怕做不好而迟迟不开始，冲动型则是因为三分钟热度很快放弃。现有的工具给的是千人一面的通用建议，没有考虑到"你是谁"，所以听起来对，执行起来却发现"不适合我"。

"0.1 要做的，就是找到每个人心里那个最容易被撬动的支点。"

为什么会想到做这个

我观察到，同样说"想健身"，A 可能需要被"推着走"，B 需要被"哄着来"，C 则需要一点荒谬感来打破心理防线。一个标准化的建议对 A 有效，对 B 可能完全没用，甚至让 B 更自责。0.1 的灵感来自于"因材施教"这个古老但很少被用在个人行动力场景里的思路。

大概是什么产品

一个围绕"性格匹配"设计的行动启动网页应用。通过简短问卷识别用户性格类型，AI 生成个性化的"0.1 步"行动建议，并用可爱的 IP 形象进行温暖的跟进提醒，最终通过感受日记帮助用户看见"开始"本身的价值。

02

目标用户及痛点

面向哪些用户

18-30 岁，有很多想法但执行力不稳定的年轻人。典型画像：收藏了 50 个教程但从未打开、每年年初列 flag 但第一周就放弃、深夜热血上头但第二天就冷却。

在什么场景下使用

深夜刷到别人的生活，突然想健身/学画画/写小说，但不知道从哪里开始；年初立了 flag 很快放弃，想重新找回动力，但不想再看千篇一律的励志文案；周末想尝试新爱好，却卡在"先买装备还是先学理论"的纠结里。

当前痛点

现有的效率工具给的建议都是"去办健身卡""每天写 1000 字"这类标准化方案。拖延型用户听到"每天"就觉得压力山大，完美主义型用户听到"1000 字"就觉得必须写出精品。结果是建议越"正确"，用户越动不起来，最后陷入"我又没做到"的自我否定循环。

03

价值与意义

社会价值

在一个"准备文化"盛行的时代，0.1 是一个温柔的反义词。它通过性格匹配降低行动门槛，通过可爱 IP 的陪伴减少孤独感，通过感受日记让用户看见"不完美地开始"也有价值。它帮助用户建立的不是"高效能习惯"，而是"做了再说"的勇气——这种勇气一旦建立，会迁移到生活的方方面面。

效率提升

从"想做"到"做"的时间从无限期缩短到几分钟。用户不再需要花几小时搜索攻略、对比方案、制定计划，只需要回答几个简单问题，就能得到一份"为你量身定制"的 0.1 步行动建议。更重要的是，它让"开始"这件事变得没有心理负担。

产品核心机制

以下是产品区别于现有工具的核心设计逻辑：

环节 功能 说明
第一步：识人 性格问卷（3-5题） 快速识别用户是拖延型、完美主义型、冲动型等，作为 AI 生成建议的输入条件
第二步：给步 AI 生成个性化 0.1 步 结合性格类型，生成具体、微小、可立即执行的第一步。拖延型给"无压力启动"，完美主义型给"允许做砸"
第三步：陪伴 可爱 IP 消息跟进 不是冷冰冰的推送通知，而是一个有性格、会撒娇、会鼓励的 IP 形象，按用户性格调整跟进频次和语气
第四步：看见 感受日记 + 成长关联 用户记录执行感受，AI 关联过去的相似经历，反馈"你上次也是从这里开始的，然后你做到了"
