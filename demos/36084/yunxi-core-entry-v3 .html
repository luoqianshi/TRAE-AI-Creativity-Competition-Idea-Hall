01

创意名称与介绍

云汐 Core：一个会陪你长期成长的个人 AI 伙伴。

现在很多 AI 工具擅长处理单次任务，却难以长期记住用户的学习目标、项目进度、个人习惯和成长轨迹。用户每次跨天继续学习、重启项目或复盘阶段进度时，都需要重新交代背景，学习资料、项目文档和复盘笔记也难以沉淀成连续的个人成长档案。

我在使用 AI 辅助开发、备考和整理科创项目时发现，AI 的即时能力很强，但长期连续性不足。于是我希望参考 TRAE 的多 Agent 协同、MCP 工具调用与工程调度思路，结合开源 Agent 框架，并在通用四级记忆思路基础上，追加全局记忆治理层与改进型时序环流式四级记忆体系，让 AI 成为一个越用越懂你的成长伙伴。

云汐 Core 是一个运行在个人笔记本上的本地 AI 中控系统，支持学习指导、工作开发、成长复盘三大模式，优先在本地沉淀用户的学习数据、项目记录和成长轨迹，并可在后续扩展外设交互入口，形成更完整的个人 AI 生态。

Mode 01

学习指导

支持学业规划、考研备考、证书学习和资料整理，让 AI 持续承接学习目标与阶段进度。

Mode 02

工作开发

支持项目开发、办公文档撰写、论文报告写作和科创资料归档，减少重复交代项目背景的成本。

Mode 03

成长复盘

支持每日复盘、技能树成长和阶段性成长总结，把碎片化努力沉淀为连续的成长档案。

02

云汐 Core 主要面向在校学生、考研备考人群、软件开发者、独立开发者、科研人员、内容创作者、竞赛参与者，以及需要长期推进学习、项目和个人成长的人群。

开发者与竞赛参与者项目开发、科创资料归档、代码协作、阶段总结项目背景和过程记录容易断裂，复盘结论难以沉淀
科研人员与内容创作者论文报告写作、办公文档撰写、内容整理文档、资料和 AI 对话分散在不同工具中，难以形成连续档案
长期成长型用户技能树成长、个人成长总结、阶段性目标管理学习经验、项目过程和成长轨迹只能零散保存，缺少可追溯资产

没有这样的系统时，用户需要在 AI 对话、代码工具、笔记软件和资料平台之间反复切换，专注节奏容易被打断。普通 AI 无法长期承接项目背景和成长轨迹，很多学习经验、项目过程和复盘结论只能零散保存，难以形成可追溯的个人成长资产。

03

长期记忆体系

改进型时序环流式四级记忆体系让云汐 Core 能长期承接用户的目标、项目与习惯。每一次继续学习、重启项目或阶段复盘时，AI 都能接上上一次的进度，而不是从零开始。

L0潮汐浅滩

即时上下文，负责当前任务、当前对话和短时操作状态。

L1近海浅层

会话蒸馏，把高价值对话整理成更稳定的短期记忆。

L2远海主盆

按项目、场景、模态分区沉淀，形成可检索的工作轨迹。

L3洋底海床

长期偏好与成长画像，记录用户持续变化的能力、习惯与目标。

这套体系的重点不是简单保存聊天记录，而是把学习数据、项目记录、复盘笔记和成长轨迹转化为更稳定的个人成长档案。

04

价值与意义

从效率提升角度看，云汐 Core 将学习规划、任务拆解、项目开发、文档写作、资料整理和复盘总结整合到同一个本地 AI 中控系统中，减少多工具切换和重复交代背景的成本。

依托改进型时序环流式四级记忆体系，AI 能长期承接用户的目标、项目与习惯，让每一次继续学习或工作都能接上上一次的进度。

云汐 Core 希望降低普通学生和青年开发者高效使用 AI 的门槛，让他们不需要复杂配置，也能拥有一个理解自己学习节奏、项目经历和成长轨迹的长期 AI 伙伴。它把碎片化努力沉淀为连续的成长档案，为新一代学习与工作方式提供一种更长期、更个性化、更有温度的 AI 新解法。
05

项目落地规划

项目整体架构、四级潮汐分层记忆体系、多智能体协同逻辑均为本项目独特设计；在原型工程落地阶段，会借鉴成熟的多 Agent 协同、MCP 工具调用、工程调度思路，并结合开源 Agent 框架逐步搭建可运行原型。后续可结合硬件终端完成跨端交互拓展，搭建一体化的云汐生态体系。
