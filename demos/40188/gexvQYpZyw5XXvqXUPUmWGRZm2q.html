把刷视频变成
碎片时间英语输入

一款 Chrome / Edge 浏览器扩展，在 Bilibili 与 YouTube 字幕中低打扰地插入英文词汇，让用户在真实语境里自然遇见、收藏和复习单词。

字幕词汇替换 Tooltip 学习反馈 复习弹幕 本地隐私优先

问题与灵感

背单词最大的阻力，不是单词本身，而是“场景”

📱

学习动作被切分

传统背单词 App 需要专门打开，看视频和学英语是两个独立动作，切换成本高，难以长期坚持。

🧩

单词与语境割裂

记住中文释义却不会在真实场景中识别，缺少高质量的双语输入语境。

👀

看懂不等于记住

整句翻译工具解决“看懂”，但不解决“记住”，用户缺少轻量的记忆闭环。

我们想做的是：把“背单词”从独立任务，变成看视频时顺手发生的微学习事件。

核心功能

不打断看视频，把字幕变成你的英语输入场

01

字幕词汇替换

按词库等级、CEFR 难度、替换比例和单句上限，在字幕中低打扰地插入英文词。

低密度 · 可控 · 真实语境
02

Tooltip 学习反馈

鼠标 hover 替换词即可查看释义、音标、词性和等级，还能标记认识 / 模糊 / 不认识 / 收藏 / 跳过。

即时反馈 · 影响后续策略
03

复习弹幕

把已收藏的生词以弹幕形式飘过视频画面，让复习自然融入观看流程。

B站特色 · 碎片化复习
04

Popup 学习助手

扩展图标一键打开今日进度、最近词汇、生词排行与快速复习卡片。

轻量 · 不离开视频页
05

视频内 Overlay

悬浮在视频上的学习面板，可直接调节策略、开关替换、查看进度和句级导航。

沉浸式 · 不打断观影
06

隐私优先设计

无自有服务器、无账号、无遥测，学习数据只保存在浏览器本地存储。

可信 · 最小权限

目标用户与使用场景

谁会用？在什么情况下用？

学生与备考人群

备考 CET4 / CET6 / 考研 / IELTS / TOEFL，需要大量真实语境输入。

上班族与自学者

白天工作，晚上通过 B站 / YouTube 教程、纪录片、科普视频自学。

“无痛学习”爱好者

对传统背单词 App 缺乏动力，希望学习自然发生在娱乐场景中。

典型使用流程

打开带字幕的视频 → 自动替换部分中文词为英文 → hover 查义并收藏 → Popup 快速复习 → 弹幕再次遇到生词。

价值与意义

从效率、体验到可信度，构建长期可用的学习工具

效率

碎片时间转化

把高频观看视频的碎片时间转化为低打扰的英语输入时间，无需额外打开 App。

语境

真实场景记忆

在真实字幕语境中遇到单词，提高识别率和长期记忆率，告别“认识释义不会用”。

可信

数据本地可控

没有远程账号和云同步，学习数据完全由用户掌控，降低对扩展权限的顾虑。

技术实现概览

基于 Chrome Manifest V3 的完整浏览器扩展

⚡

Content Script

负责字幕解析、文本替换、Tooltip 挂载、视频事件同步与弹幕渲染。

🧠

Background Service Worker

负责设置初始化、快捷键、消息转发与 chrome.storage.local 写入。

🎨

React + TypeScript UI

Popup、Options、视频内 Overlay 三端共享同一套设置与学习状态。

📚

本地 JSON 词库

支持 CET4 / CET6 / 考研 / IELTS / TOEFL，不依赖远程翻译 API。
