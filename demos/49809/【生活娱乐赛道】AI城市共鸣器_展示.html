CORE CAPABILITIES

核心能力

四层技术引擎，将冰冷数据转化为有温度的城市心跳

🌎
多源情绪融合
实时采集社交媒体、搜索趋势、天气、交通流量等 12+ 维度数据，通过加权情绪融合算法生成城市"情绪指纹"
🎧
AI 音景合成
基于情绪指纹，AI 实时合成 5 层声景（雨声、城市噪声、人声、音乐、自然），每层音量与频率由情绪驱动
🎨
粒子情绪画
Canvas 粒子系统实时渲染城市情绪——颜色映射情绪类型、粒子密度映射人口活跃度、运动轨迹映射情绪强度
📊
城市对比洞察
支持多城市情绪对比，发现"此刻哪座城市最快乐""凌晨3点谁还在焦虑"等有趣洞察，生成可视化报告
TECH ARCHITECTURE

技术原理

从数据采集到沉浸式渲染的完整技术链路

1
数据采集层
实时抓取社交媒体情绪、天气API、交通数据、搜索趋势、噪声监测等多维城市数据
NLP 情感分析 API 聚合 实时流
2
AI 情绪引擎
多源数据经情绪分类模型处理，输出五维情绪向量（愉悦/平静/焦虑/孤独/激动），生成城市情绪指纹
BERT 情感 加权融合 时序平滑
3
音景合成引擎
情绪向量驱动 Web Audio API 实时合成五层声景，每层音量/频率/节奏由对应情绪维度控制
Web Audio OSC 合成 空间混响
4
沉浸式渲染
Canvas 粒子系统 + WebGL 后处理，将情绪映射为色彩/运动/密度，实时渲染"城市心跳"视觉交响
Canvas 2D 粒子系统 WebGL
