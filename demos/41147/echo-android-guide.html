STAGE / 02环境准备

开发 Android 你只需要安装 一个软件 · Android Studio。它自带 JDK、Gradle、模拟器、SDK 管理器，全套打包好了。

2.1 下载并安装 Android Studio

1

访问 https://developer.android.com/studio，下载 Android Studio Hedgehog (2023.1.1) 或更新版本。Mac/Windows 都有对应安装包。

2

安装时一路点 Next。第一次启动会让你下载 Android SDK Platform 34 和 Android SDK Build-Tools，全部勾选默认即可，下载量约 5GB。

3

启动后看到欢迎界面就成功了。先别急着新建项目，下一步先准备模拟器。

2.2 创建一个 Android 模拟器

  1. 欢迎界面右上角 More Actions → Virtual Device Manager。
  2. 点 Create Device，选 Pixel 7（屏幕大小适中，开发体验好）。
  3. 系统镜像选 API 34 (Android 14)，没下载就点旁边的 Download。
  4. 命名 Pixel 7 API 34，完成。
  5. 点击设备列表里的 ▶ 启动它，看到一个 Android 桌面就成了。
新手提示：模拟器启动很慢（首次约 2 分钟），但启动一次后保留它一直开着，开发期间反复用同一个实例最省时间。

STAGE / 03创建 Android Studio 项目

  1. 欢迎界面 → New Project。
  2. 左侧选 Phone and Tablet，模板选 Empty Activity（注意是带 Compose 图标那个，不是 "Empty Views Activity"）。
  3. 填写以下字段：

  2. 同步完成后，点击工具栏绿色 ▶（Run），让默认模板跑起来——你应该看到模拟器里出现一行 "Hello Android!"。

STAGE / 07数据层 · DAO 与 Database

DAO（Data Access Object）= "我对数据库说什么话"。下面这两个文件涵盖了 Echo 全部 SQL 操作。

data/dao/EmotionDao.kt 
package com.yourname.echo.data.dao

import androidx.room.*
import com.yourname.echo.data.entity.EmotionEntry
import kotlinx.coroutines.flow.Flow

@Dao
interface EmotionDao {
    @Insert
    suspend fun insert(entry: EmotionEntry): Long

    @Update
    suspend fun update(entry: EmotionEntry)

    @Delete
    suspend fun delete(entry: EmotionEntry)

    // 取某时间段内全部条目（升序），用于词云聚合
    @Query("SELECT * FROM emotion_entries WHERE timestamp BETWEEN :start AND :end ORDER BY timestamp DESC")
    fun observeRange(start: Long, end: Long): Flow<List<EmotionEntry>>

    // 取所有条目（备份导出用）
    @Query("SELECT * FROM emotion_entries ORDER BY timestamp DESC")
    suspend fun getAll(): List<EmotionEntry>

    // 清空（导入时用）
    @Query("DELETE FROM emotion_entries")
    suspend fun clearAll()
}
data/dao/DailyStateDao.kt 
package com.yourname.echo.data.dao

import androidx.room.*
import com.yourname.echo.data.entity.DailyState
import kotlinx.coroutines.flow.Flow

@Dao
interface DailyStateDao {
    // 关键：REPLACE 策略 = 一天多次保存自动覆盖
    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun upsert(state: DailyState)

    @Query("SELECT * FROM daily_states WHERE date = :date LIMIT 1")
    fun observeByDate(date: String): Flow<DailyState?>

    @Query("SELECT * FROM daily_states WHERE date BETWEEN :startDate AND :endDate ORDER BY date ASC")
    fun observeRange(startDate: String, endDate: String): Flow<List<DailyState>>

    @Query("SELECT * FROM daily_states ORDER BY date ASC")
    suspend fun getAll(): List<DailyState>

    @Query("DELETE FROM daily_states")
    suspend fun clearAll()
}

package com.yourname.echo.data

import android.content.Context
import androidx.room.Database
import androidx.room.Room
import androidx.room.RoomDatabase
import com.yourname.echo.data.dao.DailyStateDao
import com.yourname.echo.data.dao.EmotionDao

    version = 1,
    exportSchema = false

abstract class EchoDatabase : RoomDatabase() {

    abstract fun dailyStateDao(): DailyStateDao

        fun getInstance(ctx: Context): EchoDatabase =

                INSTANCE ?: Room.databaseBuilder(
                    ctx.applicationContext,
                    EchoDatabase::class.java,
                    "echo.db"
                ).build().also { INSTANCE = it }
            }
    }
}

STAGE / 08数据层 · Repository 层

Repository 是 ViewModel 的"统一入口"。所有跟 DAO 的对话都包一层，将来加缓存或其他数据源就改这一层即可。

data/EchoRepository.kt 
package com.yourname.echo.data

import com.yourname.echo.data.dao.DailyStateDao
import com.yourname.echo.data.dao.EmotionDao
import com.yourname.echo.data.entity.DailyState
import com.yourname.echo.data.entity.EmotionEntry
import com.yourname.echo.util.KeywordExtractor
import kotlinx.coroutines.flow.Flow
import kotlinx.serialization.encodeToString
import kotlinx.serialization.json.Json

class EchoRepository(
    private val emotionDao: EmotionDao,
    private val dailyStateDao: DailyStateDao
) {
    // ---------- 情绪 ----------
    suspend fun saveEmotion(text: String) {
        val keywords = KeywordExtractor.extract(text, topN = 5)
        val keywordsJson = Json.encodeToString(keywords)
        emotionDao.insert(
            EmotionEntry(
                timestamp = System.currentTimeMillis(),
                eventText = text,
                keywordsCache = keywordsJson
            )
        )
    }
    fun observeEmotionsInRange(startMs: Long, endMs: Long): Flow<List<EmotionEntry>> =
        emotionDao.observeRange(startMs, endMs)

    // ---------- 状态 ----------
    suspend fun upsertDailyState(state: DailyState) = dailyStateDao.upsert(state)
    fun observeDailyState(date: String): Flow<DailyState?> = dailyStateDao.observeByDate(date)
    fun observeStatesInRange(start: String, end: String): Flow<List<DailyState>> =
        dailyStateDao.observeRange(start, end)

    // ---------- 备份 ----------
    suspend fun exportAll(): BackupBundle = BackupBundle(
        version = 1,
        exportedAt = System.currentTimeMillis(),
        emotions = emotionDao.getAll(),
        states = dailyStateDao.getAll()
    )
    suspend fun importAll(bundle: BackupBundle) {
        emotionDao.clearAll()
        dailyStateDao.clearAll()
        bundle.emotions.forEach { emotionDao.insert(it) }
        bundle.states.forEach { dailyStateDao.upsert(it) }
    }
}

@kotlinx.serialization.Serializable
data class BackupBundle(
    val version: Int,
    val exportedAt: Long,
    val emotions: List<EmotionEntry>,
    val states: List<DailyState>
)

8.1 关键词提取器

util/KeywordExtractor.kt 
package com.yourname.echo.util

import com.huaban.analysis.jieba.JiebaSegmenter
import com.huaban.analysis.jieba.SegToken
import com.huaban.analysis.jieba.WordDictionary

/**
 * 简易关键词提取：
 * Jieba 分词 → 过滤停用词与单字 → 词频统计 → 取 TopN
 * （TF-IDF 因为文档数有限，按词频已足够好用）
 */
object KeywordExtractor {
    private val segmenter by lazy { JiebaSegmenter() }
    private val stopwords = setOf(
        "的","了","是","我","你","他","她","它","这","那","在","和","与","也",
        "都","就","不","没","有","上","下","对","会","要","但","好","很","太",
        "啊","吧","呢","吗","哦","嗯","因为","所以","然后","然后","一个","什么",
        "怎么","为什么","因此","可是","不过","其实","真的","已经","还有"
    )

    fun extract(text: String, topN: Int = 5): List<String> {
        if (text.isBlank()) return emptyList()
        val tokens: List<SegToken> = segmenter.process(text, JiebaSegmenter.SegMode.SEARCH)
        val freq = HashMap<String, Int>()
        for (t in tokens) {
            val w = t.word.trim()
            if (w.length < 2) continue
            if (w in stopwords) continue
            if (!w.any { it.isLetterOrDigit() }) continue
            freq[w] = (freq[w] ?: 0) + 1
        }
        return freq.entries.sortedByDescending { it.value }.take(topN).map { it.key }
    }

    /** 词云用：返回词->频率 */
    fun extractWithFreq(texts: List<String>, topN: Int = 30): List<Pair<String, Int>> {
        val freq = HashMap<String, Int>()
        for (text in texts) {
            val tokens = segmenter.process(text, JiebaSegmenter.SegMode.SEARCH)
            for (t in tokens) {
                val w = t.word.trim()
                if (w.length < 2 || w in stopwords) continue
                if (!w.any { it.isLetterOrDigit() }) continue
                freq[w] = (freq[w] ?: 0) + 1
            }
        }
        return freq.entries.sortedByDescending { it.value }.take(topN).map { it.key to it.value }
    }
}
util/DateUtils.kt 
package com.yourname.echo.util

import java.time.Instant
import java.time.LocalDate
import java.time.ZoneId
import java.time.format.DateTimeFormatter

object DateUtils {
    private val fmt = DateTimeFormatter.ISO_LOCAL_DATE   // "2026-06-17"

    fun todayKey(): String = LocalDate.now().format(fmt)

    fun keyOf(date: LocalDate): String = date.format(fmt)

    fun rangeDays(days: Int): Pair<String, String> {
        val end = LocalDate.now()
        val start = end.minusDays(days.toLong() - 1)
        return start.format(fmt) to end.format(fmt)
    }

    fun rangeMillis(days: Int): Pair<Long, Long> {
        val now = System.currentTimeMillis()
        val start = LocalDate.now().minusDays(days.toLong() - 1)
            .atStartOfDay(ZoneId.systemDefault()).toInstant().toEpochMilli()
        return start to now
    }

    fun fmtTime(ms: Long): String {
        val d = Instant.ofEpochMilli(ms).atZone(ZoneId.systemDefault())
        return DateTimeFormatter.ofPattern("MM-dd HH:mm").format(d)
    }
}

ui/flow/WordCloudCanvas.kt 
package com.yourname.echo.ui.flow

import androidx.compose.foundation.Canvas
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.foundation.layout.height
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.geometry.Offset
import androidx.compose.ui.geometry.Rect
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.graphics.drawscope.drawIntoCanvas
import androidx.compose.ui.graphics.nativeCanvas
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import kotlin.math.cos
import kotlin.math.sin

@Composable
fun WordCloudCanvas(
    words: List<Pair<String, Int>>,
    accent: Color, accent2: Color, ink: Color,
    modifier: Modifier = Modifier
) {
    Canvas(modifier = modifier.fillMaxWidth().height(280.dp)) {
        if (words.isEmpty()) return@Canvas
        val maxFreq = words.first().second.toFloat()
        val minFreq = words.last().second.toFloat().coerceAtLeast(1f)
        val placed = mutableListOf<Rect>()
        val center = Offset(size.width / 2f, size.height / 2f)
        val paint = android.graphics.Paint().apply { isAntiAlias = true }

        drawIntoCanvas { canvas ->
            words.forEachIndexed { idx, (word, freq) ->
                val ratio = (freq - minFreq) / (maxFreq - minFreq + 0.001f)
                val fontSizePx = 14.sp.toPx() + ratio * (36.sp.toPx() - 14.sp.toPx())
                paint.textSize = fontSizePx
                paint.color = when (idx % 3) {
                    0 -> android.graphics.Color.argb(255,
                        (accent.red*255).toInt(),(accent.green*255).toInt(),(accent.blue*255).toInt())
                    1 -> android.graphics.Color.argb(255,
                        (accent2.red*255).toInt(),(accent2.green*255).toInt(),(accent2.blue*255).toInt())
                    else -> android.graphics.Color.argb(180,
                        (ink.red*255).toInt(),(ink.green*255).toInt(),(ink.blue*255).toInt())
                }
                val w = paint.measureText(word); val h = fontSizePx
                var t = 0.0; var rectFound: Rect? = null
                while (t < 200.0) {
                    val r = 4.0 * t
                    val x = center.x + r * cos(t) - w / 2
                    val y = center.y + r * sin(t) + h / 2
                    val rect = Rect(x.toFloat(),(y-h).toFloat(),(x+w).toFloat(),y.toFloat())
                    if (rect.left>0 && rect.top>0 && rect.right<size.width
                        && rect.bottom<size.height && placed.none { it.overlaps(rect) }) {
                        rectFound = rect; break
                    }
                    t += 0.15
                }
                rectFound?.let {
                    canvas.nativeCanvas.drawText(word, it.left, it.bottom, paint)
                    placed.add(it)
                }
            }
        }
    }
}

13.1 BackupManager

util/BackupManager.kt 
package com.yourname.echo.util

import android.content.ContentValues
import android.content.Context
import android.net.Uri
import android.os.Build
import android.os.Environment
import android.provider.MediaStore
import com.yourname.echo.data.BackupBundle
import kotlinx.serialization.encodeToString
import kotlinx.serialization.json.Json
import java.io.File
import java.io.FileOutputStream

object BackupManager {
    private val json = Json { prettyPrint = true; ignoreUnknownKeys = true }

    fun export(ctx: Context, bundle: BackupBundle): String {
        val text = json.encodeToString(bundle)
        val name = "echo-backup-${'$'}{System.currentTimeMillis()}.json"
        return if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
            val values = ContentValues().apply {
                put(MediaStore.Downloads.DISPLAY_NAME, name)
                put(MediaStore.Downloads.MIME_TYPE, "application/json")
                put(MediaStore.Downloads.RELATIVE_PATH,
                    "${'$'}{Environment.DIRECTORY_DOWNLOADS}/Echo")
            }
            val uri: Uri = ctx.contentResolver
                .insert(MediaStore.Downloads.EXTERNAL_CONTENT_URI, values)!!
            ctx.contentResolver.openOutputStream(uri)!!
                .use { it.write(text.toByteArray()) }
            uri.toString()
        } else {
            val dir = File(Environment.getExternalStoragePublicDirectory(
                Environment.DIRECTORY_DOWNLOADS), "Echo")
            if (!dir.exists()) dir.mkdirs()
            val f = File(dir, name)
            FileOutputStream(f).use { it.write(text.toByteArray()) }
            f.absolutePath
        }
    }

    fun import(ctx: Context, uri: Uri): BackupBundle {
        val text = ctx.contentResolver.openInputStream(uri)!!
            .bufferedReader().use { it.readText() }
        return json.decodeFromString(text)
    }
}

    }

    ) { uri -> uri?.let { vm.import(it) } }

    Scaffold(
        topBar = { TopAppBar(title = { Text("我的") }) },
        snackbarHost = { SnackbarHost(snackbar) }
    ) { p ->
        Column(Modifier.padding(p).padding(24.dp)) {
            Text("Echo · v0.1.0", style = MaterialTheme.typography.titleLarge)
            Text("Listen to your own voice.",
                style = MaterialTheme.typography.bodyMedium.copy(fontStyle = FontStyle.Italic))
            Spacer(Modifier.height(32.dp))
            ListItem(
                headlineContent = { Text("导出数据 (JSON)") },
                supportingContent = { Text("保存到 Download/Echo/") },
                modifier = Modifier.clickable { vm.export() }
            )
            HorizontalDivider()
            ListItem(
                headlineContent = { Text("导入数据") },
                supportingContent = { Text("从 .json 备份恢复") },
                modifier = Modifier.clickable {
                    pickFile.launch(arrayOf("application/json"))
                }
            )
            HorizontalDivider()
            ListItem(
                headlineContent = { Text("数据存储位置") },
                supportingContent = { Text("应用私有目录 echo.db") }
            )
            Spacer(Modifier.weight(1f))
            Text("聆听心的声音",
                style = MaterialTheme.typography.titleMedium,
                modifier = Modifier.fillMaxWidth(),
                textAlign = TextAlign.Center)
        }
    }
}
里程碑 4 达成：导出 JSON → 卸载重装 App → 导入 JSON，数据完整恢复。Echo 全部核心功能完成。

STAGE / 14打包发布与后续路线

14.1 生成签名 APK

  1. 菜单 Build → Generate Signed App Bundle / APK。
  2. 选 APK（不是 Bundle，自用更方便）。
  3. 第一次没有 keystore，点 Create new，填写：
    • Key store path：选个安全位置，命名 echo-release.jks
    • Password：自己设一个，务必记住，丢了就不能继续发版
    • Alias / Validity：随便填，有效期至少 25 年
  4. 下一步选 release，签名版本勾选 V1 + V2，点 Finish。
  5. 等几分钟，APK 出现在 app/release/app-release.apk，可以发到任何 Android 手机安装。

14.2 测试清单

  • 四个 Tab 都能打开，无崩溃
  • 情绪页输入文字 → 历史里能看到
  • 状态页滑动柱子 → 数字与高度同步变化
  • 状态页杀进程重开 → 今日数据仍在
  • 流动页切换"7/30/90 天"按钮 → 词云重绘
  • 流动页有数据时词云不重叠不溢出
  • 导出 JSON → 文件管理器在 Download/Echo/ 找得到
  • 清除应用数据 → 导入 JSON → 数据恢复
  • 飞行模式下完整流程不崩溃（验证完全离线）

14.4 当你卡住时

  1. 看 Logcat：菜单 View → Tool Windows → Logcat，搜 FATAL 或 AndroidRuntime，红色那行就是错误源头。
  2. 把错误第一行原样 Google：90% 的问题前人都遇到过，Stack Overflow 上有答案。
  3. 把整段错误贴给我：包括 Logcat 里 Caused by: 后面的内容，我来帮你逐条诊断。
  4. 定期 Git 提交：每完成一个 Stage 就 git commit 一次，出问题随时可以 git reset --hard 回滚。
