📖 产品介绍

⚡ 核心功能

🔍
智能设备发现
基于UDP广播自动发现局域网内所有在线设备，无需手动配置IP地址
⏻
一键远程关机
支持单设备和批量设备远程关机，带确认机制，防止误操作
💓
实时心跳检测
30秒心跳间隔，实时监控设备在线状态，设备掉线即时告警
🔒
安全认证机制
基于密钥的身份验证，确保只有授权控制端才能发送命令

🏗️ 技术架构

🔌
TCP/IP + UDP混合架构
UDP广播发现 + TCP可靠传输，确保高效稳定的通信
📡
端口9999监听
单端口设计，简化防火墙配置，方便企业部署
📦
JSON消息协议
标准化消息格式，便于扩展和维护
🐍
Python + Tkinter
跨平台支持，图形化界面，操作简单直观

→
2

  • ● 请确保控制端和被控端在同一局域网内
  • ● 被控端需要管理员权限运行
  • ● 建议修改默认密钥以提高安全性
  • ● 本工具仅限用于已授权的设备和场景
