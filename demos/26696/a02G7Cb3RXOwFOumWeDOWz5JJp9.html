核心功能

一站式网页自动化解决方案，覆盖从数据采集到批量处理的全部场景

👆

可视化动作编排

拖拽式流程设计，支持点击、输入、悬停、上传、滚动等 20+ 种动作类型，轻松构建复杂自动化任务。

🎯

智能元素选择器

可视化点选页面元素，自动生成稳定 CSS 选择器，支持 iframe 嵌套场景，精准定位目标元素。

🔀

多流程管理

创建、复制、重命名、切换多个工作流程，按项目场景分类管理，支持流程模板导入导出。

📊

变量与数据系统

支持静态变量、页面提取变量、模板变量替换，Excel/CSV 批量导入，实现数据驱动自动化。

🔁

循环与条件判断

表格循环、列表循环、条件分支，结合子流程批处理能力，应对复杂业务逻辑与数据遍历场景。

⏰

定时任务调度

支持一次性、每日、每周、工作日定时执行，内置闹钟调度引擎，无需值守自动运行流程。

📸

截图与数据导出

全页截图、可视区域截图，配合 Excel/CSV 数据导出，自动化结果留存与报告生成一步到位。

🔐

跨页面执行引擎

后台 Service Worker 协调动作执行，支持标签页打开/关闭/切换，跨导航场景稳定运行。

四步构建自动化流程

无需编程知识，零基础也能快速上手

1

📝 创建流程

点击扩展图标打开侧边栏，创建一个新的工作流程，为其命名并关联目标网址。

2

🎯 选择元素

使用元素选择器在页面上点选目标元素，系统自动生成稳定的 CSS 选择器。

3

⚡ 编排动作

添加动作步骤（点击/输入/提取等），配置参数与变量，按顺序组合完整流程。

4

🚀 运行与定时

点击运行测试流程正确性，配置定时任务后让自动化 24/7 不间断执行。
