创意名称 · 产品由来

趣游旅行：种草之后，就是出发

一款嵌入抖音生态、基于高德地图 SDK 的旅游路线动态规划与智能推荐轻应用（抖音小程序）。

💡 想解决什么问题

种草容易，规划难

用户在抖音刷完旅游种草视频后，难以快速将分散的打卡点转化为合理的游玩路线；且缺乏能动态调整行程、智能评估游玩时间与住宿衔接的轻量级规划工具。

# 多点路径规划 # 动态路线调整 # 时间智能评估
🎯 为什么想到做这个

切出 App 挨个查，割裂感爆棚

本人在抖音上刷到旅游景点种草视频，并有自驾旅行计划，但需要切出 App 去地图上一个个手动找点、查距离、算时间，切换体验割裂，做攻略极其费时。何不把"种草—规划—出发"串成一条线？

# 抖音种草生态 # 自驾游/自由行 # 轻量化小程序
目标用户 · 当前痛点

传统攻略 vs 趣游旅行

习惯用短视频获取旅游灵感的年轻群体（18-35 岁），最烦的就是"刷完视频，行程还是没谱"。

😓

传统地图 App

手动逐个搜索、人工脑补
  • 需手动逐个搜索打卡点，无法基于已选点位推荐周边美食与景点
  • 游玩时间估算、"继续玩 vs 去住宿"决策全靠人工脑补
  • 新增/删除一个点位 → 路线顺序与行程时间全部推倒重算
  • 抖音种草 → 切 App 查地图 → 再切回来查住宿，割裂感极强
✨

趣游旅行（抖音小程序）

所见即所行，秒级排布
  • 在抖音视频一键"加入行程"，自动聚合到路线画布
  • 基于高德 SDK 自动计算驾车/步行时间与游玩时长，智能排程
  • 增删点位 → 路线与时间动态刷新，毫秒级重排
  • 无缝接入本地生活（酒旅/团购），一站式"种草→下单"
核心功能

六大能力，撑起一条满意的路线

从短视频种草到驾车出发，每一步都被考虑到——轻、快、智能。

🗺️

多点动态路线规划

支持多个打卡点的最优路径规划，基于高德驾车/步行/公交数据，自动推荐合理顺序与路线。

⏱️

时间智能评估

结合点位热度、时间段与历史游玩数据，自动估算停留时长，提醒当前行程是否"赶得及"。

🏨

住宿衔接建议

基于当日行程终点与次日起点，智能推荐合适的住宿区域与酒店，并可直通抖音本地生活。

🍜

周边美食/景点推荐

在每一段行程之间，推荐评分高、与顺路方向匹配的美食与景点，可一键加入行程。

🎬

视频一键"加入行程"

刷到抖音种草视频时，识别视频中的地点并一键收藏，自动汇集到路线画布。

🚗

自驾优先体验

面向自驾用户提供油费/过路费预估、沿途服务区提醒与"一键导航到下个点位"。

使用演示

四步，走完一次"成都一日游"

从刷视频到出门，整个过程就在抖音里完成，无需切换应用。

📱 典型使用路径

用户在抖音刷到成都攻略 → 趣游旅行识别视频中的打卡点 → 用户一键收藏 → 系统自动排序生成最佳路线 → 中途可随时增删，行程自动刷新。

4

一键导航 · 本地生活下单
