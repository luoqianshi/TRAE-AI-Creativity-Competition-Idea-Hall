Core Features

核心功能模块

帮助用户每天完成一件低负担、可执行的小事，解决生活混乱时不知从何开始的痛点

🏠

首页

应用入口，展示四个主要功能入口：生成今天的小事、找生活搭子、睡前收纳、查看本周报告

📋

状态选择

用户回答三个问题：当前精力状态、混乱来源、可用时间，AI据此生成个性化任务

✨

今日小事

根据用户状态智能生成适合当前情况的小任务，包含任务原因和执行步骤

🎉

完成反馈

任务完成后获得正向反馈和鼓励，强化用户的成就感

👥

生活搭子

邀请好友一起完成任务、让搭子帮忙选择、获得轻确认支持

🌙

睡前收纳

整理一天的混乱，准备迎接明天，给出收纳建议和鼓励

📊

本周报告

回顾一周完成的小事，查看进步和收获，获得下周建议
