L
Agent Loop · ReAct
会自主调工具

每个角色内部跑“思考→调工具→观察→再思考”的循环：研究员会自己决定“这个期权条款要查证”，调用 retrieve 检索知识库，不够再查，多轮迭代后才产出。对标 Claude Code 的 agent loop——这不是 5 次带不同 prompt 的 LLM 调用，是 5 个能自主用工具的智能体。

V
Verifier · 独立校验
防幻觉的守门员

借鉴 Codex 的 Guardian 模式：一个独立的 LLM 在每条数据性论点写入白板前核查引用真伪。无引用的断言打“未验证”标记（质疑派优先攻击），编造的数据直接打回重做。把“防幻觉”从口号变成机制。

M
Memory · 团队记忆
越用越懂你

小队共享同一份用户画像与历史决策。研究员查到的数据质疑派能立刻引用，教练总结的偏好风险官能直接调用——这是“团队记忆”，单 Agent 的私有记忆做不到。硬约束（如“不接受异地”）作为不可违背前提注入所有角色。

K
Knowledge · 可追溯
每条数据有据可查

论点引用的数据必须标注知识库来源（knowledgeId），点开可看证据原文与可信度等级。乐观派与质疑派引用同一条数据却得出相反结论时，系统标记“解释分歧”，让辩论聚焦“如何解释”而非“事实是什么”。
