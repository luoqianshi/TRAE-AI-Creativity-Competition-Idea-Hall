创意名称：屏选 ScreenVote —— 智能投屏投票决策系统

想解决什么问题：当一群人围在电视前想投屏看点什么，每个人手机里装的视频平台各不相同， 会员权益分散在不同 App，经常陷入"你想看这个、我想看那个、谁有会员"的尴尬循环。需要一个工具来快速聚合群体意愿，并智能匹配可用的投屏资源。

💡

为什么会想到做这个？

每次朋友来家里聚会，投屏环节总要花 10 分钟讨论看什么。A 只有 B 站大会员，B 刚买了腾讯视频季卡，C 只有爱奇艺……最后往往是随便找个免费内容凑合看。这种"众口难调 + 会员分散"的痛点，几乎每个年轻人都经历过。

📱

产品形态

手机端投票决策 App + 智能投屏中间件（软件方案，兼容主流电视系统 / 投屏协议）。

所有手机扫码或靠近 NFC 加入房间 → 发起投票 → 票数最高内容自动匹配可用会员 → 一键投屏到电视。

核心交互流程

① 发起人创建"投屏房间"，生成二维码 / NFC 碰一碰加入

② 每位成员提交 1–3 个想看的影片（支持搜索或从各平台同步）

③ 全员实时匿名投票，进度条直观显示排名

④ 票数最高的内容自动检测谁有对应平台的会员，优先使用在线者的会员投屏

⑤ 一键推送至电视，无需手动切换账号

✦ TECH

硬件交互方案

📡

投屏协议兼容

基于 DLNA / AirPlay / Miracast 等标准投屏协议，覆盖市面上 95% 以上的智能电视与电视盒子。无需额外硬件，纯软件方案。

🔄

NFC 碰一碰加入

支持 NFC 标签贴于电视边框或遥控器上，手机碰触即加入投屏房间，降低多人连接门槛。这是硬件交互的核心触点。

🔐

会员凭证托管

用户授权绑定各视频平台会员（通过 OAuth 或共享验证），系统仅在投屏时临时调用，不在本地留存敏感信息。

📊

投票引擎

实时 WebSocket 多人投票，支持 Borda Count 计分制（每人可投多票权重不同），防止刷票，保证民主公正。
