为什么需要
一台实体设备？

软件版让你零成本体验 Vibemate，硬件版则把体验从屏幕里解放出来，让它真正成为一个桌面对象。

01

永远在线

不需要占用手机、不需要担心旧设备电池鼓包或充电线凌乱。插上 USB-C，它就是你工位上恒定存在的情绪灯塔。

02

专属实体交互

金属旋钮调节亮度与音量，两个实体按键直接确认/拒绝授权，扬声器提供可选的状态音反馈。这些体验是触屏无法替代的。

03

设计与品质

Soft-touch 米白机身、铝合金支架与旋钮、隐藏式走线槽，让 Vibemate Hardware 本身就是一件好看的桌面摆件。

硬件专属功能

这些功能只在 Vibemate Hardware 上提供，是旗舰版与软件版之间的核心差异。

◉

旋钮状态切换

旋转金属旋钮可在「表情 / 翻页时钟 / 天气 / 团队看板」之间切换，按下旋钮进入深度工作模式。

✓

一键授权硬件按键

橙色确认键与绿色取消键提供触觉反馈，TRAE、Claude Code 请求授权时无需看屏幕也能盲操作。

♪

状态提示音

任务完成时播放轻柔 chime，遇到错误时播放短促警示音，长时间运行中提供 subtle 心跳声，全部可独立关闭。

☀

环境光感应

内置光线传感器，自动根据桌面环境调整屏幕亮度与表情边缘呼吸灯强度，夜晚不刺眼，白天清晰可见。

⏻

离线独立运行

内置 Wi-Fi 模块与缓存，即使主电脑短暂休眠或重启，Hardware 仍可显示最后状态并在重新连接后秒级同步。

👥

团队看板 Mode

旋转到团队看板档位，可显示多台电脑、多个 AI 工具的整体状态（Hardware 独占，软件版需 Phase 3 才支持）。
