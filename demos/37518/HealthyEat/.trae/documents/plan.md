# 《吃出健康：宝妈饮食与情绪助手》—— 实现方案

## 一、项目定位与目标用户

- **产品名称**：吃出健康：宝妈饮食与情绪助手
- **产品形态**：单页网页工具（SPA），纯前端即可运行，无需登录
- **目标用户**：已生育的宝妈（25–40 岁），日常关注孩子饮食、家庭剩菜、自身身材管理与情绪稳定
- **核心价值**：在"怕浪费 → 吃剩菜 / 节食 / 暴食"的循环中，用温柔的 AI 提醒+可操作方案+正向打卡，帮助妈妈们吃得更健康、更安心
- **语气调性**：温暖治愈、理解接纳、不评判、朋友式陪伴

## 二、三大功能区概述

页面采用"一屏三个卡片"式布局，三个功能区并排展示，用户可按任意顺序点击展开。

### 功能一：剩菜大变身（解决"怕浪费"）
- **交互**：文本输入框 + 提交按钮；提供常见食物快捷标签（米饭 / 面条 / 肉类 / 蔬菜）一键填充
- **AI 响应**：根据输入关键词匹配预设的"低卡改造方案"，输出一段温馨话术 + 具体做法步骤 + 热量对比
- **数据来源**：前端内置关键词映射表（例如"米饭""排骨""红烧肉""面条""炒蛋"等常见词），命中后给出对应方案；未命中则给出通用方案
- **保留历史**：最近 3 次改造建议保存在 localStorage，可回看

### 功能二：情绪急救站（解决"过度节食 / 暴食"）
- **交互**：4 个大按钮（"今天好累，想吃点甜的""带娃崩溃，只想塞东西""想吃咸口重口味""只是想找人夸夸我"）；按钮即触发，无需输入
- **AI 响应**：每个按钮对应 2–3 套话术+替代方案，随机轮换，避免重复；输出包含：
  - 心理按摩（肯定用户情绪）
  - 无罪恶感替代食物建议（具体、可买、低 GI/低糖/高蛋白）
  - 温柔提示（"允许自己放松"）

### 功能三：自我关怀打卡
- **交互**：文本输入 + 打卡按钮；显示今日是否已打卡；下方展示"最近 7 天打卡流"
- **AI 响应**：基于输入内容（匹配关键词"睡/早/运动/水/饭"等）给出定制正向反馈；未命中关键词则给出通用鼓励
- **数据持久化**：每日一条，使用 localStorage 存储（key = `self_care_checkins`），最多保留 30 条

## 三、设计系统（视觉风格）

### 色彩方案（温馨治愈）
- **主色 A 暖黄色调**：`#F7D9A3`（米黄）、`#F6C06B`（蜂蜜色）、`#E9A45D`（暖橙，主色）
- **主色 B 浅绿色调**：`#CFE8C7`（薄荷）、`#8EC28B`（嫩芽绿，点缀）
- **背景**：`#FFFAF0`（奶油白），页面整体柔和干净
- **卡片背景**：`#FFF8E7` → `#FFF2CC` 轻微渐变
- **文字**：主文本 `#4A3A28`（深棕），辅助文本 `#8B7B5E`（土黄）
- **危险/警示**：避免，全站不使用红色强调

### 字体
- **标题**：`"Noto Serif SC", "Songti SC", serif`（衬线体，温润感）
- **正文**：`"Noto Sans SC", "PingFang SC", sans-serif`（现代无衬线，阅读友好）
- **字号**：标题 28–36px，正文 15–17px，按钮 16px

### 形状与质感
- 卡片圆角 `20px`，按钮圆角 `14px`
- 使用柔和的外阴影（`0 8px 24px rgba(233, 164, 93, 0.12)`）营造漂浮感
- 背景添加淡色噪点（`url("noise.png")` 或 CSS 渐变模糊），避免单调
- 所有卡片带"呼吸动画"：hover 轻微放大 + 颜色加深

## 四、技术选型

- **前端框架**：原生 HTML + CSS + JavaScript（无需构建工具，直接双击 index.html 即可运行）
  - 理由：功能以本地文本匹配 + localStorage 为主，无需服务器，便于移植和离线使用；降低项目复杂度
- **本地数据**：localStorage 存储用户历史
- **图片资源**：使用 `text_to_image` API 生成 1 张页面顶部 banner 图（"温馨厨房，妈妈与孩子在暖光下"）
- **图标**：纯 CSS + Unicode emoji，避免引入第三方依赖
- **响应式**：移动端优先，1024px 以上三列并排；移动端切换为单列纵向滚动
- **无障碍**：
  - 所有交互元素可 Tab 聚焦
  - 关键按钮有 `aria-label`
  - 色彩对比度 ≥ 4.5:1
  - 按钮最小点击面积 ≥ 44x44px

4. **实现功能二：情绪急救站**
   - 实现 4 个情绪按钮 + 点击随机命中一套话术

7. **本地联调与校验**
   - 用实际输入测试三条功能流，确认话术不重复且与用户示例风格一致

   - 检查色彩对比度和 Tab 键可达性

## 八、潜在风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 用户输入的菜名不在关键词表中 | 高 | 中 | 提供"_default"通用方案，话术提示妈妈可自由搭配 |
| 话术重复导致用户厌倦 | 中 | 中 | 每个情绪按钮配置 2–3 套话术，随机选取；首次匹配关键词后，下次同词换风格 |
| localStorage 被禁用 | 低 | 低 | 打卡功能降级为仅本次会话展示，不影响核心体验 |
| 移动端按钮过大/过小 | 中 | 低 | 移动端优先设计，按钮使用 em/rem，设置最小 44px 触摸区域 |
| 色彩过于"儿童化"导致用户觉得不专业 | 中 | 中 | 使用深棕主文本色平衡暖黄，字体选用衬线 + 现代无衬线组合，控制动画烈度 |
