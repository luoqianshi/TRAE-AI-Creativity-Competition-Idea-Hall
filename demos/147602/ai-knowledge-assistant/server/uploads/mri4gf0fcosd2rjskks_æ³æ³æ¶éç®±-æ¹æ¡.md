# 想法收集箱（Ideas Inbox）设计方案

## 功能概述

一个用于收集、追踪和推进个人项目/想法的管理系统。每个想法是一个独立 md 文件，支持百分比进度 + 阶段双模式追踪（水平时间轴可视化），每日进度日志记录，并在首页有入口卡片 + 独立概览页。

---

## 1. 文件结构

```
Calendar/
  Ideas/                          ← 新建文件夹，存放所有想法项目
    index.md                       ← 独立概览页（所有项目仪表盘）
    2026-07-13 做一个好看的相册网页.md   ← 每个想法一个文件
    ...
Templates/
  TEMPLATE-Idea.md               ← 项目模板（Templater 模板，放在 Templates 才能被识别）
```

> 想法项目放在 Calendar/Ideas 下，模板放在 Templates/ 下（Obsidian Templater 要求模板在 Templates 文件夹）。

---

## 2. 项目模板（Templates/TEMPLATE-Idea.md）

每个新建的想法文件自动填充以下结构：

### Frontmatter 属性

```yaml
---
home: "[[Home]]"
idea_date: 2026-07-13           # 创建日期
progress: 0                     # 百分比进度（0~100）
stage: 构思                      # 当前阶段名称
stage_index: 1                   # 阶段序号（从1开始）
stages:                          # 自定义阶段列表（可增删改）
  - 构思
  - 规划
  - 执行
  - 测试
  - 完成
---
```

### 正文结构

````markdown
# {项目名称}

## 项目描述
> 简要描述这个想法是什么，为什么想做。

## 进度
**当前进度：{progress}%**  |  **阶段：{stage_index}/{总阶段数} — {stage}**

```dataviewjs
// 水平时间轴 — 从 frontmatter 读取 stages 和进度日志自动提取日期
// 详见第 3 节
```

## 进度日志
### 2026-07-13
- 阶段：构思
- 今日进展：
- 明日计划：

### 2026-07-14
- 今日进展：完成了首页布局和图片加载逻辑
- 明日计划：加入动画效果
- 阶段切换：规划 → 执行

## 计划
> 记录项目的整体规划、里程碑、关键步骤等。

## 备注
> 其他想到的内容随时记录。
````

## 3. 阶段时间轴可视化

### 3.1 水平时间轴样式

每个节点从左到右排列，用圆点和连接线串联：

```
  ○──────●──────○──────○──────○
 构思    规划    执行    测试    完成
07-13   07-15
```

- 已完成阶段：实心圆 + 有颜色的连接线
- 当前阶段：实心圆 + 发光效果
- 未来阶段：空心圆 + 灰色连接线
- 每个节点下方显示阶段名称 + 进入该阶段的日期

### 3.2 项目文件内的时间轴

在项目文件的「进度」区域，通过一段 DataviewJS 代码自动渲染：

- 读取当前文件的 `stages` 和 `stage_index`
- 扫描正文中的进度日志，自动提取每个阶段的日期
- 渲染水平时间轴 HTML

**日期提取规则**（从进度日志中自动识别）：
- 第一条日志的日期 → 第一阶段的日期（项目创建日）
- 当日志中出现 `- 阶段切换：X → Y` 时，记录切换目标阶段 Y 的日期
- 当日志中出现 `- 阶段：X` 时（模板默认第一行），标记该阶段

> 用户只需在日志中按格式写 `- 阶段切换：规划 → 执行`，时间轴自动识别。

### 3.3 概览页卡片内的时间轴

概览页每个项目卡片中也展示一个紧凑版水平时间轴：
- 圆点更小（直径缩小）
- 只显示阶段名称，不显示日期（节省空间）
- 当前阶段同样高亮

### 3.4 CSS 样式

所有时间轴样式统一放在 `.obsidian/snippets/idea-progress.css` 中，包括：
- `.idea-timeline` — 时间轴容器（flex 水平布局）
- `.idea-timeline-node` — 单个节点（圆点 + 名称 + 日期）
- `.idea-timeline-line` — 节点间连接线
- `.idea-timeline-completed` / `.idea-timeline-current` / `.idea-timeline-future` — 三种状态
- `.idea-timeline-sm` — 概览页紧凑版

## 4. 阶段系统

- 默认提供 5 个阶段：`构思 → 规划 → 执行 → 测试 → 完成`
- **完全自定义**：用户可以在 frontmatter 的 `stages` 字段中修改阶段名称和数量
- 例如可以改为 3 阶段：`想法 → 开发 → 收尾`
- `stage_index` 标记当前处于第几阶段，时间轴据此确定高亮位置
- 阶段日期从进度日志自动提取，无需手动维护

---

## 5. 每日进度日志

在项目文件内的「进度日志」区域，按日期倒序追加：

```markdown
### 2026-07-13
- 阶段：构思
- 今日进展：完成了相册网页的 UI 设计稿
- 明日计划：开始写前端 HTML 结构

### 2026-07-15
- 今日进展：完成了整体架构设计，确定了技术栈
- 明日计划：开始写前端 HTML 结构
- 阶段切换：构思 → 规划

### 2026-07-18
- 今日进展：完成了首页布局
- 明日计划：加入动画效果
- 阶段切换：规划 → 执行
```

日志中如果发生了阶段切换，只需加一行 `- 阶段切换：当前阶段 → 新阶段`，时间轴会自动识别。

## 6. 概览页（Ideas/index.md）

概览页功能：

- **顶部统计**：项目总数、进行中数量、已完成数量
- **项目卡片列表**：每个项目一张卡片，展示：
  - 项目名称（可点击打开）
  - 紧凑版水平时间轴（圆点 + 阶段名，当前阶段高亮）
  - 进度条 + 百分比
  - 最后更新时间
  - 删除按钮（hover 显示）
- **搜索栏**：按项目名称搜索过滤
- **筛选**：按阶段筛选（全部 / 构思 / 规划 / 执行 / 测试 / 完成）
- **新建按钮**：一键使用模板创建新想法项目

整体风格与现有「生活备忘」页面保持一致，复用现有的 CSS 类。

---

## 7. 首页入口

在 `Home.md` 的「知识板块」区域新增一个卡片：

```
{ name: "想法收集", icon: "🚀", folder: "Calendar/Ideas", color: "#38bdf8", desc: ["项目","想法"] }
```

点击后进入 `Calendar/Ideas/index.md` 概览页。

---

## 8. 创建新项目的方式

- 概览页有「新建想法」按钮
- 点击后使用 Templater 模板 `Templates/TEMPLATE-Idea.md` 创建新文件
- 文件名格式：`{日期} {项目名称}.md`（如 `2026-07-13 好看的相册网页.md`）
- 创建后自动打开编辑
