该架构支持多渠道接入和智能路由分配。

占位块说明：

• 背景色：#F3F8EC（浅绿色）

• 边框：rgba(0, 142, 107, 0.08)

• 圆角：8px

• 内边距：16px 20px

• 显示内容：图片图标 + alt 文本（加粗）+ URL（灰色等宽字体）

• 最大宽度：100%，自动换行

技术实现要点

链接预览：

• 使用 CodeMirror 的 hoverTooltip 扩展

• 检测 Markdown 链接语法 [text](url)

• 鼠标悬停时创建 Tooltip DOM 元素

• Tooltip 包含链接文本和完整 URL

图片预览：

• 使用 CodeMirror 的 Decoration 系统

• 检测 Markdown 图片语法 ![alt](url)

• 将图片语法替换为占位块 DOM 元素

• 占位块显示图片图标、alt 文本和 URL
