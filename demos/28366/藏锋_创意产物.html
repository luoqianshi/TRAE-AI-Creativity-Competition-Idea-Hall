二、藏锋如何工作

它夹在你和 AI 之间，做 4 件事：脱敏 → 投喂 → 还原 → 审计。

01

读真代码

读取你本地真实 Java 项目，AST 解析符号表。

→
02

智能脱敏

类名 / 方法名 / 字符串 / 业务字段被替换为占位符；保留控制流与类型关系。

→
03

投喂 AI

脱敏代码 + 你的需求 → 安全发给 TRAE / DeepSeek / Claude / 通义。

→
04

反向还原

AI 返回的脱敏代码自动映射回真实命名，无缝合入项目。

三、四个差异化亮点

🛡

智能脱敏引擎

基于 AST 的语义保持替换：保留控制流、类型关系、调用图谱，让 AI 仍能精准理解架构，回答质量不降级。

🔁

双向映射还原

本地不可逆映射表 + 增量学习；AI 生成的新符号以 <NEW_xxx> 占位，一键命名落盘。

🤖

AI 中立适配

兼容 TRAE / DeepSeek / Claude / 通义 / Cursor，不绑定任何模型，开发者自由选最强模型。

📊

脱敏审计报告

每次脱敏自动产出可审计报告（保护词数量、密钥未外泄证明），让企业安全团队放心。
