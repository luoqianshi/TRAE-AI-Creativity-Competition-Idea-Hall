架构

分离架构：极致降本

调度与存储分离，服务器配置压到最低 1 核 2G，实际流量由对象存储 CDN 承载

🖥️
调度服务器 1 核 2G
职责：接收上传、解压校验、生成 URL、302 重定向调度、访问日志记录
不职责：不存储文件、不执行构建、不承载流量
技术栈：Node.js (Express) 或 Go (Gin)
⬆ ⬇
☁️
对象存储（核心存储层）OSS/COS/S3
职责：存储所有静态文件，承载实际访问流量（CDN 加速）
优势：海量存储、按量付费、自带 CDN、高可用
选型：阿里云 OSS / 腾讯云 COS / AWS S3
⬆ ⬇
🗄️
数据库 SQLite / Postgres
职责：存储项目元数据（URL 映射、上传者、过期时间）、访问统计、错误日志
选型：SQLite（轻量）或 PostgreSQL（扩展性）
⬆ ⬇
🎨
前端看板 Vue3 / React
职责：上传者管理界面、统计看板、错误监控
技术栈：Vue3 / React + TailwindCSS，由 TRAE 生成

💡 访问链路详解

1. 访客访问 playground.com/p/abc123
2. 调度服务器查询数据库，获取 abc123 对应的对象存储路径
3. 调度服务器返回 302 重定向到对象存储公开链接
4. 访客浏览器直接从对象存储（CDN）加载静态资源
5. 调度服务器异步记录访问日志（IP、UA、Referer、时间）
