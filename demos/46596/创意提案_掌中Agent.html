第一部分

创意名称 + 创意介绍

💡 创意名称：掌中 Agent

电脑上的 Agent 只能依赖云端 API，数据必须上传、断网就瘫痪。手机 Agent 却可以云端 + 本地双模式自由切换， 敏感数据用本地模型保护隐私，日常任务用云端 API 获得最强能力——手机才是真正有选择权的 Agent 载体。

掌中 Agent 是一款原生运行在手机上的 AI 智能体。它通过 Android 无障碍服务操作任意 App、通过 HTTP MCP 远程控制电脑、通过 Termux 本地跑脚本 —— 让 Agent 真正属于你，随身携带，随时工作。

🎯 想解决什么问题

1. Agent 被电脑绑住：现在的 AI Agent 都跑在电脑上，离开电脑就无法工作
2. 电脑 Agent 没有隐私选择权：只能走云端，敏感数据也得上传，用户毫无选择
3. 断联即瘫：电脑 Agent 一断网就完全瘫痪，而手机可以无缝切换到本地模型继续工作
4. 电脑被位置绑住：它重、它大、不能随身带，出门在外电脑不在，Agent 就停了

💭 为什么会想到做这个

有一天我突然意识到：电脑 Agent 只有云端一条路，手机 Agent 却可以云端和本地双模切换。 既然手机有更多选择，为什么要让 Agent 住在又大又重的电脑上？手机才是 24 小时陪在我们身边、永远在线的设备。 而且手机有电脑没有的能力：无障碍服务、传感器、通信能力。这些都是电脑 Agent 永远做不到的。

📦 大概是什么产品

一款Android 原生 App，运行在你的手机上。它可以是你的私人助理、效率工具、自动化脚本执行器。 配上 Termux 还能跑完整的 Linux 环境，通过 HTTP MCP 还能控制你的电脑。 简单说：一个 App，相当于一个随时待命的 AI 员工。

第二部分

目标用户及痛点

👥 面向哪些用户

核心用户群体：喜欢折腾效率工具的极客 + 需要远程控制电脑的技术人员。
次要用户：隐私敏感用户、移动办公族。
传播方式：作为一个圈子传播的小工具，因为手机 Agent 的权限很敏感，进一步推广可能需要安卓系统官方支持。

⏰ 在什么场景下使用

• 通勤路上用手机远程控制公司电脑处理紧急工作
• 睡觉前设置定时任务，让 Agent 凌晨自动跑数据备份、爬虫、报表
• 出差时电脑不在身边，只带手机也能完成所有基本工作
• 处理敏感数据时自动切换到本地模型，绝对隐私安全
