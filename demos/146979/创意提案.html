项目简介

PokerCoach AI 是一款基于大语言模型的智能扑克决策助手。用户只需对牌桌截图，系统即可通过计算机视觉自动识别牌面信息，结合 5 层 Skill 策略引擎，在 5 秒内给出符合 GTO（Game Theory Optimal）标准的职业级决策建议。

本项目基于清华大学 PokerSkill 论文思想复现，并集成了 OCR 视觉识别、动作重建、DeepSeek 策略推理等模块，形成完整的端到端决策管道。

❗
解决什么问题

入门门槛极高

德州扑克的 GTO 策略需要数年学习，普通玩家难以掌握复杂的翻前范围、翻后牌力评估和诈唬频率。

实时决策困难

牌桌上时间有限，玩家需要在几十秒内完成读牌、计算赔率、评估对手范围并做出决策，极易出错。

Solver 使用复杂

专业 GTO Solver（如 GTOWizard）需要手动输入牌局状态，操作繁琐且无法实时使用。

学习反馈缺失

普通玩家打牌后缺乏复盘工具，不知道自己哪里打错了，无法持续进步。

⚡
解决方案

PokerCoach AI 通过「视觉识别 + 动作重建 + 策略引擎」三步走，将复杂的 GTO 决策简化为「拍照 → 分析 → 决策」：

1

OCR 视觉识别

OpenCV 模板匹配识别手牌和公共牌（精度 100%），Tesseract OCR 读取底池/筹码（精度 90%），HSV 色彩过滤自动识别花色，全程无需人工输入。

2

动作重建

通过多帧序列分析，自动重建 action_history，还原翻前到当前街道的完整下注过程，为策略分析提供完整上下文。

3

5 层 Skill 策略引擎

P1 系统角色 → P2 翻前 GTO 范围表 → P3 通用原则 → P4 手牌分级（13级）→ P5 河牌指导，逐层约束 LLM 决策空间，确保输出符合 GTO 标准。

4

DeepSeek 智能决策

调用 DeepSeek v4-flash 模型，平均 1.6 秒完成一次决策，输出 JSON 格式的动作（Fold/Check/Call/Raise）和详细理由。

🚀
核心技术亮点

cv2 模板匹配 + 花色预过滤

通过红色像素阈值区分红桃/方片，避免 Ts/Td 等相似牌混淆，手牌识别率达 100%。

白色密度定位裁剪

不依赖固定偏移，通过白色像素密度自动定位牌的实际位置，解决公共牌误识别问题。

多阈值 + 众数投票 OCR

底池识别使用 6 个阈值扫描 + psm6 全文识别 + 正则提取 + 众数投票，解决 BB 被误读为数字的问题。

PokerSkill 5 层 Skill

基于清华 PokerSkill 论文思想，构建 P1-P5 五层策略系统，零训练、零 Solver 查询即可达到专家级水平。

GTO 基准测试

集成 PokerBench 数据集（50 手 GTO 标准答案），可量化评估 AI 决策与 GTOWizard 的差异。

端到端 Pipeline

截图 → OCR → 重建 → Prompt → LLM → 解析，全流程自动化，平均 5 秒完成一次分析。

应用场景
  • 扑克学习：新手玩家通过 PokerCoach AI 了解每个牌局的 GTO 决策逻辑，加速学习曲线。
  • 实时辅助：在线扑克玩家截图即可获得决策建议，避免时间压力下的错误决策。
  • 赛后复盘：批量分析历史牌局，找出偏离 GTO 的决策点，针对性改进。
  • 策略研究：扑克教练用它快速验证不同牌局的理论最优解，辅助教学。
💡
创新点
  • 零门槛 GTO：首次将「拍照识别 + LLM 策略」结合，无需手动输入复杂牌局状态。
  • 可解释的 AI：每个决策附带详细理由，不是黑盒输出，而是可学习、可验证的教学工具。
  • Skill 约束而非 Fine-tune：不训练模型，而是通过结构化 Skill Prompt 约束 LLM 行为，成本低、可迭代快。
  • 端到端自动化：从截图到决策全自动，无需任何人工干预。
