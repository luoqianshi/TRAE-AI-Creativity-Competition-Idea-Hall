习惯养成宝

一款面向日常生活的习惯养成工具，通过设定目标、每日打卡、奖励激励的方式，帮助用户培养良好习惯，实现自我提升。

核心功能

目标管理

功能点 说明
创建目标用户可自定义目标名称、类型（次数/时长/数值）、目标值、单位、周期
目标类型支持三种类型：次数型（阅读页数）、时长型（运动分钟）、数值型（体重目标）
周期设置支持每天、每周、每月三种周期
奖励设定为每个目标设定完成后的奖励内容和奖励积分
图标颜色可为目标选择个性化图标和主题色

每日打卡

  • 1打卡记录：用户每日记录完成情况，输入具体数值
  • 2连续打卡：统计连续打卡天数，激励用户保持习惯
  • 3进度可视化：进度条直观展示完成百分比
  • 4今日锁定：每个目标每日只能打卡一次，防止重复打卡
  • 5备注功能：支持添加打卡备注，记录心情或感受

奖励系统

积分累计
完成目标后获得相应积分奖励
奖励商城
积分可兑换预设奖励（吃大餐、买衣服、看电影等）
解锁机制
部分高级奖励需达到一定条件才能解锁
等级系统
用户等级和经验值，增强游戏化体验

使用流程

首次使用

  1. 打开应用，查看预设示例目标
  2. 点击「新目标」创建自己的第一个目标
  3. 设置目标名称、类型、目标值、奖励等信息
  4. 选择喜欢的图标和颜色

每日打卡

  1. 打开应用，查看今日目标列表
  2. 点击目标卡片的「打卡」按钮
  3. 输入今日完成的数值
  4. 添加备注（可选）
  5. 点击「确认打卡」完成记录

达成奖励

  1. 当目标进度达到100%时，自动弹出庆祝弹窗
  2. 获得相应积分奖励
  3. 积分累积到一定数量后，可在奖励商城兑换奖励
