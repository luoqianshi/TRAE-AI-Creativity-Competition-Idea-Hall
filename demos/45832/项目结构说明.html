# 象棋残局库生成器 - 项目结构说明

## 📁 目录结构 (最终优化版)

```
E:\xiangqitb-master/
├── 可执行文件
│   ├── xiangqitb.exe          ← 后端主程序 (C++ 编译)
│   ├── ChessEGTB.exe          ← GUI 程序 (C# 编译)
│   ├── ChessEGTB.dll          ← GUI 程序库
│   └── ChessEGTB.pdb          ← 调试符号
│
├── 残局库文件夹
│   ├── wdl/                   ← 胜平负残局库 (.lzw 文件)
│   ├── dtc/                   ← 步数残局库 (.lzdtc 文件)
│   ├── dtm/                   ← 将死步数残局库 (.lzdtm 文件)
│   └── cdtm/                  ← 连将杀残局库 (.lzcdtm 文件)
│
├── 源代码
│   ├── src/                   ← C++ 后端源代码
│   │   ├── main.cpp           ← 主程序入口
│   │   ├── chess/             ← 象棋相关类
│   │   ├── egtb/              ← 残局库生成器
│   │   └── util/              ← 工具类
│   │
│   ├── MainForm.cs            ← C# GUI 主窗体
│   └── ChessEGTB.csproj       ← C# 项目文件
│
├── 库文件
│   └── lib/                   ← 第三方库
│       ├── lz4/               ← LZ4 压缩库
│       └── zstd/              ← ZSTD 压缩库
│
├── 配置文件
│   └── option.ini             ← 全局配置文件
│
└── 文档
    ├── 项目结构说明.md         ← 本文档
    ├── GUI 使用指南.md         ← GUI 使用说明
    └── 连将杀算法实现总结.md   ← 算法文档
```

## 🎯 文件层级说明

### ✅ 保留的文件夹 (1-2 层)
- `wdl/` - 胜平负残局库
- `dtc/` - 步数残局库
- `dtm/` - 将死步数残局库
- `cdtm/` - 连将杀残局库
- `src/` - 后端源代码 (2 层：`src/chess/`, `src/egtb/`, `src/util/`)
- `lib/` - 第三方库 (2 层：`lib/lz4/`, `lib/zstd/`)

### ❌ 已删除的文件夹
- `gui/` - 已删除，所有文件移到根目录
- `bin/` - 已删除，编译输出文件在根目录
- `obj/` - 已删除，编译临时文件夹
- `x64/` - 已删除，编译输出文件夹
- `tmp/` - 已删除，临时文件夹
- `gui/wdl/` - 重复文件夹，已删除

## 🚀 使用方法

### 1. 生成残局库

**方式一：使用 GUI**
```bash
双击运行：运行残局库 GUI.bat
```

**方式二：命令行**
```bash
# 生成单个残局
xiangqitb.exe gen_single "4k4/9/9/9/9/9/9/8R/4K4 w - - 0 1"

# 生成完整残局库 (使用 option.ini 配置)
xiangqitb.exe
```

### 2. 查询残局库

使用 GUI 程序:
1. 打开 ChessEGTB.exe
2. 切换到"查询残局库"标签
3. 输入 FEN 串
4. 设置筛选条件
5. 点击"查询"按钮

### 3. 批量查询

使用 GUI 程序:
1. 打开 ChessEGTB.exe
2. 切换到"批量查询"标签
3. 输入多个 FEN 串 (每行一个)
4. 设置筛选条件
5. 点击"批量查询"按钮

## 📊 编译说明

### 后端程序 (C++)
```bash
g++ -o xiangqitb.exe src/*.cpp src/chess/*.cpp src/util/*.cpp src/egtb/*.cpp \
    lib/lz4/lz4.c lib/lz4/lz4hc.c \
    lib/zstd/compress/*.c lib/zstd/common/*.c lib/zstd/dictBuilder/*.c \
    lib/LZMA/*.c \
    -I./src -I./lib -std=c++20 -O3 -march=native -DWIDE
```

### GUI 程序 (C#)
```bash
dotnet build ChessEGTB.csproj -c Debug
```

## 🔧 配置文件

### option.ini
```ini
[Options]
# 生成类型
SaveWDL=0
SaveDTC=1
SaveDTM=0
SaveCDTM=0

# 残局库路径
wdltb=./wdl/
dtctb=./dtc/
dtmtb=./dtm/
cdtmtb=./cdtm/

# 线程数
NumThreads=8
```

## 📝 注意事项

1. **所有修改都在根目录** - 不再有 gui 子目录
2. **残局库文件在根目录** - wdl/, dtc/, dtm/, cdtm/ 直接在根目录
3. **源代码保持独立** - src/ 文件夹包含所有后端代码
4. **GUI 代码在根目录** - MainForm.cs 和 ChessEGTB.csproj 在根目录
