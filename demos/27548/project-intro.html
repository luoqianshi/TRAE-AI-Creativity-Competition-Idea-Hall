Linger

一个“懂你所想”的心灵陪伴网页：用轻量画像把你的偏好记住，再用温柔、不评判的方式回应你。它不是医疗建议，而是一个随时打开、随时可以清空的“安全空间”。

首页 → 画像引导 → 伴聊 → 便签 / 日记回顾

“不是要你立刻变好，而是先让你被温柔接住。”

功能亮点

把“好用”藏在细节里：当你开始倾诉，它会更懂你的语气、更尊重你的边界，也更照顾你的节奏。

画像引导（千人千面）

选择情绪、语气偏好、滑杆与关键词，让系统以你更舒服的方式回应你，并尽量避开“雷区”。

伴聊（AI Mock，可替换）

先以本地 Mock 实现可替换“对话引擎”，包含情绪镜像、温柔追问、建议按钮与温暖便签生成。

语音朗读（TTS）

每条回复可一键朗读，也可打开“自动朗读新回复”。基于浏览器 SpeechSynthesis，无需外部语音服务。

情绪白噪音 / 氛围声

WebAudio 本地生成白噪音并做滤波，让音色随情绪变化；支持开启/静音与音量调节。

每日温暖卡片

每天生成一句“今日温柔提醒”，一键收藏到便签墙，做你自己的小小支点。

心情日记 / 回顾

在伴聊中一键“写进日记”，在便签页可展开回看与复制，形成可被温柔回忆的轨迹。

隐私与边界

这个项目默认“只在本地”。画像、对话、便签、日记都存储在浏览器 localStorage；你可以在页面右上角“一键清空本地”立刻抹除数据。

非医疗建议
本项目用于情绪支持与自我安抚引导，不替代任何专业诊断与治疗；如遇危机请寻求专业帮助。
可控、可停、可清空
你可以随时停止对话、静音、关闭自动朗读、关闭白噪音，并一键清空本地数据。

技术栈

纯前端单页应用，强调可替换、可扩展、易部署。

前端
React 18 + TypeScript + Vite + TailwindCSS + React Router + Zustand
本地能力
localStorage（画像/对话/便签/日记） · Web Speech API（TTS） · WebAudio（白噪音）

如何运行

在项目目录执行以下命令即可启动开发预览。

安装依赖
npm install
启动开发服务器
npm run dev
类型检查 / 构建
npm run check npm run build
