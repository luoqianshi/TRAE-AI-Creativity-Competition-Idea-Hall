- 智能记录与高效复盘工具

是一款功能强大的个人记录与报表分析应用，旨在通过便捷的输入方式（语音/文本）和智能的分类统计，帮助用户轻松捕捉灵感、记录琐事并进行深度复盘。

适用场景：日常待办、心情随笔、工作记录、灵感捕捉与复盘统计。

项目介绍

基于 Flutter 框架开发，采用现代化的声明式 UI 设计，集成了语音转文字、本地化存储、数据可视化和自动化提醒等核心功能。无论是日常待办、心情随笔还是工作记录， 都能为您提供丝滑的记录体验。

技术栈Flutter · Riverpod · Drift(SQLite) · GoRouter · flutter_intl

项目核心功能

  • 🎙️ 多模态录入：支持高精度的语音转文字录入及便捷的文本输入，满足不同场景下的记录需求。
  • 🏷️ 智能标签分类：提供自定义标签功能，支持颜色和名称个性化设置，让每一条记录都井然有序。
  • 🔔 自动化提醒：支持为特定记录设置提醒时间，通过本地通知系统确保重要事项不再遗漏。
  • 📊 深度复盘报表：自动生成日、周、月报表，通过图表直观展示各项记录的分布与趋势。
  • 📂 数据导出：支持将记录导出为 Excel 文件，方便进行二次处理或跨平台备份。
  • 🌓 个性化体验：支持 10 种语言切换及深浅色主题，适配全球用户的使用习惯。

项目架构

项目采用清晰的分层架构，便于维护与扩展：

  • UI 层 (Presentation)：页面位于 lib/pages，通用组件位于 lib/widgets。
  • 状态管理 (State Management)：使用 Riverpod，配合 hooks 与 generator 构建响应式数据流。
  • 数据持久化 (Persistence)：使用 Drift（SQLite）实现本地关系型存储。
  • 导航 (Navigation)：使用 GoRouter 管理声明式路由。
  • 国际化 (Internationalization)：使用 flutter_intl 管理 ARB 资源。
  • 工具与插件 (Utilities)：SpeechToText、FlChart、Excel。

使用手册

以下内容为 的主要使用流程说明，可直接作为对外介绍或用户帮助页。

1. 录入记录

  • 在主界面长按麦克风图标，系统将自动开始监听您的语音。松开手指后，语音将转化为文字并自动保存为一条新记录。
  • 点击录入结果，即可查看并编辑该条记录。
  • 长按识别区域可以粘贴内容至识别结果。
  • 点击标签可以修改内容标签分类。

2. 为记录设置分类标签

在记录时或进入“标签管理”页面，您可以选择预设标签或创建新标签。为记录赋予标签后，您可以在报表中看到不同分类的数据占比。

  • 点击标签图标，即可查看并编辑该条记录的标签分类。
  • 您可以在标签管理页面创建新标签，或从预设标签中选择。
  • 您可以在标签管理中对标签进行修改删除排序操作。

3. 设置定时提醒通知

在输入记录时，点击时钟图标即可选择提醒时间。系统会在指定时间通过手机状态栏推送通知，提醒您关注该事项。

  • 识别结果区域有内容时会出现设置提醒图标，点击设置提醒按钮，即可选择提醒时间。
  • 系统会在指定时间通过手机状态栏推送通知，提醒您关注该事项。
  • 您可以在点击首页的通知区域查看和管理所有提醒通知。
  • 在通知列表您可以横向滑动编辑修改通知。

4. 记录管理和报表

通过底部语音左右两侧的按钮进入“报表”中心，您可以查看日报、周报或月报模式。报表包含数据汇总、事项清单以及精美的标签分布柱状图。

  • 在记录列表，您可以横向滑动编辑删除记录。
  • 在记录列表顶部，您可以点击日报、周报或月报按钮查看日报周报月报情况。
  • 报表包含数据汇总、事项清单以及精美的标签分布柱状图。
  • 在报表顶部时间区域，您可以点击左右按钮切换时间范围。

5. 导出数据到 Excel

进入“设置”页面并点击“导出数据”，您可以选择导出的时间范围。系统将生成一个标准 Excel 文件，并支持直接分享至社交媒体或保存到本地。

  • 点击“导出数据”按钮，即可选择导出的时间范围。
  • 系统将生成一个标准 Excel 文件，包含您选择的时间范围内的所有记录。
  • 您可以在文件中查看、分析和导出数据。

6. 个性化设置

  • 点击“设置”图标，即可查看并切换到设置中心。
  • 您可以在设置中心切换到 10 种语言切换及深浅色主题。
