创意名称与创意介绍
Creative Introduction
💡 今日清待 · 本地轻量化待办管理系统
痛点描述
学生、职场人群缺少无广告、无需联网、轻量化的本地待办工具，主流在线待办软件存在隐私泄露、启动卡顿、广告繁多等问题。
创作灵感
本人作为计算机专业学生，日常使用各类在线待办软件规划课程作业、实习任务，云端存储存在隐私风险，软件臃肿占用内存，因此计划纯C语言开发离线单机待办系统。
产品形态
基于标准 C99、适配CLion + CMake 控制台本地单机管理程序，完全离线运行，零网络依赖。

📄 配套编译配置 · CMakeLists.txt 关键配置
cmake_minimum_required(VERSION 3.20)
project(TodoList C)
set(CMAKE_C_STANDARD 99)
set(CMAKE_C_STANDARD_REQUIRED ON)
# Windows UTF-8 编译编码自动开启，解决中文乱码
if(WIN32)
  add_compile_options("$<$:-fexec-charset=GBK>")
  add_compile_options("$<$:-finput-charset=UTF-8>")
endif()
add_executable(TodoList main.c todo.c file_io.c ui.c utils.c)
