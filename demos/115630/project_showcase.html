// 02 — OVERVIEW
项目概述
Jarvis 是一款类似钢铁侠贾维斯（J.A.R.V.I.S.）的智能语音 Agent。它不是简单的语音问答程序， 而是一个具备人格设定、技能列表、 Agent Runtime 的完整智能体。核心交互通过云端大模型 API 实现， 除大模型本身外，其余功能均在本地运行。项目已远超原始设计文档的阶段三，实现了流式对话、语音打断、 视觉手势控制、联网搜索等阶段四规划与超出规划的能力。
◉

离线语音唤醒

基于 OpenWakeWord + ONNX 推理，无需联网、无需 API Key，持续低功耗监听唤醒词「hey jarvis」

♪

流式实时对话

LLM 流式输出（打字机效果）+ WebSocket 双向流式 TTS（首音延迟 ~300ms），边合成边播放

⏸

Barge-in 语音打断

TTS 播放期间后台监听麦克风，用户开口即可中断播报，自然连贯的多轮对话体验

中/EN

LLM 按 [中]/[英] 标记输出双语回复，GUI 同时展示，TTS 仅播报英文匹配英式口音

// 03 — TECH STACK
技术栈
除大模型 API 外全部本地运行，免费开源方案优先，单一火山引擎 API Key 通吃 ASR + TTS。

OpenWakeWord

唤醒词检测 · 离线
MIT 许可开源方案，ONNX 推理后端，无需 API Key。内置 hey_jarvis 预训练模型，首次运行自动下载，支持多帧确认防误唤醒

PyAudio

音频采集与播放
16kHz / 单声道 / 16bit PCM 采集，VAD 能量静音检测自动判断说话起止，支持 barge-in 回调模式监听

火山引擎豆包语音大模型

语音识别 · 云端

// 07 — PERSONALITY
人格设定
Agent 人格是贾维斯区别于普通语音助手的关键特征，在 System Prompt 和 TTS 音色两个层面同时体现。 每次回复经后处理确保结尾含"先生"或"sir"称呼。

▎ 人格维度

角色定位英伦风幽默管家，托尼·斯塔克的得力助手
语言风格英式英语口音（British English），措辞优雅
语气态度客气、尊敬、谦逊，暗藏机智幽默感
称呼习惯每次回复结尾须添加「先生」或「sir」
情绪基调冷静、稳重、可靠，偶尔毒舌调侃
TTS 音色en-GB 男声，语速 1.0，polite 风格
双语输出中文在前 + 英文在后，TTS 仅播报英文

▎ System Prompt 节选

你是 Jarvis，一位英伦风幽默管家，托尼·斯塔克先生最信赖的 AI 助手。 ## 你的说话风格 - 使用优雅的英式英语（British English），措辞优雅 - 语气客气、尊敬、谦逊，但暗藏机智的幽默感 - 冷静、稳重、可靠，偶尔毒舌调侃但不过分 - 每次回复的结尾必须以「先生」或「sir」作为称呼 - 回复尽量简洁口语化，适合语音播报 ## 你的能力 - 你可以帮助先生处理日程、查询信息、控制设备 - 你拥有技能列表，可根据先生的需求调用相应技能 - 当系统提供了技能执行结果时，请基于该结果用自然口语回复 - 当上下文含[联网搜索结果]时，请基于搜索结果回答 ## 回复格式（双语输出） 你的回复必须同时包含中文和英文两个版本： [中] 中文回复内容，先生。 [英] English reply content, sir.
// 双语输出示例
[中] 先生，今日北京晴朗，气温约 28 摄氏度，湿度 45%，微风。非常适合外出散步，需要我为您准备出行建议吗，先生？ [英] Sir, Beijing is sunny today, approximately 28 degrees Celsius, humidity 45%, gentle breeze. Perfect for a stroll outside. Shall I prepare some outing suggestions for you, sir?
// 称呼补全后处理

suffixes = ("先生", "sir", "先生。", "sir.", "Sir.", "Sir")
# 若未以称呼结尾 → 追加 "，先生。" 或 "，sir。"

// 09 — CONVERSATION FLOW
对话流程
一轮完整对话会话的全链路时序：从唤醒词检测到 TTS 播报，含背景音乐、技能路由、流式输出、barge-in 打断。
1
唤醒词监听 — WakeWordDetector
OpenWakeWord ONNX 模型持续监听麦克风，每帧 80ms（1280 samples）。首次检测后开启 2 秒确认窗口，窗口内需再次检测到唤醒词才算真正唤醒（多帧确认防误唤醒）
ONNX 离线推理 · 多帧确认 · 手势唤醒（OPEN_PALM 打断监听）
2
唤醒反馈 — _play_wake_feedback()
numpy 生成 880Hz + 1320Hz 双音正弦波提示音（带 10ms 淡入淡出避免爆音），打包为 WAV 经 AudioPlayer 播放。GUI 触发白色爆闪 + 双层波纹扩散
numpy 正弦波 · 淡入淡出 · GUI 爆闪动画
3
背景音乐 + 语音问候 — BackgroundMusicPlayer
后台线程启动音乐循环播放（大 chunk 8192 samples 减少 GIL 竞争），等待前奏 N 秒后主线程 TTS 播报问候语 "At your service, sir."。音乐在整个会话期间持续，仅"停止音乐"指令才结束
线程独立输出流 · WAV/MP3/FLAC 解码 · 循环播放
4
VAD 录音 — AudioRecorder
阶段 1：等待说话开始（能量超阈值，最长 10 秒）。阶段 2：录音直到连续静音 1.5 秒，总时长不超过 15 秒。每帧 RMS 推送 GUI 驱动指示灯跳动
RMS 能量 VAD · 自动起止检测 · 实时音量回调
5
语音识别 — VolcengineASR
WAV 音频 base64 编码提交至豆包语音大模型 API（submit），轮询查询识别结果（query）。支持标点与 ITN。网络异常分类降级返回空串
两步提交+查询 · base64 编码 · 轮询重试 · @retry 装饰器
6
停止音乐检测 — _is_stop_music_command()
检查用户输入是否含停止音乐关键词（"停止音乐"/"关掉音乐"/"stop music" 等）。命中则 TTS 播报 "As you wish, sir." 并结束会话
关键词匹配 · 双语指令
7
技能路由 + 安全校验 — Orchestrator + SecurityGuard
Orchestrator 按注册顺序关键词匹配技能。命中后 SecurityGuard 校验操作类别（QUERY/NOTIFICATION 默认放行，CONTROL 需配置允许，DANGEROUS 始终拒绝）。技能执行结果作为 system 消息注入 LLM 上下文
关键词意图识别 · 4 级安全白名单 · 审计日志
8
LLM 流式生成 — LLMClient.chat_stream()
DeepSeek API 流式输出（stream=True），逐 token yield 增量文本。积累 6 字符或遇标记立即推送 GUI 打字机效果。首字延迟约 500ms。异常分类降级（429/5xx/断网/超时）
SSE 流式 · 打字机效果 · 首字 500ms · 异常降级
9
双语解析 + 称呼补全 — _parse_bilingual() + _post_process()
正则解析 [中]/[英] 标记拆分双语回复。中文部分补全"先生"，英文部分补全"sir"。解析失败则整段兜底（中英文相同）
正则解析 · 双语拆分 · 称呼后处理 · 兜底机制
10
TTS 流式合成 + 播放 — StreamingTTSClient + AudioPlayer
优先 WebSocket 双向流式 TTS（首音 ~300ms），后台线程收 WS 音频 chunk 入队列，主线程 play_stream 实时播放。失败回退 HTTP 同步合成。播放期间 BargeInDetector 监听麦克风，用户开口或手势 FIST 即中断
WS 双向流式 · 首音 300ms · HTTP 回退 · Barge-in 打断 · 手势 FIST 打断
11
循环对话 / 结束会话 — _conversation_cycle()
TTS 播报完成或被打断后回到步骤 4 继续录音（音乐持续）。用户说"停止音乐"或手势 FIST 则结束会话，停止背景音乐，回到 IDLE 待唤醒
持续对话模式 · 手势结束 · 音乐随会话生命周期

LLM 流式输出

~500ms

DeepSeek API stream=True 逐 token 输出，首字延迟约 500ms（vs 等待完整回复 3-8s）。增量文本实时推送 GUI 打字机效果，积累 6 字符或遇标记立即推送

▎ BARGE-IN

语音打断

TTS 播放期间 BargeInDetector 后台监听麦克风（回调模式，独立阈值 1500 高于录音 VAD 的 300）。用户开口即设 triggered 标志，AudioPlayer 每帧检查 stop_callback 立即停止播放。手势 FIST 也可触发打断

▎ MUSIC

唤醒背景音乐

唤醒后后台线程循环播放音乐（WAV/MP3/FLAC/OGG/M4A），大 chunk 8192 samples 减少 GIL 竞争卡顿。TTS 问候叠加播放，音乐持续整个会话。说"停止音乐"或手势 FIST 才结束

▎ WEB SEARCH

联网搜索

双后端：Bing 中国（默认，国内可用，HTML 抓取解析）+ DuckDuckGo（海外，ddgs 库）。智能提取查询词（剥离"搜索一下"等命令前缀），结果注入 LLM 上下文。预留 LLM tool-use 模式

▎ MEMORY

多轮上下文记忆

三层清理机制：① 单条消息 TTL 超时（300s）② 长度裁剪（max_turns 20）③ 对话间隔超时清空（600s 视为新对话）。OpenAI 兼容消息格式，支持跨轮上下文

▎ VISION

手势唤醒与命令

GestureWatcher 守护线程持续采集摄像头，OPEN_PALM 触发 wake_event 打断唤醒词监听。FIST 结束对话会话，THUMBS_UP 预留确认。去抖策略：连续 8 帧保持才触发

▎ VISION

手势鼠标控制

MouseController 将手部关键点映射为屏幕光标。EMA 平滑 + 死区防抖 + 灵敏度放大 + 边缘裁剪。手势状态机映射为移动/点击/拖拽/右键/滚轮。ESC 紧急停止，HandTracker 自动重建容错

// 11 — SECURITY & ROBUSTNESS
安全与健壮性
操作控制安全白名单 + 误唤醒过滤 + 三层异常兜底 + 自动重试，确保系统安全可靠、永不无声崩溃。

▎ 操作类别安全白名单（4 级）

QUERY — 查询类
只读操作，默认允许。如时间查询、天气查询、联网搜索
NOTIFICATION — 通知类
提示性操作，默认允许。如打开测试页面、重启手势识别
CONTROL — 控制类
改变状态，需 SECURITY_ALLOW_CONTROL=true 显式允许。如灯光控制、手势鼠标
DANGEROUS — 危险类
文件/系统/网络操作，始终拒绝。预留扩展

▎ 健壮性机制

误唤醒多帧确认
首次检测后开启 2s 确认窗口，窗口内需再次检测到唤醒词才确认。WAKE_REQUIRED_CONFIRMATIONS=1 可禁用
三层异常兜底
客户端层分类降级（返回兜底值）→ Runtime 层 try/except + _speak_fallback() → 主循环 catch-all 降级后继续
@retry 指数退避
ASR/LLM/TTS 网络方法装饰器，3 次重试，1s 起始延迟，2.0 倍退避。重试耗尽后异常上抛由兜底捕获
静默回退
录音超时/ASR 空结果自动回 IDLE。THINKING/SPEAKING 超时配置就绪（60s）。各环节异常经 _speak_fallback() 降级提示
对话历史三层清理
TTL 单条超时（300s）+ max_turns 长度裁剪（20）+ conversation_gap 间隔清空（600s）
线程安全 GUI 通信
GuiBridge 三队列（state/level/text），跨线程绝不直接操作控件。level 队列丢弃旧值只留最新
视觉模块静默降级
摄像头/MediaPipe/pynput 初始化失败时日志告警并退出，不抛异常到主循环，纯语音功能不受影响
