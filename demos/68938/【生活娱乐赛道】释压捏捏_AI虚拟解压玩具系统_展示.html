Tech Stack

技术原理与体验设计

让虚拟捏捏拥有真实的手感

🧠 软体物理模拟引擎

基于弹簧质点系统（Mass-Spring System），将虚拟玩具表面离散为128个质点和256根弹簧。按压时局部弹簧被压缩，松开后根据材质弹性系数恢复形变。慢回弹团子的恢复系数0.3（回弹慢），软泥0.1（几乎不回弹），泡泡纸0.8（快速回弹）。

# 弹簧质点系统 force = k * (rest_length - current_length) # 胡克定律 damping = c * velocity # 阻尼力 displacement += (force - damping) * dt # 位移更新

👆 触摸压力映射与手势识别

通过触摸面积和按压持续时间估算用户按压力度。轻触产生浅凹陷，长按产生深凹陷并触发"挤压"事件。多点触控支持双手同时捏压，模拟真实捏捏玩具的两侧挤压手感。

# 压力估算 pressure = f(touch_area, duration) # 压力映射 depth = pressure * max_deform # 形变深度 if pressure > threshold: spawn_particles(touch_pos, intensity) # 触发粒子

✨ AI生成触觉反馈动画

根据按压位置和力度，AI实时生成匹配的粒子特效——按团子产生粉色星尘、捏软泥产生紫色烟雾、戳泡泡纸产生白色光点爆裂。粒子颜色、密度和运动轨迹由当前心情标签和按压力度共同决定。

# 粒子生成参数 = f(心情, 力度, 材质) particle_color = mood_palette[mood] # 心情配色 density = pressure * material_factor # 粒子密度 trajectory = physics_sim(type) # 运动轨迹

📈 情绪压力量表与个性化

用户每次进入App时填写1-10分压力自评，系统记录捏捏次数、时长、力度分布。通过分析历史数据，AI识别用户的最佳解压模式——有的人适合暴力快速捏，有的人适合缓慢深压，App自动推荐最适合的玩具和音效。

# 解压效果评估 relief_score = w1*squish_count + w2*avg_pressure + w3*session_duration if relief_score > user_baseline: recommend_similar_mode() # 推荐相似模式
