一、文件打开方式
该文件为单文件 index.html，集成了所有 HTML/CSS/JavaScript 逻辑，无外部依赖（无 CDN、无外链图片 / 字体 / 插件），打开方式如下：
基础方式：直接双击 index.html 文件，系统会调用默认浏览器（Chrome/Edge/Firefox 等）打开，离线环境下即可运行。
开发者模式：若需调试，可在浏览器中打开「开发者工具」（F12 / 右键检查），查看 Canvas 绘制、音频合成等逻辑。
适配说明：支持桌面端、平板、移动端（响应式布局），建议使用现代浏览器（Chrome 80+/Edge 80+/Firefox 75+）以保证 SpeechSynthesis、Web Audio API 等功能正常。
二、核心操作步骤
1. 主题分区切换
页面顶部导航栏包含 6 个怀旧主题分区：「市井老街」「校园童年」「老式影院」「集市小吃」「家属院」「九十年代交通工具」。
点击任意分区按钮（如「校园童年」），左侧会切换该分区的介绍文案 + 标签，右侧主画布自动绘制该分区的复古插画，同时自动播放对应旁白语音。
分区标签（如「校园童年」下的「跳皮筋」「乒乓球台」）可点击，点击后自动填充关键词并生成对应插画。
2. 复古插画生成
关键词输入：底部输入框可输入怀旧关键词（如「老路灯」「爆米花机」「二八大杠」），支持中文任意怀旧相关词汇。
生成操作：输入关键词后，可点击「生成复古插画」按钮，或按回车键触发生成；生成时右侧画布会显示「正在显影老照片…」加载动画，完成后自动绘制带复古滤镜（泛黄 / 颗粒 / 暗角）的插画，并播放对应旁白。
语音录入：点击底部「🎙 语音录入」按钮（麦克风图标），可通过语音输入关键词（需浏览器授权麦克风），停止录入后自动生成插画。
3. 时光对比功能
城市 / 街道输入：左侧「时光对比」模块的输入框，可输入任意城市 / 街道名称（如「北京胡同」「武汉江汉路」）。
对比生成：点击「对比」按钮，左侧画布绘制该地点的「复古版」插画，右侧绘制「现代版」插画，同时播放对比旁白。
切换左右：点击「切换」按钮，可交换复古 / 现代版插画的左右位置。
4. 音频控制
旁白朗读：底部「旁白朗读」开关（默认开启），点击可关闭 / 开启插画生成后的语音解说（基于浏览器 SpeechSynthesis）。
背景音乐：底部「背景音乐」开关（默认开启），开启后自动播放 Web Audio API 合成的暖色怀旧背景音乐，关闭则停止。
5. 本地保存
点击底部「保存到本地」按钮，可将右侧主画布的复古插画以 PNG 格式下载到本地（浏览器会触发文件下载）。
6. 其他细节
输入框 hover 时会显示提示（如「试试：老街道 / 童年零食 / 老式建筑」），引导关键词输入。
所有操作均离线完成，无需联网，插画为 Canvas 程序化绘制，无外部接口依赖。
三、核心功能逻辑补充
插画生成：基于关键词 + 分区场景，通过 Canvas 2D 绘制几何图形 + 简笔元素，叠加复古滤镜（泛黄、颗粒噪点、暗角、胶片划痕）模拟老照片效果。
音频逻辑：旁白使用浏览器内置 SpeechSynthesis，背景音乐通过 Web Audio API 合成暖色调正弦音（呼吸式音量），无外部音频文件。
响应式适配：平板 / 手机端自动调整布局（如主体从双栏变为单栏），保证操作体验。
