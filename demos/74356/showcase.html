The Problem

我们都在和 AI 聊天，但知识却在流失

每天大量有价值的 AI 对话，散落在不同平台、刷新即丢，难以沉淀、难以检索、难以复用。

🗑️

对话刷新即丢

AI 平台对话不会自动长久保存，跨设备、跨平台互不相通，曾经问过的好答案再也找不回来。

📋

手动整理费时

复制粘贴整理笔记耗时耗力，深度思考、联网搜索来源等结构化内容还容易丢失。

🔍

关键词搜不到

记不清原话时，关键词搜索形同虚设；缺少语义级检索，"模糊记得"也无法定位。

How It Works

四步把 AI 对话变成知识资产

安装即用，零打扰采集，AI 自动帮你整理、检索与复习。

1

自动采集

浏览 DeepSeek / 千问 / 豆包 / 复旦 Agent 时，扩展自动拦截网络请求，完整记录问答、思考过程与搜索来源。

2

向量化入库

调用 DashScope Embedding 生成向量，存入本地 IndexedDB 或远程向量库，构建个人语义索引。

3

语义检索

用自然语言提问即可跨对话秒级定位历史内容，不再依赖记清原话。

4

AI 加工

一键整理成笔记、生成测验题复习，或基于全部历史对话自由问答。

Core Features

三大核心能力

采集 + 检索 + AI 加工，构成完整的学习闭环。

多平台对话采集

双模式自动抓取，数据完整不丢字段。

  • 网络拦截模式（推荐）：直解 API 响应
  • DOM 模式：兜底提取，结构变化自适应
  • 完整保留用户提问、AI 回答、深度思考、搜索来源、对话标题
  • 导出 Markdown / JSON，方便归档分享

语义检索引擎

Embedding + 向量库，"模糊记得"也能找到。

  • 支持 text-embedding-v4 与多模态视觉模型
  • 本地 IndexedDB 零配置，开箱即用
  • 可选远程：Chroma / Milvus / pgvector / Pinecone / Supabase / Qdrant
  • 支持深度思考、联网搜索内容的过滤策略

AI 学习助手

三大 Tab，把"聊过"变成"学到"。

  • 整理信息：输入主题，AI 汇总成结构化笔记
  • 生成测验：基于历史对话自动出题，强化复习
  • 自由问答：结合全部对话记录作答，答案有据可循
  • 流式输出，结果可导出、历史自动留存
