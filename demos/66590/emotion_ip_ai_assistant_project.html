情绪记账 × AI IP手办项目创意方案

从“只有摆件功能的盲盒公仔”出发，将 IP 手办升级为用户在 App 内外都能感知、互动和依赖的情绪消费 AI 助手。它既是情绪记账产品中的角色伙伴，也是现实世界里提醒用户理性悦己消费的陪伴型入口。

Brand Proposition

悦己可以，盲目不必。

One Sentence
让每一笔消费，都成为看懂自己的情绪小票。

项目不只是“会说话的玩具”，而是围绕消费情绪记录、复盘和陪伴建立的 AI 潮玩助手体系。

01 / Project Positioning

项目定位

本项目应定位为“情绪消费陪伴型 IP 助手”，而不是单纯的 AI 玩具或盲盒公仔。它的核心价值在于把用户的消费行为、消费动机和消费后的情绪感受连接起来，帮助用户建立更清醒、更柔和、更可持续的悦己消费观。

让 IP 手办从“被观看的摆件”，变成“能陪用户理解消费情绪的 AI 伙伴”。
产品属性

情绪记账助手

在 App 内承担消费记录、情绪识别、买前冷静、买后复盘和月度报告等功能。

IP属性

潮玩陪伴角色

以可收藏、可衍生、可故事化的潮玩形象出现，增强产品记忆点和用户粘性。

硬件属性

现实世界入口

通过 NFC、二维码、桌面摆件、挂件或后期 AI 硬件，把线下 IP 与线上助手连接起来。

02 / Market Opportunity

项目机会与前景

项目的机会来自三个方向的交汇：潮玩 IP 消费、AI 陪伴产品、情绪/心理自我管理工具。单独看，每个赛道都已有竞争；但把“消费情绪记录”作为核心场景，将实体 IP、App 助手与理性悦己价值观绑定，仍然有差异化空间。

潮玩不只是玩具，而是情绪价值载体

年轻用户购买潮玩，往往不只是为了功能，而是为了收藏、陪伴、身份表达和即时情绪满足。

AI 助手需要更具体的情境

泛聊天 AI 容易同质化，而“消费前后情绪陪伴”是一个明确、频繁、可记录、可复盘的场景。

情绪记账需要更强的持续使用动机

普通工具容易被放弃，而 IP 角色可以通过陪伴感、成长感、收藏感提升用户留存。

03 / Target Users

目标用户画像

目标用户建议覆盖男女两种性别，但不要平均用力。早期应优先面向 18—35 岁、有悦己消费习惯、愿意记录生活、接受 AI 陪伴的年轻用户。

优先级最高

城市悦己型女性用户

年龄：22—32 岁，大学生、研究生、初入职场白领、设计/传媒/教育/互联网相关从业者。

消费场景：盲盒、美妆、香薰、奶茶、饰品、文创、展览、拍照打卡。

核心心理：我知道自己有时会冲动消费，但我不想被批评，我希望有人温柔提醒我。

优先级高

理性收藏型男性用户

年龄：23—35 岁，互联网、设计、游戏、数码、工程、自由职业者。

消费场景：数码产品、游戏装备、桌搭、潮玩手办、键盘、耳机、会员订阅。

核心心理：我不是乱花钱，但我容易被新东西吸引，需要一个能帮我复盘消费决策的工具。

增长用户

情绪波动型年轻用户

年龄：18—25 岁，学生或初入职场。

消费场景：外卖、奶茶、游戏皮肤、小饰品、课程会员、短视频种草商品。

适合策略：通过低价数字衍生、表情包、贴纸、月度情绪账单海报切入。

礼品场景

情侣 / 朋友送礼用户

年龄：20—35 岁。

消费场景：生日、节日、纪念日、闺蜜礼物、办公桌礼物。

适合策略：推出生日礼盒、情侣款、闺蜜款、节日限定和“送你一个不会评判你的消费小助手”。

04 / IP Worldview

IP 世界观设定

建议建立一个与情绪记账强绑定的世界观，而不是普通“可爱小动物集合”。角色、盲盒、衍生品和 App 功能都应围绕“消费情绪”展开。

世界观名称建议

  • 心账岛：温柔、治愈、适合女性与礼品场景。
  • 情绪账本局：更有系统感、适合 App 与 AI 助手设定。
  • 小票星球：更轻松、更适合潮玩系列化。

核心设定

每个人的消费都会变成一颗“情绪泡泡”。真正带来长期满足的消费会发光；被焦虑、跟风、攀比推着走的消费会变成灰色泡泡。IP 助手们的任务不是阻止用户消费，而是陪用户看懂每一次消费背后的情绪。

悦己消费不是错，盲目消费才会让人失去自由。
05 / Main Character

主 IP 角色：诺诺 Nono

建议先打造一个主 IP，再逐步扩展角色矩阵。主 IP 必须承担品牌精神：温柔提醒、不过度说教、不制造负罪感，帮助用户从“想买”走向“看懂自己为什么想买”。

示意图：大头身比例、圆润轮廓、小票折角、账本耳朵、情绪窗口、记录笔尾巴。正式设计时应形成原创外观，避免直接模仿已有潮玩 IP。

名字含义

Nono 不是强硬地说“不许买”，而是温柔地说：“等一下，我们先看看这次消费是不是你真的需要。”

外观关键词

小兽、精灵、AI 助手、大头身、圆润、半透明情绪窗口、小票折角、账本耳朵、笔状尾巴。

性格关键词

温柔、清醒、克制、不评判、不说教、懂情绪、有一点点丧萌和怪可爱。

角色职责

消费前冷静提醒、消费后情绪记录、周期性复盘、生成用户的“情绪消费地图”。

06 / Character Matrix

第一季盲盒角色设定：《今天为什么想买？》

第一季角色建议按“消费情绪类型”设计，而不是按普通动物随意组合。这样每个角色都能和 App 的情绪标签、复盘报告、消费场景绑定。

07 / IP Story

IP 故事主线

故事应围绕“消费不是被禁止的行为，而是认识自己的入口”展开。这样既符合悦己消费，也能避免项目变成单纯的消费刺激型 IP。

在“心账岛”上，每一笔消费都会落下一张小小的情绪票据。真正让人开心的消费，会变成发光的泡泡；被焦虑、跟风、攀比推着走的消费，会变成灰色泡泡，飘在空中慢慢堆积。

诺诺是心账岛上的情绪账本管理员。它不负责阻止人们消费，也不认为花钱取悦自己是错的。它相信，每个人都值得拥有让自己开心的东西，但前提是——你要知道自己为什么想要它。

于是，每当用户想买东西时，诺诺会轻轻敲一下账本：“这是你真的喜欢，还是你只是现在有点累？”“这次消费会照顾你，还是会让你明天后悔？”“如果它三天后还让你心动，我们就把它放进真正的愿望清单。”

用户每记录一次情绪，诺诺就会收集一颗情绪泡泡。时间久了，这些泡泡会组成一张属于用户自己的“心账地图”。地图上不是冷冰冰的账单，而是用户如何爱自己、如何失控、如何慢慢变清醒的成长轨迹。

08 / Product System

产品与衍生品体系

衍生品不应只做摆件，而应围绕“情绪记账入口”和“现实世界助手”展开。建议从低成本视觉衍生开始，再逐步走向 NFC 公仔、AI 挂件和桌面助手。

第一层

低成本视觉衍生

贴纸、头像、表情包、手机壁纸、App 主题皮肤、月度情绪账单海报、手账模板。

第二层

实体陪伴衍生

盲盒摆件、毛绒挂件、钥匙扣、包挂、桌面小摆件、手机支架、情绪账本。

第三层

功能型衍生

NFC 公仔底座、情绪冷静卡、桌面情绪灯、扫码唤醒 AI 助手、消费前五问入口。

第四层

数字衍生

AI 语音包、角色皮肤、专属人格、App 房间装饰、数字徽章、成长等级。

09 / MVP

最小可行版本 MVP

早期不建议直接做复杂 AI 硬件。更合理的 MVP 是“诺诺 AI 情绪消费助手 + 第一季 IP 设定 + NFC/二维码概念公仔”。这样可以先验证用户是否喜欢 IP、是否愿意记录消费情绪、是否愿意为衍生品付费。

看到想买 诺诺提醒 记录情绪 完成或放弃消费 24小时后复盘 生成情绪账单 IP 成长

App 内核心功能

  • 记录一笔消费：金额、品类、场景、对象。
  • 选择消费情绪：开心、焦虑、疲惫、冲动、奖励、跟风、空虚、实用。
  • 选择消费动机：奖励自己、被种草、社交需要、压力释放、长期需要、临时冲动。
  • 诺诺生成温柔反馈和复盘建议。
  • 月度报告：真正带来快乐的消费与后悔率较高的消费。

实体入口

  • 公仔底座或吊牌加入二维码 / NFC。
  • 手机触碰或扫码后进入 App 的诺诺助手页面。
  • 桌面摆件对应工作学习场景，包挂对应外出消费场景。
  • 后期再加入语音、蓝牙、情绪灯等硬件能力。
10 / Roadmap

项目实现路径

01

数字 IP 助手阶段

先在情绪记账 App 中上线诺诺助手，完成消费记录、情绪标签、买前冷静、买后复盘和月度情绪报告。

02

IP 视觉体系阶段

完成主 IP 三视图、表情库、动作库、颜色规范、第一季角色矩阵、短视频脚本和小红书图文模板。

03

NFC / 二维码实体公仔阶段

先用低成本方式实现“实体 IP 唤醒线上 AI 助手”，避免过早投入复杂硬件和开模风险。

04

AI 硬件阶段

在产品和 IP 验证后，再探索麦克风、扬声器、蓝牙、按键、情绪灯、充电底座等真正 AI 陪伴硬件。

12 / Key Principles

关键原则与风险提示

盲盒机制要与价值观一致

项目倡导理性悦己消费，因此盲盒机制不能过度刺激用户重复购买。建议明示款式和概率，提供非盲盒直购通道，不主动炒作隐藏款，不做强迫集齐。

AI 陪伴要避免情绪操控

诺诺不应制造依赖、不替代真实关系、不做医疗诊断、不使用羞耻感迫使用户改变消费行为。它的语气应该是陪伴式、提醒式、复盘式。

隐私数据要谨慎处理

消费记录、情绪标签、语音记录都属于敏感数据。产品需要明确告知用途，允许用户删除数据，并尽量减少不必要的数据采集。

视觉风格要原创

可以参考潮玩行业的大头身、圆润、系列化方法，但必须建立原创轮廓、符号、颜色、故事和角色体系，避免直接模仿既有 IP。
