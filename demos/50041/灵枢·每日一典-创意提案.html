创意名称与介绍

一句话定位：每天一句冷门但惊艳的古籍名句，AI 白话解读 + 古风卡片生成，一键保存分享。

项目名称：灵枢 · 每日一典

取名释义：「灵枢」取自《黄帝内经·灵枢》，意为「灵慧之枢机、典籍之精要」；「每日一典」点明产品形态。

为什么会想到做这个：

市面上古籍类产品要么学术化（全文阅读 + 长篇注解）、要么娱乐化（恶搞改编），缺乏一款轻量、有趣、适合日常碎片化阅读的入口。希望让 18-35 岁的年轻人，每天用 30 秒就能邂逅一句古籍中的惊艳好句，获得一点文化灵感。

产品形态：微信小程序（一套代码同时输出 H5 / 抖音小程序 / 支付宝小程序）

👥
目标用户及痛点

面向哪些用户：

• 在校大学生 / 文史哲专业学生 — 需要积累素材但难读完大部头

• 新媒体编辑、文案、设计师 — 寻找灵感金句与古风视觉素材

• 城市白领与文艺青年 — 希望提升文化素养，缺乏轻量入口

• 传统文化轻度爱好者 — 喜欢古风、汉服、国潮，但不会通读典籍

在什么场景下使用：

• 早高峰地铁上、午休 5 分钟、睡前 3 分钟 — 任意碎片时间

• 朋友圈发图缺文案时，复制一张古风卡片直接发

• 写文章 / 做设计时翻一翻日历找灵感

• 给孩子 / 学生做传统文化启蒙，每日一句不枯燥

五大核心痛点：

门槛高 — 古籍文言晦涩，传统 App 多为长篇全文 + 厚重注解，缺乏轻量化入口
脱节感 — 古籍内容距离现代生活远，无法产生即时情绪共鸣，"读了也用不上"
传播断 — 优质内容缺少适合社交分享的视觉形式，好句只能私藏
难坚持 — 没有持续引导机制，用户很难形成「每日读一点」的习惯
同质重 — 市面古籍类产品同质化严重，要么学术化要么娱乐化，缺差异化定位

技术实现
产品最终形态：微信小程序（用户扫码即用，无需下载 App）

开发技术栈：uni-app x 是 DCloud 推出的跨端框架，使用 Vue 3 语法编写一次代码，可同时编译为微信小程序 / H5 / 抖音小程序 / 支付宝小程序。本项目先以微信小程序作为首发平台。

前端开发：

Vue 3 uni-app x TypeScript SCSS uni-ui

后端 / 云服务（微信云开发）：

云函数 云数据库 MongoDB 云存储

AI 能力（云函数中调用）：

DeepSeek API 腾讯混元 Prompt 模板

小程序原生能力：

Canvas 2D wx.saveImageToPhotosAlbum wx.shareToWeChat uni.setStorageSync

关键实现要点：

1
名句库：预置 365 句 JSON 静态数据 + 每日云函数调度推送，覆盖《夜航船》《世说新语》《小窗幽记》《菜根谭》《幽梦影》
2
AI 解读：云函数转发到 DeepSeek API，前端 wx.request 调用自建云函数，避免暴露 API Key
3
古风卡片：Canvas 2D 实时绘制竖排文字 + 背景纹理 + 篆刻印章（wx.canvasToTempFilePath 导出图片）
4
字体优化：楷书 / 行书 / 隶书通过 fontmin 子集化处理，远程加载，首屏 < 200KB
5
打卡存储：本地 uni.setStorageSync 缓存往期数据，云数据库同步用户打卡记录
6
公益开源：名句库 JSON 以 MIT 协议开源至 GitHub，API 免费开放给乡村学校、文化馆复用

项目里程碑：
