律韵探微

解码好听的音乐与诗词背后的韵律密码

人们常觉得某首旋律好听、某首诗词朗朗上口，却说不清"为什么好听"。
音乐和诗词的美感背后有可量化的韵律规律——
音阶构成、旋律走向、平仄格律、韵脚呼应——
我们要做的，就是让这些隐藏规律被看见、被理解。

向下探索
Problem

四重困境，阻隔在美与理解之间

"好听"是直观感受，但"为什么好听"却难以言说。现有的工具要么门槛太高，要么只看局部，没有一座桥能连通音乐与诗词的韵律世界。

📉
专业工具门槛高
MATLAB、Sonic Visualiser 等专业软件界面复杂、操作困难，普通人根本不会用。音乐分析成了学术圈的自留地。
📝
诗词工具只看表面
现有诗词工具只能标注平仄对错，无法可视化展示"声律的波形"和韵律的美感来源。格律变成死规则，而非活生生的节奏。
🌉
跨领域缺少桥梁
没有工具能同时分析音乐和诗词，发现它们韵律上的共通规律。两个领域的审美智慧被割裂，无法相互启发。
🔮
"好听"缺少量化解释
美是主观的，但音阶偏好、节奏对称性、黄金比例等是有规律可循的。缺少工具将"好听"拆解为可理解的要素。

一款应用，两种韵律，无数发现

Core Features

四大核心能力

从音阶检测到跨域对比，覆盖韵律分析的完整链路。

壹
音乐音阶与旋律分析
上传音频或搜索网络歌曲，自动提取音阶分布、旋律走向、节奏脉冲。圆形音阶图直观展示调式特征，钢琴卷帘还原音符时序，旋律轮廓揭示高潮位置与黄金比例。
Web Audio API + 自相关检测
贰
古诗词平仄与韵脚解析
输入任意古诗词，自动标注平仄、识别韵脚、校验格律。声律波形将抽象的平仄转化为可视化曲线，韵脚高亮揭示押韵规律，格律校验帮助理解近体诗的声律之美。
平水韵部 + 格律模板匹配
叁
跨领域规律发现
音乐与诗词并非两个孤立世界。系统自动对比五声音阶与平仄格律的数学关联——对称性、黄金分割点、重复模式——揭示"好听"的跨域共通结构。
模式匹配 + 相似度计算
肆
网络歌曲搜索与分析
通过网易云搜索获取完整歌曲（支持会员 Cookie），或粘贴任意音频直链。代理服务绕过跨域限制，让在线歌曲分析成为可能，不再局限于本地文件。
Express 代理 + Cookie 注入
Use Cases

谁在用，怎么用

音乐爱好者
听到好听的歌，想知道它为什么抓耳
搜索一首歌 → 系统展示音阶分布（如五声宫调）→ 旋律高潮恰在黄金分割点 → "原来好听不是玄学，是数学！"
语文教师
备课需要直观展示平仄之美
输入《春江花月夜》→ 声律波形展示平仄起伏 → 韵脚高亮揭示一韵到底 → 格律校验解释为何这是"孤篇压全唐"
音乐教师
课堂需要旋律结构可视化
上传一首民歌 → 钢琴卷帘展示音符 → 圆形音阶图说明调式 → 学生直观理解"徵调式为什么听起来明亮"
创作者
从经典中提取韵律灵感
分析多首经典歌曲 → 规律发现页对比旋律模式 → "原来流行歌的副歌都在 0.62 位置出现" → 为创作提供结构参考
Value

不只是工具，是认知方式的变革

⚡
效率提升：韵律分析平民化
将音乐学和诗词格律学的专业分析能力"平民化"——任何人无需专业知识即可获得深度韵律分析。音乐教师可一键生成旋律可视化，语文教师可直观展示平仄之美，创作爱好者可快速提取经典作品的韵律结构作为参考。从"凭感觉"到"有依据"，降低韵律理解的门槛。
🏛️
社会价值：架起音乐与传统文化的桥梁
通过发现五声音阶与古诗词平仄之间的数学关联——对称性、黄金比例、重复模式——让更多人从科学角度理解中华传统韵律之美。让"好听"不再只是主观感受，推动传统文化的现代化表达与传播，让年轻一代以新的方式亲近古典之美。
