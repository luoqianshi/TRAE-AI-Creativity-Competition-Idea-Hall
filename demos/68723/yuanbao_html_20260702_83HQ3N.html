🧠 知忆 · 知识捕获 v0.1 创意提案

你只负责「说」与「看」，其余全部交给 AI Agent —— 零操作归类 + 主动关联召回 + 重要性自适应

🎯 一句话定义 —— 面向个人思考者的“AI 副驾驶”： 随时随地用语音/文字丢入碎片信息，系统自动理解、打标签、关联历史笔记， 并按重要性分级推送回顾，让每一个灵感都不再吃灰。

⚡ 与其他笔记产品的本质区别
  • 零操作录入：不需要打开特定 App → 新建页面 → 选择分类 → 填写标题。触发即录。
  • AI 主动关联：录入瞬间自动检索历史，相似笔记直接推送到眼前，而非等你搜索。
  • 重要性动态分级：根据你的行为（补充、重复、忽略、语调）自动判定重要程度，召回策略因人而异。
  • 容忍“脏记录”：一个词、半句话、中断退出，系统都能消化，不会强迫完整。

👤 典型用户画像

🧑‍💻 产品经理 / 设计师 日常冒出大量交互灵感、用户洞察，需要快速捕捉并关联旧方案，避免重复造轮子。
📚 终身学习者 阅读、听课、播客中高频吸收新概念，希望构建个人知识网络，而非散落一地。
✍️ 创作者 / 写作者 碎片灵感稍纵即逝，需要一个“零摩擦捕集器”，并在写作时自动推送相关素材。
🔬 研究者 / 分析师 长期追踪某个课题，需要跨时间片联想，并自动标记关键进展。

🔄 核心工作流

🎤 语音 / ⌨️ 文字 → 📥 捕获层 (ASR + 原始inbox) → 🤖 AI Agent 编排
🏷️ 实体提取·标签分层 → 🔍 向量检索·语义关联 → 📌 重要性判定 (行为+显式)
📲 即时推送回顾 (关联笔记) → 🗂️ 存入 Notion / 本地 DB → ⏰ 周期性复习 / 冷宫归档

🧩 功能规格 & 创新机制

📟 1. 极致便捷的捕获入口

  • 硬件级触发：iPhone 背面轻点 / AirPods 长按 / Apple Watch 语音 / Mac 全局快捷键 / Windows 截图 OCR。
  • 零界面输入：触发即开始录音或弹出极简输入框，无标题、无分类、无标签选项。
  • 脏记录友好：只言片语自动标记「待补充」；中断退出保留草稿，下次触发时询问是否继续。
  • 环境自适应：驾驶模式 → CarPlay 语音；会议模式 → 静音文字；运动模式 → 耳机录音。

🏷️ 2. 智能标签与同主题合并

  • 三级标签体系：领域 / 子领域 / 具体概念（例如 #AI/Agent/AgentOS）。自动继承已有标签，避免膨胀。
  • 三层匹配机制：精确匹配（同义词表）+ 语义匹配（向量相似度阈值 0.85/0.70）+ 行为匹配（近期高频主题主动建议建合集）。
  • 同义合并：自动识别“对话式UI / Chat UI / Conversational Interface”并归一，无需人工维护。
  • 合并确认：相似度 0.70~0.85 时轻量询问“是否合并？”，低于 0.70 仅建立弱关联。

⚡ 3. 重要性动态分级（核心创新）

🔺 自动推导信号
  • 补充细节 / 重复提及 → ⭐⭐⭐
  • 主动关联其他笔记 → ⭐⭐⭐
  • 从未查看 / 划掉推送 → ⭐
  • 语音语调急促（声纹） → ⭐⭐
✋ 显式干预方式
  • 记录末尾添加 !important / !urgent / !private
  • 长按卡片手势滑动标记“重要/不重要”
  • 每周可批量审核标签与重要性

召回策略 ⭐⭐⭐ 每次同类主题录入必弹 · ⭐⭐ 每周回顾推送 · ⭐ 仅搜索可见。紧急标记可打断当前推送。

🔗 4. 主动关联与回顾推送

  • 录入即时召回：向量检索 Top-3 相似笔记，相似度 >0.7 立即推送卡片“发现 X 条相关旧想法”。
  • 多维度触发：空闲时段（检测停止操作 30s）、睡前每日回顾、每周深度关联图谱。
  • 推送层次：卡片摘要（标题+一句话+关联数）｜ 对比视图（新旧并列）｜ 时间线演变。
  • 负反馈学习：划掉推送 → 降低同类优先级；反复查看 → 提升权重。

🧹 5. 遗忘曲线与主动清理

  • 保鲜期：每条记录标注短期（会议要点） / 长期（底层思考） / 不确定。过期自动归档。
  • 季度大扫除：列出 90 天未查看且未关联的记录，一键保留/归档/删除。
  • 回顾即刷新：主动点开查看 → 最后活跃时间更新，保鲜期重新计算。

🛠️ 技术实现概览

  • 捕获层：iOS 快捷指令 / Raycast / PowerToys + 语音 ASR (Whisper / 混元)。
  • AI Agent 编排：FastAPI + GPT-4o / Claude 3.5 Sonnet（实体提取、摘要、标签生成）。
  • 向量存储：Qdrant / Milvus + embedding text-embedding-3-small。
  • 展示层：Notion Database（用户直接浏览分类）+ 可选本地 Web 浮窗。
  • 推送通道：飞书 Webhook / Server 酱 / Telegram Bot / 本地通知。

✅ 最小可行版本可基于 Make + Notion API + OpenAI 快速搭建（约 3–5 天）

🧭 迭代路线图

  1. P0 · 基石：语音/文字捕获 + LLM 标签 + 向量关联 + Notion 写入 + 即时推送。
  2. P1 · 智能升级：重要性自动推导 + 三级标签 + 同义合并 + 脏记录处理。
  3. P2 · 生态扩展：截图 OCR、网页摘录、长录音分段、Apple Watch 独立记录。
  4. P3 · 个性化引擎：基于遗忘曲线的复习计划、每周知识图谱、行为模型持续学习。

🚀 为何不做另一个“笔记 App”

现有工具（Notion / Obsidian / Roam）强调手动整理与双向链接，用户仍需承担分类、命名、回顾决策。 知忆则把组织成本降为零，AI 主动承担“图书馆管理员 + 私人助理”角色—— 你只管生产，系统负责连接、筛选、适时提醒。

💡 商业可能性

  • 订阅制：免费版 200 条/月，Pro 版无限存储 + 高级关联图谱 + 多端同步。
  • 团队版：共享知识库，AI 跨成员关联灵感，适合小型创意团队。
  • API 开放：第三方应用（如飞书、Slack）可嵌入捕获组件，按调用量计费。
