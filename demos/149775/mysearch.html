💻 统一 API 体验

只需一次接入，即可调用任意搜索引擎：

// 传统方式：每个搜索引擎单独接入 // 需要维护 8 套 SDK，8 种不同的 API 格式 😫 const tavily = new TavilyClient({ apiKey: "tvly-xxx" }); const exa = new ExaClient({ apiKey: "exa-xxx" }); const brave = new BraveClient({ apiKey: "brave-xxx" }); // ... 还有 5 个要写 // ✅ MySearch 方式：一个接口，全部搞定 const mySearch = new MySearch({ providers: { tavily: "tvly-xxx", exa: "exa-xxx", brave: "brave-xxx", searxng: "https://searxng.example.com", // ... 配置一次，永久使用 }, defaultProvider: "auto", // 智能选择最优引擎 }); const results = await mySearch.search("AI Agent 最新进展", { provider: "tavily", // 可随时切换，代码零改动 maxResults: 5, });

使用场景

🤖 AI Agent 联网搜索
开发 AI 应用时，MySearch 作为统一的联网搜索层接入 LangChain、AutoGPT 等框架，Agent 可以智能选择最合适的搜索引擎，获取最准确的实时信息。
🔍 多源搜索对比
研究人员或内容创作者需要高质量搜索结果时，一次查询同时调用多个搜索引擎，对比不同来源的结果，去重合并，获得更全面的信息。
🛡️ 高可用搜索服务
对可用性要求高的生产环境，配置多个搜索引擎作为备份，某个服务限流或宕机时自动切换到备用服务，保证业务不中断。
