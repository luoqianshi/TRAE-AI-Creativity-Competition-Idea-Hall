智习馆 — 智能复习与错题本系统

一个基于 Web 的在线复习题库与智能错题管理系统，支持自动判题、错题收录、多课程切换与 AI 智能识别题目

话题标签： 学习工作
1

创意名称与创意介绍

创意名称：智习馆（SmartReview Hub）

产品形态：纯前端 Web 应用（无需后端服务器，浏览器即可运行）

想解决什么问题：学生在期末复习阶段，面对大量纸质或 Word 格式的复习题，缺乏一个系统化的在线练习与错题管理工具。传统复习方式无法自动判题、无法记录错题、无法追踪学习进度，导致复习效率低下、错题反复出错。

为什么会想到做这个：灵感来源于《交换与路由技术》课程的期末复习需求。在复习过程中，我们发现教材习题和课后练习分散在 Word 文档和 PPT 中，每次复习都需要手动翻阅、手动对答案，非常不便。于是想到开发一个能够自动解析题目、在线答题、自动判题并智能收录错题的 Web 系统，让复习更加高效。

大概是什么产品：一个纯前端 Web 应用，支持从 Word 文档自动识别题目（AI 辅助）、在线答题与自动判题、错题本管理、多课程切换、学习进度统计等功能，学生只需打开浏览器即可开始复习。

2

目标用户及痛点

面向哪些用户：

  • 高校学生：尤其是计算机、网络工程、通信等专业的学生，需要应对多门课程的期末考试
  • 自学者：通过教材自学并希望进行系统性练习的人群
  • 教师/助教：希望为学生提供在线练习平台的教师

在什么场景下使用：

  • 期末冲刺阶段：学生需要在短时间内系统性地复习大量题目，通过错题本反复练习薄弱环节
  • 日常课后练习：学完一章后，立即在线完成对应章节的练习题，即时查看解析
  • 考前模拟自测：利用筛选功能按章节、题型组卷，模拟真实考试环境
  • 碎片化学习：手机、平板、电脑均可访问，随时随地复习

当前痛点（如果没有这个产品）：

📝

题目分散难管理

复习题散落在 Word、PPT、纸质教材中，查找和整理耗时费力，无法快速定位薄弱章节。

❌

无法自动判题

做完题后需要手动翻到答案页核对，选择题、判断题尚可，填空题和简答题核对更加繁琐。

📚

错题无法系统收录

做错的题目没有统一的收集和管理方式，考前无法针对性地复习错题，同样的错误反复出现。

📈

学习进度不透明

不知道自己已经做了多少题、正确率如何、哪些章节需要加强，复习缺乏数据支撑。

3

价值与意义

🚀 效率提升

将传统的"翻书做题 → 手动对答案 → 手工记错题"三步流程，压缩为"在线答题 → 即时判题 → 自动收录错题"一步完成。支持 AI 智能识别 Word 文档中的题目，大幅减少题目录入成本。学习进度实时统计，帮助学生精准定位薄弱环节，避免无效重复复习。

🎓 教育公平

纯前端架构意味着无需服务器、无需付费订阅，任何有浏览器的学生都可以免费使用。数据存储在本地（LocalStorage），保护隐私的同时降低了使用门槛。让不同地区、不同学校的学生都能享受到智能化的复习工具，促进教育资源的公平获取。

🔧 技术价值

项目展示了纯前端 Web 应用的完整能力：Word 文档解析（mammoth.js）、AI 题目识别、本地数据持久化、响应式 UI 设计、多课程架构。为前端开发学习者提供了一个真实、完整、可运行的项目参考，具有教学和示范价值。

4

技术实现亮点

核心技术栈：

HTML5 CSS3 JavaScript (ES6+) LocalStorage mammoth.js AI 文档识别
🤖

AI 智能题目识别

支持上传 Word 文档或图片，通过 AI 自动识别并解析题目内容，自动分类题型（单选/判断/填空/简答），减少人工录入。

💾

纯前端无后端

所有数据通过 LocalStorage 本地存储，无需服务器部署，打开即用，数据隐私完全由用户掌控。

🌏

多课程架构

支持多课程切换（当前已实现"交换与路由技术"和"数据结构"两门课程），数据隔离存储，可扩展至任意学科。

📊

智能错题本

答错题目自动收录至错题本，支持手动添加/移除、错题重做、按章节/题型筛选，答对后可手动移出。
