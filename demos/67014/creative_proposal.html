指尖非遗工坊 V12

九项非遗技艺的沉浸式互动学习平台，让传统文化在指尖「活」起来

1创意介绍

非遗技艺是中华文明的重要载体，但传统传承方式往往依赖面对面教学、真实耗材和长期练习，学习门槛高、试错成本大、优质师资稀缺。年轻群体虽然对传统文化有兴趣，却苦于缺乏低成本、可反复练习、能即时反馈的数字化学习工具。

指尖非遗工坊 V12 正是为了解决这一痛点而诞生的 Web 互动学习平台。平台以 React + Vite + TypeScript 构建，集成剪纸、扎染、皮影、木版年画、云锦织造、木结构营造、活字印刷、宣纸制作、针灸认知九项非遗技艺，用户通过点击、拖拽、绘制等简单交互即可完成作品，并由 AI 实时给出四维评分与改进建议。

核心创新点：不是让 AI 替用户完成作品，而是将「流程导览 → 动手操作 → AI 点评 → 作品沉淀 → 学习报告」完整闭环搬到浏览器中，让每个人都能在零耗材、零风险的环境下反复体验非遗之美。

2九项非遗工坊

每个工坊都包含三种主题、不同难度、独立目标与专属 AI 评分策略，确保九项技艺互不雷同、各有侧重。

✂️

剪纸工坊

沿虚线描剪，镜像生成窗花；不同主题目标线稿完全不同。

🎨

扎染工坊

按目标放置绑扎点，再滴入指定颜色；不同折法目标点位不同。

🎭

皮影工坊

按角色要求完成动作序列；角色外形和表演目标各不相同。

🖼️

木版年画

把印章盖到目标轮廓附近，颜色和位置都要匹配。

🧵

云锦织造

按目标色谱逐行穿梭，指定行加金线；三种主题纹样不同。

🏛️

木结构营造

按槽位和顺序拼装构件；三个关卡结构图完全不同。

🖨️

活字印刷

在混合字盘里按顺序找字、排版、上墨、拓印。

📜

宣纸制作

按目标配方调纤维和水分，完成抄纸、摇帘、压榨、滴墨测试。

💆

针灸认知

文化认知：根据提示点击穴位位置，不提供医疗建议或针刺指导。

4目标用户与使用场景

核心用户

中小学生、大学生、传统文化爱好者、学校教师、博物馆与文旅场馆导览人员、家庭教育用户。

使用场景

  • 课堂教学：老师在多媒体教室投屏演示，学生同步在电脑上操作。
  • 研学活动：博物馆、非遗基地作为数字体验环节，降低真实耗材成本。
  • 课后自学：学生在家反复练习，不受时间和材料限制。
  • 路演展示：作品墙、数据看板、学习报告构成完整的项目展示素材。

当前痛点

没有产品时，用户只能通过短视频或图文教程「单向观看」，无法判断自己的剪纸是否沿虚线、皮影动作顺序是否正确、木版年画颜色是否匹配；传统教学还需准备真实材料，一位老师难以同时指导多名学生。

5技术实现

项目采用现代前端技术栈，保证开发效率、可维护性与用户体验。

React 18 Vite 6 TypeScript 5 Tailwind CSS Zustand HTML5 Canvas localStorage DOMPurify
🛡️

安全与可访问性

使用 DOMPurify 对动态 HTML 内容消毒；为画布添加 aria-label；为模态框提供 ESC 关闭、焦点陷阱与焦点管理；使用 ErrorBoundary 防止单个工坊异常导致全局白屏。

6价值与意义

社会价值

以数字化方式降低非遗学习门槛，让传统文化从「博物馆里的展品」变成「指尖上的体验」，帮助青少年建立文化认同感，助力非遗的活态传承与普惠教育。

效率价值

通过统一的四维评分体系与 AI 实时点评，平台能够替代部分人工批改工作，让老师把精力放在教学设计而非重复指导上，显著提升非遗课程的教学效率。

教育价值

每个工坊都强调「流程、顺序、准确性」而非单纯结果，培养学生的耐心、观察力与对传统文化的尊重，契合新课标对传统文化教育的要求。

让非遗技艺触手可及

指尖非遗工坊 V12 致力于用 AI 互动技术，让每一个人都能在安全、低成本、可反复练习的环境中，感受中华非遗文化的独特魅力。
