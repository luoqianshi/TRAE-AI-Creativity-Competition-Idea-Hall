学境 Quest

让学习成为一场精彩的冒险

TRAE AI 创造力大赛 · 学习工作赛道

一、创意名称 + 创意介绍

想解决什么问题

计算机专业学生面对海量课程，常常陷入"学了就忘、不知如何进阶"的困境。传统课程缺乏连贯性和趣味性，学习进度难以追踪，编程实践与理论脱节。学生需要一个能将知识串联起来、用游戏化方式驱动学习的工具。

为什么会想到做这个

作为计算机专业学生，我深知从零到一掌握技术栈的痛苦——教材枯燥、课程零散、缺乏即时反馈。如果能把学习变成"闯关升级"，每一步都有明确目标和成就感，学习效率会大幅提升。

大概是什么产品

一款面向在校计算机学生的移动端学习 App，以关卡闯关为核心，覆盖 AI/数据/算法与前后端开发方向，支持用户自定义课程资源与小组协作学习。

二、目标用户及痛点

面向哪些用户

在校计算机及相关专业学生（大一至大四），以及想要系统学习编程的转专业学生。

在什么场景下使用

课前预习、课后复习、期末备考、技能进阶、求职前系统化刷题。

当前痛点

  • 课程内容碎片化，学完一门不知道下一门该学什么
  • 缺乏即时反馈，编程作业提交后不知错在哪
  • 学习进度不可见，难以坚持
  • 纯理论学习枯燥，缺乏实战项目串联
  • 优质学习资源分散，难以发现和管理

三、价值与意义

🚀 效率提升

通过"知识学习 + 闯关挑战 + 即时反馈"的闭环，让学生每一步学习都有明确目标。关卡解锁机制确保知识体系的连贯性，避免盲目学习。自动判题功能让编程练习获得即时反馈，大幅提高学习效率。

🌍 社会价值

降低计算机学习的门槛，让更多学生能系统性地掌握编程技能。游戏化激励机制（XP、徽章、排行榜）激发学习兴趣，帮助学生建立持续学习的习惯，为未来的职业发展打下坚实基础。

核心优势：开源免费（无门槛使用）、高度可扩展（自定义学习空间）、社区驱动（小组协作共享）

四、核心功能模块

🎮 过关系统

课程拆解为关卡，每关 = 学知识 + 闯关挑战。通过后解锁下一关，编程题采用测试用例自动判分，参考 ICPC 检测机制。

📚 课程学习

支持多种格式学习资料，用户可自定义上传课程文件，整合现有公开课程资源，随用随取。

💻 在线编程

内置代码编辑器，支持多语言，沙箱隔离运行代码，检查时间/空间复杂度和代码规范。

🌳 学习路径图

技能树可视化，展示已通关/未解锁/锁定状态，跟踪学习进度，管理相关文档。

🏆 成就与激励

XP 经验、徽章、连续打卡、排行榜，代码质量排名奖励机制，激发学习动力。

👥 小组协作

建立小组空间，成员共享资源，基于角色的权限体系，支持上传、编辑、删除、审核等细粒度控制。

五、平台能力

安全保障

  • 代码运行采用沙箱隔离机制
  • 代码扫描、资源配额、网络访问控制
  • 异常行为监控，防范恶意代码、挖矿和病毒风险

内容治理

  • 机器审核（1小时内完成）+ 人工定时抽查审核
  • 违规内容驳回处理
  • 标签分类、搜索筛选、综合排序、榜单和编辑精选

离线学习

  • 课程资料、练习题、示例代码和部分视频可提前缓存
  • 无网络环境下可继续学习和编辑代码
  • 联网后自动同步进度

六、课程内容体系

方向一：AI / 数据 / 算法

  • 模块 1：Python 基础
  • 模块 2：NumPy/Pandas
  • 模块 3：数据可视化
  • 模块 4：机器学习入门
  • 模块 5：深度学习基础
  • 模块 6：综合项目（Boss 关）

方向二：前端/后端开发

  • 前端：HTML/CSS → JavaScript → React → 综合项目
  • 后端：Node.js 基础 → Express/NestJS → 数据库 → API 设计 → 综合项目

每个模块拆为 5–10 个关卡，关卡内含学习内容 + 1 个闯关挑战。

七、技术架构

移动端

React Native + Expo，React Navigation、Zustand、AsyncStorage，支持离线缓存、推送通知、代码编辑器组件。

后端

Node.js + NestJS，REST API、JWT 鉴权、WebSocket 实时判题状态。

数据库

PostgreSQL（业务数据存储），Redis（缓存、排行榜、判题队列）。

判题服务

Docker 沙箱隔离，执行用户代码，参考 ICPC 检测机制。

八、运营模式

开源免费

  • 核心功能完全免费，无门槛使用
  • 代码开源，鼓励社区贡献和二次开发

可持续发展

  • 捐赠机制：接受用户自愿捐赠
  • 企业赞助：与科技企业合作，获得资金支持
  • 企业合作：提供定制化服务或企业版
