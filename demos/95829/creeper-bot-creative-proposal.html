CREEPER BOT

像素风桌面陪伴硬件 | ESP32 + Web 控制

创意介绍

想解决什么问题：

市面上缺乏兼具游戏情怀和真实物理交互的桌面陪伴硬件，玩家想要一个既能表达个性又能实时互动的桌面伙伴。

灵感来源：

Minecraft 中 iconic 的苦力怕角色，结合 ESP32 的 WiFi 能力和伺服电机，让像素角色走出屏幕，成为可触摸、可控制的实体伙伴。

产品形态：

基于 ESP32 的 WiFi 控制桌面硬件 + 手机端 Web 控制面板，无需安装 App，扫码即用。

目标用户及痛点

面向用户：

  • Minecraft 玩家与游戏文化爱好者
  • 桌面文化 / 极客桌搭爱好者
  • 想要趣味 IoT 入门体验的新手开发者

使用场景：

  • 办公桌上的情绪调节器，工作累了戳一下
  • 直播间 / 视频背景的动态道具
  • 朋友聚会时的互动玩具

当前痛点：

  • 静态手办只能看，无法互动
  • 现有智能硬件控制复杂，需要装多个 App
  • 缺少有游戏 IP 情怀的低成本交互硬件

价值与意义

商业价值：游戏 IP 情怀 + 低成本 IoT 硬件，具备开源复刻和 DIY 套件化潜力，适合作为入门创客教育产品。

社会价值：降低智能硬件开发门槛，展示"一个 ESP32 + 网页技术"就能做出有趣的实体交互作品，鼓励更多人动手创造。

开发计划

  • Week 1: ESP32 固件开发（WiFi AP + Web Server + 舵机控制）
  • Week 2: Web 控制面板前端开发（响应式 + 像素风 UI）
  • Week 3: 结构设计与外壳 3D 打印
  • Week 4: 集成测试 + 交互优化
