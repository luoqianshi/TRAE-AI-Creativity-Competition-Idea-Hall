# 茶鉴 · 产品需求文档（PRD）

## 1. 产品概述

茶鉴是一款 AI 驱动的沉浸式评茶入门助手，通过"标准拍摄卡（硬件）+ 小程序（软件）"软硬结合的方式，帮助对茶文化有兴趣但缺乏品鉴自信的入门者，以及正在系统学评茶的进阶爱好者，看懂茶、喝懂茶、泡好茶，并沉淀为可追踪的个人品茶数据库。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心诉求 |
|------|----------|----------|
| 入门爱好者 | 注册即用 | 看懂术语、敢于评价、跟泡入门 |
| 进阶爱好者 | 注册即用 | 系统记录笔记、对比品鉴、追踪成长 |
| 茶商/茶馆 | 注册即用 | 向客户展示茶叶品质、陈列茶器 |

### 2.2 功能模块

本次 Demo 范围聚焦于 5 个核心页面：

1. **首页**：今日推荐 Agent、最近品鉴记录、底部导航栏
2. **拍照识别页**：相机界面 + 标准拍摄卡引导框、干茶/茶汤/叶底切换、AI 评分卡片
3. **Agent 点评页**：岩茶陈师傅 vs 普洱老茶客 对同一茶汤的不同点评切换
4. **跟着泡页面**：Keep 式跟练，顶部计时器、步骤引导动画、步骤说明、下一步按钮
5. **数字博古架页面**：多宝格布局陈列茶器标准照，空位虚线框 + 加号

## 3. 核心流程

用户打开茶鉴后，默认进入首页。从首页"今日推荐 Agent"可一键跳转拍照识别页；在拍照识别页选定"茶汤"并拍摄后，AI 评分卡片弹出，下方有"请师傅点评"入口进入 Agent 点评页；在 Agent 点评页可切换两位师傅查看不同风格点评，底部"跟着泡一杯"入口跳转到跟着泡页面。底部导航栏支持在五个主页面间任意切换。所有拍摄、跟泡记录会自动归档为个人品鉴日志（Demo 中以"最近品鉴记录"形式呈现）。

## 4. 用户界面设计

### 4.1 设计风格

- **整体气质**：素雅、温润、有茶文化的高级感，同时具备现代感，参考"潮汐""MOO 音乐"的质感
- **主色调**：暖白 `#F7F3EC` 作为底色（避免纯白），浅棕 `#B8997A` 作为辅助，墨绿 `#3E5641` 作为强调色，深褐 `#2C2419` 作为文字主色
- **辅助色**：汤色金 `#D4A857`（用于评分高亮）、淡墨 `#6B6660`（用于次级文字）
- **按钮风格**：圆角矩形（8–12px），主按钮为墨绿实色，次按钮为暖白底 + 浅棕描边，拍摄按钮为圆形大快门
- **字体**：标题使用衬线体（Noto Serif SC / Source Han Serif），正文使用无衬线体（Noto Sans SC），数字与计时器使用等宽特性字体
- **布局风格**：卡片式 + 留白充足，圆角 16–20px，柔和投影
- **图标/插画**：线性图标 + 极少量装饰元素，避免 emoji
- **动画原则**：过渡 240–360ms，缓动 `cubic-bezier(0.22, 0.61, 0.36, 1)`，整体"慢下来"

### 4.3 响应式

- **移动端优先**：固定画布 375×812（iPhone X），使用 `viewport` meta 锁定
- **桌面预览**：在桌面浏览器中居中展示手机外壳框（含圆角与刘海），两侧留白，背景为深色或木纹纹理
- **触摸优化**：所有可点击区域 ≥ 44×44px，底部导航与快门支持触感反馈视觉态

### 4.4 3D 场景说明

本 Demo 不涉及 3D 场景。所有视觉效果通过 CSS 渐变、阴影、SVG 与少量 JS 动画实现。
