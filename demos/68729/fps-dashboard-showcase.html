AI 模块设计器

这是本项目的核心特色功能 — 零代码自定义模块。无论是股票行情、粉丝数据、AI 用量还是硬件监控，只需要一句话描述，AI 即可自动完成。

🎯
自然语言描述需求

用中文或英文描述你想要的模块功能，AI 自动生成完整的 HTML+CSS+JS 代码。

输入："做一个网速监控模块，显示实时上传下载速度，用大号字体居中展示"
⚡
一键部署到网格

生成的模块代码自动注入布局引擎，无需重新编译 APK。即时预览，不满意可以重新生成。

🔗
PC 服务集成

模块可配置为依赖 PC 服务。系统自动注入 PC_HOST/PC_PORT 占位符，模块通过 HTTP 直连 PC 获取实时数据。

📦
完整 API 支持

AI 生成的代码可使用全部 PC 服务 API：硬件监控、媒体控制、进程管理、系统命令。接口文档自动注入上下文。

工作流程
1
在后台选择模块尺寸（如 1×2、2×2），点击 "AI 辅助设计"
2
输入自然语言需求，或选择预设模板（监控类、控制类、信息展示类）
3
AI 生成完整 HTML，适配墨水屏灰度 + 墨水屏安全 CSS + Android 4.2.2 兼容层
4
即时生效 — 保存后模块出现在仪表盘网格中，无需编译、无需重启、无需 Android 开发环境
关键技术保障
所有模块在运行时通过 CSS 注入将 flexbox 转为 float 布局（兼容 Android 4.2.2 WebView），内联 `` 通过 JS 重写避免 innerHTML 解析 bug，外部资源引用自动剥离。即使用户不会写一行代码，也能自由扩展仪表盘功能。

应用 场景

一块平板，无限可能

📈
股票 & 加密货币盯盘

实时展示多只股票/币种行情，涨跌变色标识。支持 A 股、美股、加密货币价格追踪。自定义关注列表，关键价位触发通知。

👥
社交媒体数据看板

聚合展示 B 站粉丝数、抖音播放量、微博互动数据。创作者一眼掌握全平台运营状况，无需逐一切换应用查看。

🤖
AI 服务用量监控

跟踪 OpenAI / Claude / 本地模型的 Token 消耗、API 调用次数、剩余额度。帮助开发者合理规划预算，避免超额。

🖥
PC 硬件 & 控制中心

实时展示 CPU/GPU/内存占用率，控制媒体播放、音量调节。通过宏键盘模块映射任意快捷键，替代 Stream Deck。

📶
网络 & 服务器监控

实时上传/下载速度、Ping 延迟、服务器在线状态。运维人员可自定义监控目标，支持多节点同时观察。

🧩
