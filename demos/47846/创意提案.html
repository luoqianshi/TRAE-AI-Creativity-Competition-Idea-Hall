01 / CREATIVE INTRODUCTION

创意介绍把每一张照片，变成一段异世界冒险

拍照是每个人每天都在做的事，但照片拍完就沉睡在相册。我们用 AI 把"任意一张照片"转化成有名字、有设定、有插画的奇幻物种，并由一个有记忆的星灵伙伴对此产生真实情感反应。

01

想解决什么问题

照片拍完即忘，缺乏"延续性"与"情感沉淀"。如何让一张普通照片，变成一段值得记住的异世界冒险记忆？

02

为什么会想到

收集养成游戏的收集物与现实无关、玩久易空虚；而 AIGC 多模态 + 文生图已能把任意照片变成奇幻物种——这是 AI 才能做的蓝海。

03

大概是什么产品

微信小程序。拍一张照片 → AI 一次调用完成"识别 + 转化 + 星灵反应" → 收入图鉴 → 解锁地图 → 建立长期情感羁绊。

02 / CORE LOOP

核心闭环一次拍照，五重惊喜

06 / TARGET USERS

目标用户谁会需要这样一个异世界

面向 18-30 岁热爱记录生活、喜欢收集养成与治愈系内容的年轻用户。

👥 核心用户画像

18-30 岁年轻女性为主，对收集养成、治愈系、奇幻题材有兴趣；喜欢拍照记录生活，但相册照片"拍完就忘"；想要低门槛、有情感陪伴感的小程序。

📍 典型使用场景

通勤路上看到一朵花，拍照收入"晨雾森林"；下午茶拍一杯咖啡，看 AI 把它转化成什么；睡前和星灵聊两句；周末整理图鉴回顾一周收集。

😣 当前痛点

拍照后没有延续性，照片沉睡相册；现有收集游戏收集物与现实无关；AI 工具类小程序多是一次性工具，没有长期情感钩子。

💡 我们的解法

用照片当"入场券"，AI 转化为专属物种；星灵有记忆有情绪，建立不可迁移的情感羁绊；6 大世界观 + 异世界地图，让收集变成冒险。

08 / ARCHITECTURE

技术架构AI 辅助开发 + AI 运行时能力

前端微信小程序原生 + 后端微信云开发 CloudBase，AI 能力统一走 TokenHub 端点（视觉 + 文本）+ CloudBase AI+（文生图）。

FRONTEND
微信小程序原生 · 5 个 tabBar 页（首页/拍照/世界/图鉴/我的）· 星灵形象系统纯 CSS 实现零额度消耗
BACKEND
微信云开发 CloudBase · Serverless 云函数（recognizeSpecies / spiritChat / updateSpirit / deleteSpecies / generateShareCard）
AI · 视觉
TokenHub hy-vision-2.0-instruct · 识别照片内容并理解画面（替代旧 hunyuan-vision）
AI · 文本
TokenHub hy3-preview · 物种转化 + 星灵对话 + 情绪 JSON 输出（替代旧 hunyuan-turbos-latest）
AI · 文生图
CloudBase AI+ hunyuan-image · 生成异世界物种插画（成长计划 1 万张免费额度）
DATABASE
云数据库 MongoDB · 5 集合（users / species / memories / spirit_state / conversations）· openid 隔离
SAFETY
微信官方 security.imgSecCheck · 每天 20 万次免费图片审核
