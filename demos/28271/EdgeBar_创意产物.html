核心特性

六大核心行为

复刻 Edge Bar 桌面分离模式的完整体验

📌

固定屏幕边缘

窗口锚定在屏幕右侧，占据整个屏幕高度，不会被其他普通窗口遮挡

📐

缩减桌面工作区

系统工作区自动减去侧边栏宽度，所有窗口最大化/Snap 时不覆盖该区域

👁️

始终可见

通过 Windows AppBar API 注册为系统级工具栏，与任务栏具有相同的桌面空间占用行为

↔️

可拖拽调宽

用户可拖拽左边缘自由调整侧边栏宽度（280px ~ 800px），适应不同使用场景

🫥

自动隐藏模式

鼠标离开时自动收起，靠近屏幕边缘时滑出，150ms 平滑动画过渡

🚀

开机自启 + 热键

支持随系统启动，Win + ` 全局热键快速切换显示/隐藏，系统托盘常驻

AppBar 工作流程

Windows AppBar API 核心流程

这是实现"固定到边缘 + 其他窗口自动避让"的唯一正确方式

1

注册 AppBar

向系统声明：我要成为一个应用桌面工具栏

SHAppBarMessage(ABM_NEW, ref abd)
2

查询可用位置

系统返回不与任务栏/其他 AppBar 冲突的区域

SHAppBarMessage(ABM_QUERYPOS, ref abd)
3

设定位置

系统自动修改桌面 Work Area，已最大化窗口立即收缩

SHAppBarMessage(ABM_SETPOS, ref abd)
4

移动窗口到指定位置

将窗口放置到系统分配的屏幕边缘位置

MoveWindow(hwnd, rc.Left, rc.Top, width, height, true)
5

响应系统通知

监听全屏应用、位置变化等事件，动态调整行为

ABN_POSCHANGED / ABN_FULLSCREENAPP
6

退出时注销

系统恢复原始 Work Area，桌面空间归还

SHAppBarMessage(ABM_REMOVE, ref abd)
