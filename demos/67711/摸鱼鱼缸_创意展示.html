灵感来源

办公室里所有人都在偷偷摸鱼——刷手机、发呆、假装看代码，但每个人都在"假装工作"。于是我们想：如果摸鱼本身能被设计成一件有仪式感、有反馈、不被发现的事呢？电子宠物（拓麻歌子）曾风靡一代人，如果把它升级成一个"反映你工作状态的活物"，会怎样？

产品形态

一个常驻桌面角落的电子鱼缸 Widget。鱼缸里养着代表你各项任务的"任务鱼"——你摸鱼时鱼欢快游动，你干活时鱼沉底打蔫。点击进入全屏"深潜模式"沉浸解压，一键 Boss Key 在 0.2 秒内伪装成 VS Code / Excel / 终端界面。

打工人的四重困境Pain Points

核心用户：22-35 岁办公室白领、程序员、互联网从业者——长时间对着电脑、工作节奏快、有摸鱼需求的群体。

社会价值 · 反内卷情绪出口

摸鱼鱼缸不鼓励偷懒，而是把"休息"重新定义为一件事关身心健康的事。当你的任务变成一条鱼——你休息它就活，你内卷它就死——产品用温柔又幽默的方式提醒用户：连鱼都知道要浮出水面换口气，你凭什么不休息？它为高压职场人群提供一个低门槛、无负罪感、不被发现的情绪出口，让"合理摸鱼"成为一种被许可的自我照顾。

🚀

商业价值 · 病毒传播 + 情感付费

传播天然：摸鱼神器自带社交货币，"我的鱼今天死了因为我开了 4 小时会"这类截图天然适合抖音传播，与大赛人气通道高度契合。

情感付费：稀有鱼皮肤、新深潜场景、自定义 Boss 皮肤可作为付费点。

用户黏性：任务鱼与每日工作状态绑定，形成"每天来看看我的鱼"的打卡习惯，日活留存天然高。
