01 / PROBLEM

想解决什么问题

我们在现场观察到的三个真实痛点

📍

访问位置失控

图纸一旦发到员工手机端，账号密码只能控制"谁能看"，无法控制"在哪里看"——图纸可能被带出工厂、在外部任意地点打开。

🔍

访问轨迹难追溯

发生工艺泄露或数据安全事件后，管理员无法回答"谁在什么时间、什么地点查阅了哪份文件"，缺少审计证据链。

📂

文件分散查找慢

PDF、Word、CAD 图散落在内网 OA、文件服务器、微信群等多个渠道，现场员工查找一份图纸平均耗时 3–5 分钟。

🔐

权限管理粗放

传统系统按部门分配权限过于粗放，无法与"是否在工作现场"这一关键条件联动——在职员能看，不在职时也一样能看。

02 / IDEATION

为什么会想到做这个

微信小程序的定位能力 × 企业文档管理需求的一次碰撞

在客户现场多次看到工人把生产图纸转发到私人群组、工程师在厂外讨论工艺参数。 既然微信小程序天然就在员工手机上，也具备定位能力， 何不把"能否查看文档"与"是否在厂区内"直接绑定？ 于是有了"物理围栏 = 数据边界"的核心思路。

03 / USERS

目标用户与使用场景

谁会用？在什么时候、什么地方用？

👷一线员工

车间工人、装配工、质检员，需要查阅本工位的装配图纸、工艺参数和抽样标准。

场景：在厂区车间工位上 → 打开小程序 → 查图 → 15 秒完成。

💼职能人员

采购、销售、物流等需要查阅产品基础档案、包装规格、物料清单的办公室员工。

场景：在厂区内办公室 → 按分类检索文档 → 快速导出或转发。

👨‍💼文档管理员

负责上传、分类、版本更新和权限配置的文档主管或 IT 管理员。

场景：在后台上传新图纸 → 设置分类与权限 → 绘制/更新厂区电子围栏。

📊审计与管理层

关注数据安全、访问行为与合规性的管理人员和安全审计人员。

场景：查看数据看板 → 追溯某份图纸的访问时间、人员与位置 → 生成审计报告。

💡 没有这款产品时，他们会遇到……

  • 图纸被员工转发到私人群，带出厂区后无法收回
  • 工艺参数在厂外被讨论，核心技术无法控制流向
  • 一次质量事故后，无法证明"谁看过、在哪里看过"关键文档
  • 文件散落在 OA、文件服务器、微信群，查找效率低
  • 离职员工账号未及时回收，仍能在外部访问敏感文件
  • 客户或第三方审查时，拿不出系统的访问审计数据
04 / VALUE

价值与意义

它能为企业带来什么真实改变

⚡效率提升

15 秒/ 单次查阅

把"进内网 OA → 搜索目录 → 下载 → 打开"的 3–5 分钟流程， 压缩为"打开小程序 → 定位通过 → 按分类直达"的 15 秒闭环。 现场员工的查阅效率提升 70% 以上， 减少等待与错找，直接服务于生产节奏。

🛡️数据安全与合规

三重安全防线

通过物理围栏 + 实时定位 + 访问日志三道关口， 把核心图纸、工艺参数的访问限定在厂区内，离开厂区自动锁定。 配合完整的 BrowseLog 访问记录（用户 × 时间 × 位置 × 文档）， 为制造企业的敏感数据建立"最后一公里"防线，可直接用于客户审计与内部合规。

05 / FEATURES

核心功能一览

围绕"文档、围栏、用户、日志"四大核心模块

📄

文档分类管理

按产品基础档案、生产图纸、包装要求、产品图片等结构化管理，支持多格式在线预览。

📍

电子围栏绘制

支持圆形 / 矩形 / 多边形三种围栏形态，精确描述厂区边界，并可设置多个独立围栏区域。

🔓

围栏内解锁

小程序端每 10 秒刷新定位，围栏内正常展示文档，外部自动锁定并提示需在厂区内查看。

👥

用户与角色

基于角色的访问控制（RBAC），不同岗位可访问不同分类的文档，与企业组织结构对齐。

📊

访问日志

记录每一次文档查阅——谁、什么时候、在什么位置、查看了哪份文件，用于审计与追溯。

📈

数据看板

后台提供统计视图：文档数量、活跃用户、访问频次、热门文档 TOP 10，辅助管理决策。
