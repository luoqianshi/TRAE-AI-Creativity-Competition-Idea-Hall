Pipeline

一条管线，九个阶段

每个阶段由独立的专业 Agent 执行，产出结构化文件，形成完整的设计资产链。

STAGE 01
页面定义
→ page-inventory.md
从 PRD 提取所有页面，建立页面清单与功能映射
STAGE 02
UX 架构
→ ux-architecture.md
分析用户心理、使用频率、场景，定义交互模式
STAGE 03
设计画像
→ 00-设计画像.md + 风格探索
八维设计画像 + 风格探索 HTML，锁定视觉方向
STAGE 04
Token 系统
→ design-tokens.json + CSS
完整的色彩、间距、字体、阴影 Token 定义
STAGE 05
生成页面
→ 13 个 HTML 页面
所有页面基于 Token 系统生成，风格统一
STAGE 06
文案审计
→ copy-audit-report.md
审查所有页面文案的一致性、语气和品牌调性
STAGE 07
无障碍审计
→ a11y-audit-report.md
检查色彩对比度、语义结构、可访问性
STAGE 08
Token 桥接
→ tailwind-config.js
将设计 Token 映射为 Tailwind 配置，可直接引入项目
STAGE 09
视觉资产
→ asset-manifest.md
记录所有视觉资产、图标、插图清单

Get Started

如何使用

三步启动，零配置门槛。

STEP 01
复制 skill 目录
将 design-director skill 目录复制到你的项目根目录，所有 Agent 配置即开即用。
STEP 02
填写项目配置
编辑 project-config.md，填入产品名称、PRD 路径、品牌信息，管线自动适配。
STEP 03
说"开始设计"
在 IDE 中对 AI 助手说出指令，9 个 Agent 依次执行，产出全部设计资产。
# 1. 复制 skill 到项目
cp -r skills/design-director ./my-project/.trae/skills/

# 2. 编辑 project-config.md
# 填入你的产品名称、PRD 路径、品牌偏好

# 3. 在 IDE 中对 AI 说
"开始设计"

# 管线自动执行，产出：
# ✓ page-inventory.md       ✓ ux-architecture.md
# ✓ 00-设计画像.md            ✓ design-tokens.json
# ✓ 13 个 HTML 页面           ✓ copy-audit-report.md
# ✓ a11y-audit-report.md    ✓ tailwind-config.js
# ✓ asset-manifest.md
