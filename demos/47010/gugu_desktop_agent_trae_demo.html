咕咕桌搭 Agent

一只放在桌面上的 AI 电子宠物。它通过屏幕表情、灯光、声音、实体按键和手机 App 与用户互动，帮助用户完成喝水、休息、专注、整理桌面、睡前放松等日常小任务。

产品核心功能

咕咕桌搭 Agent 不是单纯的提醒器，而是一个带有情绪反馈和实体互动的生活陪伴硬件。它把 AI Agent 的智能规划能力，转化成看得见、摸得到、能陪伴用户的桌面小伙伴。

🐣

实体电子宠物

小屏幕显示表情和状态，配合柔和灯效、提示音和震动反馈，让提醒不再像闹钟一样生硬，而是像宠物在陪你完成任务。

🎯

AI 日程小任务

用户输入今天想完成的事情，AI 自动拆成可执行的小任务，并安排适合的提醒节奏，例如喝水、休息、专注、收拾桌面。

🖐️

多模态硬件交互

支持触摸顶部、按下实体按钮、语音唤醒、手机 App 控制等多种交互方式，用户可以用最轻松的方式回应提醒。

💡

灯光情绪反馈

不同颜色和呼吸灯节奏代表不同状态：专注、休息、低电量、等待回应、任务完成，让用户不用看手机也能理解当前状态。

🌙

睡前放松模式

夜间自动切换柔和灯光和白噪音，引导用户完成拉伸、整理明日事项、放下手机等睡前流程。

🏆

养成式激励

完成任务后，桌面宠物会升级表情、解锁装扮和语音反馈，把枯燥的自律行为变成轻量游戏化体验。

使用流程

1
设定目标

在 App 中输入今天的计划，比如“写作 2 小时、少刷手机、多喝水”。

2
AI 拆解任务

Agent 自动生成轻量任务和提醒节奏，避免一次性计划太重导致放弃。

3
硬件陪伴提醒

桌面宠物通过表情、灯光和声音提醒用户，用户可触摸或按键回应。

4
形成习惯记录

每天生成小结，记录完成情况，并逐步调整更适合用户的提醒方式。

目标用户与场景

目标用户

长期坐在桌前学习、办公、剪辑、写作、画画、编程的人群；容易忘记喝水、久坐不动、拖延、熬夜刷手机的年轻用户；喜欢桌搭、电子宠物、治愈系小硬件的人群。

典型场景

学生宿舍、家庭书桌、办公室工位、创作者工作台。用户可以在学习、工作、休息、睡前等不同阶段，让咕咕 Agent 提供陪伴式提醒和轻量任务管理。

价值与意义

咕咕桌搭 Agent 的意义在于，它把 AI 从手机和电脑屏幕里“拿出来”，变成一个能通过硬件与用户互动的生活陪伴物。相比普通待办软件，它更有情绪反馈；相比普通闹钟，它更智能；相比纯聊天 AI，它更贴近日常真实场景。

轻量降低自律压力
可爱提升使用意愿
实体减少手机依赖
长期养成生活习惯

商业化方向

咕咕桌搭 Agent 可以采用“硬件销售 + App 会员 + 虚拟装扮”的商业模式。基础硬件提供屏幕、灯光、按键和基础提醒能力；会员服务提供更智能的日程规划、个性化语音、睡前模式、数据回顾等功能；虚拟装扮和表情包可以满足年轻用户个性化桌搭需求，形成持续消费空间。
