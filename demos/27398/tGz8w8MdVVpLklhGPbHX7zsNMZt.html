人生十字路口 · 决策教练

不是替你做决定，而是 summon 多位专家顾问，帮你理清纠结、看见盲区、找到最适合你的路。

一、创意介绍

学习工作赛道

想解决什么问题

人在面临重大决策时（换工作、选城市、要不要读研、分手还是继续），常常陷入反复纠结、信息过载、无法客观评估的困境。现有的工具要么太轻（投票、抛硬币），要么太重（Excel 打分表），缺少一个能真正通过对话理清思路的智能助手。

为什么会想到做这个

看到太多朋友在微信群里反复问"大家帮我看看选哪个"，得到的建议五花八门反而更焦虑。受 Professor Synapse 多专家辩论模式的启发，希望能用 AI Agent 的多视角能力，帮人真正理清自己的纠结。

产品形态

Web 应用 (Vue 3 + PHP)，AI Agent 对话式交互

二、目标用户及痛点

面向哪些用户

18-35 岁年轻人，正在面临职业选择、城市变迁、教育路径、人际关系等重大人生决策的人群。

在什么场景下使用

深夜焦虑时、拿到多个 offer 时、犹豫要不要分手时、纠结要不要换城市发展时——总之任何需要认真决策、需要客观帮自己理清思路的时刻。

当前痛点

  • 找朋友聊：朋友的身份和立场会偏颇，给的建议有倾向性
  • 自己列清单：缺乏系统性的框架，容易漏掉关键维度
  • 用 AI 问一次：单一视角的回答，缺乏深度追问，结论太浅

三、核心方案：多专家辩论决策模型

产品核心是一个 AI 决策教练 + 多专家辩论 的对话系统。当用户说出自己的纠结时，系统会经历四个阶段：

PHASE 1

决策识别

AI 分析用户输入，判断决策类型（职业/生活/情感/综合），自动选择最匹配的三位专家组成顾问团。

PHASE 2

专家独立分析

每位专家依次向用户深度追问，从各自专业视角收集关键信息，形成初步判断。

PHASE 3

专家辩论

决策教练主持圆桌辩论，三位专家基于同一组数据给出分析，产生观点碰撞。

PHASE 4

综合报告

生成结构化决策报告卡：维度对比 + 矛盾洞察 + 分阶段策略 + 行动清单。

专家角色示例（动态召唤）

💼

职业发展顾问

职业路径 / 行业趋势 / 技能成长

🧘

生活方式教练

幸福感 / 压力 / 社交 / 日常节奏

💰

财务规划师

收入 / 储蓄 / 房价 / 长期财务

根据决策类型动态切换专家阵容，如情感类换为 ❤️ 情感关系教练

最终产出：决策报告卡

多维度加权对比

每位专家对各选项分别打分，结合您的价值观权重，生成可视化对比图

核心矛盾洞察

AI 提炼对话中暴露的价值观冲突："你嘴上说要生活质量，但你的职业规划都在追求天花板"

分阶段策略建议

不是简单地选 A/B，而是给出"如果选 A，接下来三步怎么走"的路径规划

可执行行动清单

具体到：约谁聊聊、查什么数据、什么时间点做决定，推着你往前走

四、技术方案

Vue 3 PHP LLM API ECharts TRAE IDE

前端使用 Vue 3 构建对话式 UI，后端 PHP 处理 Agent 调度和 API 路由。AI Agent 层包含决策识别器、专家角色管理器、辩论主持人、报告生成器四个核心组件，通过 LLM prompt engineering 实现多角色协作。

一份纠结 → 三位专家 → 四次追问 → 一张决策路线图

五、价值与意义

效率提升：把人们通常需要反复讨论、列清单、纠结几周的决策过程，压缩到一次 15-20 分钟的深度对话中完成结构化分析。

社会价值：帮助年轻人做出更理性的重大人生决策，减少因信息不足或情绪冲动导致的决策后悔。每个人一生都会面临多次"十字路口"，好的决策工具能带来实打实的人生质量提升。
