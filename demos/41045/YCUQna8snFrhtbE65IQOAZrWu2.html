4 应用层 🌐
HTTP / HTTPS / FTP / DNS / SMTP
为应用程序提供网络服务，处理应用程序级别的数据交换，如浏览器访问、邮件发送等。
3 传输层 📡
TCP / UDP
负责端到端的数据传输，TCP提供可靠的面向连接服务，UDP提供无连接的快速传输。
2 网络层 🗺️
IP / ICMP / ARP
负责数据包的路由和转发，使用IP地址在网络中找到目标主机。
1 网络接口层 🔌
以太网 / WiFi / PPP
负责物理介质上的数据传输，处理比特流的发送和接收。
