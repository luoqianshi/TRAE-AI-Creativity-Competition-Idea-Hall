创意介绍 // OVERVIEW

想解决什么问题

坦克动荡2是一个经典的Flash游戏，简单而有趣，但是其AI没有智能，只是凭借数值碾压，不够有趣，且不支持联网对战和多人房间。

为什么会想到做这个

让AI成为真正的对手 —— 通过深度神经网络+强化学习，让每一局对战都充满未知，AI会学习你的习惯，预判你的走位，同时支持多人联网实时对战。

大概是什么产品

跨平台智能对战引擎 —— Go服务端驱动的高并发实时对战 + HTML5网页客户端 + 自主进化的神经网络AI系统。

技术架构 // ARCHITECTURE

01
客户端层
HTML5 / Canvas 网页客户端
▶

基于Canvas 2D的网页游戏客户端，支持键鼠操控，无需安装即可在浏览器中运行，实现真正的跨平台对战体验。

02
通信层
WebSocket + JSON 实时同步
▶

20Hz状态同步频率，低延迟WebSocket连接，JSON协议轻量高效，支持1-8人同房间实时对战。

03
服务端层
Go 1.22+ 高并发引擎
▶

房间管理、物理引擎（碰撞/反射/向量）、地图生成（迷宫+边模型）、道具系统、积分排行等核心游戏逻辑。

04
AI推理层
gRPC + Python GPU 神经网络
▶

GRU(128)时序网络 + 4层512 MLP策略网络，PPO+GAE+SSL在线训练，127万参数，16种AI行为模式，GPU CUDA推理加速。

05
外挂加速层
C++ 弹道计算 DLL
▶

几何镜像射击、投影闪避、最短路径寻路、弹道雷达等12个导出函数，MinGW编译CGO绑定，高性能几何算法替代暴力遍历。

价值与意义 // VALUE

商业价值

跨平台架构降低用户获取门槛，无需安装即可游玩。商业化以皮肤为主，或采用买断/付费订阅AI/联机服务器模式，不牺牲游戏体验。道具与皮肤提供个性化选择，创造可持续收入。

技术价值

完整的游戏服务端开发实践，涵盖高并发WebSocket、物理同步、状态管理。神经网络+强化学习在游戏AI中的工程化落地，GRU时序决策、PPO在线训练、遗传变异进化。C++/Go/Python多语言协作架构参考。

社会价值

AI训练框架开源可复用，降低游戏AI开发门槛。可作为高校计算机/AI专业教学案例，涵盖网络编程、物理引擎、机器学习。轻量级娱乐适合全年龄段，促进社交互动与团队协作。
