创意介绍

当经典手游遇上体感交互，会碰撞出怎样的火花？

🎯

解决什么问题

传统愤怒的小鸟只能用鼠标/触屏操作，交互方式单一。玩家无法获得"亲手拉弓发射"的沉浸感，体感游戏领域也缺少轻量级、即开即玩的 PC 端产品。

💡

灵感来源

看到 Switch 体感游戏的火爆，但 PC 端缺少类似的轻量级体感体验。想到用摄像头+手势识别，让玩家真正"用手"拉弹弓，把愤怒的小鸟从触屏游戏升级为体感游戏。

🎮

产品形态

PC 桌面应用（Python + Pygame），无需额外硬件，只需一个普通摄像头即可游玩。支持手势和鼠标双模式，18个单人关卡 + 5个双人协作关卡。

🖐️ 手势识别引擎
基于 MediaPipe Hand Landmarker 实时检测 21 个手部关键点，置信度阈值 0.6（高于默认 0.3），大幅减少误检。使用掌心坐标（landmark 9）替代指尖，稳定性提升 40%+。
🔄 One-Euro Filter
采用 CHI 2012 学术论文算法，动态截止频率随手部速度调整：手慢→强滤波→去抖，手快→弱滤波→低延迟。配合运动预测补偿，消除 30-50ms 推理延迟。
✊ 握拳检测 v4
三指标融合判定：指尖到掌心距离（权重3）+ 手指弯曲角度（权重2）+ 拇指收拢（权重1）。时序滞后阈值防止状态闪烁，力度保护机制防止快速移动中误发射。
🎮 物理引擎
基于 Pymunk 2D 物理引擎，真实模拟弹弓发射、碰撞、倒塌。5种小鸟（红/蓝/黄/黑/白）各有特殊能力，3种材质方块（玻璃/木头/石头），18+5关卡。

开发历程

从开源项目到体感升级，每一步都踩过坑

Phase 1 · 基础游戏搭建

基于 marblexu/PythonAngryBirds 开源项目，搭建 Pygame + Pymunk 物理引擎基础。实现5种小鸟、3种方块、18个关卡。

Phase 2 · 手势控制集成

集成 MediaPipe Hand Landmarker，实现实时手部追踪。初始版本使用简单 EMA 滤波，抖动严重，体验极差。

Phase 3 · 信号处理优化

引入 CHI 2012 论文 One-Euro Filter 替代 EMA，动态截止频率解决"慢手抖、快手延迟"矛盾。添加运动预测补偿推理延迟。

Phase 4 · 握拳检测精调

从单指标判定升级为三指标融合（指尖距离+弯曲角度+拇指收拢），添加时序滞后阈值和力度保护，误触率从 15% 降至 2%。

Phase 5 · 双人协作模式

新增 DualHandDetector 双手检测，5个协作关卡。两位玩家各用一只手控制不同弹弓，协作消灭猪猪。
