PART 01 / 报名帖 · SUBMISSION

这就是我们想做的

创意名称
CoCut — 实时标注器 + AI修改意见表
想解决什么问题
做短剧/视频的小团队，审片一直是"截图 + 语音 + 微信群"三件套。 上级/客户看完一集发十几张截图，每条意见都要剪辑师自己整理； 意见没结构、改一轮要反复确认，剪辑师精力全耗在"找问题"上。
为什么会想到做这个
用剪映做短剧剪辑时发现：剪映有标注功能，但无法实时共享给多人。 每次审片都要导出成片、发链接、等意见、再手动整理成表格。 能不能做一个"视频标注 + AI整理"的工具，让审片结束就能拿到一份可执行的修改意见表？
大概是什么产品
一个 Web 审片链接，多人可以同时在视频上标注，标注自动附带时间点和关键帧截图。 AI 自动整理成结构化修改意见表（序号、时间点、关键帧、修改意见、AI完善建议），支持一键导出 Excel。
面向哪些用户
① 短剧制作团队（2–10 人，需要导演/制片审核每一集）；
② 短视频代运营团队（为客户制作视频，需要客户审核确认）；
③ 企业视频团队（宣传片/培训视频，需要多部门审核）。
在什么场景下使用
剪辑师导出成片 → 发审片链接给上级/客户 → 多人异步标注 → AI自动整理修改意见表 → 剪辑师对着表格逐条修改。 核心场景：需要多人审核的一集集短剧/视频。
当前痛点
· 审片意见散落在微信截图+语音里，剪辑师要自己整理成表格；
· 截图没有时间戳，剪辑师要手动找对应画面位置；
· 意见没有优先级和状态追踪，分不清哪些改了、哪些没改；
· 模糊的意见（如"节奏不对"）需要反复沟通才能明确具体修改方案。
价值与意义 — 效率提升
把"审片→整理意见→修改"从 手工收集 + 手动整理，变成 AI自动整理 + 结构化输出。 审片结束就能拿到带时间戳和关键帧的修改意见表，剪辑师不用花时间整理，可以直接开始改片。 预计一轮审片的意见整理时间从 2–3 小时缩短到 5 分钟（约 90% 时间节省）。
价值与意义 — AI赋能
AI 不只做"整理"，还做"完善"——把上级一句模糊的"这里节奏不好"， 变成具体的修改建议（如"建议将此段转场从 0.5s 延长至 1.2s，或插入一段 B-roll 素材作为过渡"）。 让非专业人士也能给出专业级别的修改意见，降低沟通成本，提升修改一次通过率约 3 倍。

PART 03 / 功能亮点 · FEATURES

围绕"标注 · 整理 · 导出"三件事做深

⎔

多人实时标注

多人同时在视频画面上标注，点击任意位置添加批注，标注自动附带精确时间戳和当前帧关键图。

🤖

AI完善修改意见

AI 自动分析每条标注，把模糊的意见（如"节奏不好"）转化为具体参数建议（如"转场 0.5s→1.2s"）。

📋

结构化修改意见表

自动生成包含序号、时间点、关键帧截图、原始意见、AI建议、修改状态的完整表格，一目了然。

📥

一键导出 Excel/CSV

点击导出按钮即可下载结构化文件，剪辑师可以在表格中勾选完成状态，方便团队同步修改进度。

🖼️

关键帧自动截图

每次标注时自动截取当前帧作为参考图，表格中直接展示画面缩略图，剪辑师不用再反复拖动找位置。

✦

轻量化 · 无需安装

Web 审片链接，打开即用。客户/上级只需一个链接即可开始标注，无需下载安装任何软件。

LLM API Prompt Engineering JSON Schema
L4 · EXPORT

导出层 · 文件生成

将结构化意见表导出为 Excel (.xlsx)、CSV、HTML 格式。支持生成带时间戳跳转的链接，方便快速定位。

SheetJS Blob Download
为什么不直接做"剪映插件"？

剪映目前没有开放的插件体系，无法在其内部植入协作模块。所以我们把剪映当编辑器，CoCut 当标注+整理工具，通过时间戳链接让两边互通。

初期优先验证什么？

先做"标注 + AI整理 + 导出"闭环：能上传视频、多人标注、AI生成意见表、导出 Excel。这三步跑通了，就能验证用户是否愿意改变习惯用这个工具。
