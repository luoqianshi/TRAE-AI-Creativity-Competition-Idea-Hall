传统手机闹钟仅支持固定时间触发，无法应对当代职场人 "大小周"、"多地点通勤"、"弹性工作制" 等复杂生活节奏。WiseRing 用大模型理解你的意图，用地理围栏感知你的位置，用语音克隆温暖你的早晨。

随着 DeepSeek-V4 等国产大模型成本大幅下降、语音合成技术成熟（阿里 CosyVoice2 仅需3秒样本）， 用自然语言驱动复杂自动化规则已成为可能。WiseRing 瞄准全球约 15亿美元 的闹钟App市场， 以及中国 1.2亿 存在非固定作息的潜在用户。

闹钟响了二十年，

核心功能

六大模块，
构建 AI 闹钟的完整体验。

WiseRing 不是又一个闹钟 App。它是一个能理解上下文、能感知场景、能主动决策的智能时间助手。 从规则解析到语音唤醒，从地理感知到天气联动，每一个环节都经过精密设计。

MODULE 01

自然语言规则解析

用户通过语音或文字输入自然语言（如"我是大小周，周六单数上班，爸妈家早半小时"）， AI 调用 DeepSeek-V4 API 自动解析为结构化闹钟规则，生成可视化"规则卡片"供确认。 解析失败时平滑降级至手动模板。

MODULE 02

系统级保活 & 动态调度

所有规则转为 iOS 系统级通知闹钟（UNNotification），确保 App 被杀后仍准时触发。 针对 iOS 每个 App 最多 64 条待触发通知的限制，引入动态调度机制： 每日凌晨自动计算未来7天闹钟队列，确保不超限。

MODULE 03

大小周 / 单双休自动识别

设定大小周规则后，App 自动读取日历，根据周六日期奇偶判断当日是否响铃， 支持法定节假日调休数据的自动匹配。彻底解决"大小周总忘记调闹钟"这一高频痛点。

MODULE 04

多地点自动切换

预设多个地点（如"父母家"、"出租屋"），设定不同时间偏移。 通过 iOS CLCircularRegion 地理围栏 API（半径200-500米），仅在闹钟生效时段激活监控以降低功耗。

MODULE 05

AI 语音克隆唤醒

用户录制朗读语音，调用火山引擎声音复刻 API 生成专属模型。 若音乐未唤醒，自动切换本人声音播报（含时间、天气、日程）。 首次录制需活体检测+朗读随机文本，声纹数据加密存储，支持一键删除。

MODULE 06

通勤天气联动 & 日程嗅探

响铃前15分钟接入和风天气 + Apple MapKit，检测天气与路况，自动建议提前。 同时读取系统日历，识别"会议"、"航班"、"打卡"等关键词事件，提前弹窗提醒。

使用场景

四个场景，
覆盖一天中的每一个关键时刻。

场景一

大小周自动管理

周四晚，张明想起这周六是"单数"要上班。他打开 App 说："我是大小周，周六单数上班"。 AI 自动解析，显示"规则已创建：周六日期为单数时，7:30 响铃"。周六闹钟准时响起， 无需再次手动操作。从此告别"忘调闹钟"的焦虑。

01
场景二

多地点智能切换

李婷周一在父母家，周二回出租屋。App 通过地理围栏自动识别位置， 将闹钟提前30分钟，并在响铃时播报："今日通勤预计45分钟，有小雨，建议提前出发。" 换住处再也不用改闹钟，WiseRing 永远知道你在哪里。

02
场景三

渐进式强制唤醒

音乐闹钟响铃1分钟后仍未起床，App 自动切换为张明本人的声音播报： "张明，已经7:35了，今天9点有周会，请立刻起床！"语气从温柔到急促， 确保唤醒。这不是粗暴的噪音，而是来自你自己的关怀。

03
场景四

晚间打卡提醒

用户晚间常忘打卡。在 App 内设定规则："每个工作日18:00，弹窗提醒打卡"。 到点后系统发出轻量级本地通知，不干扰核心睡眠唤醒场景。 WiseRing 从"起床工具"延伸为"全天候生活管家"。

04
竞品分析

竞品做了很多，
但没有一个真正解决"智能"。

昴日验证了"自动识别非固定作息"的强需求，TimeScribe 验证了"自然语言设闹钟"的可行性， 但它们在规则引擎深度、地理位置感知、动态天气联动上均有明显短板。 WiseRing 是第一款将大模型意图识别、地理围栏、语音克隆融为一体的闹钟产品。

技术方案

轻量技术栈，
可控的成本结构。

前端采用 Swift + SwiftUI 确保原生体验与闹钟可靠性，后端使用 Python FastAPI 轻量开发。 部署于 Railway / Vercel，数据库使用 Supabase。月运营成本在 100-280 元之间（1000 DAU 规模）， 其中 DeepSeek-V4 API 占主要部分。
