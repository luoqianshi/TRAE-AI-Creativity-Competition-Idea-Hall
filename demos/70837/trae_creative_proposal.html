当前痛点：如果没有 IMAGINE，用户现在会遇到什么 →

1
没方向剧本到手，不知道角色和场景该长什么样。视觉方向决策全靠创作者经验和直觉，缺少结构化的风格引导。
2
说不出来看到参考图，视觉感受无法翻译成构图/光影/色彩/风格参数。提示词全靠试，每次都是"感觉不对"但说不清哪里不对。
3
看不清差别生成图和参考图的差距，只有模糊感觉，没有逐项诊断。改提示词全凭运气，迭代效率极低。

🎬 专注一件事：AI短剧的角色与场景生图

AI短剧制作的核心环节之一是生成角色和场景资产——女主角长什么样、赛博朋克城市什么调性。这个环节目前极度依赖创作者的经验和反复试错，是最痛、最高频、最耗时的瓶颈。

1
拿到剧本 → 需要决定角色/场景的视觉方向
"都市悬疑剧的女主角，应该是冷艳还是亲和？实验室场景用什么色调？" —— 不知道生什么图。
2
找参考图 → 确定了方向但不知道怎么写提示词
收藏了一堆参考图，知道要这种感觉，但"侧逆光""暖棕调""中景构图"这些参数不知道怎么写。
3
反复生成 → 凭感觉判断哪里不对
改了十几轮，写实变3D、比例失调、表情不对——缺少客观诊断，不知道问题出在哪。
4
图片众多 → 跨列操作繁琐，版本回溯困难
一个项目几十张图散布在多个生图列中，跨列对照、历史版本回溯、图片检索全靠手动——操作琐碎，效率极低。

⚡ 两个核心问题，一个Agent解决

问题一
🤔
不知道生什么图
有剧本、有角色设定，但不知道视觉方向怎么定。

"悬疑剧女主——冷艳还是亲和？"
"赛博朋克——霓虹紫还是冷蓝？"
"反派基地——工业风还是极简？"
Agent 做什么 → 输入剧本/角色描述 → 结合类型惯例给出风格建议 → 展示参考方向 → 用户选定后进入生图流程
问题二
😤
知道但生不出来
有参考图、有明确方向，但提示词写不到位。

"就要这种光影，怎么写？"
"出来了但不像——哪里不对？"
"改了几十轮，还是差一点"
Agent 做什么 → 右键参考图 → 路径一：结构化分析风格参数 → 自动拼提示词
生成结果 → 路径二：对比参考图诊断偏差 → 自动修正

🎯 Agent 交互：指哪改哪

Agent没有固定面板——它跟随你的焦点，出现在你正在看的地方。下面四张示意图基于 我想 创新型多列并行生图页面设计，展示 Agent 如何介入。

01
自定义光标 · 持续暴露入口
鼠标箭头右下角始终显示"右键呼叫Agent"。悬停在参考图上变为"右键分析参考图"，在生成图上变"右键诊断结果"。Agent不是藏起来的功能，而是一眼可见的存在。
02
右键唤醒 · 浮在焦点旁
不设固定侧边栏。Agent面板在鼠标点击处浮出，参数卡片在参考图旁展开，用户的眼睛不需要从操作对象上移开。
03
诊断标注 · 画在图上
不是弹出对比面板让你来回看——问题用箭头+标签直接标注在生成图上。红/黄/绿三色区分严重程度，一目了然。
04
自动操作 · Agent完成复杂流程
Agent不只是对话——它能自动执行复杂生图操作：分析参考图→创建多列并行探索不同风格→收集结果→对比诊断→修正重试。用户只需确认关键决策，中间的重复劳动全交给Agent。

🏆 差异化优势

📍

Agent不设固定侧边栏，跟随用户焦点出现在右键处。参数卡片浮在参考图旁，诊断标注画在生成图上——眼睛不需要离开操作对象。
🤖
Agent自动执行复杂流程
不只是对话——Agent能自动完成"分析参考图→创建多列并行探索→收集结果→对比诊断→修正重试"的完整工作流，用户只需在关键节点确认决策。
