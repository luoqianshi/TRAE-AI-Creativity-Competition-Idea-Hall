HOW IT WORKS

三步把声音变成画面

01

音频信号采集

Web Audio API 实时获取 AnalyserNode 的 frequencyData 与 timeDomainData，每 16ms 刷新一次频谱数据。

02

情感特征提取

结合 BPM 估计、能量曲线、调式识别三维度，把音频映射到 8 维情感向量（节奏、强度、明度、温度……）。

03

多通道渲染输出

Canvas 2D + WebGL 输出视觉层；同时调用 Vibration API 输出触觉层；情感标签驱动 UI 色彩与字幕动效。
