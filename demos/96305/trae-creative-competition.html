BaxCode

让 AI 工具协同工作 / Let AI Tools Work Together
💡 创意名称 + 创意介绍

BaxCode 是一个 AI 编程工具兼容融合平台，通过统一配置层聚合多个 AI 编程 CLI 工具（Claude Code、Codex CLI、Gemini CLI、Kimi Code 等），支持一键切换多种后端供应商（DeepSeek、MIMO、阿里云、字节跳动、硅基流动、vLLM 等）。

🎯 想解决什么问题
当前 AI 编程工具各自独立，用户需要频繁切换不同工具，每个工具都有自己的配置方式和 API 格式，导致开发效率低下、配置复杂。
💭 为什么会想到做这个
作为开发者，在使用不同 AI 编程工具时发现，每个工具都需要单独配置 API 密钥、切换后端供应商，操作繁琐且容易出错。希望有一个统一的平台来管理所有 AI 工具。
🚀 大概是什么产品
一款基于 Electron 的桌面应用程序，通过统一配置层聚合多个 AI 编程 CLI 工具，支持一键切换后端供应商，实现 AI 工具的协同工作。
⚡ 核心功能特性
