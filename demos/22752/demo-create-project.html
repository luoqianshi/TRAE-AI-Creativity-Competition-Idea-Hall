                    📖 工作原理
                
                

                    
为什么这么快？

                    
    
                        
  • 配置即代码：将所有参数抽象为 JSON 配置，替代大量交互提示
    • 
                        
  • 脚本接管：Node.js 脚本自动应答脚手架的交互问题，毫秒级响应
    • 
                        
  • 直接调用：跳过可视化页面，直接调用后端 API 生成代码
    • 
                        
  • 纯数据驱动：没有 LLM 生成过程，没有幻觉问题，结果100%可靠
    • 
                    

                    
                    
使用方式

                    
# 1. 准备配置文件
cat > config.json << 'EOF'
{
  "projectName": "demo-system",
  "projectCnName": "示例项目",
  "outputDir": "./output",
  "frontend": { "enabled": true, "framework": "vue3" },
  "backend": { "enabled": true, "components": ["redis", "mq"] }
}
EOF

# 2. 一键生成
node scripts/generator.js config.json

# 3. 启动项目
./scripts/dev-up.sh
