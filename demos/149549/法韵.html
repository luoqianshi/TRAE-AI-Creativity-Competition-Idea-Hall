Learning Loop

一次案例学习，形成六个连续动作

法韵不是输入问题、获得答案的一次性对话。学习者必须先完成自己的分析，AI导师再根据当前任务进行纠错和追问。

01导入材料从案例、判决书、书籍或公开内容建立学习来源。
02独立分析在裁判结论出现前，先建立自己的法律分析路径。
03导师纠错识别法律概念、论证结构和专业表达中的缺口。
04裁判对照完成独立判断后，再比较自己的路径与法院说理。
05对抗检验从反方立场、相似案例和事实变化检验结论。
06复习沉淀将学习结果转化为复习任务、法条关联和笔记。
Core Feature

法言法语纠错：纠正表达，也纠正思维

法韵不是把口语句子“润色得更像律师”，而是识别表达背后缺少的法律概念、主体关系和论证环节，再通过追问要求学习者重新组织答案。

14-Stage Mentoring

14个阶段，对外呈现为五类能力训练

页面不逐项公开阶段任务和推进规则，只展示学习者最终要形成的五类能力。

01案例理解

从复杂叙述中识别主体、关键事实、请求和程序背景。

02法律分析

建立规范、抗辩、构成要件与案件事实之间的结构。

03争点证明

理解争议焦点、举证责任、证据和待证事实的关系。

04判断检验

通过裁判对照、反方挑战和事实变体检验结论稳定性。

05长期沉淀

将案例经验转化为复习内容、法条关联和个人笔记。

Independent Judgment

先独立分析，再看法院怎么判

渐进解锁

裁判理由不会一开始就出现

在学习者完成必要分析前，法院结论与核心说理保持锁定，避免“看完答案再反推理由”的虚假掌握感。

事实材料独立分析导师追问裁判解锁
Adversarial Learning

得到结论后，还要经受反向检验

法韵会从相反立场、相似案例和关键事实变化三个方向继续追问，帮助学习者理解规则的适用边界。

反方质疑类案比较事实变体边界判断
Long-Term Learning

学习完成，不等于学习结束

法韵把一次案例训练继续延伸为主动复习、法条确认和知识沉淀，但只向外展示使用流程，不公开内部算法和模板。

01 · ACTIVE RECALL

主动召回复习

先独立回答，再查看AI评价、遗漏点和误解，最后完成自评并进入下一次复习。

独立回忆 → AI评价 → 用户自评 → 下次复习
02 · HUMAN REVIEW

法条人工确认

案例中提取的法律依据先进入候选区，经过编辑和确认后才进入正式法条库。

候选法条 → 人工核验 → 正式法条 → 案例关联
03 · KNOWLEDGE ASSET

可编辑知识沉淀

学习结果先生成草稿，用户预览和调整后，再下载、复制或写入个人知识库。

学习成果 → 可编辑草稿 → 用户批准 → 个人知识库
