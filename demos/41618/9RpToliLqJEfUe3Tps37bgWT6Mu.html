知识库智能助手

学习工作赛道

1. 创意介绍

想解决什么问题

企业IT部门和产品团队面临海量技术资料（产品彩页、白皮书、检测报告、报价单等）的管理难题：查找一份参数需要翻遍几十个PDF，编制招标参数时容易遗漏证明材料，报价单制作依赖人工经验容易出错。

灵感来源

在实际工作中，每次客户询问"某型号服务器支持多少块NVMe硬盘"时，都需要打开多个PDF逐一查找；编制招标参数时，37项参数对应20多份证明材料，人工核对极易遗漏。于是想到用AI构建一个"懂产品资料"的智能助手。

产品形态

一个基于 TRAE 工作流 + Python 工具链 + SQLite 全文索引的本地化知识库管理系统，支持智能检索、招标参数自动生成、证明材料自动匹配、白皮书截图自动提取。

核心创新点：不是简单的文件搜索，而是建立了"产品型号 -> 技术参数 -> 证明材料"的三层关联体系，让AI真正"读懂"技术文档。

2. 目标用户及痛点

核心用户群体

  • IT产品经理/售前工程师：需要快速响应客户技术咨询
  • 招投标专员：需要编制招标参数并匹配证明材料
  • 销售团队：需要生成配置报价单

使用场景

  • 客户询问"R5500 G6支持多少块NVMe硬盘"时，3秒内给出准确答案并附带白皮书页码
  • 编制招标参数时，自动生成34项参数并检查每项是否有对应证明材料
  • 从151页HDM3白皮书中精准定位23项管理功能的截图页码

当前痛点

  • 资料分散在几十个PDF中，没有统一索引，查找耗时
  • 招标参数编制依赖个人经验，容易遗漏或写错
  • 证明材料与参数项的对应关系需要人工维护，容易不同步
  • 从白皮书中提取功能截图需要逐页翻阅，效率极低

功能一：智能全文检索

基于 SQLite FTS5 + Trigram 分词器，支持中文关键词搜索。两段式搜索策略：先识别产品型号锁定文件范围，再扩展主题词（如"NVMe"扩展为"NVMe/U.2/E3.S/E1.S/UniBay"）提高命中率。

搜索示例：R5500 G6 NVMe
命中 8 个文件 | 耗时 18ms
  1. [产品内主题命中] H3C UniServer R5500 G6技术白皮书.pdf
     命中: NVMe硬盘、NVMe Slot、U.2 NVMe
     页码: P48-P52 (硬件规格表)
  2. [产品内主题命中] R5500 G6产品彩页.pdf
     命中: 最多支持24块NVMe
  3. [全文命中] R5500 G6招标参数.docx
     命中: 数据盘NVMe配置

功能二：招标参数自动生成

根据服务器型号和配置需求，自动生成完整的招标技术参数表（34项），包含硬件参数、管理功能、证明材料要求。支持R4930 G7和R5330 G7等多型号。

功能三：证明材料自动匹配

为每项招标参数自动匹配证明材料来源，生成覆盖对照表，标记"已覆盖/缺失/内容差异"状态。支持从白皮书自动提取功能截图作为证明。

功能四：白皮书截图自动提取

从151页HDM3技术白皮书中，通过关键词搜索精准定位23项管理功能的截图页码，自动提取为高清图片并生成证明文档。解决PDF页码偏移、目录页过滤、内容匹配验证等实际问题。

4. 价值与意义

效率提升

  • 资料查找：从人工翻PDF（5-10分钟）缩短到AI搜索（3秒），效率提升100倍+
  • 招标参数编制：从手工编写（2-3天）缩短到自动生成+人工审核（2-3小时），效率提升10倍+
  • 证明材料整理：从人工核对（1天）缩短到自动匹配（10分钟），效率提升50倍+

质量提升

  • 消除人为记忆偏差，所有参数可追溯至原始白皮书/彩页
  • 自动检查证明材料覆盖情况，避免投标时因证明缺失被废标
  • 建立"产品型号-技术参数-证明材料"的关联体系，知识可复用

社会价值

该方案可推广到任何需要管理大量技术文档的行业（制造业、医疗器械、建筑工程等），帮助企业建立可溯源、可验证的知识管理体系，降低对"老师傅经验"的依赖，让新人也能快速上手。

5. 技术实现亮点

FTS5索引优化

采用6项优化策略：automerge=8、pgsz=4096、usermerge=4、内存映射、rank列预计算、查询词扩展。单次搜索耗时从200ms优化到20ms。

PDF页码精准定位

解决白皮书PDF物理页码与印刷页码偏移问题，通过关键词搜索+目录页过滤（"..."密度检测）+内容验证三重机制，确保截图页码准确。

两段式搜索策略

第一轮识别产品型号锁定文件范围，第二轮扩展主题词提高命中率。例如"R5500 G6网卡"先锁定R5500 G6相关文件，再扩展"网卡/OCP/PCIe网卡/网络接口/NIC"。

Skill化经验沉淀

将项目经验沉淀为可复用的TRAE Skill（`bid-proof-builder`），包含完整的招标参数编制流程、证明材料管理规范、白皮书截图提取方法，便于迁移到新项目。

6. 使用 TRAE 的方式

本项目完全基于 TRAE 工作流构建，核心交互方式：

  • 自然语言查询：用户用中文提问，TRAE调用知识库索引工具自动搜索并返回答案
  • 文件生成：TRAE根据用户需求自动生成招标参数Word文档、证明材料清单、报价Excel表
  • 代码执行：TRAE执行Python脚本完成PDF截图提取、索引构建、覆盖检查等任务
  • Skill复用：将项目经验沉淀为TRAE Skill，新服务器型号可快速适配
