创意名称：Parrot Code（鹦鹉编程）

想解决什么问题

AI 编程工具的门槛依然很高——用户需要懂 Prompt 工程、会拆解任务、能管理上下文。Parrot Code 的核心理念是：把专业 Agent 包装成养成游戏，用户只需"养鹦鹉"，鹦鹉团队自动协作完成工作。

为什么会想到做这个

日常工作中大量流程化任务（写接口、改 Bug、跑测试、写文档）都需要人盯着 AI 来回调。如果把这些流程封装成不同角色的 Agent，再用养成化界面让用户"养"它们，用户只管提需求，剩下的交给鹦鹉团队。

大概是什么产品

一个养成化的 AI 编程助手，后端接入协同编排引擎，前端是可爱的小鹦鹉。每只鹦鹉都是一个专业 Agent，通过协同编排引擎串成流水线，像真正的团队一样开会、分工、交接。

🎯 需求鹦鹉

帮你把模糊想法整理成清晰需求，通过 BDD 模式（行为驱动开发）和你深入问答，构建完整场景。

🔍 分析鹦鹉

扫描现有代码，分析功能影响哪些地方，产出影响报告，避免改一个地方炸三个地方。

💻 开发鹦鹉

拿到分析报告后，开始写代码、改接口、处理依赖，一步步把功能落地。

✅ 测试鹦鹉

自动跑静态检查、单元测试、启动验证、页面检测，5 个维度全过才算完成。

📚 研究员鹦鹉

遇到复杂问题，负责查资料、做根因分析、产出研究报告，给其他鹦鹉提供决策依据。

养成机制

养成是 Parrot Code 的核心特色，但不是负担——它是一种新的协作模式，让 AI 编程变得更有趣、更有陪伴感。

📊 三维属性体系

每只鹦鹉有三个核心属性：成长值（任务积累）、压力值（连续工作累积）、心情值（受压力影响）。属性会实时变化，影响鹦鹉的工作效率和状态。

✨ 5 级稀有度 × 4 种性格

稀有度从普通到神话共 5 级，决定鹦鹉的基础能力上限。性格分沉稳、急躁、创造、学术 4 种，影响对话风格和工作方式。稀有度×性格的组合，让每只鹦鹉都是独一无二的。

🏠 虚拟经济与个性化

完成任务赚取"金羽毛"货币，可在装饰商店购买地板、墙纸、摆件。摆件具有减压效果，能降低鹦鹉压力值。用户可自由布置鸟舍，打造个性化的鹦鹉空间。

🎮 4 层交互架构

L1 鸟舍：总览所有鹦鹉和笼子，拖动布置鸟舍。
L2 笼子详情：查看团队属性，管理鹦鹉状态。
L3 团队协作：多只鹦鹉汇聚，给团队发消息。
L4 单鸟对话：与单只鹦鹉深入交流，注入差异化人设。

目标用户及痛点

面向哪些用户

  • 会用电脑、对 AI 感兴趣的普通用户（不需要会写代码）
  • 独立开发者 / 小团队，想用 AI 提效但嫌工具太复杂的
  • 喜欢养成类游戏、愿意花时间"养"一个 AI 助手的人

在什么场景下使用

  • 有一个想法想做成产品，但不知道怎么开始 → 鹦鹉团队一条龙帮你从想法变成可运行的产品
  • 日常开发中要改代码、加功能 → 分析鹦鹉扫描影响面，开发鹦鹉分工执行，测试鹦鹉自动验证
  • 遇到线上问题要排查 → 研究员鹦鹉根因分析，开发鹦鹉根据报告修复
  • 学习新技术或新领域 → 研究员鹦鹉帮你调研、整理、输出结构化报告

当前痛点

😫

AI 编程工具门槛高，不会写 Prompt 就用不好

🤯

深度使用 Vibe Coding 会使人大脑过载

😰

改代码怕炸，没有影响面分析，全靠经验猜

😤

专业流程散落在不同工具里，没人帮你串起来

😶

现有工具是"工具感"，没有"陪伴感"，用完就忘

价值与意义

🚀 降低 AI 编程门槛

不需要懂 Prompt Engineering，养一只鹦鹉就能干活。需求整理、影响分析、代码编写、自动测试这些专业流程都封装在鹦鹉的技能树里，用户只管表达想法。

💕 养成感带来粘性

不是冷冰冰的工具，而是你养大的鹦鹉。它有成长、有压力、有心情、有性格，你给它买装饰、陪它聊天、看它成长。这种"陪伴式 AI"比一次性工具有更强的用户粘性。

🤝 多 Agent 协作是未来方向

单个 Agent 能力有限，但一个团队各司其职就能完成复杂任务。协同编排引擎把需求、分析、开发、测试串成流水线，用户能感知到"我的鹦鹉团队在开会、分工、干活"。

🎨 让非程序员也能"编程"

产品经理、设计师、运营有想法但不会写代码。Parrot Code 让他们用自然语言"养成"一只会编程的鹦鹉团队，把想法直接变成可运行的产品。

与竞品的差异化

  • 比 Coze 更专业：文件管理更清晰、流程更完整（需求→分析→开发→测试一体化）、需求交互更深入（BDD 模式）
  • 比 Cursor/Copilot 更有趣：养成化界面让 AI 编程不再枯燥，缓解深度使用的大脑过载
  • 比 Devin 更灵活：用户可以自己指定哪只鹦鹉干活，也可以交给 UA 自动调度，鹦鹉就是你的员工
