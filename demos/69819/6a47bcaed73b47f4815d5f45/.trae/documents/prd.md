## 1. 产品概述

网页版批量文件重命名工具，提供多种智能重命名方式，帮助用户快速批量修改文件名，提升文件管理效率。

- 面向需要批量整理文件的用户：设计师、开发者、运营人员、普通办公用户
- 核心价值：无需安装软件，浏览器即可使用，支持多种重命名策略，实时预览效果

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册，直接使用 | 使用所有重命名功能，上传文件，预览效果，导出结果 |

### 2.2 功能模块

1. **文件上传区**：拖拽上传 / 点击选择文件，显示文件列表
2. **重命名方式选择**：6种重命名策略切换
3. **参数配置面板**：根据不同方式显示对应的配置项
4. **实时预览区**：左右对比显示原名和新名
5. **操作栏**：确定应用、重置、导出重命名映射表

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 文件上传区 | 支持拖拽和点击选择文件，显示文件总数，支持删除单个/全部文件 |
| 主页面 | 方式选择器 | 下拉选择6种重命名方式：前缀后缀、查找替换、追加序号、自动序号、插入内容、删减内容 |
| 主页面 | 参数配置区 | 根据当前方式动态显示配置表单 |
| 主页面 | 实时预览表格 | 左右两列对比原名/新名，支持搜索筛选，支持滚动浏览 |
| 主页面 | 底部操作栏 | 应用重命名、重置配置、导出映射表下载 |

## 3. 核心流程

用户上传文件 → 选择重命名方式 → 配置参数 → 实时预览效果 → 确认后导出重命名映射表（CSV）或下载重命名后的文件

```mermaid
flowchart LR
    A["上传文件"] --> B["选择重命名方式"]
    B --> C["配置参数"]
    C --> D["实时预览效果"]
    D --> E{"确认效果?"}
    E -->|是| F["导出映射表/下载"]
    E -->|否| C
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深邃蓝紫色渐变（#4F46E5 → #7C3AED），科技感与专业感兼具
- **辅助色**：青绿色（#10B981）用于成功状态，橙红色（#F59E0B）用于警告
- **背景**：深色主题，深灰渐变背景配合卡片式布局
- **按钮风格**：圆角胶囊形按钮，主按钮渐变填充，带微悬浮动效
- **字体**：现代无衬线字体，清晰易读
- **布局风格**：左右分栏布局，左侧配置区，右侧预览区
- **图标风格**：线性简约图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 顶部标题区 | 大标题 + 副标题 + 图标 |
| 主页面 | 文件上传区 | 虚线边框拖拽区域，文件列表带删除按钮 |
| 主页面 | 方式选择器 | 下拉选择框，带展开动画 |
| 主页面 | 参数配置区 | 表单项动态渲染，输入框/数字框/复选框 |
| 主页面 | 预览表格 | 斑马纹表格，左右对比，高亮变化部分 |
| 主页面 | 底部操作栏 | 三个操作按钮并排 |

### 4.3 响应式

- 桌面端：左右双栏布局（左40% + 右60%）
- 平板端：上下堆叠布局
- 移动端：单列布局，预览区可折叠
- 触摸优化：按钮最小触摸目标≥44px

### 4.4 动画与交互

- 页面加载：元素渐入动画，错落延迟
- 方式切换：配置表单平滑过渡
- 悬停：按钮/卡片微悬浮效果
- 预览更新：数字变化动画
- 文件拖拽：拖入时边框高亮动效
