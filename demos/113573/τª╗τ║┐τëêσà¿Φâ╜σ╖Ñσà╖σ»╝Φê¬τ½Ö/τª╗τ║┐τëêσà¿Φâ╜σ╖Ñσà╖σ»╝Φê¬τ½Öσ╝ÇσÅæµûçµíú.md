## 一、项目总览

### 1.1 项目定位

一款**纯本地离线运行**的轻量化工具导航网站，无需联网、无后台服务器、无广告、无跳转冗余，整合全网优质设计、编程、AI、办公类工具网址，支持本地搜索、分类浏览、收藏管理，主打极简、高效、轻量化，可本地部署、永久使用。

### 1.2 核心开发目标

1. **全离线化**：所有页面、数据、功能本地加载，零联网依赖，打开即用
2. **分类标准化**：四大核心类目 + 细分二级类目，工具分类清晰、无杂乱冗余
3. **轻量化体验**：页面秒开、无卡顿、无弹窗、无广告
4. **可自定义拓展**：支持用户本地新增、删除、收藏工具，数据本地留存
5. **极简视觉**：科技简约风，适配电脑端全尺寸屏幕，留白舒适、排版规整

### 1.3 技术选型（AI 开发专用）

- 前端基础：HTML5 + CSS3 + JavaScript（纯静态，零框架依赖）
- 数据存储：本地 JSON 文件（存储所有工具数据、用户收藏数据）
- 运行方式：本地直接打开 HTML 文件，无需服务器、无需部署环境
- 适配终端：Windows / Mac 全电脑端浏览器

## 二、整体功能架构

### 2.1 核心功能模块

1. **首页总览模块**：顶部导航栏、全局搜索框、四大分类入口、热门工具轮播
2. **分类浏览模块**：设计工具、编程工具、AI 工具、办公工具四大主类目，细分二级子类目
3. **搜索检索模块**：模糊搜索、精准匹配，支持工具名称、标签、类型搜索
4. **个人收藏模块**：本地收藏工具、取消收藏，数据永久本地保存
5. **自定义管理模块**：本地新增工具、编辑工具信息、删除冗余工具
6. **底部辅助模块**：项目说明、离线使用提示、版本信息

### 2.2 页面结构层级

- 一级页面：首页（总览 + 全部分类入口）
- 二级页面：设计工具页、编程工具页、AI 工具页、办公工具页
- 功能弹窗：搜索弹窗、收藏弹窗、新增工具弹窗

## 四、UI 视觉设计规范（AI 开发严格执行）

### 4.1 整体风格

极简科技简约风，低饱和度配色、大量留白、扁平化布局，无花哨动画，主打高效、整洁、商务质感，适配宽屏显示器。

### 4.2 色彩规范

- 主色调：浅科技蓝（#1677ff），用于按钮、选中状态、分类标题
- 辅助色：浅灰（#f5f7fa），用于卡片背景、页面底色
- 文字主色：深黑灰（#1f2329），正文、标题通用
- 文字次要色：浅灰（#666666），备注、标签文字
- 边框色：极浅灰（#eeeeee），卡片分割线、边框

### 4.3 排版规范

- 全局字体：微软雅黑、PingFang SC、无衬线自动适配
- 一级标题：24px、加粗
- 二级分类标题：18px、加粗
- 工具名称：15px、常规
- 工具简介 / 标签：12px、浅灰
- 行间距：统一 1.5 倍，整体排版宽松舒适

### 4.4 卡片样式

1. 所有工具统一圆角卡片（8px 圆角）
2. 轻微悬浮阴影，hover 状态轻微上浮、主色调描边
3. 单卡片结构：工具图标 + 工具名称 + 简短标签 + 访问按钮
4. 响应式网格布局，自动适配窗口大小

## 五、核心功能详细逻辑

### 5.1 离线运行逻辑

1. 所有工具 URL、分类信息、标签信息全部写入本地`data.json`文件
2. 页面加载直接读取本地 JSON 数据，**零联网请求**
3. 用户所有操作（收藏、新增、编辑）数据保存在本地浏览器缓存 + 本地 JSON 备份

### 5.2 搜索功能逻辑

1. 支持模糊搜索：匹配工具名称、分类、标签关键词
2. 实时检索：输入关键词即时展示匹配结果，无延迟
3. 无结果提示：未匹配工具时展示 “暂无相关工具”

### 5.3 收藏功能逻辑

1. 每个工具自带收藏星星图标
2. 已收藏图标高亮，未收藏默认灰色
3. 收藏数据本地永久留存，重启页面不丢失
4. 首页新增「我的收藏」快捷入口，一键查看所有收藏工具

### 5.4 自定义工具逻辑

1. 后台简易新增弹窗，支持填写：工具名称、网址、分类、标签、简介
2. 支持编辑已有工具信息、删除无用工具
3. 自定义数据自动同步到本地 JSON，永久保存

## 六、开发排期与落地要求

### 6.1 开发优先级（AI 执行顺序）

1. 第一优先级：搭建页面骨架、导入完整工具 JSON 数据、实现离线加载
2. 第二优先级：完成四大分类页面布局、卡片样式、hover 交互
3. 第三优先级：开发搜索、收藏、自定义工具核心功能
4. 第四优先级：优化 UI 细节、适配响应式、修复 bug、轻量化压缩

### 6.2 落地硬性要求

1. 项目打包后**纯静态文件**（HTML+CSS+JS+JSON），无多余文件
2. 整体体积极小，打开速度≤0.5 秒
3. 无任何联网代码、无广告代码、无统计代码
4. 代码结构整洁、注释清晰，支持后续手动新增工具
5. 所有工具链接 2026 年最新有效，无失效、跳转错误链接

## 七、项目交付标准

1. 完整源码文件夹（包含所有静态文件、数据文件）
2. 可直接双击`index.html`打开运行，无需任何部署操作
