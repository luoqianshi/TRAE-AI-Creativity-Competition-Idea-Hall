## 一、产品概述

### 1.1 一句话定位

**每天记录一次"工伤"，小牛马陪你自愈。**

### 1.2 目标用户画像

| 维度 | 描述 |
|------|------|
| 年龄 | 22-35 岁 |
| 职业 | 互联网、金融、服务业等高压行业从业者 |
| 工作状态 | 每天工作 8 小时以上，经常加班 |
| 心理特征 | 32.3%焦虑症检出率、43.9%情绪压抑、25.6%无人倾诉 |
| 使用场景 | 通勤地铁、午休时间、深夜睡前、厕所摸鱼 |
| 设备偏好 | 手机为主，碎片化使用（单次3-5分钟） |

### 1.3 核心价值主张

- **零门槛**：不用登录，不用注册，打开就用
- **零压力**：没有点赞，没有排名，只有抱抱
- **零上传**：所有数据保存在本地，隐私绝对安全
- **零评判**：不说教、不教育、不鸡汤，只陪伴

### 2.2 核心功能详解

#### 今日页 —— 3秒情绪记录

| 功能 | 交互方式 | 反馈机制 |
|------|---------|---------|
| 心情选择 | 点击9个选项之一 | 即时生成情绪码卡片 + 情绪天气隐喻 |
| AI连续对话 | 自动触发，可连续追问 | 流式文字输出，温暖共情 |
| 情绪天气隐喻 | 选择心情后自动展示 | 天气图标+治愈文案（如"阵雨过后会有彩虹"） |
| 快速呼吸入口 | 高压力情绪时出现 | 一键跳转4-7-8呼吸练习 |
| 打卡 | 点击打卡按钮 | 金币+经验值+连续天数 |

#### 翻一张 —— 游戏化情绪激励

| 稀有度 | 概率 | 保底 | 特效 |
|--------|------|------|------|
| N（普通） | 60% | — | 基础粒子效果 |
| R（稀有） | 25% | — | 增强粒子+音效 |
| SR（超稀有） | 10% | — | 打字机效果+流光 |
| SSR（特级） | 4.5% | 20抽 | 彩虹流光+特殊音效 |
| UR（传说） | 0.5% | 80抽 | 金色脉动+全屏特效 |

**保底机制**：SSR和UR保底计数独立运作，出SSR不会重置UR保底计数。

**翻牌后操作**：收藏 / 分享 / 发广场 / 释放（负面情绪卡片专属）

#### 情绪释放仪式（🆕 借鉴"情绪粉碎机"）

- 仅对负面情绪卡片（work/stress/anxiety/sad/tired主题）显示"释放"按钮
- 点击后：卡片文字消散 + 粒子飘散 + 震动反馈 + 随机治愈文案
- 记录释放次数，形成情绪管理闭环

#### 广场 —— 匿名情绪社区

- **完全匿名**：随机生成身份标识，关闭页面后无法追溯
- **抱抱代替点赞**：减少社交压力
- **隐私声明前置**："你的身份是随机生成的，关闭页面后无法追溯。所有数据只存在你的手机里。"
- **温暖文案**：发帖按钮为"说出去 🐮"而非"发布"

#### 跨圈层翻译（🆕 借鉴"人人皆需被看见"）

- **位置**：我的 → 翻译（NEW标签）
- **功能**：选择行业(12种) + 状态(9种) + 自由输入 → 生成家人能听懂的大白话
- **黑话翻译**：自动将KPI→工作指标、OKR→工作目标、ROI→投入产出等30+个行业术语
- **支持**：复制到剪贴板 / 分享给家人

#### AI树洞 —— 深度陪伴

- **连续对话**：支持多轮对话，AI记住上下文
- **温暖文案**：发送按钮为"告诉小牛马"而非"发送"
- **对话历史**：可查看/清空聊天记录
- **结束对话**：一键结束当前对话，AI给出总结

#### 危机干预三级系统

| 级别 | 触发条件 | 干预方式 |
|------|----------|----------|
| 一级 | 连续3天低落 | 温暖提示 |
| 二级 | 连续5天低落 | 弹窗建议（打热线/去广场/呼吸练习） |
| 三级 | 连续7天低落 | 强制弹窗 + 24小时热线号码 |

## 三、用户旅程

### 3.1 新用户首次使用（0-3分钟）

```
打开应用 → 看到动物伙伴问候 → 选择今天的心情
  → 收到AI回应 + 情绪天气隐喻 → 可选：打卡/翻牌/去广场
```

### 3.2 老用户每日使用（1-2分钟）

```
打开应用 → 快速选择心情（3秒内）→ 查看情绪天气 → 打卡
  → 翻一张卡片 → 浏览广场 → 离开
```

### 3.3 情绪崩溃时使用（5-10分钟）

```
打开应用 → 点击"发疯" → 选择"精神离职" → 收到极端共情回应
  → 翻牌后点击"释放" → 去广场发泄 → 呼吸练习 → 情绪平复
```

### 3.4 想让家人理解时（🆕）

```
我的 → 翻译 → 选择行业+状态 → 输入想说的话 → 翻译 → 复制/分享给家人
```

## 四、设计规范

### 4.1 文案风格（🆕 借鉴"小境"）

| 原文案 | 新文案 | 借鉴来源 |
|--------|--------|----------|
| 发布 | 说出去 🐮 | 小境"交给小境" |
| 发送 | 告诉小牛马 | 小境"交给一个愿意听的人" |
| 记录今天 | 交给小牛马 📖 | 小境"不是要你打卡" |

### 4.2 隐私保护设计（🆕 借鉴"地球树洞"）

- 广场发帖区显示🔒隐私声明
- 随机身份标识（会话级有效）
- 所有数据仅本地存储
- 零上传架构

### 4.3 视觉设计

| 元素 | 规范 |
|------|------|
| 配色 | 低饱和度、护眼色系，支持暗色模式 |
| 圆角 | 所有卡片 18px 圆角，柔和友好 |
| 阴影 | 极轻阴影（1px），避免压迫感 |
| 留白 | 大量留白，呼吸感视觉 |
| 响应式 | 适配375px-430px+，含320px小屏兜底 |

## 五、技术架构

### 5.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | HTML/CSS/JS | 单文件应用，零构建 |
| 存储 | localStorage | 零上传，隐私安全 |
| AI | 豆包API | 流式输出，低延迟 |
| TTS | Web Speech API | 原生语音合成 |
| 动画 | CSS + Canvas | 硬件加速 |
| 安全 | 事件委托 | 全局无eval、无console残留 |

### 5.2 安全措施（🆕 v38新增）

| 措施 | 说明 |
|------|------|
| eval()移除 | 老板键计算器改用白名单正则+Function构造器 |
| console清零 | 生产环境零console输出 |
| 事件委托 | 所有动态innerHTML不再使用onclick内联 |
| API Key编码 | btoa编码存储，兼容旧版明文 |
| XSS防护 | escapeHtml全覆盖，用户输入均转义 |
| 输入校验 | AI对话前端二次校验500字截断 |

### 5.3 性能指标

| 指标 | 目标 | 现状 |
|------|------|------|
| 首屏加载 | < 2s | ~1.5s |
| 交互响应 | < 100ms | ~50ms |
| 动画帧率 | 60fps | 55-60fps |
| 内存占用 | < 100MB | ~80MB |

## 七、使用指南

### 7.1 快速开始

1. 打开 `niujiu-demo-final.html`
2. 选择今天最像你的心情
3. 阅读AI给你的回应 + 情绪天气
4. 可选：打卡、翻牌、写日记、去广场、翻译给家人

### 7.2 快捷键

| 快捷键 | 功能 |
|--------|------|
| ESC | 切换老板键（计算器界面，支持暗色模式） |
| 空格 | 开始/停止呼吸练习 |

### 7.3 数据管理

- **导出数据**：我的 → 设置 → 导出数据
- **导入数据**：我的 → 设置 → 导入数据
- **清除数据**：我的 → 设置 → 清除所有数据
