ASCII 记事本电影院

把任意视频实时转成 ASCII 字符画，在 VSCode / 记事本里看片
一行命令把 MP4 变成 80×30 的字符像素矩阵，每秒 10 帧覆盖同一个 txt 文件 —— VSCode 里 F5 自动刷新，就是一个 ASCII 播放器。

创意名称 + 创意介绍

想解决什么问题：想看点有趣的东西，但不想安装播放器、不想开浏览器、甚至只想用记事本打发 30 秒；或者在屏幕上营造一点复古极客氛围。

为什么会想到做这个：随手刷到一个 ASCII art 视频，突然想 —— 能不能让 Windows 记事本自己动起来？于是用纯 Python 手写了 BMP/PNG/TGA 解码器、RIFF/AVI 递归扫描器、BGR→RGB 色彩通道处理，再用 ffmpeg 兜底 MP4 转 RAW AVI。

大概是什么产品：命令行工具 + 批处理，拖进任意 MP4 → 生成 video.avi → 循环覆盖 live.txt，自带 go.bat 一键启动。

目标用户及痛点

  • 面向哪些用户：极客玩家 / 桌面美化爱好者 / 计算机相关专业学生 / 需要在 demo 里炫个"小魔法"的开发者
  • 在什么场景下使用：摸鱼时、做 demo 时、朋友面前秀一下、或者单纯想让 VSCode 的 README 文件看起来"活了"
  • 当前痛点：现成的 ASCII 播放器要么依赖 ffmpeg-python，要么只能放图片，VSCode/记事本没有"自动重载同一文件"的内置按钮，很多人不知道 shutil.move 能绕过文件锁

价值与意义

    
    
      
  • 效率角度：全流程一个 go.bat，双击即用。没有 OpenCV 依赖、没有 numpy、没有 pip install，离线环境也能跑；代码 500 行，纯 Python 标准库 + 二进制 IO。
    • 
      
  • 趣味性 / 情绪价值：让"最无聊的编辑器"里出现"最不常规的电影"。在任何开发会议、Demo Day、技术分享上，打开一个 live.txt 就能当梗图 / 视频循环的投影背景。
    • 
      
  • 技术视角：自己手写的 RIFF 递归 chunk 扫描 + AVI top-down / bottom-up 自动识别 + BGR/RGB/YUV2 自动四字节码切换 —— 当练习题用也够用。
