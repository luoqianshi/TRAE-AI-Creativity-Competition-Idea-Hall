Innovation

六大核心创新

不是另一个 AI 写作工具——MetaMath-Agent 重新定义了 AI 在学术竞赛中的角色：从「文本生成器」升级为「自主编程代理」。

01

宿主侧工具编排

AI 不只是输出文字——它通过原生 tool_calls 真实调用 Read/Write/Edit/Bash 工具，在本地执行代码、读写文件、编译 LaTeX，形成完整的「思考→行动→验证」闭环。

02

多厂商原生工具调用

12+ AI 厂商走原生 Chat Completions tools 链路，保留 reasoning_content 上下文，校验 tool_calls 与 tool 消息连续闭合，支持 DeepSeek thinking 类接口。

03

来源审计 · 反编造

论文必须生成 source_audit.md，审计数据、图表、文献和关键结论来源。编译前自动检测占位符、虚构引用和断链图片，从源头杜绝 AI 幻觉进入论文。

04

确定性失败恢复

失败自动重跑支持 120–3600 秒冷却间隔、1–5 次上限，注入失败分类与真实错误片段，同模型调用串行门控，避免盲目高频重试。

05

质量门矩阵

编译前执行多层门禁：LaTeX 语法清理 → 模板遵从性检查 → 来源审计 → 图表引用校验 → Draw.io 结构诊断 → PDF 版式检查 → 双报告核验（COMPILE + VERIFY），任一失败都不能标记完成。

06

文献搜索 · 六源聚合

聚合 OpenAlex、Semantic Scholar、Crossref、arXiv、OpenAIRE、Europe PMC 六大真实论文数据库，支持 off/smart/deep 三档 AI 联动，去重后按相关性、权威性、时效性评分。

强制生成 source_audit.md，审计每条数据、每篇文献、每个结论的来源。编译前自动检测占位符、虚构 DOI 和断链图片，杜绝 AI 幻觉进入论文。

恢复

失败自动重跑

编译报错？图表缺失？系统诊断失败原因、注入真实错误片段和修复提示，冷却重试（120–3600 秒间隔），串行门控避免限流，确定性恢复。

文献

六源文献搜索

聚合 OpenAlex、Semantic Scholar、Crossref、arXiv、OpenAIRE、Europe PMC，去重后按相关性/权威性/时效性评分。三档 AI 联动：off/smart/deep，可追溯真实论文。

PDF 编辑

PDF 编辑器 · Claude Code 风格

VSCode 风格重构：侧边文件树、多 Tab 编辑器、AI 助手聊天面板（Ask/Plan/Edit 三模式）、双栏拖拽分屏、Problems 报错跳转、SHA256 冲突检测、原子回滚。

安全

工作区隔离 · 路径沙盒

每篇论文独立工作区，safe_join_workspace() 拒绝所有路径遍历。API Key 脱敏返回不入数据库，CORS 限制本机回环，Bash 工具限制在工作区内执行。

编译

xelatex 多遍编译

真实 xelatex 编译，自动幂等清理 LaTeX 语法噪声（Markdown 代码、下划线、裸 %），国赛自动回灌官方模板，编译前归一化图表路径，生成 COMPILE + VERIFY 双报告。

Security

安全设计

文件隔离

工作区限制在 app/workspaces/{wf_id}/ 内，safe_join_workspace() 拒绝所有路径遍历（绝对路径、../ 逃逸）。

API Key 安全

存储在 .env，API 返回时只返回脱敏状态，不返回原始密钥，不入数据库。

本地部署边界

CORS 与 Host 默认限制在 127.0.0.1、localhost、::1 回环访问。Bash 工具限制在工作区内执行。
