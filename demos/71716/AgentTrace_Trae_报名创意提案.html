AI Agent 的结果留下了，过程却经常丢了。

当一次任务跨过多轮尝试、报错、改方案和模型切换时，聊天窗口很难承担长期复盘、成本比较和知识沉淀。

01

步骤不可追踪

任务完成后，只能回看冗长聊天记录，难以快速知道 AI 到底改了什么、为什么这么改。

02

问题重复出现

依赖安装、路径错误、权限限制、模块缺失等问题反复发生，却没有自动沉淀为可复用经验。

03

成本只能凭感觉

耗时、token、中断次数和模型表现没有放在同一张复盘表里，无法比较真实效率。

把每次 AI 协作变成可管理资产。

AgentTrace 的 MVP 不依赖后端服务，采用本地规则解析和模板生成，让评委打开 HTML 就能看到完整流程。

LOG

项目阶段复盘

从工作记录中提取目标、阶段、完成项、关键操作和剩余风险，生成 `project-log.md`。

ERR

常见问题沉淀

识别 error、failed、permission、not found、token、context 等关键词，生成 `common-issues.md`。

TOK

成本与效率分析

结合输入 token、输出 token、耗时、费用、重试和中断，输出模型表现评分与解释。

API

结构化会话记录

把项目元信息、成本数据、问题清单和建议保存为 `session-summary.json`，方便后续复用。

MVP

内置示例体验

无需接入真实模型或账号，点击样例即可看到复盘、问题提取和导出的完整链路。

KB

个人知识库入口

将 AI 协作经验持续沉淀给下一次 TRAE、Codex、Claude Code 或 Cursor 任务使用。

MVP 工作流

围绕真实 AI 编程任务，AgentTrace 用一个轻量闭环完成记录、识别、分析和导出。

填写任务信息

记录项目名称、工具、模型、耗时和任务状态。

粘贴工作记录

输入聊天片段、命令行输出、报错和阶段总结。

生成复盘报告

自动提取阶段、文件、命令、问题和解决方案。

分析模型成本

把 token、费用、重试和中断转为可比较指标。

导出知识资产

下载 Markdown 和 JSON，继续喂给下一次 AI Agent。
