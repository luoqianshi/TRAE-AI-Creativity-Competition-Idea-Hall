❌ 痛点

科研文献越读越多，
越读越找不到「整体画面」

我们和很多人聊过同一个问题：当你硬盘里有 500+ 篇 PDF，怎么回答「这个细分方向里谁才是真正的 PI？」「我精读的论文之间有没有合作网？」——三个常见现状：

📁 1. 堆在文件夹里

按子目录分类、按时间分类、按「我看过/没看过」分类——但都是「列表」，没有「关系」。

🧠 2. 凭印象回答

「这方向的 PI 好像是 X？」——要查 Google Scholar 一条条翻，5-10 分钟过去还没确认。

📊 3. 写综述时崩溃

要梳理 100+ 篇文献的合作网、关键词、覆盖年份——只能靠 Excel 手工，零可视化反馈。

✨ 解法

把整座「论文星系」
揉进 4 张可视化卡片

PaperGalaxy 不再做「文献列表」——而是给每篇论文打上 5 个维度的标签，然后让所有维度同时变得可探索。

🌐 协作网络

两种网络切换

默认是合著网（社区着色）；切到「通讯作者中心网」时，金色枢纽节点立刻浮出水面，节点大小 = 作为通讯作者的篇数。

  • 1,131 个作者节点，14,193 条合著边
  • 18 个社区（k-means + TF-IDF 关键词）
  • 边权重 = 共同作者论文数
  • 支持按年份、边权重、社区聚焦

⚙️ 工作流

3 步把文件夹变成「论文星系」

1

PDF 自动解析

把 PDF 放进 PDFs/papers/ 任意子目录，运行 node scripts/extract-pdfs.mjs——833 份 PDF 全文解析 10 分钟完成。

2

合并 + 清洗 + 网络构建

同一个 build 脚本把缓存里的 828 篇 PDF 与已有 3,242 篇邮件下载论文按标题/DOI 合并，识别通讯作者，去重作者（8,247 个变体 → 1,131 个规范节点），生成两套网络 JSON。

3

Vite 启动 + 浏览器浏览

node node_modules/vite/bin/vite.js 启动 5173 端口。打开 http://127.0.0.1:5173/ 即看。4 个页面（首页 / 时间线 / 星座 / 网络 / 散点 / 详情 / 作者）全部响应式。

💎 价值

从「凭印象」到「数据驱动」

⚡ 效率提升

回答「这个方向的 PI 是谁」从 5-10 分钟降到 1 秒。回答「我读过哪些主题、缺什么」从手工 Excel 降到可视化散点矩阵。

🤝 社会价值

可一键分享给同组同学 / 写综述的合作者 / 基金评审——把「我过去读过什么」从个人心智变成可验证的视觉产物。

🔓 零锁定

纯前端 + 静态 JSON。导出 build 后整站 425 KB（gzip 129 KB），可托管到 GitHub Pages / Vercel / Netlify，没有云端 API、没有 SaaS 锁定。

🧩 可扩展

每加一种 PDF 维度（识别公式图、识别第一性原理、识别补充材料……）只需在 extract-pdfs.mjs 加一个 extractor，UI 端调一次即可。
