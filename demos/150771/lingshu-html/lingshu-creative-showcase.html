想解决什么问题

年轻人在面临考研/就业、职业转型、创业、感情抉择等人生重大节点时，普遍存在选择焦虑、信息过载和决策内耗的问题——反复纠结、难以取舍，甚至因害怕做错决定而陷入长期内耗，影响正常生活节奏与心理健康。

#选择焦虑
💡

灵感来源

灵感来源于金融领域的"压力测试"概念。我们发现，重大决策之所以困难，往往是因为人在平静状态下做出的选择，在遭遇突发风险和外界质疑时容易动摇。于是想到用"多智能体对抗博弈 + 黑天鹅事件扰动 + 量化评估"的组合方式，为决策者打造一个模拟真实压力的"决策风洞"。

#压力测试
🖥️

产品形态

一款基于 Web 的交互式 AI 决策辅助系统。前端采用 React + TypeScript + Vite，后端基于 Spring Boot，核心辩论引擎由大语言模型驱动，支持语音播报、实时数据可视化、PDF 报告导出等功能。

[ 目标用户及痛点 ]

精准定位处于人生关键转折期的年轻群体，直击四大核心痛点

😰

选择焦虑

面对人生重大决策，反复纠结无法下定决心，长时间陷入"选A还是选B"的思维漩涡，严重影响日常生活与睡眠质量。

🤯

信息过载

各种建议众说纷纭——父母说稳定重要，朋友说追梦想，网上又有无数案例。信息太多反而让人更加迷茫，不知道该听谁的。

😱

风险恐惧

害怕做出错误选择，担心无法承担后果。总是在脑海中推演最坏情况，导致"想太多、做太少"，行动力被焦虑完全吞噬。

😔

内耗严重

精力全部消耗在纠结中而非行动上。同样的利弊清单翻来覆去地写，却始终无法跨出那一步，时间和机会在犹豫中悄然流逝。

💡

商业价值

🌱

社会价值

当代年轻人心理健康问题日益突出，"选择焦虑"和"决策内耗"是重要诱因。灵枢通过科学化的对抗推演机制，帮助用户从"情绪内耗"转向"理性分析"，建立属于自己的决策方法论，在群体层面减少因犹豫不决带来的心理负担。

[ 系统运作机制 ]

从画像录入到评估报告，五步完成一场完整的决策压力推演

01

📋 决策画像录入

输入你的基本情况与关键参数（自律能力、经济储备、风险偏好等），系统生成个性化决策画像，为后续推演建立基准。

02

⚔️ 多智能体对抗

五方专家立场博弈，激进派、保守派、数据派、人文派、批判派围绕你的决策轮番展开激烈辩论，暴露你从未考虑过的角度。

03

🌪️ 黑天鹅事件

随机触发突发风险事件（如"考研前三个月目标院校取消该专业"），测试你的决策在极端情况下的稳定性与应变空间。

04

💀 压力极限测试

触发最坏结局推演，五方专家轮番对你的立场进行极限质疑，测试你的心理耐压阈值与抗挫能力。

05

📊 决策评估报告

生成综合评估报告，包含决策稳定性、风险承受阈值、内耗指数、贝叶斯置信度等多维度量化指标与优化建议。
