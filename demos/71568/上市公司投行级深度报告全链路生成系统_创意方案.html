九大核心模块

从数据采集到交付导出，全流程自动化

模块 01

📊 数据研调

7 维度 WebSearch 采集 + 交叉验证：公司基本信息、近 5 年财务数据、业务构成、竞争对手、估值数据、概念板块、产业链与催化剂。

模块 02

📄 报告引擎

模板替换法，15 章节 + 12 个 ECharts 交互图表，同时生成标准版 / 数据来源标注版 / 自媒体版 3 份 HTML 报告。

产出：3 x HTML 报告
模块 03

✅ 质量校验

6 类 grep 自动化验证：章节数 15、图表数 12、残留占位符检查、标签完整性等，确保交付零缺陷。

模块 04

🖼️ 封面工坊

7 大平台比例（抖音/小红书/B站/视频号/公众号/头条/通用）+ 实时编辑主标题/副标题/星级 + 一键 PNG/JPG 导出。

产出：封面生成器 HTML
模块 05

🏷️ 标题工坊

7 平台 × 4 模板 = 28 个标题公式：抖音钩子式、小红书清单式、视频号故事式、公众号深度、微博话题式、B站UP主、知乎问答。

产出：标题生成器 HTML
模块 06

✍️ 文案工坊

7 平台风格一键切换，适配各平台内容调性，支持一键复制，从此告别多平台适配烦恼。

产出：文案生成器 HTML
模块 07

🎙️ 合规出口

中英双语 4 组 Prompt：播客音频（双人对话 10-15min）+ 知识视频（7 Slide 12-15min），可直接粘贴 NotebookLM 使用。

产出：双语 Prompt TXT
模块 08

📦 印务导出

自媒体版 HTML → A4 竖版 PDF，Puppeteer 精准渲染，图表完整无切割，可直接分发或打印。

产出：自媒体版 PDF
模块 09

🔄 交付预览

所有生成物自动汇总至标准目录，一键打开浏览器预览，人工复核后即可交付。
