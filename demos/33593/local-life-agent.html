◆ 理解 / Understand

从自然语言中抽取：场景、人数、时长、距离、餐饮 / 预算 / 健康 / 老人儿童等约束，并做冲突检测。

◆ 查证 / Verify

并行调用天气、地图距离、餐厅排队、活动门票、路线耗时等工具，形成"实况画像"而非硬编码推荐。

◆ 合成 / Compose

以约束为骨架，将 1 个主活动 + 1 段餐饮 + 1 个兜底活动拼成 2–3 个差异化方案。

◆ 校验 & 重排 / Validate

检查预算 / 时长 / 距离是否超限，是否有满座 / 无票 / 天气风险，异常时自动替换或追加兜底。

◆ 确认 / Confirm

在订座、买票等高影响动作前提醒用户人工确认；用户调整某环节时，Agent 自动重排其余部分并重新校验。

价值与意义 · 不只是推荐

把"做攻略"的
6 个窗口，

效率提升：查地点 · 比路线 · 选餐厅 · 排时间 · 看风险 · 找备选，合并到一个 Agent Loop。

体验价值：通过 Loop Trace 让用户看见推荐不是硬编码文案，而是天气、活动、餐厅、路线、可预约状态组合而成的结果。

安全边界：高影响动作前保留人工确认，低影响动作自动执行，生活服务 Agent 更可信、更易落地。
