JSON Lens
结构化数据可视化工作台

一个打开浏览器就能用的 JSON 可视化工具。粘贴、导入、解析、搜索、导出，全部在本地完成， 让嵌套再深的数据也能一眼看清结构。

为什么我们还需要一个 JSON 工具？

说实话，我刚开始也没觉得这事有多麻烦。直到有次后端返回了一个嵌套了五六层的接口数据， 我在 IDE 里眯着眼睛找了半天，才发现某个字段其实是 null。那一刻我就想：能不能有个工具， 让我像看思维导图一样看 JSON？

😵

层级太深，容易看串

对象套数组、数组再套对象，纯文本模式下括号对齐一错，整个结构都容易理解错。

🔒

在线工具不敢用

有些业务数据含敏感信息，传到第三方网站总有点不放心，尤其是调试生产环境接口时。

🐢

专业软件太重

安装一个桌面客户端要几分钟，启动又慢，有时候只是想临时看一下结构，没必要大动干戈。

JSON Lens 是什么？

它是一个纯前端网页工具。你不需要安装任何东西，打开 HTML 文件就能用。左边是编辑器， 右边是可视化树，输入 JSON 的瞬间就能看到结构。所有数据都在浏览器本地处理，不会离开你的电脑。

核心功能

我不想做一个功能堆砌的工具，而是把开发者真正高频使用的操作做顺手。下面这些功能， 都是我在日常调试中反复遇到的需求。

01

双栏实时可视化

左侧编辑 JSON，右侧即时渲染成树状结构。对象、数组、字符串、数字、布尔、null 用不同颜色区分。

02

节点展开与折叠

大型 JSON 也能轻松浏览，点击箭头即可展开或收起节点，支持一键全部展开/折叠。

03

搜索与高亮定位

输入关键字后自动高亮匹配节点，并滚动定位。支持搜索 key 和 value，找字段不再靠肉眼。

04

路径复制

点击任意节点即可复制其完整访问路径，比如 data.users[0].name，写代码时直接粘贴。

05

格式化与压缩

一键把乱成一团的 JSON 排版整齐，也能把格式化的 JSON 压缩成一行，方便复制到请求体里。

06

导入导出

支持从本地 .json 文件导入，也支持导出格式化后的文本或截图友好的 HTML，方便写文档。

谁会用到它？

表面上是给开发者用的，但实际上任何需要阅读 JSON 的人都能受益。我在设计时尽量把门槛放低， 让初学者也能一眼看懂数据结构。

💻

前后端开发者

调试接口时快速查看返回结构，核对字段类型，复制路径到代码中。

🧪

测试工程师

校验接口返回的字段是否完整，快速定位异常值或缺失项。

📊

数据分析师

临时查看埋点数据、日志样本，理解 JSON 格式的原始数据。

🎓

编程初学者

通过可视化树理解对象、数组和嵌套关系，降低学习 JSON 的门槛。

价值与意义

做这个小工具不是为了替代 Postman 或者 IDE，而是填补一个中间地带：快速、安全、轻量地看懂 JSON。

使用价值

层级结构一眼看清，搜索和路径复制大幅提升调试效率。纯前端运行意味着随时随地可用， 不受网络环境和账号限制。

社会价值

降低开发者理解结构化数据的门槛，帮助初学者建立数据模型直觉， 也为技术团队提供可离线使用的免费工具。

隐私价值

JSON 数据仅在浏览器本地解析和渲染，不上传服务器、不存储缓存。 调试生产数据时也能多一份安心。

技术实现思路

为了真正做到打开即用，整个工具会做成一个单 HTML 文件，不依赖任何外部框架和后端服务。

HTML5
CSS3
原生 JavaScript
File API 导入导出
JSON.parse 本地解析
递归渲染树形节点
