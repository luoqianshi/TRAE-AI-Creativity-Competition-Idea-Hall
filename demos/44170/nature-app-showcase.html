痛点

好工具，为什么用不起来？

GitHub 上优秀的开源科研工具层出不穷，但大多数学生和研究者卡在了第一步。

⚙️

环境配置地狱

装 Python、配依赖、调版本，光是把环境跑起来就要花大半天。系统 Python 太新、缓存缺失，绘图说崩就崩。

⌨️

命令行门槛高

非计算机背景的研究者对终端望而生畏。参数怎么传、路径怎么写、报错了怎么查，每一步都是障碍。

🔧

Agent 难上手

想体验 AI 科研助手，却要先搞懂 agent 引擎配置、key 管理、prompt 调教，学习曲线陡峭到劝退。

技术亮点

五个硬核设计，解决真问题

每一个特性都来自真实痛点，用工程化方案让科研工具真正好用。

🔌

通用 Runner：一个 manifest 点亮全部 skill 核心架构

基于 manifest 驱动的通用 runner 架构，每个 skill 只需一份声明文件即可自动生成表单、接入执行引擎、渲染结果。新增 skill 不需要改一行前端代码，真正做到插件化扩展。

🐍

uv 托管 Python 3.13 隔离环境

用 uv 管理独立的 Python 3.13 环境，与系统 Python 完全隔离。彻底根治"系统 Python 太新""缺缓存导致绘图崩溃"等经典环境地狱问题，开箱即用，零配置。

🎨

4 个精修视图，体验拉满

绘图"再改一版"+选图器、润色原稿/改稿左右对照、阅读中英双语对照、审稿三栏视图——针对每个场景深度打磨交互，不是简单套壳，而是真的好用。

🛡️

独立隔离的引擎配置目录

所有 agent 引擎的配置、缓存、登录态都存放在独立的隔离目录中，绝不污染用户本机原有的任何登录凭证和配置文件。卸载即干净，放心试用。

🔒

本地运行 · 零遥测

纯本地桌面应用，复用你本机的环境与 API key，不经过任何第三方服务器。零遥测、零数据上传，你的论文数据只属于你自己。
