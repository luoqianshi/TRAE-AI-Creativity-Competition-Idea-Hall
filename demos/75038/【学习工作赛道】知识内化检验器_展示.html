// The Illusion of Knowing
你以为你懂了，其实没有
心理学中的"流畅性幻觉"——看得懂不等于记得住，记得住不等于用得出。传统学习工具只测记忆，不测理解深度。
📖
"合上书就忘了"
看完教材觉得全懂了，一合上书什么都想不起来。记忆停留在"再认"层面，远未达到"自由回忆"。
🎓
"培训完用不出"
课上听懂了，回到工位却不知如何下手。知识没有从"知道"转化为"能做到"，缺少应用层的检验。
🧩
"知识碎片化"
刷了很多课、看了很多书，但知识点之间没有连接。无法形成体系，遇到问题找不到对应的知识节点。
📝
"考试只测记忆"
选择题、填空题只能检验"记住了没有"，无法检验"理解了没有"和"能不能在新场景中使用"。

// Core Features
六大核心功能
🔬
费曼检验引擎
输入你的解释，AI检测逻辑跳步、循环论证、模糊用词。给出清晰度评分和改进建议。
🕸️
概念图谱绘制
自动识别知识点之间的关联，可视化呈现"断裂连接"——你以为懂了其实没懂的盲区。
📅
智能间隔重复
基于遗忘曲线和个人记忆数据，在最佳时间点推送复习。不是简单重复，而是变换角度。
📊
认知深度雷达
四层评估（记忆→理解→应用→创造），每次检验生成雷达图，清晰展示你在哪一层卡住了。
🎯
盲区精准定位
不只告诉你"不懂"，而是精确指出"哪个连接断了"、"哪一层没通"，给出针对性练习。
📈
成长轨迹追踪
记录每次检验结果，可视化展示认知深度的增长曲线。看见自己的进步，保持学习动力。
