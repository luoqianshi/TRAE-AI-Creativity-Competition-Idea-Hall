02 / Pain Points

为什么传统面板在 chroot 上不好用？

宝塔、1Panel 等面板面向标准 x86/云服务器设计，面对 Android chroot 的 ARM 环境与特殊内核时，兼容性成了最大门槛。

✕ 传统面板

  • ✕ ARM 架构软件包缺失或安装失败
  • ✕ 依赖原生 Docker 内核，chroot 无法直接运行
  • ✕ 报错后缺乏排障引导，新手无从下手
  • ✕ 界面臃肿，对手机小屏不友好

✓ Mini Panel

  • ✓ 原生 ARM / aarch64 适配，软件可装可用
  • ✓ 基于 DockRoot 的轻量容器，无需 Docker 内核
  • ✓ Mini Agent 智能体边解释边执行，自动排障
  • ✓ 移动端优先的简洁交互，随时随地管理
03 / Features

一个面板，覆盖个人服务器全链路

从系统监控到容器管理，从 Web 终端到计划任务，Mini Panel 把个人服务器需要的核心能力装进一个轻量面板。

01

Mini Agent

基于 ReAct 循环的自然语言运维助手，支持 OpenAI / Claude / DeepSeek / Ollama 多模型。

02

系统监控

CPU、内存、磁盘、网络实时监控，可视化图表直观展示资源使用趋势。

03

Web 终端

基于 WebSocket 的交互式终端，无需 SSH 客户端即可在浏览器里直接操作服务器。

04

文件管理

Web 文件管理器，支持上传、下载、编辑与权限管理，图形化操作更高效。

05

容器管理

基于 DockRoot 的轻量容器管理，拉取镜像、运行容器、查看日志一站式完成。

06

应用商店

一键部署 Nginx、MySQL、Redis 等常用服务，降低环境搭建门槛。

07

计划任务

Cron 表达式支持的定时任务，自动备份、清理、脚本调度信手拈来。

08

进程管理

查看与结束系统进程，快速定位资源占用异常，保障服务稳定运行。

04 / Mini Agent

会说话的服务器运维助手

不再需要记住繁杂的命令，用自然语言告诉 Mini Agent 你的目标，它会理解、规划、执行，并在破坏性操作前征求你的确认。

30 秒在手机上跑起来

确保设备已 Root 并安装 chroot Linux 模块，然后复制下方命令执行，即可自动下载并启动 Mini Panel。

BASH
