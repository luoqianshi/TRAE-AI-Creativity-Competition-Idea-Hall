核心功能

基于声学分析的智能语音训练全流程解决方案

📊

个人声音基线

通过多维度声学特征建立个人声音档案，作为后续评估的参考基准。支持持续元音、固定朗读、自然对话三种采样方式。

🎤

智能评估诊断

基于规则引擎识别声音问题，包括气息不足、语调单调、清晰度问题等，生成针对性诊断报告。

⚙️

自定义测试

支持设置语速目标、选择朗读文本，进行个性化声音分析，满足不同场景下的训练需求。

📈

历史记录追踪

记录训练日志，追踪进步曲线，可视化展示声学指标变化趋势，帮助用户了解训练效果。

🏋️

个性化训练计划

根据诊断结果生成针对性训练方案，预置多种训练项目，支持 TTS 语音引导跟练。

🔍

专业诊断分析

多维度声学指标分析，包括 HNR、Jitter、Shimmer、F0 等专业参数，提供深度声音诊断。

Voice-Coach 项目详细说明

🎯 项目亮点

核心功能

  • 个人声音基线：通过多维度声学特征建立个人声音档案
  • 智能评估诊断：基于规则引擎识别声音问题（气息不足、语调单调等）
  • 个性化训练计划：根据诊断结果生成针对性训练方案
  • 训练进度追踪：记录训练日志，追踪进步曲线

技术特色

  • 声学特征提取：使用 librosa 提取 HNR、Jitter、Shimmer 等专业指标
  • 规则引擎诊断：多维度声学规则识别声音问题类型
  • TTS 训练引导：预置语音训练音频，支持实时播放训练指导
  • 一键启动 Demo：跳过认证，预置示例数据，即开即用

🚀 快速启动

环境要求

  • Python 3.10+
  • 已配置虚拟环境 (`.venv`)

本地开发启动

cd voice-coach
.venv/bin/python -m streamlit run demo.py --server.port 8501

访问地址：https://voicecoach-demo.luckydbd.dev/

📋 Demo 预置内容

用户信息

  • 用户名：demo_user
  • 状态：已登录，无需认证

预置数据

  • 个人基线：已建立，包含 3 个示例音频
  • 评估报告：3 条历史记录（7天前、3天前、今天）
  • 训练日志：5 条最近训练记录

🎮 功能演示流程

  1. 查看个人基线：进入「基线」页面，查看个人声学特征基准值
  2. 声音评估：进入「评估」页面，选择朗读方式，上传音频查看评估结果
  3. 训练计划：进入「训练」页面，选择训练项目，播放 TTS 训练指导音频
  4. 历史记录：进入「历史」页面，查看评估报告时间线，对比声学指标变化
