为什么需要 LiteGuard

安全工具不该只服务大企业。

个人服务器同样承载着网站、接口、学习成果、游戏存档和重要数据，但许多用户只能在复杂的企业平台与难以部署的开源组件之间选择。LiteGuard 希望把持续安全值守变成一项个人也负担得起、看得懂、装得上的基础能力。

价格门槛

成熟平台往往按资产或服务收费，个人项目很难长期承担。

部署门槛

采集器、规则、模型、告警和面板需要自行组合，安装完成不等于真正可用。

认知门槛

告警描述专业而孤立，用户看到了风险，却不知道事件之间的关系和下一步动作。

从事件到判断

不是更响的告警，而是更完整的判断。

LiteGuard 将采集、关联、研判和响应组成一条连续链路。每个结论都能回到原始证据，每个高风险动作都由用户确认。

建议动作

部署

从拥有一台服务器，到开始被保护。

LiteGuard 为不同技术水平的用户提供三种入口。命令与界面均为产品概念展示，不连接真实安装服务。

熟悉容器？一条命令启动。

挂载只读日志和必要的系统视图，Agent 在宿主机旁持续观察，不要求额外部署日志集群。

Bash 
docker run -d \
  --name liteguard-agent \
  --restart unless-stopped \
  --network host \
  -v /var/log:/host/var/log:ro \
  -v /etc:/host/etc:ro \
  -v /proc:/host/proc:ro \
  liteguard/agent:latest

不使用 Docker？运行安装向导。

自动检查 Linux 环境、系统权限与依赖，并在修改配置前向用户确认。

Bash 
curl -fsSL https://get.liteguard.example/install.sh | sh

概念演示地址，不会发起真实安装。

请阅读 LiteGuard 部署说明，为当前 Linux 服务器完成环境检查、Docker 安装、LiteGuard Agent 部署与连通性验证。不得修改现有防火墙、SSH 登录方式和生产服务配置；任何高风险操作必须先向我说明影响并等待确认。
