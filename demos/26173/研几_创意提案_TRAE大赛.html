痛点洞察
当数据分析成为少数人的专利

在中国，超过 4000 万中小企业中，90% 以上的业务人员每天都在和 Excel 表格打交道——但他们不会 Python，不会 SQL，不懂统计学。数据分析这个"新时代的基础能力"，对大多数人来说仍然遥不可及。

痛点一

📊 数据在手，分析无从下手

销售经理手上有一年的销售明细表，她想看"各渠道转化率变化"，只能手动做透视表、画图表，每次都要花半天时间。换个问题，又要重做一遍。

痛点二

💰 请人分析，成本高周期长

找数据分析师出报告，一份月度分析报价 2000-5000 元，还要等 3-5 天。小企业负担不起，大企业排期紧张。数据驱动决策变成了口号。

痛点三

🔄 分析一次，下次还是从头来

同样的"月度销售趋势"，这个月分析完，下个月数据更新后又得重新来一遍。没有记忆、没有积累、没有越用越顺手的感觉。

痛点四

🔐 数据安全，不敢上云

企业内部数据敏感，不敢上传到公网 AI 工具分析。需要一款能本地运行、数据不出电脑的 AI 分析工具。

解决方案
研几：说人话，出报告

一款开箱即用的桌面端 AI 数据分析应用。用户只需双击安装、上传数据、用自然语言提问，即可获得专业的分析报告和可视化图表。全程不需要写一行代码。

🗣️

自然语言驱动

不用学 SQL、不用学 Python。像聊天一样说"帮我看下各区域销售额对比"，系统自动理解意图、匹配数据、生成分析。

🧠

自学习引擎

三层学习机制：记住你的报告风格偏好、发现数据中的周期性规律、学习你的分析习惯。用得越多，越懂你，越用越顺手。

🔒

数据安全本地化

所有数据加密存储在本地，支持 SQLCipher AES-256 加密。密钥审核机制确保数据访问安全可控。数据不出电脑，分析后不留存。

📦

开箱即用

双击安装，零依赖。不需要装 Python、Node.js 或其他任何环境。打开应用 → 上传 Excel/CSV → 开始对话分析。

🔄

多工作区隔离

支持创建多个独立工作区，每个工作区有自己独立的数据库、分析脚本、报告和偏好设置。适合管理多个客户或项目。

📄

一键导出报告

分析结果可直接导出为 HTML 交互报告、PPT 演示文稿或 Excel 文件。支持自定义样式，满足不同汇报场景的需求。

📋

报告模板引擎 核心亮点

固定周报/月报模板，用户上传或系统生成→AI拆解结构→保存为模板。下次选模板+新数据，自动填充数字和洞察，告别重复劳动。

🛡️

双重安全体系

分析前密钥审核门控 + 分析后数据即焚不留存。审计日志 append-only + HMAC 防篡改。LLM 数据脱敏，原始数据不出本地。

🔌

灵活 LLM 接入

内置 OpenAI / DeepSeek / 通义千问等多 Provider 支持。用户填入自己的 API Key 即可使用，数据经脱敏后再发 LLM。

核心亮点详解
报告模板引擎：一次打磨，永久复用

周期性报告（周报/月报/季报）的最大痛点不是第一次做——而是每次都要从头做一遍。研几的模板引擎提供两条路径，让报告从"一次性生产"变成"模板化复用"。

路径 A

📤 用户上传模板 → AI 拆解 → 保存再用

你手上有一份公司标准的月度分析 PPT 模板（固定章节、固定图表位置、固定排版风格）。直接上传到研几，AI 自动分析：

① 识别模板结构 —— 封面/目录/KPI卡片/趋势图/排行榜/总结
② 定位数据占位符 —— "上月销售额____万" → 标记为变量 {上月销售额}
③ 拆解图表类型 —— 柱状图位置 → 绑定"区域销售额"字段
④ 提取文字模板 —— 保留固定文案，标记需AI生成的洞察段落

保存为模板后，下个月只需上传新数据 + 点击"月报模板" → 30秒出报告。

路径 B

🤖 系统生成 → 用户调整 → 满意保存

没有现成模板？研几帮你从零创建：

① 告诉 AI："我需要一份月度销售分析模板，包含KPI总览、各区域对比、趋势图和下周预测"
② AI 生成初版报告（图表+分析文字+排版）
③ 你在界面上拖拽调整页面顺序、修改标题、更换图表类型
④ 调整满意后，点击"保存为模板" → 命名 → 今后所有月报自动应用

自学习引擎会记住你每次的微调偏好，下次生成的模板更贴近你的口味。
