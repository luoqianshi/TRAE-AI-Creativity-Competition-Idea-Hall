02 / 我们想做什么

用 AI 重写那些"未选择的路"

AI 人生重播器不是帮你后悔，而是用 AI 重新探索人生的分岔路口。 你只需要描述一个人生转折点，AI 会基于真实的时代背景、行业趋势和社会环境， 为每一个可能的选择生成一条平行人生故事线——像在读一本关于"另一个自己"的小说。

03 / 核心功能

不只是"如果当初"的故事

01

智能情境补全

你只需说"2019年毕业选了计算机"，AI 自动补全时代背景（互联网寒冬、疫情冲击、远程办公兴起），让故事更真实。

02

多分支平行叙事

不是一条线的故事，而是可展开、可对比的分支树。每条路都有 1年、3年、5年、10年的时间节点，像在读一本互动小说。

03

追问与深挖

用户可以随时追问："如果选了 A 但中途又遇到 XX 呢？" AI 会生成子分支，让你不断深入探索。

04

情绪色谱可视化

每条人生线配有动态情绪色谱——暖色代表充实、冷色代表迷茫、亮色代表高光时刻。用视觉感受每条路的"人生温度"。

05

回到当下

探索结束后，AI 会给出一段收束："无论选了哪条路，你都在这里。" 引导用户从好奇走向接纳，理解当下的自己。

05 / 价值与意义

为什么它值得存在？

🧠

决策辅助

把"如果当初"的模糊直觉变成结构化的未来推演，帮助用户在重大决策前看清每条路的可能走向。

"我试了我的平行人生"天然适合分享。匿名故事墙让陌生人产生意想不到的共鸣和连接。

💬

LLM 文字生成

故事叙事、情境补全、追问对话

🌳

D3.js / Canvas

🎨

CSS 动画

💾

LocalStorage

07 / 差异化优势

为什么选我们？

维度 AI 人生重播器 传统工具类作品
情感深度 触及人生选择的深层情感 解决功能性需求
互动性 用户可追问、探索、对比 单向输入输出
传播性 "我的平行人生"天然社交话题 需要主动推广
API 成本 仅 LLM 文字调用，极低成本 可能涉及图片/视频模型
技术门槛 纯前端 + LLM API，易于实现 可能需要复杂后端架构
