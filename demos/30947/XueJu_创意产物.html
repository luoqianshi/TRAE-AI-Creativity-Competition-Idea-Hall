TOPSIS 正负理想解运算

不仅计算最优选，同时算最差起点，通过欧氏几何距离得出客观的相对贴近度（C 值）

// 1. 归一化加权决策矩阵
vij = wj × (xij / √Σxij²)
// 2. 确定正/负理想解
A⁺ = (max vi1, max vi2, ... max vim)
A⁻ = (min vi1, min vi2, ... min vim)
// 3. 计算欧氏距离 → C 值（相对贴近度）
Ci = Si⁻ / (Si⁺ + Si⁻)
