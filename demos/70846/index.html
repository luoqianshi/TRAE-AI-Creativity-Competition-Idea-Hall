创意介绍

灵感源自《琵琶行》"同是天涯沦落人"

想解决什么问题

现代人面对情绪低谷时，刷到的心灵鸡汤都是"别难过、要坚强"，看似安慰却毫无温度；想找人说说话，却不知道跟谁开口；看到落叶、秋雨涌起某种情绪，却无法准确表达。用户需要的不是被教导，而是被真正地理解和懂得。

为什么会想到做这个

灵感来自白居易《琵琶行》中"同是天涯沦落人，相逢何必曾相识"的共情时刻。琵琶女一曲终了，白居易泪流满面——那不是同情，是"原来你懂我"的知己之泪。我们想让每个现代人，都能在千年前的某个灵魂那里，找到这样一位"未曾相识却心意相通"的知己。

大概是什么产品

一款 Web 应用。用户描述当下心境，AI 深度识别显性与隐含情绪，从中华诗词与历史人物经历中精准匹配最契合的那一段，并以古人身份写一封跨越时空的知己回信，让用户感到被理解、被慰藉、不再孤单。

使用流程

两种模式，一种温暖

1

输入心境

倾诉模式 选择模式

倾诉模式：自由输入当下感受，如"我很孤单悲伤，我梦到身边没有家人朋友"

选择模式：先选心情大类（失意/孤寂/悲愤…），再选细分遭遇或眼前景象

2

AI 智能分析

提取5层信息：显性情绪 → 隐含情绪 → 触发场景 → 核心痛点 → 古典意象映射

呈现确认页："我感受到了你内心深处的……"

3

三维精准匹配

心情标签 + 场景标签 + 慰藉适配度，确保匹配结果不仅相关，更能抚慰

用户来的时候已经在哭了，不能再给他看更惨的故事

4

知己回信 + 深度解读

古人以知己身份写信，按情感递进展示：共鸣锚点 → 深度内容 → 共情信 → 留白

附带诗词/人物学习模块：译文、注释、背景、赏析、延伸阅读

5

分享与收藏

生成水墨风格分享卡片，像一封私人信件。用户收藏形成"知己书信集"

当前痛点

诗词App只检索不共情：输入关键词搜到诗句，但不解释"为什么这首诗懂你"，也没有情绪抚慰。情感内容千篇一律：鸡汤文通用且空洞，不针对用户具体情境。AI聊天缺乏深度：聊天机器人陪你闲聊，但无法精准匹配到"和你走过同一条路"的历史知己。心理咨询门槛高：不是每个人都需要心理咨询，但每个人都需要被理解。

三段式知己信结构

我也在那里 "吾尝……" 先说自己的相似经历，建立"我懂你"的信任
当时我怎么想 "彼时吾心……" 不劝诫，只分享当时的心境，让你感到被理解
后来我才懂 "后吾乃悟……" 幸存者的低语，轻描淡写带出一点光
结尾不道别，只留温 —— "月色正好，愿君安眠"

价值与意义

不只是一款产品，更是一种文化连接

📜

文化传承新路径

让传统诗词和历史人物不再是课本上的死知识，而是每个人情绪低谷时真实可感的知己，让传统文化以最温暖的方式走进现代生活。

💚

心理健康守护

为用户提供一种低成本、易获取的情感慰藉方式，通过"古人也曾如此"的共鸣感缓解孤独感和无助感，形成积极的心理暗示——"最暗的夜，才见最亮的月"。

🔗

社交分享促进联结

精美的分享卡片天然具备传播属性，用户分享的不是产品广告，而是"有个人给我写了一封信"的私人记忆，能引发朋友间的情感交流。

📚

寓教于乐的学习体验

在共情过程中自然融入诗词赏析、历史知识、人物生平，让用户在情感共鸣中主动探索传统文化，实现"润物细无声"的文化教育。

🎯

填补市场空白

市面上没有一款产品同时做到"精准情绪匹配"+"深度文化共情"+"AI个性化回信"。《今古同怀》将填补这一情感与文化交织的空白地带。

🌱

社会温度传递

在这个快节奏、高压力的时代，让用户感受到"跨越千年的被理解"，传递一份温暖的社会关怀——你并不孤单，千年前的某个灵魂，懂你。
