Pain Points

当前建筑安全巡检的三大痛点

⚠

人眼漏检率高

巡检员在高层建筑中逐层排查数十个点位，疲劳作业导致裂缝、渗水、锈蚀等隐患漏检率高达30%。缺乏AI辅助，完全依赖个人经验和目视判断。

📄

纸质记录低效

"一支笔、一张表、一部手机拍照"是主流方式，巡检员回办公室后需手动录入电脑，从发现问题到派单维修平均耗时3-5天，信息传递严重滞后。

🔍

历史无法追溯

巡检记录散落在不同文件夹、不同人的手机里，出了事故难以追溯责任。缺乏统一的结构化数据库，无法进行趋势分析和预防性维护。

Solution

AI驱动的四步智能巡检闭环

01

拍照采集

巡检员用手机对准隐患点位拍照，AI实时识别裂缝、渗水、锈蚀等6大类风险

02

智能诊断

AI自动判定隐患类型和严重等级（安全/注意/危险），生成结构化巡检记录

03

自动派单

危险级隐患自动推送维修工单，附带位置标记和AI建议处置方案

04

趋势预警

后台汇聚多轮巡检数据，生成建筑安全态势热力图和隐患演变趋势报告

Core Features

六大核心功能

📷

AI视觉隐患识别

基于YOLOv8+ResNet的计算机视觉模型，支持裂缝宽度测量、渗水面积估算、钢筋锈蚀程度判定，识别准确率92%+。

🗺

建筑安全热力图

将巡检数据映射到建筑BIM模型，生成楼层级安全态势热力图，管理者一眼看清整栋楼的安全状况分布。

⚙

智能巡检路线规划

根据历史隐患分布和巡检周期，AI自动推荐最优巡检路线和优先级排序，避免重复劳动和盲区遗漏。

🔔

实时预警与派单

危险级隐患自动触发三级预警（短信+App推送+后台弹窗），同时生成维修工单并推送至责任人。

📈

隐患趋势分析

基于时序数据的隐患演变追踪，对比多轮巡检结果，自动标记恶化趋势，辅助预防性维护决策。

🔒

安全病历档案

为每栋建筑建立贯穿全生命周期的数字化"安全病历"，所有巡检记录、维修记录、照片存档可追溯。

Technical Architecture

技术架构与亮点

▶ 前端层（小程序 + Web后台）

  • WeChat 微信小程序巡检端，支持拍照、定位、离线缓存
  • Vue3 Web管理后台，ECharts数据可视化 + Three.js 3D建筑模型
  • WebSocket 实时推送巡检进度和预警消息

▶ 后端层（微服务架构）

  • Go 高性能API网关 + 巡检任务调度引擎
  • Python AI推理服务（FastAPI + ONNX Runtime）
  • MySQL 巡检记录 + 建筑档案 + 用户权限管理

▶ AI层（计算机视觉 + 时序预测）

  • YOLOv8 裂缝/渗水/锈蚀/脱落 6类隐患目标检测
  • ResNet 隐患严重等级三分类（安全/注意/危险）
  • LSTM 基于历史数据的隐患演变趋势预测

▶ 数据层（存储 + 分析）

  • OSS 巡检照片/视频云端存储，支持缩略图和水印
  • Redis 实时巡检状态缓存 + 热点数据加速
  • BIM 对接建筑信息模型，实现隐患空间定位
