TECH 01

儿童专用 NLP 引擎

针对 3-10 岁儿童语言特点优化的自然语言处理引擎，能理解口齿不清、语法不完整、逻辑跳跃的童言童语，准确率达 93%。

# 儿童意图识别 intent = child_nlp.parse( "小星那个那个...就是苹果那个题" ) return "math_help", context="苹果减法"
TECH 02

引导式辅导（Socratic Method）

不直接给出答案，而是通过提问引导孩子自己思考。结合 OCR 作业识别 + 知识图谱，精准定位孩子的知识薄弱点。

# 引导式对话策略 strategy = "hint" # 而非 "answer" response = tutor.generate( question=ocr_result, method="socratic", difficulty=child_level )
TECH 03

多模态情感识别

综合语音语调（声纹情感）、面部表情（微表情识别）、对话内容三维度判断孩子当前情绪状态，支持 8 种基础情绪识别。

# 多模态情绪融合 voice_emotion = voice_analyze(tone, pitch) face_emotion = face_detect(expression) text_emotion = sentiment_analyze(words) emotion = weighted_fuse( voice_emotion, face_emotion, text_emotion )
TECH 04

表情与动作联动引擎

根据对话内容和情绪状态，实时驱动机器人面部表情（128种）、身体摆动和发光效果，让互动更加生动自然。

# 表情联动 on emotion=happy: face.set(eyes="happy", mouth="smile") body.wiggle(amplitude=0.3) glow.color = "#e898b8"
