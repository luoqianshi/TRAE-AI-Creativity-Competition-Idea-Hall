参赛方向：社会服务｜面向银发就医与居家照护场景

银发化疗全程助手

从“一个老人每周化疗+配药很繁琐”出发，构建医院端录入、老人端同步、家属端联动的治疗陪伴系统，重点解决跨院区、记不清医嘱、药物繁多三类问题，并把操作压缩到大字提醒、一步确认、被动接收。

形式 App/小程序 + 极简适老界面
硬件 手环/吊坠 + 家中语音终端
核心场景 化疗/复查/配药

1) 创意名称 + 创意介绍

想解决什么问题

对需要长期治疗的老人（例如多发性骨髓瘤患者）来说，“每周固定化疗 + 多种药物按医嘱服用 + 定期复查”是一个高频、长周期、容错率极低的任务链。现实里最痛苦的往往不是单个动作，而是跨院区奔波、口头医嘱记不牢、药太多分不清。老人自己操作复杂电子产品也有门槛，家属一旦不在身边，执行链条就更容易断。

一句话：把“医生录入的医嘱和医院流程”直接同步成老人端看得懂、听得明白、一步就能确认的任务清单，并在关键节点自动提醒与告警。

为什么会想到做这个

灵感来自真实家庭照护经历：外公需要长期化疗与配药，流程繁琐且容易遗漏；奶奶骨质疏松，有独居跌倒经历，居家安全也需要被优先照顾。

大概是什么产品

一个面向老人、家属与医院协同场景的“治疗全程陪伴助手”。核心不是让老人自己录信息，而是由医生/护士或院方系统录入结构化医嘱，同步生成老人端的大字卡片、语音播报和一步确认提醒；同时提供家属看板与紧急告警。可选配简单硬件（手环/吊坠/家中提醒终端）增强跌倒与异常静止检测。

项目价值速览

“少漏一步”
把关键医嘱拆成可执行步骤
“少跑一次”
院区/流程导航与准备清单
“少担心”
家属联动与异常告警
“更有尊严”
回忆录与陪伴对话
合规提示：本产品不做诊断与治疗建议，仅做“信息记录、日程提醒、风险提示与联络”。涉及医疗数据需取得授权并最小化采集与加密存储。

2) 目标用户及痛点

核心用户

  • 老人患者：长期治疗、记忆力下降/视力听力下降、独居或白天独处，且不擅长复杂电子产品操作。
  • 主要照护者（家属）：不可能全程陪同，但需要随时知道老人“有没有按医嘱做”。

扩展用户（医院侧）

  • 导诊/护士：重复答疑、流程解释成本高。
  • 慢病/肿瘤随访团队：需要更低成本的随访与提醒触达。

典型痛点（从真实治疗链拆解）

  • 医嘱难记：医生口头交代多、药名相似、剂量与频次容易混淆，回家后更容易忘。
  • 步骤多且分散：挂号/缴费/检查/化疗/配药可能跨院区，老人容易迷路、走错楼、跑错队列。
  • 药物繁多：多种药并行服用，时间、餐前餐后、间隔要求很难完全记住。
  • 长期坚持难：一两个月还好，一年两年就很容易“漏一天、漏一顿”。
  • 居家风险高：骨质疏松易跌倒，独处时无人及时发现。

核心方案与功能（个人层面 + 医院层面）

个人层面：把医嘱变成“可执行任务”

  • 院方录入医嘱并同步：医生/护士或院方系统直接录入药物、剂量、时间、注意事项和复查节点，老人端自动收到整理好的任务清单。
  • 极简提醒确认：按医嘱定时提醒，页面只保留“大字提示 + 一个确认键”，也支持语音播报，尽量不让老人做复杂操作。
  • 复查与化疗前提醒：提前两天推送准备清单（证件、检查单、空腹要求、到院时间）。
  • 药物分组管理：把“今天早上/中午/晚上要吃什么”做成清楚的药物分组卡，减少面对大量药物时的混乱感。
  • 每日问候与状态自评：简单的“今天胃口/疼痛/情绪”打卡，用于家属了解与随访参考。
  • 回忆录生成：把日常对话与照片（用户授权后）整理成“家庭回忆册”，提升陪伴感与自我价值感。

医院层面：减少“跑来跑去”和信息不一致

  • 院区/流程导航：把一次化疗日的路线变成“下一步去哪、找哪个窗口、要带什么”的大字卡片与语音指引。
  • 医嘱统一同步：把医生端录入的信息直接同步到老人端和家属端，减少“口头转述”和信息丢失。
  • 一键导诊问答：把医院常见问题与科室信息做成可对话知识库，减少老人到窗口反复询问。
  • 预约与排队信息聚合（愿景）：与医院系统对接后，减少跨院区来回确认、重复填报与窗口咨询。

硬件交互增强（可选）

  • 跌倒/异常静止提醒：手环/吊坠加速度检测 + “长时间未活动”规则；触发后先语音询问，再通知家属。
  • 药盒核对：药盒贴二维码/NFC，老人“碰一下”即可看到或听到该药的服用说明与本次是否该吃。
  • 家中提醒终端：大音量、大字体、固定摆放，适合不熟悉智能手机的老人。
  • 家庭看板：家属端展示“今日任务完成度、异常告警、最近医嘱摘要”。

体验流程（用户旅程）

就医前
准备清单 + 路线卡
提前两天提醒复查/化疗安排；生成“要带什么、几点出门、去哪一栋楼”的大字卡片。
就医中
院方录入后自动同步
就诊结束后由医生/护士或院方系统录入医嘱，自动同步到老人端和家属端，避免老人自己转述出错。
回家后
按时提醒 + 一步确认
到点提醒服药；老人只需点一次“已完成”；未确认则二次提醒并提示家属介入。
独居时
跌倒/静止告警
检测到疑似跌倒或长时间静止，先语音呼叫确认；无响应则通知家属/紧急联系人。

3) 价值与意义（社会公益导向）

对老人和家庭

  • 降低漏服药/错过复查的概率，让治疗更连续。
  • 减少家属“必须全程陪同”的时间成本，缓解照护焦虑。
  • 提升居家安全感：跌倒/静止告警，关键时刻能救命。

对医院与社会

  • 导诊与流程解释标准化，减少窗口重复咨询。
  • 把复杂医疗流程“无障碍化”，更好地服务银发群体。
  • 如果未来与医院系统合作，可形成更连续的院内外照护链路。

实现思路（Demo 可落地）

能力拆分

  • 医嘱结构化：医生端/院方系统录入 → 关键信息同步 → 任务清单（时间/频次/注意事项）。
  • 提醒引擎：日程/闹钟 + 二次提醒 + 家属兜底通知。
  • 告警逻辑：跌倒/静止检测（硬件模拟亦可）+ 语音确认 + 通知。
  • 导诊知识库：医院楼宇/科室/窗口信息（首轮创意展示可用模拟数据即可）。

创意展示建议

  • 展示 1 条完整“化疗日流程卡”（下一步去哪/带什么/注意什么）。
  • 展示“医生录入医嘱 → 老人端自动生成用药提醒”。
  • 展示“跌倒触发 → 语音询问 → 家属收到告警”。
