😰 痛点问题

新能源项目概算中的设备及安装工程费用表计算复杂，容易出错：

  • 手工计算设备费、运杂费、安装费等，耗时长且易出错
  • 运杂费行（单位为%）需要特殊处理逻辑
  • 多级合计（一、二、三...）需要逐级汇总
  • 缺乏自动校核机制，差异难以发现
  • 合并单元格处理困难

✨ 解决方案

自动计算 + 智能校核，一键完成费用核对：

  • 自动计算5项费用，支持公式/数值双模式
  • 智能识别运杂费行，应用特殊计算逻辑
  • 自动计算多级合计，支持"一+二+三+..."格式
  • 自动生成校核警告，标红显示差异
  • 智能跳过合并单元格，避免处理错误

🚀 核心功能

1. 自动费用计算

设备费(不含运杂费) = 数量 × 设备费单价 / 10000
运杂费 = 设备费(不含运杂费) × D列数量 / 100
安装费 = 数量 × 安装费单价 / 10000
装置性材料费 = 数量 × 装置性材料费单价 / 10000
合计 = 数量 × 单价小计 / 10000

2. 智能校核警告

  • ✓ 设备费校核警告 = 原设备费(I列) - 计算设备费(M列)
  • ✓ 运杂费校核警告 = 原设备费(I列) - 计算运杂费(O列)
  • ✓ 安装费校核警告 = 原安装费(J列) - 计算安装费(R列)
  • ✓ 装置性材料费校核警告 = 原装置性材料费(K列) - 计算装置性材料费(T列)
  • ✓ 合计校核警告 = 原合计(L列) - 计算合计(V列)

3. 多级合计计算

自动识别层级结构：

  • 0级行：包含"设备及安装工程"的总合计行
  • 1级行：一级序号（一、二、三...）分项合计
  • 2级行：数字序号（1、2、3...）明细行
