书格

个人纸质藏书管理助手

学习工作赛道

1. 创意名称 + 创意介绍

想解决什么问题

家里书越买越多，实际分散在书架、床头、箱子里各处，想找某本书时翻半天找不到；买了新书回家，才发现原来已经有一本差不多的；同时读了好几本书，隔了几个月完全忘了每本读到哪一章。市面上没有一款真正为"家里那几百本实体书"设计的管理工具。

为什么会想到做这个

我自己家里有三百多本纸质书，之前没有任何管理习惯，直到书多到根本找不到才开始陆续录入 Excel，每次整理二十多本，已经理完一百多本。但 Excel 的搜索和浏览体验很差，我想做一个真正好用的纸质书管理工具。

大概是什么产品

一个轻量化的 Web 应用，支持手机和电脑访问。用户可以通过批量导入 Excel 快速录入书籍，按书柜/类别整理藏书，随时搜索书名查看书籍详情，并记录每本书的阅读状态。

2. 目标用户及痛点

面向哪些用户

家中有 50 本以上纸质书的阅读爱好者；书分散在多个位置，经常找不到具体位置的人；喜欢买书但容易忘记自己买过什么，导致重复购买的人；同时读多本书，需要记录每本读到哪里的用户。

在什么场景下使用

在书店看到一本感兴趣的书，想确认家里是否已经有类似的书；想找某本书重温或查阅资料，但忘了具体放在哪个位置；读完一本书想更新阅读状态，并记录一些简单的阅读心得；整理书架时，把书的存放位置同步更新到系统里；年底回顾时，看看这一年读完了哪些书、哪些还在读。

当前痛点

书实际分散在家里各处，没有统一目录，找书靠记忆和运气；买书前无法快速确认家中是否已有同类书籍，导致重复购买；同时读多本书时，容易忘记每本读到哪一章、哪一页；现有工具（豆瓣、Notion、Excel）要么侧重社交评分，要么太通用，浏览体验差，没有为纸质书管理做专门优化。

3. 价值与意义

效率提升

将"找一本书"的时间从十几分钟缩短到几秒，将"确认是否买过"的决策时间从犹豫几分钟变成秒查秒确认。搜索书名后直接展示书籍详情页面，告别密密麻麻的表格。通过阅读进度记录，让用户随时掌握每本书的阅读状态——哪些在读、哪些读完、哪些还没开始，一目了然。

社会价值

在电子书盛行的时代，很多人依然热爱纸质书的阅读体验，但缺乏匹配的工具来管理实体藏书。这个工具能让纸质书阅读者更好地利用自己的藏书资源，减少重复购买的浪费，培养持续阅读、有始有终的习惯。

4. 未来扩展方向

当前版本聚焦纸质书管理，未来可扩展支持电子书导入、读书笔记关联、阅读数据统计等功能，打造个人全链路阅读管理体验。
