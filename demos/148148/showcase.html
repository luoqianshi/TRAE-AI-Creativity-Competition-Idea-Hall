开发者的痛点

每一个嵌入式工程师都经历过的挣扎

📖

数据手册太厚

STM32F1 参考手册 835 页，找一个寄存器要翻半天，找到后还要理解位域含义

🧩

寄存器配置全靠猜

位域是 [3:2] 还是 [2:3]？枚举值 00 代表什么？配置错了系统直接跑飞

🔗

外设关系理不清

SPI 需要哪些 GPIO？哪个 DMA 通道能配 USART？中断号被谁共享？

📊

SVD 文件不好读

标准 SVD 是 XML 格式，几千行标签，肉眼根本看不出寄存器布局

核心功能

从输入到可视化，全链路 AI 赋能

📄

层次化 PDF 解析

将 PDF 数据手册解析为章节树结构，按需加载对应外设章节内容。不把整本手册喂给 LLM，大幅节省 Token 消耗。

章节树 按需加载 缓存
🤖

AI Agent 团队提取

基于 LangChain 多 Agent 协作：文档分析 Agent 定位章节，寄存器提取 Agent 分阶段提取，地址解析 Agent 推理基地址，数据整合 Agent 生成最终 JSON。

LangChain 多Agent 两阶段
🔧

SVD 文件直接导入

支持拖入 .svd / .svd.json 文件，XML 直接解析为可视化数据。bitRange [3:2] 自动转换为 bit_offset + bit_width。

.svd .json .xml
🔗

智能关联分析

规则推理 + LLM 深度分析：总线拓扑（AHB/APB1/APB2）、外设依赖关系、共享中断、DMA 通道、功能相似性。

总线拓扑 依赖关系 共享中断
🎨

交互式可视化

外设分组配色、地址空间视图、位域色块、双排序模式（按地址/按外设）。点击位域查看枚举值和读写属性。

地址条 位域色块 分组配色
🎯

AI 需求驱动配置

输入自然语言需求，AI 自动完成资源分配（引脚/DMA/中断/时钟）和寄存器配置计算，配置前后可视化对比，一键生成 C 初始化代码。
