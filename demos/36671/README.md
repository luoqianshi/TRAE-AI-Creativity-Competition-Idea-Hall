# 徽章录 - 徽章收集展示与交换记录

## 简介

徽章录是一款帮助你管理和展示徽章收藏的应用。支持多种类别和材质分类，提供稀有度评级和交换记录系统。

## 功能特点

- 🎖️ **徽章收集** - 记录徽章类别、材质、稀有度
- 🔄 **交换记录** - 追踪每枚徽章的来源和交换故事
- 💎 **稀有度评级** - 普通到传说五级稀有度
- 📊 **数据统计** - 追踪类别分布、稀有度分布和成就
- 🏆 **成就系统** - 解锁8种不同成就

## 技术栈

- React 19 + Vite 8 + Tailwind CSS 4
- React Router DOM 7 多页面导航
- localStorage 离线数据存储
- 毛玻璃风格 + 移动端优先设计

## 页面结构

| 页面 | 功能 |
|------|------|
| 首页 | 徽章类别、材质展示、最近徽章 |
| 徽章库 | 所有徽章列表，可按类别筛选 |
| 收集徽章 | 选择类别、材质、稀有度、品相 |
| 交换记录 | 所有交换列表，显示对象和类型 |
| 记录交换 | 关联徽章、记录交换对象 |
| 指南 | 徽章收藏知识与技巧 |
| 统计 | 数据统计、成就进度 |
| 我的 | 个人中心、设置、关于 |

## 数据结构

- **BADGE_CATEGORIES** - 6种徽章类别（军事、童军、运动、活动、品牌、定制）
- **BADGE_MATERIALS** - 6种徽章材质（金属、珐琅、刺绣、塑料、木质、树脂）
- **RARITY_LEVELS** - 5种稀有度（普通、稀有、珍贵、史诗、传说）
- **BADGE_CONDITIONS** - 4种品相（全新、完好、有痕迹、有损伤）

## 成就系统

| 成就 | 条件 |
|------|------|
| 初次收藏 | 收集第一枚徽章 |
| 首次交换 | 完成第一次交换 |
| 全类别 | 收集过所有6种类别 |
| 全材质 | 收集过所有6种材质 |
| 稀有猎人 | 收集10枚稀有以上徽章 |
| 七日坚持 | 连续7天记录 |
| 百枚达人 | 累计收集100枚徽章 |
| 徽章大师 | 累计完成10次交换 |

## 存储说明

- 所有数据存储在本地 localStorage
- 存储前缀：`bg_`
- 不收集、不上传任何用户数据
