ABOUT · 关于

写日记，是和过去自己的
一场温和对话。

这个小作品没有复杂的功能堆叠，只有最朴素的愿望：把每天值得记住的瞬间，存得久一点、回看时再温柔一点。 暖米色与森林绿的搭配，希望打开它的瞬间，心也跟着慢下来。

FEATURES · 功能

一些刚刚好够用的功能。

📅

日历视图

左侧日历清晰呈现所有写过日记的日期，点击即可快速定位到那一天，回看过去的自己。

✍️

Markdown 写作

支持 GFM 语法与原始 HTML 渲染，标题、列表、引用、代码块都能优雅呈现，专注内容本身。

🌿

心情 · 天气

为每篇日记打上情绪和天气标签，让记忆有更丰富的维度，多年后翻看也能瞬间回到那一刻。

🖼️

图文混排

支持图片和视频上传，通过 [图片N] 占位符优雅嵌入正文，媒体文件由 R2 对象存储托管。

🔍

全文检索

快速搜索标题和正文，组合日期筛选，让每一次回望都精准直达想要重读的那一篇。

☁️

云端同步

基于 Cloudflare D1 + Pages Functions，所有数据安全保存在云端，多设备无缝衔接。
