💡 创意介绍

用 AI 对话重新定义数据看板的搭建方式

🔍

想解决什么问题

企业数据分析师和运营人员每次做数据看板都需要重复经历：提需求 → 等研发 → 沟通修改 → 反复返工。一个简单的指标卡片修改，可能要走 3 天的流程。现有 BI 工具虽然强大，但学习成本高、操作复杂，非技术人员难以快速上手。

🚀

为什么会想到做这个

观察到团队中数据分析师 60% 的时间花在与研发沟通和等待排期上，而不是真正的数据分析。如果能用自然语言直接"告诉"系统想要什么，AI 理解意图后自动生成看板，将极大缩短从数据洞察到可视化呈现的周期。

🛠️

大概是什么产品

一个AI 数据驾驶舱搭建平台——以 Vue 3 + Vite 构建的 Web 系统，用户通过侧边栏 AI 聊天对话，即可创建、修改、组合各类数据可视化组件（图表、KPI 卡片、数据表格），实时在画布上呈现，并支持自由拖拽布局与一键预览。

🔄 AI 搭建工作流程

从自然语言到可视化看板，只需 4 步

1

用户说出需求

"帮我创建一个销售驾驶舱，左上角总销售额卡片，右边月度趋势折线图，下方 Top10 产品排行表格"

2

AI 理解意图并生成 Action

ChatService 调用 LLM（OpenAI / 国产大模型），解析语义，返回结构化的 Action JSON 数组（create_widget / update_widget / delete_widget / update_layout）

3

前端实时渲染

DashboardBuilder 接收到 Action 后，在自由画布上动态创建/修改 Widget（ECharts 图表、KPI 数字卡片、数据表格），支持拖拽调整位置

4

问数智能体注入真实数据

WidgetContainer 通过 DataAgentProxy 调用问数智能体，NL2SQL 引擎将 query 转为 SQL，从数据源查询真实数据，完成可视化渲染

👥 目标用户及痛点

谁在什么场景下，遇到了什么问题

📊

数据分析师

日常需要制作大量数据看板，但每次修改都要提需求等研发排期，一个指标卡片的变化可能要等 2-3 天。他们需要能自主快速迭代看板的工具。

👔

业务运营人员

不懂 SQL 和代码，但需要实时监控业务数据。现有 BI 工具学习曲线陡峭，无法快速搭建所需看板。他们需要零门槛、对话式的数据分析体验。

🏢

企业管理层

需要跨部门的统一数据视图，但各部门数据源分散（MySQL、ClickHouse、API 等），缺乏一站式数据汇聚和可视化解决方案。

💻

BI 开发工程师

重复处理大量低价值的看板开发需求，疲于应付业务方的各类修改请求。他们需要一个能自动化 80% 常规看板搭建的 AI 助手。
