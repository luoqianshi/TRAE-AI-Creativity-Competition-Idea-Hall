药明白

帮老人读懂药品说明的 AI 助手

产品形态：App / 小程序 | 技术栈：OCR + AI 翻译 + 语音合成

01 · 创意介绍

想解决什么问题

60%+
老年人表示看不懂药品说明书
30%+
家庭存在用药错误风险
2.8亿
中国 60 岁以上老年人口

药品说明书字体小、术语多、逻辑复杂，老年人普遍看不懂。子女不在身边时，老人容易吃错药、漏吃药，甚至因误读禁忌导致严重后果。"药明白"用 AI 把专业说明书翻译成老人听得懂的大白话，用语音播报和大字界面降低使用门槛。

为什么会想到做这个

身边长辈多次因为看不懂说明书而求助家人，甚至有一次差点吃错剂量。市面上虽有药品查询 App，但界面复杂、广告多，不适合老年人。我想做一个真正为老人设计的工具，让科技有温度。

产品形态

一款面向老年人的 App / 微信小程序，核心功能围绕"拍照-识别-翻译-提醒"闭环设计。

02 · 核心功能

📷 拍照识别

对准药品说明书拍照，OCR 自动提取文字，支持纸质说明书、药盒标签

🗣️ AI 翻译大白话

将专业医学术语翻译成通俗语言，提取用法用量、禁忌、副作用等关键信息

🔊 语音播报

一键朗读简化后的用药说明，视力不好的老人也能"听"明白

🔔 用药提醒

根据药品用法设置定时提醒，支持多药品管理，防止漏吃、重复吃

👁️ 大字模式

全局大字体、高对比度、简洁界面，专为老年人视力特点设计

👨‍👩‍👧 家属远程查看

子女可绑定老人账号，远程查看用药记录和提醒状态，安心工作

03 · 目标用户及痛点

核心用户群体

  • 主要用户：60 岁以上老年人，尤其是独居或子女不在身边的老人
  • 次要用户：中年子女，为父母管理用药、远程关注健康状况
  • 潜在用户：社区卫生服务中心、养老院护理人员

使用场景

  • 老人拿到新药，想知道"这个药怎么吃、什么时候吃"
  • 同时吃多种药，担心有没有冲突或重复
  • 记性不好，经常忘记吃药时间
  • 子女想远程了解父母是否按时服药

当前痛点

没有"药明白"时，老人只能凭经验吃药、问邻居、等子女回家再问。说明书上的专业术语（如"bid""禁忌症""肝肾功能不全者慎用"）对老人如同天书，误读风险极高。

04 · 价值与意义

价值维度具体体现
社会价值降低老年人用药错误风险，提升用药安全；缓解子女照护焦虑；助力智慧养老和银发经济发展
效率价值3 秒拍照即可获取用药要点，替代老人花十几分钟反复阅读说明书；自动提醒替代人工记忆
商业价值可对接药店（扫码购药）、医院（处方同步）、保险（用药数据风控）；适老化设计经验可复制到其他健康场景

05 · 技术实现方案

初赛 Demo 功能（1-2 周可完成）

  • 拍照上传 + OCR 文字提取（调用开源 OCR API 或 TRAE 内置能力）
  • AI 解析说明书结构，提取用法用量、禁忌、副作用
  • 大白话翻译 + 语音播报（调用语音合成 API）
  • 基础大字界面 + 单药品管理

复赛完整产品

  • 多药品冲突检测、用药日历、家属绑定与远程查看
  • 药品数据库对接，支持扫码查药
  • 社区/医院版本，支持批量导入处方

技术栈

前端：微信小程序 / React Native | 后端：Node.js + SQLite | AI：OCR + 大语言模型 API | 语音：TTS 合成 API

06 · 差异化优势

现有方案问题药明白的改进
通用药品查询 App界面复杂、广告多、不适合老人专为老人设计，零广告，极简交互
手动输入药品名搜索老人不会打字、记不住药名拍照即识别，无需输入
纯文字说明书字体小、术语多大白话翻译 + 语音播报
单一提醒工具不与药品信息关联从识别到提醒的完整闭环

07 · 开发计划

Week 1：核心功能搭建 — 拍照上传、OCR 识别、AI 翻译、大白话展示
Week 2：体验优化 — 语音播报、大字模式、用药提醒、适老化 UI 打磨
初赛：提交 Demo — 可运行的小程序，支持拍照识别 + 翻译 + 语音 + 提醒
复赛：完整产品 — 多药品管理、家属绑定、药品数据库、社区对接
