⚠

Agent 工具失败后继续瞎猜

1

Pain Signal

工具调用失败，但 Agent 没有停下来，而是基于假设继续执行后续操作。

2

Candidate Principle

遇到工具失败时，必须停止并报告不确定性，而不是基于假设继续推进。

3

Owner Decision

你审查这条候选原则，决定它的命运：

4

Expected Change

下一次同类场景中，Agent 会先报告失败原因并请求确认，而不是继续执行。

💎 价值

三个核心价值

不是让 AI 更聪明，而是让 AI 更守规矩。

🔄

减少重复纠错

同一个错误不需要你纠正第二次。Agent 会自动遵守已审查的行为原则。

👁

保护 Owner 注意力

你只审查原则，不需要每次都盯着 Agent 的每一步操作。信任来自规则，不是来自监控。

🌱

审查下的持续进化

AI Agent 在人类审查下逐步改进行为，每一步都可回滚、可追溯、可解释。

让每一次 AI 失败，
都变成下一次更稳定的行为

Agent 错题本不是另一个聊天工具，而是 AI Agent 的行为复盘与治理层。它让 AI 从"犯错-纠正-再犯错"的循环，变成"犯错-复盘-进化"的闭环。
