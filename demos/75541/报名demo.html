技术架构 亮点

面向生产可用的工程化设计 · 已在 TRAE Solo 环境跑通核心链路
🔌

插件化架构

GameTypeRegistry 注册机制，三层架构（核心层+引擎层+插件层），新品类 6 周可上线

🔄

多 Provider Failover

LLM（longcat/agnes）+ 图像（agnes/pollinations/trae）+ TTS（edge/azure/browser）三链路主备切换

⚡

SSE 流式响应

提问判断实时推送（judgment/text/fragment_earned/done 事件），跨 chunk 行缓冲防 JSON 解析失败

🛡️

三层内容安全

关键词过滤 + Prompt 约束 + LLM 审核，Galgame 启用角色关系白名单+互动边界硬编码

🎯

难度后处理

强制校准 LLM 修改的难度标签，按难度裁剪线索数量（easy=3 / medium=4 / hard=6 / hell=9）

💾

MySQL 持久化

games / play_sessions / users 三表，自动迁移兼容旧表，会话状态支持断点续玩

📊

资源系统

体力（5 分钟回 1 点）+ 碎片（提问奖励）+ 提示（看广告获取），三套资源驱动激励广告变现

🚨

限流防滥用

多级限流（generate 3/min · play 20/min · hint 10/min）+ IP 维度 + 错误暴露不隐藏

移动端 优先体验

桌面端三栏布局（场景/对话/推理板），移动端 Tab 切换单栏全屏，专为碎片化场景设计。

  • 顶部 HUD：问题数 / 体力 / 碎片 / 提示，一键看广告补充
  • 左栏：场景缩略图 + 汤面打字机（40 字/秒）+ 线索碎片条
  • 中栏：问答日志 + 建议问题 + 提问/猜测模式切换
  • 右栏：推理板（自动归纳是/否问答）+ 提问历史
  • 线索解锁弹出全屏场景卡片，多图轮播 + 配音自动播放
  • 通关 6 阶段过场动画，点击任意位置可跳过
