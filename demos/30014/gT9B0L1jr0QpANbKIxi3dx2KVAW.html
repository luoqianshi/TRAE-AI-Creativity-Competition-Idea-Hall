⚡ 项目概述

"基于 Python GUI + openpyxl 的智能化报关数据管理解决方案。 通过独立数据源实现快速查询与14字段自动填充，支持一键粘贴解析、 键盘快捷键、系统托盘运行与自动化备份清理。 V2.1 实现了企业级代码质量标准：常量化管理、统一异常处理、结构化日志与性能优化。"

本项目解决传统异地报关数据维护中依赖大型Excel工作簿、手动填写效率低下、容易出错等核心痛点。 通过智能化的数据源管理与自动填充机制，将单条数据的录入时间从 3-5分钟缩短至30秒以内， 效率提升高达 90% 以上。

🎯 核心创新

🎯

三重智能查询

BAANCode筛选 + Supplier Code精确匹配 + 供应商简称模糊搜索，毫秒级响应，支持68+供应商数据源快速定位目标。

🤖

14字段自动填充

选择供应商后自动从数据源提取A/B/C/D/E/F/K/L/M/N/O/P/Q/R共14个字段，零手动输入，彻底杜绝人为填写错误。

⌨️

一键粘贴解析

支持Ctrl+V粘贴制表符分隔的三段编号文本，正则引擎自动拆分至H/I/J列，智能解析成功率100%。

⌨️

键盘快捷键体系

Ctrl+Enter确认写入、Enter查询、Escape清空、Ctrl+S保存，高频操作效率提升300%，专业级用户体验。

📊

openpyxl静默写入

无需启动Excel程序，直接通过Python库写入A~R共18列，内存占用降低80%，写入速度提升5倍以上。

🔒

多重安全保障

写入前自动备份 + 二次确认弹窗 + 操作日志追踪 + 一键撤销机制 + 配置路径验证，数据安全全方位保障。

🧹

自动化运维

备份文件自动清理（默认保留30天），防止存储空间无限增长，运维成本降低90%，真正的无人值守。

💎

企业级代码质量

常量集中管理、统一异常处理、结构化日志、DRY原则遵循、67项验收测试全通过，代码可维护性达生产级别。

💼 应用场景

🏢

日常报关录入

关务人员每日批量录入供应商报关数据，使用快捷键+自动填充，单条录入时间<30秒。

📋

数据审计核对

主管人员通过JSONL操作日志追溯历史记录，导出CSV进行合规性审查。

🔄

错误修正撤销

发现录入错误时一键撤销最近一次写入，自动校验一致性，回退到备份状态。

💻

后台值守运行

最小化到系统托盘+开机自启，在14寸笔记本屏幕上长期运行，随时唤醒使用。
