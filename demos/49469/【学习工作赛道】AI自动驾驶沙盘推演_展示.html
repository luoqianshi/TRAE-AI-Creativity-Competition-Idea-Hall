TECHNOLOGY

技术原理与亮点

每一个路径决策背后，都有一套精密的算法在毫秒级时间内完成计算。

01

A* 启发式搜索算法

采用曼哈顿距离作为启发函数，在网格地图上平衡搜索效率与路径最优性。通过维护 openList（待考察节点）和 closedList（已考察节点），每次选择 f = g + h 最小的节点扩展，直至到达终点。

f(n) = g(n) + h(n) // g: 起点代价, h: 启发估计
02

动态障碍物碰撞检测

小车每移动一步，系统检查前方路径是否被新绘制的墙阻挡。若检测到碰撞，立即触发重新规划流程：暂停动画 → 重置搜索状态 → 以当前位置为新起点重新运行 A* → 沿新路径继续行驶。

if (pathBlocked()) { pause(); rePlan(); resume(); }
03

Canvas 动画渲染管线

使用 requestAnimationFrame 驱动的分层渲染策略：底层网格 → 障碍物 → 算法可视化层（open/closed/路径）→ 小车动画层。支持可调节的算法步进速度，让用户既能看清每一步，也能快速看到结果。

render(): grid → walls → algo-viz → car → overlay
04

网格地图状态机

每个网格单元维护状态属性（空闲/障碍/起点/终点/路径），配合事件驱动的交互系统。鼠标拖拽时通过坐标-网格映射算法实时更新地图状态，并触发重新渲染。

grid[y][x] = {type, g, h, f, parent, visited}
