01 · 创意介绍

解决什么问题
为什么要做这个产品

Android 原生音乐播放体验过于朴素 —— 系统自带的均衡器功能简陋，第三方应用充斥广告、操作粗糙， 更严重的是高负载场景下后台进程极易被系统杀死。我们希望打造一款功能完整、体验纯净、视觉精美， 并且能通过 Shizuku 获取 Shell 权限实现强力后台保活的音频调节工具。

🎧

系统功能简陋

Android 系统原生均衡器仅支持简单的几档预设，无法满足个性化的音质调校需求，对音乐爱好者来说远远不够。

🚫

第三方应用体验差

市面上的均衡器 App 广告泛滥、UI 粗糙、操作卡顿，高级效果分散在不同工具中，难以统一管理和使用。

💀

后台易被系统杀死

手机高负载场景下（游戏、视频渲染等），普通音频均衡器极易被 Android 系统清理掉后台进程，效果链瞬间失效，恢复需要重新打开应用。而 Equalix 通过 Shizuku 获取 Shell 权限，可实现更强的后台保活机制，确保音频效果持续在线。

🎵

高级效果缺失

多频段压缩、交叉馈送、真空管模拟、声道平衡等高级音频效果缺乏一站式解决方案，需要专业知识才能配置。

Android 10+ Kotlin 2.1 Jetpack Compose Material 3 AudioEffect API Room 数据库 Haze 毛玻璃 Shizuku

03 · 核心功能

产品亮点
六大核心能力

从底层的音频处理引擎到上层的交互体验，Equalix 把专业级的音频处理能力包装进优雅的毛玻璃界面中。

📊

10 段均衡器

从 32Hz 到 16kHz 的 10 段频率调节，每段 ±12dB 的调节范围。精确控制低音、中音、高音表现，针对不同音乐风格和耳机特性实现个性化调校。

10 频段 ±12dB 全局生效
🎛️

多种音频效果

低音增强、响度增强、立体声展宽、6 种预设混响、高级混响（可调衰减阻尼）、BS2B 交叉馈送、真空管模拟（偶次谐波）、5 段多频段压缩器+限幅器。

低音增强 响度 混响 压缩
🌐

全局音频生效

基于 Android AudioEffect API 实现，对系统全局音频流生效。无论你使用什么播放器、视频 App，所有声音都会经过 Equalix 的效果处理。

AudioEffect 系统级 无需 Root
💾

预设管理

内置 AutoEq 耳机补偿预设库，用户可保存自定义配置为个人预设。基于 Room 数据库实现，预设一键切换，不同场景快速匹配。

AutoEq 预设 自定义 Room 存储
✨

毛玻璃 UI

采用 Jetpack Compose + Material 3 + Haze + Backdrop 实现液态玻璃效果。动态取色主题，与你的壁纸颜色呼应，视觉精致现代。

Compose Haze 动态取色
🔒

保活与 Shizuku

前台服务 + 守护服务双进程保活，确保音频效果持续生效。集成 Shizuku API，支持声道平衡等需要系统特权的高级操作。

前台服务 守护进程 Shizuku
