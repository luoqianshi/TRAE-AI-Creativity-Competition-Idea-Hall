舒适地前行，才能持久地坚持。"

创意介绍

问题痛点：传统自律工具充满焦虑感——红色警告、紧迫提醒、冰冷的数字统计，让自律变成压力而非享受。很多年轻人因此放弃自我提升。

设计理念：创造一种不同的体验——用温暖代替焦虑，用鼓励代替催促，用治愈代替压迫。让自律成为每天的小确幸，而不是每天的心理负担。

产品形态：纯前端Web应用，包含习惯打卡、番茄钟专注计时、白噪音氛围三大功能，数据本地存储无需登录。

目标用户

  • 18-35岁追求自我提升的年轻人
  • 厌倦传统压力式打卡的用户群体
  • 学生、职场新人、自由职业者

使用场景

  • 每日早起/睡前查看今日待完成习惯
  • 工作学习时进入专注模式，配合白噪音
  • 定期回顾打卡记录，获得成就感

核心功能

今日概览

温暖问候语、进度环可视化、连续打卡天数统计

习惯打卡

自定义图标/颜色/频率，治愈动画反馈

专注计时

番茄钟 + 白噪音（雨声、森林、咖啡厅）

习惯统计

日历热力图可视化打卡记录

设计亮点

  • 深色主题 + 暖色点缀（琥珀色 #F59E0B、薄荷绿 #10B981），营造安心氛围
  • 温和动画：缓慢过渡，无突兀跳动，每次交互都舒适
  • 治愈语录："每一步都是进步"、"慢慢来比较快"等温暖鼓励
  • 侧边栏布局：现代科技风格，清晰导航

技术架构

纯前端应用，零服务器成本，数据本地存储：

React 18 TypeScript Vite Tailwind CSS Zustand Framer Motion LocalStorage

价值与意义

商业价值

  • 零服务器成本，易于部署传播（Vercel/Netlify）
  • 可扩展付费增值服务（云端同步、社区功能）
  • 治愈系设计风格契合年轻人审美，有差异化优势

社会价值

  • 提倡"舒适自律"理念，改变对自律的认知
  • 帮助年轻人以健康心态培养好习惯
  • 深色主题关怀视觉健康
