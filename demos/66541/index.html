Pixel Mentor

面向未来游戏工业流程的像素资产生产工具

不是让 AI 替代创作，而是把游戏工业流程拆解到任何人都能逐步掌握。

项目介绍

一个工具，一个步骤
逐步构建游戏美术能力

Pixel Mentor 是一套面向游戏美术生产流程的工具体系。它的核心思路非常简单：把复杂的游戏资产生产流程拆解成多个独立的、专注的软件工具。每个工具只负责一个能力，用户一步步完成，最终组合起来形成工业级的游戏资产。

本项目参赛提交的 Pixel Editor 是整个体系中的 V1 版本——一款专注于像素资产编辑的工具。它不是 Photoshop，也不是 Aseprite，它专为游戏资产制作教学而设计。

在 Pixel Editor 中，用户可以导入图片、自动生成像素图、在 Canvas 上逐像素编辑、使用调色板与多种绘图工具，最终导出符合游戏规范的 PNG 文件。每一步都在帮助用户理解像素、色彩通道、透明度等游戏美术基础概念。

核心创新

不是做更好的画笔
而是重新定义学习路径

Pixel Mentor 的创新不在于某个功能的突破，而在于产品哲学的根本不同。

01 流程拆解，而非功能堆叠 传统软件追求「一个软件做所有事」，我们选择「每个软件只做一件事」。降低认知负荷，聚焦深度理解。
02 工具即课程，操作即学习 软件界面本身就是教学载体。用户在编辑像素的过程中自然理解 RGBA、透明通道、Sprite 等概念。
03 工业规范前置 资产命名、尺寸规范、透明通道处理——从 V1 就内嵌游戏行业标准，而非事后补课。
04 渐进式产品架构 V1 到 V7 的升级路径就是完整的学习路径。用户的能力成长与产品迭代同步。
05 AI 辅助，AI 不替代 AI 参与像素化转换等辅助环节，但创作决策、资产规范、流程理解始终由人完成。

功能介绍

Pixel Editor V1 功能清单

每个功能都服务于一个明确的教学目标：理解游戏像素资产生产的某个环节。

📷

导入图片

支持导入常见图片格式作为像素化参考素材，理解不同图片到像素图的转换关系

▦

自动像素化

一键将任意图片转换为指定分辨率的像素图，直观感受像素密度的概念

▣

Pixel Canvas

精确到单个像素的 Canvas 编辑区域，支持自定义画布尺寸

🎨

RGBA 编辑

分别控制红、绿、蓝、透明四个通道，深入理解色彩通道与透明度

🎩

调色板

内置颜色库管理，支持自定义调色板，学习像素艺术的配色限制

🔎

吸管工具

从画布上拾取颜色并查看 RGBA 与 HEX 值，理解颜色编码

✎

铅笔工具

基础像素绘制工具，支持多种画笔大小，理解像素级别的精确操作

⌫

橡皮 / 透明橡皮

两种橡皮工具：普通橡皮恢复背景色，透明橡皮擦除为透明通道

▦

油漆桶填充

区域颜色填充工具，理解像素图中相邻像素的颜色关系

▦

网格编辑

可切换的像素网格覆盖层，辅助精确定位和编辑每个像素

👁

实时预览

编辑的同时实时查看最终效果，支持透明背景预览

💾

PNG 导出

导出带透明通道的 PNG 文件，符合游戏引擎通用导入规范
