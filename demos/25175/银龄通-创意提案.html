核心功能

四大功能，覆盖就诊全流程

语音交互 + 超大字体 + 极简操作，让老人用起来零门槛

1

智能挂号导航

老人只需语音说出症状（如"我头晕，血压高"），AI自动推荐对应科室，协助完成线上挂号，并展示就诊时间、地点、注意事项。

语音输入 → 症状理解 → 科室推荐 → 一键挂号
2

院内科室指引

到达医院后，AI语音引导老人找到对应科室。"从大门直走50米，右转上2楼，心内科就在左手边第3个门"，像家人在身边指路。

定位 → 语音导航 → 实时指路 → 到达提醒
3

医嘱大白话解读

拍一张病历或处方照片，AI用老人听得懂的大白话解释："医生说你血压偏高，这个药一天吃一次，饭后吃，不能和葡萄柚一起吃。"

拍照识别 → 医学术语翻译 → 大白话解读 → 重点提醒
4

用药智能提醒

回家后到点语音提醒："王阿姨，该吃降压药啦，饭后吃，一次一片。"同时推送提醒给子女，让远方的家人也安心。

处方解析 → 用药计划 → 语音提醒 → 子女同步
