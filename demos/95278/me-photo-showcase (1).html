01 / Creative Brief

把"照片垃圾"
变成"记忆财富"。

毕业季拍了上千张照片，面对杂乱的文件夹，萌生了用多模态大模型自动理解照片、生成描述、自动归类，甚至根据主题智能选片生成视频的想法。

A · WHAT

创意名称

Me-Photo —— 自部署的智能照片整理助手，为本地照片库提供自动化描述、标签化、语义搜索、主题选片与视频生成等全链路整理服务。

B · PROBLEM

想解决的问题

手机/相机拍了海量照片，散落文件夹无法按内容检索，手动打标签分类耗时费力，回忆视频选片剪辑门槛高，云服务又有隐私顾虑。

C · WHY

为什么会想到做

毕业季面对上千张杂乱照片的无奈 —— 想用多模态大模型把照片"读懂"、把回忆"激活"，让技术真正服务于个人与家庭的情感连接。

D · PRODUCT

大概是什么产品

一个 本地部署的系统（Docker 一键启动），Web UI 操作（Vue3 + FastAPI），底层 PostgreSQL + pgvector 存储元数据与向量，支持 Ollama / OpenAI 兼容 API 接入模型。

02 / Pain Points

没有它，用户现在会遇到什么。

面向有一定技术基础的个人 / 家庭用户、摄影爱好者、旅行博主、家长群体，以及需要轻量数字资产管理的小型工作室。

01

照片杂乱

文件名无意义，目录层级混乱，无法按内容快速筛选，照片像沉睡在硬盘里。

02

手动整理成本高

给照片打标签、分类费时费力，容易半途而废，最终只是把照片从一个文件夹搬到另一个。

03

缺乏语义检索

只能按日期或文件名找照片，无法根据内容或情感搜索，"去年秋天的海边合照"无从下手。

04

回忆视频门槛高

选片、排序、剪辑耗时，需要专业工具，制作一支主题视频往往要花掉整个下午。

使用场景：定期整理备份的照片库 → 自动生成标签和描述；用自然语言找照片（"生日蛋糕上的蜡烛"）；把同一主题照片一键生成视频，分享到社交平台。

03 / Product Form

本地程序 · Docker 部署 · 数据完全本地化。

一份部署在自己机器上的
"照片理解引擎"。

所有照片、描述、向量都留在本地，模型也走自部署或私有 API，避免照片外泄。Web UI 提供目录选择、模型配置、扫描整理、AI 问答、视频生成等完整工作流。

  • 01Docker 一键部署，零运维门槛，本地或家庭 NAS 均可
  • 02Web UI（Vue3 + FastAPI），浏览器内完成全部操作
  • 03PostgreSQL + pgvector，元数据与向量高性能检索
  • 04Ollama / OpenAI 兼容 API，模型可自由切换
  • 05异步任务队列 + WebSocket 进度推送，断点续传

// Tech Stack

04 / Core Features

从"看见照片"到
"理解照片"的全链路。

底层贯穿 VL 描述生成、LLM 意图理解、Embedding 语义匹配三种能力，覆盖扫描 → 理解 → 检索 → 整理 → 创作五个环节。

自动描述与标签

VL 模型为每张照片生成 50+ 字描述和 5~10 个标签，覆盖场景、人物、情感、色彩，节省 90% 手工整理时间。

VL · Auto Caption

语义搜索

口语化查询 → Embedding 向量匹配 → pgvector 检索，"生日蛋糕上的蜡烛"也能精准定位，比关键词更聪明。

Embedding · pgvector

AI 问答助手

双模式：AI 搜索调用语义匹配，整理小助手传递照片库上下文，LLM 自动编排工具完成整理决策。

LLM · Tool Calling

智能整理规则

按标签 / 时间 / 地点（EXIF GPS）/ 自定义规则分组，预览 + 确认模式防止误操作，移动复制软链接任选。

Rules Engine · Preview

主题选片与视频

AI 按主题自动筛选照片并编排叙事逻辑，FFmpeg 合成带转场和配乐的幻灯片视频，数小时缩短到 5 分钟。

FFmpeg · Theme

隐私与可配置

照片永不离开本机，模型走自部署或私有 API；VL/LLM/Embedding 模型按用途分类管理，按需切换。

Privacy · Pluggable
05 / Workflow

五步，从硬盘到回忆。

i
选择目录

服务端目录树浏览，选中待整理的照片文件夹，开始扫描。

ii
扫描入库

遍历图片格式，提取 EXIF，异步生成缩略图，建立照片索引。

iii
AI 理解

VL 模型批量生成描述与标签，Embedding 模型生成向量入库。

iv
语义检索

自然语言提问，向量匹配 + 关键词融合，定位目标照片。

v
主题创作

按主题智能选片，FFmpeg 合成回忆视频，一键导出分享。
