// Core Features

四大核心功能

I

个性化记忆匹配

AI根据老人的出生年代、家乡、职业和兴趣，从海量怀旧内容库中精准匹配最能触动其记忆的"记忆锚点"。

II

沉浸式怀旧场景

将老歌、老照片、老电影片段组合成沉浸式互动场景——老唱片在转、照片可以放大看细节、电影可以"续写结局"。

III

AI温暖对话引导

AI用温暖的语音引导老人分享回忆，像一位耐心的倾听者。每个问题都基于当前场景和老人的回答自然延伸。

IV

人生回忆录生成

自动将老人的口述故事整理成文字+配图+配乐的"人生回忆录"，可打印成册或生成家族传承数字版。

// Tech Architecture

四层技术架构

👤

用户画像构建层

子女远程设置老人的基本信息（年代/家乡/职业/兴趣），AI自动生成"记忆画像"——推算其青春期的流行文化、重大历史事件、地域特色内容。

User Profile + Era Knowledge Graph
🎵

怀旧内容匹配层

从百万级怀旧内容库（歌曲/照片/电影/新闻/广告）中，基于年代、地域、情感标签进行智能匹配，选出最能激活记忆的"锚点内容"。

Content DB + Embedding Matching + RAG
🎬

场景合成渲染层

将匹配到的内容合成为沉浸式互动场景——老歌配上当年代的影像画面、老照片加上缓慢的Ken Burns动效、电影片段配上时代背景音乐。

Scene Composer + Ken Burns + Video Stitching
💬

对话引导与记录层

基于LLM的温暖对话引擎，根据场景和老人回答自然引导回忆。语音识别+ASR将口述转为文字，自动整理为结构化的人生故事章节。

GPT-4 + Whisper ASR + Story Structuring
