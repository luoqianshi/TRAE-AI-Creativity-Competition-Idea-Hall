一个再普通不过的下午，咖啡馆的洗手间里只剩最后一格卷纸。你正准备起身，却发现身后毫无准备。 这时你会想：如果有人能立刻把纸递过来，该有多好。

纸乎就诞生于这样一个瞬间。它把"求纸欲"变成了一个微小却真实的社区—— 你发出求助，附近的人接单；你也可以在蹲坑间隙翻开"阅欲"读一篇短文，让等待不再漫长。

我们相信善意不该被距离稀释。每一次点击，都在为下一次如厕添上一份温柔。

SOS · 求纸欲
● LIVE 求助中

紧急程度 × 悬赏金
双向选择机制

低 / 普通 / 高 / 紧急 四档分级，配合地图选点与自动定位。求助者发出求助，附近响应者可接单，由求助者挑选援助人，再由援助人确认接受——形成真正的双向选择。

悬赏金会自动冻结在账户中，订单完成后自动结算给援助人，避免爽约与恶意行为。

READ · 阅欲

蹲坑间隙
读点轻松的内容

段子、趣闻、小知识、故事四类内容，覆盖厕所奇遇记、纸巾的独白、古人用什么擦屁股等趣味话题，免费读、付费读皆可。

付费阅读用功德币解锁，避免一次性消耗大量时间，又能保持阅读欲望。

MAP · 高德地图集成

附近厕所标记与求助定位

接入高德地图 Web JS API，支持自动定位、地图展示、厕所位置标记与搜索、距离计算。点击地图上的"WC"标记即可查看评分与评价。

REVIEW · 双向评价系统

求助者 ↔ 援助者 互评

订单完成后，求助者可对援助者评分（1–5 星）和文字评价，援助者亦可反向评价求助者。这种双向机制有效防止恶意求助与恶意援助，让社区氛围更健康。

02

使用流程

USER FLOW
01

发布求助

自动定位当前位置，选择紧急程度，设置悬赏功德币，描述需求。

02

响应接单

附近用户在地图或列表中看到求助，点击响应成为候选援助人。

03

双向确认

求助者从多个响应者中挑选一位，被选中的援助人确认接受后建立联系。

04

完成互评

订单完成，悬赏金自动结算给援助人，双方互评留档。

"积善之家，必有余庆。" 我们相信善意是可以被记录、被传递的。每一次发出求助，都是一次微小的善意流动；每一次接单响应，都是一次微小的善意积累。

纸乎用功德币把这一切串联起来——它不是奖励，而是一种习惯。当善意被记录下来，它就不再是孤立的瞬间，而是会沉淀为一个人的品格。
