📝一、创意名称 + 创意介绍
创意名称

Xdiary —— 你的电脑端 AI 治愈日记本

想解决什么问题

喜欢用电脑打字写日记的人，几乎没有针对电脑端优化过的日记软件。市面上好的日记应用几乎全是手机端（如 Day One、心岛日记），但在手机上用两个拇指打字写日记太慢太累，排版操作也非常不便。

而用电脑写日记时，人们只能将就使用 Word 或记事本，缺乏日记该有的仪式感、日期管理和情感回看能力。

为什么会想到做这个

作为一名大一学生，每天习惯在电脑前记录生活。手机写日记打字效率低，电脑端却没有一款真正为日记而生的软件。与其将就，不如自己动手做一个。

产品形态

一个在浏览器中直接使用的电脑端网页日记应用，支持富文本排版、AI 智能辅助和心情数据可视化。

👥二、目标用户及痛点
面向哪些用户

习惯用电脑键盘打字的学生群体（尤其是大学生和研究生）、文字工作者、以及所有觉得「手机写日记太慢」、希望用电脑高效记录生活的人。

使用场景

每天晚上睡前或空闲时间，坐在电脑前，打开浏览器进入 Xdiary，像翻开一本电子手账一样回顾和记录今天的生活。也可以在工作间隙随时打开，快速记录灵感和心情。

当前痛点
  • 电脑端没有一款体验好的日记软件，缺乏日期管理和情感追踪
  • 手机端日记键盘输入效率低，排版繁琐，不适合写长文
  • 没有 AI 辅助，写日记容易「不知道写什么」
  • 写了就忘，缺少对情绪和习惯的可视化回顾
💎三、价值与意义
🤗

情感陪伴价值

AI 在日记后送上温暖回应，让你感觉「有人在听」。心情曲线帮你看见情绪起伏，增强自我认知。

⚡

效率提升价值

键盘高效输入 + 富文本排版，让写日记从「将就」变成「享受」。AI 自动摘要与标签，回顾更有条理。

🌟

降低创作门槛

每日 AI 写作提示帮助「不知道写什么」的用户找到下笔入口，养成写日记的习惯。

🔧四、产品功能详解
4.1 富文本日记编辑器
  • 加粗、斜体、标题、列表、引用块、插图排版
  • 支持 Markdown 语法输入 / 所见即所得模式
  • 插图 base64 直接嵌入 .md 文件
  • 日历视图按日期快速选择日记
4.2 AI 智能辅助功能
A

每日写作提示

AI 每天提供一个引导性问题，如「今天让你最开心的一件小事？」

B

心情分析

AI 自动识别情绪状态（开心/平静/焦虑/难过），用户可手动调整

C

日记摘要

AI 自动将长日记总结为几句话精华，方便快速回顾

D

智能标签

AI 提取关键词标签（如「旅行」「考试」），用户可手动修改

✨ 亮点功能：AI 安慰聊天

写完日记后，AI 基于当天内容送上一句温暖回应，还可在对话窗口持续聊天。

🔐 隐私开关：可随时关闭「AI 读取日记」 | 🔑 API Key 由用户自行填入，费用自控

4.3 数据统计与可视化
  • 日历热力图：展示写作天数
  • 心情曲线 & 分布图
  • 连续写作天数统计
  • 词云 + 字数 & 篇数统计
4.4 隐私与数据安全
  • 日记 .md 本地存储，不上传服务器
  • AI 读取独立开关，默认开启可关闭
  • 首次使用引导选择存储路径
  • 导出/导入备份，换电脑不丢数据
🛠️五、技术方案
技术选型

纯原生 HTML + CSS + JavaScript 单文件网页应用，零依赖，双击即运行。

核心技术栈
技术模块方案说明
日记编辑器轻量 Markdown 编辑器（EasyMDE），Markdown + 富文本双模式
本地存储File System Access API，.md 文件存至用户指定文件夹
AI 能力调用 AI API（兼容 OpenAI 格式），用户自行填入 API Key
数据可视化Chart.js CDN，生成心情曲线、分布图、词云
视觉风格温暖治愈风 + 清新自然元素，暖色调、圆角设计
配置存储localStorage 存储用户设置、API Key、存储路径
为什么选择纯前端方案

① 技术门槛低 — 一个文件搞定，对 C++ 入门基础友好

② 即开即用 — 评委和用户双击就能跑，零安装成本

③ 稳定可靠 — 比赛演示不出环境配置问题

④ 可升级 — 将来可随时包装为 Electron 桌面应用

🎯六、关键设计决策与应对
问题决策 / 方案
AI API 费用谁承担？用户自行填入 API Key，费用归用户控制，Xdiary 零成本
浏览器如何读写本地文件？File System Access API（Chrome/Edge 原生支持）
隐私边界如何设计？AI 读取配有独立开关，关闭后聊天不可用
插图如何存储？图片 base64 嵌入 .md，日记即文件
换电脑怎么办？提供导出/导入备份，后续迭代云端同步
