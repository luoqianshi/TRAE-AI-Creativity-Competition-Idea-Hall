QuantDinger AI 智能选股助手

基于开源量化系统的 A 股板块智能分析与买卖时机推荐工具

赛道：学习工作 · 附加标签：社会公益

1. 创意介绍

想解决什么问题

普通投资者面对 A 股、港股、ETF 等海量标的时，缺乏专业分析能力，只能凭感觉选股；而专业量化工具门槛高、收费贵、操作复杂。

灵感来源

身边很多上班族和理财新手都想参与股票投资，但不会技术分析，也看不懂财报。市面上的工具信息过载，反而让人更迷茫。

产品形态

基于 QuantDinger 开源量化系统二次开发的 Web 应用，整合 A 股板块数据与 AI 分析引擎，实现“输入板块关键词，AI 自动选股并给出买卖建议”。

2. 界面原型

用户进入 AI 分析页面后，可在工具栏直接选择板块或点击快捷标签（科技、新能源、医药、军工、AI 等），系统自动完成后续分析。

3. 核心流程

输入板块关键词
→
匹配行业/概念板块
→
获取成分股
→
多维度 AI 分析
→
输出买卖建议

异步分析

点击后秒级返回任务 ID，后台分析，前端轮询，不阻塞用户操作。

三层数据保障

东方财富 API → 腾讯行情 API → 内置股票列表，保证数据可获取。

买卖时机

不仅给出方向，还输出建议入场价、止损价、止盈目标价。

风控保护

防重复提交 + 频率限制 + 超时熔断，防止服务被滥用。

4. 目标用户与价值

目标用户

没有专业背景的普通投资者、工作忙没时间盯盘的上班族、想学习量化投资的理财新手。

使用场景

用户想了解“最近军工板块怎么样”，输入关键词后系统自动找到相关股票并分析，给出可执行的买卖计划。

价值与意义

效率提升：将原本需要数小时的人工选股 + 技术分析工作，缩短为 1 分钟内完成。
社会价值：降低量化投资门槛，让普通投资者获得专业级分析辅助，减少盲目跟风投资的风险。项目基于 Apache-2.0 开源协议，可自由使用和二次开发，有利于投资教育普及。

5. 技术架构

系统采用前后端分离架构，基于 Docker Compose 一键部署。
