核心架构：观影DNA + 推荐引擎

电影猎的核心是一套观影DNA建模系统。每部电影被映射到一个6维特征空间（文艺度/烧脑指数/娱乐性/情感浓度/视觉风格/实验性），用户看过的电影共同构成其"观影DNA"——一个加权平均后的口味向量。推荐引擎通过计算候选片与用户DNA的余弦相似度，从冷门佳片库中找出最匹配的电影。

🧬 观影DNA建模
每部电影6维特征由AI+人工标注，用户DNA为其所有标记电影的加权向量，权重随评分和时间衰减
🎯 冷门度过滤
推荐池排除豆瓣标记人数>50万的热门片，聚焦标记人数<10万的优质冷门片，确保"发现感"
🎬 导演风格图谱
基于导演所有作品的特征聚类，自动生成风格画像（叙事偏好/视觉风格/主题倾向），使用LLM生成自然语言描述
📝 AI推荐理由
结合用户DNA和电影特征，由GPT生成个性化推荐理由，解释"为什么你会喜欢这部电影"，而非简单的类型匹配

数据来源与冷启动

电影数据库覆盖 TMDB + 豆瓣 + Letterboxd 三平台数据，冷门佳片库收录约 5000+ 部标记人数<10万的高分电影（豆瓣评分>7.5 / IMDb>7.0）。新用户通过"快速标记"流程（从30部代表性电影中选出看过的）完成冷启动，30秒内即可生成初始DNA。

产品形态与技术栈

移动端App：Flutter跨平台开发，核心推荐在云端完成，客户端负责DNA可视化和交互体验。

后端服务：Python (FastAPI) + 推荐引擎 (NumPy/SciPy) + 导演风格生成 (GPT-4 API) + PostgreSQL + Redis缓存 + 向量数据库(Milvus)。

商业模式：基础推荐(每日3部)免费 + 高级版¥8/月(无限推荐+导演深度解析+DNA详细报告+离线收藏)。
