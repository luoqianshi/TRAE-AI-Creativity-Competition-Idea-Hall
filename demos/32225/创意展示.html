创意介绍

解决什么问题

学校里想用 AI 的老师和同学很多，但要么访问不了官网，要么 API 太贵买不起。共享账号也不安全，谁用了多少根本没法追踪。

为什么做这个

平时学习经常需要 AI 辅助，但身边很多人要么用不了要么用得很别扭。想着干脆搭一个中转服务，大家用一个接口就能调用各种模型，还能按需分配额度。

产品形态

一个 Web 系统：后端用 Node.js 做代理转发，前端用 Vue 做管理界面。用户拿到一个 Token 就能调用 AI，后台还能看到每个人的使用情况。

核心功能

多渠道聚合

OpenAI、Qwen、DeepSeek 等多个 AI 服务统一到一个接口，自动选择可用的渠道。

用户配额管理

邀请码注册，每人有独立额度，用完了就不能再调用，后台能看到明细。

智能调度

Key 没额度了自动换下一个，某个渠道挂了自动切到其他渠道，不用人工干预。

流式输出

支持 SSE，AI 一边生成一边返回，不用等全部生成完才看到结果。

使用统计

每个请求都记录：用了什么模型、多少 token、耗时多少，方便分析成本。

安全防护

Token 认证、请求频率限制、参数过滤，防止滥用和恶意请求。
