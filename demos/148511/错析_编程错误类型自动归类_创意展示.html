认知溯源

四大思维根源

每个错误背后都对应一种特定的思维模式偏差。找到根源，才能真正避免重蹈覆辙。

🤔

想当然假设

默认输入/参数/返回值一定符合预期，不做防御性检查。这是最常见的思维根源，占比约 35%。

// ❌ user 可能为 null
console.log(user.name);
// ✅ 先校验
console.log(user?.name ?? '访客');
🚧

边界疏忽

遗漏了边界条件（空数组、索引越界、0 值、空字符串）。占比约 28%，与想当然假设常一起出现。

// ❌ 数组为空时崩溃
const first = arr[0];
// ✅ 处理边界
const first = arr.length > 0 ? arr[0] : null;
⚡

过早优化

还没实现正确功能就开始考虑"性能"或"优雅"，导致忽略基础逻辑正确性。占比约 18%。

// ❌ 先考虑性能优化
const result = cache.get(key) ?? compute();
// ⚡ 先写对，再优化
let result = compute(key); // 正确实现后加缓存
📚

知识盲区

对某个语言特性、API 行为或设计原则缺乏了解，导致使用了错误的方式。占比约 19%。

// ❌ 0.1+0.2 !== 0.3
if (a + b === 0.3) ...
// ✅ 使用容差比较
if (Math.abs(a + b - 0.3) < Number.EPSILON) ...

四大核心引擎

错析由四个相互协作的引擎构成，从代码解析到行为分析再到成长追踪，形成完整闭环。

🔍

AST 模式匹配引擎

将代码解析为抽象语法树，在语法树层面匹配预定义的错误模式。支持 JavaScript/TypeScript/Python/Java 等主流语言，可识别 100+ 种常见错误模式。

🧠

认知偏差映射引擎

基于认知心理学研究的编程思维偏差模型，将每个错误类型映射到对应的认知根源。每个错误对应 1 个主因 + 1 个辅因，准确率超过 85%。

📊

个人画像构建引擎

长期追踪用户错误数据，构建个人错误模式画像。通过时间序列分析识别高频错误类型和思维根源趋势，自动生成针对性改进建议。

💡

预防策略推荐引擎

每次错误诊断后，根据错误类型和思维根源，推荐可执行的预防策略，分为「立即修复」「代码习惯」「学习计划」三个层次，帮助用户逐步改进。
