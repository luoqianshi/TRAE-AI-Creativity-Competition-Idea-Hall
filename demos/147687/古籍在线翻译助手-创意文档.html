报名帖标准内容 直接复制粘贴到大赛报名

1. 创意名称 + 创意介绍

创意名称：古籍翻译官

想解决什么问题： 很多人对古籍感兴趣，但文言文看不懂、生僻字不会读、典故不知道出处，翻半天注释还是一头雾水。去搜翻译又常常只有干巴巴的白话，看不到背后的历史故事和文化内涵，导致很多人买了古籍也束之高阁。

为什么会想到做这个： 平时喜欢逛博物馆、看文物纪录片，发现很多老祖宗的智慧特别有意思，但一翻开原著就被文言文劝退了。要是能有个"随身翻译"，像朋友讲故事一样帮我看懂古籍就好了。

大概是什么产品： 一个古籍智能解读网站（手机/电脑都能用）

2. 目标用户及痛点

面向哪些用户： 学生党（初高中语文学习文言文）、历史文化爱好者、喜欢逛博物馆的年轻人、想读经典但怕看不懂的上班族

在什么场景下使用：

  • 做语文作业遇到不会的文言文，拍一下题目直接看解读
  • 逛博物馆看到文物上的铭文/诗句，拍个照查出处和含义
  • 睡前想读几页《论语》《史记》，遇到难懂的句子直接查

当前痛点： 查文言文翻译只能搜百度，东拼西凑不完整；手机上查字典翻半天，查到了也不知道用在这句里对不对；想看深度解读还要另外买参考书，费钱又麻烦。

3. 价值与意义

社会价值： 降低古籍阅读门槛，让更多普通人能轻松接触传统文化。以前只有文史专业的人才能啃的经典，现在学生、上班族、老年人都能看懂，让老祖宗的智慧真正"活"起来，而不是躺在图书馆里落灰。

效率提升： 学生做文言文作业从"翻 3 本书查 5 个 App"变成"拍照 3 秒搞定"，省下的时间可以用来理解内容本身，而不是纠结字词意思。

产品设计方案 国风雅致 · 宣纸鎏金

设计风格

主题：国风雅致 · 宣纸鎏金

朱红（主色）#8B2323
鎏金（辅色）#C9A961
宣纸米黄（背景）#FDF6E3
墨色（正文）#2C2C2C

字体：标题用「思源宋体」（衬线体，古籍感），正文用「思源黑体」（清晰易读）

布局：卡片化设计，带鎏金边框和印章装饰，内容区最大宽度 1080px 居中

页面结构（3 个核心页面）

页面 核心模块 功能描述
首页 Hero 搜索区 + 名句卡片 + 古籍分类 大搜索框（核心入口）+ 今日名句 + 5 个古籍分类导航 + 热门名句瀑布流
翻译解读页 原文输入 + 加载动画 + 5 维解读 白话文翻译 + 生僻字注音 + 典故出处 + 历史背景 + 现代启示 + 分享卡片生成
古籍专区页 古籍列表 + 单本详情 5 本经典古籍封面卡片，每本 10 篇预置解读内容，点击进入查看

技术实现方案 纯前端架构 · 零依赖

技术选型（零构建工具 · 双击即可运行）

层级 技术选择 说明
前端框架 原生 HTML5 + CSS3 + JavaScript 无需构建工具，零依赖，双击 index.html 即可运行
路由 原生 JS 哈希路由 (#/home, #/book/:id) SPA 单页切换，无刷新
存储 localStorage 存 API Key + 搜索历史 + 名句收藏
网络请求 原生 fetch API 直接调用大模型 HTTP 接口
图像生成 HTML5 Canvas API 生成分享卡片 PNG，无需额外库
部署 宝塔面板 Nginx 静态站点 直接丢文件即可，你已熟练掌握

核心 Prompt 设计思路

你是一位资深的国学大师，精通文言文和中国历史文化。
请对以下文言文进行解读，并严格以 JSON 格式返回5个字段（不要额外文字）：

{
"translation": "白话文逐句翻译，要通俗易懂",
"pinyin": "生僻字列表，格式：[{'字':'读','拼音':'dú'}]",
"origin": "典故出处，格式：出自《XX》XX篇，作者XX，朝代XX",
"background": "历史背景，用讲故事的口吻，200字左右",
"insight": "现代启示，结合当代生活场景，150字左右"
}
文言文内容：{用户输入原文}
