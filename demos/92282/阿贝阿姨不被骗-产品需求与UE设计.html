01 / 产品定位

我们要解决什么问题

闽南地区老年群体是电信诈骗的高发受害人群。他们日常以闽南语交流，对书面文字理解偏弱， 传统反诈宣传难以有效触达。同时，AI技术的普及让诈骗手段愈发逼真——合成语音冒充子女、 伪造短信伪装官方通知，老年人越来越难以分辨。

🎯

核心定位

一款方言优先的AI反诈助手。
不是"把文字翻译成方言"，而是从交互到输出全程以闽南语为核心媒介， 让老年人真正听得懂、说得出、用得来。

🤝

差异化价值

市面反诈工具依赖文字阅读和普通话交互。
我们用闽南语语音作为第一交互语言， 搭配家人协同判断机制， 构建"AI识别 + 方言讲解 + 家人把关"的三重防护。

📱

Demo 范围

当前以Web网页快速验证核心体验。
支持图片上传、文本粘贴、短视频拍摄三种输入； AI分析结果以闽南语播报，可方言提问，可分享至微信让家人协助。

💡 产品命名释义
"阿贝"是闽南语中对叔叔/伯伯的亲切称呼，"阿姨"则是对阿姨/婶婶的称呼。项目名"阿贝阿姨不被骗"意为"叔叔阿姨不被骗"，直接点出服务对象——闽南地区的老年男女，以及核心承诺—— 用最亲近的语言，守护最需要保护的人。

为什么不用"阿公阿嫲"（爷爷奶奶）？因为老人家都不愿意承认自己老。叫一声"阿公阿嫲"是在提醒他们"你老了"，而"阿贝阿姨"让他们觉得自己还被当作叔叔阿姨看待，年轻了一辈。这不是简单的称呼选择，而是对老年人心理尊严的尊重——我们要守护的不只是他们的钱袋子，还有他们"我还不是老人"的那份体面。名称本身就是一个方言认同信号 + 心理尊严信号， 让目标用户第一眼就感到"这是为我做的，而且懂我"。

⚙️ 非功能需求
性能：图片/视频上传后 AI 分析响应 ≤ 8秒，期间有闽南语语音安抚"阿贝稍等一下，我正在帮你看"。
适老化：最小触控区域 56px，正文字号 ≥ 18px，色彩对比度 ≥ 7:1（WCAG AAA），关键操作有语音确认。
容错：上传失败/网络超时自动重试，语音播放失败自动切换文字显示 + 重试按钮。
隐私：上传内容仅用于本次分析，不持久化存储原始数据（历史记录仅存缩略图 + 分析摘要）。

  • 🛑 第一层·破除催眠：红色全屏 + "等一下！"大字，打断骗子的情绪操控。闽南语急促喊"阿贝！等一下！先莫急！"
  • 🚨 第二层·定性判断："这是骗子！"不说"疑似诈骗"。加"冒充你孙子"具象化归因，老人一听就懂
  • 💰 第三层·损失警示："钱打出去就没了"用损失框架替代"诈骗"概念。"养老钱"激活保护本能
  • 🚫 第四层·行动指引：三个按钮各不超过4字。"不要打钱"+"打给儿子"+"发给家人看"，祈使句，动词开头
  • 🤝 第五层·家人兜底："不怕麻烦"打消老人怕给儿女添麻烦的心理障碍
  • 🔊 三重复原则："不要打钱"在视觉（红色按钮）、语音（闽南语播报）、行动（按钮文字）三通道重复出现
  • 📋 套路拆解：放在行动按钮下方，老人想看才看，不干扰核心信息传达
与旧设计的核心区别
旧设计：风险等级标题 → 语音播报 → 风险点 → 建议行动 → 按钮
新设计：破除催眠喊停 → 定性"这是骗子" → 损失"钱没了" → 行动三按钮 → 家人兜底
关键变化：①第一屏是"等一下！"不是"高危诈骗" ②用"钱没了"替代"风险等级" ③行动按钮从2个变3个，每个不超4字 ④增加"不怕麻烦"心理关怀

08 / 适老化设计

为老年人做的特殊考量

这不是"无障碍适配"，而是从零开始为老年人设计的原生体验。

  • 🔊
    语音优先，文字辅助
    所有关键信息默认以闽南语语音输出，文字仅作辅助显示。老年人不需要"阅读"才能使用——听就够了。
  • 📐
    超大触控区域
    最小触控区域 56px（超过 WCAG 建议的 44px），主操作按钮全屏宽。手指颤抖、视力不佳也能准确点击。
  • 🎨
    高对比度 + 三重编码
    色彩对比度 ≥ 7:1（WCAG AAA）。风险信息用"颜色+图标+文字"三重编码，色盲用户也能识别。
  • 🧭
    最多3步到达结果
    首页 → 输入 → 结果，不超过3个层级。无复杂导航，无折叠菜单，无侧边栏。老人不会"迷路"。
  • 🤝
    容错与确认
    关键操作（如分享）有预览确认。上传失败自动重试。语音播放失败切换文字显示。永远不会"卡住"。
  • 💬
    闽南语口语化文案
    所有文案以闽南语口语风格撰写，不用书面语、不用技术术语。"阿贝""阿姨"称呼贯穿始终，营造街坊聊天的亲切感。
  • ⏳
    等待即陪伴
    所有加载过程都有闽南语语音安抚 + 进度反馈。不让老人面对空白屏幕，消除"是不是坏了"的焦虑。
09 / 风险沟通心理学

如何让老人第一时间警觉

老年人面对诈骗信息时,往往处于情绪催眠状态——骗子用"紧急""出事了""马上转账"制造恐慌, 老人在恐惧中丧失理性判断能力。我们的反馈内容必须从心理学角度打破这种催眠, 用老人"一听就懂、一看就惊"的方式传递风险信号。以下设计基于认知心理学、恐惧诉求理论、行为经济学和行为改变跨理论模型。

🧠 七大心理学原则

1 破除催眠（Pattern Interrupt）

骗子用"紧急""马上"制造情绪催眠,老人在恐慌中无法理性思考。
AI第一句话必须"打断"这个状态——用命令式闽南语急促喊停：
"阿贝！等一下！先莫急！"
这不是礼貌用语,而是心理急救——把老人从骗子制造的情绪旋涡中拉出来。

2 损失框架（Loss Framing）

行为经济学证明：人对"失去"的敏感度是"获得"的2.5倍。
不说"这是诈骗"（抽象概念）→ 说 "打钱出去就没了,拿不回来"（具体损失）
不说"风险等级高"（专业术语）→ 说 "你的养老钱要被骗走了"（切身后果）
把抽象风险翻译成老人能感知的具体损失。

3 具象化表达（Concreteness）

老人抽象思维弱,具体记忆强。所有反馈必须把概念变成画面：
✗ "涉嫌电信诈骗" → ✓ "有人假装你孙子,说要你打钱"
✗ "虚假投资平台" → ✓ "那个理财网站是假的,钱放进去就被吃掉"
✗ "建议核实身份" → ✓ "先打电话给你儿子本人,号码是你手机里存的那个"

4 恐惧适度法则（Optimal Fear）

恐惧诉求理论：过度恐惧导致冻结（吓得不动）,不足恐惧导致忽视。
最佳公式：危险（具体）→ 后果（切身）→ 行动（简单可执行）
"这是骗子！钱打出去就没了！（危险+后果）→ 不要打钱！打给你儿子！（行动）"
关键：恐惧之后必须紧跟行动指引,否则老人会陷入恐慌瘫痪。

5 三秒法则（3-Second Rule）

老人看到结果页的前3秒决定后续行为——继续看还是关掉。
第一屏必须只传达两件事：
① 是不是骗子（红/黄/绿 + 大字 + 图标）
② 该怎么办（不要打钱 / 打给儿子）
其他信息（风险点拆解、案例参考）放在下方,老人想看才看。

6 关键信息三重复（Triple Repetition）

老人短时记忆弱,关键信息必须至少出现3次：
① 视觉：红色大字"不要打钱！"
② 语音：闽南语播报"不要打钱！"
③ 行动：按钮文字"不要打钱,打给儿子"
三通道重复确保即使老人漏看/漏听某一通道,也能接收到核心信息。

7 行动极简（One-Three Rule）

老人在紧张状态下决策能力骤降。最多给3个行动选项,每个不超过6个字：
① 不要打钱 ② 打给儿子 ③ 发给家人看
不用"建议""可以考虑""您可能需要"等模糊词。用祈使句——"不要打钱""打给儿子""发给家人看"。

📢 反馈内容五层结构

基于以上原则,高危诈骗的反馈内容按时间紧迫度分五层递进,每一层有明确的心理学目标。 老人不需要"阅读"——听一句话就知道该怎么办。

0-1秒 第一层：破除催眠 — "等一下！" 心理学目标：Pattern Interrupt
视觉
⚠️ 等一下！
闽南语语音（急促、大声）
"阿贝！等一下！先莫急！"

为什么：骗子制造的"紧急感"让老人进入情绪催眠。第一句话不是"分析结果",而是命令式喊停, 把老人的注意力从骗子的话术中拉回到AI这里。闽南语"先莫急"比普通话"不要急"更能唤起亲切感和服从感。

↓
1-3秒 第二层：定性判断 — "这是骗子！" 心理学目标：明确归因
🚨
这是骗子！
冒充你孙子要钱
闽南语语音（坚定、有力）
"这条信息是骗子发的！
有人冒充你孙子，要骗你的钱！"

为什么：不说"疑似诈骗""风险较高"等模糊表述——老人不理解概率词汇。 直接说"这是骗子",用最短的词传递最确定的判断。"冒充你孙子"是具象化归因,让老人知道骗子具体在做什么。

↓
3-5秒 第三层：损失警示 — "钱打出去就没了" 心理学目标：Loss Aversion
💰 钱打出去就没了
拿不回来的！养老钱一分都别给！

为什么：老人对"诈骗"这个概念缺乏切身感受,但对"钱没了""拿不回来"有强烈的损失厌恶。 "养老钱"三个字直接关联老人的核心资产,激活保护本能。 不说"可能造成财产损失" → 说 "钱打出去就没了"。

↓
5-8秒 第四层：行动指引 — 三个按钮 心理学目标：Self-Efficacy
🚫
不要打钱
📞
打给儿子
📤
发给家人看

为什么：恐惧之后必须紧跟可执行的行动,否则老人会陷入"知道危险但不知道怎么办"的瘫痪状态。 三个选项覆盖所有场景：不做（不打钱）→ 确认（打给儿子）→ 求助（发给家人）。 每个按钮不超过4个字,动词开头,祈使句。

↓
持续 第五层：家人兜底 — "不确定就问儿女" 心理学目标：Social Support
🤝 不确定就发给儿女看看
他们帮你判断，不怕麻烦

为什么：老人怕麻烦儿女、怕显得自己没用。"不怕麻烦"五个字打消这个顾虑。 家人协同是最后一道防线——即使AI判断有误,家人也能兜底。分享按钮在所有页面常驻。

✅ 低风险内容怎么反馈
不能说"安全"——老人听到"安全"会彻底放松警惕,后续遇到变体骗术不再警惕。

正确话术："阿贝，这条信息暂时没发现问题。不过不太确定的话就发给儿女看看，他们帮你把把关。"

心理学考量：用"暂时没发现问题"替代"安全",保留适度警觉；用"不太确定就发给儿女"维持家人协同习惯。 永远不让老人产生"AI说安全就是绝对安全"的心理依赖。
🎤 闽南语语音语气规范
高危场景：语速稍快、音量增大、语气急切但不慌张。第一句"阿贝！等一下！"要短促有力, 像邻居看到危险时喊一声。后续播报语速恢复正常,确保老人听清每个字。

警惕场景：语速正常、语气诚恳。像街坊聊天："阿贝，这条信息有点奇怪，我说给你听听……"

低风险场景：语速偏慢、语气温和。像家人叮嘱："阿贝，这条信息暂时没发现问题，不过不太确定就发给儿女看看。"

禁用语气：机械播报腔、过度温柔（显得不严重）、过度恐吓（导致老人吓得不敢动）。

T10 婚恋交友（杀猪盘） 通过社交软件建立恋爱关系，嘘寒问暖后介绍"投资"或"博彩"，初期小利诱导大额投入后消失 单身中老年、离异群体
🔓 运用方式：诈骗类型分类标签
AI分析上传内容后，将结果归入 T1-T10 中的一个或多个类型。例如，老人上传一条"孙子出事快打钱"的短信， AI判定为 T8 冒充领导熟人（ subclass: 冒充亲友紧急求助）。 每个类型预置了闽南语讲解话术模板，如T8对应的播报："阿贝，这是骗子冒充你孙子，用出事来吓你， 其实不是真的。千万别打钱，先打电话给你孙子本人确认。"

📌 数据源二：13个反诈公式

来源：大同反诈基于国家反诈中心资料整理的13个反诈公式。每个公式由"特征要素组合 = 诈骗类型"构成， 直接编码为规则引擎的匹配条件。AI检测到内容命中公式左侧的特征要素组合时，自动触发对应风险判定。

编号 公式（特征要素 = 诈骗类型） 规则引擎匹配关键词 对应类型
R1 做任务 + 小额返利 + 大额投入 = 刷单诈骗 做任务、点赞、返利、垫付、刷单、佣金 T1
R2 网恋交友 + 嘘寒问暖 + 介绍投资/博彩 = 网络交友诈骗 交友、恋爱、内部通道、投资、博彩、稳赚 T10
R3 网络贷款 + 先交钱 = 虚假网络贷款诈骗 无抵押、放款快、手续费、解冻费、保证金、先交钱 T3
R4 快递丢失 + 三倍赔偿 + 索要验证码 = 冒充客服诈骗 快递丢失、赔偿、理赔、验证码、客服 T4
R5 内部消息 + 高额回报 + 提现受限 = 虚假投资理财诈骗 内部消息、高额回报、年化收益、提现、解锁 T2
R6 涉嫌违法 + 转移资金到安全账户 = 冒充公检法诈骗 涉嫌、违法、通缉令、安全账户、自证清白、公检法 T5
R7 招聘广告 + 面试录取 + 保证金/培训费/手续费 = 求职诈骗 招聘、录取、保证金、培训费、入职费 其他
R8 航班取消 + 提供退改签 + 转账付款 = 机票退改签诈骗 航班取消、退改签、赔偿、改签链接 其他
R9 ETC失效 + 认证链接 = 虚假信息诈骗 ETC失效、认证、点击链接、验证 其他
R10 相关部门 + 退税/补贴 + 下载不明APP = 虚假退税诈骗 退税、补贴、下载APP、税务局、财政 其他
R11 客服 + 退费 + 扫二维码/点击链接 = 冒充客服诈骗 退费、扫码、退款链接、教育机构、课程 T4
R12 冒充熟人 + 着急用钱 + 帮忙垫付 = 冒充熟人诈骗 急用钱、垫付、转账、领导、亲戚、朋友 T8
R13 海外高薪 + 专业对口 + 包吃包住 = 境外诈骗 海外高薪、月薪X万、包吃住、出国、边境 高危
🔓 运用方式：规则引擎匹配
每个公式编码为多关键词共现规则。例如 R12"冒充熟人诈骗"：当AI从上传内容中提取到 "急用钱/垫付/转账" + "领导/亲戚/朋友/孙子/儿子" 两组关键词同时出现时， 规则引擎自动标记为高危，并关联到T8类型的讲解话术。 规则引擎与LLM语义分析并行运行，任一命中即可触发预警，双重保险降低漏判率。

📌 数据源三：2025年度十大高发诈骗案例

来源：2025年反诈宣传资料。每个案例包含真实话术、套路拆解、防范提醒， 作为LLM的few-shot学习素材注入Prompt，让模型"见过"真实骗术，提升识别准确率。

案例01 刷单返利 · 损失8.7万

深圳职员小王被"短视频点赞赚钱"广告吸引，初尝甜头后垫资做"高级任务"，累计投入8.7万后平台无法提现。 话术特征："点赞做任务，日赚300""升级会员接高佣金单"

案例02 虚假投资 · 损失285万

单身女子李某交友软件认识"金融分析师"，确立恋爱关系后被推荐"内部理财通道"，抵押房产投入280万后平台关闭。 话术特征："内部消息""年化30%""稳赚不赔"

案例03 冒充客服 · 损失4.2万

上海王女士接到"顺丰客服"电话称包裹丢失可三倍赔偿，点击短信链接填写银行卡和验证码后4.2万被转走。 话术特征："快递丢失""三倍赔偿""点击链接填写信息"

案例04 冒充公检法 · 损失86万

广州赵某接到"北京市公安局"电话称涉嫌洗钱，发来伪造"通缉令"，要求断绝家人联系转86万到"安全账户"。 话术特征："涉嫌洗钱""通缉令""安全账户""自证清白""不要告诉家人"

案例05 虚假贷款 · 损失9万

重庆周某点击"无抵押极速贷"广告，获批30万后被要求交3万手续费，又以"卡号错误"要6万解冻费，累计9万未放款。 话术特征："无抵押极速贷""手续费""解冻费""先交钱再放款"

案例06 冒充熟人 · 损失100万

深圳总监王某收到"董事长"微信称紧急项目需转100万定金，准确说出公司项目信息，转账后发现微信被盗。 话术特征："紧急""先转定金""稍后补手续""特事特办"

以上为十大案例中的6个代表性案例，完整案例库在系统中作为LLM few-shot素材注入

🔓 运用方式：LLM Few-shot 学习
将上述案例的"话术特征 + 诈骗类型 + 风险等级"整理为结构化Prompt，注入LLM分析请求。 例如，当老人上传一条包含"紧急""先转定金""稍后补手续"的微信截图时，LLM参照案例06的模式， 判定为T8冒充熟人诈骗，风险等级高危，并生成对应的闽南语讲解。 few-shot学习让模型具备"见过真实骗术"的经验，显著提升识别准确率。

⚙️ 三层判断架构

三类官方数据分别对应三层判断能力，逐层增强，确保判断既快又准。

L1 规则引擎层（反诈公式 → 关键词匹配） 响应 < 100ms

数据来源：13个反诈公式（R1-R13）
运行方式：从上传内容中提取文字，用OCR识别图片文字，匹配13组关键词规则。命中即标记诈骗类型 + 初始风险分。
优势：极快、零误判（规则明确）、无需调用大模型。
示例：检测到"安全账户"+"自证清白"+"涉嫌违法" → 命中R6 → 标记T5冒充公检法 → 高危

↓
L2 LLM语义分析层（案例库few-shot + 语义理解） 响应 3-8s

数据来源：10类诈骗手法分类（T1-T10）+ 2025年度十大案例
运行方式：将上传内容 + L1规则匹配结果 + 案例库few-shot prompt 一起送入大模型，进行深度语义分析。 模型理解内容含义、识别诈骗套路、拆解风险点、生成建议行动。
优势：能理解"没见过的新型骗术"、能分析图片/视频内容、能生成方言讲解话术。
示例：上传一张微信截图 → LLM参照案例06模式分析 → "这条消息用紧急语气催你转账，且说'稍后补手续'， 这是典型的冒充领导诈骗套路"

↓
L3 综合研判层（三层信号融合 → 最终结论） 输出结果

运行方式：融合L1规则匹配分 + L2语义分析结论，综合输出最终判断。
输出内容：① 风险等级（高危/警惕/安全）② 诈骗类型（T1-T10或"非诈骗"）③ 风险点拆解（3-5条） ④ 建议行动 ⑤ 闽南语讲解话术
冲突处理：若L1判定安全但L2判定高危，以L2为准（LLM能识别新型骗术）； 若L1判定高危但L2判定安全，标记为"警惕"并建议分享给家人确认。

⚠️ 官方七条铁律（贯穿所有判断结论）
国家反诈中心《防范手册》中的七条"凡是"铁律，作为AI判断的最高优先级规则，任何内容命中即直接判定高危：
  1. 凡是要求垫付资金做任务的兼职刷单，都是诈骗！
  2. 凡是宣传"内幕消息、稳赚不赔、高额回报"的投资理财，都是诈骗！
  3. 凡是宣称"无抵押、无资质"网贷，要求先交"会员费""保证金""解冻费"的，都是诈骗！
  4. 凡是自称客服，以退款理赔为由索要银行卡和验证码的，都是诈骗！
  5. 凡是自称公检法，要求将资金打入"安全账户"的，都是诈骗！
  6. 凡是自称"领导"加微信，以帮亲友为由让转账汇款的，都是诈骗！
  7. 凡是通过社交平台拉你入群，让你点击链接、下载APP投资退费的，都是诈骗！
运用方式：这七条铁律编码为一级规则（R-Iron-1 ~ R-Iron-7），优先级高于一切。 AI检测到内容命中任一铁律，直接输出高危判定 + 对应闽南语警示话术，跳过常规分析流程。
11 / 技术路径建议

Demo 实现技术方案

以下为 Demo 阶段的技术实现建议，兼顾快速验证与未来演进。

🖥 前端

  • 框架：React / Vue 3 + Tailwind CSS
  • 适配：移动端优先，响应式布局
  • 相机/录像：Web API (getUserMedia)
  • 语音录制：MediaRecorder API
  • 微信分享：JS-SDK / 分享链接

🤖 AI 能力

  • 内容分析：多模态LLM（图文理解）
  • 视频分析：关键帧提取 + 图像识别
  • 方言理解：闽南语ASR → 文本 → LLM
  • 方言播报：LLM → 闽南语文本 → TTS
  • 对话：多轮对话 + 上下文记忆
  • 判断依据：国家反诈中心官方数据（详见第09节）
💡 闽南语 TTS 实现策略
Demo 阶段（快速验证）：使用普通话 TTS 生成语音，同时显示闽南语字幕/口语化文案。重点验证"语音播报"这一交互模式是否被老年人接受。

进阶阶段（核心壁垒）：接入闽南语专项 TTS（如厦门大学闽南语语音库、或基于开源方言TTS模型微调），实现真正的闽南语语音输出。这是产品的核心差异化能力。

终极形态：闽南语端到端语音对话——老人说闽南话，AI直接用闽南话回答，无需中间文字转换，体验如同与街坊邻居聊天。
