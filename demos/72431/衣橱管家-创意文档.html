PART 01

创意名称 + 创意介绍

🏷️

创意名称

衣橱管家（FamilyFit）——简洁、有记忆点，"Family" 寓意服务全家，"Fit" 双关：合身穿搭 + 贴合生活。

❓

想解决什么问题

家里衣服越买越多，却总是"找不到、想不起、搭不出"——翻箱倒柜找衣要十几分钟，衣柜里有什么全靠记忆，出门前在镜子前试了又换，家庭成员之间谁的衣服在哪更是一笔糊涂账。

💡

为什么会想到做这个

做家务时发现，衣物管理是个被忽视的高频痛点——我们用 App 管待办、管账单、管健身，却唯独没有把家里的衣物数字化。每次换季收纳、每次出门穿搭，都是一次"重新认识衣柜"的过程。

📦

大概是什么产品

一套运行在家庭电脑上、手机浏览器同局域网访问的全栈 Web 应用——既是全家衣物的数字台账，也是一个能 2D 虚拟试穿搭的"线上衣帽间"。

PART 02

目标用户及痛点

面向用户

以家庭为单位的用户群体

尤其是家里有 2 人及以上同住、衣物量大、换季收纳频繁的家庭；也包括注重穿搭、希望提高出门效率的年轻夫妻和小家庭。

📍 在什么场景下使用

🗂收纳整理时
拍照录入新衣物，标注它放在哪个衣柜哪一层，建立"线上衣柜 ↔ 线下位置"的映射。
🔍找衣服时
在手机上按成员 / 部位 / 颜色 / 状态筛选，一秒定位"那件灰色卫衣到底在哪"。
👔出门前穿搭时
进入虚拟换衣间，按部位点选衣物，2D 图层叠加合成全身搭配，满意再从衣柜取衣，避免反复试穿。
🍂换季收纳时
把过季衣物状态改为"收纳"，统计在穿 / 收纳 / 待洗 / 淘汰数量，决定是否需要添置或断舍离。
当前痛点

没有这个产品时，用户只能靠记忆和翻找

  • 找一件衣服要把几个衣柜翻乱，耗时长、效率低
  • 不知道家里到底有多少件衣服、哪些该淘汰
  • 出门前在镜子前反复试穿，浪费时间
  • 家庭成员之间互相分不清谁的衣服在哪，重复购买、找不到的情况频发
PART 03

价值与意义

⚡

效率提升

把"找衣—试搭—收纳"三个高频家务动作从线下搬到线上，让家务变得像点外卖一样简单。

  • 找衣时间从十几分钟压缩到几秒
  • 试穿成本降为零——先在屏幕上搭好再取衣
  • 穿搭方案可保存复用，每天出门省心省力
  • 全家共享一个衣物数据库，避免重复购买
  • 换季收纳变得有据可依，不再凭记忆
🌱

社会价值

通过衣物状态追踪与使用统计，帮助家庭更理性地对待消费，呼应可持续生活方式的倡导。

  • 清楚知道自己"有什么、穿什么、缺什么"
  • 从源头减少冲动消费和衣物浪费
  • 让家务的隐形劳动被看见、被管理
  • 让家庭成员之间的衣物归属与整理责任更清晰
  • 用数字化手段延续衣物的使用寿命
