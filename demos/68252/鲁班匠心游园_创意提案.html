网页端 · 四段式功能

  1. 学习探秘 榫卯可检索字典（按受力类型查结构）· 古迹对照（佛光寺/应县木塔）· 历代匠人史（鲁班→喻皓→蒯祥→梁思成）· 鲁班机关解密闯关（原创"百工阁"世界观，5-8关）
  2. 出题工坊 3D谜题设计器（拖拽榫卯构件拼装）· 难度设定 · 推送给绑定老人 · 状态追踪"爷爷用时2分30秒"
  3. 挑战榜 全民出题墙 · 老人极简出题（选3构件或语音）· 敬老院专区（单账号批量绑定）· 排行榜
  4. 传承看板 老人认知能力趋势曲线 · AI周评语 · "爷爷完成了你设计的鲁班锁"分享卡

技术方案

网页3D：Three.js + normal map木纹材质 + AO环境光遮蔽 + 构件拆解/拼合动画
框架：React + TypeScript + Vite
自适应难度：规则引擎（连续3题错误率＜20%升档，＞50%降档）
开发工具：全程使用 TRAE IDE，保留关键对话 Session ID
部署：Vercel，提供可体验链接

差异化护城河

现有榫卯项目多停留在"展示/娱乐"层。本作品首次将榫卯做成代际双向共创传承闭环——年轻人与老人互为出题者与训练者，文化在设计与训练中代代相传。这是同类竞品完全没有的维度。
