01

创意概述

Creative Overview

中国大地上流动着 130 多种汉语方言，它们承载着每个地方最深的情感与记忆。然而在普通话高度普及的今天， 方言正以前所未有的速度从年轻一代口中消失——老人满口乡音，孙辈一句听不懂；一句"食饭未"， 可能隔开的是两代人最朴素的关心。

「AI 方言守护者」是一个以 AI 为核心的方言保护与沟通平台。它把方言从"只能口口相传、难以记录、 无法被 AI 理解"的困境中解放出来，提供方言 ⇄ 普通话实时互译、AI 方言私教、 家庭乡音档案三大能力，让方言既能"被听懂"，也能"被学会"，更能"被留住"。

本提案为 TRAE AI 创造力大赛「报名创意提案」阶段产物，后续将使用 TRAE Work / TRAE IDE 将其落地为可体验的 Web Demo。

数据为综合公开资料的趋势性概述，用于说明问题严重性。

1

代际沟通断裂

留守老人多只会讲方言，孙辈只听得懂普通话。一句关心的乡音，变成无法跨越的墙。视频通话里，老人说一堆，孩子只能尴尬地笑。

2

方言无标准文字、难以记录

绝大多数方言没有规范书写系统，靠口口相传。老人一走，一整套词汇、谚语、童谣可能就此永久消失，连记录都来不及。

3

AI 是方言的"盲区"

现有语音助手、翻译工具几乎只支持普通话与主流外语。方言用户对着手机说话，AI 一句也听不懂——他们被挡在了 AI 时代门外。

4

方言学习资源稀缺

想学回自己的母语方言，却没有体系化路径。没有教材、没有老师、没有反馈，年轻人想传承乡音也无从下手。

03

创意方案

The Solution

围绕"译、学、存"三个字，构建一个让方言重新流动起来的 AI 平台。

译 · Translate

方言 ⇄ 普通话 实时互译

老人讲方言，AI 实时转成普通话文字/语音给孩子；孩子回普通话，AI 实时合成方言语音给老人。打通视频通话、语音消息两个最日常的场景。

学 · Learn

AI 方言私教

基于 LLM 的情景化教学：从"喊阿嬷吃饭"这种真实场景出发，AI 生成对话练习、即时纠正发音、按难度进阶，让乡音可以被重新学会。

存 · Preserve

家庭乡音档案

引导老人讲述故事、童谣、谚语，AI 自动转写、标注、归档，生成一份只属于这个家庭的"乡音记忆胶囊"，可永久保存、可随时回听。

04

目标用户

Target Users
核心用户 A

与长辈沟通有障碍的年轻人

在外工作、与讲方言的祖辈沟通困难的 18–35 岁群体。他们有情感连接的需求，也愿意为"听懂家人"付费，是产品冷启动的主力。

核心用户 B

想传承乡音的方言使用者

以中老年为主，希望自己的方言不被遗忘、能被孙辈学会。他们是语料的贡献者，也是"乡音档案"最珍视的人。

延伸用户 C

方言 / 语言研究者

高校语言学、民俗学研究者，需要真实方言语料做研究。平台众包语料库可成为宝贵的学术资源。

延伸用户 D

文旅 / 影视内容创作者

需要方言台词、方言配音、地方文化内容的生产者，可调用方言 TTS 与语料授权。

05

核心功能

Core Features
FEATURE 01

方言实时翻译对话

双语对照的语音对话界面，支持方言与普通话双向实时翻译，可一键切换"通话模式"与"消息模式"。

  • 语音输入 → 方言识别 → 普通话文字 + 合成语音
  • 普通话输入 → 方言文字转写 + 方言语音合成
  • 双语气泡对照，长按可收藏生词
FEATURE 02

AI 方言私教

以真实生活场景为单元的情景化学习，LLM 扮演对话对象，即时给出发音与用词反馈。

  • 场景课程：喊人吃饭、过年问候、买菜砍价……
  • 跟读打分：音素级发音纠正
  • 每日一句 + 进度勋章，轻量持续学习
FEATURE 03

家庭乡音档案

引导式录音 + AI 自动整理，把老人的口述故事变成可永久保存的家族记忆。

  • AI 提问引导：童谣、老手艺、家乡旧事
  • 自动转写、分段、加标签
  • 生成"乡音胶囊"，可分享给全家回听
FEATURE 04

方言文化地图

以地图形式汇聚各地方言的代表性词汇、谚语、童谣音频，让方言成为可探索的文化资产。

  • 按地域浏览方言词条与真人发音
  • 同一句话在不同方言里的"千地千音"
  • 众包贡献：人人可上传自己的方言
06

AI 技术如何赋能

AI Empowerment

AI 不是锦上添花，而是让方言第一次"可计算、可交互、可传承"的核心引擎。

方言语音识别 ASR

将方言语音转成文字。基于多语种预训练模型 + 方言微调，解决"AI 听不懂方言"的根本问题。
多语种预训练低资源微调音素建模

方言语音合成 TTS

把普通话文字合成为带方言口音的自然语音，让老人听到"自己人"的声音。
零样本音色克隆方言韵律建模情感语音

方言 ⇄ 普通话翻译

方言到普通话的语义翻译，处理一词多义、俚语、谚语等方言特有表达。
LLM 翻译俚语知识库上下文消歧

LLM 情景教学与引导

大模型扮演方言对话对象与口述采访者，生成个性化练习与引导式提问。
角色扮演发音评分自适应难度
数据飞轮：用户使用与众包贡献持续回流方言语料 → 模型越用越准 → 体验提升 → 更多用户贡献，形成方言保护的良性循环。

典型用户流程

User Journey

以"孙子用 AI 和讲粤语的奶奶视频通话"为例：

STEP 1

开启翻译通话

孙子发起通话，选择"粤语 ⇄ 普通话"模式。

STEP 2

奶奶讲方言

奶奶说"食咗饭未啊？"，AI 实时识别。

STEP 3

AI 双语呈现

孙子看到"吃饭了吗？"文字 + 听到普通话。

STEP 4

孙子回话

孙子说普通话，AI 合成粤语给奶奶。

STEP 5

生词收藏 + 学习

生词自动加入"我的方言本"，推送练习。

08

创新点

Innovation
创新 01

首个"译+学+存"一体化

现有产品至多做方言翻译，本创意首次把翻译、学习、文化存档三者打通，形成完整闭环。

创新 02

众包 + AI 的活态保护

不是把方言存进博物馆，而是让每个用户的使用与贡献都成为保护动作，方言越用越活。

创新 03

情感驱动的技术落地

以"听懂家人"这一强情感动机作为切入点，让冷冰冰的语音技术有了温度与传播力。

创新 04

低资源方言的可行路径

用预训练 + 少样本微调 + 众包回流，破解方言"语料少、难建模"的工程难题。

创新 05

家庭乡音胶囊

把口述史与 AI 转写结合，创造"可回听的家族记忆"这一全新内容形态。

创新 06

方言文化地图

以地图可视化呈现"千地千音"，让方言保护变成可探索、可分享的文化体验。

Demo 体验计划

Demo Plan

初赛阶段将使用 TRAE Work / TRAE IDE 构建一个可交互的 Web Demo，聚焦核心体验，无需正式上线部署。 以下为 Demo 的核心交互预览：

dialect-guard.trae.demo / 翻译通话
奶
食咗饭未啊？今日煲咗汤，返嚟饮啦。
普通话：吃饭了吗？今天煲了汤，回来喝吧。
孙
奶奶我吃过了，等下就回去喝汤！
粤语合成：阿嫲我食咗啦，等阵就返去饮汤！
AI
已收藏生词：「煲汤」「返嚟」。已为你生成 2 张粤语学习卡片，去练一练？
体验一

方言翻译对话

模拟 2–3 种代表性方言（如粤语、四川话、闽南语）的双向翻译，可切换方言与模式。

体验二

方言学习卡片

情景化跟读练习，AI 给出发音评分与即时反馈，展示学习进度。

体验三

乡音档案预览

展示一份已生成的家庭乡音胶囊，可播放录音、查看 AI 转写与标签。

技术实现说明：Demo 中方言识别/合成/翻译将以模拟数据 + 规则映射的方式呈现核心交互逻辑， 重点验证产品价值与体验闭环，而非追求生产级模型精度。这符合大赛"可运行 ≠ 部署上线"的评审导向。

价值与展望

Value & Vision

社会价值

  • 守护濒危方言，留住地方文化的根脉
  • 弥合代际沟通鸿沟，让亲情不再被语言阻断
  • 推动 AI 包容性，让方言用户也享受技术红利
  • 沉淀开放方言语料，反哺学术与文化研究

商业价值

  • C 端：方言私教订阅 + 乡音胶囊高级存储
  • B 端：文旅方言导览、影视方言配音授权
  • 数据：方言语料库的科研与教育授权
  • 生态：与方言地区媒体、文化机构共建内容

技术最大的善意，不是让所有人都说同一种话，而是让每一种话都被听见、被听懂、被记住。
