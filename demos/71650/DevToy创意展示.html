产品概览

{ }

JSON 格式化

CDP 风格的可折叠树形视图，支持字母排序、键盘导航、搜索定位，让复杂 JSON 一目了然。

🎨

颜色转换

支持 HEX / RGB / RGBA / HSL 多种格式互转，双预览色块（实色 + Alpha 棋盘格），一键复制。

⌨️

键盘优先

全键盘操作：↑↓选择节点、←→折叠展开、Space 切换、⌘F 搜索，高效开发者的首选。

📑

多 Tab 工作区

同一工具可开多个独立 Tab，左侧工具栏 + 右侧多 Tab 布局，并行处理多项任务。
