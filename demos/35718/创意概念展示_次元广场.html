⚠️ 痛点

现有方案从未真正解决的问题

小红书、抖音、商场公众号、各品牌独立小程序……信息被切割成无数碎片。 次元广场要做的，就是把这些碎片拼成完整的地图。

📡

信息分散 · 容易错过

活动信息分散在公众号、小红书、抖音、商场电子屏等多个渠道。 用户常因「不知道有活动」而错过心仪的快闪或限定发售。

🔇

社交缺失 · 同好难觅

商场内有大量同好，但缺乏线上连接方式。 「换谷」只能靠偶遇，拼团只能靠微信群，找逛展搭子全靠缘分。

🛒

交易体验差 · 跑空常有

没有官方二手交易平台，限定谷子被黄牛抢购。 商品库存无法实时查询，用户经常跑空。 热门活动需要凌晨排队，毫无体验可言。

✦ 功能

四大核心模块
构建次元闭环

不做大而全的平台，聚焦「信息展示 + 智能推荐」， 用最小的成本验证最大的价值，完美保留后续扩展接口。

📅

智能活动日历

月度/周度双视图，支持按活动类型（IP 快闪、宅舞大赛、换谷市集、签售会）和 IP 筛选。 一键预约 + 活动倒计时，让用户再也不会错过任何一场盛会。

月视图 IP 筛选 一键预约 倒计时提醒
🗺️

交互式楼层导览

基于商场平面图的矢量地图，支持多楼层切换。 点击商家图标即可查看店铺详情、主营 IP、近期活动，搜索直达。

楼层切换 商家定位 IP 搜索 路线规划
🤖

Agent 智能推荐

首次进入引导用户选择 3-5 个兴趣标签。 Agent 基于规则引擎，智能推荐个性化活动、店铺和商品。支持自然语言追问。

兴趣标签 个性化推荐 智能问答 规则引擎
🛍️

IP 导向商品展示

按 IP / 角色 / 品类三级分类，完全摒弃传统电商的通用分类逻辑。 每个商品标注线下售卖店铺位置，支持全链路跳转。
