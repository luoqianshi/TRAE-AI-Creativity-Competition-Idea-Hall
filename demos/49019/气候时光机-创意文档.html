气候时光机

Climate Time Machine —— 用老照片看见被遗忘的气候记忆

赛道 社会公益
类型 Web 应用
工具 TRAE IDE / TRAE Work

项目概述

一句话介绍：上传一张老照片，AI 还原拍摄当年的气候数据，与今天做对比——让气候变化从抽象的数字，变成每个人相册里真实可感的记忆。

气候时光机是一款面向公众的 Web 应用。用户上传带有时间地点信息的老照片，系统自动识别照片中的场景元素（河流、植被、雪山、海岸线等），并调取该地点当年的历史气候数据，生成一份可视化的"气候记忆报告"。

与常见的"预测未来"类气候科普不同，气候时光机选择"回望过去"的视角——用祖辈生活过的地方、自己童年游玩过的场景作为情感锚点，让气候变化的冲击从"遥远的灾难预测"转化为"家门口的真实改变"。

创意背景与动机

我是一名研究气候变化的研究生，每天都在与气温曲线、降水距平、极端天气频率打交道。但我发现，当我跟家人说"全球平均升温 1.5℃"时，他们几乎没什么感觉；而当我翻出父亲 1985 年站在老家河边的照片，告诉他"那年夏天平均气温比现在低 3℃，这条河现在的汛期水位下降了 40%"时，他突然沉默了。

这个瞬间让我意识到：气候变化的震撼，不在论文里，在每个人的相册里。

目前市面上的气候科普产品，大多是"展望未来"的灾难预警——2050 年的海平面上升、2100 年的极端高温。这些很重要，但普通人很难与遥远未来的模拟图产生情感连接。气候时光机反其道而行之：不是预测未来，而是重建过去——用每个人都拥有的老照片作为入口，让气候数据与个人记忆产生交集。

目标用户与核心痛点

普通家庭用户

想了解自己或祖辈生活过的地方经历了怎样的环境变化，但不知道如何获取和理解专业气候数据。

摄影爱好者

收藏大量老照片，希望为影像赋予更深层的叙事意义，而不仅是视觉记录。

中小学教师

需要生动的气候变化教学素材，让学生理解抽象的气候概念与真实生活的关联。

地方媒体/档案馆

需要公众参与的气候历史记录工具，让市民成为气候变迁的记录者和传播者。

三大核心痛点

  • 历史气候数据公开但"沉睡"在专业数据库里，普通人无法访问，更无法与自己的生活建立联系
  • 现有气候科普以"展望未来"的灾难预测为主，缺少"回望过去"的情感连接，难以引发持续关注和行动
  • 老照片承载着珍贵的代际记忆，但这些记忆从未与科学数据产生交集，其价值未被充分挖掘

产品功能规划

MVP 功能（初赛 Demo 版本）

  • 老照片上传：支持 JPG/PNG 上传，自动提取 EXIF 中的拍摄时间和 GPS 信息；无 EXIF 时可手动输入时间和地点
  • 场景智能识别：AI 识别照片中的关键场景元素（河流、冰川、农田、森林、海岸线、建筑等），标注可能受气候变化影响的区域
  • 气候数据还原：自动调用该地点当年的历史气候数据，包括年平均气温、降水量、极端高温天数、空气质量指数等核心指标
  • 今昔对比可视化：生成并排对比卡片，直观展示"当年 vs 现在"的气候差异，用温度计、降水柱等可视化组件呈现
  • 气候记忆文案：基于数据对比，自动生成一段适合分享的文案（如"1985 年的那个夏天，平均气温 24.3℃，比今年低了 2.8℃"）

扩展功能（复赛阶段）

  • 个人气候相册：批量上传多张照片，按时间线生成个人/家族的"气候记忆时间轴"
  • 社区气候档案：开放同一地点的多用户投稿，形成城市公共气候记忆库
  • 气候行动建议：根据对比结果，推荐用户可参与的本地化环保行动
  • 方言语音播报：用当地方言或长辈口吻播报气候变迁故事（契合"智慧助老"公益方向）

技术实现方案

前端界面

React + Tailwind CSS，响应式设计，支持移动端和桌面端。照片上传、结果展示、分享功能。

图像识别

调用云端图像识别 API（豆包/CLIP）识别场景元素；EXIF 数据解析由前端直接处理。

气候数据源

中国气象数据网（CMDC）、NOAA Global Historical Climatology Network、NASA GISS 公开数据集。

数据可视化

ECharts / D3.js 制作对比图表；HTML5 Canvas 生成分享卡片图片。

文案生成

调用大模型 API，根据结构化气候数据生成情感化叙事文案。

部署

前端静态部署（Vercel/Netlify），气候数据通过 serverless 函数代理请求。

技术可行性说明：本项目技术栈成熟，核心依赖公开气候数据接口和现有 AI 服务，无需自建复杂模型。初赛周期内可完成上传→识别→查询→展示的核心链路，技术风险可控。

价值与意义

社会价值

气候变化是当下最重要的公共议题之一，但公众参与感普遍薄弱。气候时光机用"老照片"这个几乎家家户户都有的情感载体，把宏大的气候议题拉回到每个人的生活经验中。它不只是科普工具，更是一个让代际之间产生气候对话的媒介——当孙子向爷爷展示"您年轻时家门口的河比现在宽一倍"时，气候变化才真正走进了家庭。

教育价值

对于青少年而言，祖辈的故事比课本更有说服力。气候时光机可以成为学校环境教育的互动工具，让学生用家族历史理解全球变化。中小学地理、环保课程均可引入作为实践作业。

文化传承价值

老照片本身是重要的视觉史料，气候数据是科学史料。两者的结合，创造了一种全新的"环境口述史"形式，为地方档案馆、博物馆提供了公众参与的历史记录工具。

商业潜力

基础功能免费开放，可探索的商业模式包括：定制化精装气候记忆相册（面向摄影爱好者）、学校/机构教育版授权（B 端）、与地方文旅局合作的"城市气候记忆"项目（G 端）。

差异化定位

目前市面上与气候变化相关的应用主要集中在两个方向：一是专业的气象数据平台（如 Windy、中央气象台），面向专业人士；二是未来气候预测可视化（如 Climate Central 的海平面上升地图），面向公众科普。但几乎没有产品从"个人记忆 + 历史回溯"的角度切入。

气候时光机的独特定位：不是告诉你"未来会有多糟"，而是帮你发现"过去已经变了多少"。情感基调不是恐吓，而是怀旧与反思。这种差异化视角，在现有气候科普产品中具有鲜明的辨识度。
