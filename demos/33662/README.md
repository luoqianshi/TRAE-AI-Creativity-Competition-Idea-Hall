# 心眠小筑 🌸

> AI 情绪管理与助眠应用

---

## 项目简介

**心眠小筑** 是一款基于 AI 的情绪管理与助眠桌面应用，旨在通过温暖的界面、贴心的 AI 树洞对话、沉浸式放松动画、个性化音乐推荐等方式，帮助用户在忙碌的生活中找到内心的宁静。

## ✨ 产品亮点

- **AI 树洞对话**：基于火山引擎大模型，根据当前情绪状态提供个性化、温暖的对话支持
- **情绪打卡与趋势**：每日心情记录，生成情绪走势图，记录情绪标签
- **治愈短句生成**：AI 生成暖心语录，随时点亮心情
- **沉浸式放松动画**：全屏波浪粒子动画，鼠标互动，结合背景音生成
- **AI 助眠中心**：音乐推荐、原创音乐列表、睡前故事语音朗读、冥想引导
- **个人中心**：操作记录与状态追踪

## 🎯 核心功能

| 模块 | 说明 |
|---|---|
| 🏠 首页 | 心情选择 + AI 对话 + 治愈短句 + 睡前清单 |
| 💭 心情 | 打卡 + 标签 + 日记 + 情绪走势 + AI 情绪分析 |
| 🌊 放松 | 全屏波浪粒子动画 + 背景音生成 |
| 🌙 助眠 | AI 智能推荐 + 原创音乐 + 睡前故事 + 冥想引导 |
| 👤 我的 | 统计数据 + 功能菜单 + 操作记录 |

## 🛠 技术栈

| 层级 | 技术 |

## 🚀 快速开始

### 方式一：浏览器直接打开

直接双击 `index.html`，即可在浏览器中预览应用。

### 方式二：本地开发服务器

```bash
# 启动简易服务器
node server.js
```

然后在浏览器访问 `http://localhost:3000`

### 方式三：Electron 桌面应用

```bash
# 安装依赖
npm install

# 启动 Electron
npm start

# 打包发行版
npm run build        # 根据当前系统
npm run build:win  # Windows
```

## 🔧 API 配置

1. 打开 `index.html`，在 JS 配置火山引擎 API Key：

```javascript
const VOLC_API_CONFIG = {
    baseUrl: 'https://ark.cn-beijing.volces.com/api/v3',
    apiKey: '你的-API-KEY',
    model: '你的模型ID'
};
```

2. 没有 API Key 也可以使用——应用会智能降级，提供本地兜底回复。

## 📝 使用说明

1. 启动后会看到欢迎页，点击"开始探索"进入主界面
2. 选择当前心情，触发背景变色和 AI 响应
3. 点击底部导航切换不同功能模块
4. 与 AI 树洞对话，记录心情日记
5. 在放松页面体验全屏波浪动画
6. 在助眠中心体验 AI 推荐的睡前故事与音乐

## 🎨 设计特色

- **毛玻璃质感**：统一使用 backdrop-filter 实现精致的模糊感
- **情绪响应式背景**：根据心情状态切换整体色彩氛围
- **流畅过渡动画**：页面切换、按钮交互、波浪流动均有流畅动画
- **Toast 提示系统**：自定义的消息提示，替代原生 alert
- **Canvas 动态背景**：粒子动画、光晕、涟漪，配合心跳节奏
- **响应式布局**：适配不同屏幕尺寸

## 🌿 隐私与安全

- 所有日记和打卡数据仅存储在本地浏览器
- ⚠️ API Key 目前存储在前端，生产环境建议使用后端代理
- 我们不会收集或上传用户的对话与日记内容
