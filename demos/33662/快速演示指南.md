# 心眠小筑 · 快速演示指南

> 约 3 分钟即可完整体验核心功能

---

## 第 1 步：启动作品

**推荐方式（最简单）：**
- 双击 `index.html`，用浏览器打开

**备用方式：**
```bash
node server.js
# 浏览器访问 http://localhost:3000
```

---

## 第 2 步：进入应用

1. 进入欢迎页，点击 **「开始探索」**
2. 底部出现 5 个导航图标

---

## 第 3 步：体验核心功能

### 🏠 首页探索
1. 选择当前心情（😊 😐 😰 🔥 😢）
2. 观察背景颜色随心情平滑切换
3. 滚动到「AI 树洞」，输入你的心里话，点击发送
4. 体验 AI 根据情绪给出的温暖回复
5. 点击「获取短句」，看 AI 生成的治愈语录
6. 勾选下方的「睡前清单」

### 💭 心情页面
1. 点击底部「💭 心情」导航
2. 点击 **「✨ 立即打卡」**，记录今日心情
3. 查看「本月情绪走势图」曲线
4. 点击「获取安抚建议」，体验 AI 情绪解析
5. 在日记区写下文字，点击保存

### 🌊 放松页面
1. 点击底部「🌊 放松」导航
2. 进入全屏粒子动画
3. **移动鼠标**，观察波浪跟随互动
4. 背景音乐自动生成（白噪音 + 和声）
5. 点击右上角「返回首页」按钮退出

### 🌙 助眠中心
1. 点击底部「🌙 助眠」导航
2. 点击 **「🤖 AI 智能推荐」**，查看个性化推荐
3. 点击 **「🎵 AI 创造音乐」**，查看 AI 原创音乐列表
4. 点击 **「📖 睡前故事」** 或 **「🧘 冥想引导」**
5. 点击 **「▶️ 播放语音」**，AI 朗读故事引导入眠

### 👤 我的中心
1. 点击底部「👤 我的」导航
2. 查看使用数据统计
3. 查看最近操作记录

---

## 💡 最佳体验提示

- 推荐使用 **Chrome / Edge 浏览器**
- 建议将浏览器全屏（F11）以获得最佳沉浸式体验
- 在放松页移动鼠标，感受粒子互动的乐趣
- 试着对 AI 树洞说「我今天压力很大」或「心情不太好」，看看 TA 会怎么回复
- 如果浏览器提示「要求麦克风权限」，可以拒绝，不影响主要功能

---

## ❓ 常见问题

**Q: 打开后界面是空白？**
A: 请确认双击的是 `index.html`，而不是其他文件。

**Q: AI 对话没有回复？**
A: 作品内置了本地温情回复库，无需 API Key 也可以体验。如果配置了火山引擎 API Key，将获得更丰富的 AI 回复。

**Q: 播放语音没有声音？**
A: 请检查浏览器是否允许网页使用语音合成（Web Speech API）。部分浏览器可能需要在 HTTPS 或 localhost 下才能正常使用。

**Q: 日记或打卡记录会丢失吗？**
A: 不会，数据保存在浏览器本地存储。但清除浏览器缓存会清空数据。
