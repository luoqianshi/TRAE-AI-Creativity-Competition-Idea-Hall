## 一、作品简介

### 作品名称
心眠小筑 — AI 情绪管理与助眠应用

### 一句话描述
用 AI 温暖每个人的夜晚，帮你记录情绪、对话树洞、放松入眠。

### 创作背景与痛点
在快节奏的现代生活中，情绪困扰和睡眠问题日益普遍。很多人在深夜辗转反侧时，缺乏一个能够倾诉、理解和陪伴的对象。本作品希望用 AI 的力量，为每个人打造一个温暖的"情绪小站"和"睡眠港湾"。

### 适用人群
- 工作压力大、情绪需要调节的都市人群
- 失眠困扰、需要助眠引导的用户
- 希望通过日记和打卡记录自我情绪的探索者
- 对 AI 对话和情绪陪伴产品有兴趣的所有人

## 二、作品演示方式

### 方式一：浏览器预览（推荐）
1. 直接双击 `index.html`，在浏览器中打开即可体验完整功能
2. 首页 → 选择心情 → AI 树洞对话 → 切换到放松页 → 体验波浪动画

```bash
cd 项目目录
node server.js
```

### 方式三：Electron 桌面应用
```bash
npm install
npm start
```

### 快速体验路径
首页心情选择 → AI对话 → 放松页波浪动画 → 助眠中心睡前故事 → 日记打卡 → 查看情绪走势

## 四、技术架构与实现亮点

### 技术栈
| 层级 | 技术选型 |
|---|---|
| 前端框架 | 纯 HTML5（单文件应用，约207KB） |
| 桌面端 | Electron |
| 样式引擎 | CSS3 + backdrop-filter 毛玻璃 |
| 动画系统 | Canvas 2D 动态粒子 |
| 音频引擎 | Web Audio API 实时合成白噪音 + 正弦波和声 |
| 语音合成 | Web Speech API 中文朗读 |
| AI 对话 | 火山引擎豆包大模型 |
| AI 图像 | 火山引擎图像生成 API |

### 核心亮点

1. **情绪响应式视觉系统**
   - 5 种情绪 × 多层渐变背景
   - 颜色平滑插值过渡（非瞬时切换）
   - 结合心跳节奏的光晕波动

2. **沉浸式 Canvas 放松动画**
   - 2000+ 粒子实时流动
   - 鼠标位置驱动粒子聚集/散开
   - Web Audio API 实时合成白噪音和声

3. **AI 树洞对话系统**
   - 动态 System Prompt，根据情绪定制回复风格
   - 离线降级：无 API Key 时自动使用本地温情回复库
   - XSS 防护：消息内容使用 textContent + white-space: pre-wrap

4. **精致的 UI / UX 设计**
   - 毛玻璃质感卡片（backdrop-filter）
   - 自定义 Toast 提示系统（替代原生 alert）
   - 按钮悬浮水波反馈、页面切换平滑动画
   - 响应式布局，支持从手机到桌面

5. **完整的本地数据闭环**
   - 日记、打卡、标签、操作记录全部本地存储
   - 无需注册登录、隐私友好
   - SafeStorage 封装确保异常安全

## 六、API 配置说明

在 `index.html` 顶部 JS 中配置火山引擎 API：

```javascript
const VOLC_API_CONFIG = {
    baseUrl: 'https://ark.cn-beijing.volces.com/api/v3',
    apiKey: '你的 API Key',
    model: '你的模型 ID'
};
```

⚠️ 注意：即使不配置 API Key，作品依然可正常运行（本地兜底回复），不会影响功能演示。

## 七、创作历程

### 灵感来源
"心眠小筑"的灵感来源于现代人常见的两个痛点：一是情绪无处安放、缺少倾诉对象；二是夜晚失眠，但市面上没有一款温暖、轻量、沉浸式的产品。

### 开发过程
1. **构思**：以"温暖"和"轻量"为核心关键词
2. **设计**：毛玻璃 + 渐变色 + 粒子动画，营造温柔氛围
3. **开发**：单文件架构 — HTML/CSS/JS 一体化，方便部署和分享
4. **集成 AI**：接入火山引擎大模型，让 AI 真正"懂"用户的情绪
5. **打磨细节**：从 Toast 提示到 Canvas 颜色插值，逐个优化

### 使用 TRAE 的创作体验
在 TRAE 的 AI 辅助下，项目开发效率大幅提升。AI 能够根据自然语言描述，精准生成代码，帮助快速迭代功能模块。这让一个"想法"可以快速变为"可运行的作品"。
