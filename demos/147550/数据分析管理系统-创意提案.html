数据分析师的真实困境

不是缺工具，而是缺一个真正懂业务上下文的"副驾"

🧩

表结构记不住

业务表上百张、字段上千个，每次写 SQL 都要反复查 wiki、问同事，耗时且容易出错。JSON 嵌套字段的提取路径更是噩梦。

🔁

重复劳动严重

同样的留存口径、漏斗逻辑每周重写一遍。代码片段散落在各处飞书文档、本地脚本，找不到了就从头再来。

🤖

大模型不懂业务

直接问 ChatGPT 生成的 SQL，表名错、字段错、口径错。模型缺乏你的表结构、业务知识、历史分析上下文。

📚

知识无法沉淀

每次分析过程的思路、踩坑、结论都随聊天记录蒸发。新人 onboard 要重新踩一遍同样的坑。

五大核心模块

从代码编写到知识沉淀，从表结构管理到大模型分析，一站式打通分析师工作流

01

代码编辑器

双模式设计：悬浮编辑窗 + 专注编辑模式，支持 SQL / Python 语法校验与智能补全。

  • 表结构字段双击快捷插入
  • JSON 子字段自动生成提取函数
  • 高频使用表侧边栏快捷区
  • 多标签页 + 本地持久化
02

表结构管理

文件导入或手动建表，自动解析字段、JSON 子字段，构建可视化表图谱。

  • CSV / Excel / JSON 一键导入
  • 字段中文别名管理
  • 力导向表图谱 + 血缘分析
  • 多标签体系 + 使用频率统计
03

知识库管理

Markdown 所见即所得编辑，版本快照 + diff 对比，让分析知识真正沉淀。

  • 多级目录树 + 标签分类
  • 全文搜索 + 高亮匹配
  • 版本快照与回滚
  • 并排 diff 视图对比
04

大模型业务分析

自动组装表结构 + 高频表 + 知识库上下文，让大模型真正懂你的业务。

  • 多模型配置自由切换
  • 上下文智能组装
  • 生成代码一键插入编辑器
  • 多轮对话 + 会话保存
05

定时任务调度

管理分析任务脚本与业务特征，记录执行周期与产出物，不执行只管理。

  • 5 类预设任务模板
  • 任务特征反向检索
  • 日 / 周 / 月调度日历
  • 执行记录手动登记
★

数据互通层

五大模块并非孤岛，表结构、使用频率、知识库内容全链路互通。

  • 编辑器 ↔ 表结构双向联动
  • 大模型读取表结构 + 知识库
  • 任务关联脚本与数据表
  • 使用频率反哺图谱权重
