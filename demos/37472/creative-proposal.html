创意介绍

Creative Introduction

想解决什么问题

传统编程学习需要掌握英文关键字、英文函数名、英文报错信息，对中文母语用户构成了天然的语言门槛。很多对编程感兴趣的孩子、非计算机专业学生、职场人群，在看到满屏英文代码时产生畏难情绪，最终放弃学习。

为什么想到做这个

在辅导身边朋友学习编程的过程中发现，大家不是怕逻辑，而是怕"看不懂的英文"。既然我们日常用中文思考，为什么不能用中文写代码？让编程学习的第一步变得轻松自然。

产品定位

一套 中文编程语言 + 一个 交互式学习平台

用户在文码平台上用中文关键字编写代码，边学边练，在浏览器中即时看到运行结果。学完基础课程后，可以无缝过渡到标准的 Python 等主流编程语言。

一句话感受区别

传统英文代码 main.py
def greet(name):
if name == "老师":
print("Good morning!")
else:
print("Hello, " + name)
