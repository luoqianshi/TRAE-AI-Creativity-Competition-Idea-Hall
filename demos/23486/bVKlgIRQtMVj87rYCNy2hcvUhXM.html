StatLab
浏览器即用的统计分析平台

让数据分析像使用 Excel 一样简单，像使用 Stata/SPSS 一样专业

StatLab 是一款基于 Web 的统计分析工具，覆盖数据导入、清洗、描述统计、 回归分析、假设检验、可视化等完整工作流。无需安装，浏览器打开即可使用， 让每个人都能轻松进行专业级数据分析。

功能亮点

覆盖数据分析全流程，从导入到报告一键完成

📁

多格式数据导入

支持 CSV、Excel 多 Sheet 导入，拖拽上传，内置示例数据集，大文件智能预览前 1000 行。

🧹

智能数据清洗

缺失值处理、去重、类型转换、列重命名、计算列，支持 pandas query 语法筛选，全局撤销/重做。

🤖

AI 数据分析助手

自然语言交互，自动生成分析方案。支持 OpenAI、Claude、Gemini、DeepSeek 等 10+ 模型。

📈

17 种专业图表

直方图、箱线图、散点图、热力图、雷达图等，支持 The Economist、Nature、Science 等期刊风格。

📐

完整计量分析

OLS、Logit/Probit、面板 FE/RE、IV/2SLS、DID、RDD、Poisson、Hausman 检验等。

📑

报告一键导出

描述统计、回归结果一键导出 Word/Excel 报告，含智能解读与可视化图表。

核心功能展示

专业级分析能力，零门槛使用体验

🧮 Excel 式表格编辑

基于 AG Grid 的高性能表格，支持单元格编辑、矩形框选、多区域选择。内置 HyperFormula 公式引擎，支持 SUM、IF、VLOOKUP 等函数，以及统计/计量专用函数。

  • 单元格级编辑与公式计算
  • 选区状态栏实时统计
  • 快捷键支持（复制/全选/删除）
  • 以 = 开头输入生成新列
# 公式栏示例 =SUM(income) 求和 =IF(age>30, "高", "低") 条件判断 =CORREL(x, y) 相关系数 =MEAN(income) 平均值

📊 专业回归分析

覆盖经济学、社会学、医学统计常用模型，支持稳健标准误、聚类标准误，结果含智能解读。

  • OLS / WLS 线性回归
  • Logit / Probit 二值选择
  • 面板数据 FE / RE / Hausman
  • 工具变量 IV / 2SLS
  • 双重差分 DID / 断点 RDD
# OLS 回归结果示例 Dep. Variable: income R-squared: 0.847 Adj. R-squared: 0.842 coef std err t P>|t| ───────────────────────────────────────── const 2.145 0.312 6.875 0.000 education 0.523 0.089 5.876 0.000 age 0.156 0.034 4.588 0.000

🎨 期刊级可视化

17 种图表类型，内置 The Economist、Nature、Science、Lancet 等顶级期刊配色主题。

  • 分布：直方图、密度图、箱线图、QQ 图
  • 关系：散点图、气泡图、热力图
  • 趋势：折线图、面积图
  • 计量：系数森林图（回归后）
