REAL PAIN

他们不是假性努力

有些学生认真听课、认真做笔记、主动问老师、每天做专题练习，但考试反馈很差。问题不一定在态度，而可能在能力主线与学习流程之间断了一环。

01

第一印象固化

第一次接触知识点时形成了错误感觉，后续学习一直带着这个错误起点。

02

听懂不等于封装

老师讲清了内部逻辑，但学生还没有把它和自己的旧知识连起来。

03

感觉没有变直觉

“太难了”“我不会”“好别扭”长期占据高权重，做题时自然先退缩。

04

权重不会调整

做了很多题，却没有让信任权重、重要性权重和错误印象权重发生变化。

SIX PROBLEMS

六个问题，决定产品架构

六六学神从高考能力主线、第一印象、知识封装、直觉训练、名词解释、信任与重要性权重六个入口设计 Agent 行为。

高考的隐藏主线

围绕记忆、数理、推演三项能力训练，同时把表达、创造、感知、操作、热爱等能力作为辅助入口融入学习。

第一印象固化

帮助学生说出第一次接触知识点时的感觉，找出错误印象，避免带着错误起点进入后续学习。

知识点封装缺失

在老师讲清内部逻辑之后，继续帮助学生建立旧知联系，把知识压缩成少数记忆点和应用场景。

感觉变直觉

把混乱、杂乱、不可描述的感觉，训练成有逻辑、有条理、有依据、能复现的学习直觉。

概念名词解释

拆解中文名词，必要时补充英文来源、词源、断句方式和命名原因，降低“这个词好别扭”的初始阻力。

权重账本

管理知识来源的信任权重，以及知识点在个人体系中的重要性权重，让做题反馈能真正改变大脑里的排序。

ENCAPSULATION

知识点封装，不是多听一遍课

六六学神把一次学习拆成可观察的流程。每一步都要求学生给出反馈，避免用一句“我大概懂了”糊弄过去。

第一印象先说出“难、熟、别扭、没感觉”。
内部逻辑用数理和推演理解结构。
旧知关联调出已经封装过的知识点。
错误降权去掉错误方向和负面感觉。
封装卡
1

采集第一印象

学生先说出脑子里的第一反应：难、别扭、熟悉、像某个旧知识，还是完全没感觉。

2

理解内部逻辑

Agent 用学生能接受的表达讲清结构，再让学生用费曼方式复述。

3

连接已有知识

根据学生反馈寻找旧知识锚点，而不是只使用老师脑子里的通用联系。

4

完成知识封装

保留关键记忆点、应用场景、推演方向和“我能复现”的掌握感。

5

做题后再校准

用错题反馈调整信任权重、重要性权重和第一印象权重。

AGENT SYSTEM

Agent 架构

核心不是更长的讲解，而是更准确的追问、更个性化的封装，以及可持续更新的学生知识画像。

讲解、追问、封装、校准

Agent 先判断学生卡在概念、推演、记忆、旧知关联还是负面印象，再选择费曼复述、苏格拉底反问、名词拆解或错题复盘。每次学习结束后，系统生成一张“封装卡”，记录这个知识点的记忆点、应用场景、易错印象和权重变化。

660 分不是玄学

六六学神不承诺一键提分。它把 660 分拆成可训练的目标：更稳定的记忆调用、更清楚的数理理解、更可复现的推演链路，以及一次次做题后的重新封装。
