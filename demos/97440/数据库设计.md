# 候鸟旅居通 数据库设计文档

## 技术选型

- 数据库引擎：SQLite 3
- ORM：SQLAlchemy 2.0
- 字符集：UTF-8
- 第一阶段使用 SQLite（零配置），后续可平滑迁移到 PostgreSQL/MySQL

---

## 表结构总览

```
┌─────────────┐     ┌──────────────┐     ┌───────────┐
│   cities    │────→│   houses     │     │   users   │
│  (城市主表)  │     │  (房源表)     │     │  (用户表)  │
└─────────────┘     └──────────────┘     └───────────┘
      │                                        │
      │                                        │
      ▼                                        ▼
┌─────────────┐     ┌────────────────┐  ┌───────────────┐
│   reviews   │     │  house_reviews  │  │  favorites   │
│ (城市评价)   │     │  (房源评价)      │  │  (收藏)       │
└─────────────┘     └────────────────┘  └───────────────┘
```

## 1. cities（城市主表）

旅居目的地核心数据，每条记录代表一个城市或地区。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| id | INTEGER PK | 主键自增 | 1 |
| name | VARCHAR(50) | 城市名称 | 六盘水 |
| province | VARCHAR(50) | 省份 | 贵州 |
| lat | FLOAT | 纬度（地图用） | 26.59 |
| lng | FLOAT | 经度（地图用） | 104.83 |
| altitude | INTEGER | 海拔（米） | 1800 |
| summer_temp | VARCHAR(20) | 夏季平均温度 | 22℃ |
| winter_temp | VARCHAR(20) | 冬季平均温度 | 5℃ |
| air_quality | VARCHAR(20) | 空气质量等级 | 优/良 |
| humidity | VARCHAR(20) | 平均湿度 | 65% |
| rent_avg | INTEGER | 月租均价（元） | 1500 |
| rent_desc | VARCHAR(100) | 房租范围描述 | 800-1500/月 |
| medical_score | FLOAT | 医疗评分（0-5） | 4.0 |
| transport_score | FLOAT | 交通评分（0-5） | 4.0 |
| living_score | FLOAT | 生活便利评分（0-5） | 4.5 |
| elderly_score | FLOAT | 老人适合度综合评分（0-100） | 92 |
| category | VARCHAR(20) | 分类：避暑/避寒 | 避暑 |
| tags | TEXT | 标签（逗号分隔） | 中国凉都,高海拔,夏季避暑 |
| description | TEXT | 城市描述文本 | 六盘水被誉为... |
| image | VARCHAR(200) | 本地图片路径 | (预留) |
| hospitals_3a | INTEGER | 三甲医院数量 | 3 |
| has_high_speed_rail | INTEGER | 是否有高铁（0/1） | 1 |
| airport_distance | INTEGER | 机场距离（公里） | 20 |
| image_url | VARCHAR(500) | 在线图片URL | https://... |

### 索引

```sql
CREATE INDEX idx_cities_category ON cities(category);
CREATE INDEX idx_cities_elderly_score ON cities(elderly_score DESC);
CREATE INDEX idx_cities_rent_avg ON cities(rent_avg);
CREATE INDEX idx_cities_name ON cities(name);
```

### 权重算法（elderly_score）

```
elderly_score = 
  气候得分 × 30% +
  医疗得分 × 20% +
  房价得分 × 20% +
  交通得分 × 15% +
  生活便利得分 × 15%
```

各项得分均归一化为 0-100 分。

## 2. houses（房源表）

短期/长期租赁房源信息。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| id | INTEGER PK | 主键自增 | 1 |
| city_id | INTEGER FK→cities.id | 所属城市 | 1 |
| title | VARCHAR(200) | 房源标题 | 六盘水钟山区温馨一室 |
| price | INTEGER | 月租金（元） | 1200 |
| area | VARCHAR(50) | 面积 | 35㎡ |
| house_type | VARCHAR(50) | 户型 | 一室一厅 |
| category | VARCHAR(50) | 类型：公寓/民宿/康养社区/农家乐 | 公寓 |
| contact | VARCHAR(100) | 联系方式 | 张先生 138****5678 |
| nearby_hospital | VARCHAR(100) | 附近医院 | 市人民医院1.5km |
| nearby_market | VARCHAR(100) | 附近菜市场 | 明湖菜市场500m |
| min_rent | VARCHAR(20) | 最短租期 | 1个月 |
| rating | FLOAT | 评分（0-5） | 4.5 |
| image | VARCHAR(200) | 本地图片路径 | (预留) |
| image_url | VARCHAR(500) | 在线图片URL | https://... |
| description | TEXT | 房源描述 | 精装修公寓... |

### 索引

```sql
CREATE INDEX idx_houses_city_id ON houses(city_id);
CREATE INDEX idx_houses_price ON houses(price);
CREATE INDEX idx_houses_category ON houses(category);
```

```sql
CREATE UNIQUE INDEX idx_users_username ON users(username);
```

## 5. reviews（城市评价表）

用户对城市的旅居体验评价。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| id | INTEGER PK | 主键自增 | 1 |
| city_id | INTEGER FK→cities.id | 评价城市 | 1 |
| user_name | VARCHAR(50) | 用户昵称 | 王大爷 |
| rating_living | INTEGER | 居住体验评分（1-5） | 5 |
| rating_medical | INTEGER | 医疗方便评分（1-5） | 4 |
| rating_market | INTEGER | 买菜方便评分（1-5） | 5 |
| rating_elderly | INTEGER | 老人友好评分（1-5） | 5 |
| content | TEXT | 评价内容 | 我和老伴去年住了45天... |
| stay_duration | VARCHAR(50) | 居住时长 | 45天 |
| created_at | DATETIME | 创建时间 | 2024-06-15 |

### 索引

```sql
CREATE INDEX idx_reviews_city_id ON reviews(city_id);
```

## 第一阶段种子数据

### 首批城市数量：50+

覆盖以下维度：

- **避暑城市**（25+）：六盘水、昆明、贵阳、大理、丽江、成都、大连、青岛、烟台、威海、承德、长白山、西昌等
- **避寒城市**（20+）：西双版纳、三亚、陵水、北海、珠海、厦门、海口、南宁、湛江、惠州等
- **地理分布**：覆盖云南、贵州、四川、海南、广东、广西、福建、山东、辽宁、浙江、江苏、河北、吉林、安徽、江西、河南、湖北等省份

### 首批房源：16+套

覆盖：公寓、民宿、康养社区三种类型，价格区间 1000-5000元/月

### 首批评价：10+条

真实模拟退休老人视角的旅居体验评价
