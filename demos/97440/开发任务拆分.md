## Phase 2: 后端 API

### 2.0 FastAPI 基础

- [ ] 2.0.1 创建 FastAPI 应用实例
- [ ] 2.0.2 配置 CORS
- [ ] 2.0.3 配置静态文件挂载
- [ ] 2.0.4 启动种子数据（on_event startup）

### 2.1 首页 API (P0)

| 端点 | 方法 | 说明 |
|------|------|------|
| GET /api/categories | GET | 返回首页四大板块数据 |

**返回数据**：
```json
{
  "summer": [...],        // 8个避暑城市
  "winter": [...],        // 8个避寒城市
  "cheapest": [...],      // 8个最便宜城市
  "best_medical": [...]   // 8个医疗最好城市
}
```

### 2.2 城市列表 API (P0)

| 端点 | 方法 | 参数 | 说明 |
|------|------|------|------|
| GET /api/cities | GET | category, search, min_budget, max_budget, min_medical, sort | 城市列表+筛选排序 |

**实现要点**：
- 支持按分类筛选（避暑/避寒）
- 支持按价格范围筛选
- 支持按医疗评分筛选
- 支持按综合/价格/医疗排序

### 2.3 城市详情 API (P0)

| 端点 | 方法 | 说明 |
|------|------|------|
| GET /api/cities/{id} | GET | 城市详情+房源+评价 |

**返回数据**：城市基础信息 + 房源列表 + 评价列表

### 2.4 房源 API (P0)

| 端点 | 方法 | 参数 | 说明 |
|------|------|------|------|
| GET /api/houses | GET | city_id, min_price, max_price, category | 房源筛选列表 |

### 2.5 搜索 API (P1)

| 端点 | 方法 | 参数 | 说明 |
|------|------|------|------|
| GET /api/search | GET | q | 全文搜城市和房源 |

### 2.6 AI 推荐 API (P1)

| 端点 | 方法 | 参数 | 说明 |
|------|------|------|------|
| GET /api/recommend | GET | age, budget, month, health, preference | 智能推荐排行 |

**算法见 AI推荐算法设计文档**

## Phase 3: 前端页面

### 3.0 项目脚手架

- [ ] 3.0.1 创建 index.html 骨架

### 3.1 首页 (P0)

**UI优先级**：
1. 快速入口按钮（5个：避暑/避寒/低价/医疗/安静）
2. 夏季避暑推荐卡片网格
3. 冬季避寒推荐卡片网格
4. 低价城市推荐
5. 医疗最好城市推荐

**组件**：
- CityCard（城市卡片，复用）

### 3.2 城市列表页 (P0)

- 避暑页：显示所有避暑城市
- 避寒页：显示所有避寒城市
- 排行榜：按不同维度排序

**组件**：
- FilterBar（筛选栏）
- CityCard（城市卡片，复用）

### 3.3 城市详情页 (P0)

**浮层弹窗，展示**：
- 城市名称/省份/分类标签
- 综合评分大数字
- 气候数据网格（温度/海拔/湿度/空气质量）
- 居住成本（月租/生活评分）
- 医疗资源（评分/三甲数量）
- 交通（评分/高铁/机场距离）
- 房源列表（卡片样式）
- 评价列表（带星级打分）

### 3.4 房源页 (P0)

- 筛选栏（类型 + 价格区间）
- 房源卡片列表
- 联系房东按钮（弹窗显示联系方式）

### 3.5 AI 推荐页 (P1)

- 表单（年龄/预算/月份/健康/偏好）
- 提交按钮
- 推荐结果卡片列表

### 3.6 搜索页 (P1)

- 搜索输入框
- 搜索结果（城市+房源混合显示）

### 3.7 我的页面 (P2，MVP暂缓)

- 收藏列表
- 旅居计划
- 发布评价

### 3.8 响应式适配

- 桌面端：多列网格
- 手机端：单列 + 字体放大
