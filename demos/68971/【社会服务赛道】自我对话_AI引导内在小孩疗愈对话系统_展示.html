Tech Stack

技术原理与安全设计

疗愈需要的不只是温柔，更需要专业与严谨

🧠 IFS内在家庭系统疗法模型

基于Richard Schwartz博士的IFS疗法框架，将人格解构为"管理者""消防员""被放逐者"（内在小孩）等部分。AI引导对话始终围绕"与被放逐者建立连接"这一核心目标，避免误入其他心理防御机制。

# IFS对话阶段 phases = [ "建立关系", # 与内在小孩建立初步连接 "倾听感受", # 邀请表达被压抑的情绪 "理解需求", # 挖掘情绪背后的真实需求 "给予安抚", # 引导用户进行自我关怀 "整合接纳" # 完成对自我的重新认同 ]

💬 情绪识别与对话状态机

系统实时分析用户回复中的情绪信号（通过关键词匹配+情感分析模型），动态调整引导话术。当检测到阻抗或强烈负面情绪时，自动放慢节奏、提供更多安全感，绝不逼迫用户深入。

# 情绪响应策略 if sentiment == "resistance": respond_with_reassurance() # 提供安全感 elif sentiment == "sadness": validate_and_hold_space() # 共情与陪伴 elif sentiment == "breakthrough": deepen_exploration() # 适度深入

🛡 童年记忆安全回溯协议

对话开始前进行"安全锚定"——引导用户确认当前处于安全环境。对话过程中设置3个检查点，用户可随时暂停或退出。系统禁止直接追问创伤细节，只关注"当时的感受"而非"事件本身"。

# 安全协议 safety_checks = ["环境安全", "情绪稳定", "可暂停"] forbidden_topics = ["创伤细节", "自责归因"] always_offer = "你现在可以随时停下来"

📈 渐进式自我接纳训练

每次对话生成"自我关怀指数"——衡量用户在对话中表现出的自我接纳程度。长期追踪显示用户的情绪词汇丰富度、自我批评频率变化，AI据此调整后续对话的难度和深度。

# 自我关怀指数 sci = w1*self_compassion_words \ + w2*emotional_awareness \ - w3*self_criticism_freq trend = calc_weekly_trend(sci_history)
