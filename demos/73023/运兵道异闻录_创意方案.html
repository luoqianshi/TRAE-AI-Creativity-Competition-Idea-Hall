《运兵道异闻录》

AI 地下城探险 · 曹操运兵道互动叙事游戏

TRAE AI 创造力大赛参赛作品

主赛道：生活娱乐 附加赛道：社会公益

一、创意概述

本作品是一款以安徽亳州曹操地下运兵道为原型的AI互动叙事游戏。玩家扮演东汉末年曹军守将，在真实的运兵道结构中部署防御，阻挡敌军掘子军的夜袭。

游戏采用极简的"互动叙事 + 轻决策"模式：每回合呈现一个地道场景，玩家从3个战术选项中选择应对方式，AI实时生成叙事结果。全程纯前端HTML实现，零基础可在9天内完成Demo。

二、游戏核心逻辑

2.1 核心循环

  • 场景呈现：AI生成当前地道段落的文字描述与背景图
  • 决策选择：玩家从3个选项中选择战术应对
  • 结果生成：AI根据选择 + 真实地道机制，生成战斗叙事
  • 状态更新：推进敌军距离、消耗道具、进入下一场景
  • 胜负判定：撑过5个场景且指挥室未被突破 = 胜利；敌军抵达指挥室 = 失败

2.2 关键设计原则

  • 真实优先：所有场景、机关、道具均基于运兵道考古资料
  • 决策有代价：每个选项都有明确收益与风险，没有"正确答案"
  • AI叙事变化：同样的选择，AI每次生成的描述不同，增加重玩价值

三、真实资料依据

曹操地下运兵道位于亳州老城区地下，是迄今中国规模最大、年代最早、保存最完整的地下军事通道。

3.1 规模与走向

以大隅首为中心，呈十字形向四面延伸，分别通达四个古城门。全长8000多米，深埋地下2-7米，有上下双层结构（古代"立交桥"）。目前仅开发约600米供游览。

3.2 真实功能区

设施真实功能游戏化机制
猫耳洞单行道两侧，士兵藏身伏击伏兵位，敌军经过时触发突袭
障碍券/障碍墙阻挡敌兵推进消耗敌军一回合，但可被工兵破坏
绊腿板绊倒入侵者陷阱，敌方前锋眩晕，但后续敌军会警觉
拦马墙单行道每隔一段，高约1.5米分段阻击点，可逐个击破敌军
指挥室大隅首地下，调度全局玩家大本营，被攻破即游戏结束
灯龛砖壁1米高处放灯照明视野控制，熄灭后敌方看不清陷阱
通气孔通风+排烟敌方火攻时若被封，守军持续受伤
储藏室储备军需物资道具补给点，可补充亳州特色物资

四、攻守双方设定

4.1 守方：曹军

  • 身份：运兵道守备部队（虎贲禁卫）
  • 兵力：有限，每关可部署人数固定
  • 优势：熟悉地形，可利用地道机关
  • 劣势：兵力不足，信息有限（需靠罂听侦察）

4.2 攻方：掘子军

  • 身份：袁绍/敌军专门训练的地道掘进部队（历史上官渡之战确有此编制）
  • 特点：擅长挖掘与地下作战，有工兵可破坏障碍
  • 推进方式：每回合固定向前推进，玩家决策只能延缓或削弱，无法完全阻止

五、地图与场景设计

游戏采用"单路线推进"模式，共5个固定场景，对应运兵道真实结构：

第1更 · 东门入口
敌军状态：前锋刚入，队形松散
决策选项：伏兵突袭 / 放下绊腿板 / 派斥候侦察
第2更 · 单行道+拦马墙
敌军状态：前锋被阻，工兵上前
决策选项：加固障碍 / 猫耳洞侧击 / 撤退保存实力
第3更 · 双层交叉路口
敌军状态：敌军分兵两路
决策选项：封堵上层 / 伏击下层 / 牺牲一路保另一路
第4更 · 储藏室附近
敌军状态：敌军疲惫，但发现补给
决策选项：烧毁物资阻敌 / 用酒设火陷阱 / 让出物资拖延
第5更 · 指挥室外围
敌军状态：精锐尽出，总攻
决策选项：死守卫指挥室 / 设最后陷阱 / 点燃全道玉石俱焚

六、亳州特色道具系统

道具不是简单的"血药/蓝药"，每个都有独特的战术机制与副作用：

七、极简版实现方案（零基础9天）

7.1 技术架构

纯前端单HTML文件，零后端，零部署。浏览器打开即可运行。

  • 页面结构：一张古风地道背景图 + 文字叙述区 + 3个选项按钮 + 进度条（敌军距离）
  • AI集成：调用大模型API，根据玩家选择+场景ID生成叙事文本
  • 状态管理：JavaScript变量记录当前场景、敌军距离、道具数量
