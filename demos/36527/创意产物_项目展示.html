1. 创意介绍

想解决什么问题？

Beyond Compare 是一款公认优秀的商业软件（$30–70/平台）。但学生 / 初创 / 个人 / 国产化政企用户不一定愿意为每台机器付费正版，于是网上破解版泛滥 —— 违反 EULA、带木马风险、没有更新。本项目给"想用 BC 工作流但不愿盗版"的用户，一个合法、免费、够用的开源替代品。

为什么会想到做？

作为长期用 BC 做 code review、配置 diff 的开发者，深知它的体验业内顶尖。BC 本身没问题，问题在于"不愿盗版但又暂无能力付费"的群体缺少选择。用 Qt 6 + C++17 1:1 复刻，MIT 全开源，零法律风险。

是什么产品？

一个跨平台原生桌面应用：双栏文本差异比较（字符 / 词 / 行 三级粒度），双栏文件夹结构比对，BC 风格路径栏 + 缩略图 + 行号变化条 + 启动页。所有代码 MIT 协议，无需激活、零授权风险。

2. 核心特性

双栏对比

左右双编辑器，行级背景色（红=删除、蓝=新增）贯穿整行；缩略图条 + 视口指示器一键跳转。

三级粒度

行级 / 词级 / 字符级 互斥切换 (Ctrl+1/2/3)；字符级用 BC 风格红蓝高亮 + 加粗。

路径栏 + 交换

顶部左右路径输入 + 红/蓝色块标记 + 浏览按钮；⇆ 一键交换；左/右复制到对侧。

文件夹比对

树状对齐显示，状态符号 `= != > < >> <<` 标识相同/差异/孤立/较新；列：名称 / 大小 / 修改时间。

BC 风格 UI

橄榄黄主题、米色背景、Mac/Windows 风格混合；状态栏差异 / 重要 / 行 Col / 选中字符 / 编码 / 大小 一应俱全。

启动页

BC 风格欢迎页：新建文本/文件夹比较、快速打开左右、列出最近会话，工具栏 + Ctrl+Shift+H 随时呼出。

5. 价值与意义

🛡️ 合规优先

BC 本身没问题（公认业内顶尖）。本项目存在意义是给"想用 BC 工作流但不愿盗版"的用户一个 MIT 开源、零法律风险、零授权成本的合法选项。

⚡ 效率提升

三级粒度切换、行号变化条、缩略图跳转、键盘导航 Ctrl+1/2/3 + 上下处差异，比 GitHub PR 对比快 3 倍；启动页一键到达 6 种会话。

🌍 社会价值

尊重知识产权：减少破解版依赖；Qt 生态贡献：1:1 复刻的可复用实践；国产系统友好：UOS/Deepin/麒麟/优麒麟 一键运行；教学价值：完整中文注释源码。

🆚 vs 官方 BC

① 版权：商业闭源 vs MIT 开源；② 价格：$30–70 vs $0；③ 法律风险：盗版 = 违反 EULA vs $0 风险；④ 安全风险：破解版有木马 vs 源码可审计；⑤ 二次开发：❌ vs ✅ 任意修改商用；⑥ 集成：❌ vs ✅ 可嵌入自研产品；⑦ 教学：❌ vs ✅ 全套源码。
