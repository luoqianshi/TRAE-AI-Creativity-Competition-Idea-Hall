01

HTML基础

1.1
标签语法与HTML骨架
▾

概念说明

HTML（超文本标记语言）通过标签描述网页结构。标签由尖括号包围的关键词组成，通常成对出现。

核心要点

  • 双标签：<标签名>内容</标签名>，如 <p>段落</p>
  • 单标签：<br>、<hr>、<img>，无需结束标签
  • 标签关系：嵌套关系（父子）和并列关系（兄弟）

代码示例

HTML
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>网页标题</title>
</head>
<body>
    Hello World!
</body>
</html>
注意：DOCTYPE必须写在第一行；charset必须设为UTF-8否则中文乱码；lang属性有助于SEO。
1.2
排版标签与文本格式化
▾

排版标签

  • <h1>~<h6>：标题标签，h1最大，一个页面h1只用一次
  • <p>：段落标签，段落间有间距
  • <br>：换行（单标签），无间距
  • <hr>：水平线（单标签）

文本格式化标签（优先用语义标签）

  • <strong>：加粗（语义=重要）✅
  • <em>：倾斜（语义=强调）✅
  • <ins>：下划线（语义=新增）✅
  • <del>：删除线（语义=删除）✅
1.3
图像标签与路径
▾

img标签属性

  • src：图片路径（必需）
  • alt：替换文本，图片加载失败时显示（必需）
  • title：鼠标悬停提示
  • width/height：宽高（建议只设一个保持比例）

相对路径规则

路径
// 同级目录
<img src="logo.png" alt="Logo">

// 下级目录
<img src="images/photo.jpg" alt="照片">

// 上级目录
<img src="../assets/icon.png" alt="图标">
1.4
超链接与多媒体标签
▾

超链接 a 标签

HTML
<!-- 外部链接，新窗口打开 -->
<a href="https://www.bilibili.com" target="_blank">B站</a>

<!-- 空链接 -->
<a href="#">暂未开放</a>

多媒体标签

  • <audio>：音频，支持MP3/WAV/Ogg
  • <video>：视频，支持MP4/WebM/Ogg
  • controls：显示播放控件
  • autoplay + muted：自动播放需配合静音
  • loop：循环播放
02

HTML进阶

2.1
列表标签
▾

三种列表

  • 无序列表：<ul> + <li>，用于导航、新闻列表
  • 有序列表：<ol> + <li>，用于排行榜、步骤
  • 定义列表：<dl> + <dt> + <dd>，用于术语解释
HTML
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>
注意：ul/ol的直接子元素只能是li；CSS用 list-style: none 去除小圆点。
2.2
表格与合并单元格
▾

表格结构

  • <table>：表格容器
  • <tr>：行
  • <td>：单元格
  • <th>：表头单元格（默认加粗居中）
  • <thead>/<tbody>/<tfoot>：语义化结构标签

合并单元格

  • rowspan：跨行合并（垂直方向）
  • colspan：跨列合并（水平方向）
步骤：1.确定跨行还是跨列 → 2.在目标单元格加属性 → 3.删除被合并的多余单元格
2.3
表单（重点）
▾

input类型

  • text：单行文本框
  • password：密码框（显示为点）
  • radio：单选按钮（name相同为一组，互斥）
  • checkbox：复选框
  • file：文件上传
  • submit/reset/button：按钮

其他表单元素

  • <select> + <option>：下拉菜单
  • <textarea>：多行文本域
  • <label>：绑定表单控件（for属性对应id）
HTML
<label for="username">用户名：</label>
<input type="text" id="username" placeholder="请输入">

<label><input type="radio" name="gender" value="male" checked>男</label>
03

CSS基础

3.1
CSS引入方式与选择器
▾

三种引入方式

  • 外部样式（推荐）：<link rel="stylesheet" href="xx.css">
  • 内部样式：<style>标签写在head中
  • 内联样式（不推荐）：style="属性:值"

基础选择器

  • 标签选择器：p { } — 选中所有p标签
  • 类选择器（最常用）：.box { } — 选中class为box的元素
  • id选择器：#header { } — 选中id为header的元素（唯一）
  • 通配符：* { } — 选中所有元素
3.2
字体与文本属性
▾

字体属性

CSS
font-size: 16px;          /* 字号 */
font-weight: 400;          /* normal=400, bold=700 */
font-style: italic;        /* 倾斜 */
font-family: "Microsoft YaHei", sans-serif;
line-height: 1.5;          /* 行高，推荐用数字 */

/* 复合属性（必须按顺序）*/
font: italic 700 16px/1.5 "Microsoft YaHei", sans-serif;

文本属性

  • text-indent: 2em：首行缩进2字符
  • text-align: center：水平对齐（left/center/right/justify）
  • text-decoration: none：去除a标签下划线
  • color: #333：文字颜色
04

CSS进阶

4.1
复合选择器与伪类
▾

复合选择器

  • 后代选择器：.box p（空格，选中所有后代）
  • 子代选择器：.box > p（只选直接子元素）
  • 并集选择器：.box, p（逗号，同时选中）
  • 交集选择器：.box.active（同时满足）

结构伪类选择器

CSS
li:first-child { }      /* 第一个 */
li:last-child { }       /* 最后一个 */
li:nth-child(3) { }     /* 第三个 */
li:nth-child(odd) { }    /* 奇数行 */
li:nth-child(even) { }   /* 偶数行 */
li:nth-child(2n+1) { }  /* 公式：奇数行 */
4.2
CSS三大特性
▾

三大特性

  • 层叠性：相同选择器相同属性，后面的覆盖前面的
  • 继承性：子元素自动继承父元素文字相关属性（color、font-size、line-height）
  • 优先级：不同选择器权重不同

优先级权重

权重
继承 / *     →  0,0,0,0  （最低）
标签选择器    →  0,0,0,1
类/伪类选择器 →  0,0,1,0
id选择器      →  0,1,0,0
内联样式      →  1,0,0,0
!important    →  最高（少用）
注意：权重不能进位（11个类选择器不会超过1个id选择器）。
4.3
背景属性与显示模式
▾

背景属性

CSS
/* 拆分写法 */
background-color: #f5f5f5;
background-image: url("bg.jpg");
background-repeat: no-repeat;
background-position: center;
background-size: cover;  /* cover铺满裁切, contain完整留白 */

/* 复合写法 */
background: #f5f5f5 url("bg.jpg") no-repeat center/cover;

显示模式

  • 块级（div/p/h/ul/li）：独占一行，可设宽高
  • 行内（span/a/strong）：一行多个，不可设宽高
  • 行内块（img/input/td）：一行多个，可设宽高
  • display转换：inline-block / block / inline

盒子模型

5.1
盒子模型组成与box-sizing
▾

四部分组成

content（内容）→ padding（内边距）→ border（边框）→ margin（外边距）

box-sizing

CSS
/* 默认：width只是内容宽度 */
/* 实际宽度 = width + padding + border */
* { box-sizing: content-box; }

/* 推荐：width包含padding和border */
* { box-sizing: border-box; }

外边距居中

CSS
/* 块级元素水平居中（需固定宽度）*/
.container {
    width: 1200px;
    margin: 0 auto;
}
5.2
外边距问题与圆角阴影
▾

外边距塌陷（垂直方向）

  • 问题：父元素无上边框时，子元素上margin传递给父元素
  • 解决1：父元素加 overflow: hidden
  • 解决2：父元素加 padding-top 或 border-top
  • 解决3（推荐）：父元素加 display: flex

圆角与阴影

CSS
border-radius: 10px;     /* 四个角 */
border-radius: 50%;      /* 圆形（正方形元素）*/

/* 水平偏移 垂直偏移 模糊度 阴影大小 颜色 */
box-shadow: 2px 2px 10px rgba(0,0,0,0.2);
06

浮动与Flex布局

6.1
浮动与清除浮动
▾

浮动特点

  • float: left/right — 脱离标准流
  • 浮动元素顶部对齐，一行排满自动换行
  • 问题：父元素高度塌陷

清除浮动（推荐双伪元素法）

CSS
.parent::before,
.parent::after {
    content: "";
    display: table;
}
.parent::after {
    clear: both;
}
6.2
Flex布局（重点）
▾

容器属性（父元素）

  • justify-content：主轴对齐（flex-start/center/flex-end/space-between/space-around/space-evenly）
  • align-items：侧轴对齐（flex-start/center/flex-end/stretch）
  • flex-direction：主轴方向（row水平/column垂直）
  • flex-wrap：换行（nowrap/wrap）

子项属性

  • flex: 1：等分剩余空间
  • align-self：单独控制对齐

常用布局

CSS
/* 水平垂直居中（最常用）*/
.center {
    display: flex;
    justify-content: center;
    align-items: center;
}

/* 等分布局 */
.nav { display: flex; }
.nav-item { flex: 1; text-align: center; }

/* 两端对齐+换行 */
.cards {
    display: flex;
    flex-wrap: wrap;
    justify-content: space-between;
}

定位与装饰

7.1
定位（子绝父相）
▾

四种定位

  • static：静态定位（默认）
  • relative：相对定位（相对自身原来位置，不脱标）
  • absolute：绝对定位（相对最近的定位祖先元素，脱标）
  • fixed：固定定位（相对浏览器视口，脱标）

子绝父相 + 居中

CSS
.parent { position: relative; }
.child {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}

/* 固定导航 */
.fixed-nav {
    position: fixed;
    top: 0;
    z-index: 999;
}
08

2D/3D转换与动画

8.1
2D转换
▾

transform函数

  • translate(x,y)：平移（常用于居中）
  • rotate(deg)：旋转
  • scale(x,y)：缩放
  • skew(x,y)：倾斜
CSS
.card { transition: transform 0.3s; }
.card:hover { transform: scale(1.05); }

.icon:hover { transform: rotate(180deg); }
8.2
动画 animation
▾

定义与应用动画

CSS
@keyframes move {
    0% { transform: translateX(0); }
    50% { transform: translateX(200px); }
    100% { transform: translateX(0); }
}

.box {
    /* name duration timing delay iteration direction fill-mode */
    animation: move 2s ease 0s infinite alternate;
}
transition vs animation：transition需要触发条件（如hover），只能A→B；animation可自动执行，支持多关键帧。

移动端适配

9.1
rem与vw/vh适配
▾

rem适配

  • 1rem = html的font-size值
  • 配合媒体查询或flexible.js动态修改根字号
  • 设计稿375px时，根字号设为37.5px

vw/vh布局（推荐）

CSS
/* 1vw = 视口宽度的1% */
/* 设计稿375px时，1vw = 3.75px */

.box {
    width: 20vw;    /* 75px / 3.75 = 20vw */
    height: 10vw;
    font-size: 4vw;   /* 15px / 3.75 ≈ 4vw */
}
