// Inspiration

灵感来源：路况共建 × 组队开荒

将反诈宣传从"被动灌输"转变为"全民参与"，灵感来源于两个经典模式

🗺️

高德地图 · 路况共建

每位驾驶员都可以实时上报路况，汇聚成一张万人共绘的实时导航图。反诈情报也可以如此——每个遭遇骗局的人，都是最前线的"路况上报员"。

🎮

游戏 · 组队开荒

游戏中玩家通过共享攻略、标记陷阱来实现高效通关。我们将反诈知识转化为可视化的"攻略标记"，让新手和老手互相守护。

🤖

AI 脱敏 · 安全分享

用户上传诈骗截图后，系统通过AI前端自动脱敏处理，智能识别并遮挡手机号、银行卡号、身份证号等个人敏感信息，彻底消除隐私顾虑。

// Core Features

核心功能矩阵

四大核心模块，构建从情报采集到预警分发的完整闭环

📊

实时反诈气象看板

首页展示实时数据可视化大屏：全国诈骗热度地图、新型骗局发现趋势、各地区高发类型分布。如同天气预报，一眼掌握全国"诈骗天气"。

🔍

反诈热搜榜

基于全站情报数据自动生成实时热搜，展示当前最活跃的骗局类型、最新出现的诈骗话术、以及传播最快的新型剧本，让用户第一时间获取预警。

🛡️

一键情报上报

支持截图、链接、短信等多种形式上报，AI自动识别骗局类型并分类归档。上传后自动脱敏，零门槛参与全民反诈。

👥

家庭守护组队

子女可为父母创建"守护群组"，当父母收到疑似诈骗信息时，系统自动向子女推送预警通知，形成家庭联防联控的安全网络。

// Target Users

目标用户画像

两大核心人群，一个共同使命

👨‍💻
Core User A

数字原生代 · 信息防备者

25-40岁，频繁遭遇垃圾短信/骚扰电话的年轻网民。具备基本的数字素养，对新型AI诈骗高度警惕，是情报贡献的主力军，也是守护父母财产安全的发起者。

👩‍🏭
Core User B

银发族 · 潜在受害者

50岁以上，信息获取渠道有限的中老年群体。对新型骗局识别能力弱，是最需要被保护的人群。通过子女"守护组队"功能间接受益。

👨‍👩‍👧
Core User C

家庭守护者 · 关联用户

关注家庭安全的父母或子女，希望通过技术手段构建家庭联防安全网。每周定期查看黑产动向，为家人提供防骗提醒。

// Pain Points

当前痛点分析

传统反诈生态中的结构性困境

⚠️ 宣传滞后

传统反诈宣传周期长、迭代慢，从发现新型骗局到制作宣传材料需要数周时间，而骗子的剧本平均3-5天就会迭代一次。

😔 灌输式体验

长篇反诈文章、枯燥的案例警示，用户难以产生共鸣，更谈不上主动传播和参与。

🔒 隐私顾虑

用户想分享遭遇的骗局，但害怕泄露个人信息，社交平台上缺乏安全的脱敏分享机制。

💎 羞耻感壁垒

受害者受骗后常因羞耻感选择隐瞒，72%的受害者不会向任何人透露，导致同类型骗局反复得手。

🌐 信息孤岛

每个人遇到的骗局信息分散在各自的手机里，无法形成有效的预警网络，新型诈骗剧本在暗处野蛮生长。

🧹 代际数字鸿沟

年轻一代获取新型诈骗信息的渠道与中老年群体完全脱节，子女想提醒父母却找不到有效的预警工具。

// Social Impact

社会价值与意义

超越产品本身的社会影响力

01

范式转换：从被动防御到主动共建

打破传统反诈的被动局面，将用户从"潜在受害者"转变为"反诈情报员"，通过全民参与构建动态防御体系，实现对黑产剧本迭代的"以快制快"。

02

隐私破局：AI脱敏消除分享顾虑

前端自动脱敏机制完美解决隐私隐患，用户可以放心地分享遭遇的骗局详情，不用担心个人敏感信息泄露，让信息流动的"最后一公里"彻底打通。

03

代际连接：科技弥合数字鸿沟

"家庭守护组队"功能让年轻一代有能力为父母构建安全防护网，用技术手段弥合代际信息差，实现对中老年群体的精准守护。

04

群体智慧：用网络效应对抗黑产

"反诈热搜榜"和"高发套路地图"实现全网实时情报共享，利用群体智慧的网络效应，让每一个人的情报贡献都能保护千万人。

05

消除羞耻：去标签化的安全社区

匿名上报 + 社区互助模式，让受害者可以在无心理负担的环境中分享经历，将"受骗"从个体耻辱转化为全民可用的防御资源。

// Tech Stack

技术方案概览

基于小程序端的轻量化技术架构

📱

前端：微信小程序

零下载、即用即走的产品形态，极大降低使用门槛。Canvas + WebGL驱动数据可视化看板，提供媲美原生App的流畅体验。

🧠

AI引擎：多模态识别

基于OCR + NLP的骗局文本智能识别，结合图像理解模型自动分类，前端本地脱敏处理确保数据不出设备。

☁️

后端：Serverless + CDN

采用Serverless架构按需扩容，配合CDN加速静态资源和看板数据分发，支撑百万级并发的实时数据展示需求。

🔒

安全：隐私优先设计

端到端脱敏流程，敏感信息在设备本地处理，不上传原始数据。匿名化存储 + 差分隐私技术确保用户身份不可追溯。
