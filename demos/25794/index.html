01 / 简介

什么是 MoleWikiGraph？

MoleWikiGraph 采用独特的"LLM Wiki + 知识图谱 + 向量检索"三层架构， 将文档自动解析、提取实体关系、构建知识图谱。

不同于传统 RAG（纯向量检索）或纯知识图谱方案，MWKG 将文档消化为 Wiki 页面（可编辑）+ 知识图谱（结构化关系）+ 向量索引（语义检索）， 三层协同提供更全面的知识服务。

所有数据纯本地存储，核心检索仅需 SQLite + Python，无需 Elasticsearch、PostgreSQL、Milvus 等外部服务。 提供三种运行模式：规则模式（无需 LLM，快速体验）、LLM 模式（本地 Ollama/vLLM，高质量摘要和检索）、 Skill 编排模式（利用 AI 助手内置 LLM，无需额外配置），灵活适配不同场景。

02 / 架构

三层知识架构

文档 → 知识的三层转化，每一层都有独特的价值

📖
LAYER 01

LLM Wiki 层

将文档自动生成为可编辑的 Wiki 页面，支持 Markdown 格式。用户可人工修正内容，修改即时反向同步到检索索引，实现人机协同的知识管理。

🌐
LAYER 02

知识图谱层

自动提取文档中的实体（人物、地点、概念、代码模块等）及其关系，构建 SQLite 存储的结构化知识图谱，支持多跳关系查询和路径追踪。

🔍
LAYER 03

向量检索层

基于 sqlite-vec 和 bge-large-zh-v1.5 模型构建向量索引，实现语义级别的相似度检索，让"意思相近但用词不同"的内容也能被找到。

03 / 特性

核心特性

从知识提取到智能检索，每个环节都经过精心设计

⚡

四路并行检索

图谱检索 + FTS5 全文检索 + 向量语义检索 + Chunk 检索四路并行，通过 RRF 融合排序，多维度覆盖确保不遗漏任何相关信息。

🎯

查询意图自适应

识别 7+ 种查询类型（事实/关系/分析/结构/流程/总结/因果/比较），动态调整检索路径权重和评分策略，实现查询感知的精准检索。

📚

领域词典自动构建

基于 N-gram 频率统计 + PMI 复合词识别 + 信息熵的纯统计路径，叠加 LLM 精筛和同义词挖掘，自动挖掘领域专有名词。

🔄

人在回路 Wiki 同步

生成的 Wiki 页面可人工编辑和修正，修改通过反向同步即时反映到检索索引中，实现人机协同的持续知识优化。

🤖

Skill 编排模式

创新的 export-chapters + import-extractions 机制，让 AI 助手利用内置 LLM 进行实体关系提取，无需额外部署 LLM 服务。

🌍

中文深度优化

jieba 分词 + FTS5 预分词策略 + 同义词替换 + 停用词过滤 + 零匹配词保护，原生支持中文全文搜索，无需额外配置。

04 / 检索

四路并行智能检索

不是简单的多路合并，而是查询感知的精准检索

根据查询意图，动态选择最优检索路径

系统识别 7+ 种查询类型，为不同类型的问题分配不同的检索策略和权重， 确保每个问题都能获得最精准的答案。

图谱检索 实体匹配 + 2跳关系遍历

06 / 用法

三种交互方式

CLI、MCP Agent、Web UI —— 适配不同用户群体

💻

CLI 命令行

13 个子命令覆盖知识库全生命周期，适合开发者和高级用户快速操作。

# 初始化知识库
mwkg init my-kb

# 导入文档
mwkg import ./docs

# 查询知识
mwkg query "AuthService 依赖哪些模块"
🤖

MCP Agent

通过 MCP 协议暴露工具接口，AI 助手可直接调用知识库。

# 启动 MCP Server
mwkg agent --port 8080

# AI 助手自动调用:
# - search_knowledge
# - get_entity
# - import_documents
# - export_chapters
🌐

Web UI

基于 FastAPI + Vue.js 的完整 Web 应用，适合非技术用户。

# 启动 Web 服务
mwkg web --host 0.0.0.0

# 访问 http://localhost:8000
# 知识库管理 / 文档浏览
# 实体查看 / 图谱可视化
# 智能搜索 / 配置管理

08 / 隐私

纯本地 · 隐私优先 · 灵活部署

你的数据，永远只属于你

🔒

数据永不离开本地

所有文档、实体、关系、向量索引均存储在本地 SQLite 数据库中，无需上传到任何云端服务。

⚙

核心零外部依赖

基础检索功能仅需 Python + SQLite，无需 Elasticsearch、PostgreSQL、Milvus 等外部服务即可运行。LLM 增强功能可选配本地 Ollama/vLLM。

🏠

三种运行模式

规则模式：无需 LLM，纯统计方法快速体验；LLM 模式：本地 Ollama/vLLM 提供高质量摘要；Skill 模式：利用 AI 助手内置 LLM，零额外配置。

🗃

多知识库隔离

支持多个知识库独立管理，不同项目、不同领域的知识完全隔离，互不干扰。
