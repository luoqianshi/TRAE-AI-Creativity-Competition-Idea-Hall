Guiwei

本地优先的家庭物品定位应用。
记录物品存放位置，通过关键词搜索、导航浏览或扫码快速找到。
所有数据存储在设备本地，不上传任何信息。

核心功能特性

🏘️

五级层级结构

支持 House → Floor → Room → Container → Item 五级层级，完整模拟现实家居收纳结构

📱

多种物理输入

支持 QR 码扫码、1D 条形码识别和 NFC 近场通信，让查找物品变得直观便捷

🔍

智能搜索

支持关键词搜索（name/tags/note），实时响应，快速定位物品位置

🔒

本地优先

所有数据存储在设备本地 SQLite 数据库，无需网络连接，隐私安全有保障

📷

物理码生成

为任意层级生成 QR/NFC 码，截图保存或打印贴在实体位置，扫码直达

🗑️

软删与级联

支持软删除和级联软删，删除层级时自动处理下属所有数据，可恢复

层级 中文 必有字段 关系
House 房子 id / code / name / createdAt / updatedAt 1:N Floor
Floor 楼层 id / code / houseId / level / name N:1 House; 1:N Room
Room 房间 id / code / floorId / name N:1 Floor; 1:N Container/Item
Container 容器 id / code / roomId / name N:1 Room; 1:N Item
Item 物品 id / code / name / tags / note N:1 Container 或 N:1 Room

码标识系统

为每个层级生成物理码，实现"扫码即查"的直观体验。支持 QR 码、条形码和 NFC 标签三种格式。

📱
QR 码
最通用的码格式，相机即扫，分辨率 ≥ 512×512
guiwei://room/3f9b1c4e-7a82-4d1f-9e3a-2c5b8e6f1a4d
🏷️
1D 条形码
仓储行业标准格式，兼容现有条形码扫描仪
guiwei://item/1a2b3c4d-5e6f-7g8h-9i0j-klmnopqrstuv
📡
NFC 标签
靠近即识别，贴在抽屉外侧，无需打开即可查看内容
guiwei://container/5f4d3c2b-1a09-8g7f-6e5d-4c3b2a109876

核心使用流程

01
建立层级库
从创建第一栋房子开始，逐层建立收纳结构：House → Floor → Room → Container
02
生成物理码
为房间、容器生成 QR/NFC 码，截图保存或打印贴在实体位置
03
添加物品
手动选择位置、扫码选位置或 NFC tap，三种方式添加物品并记录详情
04
查找物品
关键词搜索、导航式浏览或扫码/NFC，三种方式快速定位物品
05
管理与维护
修改物品信息、移动位置、软删操作，支持级联删除和恢复
