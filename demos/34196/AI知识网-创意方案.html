创意名称 + 创意介绍

Project Overview

创意名称

AI知识网（AI Knowledge Net） —— 一个极简输入框，自动编织你的知识图谱。让碎片化知识自动关联、可视化呈现。

想解决什么问题

我们每天都在想、学、听、看、聊——无数碎片化的信息涌入大脑，却很少有工具能帮我们把这些零散的知识串联起来。笔记软件太重、思维导图太累、知识库太复杂。我们需要一个零门槛的方式，让每一个想法自动找到它在知识网络中的位置。

为什么会想到做这个

人类大脑天然就是网状结构——一个概念触发另一个概念，一个记忆唤起另一个记忆。但现有工具都是线性或树状的（笔记、文件夹、思维导图），无法还原大脑的真实运作方式。AI 可以理解语义、发现关联，帮我们自动构建知识网络，让"输入"和"看见"之间零距离。

大概是什么产品

一个极简 Web 应用：页面中央只有一个输入框。用户输入任何内容（想法/知识点/人名/事件/概念），AI 自动分析语义、提取实体、判断关联，将其自动添加到一张 Mermaid 知识图谱上。每个用户有一张默认主图表，也可以创建多个主题图表（如"工作知识网""读书笔记网""生活灵感网"）。

产品核心功能

Core Features
⌨️

极简输入框 · 核心交互

页面中央只有一个输入框。用户输入任何内容（一句话、一个词、一段描述），AI 自动完成后续所有工作。无需选择分类、无需手动连线，输入即入网。

🤖

AI 语义分析 · 自动关联

AI 分析输入内容的语义，提取实体（人名/地名/概念/事件），判断与现有节点的关联关系（因果/相关/包含/对比），自动在图谱上创建节点并连线。

📊

Mermaid 图表渲染

使用 Mermaid.js 实时渲染知识图谱。支持多种图表类型：flowchart（流程图）、graph（关系图）、mindmap（思维导图）。用户可切换视图模式。

🗂️

多图表管理

每个用户有一张默认主图表（"我的知识宇宙"），可创建多个主题图表（如"工作知识网""读书笔记网""项目知识网"）。不同图表之间节点可跨图表引用。

🔍

节点详情与溯源

点击任意节点，展开详情面板：显示原始输入内容、关联节点列表、创建时间、关联理由（AI 解释为什么这样连线）。支持手动调整关联。

📤

导出与分享

支持导出为 Mermaid 代码、SVG 图片、PNG 图片、Markdown 文档。可生成分享链接，让他人查看你的知识图谱（可设置公开/私密）。

用户使用流程

User Journey
STEP 1 注册与初始化
  • 注册账号（邮箱/第三方登录）
  • 系统自动创建一张默认主图表："我的知识宇宙"
  • 进入主界面，看到中央输入框和空白图谱区域
STEP 2 输入与自动入网
  • 在输入框输入任何内容（如"今天学了机器学习的梯度下降算法"）
  • AI 分析语义，提取实体："机器学习"、"梯度下降"、"算法"
  • AI 判断关联："梯度下降"属于"机器学习"的子概念，"算法"是通用类别
  • 自动在图谱上创建节点并连线，用户无需任何额外操作
STEP 3 查看与探索
  • 图谱实时更新，用户看到新节点出现在网络中
  • 点击任意节点，查看详情面板：原始输入、关联节点、AI 关联理由
  • 拖拽节点调整布局，或切换图表类型（flowchart/graph/mindmap）
STEP 4 管理与沉淀
  • 创建新图表（如"读书笔记网"），专门记录某本书的知识
  • 跨图表引用：在"读书笔记网"中引用"主图表"已有的节点
  • 导出图表为图片或代码，分享给他人或嵌入其他文档
  • 长期积累后，形成独属于你的知识宇宙

技术方案与实现思路

Technical Approach

前端与可视化

Mermaid.js React / Vue 3 TypeScript D3.js（可选增强） TailwindCSS PWA（离线可用）

AI 与语义分析

OpenAI GPT-4 / Claude NER 实体识别 关系抽取模型 Embedding 向量化 知识图谱推理

后端与存储

Node.js / Python FastAPI PostgreSQL（节点/边存储） Redis（缓存） 向量数据库（Milvus/Pinecone） JWT 认证

AI 关联判断的技术细节

输入层：用户输入文本，系统进行预处理（清洗、分词）。

实体提取：使用 NER 模型识别文本中的实体（人名/地名/概念/事件/时间等）。

关系判断：LLM 分析实体之间的语义关系，判断关联类型（因果/包含/相关/对比/时间先后等）。

图谱更新：根据分析结果，生成 Mermaid 代码，更新图表数据，前端实时渲染。

向量检索：将节点 Embedding 存入向量数据库，支持语义相似度检索，发现潜在关联。

总结

Summary

AI知识网不是又一个笔记软件，而是一个极简输入框 + 一张自动生长的知识图谱。它用 AI 替代了所有繁琐的手动操作，让知识管理真正变成"输入即入网"。

它解决了传统工具"太重、太累、看不见"的问题，用网状图谱还原大脑的真实结构，帮助用户从碎片化知识升级到系统性认知。

从技术上看，它依赖的LLM 语义分析、NER 实体识别、Mermaid 渲染都已成熟；从产品上看，它零门槛、高价值、强差异化；从意义上看，它帮助每个人编织属于自己的知识宇宙——这是可传承、可复用、可进化的个人资产。
