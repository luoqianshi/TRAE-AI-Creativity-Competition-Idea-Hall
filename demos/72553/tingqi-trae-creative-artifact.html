目标用户与痛点

听栖面向的是已经长期听歌、但无法看懂自己口味变化的人。它解决的不是“有没有歌播”，而是“推荐为什么这样、我能不能修正”。

Users & Pain

网易云重度用户

  • 长期积累了排行、红心和最近播放
  • 平台知道很多，但用户自己看不见完整画像

桌面工作/学习用户

  • 需要音乐陪伴，但不想频繁切歌
  • 不希望强歌词或过熟旋律打断专注

陷入短期循环的人

  • 最近反复听同一类歌，却不知道是不是长期口味变化
  • 想换一点，但又不想一下子跳太远

想干预推荐的人

  • 平台推荐依据不透明
  • 很难告诉系统“这个判断不准”或“这只是一时状态”

核心解决方案

听栖把网易云已有数据变成一个可操作的个人音乐解释层，重点不是替代平台算法，而是补上用户可见、可改、可验证的部分。

                用户使用路径

                这份创意 HTML 必须让评委在几分钟内看懂听栖的体验闭环，而不是看一页抽象概念海报。

                Demo Flow
                1. 授权登录 用户扫码登录网易云，听栖读取周榜、总榜、最近播放与红心歌单元数据。
                2. 看见状态 首页第一屏直接展示本周音乐状态、长期锚点和短期循环，而不是播放器。
                3. 选择迁移 用户不直接选歌，而是选择继续沉浸、轻微换轨或跳出循环。
                4. 推荐校准 系统生成带证据的推荐假设卡，用户通过播放、跳过、喜欢或否认来更新下一轮。
                创意附件中的操作按钮是前端模拟，但字段、文案与产品逻辑都对齐未来真实实现：`play / skip / like / reject_tag / freeze_tag`。

                与普通 AI DJ 的差异

                网易云负责曲库、播放和大规模推荐候选，听栖负责个人可解释层、用户校准和本地反馈闭环。

                Difference

                普通 AI DJ

                • 强调自动播歌和情绪陪伴
                • 推荐理由通常不可见或过于笼统
                • 用户反馈只体现在黑箱结果中
                • 容易落回“另一个播放器”的叙事

                听栖 TingQi

                • 强调真实数据接入后的口味解释与纠偏
                • 每个标签都有证据，每次推荐都有假设
                • 用户可以确认、否认、冻结或修正画像
                • 反馈审计明确告诉用户系统学到了什么

                MVP Demo 计划

                比赛阶段的目标不是完整生产级播放器，而是用最短路径证明产品边界、推荐解释和反馈闭环成立。

                MVP Plan
                样本数据加载与同步状态展示必须实现
                本周音乐状态面板与状态迁移动作必须实现
                口味账本、口味 Diff 与推荐假设卡必须实现
                反馈按钮、审计日志与隐私遮罩必须实现
                TTS、社区分享、多端同步本轮暂不做
                复杂训练模型与完整播放器皮肤后续再做
                最小实现原则：每个模块都要回答三个问题，它是否更能解释推荐，它是否更能让用户修正判断，它是否让下一轮推荐更可验证。

                技术可行性与隐私

                创意附件展示的是产品外观与交互蓝图；真实版本将以桌面端优先的技术路径落地，同时保持数据默认只在本机。

                Feasibility
                开发方式TRAE IDE / TRAE Work 协同完成
                桌面端优先Electron + React + TypeScript
                本地数据层SQLite 保存画像、反馈与审计
                数据接入ncm-cli 读取周榜、总榜、最近播放与红心数据
                展示安全默认开启隐私遮罩，避免公开暴露私人歌名和播放次数
                比赛提交单文件 HTML 可直接打开与上传
                本页面中的曲目名称和证据文案均为脱敏模拟，不包含任何真实账号、播放次数、token、凭证或私人原始 JSON。
