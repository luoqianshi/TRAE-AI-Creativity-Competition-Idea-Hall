01 · 创意介绍

为什么会有 CellDebate？

用一个想法，让 AI 自己跟自己「吵架」—— 这不是娱乐，而是一种全新的认知工具。

🎯

发现的痛点

单一 AI 模型存在固有偏见和知识盲区。当你向一个模型提问，你得到的只是"它的"答案，而非"更接近真相"的答案。

💡

创作动机

受人类辩论赛启发——真理越辩越明。如果让 GPT、Claude、文心一言等不同模型围绕同一议题展开辩论，会不会碰撞出更有深度的认知？

🛠️

产品形态

前后端分离的 Web 应用。用户设定辩题、选择模型、配置规则，即可观看模型之间的多轮次实时辩论。支持自定义 API 接入。

✨

独特之处

不只是"聊天机器人"，而是有辩论流程引擎的 AI 竞技场。包含开篇陈述、反驳、自由辩论、总结陈词四个阶段。

02 · 核心方案

CellDebate 如何工作？

从配置到辩论，三步即可体验 AI 巅峰对决。

STEP 01

配置辩论

输入辩题，选择 2~4 个模型，为每个模型设定角色立场，配置辩论轮次和参数。所有 API 配置集中管理，支持一键测试连通性。

STEP 02

实时观战

辩论以流式（SSE）方式实时输出，打字机动画逐字呈现。不同模型用不同颜色区分，辩论进度一目了然。

STEP 03

回顾分析

辩论结束后可浏览完整对话记录，按轮次或按模型筛选查看。支持历史辩论存档，方便对比不同模型的表现。

CORE

辩论引擎

内置完整的辩论流程引擎：开篇陈述 → 多轮反驳 → 自由辩论 → 总结陈词。每个阶段都有针对性的系统提示词。

辩论流程一览

📝 用户配置辩题 & 模型 → 🎤 开篇陈述 → ⚡ 多轮反驳 → 💬 自由辩论 → 🎯 总结陈词

04 · 价值与意义

为什么 CellDebate 值得做？

从效率提升到社会价值，CellDebate 在多个维度创造真实价值。
