一、创意名称与介绍

创意名称

本草炼丹录 —— 一款以《本草纲目》药材知识为底层体系的 Web 端互动经营游戏。

想解决什么问题

传统中医药文化博大精深，但现有的传播方式多为枯燥的文字阅读或简单的查询工具，年轻人缺乏接触和了解中草药知识的有趣途径。如何让《本草纲目》中的药材知识以有趣、互动的方式触达更多人，是本项目要解决的核心问题。

为什么会想到做这个

灵感来源于《我的世界》的工作台合成系统和经营类游戏的商业循环玩法。我想到：如果将真实的中草药知识融入"采集-合成-售卖"的游戏循环中，玩家在游戏过程中就能自然地记住药材的外观、属性和配方关系，实现"寓教于乐"。

大概是什么产品

一个纯 Web 端的互动经营小游戏。玩家在网页中浏览虚拟草药园，采摘各类中草药，通过"炼丹工作台"按照真实方剂配方合成丹药/中成药，然后在集市售卖获利，再用收益购买更多草药种子或稀有药材，形成完整的游戏循环。

在什么场景下使用

  • 碎片化时间：通勤、课间、午休时打开浏览器即玩，无需下载安装
  • 学习辅助：中医药课程学习之余，通过游戏巩固药材知识
  • 亲子互动：家长和孩子一起"采药炼丹"，在游戏中传递中医文化

当前痛点

  • 学习门槛高：《本草纲目》收录 1892 种药物，传统方式学习枯燥乏味，记忆困难
  • 缺乏互动体验：现有的中药知识网站/App 都是单向查询，无法形成主动探索和记忆
  • 文化传承断层：年轻人与传统中医药文化之间缺少有吸引力的连接方式
  • 无 Web 端同类产品：市面上类似游戏均为客户端下载版或手机 App，无法即开即玩

三、核心功能设计

🌿 草药园浏览采集

可视化药园场景，按《本草纲目》分类（草部、木部、果部等）展示不同区域。点击/拖拽采摘，获得药材放入背包。

⚗ 炼丹工作台

类似"我的世界"合成台。将药材拖入格子，按正确配方组合即可合成丹药。配方来源于真实中药方剂。

🛒 集市交易

售卖合成的丹药/中成药获取金币。不同丹药价值不同，稀有配方利润更高。

🌱 种子商店

用金币购买草药种子，种植后在药园中生长。不同种子有不同的生长周期和稀有度。

📖 本草图鉴

收集和解锁药材图鉴，展示药材的真实介绍、药性、功效等知识，逐步点亮整部《本草纲目》。

🏆 成就系统

完成特定任务解锁成就徽章，如"集齐六味地黄丸原料"、"种满百草园"等。

四、价值与意义

社会文化价值

以游戏化方式传播中医药文化遗产，让《本草纲目》从书架走入屏幕。通过互动体验降低知识门槛，使传统文化在数字时代焕发新生，尤其帮助青少年建立对中医药的基础认知和兴趣。

教育价值

寓教于乐：玩家在"采药-识药-配方-合成"的过程中，不知不觉掌握药材外观辨识、药性归类、经典方剂组成等知识。相比死记硬背，游戏化学习的记忆留存率可提升 3-5 倍。

商业潜力

  • 低门槛传播：Web 端即开即玩，无下载成本，易于社交分享和传播
  • 长线运营空间：可持续更新药材、配方、季节活动，保持内容新鲜度
  • 差异化定位：市场空白——目前无同类 Web 端本草互动游戏产品
  • 可拓展方向：后期可与中医药教育机构合作，作为教学辅助工具
