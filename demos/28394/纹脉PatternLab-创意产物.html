壹
立项缘起

传统纹样是中华文化最具辨识度的视觉语言之一，也是当下被使用率最低、被误用率最高的「沉睡资产」。 博物馆里的云雷纹、敦煌壁画里的宝相花、瓷器上的缠枝纹——它们共享同一个困境：能看，不能用。

资产形态过时

素材库以位图为主，无法放大、改色、衍生，更不支持参数化复用。

AI 直出不可控

通用绘图模型生成的「中国风」常出现对称失误、寓意错配，专业用户不敢直接拿去商用。

专业工具门槛高

Houdini / Grasshopper 能做参数化纹样，但只属于少数图形学专家，离普通设计师与文化研究者太远。

纹脉 PatternLab 的判断很直接：传统纹样不该是图片，而应该是函数。 只要把「云雷纹由 1 个母题 + 4 重对称 + 旋转角 90° 构成」这样的规则写成代码， 纹样就可以被衍生、被组合、被 Prompt 调用，也才真正具备进入现代设计与生产链路的能力。

解决方案 · 双轨驱动

平台用一套底层「纹样引擎」承载经典纹样的数学表达，对外提供两条交互轨道：专业代码轨 面向懂参数的设计师与开发者， 自然语言轨 面向所有想要「一句话生成纹样」的普通用户。两条轨道共享同一份引擎与同一份资产，输出全程一致。

专业代码模式 · 高精度衍生

面向设计师 / 开发者 / 高校师生
  1. 选择基础纹样函数（如 cloudThunder()）
  2. 调整母题、对称阶数、旋转角、笔画粗细等参数
  3. 实时 SVG 预览，支持代码片段复制与版本管理
  4. 一键导出 SVG / PNG / GLB / U3M / DXF
// 云雷纹参数化定义 function cloudThunder(p) { return rotateTile( motif: "spiral_square", symmetry: p.sym, // 对称阶 4 / 8 angle: p.angle, // 旋转 0-90° stroke: p.stroke, // 线条粗细 palette: p.palette // 朱砂 / 石青 / 石绿 ); }

自然语言 Prompt 模式 · 全民可用

面向普通用户 / 内容运营 / 非设计背景人群
  1. 用一句话描述需求（场景 + 寓意 + 风格）
  2. 大模型解析为「纹样意图」并匹配引擎函数与参数
  3. 同时生成 3 个候选方案，可微调或换一组
  4. 满意方案直接导出为可商用资产
用户原话：「我想要一个带福气寓意、暖色调、能用在手机壳上的缠枝纹」
引擎解析：纹样=缠枝莲｜寓意=福气（蝙蝠点缀）｜色调=朱砂+赭石｜画幅=手机壳竖版｜对称=连续平铺

在线小样 · 拖动即可生成

下面这个最小可玩 Demo 已经把「程序化生成」的雏形跑起来了。拖动滑杆或试试自然语言 Prompt，纹样会实时重绘。

构成法则参考： 雷纹 取商周青铜器「方折回旋的双钩方螺旋单元 + 镜像连续带」构图； 宝相花 取唐代金银器与敦煌藻井「八瓣多层径向对称（尖瓣 / 圆瓣 / 卷草瓣 / 花蕊）」构图； 回纹 取标准希腊键纹与中国「富贵不断头」回字纹「凹」字单元横向连续带构图。

本 Demo 使用本地规则解析，正式版接入大模型后语义理解将更精准。
