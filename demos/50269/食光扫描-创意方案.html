创意介绍

食光扫描是一款基于 AI 视觉识别的健康饮食管理 Web 应用。用户只需对着餐盘拍一张照片，系统即可在数秒内识别菜品、估算热量与营养成分，并结合个人档案自动计算「今日还能吃多少」。

想解决什么问题：传统饮食记录需要手动查表、逐条输入，门槛高、难坚持；很多人想控热量却不知道自己到底吃了多少。

灵感来源：身边减脂和健康管理的同学，每次吃饭都要打开多个 App 查热量、记份量，过程繁琐且容易放弃。我们希望用「拍照即记录」的方式，把饮食管理变得像发朋友圈一样简单。

产品形态：移动端优先的 Web 应用（React + FastAPI），支持拍照/相册上传、个人热量预算、饮食记录与周趋势分析。

用户使用流程

1
设置个人档案
填写身高、体重、活动量与目标（减脂/维持/增肌），系统自动计算每日热量预算。
2
拍照识别
餐前拍一张照，AI 识别菜品名称、热量及蛋白质/碳水/脂肪/纤维等营养数据。
3
调整 & 保存
选择餐次，通过滑块微调份量（50%~200%），一键保存到饮食记录。
4
查看看板 & 趋势
首页查看剩余热量，记录页浏览近 7 天热量折线图，持续追踪饮食变化。

目标用户与痛点

  • 核心用户：有减脂、控糖、增肌需求的年轻白领；关注健康但嫌传统记饮食太麻烦的人群。
  • 使用场景：工作日午餐、外卖点餐、家庭聚餐后，想快速了解这顿饭吃了多少热量。
  • 当前痛点：手动查食物数据库耗时、份量难估、多道菜合计麻烦；记了几天就放弃，缺乏「还能吃多少」的即时反馈。

价值与意义

⚡ 效率提升

将「查表 + 输入 + 计算」压缩为「拍一张照」，单次记录从 3~5 分钟缩短至 10 秒内，显著降低坚持门槛。

💚 社会价值

帮助更多人建立科学的饮食意识，减少因信息不对称导致的盲目节食或过量摄入，促进全民健康管理。

技术方案

前端采用 React 18 + TypeScript + Tailwind CSS，后端 FastAPI + SQLite，AI 识别接入阿里云百炼 qwen3-vl-plus 视觉大模型，支持多道菜识别与置信度提示。
