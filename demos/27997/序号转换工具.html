序号转换工具 - 使用方法

一、字符提取功能（左侧）

1. 输入数据：在文本框中每行输入一组数据，支持数字、字母、符号混合内容，无长度限制。

2. 设置范围：在"从第X位"和"到第X位"输入框中填写要提取的字符位置（从1开始计数）。

3. 点击提取：点击蓝色"提取"按钮，系统会批量处理所有数据，结果以表格形式展示。

4. 操作按钮：

- 导入序号转换（绿色）：将提取结果自动导入右侧序号转换功能

- 复制输入（灰色）：复制原始输入的所有数据

- 复制输出（橙色）：复制提取结果的汇总（逗号分隔）

5. 清空：点击输入框右上角的"清空"按钮，可快速清除所有输入和结果。

二、序号转换功能（右侧）

1. 输入序号：在文本框中每行输入一个序号，支持换行、空格、逗号、分号等多种分隔方式。

2. 选择分隔符：点击分隔符按钮选择输出格式（逗号、分号、竖线、空格、顿号、换行、自定义）。

3. 转换：点击蓝色"转换为横向格式"按钮，生成横向排列的结果。

4. 复制结果：点击绿色"复制结果"按钮，将转换后的内容复制到剪贴板。

5. 清空：点击输入框右上角的"清空"按钮，清除输入和结果。

三、快捷键

- Ctrl + Enter：在输入框中按此快捷键可直接触发提取或转换操作

四、使用示例

场景1 - 提取编码：

输入：A1B2C3D4E5 / X9Y8Z7A6B5
提取第3-6位 → 结果：2C3D / 8Z7A

场景2 - 序号转换：

输入：13818 / 13819 / 13820
选择逗号分隔 → 结果：13818,13819,13820
