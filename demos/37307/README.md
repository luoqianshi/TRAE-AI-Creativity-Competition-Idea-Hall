# 教案叙事工坊

> 让每一节课都成为动人的故事

## 📌 项目简介

**教案叙事工坊**是一款面向师范生与中小学教师的叙事化备课助手，区别于普通教案生成器，不再只罗列教学目标，而是生成一整节课堂教学剧本。

本项目参加 **TRAE全民AI创造力大赛 - 学习工作赛道**，旨在通过AI技术将传统教案转化为生动的课堂叙事，让备课更有温度，让教学更有故事。

## ✨ 核心功能

### 1. 智能输入
- **学段选择**：小学低年级、小学中年级、小学高年级、初中、高中
- **科目选择**：语文、数学、英语、科学、道德与法治、历史、地理、物理、化学、生物
- **课文题目**：自由输入课文或知识点名称
- **课时时长**：20分钟（微课）、40分钟、45分钟、90分钟（双课时）

### 2. 五大生成板块

#### 📖 课堂情景导入
- 情景创设方案
- 开场白设计
- 多种导入方式（情境导入、问题导入、故事导入）

#### 🎯 故事主线梳理
- 开端：导入阶段
- 发展：探究阶段
- 高潮：实践阶段
- 结局：总结阶段

#### 🎮 课堂互动小游戏
- 知识接龙
- 角色扮演
- 抢答竞赛
- 时长控制建议

#### ❓ 递进式提问清单
- 基础层：激活经验
- 理解层：检测理解
- 应用层：促进迁移
- 拓展层：激发创新

#### 📝 板书设计大纲
- 总-分-总结构
- 知识脉络呈现
- 学生生成性内容记录
- 核心要点区域

### 3. 实用功能
- **一键生成**：快速生成完整教案叙事
- **复制文本**：一键复制所有内容到剪贴板
- **清空内容**：重置所有输入和输出

## 🎨 设计特色

### 视觉风格
- **柔和书香配色**：浅米色(#FDF8F3) + 青蓝色(#7EC8C8) 主色调
- **卡片式布局**：圆角卡片设计，视觉层次分明
- **舒适字体**：思源宋体 + 思源黑体，护眼阅读体验

### 交互体验
- **翻页动画**：生成结果时带有优雅的翻页效果
- **平滑滚动**：页面内平滑导航
- **加载状态**：生成过程中的视觉反馈
- **表单验证**：智能提示必填项

## 🛠️ 技术栈

- **前端框架**：原生 HTML5 + CSS3 + JavaScript
- **CSS框架**：Tailwind CSS (CDN)
- **字体服务**：Google Fonts (Noto Serif SC, Noto Sans SC)
- **设计模式**：单页应用 (SPA)

## 🚀 使用方法

### 在线预览
1. 在浏览器中打开 `index.html` 文件
2. 或部署到任意静态网站托管服务

### 操作步骤
1. 点击"开始创作"进入备课输入区
2. 选择学段、科目，填写课文题目和课时时长
3. 点击"一键生成"按钮
4. 查看五大板块的生成结果
5. 使用"复制文本"导出内容

## 💡 创新点

### 1. 叙事化备课理念
突破传统教案生成的框架，将教学设计转化为一个完整的故事，让教师备课更有代入感。

### 2. 五维一体设计
从情景导入到板书设计，覆盖课堂教学的完整流程，形成闭环的教学设计体系。

### 3. 递进式提问系统
基于布鲁姆认知分类学，设计四个层次的提问，促进学生思维发展。

### 4. 游戏化教学元素
融入课堂互动游戏设计，提升学生参与度和学习兴趣。

### 5. 可视化板书设计
提供结构化的板书设计框架，帮助教师清晰呈现知识脉络。
