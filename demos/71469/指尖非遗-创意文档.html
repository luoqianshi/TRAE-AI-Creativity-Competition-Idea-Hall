指尖非遗

TRAE AI 创造力大赛创意文档
赛道：非遗创新创意开发 类型：创意互动 / 公益服务 形态：Web 互动体验平台

一、创意名称 + 创意介绍

创意名称

指尖非遗

想解决什么问题

非遗技艺承载着中国传统文化的精髓，但多数人只能在视频里"看"非遗，无法亲身体验制作过程；线下的非遗体验工坊门槛高、覆盖窄、成本高，年轻人和偏远地区用户很难接触到。我们希望让用户足不出户就能"动手"参与非遗创作，把"观看式传播"升级为"参与式传播"。

为什么会想到做这个

非遗传播一直存在"看得多、做得少"的痛点——短视频让更多人看到了非遗的美，但看完就划走了，记忆不深。我们想做一款让用户从"看客"变成"匠人"的产品，让非遗不止于被欣赏，更能被亲手创造，从而真正记住并爱上它。

大概是什么产品

一个基于浏览器的 Web 互动体验平台，用户可在线模拟剪纸、扎染、漆扇、皮影等多种非遗技艺的制作流程，配合操作记录生成专属作品并分享传播。

二、目标用户及痛点

面向哪些用户

  • 18-35 岁对传统文化感兴趣的年轻群体（大学生、文化爱好者、国风受众）
  • 中小学文化课教师（需要非遗教学素材）
  • 非遗传播机构与文旅景区（需要数字化互动展品）

在什么场景下使用

  • 课余/休闲时间，体验一段 5-10 分钟的非遗制作流程
  • 课堂教学中，老师演示非遗技艺过程，学生跟做
  • 文旅场景下，游客扫码体验当地非遗项目

当前痛点

  • 线下体验工坊：地域受限、价格不低、项目单一
  • 短视频/纪录片：只能看不能动手，记忆与情感投入有限
  • 现有非遗数字产品：多为静态图文或视频，互动性弱，难以形成传播裂变

三、价值与意义

社会价值 — 让非遗从"被看见"走向"被参与"

通过低门槛的在线互动体验，让原本小众、稀缺的非遗技艺触达更广泛的人群，尤其是年轻人。当用户亲手"做出"一张剪纸、一把漆扇，他们对非遗的情感连接与传播意愿会显著增强，有助于非遗的活态传承。

效率提升 — 降低非遗体验与教学的成本

将线下需要场地、材料、传承人讲解的体验流程，转化为浏览器即可完成的互动产品。对老师而言，节省备课与组织成本；对传播机构而言，可批量复用、快速部署到多场景，是文旅与教育数字化的有效补充。

四、核心创意与产品方案

核心理念

"操作即作品" — 用户的每一次剪、染、绘都被真实记录并成为最终作品的一部分，而非 AI 重绘的"套壳结果"。这与非遗"手作"精神高度契合，也让用户获得真正的创作者感。

MVP 首发方向：剪纸

在剪纸、扎染、漆扇、皮影四个候选方向中，首发选择剪纸，理由：

  • 技术门槛最低（2D 操作，Canvas/SVG 即可实现）
  • "折叠→剪→展开"的揭晓瞬间天然有传播力（类似盲盒机制）
  • 折叠是对称的，用户即使剪得乱，展开后也容易"看起来不错"——容错率高，新手友好

自由创作范围

  • 工艺步骤：固定引导（折叠次数、剪刀工具、展开动作）
  • 图案纹样：用户自由发挥（剪的位置、形状完全由用户决定）
  • 每个用户的作品都不同，但都符合剪纸的基本工艺逻辑

核心交互流程

[折叠] → [剪裁] → [展开揭晓] → [作品保存] → [图鉴解锁] │ │ │ │ │ │ │ │ │ └ 解锁该技艺卡片 │ │ │ └ 导出图片+操作回放 │ │ └ 核心爽点:对称变换动画揭晓 │ └ 看不见最终效果,只在折叠状态下操作 └ 选择折叠方式(对折/田字折/六角折等)
核心爽点：剪的过程中用户看不见展开后的效果，只在折叠状态下看到剪痕；点击"展开"瞬间，Canvas 做对称变换 + 短动画 → 揭晓成品。这一刻是产品的情感高潮，也是传播的关键时刻。

五、用户留存机制

收集 + 成就体系

  • 每完成一种非遗技艺，解锁对应图鉴卡（含技艺介绍、传承人、历史沿革）
  • 同一技艺内通过图案库 + 难度分级 + 主题挑战扩展可玩性
    • 主题示例：十二生肖系列、节日系列、节气系列
  • 目标：用同一技艺（剪纸）撑起 20+ 次不同体验，而非急着铺品类

轻社交（不依赖账号体系）

  • 每周限时主题挑战（如"本周主题：龙年剪纸"）
  • 作品墙 + 点赞（分享链接即可参与，无需登录）

六、内容准确性保障方案

三层内容结构

第 1 层：固定权威内容（不可改）
· 技艺名称、历史沿革、工艺步骤、传承谱系
· 来源：中国非物质文化遗产网官方条目（https://www.ihchina.cn）
· 标注：[内容来源：中国非遗网，链接]
第 2 层：AI 生成内容（可标识）
· 技艺介绍拓展、趣味知识、配图
· 标注：[AI 辅助生成，仅供参考]
第 3 层：用户创作内容（用户自己做的）
· 用户剪的图案、命名的作品
· 标注：[用户创作，非非遗原作]

数据源（已确认可用）

  • 中国非物质文化遗产网（ihchina.cn）— 官方非遗项目名录
  • 中国非遗数字博物馆 — 图文资料
  • 国家级非遗代表性项目名录 — 按编号查询

风险规避

  • 不自创非遗知识，所有事实类内容必须有出处链接
  • 用户作品明确标注"创作"而非"非遗原作"，避免误导
  • 页面底部声明："本产品旨在传播非遗文化，工艺步骤参考公开资料，如内容有误欢迎反馈"

七、技术实现概要

技术栈（匹配"会一点前端"的技术基础）

  • 前端：HTML5 Canvas + JavaScript（剪纸核心交互）
  • AI 能力：TRAE IDE 辅助生成动画代码、操作录制逻辑、API 调用
  • 数据：content.json 结构化存储非遗内容（分层标注来源）
  • 部署：静态站点即可，可托管于任意免费平台

关键技术点

  • Canvas 操作录制（记录用户剪裁轨迹）
  • 对称变换动画（展开揭晓效果）
  • 操作回放与图片导出
  • 图鉴系统数据结构

八、开发路径规划

阶段 1：MVP 验证（剪纸核心交互）

  • 完成折叠→剪→展开→保存的核心流程
  • 验证"展开揭晓"爽点是否成立
  • 整理剪纸权威内容卡片

阶段 2：内容与留存

  • 图鉴系统 + 主题挑战
  • 作品墙与分享
  • 内容准确性自检清单落地

阶段 3：品类扩展（视情况）

  • 评估是否新增扎染/漆扇等其他技艺
  • 复用核心框架，扩展数据

九、风险与应对

风险 应对
内容准确性被质疑 三层内容结构 + 来源标注 + 反馈声明
用户做完即走 主题挑战 + 收集体系 + 轻社交
技术门槛 剪纸 2D 操作难度低 + TRAE IDE AI 辅助
单一技艺乏味 同技艺内做深度（图案库/难度/主题）而非横向铺品类
