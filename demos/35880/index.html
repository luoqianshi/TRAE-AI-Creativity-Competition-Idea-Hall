03 / FULL-BOOK ANALYSIS

五级流水线全书分析

从语义分块到实体追踪、事实抽取、记忆分层、卡片生成——五级流水线逐层提炼，证据门禁确保每一步都有据可依。

L1

语义分块

按场景边界将章节原文切分为语义块（Semantic Block），保留句子重叠和 hash 指纹，支持增量重算。

L2

实体提及与共指

从语义块中抽取人物、地点、组织等实体提及（Mention），通过共指消解（Coreference）合并为稳定实体。

L3

原子事实抽取

基于语义块和实体上下文，抽取带证据引用的原子事实（Atomic Fact），每条事实可溯源至原文 quote。

L4

记忆分层

对事实做三维分类（时间跨度/重要性/性质），压缩稀释记忆为摘要，保留重要长期记忆的完整细节。

L5

卡片生成与探针

生成人物卡、世界观卡、总纲等候选卡片，同时规划文章探针主动验证一致性，证据不足的字段被门禁拦截。

🛡️
证据门禁：证据不足的字段不会被覆盖到正式设定，避免无证据污染。

06 / PROBE

文章探针机制

不依赖被动向量检索，基于长期记忆主动规划、定向搜索特定文本区域，验证伏笔回收、实体状态一致性和世界规则遵守。

🎯

伏笔回收探针

追踪早期埋下的伏笔，验证后续章节是否合理回收，确保叙事闭环。

伏笔定位→定向验证→一致性判定
👤

实体状态探针

追踪角色境界、身份、位置等状态变化，检测跨章节的状态跳跃和矛盾。

状态追踪→差异检测→冲突报告
🌍

世界规则探针

验证当前情节是否遵守已建立的世界观规则，标记异常和特殊设定。

规则匹配→异常标记→规则例外
🤝

监控角色间关系变化，验证敌对/同盟/师徒等关系的转变是否有铺垫。

关系时间线→变化验证→铺垫检查
