# 信用卡权益管家

一款帮助用户管理多张信用卡权益的应用，让用户能够清晰了解每张卡的权益详情、使用时间和剩余额度，智能推荐当日最优权益使用方案。

## 功能特点

### 1. 卡片管理
- 添加新卡片（支持8家主流银行）
- 卡片列表展示（精美的信用卡设计）
- 删除卡片功能
- 卡片详情查看

### 2. 权益同步
- 自动同步银行权益数据
- 手动同步按钮
- 单卡权益同步功能

### 3. 今日权益推荐
- 根据当前日期智能筛选可用权益
- 按剩余次数排序推荐
- 立即使用按钮

### 4. 其他权益推荐
- 显示非今日可用的权益
- 标注下次可用日期
- 权益详情查看

### 5. 额度管理
- 显示总额度和已用额度
- 进度条可视化额度使用情况
- 卡片详情页展示完整额度信息

### 6. 卡面展示
- 精美信用卡设计（EMV芯片、银联标志、NFC图标等）
- 多种卡面颜色可选
- 悬停动画效果

## 使用方法

1. 双击打开 `信用卡权益管家.html` 文件
2. 即可在浏览器中直接使用
3. 数据会自动保存在浏览器本地存储中

## 预置示例卡片

应用已预置3张示例卡片供体验：
- 招商银行经典白金卡
- 工商银行牡丹白金卡
- 浦发银行AE白

## 技术特点

- 纯HTML/CSS/JavaScript实现，无需安装任何软件
- 数据存储在浏览器本地（LocalStorage）
- 响应式设计，支持桌面和移动设备
-精美的UI设计和流畅的动画效果
