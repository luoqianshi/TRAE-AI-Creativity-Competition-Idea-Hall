痛点分析

👴

老人孤独与数字鸿沟

  • ✓ 中国60岁以上老人已达3.2亿，超1亿独居
  • ✓ 90%以上老人不会使用智能手机复杂功能
  • ✓ 子女在外工作，老人情感陪伴缺失
  • ✓ 传统娱乐方式单一，精神生活匮乏
🎭

非遗传承危机

  • ✓ 超50%非遗项目面临传承人断层
  • ✓ 年轻人对传统技艺缺乏兴趣和认知
  • ✓ 传承方式传统，缺乏现代化传播手段
  • ✓ 非遗作品缺乏市场渠道，难以变现

我们的解决方案：用AI技术同时解决两大社会问题，让老人获得陪伴，让非遗获得新生
