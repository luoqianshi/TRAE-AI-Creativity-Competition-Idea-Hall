💡 创意介绍

🤔 想解决什么问题？

作为大气科学专业的学生，日常需要观看大量中英文双语网课（如气象动力学、数值天气预报、卫星遥感等课程）。网课往往没有字幕或文字稿，遇到重点内容只能反复暂停、手动记录，一节课下来笔记零散且耗时。现有工具要么只能录音，要么只能翻译，无法将"听课-转录-整理笔记"的 workflow 打通。

灵感来源：在学习《数值天气预报》网课时，老师讲解的公式推导和物理过程非常密集，暂停记笔记就会漏听下一段。希望能有一款工具自动将网课语音转为文字，并一键保存到笔记，让我专注理解而不是机械记录。

产品形态：一款浏览器扩展（Chrome/Edge），专为网课学习场景设计，集成语音转文字、整页翻译、划词查词、笔记导出四大模块，打造"听课即记录"的智能学习助手。

🚀 核心功能模块

🎤

语音转文字 (STT)

捕获浏览器任意标签页音频，通过 Whisper API 实时转录为文字。支持 1x/2x/4x/8x 倍速播放加速识别，切标签页不中断，视频静音也能录。

支持所有网站
🌐

整页翻译

一键翻译整个网页，采用 textContent 替换技术不破坏 DOM 结构。支持分块翻译 + 断点续翻，大页面也能流畅处理。

一键还原原文
✂️

划词翻译

选中任意文字即弹出智能工具栏，支持即时翻译、记入笔记。工具栏位置可拖拽，自动适应页面布局。

选词即出
📝

IMA 笔记集成

STT 结果和翻译内容一键保存到 IMA 知识库（ima.qq.com），支持导出 TXT、复制剪贴板，构建个人知识管理体系。

知识沉淀

🏗️ 技术架构

基于 Chrome Extension Manifest V3 构建，采用 Service Worker + Offscreen Document 架构：

Chrome Extension MV3 Service Worker Offscreen Document tabCapture API Whisper API OpenAI Compatible API IMA OpenAPI React + TypeScript

🔧 技术亮点

  • Offscreen Document：解决 Service Worker 无法使用 MediaRecorder 的限制，实现后台持续录音
  • 自动保活机制：录制/识别期间自动防止 Service Worker 被浏览器回收
  • 最高 z-index 弹窗：识别进度弹窗 z-index 设为 2147483647，确保不被任何页面元素遮挡
  • 配置迁移：支持老用户配置自动迁移到新版本
  • 多 Provider 支持：OpenAI / Gemini / OpenRouter / 自定义 API 统一接入
