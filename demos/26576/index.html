// PAIN POINTS

程序员的四大健康困境

长期沉浸编码的代价，远比你想象的严重

时间感知消失

进入心流状态后完全忽略时间流逝，连续编码数小时不起身，久坐导致腰酸背痛、颈椎劳损。

眼疲劳加剧

长时间盯着屏幕，眨眼频率骤降，干眼症、视力模糊频发，蓝光伤害持续累积。

饮水严重不足

专注编码时忘记喝水，日均饮水量远低于健康标准，脱水影响思维敏捷度和代码质量。

休息效率低下

普通计时器粗暴打断思路，没有适配开发间隙的放松方案，休息反而增加认知负担。

// CORE FEATURES

四大核心功能模块

专为编码场景设计的智能健康助手

SMART TIMER

智能编码节奏计时器

基于 AI 感知编码活跃度，自动匹配工作节奏。在代码提交、编译等待等自然间隙柔性提醒休息，绝不粗暴打断思路。

  • 检测键盘/鼠标活跃度判断编码状态
  • 在编译/测试等待间隙触发休息提醒
  • 自定义番茄钟 / 52-17 / 自由模式
HEALTH DASHBOARD

健康数据可视化看板

实时追踪每日编码时长、休息次数、饮水记录、疲劳指数，生成周报月报，用数据驱动健康习惯养成。

  • 每日/每周/每月编码时长统计
  • 疲劳峰值检测与健康评分
  • 数据导出与趋势分析
RELAX GUIDE

程序员专属放松教程

提供 1-5 分钟碎片化放松方案，涵盖颈椎拉伸、眼部放松、肩背活动、深呼吸练习，专为工位场景设计。

  • 1 分钟快速眼部放松操
  • 3 分钟工位颈椎拉伸指南
  • 5 分钟正念呼吸冥想
AI ASSISTANT

AI 健康建议引擎

基于编码行为数据，AI 智能分析疲劳模式，个性化推荐休息方案，随编码习惯进化持续优化建议策略。

  • 学习个人编码节奏，自适应提醒
  • 根据时段推荐不同放松方案
  • 与 Vibe Coding 工作流深度集成
