一套键鼠，
连接两种系统。

CrossKey 是一款运行在局域网中的跨平台键鼠与剪贴板协同工具，让用户使用 Mac 的键盘和触控板无缝控制 Windows，减少多设备学习、开发和办公中的频繁切换。

Problem

多设备并不等于
高效率

在跨平台开发、课程学习、内容创作和专业软件使用场景中，Mac 与 Windows 往往同时存在，但设备之间仍然是割裂的。用户不得不反复切换输入设备和传递内容，打断专注状态。

⌨

两套键鼠占用空间

桌面设备繁多，手臂频繁移动，长期操作容易造成疲劳，也增加误操作概率。

⇄

内容传递步骤繁琐

代码、命令、网址和文字常借助聊天软件或云盘中转，简单复制也变成多步操作。

◫

远程桌面过于沉重

传统远程桌面需要传输画面，对网络和带宽要求更高，不适合近距离双机协同。

Users & Scenarios

为真实的双机工作流设计

CrossKey 重点服务同时使用 Mac 与 Windows 的人群，将两台独立电脑连接成一个更自然的协作工作空间。

软件开发者Mac 编写代码，Windows 运行、调试或验证兼容性。
学生与实验室一台设备查阅资料，另一台运行课程实验或专业软件。
设计与内容创作跨系统调用软件、素材和文件，减少设备切换。
多设备办公用户在有限桌面空间内，用一套熟悉的输入设备完成工作。
Solution

不传画面，
只传必要的输入

CrossKey 通过局域网建立轻量连接：Mac 捕获键盘和鼠标事件，经认证后发送到 Windows，由 Windows 模拟输入；同时支持纯文本剪贴板双向同步。

Mac 输入端

捕获用户操作

  • 键盘按下与释放事件
  • 触控板移动与左右点击
  • F8 快捷键切换控制模式
  • Command 到 Ctrl 的习惯映射
UDP 5051 · 自动发现Windows 广播地址，Mac 自动搜索，无需反复手动填写 IP。
HMAC 挑战认证 · 六位配对码配对码不直接在网络中发送，用于确认可信设备身份。
TCP 5050 · JSON 事件协议稳定传输键鼠事件，并支持断线后的自动发现与重连。
双向纯文本剪贴板默认在控制模式中同步，并设置最大文本大小限制。
Windows 接收端

还原输入行为

  • 接收并校验输入事件
  • 模拟键盘、鼠标操作
  • 广播局域网服务地址
  • 显示连接和认证状态
Current Progress

已经完成的
可运行原型能力

以下能力已经在当前 CrossKey 仓库中实现。项目并非只有概念，而是具备安装、配对、连接、控制、诊断和测试流程的技术原型。

FEATURE 01

键鼠实时转发

Mac 键盘、触控板移动和鼠标点击通过 TCP 发送到 Windows。

FEATURE 02

快捷键一键切换

按 F8 在本机模式与 Windows 控制模式之间快速切换。

FEATURE 03

局域网自动发现

Windows 通过 UDP 广播服务，Mac 自动获取地址并连接。

FEATURE 04

安全配对认证

使用六位配对码和 HMAC 挑战认证，配对码不在网络中明文传输。

FEATURE 05

文本剪贴板同步

支持 Mac 与 Windows 纯文本双向同步，并限制最大同步大小。

FEATURE 06

断线自动恢复

网络短暂中断或 Windows 重启后，Mac 自动尝试重新发现和连接。

FEATURE 07

连接诊断工具

提供网络、端口、自动发现和配对状态检查，降低配置门槛。

FEATURE 08

测试与打包

包含协议、认证、配置、发现等单元测试，并支持两端单文件打包。

Value

把“设备切换”
变成“模式切换”

CrossKey 的价值不在于替代所有远程控制工具，而是专注解决同一桌面、同一局域网内的双机协同，让用户始终使用自己最熟悉的输入设备。

旧

传统双机操作

  • 准备并摆放两套键盘鼠标
  • 复制文本需要聊天软件或云盘中转
  • 远程桌面传输画面，体验偏重
  • IP 变化或断线后需要重新配置
新

CrossKey 协同体验

  • 一套 Mac 键盘与触控板控制两台电脑
  • 文本剪贴板在双端直接同步
  • 仅传输入事件，局域网内轻量低延迟
  • 自动发现、认证、断线重连和诊断
让用户专注于正在完成的任务，而不是把时间浪费在设备之间。
