## 一、Demo 简介

**院内智能康复训练系统**是一款面向脑卒中、脊髓损伤、术后运动功能障碍患者的医院场景康复方案。系统将康复训练严格限定在医院康复科、神经内科、骨科病房内，由康复医师制定处方、康复治疗师执行训练、护士现场巡视，外骨骼与 AI 系统负责实时动作辅助、风险预警和数据记录，形成“人机协同、医护兜底”的院内智能康复新模式。

本 Demo 是一个**可交互的 HTML 产品原型**，你可以：

- 查看基于真实互联网数据的行业背景（卒中患者、康复人才缺口、住院跌倒风险、外骨骼市场规模）；
- 切换 4 种康复训练模式（被动/主动助力/主动阻力/镜像训练），实时观察外骨骼运动、关节角度和助力扭矩变化；
- 触发“疲劳预警”和“跌倒防护”安全场景，查看三级安全防护如何联动响应；
- 与 AI 语音助手对话，体验训练指导、疲劳关怀、异常处理和正向激励；
- 查看医生/护士监护面板、系统架构和参赛信息。

## 二、Demo 创作思路

### 灵感来源

我国脑卒中、脊髓损伤等导致运动功能障碍的患者已突破千万。央视网报道，我国现有脑卒中患者近 1500 万人，每年新发病例约 330 万人，约 80% 留有不同程度残疾。然而，康复医疗资源严重短缺：康复医师占基本人群比例仅 0.4:10 万，远低于发达国家 5:10 万；全国康复治疗师总数不足 10 万人，每 10 万人口仅为国际标准的 1/4。与此同时，住院患者跌倒风险突出，全国二级以上医院住院患者跌倒/坠床发生率为 0.48‰，单例跌倒平均额外支出 12600 元。

面对这些数据，我们希望打造一款在医院可控环境中，由医护人员全程监护、智能设备辅助执行的康复训练系统，既放大治疗师服务能力，又最大程度保障患者安全。

### 核心设计

本作品的核心思路是 **“人机协同、医护兜底、数据驱动”**：

- **人机协同**：外骨骼和 AI 语音承担动作辅助、训练引导、风险提示，治疗师和护士负责方案执行、现场监护和应急处置；
- **医护兜底**：所有训练在医院内进行，医生制定处方，护士评估跌倒风险，急救设备和医护人员随时待命；
- **数据驱动**：训练数据实时上传医院数据中心，与 HIS/EMR 对接，支持疗效评估和临床研究。

### 技术亮点

| 模块 | 方案 |
|------|------|
| 动作捕捉 | IMU + 视觉/光学 + 足底压力多源融合，健侧带动患侧的镜像学习 |
| 外骨骼控制 | 被动/主动助力/主动阻力/镜像四种模式，柔顺阻抗控制避免二次损伤 |
| 安全防护 | 失衡预警 → 紧急制动 → 气囊防护三级联动 |
| 生理监测 | 心率、血氧、皮电实时监测，异常时自动降强度并告警 |
| AI 语音 | 本地 ASR + 云端大模型，承担教练、安全员、陪伴者和数据桥梁 |
| 数据合规 | 院内局域网部署，国密加密，医疗数据不出院 |

- 通过 TRAE Work 生成完整方案规划，包括：

## 五、项目价值

### 社会价值

- 帮助脑卒中、脊髓损伤、术后患者在医院获得持续、专业、个性化的康复训练；
- 显著降低院内康复训练中的跌倒和二次损伤风险；
- 缓解康复医疗资源紧张，一名治疗师可同时监护多名患者；
- 提升老年人/残障人群的生活质量，具有强烈的智慧助老和社会公益意义。

### 商业价值

- 设备销售/租赁 + 按次服务 + 数据服务的多元化收入模式；
- 面向医院康复科、神经内科、骨科等科室，采购需求明确；
- 可对接医保收费项目和长护险，提升可及性。
