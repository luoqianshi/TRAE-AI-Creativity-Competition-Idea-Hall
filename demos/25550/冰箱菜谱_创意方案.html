01 — The Problem

每天最难的不是做饭，是"想做什么"。

现状
😩

传统菜谱 App 的反人类逻辑

  • "菜谱找食材"——先选菜，再发现缺这少那，只能放弃或跑超市
  • 只能按菜名搜索，可"不知道菜名"才是真正的痛点
  • 按分类翻浏览，十几分钟也翻不到合适的
  • 食材快过期了也不知道能做什么，最后只能扔掉
  • 外卖 App 一打开就赢了——做饭的门槛被无限抬高
冰箱菜谱
🧊

把逻辑反过来：食材找菜谱

  • 勾选冰箱里现有的食材，系统立刻给出能做的菜
  • 按匹配度排序，100% 匹配的菜优先展示
  • 不用知道菜名，告诉它"我有什么"就够了
  • 标注还缺哪些食材、能否替换，缺一门也能做
  • 快过期的食材优先匹配，减少浪费省钱又环保
02 — Core Features

三种找菜方式，总有一种适合你。

核心亮点
Feature 01
🧊

冰箱模式

勾选手边有的食材，系统按食材匹配度从高到低推荐菜谱。这是冰箱菜谱的灵魂功能——让食材反过来推荐菜谱。

匹配度 = 已选食材 ∩ 菜谱食材 ÷ 菜谱总食材数
Feature 02
🔍

关键词搜索

直接搜菜名，比如"番茄炒蛋"。适合已经知道想吃什么的用户，是最基础也最高效的找菜方式。

query → 模糊匹配 title / desc / 食材
Feature 03
🎛️

条件筛选

按难度、耗时、分类、排序多维筛选，精准定位想要的菜谱。

难度 · 耗时 · 分类 · 热度 / 评分 / 收藏

06 — Value & Meaning

不止是菜谱，是减少浪费的生活方式。

30s
⚡

效率提升

Efficiency First

把"想菜谱"这个每天耗时 10–30 分钟的决策过程压缩到 30 秒以内。用户只需勾选食材，系统立刻给出按匹配度排序的候选菜谱，并标注还缺哪些食材、能否替换——让做饭决策从"翻找"变成"选择"。

0浪费
🌱

社会价值

Less Waste, More Care

减少家庭食物浪费。中国家庭每年因"不知道怎么做"而扔掉的食材数量惊人。冰箱菜谱通过精准匹配，让每一份食材都能找到归宿，既省钱又环保，呼应"光盘行动"和节约粮食的社会倡议。
