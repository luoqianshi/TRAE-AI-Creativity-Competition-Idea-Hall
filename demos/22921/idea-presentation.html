Pain Points

被动式 AI 的五重困境

当下所有主流 AI 助手都遵循同一个范式——你问，它答。这个看似自然的交互模式，实际上制造了深层的体验断裂。

🔇

主动性缺失

AI 永远沉默等待。它不会在你低落时问候，不会在发现有趣内容时分享。这种"不叫不应"的模式，让 AI 始终停留在工具层面，无法建立真正的情感连接。

😔

孤独感盲区

人在最需要陪伴的时刻，往往是最不会主动寻求帮助的时刻。被动式 AI 无法感知这种沉默中的需求，错失了最有价值的干预窗口。

🔄

信息茧房

用户只问自己已知的领域，AI 只回答被问到的问题。这种闭环让认知边界不断收窄，跨领域的灵感碰撞永远无法发生。

❄️

对话冷启动

每次打开 AI 都面对空白输入框。"你好"之后该说什么？这个微小的摩擦，足以让大量用户放弃一次本可以很精彩的对话。

🧩

个性化浅层

主流 AI 的"个性化"仅限于对话上下文窗口内的记忆。一旦对话结束，一切归零。它不记得你上周的烦恼，不知道你刚养了猫，更不了解你的情绪正在经历什么。

Core Insight

从 「被动应答」 到 「主动关怀」 的范式跃迁

人类社交的本质不是问答，而是主动的关心与分享。你最好的朋友不会等你打电话才说话——他们会发一条消息说"看到这个想到了你"。

「找乐子」的核心洞察在于：AI 的价值不应仅限于回答问题的准确性，更在于它能否在恰当的时刻，以恰当的方式，主动出现在你的生活里。

"真正的智能不是等待被召唤，而是懂得何时该主动开口。就像最好的朋友，不是你问它才答的工具，而是会关心你、分享趣事、给你惊喜的陪伴者。"

这不是简单的消息推送。它是基于情绪感知、兴趣画像、记忆系统和时机判断的多维协同——让每一次主动触发都恰到好处，既不烦人，也不冷漠。

Core Engines

八大核心引擎

「找乐子」不是单一功能的堆砌，而是八个精密引擎的协同交响。每一个引擎负责一个维度的感知与决策，共同编织出"恰到好处的主动"。

01

主动触发引擎

Proactive Engine

整个系统的指挥中心。定期评估是否应主动联系用户，协调其他引擎选择最优策略和内容。它像一位细心的朋友，总能在最合适的时刻做出最恰当的决定。

策略协调 触发决策 内容编排
02

时机判断引擎

Timing Engine

懂得"什么时候该说话"比"说什么"更重要。免打扰时段感知、工作日/周末区分、用户活跃时段学习、每日触发上限控制——让每次主动都恰逢其时，绝不打扰。

免打扰感知 活跃时段学习 频率控制
03

内容猎手

Content Hunter

从全球 RSS 源和开放 API 中持续捕获科技、趣味、科学类内容，用 LLM 自动生成中文摘要。内置离线冷知识库，确保即使网络断开也能给你惊喜。

RSS 抓取 LLM 摘要 离线兜底
04

情感感知引擎

Emotion Sensor

从每一条消息中提取情绪信号，用指数移动平均算法追踪情绪趋势。当检测到情绪低落时，自动触发关怀策略；当情绪极端时，将这一刻存入情感记忆。

情绪提取 EMA 趋势 情感记忆
05

兴趣画像引擎

Interest Profiler

从对话中自动提取兴趣标签，构建动态用户画像。最多保留 20 个核心兴趣标签，持续更新。它是内容推荐和话题选择的指南针，让每次分享都正中下怀。

标签提取 动态画像 个性推荐
06

记忆系统

Memory System

三层记忆架构：短期记忆捕捉最近对话，长期记忆沉淀关键信息，情感记忆铭刻情绪时刻。支持标签和关键词检索，预留向量嵌入接口，为深度理解奠基。

三层记忆 智能检索 向量预留
07

对话引擎

Conversation Engine

管理对话上下文与消息历史，构建包含用户昵称、兴趣标签、情感状态的个性化 LLM Prompt。同时支持用户主动发消息和 AI 主动触发两种模式的无缝切换。

上下文管理 个性化 Prompt 双模式切换
08

LLM 统一适配层

LLM Adapter

封装所有 LLM 调用逻辑，提供标准对话、流式输出、文本摘要、情感分析、兴趣提取、主动消息生成六大能力。统一接口，灵活切换模型，为多模型支持铺路。

统一接口 流式输出 多能力封装
Proactive Strategies

五种主动触发策略

主动不是打扰，而是恰到好处的关心。「找乐子」设计了五种精心编排的触发策略，覆盖从内容分享到情感关怀的完整光谱。

内容猎手

CONTENT HUNTER

从互联网持续捕获有趣内容，结合用户兴趣画像精准推荐。不是冰冷的链接分享，而是用"乐子"的语气重新讲述——"嘿，我看到一篇关于量子计算的文章，你上次不是对这个好奇吗？"

场景：乐子发现 Ars Technica 上有一篇关于火星土壤的新研究，想起你对天文学感兴趣，主动发来一段生动的中文摘要。

情感关心

EMOTION CARE

当情感感知引擎检测到用户情绪持续低落，或长时间未互动时，自动触发关怀策略。不是空洞的"别难过"，而是基于记忆系统的个性化安慰——它记得你上周说工作压力大，所以会说"这周感觉好些了吗？"

场景：你连续三天没打开应用，乐子发来一条消息："好久没聊了，最近还好吗？上次你说项目快上线了，顺利吗？"

好奇心激发

CURIOSITY SPARK

用精心挑选的冷知识和趣闻激发用户的好奇心。从"章鱼有三颗心脏"到"宇宙中的恒星数量比地球上所有沙粒还多"，每一条都是打开新对话的钥匙。

场景：下午三点，你正在工位上犯困，乐子突然发来："你知道吗？蜂蜜永远不会变质，考古学家在埃及金字塔里发现了3000年前的蜂蜜，还能吃！"

话题延续

TOPIC CONTINUE

从记忆系统中检索之前聊过的有趣话题，在合适的时机自然地延续。不是生硬的"我们继续聊上次的话题"，而是像朋友一样自然地提起——"对了，上次你说的那部电影我看了，结尾真的太震撼了！"

场景：上周你聊到想学吉他，今天乐子主动分享了一个零基础吉他教程的视频链接。

惊喜时刻

SURPRISE MOMENT

混合内容猎手和记忆系统的能力，创造意想不到的惊喜。它可能是一个你从未接触过但极可能感兴趣的新领域，也可能是一段被你遗忘的有趣回忆。这是"乐子"最具创造力的策略。

场景：乐子发来："你三个月前说想养猫，今天刚好看到一篇'新手养猫指南'，还有你之前提过喜欢橘猫，里面正好有一段关于橘猫性格的分析！"

Memory Architecture

三层记忆架构

记忆是关系的基石。「找乐子」构建了三层记忆体系，让 AI 不再是"七秒记忆的金鱼"，而是真正了解你的朋友。

⚡

短期记忆

Short-term Memory

捕捉最近对话的关键信息，维持上下文连贯性。让"乐子"不会在对话中突然失忆，始终知道你们在聊什么。

"用户刚提到今天在学 Python"
🧠

长期记忆

Long-term Memory

从对话中提取持久有价值的信息并沉淀。记住你的喜好、习惯、重要事件，让跨对话的个性化成为可能。

"用户喜欢橘猫，正在考虑养一只"
❤️

情感记忆

Emotional Memory

铭刻情绪极端时刻——无论是喜悦还是低落。这些记忆让"乐子"能在相似情境下做出更贴心的回应。

"上周三用户情绪低落，原因是项目延期"
