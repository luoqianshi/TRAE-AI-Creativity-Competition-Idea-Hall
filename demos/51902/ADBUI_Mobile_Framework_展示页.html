ADBUI Mobile Framework

基于 TRAE + ADB 的轻量级 Android UI 自动化测试框架

零配置 JSON 驱动 安全模式 自动生成报告

核心能力

截图 & UI XML 观察

自动抓取手机屏幕截图和 UI 层级 XML，完整记录每一步操作后的页面状态。

坐标点击 & 滑动

支持精准坐标点击、多方向滑动操作，覆盖常规 UI 交互场景。

文本输入 & 按键

支持文本输入和系统按键（返回、首页、搜索等），模拟真实用户操作。

App 启动

通过包名一键启动目标 App，无需手动操作手机。

页面断言

支持文本存在/不存在断言、Activity 匹配断言，自动验证页面状态。

安全模式

点击前自动检测风险控件（加购、支付、删除等），防止误操作导致损失。

快速开始

1. 观察当前页面

# 单独使用底层脚本 .\trae_phone.ps1 -Action observe

2. 执行 JSON 测试用例

# 执行冒烟测试 .\run_mobile_tests.ps1 -CasePath .\cases\smoke_observe.json # 执行京东只读探索测试 .\run_mobile_tests.ps1 -CasePath .\cases\jd_iphone_readonly.json # DryRun 模式（只校验不操作手机） .\run_mobile_tests.ps1 -DryRun

3. JSON 用例示例

{ "name": "jd_iphone_readonly", "description": "京东 App iPhone 搜索链路只读探索", "safeMode": true, "steps": [ { "name": "启动京东", "action": "start", "package": "com.jingdong.app.mall" }, { "name": "点击搜索框", "action": "tap", "x": 520, "y": 145 }, { "name": "输入 iphone", "action": "text", "value": "iphone" }, { "name": "确认搜索结果", "action": "assertText", "text": "iphone" } ] }

每次执行自动生成 run.log、results.json 和 report.html，包含每一步的执行状态、耗时、截图和 UI XML。

框架对比优势

  • vs Appium：无需安装 Node.js/Java/驱动，仅需 ADB 即可运行，配置成本降低 90%
  • vs 原生脚本：JSON 驱动用例，非开发人员也能编写和维护测试场景
  • vs 其他工具：内置安全模式，自动拦截风险操作，让自动化测试更安心

适用场景

  • 新功能上线前的快速冒烟测试
  • 回归测试中验证核心链路是否正常
  • 探索式测试中批量检查页面状态和文本内容
  • 日常开发中快速定位 UI 问题
  • 只读自动化测试（避免触发加购、支付等风险操作）
