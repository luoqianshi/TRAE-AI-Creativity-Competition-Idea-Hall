§ 07 · ROADMAP

待改进项 · 下一阶段路线图

基于代码分析的高优先级改进点。
🔐

数据库初始化互斥锁

避免 initDB 被多个 hook 并发调用导致数据库连接状态混乱，已在 db/index.ts 实现 Promise 队列。

PRIORITY · HIGH
🧩

代码拆分 App.tsx

当前主 App.tsx 承载过多逻辑（搜索/过滤/标签/收藏夹/AI 调用），建议抽为独立 hooks + 子组件。

REFACTOR · MID
🖼️

大图片存储优化

剪贴图片直接存 base64 会让 IndexedDB 体积膨胀，建议写入 filesystem API / userData 目录，DB 仅保存路径与缩略图。

PERF · HIGH
⌨️

全局快捷键冲突检测

electron 注册 globalShortcut 失败时静默降级，缺少 UI 提示用户修改冲突键，需要在 Settings 面板增加检测。

UX · MID
🛰️

多端同步（可选模块）

把 db/clips 导出为 delta JSON，通过 WebDAV / iCloud Drive 同步，不影响本地优先架构。

FEATURE · LOW
⚙️

构建产物精简

180MB exe 对便携分发略大。开启 asar 压缩 + 仅打包必要 binary（去掉 Tesseract 训练数据选项），可降到 ~90MB。
