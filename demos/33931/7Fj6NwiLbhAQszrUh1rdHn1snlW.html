GPoseSensei

FF14 集体动作 (GPose) 摄影辅助插件
提供构图参考线、天气时间控制、画面分析与 AI 点评功能

安装说明

Overview

GPoseSensei 是一个基于卫月框架 (Dalamud) 的《最终幻想14》辅助插件。它不修改任何游戏内的动作或骨骼数据，仅在 GPose 模式下提供纯 UI 层的构图辅助线、静态画面参数分析以及基于大语言模型的截图点评，作为摄影后期的前置辅助工具。

Features

[01] COMPOSITION

构图辅助线

在游戏画面上叠加三分线、黄金螺旋、对角线、十字线等参考线。支持鼠标拖拽调整，提供 21:9、1:1 等比例遮罩，用于辅助预览裁剪效果。

[02] ANALYSIS

快照与参数分析

截取当前画面进行数据分析。提取主色调，生成明暗直方图、RGB 直方图和矢量示波器。同步记录截图时的天气、时间、FOV 等环境参数。

[03] AI_REVIEW

AI 截图点评

接入大语言模型（需配置 API Key）。可将快照与拍摄意图发送给 AI，获取基于画面内容的基础评分和改进建议文本。

[04] ENVIRONMENT

天气与时间控制

在 GPose 模式下自由修改当前的环境天气与时间。支持冻结时间以锁定完美的光影氛围，绝不干扰正常游戏和探索体验。

[05] SETTINGS

自定义配置

辅助线为独立渲染层。支持自定义线条颜色、透明度和粗细，并支持绑定局部快捷键，用于在拍摄过程中快速切换构图模式。

Instructions

  • 01

    安装插件

    在卫月框架 (Dalamud) 插件管理器中搜索 GPoseSensei 并完成安装。

  • 02

    开启 GPose

    在游戏聊天框输入 /gpose 进入集体动作模式。

  • 03

    调整构图线

    打开插件设置面板，选择构图类型。勾选“解锁构图线”后，可用鼠标拖拽线条；按住 Shift 键可吸附居中。

  • 04

    分析与点评

    在面板点击“开始快照分析”生成直方图等数据。如需 AI 点评，可填入备注并点击“发送给 GPoseSensei 分析”。

  • 05

    环境控制

    在设置面板中开启“天气与时间覆盖”，可自由切换天气并滑动调整艾欧泽亚时间 (ET)，获取完美拍摄光影。
