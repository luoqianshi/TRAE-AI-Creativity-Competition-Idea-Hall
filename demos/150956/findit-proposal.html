01 · 问题背景

磁盘空间，被不知不觉蚕食

C 盘红了，却不知道哪个目录占得最多、哪些能删、删完会不会又涨回来。面对成百上千个文件夹，用户根本无法判断每一个的用途与去留。

🔴

空间不可见

系统自带工具只能看到总体占用，无法下钻到目录层级，空间消失得无声无息。

迷失

用途不可知

成百上千的文件夹，是系统组件？游戏缓存？还是开发产物？用户无从判断。

⚠️

删除不可决

删了会不会崩系统？会不会丢数据？删完会不会自动重建涨回来？决策成本极高。

02 · AI 解决方案

让 AI 成为语义通才

LLM 了解各系统组件、构建缓存的命名惯例，能把磁盘清理从"用户单挑"变成"用户 + AI 协作"。扫描引擎算空间，AI 判可删性，用户做最终决策。

01

扫描引擎

高速遍历文件系统，精确计算每个目录的空间占用，构建可持久化的结构化数据。

02

AI 语义研判

LLM 识别目录用途与风险等级，给出"可删 / 谨慎 / 保留"建议与重建说明。

.gradle .m2 .ivy2 node_modules
03

用户决策

AI 提供建议与依据，用户掌握最终删除权——AI 不越权，只赋能。

LLM 知道这些"潜规则"

大模型在训练中吸收了海量技术文档、社区问答与工程实践，天然掌握各类缓存目录的语义：

  • node_modules — npm 依赖，删后 npm install 可重建
  • __pycache__ — Python 字节码缓存，可安全删除
  • .gradle / .m2 / .ivy2 — 构建工具缓存，按需清理
  • WinSxS — Windows 组件存储，需专用工具清理
  • Steam appcache — 游戏缓存，不影响存档
