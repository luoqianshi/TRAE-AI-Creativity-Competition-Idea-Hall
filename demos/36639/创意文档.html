📋 项目背景

随着中国社会老龄化程度不断加深，空巢老人、独居老人的数量持续增加。根据第七次全国人口普查数据，中国60岁及以上人口已达2.64亿，占总人口的18.7%。

虽然市面上存在各种智能助手（如小爱同学、天猫精灵等），但这些产品往往功能过于繁杂，交互方式复杂，不够"有温度"，难以真正满足老年人的情感陪伴需求。

✨ 核心功能

💬

语音聊天

  • ✓ 长按说话，松开自动发送
  • ✓ AI情感化回复，像子女一样温暖
  • ✓ 三种声音模式：儿子/女儿/默认

示例：
用户：我想孩子了
AI：爸，我们也都很想您！有空多视频聊聊，看到您我们就放心了 ❤️

📸

家庭相册

  • ✓ 温馨的家庭照片浏览界面
  • ✓ AI自动描述照片内容
  • ✓ 语音讲述照片背后的故事

示例：
AI：这是去年春节拍摄的全家福，我们一家人团聚在一起，每个人都笑得很开心。

  • ✓ 午间关怀（天气提醒、午餐建议）
  • ✓ 晚间祝福（晚安、适当活动）
