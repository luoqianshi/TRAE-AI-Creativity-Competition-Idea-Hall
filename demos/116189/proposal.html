项目简介

「鱼遇」是一款面向水族爱好者群体的一站式微信小程序，集水族用品商城与鱼友交流论坛于一体。用户可以在平台上浏览和选购专业的水族器材、鱼粮、装饰品等商品，同时也能在社区板块中发帖交流养鱼经验、求助鱼病诊断、分享鱼缸造景作品。

💡核心价值：降低新手入坑门槛，连接分散的鱼友社群，打造一个「买得到好货、聊得到行家」的水族生态平台。

项目背景

⚠ 行业痛点

  • 新手缺乏专业知识，容易购买到低质量、不匹配的水族产品
  • 鱼友交流分散在微信群、贴吧等平台，缺乏专业的移动端社区
  • 线下水族店价格不透明，选择有限，缺乏用户评价参考

✨ 我们的方案

  • 基于微信小程序打造轻量级水族商城，降低用户使用门槛
  • 内置鱼友论坛，按板块分类讨论，沉淀优质养鱼经验
  • 商城+社区一体化设计，实现「边买边学」的闭环体验

中国水族爱好者群体超 3000万，年市场规模超 100亿元，且持续增长中。

整体架构

Client

小程序客户端

Uni-JS / 微信小程序

API

SpringBoot 后端

Controller - Service - Mapper

Data

数据持久层

MySQL + Redis + 阿里云OSS

架构说明： 系统采用前后端分离架构。前端使用微信小程序原生框架配合 Uni-JS 进行跨端开发，通过 HTTP 请求与后端 API 交互。后端基于 Java SpringBoot 框架，采用经典的 Controller - Service - Mapper 三层架构，Controller 负责路由转发与参数校验，Service 处理业务逻辑，Mapper 通过 MyBatis 操作数据库。数据层使用 MySQL 8.0 存储核心业务数据，Redis 作为热点数据缓存（如帖子列表、热门商品），阿里云 OSS 负责存储用户上传的图片和商品图片。

技术栈

WX

客户端

微信小程序 + Uni-JS

使用微信小程序原生框架开发，借助 Uni-JS 提升跨端兼容性。通过微信授权实现免登录，提供流畅的移动端购物与社区体验。

SB

后端框架

Java SpringBoot (TRAE-IDE)

基于 SpringBoot 2.x 构建后端服务，采用 TRAE-IDE 进行 Java 代码编写，利用 AI 辅助快速生成接口代码、优化代码质量。

DB

数据库

MySQL 8.0 + Redis

MySQL 8.0 存储用户、商品、帖子等核心数据。Redis 作为缓存层，加速热门内容加载，降低数据库压力。

ECS

服务器

阿里云 ECS (CentOS 7)

使用阿里云 ECS 云服务器部署后端服务，CentOS 7 环境运行 Jar 包，配置 Nginx 反向代理实现域名访问与负载均衡。

OSS

对象存储

阿里云 OSS

阿里云 OSS 负责存储用户上传的图片（帖子配图、商品图片等），通过 CDN 加速图片访问，保障加载速度。

功能模块

商城模块

  • 1 微信授权登录 — 一键授权，免注册快速体验
  • 2 商品分类浏览 — 鱼缸/过滤/灯光/鱼粮/装饰品等分类
  • 3 商品详情 — 图文详情、规格参数、用户评价
  • 4 购物车 — Demo阶段仅展示购物车功能，不做支付

论坛模块

  • 1 发帖功能 — 支持文字+图片富文本内容发布
  • 2 板块分类 — 新手求助 / 鱼缸造景 / 鱼儿疾病 等
  • 3 评论回复 — 支持楼中楼回复，构建讨论链
  • 4 热门帖子 — 基于浏览量/回复数推荐热门内容

部署方案

阿里云 ECS 服务器

CentOS 7 环境部署 SpringBoot Jar 包，通过 Nginx 反向代理提供 API 服务，配置域名与 SSL 证书。

阿里云 OSS 对象存储

存储商品图片、用户头像、帖子配图等静态资源，配合 CDN 加速分发，降低服务器存储压力。

MySQL 数据库 + Redis 缓存

MySQL 8.0 存储业务数据，Redis 缓存热点数据（热门帖子、商品列表等），提升接口响应速度。
