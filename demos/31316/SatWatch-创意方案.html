SatWatch 卫星守望

抬头仰望，知道每一颗星的名字

基于 Orekit 轨道力学引擎的卫星过境预测与轨道可视化工具。
输入你的位置，即可看到头顶卫星的实时位置、未来过境时间与最佳观测窗口。

1. 创意介绍

想解决什么问题：天文爱好者、学生想知道"今晚头顶有哪些卫星经过、什么时间、朝哪个方向看"，但现有工具要么太专业（需要理解轨道六根数），要么信息不直观（只有文字表格），普通人难以使用。

为什么会想到做这个：每次看到夜空中移动的光点，都会好奇"那是 ISS 吗？还是星链？"——这种好奇心是普遍的，但把好奇心变成确定答案的门槛太高了。我熟悉 Orekit 轨道计算库，想把这个专业能力变成人人可用的产品。

产品形态：Web 网站（PC + 移动端自适应），无需安装，打开即用。

🔍

发现难

不知道什么时候有卫星过境，错过最佳观测时机

📐

门槛高

📊

不直观

2. 目标用户及痛点

  • 天文爱好者：在晴朗夜晚想观测卫星过境，但不知道准确时间和方位。当前只能靠零散的社交媒体信息或英文网站，信息滞后且不精准。
  • 中小学教师：在科学课/天文社团中想带学生观测卫星，但缺乏直观的教学工具。当前只能用文字描述，学生难以理解轨道运动。
  • 航天科普工作者：需要在科普活动中展示卫星实时位置和轨道，但专业软件界面复杂，不适合公众展示。

使用场景：晴朗傍晚，用户打开 SatWatch，自动定位后看到一张"星空图"——天穹极坐标投影上标注了未来2小时所有可见卫星的轨迹线、出现时间和方位。点击 ISS 轨迹，弹出详细过境信息：22:13 从西北方升起，22:18 达到最高点（海拔65°），22:23 从东南方消失，亮度 -3.2 等，肉眼可见。

4. 价值与意义

📚 教育价值

将抽象的轨道力学变成可触摸、可交互的体验。学生不再只是背诵开普勒三定律，而是亲眼看到卫星如何沿椭圆轨道运动、过境时间如何随观测位置变化。从"知道"到"看见"，是认知的飞跃。

🌐 社会价值

降低航天科普门槛，让更多人"抬头看天"。在光污染日益严重的城市，一次 ISS 过境的观测体验，可能就是一个孩子走向科学之路的起点。SatWatch 让这种体验不再依赖运气，而是精准可期。

5. 技术方案

后端基于 Orekit 轨道力学库进行 SGP4 轨道传播与过境预测计算，前端使用 Three.js 自定义渲染 3D 地球与卫星轨迹。

Java + Spring Boot Orekit 轨道力学 Hipparchus 数学库 SGP4/SDP4 传播器 TLE 轨道数据 React + TypeScript Three.js 3D 渲染 Vite 构建
