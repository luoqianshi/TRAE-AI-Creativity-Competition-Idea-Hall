1 二次函数顶点式 · 基础巩固 ⭐ 基础
将二次函数 y = 2x² - 8x + 5 化为顶点式，并写出顶点坐标和对称轴。
顶点式：y = 2(x - 2)² - 3
顶点坐标：(2, -3)
对称轴：x = 2
2 一元二次方程判别式 · 基础巩固 ⭐ 基础
关于 x 的方程 x² - (k+3)x + 2k = 0 有两个不相等的实数根，求 k 的取值范围。
Δ = (k+3)² - 8k > 0
k² + 6k + 9 - 8k > 0
k² - 2k + 9 > 0
(k-1)² + 8 > 0 恒成立
∴ k 为任意实数
3 等腰三角形证明 · 能力提升 ⭐⭐ 中等
已知：在△ABC中，AB=AC，点D、E分别在AB、AC上，且AD=AE。
求证：∠BDC = ∠CEB。
证明：
∵ AB=AC，AD=AE
∴ BD=CE（等量减等量）
又∵ AB=AC，AD=AE
∴ △ADC≌△AEB（SAS）
∴ DC=EB
又∵ BC=CB
∴ △BDC≌△CEB（SSS）
∴ ∠BDC=∠CEB
4 因式分解 · 规范训练 ⭐⭐ 中等
因式分解（要求写出完整步骤）：
(1) 3x³ - 12x
(2) x²y - 4xy + 4y
(1) 3x³ - 12x = 3x(x² - 4) = 3x(x+2)(x-2)
(2) x²y - 4xy + 4y = y(x² - 4x + 4) = y(x-2)²
5 二次函数解析式 · 计算训练 ⭐⭐ 中等
已知二次函数图像经过点 (0,3)、(1,0)、(3,0)，求该函数的解析式，并计算当 x=2 时的函数值。
设 y = a(x-1)(x-3)
代入 (0,3)：3 = a(-1)(-3) = 3a → a=1
∴ y = (x-1)(x-3) = x² - 4x + 3
当 x=2：y = 4 - 8 + 3 = -1
6 二次函数综合 · 拔高挑战 ⭐⭐⭐ 困难
抛物线 y = x² - 2x - 3 与 x 轴交于 A、B 两点（A在B左侧），与 y 轴交于点 C。点 P 在抛物线上，且 S△PBC = S△ABC，求点 P 的坐标。
A(-1,0), B(3,0), C(0,-3)
S△ABC = 1/2×4×3 = 6
设 P(m, m²-2m-3)
BC直线：y = x-3
P到BC距离 = |m-(m²-2m-3)-3|/√2 = |m²-3m|/√2
1/2×√18×|m²-3m|/√2 = 6
解得 m=0（舍，即C点）或 m=3
或 m=0, m=3 之外还有 m=-1, m=4
∴ P(4,5) 或 P(-1,0)（即A点）
