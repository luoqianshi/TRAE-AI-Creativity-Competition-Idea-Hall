技术方案

极简架构，极速开发

整个产品不需要后端，不需要数据库，不需要 AI API

前端 HTML / CSS / JavaScript 打包 Vite + TypeScript 动画 CSS Keyframes + GSAP 部署 Vercel / GitHub Pages 分享 Canvas → PNG 导出
数据层 本地 JSON 词库文件，每类配方 200+ 精选词条，总计 3600+ 词条。支持用户自定义扩展词库。
逻辑层 纯前端随机选择引擎，带「避免连续重复」的智能随机算法。锁定功能通过状态标记实现。
交互层 CSS 动画驱动老虎机滚动效果，无依赖渲染。GSAP 仅用于入场动画增强。
分享层 Canvas API 将结果渲染为 1080×1920 分享卡片，用户可一键下载为 PNG。
MVP 工期 核心功能 1 名前端工程师 × 5-7 天可完成。词库编辑需额外 2-3 天。
