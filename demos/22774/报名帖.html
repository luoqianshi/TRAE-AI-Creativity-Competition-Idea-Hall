一、创意名称 + 创意介绍

创意名称

天才计划（Genius Plan）—— 几何-视觉解耦的两阶段 3D Gaussian Splatting 训练框架

想解决什么问题

当前 3D Gaussian Splatting（3DGS）技术虽然渲染效果惊艳，但存在一个根本性的矛盾：视觉质量要求高斯自由生长（离开表面、表达体积效果），而物理碰撞要求高斯严格贴在物体表面（才能建水密 Mesh 做碰撞检测）。用同一套高斯同时满足这两个互相矛盾的目标，既做不出好看的渲染，也做不出可靠的物理仿真。

为什么会想到做这个

这个想法来自一个完全没有游戏引擎背景的人，从"什么是 Mesh"开始提问，在没有任何参考资料的情况下，通过纯粹的逻辑推导独立发现的。核心洞察极其简单：如果两个需求互相矛盾，那就没有理由用同一套表示去满足它们——分开是唯一自然的解。这个设计模式游戏行业花了十多年才沉淀成共识，但在这里它被从第一性原理重新推导了出来。

大概是什么产品

一个面向稀疏视图 3D 重建的双阶段训练框架：第一阶段用强几何约束训练"碰撞高斯"并提取碰撞 Mesh；第二阶段释放约束训练"视觉高斯"自由生长。渲染时两套高斯一起画，碰撞时只用第一阶段的 Mesh。最终输出同时支持高质量实时渲染和物理引擎碰撞检测。

当前痛点

如果没有这个产品，用户现在面临的是二选一的困境：

  • 用 3DGS 做渲染 → 效果好看，但没有碰撞几何，无法做物理交互
  • 用传统 Mesh 重建 → 能做碰撞，但稀疏视图下纹理区重建好、平坦区空洞多，视觉质量差
  • 现有方案（如 SuGaR）试图让高斯贴表面 → 虽然能提 Mesh，但牺牲了 3DGS 最擅长的体积效果和自由表达能力

用户被迫在"好看"和"能碰"之间做选择，没有一个框架能同时做好两件事。

四、方案详情

核心洞察

视觉质量和碰撞精度对高斯的要求是互相矛盾的。
前者需要高斯自由生长（离开表面、体积效果、半透明过渡），
后者需要高斯严格贴在物体表面上（才能建水密 Mesh 做碰撞检测）。

没有理由用同一套高斯去满足两个互相矛盾的目标。
分开是唯一自然的解。

关键技术组件

  • 边缘特征点 SfM：用 LSD 线段检测替代传统角点，让初始点云天然落在物体边界
  • 边界约束 Densification：Canny/Sobel 边缘 mask 限制高斯只在表面增密
  • 碰撞 Mesh 提取：Poisson Surface Reconstruction 从 80k 表面高斯建水密 Mesh
  • 两套高斯协作：collision_enabled 布尔标记天然解耦，渲染时一起画，碰撞时只用 Mesh

未解决的开放问题（坦率承认）

  • 边缘特征点 SfM 的匹配歧义：切线方向有天然歧义
  • 平坦区域密度不足：白墙、桌面等无纹理表面覆盖不够
  • visual 高斯在碰撞 Mesh "外侧"的合理性：需保证不穿透内部
  • Stage 1 冻结后视觉质量上限：部分表达能力被锁死
