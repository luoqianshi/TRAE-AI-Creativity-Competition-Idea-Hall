# 错题本 - 智能错题管理系统

一个功能完整的网页版错题本应用，支持题目识别、错题管理、搜索和导出功能。

## 功能特性

### 1. 错题本管理
- 创建、编辑、删除错题本
- 支持多个错题本分类管理
- 错题本列表展示

### 2. 题目识别系统
- **相机拍照**：使用设备相机直接拍摄题目
- **相册选择**：从本地相册选择图片
- **OCR识别**：集成第三方OCR服务识别图片中的文字
- **多引擎支持**：支持多个OCR引擎，提高识别准确率
- **手动编辑**：识别结果可手动修正

### 3. 错题管理
- 添加、编辑、删除题目
- 支持图片上传（多张）
- 题目文本编辑
- 错误原因标签（计算错误、概念不清、审题不仔细等）
- 批注功能

### 4. 搜索功能
- 全文搜索题目内容
- 搜索批注和错误原因
- 实时搜索结果展示

### 5. 导出功能
- **PDF导出**：生成PDF文档
- **Word导出**：生成DOCX文档
- **HTML导出**：生成网页格式
- **Markdown导出**：生成Markdown文档
- **JSON导出**：导出原始数据

### 6. 本地存储
- 使用IndexedDB进行本地数据存储
- 数据持久化，无需服务器
- 支持大量数据存储

## 技术栈

- **前端框架**：纯JavaScript（Vanilla JS）
- **UI框架**：原生CSS
- **数据存储**：IndexedDB
- **OCR服务**：OCR.space API（可替换为其他服务）
- **导出库**：
  - jsPDF（PDF导出）
  - docx（Word导出）

## 快速开始

### 1. 克隆或下载项目

```bash
git clone <repository-url>
cd MistakeCloud
```

### 2. 直接打开

直接在浏览器中打开 `index.html` 文件即可使用。

### 3. 使用本地服务器（推荐）

```bash
# 使用Python
python -m http.server 8000

# 使用Node.js
npx http-server

# 使用PHP
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`

## 使用说明

### 创建错题本

1. 点击右上角的 "+ 新建错题本" 按钮
2. 输入错题本名称和描述
3. 点击"创建"按钮

### 添加题目

1. 选择一个错题本
2. 点击 "+ 添加题目" 按钮
3. 上传图片或使用相机拍照
4. 点击"识别文字"进行OCR识别
5. 编辑识别结果
6. 选择错误原因
7. 添加批注
8. 点击"保存"

### 编辑题目

1. 点击任意题目查看详情
2. 点击"编辑"按钮
3. 修改题目内容、错误原因或批注
4. 点击"保存"

### 搜索题目

1. 点击右上角的搜索图标
2. 在搜索框中输入关键词
3. 实时查看搜索结果

### 导出错题本

1. 选择一个错题本
2. 点击"导出"按钮
3. 选择导出格式（PDF、Word、HTML、Markdown、JSON）
4. 等待导出完成

## 配置OCR服务

默认使用OCR.space API，需要配置API密钥：

1. 在 `ocr.js` 文件中找到：
   ```javascript
   this.apiKey = 'YOUR_OCR_API_KEY';
   ```

2. 替换为你的OCR.space API密钥

3. 获取API密钥：
   - 访问 [OCR.space](https://ocr.space/)
   - 注册账号
   - 获取免费API密钥

### 支持的OCR服务

- OCR.space（默认）
- Tesseract.js（需要引入库）
- Google Vision API（需要配置密钥）

## 数据模型

### 错题本
- id: 唯一标识
- name: 错题本名称
- description: 描述
- createdAt: 创建时间
- updatedAt: 更新时间

### 题目
- id: 唯一标识
- bookId: 所属错题本ID
- questionText: 题目文本
- errorReason: 错误原因数组
- annotations: 批注
- images: 图片数组
- createdAt: 创建时间
- updatedAt: 更新时间

## 常见问题

### Q: OCR识别不准确怎么办？
A: 
1. 确保图片清晰，光线充足
2. 使用"重新识别"功能
3. 手动编辑识别结果
4. 尝试不同的OCR引擎

### Q: 数据会丢失吗？
A: 数据存储在浏览器的IndexedDB中，清除浏览器数据会删除所有数据。建议定期导出备份。

### Q: 可以在手机上使用吗？
A: 可以，支持响应式设计，在移动设备上也能正常使用。

### Q: 相机无法使用？
A: 
1. 确保在HTTPS环境或localhost下运行
2. 检查浏览器相机权限
3. 某些浏览器可能需要用户交互才能访问相机
