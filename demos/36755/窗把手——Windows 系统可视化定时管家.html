01

创意名称 + 创意介绍

从一个睡前的小摩擦，到一个值得被填补的体验缺口

想解决什么问题

定时关机、定时重启是几乎所有 Windows 用户都会遇到的高频需求，但至今没有一个优雅的解决方案。用户要么去记 shutdown /s /t 3600 这样的命令行指令，要么在层层嵌套的系统设置里翻找。

灵感来源

睡前想设定电脑在播放助眠音乐 30 分钟后关机，却发现没有一个直观的方式完成这件事。明明是再简单不过的需求，却要打开命令行输入一串参数。

产品形态

一款 Windows 桌面端的可视化定时关机/重启管理程序，支持场景化建议与直观交互，让定时管理从"需要查教程"变成"一看就会"。

02

目标用户及痛点

那些被忽视的日常场景，那些本可以更简单的事

夜生活群体

深夜助眠音视频/下载文件，希望设定倒计时自动关机，不用熬夜等待。

高效工作者

长时间运行任务（渲染、编译），完成后需要自动重启，释放系统资源。

午休办公族

午休或离开工位，希望电脑定时启停，省电又省心。

家长用户

希望管理孩子电脑使用时间，定时关机帮助养成健康的使用习惯。

没有可视化入口

Windows 不提供直观的定时关机、重启界面，用户必须使用命令行或深度设置。

没有场景感知

系统不会根据使用时间、运行状态等给出任何建议，用户全靠经验判断。

操作门槛高

shutdown /s /t 对普通小白或入门用户不友好，且无法中途直观查看倒计时或修改计划。

03

价值与意义

不只是效率工具，更是数字生活的体验升级

效率提升

用拖拽、点选等自然交互替代命令行操作，让定时关机/重启从"需要查教程"变成"一看就会"。同时基于场景（深夜、下载中、长时间未重启等）给出个性化建议，帮助用户更合理地管理电脑状态，减少因忘记关机导致的电量浪费或因长期不重启导致的系统卡顿。

社会价值

定时关机/重启是几乎所有 Windows 用户都会遇到的需求，但这个高频场景长期处于"能用但不优雅"的状态。"窗把手"填补的是一个被忽视的大众需求——让每一位 Windows 用户都能用最自然的方式管理自己的设备，降低数字生活的操作门槛。
