01

记录今天发生了什么

输入行为、持续时间、当时目的、结束后情绪，也可输入被批评、拖延、争吵、完成任务等情绪事件。

02

分析奖励结构

系统不只问“花了多久”，而是评估奖励质量、刺激强度、恢复成本、延迟收益、注意力碎片化与精神熵值。

03

生成多巴胺主权表盘

把高质奖励比例、高耗散奖励比例、恢复资产、注意力债务、主要熵源等信息压缩到一个可视化界面。

04

给出低熵行动建议

不是宏大目标，而是立即可执行的 10 分钟动作，让用户用微小调整减少噪音、恢复秩序、积累主动选择感。

为什么现代人需要奖励结构账本

现代人的问题不只是“时间不够”，而是大量即时刺激把一天切碎，让恢复、创造、专注与真正快乐都被埋进噪音里。

短视频、游戏、信息流、碎片化社交、情绪性购物、熬夜刷屏、无目的浏览，并不一定全是坏的。但当用户无法看见这些行为对注意力、身体状态、情绪余波和长期目标的影响时，就容易把“短暂刺激”误认成“有效恢复”，把“长期耗散”误认成“即时快乐”。

时间记录只能告诉用户“做了多久”，却不能解释这个行为结束后是更稳定，还是更空、更乱、更累。
情绪日记能记录难受，却往往无法把感受与具体行为、环境、时间段和触发事件连接起来。
很多自律工具用打卡与惩罚驱动用户，却很少帮助用户理解自己为什么总在特定场景里失控。
用户知道自己刷手机很多，但并不知道真正的熵源是睡前、被批评后、任务堆积后，还是饭后空白时段。

核心矛盾

用户缺的不是意志力，而是看见奖励后果的能力。

目标用户

面向已经意识到“廉价刺激正在消耗自己”，但不想被羞辱式自律工具裹挟，而是想真正理解自己奖励结构的成年用户。

想减少刷屏、游戏、碎片化社交带来的空虚感，却不知道如何追踪失控场景与后果。

User Profile

想建立低熵生活的人

希望重新排序娱乐、休息、学习、运动与创作，让滋养性的行为重新回到生活主轴。

User Profile

注意力经常被打散的人

创作者、学生、自由职业者、上班族，常常感到精神碎片化、持续专注能力下降。

User Profile

想记录行为与情绪关联的人

不是单纯记心情，而是希望看见某个行为、事件、时间段如何影响第二天的状态与选择。

核心指标体系

页面采用数据表盘式表达，强调这些指标是产品化隐喻，用于行为复盘与生活方式观察，不等同于医学指标。

Reward Quality

奖励质量

衡量行为结束后，用户是更清醒、更稳定、更有力量，还是更空、更乱、更后悔。

核心关注“精神回报”，而非时长本身。

Stimulus Intensity

刺激强度

衡量行为带来的即时刺激峰值，短视频、游戏、争论、购物往往更高。

高刺激不一定有害，但高刺激且低回报值得警惕。

Recovery Cost

恢复成本

衡量行为结束后，需要花多久才能恢复注意力、身体状态与情绪稳定。

高恢复成本会侵蚀后续时间段的可用能量。

Delayed Return

延迟收益

衡量行为是否会形成长期积累，例如睡眠、阅读、创作、运动、整理空间。

当下不一定轻松，但能为明天留资产。

Fragmentation

注意力碎片化

衡量行为是否打断持续专注，让用户频繁切换任务与情绪，制造任务残留。

碎片化越高，越容易形成“忙了一天却什么都没留下”的感受。

Mental Entropy

精神熵值

衡量混乱度、噪音、反刍、任务残留、情绪残留与身体负担的综合水平。

它描述生活秩序感，而不是检测真实神经递质。

Attention Debt

注意力债务

记录高刺激行为对后续专注力造成的损耗，反映“今天透支了多少明天的稳定性”。

它常常来自失控式刺激，而不是单次放松本身。

Recovery Asset

恢复资产

记录真正帮助用户恢复身心稳定的行为，如睡眠、散步、洗澡、认真吃饭与安静阅读。

恢复资产越稳，越能抵抗高刺激环境的牵引。

行为分类系统

系统不把行为简单道德化，而是允许同一个行为在不同情境下呈现不同结构结果。点击卡片可展开查看说明。

典型特征是：刺激不一定强，但结束后情绪更稳、身体更松、注意力更容易归位。它们构成用户的恢复资产，是低熵生活的底盘。

这类行为通常拥有较高的延迟收益。用户可能会累，但那是有产出的累，而不是被刺激掏空后的虚脱。系统会帮助用户识别这种“有证据的消耗”。

重点不是“不能做”，而是看它是否制造了恢复成本与注意力债务。适度游戏可能是放松，失控刷屏则可能是逃避，DopaLedger 会把这种差别显性化。

它们通常会带来睡眠债务、情绪残留、任务残留或反刍。系统不做道德判罚，而是提示代价、触发场景与后续需要配置的恢复动作。

典型使用场景

页面把同一种“今天发生了什么”转换为结构化分析结果，让用户看见行为后的精神回报与隐性成本。点击场景可展开分析。

系统分析为高刺激、高恢复成本、低延迟收益、高精神熵。它不仅占据了 90 分钟，还稀释了睡前稳定感，增加了第二天的注意力债务。

系统将其识别为恢复型奖励。它会降低精神熵、提高恢复资产，并为晚间入睡和第二天的注意力稳定提供基础。

系统分析为建设型奖励，长期收益高，恢复成本中等。它属于“有证据的累”，会被计入正向的延迟收益与自我证据。

系统会把它识别为高反刍事件，精神熵值上升，并建议把事实层、情绪层、行动层拆开，先降低混乱度，再安排一个 10 分钟低熵动作。

系统不会审判用户，而是明确指出即时刺激高、睡眠债务增加、恢复成本高，并建议限制时段或为之后配置恢复动作。

系统将其视为低刺激、高恢复、低熵生活行为。它看起来普通，却能帮助用户从碎片化状态中重新回到身体与现实。

核心功能模块

从输入、分析、可视化到反馈建议，形成一条完整的生活复盘闭环。

每日行为记录

输入今天做了什么、持续多久、当时目的是什么、结束后情绪如何。支持文本输入与预设快捷行为。

情绪与事件输入

记录争吵、拖延、被批评、完成任务、收到好消息等事件，系统分析其精神熵值与后续残留。

奖励结构分析

基于行为类型、时长、情绪反馈与备注，生成奖励质量、刺激强度、恢复成本、延迟收益分析。

精神熵值分析

评估混乱度、反刍程度、任务残留、情绪残留与身体负担，帮助用户看见“乱”的来源。

多巴胺主权表盘

展示高质奖励比例、高耗散奖励比例、注意力债务、恢复资产、主要熵源与趋势变化。

低熵行动建议

生成一个可立即执行的 10 分钟动作，如散步、写 5 行复盘、关闭通知、提前睡觉、整理桌面。

触发场景识别

识别哪些时间、情绪、地点或事件最容易把用户推入高耗散行为，如睡前、饭后无聊、被批评后。

周报与趋势

每周生成奖励结构趋势，回答哪些行为真正滋养用户，哪些行为长期制造债务与精神熵。

个人规则库

沉淀适用于自己的低熵规则，例如睡前 30 分钟不刷短视频、高刺激后必须配置一个恢复动作。

风险与边界

这是一个必须被明确写清的板块。DopaLedger 讨论的是行为奖励结构与精神秩序感，而不是医学检测或治疗行为。

产品边界声明

本产品不测量真实多巴胺水平，也不声称测量任何真实神经递质数据。
本产品不提供医学诊断、心理诊断或治疗建议，只用于自我观察和生活方式复盘。
“多巴胺”“精神熵值”“注意力债务”等均为产品化的行为复盘指标，不等同于医学指标。
系统分析结果不应用于疾病判断。如果用户长期出现严重失眠、持续低落、自伤想法、强迫行为、物质依赖或无法正常生活，应寻求专业帮助。

设计伦理要求

系统不应制造羞耻感，不应把娱乐、休息或放松一概判定为“劣质”。
AI 建议必须允许用户调整，不应把用户推向极端禁欲或过度自责。
数据默认本地保存，用户可删除记录，隐私数据不应用于广告推荐。
同一个行为在不同情境下可以得到不同分析结果，系统关注的是结构后果，不是道德立场。

交互与可视化

  • 用 CSS 与轻量 JS 实现精神状态表盘、奖励结构图、熵值趋势图与行为卡片交互。
  • 支持表单输入行为、持续时间、结束后情绪与备注，也支持预设快捷行为。
  • 输出奖励质量、刺激强度、恢复成本、延迟收益、精神熵值与低熵行动建议。

部署方式

  • 静态网页部署，或直接以 HTML 文件形式体验。
  • 手机端优先设计，兼容桌面浏览器，便于比赛评审快速浏览。
  • 本页即为一个单文件 HTML 创意提案原型，满足无外链、可离线展示的要求。

Demo 核心闭环

围绕“输入行为 → 分析结构 → 生成表盘 → 形成趋势”建立最小可演示产品。

复赛迭代路线

复赛阶段的目标不是堆功能，而是让“理解用户奖励结构”这件事变得更准确、更个体化、更可信。

模型与分析升级

  • 接入真实大模型 API，提高行为与事件分析质量。
  • 增加个人化规则学习，根据用户长期反馈调整评分权重。
  • 增加情绪事件的事实层 / 情绪层 / 行动层拆解。
  • 增加个人触发场景识别与低熵行动库。
  • 支持用户自定义行为分类和个人规则库。

产品与数据能力

  • 增加周报、月报和长期趋势图。
  • 增加数据导出功能，支持用户带走自己的行为账本。
  • 增强隐私加密与本地优先存储能力。
  • 增加桌面小组件或手机快捷记录入口，降低记录摩擦。
  • 进一步优化“娱乐不是敌人，失控才是问题”的解释型体验。

产品原则

这不是一套让用户更焦虑的系统，而是一套帮助用户更快理解自己、调整行为、恢复秩序的产品原则。

1

不测量真实多巴胺，只分析奖励结构

我们讨论的是行为后的精神回报、刺激强度、恢复成本与长期收益，而不是医学检测结果。

2

不羞辱用户，只帮助用户看清后果

系统不是道德裁判，而是把用户的行为后果可视化，让解释先于责备。

3

不追求极端禁欲，而是恢复选择权

目标不是让用户“不快乐”，而是重新选择真正想要的快乐与恢复方式。

4

娱乐不是敌人，失控才是问题

同一种娱乐在不同情境下可能是滋养，也可能是逃避，系统会用结构结果来区分。

5

低熵生活不是苦修，而是减少噪音

真正的低熵生活，不是把生活变窄，而是保留那些能稳定滋养自己的行为与关系。
