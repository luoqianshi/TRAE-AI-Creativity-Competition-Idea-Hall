StockAI

多 AI 驱动的智能股票分析桌面系统
基于 Electron 的跨平台桌面端，整合实时行情 · AI 智能分析 · 策略回测

1 创意名称 & 创意介绍

想解决什么问题
散户投资者在进行股票投资决策时，面临信息碎片化、技术分析门槛高、多源数据难以整合的痛点。普通投资者通常需要同时使用多个软件（行情软件、选股工具、AI 对话工具），来回切换效率低下。
为什么会想到做这个
当前市场上有同花顺等行情软件（缺乏 AI 智能分析）、有 ChatGPT 等通用 AI 对话工具（缺乏股票专有数据接入）、有量化回测平台（需要编程能力）。将这三者整合到一个桌面应用中，让普通投资者也能用自然语言进行选股和个股深度分析——这个空白就是开发的灵感来源。
产品形态
一款基于 Electron + React + TypeScript + Tailwind CSS 的跨平台桌面客户端软件（Windows/macOS/Linux），内嵌 Python 本地代理服务，同时包含 Streamlit Web 版本。
Electron 桌面端 React + TypeScript Python 代理服务 Streamlit Web 版 跨平台

2 目标用户及痛点

面向哪些用户
  • ● A 股散户投资者，尤其是有一定投资经验但缺乏编程/量化能力的个人投资者
  • ● 希望通过 AI 辅助进行选股决策和多维度分析的股民
  • ● 对多 AI 模型对比感兴趣的技术型用户
在什么场景下使用
  • ● 开盘前/收盘后：使用 AI 智能选股功能，输入选股策略条件，让 AI 从预置股票池中筛选符合条件的个股
  • ● 盘中盯盘时：使用多 AI 辩论功能，对关注的某只个股进行五维度（技术面、资金面、消息面、基本面+大盘环境、综合决策）未来趋势推演
  • ● 周末复盘时：使用策略回测模块，对自选策略在历史数据上进行收益率、夏普比率、最大回撤等专业指标验证
  • ● 日常盯仓：通过自选股列表实时查看持仓行情、涨跌通知、多 AI 模型对话
当前痛点（没有本产品时）
📉
行情与 AI 分离
用户如需 AI 分析股票，需手动将行情数据复制到 ChatGPT 等工具中，操作繁琐且 AI 缺乏实时数据接入。
🛠️
量化回测门槛高
策略回测需要 Python 编程能力或使用专业量化平台，普通散户无法独立完成策略的历史验证。
🔄
多平台切换低效
行情软件、AI 对话工具、回测平台各成一体，投资者需在多个软件间频繁切换，效率极低。
📊
分析维度单一
传统行情软件只提供基础图表和指标，缺乏从技术面、资金面、消息面、基本面等多维度综合分析的能力。

3 价值与意义

⚡
效率提升

将实时行情、AI 对话分析、策略回测三大功能整合到一个桌面应用中，用户无需在多个软件之间切换：

  • 代理服务本地运行于端口 9999，直接调用新浪财经免费 API 获取 A 股实时行情，数据与 AI 分析链路在同一应用内闭环
  • AI 智能选股自动拉取 32 只预置股票池的实时行情，结合用户输入的自然语言策略，AI 直接输出筛选结果及理由
  • 多角色 AI 辩论通过 5 轮递进式对话（技术面多头 → 资金面空头 → 消息面中立 → 基本面全局 → 最终决策官），输出量化的明日涨跌概率
  • 策略回测引擎支持 4 种预定义策略和自定义表达式，输出年化收益率、夏普比率、最大回撤等专业指标
💰
商业价值
  • 产品已完成 Windows 平台 NSIS 安装包构建（StockAI Setup 1.0.0.exe），具备分发条件
  • 集成 7 个主流 AI 大模型（GPT、豆包、通义千问、文心一言、讯飞星火、Kimi、DeepSeek），用户通过自有 API Key 接入，产品不承担模型调用成本
  • 金融投资辅助工具赛道市场空间大，散户投资者群体付费意愿较高，产品具备增值功能商业化潜力
