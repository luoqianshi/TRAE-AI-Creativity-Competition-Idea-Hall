Part 01 / Creative Introduction

创意名称 + 创意介绍

发现痛点、找到动机、定义产品形态 -- 一个覆盖动画全场景的三维产品。

核心要点 痛点 资源分散 + 2D 预览局限 + PPT 无法展示动效 动机 HTML替代PPT + HyperFrames + WebXR 三者交汇 形态 零依赖单文件 Web 应用
◎
Problem
发现的痛点
前端动画资源分散，学习成本高；动效在 2D 屏幕中难以想象实际空间效果；传统 PPT 演示无法展示交互式动画，视频制作又需要专业工具链。
⚡
Motivation
灵感来源
HTML 正在取代 PPT 成为新的演示载体（如 HTML Deck），HyperFrames 让 HTML 视频合成成为可能，WebXR 让 AR 体验能在浏览器中直接运行。三者的交汇点，就是一个"从灵感到演示"的完整动画工作流。
★
Innovation
创新点
不只是一个动画库，而是一个三维产品：动画灵感画廊（2D）+ AR 空间预览（3D）+ HyperFrames 视频合成（演示输出）。同一个动画代码，在三种形态中无缝流转。

产品形态：零依赖单文件 Web 应用

一个纯 HTML + CSS + JS 单文件，在浏览器中直接打开。包含动画画廊浏览、AR 摄像头互动预览、HyperFrames 视频导出三个功能模块。无需安装任何依赖，无需构建工具链，手机或电脑均可运行。

01

面向哪些用户

前端开发者（找动画灵感）、UI/UX 设计师（在真实空间中预览动效方案）、内容创作者（用 HTML 替代 PPT 做动画演示）、技术讲师（制作交互式教学视频）、学生（学习动画原理的沉浸式工具）。

02

在什么场景下使用

日常开发中快速查找动画效果；设计评审时打开手机 AR 实时展示动效在真实环境中的表现；用 HyperFrames 将选好的动画效果合成一段视频，替代传统 PPT 进行项目汇报或技术分享。

03

当前痛点

动画资源分散且依赖第三方库；动效设计只能在 2D 屏幕中预览，无法感受真实空间效果；PPT 无法展示交互式动画，录屏又缺乏专业感；从"找到动画"到"做成演示"需要跨越多个工具，链路断裂。

Part 03 / Value & Significance

价值与意义

效率提升 + 社会价值，双维度说明。

核心要点 效率 找灵感到做出演示，数小时缩短到分钟级 社会 验证 HTML 替代 PPT 可行性，推动开源学习
Efficiency

效率提升：打通"灵感到演示"全链路

传统流程是：在 CodePen 找效果 - 复制代码到项目 - 用 PPT 或录屏做演示。MotionSpark AR 将这三个步骤合并为一个连续体验：在画廊中浏览效果 - 一键切换到 AR 模式在真实空间预览 - 直接用 HyperFrames 合成视频。同一段动画代码在三种形态中复用，无需重复开发，将"找灵感到做出演示"的时间从数小时缩短到分钟级。

Social Value

社会价值：推动 HTML 演示文化与开源学习

MotionSpark AR 验证了"HTML 替代 PPT"的技术可行性 -- 用动画和 AR 增强传统演示形式，让知识分享更有沉浸感。作为零依赖的开源项目，它降低了动画学习和 AR 体验的门槛。长远来看，这种"画廊 + AR + 视频"的三维产品模式可以推广到配色、排版、3D 模型等更多设计领域，形成开源社区驱动的创意工具生态。
