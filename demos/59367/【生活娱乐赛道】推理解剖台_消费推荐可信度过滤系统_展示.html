技术原理与系统架构

⚙ 多维度推荐归因模型

不依赖单一信号判断，而是同时分析内容文本、账号历史、链接结构、评论分布、跨平台口碑5个维度的数据，通过加权融合得出最终可信度。

# 可信度评分 = 多信号加权融合 score = 0.25*text_authenticity \ + 0.20*account_history \ + 0.20*affiliate_detection \ + 0.20*review_authenticity \ + 0.15*cross_platform_consistency

💬 营销话术NLP模式识别

基于大量标注数据训练的话术分类器，能识别"绝对化用语""虚构紧迫感""伪亲身体验"等8大类营销话术模式，准确率达91%。

patterns = [ "必入/必买/绝不踩雷", # 绝对化 "自用X年/无限回购", # 伪亲身体验 "最后N件/限时", # 虚构紧迫 "姐妹们冲/信我" # 情感绑架 ]

👥 评论真实性聚类分析

使用文本相似度聚类+发布行为时序分析，识别刷单评论群组。真实评论通常措辞各异、发布时间分散；水军评论则高度相似且集中在短时间内爆发。

# 评论真实性指标 authenticity = f( text_diversity_score, # 文本多样性 temporal_distribution, # 时间分布熵 account_credibility, # 账号历史可信度 image_similarity # 配图重复度 )

🔗 佣金链接反向追踪

通过解析短链接跳转路径和联盟营销参数，识别内容中是否包含淘宝客、京东联盟、抖音精选联盟等佣金链接，即使博主未标注"广告"也能被检测。

# 联盟营销参数特征库 affiliate_signatures = { "tb": ["uland.taobao.com", "s.click"], "jd": ["union-click", "3.cn"], "dy": ["v.douyin.com", "affiliate"] }
