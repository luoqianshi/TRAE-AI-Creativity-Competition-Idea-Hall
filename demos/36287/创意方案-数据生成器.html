核心功能

产品如何解决问题？

1

可视化配置变量

在 GUI 中拖拽配置每个变量的类型、数据源、分隔符与循环次数。支持变量间依赖引用，如将数组长度 max 设为「n」实现动态约束。

2

智能生成测试数据

内置均匀随机、边界强化、高斯分布、自定义分段概率等多种分布策略；通过安全沙箱执行自定义 Python 代码，灵活应对复杂构造需求。

3

AI 生成解题代码

一键调用 DeepSeek / Nuwa 等大模型生成 solve 函数，流式回显到内置代码编辑器（支持语法高亮、代码补全、错误检测）。

4

自治 Agent 多轮修复

Isolated Agent 引擎自动执行代码、分析错误、修改代码、自测验证，最多 30 轮自治迭代，直至通过全部测试点。

5

双算法对拍验证（可选）

并发运行两个独立 Agent 分别生成暴力解与优化解，交叉比对输出结果。若不一致则自动注入反馈重试，确保代码逻辑严谨无误。

技术实现

关键技术亮点

🔒

双层安全沙箱

AST 静态守卫拦截危险导入与函数调用；子进程隔离执行确保主进程不受崩溃/死循环影响，双重保险保障本地安全。

♻

自治 Agent 协议

定义 read / run / modify / self_test / finalize 五种标准动作，Agent 自主决策修复路径，具备防死循环与无进展检测机制。

🌐

多平台 LLM 兼容

支持 DeepSeek、Nuwa 等所有 OpenAI 兼容 API，平台配置、模型列表、价格信息均可动态切换，不绑定单一供应商。

📈

智能分值分配

支持按权重自动分配测试点分值，采用最大余数法保证总和精确等于题目总分，省去人工计算的繁琐。

技术栈

Python PySide6 AST 静态分析 OpenAI 兼容 API 多线程 / 子进程 QSS 样式表 QSettings 持久化 SHA256 版本追踪
