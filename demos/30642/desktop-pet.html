一、创意名称与介绍

🎯 创意名称

桌面上的小毛球 · MoodPet

❓ 想解决什么问题

长时间对着电脑工作或学习的人，常常会感到孤独、焦虑或情绪低落，却没有一个随时可以"摸一下"的情绪出口。我们需要一个轻量、有趣、不打扰工作节奏的桌面陪伴者。

💡 为什么会想到做这个

灵感来自小时候养电子宠物的快乐，以及看到同事们工作压力大时，喜欢在桌面放一些解压小玩具。我们想把那种"被回应"的温暖带到数字桌面上，让每一次点击都像在和一只懂你的小毛球对话。

📦 大概是什么产品

一款轻量的桌面情绪宠物应用（Web / Desktop Widget），用户可以给宠物起名字，通过点击它来表达不同情绪，宠物会用动画、文字、表情给出温暖回应。

二、目标用户与使用场景

👥 核心用户
  • 长时间使用电脑的上班族、程序员
  • 居家学习的学生党
  • 喜欢治愈系内容、养电子宠物的年轻人
  • 希望通过轻量互动缓解焦虑的人
🖥️ 使用场景
  • 工作间隙 / 摸鱼时刻，点一下解闷
  • 遇到 Bug 或 Deadline 压力大时，发泄情绪
  • 早晨开机 / 晚间下班，跟它打个招呼
  • 孩子上网课累了，和小宠物互动放松

😵 当前痛点（如果没有它）

  • 桌面空空，情绪没有即时的"被接住"感
  • 想解压却要打开手机刷社交，反而更分心
  • 电子宠物产品要么太老、太重，要么数据化不够
  • 一个人在家工作/学习时，偶尔会感到"房间里好安静"

三、价值与意义

💼 社会价值：让每个桌面都有一个情绪出口

现代人的情绪问题越来越被关注。"小毛球"不治病，但它能在你需要一个温暖回应的那一刻，做你桌面最小的朋友。它用极低的成本、极轻的交互，给用户带来一次次的微笑 —— 这正是我们想送给世界的东西。

⚡ 效率提升：把"分心的 5 分钟"变成"解压的 10 秒"

当用户感到烦躁时，不用再打开手机、社交 App、视频网站来回避压力；只需点三下桌面的小毛球，10 秒内完成一次情绪互动，再快速回到工作中。它让"摸鱼"变得更高效、更有边界。

💰 商业价值（可选）

  • 可拓展为桌面 Widget / 浏览器插件 / 移动端 App 多端形态
  • 支持皮肤、服装、配饰的个性化购买（虚拟道具）
  • 联动番茄钟、待办清单等效率工具，做成"陪伴型效率助手"

四、核心交互与未来扩展

🖱️ 核心交互逻辑

用户在一定时间窗口内连续点击宠物 → 系统识别点击次数 → 映射到不同情绪 → 触发对应动画 + 对话 + 颜色变化。

🚀 未来可扩展方向

  • 接入大模型 API：让宠物能根据用户输入的文字做出回应
  • 情绪积累系统：每天互动累积好感度，解锁新服装与动作
  • 多宠物系统：支持同时养多只，让它们互相"串门"
  • 跨桌面小组件：Mac / Windows / 浏览器标签页都能出现
  • 朋友分享：把宠物的表情截图一键发送给好友
