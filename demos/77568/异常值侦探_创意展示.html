// Pain Points

数据分析师的困境

发现了异常，却说不清为什么

🧬

检测工具输出太数学化

Isolation Forest 给你一个异常分数，Z-Score 给你一个标准差倍数——业务人员根本看不懂。数据分析师需要额外花时间翻译成"人话"。

💭

原因分析全靠猜

发现异常后，分析师开始翻日志、查配置、问同事——这个过程可能耗时数小时甚至数天，而且高度依赖个人经验。

🏢

中小企业没有数据团队

异常在报表里藏了好几个月都没人发现。等终于发现时，问题已经造成了巨大损失。不是不关心数据，而是缺少工具。

// Features

核心功能

01

智能算法选择

自动分析数据分布特征，推荐最适合的检测算法。正态分布用 Z-Score，偏态分布用 IQR，复杂多维用 Isolation Forest

02

严重度分级

不只标记"是否异常"，还评估严重程度：轻微波动 / 需关注 / 严重异常 / 紧急。颜色编码一目了然

03

关联分析

自动检查异常点是否与其他维度存在关联——"订单下跌的同时，客服工单激增 200%，高度相关"

04

自然语言解读

用大白话解释分析结果，非技术人员也能理解。支持一键生成分析摘要，可直接发送到工作群

05

定时巡检

设置自动巡检计划，每天/每周自动扫描数据，发现异常后推送通知到飞书/钉钉/Slack

06

BI 集成

提供 Tableau、Power BI、Grafana 插件，在现有仪表盘中一键添加"异常洞察"面板
