问题

手表，正在变成腕上的第二个手机

它承接消息、App、通知，时时刻刻提醒你；屏幕不能无限放大，功耗与成本却卡得很死，于是只能两天一充。但很多人并不想要这些——他们只想要一块安静走时、顺带懂自己身体的表。一旦要频繁充电、又被反复打扰，最该被连续记录的睡眠与运动数据，反而因为"摘下来"和"嫌烦"断了档。

定位

不是阉割的手表，也不是加强的手环

它精准跨过手表的两条分水岭——自主（板载存储 + 端侧算法，离开手机也能独立运算）与智能（算力全砸在"读懂身体"上）；同时主动拒绝会摧毁"无感 + 长续航"的其余一切。

为什么是新物种

它由"拒绝做什么"来定义

专精

只做深一件事

只在"健康 + AI 监测"一个方向做深，在这件事上比通用智能手表更专业——而不是什么都做、什么都浅。

开放

数据归你

佳明、Whoop、Oura 都是封闭生态。Airfit 开放数据格式、算法与固件，数据归用户所有、算法可被社区改进。

克制

少打扰

一块安静的 MIP 表盘 + 最简提醒。唯一保留的便利是 NFC 一碰即走——无需亮屏、无需扫码、近乎零功耗。

AI 如何落地

两层智能

On-device · 端侧

长在硬件里真护城河

去伪影、HRV 等信号处理打底，之上用轻量 TinyML 跑睡眠分期、活动识别、异常检测，并形成个性化基线。难点也是亮点：在纽扣电池级功耗下做实时、连续推理——这是"贴一个通用大模型"替代不了的。

Cloud Agent · 云端

让数据可对话

同步后，大模型驱动的健康 Agent 不止写总结，而是可被追问（"我最近睡得怎么样""为什么这周静息心率偏高"），背后挂 HRV 统计、人群基线对比、趋势识别、报告生成等明确工具。

端侧让设备长续航地连续感知，云端让数据变成你能对话的健康洞察。
