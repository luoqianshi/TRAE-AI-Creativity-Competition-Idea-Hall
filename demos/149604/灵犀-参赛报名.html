02/13
创意介绍

AI 不该是每次从零开始的问答框

现在的 AI 助手，用完即关——
不记得你昨天做了什么，不会自己动手，
更不会把你的知识连到外面去。

灵犀想做一个真正有连续性的桌面 Agent：它记得你读过、想过、聊过的一切，能自己开浏览器把事做完，还会主动把你已知的，连到你没碰过的领域。

03/13
目标用户及痛点

谁会用，什么时候用，现在卡在哪

面向谁

知识工作者、学习者、需要长期管理信息和知识的人。日常大量使用电脑，需要 AI 不只是回答问题，而是真正帮忙干活。

什么场景

日常工作时整理信息、处理重复流程；学习时梳理知识结构、发现盲区；需要跨工具协作、跨场景记忆的时候。

当前痛点

AI 每次从零开始，不记得上下文；只会说不会做，给步骤让你自己点；封闭孤岛，不能跟其他工具协作；能力固定，用久了没有增量。

更深的痛点

大多数 AI 在加固你的信息茧房——推荐你喜欢的、回答你领域的、优化你已有的。输入越多，困得越死。

05/13
Agent 能力

它会自己动手做事

浏览器自动化

自己开浏览器、填表单、走完一整个流程，不只给步骤让你自己点。说一句话，它把事做完。

开放协作（MCP）

基于开放协议，能跟其他 Agent 一起干活，还能帮别的 Agent 做代码审查和质量把关——不封闭，是生态里的一员。

桌面遮罩形态

能收起界面，变成一个透明置顶的小形象静静待在桌面上。需要时一句话叫出来，不抢占你的屏幕。

能力可生长

加一个技能就多一项本事。壳核分离、能力插件化，不是固定的工具，是为长期生长而生的。

08/13
Agent 协作

不止一个 Agent，是一支互相校验的团队

灵犀不会独自闷头改。复杂任务被拆给专精子 Agent 分头处理，彼此交叉核查，卡住就上报，不装懂、不空转。

需求评审子 Agent

接到需求先拆解、定 review 计划，多 Agent 对齐一遍再动手，不是"想当然就开始改"。

代码评审子 Agent

改动前先看 diff、观察真实改了什么，再验证结论是否成立，不听一句话就盖章通过。

任务与消息路由

Agent 之间派发任务、传递结果都走统一通道，身份和来源可追溯，不会张冠李戴、互相顶替。

卡点主动求助

遇到解不了的问题会主动喊人或调外部工具，问题被摆出来，而不是被悄悄吞掉、假装完成。

价值：把"一个 AI 全权拍板"换成"多个视角互相制衡"，复杂工作的出错率和返工成本因此下降。

09/13
深度自动化

自动化再进一步：把"能做"变成"办成"

不满足于走通一次流程演示。遇到限制会换策略重试，遇到真实账户操作也能走完整个链路。

网页级深度自动化

搜索、抓取、比对多方来源，遇到反爬或访问限制会自己换 User-Agent、换路径重试，不是一试就放弃。

真实账户级操作

能进控制台核对余额、走多步的充值 / 汇款流程，卡在需要人工确认的环节会如实说明，不是编一个"已完成"。

界面随协作场景进化

长时间盯屏协作时一键切换深色模式，减少视觉疲劳，界面服务于"长期一起干活"而不只是好看。

价值：自动化不停在"演示级"，而是能顶到真实业务操作的深度，每一步留痕，出问题可回溯、可追责。

10/13
场景深化

自动化落地：学习 × 日报，从记录变成推进

学习：讲完还会追问你

不是单向输出课件，讲完一个知识点会顺手抛一个开放式问题让你先想，再结合你的回答继续深入，讲练自动衔接。

日报：能追问的工作记忆

每天自动生成带"洞察 / 待办 / 成长"标签的复盘卡片，任意一条都能直接追问下去，日报从"存档"变成"可对话的进度台账"。

价值：学习和日报共用同一套记忆与自动化能力——学到的会被日报引用，做过的事会反哺学习判断，两者互相印证、不是两个孤立功能。

学习：知识地图 + 断点续学

课程按"基础 / 进阶 / 前沿"分层拆解到具体小节，每节标出已掌握 / 待解锁 / 讲练结合，回来一键"接着学"，不用重新找进度。

学习：讲完立刻追问，逼你想一步

讲完"多模态融合的三种方式"，不是甩课件就完事——会追问"哪种更像人脑处理过程"，等你回答后再顺着你的思路继续深入，真正做到讲练结合。

日报：每天的洞察自动沉淀成卡片

按天生成的复盘卡片，正文之外单独抽出"洞察"标签和条数统计，每条洞察都带"追问"入口，点开就能继续深挖，不是看完就扔的流水记录。

11/13
技术底气

为什么能做到

技术不是炫技，是质量底线。点到为止，体现先进性和稀缺性。

多模态统一记忆大脑 听觉、视觉、文本进同一个记忆核心——大多数 AI 没有这个能力。
全双工语音 像打电话一样，能随时打断、接着话茬说，延迟低于 1 秒。
壳核分离 + 能力插件化 为长期生长而生，加技能就多本事，不是固定的工具。
检索准、接地 向量 + 图谱融合检索，这是破壁不变成噪声的底线。
多 Agent 任务路由与追溯 子 Agent 之间的任务分发、身份、结果传递走统一通道，卡点能主动上报求助——协作而非黑箱空转。
12/13
价值与意义

不只是效率工具

效率

从"给步骤"到"自己做完"

AI 自己开浏览器、走流程、填表单，用户不用手动操作。把重复性工作交给 Agent，人专注决策。

认知

从"加固茧房"到"打破茧房"

大多数 AI 越用越窄。灵犀反着来：把你已知的连到未知的，让 AI 带你看见你不知道的——这是社会认知层面的价值。

协作

从"单点执行"到"多方互检"

需求评审、代码评审各有专精子 Agent 交叉核查，卡点主动求助不装懂，复杂任务的可靠度不依赖单一模型的一次判断。
