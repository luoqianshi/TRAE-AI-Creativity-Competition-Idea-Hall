Why Memory

为什么我们需要 Memory？

社交媒体让我们习惯了"分享"，但有些回忆，不该被公开。 它们属于你自己、你的家人、你的爱人——和那些再也回不来的人。

🗑

照片散落各处

微信、相册、云盘……珍贵回忆被碎片化分散，找不到、存不住、回不去。

🔒

隐私无法保障

社交平台默认"可见"，你的私人时刻随时可能被泄露、被误发、被遗忘。

👫

集体回忆无处安放

家庭聚会、社团活动、宠物成长……多人共同的经历，却没有一个专属的私密空间来珍藏。

💕

逝者的记忆在消失

当亲人离去，他们的故事、照片、声音也在慢慢消散。我们需要一个地方，永远记住他们。

Core Features

核心功能

Memory 不只是一个存储工具，它是一个围绕"回忆"构建的完整体验——从记录到守护，从个人到集体，从现在到永恒。

👤

个人回忆板块

创建只属于你自己的回忆空间。支持文字日记、照片、文档、PPT、音频等多种格式，按时间线自动排列。

👥

多人回忆空间

邀请家人、伴侣、朋友或社团成员共建回忆。每个人都能上传内容，管理员可设置审核与编辑权限。

🔐

绝对隐私隔离

每个人的板块完全隔离，无法通过头像、链接或任何方式窥探他人内容。端到端加密，数据只有你能看到。

📅

纪念日与备忘录

自动记录重要日期——在一起的每一天、宠物的生日、家人的纪念日。支持自定义提醒，不再遗忘。

📦

时光胶囊

写给未来的信。设定一个开启时间，将回忆封存。到期时你会收到来自过去的惊喜，也可以留给逝者的纪念空间。

🎨

语音快速记录

来不及打字？直接语音录入，AI 自动转写为文字记录并添加时间标签，随时随地捕捉灵感与感动。

Security First

隐私，是我们的底线

Memory 从设计之初就将安全作为第一优先级。 我们相信，真正的私密意味着：你的回忆，只有你和被你邀请的人能看到。

  • ✓ 端到端加密 — 数据在传输和存储全程加密，连平台方也无法读取
  • ✓ 板块完全隔离 — 无法通过头像、链接、搜索等任何方式进入他人空间
  • ✓ 分层权限控制 — 创建者/管理员/成员三级权限，精细化控制编辑与查看
  • ✓ 本地备份支持 — 支持离线导出，数据永远属于你自己
