/ Risk Factors

持仓集中的四大风险

集中度风险正在让基金组合变得脆弱

📊

前十大占比过高

部分基金前十大重仓股占比超过70%，净值波动接近个股水平。一旦前十大中的某只重仓股暴雷，基金净值将遭受重创。

🏭

行业押注式投资

不少基金集中押注单一行业（如新能源、白酒、半导体），行业景气度下行时基金净值腰斩，投资者承受远超市场平均水平的回撤。

🔄

"伪分散"假象

投资者持有3-5只基金看似分散，实则每只基金都重仓了同一批股票（如茅台、宁德时代），导致组合实际风险高度集中。

📉

风格漂移难追踪

基金的持仓风格可能在季度间发生漂移（从均衡→集中），但普通投资者不会逐季对比持仓变化，等发现时已经承受了集中度风险带来的损失。

/ Core Metrics

八大分析指标

从多维度量化集中度风险

01 / 前十大占比

Top10 Holding Ratio

计算前十大重仓股占基金资产净值的比例。通常<40%为分散，40%-60%为中等，>60%为高度集中，需警惕个股风险。

02 / HHI赫芬达尔指数

Herfindahl Index

计算所有持仓个股占比的平方和，HHI越接近1说明持仓越集中。HHI>0.25为高度集中，0.15-0.25为中等，<0.15为分散。

03 / 行业集中度

Sector Concentration

统计前三大行业持仓占比之和。>60%为高度行业集中，40%-60%为中等，<40%为行业分散。同时识别行业押注行为。

04 / 个股间相关性

Cross Holding Correlation

分析基金持仓个股之间的行业/风格相关性。高相关性意味着看似分散的持仓实际风险高度同质化。

05 / 有效持仓数

Effective Holdings

基于HHI计算有效持仓数（1/HHI），反映"等效的独立持仓数量"。有效持仓数<10表示风险高度集中。

06 / 最大单只占比

Max Single Weight

单只最大重仓股占净值比例，>10%需警惕，>15%为高度风险。单只股票暴雷时对净值影响直接可见。

07 / 风格漂移指标

Style Drift Score

对比当前持仓与历史持仓的行业分布变化，量化风格漂移程度。高漂移分数意味着基金策略可能已发生重大变化。

08 / 组合重叠度

Portfolio Overlap

用户持有多个基金时，计算基金间重仓股的重叠程度。高重叠度说明"伪分散"，实际风险与单只基金无异。

核心算法流程

持仓数据标准化

支持基金代码自动拉取、CSV上传和手动输入三种方式。将多源持仓数据统一为标准化格式，对齐行业分类（中信/申万/SW），自动识别股票代码和权重。

集中度指标计算引擎

实现前十大占比、HHI指数、行业集中度、有效持仓数等8项指标的精确计算。HHI = Σ(wi²)，其中wi为第i只股票的持仓权重，直接反映持仓的集中程度。

多基金重叠度分析

当用户输入多只基金时，构建基金-个股持仓矩阵，计算Jaccard相似度和加权重叠度指标，量化"伪分散"程度。重叠度>0.5即为高度重叠。

风险评级模型

基于8项指标加权计算综合风险评分，按风险等级分为低/中/高/极高四档。模型参数可自定义，满足不同投资者的风险偏好。

🔧 技术亮点

  • 8维风险指标矩阵：从持仓占比、行业分布、相关性、风格漂移等多维度全面量化集中度风险
  • 多基金穿透分析：同时分析多只基金的持仓重叠度，识别组合层面的"伪分散"风险
  • 历史数据对比：支持季度持仓数据对比，自动检测风格漂移和集中度变化趋势
  • 自定义阈值：风险判定阈值可自定义，适应不同投资风格和风险偏好的用户
  • 数据源可扩展：支持接入天天基金/东方财富/同花顺等主流平台API自动获取持仓数据

💻 产品亮点

  • 一键输入：输入基金代码自动拉取最新持仓数据，无需手动整理
  • 仪表盘可视化：雷达图、HHI热力图、行业分布饼图、历史趋势线等多维可视化
  • 风险评分卡：每个指标单独评分并汇总为综合得分，直观展示风险画像
  • 调仓建议生成：基于风险分析结果，自动输出结构化的持仓优化建议
  • 报告导出：一键生成PDF格式的专业集中度风险分析报告，可用于投顾服务
