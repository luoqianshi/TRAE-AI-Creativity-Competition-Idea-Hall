一、创意名称 + 创意介绍

创意名称：随身护

随身护是一款专为银发老人（60岁以上）和残障人士设计的移动应用，通过智能定位、路况通报、志愿者帮扶等功能，为特殊群体提供安全、便捷的生活服务保障。我们致力于通过科技手段，为老年人和残障人士搭建一个温暖的守护网络，让志愿者的爱心能够精准传递到需要帮助的人手中。

二、想解决什么问题

老年人和残障人士在出行时面临路况障碍无法及时知晓、紧急情况难以快速求助、健康管理缺乏有效工具等痛点，需要一个综合性的服务平台来保障他们的出行安全和生活便利。

三、为什么会想到做这个

看到身边的老人和残障朋友在日常生活中遇到诸多不便，尤其是出行时的安全隐患，我们希望通过科技手段为他们搭建一个温暖的守护网络，让志愿者的爱心能够精准传递到需要帮助的人手中。每个人都会变老，每个人都可能面临身体上的不便，我们希望用技术的力量，让这个社会更加温暖、更加包容。

四、大概是什么产品

一款基于React + Node.js开发的移动端App，提供路况通报、紧急求助、健康管理、志愿者服务等核心功能，支持iOS和Android双平台。

五、目标用户及痛点

面向哪些用户

  • 60岁以上的银发老人
  • 各类残障人士（视力障碍、听力障碍、肢体障碍等）
  • 愿意奉献爱心的志愿者群体

在什么场景下使用

  • 老年人日常出行、散步
  • 残障人士外出办事、购物
  • 突发紧急情况求助
  • 健康数据记录与预警
  • 志愿者服务响应

当前痛点

  • 没有统一的平台整合路况信息，无法提前知晓道路障碍
  • 紧急情况时难以快速联系到志愿者
  • 健康数据缺乏系统化管理，异常情况无法及时预警
  • 界面设计不适合老年人使用（字体小、操作复杂）

六、核心功能亮点

📍

路况通报

实时上报道路障碍、施工、积水等情况，支持图片上传佐证

🆘

紧急求助

一键呼叫在线志愿者，支持电话联系，设置紧急联系人

❤️

健康管理

血压/血糖记录与异常警报，定时吃药提醒

🎧

语音导航

为视力障碍用户提供语音指路服务

👥

志愿者服务

严格考核机制，服务后评分评价

🔊

大字体模式

针对老年人优化界面显示，声音清晰洪亮

七、价值与意义

社会价值

通过科技手段关爱特殊群体，促进社会和谐，让老年人和残障人士能够更安全、自信地出行和生活，感受到社会的温暖与关怀。

效率提升

建立志愿者与服务对象的高效匹配机制，缩短求助响应时间，提高服务效率；通过智能语音播报和大字体界面，提升特殊群体的使用体验。

八、技术实现

React Vite Node.js Express JWT Leaflet Web Speech API styled-components
