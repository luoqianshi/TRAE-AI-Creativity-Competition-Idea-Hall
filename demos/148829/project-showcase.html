Core Concept

灵感来自经典的 Powder Game，用现代浏览器技术重新打造：像素级物理沙盒 + 确定性反应 + 挑战关卡驱动

48 种像素元素

粉末、液体、气体、能量、机关、生命体六大类。沙子会坍塌、水会流动、火焰会引燃、火药会爆炸——每种元素都有明确的物理规则。

⚙

确定性物理引擎

固定 seed + 可复现的元胞自动机。同样的布局永远产生同样的结果，这对内容创作者录屏、玩家复现连锁反应至关重要。

不只是自由沙盒。3 个正式关卡要求你用有限预算的元素完成目标：灭火、搭桥、爆破——每关都有稳定通关路径。

💡

反应发现系统

🖼

物理直觉，无需公式

玩家在玩的过程中自然理解密度、相变、导电、连锁反应等概念。水浇灭火焰、电流引爆火药、种子遇水长成木头——规则直观，结果可预测。

  • 粉末会坍塌、会随坡度滚落
  • 液体按密度分层，高密度在下
  • 气体上浮、会横向漂移扩散
  • 机关（风扇/泵/弹簧）可以搬运和推动物质

Tech Stack

技术亮点

纯前端实现，零第三方运行时依赖，所有代码用 TypeScript 手写。

⚒

固定步长物理循环

60 tick/s 固定步长，积压超过 5 帧时自动丢弃，保证任何设备上模拟结果一致。Seeded RNG（Mulberry32）取代 Math.random()，彻底消除随机抖动。

📊

TypedArray 缓冲区

物理状态全部用 Uint8Array/Int8Array/Int16Array 存储，热循环内零 GC。30,000 格网格每 tick 完整扫描一次，渲染层直接写 ImageData，p95 < 4ms。

🛠

元素注册表驱动

48 种元素的所有参数（颜色、密度、行为、flags）集中在一个 JSON 注册表中。TypeScript 枚举由脚本自动生成，确保"唯一事实源"——改注册表一处，代码自动同步。

🔒

确定性 Hash 测试

每个物理快照可用 FNV-1a 计算 hash。测试用固定 seed + 输入时间线 + hash 断言，确保任何代码改动都不会悄悄改变物理行为。
