生活剧本杀
在 AI 剧情里，预演你的人生

当朋友来借 5 万、当同事甩锅给你、当父母第七次催婚 —— 你怎么说？

赛道生活娱乐 × 学习工作（跨界） 形式纯前端 Web + LLM API 难度★★★★☆ 周期MVP 5 天 / 完整版 12 天

1产品定位

1.1 一句话定义

「人生预演沙盘」 —— 把生活中"说不出口、不知道怎么开口"的真实困境，做成 5-10 分钟的轻量剧本杀。用户扮演自己，在 AI 驱动的剧情中尝试不同话术，结束后得到一份沟通分析报告。

1.2 解决的问题

真实痛点现有方案我们的差异化
不知道怎么拒绝别人搜公众号文章，看完还是不会在剧情里实际演练一次
职场冲突不会处理看职场课，情境不同用不上剧本就是你的真实场景
亲子/亲密关系紧张心理咨询贵、约不上5 分钟试 3 种说法，看后果
说话总是得罪人凭感觉、事后后悔AI 实时反馈「这句话的影响」

1.3 目标用户

  • 核心：18-35 岁职场新人 + 大学生 + 社恐人群
  • 延伸：35-50 岁父母（亲子沟通）、被催婚/催生人群、初为管理者
  • 公益属性：青少年沟通能力训练、亲子关系修复

2核心玩法

2.1 用户旅程（5 步）

① 选剧本（场景库） ↓ ② 看背景（角色、时间、前情提要） ↓ ③ 进入剧情（AI 扮演对手 / 旁观者，每轮给 3-4 个选项 + 自由输入） ↓ ④ 实时反馈（每轮对话后，HUD 浮窗显示「亲密度 / 压力值 / 信任度」变化） ↓ ⑤ 结束报告（沟通分析 + 最佳路线回放 + 改进建议）

2.2 一个完整剧本示例

剧本名：《朋友来借 5 万块》
角色：你（朋友 A）+ 老同学 B
场景：咖啡馆，下午 3 点
前情：B 之前找你借过 2 次钱，都还了。这次说生意周转，3 个月还。
关系起点：亲密度 70 / 信任度 80 / 压力值 10
目标：维护关系 + 守住自己的钱 + 不内疚

对话轮次（共 5 轮）：

  1. B 开口诉苦 → 你选回应方式
  2. B 提到具体数字 → 你表态
  3. B 加码（能否多借点）→ 你选坚持 / 妥协
  4. B 打感情牌 → 你回应
  5. 结局收尾 → 你怎么收场

结局分支：

  • 完美：借一部分 + 写借据 + 关系不变
  • 一般：借了 / 没借但关系降温
  • 翻车：钱借出去 / 朋友翻脸

2.3 三个内置剧本（MVP 必做）

剧本场景难度戏剧冲突

4技术方案

4.1 技术栈

  • 前端：纯 HTML + CSS + JavaScript（单文件可运行）
  • AI：第三方 LLM API（DeepSeek / 通义千问 / 智谱 GLM-4，性价比高）
  • 存储：localStorage（用户历史记录）
  • 可视化：原生 SVG / Canvas（雷达图、折线图）
  • 状态管理：原生 JS 状态机

4.3 关键 Prompt 设计

角色扮演 Prompt（核心）

PROMPT 
你现在扮演 [角色名]，[角色背景]。
性格：[性格特点]
说话风格：[语言习惯，比如"口头禅是 XX"]
当前关系值：亲密度 X / 信任度 Y / 压力值 Z
前情提要：[剧本背景]

对话规则：
1. 每次回复 1-3 句，模拟真实口语
2. 根据用户的"关系值"调整态度
3. 不要主动给建议，你就是角色本身
4. 如果用户的话术有攻击性，关系值会下降
5. 输出格式必须是 JSON：
   { "reply": "你的台词",
     "moodChange": { "intimacy": 0, "trust": 0, "pressure": 0 } }

报告生成 Prompt

PROMPT 
基于以下对话历史，从 5 个维度评分（0-100）：
1. 立场清晰度：是否明确表达了自己的边界
2. 共情表达：是否让对方感到被理解
3. 节奏控制：是否在关键时刻推进或暂停
4. 替代方案：是否给出了可执行的替代选项
5. 关系维护：是否避免了不必要的伤害

输出 JSON：
{ "scores": {...}, "highlights": [...], "improvements": [...] }

8风险与应对

风险应对方案
LLM 回复太慢流式输出 + 打字机效果 + 加载动画
LLM 输出格式不对JSON 校验 + 自动重试 + 降级到预设回复
API 费用选用 DeepSeek/智谱 Flash 等便宜模型，单次对话 < 0.1 元
用户填错 API Key提供 mock 模式（内置预设对话树，零成本体验）
剧本内容争议选择普世困境，避免政治/宗教敏感话题
