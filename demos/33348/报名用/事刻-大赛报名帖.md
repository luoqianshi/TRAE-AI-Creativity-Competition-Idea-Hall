【标题】【学习工作赛道】事刻（TimeTrace）——多视角事件叙事工具

【标签】学习工作

【正文】

## 一、创意名称 + 创意介绍

**创意名称**：事刻（TimeTrace）

**创意介绍**：事刻是一个「关系驱动的事件叙事工具」。当你想要搞清楚"某个事件从哪里来、引发了什么、换个角度又怎么看"时，现有工具很难帮到你——笔记是平面的，时间线工具只有一条线，思维导图没有时间轴。事刻 2.0 创新性地采用**共享时间轴 + 多列轨道 + 关系边**三层架构：左侧时间轴是所有列的绝对基准，每一列是一条叙事线，事件按时间垂直排列；叙事族把相关叙事线归为一组；更关键的是——事件与事件之间还有一层"关系边"，一条叙事线可以从任意事件节点"分叉"出新的分支列——因果分支用于还原产业链传导，平行分支用于展现不同维度的解读——从而将复杂事件的多元因果关系和多视角解读统一呈现在一个可交互的画布上。

**想解决什么问题**：在AI行业快速发展的今天，一个关键事件（如DeepSeek V3开源）会同时引发价格战、监管反应、技术跟进等多条连锁反应。现有工具无法在同一视图中清晰呈现这些因果链和多维叙事——用户需要在多个笔记、文章、工具之间反复横跳拼凑全貌。

**为什么会想到做这个**：在研究AI行业演进时，我发现任何一个里程碑事件都不是孤立存在的，但现有工具都默认"一件事只有一个故事"，这违背了真实世界的复杂性。我希望做一个工具，让"事件 → 因果链 → 多视角"的认知过程变得可视化、可交互。

**产品形态**：Web 网页应用（桌面端 + 移动端双视图），前端 HTML + 独立数据文件（data/ 文件夹）。

## 二、目标用户及痛点

**目标用户**：
- **行业研究者/分析师**：需要梳理AI、科技、金融等领域的复杂事件演变
- **知识工作者**：阅读行业新闻时需要理解事件之间的因果关联
- **产品经理/策略人员**：需要对比不同竞争者的技术路线和决策逻辑
- **科技爱好者/学习者**：想系统性理解某个领域的发展脉络

**使用场景**：
- 行业研究：梳理"DeepSeek V3开源 → API价格雪崩 → 字节跟进 → OpenAI降价"的完整因果链
- 技术追踪：以时间轴对齐的方式对比OpenAI与DeepSeek两条技术路线的演进节奏
- 政策分析：从"法规发布 → 企业合规 → 执法实践"的事件链理解AI治理进展
- 学习理解：通过多视角（技术、商业、政策）对比理解行业全貌

**当前痛点（缺失事刻时）**：
- 用笔记/Wiki记录，时间是平面属性，看不到事件之间的先后关系和因果传导
- 用时间线工具（如TimelineJS）只能画一条线，无法表达分支和不同视角
- 用思维导图可以分支，但没有时间轴对齐，事件的时间先后关系完全丢失
- 用户需要在多个工具和资料之间反复跳转，靠脑力拼凑全局认知

## 三、价值与意义

**效率提升价值**：
事刻将"阅读多篇文章 → 脑补因果链 → 手动画时间线 → 整理多视角"的认知过程压缩到一个交互视图中。用户不再需要在不同窗口间反复横跳，一个画布即可完成"追根溯源（事件因果链）→ 深度钻研（嵌套分支细节）→ 换个视角（跨叙事跳转对比）→ 掌握全貌（扫读+收束）"的完整体验。按行业研究者的日常，这可能将事件分析效率提升3-5倍。

**社会价值**：
在信息过载和"后真相"时代，公众理解复杂事件（如AI政策演变、科技竞争）的成本极高。事刻提供了一种"看见完整故事"的工具——不是简化，而是可视化复杂性本身，这有助于提升公众的信息素养和批判性思维能力。

## 四、创意产物

**事刻 2.0 HTML 原型文件**：`事刻-prototype-v2.html`（本作品已上传社区，打开 HTML 即可在浏览器中直接体验全流程交互。

该原型完整实现了：

- **关系驱动的叙事引擎**：4 个叙事族（DeepSeek 体系、OpenAI 体系、全球 AI 政策、字节跳动 AI 体系），11 条叙事线，事件节点与关系边分离存储
- **双视图切换**：画廊视图（叙事族广场 + 叙事线卡片）+ 时间线视图（共享时间轴 + 多列轨道）
- **共享时间轴 + 多列轨道**：主叙事列可展开因果/平行分支列，列间通过日期严格对齐
- **分支展开面板**：点击 [+N分支] 展开新列，分支终点以虚曲线汇合回主线
- **跨叙事跳转**：同一事件在不同叙事线间的关联跳转（如 R1 发布 ↔ GPT-4）
- **关系边类型**：MAIN_SUB（主-子）、DERIVED（派生视角）、COMPARE（对比视角）四类边类型
- **Popover 浮层详情**：事件摘要、叙事解读、关联分支、跨叙事引用
- **Hover 联动高亮**：鼠标悬停分支列头 → 源事件节点脉冲高亮 + 连接线加粗变色 + 因果/平行标签浮现
- **嵌套分支**：支持二级分支展开
- **迷你地图**：时间轴导航
- **时间跳跃标记**：超过40天无事件显示"X天后/X个月后"
- **世界级视觉重构**：暖色调色板、多层阴影系统、充足留白与节奏、Poppins/Lora 字体排版、微交互动画
- **移动端适配**：底部抽屉、触摸友好、单列移动端交互视图

共计 **300+ 事件**、**11 条叙事线**、**4 个叙事族**、**多组关系边**，可在浏览器中直接打开体验全流程交互。
