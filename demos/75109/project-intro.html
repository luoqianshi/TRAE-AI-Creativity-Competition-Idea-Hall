USER ROLES

用户角色权限

三级用户体系，严格的权限划分，保障社区生态安全。

🏠
认证住户
核心用户 · C端

手机号+实名+住所双重认证，享受全部社区服务权限。

  • ✓ 浏览、购买平台全部服务与产品
  • ✓ 发布二手交易、便民服务、个人增值服务
  • ✓ 对所有产品/服务进行匿名评论
  • ✓ 参与小区团购、邻里互动
🏪
认证商家
B端用户

上传营业执照、门店实景照片、经营许可证，绑定服务小区。

  • ✓ 发布跑腿、代买菜、送餐、社区团购
  • ✓ 接收用户订单、履约服务、处理售后
  • ✓ 查看用户匿名评论，可合规申诉
  • ✗ 不可发布个人职业类增值服务
👤
未认证游客
受限浏览

仅可浏览首页公开内容，无法进行任何互动操作。

  • ✓ 浏览首页页面
  • ✗ 无法查看详细产品信息
  • ✗ 无法下单、发布内容、评论
  • ✗ 无法参与任何社区交易互动

CORE HIGHLIGHTS

核心亮点总结

四大产品核心亮点，构筑差异化邻里生态。

01

强真实社区闭环

住所+实名双重核验，纯粹邻里生态，规避外部人员乱象。 安全性远高于通用生活平台，一户一号规则防恶意注册。

02

服务生态完整

覆盖刚需便民、闲置交易、个人职业增值服务， 满足住户日常全场景需求，标准化与个性化并存。

03

差异化邻里资源

盘活住户个人职业资源，打造小区专属内部优惠。 强制审核4项资料，资质公示板全公开，实现邻里互惠共赢。

04

透明监督机制

增值服务资质、定价、市场价全公开，全品类匿名评论。 前台匿名显示、后台留存可溯源，保障用户知情权与监督权。

🔐 风控规则

  • ✓ 真实性风控：无资质、无定价对比材料的个人增值服务一律禁止上架
  • ✓ 内容风控：AI敏感词审核+人工复核，杜绝涉黄、涉诈、辱骂内容
  • ✓ 交易风控：订单记录、沟通记录、履约凭证全留存
  • ✓ 合规管控：禁止金融诈骗、虚假宣传、违规产品
  • ✓ 定期复核：每年度自动复核住户住所、商家经营资质
  • ✓ 一户一号：一套住房仅可绑定一个主账号
