一、创意名称与介绍

🎯 解决什么问题

产品经理做用户研究时，绘制旅程地图需要手动整理大量访谈数据、凭经验推测情绪曲线，耗时 2-3天 且容易遗漏关键痛点。

💡 灵感来源

作为 PM，每次写 PRD 都要花大量时间做旅程分析。LLM 的链式推理能力恰好适合这种"结构化思考→细节填充→情感评估"的流水线任务。

📦 产品形态

Web 应用（AI SaaS 工具），输入产品名+用户画像即可一键生成可视化旅程地图，支持人工纠偏和导出交付物。

核心价值主张：将 2-3 天的旅程地图绘制工作缩短至 8秒，AI 完成 80% 的体力活，让 PM 专注于 20% 的专业判断。

二、目标用户及痛点

👥 目标用户

产品经理 UX 设计师 用户研究员 创业者 产品实习生

🎬 使用场景

  • 需求评审前快速生成用户视角分析
  • 竞品体验对比分析
  • 向 Stakeholder 汇报用户洞察
  • 教学场景：学习用户旅程方法论

🔥 当前痛点

  • 手工绘制耗时 2-3 天，效率低下
  • 情绪曲线主观性强，缺乏数据支撑
  • 容易遗漏关键用户痛点和机会点
  • 现有工具需要逐项填写，无 AI 推理辅助
  • 导出格式单一，难以直接用于汇报

三、价值与意义

  • 效率提升：将传统 2-3 天的工作量缩短至 8 秒，效率提升 99%
  • 质量保障：链式推理确保情绪曲线平滑，相邻阶段差值 ≤ 3，避免跳跃和幻觉
  • 人机协作：AI 做体力活，PM 做判断，支持人工纠偏和局部重绘
  • 商业价值：可作为 SaaS 产品嵌入协作工具，提供 API 和企业部署方案
  • 教育价值：帮助新手 PM 快速掌握用户旅程地图方法论

四、核心功能与技术亮点

🧠 V2 链式推理（核心亮点）

4 步串行推理：阶段拆解 → 行为痛点填充 → 情绪机会评分 → 汇总图表生成。每步有独立 Prompt 和中间产物，可追溯、可调试。

⚡ SSE 流式输出

实时推送 4 步进度，前端展示思考时间线，用户不再面对黑盒等待，建立产品信任感。

✏️ 人工纠偏 + 局部重绘

支持滑块拖拽调整情绪分数，修改后仅重算后续阶段，保持曲线连续性，体现"AI 辅助而非替代"理念。

📊 V1+V2 对比模式

同屏展示单次生成与链式推理的差异，用数据证明方法优劣，适合面试演示和方法论验证。

💾 语义缓存

基于 product+persona 的 MD5 匹配缓存，重复查询直接命中，降低 API 成本。

📤 一键导出

支持导出 Markdown 报告和 2x 分辨率 PNG 截图，直接用于汇报和交付。
