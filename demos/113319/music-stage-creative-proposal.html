01 创意介绍

想解决什么问题：本地音乐播放器长期沦为"听响"工具，缺乏与音乐情绪同步的视觉氛围；流媒体视觉方案依赖订阅、有网络延迟、数据上云。

为什么会想到做这个：很多乐迷把听歌当背景活动，但好音乐值得被"看见"。想为本地珍藏曲目重建演唱会般的仪式感，又不必交出隐私或钱包。

是什么产品：一个基于 Web Audio + Canvas 的渐进式网页应用——七个音频引擎统一于单 rAF 时钟的私人音乐舞台。

02 目标用户与场景

面向谁：注重听觉审美的本地乐迷、厌倦千篇一律播放器 UI 的深夜收听者、珍藏实体唱片的数字原住民。

用在哪：深夜书房独处、望向窗外的放空时刻、阅读时的氛围垫底——任何你值得一场私人演出的瞬间。

什么痛点：传统播放器只有二维波形或频谱，无法营造三维空间感；流媒体可视化让渡了数据主权。

03 七个引擎 · 一个舞台

所有运动由单一弹簧时钟驱动，所有读数从一根 AudioSignal 总线分蘖——不线性、不上传、不订阅。

◉

Vinyl Stage

惯性唱盘、五态唱臂编排；低频让盘面呼吸，高频擦亮流动高光。

◎

Lyrics Stage

歌词在景深中推镜浮动，换行是焦点转移，模糊量化为 4 档弹簧切换。

◈

Ambient Stage

呼吸渐变、频带光斑、环形舞台灯；节拍环、胶片颗粒、三层尘埃。

◇

Camera Engine

指针视差、副歌推近、空闲李萨如漂移——输出 --cam-* 给全站。

◆

Artwork Engine

封面管线：ID3 / FLAC → IndexedDB → iTunes → CAA → 生成兜底黑胶标。

◊

Particle Engine

三层景深尘埃自然游走、节拍冲量、Treble 闪烁微光；Sprite 缓存 0 内存泄漏。
