01

普通攻略 · 通用 AI · Game Skill Forge

三种方案在「知道你在哪」「回答够不够准」「能不能引用来源」三个维度上的真实差异。
传统攻略

Wiki / 论坛 / 视频

  • 不知道你当前等级、装备、进度
  • 默认你已经满足前置条件
  • 版本更新后旧攻略可能不适用
  • 需要自己在几十页内容里筛选
  • 回答泛化,卡关依旧卡关
通用大模型

GPT / 通用助手

  • 无法持久记住你的游戏档案
  • 容易胡编路线和 Boss 信息
  • 不知道你具体缺哪种资源
  • 无法标注引用来源片段
  • 回答像是"标准答案",不落地
Game Skill Forge

记住进度的本地技能包

  • 维护玩家进度档案(等级/装备/卡点)
  • 专属知识库 + 可点击追溯的引用片段
  • 根据当前状态生成"可执行"路线清单
  • 优先本地小模型,游戏数据不上云
  • 卡关、配装、资源规划一次性解决

03

技术流程:一条数据管道

从游戏资料导入到个性化攻略生成,全链路可在本地完成。
1

用户资料输入

粘贴 Wiki / 论坛 / 笔记 / 网页内容,支持 Markdown、HTML、纯文本。

2

游戏知识库

分块 + 向量索引,按「任务 / Boss / 装备 / 区域」四象限检索。

3

玩家进度档案

YAML 记录:等级、装备、已完成任务、卡点、目标时间窗。

4

本地小模型

RAG + 结构化输出(JSON Schema),确保回答可追溯、可重算。

5

个性化攻略

输出路线、配装、资源、风险四个模块,并带引用片段。

04

技术路线：从游戏知识库到个性化技能包

两阶段演进,让本地小模型逐步成为真正懂你的专属游戏助手。
1

本地 RAG 阶段

本地小模型 + RAG 检索,融合 Wiki / 论坛攻略与玩家当前进度,生成个性化建议。

2

LoRA / QLoRA 阶段

轻量微调能力,将游戏回答风格、规划模板和玩家偏好沉淀为可复用技能包。

3

专属游戏助手

不同游戏、不同玩家的经验均沉淀为本地技能包,真正实现"装上就能用"。

产品第一阶段采用本地小模型结合 RAG 检索,让模型根据游戏 Wiki、论坛攻略和玩家当前进度生成个性化建议。
后续可加入 LoRA / QLoRA 微调能力,将某一款游戏的回答风格、规划模板和玩家偏好沉淀为轻量级技能包,让本地小模型逐步变成专属游戏助手。
