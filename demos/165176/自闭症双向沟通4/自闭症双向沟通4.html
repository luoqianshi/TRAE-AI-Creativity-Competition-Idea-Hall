自闭症双系统双向沟通翻译工具 Demo V3 · 自定义视觉符号 + 听觉安抚素材

核心范式：双系统不融合 · 低层感知协议 · 双向翻译

本 Demo 完全依据论文《Dual-System Communication Model: A New Bidirectional Paradigm for Autism Spectrum Disorder Based on a Shared Low-Level Perceptual Protocol》构建：将自闭症心智（系统 A）与神经典型心智（系统 B）视为两套独立、平等但底层逻辑不同的信息处理系统，不要求任意一方改造，而是借助 颜色 + 三种基础几何图形 + 纯器乐音乐 三类跨人群共享的低层感知信号，作为中立的中间通用协议（physical-layer consensus），完成 A↔B 双向情绪—强度—唤醒度翻译。本版将图形层收敛为最底层的三态感知协议：圆形代表心情最好 / 安全放松，方形代表中等 / 可控边界，三角形代表最尖锐 / 高应激预警。

演示链路

  • 儿童端：点击 红 + 三角 + 快鼓 → 家长端弹出「濒临崩溃」预警 + 干预建议。
  • 家长端：点击「等待 5 分钟」 → 儿童端全屏变蓝 + 方形稳定边界 + 舒缓钢琴音乐。
  • 所有交互写入情绪日志，可一键导出 CSV，用于家庭 / 学校 / 临床复盘。

V3 新增功能

  • 视觉符号自定义：家长可为圆形 / 方形 / 三角形上传自定义图片，替代默认 SVG，以适配孩子熟悉的视觉符号体系。
  • 听觉安抚素材：家长可上传或录制安抚音频；当系统检测到孩子发送高应激信号时，可自动播放安抚音源。

技术与价值

  • 无需昂贵脑机接口或可穿戴硬件，普通手机 / 浏览器即可运行。
  • 规则驱动确定性映射（无 AI 黑箱），完全可解释、可审计。
  • 无胁迫、无惩罚、无错点击，降低自闭症儿童感官过载与情绪崩溃风险。
  • 可扩展至 ADHD、失语症、ICU 患者、老年认知障碍等沟通受限人群。

① 视觉符号自定义

为孩子上传熟悉的视觉符号图片，替代默认几何图形。上传后儿童端图形选择器将优先显示自定义图片。图片保存在本地浏览器中。

③ 协议含义自定义

每个孩子对颜色、图形、音乐的感受可能不同。您可以在此修改每种颜色代表的情绪、每种图形代表的意图、每种音乐代表的唤醒度描述。自定义后的含义将替换系统默认显示，原始协议数据（色值、图形形状、音乐参数）不变。数据保存在本地浏览器中。

④ 听觉安抚素材

上传或录制一段安抚音频（如家长温柔语音、白噪声、舒缓音乐）。开启自动播放后，当系统检测到孩子发送高应激信号时将自动播放安抚音源。
