// Features
核心功能
01

持仓导入多源支持

手动输入基金代码/股票代码、截图识别持仓页面、对接券商 API 自动同步。无论你用什么方式管理投资，都能导入分析

02

底层穿透分析

自动穿透基金的持仓结构，获取前十大重仓股、行业配置、债券久期等底层信息。你知道你买的基金到底持有什么

03

相关性热力图

计算所有持仓两两之间的相关系数矩阵，用颜色深浅直观展示。一眼看出哪些资产"同涨同跌"

04

风险维度雷达图

从集中度、行业分布、地域分布、资产类别、市值风格五个维度评估，生成雷达图让你看清组合的风险轮廓

05

模拟调仓工具

"如果我卖掉这只基金，换成那只会怎样？"模拟调整前后健康度变化，帮你做出更明智的决策

06

定期健康报告

每月自动生成持仓健康报告，追踪风险指标的变化趋势。持仓集中度在上升？行业暴露在偏移？第一时间发现
