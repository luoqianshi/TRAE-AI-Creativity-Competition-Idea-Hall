Project Overview

// 项目概述

创意灵感来源 —— 源自《钢铁侠》中贾维斯（JARVIS）式的 AI 管家：一个始终在线、冷静睿智、拥有全息界面的数字伙伴，让「对话即操作」成为桌面本能。

解决的问题 —— 传统桌面交互割裂：窗口、任务栏、AI 工具各自为政，信息需主动查找、操作需手动切换。JARVIS 将 AI 融入系统底层，消除应用墙与工具孤岛，把「想到」直接变成「得到」。

产品形态 —— 一个运行于 Windows 的科幻桌面外壳，以全屏 HUD 替代原生桌面，AI 成为桌面本身；其余应用程序仍正常运行于其上层，不破坏既有工作流。系统运行于高性能移动工作站（旗舰级CPU+16GB VRAM独显+32GB DDR5内存），本地模型与 HUD 全程在本机运行，隐私不出本机。

Core Features

// 核心功能

全双工语音对话

本地 MiniCPM-o 4.5 模型实时响应，支持 BARGE-IN 随时打断；语音 / 视觉双通道输入，对话不再需要「按下说话」的停顿。

科幻 HUD 仪表盘

30 层动态扫描环构成中央视觉核心；左栏系统监控、右栏时间 / 天气 / 日历 / 通知，一屏全览所有关键信息。

智能 Dock 栏

自动同步桌面快捷方式，IShellItemImageFactory 提取 256px Jumbo 高清图标；5 种进程状态实时监控（未运行 / 运行中 / 启动中 / 前台 / 无响应）。

Soul-seed 人格记忆

四类长期记忆（情节 / 语义 / 关系 / 程序），越用越懂你；主动感知系统异常并在第一时间提醒，而非被动等待指令。

System Architecture

// 系统架构
flowchart TD subgraph UI[用户界面层] A1[jarvis.html · WebView2 全屏渲染 HUD] end subgraph OR[编排层 · Bridge] A2[IntentClassifier → ChannelRouter → StateMachine] end subgraph AI[AI 双通道层] A3[快通道 · llama-omni-server 本地 MiniCPM-o 4.5] A4[慢通道 · 云端大模型 + 联网搜索 + 长期记忆] end subgraph HO[宿主层 · C# / .NET 8] A5[WorkerW 嵌入 · MetricsCollector · DockProcessMonitor · DesktopAppSync · 看门狗 · APG + MG] end UI --> OR OR --> AI AI --> HO A3 -. 实时 / 隐私不出本机 .-> OR A4 -. 深度 / 复杂任务 .-> OR
⚡ 快通道（实时）

本地 llama-omni-server 直驱 MiniCPM-o 4.5，全双工语音对话，首包延迟 <500ms；语音与视觉仅在本机处理，隐私不出本机。

🧠 慢通道（深度）

云端大语言模型（OpenAI兼容API，支持自定义替换）负责深度推理，联动联网搜索与长期记忆；复杂任务由编排层自动路由至此。

Technical Highlights

// 技术亮点

双 AI 通道路由

实时 / 深度自动切换，意图 classifier 与唤醒词协同决策。

自适应性能调度 APG

五档渲染质量动态调整，检测到游戏 / 独占全屏时自动降帧释放 GPU。

内存治理层 MG

高负载时自动挂起 WebView2，渲染进程物理内存由 ~500MB 降至 <40MB。

DesktopAppSync 图标同步

IShellItemImageFactory 提取 256px Jumbo 高清图标，FileSystemWatcher 实时同步。

WorkerW 桌面层嵌入

替代原生桌面并落入桌面底层，其余应用正常浮于上层，互不干扰。

看门狗保底机制

宿主崩溃时自动恢复原生桌面与任务栏并通知用户，永不锁死系统。

Project Value

// 价值与意义

效率价值 —— AI 融入系统底层，无需切换应用，想到即说、说到即得。信息从「主动查找」转变为「被动接收」，把桌面从操作对象升级为协作伙伴。

范式价值 —— 探索未来人机交互的可能形态：AI 不再是一个被调用的工具，而是有记忆、有人格、能主动关怀的数字伙伴，为下一代操作系统提供一种可想象的蓝图。
