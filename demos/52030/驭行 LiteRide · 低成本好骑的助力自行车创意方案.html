01

创意名称与介绍

创意名称：驭行 LiteRide。“驭”取驾驭、掌控之意——人始终是骑行的主导者；“Lite”代表轻量、低成本、无负担；“Ride”是骑行的纯粹乐趣。合在一起，就是一台让人轻松驾驭、保留骑感的轻量助力自行车。

想解决什么问题

市面上没有既低成本又好骑的助力自行车。普通自行车上坡、起步吃力；而电动自行车虽然省力，却完全丧失了“骑行”的质感——它更像一台带脚踏的电动车，骑感笨重、车体沉、且很多场景下不属于“自行车”路权。我们想填补中间这块空白。

为什么会想到做这个

本人是一名自行车爱好者，也是一名硬件工程师。长期骑行中，我深刻体会到上坡与起步时的体力负担；而当我尝试市面上的助力自行车时发现——要么不好骑，要么价格高。在对助力车的主要构成（车架、力矩传感器、中置电机、控制器、电池、显示交互）逐一拆解分析后，我发现：用合理的硬件选型与自研控制算法，完全可以在控制成本的同时做出骑行感受良好的助力车，于是决定亲手造一台。

大概是什么产品

最终产品是一台电助力自行车（Pedelec）：以人力踩踏为主，电机按踩踏力度实时提供比例助力。它外形接近一辆自行车，重量更轻；内置中置电机 + 力矩传感器，起步、上坡时电机无声介入，平路巡航时几乎感知不到电机的存在。整车目标售价控制在 3000 元以内，约为进口中高端助力车价格的一半[1]。

02

目标用户及痛点

A

骑行爱好者

热爱骑行、对“骑感”有要求，但希望长距离与爬坡时更轻松的广大车友。

B

通勤族

日常 5–15km 通勤，不想到公司一身汗，又嫌弃电动车笨重难骑的人群。

C

周末骑游者

周末郊游、休闲骑行，追求健康环保出行方式的城市居民。

使用场景

日常通勤和外出骑行都可以。城市早晚通勤中，起步红灯多、天桥坡道多，助力让骑行不再气喘吁吁；周末郊游爬坡、逆风时，比例助力延续骑行乐趣而不至于劝退；短途取物、校园代步，轻便的车身也比电动车更灵活、更好停放。

社会价值

从社会价值上说，此产品是科技和人的结合。它不取代人的骑行，而是用智能硬件恰到好处地延伸人的体力，鼓励更多人走出车厢、重新骑上自行车，符合低碳环保的理念。每多一台被骑行的助力自行车，都是对城市拥堵与碳排放的一份微小改善——让“骑得动、骑得远、骑得爽”成为日常。

“让科技隐于骑行，让骑感回归纯粹。”

这是驭行 LiteRide 的产品哲学：硬件交互的最高境界，是用户几乎感知不到硬件的存在。

04

硬件交互方案

本创意归属于“硬件交互”赛道。骑感好坏，本质上取决于人 → 传感器 → 控制器 → 电机这条交互链路的响应是否自然。以下是驭行 LiteRide 的核心硬件交互架构：

图 3 · 驭行 LiteRide 硬件交互闭环：踩踏力度被实时感知，电机按比例输出助力，形成“人机协同踩踏”。

关键交互部件

①

中置力矩传感器

安装在五通轴，实时采集骑行者踩踏扭矩（1:250 力矩倍率）。这是“好骑”的核心——决定助力何时来、来多少，让电机跟着人的发力节奏走。

②

中置电机 + 控制器

250W 中置电机经减速驱动曲柄，助力通过链条传递，而非直接驱动轮子，因此保留真实的脚踏骑行质感。MCU 运行自研比例助力算法，响应延迟 < 50ms。

③

车把显示交互模组

小巧 OLED 显示当前档位、实时助力比、剩余续航；三档助力（经济 / 标准 / 运动）一键切换，是人与车之间最直接的硬件交互入口。

“好骑”是怎么定义的

好骑 = 跟脚。踩多少、助多少，起步柔和不窜，上坡有力不闷，停止踩踏则电机立刻停止——没有“拖拽感”与“突兀感”。这依赖力矩传感器的高速采样与控制算法的平滑曲线，也正是低成本竞品最容易偷工减料、导致“不好骑”的地方。我们坚持把力矩传感器作为不可妥协的标配。

05

低成本是如何做到的

“低成本”不等于廉价堆料，而是把成本花在决定骑感的关键部件上，在非关键处做减法。我们对 BOM 做了细致拆解与选型：

降本策略

α

标准化车架平台

采用成熟标准车架与传动套件，避免开模溢价，把预算让给电驱核心。

β

核心部件自研

力矩传感器与控制算法自研，电机选用成熟国产中置方案，性能/成本比最优。

γ

克制的电池规格

36V/10Ah 锂电满足 60km+ 助力续航即可，不为冗余容量买单，整车也更轻。

经测算，整车 BOM 约为 2000 元，叠加组装、渠道与合理毛利后，零售可稳压在 2999 元档——这是进口中端助力车价格的约一半，却保留了决定骑感的力矩传感 + 中置电机方案[1]。

06

落地路线

PHASE 1 · 概念验证

原型机搭建

选定车架平台，采购中置电机与力矩传感器，搭建第一台工程样机，验证“比例助力 + 跟脚”骑感。

PHASE 2 · 算法调校

助力曲线优化

多路况（平路 / 坡道 / 逆风）采集踩踏数据，迭代助力曲线，做到起步柔、中段顺、收力快。

PHASE 3 · 小批量试产

BOM 锁定与供应链

锁定 BOM 与供应商，小批量试产 50 台，邀请骑行社群内测，收集真实骑感反馈。

PHASE 4 · 量产上市

众筹与发售

以 ¥2999 档定位发起众筹，面向骑行爱好者与通勤族正式发售，持续 OTA 优化助力算法。

07

写在最后

作为一个骑车的人，我太清楚“好骑”二字的分量；作为一个硬件工程师，我也相信把对的技术放在对的位置，成本与体验并不对立。驭行 LiteRide 不是要造一辆更快的电动车，而是要造一辆让你愿意每天骑、骑得轻松、骑得开心的自行车。

低碳、健康、有骑感、买得起——这台低成本好骑的助力自行车，值得被造出来。
