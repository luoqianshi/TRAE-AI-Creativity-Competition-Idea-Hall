PROJECT OVERVIEW

项目简介

让AI成为每一位农户身边的"植物医生"

🪴

AI视觉识别引擎

当深度学习遇见智慧农业

绿智是一款专为温室大棚设计的农作物病虫害AI识别与防治助手。我们利用YOLO目标检测模型与千万级病虫害图像数据集，训练出高精度识别引擎，可在手机端离线运行，实现毫秒级识别响应。

产品面向温室大棚管理者与广大农户，解决传统农业中"病虫害难识别、乱用药、防治滞后"三大核心痛点。用户只需打开手机对患病植株拍照，系统即可自动识别病虫害类型、严重程度，并智能推荐最优防治与用药方案。

🌱 技术栈覆盖：YOLOv8 · NCNN移动端推理 · Chart.js可视化 · Android原生

CORE FEATURES

核心功能

三大核心模块，覆盖病虫害管理全流程

📸

拍照一键识别病害

打开手机摄像头对准患病植株，系统基于YOLOv8深度学习模型在0.3秒内完成病虫害识别，支持50+种常见农作物病害，精准定位叶片病斑位置。

🧠

AI智能推荐防治与用药方案

识别后自动匹配病虫害知识图谱，生成农药品类、稀释比例、施药周期等完整防治方案，并优先推荐低毒生物农药，减少化学农药滥用。

📊

大棚健康度历史折线图

按日/周/月自动统计大棚内病虫害发生频次，生成健康度趋势折线图，支持历史数据对比。当健康指数低于阈值时自动预警提醒。
