1产品定位

PhoneAgent 是一款跨平台（iOS + Android）的手机 AI Agent App。用户可自由配置任意第三方模型（OpenAI / Claude / DeepSeek 等），拥有长期记忆、知识库、文档解析、语音交互、自定义 Agent 角色。


iOS 用户享受完整的 AI 基础功能；Android 用户在此基础上额外获得系统级操控能力——让 AI 不只会聊天，还能真正帮你操作手机。

2技术栈

共享层~70%
TypeScript + Expo 负责 AI 聊天、LLM 调用、Agent 引擎、记忆、知识库、文档解析、TTS/ASR、图像生成、Sub-Agent。
Android 原生层~30%
Kotlin + Expo Module API 负责无线 ADB 连接、Shell 命令执行、屏幕截图与 UI 树解析、屏幕控制、悬浮窗、无障碍服务、通知监听。
iOS 层Expo 内置
直接使用 Expo 内置能力，获得全部 AI 功能，无需额外原生模块。
核心技术：通过无线 ADB（muntashirakon libadb 库）实现手机自配对，AI 可直接在手机端执行 Shell 命令、截图感知屏幕、操控 UI 界面，无需连接电脑，纯手机端独立运行。
