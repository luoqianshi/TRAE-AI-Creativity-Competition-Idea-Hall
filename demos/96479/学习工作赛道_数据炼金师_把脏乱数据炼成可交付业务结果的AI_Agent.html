1. 创意名称 + 创意介绍

它不是一个只会“清洗表格”的脚本，而是围绕业务目标交付结果的数据处理 Agent。

创意名称

数据炼金师：把脏乱数据炼成可交付业务结果的 AI Agent。

想解决什么问题

运营、财务、人事、销售、项目管理等岗位经常要处理格式混乱、字段不统一、规则分散的业务数据。传统方式需要人工写公式、做 VLOOKUP、查异常、整理图表和报告，慢且容易出错。

为什么会想到做这个

真实工作里的数据问题往往不是标准分析题，而是“文件很乱、规则不清、目标很急、结果必须能交付”。我希望用 Agent 理解业务目标，用确定性数据底座完成真实处理。

大概是什么产品

一个面向学习工作场景的智能数据处理 Web Agent 系统，同时支持 CLI 批处理和 API 接入。

2. 目标用户及痛点

目标不是替代专业数据团队，而是让高频办公数据处理变得更容易、更可靠。

面向哪些用户

运营、财务、人事、销售、项目管理、数据分析助理，以及没有专职数据工程师但经常需要整理业务文件的中小团队。

在什么场景下使用

清洗 Excel/CSV、合并多张表、检查异常、整理导入模板、从说明文档抽取规则、生成业务分析结论时使用。

当前痛点

  • 数据来源杂，文件格式多，字段命名不统一。
  • 业务规则散落在文档、模板、口径说明里。
  • 结果表常混入过程 sheet 和技术字段，业务用户拿到后仍然难用。

产品如何工作

从一堆文件到可交付结果，核心链路是 discover → plan → answer。

01 INPUT上传文件

Excel、CSV、PDF、DOCX、JSON Schema、导入模板。

02 DISCOVER理解数据

自动画像、识别字段、发现多表关系和质量问题。

03 PLAN生成计划

根据业务目标定位主表、关键字段、匹配关系和规则。

04 RUN确定执行

lookup、公式、规则校验、异常识别、质量评分。

05 EXPLAIN解释结果

输出关键异常、影响范围、建议动作和图表。

06 DELIVER交付产物

最终 Excel、复核清单、业务报告和审计包。

核心设计：AI 理解 + 确定性数据底座

数据炼金师不是让大模型直接改数据，而是让 AI 做理解和规划，让工程化引擎做可验证执行。

Agent 理解层

  • 理解用户自然语言业务目标
  • 定位上传文件中的表、字段和规则
  • 生成可审阅的 JobConfig 处理计划
  • 解释结果、风险和下一步动作
→

确定性执行层

  • 读取多格式文件并做数据画像
  • 执行 lookup、公式、清洗和规则校验
  • 生成异常复核、质量评分和图表
  • 保留审计追溯，避免黑盒改数据

最终交付什么

用户不需要看一堆过程表，优先拿到能直接使用和复核的问题结果。

REPORTbusiness_answer.html

业务结论、质量评分、关键异常、建议动作和图表。

EXCELfinal_result.xlsx

处理结果和问题说明，减少冗余 sheet 和技术字段。

REVIEWexceptions_for_review.xlsx

需要人工确认的问题记录，方便业务复核。

CHARTcharts/

异常分布、质量评分、匹配率等可视化分析。

AUDITaudit_package/

血缘、规则命中、字段变化和执行追溯，面向排查和验收。

3. 价值与意义

让数据处理成为更高效、更低门槛的办公能力。

效率提升

把人工半天甚至几天的数据理解、清洗、匹配、异常识别和结果整理，压缩成上传文件、输入目标、获取结果的流程。

降低门槛

不会写复杂公式、脚本或 BI 查询的业务用户，也能完成多表合并、规则校验、异常复核和业务结论生成。

工程化落地

项目已具备 Web 控制台、CLI、API、JobConfig 校验、确定性回退、审计追溯、Demo 和自动化测试。

让每一堆乱数据，都能被炼成一份看得懂、用得上、交得出去的业务结果。
