Part 01

创意名称与介绍

创意名称

「一人食 · 治愈小食堂」

想解决的问题

一个人在家，打开冰箱一堆食材不知道怎么做，外卖点来点去就那几家，做饭又怕做多了吃不完浪费。想吃点好的犒劳自己，结果对着菜谱刷了半小时还在纠结——最后泡了碗面。

为什么会想到做这个

每次加班到家快十点，肚子咕咕叫，打开冰箱只有半颗白菜、两个鸡蛋。想做点好吃的，不是翻菜谱翻到饿过头，就是做出来味道一言难尽。如果能有个"虚拟小厨房"，帮我看看冰箱里有什么、能做什么、怎么做，还能模拟出最适合一人份的暖心料理，那该多好。

产品形态

一个可以 DIY 虚拟厨房、根据冰箱库存智能推荐一人食食谱的互动网页。用户可以"打开冰箱"选择食材，系统自动匹配能做的一人份料理，并模拟烹饪过程——切菜声、煎炒声、咕嘟咕嘟的炖煮声，搭配温馨的暖色调氛围，打造属于自己的"深夜治愈小食堂"。

Part 04

核心功能设计

虚拟冰箱 · 食材管理

用户点击冰箱门打开，从预设食材库中选取家中现有的食材。冰箱界面模拟真实的冰箱隔层效果：

  • 15+ 常见食材：鸡蛋、番茄、米饭、面条、鸡腿、五花肉、豆腐、白菜等
  • 点击选取 / 取消：选中食材高亮显示，可重复选取增加数量
  • 智能感知：选取食材后自动触发推荐，不用手动搜索

智能食谱推荐

根据冰箱里的食材，智能计算能做哪些菜：

🧮

匹配度计算

每道菜需要哪些食材，与冰箱已有食材对比，显示匹配百分比

⏱️

多维排序

按匹配度、烹饪时间、难度、热量等多维度排序展示

🔍

缺少食材提示

还缺什么一目了然，也可以选择"不完美匹配"的菜谱

沉浸式烹饪模拟

  • 分步引导：每道菜拆解为3-5个步骤，逐条展示
  • 进度条动画：烹饪进度实时推进，每一步切换不同的烹饪表情和图标
  • 粒子特效：烹饪过程中飘出星星火花、香味粒子，完成时撒花庆祝
  • 完成提示：Toast 通知 + "今天也有好好爱自己"的治愈文案

料理勋章系统

  • 渐进解锁：完成第1道解锁"初次下厨"、第3道解锁"三菜达人"、第5道解锁"小厨神"、全部解锁"全收藏"
  • 可视化反馈：勋章从灰色解锁为彩色，弹出解锁动画和通知
  • 成就感驱动：鼓励用户多尝试不同菜品，提升烹饪技能

Part 05

数据与内容来源

食谱数据

初期内置10道经典一人食菜谱，覆盖多种烹饪场景：

  • 快手简单型：番茄炒蛋盖饭、葱油拌面、芝士吐司煎蛋（8-15分钟）
  • 家常舒适型：鸡蛋炒饭、白菜豆腐汤、日式酱油拉面（10-20分钟）
  • 进阶犒劳型：虾仁滑蛋饭、咖喱鸡肉饭、土豆炖五花肉（18-35分钟）
  • 暖心锅物型：简易寿喜锅（20分钟）

营养与热量估算

参考《中国食物成分表》和主流健康 App（薄荷健康、Keep 饮食等）的公开数据，结合一人份食材用量估算每道菜的热量范围。
  • 每道菜标注预估热量（千卡），帮助用户控制饮食
  • 烹饪时间按实际操作经验估算
  • 难度分级：简单（无需技巧）/ 中等（需基本刀工和火候掌控）

Part 07

技术实现路径

技术栈选择

  • 前端：HTML5 + CSS3 + 原生 JavaScript（无需框架，轻量易部署）
  • 冰箱交互：CSS 动画控制冰箱开合状态 + 点击事件管理食材选择
  • 食谱引擎：基于匹配度算法的纯前端逻辑（JS 数组操作与排序）
  • 动效：CSS3 Animations + JavaScript 粒子系统（无第三方依赖）
  • 数据存储：LocalStorage 保存用户烹饪记录和勋章进度
  • 部署：可发布到 GitHub Pages / Vercel / Netlify（免费）

总结

「一人食 · 治愈小食堂」是一个兼具实用性与情感温度的互动网页产品。它通过虚拟厨房的沉浸式体验，让独居青年能够：

  • 告别"不知道吃什么"的选择困难
  • 零成本试错，提升烹饪自信
  • 在每一次下厨中找到"好好爱自己"的仪式感
  • 减少食物浪费，培养健康的饮食习惯

在独居经济持续升温的今天，这个产品切中了大量年轻人的真实痛点——技术门槛适中、创意空间大、情感价值突出，非常适合作为生活娱乐赛道的参赛作品。
