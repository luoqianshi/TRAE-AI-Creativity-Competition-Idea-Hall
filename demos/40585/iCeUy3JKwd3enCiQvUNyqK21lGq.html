THE PROBLEM

从"信息抽取"到"知识织网"

现有工具只能抽取扁平实体列表，无法自动发现跨文档深层关联。GraphWeaver用多Agent协作+RAG检索实现自动化的"读取→抽取→关联→建图"闭环。

✕

传统要素提取

需预设Schema → 按类型逐个抽取 → 得到扁平列表 → 人工建图。无法发现Schema外的实体，无法自动建立关联，跨文档同一实体无法消歧合并。

◆

GraphWeaver 织图

Schema-free抽取 → 多Agent协作流程 → 实体消歧合并 → 幻觉检测抑制 → 结构化输出。Agent通过RAG检索驱动多步骤协作，完成从文本到图谱的自动化转化。

MULTI-AGENT SYSTEM

五Agent协作架构

基于LangGraph状态机编排，5个专业化Agent各司其职，通过多步骤协作循环完成"读取→抽取→关联→建图→校验"的自动化流程。

◉
Coordinator
协调Agent
任务调度，评估当前图谱状态，决定下一步检索哪些资料，判断是否收敛终止。
⬡
Retriever
检索Agent
RAG混合检索引擎，向量+BM25+重排序三路召回，为Extractor提供精准上下文。
◈
Extractor
抽取Agent
基于Prompt的实体关系抽取，Schema-free输入，结构化JSON输出，记录来源分块。
⬢
Merger

三阶段实体消歧（精确匹配→Embedding相似度→LLM确认），解决跨文档同一实体不同称呼合并。

语义分块 Semantic Chunking

按语义边界切分而非固定长度，计算相邻段落Embedding相似度，在语义断点处切分，保留上下文完整性。分块大小256-512 tokens。

查询改写 Query Rewrite

Agent原始查询经LLM改写为3个变体：语义扩展（同义词）、关键词精确（专有名词）、关系导向（寻找关联），提升召回率。

RRF融合 Reciprocal Rank Fusion

无需分数归一化，仅基于排名融合。公式：score(d) = Σ 1/(k + rank_i(d))，k=60。简单有效，工业界标配。

Cross-Encoder重排 Rerank

Bi-Encoder负责快速召回，Cross-Encoder负责精准排序。bge-reranker-large对query-document对做深度交互，精度显著提升。
