01 / PROBLEM · 问题缘起

生活中有太多 选择题，
而我们只想快点 吃一顿饭。

每到饭点就是意志力的消耗战。打开外卖软件 → 滑动 10 分钟 → 还是没选好。这是城市生活中一个真实的「小烦恼」。
🌀

决策疲劳 · Decision Fatigue

面对上百个选项，越看越饿、越饿越纠结。意志力被小决策耗尽，真正重要的事却无从下手。

🗣️

社交博弈 · Social Loop

「随便。」「都行。」「你定吧。」 —— 团队聚餐的对话循环，永远在原地打转。

🧠

小事内耗 · Mental Overhead

周末去哪玩？今晚看什么电影？先做哪一项任务？这些高频小决策每天吞噬我们的带宽。

🎯

核心目标 · The Goal

让「随机」成为一种「仪式」 —— 把纠结的过程变成一次有趣的转盘互动，用不到 10 秒让命运和你的好运气帮你做选择。

02 / FEATURE MATRIX · 功能矩阵

一个核心玩法
加上 六个扩展维度。

从旋转物理到模板管理，每一个细节都经过产品思考，确保简单但不简陋。
F·01

物理转盘

基于 requestAnimationFrame 驱动，独立角速度 / 减速度，旋转约 3 秒内平滑停驻。

F·02

二级转盘

先选「大类」再选「具体项」—— 例如：外卖 → 螺蛳粉 / 黄焖鸡 / 比萨。

F·03

模板管理

内置「今天吃什么」模板，并支持用户自建 / 编辑 / 切换 / 删除。

F·04

表情 & 配色

每个选项自带 emoji + 自动着色；30 色调色板，保证相邻扇区对比明显。

F·05

本地持久化

localStorage + schema 归一化，模板数据跨会话保存，并兼容数据格式升级。

F·06

桌面 & 浏览器

Electron 打包 Windows 安装包（NSIS），同时也可作为网页直接打开。

STEP 01
启动

加载模板与当前选择，恢复上次状态。

STEP 02
旋转

点击按钮或按空格键，转盘加速至稳定速度。

STEP 03
停驻

点击「停止」触发匀减速模式，精准停在某一扇区。

STEP 04
二级

如选项有子转盘则进入下一层，否则弹出结果。

STEP 05
揭晓

弹窗呈现最终选择 ——「今天就吃它！」

04 / DESIGN VISION · 设计语言

深夜里依然
能看到一点 温暖的光。

深蓝夜幕 + 珊瑚红 + 暖金，像午夜小吃摊的那盏灯 —— 给人一点期待、一点暖意。
色彩

珊瑚红做主视觉，暖金做指针、冷蓝做代码，一张一弛，避免单调。

#ff6b6b#ff9f43#f4d03f#70a1ff
字形

Noto Serif SC 衬线做中文标题，Fraunces 做英文标题，JetBrains Mono 做代码。

动效

转盘匀速旋转 + 匀减速停驻；页面滚动渐入；按钮 hover 有上浮与高光变化。

响应式

桌面 500px 转盘 → 移动端 340px 收缩；栅格自动折叠，演示 / 手机都可用。

05 / HIGHLIGHTS · 项目亮点

让评委一眼
记住的 七个关键词。

从创意立意到技术执行，每一项都能单独拉出来做一分钟讲解。

不是「又一个 App」，
而是一次关于 日常仪式感 的尝试。

LuckyWheel 把最小的生活决策做成可把玩的小玩具。它不需要网络、不需要账号、不需要学习成本 —— 一打开就能转。

创意将选择困难变成幸运仪式，小工具承载大情感。
视觉纯 CSS conic-gradient 渲染转盘，零图片资源、零依赖。
动画rAF 驱动的物理模拟，旋转 / 停驻手感真实可预测。
架构Vue 3 + TS + Electron 的现代轻量组合，类型与持久化齐全。
扩展性模板系统让转盘不止是吃饭，而是通用决策工具。
数据schema 归一化 + 安全 JSON 解析，避免本地存储升级出错。
分发electron-builder 一键打包 Windows 安装包，即下载即使用。
体验空格键快捷键；可预测的交互节奏；玩起来有节奏感。
06 / ROADMAP · 未来方向

从 v1.0 出发，
有 六条清晰的下一步。

每一步都在为「让转盘更懂你」而服务。
v1.1

云端模板库

用户把自己的转盘模板分享给所有人 ——「周末去哪玩」「今晚看什么电影」「任务排序」。

  • 模板搜索 / 收藏 / 导入
  • 社区点赞与排行榜
v1.2

音效与振动

转盘旋转时发出「咔哒 · 咔哒」的节拍音；指针扫过扇区的微振动。

  • Web Audio API 节拍合成
  • 与当前角速度同步
v1.3

历史统计 · 偏好画像

记录过去一个月你吃了多少次黄焖鸡，生成个人「隐藏偏好」报告。

  • 数据可视化饼图
  • 周期性趋势分析
v1.4

移动端打包

迁移到 Capacitor / Tauri，同时打包 iOS 与 Android。

  • 原生手势交互
  • 小组件 / 快捷方式
v2.0

AI 灵感注入

接入大模型，根据当天天气、心情、近期选择记录，自动生成推荐选项。

  • LLM 生成创意选项
  • 上下文感知（天气 / 时间 / 位置）
v2.1

分享卡片 · 社交传播

一键生成转盘结果图片，分享到朋友圈：「今天我抽到了螺蛳粉！🎯」

  • 可自定义海报模板
  • 动画 GIF / 短视频导出
