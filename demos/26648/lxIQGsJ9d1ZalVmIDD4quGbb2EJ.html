💡 创意介绍

想解决什么问题：开发者在使用不同 AI 编程助手（Claude Code、Codex CLI、Cursor、Windsurf 等）时，每个工具有各自独特的系统提示词、规则文件和工作流配置，切换工具意味着重新适应，造成时间和精力的浪费。

为什么会想到做这个：我自己就在 Codex CLI 和 Claude Code 之间来回切换，每次都需要重新理解每个工具的规则体系和配置方式。我相信很多开发者都有同样的困扰。

产品形态：一个基于 Web 的 AI 编程规则翻译与管理系统，支持多平台规则互转、配置导出和团队协作。
