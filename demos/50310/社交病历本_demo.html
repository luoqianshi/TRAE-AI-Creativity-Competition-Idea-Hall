SYSTEM ARCHITECTURE

非标情绪的量化引擎

不是简单调用 API，我们构建了针对社交记录的混合解析架构

01

数据萃取层

采用端侧 OCR 与大模型协同解析，将非结构化的聊天截图或杂乱文本转化为携带时间戳、角色标签的标准化 JSON 数据流。

02

规则诊疗引擎

硬编码心理学指标基线。精确计算时延中位数、主动发起比率与信息熵，为模糊的“冷淡感”提供铁证，拒绝幻觉。

03

LLM 处方大模型

基于深层语境分析潜在的 PUA、情绪勒索与冷暴力倾向，将冷冰冰的数据翻译为具有人文关怀的“医疗处方”和社交分享卡片。
