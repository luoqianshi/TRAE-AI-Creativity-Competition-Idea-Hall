📱 核心功能特性

📊 智能屏幕分析

接入系统 ScreenTime API，自动获取各 App 使用时长，生成可视化报表，清晰展示数字生活习惯。

🎯 个性化目标设定

根据用户历史数据智能推荐屏幕时间目标，支持总时长限制和单 App 限额，循序渐进养成好习惯。

✨ 替代活动推荐

基于时间段和用户兴趣，智能推荐冥想、阅读、运动等替代活动，帮助用户填补戒断空白。

🏆 成就激励系统

gamification 设计，连续达标解锁成就，生成周报月报分享卡片，让自律变成一场有趣的游戏。

🧘 专注模式

一键开启专注模式，期间屏蔽娱乐 App，记录专注时长，帮助用户进入深度工作状态。

👥 社交挑战功能

和朋友组队参加排毒挑战，互相监督打卡，分享进步，让数字排毒不再是一个人的战斗。

⚙️ 技术实现方案

  • 数据获取： iOS 使用 ScreenTime API，Android 使用 UsageStatsManager，用户授权后自动获取 App 使用时长
  • 前端框架： React Native / Flutter 跨平台开发，一套代码适配 iOS 和 Android
  • 数据存储： 本地 SQLite 存储用户数据，云端同步支持多设备
  • 推送通知： 智能提醒系统，检测到超时使用自动推送温和提醒
  • 数据可视化： 使用 D3.js / Chart.js 生成图表和报告
  • 隐私保护： 所有数据本地加密存储，用户可选择是否云端同步
