牌桌把过去、现在与未来组织成一条可阅读的线索，让用户先看见自己的处境，再决定下一步行动。

USER FLOW

从一个问题开始，而不是从复杂提示开始。

应用把提问、选阵、抽牌、等待、翻牌、解读和追问连成完整闭环，降低用户表达门槛。

01 输入问题

用户把考试、人际、选择或情绪困惑写成一句具体问题。

02 选择牌阵

单牌适合快速启示，三牌适合梳理过去、现在、未来。

03 点击抽牌

牌背停顿、放大与翻转形成仪式感，让用户能看清牌面。

04 阅读解读

系统结合问题、牌位、牌义和正逆位生成更贴近处境的叙事。

05 连续追问

用户可围绕当前牌面继续提问，把一次娱乐体验延展为自我整理。

VALUE & BUILD

创意价值来自“仪式感”和“可继续对话”的结合。

VALUE 01

低压力表达

用户不必一开始就组织复杂需求，只需要写下一个真实问题，牌桌会帮助他把情绪和思路拆成可阅读的线索。

VALUE 02

沉浸式参与

手动抽牌、放大等待、正逆位展示和暗色金线视觉，让结果不是直接丢给用户，而是由用户参与完成。

VALUE 03

可持续扩展

Electron、React、TypeScript 与接口封装分层清晰，后续可继续增加历史记录、分享卡片、校园问答和更多主题牌桌。
