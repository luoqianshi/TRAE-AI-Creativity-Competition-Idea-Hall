01 / 创意介绍

为什么需要这个产品？

背单词 App 的例句离真实阅读太远，查词和背词流程被打断，语境记忆才是关键。

🎯

想解决什么问题

背单词 App 里的例句往往和用户的真实阅读场景脱节，记住的单词一到实际文章里还是认不出来。用户需要手动切换 App 查词、复制例句、记录来源，流程繁琐且容易遗忘。

💡

为什么会想到做这个

用墨墨背单词的用户大多有浏览英文内容的习惯，但背词流程和阅读流程是割裂的。直接在浏览器中完成「查词→收藏→抓取原句→关联来源」的闭环，背词效率会大幅提升。

🧩

产品形态

一款浏览器插件，与墨墨背单词 App 云词库打通，让学习场景从「刻意背词」扩展到「日常阅读即学习」。

02 / 目标用户及痛点

谁在用？在什么场景下？

覆盖备考学生、研究生、开发者等经常在浏览器中阅读英文内容的墨墨用户。

👥

面向哪些用户

备考考研/四六级/雅思托福的学生、阅读英文论文的研究生、浏览英文技术文档的开发者——所有使用墨墨背单词且经常在浏览器中阅读英文内容的人。

📍

在什么场景下使用

在浏览器中阅读英文文章、论文、技术文档、新闻时，遇到不认识的单词，点击即可查词并一键收藏到墨墨云词本，同时自动保存原始句子和来源页面。

当前痛点

1

查词过程割裂

需要划词→复制→打开词典或翻译工具→再手动录入背单词 App，步骤多，体验差。

2

语境丢失

收藏到 App 后，单词脱离了当初阅读的原文语境，复习时只能看 App 自带的例句，和自己实际阅读的内容无关。

3

无法追溯来源

过几天看到某个收藏的单词，不记得是在哪篇文章、哪个上下文里遇到的，记忆线索断裂。

03 / 核心功能

四大核心能力

从查词到助记，一站式完成语境单词的收集与整理。

01 🔍

点击查词

在网页中点击任意英文单词，即可弹出释义弹窗，无需离开当前页面，阅读流不被打断。

02 📚

收藏到云词本

一键将生词加入墨墨云词本，支持设置默认云词本，所有收藏自动同步到你的墨墨账号。

03 📝

自动保存原句与来源

通过标点符号自动判断句子边界，将生词所在句子保存到例句库，自动添加来源字段（URL + 页面标题），支持手动调整句子范围。

04 ✏️

编写助记

在查词界面提供「编写助记」入口，支持从 14 种固定类型中选择（词根词缀、谐音、联想等），编辑完成后直接提交到墨墨助记库。

04 / 技术可行性

墨墨开放 API 全覆盖

所有核心功能均已通过墨墨开放 API 验证可行，接口齐备，无技术障碍。

功能 对应 API 关键字段
查词 GET /api/v1/vocabulary spelling → id
收藏到云词本 POST /api/v1/study/add_words words: [{id}]
获取云词本列表 GET /api/v1/notepads 返回所有云词本
创建例句（含来源） POST /api/v1/phrases phrase, origin, interpretation, tags
创建助记（含类型） POST /api/v1/notes note_type, note, voc_id

助记类型（14 种固定分类）

词根词缀 辨析 联想 谐音 词源 固定搭配 语法 派生 串记 扩展 近反义词 口诀 合成 其他
05 / 实现计划

分三步走，逐步迭代

从 MVP 核心功能起步，逐步接入大模型和个性化能力。

Phase 1

MVP

  • 点击查词
  • 收藏到云词本
  • 自动抓取原句 + 手动调整
  • 来源字段自动填充
  • 助记手动选择类型
Phase 2

智能增强

  • 支持切换默认云词本
  • 助记类型大模型自动识别
  • 句子翻译自动生成
Phase 3

生态完善

  • 学习进度同步展示
  • 个性化复习推荐
  • 生词本导出
06 / 价值与意义

不止是效率工具

⚡

效率提升

将原本「查词→手动录入→复制例句→记录来源」的多步操作压缩为一次点击，阅读流不被打断，生词收集效率大幅提升。带着用户自己阅读过的原句复习，记忆效果远好于通用例句。

🌐

产品生态价值

插件将墨墨背单词的能力从 App 延伸到浏览器，让学习场景从「刻意背词」扩展到「日常阅读即学习」，增加了用户与产品的接触频次。自动生成的语境句库和来源字段也为墨墨构建了更丰富的用户数据资产。
