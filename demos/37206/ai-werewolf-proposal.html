9 个常驻 AI 角色

每个角色拥有独特性格维度（攻击性/保守性、逻辑型/直觉型、信任型/怀疑型、活跃型/沉默型）、专属口头禅和 AI 生成的头像。角色跨局保留，形成可辨识的「人物 IP」。

02

跨局记忆积累

基于向量嵌入（Embedding）技术，每个角色拥有独立的事件记忆、发言记忆、关系记忆和策略记忆。新对局开始时，自动加载相关角色的长期印象——「玩家 X 擅长伪装」「玩家 Y 容易冲动」。

03

人格动态演化

角色不是静态的——胜败经历会重塑性格参数。一个反复被欺骗的「单纯」角色会逐渐变得多疑和心机；一个靠运气连胜的「保守」角色可能会变得大胆冒进。每一次对局都是人物弧光的推进。

沙箱信息隔离

每个 AI 只能访问其角色应知的信息——狼人夜间互通但不知道神职操作，女巫独立决策，平民只知公共信息。严格的信息不对称保证了博弈的真实性与公平性，杜绝「上帝视角」作弊。

技术实现

驱动演化的引擎

多智能体编排

每个 AI 角色作为独立 Agent 运行，拥有专属的 System Prompt、记忆库和决策上下文。编排器协调各 Agent 在不同阶段的行动顺序与信息交换。

向量记忆系统

ChromaDB 存储角色的事件/发言/关系/策略四类记忆，Embedding 模型将文本转为向量。决策前检索 Top-K 最相关记忆作为 Prompt 上下文，实现「回忆」机制。

信息沙箱隔离

基于角色权限的 Game Context 过滤器：狼人仅见狼人频道，神职各知各的信息，平民只接收公共信息。确保博弈信息不对称的真实性。

多 LLM 后端支持

统一的 LLM 抽象层，支持 OpenAI、Anthropic Claude、Ollama 本地模型等灵活切换。可根据成本和性能需求选择最合适的推理后端。
