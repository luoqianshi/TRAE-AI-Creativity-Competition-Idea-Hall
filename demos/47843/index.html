项目名称：ShadowPlay-AI：智能跨端皮影声光互动剧场

核心玩法：

  • 体感拉线人偶：手机扫码立刻成为皮影操纵棒。挥动手机，屏幕上的皮影手脚关节根据倾斜度同步灵敏舒展，复刻传统皮影“挑、提、推”的牵引美感。
  • 声光同步大戏：手机对着嘴配音时，皮影嘴巴同步开合；大声叫喊或念白，舞台会触发雷电、火光特效，并根据语调生成锣鼓敲击伴奏，让一个人的独角戏拥有史诗舞台效果。
  • 抖音一键录屏二创：支持将演练视频和音频录制，加盖“非遗保护印章”专属水印，一键导出用于自媒体传播。

技术框架：基于 HTML5 开放规范设计，实现真正的跨端互联。

  • WebRTC 数据通道 (Data Channel)：通过点对点信道建立超低延迟通信，数据同步延迟控制在 15 毫秒以内，确保体感操作没有任何滞后感。
  • Web Audio API 物理建模合成：抛弃传统的庞大音频加载，纯代码算法物理建模大锣（包含音高下弯和泛音衰减）和钹（高频白噪包络控制），体积小，发声速度快。
  • SVG 骨骼动力学 (Inverse Kinematics)：将皮影人偶解构为头部、躯干、大臂、前臂、手掌和金箍棒，以反向动力学（IK）控制拉线杆对肢体偏转角的约束。

TRAE Work / IDE 赋能细节：

  • 复杂 SVG 建模渲染：利用 Trae 的 AI 代码编写能力，自动计算孙悟空手足四肢的旋转原点（Transform Origin）和骨骼约束。
  • Web Audio 合成音色调试：在大锣、小锣、钹的频率包络和白噪音发生器（White Noise Generator）参数调优上，利用大模型快速迭代物理建模公式。
  • WebRTC 握手逻辑生成：Trae 可以帮助快速编写多端信令服务器（Signaling）的 WebSocket 链接握手逻辑。
