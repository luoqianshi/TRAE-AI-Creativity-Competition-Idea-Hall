你是不是也遇到过这些问题？

大赛申报流程复杂、格式要求多、容易遗漏关键环节

01

流程太长，记不住

选题→报名帖→HTML→初赛深化→初赛帖→评委打分→视频脚本→打分预测→回收，9 个环节，漏一个都影响结果。

02

模板格式总出错

报名帖≥100字 4 个必填项、初赛帖≥3 截图+≥3 Session ID、Session ID 三段格式不能截断……每次都要翻文档检查。

03

不知道评委怎么打分

创新性、实用性、完成度、技术实现各占多少权重？7 位评委各有风格，怎么提前校准？

04

流量资源不会用

5W 流量券怎么申领？飞书群盲盒怎么参与？抖音人气通道怎么算分？资源就在那里，但没人告诉你什么时候用。

8 阶段自动化流水线

点击每个阶段查看详细说明和产出物

0
Onboarding · 规则介绍 引导

展示大赛规则速览、当前进度、重要链接，引导用户选择新选题或继续已有 demo

首次触发时，自动读取 state.md 获取当前进度，展示大赛规则速览（赛道、报名要求、初赛要求），让用户快速了解比赛全貌。

无文件产出，纯对话引导
1
选题 · 确定方向 策略

确认赛道、产品形态、痛点、目标用户，做选题合规检查，创建 demo 目录

和用户讨论选题方向，确认赛道（四选一+可选社会公益）、产品形态、痛点、目标用户。帮用户做选题合规检查，确保选题合理有差异化。确认后自动创建目录并编号。

选题.md
2
报名帖 · 社区发布 内容

按模板起草报名帖（创意名称+介绍、目标用户、价值意义、附 HTML），提醒发布

基于选题内容，按官方模板起草报名帖：创意名称+介绍、目标用户及痛点、价值与意义、附带 HTML 文件。正文字数≥100 字，4 个必填项齐全。

报名帖.md
3
HTML 产品介绍页 设计

生成精美单 HTML 产品介绍页，展示核心功能（痛点→方案→价值），响应式布局

基于选题和报名帖，用 TRAE 生成单 HTML 产品介绍页。要求：精美 UI 设计、展示核心功能、响应式布局（桌面+平板+手机）、包含交互元素。纯单文件，可直接在浏览器打开，上传到报名帖作为附件。

产品介绍页.html
4
初赛深化设计 优化

结合初赛评审 4 维度，深化 demo 功能和交互，准备截图和 Session ID

报名通过后，结合初赛官方评审 4 维度（创新性 30%、实用性 30%、完成度 20%、技术实现 20%）深化 demo。讨论是否需要增加功能、优化 UI、补充交互。准备≥3 张截图和≥3 个 Session ID。

深化后的 demo（HTML 更新或新代码）
5
初赛帖 · 深度展示 核心

按模板起草初赛帖（打招呼+Demo 简介+创作思路+体验地址+TRAE 实践过程），附截图+Session ID

按官方模板起草初赛帖：打招呼、Demo 简介、创作思路、体验地址（三选一）、TRAE 实践过程（≥3 截图+≥3 完整 Session ID）。发布后提醒：初赛专区发帖→抖音发视频→申领 5W 流量券→飞书群盲盒。

初赛帖.md
5B
模拟评委打分 核心

7 位独立人格评委模拟评审，4 维度打分+通过/不通过+点评意见，综合预测晋级概率

基于初赛帖和 HTML 产品页，7 位评委（罗永浩/王兴兴/胡彦斌/Tim/楼天城/熊老师/黎黎老师）独立评审。每位评委按 4 维度打分（每维度 10 分）+ 给出通过/不通过 + 点评意见。7 位评委中≥4 位通过则整体预测通过。

模拟评委打分.md
6
视频脚本 · 产品体验 传播

生成 60-90 秒产品体验视频脚本（惊艳成品→可玩功能→关键过程→获取方式），含拍摄要点

基于 demo 特点，起草 60-90 秒产品体验视频脚本。结构：惊艳成品(3 秒钩子)→可玩功能展示→深度体验+反差感→关键过程(可信度证明)→获取方式+CTA。全程展示交互操作，含拍摄要点和标签策略。

口播稿.md
7
打分预测 · 数据校准 分析

调用 cheat-on-content 评分体系，三原则预检+7 维度评分+bucket 预测+反事实场景

读取评分公式和参考标准，对视频脚本做三原则预检（稀缺性/利他性/高密度），逐维度打分（ER/SR/HP/QL/NA/AB/SAT），计算 composite 综合分，给出 bucket 预测+概率分布+中枢，锚点对比历史数据，反事实场景+风险提示。

打分预测.md
8
回收 · 复盘迭代 闭环

发布后数据回收、对比预测 vs 实际、分析偏差、沉淀经验到 state.md

视频发布后，产出回收骨架。用户填写实际数据后做复盘分析，对比预测 vs 实际，分析偏差原因，沉淀经验到 state.md。每个 demo 的经验积累让后续预测越来越准。

回收.md

三大流量引擎，一套打通

不只是做产品，更是系统性获取流量

5W 视频流量券

每个初赛作品可申领一次 50,000 曝光流量扶持。官方直接推流，让你的作品被更多人看到。名额有限，先到先得。

1 作品 = 50,000 曝光

批量策略：前 3-5 个 Demo 保证高质量，拿到前几波 5W 后观察官方限制，再决定是否继续批量。

抖音人气通道

独立晋级通道，TOP 50 直接晋级复赛。带话题 #vibecoding大赏 #traeai创造力大赛 发布视频即可参与。

人气分 = 点赞 + 评论×2 + 收藏 + 转发

门槛：单条点赞≥500 才能入榜。同一作品可发多条，取最高一条计分，截止 7 月 15 日。

飞书群盲盒活动

每个工作日抽 3 位送神秘盲盒。参与条件：报名通过+初赛帖+抖音视频+飞书群发帖，缺一不可。6.23 起有效。

4 步完成 = 1 份候选

冲刺日行动清单：初赛专区发帖→抖音发视频→申领 5W 流量券→飞书群盲盒发帖，一天内完成 4 件事。
