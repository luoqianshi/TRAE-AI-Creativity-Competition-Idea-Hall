Pain Points

家长和学生正在经历的麻烦

《国家学生体质健康标准》覆盖 12 个年级，但规则复杂、计算繁琐，普通家庭很难轻松应对。

📋

规则复杂难记

不同年级、性别的项目、权重、加分规则各不相同，家长经常搞不清楚孩子该测什么。

🧮

手动计算易错

Excel 评分表查起来慢，线性插值容易算错，一次体测要处理十几个单项数据。

🎯

训练没有方向

不知道弱项该练什么、练多久，网上训练方法质量参差不齐，动作对不对也没人把关。

📈

进步缺少记录

成绩变化靠记忆或零散表格，缺少可视化趋势，孩子看不到自己的成长轨迹。

👨‍👩‍👧‍👦

多孩管理混乱

一个家庭多个孩子的体测数据分散在不同地方，切换查询非常麻烦。

🎖️

激励效果不足

缺少同龄人横向对比和正向反馈，孩子参与体测和训练的积极性不高。

Core Features

一个微信小程序，解决体测全链路问题

基于微信云开发，从成绩计算到训练打卡，从 AI 咨询到同伴激励，完整覆盖体测场景。

🧮

智能体测评分

内置小学一年级至高中三年级完整评分库，录入成绩后 0.3 秒自动计算单项分、附加分、总分与等级。

📊

可视化趋势

通过折线图、雷达图和成长曲线，直观展示历次体测变化，快速定位薄弱项目。

🤖

AI 训练咨询

接入大模型能力，提供跳绳、耐力跑、仰卧起坐等项目的科学训练建议与安全提示。

📅

训练计划与打卡

根据薄弱项目生成个性化周计划，每日打卡记录，连续打卡解锁勋章激励。

👨‍👩‍👧‍👦

多孩子档案

一个账号管理多个孩子，自动根据出生日期或入学年份升级年级，数据云端同步。

🏆

排行榜与分享

同校同年级匿名排行榜、进步榜、荣誉标签；成绩海报、进步勋章、打卡卡片一键分享。

Value

为什么这个创意值得做

从效率提升到社会价值，产品试图让体测这件事变得更简单、更科学、更有激励性。

0.3s

效率提升

家长无需再查表、插值、算权重。录入身高、体重和各项成绩后，系统自动完成从小学到高中的完整评分计算，一个家长可统一管理多个孩子档案，体测季准备时间从小时级缩短到分钟级。

公益

社会价值

体测成绩与评优评奖及毕业挂钩，产品帮助家庭更科学地管理青少年体质健康。排行榜默认关闭、匿名展示、仅同校同年级可见，充分保护未成年人隐私，鼓励正向运动习惯而非焦虑竞争。
