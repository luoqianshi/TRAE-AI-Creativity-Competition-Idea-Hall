PART 01
创意名称 & 创意介绍

创意名称：清道夫（Scavenger） —— 像清道夫鱼守护鱼缸一样，默默守护每一片内容社区的清洁。

🎯
想解决什么问题

评论区治理，又贵又慢又易伤人

广告引流、辱骂攻击、刷屏灌水、涉敏内容层出不穷。传统敏感词 + 人工审核规则僵硬、误伤率高、人力成本高、风险发现严重滞后。

💡
为什么会想到做这个

UGC 是产品最大的资产，也是最大的雷区

做内容社区时发现：一条漏放的诈骗评论可能毁掉用户信任，一次误删的差评又会激怒真实用户。我们想要一个「既懂规则、又懂语义、还能被人纠错」的智能中台。

📦
大概是什么产品

一套可独立部署的风控 Agent 系统

以 REST API / SDK / Webhook 形式接入小程序、Web、App、后台系统的内容风控服务，配套 React 管理后台与自然语言运维对话。

一句话概括

清道夫 = 规则引擎的「快」 + 大模型的「懂」 + 行为分析的「准」 + 人工复核的「稳」，四位一体，为任何评论区提供开箱即用、可解释、可追溯的自动化内容风控闭环。

评论提交→ 规则检测→ 行为加权→ LLM 语义审核→ 风险融合→ 决策路由→ 放行/待审/隐藏/删除/禁言→ 人工复核反馈

PART 03
价值与意义

从效率提升与社会价值两个角度，清道夫把「被动救火」变为「主动治理」。

⚡ 效率提升

把人从重复审核中解放出来

  • 低风险内容毫秒级快速通道放行
  • 高风险自动隐藏，人只看「不确定」内容
  • 自然语言对话式运维，一句话生成日报
  • 人工反馈沉淀为样本，规则持续自迭代
🌱 社会价值

营造更清洁、更友善的网络空间

  • 及时拦截诈骗、涉敏、辱骂内容，保护用户
  • 降低未成年人接触不良信息的风险
  • 可解释的处置理由，让治理更透明公正
  • 减少误伤，保护正常表达与真实评价
💼 商业价值

可复用、可开源、可商业化的中台

  • 一次部署，多业务多租户复用
  • Provider 热切换，模型成本可控可降级
  • 降低平台合规风险与舆情损失
  • 工程化 Agent 能力，具备开源与产品化潜力

核心价值主张

让内容安全不再是「成本中心」，而是可被信任的「基础设施」—— 用更低的人力、更快的响应、更少的误伤，守护每一个社区的内容健康。
