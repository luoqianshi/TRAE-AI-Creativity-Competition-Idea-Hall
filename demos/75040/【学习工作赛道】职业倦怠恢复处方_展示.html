// 4 BURNOUT TYPES

四种倦怠类型：不同病因，不同处方

职业倦怠不是铁板一块。不同类型的倦怠需要完全不同的恢复策略，用错方法可能越休息越累。

⚡

身体透支型

长期加班、睡眠不足、饮食不规律。身体发出信号：头痛、腰酸、免疫力下降。

核心恢复：运动处方 + 睡眠调整
♥

情绪耗竭型

情绪被掏空，对什么都提不起兴趣。容易烦躁、哭泣，或者麻木无感。

核心恢复：情绪释放 + 心理滋养
★

价值感缺失型

觉得工作没意义、自己没价值。每天重复同样的事，看不到成长和回报。

核心恢复：意义重建 + 成就积累
●

人际疏离型

不想和人说话，和同事关系淡漠。孤立感强，觉得没人理解自己。

核心恢复：社交重建 + 连接恢复

      // TECH STACK

      技术原理

      AI 心理评估模型 + 个性化推荐算法 + 行为追踪系统，构建从诊断到恢复的完整闭环。

      AI 倦怠评估模型

      基于 Maslach 倦怠量表（MBI）和积极心理学框架，结合大语言模型进行深度语义分析，精准识别四种倦怠类型及混合类型。

      个性化处方引擎

      基于认知行为疗法（CBT）和积极心理学循证方案，根据倦怠类型、严重程度、个人偏好生成可执行的每日恢复计划。

      自适应调整算法

      根据每周复评数据和每日任务完成情况，动态调整恢复方案的难度、节奏和内容，确保方案始终匹配当前状态。
