05 · 使用教程

3 步用起来：打开网页，就让机器人动起来

下面是网页版快速上手步骤——不用装环境、不用会写代码，跟着走一遍即可。

1

打开网址，注册并登录

浏览器进入 rdkstudio.d-robotics.cc，点右上「去注册」，用手机号或邮箱自助注册（填用户名、密码、手机号 + 验证码），几十秒完成，然后登录进入工作台。

页面长什么样：进入后是一张登录卡片，右上角可切换中英文；卡片上方有「账号登录 / 短信登录 / 邮箱登录」三个页签，下面是用户名、密码输入框和橙色「登录」按钮。点右上角「还没有账号？去注册」进入注册页，切「手机注册」或「邮箱注册」，填好信息、获取并填入验证码，点底部注册按钮即可。

  • 已有账号可直接用账号 / 短信 / 邮箱任一方式登录。
  • 登录后页面底部有三个入口：工作台（看设备与执行过程）、对话（和 AI 智能体说话）、更多（设置等）。
2

连接你的机器人 / 开发板

点右上角的 「连接设备」，按引导把你的开发板、桌面机械臂或人形机器人接进来——同一局域网可自动发现，也支持扫码或填写地址连接。连接成功后，设备会显示在工作台里。

入口在哪：登录后页面右上角有「连接设备」按钮，旁边是网络状态和账号图标。点开后按引导选择连接方式：同一局域网内可自动发现设备、也支持扫码或手动填写设备地址与账号。连接成功后，设备会出现在「工作台」里并显示在线状态。

  • 手边暂时没有设备也没关系，可以先在「对话」里体验 AI 的规划与讲解能力。
  • 连上后，终端、文件、可视化画面都收进网页里，不用再单独开一堆工具。
3

在「对话」里用一句话下达任务

切到 「对话」，把你想做的事直接说出来。AI 智能体会自己连设备、执行命令、跑模型、驱动硬件，整个过程在工作台里实时可见，做完还会回来告诉你结果。下面这些指令可以直接照抄试：

「帮我连接局域网里的开发板，连上后告诉我系统信息。」
→ 自动发现并 SSH 连上，回报板卡状态。
「用摄像头识别桌面上有哪些物体，标注出来给我看。」
→ 拍照做视觉识别，返回一张带标注框的图。
「在板子上跑 YOLO 目标检测，做成网页让我实时看到检测框。」
→ 板端 BPU 跑检测 + 网页视频流，浏览器实时看画面。
「让机械臂把这几个彩色圆环从大到小叠成一座塔。」
→ 相机识别套环 → 规划路径 → 驱动机械臂搬运叠塔。
「给板子部署一个能看图对话的本地视觉大模型。」
→ 本地部署多模态模型，上传图片就能问答。

执行时你会看到：AI 一边回复、一边把每一步实时打出来——「正在连接设备 → 正在执行命令 → 正在识别 → 正在驱动机械臂 → 完成」，终端输出、标注图片、检测画面都会内嵌在对话里，工作台同步显示设备状态。做完它会用一句话总结结果，涉及真实硬件动作前还会先请你确认。

✦

完整走一遍（一个例子）

假设你有一块开发板和一个 USB 摄像头，想让它认出桌上的东西：

  • ① 打开 rdkstudio.d-robotics.cc，注册并登录；
  • ② 点右上「连接设备」，在局域网里选中你的开发板连上；
  • ③ 切到「对话」，输入：「用摄像头识别桌面上有哪些物体，标注出来给我看。」
  • ④ AI 自动在板端拍照、跑视觉识别，几十秒后在对话里返回一张带标注框的结果图；
  • ⑤ 想继续就接着说，例如：「把检测做成网页，让我实时看到画面。」——它会起一个实时视频流页面给你。

全程你只说了两句话，没写一行代码，机器人就真的动起来了。

💡 小贴士

  • 指令越具体越好：说清用哪台设备、做什么、想要什么结果，AI 一次就能规划到位。
  • 涉及真实硬件动作（移动机械臂、写删文件、刷机等）时，AI 会先征得你确认再执行。
  • 桌面端与网页端是同一套，换电脑登录同一账号即可无缝继续。
  • 不知道从哪开始？直接问它「我有一块开发板，能带我做点什么？」它会给你上手建议。
