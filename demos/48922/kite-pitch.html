Kite

装一个 CLI，就能拥有一套带可视化界面的自动化部署系统。
让学生和独立开发者，告别"打包 → SCP → SSH → 重启"的繁琐循环。

$npm i -g @kitecd/cli
$kite serve
$kite push
1

创意介绍

🎯

想解决什么

个人开发者每次部署都要重复打包、上传、SSH、解压、重启，繁琐又易翻车。

💡

为什么做

Jenkins/K8s 太重，裸脚本太脆；缺一个"安装即用"的中间形态。

📦

产品形态

一个 NPM CLI 包，内置 Vue3 Web 管理端 + Elysia Server，开箱即用。

2

目标用户 & 使用场景

👥

核心用户

在校学生、独立开发者、不熟悉运维的前端/全栈工程师。

🖥️

使用场景

把课设、毕设、Side Project、个人博客频繁部署到自己的云服务器。

⚠️

当前痛点

跨平台脚本差、Token 散落易泄露、多环境靠人脑、无可视化记录。

3

有 Kite 之前 / 之后

// BEFORE

  • 手写 SCP/SSH 脚本，跨平台一堆坑
  • Token 写在 .env 或聊天记录里
  • dev / staging / prod 切换靠记忆
  • 5–10 分钟手工流程，每天重复 N 次
  • 没有可视化部署历史

// AFTER · with Kite

  • 一条 kite push 秒级完成
  • Token 由 CLI 统一管理，自动脱敏
  • kite.config.<env>.json 一键切换环境
  • Web 管理端可视化看项目、Token、记录
  • Bun / Node 双运行时，开箱即用
4

价值与意义

⚡

效率提升

把 5–10 分钟手工部署，压缩成一条命令的秒级操作；多环境切换零心智负担。

🎓

学习价值

让学生用一行命令把作品发布上线，把"部署"从玄学变成可掌握的基础能力。

🧱

工程示范

Bun Monorepo + TS + Vue3 + Elysia + Drizzle，本身就是一份现代全栈样本。
