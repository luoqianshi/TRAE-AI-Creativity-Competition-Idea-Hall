外婆
之印

"縷金作勝傳荊俗，剪紙為人起晉風。"

— 唐 · 李商隱《人日即事》

剪纸不是博物馆玻璃柜里的标本。
它本来就长在窗上、贴在门上、压在嫁妆箱底。
《纸上春秋》想做的，是让你亲手把它从纸上剪出来。

CORE LOOP

核心玩法 · 折 / 描 / 剪 / 展

每一刀都是一次决定
折
叠纸

选择对折 / 三角 / 四角 / 五角 / 六角 / 团花折法。 折几次、怎么折，决定了你能不能剪出对称的窗花。

描
起稿

在折好的纸上描一半纹样：花瓣、鱼鳞、寿字、忍冬纹。 系统提供"骨线辅助"，也允许你完全徒手。

剪
下刀

鼠标即剪刀。沿着描线一气呵成， 线条节奏决定是"洗练明快"还是"碎屑满地"—— 剪坏了要从头再来。

展
开纸

最高光的时刻——纸张缓缓展开，对称图形从黑暗中浮现。 系统按"造型 / 线条 / 装饰 / 寓意"四维打分。

STORY

六章剧情 · 一年四季

没有教科书一样的"知识弹窗"。 历史与技艺都藏在街坊的请求、孩子的问题、博物馆的来信里。 你做对了，自然会有人讲故事给你听。

叙事原则
  • · 不堆百科，让 NPC 说人话
  • · 剪坏了，外婆会托梦讲一段
  • · 每一种技法都对应一段历史
  • · 玩家最终要回答：它为什么还值得存在？
第一章
归乡 · 推开那扇门

外婆离开，铺子蒙尘。你跟着泛黄的笔记，第一次学"对折剪法"，剪出一个歪歪扭扭的喜字贴在自家窗上。
学到：对称折剪法 · 剪纸的"装饰 / 吉祥 / 传承"三重身份。

第二章
街坊 · 一福一寿

王婶要给孙子办满月，李叔托你剪个"寿"。你开始学三角折、四角折，了解为什么"先内后外、先细后粗"。
学到：三角 / 四角折剪法 · 阳刻与阴刻的差别。

第三章
游客 · 把团花卖出去

民宿老板带客人上门，要的是"能拍照、能带走、有故事"的团花。你开始挑战六角折与团花构成。
学到：五角 / 六角折剪法 · 团花的对称放射构图。

第四章
学校 · 教孩子撕纸

小学美术课请你去上一节非遗课。剪刀对孩子太危险，你要教他们撕纸、撕纸贴、拉毛画——用最朴素的方法做出最大胆的造型。
学到：撕纸 / 拉毛画 / 染纸 · 非遗的"低门槛传承"。

第五章
博物馆 · 复刻南北朝

博物馆寄来一张南北朝"对马团花"的高清照片，要你按原工艺复刻。点色、染色、襯色一齐上阵——这是手艺人最难也最骄傲的活儿。
学到：点色 / 染色 / 襯色剪纸 · 中国最早剪纸的历史源流。

终章
开窗 · 你自己的纹样

最后一道关：不再有"参考稿"。你要为自己的小店设计一张可以挂一整年的"年画窗花"。 它会作为你的存档封面，也可以一键导出为高清 SVG / PNG，贴在你真实的窗上。
学到：这门手艺为什么还值得存在——答案由你给出。

VALUE

为什么是"游戏"，
而不是又一段视频？

纪录片告诉你剪纸"曾经"如何辉煌， 短视频告诉你"看，这个老人多厉害"。 但这门手艺真正的传承，从来不靠观看， 靠的是"我也试了一下"。

《纸上春秋》把剪刀塞进每一个浏览器， 让任何人在 5 分钟内剪出第一张窗花， 在 5 小时后亲手复刻一张南北朝团花。
