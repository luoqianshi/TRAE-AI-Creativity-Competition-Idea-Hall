## 二、本模块发现的新组件需求（建议补充清单）

> 以下组件为 BL-01 业务场景所需的"消防行业专属组件"，组件库 V1.0 中**部分未覆盖**或**未覆盖**，按"先基础控件实现 + 标注'待组件补充'"原则处理。

### 2.1 评分可视化组件（⭐ 高优先级）

| 项 | 内容 |
|---|---|
| **组件名称** | AI 6 维度评分可视化组件 |
| **适用业务场景** | 商机自动评级（V1.1 PRD 重新设计的 AI 6 维度综合评分法）|
| **当前实现方式** | 基础 div + CSS 进度条 + chip 显示（在 P02/P05 中实现） |
| **组件库缺失原因** | V1.0 组件库未包含"多维度评分可视化"组件（最接近的是 KPI 卡，但功能不同） |
| **补充建议** | 在组件库 V1.0 中新增 "AI 6 维度评分可视化"组件，作为通用组件供 BL-01~BL-15 复用 |
| **核心功能** | ① 6 维度单维度评分横向柱 ② 总评分进度条 ③ 评级结论徽章 ④ 评级理由文本块 ⑤ 风险提示文本块 ⑥ 人工 override 入口 |

### 2.2 商机/续约状态机组件（⭐ 高优先级）

| 项 | 内容 |
|---|---|
| **组件名称** | 商机状态机可视化组件（9 态） |
| **适用业务场景** | 商机全生命周期状态机流转（待评级/已评级/踏勘中/已立项/未中标/已中标/已签约/已流失/已续约）+ 续约独立状态（已续约/未续约/已流失）|
| **当前实现方式** | 基础 div + CSS flexbox（在 P02 状态机 Tab 中实现） |
| **组件库缺失原因** | V1.0 组件库含"审批流程卡片"，但"状态机"与"审批流"不同（审批流是事件流，状态机是状态流转） |
| **补充建议** | 在组件库 V1.0 中新增 "通用业务状态机"组件，支持横向/垂直双向展示 |
| **核心功能** | ① 自定义节点数（≤12） ② 节点图标 + 标签 ③ 当前节点脉冲动画 ④ 已完成节点变绿 ⑤ 终止节点红色 ⑥ 状态变更历史时间线附属 |

### 2.3 双引擎入口卡（⭐ 中优先级）

| 项 | 内容 |
|---|---|
| **组件名称** | 双引擎入口切换组件（手动 + 飞书机器人/爬虫等） |
| **适用业务场景** | 商机录入（手动 + 飞书机器人）+ 维保工单（手动 + 系统自动）+ 报销录入（手动 + OCR）|
| **当前实现方式** | 基础 div + CSS grid（在 P03 中实现） |
| **组件库缺失原因** | V1.0 组件库未包含"双模式入口切换"组件 |
| **补充建议** | 在组件库 V1.0 中新增 "双引擎入口"组件，可配置 2-3 种入口模式 |
| **核心功能** | ① 双引擎卡可切换显示 ② 不同引擎对应不同的子面板 ③ 引擎选择持久化 ④ 移动端友好 |

### 2.4 实时表单预览组件（⭐ 中优先级）

| 项 | 内容 |
|---|---|
| **组件名称** | 实时表单结果预览组件 |
| **适用业务场景** | 商机登记金额变更实时显示评级预览、税额自动算、立项决策实时汇总评分 |
| **当前实现方式** | 基础 div + CSS（在 P03/P05 中实现） |
| **组件库缺失原因** | V1.0 组件库未包含"实时预览面板"组件（最接近的是"金额自动计算卡片"，但通用性不足） |
| **补充建议** | 在组件库 V1.0 中升级现有"金额自动计算卡片"为"实时结果预览面板"，增加顶部固定锚点 + 可滚动 |
| **核心功能** | ① 监听多个表单字段 ② 实时汇总显示 ③ 颜色变化提示（绿/黄/红） ④ 移动端折叠为底部弹出 |

### 2.5 多选 chip 组件（⭐ 低优先级）

| 项 | 内容 |
|---|---|
| **组件名称** | 多选 chip 组件 |
| **适用业务场景** | 关系维护沟通对象多选、班组系统范围配置、跨模块字段多选 |
| **当前实现方式** | 基础 div + CSS（在 P07 中实现） |
| **组件库缺失原因** | V1.0 组件库未包含"多选 chip"组件 |
| **补充建议** | 在组件库 V1.0 中新增 "多选 chip"组件，支持单选/多选/必选/最多 N 项配置 |
| **核心功能** | ① 单选/多选切换 ② 可配置最大项数 ③ 必选校验 ④ chip 删除/添加交互 |

### 2.6 抽屉详情组件（⭐ 中优先级）

| 项 | 内容 |
|---|---|
| **组件名称** | 右侧抽屉详情组件 |
| **适用业务场景** | 商机行点击抽屉、续约商机详情、班组详情、人员详情 |
| **当前实现方式** | 基础 div + CSS（在 P01 中实现） |
| **组件库缺失原因** | V1.0 组件库未包含"通用抽屉"组件（最接近的是模态弹窗，但抽屉用于"展开详情"更合适） |
| **补充建议** | 在组件库 V1.0 中新增 "通用业务抽屉"组件，支持自定义 width（左/右滑入）|
| **核心功能** | ① 左侧/右侧可选 ② 自定义宽度 ③ 标题 + 操作按钮区 ④ 抽屉内可滚动内容区 ⑤ ESC 关闭 ⑥ 蒙层点击关闭 |
