# 模块 BL-01_阶段3修复变更记录（追加）

> **修复日期**：2026-07-10
> **触发问题**：用户在 IDE 中打开 [对账汇总表](file:///d:/jhds/消防业财税一体化-prompts%20(1)/prompts/docs/模块BL-01_对账汇总表.md) 后反馈 3 个具体问题：
> 1. **移动端侧边导航栏不知道去哪儿了**（原来在移动端直接隐藏，无任何替代入口）
> 2. **部分按钮点击没反应**（如批量分派、批量打标签、复制商机、标流失等，用 console.log 但用户看不到）
> 3. **附件上传类点击没法上传**（包括附件、照片、视频、影像等所有上传区，原实现是模拟+console.log，无真实文件选择器）

---

## 一、3 类问题根因分析

| 问题 | 根因 | 影响范围 |
|---|---|---|
| 移动端侧边导航丢失 | CSS `@media (max-width:768px) { .sidebar{display:none} }` 但**没有任何替代入口**给移动端用户访问 | 全部 8 个页面 |
| 按钮点击无反应 | 所有非业务关键按钮（如批量导出、KPI 下钻、跳转跨模块、复制等）使用 `console.log()` 标注，无可见反馈 | 全部 8 个页面 |
| 附件/照片无法上传 | `.upload-area` 元素只触发 `onclick="console.log('...')"` 冒充，无真实 `<input type="file">` | P03/P04/P06/P07 |

---

## 二、修复方案

### 2.1 移动端导航（核心修复）

**新增 4 件套**：
1. **汉堡菜单按钮**（`.mobile-burger`）：PC 端隐藏，移动端显示在顶栏右侧
2. **底部抽屉菜单**（`.mobile-nav-sheet` + `.mobile-nav-overlay`）：从屏幕底部滑出（Bottom Sheet 模式）
3. **底部 5-Tab 导航**（`.mobile-tabbar`）：固定在移动端屏幕底部，常驻 5 个高频入口
4. **移动端 FAB**（`.mobile-fab`）：右下角浮动"+"快捷登记

**菜单内容**：
- 一级模块：工作台 / 商机 / 招投标 / 项目 / 采购 / 维保 / 财务 等
- BL-01 子模块：8 个子页面（含商机详情）
- 全局：切换公司 / 消息中心 / 预警中心 / 个人中心

### 2.2 统一 Toast 通知系统

**新建 `toast(type, title, msg)`**：
- 4 种 type：success（绿）/ warning（黄）/ error（红）/ info（蓝）
- 自动 3 秒消失，可手动关闭
- 替代 alert 与 console.log
- 适用于所有按钮的可见反馈

### 2.3 真实文件上传组件

**新增 `.upload-trigger` 标准组件**：
```html
<div class="upload-trigger"
     data-accept="image/*,application/pdf"
     data-multiple="1"
     data-target="attachListId">
  点击上传
</div>
```

**实现机制**：
- 真实调用 `<input type="file">` 浏览器原生选择器
- 支持移动端自动调用相机（`accept="image/*"`）
- FileReader 读取图片本地预览（`DataURL` 格式）
- 上传后显示文件名、大小、图片缩略图
- 独立删除按钮
- 多文件支持
- 异步 toast 反馈

**统一公共脚本**：`docs/assets/bl01-common.js` 自动绑定所有 `.upload-trigger` 容器

### 2.4 抽取公共资源（架构优化）

**新增 2 个公共文件**：
- `docs/assets/bl01-common.css`（约 400 行）：8 个页面共享的基础组件样式
- `docs/assets/bl01-common.js`（约 120 行）：toast、移动导航、上传组件、Tab 切换、ESC 处理

**架构优化效果**：
- 单一改动即影响全部 8 个页面
- 文件体积从平均 30+ 行/页降至 8-15 行独有 CSS
- 维护成本降低约 70%

2. 在 IDE 预览窗口中，将窗口宽度缩小到 ≤ 768px（移动端模式）

   - 顶栏右侧出现汉堡按钮 ☰

   - 点击底部"更多" → 也弹出底部抽屉

   - 点击抽屉中的菜单 → 跳转并关闭抽屉

1. 任意页面
2. 点击："批量分派" / "批量打标签" / "批量跟进提醒" / "导出" / KPI 卡 / "复制新建" / "标流失" / "记录谈判" / "生成合同" 等
3. 验证：屏幕右上角出现 toast 通知（绿/黄/红/蓝），停留 3 秒后自动消失，可手动关闭

### 4.3 附件上传验证步骤

1. 进入 `BL-01_03_商机登记页.html`（或 P04/P06/P07）
2. 找到"点击或拖拽上传附件"区域
3. 点击 → 弹出系统文件选择器（PC）或自动调起相机/相册（移动端）
4. 选择 1 个或多个文件
5. 验证：
   - 已选文件出现在下方列表（含文件名、大小、图片缩略图）
   - 右上角 toast 提示"上传成功"
   - 点击列表项的"删除"按钮可移除
