| 维度 | 设计要点 |
|---|---|

## 五、响应式断点、导航转化方式与重排规则

### 5.1 断点定义（与 visual-responsive-spec.md §2.1 一致）

| 断点 | 范围 | 处理方式 |
|---|---|---|
| `lg` (≥1024px) | PC 端 | 完整布局：顶部 64px 导航 + 220px 侧栏 + 24px 内边距 |
| `md` (768-1024px) | 笔记本/平板横屏 | 侧栏自动隐藏，主区单列流式 |
| `sm` (≤768px) | 手机 | 顶部导航折叠为汉堡菜单；表格转为卡片列表 |

### 5.2 导航转化方式（强制要求）

- **PC 端（≥768px）**：顶部蓝色 64px 导航栏完整显示（含一级模块 + 全局搜索 + 通知铃铛 + 个人头像）；左侧 220px 二级导航栏完整显示（含 BL-01 子模块分组）。
- **移动端（<768px）**：
  - 顶部导航：一级模块菜单隐藏，**显示汉堡按钮 ☰**（位于右上角）
  - 汉堡菜单：点击展开侧滑菜单（包含全部一级模块 + 模块内快捷入口）
  - 左侧导航：完全隐藏，仅通过汉堡菜单访问
  - **必须可用**：汉堡菜单交互完整（点击展开/再次点击收起 + 点击任意菜单跳转到对应页面）

### 5.3 重排规则（8 页面统一遵循）

| 元素 | PC 端（≥1024px） | 移动端（<768px） |
|---|---|---|
| 顶部导航 | 一级模块水平排列（最多 8 个）+ 全局功能 | 汉堡菜单 + 消息铃铛 + 头像 |
| 左侧导航 | 220px 固定分组列表 | 完全隐藏 |
| KPI 网格 | 4-5 列网格 | 2 列或单列 |
| 数据表格 | 全字段+列固定 | 转为卡片（thead 隐藏，每行作为卡片） |
| 表单 | 双列网格 | 单列流式 |
| 按钮组 | 在表单底部右侧水平排列 | 在底部"粘性"固定（或垂直堆叠倒序） |
| AI 评级维度 | 3 列网格 | 单列堆叠 |
| 抽屉/弹窗 | 居中弹窗或右侧抽屉 | 全屏抽屉 |
| Tab 切换 | 水平 Tabs | 水平滚动 Tabs |
| 时间线 | 居左垂直时间轴 | 居左垂直时间轴（保留） |

### 5.4 一致性保证

- 8 个页面共用同一套 CSS 变量（颜色/字体/间距），保证视觉一致性
- 顶栏 64px + 侧栏 220px + 内容区内边距 24px 在所有页面保持一致
- 状态标签/评级标签/风险预警红框组件样式在所有页面统一调用
