键上流声

TypeFlow — 让你的键盘变成乐器

产品概念

「键上流声」是一个伪装成在线文档编辑器的网页应用。打开后，它看起来和 Typora、Notion 一样简洁干净——白底黑字，光标闪烁，仿佛你真的在写一份工作报告。

但当你开始打字，每一个按键都会唤醒一个音符。A 是 Do，S 是 Re，D 是 Mi……你的工作汇报变成了爵士即兴，你的周报变成了电子乐章。

核心体验：不需要任何音乐基础，只要会打字，就能即兴创作旋律。按下空格是鼓点，回车是和弦，退格是刮碟声。

视觉风格

默认界面：极简白底编辑器，1.5 倍行距，灰色光标，看起来像专业写作工具。

视觉反馈：

  • 每次按键，字符上方飘起一个半透明音符（🎵），1 秒后消散
  • 屏幕底部有一条音频波形，随声音实时跳动
  • 长时间不打字，波形变成平缓的呼吸灯效果

开发计划

初赛阶段（Demo）

实现中排 A-L 音阶映射 + 钢琴音色 + 基础音符动画 + Esc 伪装模式

复赛阶段（完整产品）

加入上下排八度、5 种乐器切换、节奏伴唱、录音回放、波形可视化

决赛阶段（精致打磨）

乐谱生成、分享功能、主题皮肤、多人联机合奏

技术方案

纯前端实现，无需后端：

  • 音频引擎：Web Audio API（OscillatorNode 生成波形，模拟不同乐器音色）
  • 动画系统：CSS @keyframes 做音符飘起，Canvas 做底部波形可视化
  • 录音功能：MediaRecorder API 导出音频文件
  • 创作工具：TRAE Work / TRAE IDE 全流程开发
