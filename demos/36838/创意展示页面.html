赛道：学习工作
1. 创意名称 + 创意介绍
CodeQuest —— C++ 闯关学习平台
想解决什么问题

很多 C++ 初学者被"C++ 很难"的刻板印象吓退，还没开始学就放弃了。本作品希望通过游戏化的闯关模式，降低 C++ 的学习门槛，让新手在趣味互动中建立信心、理解核心概念，不再畏惧 C++。

为什么会想到做这个

自己学习 C++ 后发现并没有传说中那么难，但网上充斥着"劝退"言论。同时看到国外有用游戏教 Python 的成功案例（如 CodeCombat），于是想为 C++ 初学者做一款类似的互动学习工具。

大概是什么产品

一个 Web 端的 C++ 编程闯关游戏，支持在 Android、Windows、macOS 的浏览器中直接运行，无需安装复杂环境。

2. 目标用户及痛点
面向哪些用户
  • 零基础的编程新手
  • 想入门 C++ 但不知从何开始的学生或自学者
  • 对 C++ 感兴趣但被"难度"劝退的潜在学习者
在什么场景下使用
  • 想尝试学 C++，但不想先配环境、看视频
  • 课余或碎片时间，想边玩边学
  • 传统教程看不进去，需要更有反馈感的学习方式
当前痛点
  • 网上"C++ 太难"的负面声音多，容易打击信心
  • 视频教程动辄几十小时，内容枯燥，难以坚持
  • 缺少即时反馈，写错代码不知道错在哪
3. 价值与意义
效率提升
  • 把 C++ 核心语法和概念拆解成短关卡，每关 5–10 分钟，利用碎片时间即可学习
  • 即时运行、即时反馈，写代码像玩游戏一样有成就感
  • 免去配置开发环境的繁琐步骤，打开浏览器就能开始
独特价值
  • 用游戏机制（闯关、积分、提示系统）替代传统"看视频+记笔记"模式
  • 让学习者在"玩"中自然理解变量、循环、函数、指针等 C++ 核心概念
期待在比赛中把这款作品做出来，让更多人对 C++ 产生兴趣！
