创意名称 + 创意介绍

创意名称

ScreenShield —— 屏幕隐私守护者

想解决什么问题

在日常办公、远程协作和在线学习场景中，用户频繁需要共享屏幕，却常常无意间暴露密码、私聊消息、财务信息等敏感内容。同时，在公共场合使用电脑时，旁人瞥视也可能造成隐私泄露。目前市面上缺乏一种能在屏幕内容呈现之前就主动检测并保护敏感信息的本地化工具。

为什么会想到做这个

灵感来源于一次真实的线上会议经历：一位同事在共享屏幕时，聊天窗口弹出了包含薪资信息的私聊，整个会议组都看到了。这种"事后才意识到"的隐私泄露几乎无法避免。我们意识到，如果有一个本地运行的 AI 助手，能在屏幕上实时识别这类敏感区域并自动模糊或提醒用户，就能从根本上预防此类问题。

大概是什么产品

一款运行在 PC 本地的桌面端系统应用（支持 Windows / macOS），以常驻后台的轻量代理形式运行，配合屏幕覆盖层实现实时隐私保护。

目标用户及痛点

面向哪些用户

  • A 远程办公 / 混合办公族：每天需要频繁加入 Zoom / Teams / 飞书会议并共享屏幕的白领群体。
  • B 内容创作者与开发者：在直播、录屏、写代码时需要保护 API Key、数据库密码等技术敏感信息。
  • C 学生与教育工作者：在网课、在线答辩等场景中保护个人隐私和学术数据。
  • D 隐私敏感型用户：在咖啡厅、图书馆等公共场所使用电脑，担心旁人窥视。

在什么场景下使用

  • 1 屏幕共享前：开启 ScreenShield 后，一键扫描当前屏幕，快速定位并遮盖所有敏感区域。
  • 2 会议进行中：实时监控屏幕变化，当检测到新出现的聊天窗口、通知弹窗包含敏感内容时，自动模糊处理。
  • 3 公共场合办公：启用"防窥视模式"，对指定应用窗口（如密码管理器、银行 App）进行全局模糊。
  • 4 直播 / 录屏：保护主播的本地隐私文件、后台管理界面不被观众看到。

当前痛点

人工遮挡不可靠

用户在共享屏幕前手动关闭窗口或遮挡区域，容易遗漏，且操作繁琐打断工作节奏。

弹窗与通知失控

会议中突然弹出的私聊消息、邮件通知无法预知，往往是隐私泄露的"重灾区"。

技术门槛高

开发者需要手动配置虚拟桌面、多显示器策略来隔离敏感内容，普通用户几乎无法操作。

价值与意义

💰

商业价值

面向企业级市场，可作为员工数据安全合规工具，帮助企业满足 GDPR、个人信息保护法等法规要求。同时可拓展为 SaaS 订阅模式，面向个人用户提供高级检测规则与自定义保护策略。

⚡

效率提升

消除用户在屏幕共享前的手动检查焦虑，将"关闭窗口 → 检查遗漏 → 开始共享"的流程从平均 2 分钟压缩至 1 秒。让用户专注于会议内容本身，而非隐私防范。

🌐

社会价值

降低因隐私泄露导致的网络诈骗、身份盗用风险，特别保护缺乏技术意识的老年用户和年轻学生群体。推动"隐私保护前置化"的理念——不是事后补救，而是事前预防。

🤖

技术创新

探索本地化 AI 视觉理解在隐私保护领域的创新应用。通过本地模型（如轻量化 OCR + NLP 分类）实现端侧推理，不依赖云端传输，用户数据零上传，从根本上解决隐私悖论。

核心理念：ScreenShield 不仅是一个工具，更是一种新的隐私保护范式——从"用户主动防御"转向"AI 主动守护"。我们相信，最好的隐私保护不是教会用户更小心，而是让技术替用户操心。
