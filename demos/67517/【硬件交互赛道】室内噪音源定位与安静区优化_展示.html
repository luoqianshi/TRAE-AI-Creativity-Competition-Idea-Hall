NOISE PAIN MAP

每个房间都有一个“吵点”，但它很难被准确找到

噪音不是均匀分布的。窗边、管道井、外机墙、电梯井、楼板传声点，都会让同一个房间出现明显的安静区和噪音区。

01

低频嗡鸣找不到源头

明明听得到“嗡嗡声”，却分不清是空调外机、冰箱压缩机，还是楼板震动传来的。

02

床位摆错整晚睡不好

靠窗、靠墙、靠管道井的位置可能刚好是噪音汇聚点，换个方向反而更安静。

03

隔音材料买了也没效果

不知道应该堵窗缝、铺地毯、挂厚帘，还是挪家具，钱花在了错误位置。

04

白天安静，夜里才出现

噪音具有时间性和间歇性，靠一次主观听感很容易误判，需要连续采样和可视化。

参赛文案结构

保持“创意名称 + 目标用户 + 价值意义 + 附件说明”的格式，但把痛点从网络信号换成室内噪音和安静区优化。

1. 创意名称 + 创意介绍

「楼上的脚步声到底从哪传来」室内噪音源精确定位与安静区布置优化。用户拿着手机在室内行走，App 实时采集分贝、频谱和位置轨迹，生成噪音热力图，并推荐床位、书桌和隔音材料布置方案。

2. 目标用户及痛点

  • 租房居住、浅睡眠、临街居住用户
  • 远程办公、学习备考、播客录音人群
  • 不知道噪音源方向，只能反复挪家具
  • 隔音建议太泛，无法匹配自己的房间

3. 价值与意义

把安静区寻找从“凭感觉试错几周”压缩到“行走5分钟出热力图+1次调整”，帮助普通人用零装修或低成本软装改善睡眠、学习和工作环境。

4. 附件说明

HTML 文件包含噪音采集行走模拟 Demo、实时噪音热力图生成、安静区优化建议和技术原理说明，可作为 TRAE Work 创意产物附件提交。

TECH PRINCIPLE

手机传感器 + 声学特征 + 空间插值

Demo 用简化模型演示产品逻辑，真实产品可使用手机麦克风采集声压级与频谱，结合 IMU/PDR 行走轨迹估计室内位置。

01

行走采样

手机麦克风采集 dB(A)、低频占比、峰值频率，IMU 记录移动轨迹和方向。

02

噪音分类

根据频谱区分脚步冲击、交通低频、设备嗡鸣、人声混响等来源类型。

03

热力图生成

对采样点进行 IDW/克里金插值，生成房间级噪音分布和安静区边界。

04

优化推荐

结合床/桌/窗/墙位置，推荐安静摆放点和密封条、厚帘、地毯等低成本方案。

VALUE

让“吵不吵”从感受变成证据

效率提升

5分钟完成房间采样，自动发现最安静位置，减少反复搬床、搬桌、买错材料的试错成本。

低成本改善

优先推荐无需装修的调整方案，例如床位移动、软装吸声、窗缝密封和噪音源避让。

社会价值

帮助租房群体和浅睡眠人群改善睡眠与工作质量，让安静不只依赖高预算装修。
