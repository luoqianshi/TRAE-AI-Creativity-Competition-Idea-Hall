用户痛点

😰

磁盘空间告急

AI模型、视频素材、临时文件堆积如山，不知道哪些该删、哪些该留，眼睁睁看着磁盘变红。

😱

误删文件

手动整理文件时，一不小心删错了重要文件，追悔莫及，却无法恢复。

😓

重复劳动

每次整理完，过段时间又乱了，需要重新开始。缺乏自动化和持续维护机制。

解决方案

🤖

AI 智能分析

自动识别文件类型、用途和使用频率，智能判断是否应该迁移或保留。

🔒

安全第一

永不直接删除，所有操作都是移动到「待删除文件夹」，30天内随时可恢复。

⏱️

后台自动运行

定时扫描、智能分析、缓慢迁移，全程在后台执行，不打扰正常工作。

核心功能

🔍

智能扫描

集成 WizTree 高速扫描，按目录/类型/大小筛选，支持 CSV 导出。

🧠

AI 分析

规则引擎 + AI 兜底，自动识别文件用途、来源和迁移建议。

📋

标记管理

自动生成标记，支持手动修改，按标记分类生成迁移计划。

📦

安全迁移

先复制后删除，预校验机制，完整操作日志，全程可追溯。

↩️

一键恢复

支持单个/批量/通配符恢复，随时将文件移回原位。

📊

操作审计

记录所有操作，支持按时间/类型/路径查询，生成统计报告。

价值与意义

⚡

效率提升

自动化处理节省大量手动整理时间，后台运行不打扰工作，智能分析减少决策负担。

🛡️

数据安全

永不删除，30天回收站，完整审计日志，一键恢复机制，确保数据万无一失。

🌱

资源优化

智能识别闲置资源，释放磁盘空间，延长硬盘寿命，节能减排。

目标用户

🎨 设计师 & 创意工作者

拥有大量 AI 绘图素材、模型文件，需要智能分类和整理。

💻 开发者

积累了大量开源库、项目文件、临时文件，需要自动化清理。

🎬 视频创作者

素材堆积、版本混乱，需要系统化管理空间和素材。

📚 数据分析师

数据集、模型文件、实验结果繁多，需要高效管理。

快速使用

# 扫描目录 python file_warden.py scan "D:\dev" # 分析文件 python file_warden.py analyze # 迁移文件（AI模型优先） python file_warden.py migrate --tag "AI模型" # 恢复文件 python file_warden.py restore "Wan2.2_v1.1.safetensors" # 查看统计 python file_warden.py stats
