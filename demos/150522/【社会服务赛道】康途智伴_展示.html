📝

训练无人监督纠正

患者在家独自训练，没人看动作是否标准、量是否够。很多人凭感觉练，练不到位或练过了头，恢复效果大打折扣。

📋

方案一成不变

康复科医生出院时开的训练方案三个月不变，无法根据实际恢复进度动态调整，错过最佳康复窗口期。

🚨

异常发现不及时

患者训练中出现疼痛加剧、关节僵硬等异常，常常选择硬扛或拖延就医，导致二次损伤甚至不可逆后果。

TECH 02

个性化康复进度建模

基于患者年龄、手术类型、基础指标建立个性化恢复基线曲线，对比实际训练数据，识别恢复偏快/偏慢/异常停滞等情况。

# 恢复进度偏差检测 baseline = get_recovery_curve(age, surgery_type) deviation = compare(actual_progress, baseline) if deviation > threshold: trigger_adjustment()
TECH 03

AI 动态方案生成

根据恢复进度、训练完成率、疼痛评分等多维指标，结合医学康复指南知识库，自动生成下一阶段的训练方案调整建议。

# 方案调整逻辑 new_plan = ai_planner.generate( current_plan=plan, progress=progress, pain_score=pain, guideline="knee_rehab_v3" )
