01 / 创意介绍

AI 不该每次都重新认识你

🧠

想解决的问题

AI 对话工具（ChatGPT、Claude 等）每次开对话都是"失忆"状态。你上周聊过的项目、你的写作偏好、你踩过的坑，下次全忘了。用户反复重复背景信息，效率极低。

💡

为什么会想到做这个

作为重度 AI 用户，每天用 Claude Code 写代码、做内容、管项目。同样的话说了无数遍："我喜欢简洁代码"、"别用破折号"、"先搜索再回答"。与其每次手动说，不如让 AI 自己记住。

📦

大概是什么产品

一份 SKILL.md 文件，装进 Claude Code 或 Codex。AI 自动获得：知识库管理（Obsidian 联动）、持久记忆、AI 写作、自媒体工具、电脑控制、自动进化引擎。40+ 功能，3 步安装。

02 / 目标用户及痛点

谁需要第二大脑

🧑‍💻 程序员 / 开发者

场景：每天用 AI 写代码、调试、做 Code Review

痛点：AI 不记得你的代码风格偏好、项目架构约定。每次都要重新解释。"别用 var"、"用函数式写法"、"先看现有代码再改"——说了一百遍。

✍️ 自媒体创作者

场景：用 AI 写脚本、标题、文章，多平台分发

痛点：AI 不知道你的文风、人设、历史选题。生成的标题总差一口气。想找之前写过的素材，翻聊天记录翻不到。

📊 知识工作者 / 研究者

场景：大量阅读、笔记、知识整理、输出报告

痛点：笔记散落在各种工具里，AI 搜不到。想让 AI 基于已有知识库回答问题，但它没有访问权限。知识不成网，成孤岛。

🎯 效率工具控

场景：同时用多个 AI 工具，追求自动化

痛点：每个工具都要单独配置、单独对话。想要一个统一入口：记笔记 + 搜知识 + 写文章 + 控制电脑 + 追踪数据，全在一个对话里搞定。

03 / 解决方案

Nexus 怎么工作

1

触发词拦截

用户说"外脑 AI Agent 最新进展"，Nexus 自动拦截 → 分类（知识/洞察/项目/日常）→ 深度加工 → 写入 Obsidian 知识库。用户不需要打开任何笔记软件，说一句话就记完了。

2

双向链接自动补全

写入新笔记时，Nexus 用 ripgrep 搜索知识库已有笔记，自动在底部补 [[双向链接]]。知识不成孤岛，自动成网。每篇笔记至少 3 个双链。

3

用户档案自动维护

Nexus 持续更新 user-profile.md：你的身份、偏好、高频话题、近期关注。下次对话开始时，AI 先读档案，已经知道你是谁、喜欢什么。

4

Nexus Evolve — 自动进化引擎

每晚凌晨自动扫描所有历史对话 → AI 提取反复出现的任务和偏好 → 门控验证（≥3 个会话证据 + 比现有规则更优 + 离线回放通过）→ 自动写回 CLAUDE.md。第二天打开，AI 已经更懂你了。
