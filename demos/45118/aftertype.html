“打字”在当代工作里无处不在，却很少属于个人。Aftertype 把字符从“疲惫的痕迹”转成“生活的生产力”。

PROBLEM

工作变成纯消耗，意义感断裂

年轻人被困在工作里：时间被剥夺、生活半径收缩、情绪内耗加重。即使有空，也渐渐失去探索世界的勇气与期待。

时间被挤压 意义感断裂 生活萎缩 焦虑内耗
INSIGHT

字符属于公司，但“字符值”可以属于你

当码农写代码、产品写 PRD、运营写文档… 每天输出的字符本质上是“劳动的计量器”。既然无法否认工作，就让它至少能兑换一点生活。

把工作转成可能性 不打鸡血 不强迫自律 让她去生活
Typing-to-Life Loop 工作越多 → 她的生活越精彩 → 情感越深

目标用户：被工作吞没的知识工作者

25-35 岁，一线城市白领与互联网从业者。日均打字量 8000-15000 字。

他们不缺“应该去生活”的道理，缺的是在高压之后仍能对生活保有一点点期待的能量。

SCENES

三个微小但关键的打开时刻

加班、通勤、收工。每次打开不是“任务提醒”，而是“生活回声”。

加班时：她在替你生活 通勤/午休：刷她的动态 收工后：看今天的字符换来了什么 想买点什么：进入商店
GAP

现有产品的空白

桌宠/电子宠物需要你投入时间去照顾；习惯养成类 App 催你去做事。Aftertype 反过来：把你已经在做的事（工作打字）转化为生活想象力。

不是“再多做一点” 是“让消耗变成希望” 不是强控制 是带一点真实的不可控

产品形态：移动 App + 桌面端字符采集器

核心体验是一条“数字人生活 Feed”，以及一套双货币体系。

你不需要“做更多”。你只需要继续工作，她就会继续生活。

MVP 核心
字符采集 → 兑换货币 → 数字人自主生活 → Feed 呈现。把“今天打了 12000 字”变成“她用这些字符去巴黎看了展”。
不可控感
你不能强制她去哪。她有时候去巴黎，有时候在家看书。这种不可控让体验更像生活，而不是任务系统。
商店
用 Char 或 Token 为她挑选物品，让品牌植入成为“经历”，而不是“露出”。
体验语气
不催促、不说教、不评判。像一条安静的回声：你在努力，她也在好好生活。
Char（零门槛） earned from typing

基础体验的普惠性：每一次打字都能获得，驱动日常生活事件与普通物品。

Token（有门槛） scarcity layer

高阶体验的稀缺性：限量款机制与更深度的 AI 互动，形成“越投入 → 越精彩”的增长飞轮。

价值与意义：把焦虑换成一点点希望

不是反抗现实，而是在现实里给生活留一道缝。

Aftertype 的核心不是“效率”，是“情绪转化”。让工作不再完全被公司占有，让个体重新拥有一种微弱但持续的生活感。

SOCIAL VALUE

重构工作的意义感

当你没时间去看的世界，她替你去了；你没力气做的事，她在做。替代人生不是逃避，而是把疲惫变成一种温柔的证据：你仍然与世界保持连接。

不打鸡血 不强迫改变 把消耗变成可能性
BUSINESS VALUE

品牌情感场景植入

品牌不是买一块 banner，而是买一次“被经历”的场景。当她背上帆布包、住进民宿、收到限量手袋，品牌进入用户的情感叙事：不是被看到，而是被记住。

场景即广告 情绪即粘性 双货币护城河
FAR VISION

AI 原生消费（远期想象）

当数字人具备更强的自主决策能力，一个更激进的方向是：由她自己向品牌完成购买决策。 但这需要品牌信任、结算机制、风控体系与更精细的“自然交互”呈现。MVP 阶段更现实的路径，是由用户为她购买，让“替代人生”先成立。

复杂但想象力巨大 先让体验真实 再谈交易链路
