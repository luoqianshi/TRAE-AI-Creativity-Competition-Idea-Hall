CORE FEATURES

四大核心能力，覆盖墨水屏壁纸全场景

FEATURE 01

墨水屏二值化工作台

不是简单加个黑白滤镜。本工作台输出仅 #000 与 #FFF 的纯二值化图像，专为墨水屏的物理特性重新设计。

  • 实时阈值滑块（0-255），拖动即看效果
  • 4 种二值化模式：全局阈值 / Otsu / 自适应 / Kindle 优化
  • 100% / 200% / 400% / 800% 像素级预览
  • 黑白占比与残影风险实时分析
