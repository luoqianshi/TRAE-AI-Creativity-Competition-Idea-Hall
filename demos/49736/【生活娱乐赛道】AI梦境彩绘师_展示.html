TECHNOLOGY

技术原理与亮点

每一个梦境背后，都有一套精密的算法在编织色彩与声音。

01

关键词驱动的程序化绘画

根据关键词匹配色彩体系（HSL 色环定位）、构图规则（中心放射/水平分层/螺旋）和画笔算法（流体/粒子/有机曲线）。每个关键词对应独特的绘制管线，确保"会飞的鱼"和"燃烧的花"呈现截然不同的视觉语言。

keyword → colorPalette + composition + brushAlgo → Canvas API
02

Canvas 实时动画管线

采用 requestAnimationFrame 驱动的渐进式绘制策略。背景层→主体层→粒子层→光晕层依次渲染，每层都有独立的动画参数（速度、透明度、位置偏移），形成层次丰富的动态视觉效果。

renderLoop: bgLayer.draw() → bodyLayer.draw() → particleLayer.draw() → glowLayer.draw()
03

Web Audio 氛围合成

使用 OscillatorNode 生成基础音调，BiquadFilterNode 塑造音色，GainNode 控制 ADSR 包络，ConvolverNode 添加空间混响。不同关键词映射到不同的调式音阶和波形类型（正弦/三角/锯齿）。

osc → filter → gain → reverb → destination | note = keyMap[keyword]
04

荣格象征学解析引擎

构建梦境意象符号库（水/飞行/火/建筑等），结合情感极性分析，从"自由-束缚""创造-毁灭""探索-逃避"等心理维度输出解析文本，让解梦既有文学美感又有心理学依据。

symbolLib[fish] = {freedom: 0.8, emotion: "渴望突破"}
