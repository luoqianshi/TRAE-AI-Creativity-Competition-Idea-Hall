CORE FEATURES

六个核心模块，覆盖背诵全流程

从导入到坚持，每一项功能都对应一个真实的用户价值。

AI 协作式导入

提供标准化提示词模板（法条拆解 / 名词解释 / 简答 / 数字记忆），用户用自己惯用的 AI 工具（ChatGPT / Claude / DeepSeek 等）批量转换后，按指定格式一键导入。算力成本留在用户侧，价值留在产品侧。

P0 · 录入

动态红黑榜记忆引擎

答对 3 次入红榜休眠，答错 1 次入黑榜强攻。黑榜按 5min → 15min → 1h → 睡前 递减间隔反复摩擦，只盯错题，放过熟题。

P0 · 引擎

三击热区无摩擦交互

背诵界面仅 3 个巨型热区——左=忘记、中=模糊、右=掌握。专为地铁、午休单手大拇指操作设计，<100ms 跟手响应。

P0 · 交互

通勤盲听模式

调用系统 TTS 语音朗读 + 蓝牙耳机音量键 / 双击手势反馈。视线零占用，驾车、地铁、运动中都能完成复习。

P0 · 场景

考前 24h 突击模式

考前一键开启，自动冻结红榜全部休眠卡，100% 算力轮播黑榜错题。直击"临时抱佛脚"的最高性价比策略。

P0 · 冲刺

双端兼容 & 隐私优先

同时支持 Android 9.0+ 与 HarmonyOS 4.0+。题库本地 SQLite 存储，数据默认不出设备，无网完全可用。
