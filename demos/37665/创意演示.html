✨ 解决方案

六边形地图编辑器

直观的六边形网格系统，支持多种地形类型，快速绘制战斗地图

角色管理系统

预设角色库，一键放置角色，自动计算移动距离和战斗状态

战斗管理

🎮 功能演示

核心功能

  • 六边形网格地图绘制
  • 多种地形类型（平地、障碍、水域等）
  • 角色预设库（玩家角色、怪物）
  • 拖拽放置/删除角色
  • 自动移动距离计算
  • 回合制战斗管理
  • 地图保存/加载
  • 角色编辑面板

技术特点

  • React + TypeScript 开发
  • Zustand 状态管理
  • Canvas 高性能渲染
  • 响应式设计
  • 本地存储支持
  • 开源免费
React TypeScript Zustand Canvas TailwindCSS
