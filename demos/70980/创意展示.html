UAI

UAI 便携助手

装进口袋的本地 AI 系统专家 —— 一款将本地大模型与系统工具封装进 U 盘的便携 AI 助手，插上任意 Windows 电脑即可对话式管理进程、软件、服务、诊断与报告生成。

U 盘便携 本地推理 零安装零残留 Function Calling 隐私安全 离线运行
01 / PROBLEM

我们解决了什么问题

传统系统维护工具的困境 vs UAI 的解法

×
传统方案的痛点
  • 清理/维护工具需安装，常捆绑推广软件、窃取隐私
  • 云端 AI 助手依赖网络，系统级操作需上传敏感信息
  • 远程协助体验差，老年人难以配合操作
  • 多台设备维护需重复安装配置，缺乏便携方案
  • 系统问题排查门槛高，普通用户看不懂任务管理器
  • IT 运维现场支持需在客户机装软件，污染宿主系统
✓
UAI 的解决方案
  • 整体打包至 U 盘，插入即可双击运行，无需安装
  • 本地 AI 推理，全程离线，不上传任何数据
  • 对话式交互，老人说一句"清理垃圾"即可执行
  • 一份配置随 U 盘迁移，多设备复用零配置
  • AI 自动调用 14 个系统工具，复杂操作自动化
  • 用完拔出 U 盘，宿主电脑零残留、零痕迹
02 / ARCHITECTURE

技术架构

分层设计 · 模块解耦 · 便携优先

桌面壳
Tauri 2.0 Rust 后端 + 原生 WebView 前端，体积仅 6.3MB
AI 引擎
llama.cpp sidecar 子进程（llama-server.exe），OpenAI 兼容 API
AI 模型
Qwen2.5 7B-Instruct Q4_K_M 约 4.5GB，支持 32K 上下文，本地 GPU 推理
通信层
Tauri Channel + SSE 流式响应 + Function Calling 多轮工具调用
工具层
14 个预设系统工具 进程/服务/软件/诊断/清理/报告，Rust 实现
权限网关
oneshot channel + 120s 超时 敏感/危险操作弹窗确认，防 AI 误操作
便携层
exe + runtime + config 同级目录 配置文件随 U 盘迁移，不写注册表
03 / FEATURES

五大核心功能

对话即操作 · 工具自动调用 · 一键完成

💬
AI 对话
本地大模型流式对话，AI 通过 Function Calling 自主调用 14 个系统工具完成实际操作，"对话即操作"。
list_processes kill_process run_powershell
📦
软件管理
独立 UI 页面，软件列表总览、单个卸载/强力卸载、安装监控、更新检查，左列表右详情布局。
list_installed_software uninstall_software force_uninstall_software
🩺
诊断中心
磁盘/内存/CPU/服务/系统文件/网络六大模块诊断，垃圾清理支持临时文件、回收站、更新缓存等 6 类目标。
diagnose_system clean_junk_files get_gpu_info
📊
报告中心
系统诊断/软件清单/启动项/进程四类报告，一键导出 HTML/Word/PDF，保存到桌面便于归档。
generate_document report_generate
⚙️
设置中心
模型切换（扫描可用 .gguf）、AI 推理参数（上下文/GPU/温度）、监控设置，配置文件跟随 U 盘迁移。
config_save config_switch_model
🛡️
权限网关
敏感操作（杀进程/卸载/清理/PowerShell）弹窗确认，120 秒超时自动拒绝，AI 不可越权操作。
tool_confirm Allowed Tools

使用场景

02

网管/维修师傅随身携带 UAI U 盘，到客户现场插入电脑即可诊断+清理+生成报告，不污染客户机，报告带走归档
03
社区公益维修
志愿者带着 UAI U 盘到社区为居民修电脑，一份工具多方复用，降低公益门槛，对话式操作老幼皆宜
