创意介绍

问题、灵感与产品形态

Problem

想解决的问题

主流编程语言的语法全部基于英文抽象符号（for/while/break），对中文母语者增加了额外的认知负担。学习编程的第一道门槛往往不是逻辑本身，而是符号语言。

Inspiration

灵感来源

如果循环可以用"登峰"和"探底"来表达，代码会像自然语言一样直观。hilltop 先升后降、hillbottom 先降后升 — XLang 将中文语义融入语法设计，让控制流意图一目了然。

Product

产品形态

完整的编程语言工具链：xlangc.py（C++17 转译器）、xlangcc.py（x86_64 原生编译器）、xlang_libs.py（标准库）、playground.html（Web IDE）。

核心语法

XLang 独创的中文语义控制流

XLang 源码 (.xl)
loops.xl
# hilltop: 先上升后下降 # 语法: hilltop(类型 变量; 变量 : 起->峰->终): hilltop(int i = 1; i : 1 -> 5 -> 1): out("%d", i) # hillbottom: 先下降后上升 hillbottom(int i = 5; i : 5 -> 1 -> 5): out("%d", i) # forrand: 循环 10 次, rand = random(1,5) forrand(10, 1, 5): out("rand = %d", rand) # 简写循环: 1->5 表示 1 到 5 for(int i; i : 1 -> 5): out("%d", i) # 带步长 for(int j; j : 1 -> 5, 2): out("%d", j) # 倒序 for(int k; k : 5 <- 1): out("%d", k)
等效 C++ 代码
output.cpp
// hilltop → 两段 for 循环 for(int i=1; i<=5; i+=1) ... for(int i=4; i>=1; i-=1) ... // hillbottom → 先降后升 for(int i=5; i>=1; i-=1) ... for(int i=2; i<=5; i+=1) ... // forrand → 随机循环 for(int __i=0; __i<10; ++__i) { int rand = __xl_rand_int(1,5); if(rand == 0) break; } // for(int i; i:1->5): → i=1;i<=5;i+=1 // for(int j; j:1->5,2): → j=1;j<=5;j+=2 // for(int k; k:5<-1): → k=5;k>=1;k-=1
03

mainly 修饰符

任意函数均可成为程序入口

mainly.xl
# 传统入口 mainly code(): out("Hello XLang") return 0 # mainly 修饰任意函数 (必须有 3+ 参数) mainly int compute(int a, int b, int c): out("%d + %d + %d = %d", a, b, c, a+b+c) return a + b + c
Rule

规则

被 mainly 修饰的函数必须拥有 3 个或更多参数。如果没有 mainly code():，则被修饰的函数直接作为程序入口。

Init

参数初始化

C++ 转译器中参数自动初始化为 0；原生编译器中参数寄存器在函数 prologue 中被清零，行为一致。

08

双编译器架构

xlangc.py — C++17 转译器
$ python3 xlangc.py demo.xl -o demo.cpp $ g++ -std=c++17 demo.cpp -o demo # 完整支持 97 个关键字 # 支持所有标准库函数 # 跨平台编译运行 # 生成可读 C++17 代码
xlangcc.py — x86_64 原生编译器
$ python3 xlangcc.py demo.xl -o demo $ ./demo # 直出 x86_64 机器码 # 零依赖运行 # 支持 int/double 运算 # 寄存器传参约定

同一份 .xl 源码，两种编译路径

开发时用 C++ 转译器获得完整的标准库和调试能力；部署时用原生编译器生成独立的 x86_64 二进制。
