Features

六大核心功能

从拍照识别到个性化建议，覆盖食品安全分析的完整链路

智能识别

拍照或上传配料表图片，OCR 精准识别文字，AI 自动结构化解析每种成分名称和含量

成分分析

逐条分析每种添加剂、主料、辅料、过敏原的安全性与作用，标注是否为高风险成分

风险评级

可视化风险雷达图，从添加剂、过敏原、高糖、高盐、高脂肪等维度展示风险分布

健康匹配

结合用户身高、体重、年龄、慢性病、饮食禁忌，计算个人专属风险等级

综合评分

A/B/C/D 四级可食用评分，配合百分制打分和综合概述，让安全性一目了然

食用建议

基于个人健康状况给出"推荐/谨慎/不建议"结论，并提供具体食用量建议和替代方案

Users

精准服务六大人群

每个群体都有独特的饮食安全需求，我们一一覆盖

健身/减脂人群

严格控制热量与宏量营养素

需要精确控制蛋白质、碳水、脂肪比例，关注隐藏的糖分和反式脂肪酸

慢性病患者

糖尿病、高血压、肾病等

需要严格限制钠、糖、蛋白质等成分摄入，配料表上的专业术语看不懂

宝妈群体

婴幼儿食品安全第一

关注婴幼儿食品中的添加剂、防腐剂、过敏原，需要专业可靠的判断依据

老年人群

视力与健康双重挑战

视力不佳难以阅读小字配料表，同时高盐、高糖、高脂肪食品风险较高

素食/宗教饮食

精准识别隐藏成分

需要辨别配料表中隐藏的动物成分、酒精、宗教禁忌食材

健康意识人群

追求品质生活

想吃得健康但缺乏专业知识，希望有一个简单可靠的食品安全助手

Value

三重价值驱动

商业价值、效率价值、社会价值三位一体

商业价值

  • ●健康饮食万亿级市场规模
  • ●"免费基础版 + 付费深度报告"模式
  • ●可向食品企业提供 B 端数据服务
  • ●与健康机构、保险公司合作变现

效率价值

  • ●3 秒完成配料表全量分析
  • ●从"看不懂"到"秒懂"，决策效率提升百倍
  • ●AI 结构化 JSON 输出，前端直接渲染
  • ●无需专业知识，降低健康饮食门槛

社会价值

  • ●提升全民食品安全意识

  • ●助力"健康中国"战略落地
Tech Stack

技术架构方案

Flutter + H5 双端覆盖，AI 大模型驱动，全链路技术方案

Flutter 跨端 App

一套代码覆盖 iOS 和 Android，提供原生级体验，支持相机调用、本地存储、推送通知

H5 轻量化网页

无需下载，微信/浏览器即扫即用，降低使用门槛，适合一次性查询场景

AI 大模型分析

调用大模型 API（TRAE/Claude/DeepSeek）进行成分分析，输出统一 JSON 格式，便于前端可视化渲染

OCR 文字识别

集成百度/腾讯/阿里云 OCR 服务，精准识别配料表图片中的文字，支持中英文混合识别
