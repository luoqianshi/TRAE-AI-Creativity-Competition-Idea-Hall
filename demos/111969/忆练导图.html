Introduction

知识点和题目，
不该是两座孤岛

市面上的工具要么只有记忆卡片（如 Anki），要么只有思维导图，要么只有题库。知识体系、练习题、复习计划被割裂在三个不同的工具里，学习效率低下。

MindMap Anki 把这三者合为一体：用思维导图组织知识体系，在末端节点创建 Anki 风格的题目卡片，内置 SM-2 间隔重复算法自动安排复习。

产品形态是一个纯前端网页应用，打开浏览器即可使用，数据存储在本地，无需注册登录。

Pain Points

学习效率低的根源

大学生在复习备考时，面临的核心问题不是不努力，而是工具割裂导致效率低下。

知识点和题目割裂

Anki 只有记忆卡片，没有知识体系；题库只有题目，看不到知识全貌。两者分开复习，来回切换浪费时间。

复习不科学

没有遗忘曲线提醒，不知道该复习什么。要么重复复习已掌握的内容，要么遗漏薄弱环节，事倍功半。

思维导图不能互动

现有思维导图工具只能展示知识，不能在上面做题、不能追踪复习进度，看完就忘，缺乏主动回忆。

Core Features

三大功能，合而为一

思维导图 + Anki 卡片 + 遗忘曲线，一个工具搞定全部。

可视化思维导图

自由创建和编辑思维导图，将知识点按层级组织。拖拽缩放、展开折叠，清晰展示知识体系全貌。

在知识点上创建题目

在思维导图的末端节点上直接创建题目，支持文字、图片、自定义选项。把每个知识点变成可练习的 Anki 卡片。

内置遗忘曲线

基于 SM-2 算法自动计算最佳复习时间。节点颜色实时反映复习状态，科学安排复习计划。
