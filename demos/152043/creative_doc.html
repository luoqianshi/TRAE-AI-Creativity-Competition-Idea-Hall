使用指南

快速上手大数据分析平台

🖥️

启动后端服务

运行 python backend/simple_server.py 启动API服务，监听端口8000

🌐

启动前端服务

运行 python -m http.server 8080 启动静态文件服务，访问端口8080

📁

上传数据

在前端界面点击上传区域，选择CSV文件进行数据导入

🔍

选择分析维度

点击地区分析、趋势分析、产品分析按钮切换不同的分析视角

📊

查看可视化结果

系统自动生成图表和统计数据，在仪表盘展示核心指标

💡

获取智能洞察

阅读系统生成的智能洞察，获取数据背后的业务价值
