解决什么问题

🍎

macOS 无类似工具

市面上的图色工具大多仅支持 Windows 系统，Mac 用户无法使用，学习 AutoX.js 等辅助框架时缺少配套工具。

🔄

多软件切换繁琐

开发时需要在 VSCode、取色工具、截图软件之间来回切换，效率低下，打断开发思路。

📝

手动编写代码

获取颜色和坐标后，需要手动编写找色找图代码，容易出错，且不同平台语法不同。

🤖

AI 协作不便

使用 Trae 等 AI 编程工具时，无法同时进行取色操作，需要在多个窗口间切换。

// 图色助手 - 自动生成的找色代码
function findTargetColor() {
  let x = -1;
  let y = -1;
  
  // 截图并获取颜色数据
  let img = captureScreen();
  
  // 👇 点击图片取色后将在此插入代码
  
  if (x !== -1 && y !== -1) {
    toast("找到颜色: (" + x + ", " + y + ")");
    click(x, y);
  } else {
    toast("未找到目标颜色");
  }
  
  img.recycle();
  return { x, y };
}
