PyArena

智慧安全编程学习平台
一款融合在线编程沙箱、AI 智能辅导、网络拓扑实验的一站式 IT 技能学习平台
让每个初学者都能在浏览器里安全地写代码、跑实验、学网络，无需任何本地环境配置。
💡

一、创意名称与介绍

PyArena — 解决什么问题？为什么做它？它是什么？
🎯 想解决什么问题
传统 IT 教学中，学生需要本地安装 Python、配置网络环境、搭建虚拟机才能开始练习——高门槛的环境配置让大量初学者在"写第一行代码之前"就放弃了。同时，教师在批改编程作业、分析学生错误时效率极低，无法做到针对性辅导。
🚀 灵感来源
在信息安全与网络工程教学中，学生缺少一个"可以随便折腾、不会弄坏"的实验环境。同时，编程初学者遇到报错时往往束手无策，需要一位"随时在线的 AI 助教"来引导他们理解错误、自己修复。
🖥️ 产品形态
一款基于 Web 浏览器的在线学习平台（Django 全栈 Web 应用），学生打开浏览器即可学习课程、运行代码、做网络实验、参加测验——零安装、零配置、随时随地。
⚙️

二、核心功能矩阵

6 大核心模块，覆盖 IT 学习的完整闭环
📖

体系化课程学习

涵盖 Python 基础、Django Web 开发、Linux 运维、网络安全、人工智能、OpenCV 计算机视觉等 10+ 门课程，章节式推进，支持 Markdown 图文与视频教学。

💻

在线编程沙箱

浏览器内直接写 Python 代码并实时运行，服务端安全沙箱隔离，支持 input() 交互式输入，有代码超时保护和安全检查，自动缓存代码防丢失。

🌐

虚拟网络拓扑模拟器

可视化拖拽搭建网络拓扑：路由器、交换机、服务器、PC 等 10+ 种设备，支持配置 IP、VLAN、静态路由，模拟 ping 连通性测试——让学生在浏览器里拥有自己的"网络实验室"。

📝

智能测验系统

每章节配套选择题与编程题，编程题支持多组测试用例自动判分，难度分级，答题记录完整保存。

📊

学习进度看板

可视化展示课程完成度、做题数、正确率、学习时长等数据，帮助学生清晰掌握自己的学习状态与薄弱点。

🤖

三、AI 智能辅导（核心亮点）

接入 DeepSeek 大模型，做每个学生的专属 AI 编程助教

🌟 代码出错？AI 来引导你修复！

当学生代码运行报错时，系统自动解析错误类型、定位行号，并调用 AI 进行引导式教学——不直接给答案，而是用提问帮助学生自己发现问题。

❯ 学生代码运行报错:
NameError: name 'prnt' is not defined (第 3 行)

🤖 AI 助教回复:
### 🔍 问题在哪
第 3 行调用了 `prnt()` —— 看起来像是少了一个字母？

### 🎯 怎么修复
Python 中打印输出的内置函数叫什么？仔细对照一下拼写~
👥
