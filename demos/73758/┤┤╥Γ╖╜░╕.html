一、创意介绍

想解决什么问题

科研论文中的数据造假是一个严重且隐蔽的问题。一篇投稿论文的 Supplementary Table 可能包含数十个工作表、数千行数据，编辑和审稿人只能依靠肉眼逐一核对——这不仅耗时巨大，还极容易遗漏微妙的数值规律。例如，"表 A 第 3 列的数据乘以 1.08 正好等于表 B 第 7 列的数据"——这种人工几乎不可能发现的规律，正是数据造假的常见痕迹。

为什么会想到做这个

身边有多位学术期刊编辑朋友，长期饱受论文数据审稿之苦。一份稿件的数据附件，人工核对需要数小时甚至数天。如果有一个工具能在数十秒内自动扫描所有数据模式异常，他们就能把精力放在真正需要专业判断的地方。

大概是什么产品

桌面端（Windows EXE 免安装运行）+ Web 端（浏览器即用），两端的核心比对引擎完全共享同一套算法，确保结果一致。

二、目标用户及痛点

面向哪些用户

  • 学术期刊编辑与审稿人
  • 科研诚信审查专员
  • 高校学术道德委员会成员
  • 需要内部数据复核的研究团队与实验室

在什么场景下使用

编辑收到投稿论文后，将其 Supplementary Tables（Excel/CSV 格式）上传至工具。一键启动比对后，工具自动：

  1. 智能识别每个 Sheet 中的数值矩阵（跳过表头/空行/非数据区域）
  2. 在同一文件内和跨文件之间检测精确重复、等比关系、等差关系、小数位截断痕迹
  3. 生成结构化的比对报告（支持 Excel/PDF 导出）

当前痛点对比

没有工具时

  • 人工肉眼比对，数百行数据需数小时
  • 难以发现跨表、跨文件的数值规律
  • 比对结果无法系统化记录和导出
  • 多个编辑之间无法共享审查进度

使用本工具后

  • 全自动扫描，数十秒出结果
  • 自动检测四种算法模式，一网打尽
  • 一键导出 Excel/PDF 报告
  • Web 端支持多人协作（密码保护）

三、核心功能亮点

四种智能比对算法

算法 说明 示例
精确值相等 检测完全一致的数据行/列 表A的第3行 = 表B的第5行
等比关系 检测通过固定比例缩放的数据 表A × 1.08 = 表B
等差关系 检测具有固定偏移的数据 表A + 0.5 = 表B
小数位连续相等 检测尾数相同的数据段 两个数据段末3位完全相同

四、价值与意义

效率提升

将数小时的人工数据核对压缩到数十秒。一个 50MB 的 Excel 附件——数十个工作表、数千个数值矩阵——全自动扫描、比对、输出结构化报告，让审稿效率产生数量级的提升。

社会价值 — 守护学术诚信

学术诚信是整个科研体系的基石。Nature 曾报道，每年有上千篇论文因数据问题被撤稿，而被发现只是冰山一角。让造假成本更高、让检测成本更低，就是为健康的学术生态添砖加瓦。
