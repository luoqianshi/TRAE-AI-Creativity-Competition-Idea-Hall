01 creative intro

画面好看交给真实影像
声音联动交给前端效果

想解决什么问题

现代人入睡困难、睡眠质量差，市面上的白噪音 App 要么音色单一（只有纯噪音没有真实环境音），要么界面花哨复杂（睡前越看越清醒），缺少一个"声音真实自然、界面极简助眠"的解决方案。

为什么会想到做这个

我自己就是长期入睡困难的人，试过很多白噪音产品，发现两个普遍问题——合成白噪音听久了有"机器味"，不放松；界面信息密度高、亮度过高、交互繁琐，睡前用反而更精神。于是想做一个"画面像雨夜玻璃窗、声音像真实雨声、操作几乎为零"的睡前声景工具。

"画面好看"和"音频联动"这两件事，应该拆开用最简单可靠的手段分别解决，而不是指望一套复杂系统同时搞定。"

大概是什么产品

一个纯前端的网站应用（React + Web Audio API），打开即是全屏沉浸声景——循环实拍雨景视频打底（玻璃模糊处理），13 个白噪音音轨可自由开关叠加（含真实录音 + 算法合成两种音源），音频变化实时驱动画面上的雨滴涟漪效果。

核心思路

把"画面好看"交给真实拍摄的循环视频，把"音频联动"交给一层轻量的、故意做得夸张可感知的前端叠加效果。不追求"逼真"，追求"看得出联动"——用户瞥一眼就能确认，哦，这个画面真的在跟着声音活着。

02 users & pain points

为每一个睡不好的人
做一个不抢戏的陪伴者

i.
音色塑料感重
现有白噪音 App 多用合成音源，听久了有"机器味"。循环点有明显"咔哒声"，打断入睡节奏。真实环境音（雨声、篝火、海浪）的质感难以用简单合成复刻。
ii.
界面过亮过载
界面信息密度高、亮度过高、交互繁琐，睡前使用反而刺激神经。弹窗、广告、付费引导层出不穷，本来要睡觉，结果越用越清醒。
iii.
音轨固定不可叠加
大部分产品只能选一个预设场景，无法自定义"专属声境"。想要"雨声 + 远雷 + 篝火"这种组合？做不到。用户的个性化需求被锁死在预设里。
iv.
没有沉浸感
体验停留在"听收音机"层面，没有"画面跟着声音动"的视听协同。闭上眼是声音，睁开眼是静态封面，缺少让人愿意留下的氛围。
v.
下载安装门槛
需要下载 App、注册账号、授予权限，睡前才想起来用的人根本没耐心。一个"打开链接就能用"的网页形态，能覆盖更多临时性、低频次的使用场景。
vi.
版权风险不明
音视频素材来源不清，用户分享使用时心里没底。需要一套"录音 + 算法合成"的双轨方案，合成层既兜底版权风险，又作为技术亮点。

04 value & meaning

不只是助眠工具
是一份睡前的仪式感

社会价值
让 3 亿睡不好的人，几分钟进入放松状态
根据《中国睡眠研究报告》，超过 3 亿中国人有睡眠障碍，其中入睡困难占比最高。潮汐眠境用零门槛的网页形态（无需下载安装、打开即用）+ 真实自然音源 + 极简暗色界面，降低助眠工具的使用门槛，让更多人在睡前几分钟就能进入放松状态。

音频联动可视化效果还能提供"视听协同放松"的沉浸体验，比纯音频更有助眠效果——这是把"听白噪音"从被动接收升级为沉浸式氛围体验。
技术价值
用前端工程手段解决音频体验问题
项目用 Web Audio API 实现两个技术亮点：

一是录音文件首尾等功率交叉淡化算法实现样本级无缝循环（解决白噪音 App 普遍存在的循环咔哒声）；

二是 10 种环境音合成器作为录音兜底方案（零版权风险 + 可离线运行）。这两个技术点本身就是"用前端工程手段解决音频体验问题"的实践案例，对同类产品有参考价值。

05 technical highlights

不靠复杂架构
靠精准的工程取舍

i
无缝循环算法
web audio api
录音文件加载时对首尾做 50ms 等功率交叉淡化（sin/cos 曲线），处理后 buffer 用 loop=true 播放，样本级精确循环，无咔哒声。加载时一次性处理，运行时零开销。
ii
双音源架构
recording + synthesis
每个音轨同时创建合成器作为兜底，录音文件存在用录音，加载失败静默回退到合成。白/粉/褐噪音始终合成，零版权风险。合成层也是技术加分项。
iii
音频驱动可视化
canvas + analyser node
AnalyserNode 接在 masterGain 后取所有音轨混合数据，频谱分段驱动雨滴生成——音频变化自然决定雨滴密度、位置、大小，不是固定频率的机械生成。
iv
玻璃模糊性能优化
css filter strategy
Edge 浏览器在视频元素上直接 blur() 极耗 GPU。改用 backdrop-filter 遮罩模拟模糊感，13 个卡片的 backdrop-filter 全部移除改纯色半透明，DPR 限制 1.5。
v
自定义背景持久化
localStorage + dataurl
用户可上传图片/视频替换背景，图片转 DataURL 存 localStorage 跨刷新保留，视频因 5MB 限制刷新后回退默认。三层背景源（默认/自定义视频/自定义图片）统一滤镜。
