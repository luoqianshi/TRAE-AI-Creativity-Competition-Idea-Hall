## 1. 创意名称 + 创意介绍

### 1.1 创意名称

**PAW PAW｜给狗狗家长的 AI 暖心照护提醒板**

> Logo 字标草图：圆润衬线字体，第二个 "PAW" 的 A 用 🐾 爪印替代；品牌名节奏感强，亲切易记。
> Slogan：*让每一次照护都不掉线。*

### 1.2 创意介绍（≤200 字）

**想解决什么问题？**

中国 5,343 万城市犬背后，藏着三类高频"被遗忘"：驱虫周期、洗澡时间、生日仪式。再加上遛狗时没人记录"今天走了多远"。宠物店推销、朋友圈提醒都不持久。养狗家长既怕漏，又被信息洪流淹没。

**为什么会想到做这个？**

我自己就是"忘了给 Max 体外驱虫、晚了一周才发现"的真实用户。一次遛狗时看到陌生人用运动 App 记录跑步，突然想：**为什么遛狗没有人记录？** 主流宠物 App 多在做社区或电商，"提醒"反而没人深做——于是就有了 PAW PAW。

**大概是什么产品？**

一款 iOS + Android 双端的"暖心提醒 App"，9 大功能（驱虫 / 洗澡 / 生日 / 遛狗 / 多宠物档案 / 智能周期推荐 / 本地推送 / 庆祝动效 / 离线全功能），100% 数据本地存储，60fps 微动效，0¥ 永久免费。

## 2. 目标用户及痛点

### 2.1 面向哪些用户？

| 用户类型 | 占比（基于 5,343 万城市犬 × 69% 90/00 后宠物主） | 核心动机 |
|---|---|---|
| **新手养狗家长**（首 1 年） | ~38% | 不懂驱虫/洗澡频率，怕出错 |
| **多宠物家长** | ~22% | 多只狗健康节点易混淆 |
| **数据控 90/00 后** | ~31% | 想"打卡"遛狗，分享到小红书 |
| **异地养宠打工人** | ~9% | 周末遛狗 + 工作日寄养，节点易漏 |

### 2.2 在什么场景下使用？

| 场景 | 触发动作 | App 响应 |
|---|---|---|
| **周一早 9 点** | 收到"Max 该体外驱虫了"本地推送 | 1 键打卡完成 |
| **晚上 19 点** | 准备出门遛狗 | 点击底部 🐾 Tab → 1 秒启动实时记录 |
| **遛狗途中** | 偶遇朋友 | 把手机亮给朋友看"已走 0.8 km" |
| **遛狗结束** | 回到家 | 看到 18 分钟/1.2 km 总结，惯性点"分享" |
| **生日当天早 9 点** | 打开 App | 全屏彩纸 + 派对帽，2 岁啦 |
| **出差路上** | 突然想 Max | 打开 App 看历史轨迹、"上次溜了 2.3 km" |

### 2.3 当前痛点（没 PAW PAW 时会发生什么？）

| 痛点 | 现状 | 后果 |
|---|---|---|
| **驱虫忘做** | 体外每月 1 次，体内每 3 月 1 次，全靠记忆 | 跳蚤、蜱虫感染，皮肤病 |
| **洗澡凭感觉** | 忙就拖，懒就忘 | 异味、毛结、皮肤问题 |
| **遛狗没数据** | "今天走了 1 小时"，没距离 | 坚持不下来，看不到进步 |
| **多只狗混淆** | 家里的狗+父母家的狗 | 给 A 做了驱虫，以为 B 也做了 |
| **生日错过** | 工作忙忘了 | 失去了"仪式感"和发圈机会 |
| **App 太重** | 主流宠物 App 塞社区+电商+医院 | 注册 5 分钟，没人看通知 |
| **没网用不了** | 通勤地铁、出差、乡下 | 提醒 App 反而成了"摆设" |

**一句话痛点**：现有的宠物 App 把"提醒"做成通知通知通知，**而 PAW PAW 把"提醒"做成一个值得期待的小故事**。

## 3. 价值与意义

### 3.1 商业价值（3 年维度）

| 指标 | 估算依据 | 目标 |
|---|---|---|
| **TAM** | 中国 5,343 万城市犬 + 单狗年消费 ¥3,000 | ¥1,606 亿总市场 |

| **LTV** | ¥120/年 × 3 年留存 | ¥360 |
| **LTV/CAC** | 14.4（健康线 > 3） | ✅ |

### 3.2 效率提升（用户视角）

- **健忘成本降低 80%**：原本 1 个月漏 1-2 次驱虫 → 现在几乎 0 漏
- **遛狗坚持率 +200%**：30 天挑战达成率从 12% → 40%（有数据反馈 + 分享激励）
- **多宠物切换时间 < 5 秒**：原 App 找宠物档案 30+ 秒 → 顶部下拉 1 秒
- **决策时间 -90%**："Max 该洗澡了吗？" → 看一眼 App，1 秒判断

### 3.3 社会价值

1. **降低宠物遗弃率**：研究显示，宠物健康问题（皮肤病/寄生虫）是弃养第 3 大原因。PAW PAW 让"健康疏忽"变 0，直接减少弃养。
2. **陪伴时间可量化**：用"遛狗累计里程"重塑"养狗的意义"——从"喂饱就行"到"我陪它走了 128 公里"。
3. **老龄化城市的温暖缓冲**：上海/北京独居老人养狗率上升，App 操作极简（4 步 Onboarding），帮他们"被提醒"。
4. **建立宠物友好社区文化**：把"养狗"从私事变成可分享、可记录、可鼓励的公共叙事。
