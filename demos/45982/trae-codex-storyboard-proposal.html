AI 视频创作的本地分镜工作台

把脚本、分镜和素材生成放进同一张工作台。

Codex Storyboard 让 Codex 直接创建视频项目、规划镜头、生成图片或视频素材，并自动回填到对应分镜，减少创作者在文档、表格、素材文件夹和 AI 对话之间反复切换。

分镜项目管理 素材自动回填 本地优先保存
1 个本地分镜工作台，集中管理脚本、镜头、提示词和素材。
5 种画面比例，覆盖短视频、横屏课程、方形社媒等常见格式。
3 类AI 素材路由：Image Generation、HyperFrames、Remotion。
0 复制Codex 通过 MCP 写入项目，生成结果自动回到对应镜头。

Problem & Solution

短视频创作不是缺 AI，而是缺一个承接 AI 的生产流程。

脚本、镜头、视觉规范和素材生成如果分散在不同工具里，创作者会把大量时间花在整理、命名、复制和回填上。

当前痛点

AI 生成内容之后，仍然需要人工把它们变成可执行的分镜表和素材清单。

信息分散脚本在文档里，提示词在聊天里，素材在文件夹里，镜头状态很难一眼看清。
回填低效生成素材后还要下载、重命名、对应镜头，批量项目尤其容易出错。
风格不稳同一条视频里的图片和视频素材缺少统一视觉规范，整体质感容易割裂。

解决方案

Codex Storyboard 把 AI 对话生成的创意直接写进本地分镜表，并把素材生成队列、视觉规范和最终预览放在同一个工作台里。

Workflow

从一句视频想法，到一张可执行的分镜表。

用户不需要理解 MCP、本地 API 或文件路径，只需要把主题、平台和风格告诉 Codex。

说出创意 告诉 Codex 视频主题、时长、平台、受众和视觉风格。
创建项目 自动生成镜头、台词、画面描述、时长和生成方式。
检查分镜 在本地网页里像表格一样编辑和验收每个镜头。
生成素材 按镜头路由到图片生成、HyperFrames 或 Remotion。
自动回填 素材生成完成后回到对应镜头，直接预览和替换。

Product Screens

真实产品界面展示。

页面围绕专业内容生产场景设计，信息密度接近剪辑台和项目管理工具，重点服务检查、修改和验收。

多项目管理

不同视频选题可以独立保存、打开、重命名和删除，适合持续运营多个内容系列。

新建项目与画面比例

支持 9:16、16:9、3:4、4:3、1:1，创建时就确定目标发布形态。

分镜表格

镜头类型、媒体类型、台词、提示词、生成状态和素材预览集中在一张表里。

素材生成与回填

单镜头或批量加入队列，生成完成后自动回填到对应镜头，降低人工整理成本。

Target Users

面向需要高频产出视频内容的人。

短视频创作者 自媒体运营 课程内容制作者 产品演示团队 AI 工具测评博主 知识视频创作者

典型使用场景

把一篇文章改成短视频脚本；规划产品功能介绍视频；批量制作 AI 工具教程；为课程、演示和营销内容生成统一风格的镜头素材；把多人协作中的脚本和素材状态统一到一张可验收的表格。

Value

它的价值不只是生成内容，而是重塑内容生产链路。

Codex Storyboard 把 AI 能力放进可管理、可检查、可迭代的生产流程里。

效率提升

减少从 AI 对话到表格、素材文件夹、剪辑软件之间的手动搬运，让项目状态更清晰。

流程沉淀

每个视频项目都保留脚本、分镜、提示词、视觉规范和生成结果，方便复盘和二次创作。

本地优先

项目和素材默认保存到本机，适合创作者管理尚未公开的脚本、选题和素材资产。
