1创意介绍

想解决什么问题：多人旅行时垫付、代买、拼餐等账目分摊混乱，手动对账容易出错且收尾转账繁琐。

灵感来源：每次和朋友旅行结束后，总要花大量时间翻聊天记录算账，经常出现"谁欠谁多少钱"的混乱局面，传统记账软件又过于复杂且不适合旅行场景。

产品形态：一个轻量化的网页应用，支持创建旅行房间、快速记账、智能分摊核算和一键生成最优转账方案。

核心亮点：智能最优转账方案

通过贪心算法自动计算最少转账次数的结清方案。例如：A 多付 200，B 欠 120，C 欠 80 → 直接 B 转 A 120、C 转 A 80，不产生多余中转。

2目标用户及痛点

  • 核心用户：结伴出游的朋友、家庭亲子旅行、公司团建等多人共同消费场景。
  • 使用场景：旅行途中的餐饮、交通、门票、住宿等各类共同消费后，需要记录和分摊账目的时刻。
  • 当前痛点：没有专门工具时，需要手动记录每笔开销，再通过 Excel 或计算器反复核算，最后还要在群里多次小额转账，效率低且容易出错。

3价值与意义

效率提升：通过智能分摊算法，将复杂的多人账目自动简化为最少次数的转账操作，省去大量手动计算时间。支持均分、成人儿童比例分摊、自定义分摊等多种模式，适配不同旅行场景。

社会价值：降低多人出游的"算账摩擦"，让朋友、家人之间的金钱往来更透明，减少因账目不清产生的尴尬和矛盾，提升群体出行的幸福感。

4核心功能

🏠

创建旅行房间

输入行程名称，添加同行伙伴，支持标记成人/儿童身份。

📝

快速记账

6 大消费分类，选择付款人，一键记录每笔开销。

⚖️

多种分摊

均分、成人1儿童0.5比例、自定义份数，灵活适配场景。

🧮

智能结算

自动核算每人收支，生成最少转账次数的结清方案。

📊

分类统计

可视化展示各类消费占比，预算进度实时管控。

📤

导出分享

一键导出 CSV 账单，生成文字版结算单分享到微信群。

5使用方式

本项目为纯前端网页应用，使用 React + Vite + Tailwind CSS 开发，数据通过浏览器 LocalStorage 本地持久化。

  • 打开网页 → 创建旅行房间 → 添加成员 → 开始记账
  • 点击"记一笔" → 填写金额、分类、付款人、分摊规则 → 保存
  • 点击"一键结算" → 查看统计结果与最优转账方案
  • 点击"分享" → 复制文字版结算单到微信群
