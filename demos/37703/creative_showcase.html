// 01 问题

Windows 蓝牙音频
被困在石器时代的编解码里

01

原生支持贫瘠

Windows 默认只支持 SBC 和 AAC，无法发挥高端 LHDC 耳机的硬件潜力，Hi-Res 耳机被迫降级为普通音质。

02

专有协议封闭

LHDC 是 Savitech 专有编解码器，文档与 SDK 不公开，需要逆向 AOSP 实现并移植到 Windows 内核空间。

03

驱动开发门槛高

Windows 内核驱动涉及 WDK、KMDF、驱动签名、内核调试，对独立开发者来说是一座技术高山。

04

现有方案缺失

市场上的第三方 A2DP 驱动只支持 LDAC/aptX，没有任何现成工具能让 Windows 用上 LHDC v5。

// 03 特性

不只是驱动
是一次音频解放

01

原生 KMDF 驱动

基于 Windows Driver Framework 构建，深度集成蓝牙协议栈，而非外挂式 Hook，更稳定、更原生。

02

AOSP 移植编解码

从 Android 开源项目中提取 LHDC 编解码实现，跨平台移植为 Windows 原生 DLL。

03

Hi-Res 全规格

支持 24bit / 192kHz 采样、1Mbps 码率、自适应比特率，让 Windows 也能播放录音室级蓝牙音频。

04

实时状态面板

独立的配置工具显示当前连接编解码器、码率、采样率，让技术细节一目了然。

05

低延迟模式

支持 LHDC LLAC 低延迟模式，为游戏和视频场景提供更同步的音画体验。

06

开放学习价值

完整记录从 WDK 环境搭建到 AVDTP 协议实现的每一步，作为 Windows 驱动开发的实战教材。
