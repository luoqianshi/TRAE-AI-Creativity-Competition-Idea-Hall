01 · 问题与痛点

散户与非专业投资者在金融交易中面临的真实挑战
📊

信息过载，分析维度单一

财报、新闻、技术指标、舆情分散在各处，一个人难以同时兼顾基本面、技术面与情绪面的综合判断。

🧠

情绪化决策，缺乏辩论机制

单个人容易被市场情绪左右，缺少多空双方理性辩论的过程，常常追涨杀跌或过早止盈止损。

🔍

决策过程黑盒，难以复盘

"凭感觉"买入后一旦出错，无法定位是信息源、判断逻辑还是执行时机出了问题。

🌐

多市场覆盖成本高

美股、港股、A股、加密货币…不同市场数据来源、交易规则各异，个人研究者精力有限。

🎯 分析师团队 · 四大维度并行分析

  • 基本面分析师 — 评估公司财务、业绩指标、内在价值与潜在风险
  • 情绪分析师 — 聚合新闻、StockTwits、Reddit 舆情，研判短期市场情绪
  • 新闻分析师 — 监控全球新闻与宏观指标，解读事件对市场的影响
  • 技术分析师 — 利用 MACD、RSI 等指标识别交易形态与价格趋势

⚔️ 研究员团队 · 多空对抗式辩论

  • 多头研究员与空头研究员对分析师结论进行批判性评估
  • 通过结构化辩论，在潜在收益与风险间取得平衡
  • 支持配置最大辩论轮次，让论证更充分

💼 交易员 + 风控 + 组合管理 · 三级决策漏斗

  • 交易员汇总报告，决定交易时机与仓位规模
  • 风控团队持续评估组合风险、市场波动与流动性因素
  • 组合经理最终审批或否决交易提案，输出结构化决策

03 · 核心功能

为专业与非专业投资者设计的实用能力
🧩

模块化 Agent 架构

基于 LangGraph 构建，节点职责清晰，可单独替换或扩展任意分析模块。

🌍

全球市场覆盖

支持美股、港股、A股、东京、伦敦、印度、加密货币等 Yahoo Finance 覆盖的所有市场。

🤖

多 LLM 提供商

兼容 OpenAI、Anthropic、Google、DeepSeek、Qwen、GLM、MiniMax、Ollama 本地模型等 10+ 种。

📝

决策日志持久化

自动记录每次分析，下次运行时注入历史决策与反思，让系统从经验中学习。

🔄

断点续跑

LangGraph checkpoint 机制，崩溃或中断后从最近成功节点恢复，无需重新开始。

🖥️

交互式 CLI + Web UI

命令行向导式体验，也支持 Web 端可视化分析报告，随时查看各 Agent 推理过程。

🐳

Docker 一键运行

提供 Docker Compose 配置，免去环境依赖烦恼，一条命令启动全套服务。

🔬

可复现性控制

支持固定分析日期、调节温度、切换非思考模型，尽量降低 LLM 输出随机性。

05 · 使用流程

从启动到拿到决策建议，4 步完成
01

安装与配置

克隆项目、配置 .env 文件中的 LLM API Key，支持本地 Ollama 或云端模型。

02

选择标的

输入股票代码（如 AAPL、600519.SS、BTC-USD）与分析日期，选择研究深度。

03

Agent 协作分析

观察四大分析师 → 研究员辩论 → 交易员 → 风控 + 组合经理的完整推理链。

04

获取决策报告

输出结构化的交易建议，含理由、风险提示与历史复盘反思，辅助你的最终判断。

06 · 价值与意义

对个人、行业与社会的三层价值

💡 效率提升价值

将原先需要 数小时 的多维度研究（查财报、看新闻、算技术指标、读评论）压缩为 几分钟 的自动化流程。

Agent 协作机制替代个人独自分析，避免遗漏重要信息维度。

🎓 教育与研究价值

以开源框架形式呈现 对冲基金决策流程，让非专业投资者也能理解专业机构的分析思路。

支持学术研究：已发布 arXiv 技术报告，可用于多智能体系统与量化金融交叉研究。

🌱 社会价值

降低投资者的 信息不对称，推动决策过程从"凭感觉"走向"有依据"。

透明的 Agent 推理链帮助用户理解每一个结论的来源，培养理性投资习惯。
