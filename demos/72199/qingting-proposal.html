💡 创意背景

青少年心理健康问题日益严峻，但专业资源稀缺、求助羞耻感强、隐私顾虑重。青听 是一个不需要预约、不会评判、所有数据只存你手机里的 AI 心理健康伴侣。通过多模态情绪感知和 3 阶梯对话体系，帮助青少年在安全的环境中认知、表达和管理情绪。

🧩 核心功能

💬

心声对话

AI 情绪伙伴实时倾听。情绪关键词识别 + 上下文回复 + 危机关键词自动预警

📸

表情识别

摄像头实时检测 7 种面部情绪（开心/悲伤/愤怒/恐惧/惊讶/厌恶/平静），模型本地运行

📅

心情月历

动态月历视图 + SVG 柱状图趋势分析 + 14 日情绪周报

🛠️

减压工具箱

4-7-8呼吸法 / 正念冥想 / 情绪涂鸦 / 白噪音引擎（雨林/海洋/森林/粉噪）

🆘

求助通道

一键拨打 24h 心理援助热线 + 危机干预指南 + 专业资源推荐

🌱

新手指引

3 步 Onboarding 引导，帮助用户快速了解功能并开始情绪记录之旅

✨ 核心亮点

隐私双盲 — 全部数据本地存储，零服务器
3阶梯对话 — 宣泄→CBT引导→专业转介
多模态感知 — 文字+表情+月历趋势
PWA可安装 — 手机桌面直达，离线可用
AI完全本地运行 — face-api.js 模型离线
危机自动预警 — 自杀/自残关键词实时检测

🔧 技术方案

React 19 TypeScript Vite 6 TailwindCSS 3 Framer Motion 12 face-api.js TensorFlow.js PWA Dexie.js IndexedDB Web Audio API Noto Sans SC

🔐 隐私承诺

  • 所有情绪数据仅存储在你的手机本地（localStorage + IndexedDB）
  • 表情识别模型全部本地运行，摄像头画面不离开你的设备
  • 不收集任何个人身份信息
  • 不连接任何远程服务器（除字体CDN）
  • 无第三方统计、埋点或上报
