Chapter One — 创意介绍

一个关于表达公平的
简历生成工具。

想解决什么问题 / 01

大多数求职者在写简历时，要么面对空白文档无从下手，要么花了大量时间排版却仍然做出格式混乱、重点不突出的简历。

尤其是非设计背景的用户，很难在短时间内产出一份既专业又美观的简历。

为什么会想到做这个 / 02

求职是几乎每个人都会经历的场景，但"会做事"和"会写简历"之间存在巨大鸿沟。

很多人明明有很好的经历和能力，却因为简历表达不清、排版不专业而错失面试机会。灵感来源于身边反复出现的一个现象——朋友之间最常求助的不是技术问题，而是"帮我看看简历怎么改"。

大概是什么产品 / 03

一个基于 Web 端的智能简历生成工具，用户填写结构化的经历信息后，系统自动生成排版精美的 PDF 简历，并提供针对不同岗位的优化建议。

02
Chapter Two — 目标用户及痛点

为三种人而设计，
解决四个真实痛点。

Core User · 核心用户

应届毕业生— 第一份专业简历

即将步入职场，简历经验为零，急需第一份专业简历来打开求职大门。

Switcher · 跳槽者

职场跳槽者— 重新提炼经验

工作几年后需要更新简历，但不确定如何提炼过往经验，让经历更有说服力。

Freelancer · 自由职业

自由职业者— 作品型简历

远程工作者需要一份可灵活定制的作品型简历，来争取不同类型的项目机会。

在什么
场景下使用？

校招 / 秋招 / 春招集中投递期，需要在短时间内产出多份针对不同岗位的简历。

从传统行业跳槽到互联网等新领域，需要重新组织和包装自己的过往经历。

参加招聘会前临时需要一份拿得出手、能立刻给人留下印象的简历。

痛点 / Pain Point
具体表现 / Symptom — 没有 MyResume 时
P01不知如何下笔
面对空白 Word 文档，不清楚简历该包含哪些模块、经历该怎么描述，迟迟无法开始第一行字。
P02排版能力不足
用 Word 或免费模板调整格式，间距不统一、字体混乱、导出后变形，专业感大打折扣。
P03一份简历投所有岗位
因为修改成本高，用户倾向于用同一份简历投递不同岗位，导致岗位匹配度低、回复率差。
P04缺乏反馈机制
写完后不知道好不好，只能靠朋友随口点评，没有系统性的优化建议来指导迭代。

Chapter Three — 价值与意义

不止于效率，
更关乎公平。

Value 01 — 效率提升

把 6 小时，
压缩到 30 分钟。

传统制作一份质量尚可的简历，从构思内容到调整排版，通常需要 3–6 小时。

MyResume 通过结构化表单引导 + 自动生成排版，将这一过程压缩到 30 分钟以内。用户可以把省下来的时间用于真正重要的事情——研究目标公司、准备面试。

6–10×
效率提升倍数
30min
完成一份简历
3–6h
传统耗时
Value 02 — 社会价值

让能力表达，
回归公平。

简历质量不应成为阻碍人才被看见的门槛。

很多优秀的求职者——尤其是来自非重点院校、缺乏社会资源的学生——并非能力不足，而是缺少"包装能力"。

MyResume 通过降低专业简历的制作门槛，让能力表达回归公平，帮助更多人获得平等的面试机会。

"不是能力不足，
而是缺少被看见的方式。"
