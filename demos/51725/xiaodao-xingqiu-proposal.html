一个用 Godot 打造的低门槛小世界游戏：像次世代版 Minecraft 一样自由创造，但节奏更休闲友好。玩家有自己的角色，也有由 Agent 驱动的人形宠物伙伴，智能体会帮忙建造、生活、互动和生成故事。

把开放世界创作变成休闲日常

目标用户是喜欢 Minecraft 式自由创造、模拟经营、养成和轻社交的年轻用户，也包括有想象力但不擅长手动搭建、希望用一句话创建游戏内容的人。

用户痛点

很多开放世界和建造类游戏自由度高，但上手门槛、操作负担和内容规划成本也高；用户想创造一个世界，却常常卡在采集、搭建和规则理解上。

核心体验

玩家扮演自己的角色，在小岛上探索、建造、经营生活；身边的人形伙伴由 Agent 驱动，会主动帮忙搭建、整理、提出灵感，也能根据玩家一句话生成布局和事件。

差异化

Godot 负责实时场景、天气和互动表现，Agent 负责角色行为、建造规划和内容生成，让世界里的人物不再只是摆件，而是能理解目标、执行任务、推动故事的伙伴。

产品形态

先做 PC 与 Web 可体验 Demo，后续扩展到移动端。玩法从单人小岛生活开始，逐步加入 Agent 伙伴系统、自动建造工坊、好友拜访、主题市集和创作者生态。

初始版本

  • 创建玩家角色，进入一座可探索、可建造、可生活的小岛。
  • 拥有一个人形宠物伙伴，由 Agent 驱动日常行为和互动反馈。
  • 输入一句创作需求，让 Agent 伙伴自动生成小屋、小岛或任务方案。
  • 保存并分享自己的小岛截图或 HTML 展示页。

Agent 能力

  • 将“森林茶屋”“海边工坊”等自然语言需求拆成可执行建造步骤。
  • 驱动玩家伙伴执行采集、摆放、整理、陪伴和访客接待等行为。
  • 生成伙伴性格、日记、小岛访客事件和每日轻任务。

Agent 扩展

后续可以做成多 Agent 协作：设计师 Agent 负责空间风格，伙伴 Agent 负责角色行为和陪伴剧情，任务 Agent 负责每日事件，市集 Agent 负责推荐玩家和创作者发布的素材。

商业价值

可通过主题家具包、伙伴外观、创作者素材分成、Agent 能力订阅和季节活动变现，同时让用户持续沉淀个性化资产，提高留存与分享传播。

主题家具 伙伴外观 创作者市场

社会价值

它不是强调竞争的开放世界，而是一个低压力的数字角落。用户可以通过布置空间表达情绪，也能通过 Agent 伙伴的陪伴和主动行为获得稳定、轻量的精神放松。

情绪疗愈 审美表达 轻社交

Demo 目标

初赛 Demo 计划展示一个可操作的小岛：玩家能控制自己的角色，看到 Agent 伙伴主动行动，切换地形、改造小屋、保存布局，并让 Agent 根据一句话生成新的建造目标与摆放方案。这个版本能证明休闲版开放世界、智能体行为和内容生成可以结合在一起。
