01 / Problem

手机不是敌人，
失控才是。

我们不想消灭手机，而是想保留它的"有效信息"——闹钟、日程、来电——同时屏蔽掉那些吞噬注意力的"无效信息"——短视频、小说、无限流。

注意力碎片化

平均每 4 分钟查看一次手机，深度专注几乎不可能。短视频与推送让大脑长期处于多任务切换状态。

闹钟与干扰同源

为了不错过闹钟而把手机放在身边，结果却被一条推送带走 40 分钟。有效信息与干扰信息共用同一设备。

缺乏行为反馈

传统番茄钟依赖自律，没有客观的距离证据，也没有对"假装专注"行为的识别与记录。

02 / Concept

距离，是专注的
物理边界。

用手环作为"注意力哨兵"，
接管手机的有效信息。

进入专注模式后，手环通过蓝牙与手机建立连接，继承闹钟、来电、日程等关键提醒。手机本身被物理隔离，超出蓝牙极限距离即视为脱离专注区。

  • 01
    信息继承，而非信息屏蔽 闹钟、来电、日程同步到手环，错过重要事项的风险为 0
  • 02
    距离即证据 蓝牙 RSSI 测距，过近警告，过远脱离，全程客观记录
  • 03
    行为即身份 不是问"你专注了吗"，而是用行为定义你是谁
03 / User Flow

一次完整的专注旅程

从进入专注模式到最终身份判定，每一步都有明确的物理信号与系统响应。

进入专注模式

手环与手机建立蓝牙连接，继承闹钟、来电、日程等关键信息。手机进入"隔离态"。

01
02

实时距离监测

蓝牙 RSSI 持续测距。手机过近（<安全距离）触发警告；超出蓝牙极限距离则视为脱离专注区。

过近警告 · 3 分钟倒计时

手机进入警告区，手环震动 + 屏幕提示。3 分钟内未远离，系统弹出"摆烂选项"。

摆烂选项出现

同时收集手机屏幕状态、传感器数据，为后续身份判定准备证据。

身份判定

根据用户选择与实际行为，判定为「专注者」「摆烂者」或「偷跑者」。

04 / Identity

三种身份，
一面镜子。

我们不评判，只记录。但每一次选择都会在数据中留下痕迹，最终汇聚成你与手机关系的画像。

专注者
The Focuser

选择远离手机，坚持完成专注周期。手机始终在安全距离之外，闹钟与来电由手环代为传达。

CONDITION → choose "远离手机" AND distance ≥ safe
摆烂者
The Slacker

选择摆烂，并且真的拿起了手机。诚实但失控——至少对自己诚实，这是改变的第一步。

CONDITION → choose "摆烂" AND screen-on = true
偷跑者
The Backstabber

嘴上说摆烂，身体却很诚实——选择了摆烂但实际并未看手机。系统识破这种"自我欺骗"，记录为偷跑者。

CONDITION → choose "摆烂" AND screen-on = false
05 / Features

核心功能

F1

专注模式启动

一键进入，手环接管手机关键提醒，手机进入隔离态。

F2

关键信息继承

闹钟、来电、日程同步至手环，确保不漏掉有效信息。

F3

蓝牙距离感知

RSSI 测距，过近警告，蓝牙极限距离为专注区上界。

F4

3 分钟警告倒计时

过近后给予 3 分钟缓冲期，到期弹出摆烂选项。

F5

行为证据收集

同步手机屏幕状态、传感器数据，作为身份判定依据。

F6

三态身份判定

专注者 / 摆烂者 / 偷跑者，基于选择与实际行为交叉验证。

F7

每日汇总

当日专注次数、时长、身份分布、最长连续专注。

F8

每周 / 每月画像

趋势曲线、身份占比变化、专注力成长轨迹。
