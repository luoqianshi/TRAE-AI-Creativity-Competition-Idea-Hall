关于本项目

🔮 今日精神状态模拟器

一款面向大学生和年轻用户的 AI 娱乐互动网页应用。把年轻人日常生活中的学习、考试、早八、宿舍、食堂、社交、实习、熬夜、摆烂等场景，转化成游戏化、段子化、可分享的娱乐内容。

✨ 创意亮点

  • 将 AI 内容生成与小游戏交互结合，不是普通聊天工具
  • 以年轻人的真实生活情绪为切入点，娱乐性和传播性强
  • 支持身份、状态、场景、天赋和风格组合，生成结果丰富
  • 通过属性变化和多结局机制增强互动感
  • 支持生成社交分享文案和报告卡片，适合传播
  • 技术实现轻量，便于部署和展示

🛠️ 技术栈

HTML + CSS + JavaScript（纯前端实现）

使用 html2canvas 实现卡片截图保存

代码预留大模型 API 接口，可后续扩展

🚀 后续扩展

  • 接入大模型 API 实现动态内容生成
  • 添加更多场景、天赋和结局模板
  • 增加用户系统和排行榜功能
  • 支持多语言和主题切换
  • 开发小程序版本
