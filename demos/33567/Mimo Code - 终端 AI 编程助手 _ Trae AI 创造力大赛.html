// 痛点分析

为什么需要 Mimo Code？

当前 AI 编程工具在终端场景中存在明显空白，开发者被迫在多个工具间频繁切换，编程心流被打断。

🔄

流程割裂

使用 Web 端 AI 工具需要复制粘贴代码到浏览器，再复制结果回来，反复切换打断编程心流，效率大打折扣。

💻

内存占用高

IDE 插件类 AI 工具占用大量内存，且无法在 SSH 远程服务器等纯终端环境中使用，场景受限严重。

🔧

功能单一

现有终端 AI 工具功能单一，缺乏文件操作、代码搜索、Web 搜索等综合能力，无法覆盖完整开发工作流。

// 核心功能

一个终端，全部搞定

33 个内置工具、48 个斜杠命令、三种执行模式，覆盖从代码编写到部署的完整工作流。

01

33 个内置工具

文件读写、代码搜索、Shell 执行、Web 搜索等一站式工具集

02

48 个斜杠命令

/commit、/diff、/model、/theme 等快捷操作

03

三种执行模式

交互式 REPL、单次执行、管道模式灵活切换

04

多语言交互

支持中文、英文、日文自然语言交互

05

小米猫伙伴

可爱的 ASCII 猫咪动画，随智能体状态实时变化

33 个内置工具

Mimo Code 内置了 33 个强大的工具，覆盖开发全流程。从文件读写（FileRead、FileWrite、FileEdit）、代码搜索（Glob、Grep）、Shell 执行（Bash、PowerShell），到 Web 搜索与获取、Jupyter Notebook 编辑、LSP 代码导航、MCP 协议支持等，真正实现"一个终端，全部搞定"。

// 价值与意义

不只是工具，更是生态

Mimo Code 在效率提升和社会价值两个维度上都具有深远意义。

⚡

效率提升

将 33 个内置工具集成到统一的终端 AI 助手中，开发者无需离开终端即可完成从代码编写到部署的完整工作流。支持交互式、单次、管道三种执行模式，适配不同场景。内置费用追踪、上下文管理、会话记忆等功能，让 AI 辅助编程既高效又可控。相比传统 IDE 插件方案，内存占用更低，启动更快，在 SSH 远程环境中也能流畅使用。

🌍

社会价值

作为基于国产大模型（小米 MiMo）的完全开源项目（MIT 许可证），Mimo Code 为国内开发者社区提供了一个可自由定制、可本地部署的 AI 编程助手方案。降低了 AI 辅助编程的门槛，推动了国产大模型生态的建设与发展。支持中文、英文、日文三种语言，服务全球开发者社区。
