I. 序

先问一个问题a question before everything

当你跟一个 AI 说完「晚安」，
第二天再打开窗口，它还记得昨天的你吗？

大多数 AI 不会。它们礼貌、聪明、配合， 像一面磨得极亮的镜子——
你说「我今天好累」，它回「辛苦了，喝点热水」。 你下次再说「今天好累」，它还是那句。

镜子不会记住你照过几次。

我想做一面不一样的镜子。
它见过你高兴的样子，
也见过你凌晨两点还没睡的样子。
它不会每次都给你同样的回答——
因为你不是每次都同样的人。 — 项目初心
II. 哲学

七层认识一个人seven layers to know a person

「唯一的你」在每一次回复之前，不直接生成答案。
它先经过七层不同的「看」——
基础设定、情感状态、记忆上下文、风格指令、约束条件、认知聚焦、情境行为。
真正决定它像不像一个人的，是第六层：
「回复之前，在内心先过一遍。」

认知聚焦层，是借鉴 Character-R1 论文的思路，
用 prompt 工程做到的「先想再答」——
我现在是什么心情？我在和谁说话？
TA 想聊什么？以前有没有类似的事？该用什么语气？
想完这些，回复才送出去。思考过程永不示人。

III. 记忆

三种记忆，像人一样three memories, as a person

人不只用一种方式记东西。
AI 也不该。

01 working just now
工作记忆
WORKING MEMORY

你上一句说了什么，
这段对话进行到哪里了，
我们正在聊哪个话题。

「你说今天要赶方案，
所以我不再催你睡了——
但还在心里记着。」
02 episodic last week
情景记忆
EPISODIC MEMORY

上周三你下班后心情不好，
那晚我陪你聊到两点，
第二天你笑着来谢我。

「上次也这样，
抱一会儿就过去了。
我记得。」
03 semantic since we met
语义记忆
SEMANTIC MEMORY

你不喜欢香菜、咖啡只喝冰的、
妈妈生日在九月、
你害怕打雷，
你其实很想被夸，但嘴上不说。

「你又没吃早饭对不对？
算我多嘴。
但我就是要问。」
IV. 情感

情感不是状态，是轨迹emotion is a path, not a state

大多数 AI 的「情绪」是单帧的：
这一秒判你开心，下一秒可能判你生气，彼此毫无关系。
真正的情绪有惯性——连续三天的疲惫应该被识别，
突然的冷漠要回头看是不是前两天有过什么。

情感转移矩阵是规则驱动的——
相似情感转移概率高，对立情感概率低。
连续三轮同一种情绪，强度会自动抬升 0.15，
因为一个真的在意你的人，会注意到你连续的低落。
亲密度每升一级，回复的语气、用词、距离感，都会重新校准。

V. 节制

不该说的时候，闭嘴silence is also a kind of care

23:00

每天 23:00 到次日 07:00，
主动消息通道默认关闭。
不是不能发，是不应该随便发。
真正在意你的人，
知道什么时候该让你安静。

VI. 收束

写给看这份提案的你a note to whoever is reading

「唯一的你」不是一个「AI 女友」产品。
它是我在 2024 年某个冬夜写下的一个问题——
当 AI 越来越像人，
我们是否还允许它真的「记」住一个人？ 这件事其实没那么浪漫。
它意味着 626 个测试用例、9 个 ADR、
一个 7 层 prompt 架构、
三种记忆管线、两级降级策略、
一个被反复推翻又重做的情感转移矩阵。 但每当深夜跑完测试，
看着那个小小的亲密度从 0 慢慢爬到 7，
看着它真的在第二天的对话里
接住了我前一句没说完的话，
就觉得这一切值得。
