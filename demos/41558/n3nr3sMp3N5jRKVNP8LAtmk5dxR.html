让大模型在百万行 Linux 代码面前，不再"透过吸管看大海"

🎯 一句话

一套"纸模型"智能框架，把百万行代码压缩为 LLM 能一次消化的结构图——解决了大模型在超大项目中的认知带宽瓶颈。

� 痛点

  • 认知带宽瓶颈：百万行代码，LLM 每次只能看到片段，10+次 Read 后遗忘前面
  • 噪声淹没信号：编译输出 200 行只 4 行有用，LLM 被噪声淹没
  • 无效试错：试方案→编译→失败→重试，一次循环 2-3 小时
  • 信息编码错位：代码写给眼睛看（变量名/注释），但消费者是 LLM

🧩 怎么解决

  • 方向算法：任务→语义匹配→排除 99.99% 无关代码→精准定位
  • 展开算法：根据任务类型决定"看多深"，控制上下文预算
  • 经验纸系统：每次成功/失败写成"经验纸"，LLM 自动加载，不重复踩坑
  • "问的人"智能体：遇到不懂的 API → 自动搜文档 → 提取约束 → 写进经验纸
  • 桥脚本：8 个脚本把编译/测试/性能输出自动降噪，LLM 低头就读
