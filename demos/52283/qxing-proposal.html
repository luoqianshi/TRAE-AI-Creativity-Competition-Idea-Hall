01 — 痛点

散落的星辰

连续血糖仪（CGM）是一种贴在身上的微型传感器，24 小时自动监测血糖变化。当多位长辈使用不同品牌的 CGM，血糖数据散落各家 App，子女难以一眼看全。

◐

安卓断连

安卓手机后台常杀进程（5 家主流厂商均有用户反馈），导致 CGM App 断连。虽有断连提醒，却常以刺耳告警惊吓老人，且提醒本身也容易失效。

// 星点熄灭
// 调研 50+ 笔记，欧态官方承认根因为后台进程被回收
◇

生态绑定

多位长辈使用不同品牌 CGM 时，子女需切换多个 App 才能分别查看；更换设备后历史数据留在原厂商 App，无法迁移。数据被锁在各家生态里——既看不全，也带不走。

// 星座割裂
// 4 家第三方手表方案均被吐槽断连
◑

被动查看

3 家厂商远程看护方案均依赖对方 app 前台运行，子女仍需主动打开 App。没有 AI 主动推送的"今日放心"摘要，日常看护变成一件需要惦记的事。

// 等不来星光
// 欧态官方承认"对方 app 被后台关闭"会失效
◓

手表困局

市面 4 家第三方专用 CGM 手表方案虽已商业化，但均被用户吐槽断连、年费订阅——手表方案同样卡在断连与生态割裂上。

// 星外无星
// 调研 4 家品牌，最高赞吐槽"才用一天就断联三次"

谁在牵星

04 — 价值与意义

星辰的温度

单个厂商能做好的，QXing 不重复；目前缺失的跨品牌统一，QXing 来补足。

社会价值

跨品牌的统一看护视角

各厂商 App 虽已提供各自的远程查看功能，但协议互不互通，无法跨品牌汇聚。QXing 作为中立基座，补足这一空缺：先把所有长辈的设备状态、血糖趋势汇聚到同一个界面，再由 AI 浓缩成每日健康摘要。

今天爷爷的血糖控制得很棒，达标率 85%。下午 3 点的低血糖可能是没吃加餐，明天建议提醒他下午补一餐。
效率提升 / 产业价值

一次适配，全行业受益

每家 CGM 厂商各自对接智能家居平台意味着重复造轮子，中小厂商往往无力承担。QXing 提供一次标准适配，全行业受益——让中小 CGM 厂商也能低成本接入智能家居生态，语音播报血糖不必依赖某一家大厂。

中立基座 · 一次适配 · 全行业受益 — 让任何 CGM 品牌都能接入智能家居生态。
