客户信息查询 - 标准响应
启用
BODY-CUST-QUERY-V3 · 8字段 · 引用 468 次
字段结构树：
▣ response (Object)
◉ code String · 必填
◉ message String · 必填
▣ data (Object)
◉ customerId String · 必填
◉ customerName String · 必填
◉ idCardNo String · 脱敏
◉ phone String · 脱敏
▣ address (Object)
◉ registerTime DateTime

// 标准响应示例 { "code": "00000", "message": "success", "data": { "customerId": "C20260604001", "customerName": "张三", "idCardNo": "110***********1234", "phone": "138****5678" } }
订单创建 - 标准请求
启用
BODY-ORDER-CREATE-V2 · 12字段 · 引用 326 次
字段结构树：
▣ request (Object)
◉ orderNo String · 必填
◉ requestId String · 幂等
◉ customerId String · 必填
◉ amount Number · 必填
◉ currency String · 默认CNY
▣ productList (Array)
▣ [0] (Object)
◉ productId
◉ quantity
◉ remark String · 可选
JSON示例：
{ "orderNo": "ORD202606040001", "requestId": "REQ-550e8400-e29b", "customerId": "C20260604001", "amount": 299.00, "currency": "CNY", "productList": [ { "productId": "P001", "quantity": 2 } ] }
