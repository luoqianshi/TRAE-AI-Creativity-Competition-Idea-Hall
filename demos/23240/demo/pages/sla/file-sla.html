文件服务 SLA 指标

专用于文件传输类服务的服务水平协议 · 关注及时性、完整性、异常处置能力
传输及时率
On-Time Delivery · 按传输频率检查文件是否按时到达
核心指标
目标 ≥ 99.00%
衡量文件在约定时间窗口内送达接收方的比例。按不同传输频率（实时/日终/周/月）分别计算。
及时率 = 按时到达文件数 / 应到文件总数 × 100%
测量周期日 / 月
告警阈值低于 98.5%（日）/ 99.0%（月）
判定依据接收方确认时间 ≤ SLA 约定时间
采集点文件传输平台（FXP）

≥ 99.9%
B 级（重要）
≥ 99.5%
C 级（一般）
≥ 99.0%
传输成功率
Transfer Success · 文件传输成功数 / 总传输数
核心指标
目标 ≥ 99.50%
衡量文件传输的技术成功率，含自动重传。多次重试后成功计为成功，超过最大重试次数计为失败。
成功率 = 成功传输数 / （成功数 + 失败数） × 100%
测量周期日 / 月
告警阈值单日低于 99.0%
判定依据接收方 MD5 校验通过
最大重试次数3 次（指数退避）
A 级（核心）
≥ 99.9%
B 级（重要）
≥ 99.5%
C 级（一般）
≥ 99.0%
文件完整性率
File Integrity · 文件未损坏且记录数一致的比例
核心指标
目标 ≥ 99.90%
通过 MD5/SHA256 校验、文件大小校验、记录数对账、关键字段抽样校验等方式，综合判定文件内容是否完整。
完整率 = （通过校验文件数）/ 已到达文件总数 × 100%
测量周期每次传输
告警阈值单个文件不完整立即告警
判定依据哈希 + 记录数 + 抽样字段三重校验
异常处理自动重传 + 人工双审
A 级（核心）
≥ 99.99%
B 级（重要）
≥ 99.90%
C 级（一般）
≥ 99.50%
异常处理时效
MTTR · 传输异常发现到处理完成的时间
关键指标
目标 ≤ 2 小时
从异常被系统监控发现或人工上报起，到问题根因确认并恢复文件传输（重传成功或确认跳过）的全流程时长。
MTTR = 异常恢复时间 - 异常发现时间（按 P0/P1/P2 分类）
测量周期事件（次）
P0 紧急≤ 30 分钟响应 / ≤ 2 小时恢复
P1 高≤ 1 小时响应 / ≤ 4 小时恢复
P2 中 / P3 低≤ 4 小时响应 / ≤ 8 小时恢复
A 级（核心）
≤ 2h
B 级（重要）
≤ 4h
C 级（一般）
≤ 8h
