过渡期规范
  • A 级文件：过渡期 ≥ 30 天
  • B 级文件：过渡期 ≥ 14 天
  • C 级文件：过渡期 ≥ 7 天
  • 过渡期内新旧版本文件同时生成并传输（双文件并行）
  • 过渡期结束前需确认所有接收方已完成改造并切换
兼容性要求
  • 向下兼容原则：新增字段必须允许为空；原有字段不得删除或修改含义
  • 接收方提前通知：变更影响方清单必须完整，提前 7/14/30 天邮件告知
  • 双文件发布策略：建议过渡期内同时生成新旧两版文件，供接收方平滑切换
