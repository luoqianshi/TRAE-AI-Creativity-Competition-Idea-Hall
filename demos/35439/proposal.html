01 — 创意概览

创意名称与核心介绍

💡

创意名称

体感防走神·沉浸式专注书桌
Motion-Focus Desk

🎯

想解决什么问题

解决当代学生和职场人在自学或工作时"身体在坐，脑子在飞"、容易分心走神、专注力碎片化的问题。让专注不再只是"挂机凑时长"，而是真正可感知、可量化的"心流状态"。

🔍

灵感来源

周末在上海图书馆和自习室的观察：很多人虽然坐在书桌前，但每隔几分钟就会摸一下手机，或身体频繁晃动，学习效率极低。传统的番茄钟只能约束时间，无法约束当下的"状态"。

📱

产品形态

这是一款结合手机陀螺仪 / 加速度传感器的 Web App（网页应用）。用户将手机平放在书桌或手边，应用能实时监测用户的"身体稳定性"，并以此作为专注力的评分依据，生成沉浸式的白噪音环境。无需额外硬件，一部手机即可开启"体感专注模式"。

02 — 问题洞察

当前痛点深度分析

目前市面上的专注软件（如 Forest、番茄ToDo 等）大多依赖用户手动点击"开始"和"结束"，无法感知用户当下的真实状态。如果用户在计时期间发呆、玩手机或频繁起身，软件是无法识别的，导致"挂机凑时长"现象严重——数据好看，但实际效率低下。

01

挂机凑时长

用户点击开始后做其他事，计时器照常运行，最终统计的学习时长毫无意义，自欺欺人。

02

无法感知状态

传统工具无法区分"专注学习"和"发呆走神"，只记录时间、不记录质量，数据维度单一。

03

缺乏沉浸引导

仅有计时功能，缺少环境营造和感官引导，用户难以进入并维持"心流"状态。

03 — 用户画像

目标用户及使用场景

📚

备考学生

考研 / 考证 / 高考

需要长时间高强度学习，容易被手机干扰，渴望真实有效的专注力监测工具。

💼

居家办公者

远程工作 / 自由职业

在家办公缺乏监督，容易分心，需要外部工具帮助建立工作节奏和专注环境。

🧒

多动倾向儿童

家长辅助模式

通过有趣的体感反馈和游戏化设计，帮助注意力不集中的孩子建立专注习惯。

使用场景

用户在书桌前打开应用，将手机平放作为"监测器"，选择白噪音环境，开始一天的学习或工作计划。应用全程在后台监测手机的稳定性——手机越稳定，说明用户越专注；手机被拿起或频繁晃动，则触发提醒。

04 — 产品设计

核心功能模块

  • ✓

    体感专注监测引擎

    利用 DeviceMotion API 与 DeviceOrientation API，实时采集手机三轴加速度和陀螺仪数据。通过算法计算"稳定性指数"（0-100分），量化用户当前的身体稳定程度。手机平放不动 → 高分；手机被拿起、晃动 → 低分。

  • ✓

    沉浸式白噪音环境

    内置多种高品质环境音效：雨声、森林、咖啡馆、海浪、白噪音、篝火等。用户可根据偏好选择，并可调节音量和混音比例。声音环境与专注状态联动——专注度高时音效更纯净，走神时音效渐变提醒。

  • ✓

    智能走神提醒

    当检测到手机被拿起、频繁晃动或长时间无稳定信号时，系统通过轻柔的触觉反馈（振动）或声音渐变提醒用户回到专注状态，而非粗暴的弹窗打断。

  • ✓

    专注力数据看板

    每次专注会话结束后，生成详细的专注报告：稳定性曲线图、高分时段、走神次数、有效专注时长、趋势对比等。用数据可视化帮助用户了解自己的专注模式，持续优化。

  • ✓

    游戏化激励机制

    连续专注可获得"专注勋章"和成就徽章；建立"专注段位"系统（青铜→白银→黄金→钻石→王者）；支持好友排行榜，增加社交激励。

  • ✓

    家长辅助模式

    针对多动倾向儿童设计：卡通化界面、趣味音效反馈、专注时长兑换虚拟奖励、家长端远程查看报告，帮助家长了解孩子的专注状态变化。

05 — 技术实现

技术架构与方案

前端技术栈

React 18 + TypeScript Vite Tailwind CSS Web Audio API DeviceMotion API DeviceOrientation API Chart.js / D3.js PWA (离线可用)

后端技术栈

Node.js / Bun PostgreSQL Redis (实时排名) WebSocket JWT 认证 Docker 部署

核心算法：稳定性指数计算

StabilityScore = 100 − (α × AccelerationVariance + β × RotationVariance + γ × PickupPenalty)

其中：AccelerationVariance 为加速度方差（反映手机是否被移动），RotationVariance 为陀螺仪角度变化方差（反映手机是否被旋转/拿起），PickupPenalty 为拿起惩罚项（检测到屏幕朝上→朝下翻转时触发大幅扣分）。α、β、γ 为可调权重参数。

技术亮点

无需额外硬件

完全基于手机内置传感器，Web API 标准实现，跨平台兼容（iOS Safari / Android Chrome 均支持）。

PWA 离线可用

通过 Service Worker 实现离线白噪音播放和本地数据缓存，无网络环境也能正常使用。

低功耗优化

智能采样频率调节（专注时降低采样率，异常时提高），平衡监测精度与电量消耗。

隐私优先

传感器数据仅在本地处理，不上传原始运动数据，仅上传聚合后的专注指数，保护用户隐私。

06 — 价值评估

价值与意义

⚡

效率提升

将"专注"从单纯的"时间累积"升级为"质量监测"。通过物理层面的体感反馈，强制用户进入"心流"状态，真正提升单位时间内的产出，让每一分钟都有价值。

💎

商业价值

随着远程办公和终身学习的普及，付费自习室和专注类工具市场巨大。本产品可作为智能书桌配件的配套软件，或作为独立 SaaS 服务提供给教育机构和企业。

核心差异化优势

传统专注工具记录"时间" → Motion-Focus Desk 记录"状态"

从"你学了多久"到"你有多专注"——这是专注力工具的一次范式升级。
