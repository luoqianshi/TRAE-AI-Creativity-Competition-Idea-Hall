1创意介绍

桌面陪伴类设备长期存在两个极端——纯软件桌宠缺少实体存在感，纯硬件玩具又缺少 AI 大脑，功能割裂、交互僵硬。 CorePet 把"实体硬件 + 大模型 AI + 多模态交互"融合到一台 ESP32-S3 设备上，让它能听、能看、能动、能陪伴，而不是一个只会循环动画的摆件。

💡 灵感来源

嵌入式课程综合实训 + 个人桌面陪伴需求。M5Stack CoreS3 硬件底子完整，加上 XiaoZhi AI 大模型能力，决定做一个真正能日常使用的 AI 桌宠。

🧩 产品形态

基于 ESP32-S3 的智能桌面宠物硬件，集成表情、触摸、IMU、摄像头、AI 语音、AI 视觉、舵机动作、番茄钟、相册、音乐、备忘、心情系统。

🎯 核心目标

让 AI 真正成为硬件的大脑，而不是独立的对话框。一句话就能驱动摄像头、舵机、备忘、页面切换，形成"语音→硬件动作"的闭环。

// FreeRTOS 多任务协作架构
Touch task    (50Hz)  → GestureManager → AppState → stateChangeHandler()
UI task       (20FPS) → 当前 UI 类绘制页面（PSRAM Canvas）
Camera task   (15FPS) → CameraManager 帧 → Camera Debug / AI Vision UI
Vision task   (5FPS)  → 启发式 FaceDetector → FaceTracker / 拍照居中
AI task       (50Hz)  → XiaoZhi WebSocket、Opus 音频、MCP 工具
Power task    (1Hz)   → 电池/休眠状态与低电压回调
Network task  (5s)    → Wi-Fi 重连、NTP 同步、Web 服务
Music task    (事件)  → SD MP3/WAV 流式播放

// 状态机驱动 14 个页面
FACE → MENU → WIFI_INFO / CAMERA_DEBUG / AI_VISION / POMODORO
     → MUSIC / SYSTEM_INFO / AFFINITY / AI / SETTINGS / MEMO / ALBUM / SERVO_TEST / SLEEP

// 资源所有权
相机：懒启动，前台 Camera/AI Vision 才拥有采集
音频：小智语音独占麦克风/扬声器，音乐播放前自动停止
舵机：统一经过 ServoMotionController，避免大角度跳转
SD 卡：容错重试 25/10/4/1 MHz，缺失不重启

9价值与意义

⚡ 效率提升

CorePet 把番茄钟、备忘提醒、语音助手、相册、音乐播放、桌面陪伴整合到一台 ESP32-S3 设备上，减少多设备切换。通过 XiaoZhi MCP 工具，AI 可以直接调用摄像头拍照、描述场景、控制舵机、添加备忘、切换页面，形成"一句话驱动硬件"的闭环体验，让 AI 真正成为硬件的大脑而不是独立的对话框。

💖 社会价值

CorePet 内置亲和度/心情系统，会根据用户的互动频率在 Lonely / Quiet / Warm / Happy / Lively 五种心情之间动态切换，长时间不互动会自然衰减，连续互动有连击加成，让桌宠有"被需要"的情感反馈。这对独居、久坐、缺少陪伴的人群是一种低成本的情感支持。同时整个项目开源，可以作为嵌入式 AI 教学的完整样板，降低后来者的入门门槛。

10差异化亮点

🔗 真正的 AI-硬件闭环

不是"硬件 + 独立 AI App"，而是 AI 通过 MCP 协议直接调用硬件能力。说一句"拍张照"就能驱动摄像头，"跳个舞"就能驱动舵机。

🎭 多模态融合

触摸 + IMU + 语音 + 视觉 + 舵机五路输入输出同时整合，表情系统会根据所有输入动态切换，不是单一交互。

💖 情感化设计

亲和度心情系统让桌宠有"被需要"的感觉，长时间不互动会孤独，连续互动会开心，这是纯功能设备无法提供的。

📚 完整开源样板

12000+ 行 C++ 代码，覆盖 14 种外设、7 个 FreeRTOS 任务、状态机、AI 协议、电源管理，是嵌入式 AI 的完整教学案例。

🛡️ 工程稳定性

Brownout 安全模式、相机懒启动、舵机安全运动规划、SD 卡容错重试、PCA9685 缺失自动降级，不是玩具级 demo。

🌐 远程可控

自带局域网 Web 控制页面，可远程切换页面、控制舵机、浏览相册，AI 与 Web 双通道控制硬件。
