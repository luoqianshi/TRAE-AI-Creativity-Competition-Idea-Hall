PROBLEM

三个真实痛点：信息差让人被骗、白跑、错过

农村老人 · 领鸡蛋

村口听说超市免费领鸡蛋，去了发现是传销洗脑会场。老人无法辨别真假，也不敢去。

痛点：不知道消息真假，怕被骗进传销
📜

大学生 · 考教资

想考教师资格证/教练证，搜出来一堆中介广告，报名费翻倍，还可能是假官网、假证书。

痛点：分不清官方渠道，被中介钓鱼
🏆

普通人 · 找赛事

TRAE 大赛很火，但不知道去哪报名、怎么报名。搜到山寨入口，填了信息才发现被骗。

痛点：找不到官方入口，踩坑山寨

ARCHITECTURE

双端产品架构：App 发现 + 后台验真

产品由手机 App（用户端）和Web 管理后台（运营端）组成，两端协同：管理端负责「收→审→标→发」，App 端负责「查→看→信→报」。

🖥️ Web 管理后台

运营端：收 → 审 → 标 → 发

爬虫汇聚：自动采集公开活动页
待审队列：用户上传 + 爬虫抓取
AI 初审：诈骗话术/传销词/假官网检测
人工复审：运营/群众监督复核
可信算法：备案+域名+交叉信源+投诉
分区推送：地理半径 / 全国类目
⇄ 数据流
📱 手机 App

用户端：查 → 看 → 信 → 报

发现：附近活动 / 全国考证赛事
检索：按类型·距离·可信度筛选
查看：可信分 + 官方链接 + 防骗提示
信任：红黄绿标签一目了然
上传：拍照/链接提交验真
举报：遇到虚假活动一键反馈
📡
DATA SOURCE

信息获取三通道：每条信息必须过审才展示

A

爬虫自动采集

管理端爬虫自动抓取公开活动页面（政府公告、超市官网、考试院通知等），进入待审队列。

来源：公开网页 · 政府公告
B

用户上传求证

用户在 App 拍照上传传单、粘贴链接，提交后进入待审队列，由平台验真后反馈结果。

来源：用户拍照 · 链接提交
C

认证主办方发布

经过认证的主办方（商家/机构）可自助发布活动，享有「已认证」标识，后期能力。

来源：认证商家 · 官方机构

核心原则：无论哪个通道，所有信息必须经过审核验真后才能在 App 展示，不存在「直接发布」。

🛡️
VERIFICATION

可信验真机制：AI 初审 → 人工复审 → 可信分

这是活动真探的核心差异化——不是简单「审核一下」，而是五步验真流水线，最终输出可信分和红黄绿标签。

1
信息入库

爬虫抓取 / 用户上传 / 主办方发布，进入待审队列

→
2
AI 初审

检测诈骗话术、传销关键词、假官网域名、异常联系方式

→
3
人工/群众复审

运营人工复核 + 群众举报监督，交叉验证

→
4
可信算法打分

工商备案 + 域名年限 + 交叉信源 + 历史投诉，综合计算

→
5
输出标签

🟢 已核实 / 🟡 待核实 / 🔴 有风险 + 可信分数

为什么老人不会被「免费领鸡蛋」骗去传销？
老人在 App 看到领鸡蛋活动时，系统已用 AI 检测过「传销话术」「无工商备案」「异常聚集地点」等特征。如果活动没有备案、地点在偏僻小区、联系方式异常，可信分会很低，标签显示🔴「有风险」，并弹出防骗提示：「该活动未核实主办方资质，请谨慎前往，警惕传销」。老人看到红标就不去了，子女也能远程查看帮把关。

SEARCH MODE

地理活动 vs 线上活动：两套检索逻辑

维度 📍 地理类活动 🌐 线上类活动
典型场景 超市领鸡蛋、社区义诊、农村集市福利、线下促销 教师资格证、教练证、TRAE 创造力大赛、线上赛事
检索逻辑 按地图 / 半径检索（2km / 5km / 10km），LBS 推送 按类目全国检索，不限地理位置
核心信息 时间、地点、距离、主办方核实状态 含金量、难度、费用、唯一官方报名链接
验真重点 主办方工商备案、活动地点真实性、传销特征检测 官方域名验证、报名渠道唯一性、中介钓鱼检测
防骗提示 「警惕传销」「核实主办方」「勿去偏僻地点」 「认准官方入口」「警惕中介加价」「核对域名」
推送方式 进入用户时自动推送周边活动 用户主动搜索 / 订阅类目更新通知

SCENARIOS

三大典型场景：从痛点到解决方案

场景 1 🥚 农村老人 + 超市领鸡蛋 + 防传销
❌ Before

张大爷在村口听人说超市免费领鸡蛋，不知道是不是传销，去了怕被骗，不去又怕错过实惠。

✅ After

打开 App 看 2km 内活动，显示「主办方已核实 + 工商备案」，可信分 85/100，绿色标签，放心去。

App 端：首页「附近」Tab → 看到领鸡蛋活动 → 可信分 85 🟢 → 点击查看防骗提示 → 放心前往
管理端：爬虫抓取超市活动 → AI 检测无传销特征 → 核实工商备案 → 打绿标 → 推送给 2km 内用户
场景 2 📜 大学生 + 教资/教练证 + 辨中介钓鱼
❌ Before

小李想考教师资格证，搜出来一堆中介广告，报名费翻倍，分不清哪个是官网，怕填了信息被骗。

✅ After

在 App「考证」Tab 搜索教资，看到含金量、难度、费用、唯一官方报名链接，可信分 95 🟢，直接跳转官网报名。

App 端：「考证」Tab 搜索 → 教资详情页 → 可信分 95 🟢 → 含金量/费用/难度一目了然 → 点击「官方报名」跳转官网
管理端：爬虫抓取考试院公告 → AI 验证官方域名 → 屏蔽中介钓鱼链接 → 标注唯一官方入口 → 全国推送
场景 3 🏆 普通人 + TRAE 大赛 + 找官方报名入口
❌ Before

小王听说 TRAE AI 创造力大赛很火，但不知道去哪报名、怎么报名，搜到山寨入口差点填了信息。

✅ After

在 App「赛事」Tab 搜索 TRAE，看到官方报名链接、报名教程、时间节点，可信分 98 🟢，一键跳转官网。

App 端：「赛事」Tab 搜索 TRAE → 详情页可信分 98 🟢 → 官方链接 + 报名教程 + 时间线 → 一键跳转
管理端：主办方认证发布 / 爬虫抓取官网 → AI 验证 trae.cn 域名 → 标注官方入口 → 屏蔽山寨链接
