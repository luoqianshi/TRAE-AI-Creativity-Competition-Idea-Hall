创意说明书 v0.2

不是替你找工作，是帮你重新想象自己

《牛马转生指南》面向 18-35 岁、正在经历裁员、待业、离职、转行或职业倦怠的年轻人。它借用人格测试的轻松入口，但拒绝用四个字母定义用户；AI 会把回答、现实限制与可迁移能力组合成"脑洞职业 + 现实岗位映射 + 7 天试活任务"。

01 / TARGET USER

给人生按下暂停键的人

18-35 岁年轻人，正在经历裁员、待业、离职、转行或职业倦怠。招聘平台根据旧履历继续推荐相似岗位；传统职业规划严肃、昂贵、压力大；纯娱乐测试又停在标签和分享，没有下一步。

02 / CORE PAIN

把焦虑变成可开始的问题

用户最缺的往往不是更多 JD，而是重新描述自己的语言。传统职业测评像考试，求职平台又直接把人推回岗位列表。我们用轻松方式承接就业焦虑，把注意力从旧职位名称转向可迁移能力。

03 / AI ROLE

AI 负责制造"意外的合理"

正式版会让 AI 结合行为偏好、能力碎片和现实约束动态生成结果，解释脑洞职业与真实岗位、可迁移技能之间的连接。当前离线 HTML 用规则化内容模拟，展示产品体验框架。

04 / CORE VALUE

从分享卡走向一次小行动

每份结果附带 7 天内可完成的"试活任务"，用低成本行动替代高成本裸辞，兼顾传播性与实际价值。结果卡适合社交传播，降低职业探索的心理门槛。

05 / SAFETY

不预测命运，不承诺就业

结果仅供娱乐与自我探索，不构成职业、心理、法律或财务建议。不预测命运、不承诺就业、不鼓励冲动裸辞。产品明确标注边界，不收集敏感信息，不给出成功率数字。

06 / VISION

从一次测试到持续探索

结果卡适合传播，后续可扩展职业故事库、技能体验任务和职业探索社区。愿景是让每个"暂停中的人"都能用低成本试错，找到旧工牌之外的可能性。
