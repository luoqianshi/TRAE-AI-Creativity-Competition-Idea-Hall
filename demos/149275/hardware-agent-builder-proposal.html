Hardware Agent Builder：硬件版 Claude Code

让 AI Agent 不只写方案，而是直接读硬件工程、改 BOM、改 PCB、改固件、适配模型、读取调试反馈，并生成可以继续打样的原型交付包。

一句需求

Agent 自动生成需求、BOM、原理图、PCB、固件、模型和测试报告。

一次硬件闭环

发现内存、电流、接口和制造风险后，Agent 自动修改工程文件。

一个交付包

01 / Problem

想解决什么问题

  • 个人开发者想做 AI 硬件，但不知道应该选 ESP32-S3、RV1106、树莓派还是其他芯片，也不知道模型能不能跑在端侧。
  • 元器件平台只卖零件，开源项目只给某一版接线，方案商又主要服务大客户，普通创客很容易买错料、接错线、烧坏板子。
  • 硬件开发链路被切成很多孤岛：BOM、原理图、PCB、固件、模型量化、外壳结构、测试报告和制造交付之间缺少一个能闭环工作的 Agent。
02 / Product

产品形态

Hardware Agent Builder 是一个硬件 Agent IDE。它的体验像 Claude Code，但对象不是软件代码仓库，而是一个完整硬件工程仓库。用户输入需求后，Agent 会生成工程文件、检查约束、模拟构建和调试，再根据反馈持续修改，直到形成可交付的原型包。


硬件工程仓库 BOM 自动修复 PCB 约束检查 固件补丁 模型量化 制造交付包
03 / Agent Loop

从需求到打样包的闭环

1

解析需求

识别离线推理、电池供电、摄像头、电机和成本限制。

2

生成仓库

创建 requirements、BOM、schematic、PCB、firmware、model 等文件。

3

运行构建

检查 Flash、RAM、模型大小、接口映射和固件编译风险。

4

烧录调试

读取串口、电池电压、电机电流、推理延迟和错误日志。

5

自动修复

增加续流二极管、更新 PCB 走线、修补固件缓启动和电流限制。

6

打包交付

生成 Prototype Kit v1，包含测试报告和制造注意事项。

04 / Example

示例执行过程

> analyzing requirement: 离线识别猫脸的宠物喂食器
> created hardware repo: 9 files generated
> selected ESP32-S3 + OV2640 + TFLite Micro
> memory warning: float32 model arena = 616KB
> action: quantize model to int8, arena reduced to 384KB
> flashing firmware and reading serial telemetry...
> issue detected: motor current spike = 940mA
> action: add SS14 flyback diode + DRV8833 driver + firmware soft-start
> rerun test: inference p95 = 186ms, motor peak = 410mA
> Prototype Kit v1 ready
05 / Files

Agent 会操作的工程文件

requirements.md

记录产品目标、约束条件、验收指标和用户需求。

bom.json

记录芯片、摄像头、电源、电机、驱动器、电容和成本信息。

schematic.json / pcb.layout

记录接口连接、走线约束、电源路径和制造风险。

firmware/main.cpp

记录摄像头初始化、模型加载、推理逻辑、电机控制和保护策略。

model/cat_face_int8.tflite

记录模型格式、量化方式、内存占用和端侧推理延迟。

manufacturing-order.json

记录可打样输出、测试结果和工厂装配注意事项。

06 / Users

目标用户和场景

  • 独立开发者：想把 AI 应用从网页或 App 带到真实设备里，但缺少硬件系统经验。
  • 硬件创客和校园团队：需要快速验证 AI 眼镜、宠物设备、桌面机器人、智能门铃、传感器节点等原型。
  • 小型创业团队：希望在找方案商或工厂之前，先得到一份更完整的工程打样包和风险清单。
07 / Value

价值与意义

效率提升

把早期硬件探索从“反复搜索和踩坑”变成可追踪的 Agent 工作流，减少买错料和调不通的时间。

商业价值

AI 硬件需要新的开发工具层。这个产品可以服务创客、教育、小团队和未来的小批量制造。

社会价值

降低硬件创新门槛，让更多教育、公益、适老化、农业、宠物和无障碍设备更快完成原型验证。

08 / Roadmap

后续可落地路线

第一阶段先用 HTML Demo 展示“需求 - 工程仓库 - 调试反馈 - 自动修复 - 交付包”的完整产品逻辑。第二阶段接入 KiCad/立创 EDA 生成原理图和 PCB，接入 PlatformIO 编译固件，接入真实串口日志和模型量化工具。第三阶段连接元器件供应链和打样服务，让 Agent 输出更接近真实制造的原型套件。
