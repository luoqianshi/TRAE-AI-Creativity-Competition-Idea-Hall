茶 伴

沉浸式3D茶道体验

作品简介

"在繁忙的都市生活中，寻找一片宁静的角落。
茶烟袅袅，时光慢下来，让心灵归于平静。"

🌅

三种主题场景

窗边茶室、湖边廊亭、山间雨院，每个场景都有独特的氛围和视觉设计。

☔

时间与天气

清晨、白天、黄昏、夜晚四种时间，晴天、阴天、雨天三种天气，随心切换。

👐

茶道手势动画

拿杯、倒茶、分茶、闻香、奉茶，完整的茶道流程，自然流畅的手部动画。

核心功能

1

场景切换

三种主题场景，带平滑过渡动画

2

真实时间同步

自动同步本地时间，或手动切换氛围

3

四种视角模式

第一人称、侧景、俯视、环绕观察

4

环境音效

低音嗡声、风声、雨声，随场景动态变化

5

茶道仪式

完整的茶道流程，十个步骤自动播放

6

沉浸式模式

隐藏所有 UI，完全沉浸在茶道氛围中

创作历程

第一阶段
项目搭建

使用 Vite + React 初始化项目，配置 Three.js、React Three Fiber、@react-three/drei 等依赖，建立基础项目结构，实现全屏 3D 容器和基础光照。

第二阶段
场景系统开发

设计并实现三个主题场景，创建场景切换功能，实现天空盒、远山、水面、建筑等环境元素，添加风动效果。

第三阶段
时间天气与视角

实现本地时间自动同步，开发四种时间氛围和三种天气系统，设计四种可切换视角，配置对应的光照和颜色。

第四阶段
茶桌与交互系统

建模并渲染茶具，开发手部骨骼动画系统，实现核心手势动画，优化动作细节和手指弯曲效果，添加热气粒子。

第五阶段
用户界面与音效

设计极简风格 UI，实现顶部控制栏和底部控制面板，使用 Web Audio API 创建环境音效系统，根据场景和天气自动调整参数。

价值与意义

🏛️
文化传承

将传统茶文化与现代 Web 3D 技术结合，降低学习门槛，数字化传承茶道艺术。

🧘
心理健康

舒缓的环境音效、优雅的动画，帮助用户放松心情、缓解焦虑，进行正念练习。

💻
技术示范

展示 React Three Fiber 的高性能应用，音效系统、动画状态机等都是很好的学习案例。

♿
可访问性

时间自由、空间灵活、成本极低，任何人都可以随时随地体验茶道的魅力。

技术栈

React 18 Vite Three.js React Three Fiber @react-three/drei Web Audio API CSS3 HTML5
