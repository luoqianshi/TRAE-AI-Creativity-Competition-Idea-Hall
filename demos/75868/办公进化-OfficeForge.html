01 / 痛点与机会

小公司上不起 ERP，只能 手工拼 Excel。

大量小办公公司和个人经营者，因为成本问题不上 ERP 或办公系统，每个月都在重复人工录入、对字段、汇总订单。

手工时代

现状

  • ×A：汇总订单表，B：每月订单表，字段对不上，靠人肉比对。
  • ×重复录入、复制粘贴、VLOOKUP 写错一个就全表错位。
  • ×临时需求（拆列、合并、清洗）没人开发，只能熬夜手填。
  • ×提需求给软件厂商？门槛高、周期长、买不起。
OfficeForge 时代

进化后

  • ✓提需求像聊天一样，LLM 判断价值，有价值的进待办。
  • ✓开发完成即上线，所有人立刻可用，工具池越积越厚。
  • ✓首个技能：拖拽列做字段映射，B 表内容一键填进 A 表。
  • ✓LLM 还会逛社区，自己挖掘办公需求并自进化。
真实场景 · 订单汇总

老板要 订单汇总表 A，但数据散落在 每月订单明细 B 里——字段名、列数都不一样。以前要打开两个 Excel 窗口对来对去填一下午，现在 拖几下、提交、下载，几分钟搞定。

02 / 创意介绍

从一个功能起步，让 LLM 自己长出工具池。

平台初期只交付一个已开发功能。后续需求由匿名或注册用户提出，LLM 分析价值后进入待办任务，开发完成即发布上线，可直接在线使用。

STEP 01
💡

用户提需求

匿名 / 注册用户用自然语言提交办公痛点。

STEP 02
🧠

LLM 分析价值

判断是否普适、是否可复用，决定是否进入待办。

STEP 03
📋

进入待办任务

有价值的自动排期，按优先级等待开发。

STEP 04
🛠️

开发并发布

开发完成即上线，无需重新部署分发。

STEP 05
🌐

在线直接使用

所有人打开网页即可调用该技能。

STEP 06
🔁

LLM 自进化

浏览社区、沉淀反馈，主动挖掘下一批需求。

闭环 / FLYWHEEL 需求越多 → 价值判断越准 → 工具越丰富 → 用户越多 → 飞轮自转，办公能力持续生长。 SELF-EVOLVING

04 / 价值与意义

让 AI 成为小公司的 免费信息化部门。

VALUE 01
¥

商业价值

以"一个功能 → 用户提需 → LLM 派单 → 上线"的飞轮替代传统 SaaS 的功能堆叠，边际成本趋近于零。早期靠首批工具获客，后期靠沉淀的工具池与数据建立壁垒。

VALUE 02
⏱

效率提升

首个技能即把"对字段、填订单"从半天压缩到几分钟；后续高频办公操作（PDF 拆分、图片批处理、文档整理）逐个上线，重复劳动持续被替代。

VALUE 03
⌂

社会价值

让上不起 ERP 的个人经营者、小微企业，也能享受与大企业同等的信息化能力，缩小"数字办公鸿沟"，让低成本创业更体面、更可持续。

05 / 目标用户

谁会用 OfficeForge？

🏢

小型办公公司

无专职 IT、无 ERP，每月靠手工拼 Excel 订单 / 报表，重复劳动多、易出错。

👤

个人经营者

一人身兼数职，对账、汇总、整理文档耗时巨大，请不起开发又急需小工具。

📊

临时办公场景

合并月度订单、清洗客户名单、批量改格式——用完即走，无需安装软件。

🧩

需求提出者

有办公痛点却无处诉说的人，提需求由 LLM 接住，并可能进化为通用技能。
