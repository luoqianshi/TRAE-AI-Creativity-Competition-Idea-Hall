PAIN POINTS

为什么找个文件这么累

// 01

搜索慢还搜不全

Windows 自带搜索输个关键词转半分钟，还经常搜不到明明存在的文件，急用的时候更崩溃。

// 02

得记完整文件名

Everything 这类工具是快，但得输入记得的全名，记不清一个字就废了，模糊记忆根本接不住。

// 03

手动翻文件夹眼花

资源管理器一层层点进去，嵌套三四层就翻到头晕，按修改时间排序也得一行行肉眼扫。

WORKFLOW

四步定位

01

录入碎片线索

选大概时间、类型、位置，输入记得的关键词碎片，不用拼完整文件名。

02

雷达扫描

启动扫描，雷达屏旋转探测，命中文件光点依次点亮浮现。

03

匹配度排序

按时间、类型、位置、关键词四维加权算分，从高到低排列候选。

04

定位回溯

看路径、修改时间、匹配度，一眼定位是哪个文件、在哪个文件夹。

VALUE

价值与意义

效率

社会
