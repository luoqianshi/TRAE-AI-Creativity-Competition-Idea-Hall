# 驾驶员疲劳监测 - v1.0.0

## 项目简介
基于 Web 技术的驾驶员疲劳监测 PWA 应用，通过前置摄像头实时检测驾驶员生理特征，预防疲劳驾驶。

## 核心功能

### 👁️ 眼睛检测
- **眨眼频率检测**：按单位时间（次/分钟）统计眨眼次数，异常高低均触发预警
- **闭眼时长检测**：实时监测单次闭眼时长，超过阈值判定为疲劳
- **PERCLOS 算法**：统计时间窗口内眼睛闭合比例，评估疲劳程度
- **长闭眼检测**：记录长时间闭眼次数，作为疲劳指标

### 🫦 打哈欠检测
- 通过嘴巴纵横比（MAR）检测嘴巴张开程度
- 结合持续时间判断，避免误检
- 连续打哈欠计数，触发分级预警

### 📐 低头检测
- 基于人脸关键点计算头部俯仰角
- 持续低头超过阈值触发报警

### ⏱️ 驾驶时长监测
- GPS/北斗定位辅助监测驾驶时长
- 可设置连续驾驶阈值，超时提醒

### 🔔 多级预警响应
- **三级预警体系**：根据疲劳程度触发不同级别报警
- **多种响应方式**：
  - 🔊 声音警报
  - 💡 屏幕闪烁
  - 📳 震动提醒
  - 🗣️ 语音提示

### ⚙️ 个性化设置
- 眨眼频率灵敏度独立调节（支持自定义数值）
- 闭眼时长灵敏度独立调节（支持自定义数值）
- 打哈欠灵敏度三级可调
- 低头检测灵敏度三级可调
- 预警响应方式可自由组合
- 连续驾驶时长阈值可设

## 技术特点
- **纯 Web 实现**：无需安装，浏览器即可使用
- **PWA 支持**：可添加到主屏幕，离线运行
- **MediaPipe Face Mesh**：高精度 468 点人脸关键点检测
- **实时处理**：本地计算，不上传任何图像数据
- **隐私安全**：所有检测在本地完成，保护用户隐私

## 使用方法

### 部署要求
- HTTPS 环境（摄像头访问要求）
- 现代浏览器支持（Chrome、Safari、Edge 等）
- 设备有前置摄像头

### 本地测试
```bash
# 进入发布目录
cd releases/v1.0.0

# 启动本地服务器（任选其一）
python -m http.server 8080
# 或
npx serve .
```

然后在浏览器中打开 `http://localhost:8080`

### 手机使用
1. 将文件部署到 HTTPS 服务器
2. 用手机浏览器打开网址
3. 点击"添加到主屏幕"安装为应用
4. 打开应用，允许摄像头权限
5. 点击"开始监测"即可使用
