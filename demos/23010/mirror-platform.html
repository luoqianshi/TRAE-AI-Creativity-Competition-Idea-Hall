01 / ORIGIN & PAIN

真实社交的代价，
从来不是技术问题。

我们不缺乏沟通理论、情商课、社交话术。我们缺的是一个可以安全试错、即时反馈、长期复盘的训练场。 「社交镜像」诞生的起点，就是这种长期未被满足的、几乎是结构性的社会需求。

P / 01

开口即不可逆。

真实社交里没有"读档"。一次错误的表达、一次情绪化的回应，会在人际网络中留下长尾代价——关系降级、信任裂痕、甚至职业机会流失。

HIGH STAKES
P / 02

现有方案，要么太轻，要么太重。

课程与书本停留在"知道"层面，无法迁移到真实场景；VR/角色扮演成本高、场景预设僵化； 找朋友模拟又涉及隐私与面子问题，且反馈极不可控。中间地带长期缺位。

GAP / 结构性
P / 03

社交焦虑是代偿产物。

当个体长期缺乏"低风险高密度"练习机会，焦虑会被固化为性格。我们观察到：不是不会，而是没机会练、不敢练、练了没人评。

NEED
P / 04

复盘无数据。

真实社交后，我们靠"感觉"判断得失——情绪化归因、选择性记忆、确认偏误。缺乏第三方视角与可量化的行为轨迹，让成长变得模糊。

DATA BLIND
P / 05

不同对象，不同剧本。

老板、客户、伴侣、父母、孩子……同一种表达方式在不同关系图谱中产生截然不同的化学反应。一套话术打天下，必然在某些场合失效甚至反噬。

CONTEXT-AWARE
→ OUR ANSWER

我们不教你怎么说话，而是给你一面 社交的镜子—— 让你在做出选择之前，先看见它会照出什么样的回响。

可逆 / Reversible

每一次选择都可以"重开"，让试错成本从人生级降至操作级。

可控 / Controllable

可调难度、可调角色、可调心理参数，把社交训练变成可设计的实验。

可量化 / Quantifiable

每次互动沉淀为可追溯的数据轨迹，让成长从感觉变成可证明的复利。

02 / CORE MECHANICS

三个机制，
构成社交的最小可玩单元。

我们刻意把系统做得克制：少即是多。三个互相咬合的机制，足以支撑从日常寒暄到高风险谈判的所有训练场景。

01 MECHANIC

剧本角色扮演

不是简单的"假扮对方说话"。我们为每个剧本注入完整的人物前史、心理剖面、即时情绪与隐藏诉求。 你面对的不是脚本，而是由 LLM 驱动的、具备人格一致性的"对方"——他会记住你三句话前的承诺，会在压力下情绪波动，会因为你的不当表达而真的关闭对话窗口。

// SCRIPT ENGINE ● ACTIVE
02 MECHANIC

失败阈值机制

每一个 NPC 都有动态变化的"心理阈值池"：耐心值、信任值、面子值、安全距离…… 你的每一句话、每一个动作，都会被映射为对阈值的扰动。逼近阈值时，NPC 会先试探性退缩；突破阈值，则触发关系降级甚至当场破裂。 失败不是终点，而是可以被精确诊断的反馈。

// THRESHOLD MODEL ● LIVE
03 MECHANIC

社交链成长体系

成功的高质量互动，会沉淀为持久的社交资产——信任度、好感度、共同记忆节点。 这些节点彼此相连，构成属于你个人的社交图谱。你不再只拥有一个"对方"，而是拥有一个不断自我增强的关系网：每一次训练都在为下一次铺路，每一次真诚都在被系统记住。

// SOCIAL GRAPH ● GROWING
04 MECHANIC

事后复盘

每一场剧本对话结束，都不是句号，而是复盘的起点。系统回放完整对话流，标注每一个关键转折点——哪句话拉高了信任、哪句话逼近了阈值、哪句话本可以更体面。 配合阈值曲线、情绪热力图、可选替代话术，让"感觉哪里不对"变成"我知道哪里不对、下次怎么改"。可积累的复盘笔记，构成你的个人社交成长档案。

// POST-REVIEW ● REPORT
03 / TECHNICAL HIGHLIGHTS

当心理科学遇见
多 Agent 工程化。

我们没有把"AI 陪聊"包装成社交训练。在底层，我们花了大量工程投入在三个真正决定系统可信度的地方。

T / 01 · PSYCHOLOGICAL MODEL

DISC × HEXACO 双模型嵌入

单一模型容易失真。我们将工业界最被广泛验证的 DISC（支配/影响/稳态/谨慎）与学术界更精细的 HEXACO（诚实-谦逊/情绪性/外向性/和悦性/尽责性/开放性） 共同量化为角色的行为基线参数，再叠加即时情绪扰动，让每个角色既有稳定人格，又有活人感。

DISC · 4 DIM
D 支配性
I 影响性
S 稳态性
C 谨慎性
HEXACO · 6 DIM
H 诚实-谦逊
E 情绪性
X 外向性
A 和悦性
C 尽责性
O 开放性
T / 02 · AGENT ARCHITECTURE

多 Agent 分级协同

一台单机 LLM 撑不起真实社交场域的复杂度。我们采用四层 Agent 架构，让不同的智能体各司其职、互相对话。

ORCHESTRATOR调度 / 剧本执行
CHARACTER角色 / 人格一致性
EMOTION情感 / 阈值计算
MEMORY记忆 / 上下文整合
T / 03 · EVENT MEMORY

事件记忆模块

让 NPC 真的"记住"你。系统采用长期记忆 + 情景记忆双轨制：长期记忆沉淀人格底色与关系基调，情景记忆索引关键事件、承诺、冲突点。 跨剧本、跨场景连续——你在第 12 轮许下的承诺，会在第 27 轮被对方主动提起。

LONG-TERM向量持久化 · 关系基线
EPISODIC事件流 · 时间锚定
RETRIEVAL语义召回 + 时序衰减
CONFLICT承诺一致性校验

05 / PSYCHOLOGY & EMOTION

最难开口的，
从来不是话术，是情绪。

我们在 DISC/HEXACO 之上，再叠一层依恋理论与情绪反应模式。让你面对的不只是"性格不同的人"，更是"带着不同伤口、不同防御、不同表达习惯的人"。

&

「我喜欢你，但我说不出口」—— 心理对抗

这是社交训练里最常见也最被低估的命题。我们专门为这类"想说而不能 / 想留而不舍 / 想断而不忍"的心理对抗场景设计剧本—— 欲言又止、故作冷漠、突然失联、半推半就…… 你的对手不再只回应你的"话"，而是回应你的"没说出口的话"。

四类 依恋风格，四种亲密关系剧本

ATTACHMENT / 4 TYPES
BOWLBY · AINSWORTH
AT / 01
安全型
Secure

能稳定表达需求、也愿意给对方空间。最容易开展的关系剧本——但安全本身也是值得练习的能力。

TRIGGER KEY "我需要你" / "我愿意等你"
AT / 02
焦虑型
Anxious

渴望确认、害怕被抛弃、一句未及时回复就会陷入内耗。剧本会模拟"已读不回"、"突然冷淡"等触发点。

TRIGGER KEY "你是不是不在意我了"
AT / 03
回避型
Avoidant

关系一靠近就退后、表达爱意时别扭、用"我没事"代替"我需要你"。剧本会逼你识别对方的反向信号。

TRIGGER KEY "我们是不是太近了"
AT / 04
混乱型
Disorganized

既渴望又恐惧、推开了又拉回、来不及解释就消失。最难预判的一类——也是最高阶的训练对象。

TRIGGER KEY "别走" / "算了吧" 同义反复

六种 情绪反应模式，构成对话的潜台词

EMOTION / REACTIVE
MICRO-EXPRESSIONS

你说的每句话，对方的回应不止是字面意思。

同一句"我没事"，背后可能是安抚、可能是压抑、可能是反讽、可能是求助。系统不只让 NPC 听懂你的字面词，更让 NPC 以自己的反应模式回应。 你在剧本里读懂这些，真实社交里才能读懂这些。

// SAMPLE DIALOGUE
"我喜欢你。"
—— 然后对方沉默了 12 秒，只回了一句"嗯"。
沉默
SILENCE

不是无话可说，是正在重新评估。可能是接纳、可能是消化、也可能是关闭。

防御
DEFENSE

用"我开玩笑的"覆盖真心话，用"你想多了"否认感受。先自我保护，再考虑对方。

反问
COUNTER

用"那你呢？""你为什么突然说这个？"把球踢回来——往往是最难接的一招。

转移
DEFLECT

用无关话题岔开、用玩笑稀释重量。"我们吃饭吧"可能是世界上最温柔的拒绝。

爆发
ERUPTION

阈值突破后的倾泻。系统会捕捉从压抑 → 暗示 → 爆发的临界过程，让你看到"哪里本可拦住"。

撤退
WITHDRAW

关系破裂前的最后通牒式沉默。突然已读不回、突然下线、突然"我们冷静一下"。

06 / SOCIAL VALUE

让开口不再是少数人的天赋。

我们相信社交能力是一种可习得的技能，不是一种出厂设置。这个信念，决定了产品的一切。

如果有足够多的人，
在足够安全的环境里，
被认真地陪练过，
那么这个世界，
会少一些误读，
多一些理解。

V / 01

从天赋到技能

把社交能力从"性格决定论"中解放出来。内向者不必假装外向，所有人都有机会成为更好的沟通者。

V / 02

降低真实代价

把试错留在镜像里，把成熟带到现实中。在重要的对话发生之前，先预演它一百次。

V / 03

推动心理学的工程化

让 DISC、HEXACO、依恋理论等严肃的心理学研究，第一次在消费级产品中真正被严肃地"用"起来。

V / 04

为焦虑者建一个安全场

为社交焦虑、回避型依恋、表达障碍的群体，提供一个零评判的练习空间。失败不丢人，丢人的是从不开始。

V / 05

让复盘成为习惯

用数据轨迹取代感觉判断。让每一次互动都有迹可循，让成长变成可证明的复利。
