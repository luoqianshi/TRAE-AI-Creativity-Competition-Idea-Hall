TRAE 信号灯

余光一瞥，即知 AI 任务进展。将屏幕内的状态变化，映射为桌面上的灯光语义。

Agent 工作中

需要介入

任务完成
绿灯常亮 — 可以回来看结果
How it works

工作流程

从 TRAE Agent 事件触发到信号灯亮起，全程自动、实时、无需手动操作。

💬
TRAE 事件触发
Agent 开始执行、完成任务或需要确认时，自动触发 Hook
⚙️
状态计算
后台驱动进程汇总所有会话状态，计算信号灯应显示的颜色
📡
蓝牙下发
通过 BLE 将灯光指令无线发送给桌面上的 ESP32 硬件
💡
灯光呈现
红/黄/绿 LED 实时反映当前状态，余光可感知
Pain Points

解决的痛点

🔄 频繁切窗口

Agent 执行期间反复 Alt-Tab 查看进度，打断当前工作的专注力

⏳ 不敢离开屏幕

怕错过 Agent 完成的时刻，只能干等在 IDE 前面

🔕 错过人工确认

Agent 等待操作确认时无明显提醒，导致任务空转浪费时间

🧠 认知负担

大脑需要持续记住"还有个任务在跑"，占用工作记忆

Value

价值与意义

将"主动轮询"变为"被动感知"，消除无效窗口切换。开发者安心做其他事，仅在黄灯时精准介入，最大化人机协作效率。
