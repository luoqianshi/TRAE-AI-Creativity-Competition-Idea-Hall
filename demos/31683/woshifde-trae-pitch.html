02 · 方案

把咨询团队压成一个 Agent。

FDE = Forward Deployed Engineer，一个驻场到生意现场的 AI。 上传 Excel → 自动识别字段 → 跑 35 个经营指标 → LLM 写诊断 → 生成本周行动。 整套流程 5 分钟内跑完，输出像麦肯锡报告一样的 PDF。

04 · 技术架构

不是套壳 ChatGPT，
是一个完整的多 Agent 经营操作系统。

本体 ONTOLOGY
11 个实体 · 35 个指标 · 15 个问题检测器

把"销售/库存/现金流"抽象成可计算的实体图。库存周转、坪效、客单价、复购率… 所有指标确定性算出，LLM 只负责讲人话。

多 AGENT 流水线
Finding → Solution → Editor

Postgres 做任务队列（SKIP LOCKED），独立 agent-team container 轮询。 每个 Agent 受工具调用约束，完整 trace 可回放。

字段识别
LLM + 规则双层匹配

中文列名"金额/客户/数量"自动对齐本体字段。识别失败的列让用户在 UI 上 1-click 修正。

PDF 报告
咨询级排版 · LLM 重写

puppeteer + chromium 服务端渲染。LLM 把模块化数据重写成 BLUF 报告：执行摘要、关键发现、90 天路线图。
