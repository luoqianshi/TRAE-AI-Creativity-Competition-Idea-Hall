// TECH PRINCIPLES

四层分流引擎

从用户回答到渠道推荐，全链路智能判断。

LAYER 01 — INPUT
结构化问题引导
将复杂的法律判断拆解为5-8个普通人能回答的简单问题，采用分支逻辑——根据第1个问题的回答，后续问题自动调整。例如选择"劳动纠纷"后，后续问题聚焦工资/辞退/工伤等细分方向。
LAYER 02 — CLASSIFY
案件类型判定
基于决策树模型，根据用户的多维回答交叉判断案件类型。覆盖劳动纠纷、合同纠纷、婚姻家庭、交通事故、消费者权益、刑事、行政、知识产权8大类型，每个类型再细分3-5个子类型。
LAYER 03 — ROUTE
渠道智能匹配
每个案件类型对应1-3个最优法律援助渠道，按优先级排序。例如劳动纠纷首选劳动仲裁委，次选工会法律援助，备选法院诉讼。同时标注各渠道的"免费/收费""门槛条件""处理周期"。
LAYER 04 — GUIDE
材料与时效提醒
根据案件类型自动生成"材料清单"（必备+建议），标注每项材料的获取方式。同时计算并提醒维权时效截止日期， urgency高的案件以红色警示。最后推荐就近的法律援助服务点。
