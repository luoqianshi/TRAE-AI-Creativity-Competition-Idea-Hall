03家庭急救三大痛点

PAIN · 慌乱中找不到答案
01PANIC

慌乱中没人能拍板

孩子烫伤，全家炸锅。老婆喊冲水，丈母娘喊涂牙膏，老父亲喊上冰块——关键时刻没人能统一口径。宝贵的黄金三分钟，就耗在互相质疑和争吵上。

02WRONG

土办法多是禁忌

流鼻血仰头会让血液倒流入气管，烫伤涂牙膏会污染创面，挑水泡会增加感染——老人坚持的"土办法"恰恰是急救禁忌，越救越伤，越帮越乱。

03DELAY

知识调不出来

海姆立克在哪学过？婴儿异物卡喉是拍背还是拍胸？知识在脑子里却调不出来，没人有空去翻百度看三分钟视频，全靠模糊记忆赌一把。

04四步工作流

FLOW · SELECT → SHOW → WARN → CALL
01
SELECT

选意外类型

从流鼻血、烫伤、异物卡喉、扭伤、中暑、宠物咬伤、割伤、触电八类中选定意外类型，再选伤者年龄与严重程度。

02
SHOW

看四格漫画

结果台立即吐出四格漫画分步演示，每格一个动作配对话气泡讲解，panelDrop 逐格入场，bubblePop 气泡弹出。

03
WARN

避禁忌警告

绿色✓标记正确做法，红色✗标记禁忌警告，3 stat 显示步骤数与禁忌数，让全家三十秒达成共识不再争吵。

04
CALL

判何时就医

底部警告条明确何时立即就医，所有触电与动物咬伤都需就医评估，为送医争取最宝贵的窗口。

05救急手册的价值

VALUE · 把急救变成肌肉记忆
VALUE · 01 · SAFE

把知识变可视化

四格漫画分镜的好处是每格只讲一件事，视觉记忆比文字强十倍。你记不住"冲水15-20分钟"，但你会记住那个橙色漫画小人举着水龙头说"冲够15分钟"的画面。

VALUE · 02 · LIFE

把慌乱变有序行动

绿色✓标正确做法、红色✗标禁忌，让全家三十秒达成共识，不再为要不要涂牙膏吵到错过最佳时机。把慌乱变成有序，把争吵变成行动，为送医争取最宝贵窗口。
