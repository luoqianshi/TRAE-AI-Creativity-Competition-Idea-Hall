创意介绍

痛点：AI 不认识你

你每次问 ChatGPT / Claude 一个问题，它对你一无所知。它不知道你的背景、经历、偏好、手头有什么资料——所以答案总是泛泛而谈。

🔒

数据碎片化

你的知识分散在文档、笔记、聊天记录、邮件、代码库里——没有统一入口，AI 无法读取。

🧩

AI 没有个人记忆

每次对话都是「失忆」的，AI 不知道你是谁、做过什么、有什么目标。建议永远停在「通用」层面。

☁️

隐私顾虑

不敢把全部个人数据上传到云端 AI。需要一种方案——数据完全在本地，模型也跑在本地。

🎯

缺乏个人化决策支持

无论是职业选择、学习计划还是日常决策，都需要一个「了解你全部情况」的顾问，而不是通用答案机器。

「第二个我」是一个运行在你本地的数字人系统。它接入本地大模型（Ollama / llama.cpp 等），获得读取你所有文件的权限，自动构建你的个人知识图谱和数字画像。从此，你问 AI 的任何问题，它都站在「完整了解你」的基础上回答。

产品形态

它怎么工作？

1

🔌 接入本地模型

支持 Ollama、llama.cpp、vLLM 等主流本地推理框架。无需联网，数据不出本机。也支持远程 API 模式（可选）。

2

📂 扫描与索引

用户授权后，扫描指定目录（文档 / 笔记 / 代码 / 邮件 / 聊天导出等），提取文本、元数据、文件关系，建立本地向量索引。

3

🧬 构建个人知识图谱

从文件中抽取实体与关系：你的项目经历、知识领域、人际关系、时间线、写作风格、技能图谱、兴趣偏好。

4

👤 生成数字人档案

自动生成结构化的个人档案——背景摘要、知识结构、能力画像、价值观倾向、决策偏好。支持人工校验和补充。

5

💬 情境感知对话

每次对话，系统自动将「数字人档案 + 相关文件上下文」注入 prompt。AI 以「最了解你的人」的身份与你对话。

6

📊 持续进化

每次对话、每份新文件都在丰富数字人档案。时间越久，它越了解你，建议越精准。

"学了一个新领域，感觉和之前的知识有断层。问：我学过的 A、B、C 和新学的 D 之间有什么联系？有什么项目可以把它们串起来？它调取你的学习笔记和项目记录，帮你绘制专属知识图谱。"

价值与意义

为什么值得做？

⚡ 效率革命

无需反复描述你的背景和需求。AI 从一开始就了解你的全部语境，每次对话节省 5-10 分钟的「背景说明」时间，建议质量从「通用级」跃升至「专家级」。

🔐 隐私优先

所有数据存储在本地，模型推理在本地完成。这是真正意义上的「隐私 AI」——你拥有自己全部数据的完全控制权，没有上传、没有泄露风险。

📈 商业价值

个人知识管理市场年增长 15%+，AI 个人助理是明确的趋势方向。可走「免费基础版 + 付费高级版（更大知识库/更精细画像）」模式，也可面向企业提供员工数字人档案 SaaS。

🌱 长期护城河

使用越久，数字人档案越丰富。用户对「了解我的 AI」的粘性极高——迁移成本不仅是数据，更是已经构建好的数字人画像。这是时间积累的壁垒。

技术实现

用 TRAE 快速原型

🖥️

桌面 GUI

TRAE Work 生成 Electron / Tauri 跨平台桌面应用，提供文件管理、对话界面、数字人画像可视化面板。

📦

向量存储

接入 Chroma / LanceDB 等本地向量数据库，存储文件嵌入和知识图谱，全部在本地运行。

🧠

模型接入层

统一接口对接 Ollama / llama.cpp / OpenAI API，支持不同模型按需切换。

📄

文件解析器

支持 Markdown / PDF / Word / 代码 / 纯文本等多格式解析，提取结构化信息。

MVP 开发路径：TRAE Work 生成桌面原型 → 接入本地 LLM → 实现文件索引与 RAG → 构建个人知识图谱 → 实现情境感知对话 → 持续优化画像精度。全程数据本地化，不上云。
