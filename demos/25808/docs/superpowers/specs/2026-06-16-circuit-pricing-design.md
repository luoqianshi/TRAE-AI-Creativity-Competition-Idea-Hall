# 回路级价格管理方案设计

**日期**：2026-06-16
**状态**：已确认
**版本**：v1.0

---

## 1. 背景与目标

### 1.1 问题描述

当前系统存在以下问题：
- 水电气单价分散在多个板块配置，容易不一致
- 无法为不同回路（主电网、备用电源等）设置不同单价
- 历史数据追溯时单价显示不准确

### 1.2 目标

- **一处配置**：在系统字典集中配置，全系统自动同步
- **回路级定价**：不同回路可设置不同单价
- **时间维度**：每个回路的价格可随时间变化（时光轴）
- **历史追溯**：查看历史数据时显示当时执行的单价
- **未配置告警**：回路未配置价格时明确提示，不静默使用默认值

## 2. 数据结构设计

### 2.1 新增类型

```typescript
// 价格查询结果
interface 价格查询结果 {
  单价: number;
  状态: 'found' | 'not_found' | 'unconfigured';
  回路名称?: string;
  告警信息?: string;
  建议单价?: number;
}

// 回路价格历史
interface 回路价格历史 {
  回路id: string;
  回路名称: string;
  默认单价: number;
  历史记录: 单价变动事件[];
}

// 字典配置扩展
interface 字典配置 {
  // ... 现有字段 ...

  // 新增：回路价格历史列表
  回路价格历史列表?: 回路价格历史[];
}
```

### 2.2 价格获取优先级

```
获取某回路在某日期的单价:
1. 在 回路价格历史列表 中查找该回路
2. 若存在，查找该回路历史记录中生效日期 <= 查询日期 且 (结束日期 >= 查询日期 或 无结束日期) 的记录
3. 若找到，返回该记录中的单价，状态为 'found'
4. 若未找到，返回单价=0，状态为 'not_found'，显示告警信息和可用建议单价
5. 若回路未配置，返回单价=0，状态为 'unconfigured'，显示告警信息
```

### 2.3 UI 状态处理

| 状态 | 显示效果 |
|------|----------|
| `found` | 正常显示单价 |
| `not_found` | 显示"未配置" + 告警提示 + 显示建议单价 |
| `unconfigured` | 高亮整行/列 + 告警提示 |

## 4. 统一价格查询 API

### 4.1 核心函数

```typescript
// src/shared/utils/pricing.ts

/**
 * 统一价格查询入口
 * 所有板块统一调用此函数获取回路单价
 */
export function getPrice(
  回路id: string,
  日期: string,
  限额配置: 字典配置
): 价格查询结果

/**
 * 获取某日所有回路的汇总价格（用于大盘展示）
 */
export function getDailyPrices(
  日期: string,
  限额配置: 字典配置,
  回路配置列表: DailyFieldConfig[]
): { 电: 价格查询结果; 水: 价格查询结果; 气: 价格查询结果 }
```

### 4.2 数据流向

```
系统字典配置 → 回路价格管理 → 回路价格历史列表
                              ↓
                      统一价格查询 API
                              ↓
        ┌───────────────┼───────────────┐
        ↓               ↓               ↓
    历史抄表库      用电/用水看板      综合能耗大盘
```
