核心亮点

发布与浏览更顺滑

用户可以快速发布失物、招领信息，也能在大厅中按关键词查找目标内容，减少信息遗漏。

闭环管理更完整

管理端支持账号、内容和公告管理，适合在答辩或汇报时强调“项目可运营”。

结构清晰易扩展

前后端分离，页面与接口边界明确，后续增加消息提醒、审核流程或统计面板都很方便。

技术结构

前端用户端

基于 uni-app 的移动端页面，覆盖首页、详情、发布、我的发布、公告中心、账号管理等核心路径。

pages.json Vue 页面 移动端适配
01
展示层

把首页、详情页和个人中心做成清晰的浏览路径，突出校园场景的易用性。

02
业务层

通过统一 API 连接失物、招领、认领、公告和上传图片等功能模块。

03
数据层

后端使用数据库持久化用户、内容和状态，形成完整的数据管理闭环。
