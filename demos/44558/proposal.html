工作台

为什么需要它？

Agent 在烧钱，没人知道烧在哪

公司里十几个 Agent 各调各的 API，月底账单一来才发现 Token 费用翻了 3 倍——但不知道是哪个 Agent、哪个任务、哪个人用的。没有 HR 给 Agent"算工资"，成本就是个黑箱。

该招人还是上 Agent？没人帮算这笔账

一个客服岗，招个新人月薪 8000，上个 Agent 每月 200 块但质量差点。到底值不值？没有工具把"人力成本 + Agent 成本 + 质量差异"放进同一个坐标系算 ROI，管理者只能拍脑袋。

Agent 出了事，不知道该谁负责、合不合规

客服 Agent 错批了一笔退款，损失 2 万——是 Agent 的错？是配置的人的错？数据有没有出境？用的模型备案了没？在中国，AI 合规是硬约束，但企业连"自查清单"都没有。

创意介绍

目标用户

已经或正在用 AI Agent 干活的小型 AI-NATIVE 团队（10-50 人，每个职能都配了 Agent）的团队 Lead / 运营负责人 / 兼职管 AI 的"准 ARD"角色。

典型场景

你是 DemoCo（一家 ~30 人的 SaaS 公司）的 CEO。一打开 ARD，看到一张混编组织图：市场品牌中心是"林夏（人）带着 4 个文案 Agent + 2 个新媒体 Agent"，客户成功中心是"陈薇（人）带着 6 个客服 Agent"。点"一键诊断"，系统扫一遍告诉你：本月 Token 成本可控，但客服 Agent 信任等级偏高、合规缺 3 项。点进去，逐项处理。

核心功能

🏥

一键诊断

点一下，系统扫遍你的混编组织，出一份体检报告：成本是否可控、哪些 Agent 信任过高、合规缺哪几项、成熟度在第几阶段。每个红黄项可点进去直接处理——报告本身就是进入全链路管理的导航器。

💰

质量-成本权衡沙盘

把"招人 / 上 Agent / 换模型"三种选择统一货币化，在"月度成本预算帽"内算 ROI。比如客服 Agent 从强模型换便宜模型，质量从 79% 掉到 67% 但省 600 块——客服场景 67% 还够用，这笔降级就值得。

🎖️

信任等级徽章

每个 Agent 头顶一个信任等级：🟡人在环中（HitL）→ 🔵人在环上（HotL）→ 🟢人外围（HoP）。可视化进度，且能根据质量波动自动建议升降级。

📊

双轨绩效

人和 Agent 用不同的指标，但对齐同一个业务目标。人评"协作力 + 判断力"，Agent 评"DTC + 质量 + Token 成本"。左边人、右边机、中间是业务 KPI——一眼看出谁在贡献。

一次使用流程

1

进入工作台

一打开就是 DemoCo 的混编组织图，看到人和 Agent 在同一棵树里。

2

一键诊断

点"诊断我的 Agent 管理"，等几秒，体检报告跳出（绿勾红叉 + 成熟度评级）。

3

跟着报告走

点红黄项，逐个跳到对应模块（成本/绩效/治理）处理。

4

做决策

在"质量-成本沙盘"里模拟"换模型/换人"，看 ROI 和成本帽，决定值不值。

5

看全局

在"管理模式总览"看 SSC/HRBP/COE 三支柱的健康度和配比是否合理。
