Script Pack 内容生产中枢

Script Pack 不是一段普通文案，而是把标题、口播、分镜、镜头时长、拍摄提示、平台文案、标签、评论引导等内容结构化封装，形成可解析、可执行、可复用的内容资产。它让 AI 生成的内容不再是一次性消费品，而是可以沉淀、优化、复用的创作资产。

核心创新点

1. 结构化内容生产创新
以 Script Pack 为核心载体，把选题、脚本、分镜、拍摄提示和发布素材封装为可执行内容资产，突破传统 AIGC 只输出文本的局限。
2. 拍同款创作模式创新
从参考视频中提取开头钩子、内容铺垫、核心表达、情绪转折、结尾引导，帮助创作者复现优质内容方法。
3. 多 Agent 协同创新
构建热点分析、脚本生成、质量评估、内容修正等多 Agent 协同机制，提高内容专业性、一致性和可控性。
4. 知识增强生成创新
融合热点库、人设库和平台风格知识库，降低大模型幻觉，提高生成稳定性和行业适配能力。
5. 多模态视频理解创新
自动分析参考视频的镜头结构、运镜节奏、构图逻辑和口播策略，为跟拍提供结构化依据。
6. 数据驱动运营创新
构建热点采集、审核发布、反馈优化机制，形成"生成—发布—反馈—优化"的运营闭环。
