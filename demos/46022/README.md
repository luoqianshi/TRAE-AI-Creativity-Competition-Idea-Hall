# Text2SQL Agent - 自然语言查询数据库平台

## 📖 项目简介

这是一个支持用自然语言查询数据库的智能平台Demo。用中文描述你的数据需求，AI会自动生成SQL语句、执行查询并返回分析报告。

## 🚀 快速开始

### 方式一：直接打开（推荐）
双击 `index.html` 文件即可在浏览器中打开体验。

### 方式二：本地服务器
如果你有Python或Node.js环境，可以启动本地服务器：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server -p 8000
```

然后访问 `http://localhost:8000`

## ✨ 功能模块

### 1. 智能查询引擎
- 自然语言输入 → 生成SQL → 执行查询 → AI解读
- 四步流程可视化动画展示
- 支持示例问题一键体验

### 2. 数据管道
- SIF关键词排名同步状态
- 领星广告数据同步状态
- 链仓库存数据同步状态

### 3. 监控告警
- 预置规则：广告浪费告警、断货预警、滞销预警、库存异常
- 最近告警记录展示

### 4. 业务规则
- 领域模板市场（广告/电商/CRM/通用）
- 模板评分与采用功能

### 5. 会话管理
- 历史对话列表
- 创建/切换/删除会话
- 自动保存查询历史

### 6. 数据连接
- MySQL连接管理界面
- 连接测试、Schema刷新
