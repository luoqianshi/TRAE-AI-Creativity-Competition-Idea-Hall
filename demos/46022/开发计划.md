# 亚马逊跨境电商数据查询平台 - 开发计划

> **版本**: v1.0  
> **日期**: 2025-06-24  
> **目标**: 打造亚马逊跨境电商运营的数据查询 + 监控告警工具

---

## 一、项目概述

### 1.1 产品定位

**聚焦定位**：亚马逊跨境电商运营的数据查询 + 监控告警工具

- **目标用户**：公司内部运营团队
- **业务场景**：亚马逊家居品类，FBM模式，第三方海外仓
- **核心价值**：跨系统数据关联（广告 × 库存 × 销量），消除运营在多平台间手动切换的痛点

### 1.2 差异化价值

解决运营当前工作流痛点：
| 数据类型 | 当前平台 | 痛点 |
|---|---|---|
| 库存 | 链仓后台 | 三个平台来回切换 |
| 销量 | Amazon Seller Central | 数据关联全靠脑记 |
| 广告 | SIF工具 | 无法做交叉分析 |

**核心场景**：运营可以问 "库存不足30天销量、且正在跑广告的ASIN有哪些？"

### Phase 4：监控告警上线（第8-9周）

#### 3.4 监控告警规则配置

| 任务 | 描述 | 负责人 | 预估工时 | 依赖 |
|---|---|---|---|---|
| **MON-001** | 配置库存预警规则（不足15天销量） | 运营+开发 | 8h | 数据已入库 |
| **MON-002** | 配置滞销品提醒规则（库龄>90天） | 运营+开发 | 8h | MON-001 |
| **MON-003** | 配置爆品断货预警规则 | 运营+开发 | 8h | MON-001 |
| **MON-004** | 配置广告浪费告警规则 | 运营+开发 | 8h | MON-001 |
| **MON-005** | 配置飞书推送Webhook | 开发工程师 | 4h | 飞书账号 |
| **MON-006** | 测试告警触发与推送 | QA | 8h | MON-001~MON-005 |

**监控规则配置**：

| 规则名称 | SQL逻辑 | 告警频率 |
|---|---|---|
| 断货预警 | `stock_quantity / avg_daily_sales < 15` | 每天 9:00 |
| 滞销提醒 | `age_days > 90 AND stock_quantity > 100` | 每周一 10:00 |
| 爆品预警 | `avg_daily_sales > 50 AND stock_quantity < 200` | 每天 14:00 |
| 广告浪费 | `spend_7days > 200 AND orders = 0` | 每天 18:00 |

## 四、技术架构

### 4.1 总体架构图

```
┌─────────────────────────────────────────────────┐
│              数据管道层 (pipeline/)              │
│                                                 │
│  SIF 广告数据 → requests 模拟 →  MySQL          │
│  Amazon 报表  → Playwright RPA →               │
│  链仓库存数据 → requests 模拟 →                 │
│                                                 │
│  AsyncIOScheduler 定时驱动                      │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│            Agent 查询层 (agent/)                 │
│                                                 │
│  广告 × 库存 × 销量 交叉查询                     │
│  LangGraph 4 节点流程                           │
│  retrieve_schema → generate_sql → execute_sql   │
│  → generate_answer                             │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│           监控告警层 (agent/monitor.py)          │
│                                                 │
│  库存预警 + 广告异常 → 定时SQL → 飞书推送        │
│  AsyncIOScheduler + CronTrigger                 │
└─────────────────────────────────────────────────┘
```

## 七、风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|---|---|---|---|
| SIF接口变更 | 中 | 数据抓取中断 | 定期检查，异常告警通知 |
| Amazon风控 | 高 | RPA被封 | 使用专用账号，控制请求频率 |
| 数据一致性 | 中 | 多数据源时间差 | 统一时间戳，数据版本管理 |
| 定时任务失败 | 低 | 数据滞后 | 失败重试机制，告警通知 |
