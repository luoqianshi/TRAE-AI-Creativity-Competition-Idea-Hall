云烯Agent
面向功能材料研发的"预测—仿真"全链路 AI Agent 平台

借鉴开源 AI Agent 的多智能体架构思路，构建一款本地部署的桌面端智能体软件： 自动管理实验数据、解析 PDF/CAJ 论文、预测关键性能、反向推荐最优配方，并引入传输线模型（TLM）等仿真计算能力，把"经验+试错"的研发流程升级为"AI 预测 → 仿真验证 → 实验迭代 → 模型自进化"的闭环。 首版聚焦石墨烯基复合吸波材料，架构保持通用，可横向扩展至导热、导电、储能电极等其他功能材料体系。

参赛形式：个人参赛 赛道：学习工作 / AI for Science 产品形态：桌面端 Agent（Windows / macOS / Linux） 核心能力：性能预测 + 配方推荐 + TLM 仿真 首版场景：石墨烯基复合吸波材料 可扩展场景：其他功能材料体系

① 创意名称 + 创意介绍

创意名称：云烯Agent — 面向功能材料研发的"预测—仿真"全链路 AI Agent 平台

想解决的问题：功能材料研发高度依赖"经验 + 试错"，配比组合多、实验周期长、成本高；历史实验数据与公开论文散落在 Excel/PDF/CAJ 等多种介质，难以统一检索与复用。

动机来源：本人长期从事材料研发相关工作，积累了一批自研实验数据。日常深感效率瓶颈。开源 AI Agent 的爆发让我意识到：可以让 AI 像一位"不知疲倦的研发助理"一样自动阅读论文、推理配方、预测性能。

产品形态：本地部署的桌面端 Agent，融合数据管理 + 材料知识图谱 + 机器学习预测模型 + TLM/CST 仿真 + LLM 对话交互；先在石墨烯吸波材料上跑通"预测—仿真"全链路，架构保持通用以便横向扩展。未来可进一步对接实验设备、部署到实验机器人成为其"大脑"，实现材料研发的全链路智能化。

② 目标用户及痛点

核心用户（首版）石墨烯基复合吸波材料研发人员 潜在用户其他功能材料研发人员、高校材料课题组 场景 1配方推演：给定目标性能，推荐候选配比与工艺 场景 2数据分析：批量导入实验数据，自动提取特征 场景 3文献调研：Agent 阅读 PDF/CAJ，抽取关键实验参数 场景 4新组合发现：预测值得验证的新型复合体系
  • 数据孤岛：实验记录与论文分散在多种介质，难以统一检索与复用
  • 迭代缓慢：一组配方从配料到拿到关键性能曲线需数天到数周
  • 经验依赖：配方设计高度依赖资深人员，新人上手困难
  • 缺少定量预测：无法提前判断"这个配方值不值得花时间做"

③ 价值与意义

效率提升：把研发路径从"盲目试错"改为"AI 预测 → 实验验证 Top-N → 模型增量学习"的闭环，有效配方筛选周期预计可缩短 30%–50%。

技术独特性：与大多数参赛者不同，本项目拥有一批自研积累的真实实验数据作为训练基础，这是区别于纯"基于公开论文 + LLM 幻觉"项目的核心优势，也是防止低水平重复的天然护城河。

通用可扩展：数据层、知识层、模型层、Agent 层全部解耦设计；首版完成后，替换一批结构化的实验数据表即可迁移到其他功能材料体系。

社会价值：探索 AI Agent 在硬科技（材料科学）场景下的低成本落地路径，让中小规模的研究者也能用上 AI 辅助研发工具。

拥有自研实验数据，模型可实际落地 首版聚焦石墨烯，可横向扩展 本地部署，数据不离开研发环境

④ 技术思路（可落地 MVP）

  • 数据层：SQLite/PostgreSQL 统一存储配方与性能；PyMuPDF/pdfplumber 解析 PDF；CAJ 先转 PDF 再进入同一管线。
  • 知识层：基于材料学原理的知识图谱（组分—结构—性能关系）+ RAG 文献检索索引。
  • 模型层：GBDT/随机森林做关键性能指标回归 Baseline；给定目标性能时用贝叶斯多目标优化反向推荐配方；新材料组合基于知识图谱做链路预测。
  • Agent 层：四种子 Agent（数据工程师 / 文献挖掘 / 预测 / 研发助手），借鉴多智能体编排；本地开源 LLM（Qwen / DeepSeek / Llama 系列）+ TRAE Work 辅助原型搭建。
  • 桌面端：Python 核心 + 跨平台 UI，Windows/macOS/Linux 均可运行。

🚀 首版开发路径（先跑通石墨烯"预测—仿真"全链路）

1
数据标准化

自研实验数据统一入库，建立配方与性能两张核心表。

2
ML 预测模型

训练 RL、EAB、介电磁参数等关键指标回归模型。

3
TLM 仿真

基于传输线模型计算 RL 曲线，与 ML 预测形成交叉验证。

4
反向推荐 + 文献

给定目标性能输出 Top-N 配方；PDF 自动抽取关键参数。

5
Agent 桌面 UI

对话式交互 + 预测与仿真可视化，正式投入使用。

🔮 未来展望

本项目不止于一个软件 Agent。长远来看，它可以逐步向下游延伸： 从 TLM 仿真进阶到 CST 等全波电磁仿真 → 对接矢量网络分析仪、热压机等实验设备 → 部署到实验机器人成为其"大脑" → 最终实现从文献阅读、配方设计、仿真验证到实验执行的材料研发全链路智能化， 用 AI 真正加速中国新材料研发进程。

📌 为什么这个项目值得参赛

① 场景够"硬"：当下大多数 AI Agent 集中在办公、客服、代码生成等"软"场景，真正落地到材料科学这种硬科技场景的还不多见。 把 AI Agent 用在吸波材料这种关键新材料研发上，本身就是一个有差异化的方向。

② 数据有壁垒：与纯靠公开论文 + LLM 生成的项目不同，本项目基于一批自研积累的真实实验数据训练模型， 这是天然的技术护城河——别人抄得走架构，抄不走数据。

③ 预测—仿真双引擎：不是只靠 ML 黑盒预测，而是把「数据驱动的机器学习预测」与「物理驱动的 TLM/CST 仿真」 做交叉验证，结果更可信。既有 AI 的灵活性，又有物理模型的可解释性，这是区别于纯 LLM 材料问答项目的核心技术亮点。

④ 路径够清晰：从"预测—仿真"双引擎的桌面端 Agent，到对接实验设备自动采集数据，再到部署成为实验机器人的"大脑"， 每一步都有明确的价值落地，不是空中楼阁。参赛本身就是对这条路径最好的验证。

⑤ 真需求驱动，想象空间大：这不是一个为了比赛硬凑的 idea，而是我自己每天做研发都想用的工具。 首版跑通石墨烯吸波材料后，架构可以横向迁移到导热、导电、储能电极等其他功能材料体系， 具备成为"材料研发通用基础设施"的潜力。
