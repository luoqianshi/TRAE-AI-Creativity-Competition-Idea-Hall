一、创意名称 + 创意介绍 —— 我们要解决什么问题

1想解决什么问题

许多音乐爱好者、学生、老师在学习和享受音乐的过程中，被「工具碎片化」困扰： 听歌用播放器、练琴用另一个软件、写乐谱又要打开专业编辑器、想在电脑上弹两曲还要外接 MIDI 键盘。 不同软件之间数据割裂、界面不统一、学习成本高，让"享受音乐"变成了"折腾工具"。

2为什么会想到做这个

在日常音乐学习与创作中，我们发现身边的同学、老师常常在多个软件之间反复切换， 却始终缺少一个"开箱即用、功能完整"的桌面工具。MusicAgent 的动机， 就是把音乐爱好者真正需要的能力整合到同一款产品里，让工具为音乐服务，而不是相反。

3大概是什么产品

一款基于 Electron + TypeScript 的桌面音乐应用， 集成音乐库管理、虚拟键盘演奏、下落式练习、乐谱编辑、MIDI 输入、自定义音色等 8 大模块。

三、核心功能模块 —— 8 大任务域一览

模块能力描述
🎵 音乐库支持 MP3 / FLAC / OGG / M4A 导入，元数据解析、封面提取、拼音全文搜索、播放列表与最近添加
📝 歌词LRC 解析与时间同步滚动、逐句高亮，跟随播放自动定位
🎹 键盘演奏60 / 75 / 100 / 数字键盘多种布局，5 种内置音色，支持八度调整与延音、混音
🎛 自定义音色采样导入（wav/mp3）、ADSR / 滤波器编辑器，用户可自制专属音色
🎯 练习模式下落音符 + Perfect / Good / Miss 判定，节奏偏差统计，分段/慢速练习，自动生成练习报告
📜 乐谱编辑Piano Roll 编辑器、BPM 网格、拖拽时长，支持 MIDI / MusicXML / JSON 导入导出
🎼 MIDI接入 Web MIDI API，支持外接 MIDI 键盘演奏与录音
🔊 音频引擎6 种乐器模块、混音台、EQ、压缩器，±5 音分精度，4 种实时可视化
🤖 智能推荐加权评分 + 可解释理由，支持歌手 / 语言偏好过滤
👤 个人资料头像上传裁剪、昵称签名、偏好设置；播放历史自动记录与统计

五、价值与意义 —— 效率提升 + 社会价值

🚀 效率提升

把"听歌 → 演奏 → 练习 → 写谱"串成一条链路，免去用户在多款软件之间反复切换的成本，显著降低音乐学习与创作的门槛。

  • 一个桌面 App 涵盖 8 大模块，无需分别安装与学习
  • 智能练习模式自动给出节奏反馈，替代传统人工判分
  • 统一的数据与账号体系，播放 / 练习 / 收藏一处管理

🌱 社会价值

让买不起或不方便使用专业乐器的人，也能用一台电脑完整地享受与学习音乐，促进音乐教育的普及。

  • 无需真实钢琴，仅需电脑即可开始练习
  • 自定义音色 + 乐谱编辑，让创作触手可得
  • 开源与开放的架构，欢迎学校与社区二次开发
