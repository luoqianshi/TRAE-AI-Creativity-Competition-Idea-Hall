01 / Pain Points

嵌入式调试的痛点

串口数据是裸字节流，传统工具让开发者苦不堪言。

😵 肉眼读字节，效率极低

调试温度传感器，串口输出 `0x01 0x2A 0xF5`，需要手动换算成温度值，再记录到Excel才能画图看趋势。一次调试耗时30分钟以上。

→ SerialMaster 自动解析映射，连接即出实时曲线

🪟 多路数据，窗口堆叠

同时监控温度、电压、电流、功率时，只能开4个串口助手窗口来回切换，屏幕被占满，数据对比全靠记忆，极易眼花出错。

→ SerialMaster 支持11路同时可视化，一屏尽览

🔧 频繁切换，重复配置

上午调试SH79F灶具板（115200波特率），下午调试STM32电机板（9600波特率），每次都要重新配置一遍参数，消磨耐心。

→ SerialMaster 预设管理，一键切换设备配置

💨 异常稍纵即逝，无据可查

偶发的通信异常或传感器跳变，往往在眨眼间错过。没有自动记录，问题复现困难，调试陷入死循环。

→ SerialMaster 自动日志，异常数据永不丢失

03 / Features

六大核心功能

从连接到分析，覆盖串口调试全流程。

🔌

自动扫描连接

一键扫描系统可用串口，支持9600/19200/38400/115200等全部常用波特率，3秒完成连接配置。

📈

11路实时曲线

自研Canvas渲染引擎，最多11通道同时可视化，每路独立颜色、名称、Y轴量程，60FPS流畅刷新。

📋

帧数据表格

逐帧解析显示原始字节与换算结果，时间戳精确到毫秒，支持文本/HEX/混合三种显示模式。

⚡

快捷指令按钮

把常用调试命令保存为按钮，点一下就发。支持文本和HEX两种格式，调试效率提升10倍。

💾

预设配置管理

不同设备参数保存为预设配置文件，切换项目时一键加载，告别重复配置的繁琐。

📝

自动日志记录

所有收发数据自动存入本地SQLite数据库，支持按时间范围检索导出，异常数据有据可查。
