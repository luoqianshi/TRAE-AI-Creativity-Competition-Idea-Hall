PITCH

玩家穿越成新皇，用自然语言统治天下——可以做圣君，也可以做暴君，一切由你，后果也由你。

这是一个开放沙盒：你可以下江南减税、封宗室、宣战蛮夷， 也可以当庭诛杀大臣、终日酒池肉林、把国库赏给戏子、假装病重不上朝—— 系统绝不阻止，只负责让王朝用真实的方式反噬回来。

Agent 负责推演角色与派系反应， 规则引擎负责结算所有数值与状态—— 最大的自由度、最真实的后果。

核 心 架 构 · Agent 演 算 + 规 则 引 擎

ARCHITECTURE · AGENT + RULE-FRAMEWORK

玩家的每一条自然语言，都由两套系统接力处理： Agent 负责把"朕意"翻译成可执行的动作，并让 NPC、派系、敌国据此推演反应； 规则引擎 负责结算所有数值与状态（国库、忠诚、兵力、法统、民怨、外交）—— 玩家永远是最终决策者，系统绝不拦截，也绝不替玩家"做对的选择"。

拟 旨 卡 · 三 色 警 示（建 议 而 已）

WARNING SYSTEM · SUGGESTION ONLY

系统三色只是"史官的风险提示"，不是拦路虎。 红牌命令玩家可以一键"朕意已决"强制执行—— 但世界会用真实的方式反噬回来：忠臣辞官、派系起兵、民间暴动、敌国入侵。 系统不阻止你做暴君，只让你知道你即将做什么。

// 设计原则：拟旨卡 = 风险披露器，≠ 权限控制

绿 牌 · 风险低

九 大 政 治 子 系 统

POLITICAL PHYSICS

权 力

皇帝威望、部门服从、强制力、恐惧值。决定命令直达率与抗命成本。真相层：实际服从 ≠ 表面恭顺。

// 结算节奏：月

资 源

库银、粮仓、人力、行政注意力、运输能力。决定能否执行与能执行多久。真相层：部门会虚报瞒报库存。

// 结算节奏：月

派 系

阵营规模、互信、仇恨、席位、交易债。左右任命、弹劾、拥立、结党。真相层：私下交易默认隐藏。

// 结算节奏：周/月

信 息

真实状态、上达状态、流言、证据完整度。决定玩家能否正确判断局势。真相层：地方和派系都加工信息。

// 结算节奏：日 / 事件触发

继 承

储位法统、皇子能力、母族势力、教育、流言。决定皇子争斗与晚期主线。真相层：许多支持网络暗藏。

// 结算节奏：月/季

地 方

省治安、产出、灾荒、文化张力、自治倾向。决定各省对同一政策的反应差异。真相层：执行细节高度失真。

// 结算节奏：月

军 事

战备、士气、忠诚、补给、将领声望。决定战争与镇压的真实效果。真相层：将领私心与边军状态可隐藏。

// 结算节奏：月 / 战时周

法 统

礼制支持、法令一致性、先例、民间认可。决定高压政策的可持续性。真相层：流失通常滞后爆发。

// 结算节奏：季/年

时 间

日常打断、月度主循环、季度朝会、年度大典。决定后果显现顺序。真相层：许多坏事不会立刻爆。

// 结算节奏：日/月/季/年

命 运 权 重 · 位 高 则 重，位 微 则 轻

FATE WEIGHT · VARIABLE

每一个角色、每一个派系、每一个事件都有一个命运权重。 位置越高、与越多、影响越大、牵扯越深——反过来说， 一个普通百姓的死亡几乎没什么人记得，一位内阁首辅的倒下可能把半朝动荡。

// 核心公式：影响力 ∝ 命运权重 × 事件强度 × 关系网半径

位 高 则 重

皇帝、首辅、皇子的每一个决定都会被放大： 皇帝随口一句、一个犹豫、一个判决——都会在朝堂荡开去

// 权重 90–100 · 后果可能引起派系洗牌

位 微 则 轻

市井小民、普通士兵的日常，系统批量结算。他们只做"会说话的背景"的 几乎不会影响全局。

// 权重 1–20 · 几乎无全局影响

允 许 有 变 数

但偶尔——极低概率——一个小人物也可能撬动时代。 一位无名刺客、一场洪水、一封意外的密信—— 系统保留低概率但真实存在的变数事件。

// 变数事件：低概率 · 但真实

变 数 · 当 小 人 物 撬 动 时 代

原权重 5 → 事件后突升至 75。

// 原权重 15 → 事件后权重 85
// 变数事件 · 0.5% 触发

// 影响半径随扩散，最终可引起叛乱
// 变数事件 · 0.1% 触发

皇子染病 · 一位被忽视的皇子突然重病。

// 继承顺位洗牌 · 全朝重新站队

权 重 如 何 计 算

命运权重 FateWeight = 基础权重（身份 / 官位 / 派系基础值） × 当前事件强度（这条命令 / 事件有多重大） × 关系网半径（有多少相关者卷入） × 随机性（0.3x – 3.0x） 权重越高，结算时数值影响越大， 也越容易被其他高权重者反制。 // 但永远保留最后一项随机性， // 所以小人物也可能撬动时代， // 高权重者也可能意外失势。

执行偏差模型 · 为什么好政策会做坏

官员对圣旨的六种偏差处理，直接解释"朝令不出宫门"的政治现实。

能力偏差
同样的命令，能力不足的人落地更慢、更错、更贵。
腐败偏差
执行途中截留资源、插入自己的私货与人脉。
过度执行
为表忠心而加码，导致民怨沸腾或法统受损。
观望偏差
等风向不敢先做，产生"朝令不出宫门"的窒息感。
曲解偏差
按自己私利理解皇帝意图，原旨完全走样。
泄密偏差
公开/半公开/暗中放风给派系或敌国。

写 作 风 格 · 当年明月式

系统会在最终结算时，把以下资料打包投喂给 AI 进行"史书生成"：

输入给史书 AI 的资料包 · 完整事件日志（event log · 按回合排序） · 所有 NPC 的初始/最终命运权重与关键转折 · 各派系势力曲线（每季度快照） · 国库 / 军力 / 法统 / 民怨 数值曲线 · 皇帝本人的关键决策与关键性格标记 · 重要变数事件（小人物撬动时代）的前后因果 写作参考资料：《明朝那些事儿》全卷文本作为风格参考 写作原则： · 不评分、不颁奖、不给"成功/失败"二元标签 · 写得好的地方夸，做错的地方骂，可笑的地方笑 · 对暴政、昏政、恶政，敢于尖刻评价 · 对善政、克制、智慧，也真诚地赞美

不 同 的 结 局，不 同 的 书

// 仁政型

书名示例：《一个懂得克制的皇帝和他还算太平的三十年》

书中写你如何在权臣、派系、皇子之间做平衡，如何拒绝好大喜功的诱惑， 最终留下一个"不算精彩、但百姓还算太平"的时代。

// 暴君型

书名示例：《他杀了一半朝臣，然后呢？》

书中用讽刺的笔调写你如何廷杖、抄家、清洗， 如何把朝堂变成屠宰场，以及你死后一切如何崩塌。

// 荒诞型

书名示例：《一个把国库赏给戏子的皇帝》

用哭笑不得的口吻写你二十年不上朝、把军饷拿去修花园、 把朝廷变成笑话——但偏偏你的王朝竟然还撑了下来。

// 权臣被反杀型

书名示例：《他以为自己掌控一切，结果被一个小兵撬动了时代》

重点写"变数事件"——你如何在一切尽在掌握的时刻， 被一个权重原本只有 5 的小人物撬动全局、最终改写了历史。

输 出 · 每 一 局 都 是 一 本 可 导 出 的 书

· 最终结算生成一部 6–12 卷的纪传体史书， 用当年明月的口吻写成，3 万–8 万字，随玩家回合长度动态生成。
· 玩家可选择直接阅读 / 导出 epub / txt / 生成封面与插图。
· 系统绝不评分、不发勋章、不打成功或失败的标签—— 只给你一部"写你自己的书"。
