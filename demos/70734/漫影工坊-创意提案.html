创意介绍

🎯
想解决什么问题

多工具横跳，单条数小时

做一条卡通短视频，要在文案、分镜、绘图、配音、剪辑、字幕等六七款工具间反复横跳：手动搬运素材、逐个调试参数、统一风格，单条视频动辄数小时，批量生产几乎不可能。

💡
为什么会想到

环节已成熟，缺一个编排层

AIGC 各环节模型——文生图、图生视频、TTS、ASR——已逐一成熟，但它们是孤岛。大量自媒体、教育、营销创作者想做卡通视频，却被工具门槛卡住。缺的不是一个新模型，而是一条把它们串起来的「流水线」。

🎬
大概是什么产品

卡通视频自动化生产工作台

基于 TRAE 的卡通视频自动化生产工作台：输入一段文案，自动完成「文案拆解 → 分镜脚本 → 卡通图片生成 → 视频片段生成 → 配音字幕 → 合成成片」全流程，输出可直接分发到抖音/B站/视频号的 MP4。

当前痛点 · 没有它会怎样

  • 多工具切换：文案、绘图、配音、剪辑分散在六七款软件里，反复导入导出
  • 手动衔接：每个环节产出的素材要人工对齐到下一环节，易错且耗时
  • 风格难统一：不同分镜的图片风格漂移，全片视觉割裂
  • 单条产出慢：一条 1 分钟卡通视频动辄数小时，无法规模化
  • 门槛高：需精通 Midjourney/SD、剪映、TTS、字幕等多款工具
  • 无法批量：内容矩阵运营需要稳定产能，人工流程上限太低

价值与意义

效率提升 · 商业价值
效率提升

数小时 → 分钟级

10× 提速

把「数小时/条」压缩到「分钟级/条」。全流程自动编排，创作者只需把关创意与文案，把分镜、绘图、配音、字幕、合成的重复劳动交给流水线。产能从「一天几条」跃升到「一天几十条」。

商业价值

低门槛生产能力

0 门槛入局

低门槛卡通视频生产能力 = 内容工作室产能放大 + 个人创作者零门槛入局。支撑 MCN、教育、营销团队的规模化内容供给，让「会写文案」成为做卡通视频的唯一前置条件。

Skill 与工具规划

每个环节封装为 Skill，统一编排
MASTER cartoon-pipeline
编排层 · Orchestrator

流水线总调度 Skill：接收一段文案输入，按顺序串联下方 5 个子 Skill，输出最终成片。负责中间产物存储、失败重试、进度回传、风格一致性校验，对外只暴露「文案 → 成片」一个接口。

输入一段主题文案 / 文章 输出可分发的卡通视频 MP4 + 字幕 SRT
TRAE AgentSkill 机制任务队列对象存储
SKILL 01 script-breakdown
阶段 1 · 文案拆解

用 LLM 把长文案按场景拆成分镜表：每个分镜含场景描述、旁白文本、画面提示词、镜头时长。控制单镜时长在 2–5 秒，保证节奏适合短视频。

输入主题文案 输出分镜表 JSON（scene_id / narration / visual_prompt / duration）
TRAE 内置 LLM结构化输出
SKILL 02 cartoon-image-gen
阶段 2 · 卡通图片生成

调用文生图模型，为每个分镜生成卡通图。注入统一风格前缀（吉卜力 / 扁平卡通 / 3D 卡通），支持参考图锁定角色形象，保证全片风格一致、人物不漂移。

输入visual_prompt + 风格 + 参考图 输出每个分镜的卡通图片
即梦可灵SDXL
SKILL 03 video-clip-gen
阶段 3 · 视频片段生成

把静态分镜图 + 运镜指令（推/拉/摇/移）转成 2–5 秒动态片段。对生成失败或运镜异常的片段自动重试，保证片段数量与分镜一一对应。

输入卡通图 + 运镜描述 输出带动态效果的视频片段
可灵即梦Runway
SKILL 04 tts-subtitle
阶段 4 · 配音与字幕

把旁白文本转成语音，并生成带时间戳的 SRT 字幕。支持多音色选择，音画时长对齐——字幕时间轴由 TTS 实际返回时间生成，杜绝错位。

输入旁白文本 + 音色 输出配音音频 + SRT 字幕
豆包语音合成火山引擎 TTS
SKILL 05 video-compose
阶段 5 · 合成输出

按分镜顺序拼接视频片段，叠加音轨、烧录字幕、加转场，输出最终成片。支持横屏 16:9 与竖屏 9:16 一键切换，适配不同分发平台。

输入片段序列 + 音频 + 字幕 输出最终成片 MP4
FFmpeg转场字幕烧录

技术架构

四层结构 · 各司其职
交互层INTERACTION
用户输入文案、选择风格/音色/画幅，查看流水线进度与预览，下载成片。Web 工作台形态。
编排层ORCHESTRATION
cartoon-pipeline 总调度：串联 5 个子 Skill，管理中间产物、失败重试、风格一致性校验，对外暴露「文案 → 成片」。
能力层SKILLS
5 个原子 Skill：script-breakdown / cartoon-image-gen / video-clip-gen / tts-subtitle / video-compose，每个封装一类 AIGC 能力。
模型层MODELS
底层 AIGC 模型与工具：LLM、文生图、图生视频、TTS、FFmpeg，由各 Skill 按需调用，可替换为同类模型。
