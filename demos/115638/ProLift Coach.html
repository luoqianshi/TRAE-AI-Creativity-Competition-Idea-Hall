我的

从“记录工具”升级成“训练决策系统”

当前前端 Demo 已覆盖训练者每天最常见的决策闭环：看状态、练计划、记动作、算营养、问教练、看周期、追数据。

训

今日训练

  • 根据真实日期生成今日训练页
  • 展示动作、组数、次数、重量、RPE
  • 支持动作完成打标和动作库追加
  • 根据备赛周期提示当前训练阶段
历

训练日历

  • 按月展示训练安排、减量带和赛事备赛带
  • 只有真实今天使用高亮大圆标识
  • 赛事日使用小色点，避免误导
  • 女性周期用“经/卵/排/黄”小标识提示
营

营养计算

  • 按性别、年龄、身高、体重计算基础代谢
  • 拆分基础活动、今日训练消耗和 TDEE
  • 根据动作库、组次、重量和 RPE 估算训练热量
  • 自动生成蛋白、碳水、脂肪目标
聊

AI 教练对话

  • 流式回复，像和真人教练聊天
  • 支持动作执行：创建赛事、记录 PR、加入训练
  • 刷新重新开始，切换 Tab 不丢会话
  • 连接异常时自动重连和清晰兜底
数

数据工具

  • 支持 1RM 估算和 Sinclair 计算
  • 计算器数字可手动编辑
  • 体重变化联动营养和辛克莱尔
  • PR 记录用于后续趋势分析
女

女性训练支持

  • 默认女性画像，营养公式按女性计算
  • 按 30 天周期估算经期和相位
  • 首页和日历均有周期提示
  • 根据周期给出训练强度和恢复建议

四个高频训练旅程

力量训练的核心不是单次回答，而是每一天、每一周、每一个周期都能持续做出更好的训练选择。

备赛倒计时12 周周期：体积、强度、峰值、减量
每日决策结合睡眠、HRV、主观疲劳决定练或休
瓶颈突破分析训练量、强度、恢复和技术问题
伤后复训替换动作，保护伤处，保留训练刺激

用户使用流程

1
建档
录入身高、体重、年龄、目标、训练频次、伤痛和偏好。
2
生成计划
AI 根据用户画像和备赛阶段生成本周训练安排。
3
每日执行
训练前看恢复状态，训练中打卡动作，训练后记录反馈。
4
动态调整
根据少练、受伤、疲劳、体重变化自动调整后续计划。
5
长期进步
归档训练周期，追踪 PR 趋势，持续更新用户画像。

Multi-Agent Supervisor 架构

ProLift Coach 的核心不是一个大而全的聊天框，而是由多个专业角色协作完成训练决策。

AI 教练团队

总教练 Coach 意图理解、用户画像、任务分发、冲突仲裁和每日推送。
规划师 Planner 周期化训练、PR 管理、动作偏好和训练进阶策略。
诊断师 Diagnosis 恢复分析、疲劳预警、伤病评估和康复替代方案。
营养师 Nutrition 宏量营养、训练消耗、补剂循证和赛前体重管理。
前端体验 Web App，今日训练、计划日历、AI 教练、数据工具和个人页联动。
后端 Agent 流式回复、意图路由、动作抽取和本地训练数据写入。
知识库 训练、营养、康复相关 RAG 文档，后续升级向量语义检索。
记忆层 当前本地画像与训练记录，后续接入持久化记忆实现跨设备使用。
扩展接口 MCP Server 预留穿戴数据入口，可接入 HealthKit、Health Connect、华为 Health Kit。
安全兜底 连接自动重试、工具失败降级、RAG 无召回时标注经验回答，医疗边界提醒就医。

三阶段产品演进

当前 Demo 已跑通训练 Agent 的产品闭环，后续可以从前端演示快速进入 POC 和商业化部署。

Phase 1 · Demo 验证期

  • 跑通 AI 教练逻辑
  • 完成今日、计划、教练、数据功能闭环
  • 验证训练、营养、恢复、女性周期等核心场景
  • 用 TRAE Work HTML 展示完整创意方案

Phase 2 · POC 多端期

  • 扩展小程序和移动端 App
  • 建设教练 SaaS 后台和白标学员端
  • 接入持久化记忆和向量知识库
  • 接入真实穿戴设备数据

Phase 3 · 商业化规模期

  • 提供 SDK 和 OpenAPI
  • 嵌入手机厂商和智能穿戴生态
  • 扩展语音陪练和视觉动作识别
  • 上架 MaaS 市场，按调用量变现
