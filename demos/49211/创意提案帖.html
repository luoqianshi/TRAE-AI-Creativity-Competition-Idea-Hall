天机盘

TIAN JI PAN

一个黑金古风的在线算命罗盘，输入姓名生辰，转动天干地支八卦盘，以《风云》泥菩萨口吻为你批断前程姻缘财运劫难。

乾坎艮震 巽離坤兌

创意来源

小时候看《风云》，泥菩萨推演天机、批言断命的桥段让我念念不忘。那句经典台词至今回响：

"成也风云，败也风云。"

—— 《风云》泥菩萨

我想：能不能让每个普通人，都体验一次泥菩萨推卦的感觉？

不是简单的"运势测试"H5，而是一个有仪式感、有沉浸感的江湖算命体验。

于是有了「天机盘」。

核心玩法

三幕仪式感交互流程：

01

起坛

墨色 parchment 上金色大字"天机盘"缓缓浮现，六芒菱形按钮"開始問卜"散发幽光。Framer Motion 页面切换营造仪式感。

02

问卦

输入尊姓大名、生辰八字，选择所问之事：前程、姻缘、财运、劫难。四角金线边框，黑金古风输入框，每一步都有交互反馈。

03

开卦

天机罗盘旋转动画 → 五秒惯性减速 → 指针定格 → 金色光晕脉冲 → 七言绝句批言逐字浮现 → 武侠风解卦展开。

玄学设定

姓名转 ASCII 码拼接生日数字，使用简单哈希算法计算，结果对 8 取模得到卦象索引。

同一姓名 + 生日永远得到同一个卦象，增加"天命不可违"的真实感。

技术亮点

模块 技术 亮点
罗盘组件 SVG + Framer Motion 外圈天干地支逆时针转、内圈八卦顺时针转，贝塞尔缓动 [0.17, 0.67, 0.12, 0.99] 模拟真实物理惯性
毛笔字效果 React 自定义 Hook 逐字淡入上浮动画，支持换行符，诗词 120ms/字、解卦 50ms/字，模拟毛笔书写节奏
音效系统 Web Audio API 锯齿波低频机械转动声、三音和弦定卦"叮"声、白噪声滤波毛笔摩擦声，纯合成零音频文件
八卦文本库 手写 32 组批言 8卦 × 4类 = 32组，每组七言绝句批语 + 100字武侠风解卦，模仿《风云》泥菩萨口吻
视觉体系 Tailwind CSS + SVG 黑金古风配色、SVG 噪点纸张纹理、金色渐变文字、四角金线边框、太极图装饰

作品定位

  • 品类：趣味互动体验 / 传统文化创意产品
  • 目标用户：喜欢古风文化、武侠情怀的年轻用户；朋友圈求运势的社交人群
  • 差异化：不是简单的运势测试，而是一个完整的"仪式感"体验——从视觉、音效到交互，全程营造江湖问卦的沉浸氛围

竞赛价值

  • 创意完整度高：从起卦算法到批言文本库，从罗盘动画到音效系统，形成完整的体验闭环
  • 技术实现精巧：纯前端实现，零依赖外部 API，SVG 罗盘 + Web Audio API 音效，展现扎实的前端功底
  • 文化价值：以现代 Web 技术重新演绎传统八卦文化，让年轻用户以趣味方式接触易经智慧
  • 可扩展性强：可接入 AI 大模型实现个性化批言生成，可增加更多卦象类别，可做成小程序/H5 独立产品
