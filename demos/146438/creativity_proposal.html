文玩鉴宝

普通人身边的文玩珠宝鉴别助手 · 知识百科 + 品相估价 + 假货案例库

项目概述

「文玩鉴宝」是一款面向文玩珠宝爱好者的纯工具型鉴别助手。以知识百科和假货案例库为核心资产，AI 辅助品相识别，帮助用户在购买前快速了解真假、品相与价值。

市场上没有任何平台提供「按品相拆分估价」和「市场假货案例图库」功能，这是两个明确的市场空白，也是本产品的核心切入点。

"最近市场上出了什么新假货？" —— 需要查询市场行情和最新假货套路，提升防范意识。

市场机会与差异化
行业三大结构性问题
  • 鉴定公信力缺失 — 微拍堂、闲鱼验货宝等平台的鉴定结果频繁被质疑，天天鉴宝已暴雷停运
  • 品相评估无标准 — 行业高度依赖个人经验，无标准化分级体系，同一件物品不同鉴定师价格差异巨大
  • 假货识别知识碎片化 — 知识散落在论坛帖子、短视频评论中，没有平台系统性整理
我们的核心差异化
  • 两个"全网首创"功能 — 按品相拆分估价 + 市场假货案例图库，构成不可替代的竞争壁垒
  • 纯工具型定位 — 不做交易，避开电商模式导致的资金链和公信力风险
  • 知识为主，AI为辅 — 知识百科和案例库是核心资产，AI 识别明确标注"仅供参考"
技术方案
技术栈
React 18 TypeScript Vite Tailwind CSS React Router Zustand lucide-react
核心算法
  • 品相加权评分算法 — 各维度等级 × 权重比例，计算加权总分（0-100），映射价格区间表
  • AI 识别模拟 — 前端模拟 2.5s 加载过程，返回概率化识别结果，随机抽取品类和品相等级
  • SVG 雷达图 — 可视化展示各维度品相评分，直观呈现多维度对比
产品设计亮点
  • 东方雅致美学 — 宣纸米白底、金箔点缀、青玉绿提色、衬线宋体标题，营造"老字号珠宝行"可信质感
  • 移动端优先 — 最大宽度 480px 居中展示，桌面端左右纹理渐变留白，模拟手机框效果
  • 严谨的免责声明 — AI 识别结果顶部固定黄色提示条，明确标注"仅供参考，不作为鉴定依据"
  • 学习路径引导 — "认识品类 → 看懂品相 → 识别假货 → 自信选购"四步引导，助力零基础入门
