// Core Concept

从"凭感觉"到"看数据"

每一个动作的细节，AI 帮你看得清清楚楚

📷

实时姿态识别

基于 MediaPipe Pose，通过手机摄像头实时捕捉滑板者的 17 个人体关键点，在画面上叠加骨骼连线，让你"看见"自己的动作

🤖

AI 姿势分析

大模型对比你的关键点数据与标准动作库，逐帧分析差异：重心位置、肩膀角度、翻板时机——精确到毫秒级

🎯

个性化改进建议

不只是告诉你"哪里不对"，还给出具体的改进方案："重心前移 5cm""翻板时机晚 0.2 秒""起跳前膝盖多弯曲 15 度"

// Pain Points

滑板手的困境

练了两个月 Ollie 还学不会？问题可能只是一个细节

🧰

看不出哪里不对

自己录了视频反复看，感觉每个动作都差不多，但就是做不标准。缺乏专业视角，不知道该关注哪些关键帧。

📸

教程没有个性化反馈

网上教程只展示"正确动作"，但每个人的身高、体重、滑板配置不同，同样的教程并不适合所有人。

👌

微小差异肉眼难辨

翻板时机差 0.2 秒、重心偏移 3cm——这些决定动作成败的微小差异，肉眼和普通视频根本分辨不出来。

// Features

核心功能

01

实时骨骼叠加

摄像头画面上实时绘制 17 个关键点和骨骼连线，让你在练习时就能"看见"自己的姿态是否正确

02

逐帧慢动作对比

你的动作与标准动作并排播放，逐帧对比。关键差异点自动高亮，不用再"肉眼找不同"

03

动作评分系统

综合重心控制、时机把握、身体协调、落地稳定四个维度，输出 0-100 分的动作评分和等级（S/A/B/C）

04

进步追踪

记录每次练习的动作评分，生成进步曲线。看到自己从 C 到 A 的提升过程，保持练习动力

05

Trick 难度分级

内置 50+ Trick 数据库，按难度从入门到专家分级推荐。告诉你"先学好 Ollie，再学 Kickflip"

06

装备推荐

根据你的身高、体重和动作风格，推荐适合的板型尺寸、轮子硬度、轴承类型——装备也影响动作表现

// Value

价值与意义

⚡ 效率提升：从"盲练"到"精准修正"

将学习新 Trick 的时间从数周缩短到数天。AI 精确到帧的姿势分析替代了"凭感觉"的盲练模式。每一次尝试都有数据反馈，让滑手明确知道该改哪里。进步可追踪、成就可量化，大幅提升练习动力和效率。

💰 商业价值：8000万滑手的市场

全球滑板参与者超 8000 万，中国市场快速增长。C 端：App 付费订阅（月费解锁高级分析）+ 训练计划定制。B 端：滑板俱乐部教练版（批量管理学生数据）。品牌合作：根据动作数据推荐装备，与滑板品牌联合营销。
