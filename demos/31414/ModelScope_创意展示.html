一、产品概述

产品定位：ModelScope 是一款面向 PyTorch 用户的模型结构可视化与理解工具。用户上传 Python 文件后，工具自动识别所有继承自 nn.Module 的模型类，解析层定义与调用顺序，生成可交互的网络拓扑图。

产品形态

🌐 Web 端工具

浏览器访问的独立网页版本，便于演示和分享

🔌 VS Code 插件

嵌入 IDE，实时解析代码并显示结构图谱

核心价值

  • 源码到结构图自动化：告别手动绘图，从 .py 文件直接得到模型结构图
  • 深度理解模型设计：悬浮查看每层的参数、输入输出形状
  • 交互式探索：点击节点跳转到对应代码，实现双向联动
  • 隐私友好：代码解析可在本地完成，无需上传服务器

二、目标用户

用户类型 核心痛点
深度学习初学者 难以将 forward 中的调用链映射为整体结构
论文复现研究者 手绘结构图耗时且易错，代码可能包含大量模块封装
算法工程师 缺少直观的模型架构文档，沟通成本高
高校教师/培训讲师 现有工具无法从代码直接生成可编辑的结构图

三、核心功能

📁 模型发现与解析

支持拖拽上传单个 .py 文件，自动扫描识别所有 nn.Module 子类，解析 __init__ 中的层定义和 forward 中的调用链

🕸️ 结构图生成

提取层类型、关键参数，建立节点间的有向边，处理分支逻辑（if/else、torch.cat、+ 等操作）

🎯 交互式看板

力导向/层次布局的节点-边图，支持缩放、平移、节点拖拽，点击节点显示属性面板

🔗 代码联动

点击图中节点滚动到对应代码行并高亮，代码中选中层名图中节点高亮闪烁，建立双向映射关系

📤 导出功能

导出为 PNG 图片，导出为 JSON 供其他工具使用

四、技术方案

技术栈

Vue 3 Vite Element Plus D3.js / AntV G6 FastAPI Python AST TypeScript VS Code API

解析流程

  1. 接收 Python 源代码
  2. 使用 AST 模块解析代码结构
  3. 识别 nn.Module 子类和层定义
  4. 构建调用链和依赖关系
  5. 生成结构图 JSON 返回前端
