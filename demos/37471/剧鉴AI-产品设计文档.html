二、产品定位

2.1 一句话描述

剧鉴 AI：输入您的 AI 漫剧/仿真人剧剧本，3 分钟内获得「剧本爆款潜力评分 + 改进建议 + 第一集成片 Demo」的一站式决策工具。

2.2 目标用户（按优先级排序）

用户画像核心诉求付费意愿
P0：短剧工作室 / MCN（3-20 人团队）降低选题风险，快速验证剧本可行性，减少"拍了才知道不爆"的损失⭐⭐⭐⭐⭐ 高
P1：个人创作者 / 网文作者转短剧不知道自己的剧本是否符合平台算法偏好，需要快速获得可视化 Demo 用于投稿⭐⭐⭐⭐ 中高
P2：平台内容采购编辑（抖音/快手/腾讯）海量投稿中快速筛选有潜力的剧本，提高审稿效率⭐⭐⭐ 企业付费
P3：小说IP方 / 版权方IP 漫剧化前快速评估改编可行性，生成 Demo 用于招商⭐⭐⭐ 项目制付费

2.3 核心价值主张

Before（无剧鉴 AI）
  • 凭经验判断剧本，爆款率 0.16%
  • 花 3-7 天 / 5000-20000 元制作第一集 Demo 投稿
  • 不知道平台喜好，反复修改剧本
  • 前三集/前十集节奏凭感觉
After（有剧鉴 AI）
  • 数据化打分，预估爆款概率，筛掉 70% 低质剧本
  • 3 分钟 / 10-50 元生成第一集 AI Demo
  • 针对抖音/快手/视频号三平台分别给出优化建议
  • 可视化冲突升级曲线，精确指出薄弱环节

3.2 模块一：剧本输入与结构化解析

功能目标：支持多种格式剧本输入，自动解析为标准化数据结构。

📝 纯文本粘贴

核心功能，用户最常用的输入方式

💡 创意短句扩展

📊 剧本结构化字段（由 LLM 自动提取）：

  • 总集数、单集预估时长
  • 每集的：场景描述、对白、动作、情绪标签、画面提示
  • 角色清单（姓名、身份标签、性格关键词）
  • 题材标签（男频/女频/悬疑/甜宠/玄幻等 20+ 细分类）
  • 关键节点：钩子、反转、爽点、悬念

3.3 模块二：剧本评估引擎（核心差异化）

功能目标：对剧本进行多维度打分，输出爆款潜力预估 + 具体改进建议。

3.3.1 评估维度体系（总计 100 分）

维度权重评估指标（由 AI 自动检测）示例低分问题
1. 开场钩子15%黄金 3 秒冲击性；10 秒内明确主角+反派+核心冲突；结尾悬念强度"前 15 秒均为背景铺垫，缺少冲突"
2. 节奏与反转密度15%每集情绪转折次数（目标≥6次/集）；冲突升级曲线是否持续向上"第 5-7 集冲突强度下降，出现'空集'"
3. 人物与动机12%主角动机是否具体可量化；反派压迫感；角色差异化程度"主角目标模糊——'追求幸福'太抽象"
4. 冲突强度与层次12%一级/二级/三级冲突的分层清晰度；情绪压力等级波动"连续 3 集压抑无释放，观众易流失"
5. 视觉化程度10%剧本可直接转化为画面的比例"台词中含大量'他心想…'，难以转化为镜头"
6. 对白质量10%无效台词占比（目标<10%）；单句长度；信息密度"第 2 集寒暄台词占比 25%，建议删除"
7. 题材差异化10%与同类题材作品的差异化程度；是否有独特"卖点钩子""又是'豪门弃妇+重生'，与当前 300+ 部作品同质化"
8. 平台适配性8%竖屏镜头设计；90 秒单集完整性；算法友好性"过多全景/宽幅横向动作，竖屏呈现效果差"
9. 合规性5%敏感内容检测；价值观导向；备案兼容性"含血腥/擦边内容，存在审核不通过风险"
10. 历史爆款匹配度3%与平台历史爆款在结构/节奏上的相似度— —

3.3.2 阶段性评估报告

系统自动生成 三份独立报告，用户可选择：

  1. 第一集评估报告（免费）：单集 10 维度打分 + 问题定位 + 优化建议
  2. 前三集评估报告：留客期节奏评估 + 信息铺陈密度分析 + 前三集钩子链检测
  3. 前十集评估报告：完整冲突升级曲线 + 情绪曲线可视化 + 中段钩子强度检测

📋 报告输出示例：

📊 剧本总评分：78/100 （行业均值 52 分）
🎯 预估爆款概率：12.3% （行业基线 0.16%，您的剧本优于 87% 已上线作品）

━━━━ 核心问题 ━━━━
🔴 严重问题（需立即修改）：
   · 第1集开场 0-15秒 为背景铺垫，缺少黄金3秒冲击画面
     → 建议：直接从"女主被当众扇耳光"开始，背景通过道具/对白暗示
   · 无效台词占比 23%（目标<10%）

🟡 中等问题（建议优化）：
   · 第3-5集 冲突强度曲线持平，未实现持续升级
   · 反派人设标签化严重，缺乏合理动机

🟢 亮点保留：
   · 第1集结尾"你到底是谁？"黑屏钩子 ✅ 优秀，可提升次集点击率 35%
   · 第7-10集 冲突层次清晰，情感+阴谋双线并行

━━━━ 平台适配建议 ━━━━
📱 抖音：建议强化"打脸/反转"元素，符合高情绪密度偏好  预计完播率 62%
🎬 快手：适合情感向推流，保留 CP 冲突线                预计完播率 58%
📺 视频号：适合家庭/社会议题，需调整价值观表述          预计完播率 48%

━━━━ 预估数据表现（基于历史同类剧本）━━━━
首集完播率：约 58-65%
次集留存率：约 42-48%
万播放收益：约 15-25 元（抖音中视频计划）
建议投入成本：≤ 3000 元/60集（含 AI 生成）
回本周期预估：约 5-8 万播放

3.3.3 数据模型与训练策略

  • 基础层：LLM（DeepSeek / Qwen / Claude）进行剧本结构解析与维度检测
  • 增强层：自研规则引擎（检测对白长度、场景数量、反转密度等可量化指标）
  • 差异化核心：爆款剧本特征库——持续采集已上线作品的播放数据与剧本文本，训练分类模型输出"历史爆款匹配度"
🏰 核心壁垒：随着用户量增长，剧本→数据的反馈闭环将持续强化评估模型的准确度。

3.4 模块三：第一集成片 Demo 生成引擎

功能目标：从剧本自动生成 90 秒竖屏成片 Demo，包含：分镜设计 → 角色定妆 → 视频生成 → 配音 → 字幕 → 成片拼接。

3.4.1 生成流程（全自动化，约 10-20 分钟）

剧本解析
   ↓
LLM 分镜拆解（将 90 秒剧本拆分为 8-12 个镜头，每个镜头 5-15 秒）
   ↓
角色定妆图生成（3-5 个核心角色，三视图+一致性保证）
   ↓
逐镜头视频生成（调用 Kling / Seedance / Wan API，支持多模型并行）
   ↓
配音生成（TTS，支持多音色，情绪匹配）
   ↓
BGM/音效自动匹配
   ↓
字幕自动生成（硬字幕，9:16 适配）
   ↓
镜头拼接 + 转场 → 输出 90 秒 MP4

3.4.2 关键技术参数

参数可选值推荐默认
视频风格仿真人 / 2D 动漫 / 3D 卡通 / 写实仿真人（最高分成系数）
视频模型Kling V3-Omni / Seedance 2.0 / 阿里 Wan 2.2 / 本地开源Kling（性价比最优）
分辨率720P / 1080P / 4K720P（Demo 用途，成本最优）
单镜头时长5秒 / 10秒5-10秒自动智能分配
配音音色男声/女声 × 青年/中年 × 情绪标签AI 自动匹配角色人设
运镜模式自动 / 快节奏 / 情感向自动（根据镜头情绪标签）

💡 注：成本包含视频生成、配音、BGM、字幕全链路。用户实际支付价格含服务毛利。

3.4.4 Demo 质量保障策略

  • 角色一致性：同一角色所有镜头使用相同 reference image + 固定随机种子
  • 多模型并行：同一镜头可在 2-3 个模型上同时生成，系统自动选择最优结果
  • 人工可选干预：高级版用户可在每一步暂停，手动调整分镜/角色形象后继续生成
  • 失败重试：镜头生成失败自动重试 2 次，仍失败则降级使用经济版模型

3.5 模块四：项目管理与工作台

  • 剧本版本管理：支持多版本对比，记录每次评估的分数变化
  • 生成历史：所有 Demo 生成记录可追溯、可重生成（修改参数后重新跑）
  • 团队协作：企业版支持多人协作、角色权限（管理员/编辑/审阅）
  • 数据看板：展示工作室的剧本评估分数分布、爆款率趋势、成本收益统计

3.6 模块五：剧本市场（增值功能，V1.5 上线）

  • 优质剧本可在平台内挂牌出售
  • 平台作为"数据背书"——标注该剧本的评估分数，提升交易可信度
  • 交易分成：平台抽成 5-10%

BGMSuno API + 版权音乐库自动情绪匹配
向量检索pgvector / Milvus存储剧本特征向量，支持"爆款相似度"检索
任务队列Redis + BullMQ视频生成任务异步排队，支持优先级调度
文件存储对象存储（OSS/MinIO）视频/图片文件存储，CDN 加速分发
视频编排FFmpeg + 自研拼接服务镜头拼接、音量平衡、字幕烧录

4.3 可扩展性设计

  • 多模型可插拔：视频生成层设计为抽象接口，后续可轻松接入新模型（如 Sora 3、国产新模型）
  • 本地化部署选项：企业版可私有化部署（适合对数据安全要求高的 MCN / 平台客户）
  • SaaS 多租户架构：从第一天起设计多租户隔离，支持团队/企业级客户
  • GPU 资源弹性伸缩：经济版使用本地 GPU 池，标准版/高级版调用云 API，按需扩展

4.4 技术挑战与应对策略

挑战严重度应对方案
视频生成 API 费用高⭐⭐⭐⭐①本地 Wan 模型作为经济版降低边际成本；②多模型智能路由选择最优性价比；③用户按档位付费覆盖成本
角色一致性难以保证⭐⭐⭐⭐①同一角色全镜头使用相同 reference image + 固定 seed；②Kling V3-Omni 原生 multi-shot 能力；③失败自动重试；④提供人工编辑入口

风险概率影响应对策略

十一、差异化策略总结

剧鉴 AI 的核心竞争壁垒，按建立顺序排列：

🏆 产品体验差异化 — MVP 阶段

市场上第一款同时提供"评估+Demo"的一站式工具，体验闭环。用户无需在多个平台间切换，降低决策效率提升 10 倍。

用户越多 → 评估样本越多 → 模型越准 → 吸引更多用户。这是巨头难以复制的优势，因为他们缺乏中立的跨平台数据积累。

🏅 品牌与信任 — 上线后 6-12 个月

当"剧鉴 AI 高分剧本"成为投稿成功的代名词，品牌护城河建立。创作者将主动寻求剧鉴 AI 认证，平台将参考剧鉴 AI 评分。

⚙️ 多模型编排能力 — v2.0 阶段

自研最优模型调度算法 + prompt 工程积累，降低生成成本。内部形成"模型市场"能力。

🌐 生态与网络效应 — v3.0 阶段

剧本市场 + 平台 API 合作，形成供给-需求双边网络。创作者在平台交易剧本，平台根据评估匹配买家。
