项目简介

ChatDM 是一款 FF14 智能辅助主持插件

通过监听聊天与掷骰，全自动主持海龟汤、终极密码等文字小游戏

同时接入 AI 引擎，提供角色闲聊、塔罗占卜等趣味互动，是店长开店营业、活跃气氛的得力助手

核心机制

  • 指令监听：默认监听 说话 (Say) 频道中的 \dm 开头的文本。
  • 掷骰监听：监听系统掷骰 /random 结果。
  • 结果播报：默认在 喊话 (Yell) 频道进行播报。
  • 零门槛参与：未安装插件的玩家也可以直接通过聊天框发送指令参与，只要场内有一名玩家开启了该插件即可。
  • 可见性说明：前缀使用 \dm 指令会作为正常的聊天文本发出，因此其他玩家也能在聊天频道中看到指令内容。/e \dm 会发送隐藏指令，仅自己可见。
  • 功能开关：在插件设置中可以按需开启或关闭各个独立游戏与工具模块。关闭后，将忽略对应的指令。

隐私与数据安全

  • 数据本地化：聊天记录仅保存至本地，用于填充 AI 上下文及生成画像。绝不会上传任何信息至外部服务器。
  • 玩家画像管理：画像数据同样仅存本地。需在设置中手动生成（每次限分析单日日志），生成后支持手动修改。
  • API 密钥：内置 DeepSeek Key 为作者提供，余额有限，随时可能失效。请勿滥用，建议在配置中替换为您自己的 Key。

下载与安装

下载地址

点击下载最新版插件 (latest.zip)

游戏内激活

  1. 启动游戏并打开 Dalamud 设置（聊天框输入 /xlsettings）。
  2. 进入 Experimental（实验性功能），将生成的 ChatDM.dll 所在的完整目录路径添加到 Dev Plugin Locations（开发插件位置）。
  3. 打开插件安装器（聊天框输入 /xlplugins）。
  4. 进入 Dev Tools > Installed Dev Plugins（开发工具 > 已安装的开发插件），启用 ChatDM。

插件配置面板 (/chatdm)

在游戏内聊天框输入 /chatdm 即可打开插件的配置界面。配置界面包含 基础配置 (Basic) 和 记忆管理 (Memory) 两个分页。

1. 基础配置 (Basic)

  • 功能开关：可以按需单独开启或关闭各个小游戏（SOUP, WHO等）和娱乐工具（CHAT, LUCKY等）。关闭后将不再响应对应的指令。
  • 基础设置：
    • 指令监听频道：设置插件监听指令的频道，默认 10=说话(Say), 11=呼喊(Yell), 56=默语(Echo)。
    • 结果播报频道：设置游戏结果和 AI 回复的发送频道，默认 11=呼喊(Yell), 10=说话(Say)。
    • 仅自己模式：开启后，全局指令及开启游戏的指令（如 \dm start）将只响应您自己发出的聊天，防止多人安装插件时重复触发。进行中的交互指令（如 \dm ask）不受影响。
  • 高级设置：
    • DeepSeek API Key：必须配置此项才能驱动所有带有 AI 标识的功能。
    • 系统提示词配置：支持自定义 AI 闲聊、妈咪bot、角色欢迎词等所有 AI 功能的系统提示词，以改变 AI 的回复风格。

2. 记忆管理 (Memory)

插件会自动记录聊天记录（仅在本地），通过 AI 分析可提取出其他玩家的画像，让 AI 在后续互动（如闲聊、测算CP）中更了解这些玩家的设定。

  • 日志分析区：列出所有本地的聊天日志文件。点击“AI 分析”按钮，插件会在后台调用 DeepSeek 分析该日志，自动提取并保存玩家画像。
  • 记忆编辑区：
    • 选择已提取的玩家，可手动修改其 别名（用逗号分隔，方便 AI 识别其不同称呼）。
    • 可自由编辑该玩家的 玩家画像 (Profile) 文本，或直接删除该玩家的记忆。

全局命令

在聊天框输入以下命令进行全局控制：

  • \dm help：列出所有内置命令与说明。
  • \dm list：列出所有内置游戏，包含游戏名称与对应的游戏代码。
  • \dm <游戏代码> help：查看指定游戏的帮助与指令。
  • \dm <游戏代码> start：开始指定代码的游戏（例如 \dm ROLL start）。
  • \dm current：输出当前正在进行的游戏说明与进度。
  • \dm kill：强制结束当前游戏。
  • /chatdm：打开插件设置面板（支持修改监听/播报频道与开启本地日志）。

独立命令

1. AI 闲聊 (CHAT)AI

  • 全局命令：\c [额外话题/指令]
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    • 输入 \c，AI 将化身为群聊的“吃瓜群众”或“气氛组”，根据最近的聊天记录生成一句简短的闲聊或锐评。
    • 可以附加话题进行引导，例如 \c 锐评一下刚才的发言，AI 会着重围绕该话题进行回应。
    • 特殊指令：玩家可以在普通说话前增加 \spec（或直接使用 \c \spec），代表这是最高优先级的临时人设或行为要求（如 \spec 扮演猫娘）。且越近发出的指令优先级越高。
///

2. 明日运势 (LUCKY)AI

  • 全局命令：\lucky
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    1. 输入 \lucky，艾欧泽亚占星术士将为发言人生成专属运势。
    2. 每人每日限生成一次
///

3. 妈咪bot (MOM)AI

  • 全局命令：\mom [额外话题]
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    • AI 化身为充满母性关怀的知心大姐姐，拥有心理学知识。语气温暖、不急不躁。
    • 主要回复触发指令的玩家，但也兼顾当前群聊氛围。
    • 生成1~3句温暖短句，可能附带可爱的小动作，自动在 表情动作 (Emote /em) 频道发送。
    • 本功能不支持 \spec 特殊指令注入，保持人设纯粹。
///

4. 角色欢迎词 (GREET)AI

  • 全局命令：\greet [目标]
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    • 优先解析命令后携带的文本参数，其次读取当前游戏内实际选中的目标。如果都没有获取到，则静默不进行任何处理。
    • AI 将化身“挂机闲聊店的店长”，根据发送者与目标对象（玩家、宠物、NPC 等）的信息，生成一段专属欢迎词并在 喊话 (Yell) 频道发送。
///

5. 表达爱意 (LOVE)AI

  • 全局命令：\love [目标]
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    • 优先解析命令后携带的文本参数，其次读取当前游戏内实际选中的目标。如果都没有获取到，则静默不进行任何处理。
    • 获取双方画像，AI 将结合角色设定与情感随机性，生成一段专属文案并在 喊话 (Yell) 频道热烈播报。
///

6. 道晚安 (NN)AI

  • 全局命令：\nn [目标]
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    • 目标获取逻辑与 `\love` 相同，支持文本参数与当前选中目标。
    • AI 化身为感性旅人，结合角色特征与画像，生成一段治愈或浪漫的晚安语并在 喊话 (Yell) 频道播报。
///

7. 羁绊测算 (CP)AI

  • 全局命令：\cp [玩家A] [玩家B] [玩家C]
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    • 支持测算最多 3 人的羁绊/CP关系。若不带参数，则测算自己与当前选中的目标。
    • 获取所有目标的画像（支持视野外记忆兜底），AI 生成带有“缘分指数”、“关系标签”的幽默测算结果，并在 喊话 (Yell) 频道播报。
///

8. 塔罗牌占卜 (TAROT)AI

  • 全局命令：\tarot [类型] [问题] [@目标]
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。
  • 功能说明：
    • 使用 22 张大阿卡纳牌。支持多种占卜模式：单牌运势 (\tarot)、Yes/No 问题解答 (\tarot ask [问题])、时间三牌阵 (\tarot time) 和 破局三牌阵 (\tarot solve [问题])。
    • 支持通过加上 @玩家名 为他人进行占卜。AI 会扮演 FFXIV 占星术士进行充满代入感的解读。
    • 抽牌及正逆位判定均在本地代码中随机生成，确保结果公正无重复。
///

9. 自动情感响应 (AUTOEMOTE)AI

  • 全局机制：支持被动触发与主动命令触发。
  • 全局命令：\re (用于主动触发)
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 并且在设置界面开启此功能（被动触发需要），同时提供你想要的回复系统提示词（System Prompt）。
  • 功能说明：
    • 被动自动响应：监听周围其他玩家对你使用的自定义情感动作或标准情感动作并自动回应。
    • 主动触发响应：发送 \re 主动回应最近 10 分钟内最近一次对你做出的情感动作（无视防刷屏与配置开关）。
    • 根据预设的系统提示词（如你的人设、性格）结合对话历史和对方的角色画像，AI 会以第一人称视角自动生成符合你设定的回应。

游戏规则与指令

1. 海龟汤 (SOUP)AI

  • 游戏代码：SOUP
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。本游戏免报名。
  • 游戏流程：
    1. 开始：使用 \dm SOUP start [rule=自定义规则/风格] 开始，AI 法官会自动生成汤面并播报。
    2. 提问与判定：玩家发送 \dm ask <问题> 向法官提问。法官回答是/不是等，并自动判定是否解开真相。
    3. 获取提示：玩家发送 \dm tip 向法官请求提示。
    4. 结束与结算：解开真相自动公布汤底。玩家也可发送 \dm giveup 直接放弃游戏并公布汤底。
///

2. 猜猜我是谁 (WHO)AI

  • 游戏代码：WHO
  • 前置配置：需要在插件设置中配置 DeepSeek API Key 才能使用。本游戏免报名。
  • 游戏流程：
    1. 开始：使用 \dm WHO start [提示词] 开始。不带参数默认限定在 FF14 世界观内。
    2. 提问与猜测：玩家发送 \dm ask <问题或猜测> 提问或直接抢答。AI 酌情回答是/否/不一定等，若猜中则自动公布答案并结束游戏。
    3. 获取提示：玩家发送 \dm tip 请求提示。
    4. 放弃游戏：玩家发送 \dm giveup 放弃游戏，公布答案并结束。
///

3. 点数比拼 (ROLL)

  • 游戏代码：ROLL
  • 游戏流程：
    1. 开始：检测到命令 \dm ROLL start 后，开始一轮游戏。
    2. 掷点：参与的玩家输入 /random。
    3. 收集：插件自动获取所有发送玩家的名称与随机数值。
    4. 结束：检测到命令 \dm end 后，输出最高分与最低分的玩家，该轮结束。平局将自动随机选择。
///

5. 终极密码 (BOMB)

  • 游戏代码：BOMB
  • 游戏流程：
    1. 报名：使用 \dm BOMB start [最大值] 开始报名（默认范围 1~100，最高可设置上限为 1000）。
    2. 掷点排号：参与玩家发送 /random 报名，点数决定猜测顺序。
    3. 开始游戏：使用 \dm play 结束报名并开始游戏。
    4. 轮流竞猜：轮到的玩家发送 \dm guess <数字> 竞猜密码，系统自动缩小范围。可使用 \dm skip 跳过当前玩家。
    5. 结束：猜中炸弹数字的玩家将触发“BOOM”播报，游戏自动结束。
///

6. 俄罗斯轮盘 (GUN)

  • 游戏代码：GUN
  • 游戏流程：
    1. 装弹：使用 \dm GUN start [弹容量] [实弹数量] 开始游戏（默认 6 容量 1 实弹）。
    2. 开枪：玩家随时发送 \dm shoot 扣动扳机。
    3. 结束：如果击发实弹将触发中枪播报。仅有 1 发实弹时，中枪后自动结束；多发实弹时，需全部实弹击发完毕才自动结束。
///
