> 版本：v2.0 | 日期：2026-06-09 | 状态：设计中

---

## 1. 产品定位

### 1.1 一句话描述

一款极简的消耗品管理工具，帮助用户记录购买价格和使用周期，作为个人消费的参考数据库。

### 1.2 产品理念

> **不制造消费焦虑，而是帮助用户心里有数。**

用户从"大促囤货、过度消费"转向"极简生活、按需购买"。这个 App 不是省钱利器，而是断舍离的伙伴——知道自己有什么，不再乱买。

### 1.3 目标用户

| 维度 | 描述 |
|------|------|
| 用户画像 | 一线城市独居青年，25-35岁，注重生活品质 |
| 消费理念 | 极简生活，只买需要的，不过量囤积 |
| 使用场景 | 大促期间辅助决策、日常记录购买和使用 |
| 核心痛点 | 囤了用不完、比价花太多时间、不知道历史买过多少钱 |

### 1.4 App 定位

**个人消耗品价格参考数据库**

- 不是实时比价工具（不抓取电商价格）
- 不是记账工具（不记录所有支出）
- 是一个"我的消耗品价格手册"，有需求时才打开

## 2. 市场分析

### 2.1 现有竞品

| 类型 | 代表应用 | 核心功能 | 局限 |
|------|---------|---------|------|
| 单位价格计算器 | Unit Price Calculator | 一次性比价 | 不保存历史 |
| 价格记录本 | Price Book, ITAGP | 价格追踪、云同步 | 无使用周期追踪 |
| 资产记账 | 记价本 | 拍照记账、资产统计 | 更偏资产管理 |

### 2.2 差异化

| 维度 | 现有应用 | 有数 |
|------|---------|------|
| 定位 | 价格记录/比价 | **消耗品参考数据库** |
| 使用追踪 | ❌ 无 | ✅ 记录使用周期 |
| 价格对比 | 实时抓取电商 | **用户自己的历史价格** |
| 用户引导 | 刺激消费（"历史低价！快买"） | **克制呈现（平静地展示数据）** |
| 理念 | 帮你省钱 | **帮你心里有数** |

## 3. 核心用户旅程

### 3.1 大促期间：辅助决策

```
大促来了（618/双11）
    ↓
打开 App
    ↓
首页按"剩余天数"查看消耗品列表
    ↓
点击某个商品进入详情
    ↓
查看历史购买价格（我的价格手册）
    ↓
去电商平台看当前价格，与历史对比
    ↓
决策：买 or 不买
    ↓
回到 App 记录本次购买
```

### 3.2 日常：记录购买

```
买了新的消耗品
    ↓
打开 App → 点击添加
    ↓
输入商品名称（或选择历史商品）
    ↓
输入价格、容量、购买日期
    ↓
系统自动计算单价
    ↓
保存
```

### 3.3 用完：标记用完

```
某个消耗品用完了
    ↓
打开 App → 进入商品详情
    ↓
标记用完 → 选择用完日期
    ↓
系统计算本次使用周期
    ↓
更新首页剩余天数
```

## 5. 数据模型

### 5.1 实体关系

```
Consumable (消耗品)
├── id: UUID
├── name: String              // 品名
├── category: String          // 品类（洗护/护肤/清洁/个护）
├── createdAt: Date
└── updatedAt: Date

Purchase (购买记录)
├── id: UUID
├── consumableId: UUID (FK)    // 关联消耗品
├── price: Decimal             // 价格
├── quantity: Decimal           // 容量（纯数字）
├── date: Date                 // 购买日期
├── unitPrice: Decimal         // 单价（自动计算）
├── createdAt: Date
└── usages: [Usage]            // 关联使用记录

Usage (使用记录)
├── id: UUID
├── purchaseId: UUID (FK)       // 关联购买记录
├── openDate: Date             // 开封日期
├── usageFrequency: String     // 使用频率
├── finishDate: Date?          // 用完日期（可后续补充）
├── actualDuration: Int?        // 实际使用天数（自动计算）
├── createdAt: Date
└── updatedAt: Date
```

### 5.2 核心计算逻辑

| 计算 | 公式 |
|------|------|
| 单价 | price ÷ quantity |
| 剩余天数 | 预测用完日期 - 今天（基于使用频率推算） |
| 实际使用周期 | finishDate - openDate |
| 平均单价 | 所有购买记录的 unitPrice 平均值 |
| 平均使用周期 | 所有已完成 Usage 的 actualDuration 平均值 |

## 7. 设计规范

### 7.1 配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 强调色 | #2D9B8E | 青绿色，唯一强调色 |
| 背景 | #FAFAFA | 淡灰白 |
| 卡片 | #FFFFFF | 纯白 |
| 主文字 | #1A1A1A | 近黑 |
| 副文字 | #6B6B6B | 中灰 |
| 辅助文字 | #C5C5C5 | 浅灰 |
| 边框 | #EEEEEE | 极浅灰 |

### 7.2 设计原则

- **一种强调色**：所有强调只用青绿色
- **不制造焦虑**：无颜色分级（无红/黄/绿），无紧迫感暗示
- **克制呈现**：大量留白，信息密度适中
- **极简交互**：一步完成操作，不跳转不必要的页面
