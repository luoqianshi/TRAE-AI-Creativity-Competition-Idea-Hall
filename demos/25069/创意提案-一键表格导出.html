💡 想解决什么问题

在日常工作和学习中，我们经常在网页上遇到需要整理的数据表格——财务报表、统计数据、课程表、商品清单等。当前用户只能手动复制粘贴到 Excel，遇到合并单元格、大量数据时效率极低且容易出错。

🎯 产品一句话

一款浏览器插件，点击图标即可自动检测当前网页中的所有表格，一键导出为格式规范的 Excel 文件，支持批量导出、表格定位、合并单元格还原等功能。

💭 灵感来源

作为经常需要整理网页数据的职场人和学生，我深刻体会到手动复制表格的痛苦：格式错乱、合并单元格丢失、数据量大了根本处理不过来。于是想到：能不能让浏览器自动帮我完成这个重复劳动？用 TRAE AI 辅助开发，从想法到可用插件仅用了很短时间。

2目标用户与痛点

👥 核心用户群体

  • 职场办公人员：需要定期从各类系统后台、报表网站导出数据做分析
  • 数据分析从业者：经常从网页抓取表格数据进行清洗和可视化
  • 学生与研究人员：需要整理学术论文、实验数据、课程信息中的表格
  • 电商运营：需要整理竞品数据、商品列表、销售报表

📍 使用场景

  • 打开某个包含数据表格的网页，点击插件图标
  • 查看检测到的表格列表，预览内容确认是否为目标表格
  • 点击「导出 Excel」保存单个表格，或「导出全部」批量保存
  • 遇到多个相似表格时，使用「定位」功能在页面中高亮对应表格

😫 当前痛点

  • 手动复制粘贴：网页表格复制到 Excel 后格式全乱，需要大量手动调整
  • 合并单元格丢失：原网页的 colspan/rowspan 结构无法保留
  • 逐个处理效率低：一个页面有多个表格时需要重复操作多次
  • iframe 内表格难处理：嵌套页面中的表格普通方法无法获取
  • 数据安全隐患：部分在线转换工具需要上传数据到第三方服务器

3核心功能

🔍

自动检测

一键扫描当前页面所有表格，包括 iframe 内嵌表格，自动过滤无意义布局表格

👁️

预览 + 定位

显示表格行列数与内容预览；点击定位可在页面中高亮并滚动到对应表格

📄

单个导出

每个表格可单独导出为 .xlsx 文件，文件名自动带上时间戳

📦

批量导出

一键将页面上所有表格导出到同一个 Excel 工作簿，每个表格一个工作表

🔗

合并单元格

正确处理 colspan/rowspan，还原合并单元格结构，数据不重复不丢失

🔒

纯本地处理

所有数据在浏览器本地生成，不上传任何服务器，保护数据隐私安全

4价值与意义

⚡ 效率提升

将原本需要数分钟的手动复制粘贴工作缩短到几秒钟。批量导出功能让多表格页面一键搞定，大幅提升数据整理效率。合并单元格的正确处理避免了导出后反复调整的麻烦。

5技术实现

🛠️ 技术栈

Manifest V3 Chrome Extension API SheetJS (xlsx) JavaScript HTML/CSS Blob 下载

⚙️ 核心算法

表格解析采用占位矩阵算法处理 colspan/rowspan：遍历每个单元格时，根据跨行跨列属性在二维矩阵中标记占用位置，确保合并单元格结构完整还原到 Excel 中。
