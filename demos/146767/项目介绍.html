CORE LOOP · 核心闭环

把“会做题”变成看得见的前进

当玩家遇到难以跨越的机关，可以直接发起“答题跳关”。答案正确后，系统按正常通关流程结算：进入下一关、记录完成度、解锁新内容，并获得对应的首通成长奖励。

知识不是附加功能在《学霸闯关记》中，答题是一条与操作闯关并行的通关路径。玩家不只是在“完成练习”，而是在用知识解决眼前的游戏挑战。
01进入挑战面对平台、陷阱、假门与其他机关。
02开启答题随机抽取题目，尽量避免本关重复出现。
03判断答案支持答案格式归一化和多种可接受表达。
04通关成长答对后正常结算关卡、进度与首通奖励。

LEARNING VALUE · 学习价值

从“要我学”到“我要闯”

游戏并不替代系统学习，而是用轻量的关卡目标、积极的即时反馈与可重复挑战的过程，帮助玩家在娱乐中巩固已有知识、建立解决问题的信心。

知识巩固把计算、词汇、诗词和常识放进具体情境，让回忆与应用同时发生。
问题解决在操作挑战与知识作答之间作出选择，培养观察、判断和策略意识。
学习自信每次正确回答都会转化为进度和奖励，持续积累“我能做到”的体验。

GET STARTED · 开始体验

打开浏览器，即刻出发

项目采用单文件 HTML 实现。无需安装依赖，无需配置环境，直接运行即可体验答题与闯关融合的学习冒险。

  1. 在项目目录中打开 index.html。
  2. 注册本地账号保存进度，或使用游客模式快速体验。
  3. 用方向键或 A/D 移动、W/空格跳跃；遇到难关时，使用“答题跳关”。
