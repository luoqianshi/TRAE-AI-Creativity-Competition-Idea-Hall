# 《心事画廊》H5 可交互原型

## 说明

这是《心事画廊》的可交互 H5 原型，用于验证视觉设计与核心交互流程。

## 如何运行

直接用浏览器打开 `index.html` 即可，无需任何构建或服务器。

推荐使用手机浏览器或桌面浏览器的移动端调试模式查看。

## 包含页面

- **欢迎页**：品牌介绍、示例画作轮播、进入应用
- **日记输入页**：文本输入、实时背景渐变、情绪识别
- **生成中页**：水墨晕染加载动画
- **结果展示页**：情绪画展示、诗句、原文折叠
- **情绪画廊页**：月度色环、日历网格、月份切换
- **画作详情页**：全屏画作、原文、删除/对比/分享
- **双画对比页**：并排展示两幅画
- **我的页**：统计、主题切换、字体切换、API KEY 配置、清空数据

## 配置项

### 主题切换

在"我的 → 主题"中可切换三种主题：

- **奶油水彩风**：温暖柔和的奶油色调
- **胶片日记风**（默认）：文艺怀旧的胶片灰色调
- **极简留白风**：干净克制的黑白灰色调

### API KEY 配置

在"我的 → AI 画作生成设置"中可配置画作生成服务的 API KEY：

- 输入框为密码类型，保护密钥安全
- 点击右侧问号图标显示配置说明
- API KEY 仅保存在浏览器本地（localStorage），不会上传服务器

## 技术栈

- 原生 HTML5 / CSS3 / JavaScript
- 无外部依赖
- 数据保存在 localStorage
