问题与痛点

为什么需要这个工具？

制作 HOI4 历史题材 MOD 时，事件图片的制作流程繁琐、重复、容易出错。 每张图片都要经历裁切、套版、格式转换、注册等多个步骤。

🖼

照片尺寸不统一

历史照片分辨率和宽高比不统一，手动裁切容易变形或漏出底图，反复调整浪费时间。

📂

PSD 图层容易破坏

模板里的遮罩、投影、外发光、污渍和纸张质感很容易被错误覆盖，返工成本高。

📦

DDS 格式要求严格

HOI4 要求 B8G8R8A8_UNORM DDS，错误压缩格式或缺失 Alpha 会导致游戏内显示异常。

📝

GFX 注册易出错

事件图片生成后还要手动写 spriteType 注册，容易出现命名冲突或路径错误。

🔄

批量制作重复劳动

一张图就要重复多次裁切-套版-导出-注册流程，批量制作时人工检查成本很高。

工作流程

从照片到游戏内事件图

一条完整的自动化管线：输入历史照片，输出 HOI4 可用的 DDS 事件图片并注册 GFX。

1
render_country_event_picture

输入历史照片

用户指定源图片路径、sprite 名称和输出文件名。支持 PNG、JPG 等常见格式。

2
OpenAI Vision / 居中 cover

AI 智能识别与裁切

调用 OpenAI Vision 分析照片内容，识别主体位置和最佳裁切区域；未配置 API 时自动退回居中 cover 裁切。等比缩放，不拉伸不变形。

3
Photoshop COM / Pillow

PSD 模板套版渲染

照片放入 PSD 模板的 your pics here 图层位置。Photoshop 后端保留投影、外发光、调整层和纸张纹理；无 Photoshop 时降级为 Pillow 近似渲染。

4
save_b8g8r8a8_dds

DDS 导出与校验

导出 B8G8R8A8_UNORM / 8.8.8.8 BGRA / 32 bpp unsigned DDS 文件，保留完整 Alpha 通道。写入后自动读取头信息自检。

5
register_event_sprite

GFX 自动注册

自动在 .gfx 文件中写入 spriteType 注册代码。同名 GFX 已存在时返回冲突并跳过，避免覆盖。

工具集

5 个 MCP 工具

每个工具负责管线中的一个独立环节，可单独使用，也可组合成完整流程。

🔍

inspect_event_template

检查 PSD 模板结构：图层树、照片槽位、遮罩层、调整层、Photoshop 后端可用性和 DDS 输出格式。

🖼

render_country_event_picture

核心工具。输入源图片，完成 AI 裁切、PSD 套版、DDS 导出、GFX 注册，返回完整结果和警告信息。

📦

batch_render_country_event_pictures

批量生成。接受图片列表，逐个处理。单项失败不会中断其他条目，最后汇总成功、失败和需要人工复核的条目。

📝

register_event_sprite

单独写入 .gfx 注册代码。自动检测同名 sprite 冲突并跳过，保护已有注册不被覆盖。

✅

validate_dds

校验 DDS 文件是否为 HOI4 要求的 B8G8R8A8_UNORM 格式，检查位深、通道掩码和 Alpha 完整性。

使用示例

一次调用，全部完成

通过 MCP 协议调用，AI Agent 直接执行完整流程，无需手动切换工具。

render_country_event_picture 调用示例 
// MCP 工具调用参数
{
  "source_image": "D:\\photos\\stalingrad_1942.png",
  "sprite_name": "report_event_stalingrad",
  "output_name": "report_event_stalingrad",
  "register_gfx": true,
  "keep_preview_png": false,
  "render_backend": "auto"

  "gfx_registration": { "status": "written" },
  "needs_manual_review": false,
  "warnings": []
}

质量保障

人工复核规则

以下情况会自动标记 needs_manual_review=true，提醒 Modder 人工检查。

裁切保留面积 < 60%

原图内容在裁切后丢失过多，可能丢失重要画面元素。

放大倍率 > 2.0

源图片分辨率过低，放大后可能出现明显模糊或锯齿。

宽高比极端

原图宽高比与目标区域差异过大，画面内容变形风险高。
