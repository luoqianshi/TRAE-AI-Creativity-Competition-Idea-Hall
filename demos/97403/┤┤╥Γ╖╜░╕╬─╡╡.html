1. 创意名称 + 创意介绍
创意名称：友旅AA账
想解决什么问题

旅游时账单复杂难理清——有时全部人一起花钱，有时只有部分人参与；出国游更是麻烦，现金、支付宝、VISA混用，汇率实时波动，到最后根本算不清每个人该出多少钱。

为什么会想到做这个

每次和朋友旅行，记账都是最大的痛点。有人用Excel记，有人用备忘录记，结算时总要反复核对，还经常因为汇率换算出错。希望能有一款专门为旅行设计的记账工具，让旅途只留下美好回忆。

大概是什么产品

旅行场景专属的多人记账小程序

2. 目标用户及痛点
面向哪些用户

热爱结伴旅行的年轻团体，尤其是经常进行跨国旅行的学生和职场新人。

在什么场景下使用

多人共同出游时，无论是国内短途还是国外长途，需要记录各类消费并最终AA结算。

当前痛点

手动记录多笔外币消费并换算汇率极其繁琐，且容易因汇率波动或记错金额导致账目不平；混合支付场景下，难以清晰区分个人垫付与公共支出，结算时往往需要反复核对聊天记录和账单，耗时耗力且易引发朋友间的尴尬与误会。

3. 价值与意义

效率提升

将原本需要数小时的对账结算工作缩短到几秒钟，自动处理多币种汇率换算、部分参与人费用分摊、备用金抵扣等复杂场景，让旅行记账变得轻松简单。

社会价值

减少朋友间因金钱结算产生的矛盾与尴尬，让旅行回归纯粹的快乐，让友谊不因琐碎的算账而受到影响。

4. 产品核心功能
P0必须实现
旅行管理
  • 创建旅行（设置名称、出发日期、目的地）
  • 添加/删除成员（管理员权限）
  • 切换国内/国外模式
账单记录
  • 输入金额、币种（支持多种外币）
  • 选择付款人、参与人（支持部分人参与）
  • 选择支付方式（微信、支付宝、信用卡、现金、备用金）
  • 输入备注（可选）
  • 记录后自动生效，无需确认
账单审核
  • 普通成员发起修改/删除申请
  • 创建人审核通过/拒绝
  • 审核通知机制：打开小程序时自动弹窗提示、待审核列表、微信消息推送（需用户授权）
备用金管理
  • 共用池模式，按需充值
  • 记录每个人的充值金额
  • 付款时显示"备用金池"作为付款人
  • 余额实时显示
多币种结算
  • 汇率API可用时：按消费日汇率自动换算成人民币
  • 汇率API不可用时：按原始币种分开显示结算金额
  • 手动简化债权债务（用户手动选择抵消）
P1后续优化
汇率API对接
  • 对接免费汇率API（如Fixer.io）
  • 支持实时汇率查询
账单分享与同步
  • 通过微信转发实现多人协作
  • 账单版本号机制，避免数据冲突
管理员权限设置
  • 指定多个管理员
  • 权限分级管理
5. 权限模型
角色 权限
创建人 所有权限 + 审核修改/删除申请
管理员 创建账单、修改/删除账单（无需审核）、添加/删除成员、管理备用金
普通成员 创建账单（无需审核）、查看账单、发起修改/删除申请（需创建人审核）
6. 技术方案
数据存储

微信小程序云开发

  • 云数据库：存储旅行、账单、成员、备用金等数据
  • 云函数：处理汇率换算、结算计算、审核通知等逻辑
汇率API
  • 免费API：Fixer.io（支持170+币种）
  • 备用方案：手动输入汇率
结算算法
  1. 按币种分类所有账单
  2. 计算每个人的收支（收入为正，支出为负）
  3. 生成债权债务关系（A欠B多少，B欠C多少）
  4. 用户手动简化债务

8. 创意亮点总结
  1. 无需确认的轻松记账：记录后自动生效，避免繁琐流程，保持朋友间的信任与默契
  2. 多币种灵活结算：支持国内/国外模式切换，汇率API自动换算，API不可用时按币种分开显示
  3. 备用金池管理：共用池模式，按需充值，付款时自动扣除，简化集体消费场景
  4. 部分参与人支持：灵活选择付款人和参与人，支持"只有部分人参与"的复杂场景
  5. 创建人审核机制：普通成员修改/删除需审核，确保数据准确性的同时保持操作灵活性
