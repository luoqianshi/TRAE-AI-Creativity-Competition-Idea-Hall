Engineering

清晰到能当教材的代码结构

每一行代码都在告诉你：AI应用应该如何工程化

localmind/
├── cmd/main.go              // 入口：解析参数，启动服务
├── internal/
│ ├── config/                // 配置管理（Viper热加载）
│ ├── core/                  // 核心引擎：对话、记忆、知识库、工具
│ ├── model/                 // LLM抽象：Ollama/OpenAI/DeepSeek统一接口
│ ├── store/                 // 数据层：SQLite + 向量存储
│ ├── tool/                  // 内置工具：计算器、时间、搜索
│ └── api/                  // HTTP接口：SSE流式对话、文件上传
├── web/                       // 内嵌前端：纯HTML/JS，无需构建
├── config.yaml             // 用户配置：模型、API Key、参数
└── README.md              // 面向小白的完整教程
