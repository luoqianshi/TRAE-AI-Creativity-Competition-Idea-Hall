用经济激励替代平台验证，用 AI 匹配打破信息垄断

把交易的决定权还给买卖双方 · 信息归信息，交易归交易

1

创意介绍

想解决什么问题：房产交易、顺风车出行、个人特殊需求等场景中，信息被平台垄断把控，平台靠信息不对称获取高额利润甚至扭曲交易本身。买卖双方无法直接建立沟通，被迫接受平台的高额抽佣和规则约束。

为什么会想到做这个：房产交易平台靠信息垄断收2.7%佣金，出行平台靠派单权抽走25-30%，本质都是把"信息撮合"和"交易控制"绑在一起。个人特殊需求（找修钟表的人、拼单海运、遛狗搭子）更是连信息发布渠道都没有，只能发朋友圈然后被信息流淹没。信息应该自由流动，交易应该回归双方自主决定。

大概是什么产品：微信小程序。一个个人CTC（Consumer-to-Consumer）信息交换平台，主打真实供给发布和真实需求发布，AI设计信息传递规则，最大可能性为双方建立沟通渠道，平台不参与交易。

25-30%

出行平台抽佣比例。司机端到手少，乘客端支付多，中间差额全被平台以"派单权"名义拿走。

个人特殊需求者

0

没有信息发布和交换的渠道。想找修老钟表的人、拼单海运、同小区遛狗搭子——只能发朋友圈，几分钟就被淹没。

核心痛点总结：所有这些场景的本质问题只有一个——信息不对称被平台武器化。平台不是信息的生产者，却是信息的守门人。买卖双方既是信息的来源，又是信息的消费者，却被平台从中截断。

3

核心机制：经济激励即验证

不验证，只激励——用经济博弈替代平台审核

传统去中介化平台的死穴：要保证信息真实就必须做验证，做了验证就变成了"平台"，而平台正是要打掉的对象。情报站的解法是让市场自己筛选质量——发布者付费证明信息真实诉求，解锁者付费证明需求真实意图，虚假信息无人解锁自然亏损淘汰。

核心经济规则

发布信息 ¥1/天（发布者支付） → 解锁联系 ¥10/次（需求者支付） → ¥8 归发布者 + ¥2 归平台

自净化机制：

虚假/无价值信息 → 无人支付¥10解锁 → 发布者持续亏损¥1/天 → 自然淘汰

真实/有价值信息 → 多人支付¥10解锁 → 发布者净赚 ¥8n - ¥1/天 → 正向激励

对比维度 传统平台 情报站
信息真实性保障 平台审核认证 发布者付费 = skin in the game
需求真实性保障 平台身份验证 解锁者付费 = 真实意图证明
质量过滤 平台规则 + 人工审核 经济博弈自然淘汰
交易控制权 平台撮合 + 抽佣 双方直接沟通，平台不介入
信息获取成本 免费但信息被控制 ¥1/天发布，信息自由流动
4

AI 引擎设计：四层能力

AI 嵌入信息流转的每个环节，不做"认证"做"信号"——展示信用等级但不阻止交易，决策权在用户手里。

L1 结构化层

需求结构化引擎

用户口语化描述，AI 自动提取实体、状态、意图、约束，生成结构化情报标签和匹配参数。

输入："家里闲置某品牌婴儿车，8成新，同小区可自取"
输出：[母婴] [闲置] [同城自取] [8成新] → 匹配范围3km
L2 语义匹配层

意图对齐 + 模糊匹配

不是关键词匹配，是意图理解。识别供需两端的语义等价性，做双向匹配推送。

"处理掉闲置婴儿车" ↔ "新生宝宝需要婴儿车"
→ AI 识别为同一组供需，匹配度 92%
L3 信用评估层

多维度信用信号

信息一致性检测 + 账号行为画像 + 被解锁率 + 评价记录 + 异常标记，自动计算A/B/C/D信用等级。

信号是参考不是门槛——平台告诉你可信度，
但不阻止你交易。决策权在用户手里。
L4 信息路由层

动态推送策略

根据供需密度、地理范围、时效性动态决定推送策略。规则透明可解释，不做黑箱排序和竞价排名。

供需密度低 → 扩大地理范围
时效性强 → 优先推送，缩短生命周期

价值与意义

商业价值

打破信息垄断带来的超额利润。信息层免费+AI增值服务收费+代理服务市场化抽佣，薄利多匹配。每次匹配平台仅净赚¥1.4，但飞轮效应显著。

效率提升

AI 语义匹配让"处理掉闲置婴儿车"和"新生宝宝需要婴儿车"这样意图相同但表述不同的供需直接对接。传统平台按品类分类完全做不到。

社会价值

让信息回归自由流动，让交易回归双方自主决定。个人特殊需求第一次有了专门的发布和交换渠道。经济激励机制让真实信息自然涌现，无需平台权威背书。
