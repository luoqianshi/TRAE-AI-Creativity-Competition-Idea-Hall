开场 你好，我是今天的面试官。看到你简历上写了熟悉分布式系统，那我们先聊聊：请介绍一下你对分布式锁的理解，以及你在项目中是如何使用的？
🧑‍💻
分布式锁主要用于在分布式系统中保证同一时刻只有一个客户端能访问共享资源。我在项目中用的是 Redis 实现的，用 SETNX 命令加锁，然后设置过期时间防止死锁。
👨‍💼
⚡ 实时追问 你提到用 SETNX 加锁并设置过期时间，那如果加锁和设置过期时间不是原子操作，会出现什么问题？你是怎么解决的？
🧑‍💻
嗯...如果 SETNX 成功但还没设置过期时间服务就挂了，那这个锁就永远不会释放，导致死锁。解决方法是可以用 SET 命令的 NX 和 EX 参数组合，保证原子性。
👨‍💼
⚡ 深度追问 回答正确。那再深入一下：如果锁的过期时间到了，但持有锁的线程还没执行完业务逻辑，这时候另一个线程拿到了锁，两个线程同时操作会有什么风险？Redisson 是怎么解决这个问题的？

分布式锁用 Redis SETNX，设置过期时间防死锁。加锁和设置过期要原子操作，用 SET NX EX。
✅ 参考答案（RAG检索）
