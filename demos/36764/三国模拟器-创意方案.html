创意简介

CONCEPT OVERVIEW

《三国演义》是中国最广为人知的经典名著之一，然而千百年来，读者只能旁观这段历史——无法干预，无法参与。

《三国模拟器》以《三国演义》为世界背景，玩家扮演角色置身其中，通过自然语言与由 LLM 扮演的 NPC 真实对话。NPC 借助 Function Call 机制实时反馈——好感度、势力关系、剧情节点等数值随对话动态变化，玩家的每个抉择都可能改变历史走向，走出心目中的最好结局。

这不是预设选项的分支叙事，而是真正由 AI 驱动的活的三国世界。

核心机制

CORE MECHANICS

🧠

LLM 驱动的 NPC

曹操、诸葛亮、关羽……每位角色由 LLM 扮演，拥有独立的性格、立场与记忆。对话不依赖预设脚本，真实响应玩家的每一句话。

⚙️

Function Call 反馈

NPC 通过 Function Call 工具改变游戏数值——好感度升降、势力关系转变、关键事件触发。每次对话都在悄悄重塑世界。

🔀

玩家主导的结局

没有唯一剧本。玩家在关键剧情节点的选择将影响事件走向，赤壁之战的结果、三国的归属——都可能因你而改变。

目标用户与痛点

TARGET USERS & PAIN POINTS

策略游戏门槛过高

《三国志》等游戏偏重数值策略，叙事沉浸感弱，大量用户被拒于门外。

名著只能被动阅读

小说、影视无法互动，"如果我在场会怎么做"的想象永远无法实现。

NPC 对话死板

现有互动游戏依赖预设选项，缺乏真实感，无法自然地与角色沟通。

缺乏真实影响力

玩家的选择往往只是表面分支，无法真正感受到"我改变了什么"。


核心用户群：三国 / 历史文化爱好者、互动小说与文字游戏玩家，以及对 AI 对话交互感兴趣的 18–35 岁年轻用户。

使用场景：碎片化休闲时间，脑中浮现"如果我在赤壁现场会怎么做"的冲动时。

价值与意义

VALUE & SIGNIFICANCE

📈 商业价值

本 demo 验证了"LLM 驱动叙事互动"作为新娱乐形态的可行性。以《三国演义》公版 IP 为起点，后续可延伸为内容创作平台，形成 UGC 生态——创作者发布剧本、玩家付费体验，撬动经典 IP 二次创作市场。

🏛️ 社会价值

以游戏化方式重新演绎《三国演义》，让年轻一代在沉浸式互动体验中自然接触传统文化经典，用 AI 技术降低名著的接触门槛，让经典活起来。
