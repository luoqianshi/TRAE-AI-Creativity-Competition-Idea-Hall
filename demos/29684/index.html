模型原理

宏观经济方程组

本模型基于凯恩斯主义宏观经济学的 IS-LM-AD-AS 框架，结合中国实际经济数据进行参数校准。核心方程组如下：

消费函数：C = C₀ + c(Y - T)
投资函数：I = I₀ - dr + εG
税收函数：T = T₀ + tY + AI_tax
总需求：AD = C + I + G + (X - M)
均衡产出：Y = AD = AS

AI 税传导机制

AI 税作为新型数字资源税，其经济传导机制分为三个阶段：

阶段 时间范围 主要影响 GDP 冲击系数
短期 1 年内 企业成本上升，投资下降 -0.30% / 每 1% 税率
中期 1-3 年 再分配效应显现，失业人员再培训 -0.10% / 每 1% 税率
长期 3 年以上 劳动力转型完成，技术红利公平分配 +0.05% / 每 1% 税率

关于

项目介绍

中国经济仿真模型（China Economic Simulation Model, CESM）是一个面向公众教育的宏观经济政策仿真工具。本项目受 Salesforce 研究院"AI Economist"项目启发，旨在将前沿的经济仿真研究理念本土化，以纯 Web 形式实现中国宏观经济实时仿真。

技术实现

  • 前端框架：纯 HTML/CSS/JavaScript，无外部依赖（除 Chart.js）
  • 仿真引擎：基于凯恩斯 IS-LM-AD-AS 框架的自定义 JavaScript 类
  • 数据可视化：Chart.js 实现折线图、饼图、柱状图
  • 响应式设计：适配桌面、平板、手机多种设备
  • 计算优化：O(n) 时间复杂度，支持实时仿真
