def binary_search(arr, target):
    left, right = 0, len(arr) - 1

    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

数据结构 中等 2023 年 · 408 真题
给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值 target 的那两个整数，并返回它们的数组下标。你可以假设每种输入只会对应一个答案，且同一个元素在答案里不能重复出现。
🔖 加入错题本
↗ 分享
🤖 AI 分步解析 · 5 步
1
理解题意：在数组中找两个数，使它们之和等于 target，返回下标。
2
暴力解法：双重循环枚举所有数对，时间复杂度 O(n²)，可过但不够优。
3
优化思路：以空间换时间，用哈希表存储已访问的元素和下标。
4
具体步骤：遍历数组，对每个 num 检查 complement = target - num 是否在哈希表中。
5
复杂度分析：时间 O(n)，空间 O(n)。命中即返回，避免重复访问同一元素。

哈希表 (Hash Table)
数据结构 · 查找 难度 ★★★ 关联 23 个题目 · 4 个前置 · 2 个误区
概念解释
哈希表是根据关键码值（Key）直接进行访问的数据结构。它通过把关键码值映射到表中一个位置来访问记录，以加快查找速度。这个映射函数叫做散列函数，存放记录的数组叫做散列表。
前置知识点

def binary_search(arr, target):
    left, right = 0, len(arr)  # 🐛 边界错误

    while left < right:  # 🐛 应为 <=
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid  # 🐛 应为 mid - 1
    return -1

LuckyKang · 2 小时前 📌 置顶 ✓ 已解决
做历年真题时遇到 2021 年第 8 题，关于快速排序的最坏情况分析。教材说快排平均 O(nlogn) 最坏 O(n²)，但实际工程中好像很少遇到 O(n²)？是不是有什么优化（随机化、三数取中）能做到概率保证？麻烦大佬讲讲～
📚 数据结构 ⚡ 排序 ❓ 答疑 🔥 408

💬 23 条回复 · 按热度排序
王
王老师-数据结构 ✓ 教师认证 1 小时前
好问题！理论上快排在最坏情况（每次选的 pivot 都是最大/最小）会退化为 O(n²)。但实际工程里我们用随机化 pivot或三数取中，期望复杂度就是 O(nlogn)。408 考试只要答出"最坏 O(n²)，平均 O(nlogn)"即可拿满分。
