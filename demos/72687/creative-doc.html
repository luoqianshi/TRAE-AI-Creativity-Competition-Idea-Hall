01 / 创意介绍

让软件交易不再靠熟人介绍

企业采购软件时，往往依赖销售上门推销或熟人推荐，信息不透明、选择面窄、决策周期长。软件创作者则苦于没有好的渠道触达目标客户，好产品常被埋没。未世界要做的，是一个让双方高效相遇的交易平台。

01

想解决什么问题

企业找软件难、比价难、决策难；创作者卖软件难、获客难、展示难。两端信息严重不对称。

02

为什么会想到做这个

在服务中小企业的过程中，发现大量企业仍在用 Excel 管库存、用纸笔管流程，不是不想用软件，而是找不到、看不懂、不敢买。

03

大概是什么产品

一个 Web 端的软件交易平台。创作者上传作品，企业用户浏览、比价、评价、一键购买，全程在线完成。

02 / 目标用户与痛点

两端用户的真实困境

没有未世界之前

  • 企业想找 ERP，只能百度搜索或问同行，信息碎片化
  • 软件价格不透明，同一款软件不同销售报价差 30%
  • 无法看到真实用户评价，决策全凭销售一张嘴
  • 创作者依赖渠道商分销，利润被层层压缩
  • 好软件缺乏曝光渠道，小团队作品难以触达客户
  • 购买后找不到客服，售后体验差

有了未世界之后

  • 6 大分类导航，企业 3 秒找到目标软件品类
  • 明码标价 + 原价对比，价格完全透明
  • 真实用户评价 + 评分分布，决策有据可依
  • 创作者直接上架，直面客户，利润最大化
  • "最新上线""销量冠军"等推荐位，好作品自然浮现
  • 详情页内置客服表单，一键联系售后
03 / 核心功能

六个核心体验闭环

结构化软件展示

大图卡片展示截图、名称、核心功能、价格，让企业用户一眼看清软件全貌。

智能搜索与分类

搜索框 + 6 大分类导航（企业管理/设计创意/开发工具/数据分析/营销推广/安全运维），精准触达。

详情页深度信息

演示视频/多图轮播 + 功能列表 + 用户评价 + 一键购买 + 客服表单，决策所需信息一页俱全。

创作者中心

创作者可上传软件、管理作品、查看销售数据和评价，实现自助式经营。

热门推荐机制

"最新上线""销量冠军""用户好评"三大 Tab，帮助优质软件获得更多曝光。

购物车与购买

加入购物车到一键购买，购买流程极简，降低企业采购决策门槛。

04 / 页面设计

四个核心页面

01

首页

第一印象决定留存。首页用编辑杂志风的大图卡片 + 清晰分类，让用户秒懂平台价值。

  • 顶部：搜索框 + 分类导航 + 创作者中心入口
  • Hero 区：大图卡片展示精选软件（含截图、名称、核心功能、价格、立即购买）
  • 热门区："最新上线""销量冠军""用户好评"Tab 切换
  • 底部：创作者招募 CTA
02

商品详情页

采购决策的核心场景。左侧看产品，右侧做决策，底部看口碑。

  • 左侧：演示视频 / 多图轮播 + 缩略图切换
  • 右侧：名称、价格、功能列表、核心亮点标签、一键购买按钮
  • 右侧底部：联系客服折叠表单
  • 底部：评分分布 + 用户评价列表
03

创作者中心

让创作者自助经营，降低平台运营成本。

  • 顶部：4 个统计卡片（总销售额/作品数/总评价/平均评分）
  • 中部：软件上传表单（含分类、价格、功能、截图填写）
  • 底部：已发布作品管理表格
04

登录 / 注册

简洁的登录注册页，支持企业用户和创作者两种身份。

  • 登录 / 注册 Tab 切换
  • 登录：邮箱 + 密码 + 记住我
  • 注册：邮箱 + 密码 + 企业名称
