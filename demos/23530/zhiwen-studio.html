A

智能复制格式化助手

Chrome 浏览器扩展 · Manifest V3

安装到 Chrome 后，复制网页内容时自动清理格式、移除超链接、统一文本排版， 一键粘贴到公众号、CSDN、知乎等富文本编辑器直接使用。

  • 智能移除超链接，保留纯文本，不破坏阅读体验
  • 自定义 HTML 模板：图片/文本双模板，支持占位符
  • 图片格式自动转换：PNG / JPEG 可调质量，避免错链
  • 文本自动 首行缩进 2 字符 / 两端对齐
  • 兼容微信公众号、知乎、简书、CSDN、掘金、GitHub 等
  • XSS 防护 + 设置导入导出 + 实时预览
B

公文规范核查与合并工具

桌面端 Web 应用 · FastAPI + React + Vite

双击 wordcheck.exe 启动（无需 Python 环境），上传 Word 后自动按 公司模板 + GB/T 9704-2012 国标核查 30+ 项格式问题，可选 AI 语义核查， 并能把多源材料合并为统一格式的验收文档。

  • 7 大类核查：页面 / 页眉页脚 / 标题 / 正文 / 层次 / 表格 / 空白
  • AI 语义核查（可选）：错别字、语病、用语、数字格式
  • 支持合并 Word / Excel / 图片 / PDF，自动应用模板
  • PyInstaller 打包为单文件 exe，免 Python 环境
  • 集成 poppler 便携版，自动识别路径，离线可用
  • 核查结果带位置 / 上下文 / 修改建议，前端可预览全文
