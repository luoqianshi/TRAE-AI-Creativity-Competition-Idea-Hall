🏷️ 学习工作赛道 🧠 AI + 教育 🎬 PixiJS 动画引擎

💡创意介绍

📖

想解决什么问题

传统题库系统中，学生面对纯文字题目和静态解析往往难以理解抽象概念（如数学函数图像、物理力学分析、几何图形变换）。本创意通过AI 自动将题目内容转化为 PixiJS 交互动画，让学生直观"看"懂解题过程。

🎯

为什么会想到做这个

在教育系统开发实践中，我们发现传统的"文字解析"方式对抽象学科（数学、物理、化学）的题目效果有限。受 Khan Academy 和 3Blue1Brown 等优质教育内容启发，我们意识到视觉化动画是理解抽象概念的最佳方式。

🖥️

大概是什么产品

这是一个嵌入现有考试系统的 Web 功能模块 — 在题库管理后台引入 AI 动画生成能力，在学生考试结果页提供动画播放入口。基于 ASP.NET Core + SemanticKernel/MAF/MAF + PixiJS v8 构建。

// 默认动画模板：正弦函数图像 + 坐标系
function createAnimation(app, container) {
  const W = app.screen.width;
  const H = app.screen.height;
  const colors = {
    axis: 0x888888,
    curve: 0x5FB878,
    point: 0xff6347
  };

  // 绘制坐标系
  const axes = new PIXI.Graphics();
  axes.rect(0, 0, W, H);
  axes.fill({ color: 0x1a1a2e });
  app.stage.addChild(axes);

  // 动画状态机：绘制→追踪→重置
  let phase = 'drawing';
  let drawProgress = 0;
  let elapsed = 0;

  function animate(ticker) {
    if (phase === 'drawing') {
      drawProgress += ticker.deltaTime * 0.008;
      drawCurve();
    }
    else if (phase === 'tracing') {
      elapsed += ticker.deltaTime;
      updateDot();
    }
  }
  app.ticker.add(animate);

  return { play, pause, reset, setSpeed, destroy };
}

🔧技术方案亮点

🧠

SemanticKernel/MAF AI 驱动

通过 Microsoft.SemanticKernel/MAF 注入大模型能力（支持 DeepSeek / 混元 / Qwen），AI 自动分析题目语义并生成符合规范的 PixiJS 动画代码，包含严谨的 System Prompt 工程和代码清洗管道。

🎨

Monaco Editor + PixiJS 双引擎

管理后台集成 Monaco 代码编辑器（VS Code 同款内核）和 PixiJS v8 Canvas 渲染引擎，左侧编辑代码、右侧实时预览动画，支持播放/暂停/速度调节/全屏。

📋

可成长模板系统

设计 8 大预置模板方向，支持教师将优秀动画保存为可复用模板。AI 生成时自动匹配学科模板进行参数替换，模板库随使用持续成长。
