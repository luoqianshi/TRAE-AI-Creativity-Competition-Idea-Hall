03

四大核心能力

从"看见"到"记住"再到"回答"，构成一条完整的居家记忆闭环。

能力 01

随手拍 · 自动建档

// multimodal vision

调用本地多模态大模型，对一张照片做尽可能详尽的抽取；没有大模型时降级为"物品检测 + OCR + 正则"组合，保证可用。

  • 基础属性：名称、分类、品牌、规格
  • 时间属性：生产日期、保质期、有效期
  • 成分属性：配料表、营养成分（如有）
  • 位置属性：所在储物柜 / 第几层 / 房间
  • 环境上下文：周围还有什么、是否开封
能力 02

本地物品数据库

// local-first storage

所有识别结果结构化入库，沉淀成你的"居家记忆体"。数据完全留在本机，不上云、不外传，隐私自洽。

  • 结构化字段：可按分类/位置/时间检索
  • 原图留存：每条记录绑定原始照片
  • 增量更新：补拍即可修订属性
  • 过期预警：自动标记临期 / 已过期
  • 本地导出：JSON / 备份，随时带走
能力 03

开口问 · 大模型作答

// natural language retrieval

像问豆包一样直接语音提问，由大模型把自然语言翻译成对数据库的检索，再组织成人话回答——不背表单、不记字段名。

  • 位置类："电池放哪了""创可贴在哪个柜子"
  • 统计类："今年买了多少纸巾""还有几瓶水"
  • 提醒类："什么快过期了""药箱缺什么"
  • 成分类："这瓶酱油含不含谷氨酸钠"
  • 语音输入：解放双手，厨房里也能问
能力 04

A2A · 管家即 Agent

// agent-to-agent ecosystem

借助 A2A 协议把应用封装成一个私人管家 Agent，未来可便捷接入豆包、微信小微等 AI 助手，跨端调用、统一管理。

  • 标准化接口：查询 / 入库 / 提醒皆可远程调用
  • 多端入口：音箱、车机、手机助手都能问
  • 能力组合：与购物、日历、提醒类 Agent 联动
  • 数据主权：本地是唯一真相源，外部只读授权
  • 渐进生态：先单机可用，再开放互联

状态: 充足 / 临期监控中

开口即找回

下次需要时，一句话语音提问，大模型检索数据库并自然作答。

🎤 "纸巾还有几包？"
→ "客厅电视柜第 2 层
还有 8 包，够用约 2 个月。"
05

技术思路

本地优先，能用大模型就用大模型

识别层优先调用本地多模态大模型（如可部署的视觉理解模型），对单张照片做端到端的属性抽取；当本机算力或环境不具备时，自动降级为"轻量物品检测模型 + OCR + 正则提取"的组合管线，确保在任何机器上都跑得起来。

检索层把用户自然语言问题交给大模型，由它生成结构化查询落到本地数据库，再把结果组织成口语化回答。整套数据链路不出本机。

本地多模态 LLM 物品检测 OCR 自然语言检索 语音输入 Local Storage A2A 协议 纯网页 / PWA

↕
