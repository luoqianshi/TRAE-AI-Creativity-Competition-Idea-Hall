§01

Every cat you've passed
is a ghost.

城市里到处都是流浪猫、店猫、小区狗。但每一次遇见都只是擦肩而过——随手拍了就堆在相册里，再也翻不回来。

没有"我到底遇见过多少只"的成就感，没有"那只橙猫周二还在不在"的追踪，现有宠物 App 只关心你自家的宠物——没人服务"路过的别人的动物"这个长尾场景。

// 现状痛点

  • 相册堆满随手拍，无结构化整理
  • 找不回某只特定的猫
  • 没有"遇见过多少只"的成就来源
  • 流浪动物缺乏众包登记数据
  • 救助组织难以追踪城市动物

三步上链 / 3-STEP LOOP
STEP 01

Spot

路上看到猫 / 狗。打开 App，进入拍摄模式，地图提示附近被记录过的动物。

// 发现
STEP 02

Shoot

对准主体拍摄。取景框十字准星锁定——致敬 Pokemon GO 的捕获瞬间。

// 拍摄
STEP 03

Collect

AI 自动抠图，主体从背景分离，落进你的图鉴：时间 / 地点 / 品种 / 稀有度。

§05

Value & Meaning

COMMERCIAL

商业
价值

  • 图鉴皮肤 / 涂鸦贴纸 / Riso 滤镜付费包
  • 宠物用品品牌 × 流浪动物救助机构联名企划
  • 接入「附近遇到的猫狗」流量，做本地生活导流（宠物店 / 猫咖 / 宠物友好餐厅）
  • 城市动物 IP 化：每只明星街猫可衍生周边
SOCIAL

社会
价值

  • 把随手拍从一次性消费变成可积累的数字资产
  • 每只流浪动物带「绝育 / 寻家」标签，形成城市众包地图
  • 为救助组织提供数据底座，追踪个体动态
  • 让街拍顺便做件好事——游戏化公益
