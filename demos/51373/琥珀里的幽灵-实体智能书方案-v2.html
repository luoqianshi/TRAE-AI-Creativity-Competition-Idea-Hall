温变琥珀封面

对应段落：封面 & "琥珀在浑浊空气中泛着油光"

封面上使用大面积31°C温敏微胶囊油墨印刷琥珀图案。常温下呈深琥珀色不透明；手指触摸3-5秒后，体温使油墨变为半透明，内部隐藏的「幽灵」轮廓（母亲侧影或分子结构）逐渐浮现。离开后约10秒恢复原状，可循环触发。

体温是输入信号，变色是输出响应——物理版 onClick → style change。

透明叠层 · 物理版 z-index

对应段落：地下市集场景切换、神经接口数据叠加、艾娃全息投影

物理逻辑 · 拉杆触发爆炸

对应段落：林渊砸碎薄荷醛试管

书页侧面嵌入纸板滑轨拉杆。读者向右拉动拉杆，当越过特定位置（触发阈值）时，内部弹簧机构弹出「试管破碎」的立体画面，同时拉杆表面涂有薄荷微胶囊——摩擦即破裂释放薄荷香。

这是物理版 if (position > threshold) { trigger(); }。拉杆滑动的阻尼感模拟了「玻璃碎裂前的张力」，越过阈值的瞬间弹出+气味释放，制造完整的感官冲击。

渐进智能 · 刮开涂层记忆

对应段落：林渊切开琥珀吸入原始气味，唤回被删除的母亲记忆

银色刮开涂层（类似彩票涂层）覆盖在母亲形象插画上。孩子用指甲或附赠木棒刮开后，被「神盾科技」封锁的画面逐渐显现——关键是这个操作不可逆，刮开后无法复原。

这就是物理的「状态已更改」。整本书有 7 块记忆碎片，全解锁后拼成完整故事，等价于 useState 持久化。刮开的动作本身，就是读者与「神盾科技审查系统」的对抗。

物理逻辑 · 双开门分支叙事

对应段落：林渊面临选择——"通风管道"vs"正面冲突"

对开页面设计，左右各一扇纸板门。先翻开哪一扇，后续情节即按该线展开。两扇门后的内容完全不同：左门通向通风管道逃亡线（解锁隐藏章节），右门通向正面冲突线（触发追捕剧情）。

中间压线设计了「破拆痕」——一旦选择就很难回头（增加戏剧张力）。翻页方向就是物理版的 event.target.id 选择器，也是 if-else 的实体化。读者可以回头再试另一条线，体验不同结局。

物理逻辑 · 打孔卡带编程

对应段落：艾娃分析"原罪"气味分子——只有特定组合才能解锁完整记忆

附赠的打孔卡带，孩子用木棒戳穿孔位形成「气味配方」，插入书脊的读取槽位，书本通过机械结构联动，呈现对应场景。5种气味（森林、棉被、汗水、肥皂、奶味）× 4种浓度 = 20种组合，但只有特定配方才能解锁「母亲记忆」。

等价于 API 的 query params。读者需要在前面的页面中收集线索（温变页浮现的文字提示配方比例），才能打出正确的孔。错误配方会触发「防火墙失效」的错误页面。

READING GUIDE

阅读流程指南

这不是线性阅读。读者需要按照特定顺序操作，才能解锁完整叙事。错误的顺序会导致「数据丢失」。

STEP 01 / 准备
打开书盒，清点工具
书盒内除书籍外，还包含：UV-LED笔×1、光栅动画片×1、红色滤镜片×1、打孔木棒×1、密码线索卡×1。
⚠ 注意：UV笔内含微型纽扣电池（CR2032），仅供照明用途，不属于「电子产品」范畴
STEP 02 / 封面觉醒
触摸琥珀，唤醒幽灵
将手掌放在封面琥珀图案上3-5秒。体温使温敏油墨变透明，内部隐藏的「幽灵」轮廓浮现。这是你的第一次「感官接入」。
🌡️ 冬季体温较低时，可双手交替覆盖以维持温度
STEP 03 / 拉杆引爆
拉动拉杆，释放薄荷醛
翻到第45页，找到侧边滑轨。向右拉动拉杆越过红线阈值——「砰！」立体画面弹出，同时薄荷香气从拉杆表面释放。
💥 这是你的第一件「武器」，也是第一次触发物理条件判断
STEP 04 / 刮开记忆
刮开涂层，对抗审查
找到标有「神盾科技·记忆封锁」的页面，用指甲或木棒刮开银色涂层。母亲的形象逐渐显现——一旦刮开，永不复原。
🧠 全书共有7块记忆碎片，散落在不同章节
STEP 05 / 跨页扫描
透过窗口，发现档案
翻到第3页（艾娃扫描），透过琥珀形状的镂空窗口，你能直接看到第7页的内容——那是被框住的「原罪档案」。
👁️ 视线就是鼠标，窗口就是超链接
STEP 06 / 配方编程
打孔卡带，输入配方
根据前面页面中收集的线索（温变页浮现的文字提示配方比例），在附赠卡带上用木棒戳出正确的孔位组合。插入书脊读取槽，机械结构联动呈现对应场景。
⚗️ 正确配方解锁母亲记忆；错误配方触发「防火墙失效」
STEP 07 / 分支选择
双开门，决定命运
在逃亡章节，你面前有两扇纸板门。先开左门→通风管逃亡线（解锁隐藏章节）；先开右门→正面冲突线（触发追捕剧情）。可回头再试另一条线。
🔀 这是物理版 if-else，你的选择决定叙事走向
