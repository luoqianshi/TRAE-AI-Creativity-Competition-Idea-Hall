📚 小说世界

让你走进小说里 —— AI 驱动的 3D 小说场景生成平台

"文字描述 → AI 解析 → 3D 世界"

🎯 使用流程

1

上传小说

输入小说名称和内容，或直接上传 .txt 文件。支持任意中文/英文小说文本。

2

AI 解析

AI 自动提取场景中的地点、物体、建筑风格、光照氛围等关键信息。

3

生成 3D 世界

基于解析结果，自动生成可交互的 3D 场景，支持自由浏览。

4

探索分享

在 3D 世界中漫步，保存项目到画廊，生成分享链接给朋友。

✨ 核心功能

🤖

AI 智能解析

支持 OpenAI、Claude 及自定义 AI 端点，自动提取小说中的地点、物体、氛围等信息，生成结构化的世界蓝图。

🎮

3A 级 3D 渲染

基于 Three.js 构建，包含 PBR 材质、Bloom 泛光、粒子氛围、高级光照等效果，打造沉浸式视觉体验。

🎨

多材质系统

支持金属、玻璃、发光、石材、木材等多种材质，根据物体类型自动匹配最合适的视觉效果。

🌟

氛围粒子系统

根据场景情绪（神秘、浪漫、紧张等）动态生成粒子效果，增强场景感染力。

📱

演示模式

无需 API Key 即可体验完整功能，内置演示数据，让用户零门槛感受产品魅力。

💾

配置持久化

自动保存用户的 API 配置到本地，刷新页面无需重复输入，支持一键清除。
