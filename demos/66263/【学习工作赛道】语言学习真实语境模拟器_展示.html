// Problem

学了这么多年，为什么还是开不了口？

传统语言学习和真实语言运用之间，隔着一道看不见的鸿沟。

📖

课本对话 ≠ 真实对话

课本教 "How are you? I'm fine, thank you." 但真实对话远不止如此——没人真的这么说话。

🧠

认识单词 ≠ 会用单词

背了 3000 个单词，到了餐厅却想不起"菜单"怎么说。因为没有在场景中用过，大脑提取不出。

💰

找外教成本高

一对一外教 200-400 元/小时，时间不灵活，而且大部分时间其实在听老师说，自己开口机会有限。

😰

开口焦虑

怕说错、怕发音不标准、怕被笑话——在没有安全环境的条件下，很难迈出开口的第一步。

// Core Features

核心能力

🎭

AI 角色扮演

AI 扮演咖啡师、面试官、医生等角色，根据场景调整语气、语速和专业术语，营造真实对话感。

🔀

动态对话分支

对话不是固定脚本——AI 根据用户的回答动态推进，不同选择走向不同对话分支，每次练习都不同。

📊

三维实时反馈

对话结束后从"用词准确度""语法正确性""文化得体性"三个维度给出评分和改进建议。

📈

自适应难度

根据用户表现自动调节对话难度——初学者从简单句式开始，进阶者面对更复杂的对话情境。

🌍

文化知识嵌入

对话中穿插文化提示——如"在法国午餐要先跟服务员说 Bonjour"，避免文化冒犯。

📝

语境词汇本

自动收集对话中遇到的生词和表达，按场景分类，附带原句上下文，告别脱离语境的单词表。

// Architecture

技术原理

四层架构，从场景构建到智能反馈的完整链路。

01

场景引擎层

基于真实语料库构建场景模板，包含角色设定、对话目标、关键节点和分支逻辑。每个场景经过母语者审核，确保对话自然度和文化准确性。

场景模板分支逻辑母语者审核
02

对话 AI 层

基于大语言模型微调的对话引擎，支持角色扮演、动态推进和难度自适应。结合 TTS/ASR 实现语音对话，模拟真实口语交流体验。

LLM微调角色扮演TTS/ASR
03

评估反馈层

对话结束后，NLP 模型从用词、语法、得体性三维度分析用户表达，对比母语者常用表达给出改进建议，并标注"更地道的说法"。

三维评估地道表达对比改进建议
04

学习追踪层

记录用户在每个场景的表现、常用错误模式和高频词汇盲区，生成个人语言能力图谱，智能推荐下一步练习场景。
