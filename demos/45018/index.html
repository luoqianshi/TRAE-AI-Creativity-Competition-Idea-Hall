Starlens 是什么

Starlens 是一个将 GitHub Stars 转化为个人知识库的工作台。它不只是帮你同步和整理 Stars，更将这些仓库变为 AI Agent 可直接调用的编程上下文，让你的每一次 Star 都在未来持续产生价值。

  • 本地优先，数据自主

    所有 Stars 数据同步到本地 SQLite，你完全拥有自己的知识库

  • AI 增强，而非替代

    自动生成仓库摘要，你可以补充自己的标签和备注

  • Agent 原生接入

    通过 MCP 协议，AI 编程助手可直接查询你的知识库

核心功能

从同步到搜索，从整理到调用，Starlens 覆盖 Stars 知识管理的完整链路。

本地同步

一键将你的 GitHub Stars 同步到本地 SQLite 数据库，增量更新，离线可用。支持按语言、主题、星数等多维度过滤。

AI 智能摘要

自动读取 README 和元数据，用 LLM 生成轻量摘要，一句话说清这个仓库能做什么。

标签与备注
