创意背景与市场痛点

中国计算机类专业在校生规模超过80万人，每年参与课程设计、综合实训与毕业设计的学生人次以百万计。实训是连接理论教学与工程实践的核心枢纽，但当前环节存在系统性短板——学生在选题、开发、交付、考核的完整链路中，缺少系统化的智能辅助工具。以下是五大核心痛点：

选题失配：不知"做什么、做多深"

学生面对课程设计、综合实训、毕设三类不同深度的实训任务，无法准确判断选题边界与难度梯度，频繁出现"大题小做"或"小题大做"。

规划缺失：项目启动靠手动拼凑

项目架构设计、数据库表结构、团队分工、周排期全靠手动从零整理，一份完整方案往往需要3-5天，质量参差不齐。

文档不规范：格式反复修改浪费精力

实训报告、答辩PPT等交付物缺少标准化高校模板，参考文献不遵循GB/T 7714标准，大量时间耗费在格式调整上。

报错修复泛化：通用AI"懂很多，解不准"

Java Spring Boot、鸿蒙ETS、Vue/React等框架报错具有高度特异性，通用AI的修复建议往往停留在表面，缺少完整可替换代码模块。

第五大痛点隐藏在实训收尾阶段——缺少配套自测编程题库，学生无法复盘考核知识点，教师也缺乏标准化评估依据。五个痛点串联成"选题-规划-开发-交付-考核"完整链路，每个环节的薄弱都会向后传导。

五大核心功能

Feature 01

实训智能选题与全套项目方案生成

输入课程名称、实训类型、技术栈偏好与难度期望，自动生成3-5个适配选题及项目概述。选定后一键输出完整项目方案：技术架构图、数据库ER设计与建表SQL、模块拆解、团队分工建议、4-8周开发排期甘特图，每步输出均附带高校实训规范格式说明。

Feature 02

标准化全套实训交付文档一键生成

基于项目方案自动生成：实训开题报告、实训周记模板（按周填充框架）、结题报告全文框架、答辩PPT大纲页、参考文献列表（严格遵循GB/T 7714-2015标准）。所有模板对标高校计算机专业通用实训文件规范，填充具体技术内容即可直接提交。

Feature 03

代码报错专属解析与完整可替换修复代码

粘贴报错日志或异常堆栈，系统自动识别技术栈（Java Spring Boot / 鸿蒙ETS / Vue / React / MySQL等），给出框架专属的根因分析，并提供完整可替换的修复代码模块。每个方案标注适用版本、前置依赖与潜在副作用，精准定位并解决问题。

Feature 04

实训知识点自测题库自动生成

根据实训项目涉及的技术栈与知识点，自动生成配套题库，题型覆盖单选题、多选题、简答题与编程实践题，每题附带标准答案与解析。按知识模块分类，支持自定义题量与难度分布，作为实训后复盘工具或教师出题参考。

Feature 05

答辩创新点提炼与路演演示脚本生成

基于项目完整方案与开发记录，自动提炼3-5个差异化创新点（技术选型创新、架构设计亮点、业务场景创新等），生成结构化答辩陈述稿与配套路演演示脚本。按"开场引入-技术展示-创新点阐述-总结展望"四段式组织，标注每页PPT对应的口头讲解要点与预估时长。
