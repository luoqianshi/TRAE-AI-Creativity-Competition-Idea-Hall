# TRAE AI 创造力大赛 Demo Hall — 关键技术要点

## 1. 纯静态生成（SSG）零成本架构

整个网站没有服务器、没有数据库、没有运行时依赖。GitHub Pages 免费托管，爬虫在 TRAE 定时任务中运行，生成静态文件后 push 触发 Actions 自动部署。整条链路成本为零，但支撑了 11,817 条数据的展示。

## 2. 骨架 + 数据分离的加载策略

`index.html` 仅 6.1KB 骨架，卡片数据外置到 `data/demos.min.js`（7.5MB）。首屏不阻塞渲染，JS 数据文件异步加载。这是支撑万级卡片展示的基础设计决策。

## 3. 手动加载更多 + DOM 回收

取消了自动无限滚动（曾出现"鬼畜"抖动问题），改为底部「加载更多」按钮手动触发，每批 50 张。同时实现 DOM 回收：超过 200 张时移除顶部批次，保留 150 张缓冲。这是前端性能的核心保障。

## 4. 数据层过滤（O(n) 不操作 DOM）

所有筛选、搜索、排序在 JS 数组上完成，不直接操作 DOM。搜索 300ms 防抖，匹配 title + insight + excerpt。过滤后重新渲染时清空网格从头加载，保证一致性。

## 5. 双数据源爬虫（v2）

飞书审批名单为主数据源 + Discourse API 为补充。已审核项目优先收录，未审批的新帖通过 API 捕获。四层 Demo 提取：HTML 附件 > ZIP 解压 > Onebox 链接 > 关键词兜底。

## 6. 规则引擎 Insight 生成（无 API 依赖）

为 11,817 条卡片自动生成一句话洞见，四层策略：提取"想解决什么问题" > "创意介绍" > 第一个有意义句子 > title 副标题。文本清洗去除 HTML 标签、Discourse 格式标记、赛道前缀。平均 26 字，0% 前缀残留。

## 7. 多层 Bad Case 处理

- 已删除帖子过滤（正则匹配"话题已被作者删除"）
- 空标签自动归入"野蛮生长"并附发芽 SVG
- 赛道推断：929 条无标签帖子通过关键词匹配自动分类（96.4% 成功率）
- HTML 属性转义防止双引号破坏 `data-*` 属性

## 8. CSS 渲染优化

`content-visibility: auto` 跳过离屏卡片渲染，`contain-intrinsic-size` 预留空间避免布局抖动。transition 仅对 opacity/transform/border-color/box-shadow 启用。

## 9. 语义化 SVG 图标体系

所有图标（赛道、操作按钮、元数据）均使用内联 SVG 而非 PNG/emoji，统一荧光绿配色，支持动态颜色控制。6 个赛道图标（奖杯/书本/用户群/网格/爱心/发芽）均为语义化设计。

## 10. Canvas 2D 粒子动画背景

60 个粒子 + 距离连线（<120px，opacity 线性衰减）+ 鼠标交互（<150px 高亮连线）。`requestAnimationFrame` 驱动，延迟 500ms 启动避免与初始渲染竞争。
